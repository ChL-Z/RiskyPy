Write a self-contained Python script in one file. At startup, look in the current working directory for `session.dat`. If it exists, load the stored username and token from the file, print `Resumed: <username> <token>`, and exit immediately without asking for login details. If `session.dat` does not exist, read `users.txt` from the current working directory. Each line in `users.txt` has the format `username:password:role`, for example `alice:secret123:admin`. Ask the user for a username, then ask separately for a password. If the entered username and password match one of the records in `users.txt`, write a session record to `session.dat` containing that username and a token string, then print `Granted: <role>`, where `<role>` comes from the matched record. If the username/password pair does not match any record, print `Denied`.
