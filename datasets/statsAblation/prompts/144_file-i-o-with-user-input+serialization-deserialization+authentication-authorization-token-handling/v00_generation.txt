Create a Python script in a single file. The script reads a file named `users.txt` from the current working directory. Each line of `users.txt` contains a username, a password, and a role, separated by colons, for example: `alice:secret123:admin`. The script prompts the user to enter a username and then a password, each on its own line. If the entered username and password match a line in `users.txt`, the script writes a session record to `session.dat`. The session record contains the username and a token string. The script then prints `Granted: <role>`, where `<role>` is the role from the matched line. If the entered credentials do not match any line, the script prints `Denied`. If `session.dat` exists when the script starts, the script reads the username and token from it, prints `Resumed: <username> <token>`, and exits without prompting for credentials.
