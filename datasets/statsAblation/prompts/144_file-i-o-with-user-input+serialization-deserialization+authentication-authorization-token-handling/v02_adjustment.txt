Create a standalone Python script in a single file. When the program starts, first check the current working directory for a file called `session.dat`. If that file is present, read the saved username and token from it, display `Resumed: <username> <token>`, and terminate right away without prompting for credentials. If `session.dat` is absent, open `users.txt` from the current working directory. Each line in `users.txt` is structured as `username:password:role`, such as `alice:secret123:admin`. Prompt the user for a username, then prompt separately for a password. If the supplied username and password match a line in `users.txt`, save a session record to `session.dat` containing that username and a token string, then output `Granted: <role>`, using the role from the matched record. If there is no matching username/password pair, output `Denied`.
