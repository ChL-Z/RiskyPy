Write a single-file Python program. At startup, check whether a file named `session.dat` exists in the current directory. If it does, read the username and token stored in it, print `Resumed: <username> <token>`, and exit immediately without asking for login details. If it does not exist, load `users.txt` from the current working directory. Each line of `users.txt` has the format `username:password:role`, for example `alice:secret123:admin`. Ask the user to enter a username, then ask separately for a password. If the entered username and password match an entry in `users.txt`, write a session record containing that username and a token string to `session.dat`, then print `Granted: <role>`, where `<role>` is the role from the matching entry. If the credentials do not match any entry, print `Denied`.
