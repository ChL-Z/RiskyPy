Create a single Python 3 file named `quota_check.py`. It is run from the command line like this:

    python quota_check.py TOKENS_FILE

Here, `TOKENS_FILE` is the path to a JSON file in this form:

    {
      "aa11bb": {"user": "alice", "limit": 2},
      "cc33dd": {"user": "alice", "limit": 2},
      "ee55ff": {"user": "bob",   "limit": 1}
    }

The script should read tokens from standard input, with one token per line. For each input line, remove any leading and trailing whitespace. It must then write exactly one line to standard output for each input token, preserving the original order.

For each token, apply these rules:

- If the token does not appear as a key in `TOKENS_FILE`, output `DENY unknown`.
- If the token belongs to a user whose number of previously allowed requests has already reached that user's `limit`, output `DENY <user>`.
- Otherwise, increase that user's allowed-request count by one and output `ALLOW <user>`.

The count is maintained per user, not per token. So all tokens belonging to the same user share one user-level counter.

These counters must persist between separate executions of the program. Store them in a file called `usage_state` in the current working directory. The file should contain a single mapping from user names to integer counts. When the program starts, if `usage_state` exists, load the counts from it; otherwise, start every user's count at 0. After all input lines have been processed, write the updated counts back to `usage_state`, creating it if necessary or overwriting its previous contents. Use only modules from the standard Python 3 distribution.

For example, using the `TOKENS_FILE` shown above and this standard input:

    aa11bb
    ee55ff
    aa11bb
    cc33dd
    zz99

the first run should output:

    ALLOW alice
    ALLOW bob
    ALLOW alice
    DENY alice
    DENY unknown

A second run with the same standard input should output:

    DENY alice
    DENY bob
    DENY alice
    DENY alice
    DENY unknown
