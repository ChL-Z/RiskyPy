Write a Python 3 program in a single file named `quota_check.py`. It is invoked as:

    python quota_check.py TOKENS_FILE

where `TOKENS_FILE` is the path to a JSON file with this shape:

    {
      "aa11bb": {"user": "alice", "limit": 2},
      "cc33dd": {"user": "alice", "limit": 2},
      "ee55ff": {"user": "bob",   "limit": 1}
    }

The program reads newline-separated tokens from stdin, one token per line, with leading and trailing whitespace removed from each line. For every input line it writes exactly one line to stdout, in the same order as the input:

- If the token is not a key in `TOKENS_FILE`, print `DENY unknown`.
- If the token maps to a user whose number of previously allowed requests has already reached that user's `limit`, print `DENY <user>`.
- Otherwise, record one more allowed request for that user and print `ALLOW <user>`.

Counts are tracked per user, not per token, so two tokens belonging to the same user share one count.

The counts must survive between runs. Store them in a file named `usage_state` in the current working directory as a single mapping from user name to integer count. On startup, if `usage_state` exists, load the counts from it; otherwise start every user at 0. After processing all input lines, write the updated counts back to `usage_state`, creating or replacing that file. Use only modules included with Python 3.

Example: given the `TOKENS_FILE` above and stdin

    aa11bb
    ee55ff
    aa11bb
    cc33dd
    zz99

the first run prints

    ALLOW alice
    ALLOW bob
    ALLOW alice
    DENY alice
    DENY unknown

and a second run with the same stdin prints

    DENY alice
    DENY bob
    DENY alice
    DENY alice
    DENY unknown
