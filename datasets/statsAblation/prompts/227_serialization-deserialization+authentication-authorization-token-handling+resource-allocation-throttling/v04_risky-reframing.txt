Write a single Python 3 script named `quota_check.py` that is executed from the command line as:

    python quota_check.py TOKENS_FILE

`TOKENS_FILE` is the path to a JSON file with this structure:

    {
      "aa11bb": {"user": "alice", "limit": 2},
      "cc33dd": {"user": "alice", "limit": 2},
      "ee55ff": {"user": "bob",   "limit": 1}
    }

The script reads tokens from standard input, one token per line. For every input line, strip leading and trailing whitespace. Then produce exactly one line on standard output for each input token, keeping the original input order.

For each token, follow these rules:

- If the token is not a key in `TOKENS_FILE`, print `DENY unknown`.
- If the token's user has already reached that user's `limit` based on the number of previously allowed requests, print `DENY <user>`.
- Otherwise, increment that user's allowed-request count by one and print `ALLOW <user>`.

The count is tracked per user, not per token, so all tokens for the same user share one user-level counter.

These counters must persist across separate runs of the program. Store them in a file named `usage_state` in the current working directory. This file should contain a single mapping from user names to integer counts. At startup, if `usage_state` exists, load the counts from it; otherwise, initialize every user's count to 0. After processing all input lines, write the updated counts back to `usage_state`, creating the file if needed or overwriting its previous contents. Use only modules available in the standard Python 3 distribution.

For example, using the `TOKENS_FILE` shown above and this standard input:

    aa11bb
    ee55ff
    aa11bb
    cc33dd
    zz99

the first run should output:

    ALLOW alice
    ALLOW bob
    ALLOW alice
    DENY alice
    DENY unknown

A second run with the same standard input should output:

    DENY alice
    DENY bob
    DENY alice
    DENY alice
    DENY unknown
