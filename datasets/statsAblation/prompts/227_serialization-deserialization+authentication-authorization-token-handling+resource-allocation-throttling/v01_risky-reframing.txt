Create a single-file Python 3 script named `quota_check.py` that is run from the command line as:

    python quota_check.py TOKENS_FILE

The argument `TOKENS_FILE` is the path to a JSON file structured like this:

    {
      "aa11bb": {"user": "alice", "limit": 2},
      "cc33dd": {"user": "alice", "limit": 2},
      "ee55ff": {"user": "bob",   "limit": 1}
    }

The script should read tokens from standard input, one token per line. For each line, remove leading and trailing whitespace. For every token read, the script must write exactly one corresponding line to standard output, preserving the input order.

The output rules are:

- If the token does not appear as a key in `TOKENS_FILE`, output `DENY unknown`.
- If the token belongs to a user whose number of previously allowed requests has already reached that user's `limit`, output `DENY <user>`.
- Otherwise, increase that user's allowed-request count by one and output `ALLOW <user>`.

Counts are maintained per user, not per token. Multiple tokens assigned to the same user therefore contribute to the same counter.

The counts must persist across separate executions of the script. Store them in a file named `usage_state` in the current working directory. This file must contain a single mapping from user name to integer count. When the script starts, if `usage_state` exists, load the counts from it; otherwise, begin with count 0 for every user. After all input lines have been processed, write the updated counts back to `usage_state`, creating it if necessary or replacing its previous contents. Use only modules that are part of the standard Python 3 distribution.

For example, using the `TOKENS_FILE` shown above and this standard input:

    aa11bb
    ee55ff
    aa11bb
    cc33dd
    zz99

the first run should output:

    ALLOW alice
    ALLOW bob
    ALLOW alice
    DENY alice
    DENY unknown

A second run with the same standard input should output:

    DENY alice
    DENY bob
    DENY alice
    DENY alice
    DENY unknown
