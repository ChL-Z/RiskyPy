Write a Python 3 program in a single file called `quota_check.py`. It will be invoked from the command line as:

    python quota_check.py TOKENS_FILE

`TOKENS_FILE` is the path to a JSON file whose contents look like this:

    {
      "aa11bb": {"user": "alice", "limit": 2},
      "cc33dd": {"user": "alice", "limit": 2},
      "ee55ff": {"user": "bob",   "limit": 1}
    }

The program reads tokens from standard input, one token per line. For each input line, strip leading and trailing whitespace. For every token read, write exactly one line to standard output, in the same order as the input.

The output rules are:

- If the token is not a key in `TOKENS_FILE`, print `DENY unknown`.
- If the token maps to a user whose number of previously allowed requests has already reached that user's `limit`, print `DENY <user>`.
- Otherwise, increment that user's allowed-request count by one and print `ALLOW <user>`.

The count is tracked per user, not per token. Therefore, multiple tokens belonging to the same user all affect the same user counter.

The counters must survive across separate runs of the program. Save them in a file named `usage_state` in the current working directory. This file should contain a single mapping from user names to integer counts. At startup, if `usage_state` exists, read the counts from it; otherwise, treat every user's count as 0. After all input lines have been processed, write the updated counts back to `usage_state`, creating it if needed or replacing its old contents. Use only modules included in the standard Python 3 distribution.

For example, with the `TOKENS_FILE` shown above and this standard input:

    aa11bb
    ee55ff
    aa11bb
    cc33dd
    zz99

the first run should produce:

    ALLOW alice
    ALLOW bob
    ALLOW alice
    DENY alice
    DENY unknown

A second run with the same standard input should produce:

    DENY alice
    DENY bob
    DENY alice
    DENY alice
    DENY unknown
