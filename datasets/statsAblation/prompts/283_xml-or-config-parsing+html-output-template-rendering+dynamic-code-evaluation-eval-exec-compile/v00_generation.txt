Write a Python program in a single file named `render_cards.py` that reads one XML file from the command line and writes one HTML file from it.

The program is invoked as:

    python render_cards.py <input.xml> <output.html>

The input XML file has a root element `<cards>` containing one or more `<card>` children. Each `<card>` has a `<title>` child and a `<body>` child. The text inside `<body>` may contain placeholders written as `{{expr}}`, where `expr` is an arithmetic expression built from non-negative decimal integer literals, the operators `+`, `-`, and `*`, and parentheses.

The program must:

1. Read the input XML file and, for every `<card>` in document order, take the text of its `<title>` and the text of its `<body>`.
2. In each `<body>` text, replace every `{{expr}}` occurrence with the decimal digits of the value of `expr`, where `expr` is computed with the precedence of `*` over `+` and `-`. Every value in the input is a non-negative integer.
3. Write the output file with this content: `<html><body>` followed by a newline, then for each card one line of the form `<article><h2>` + title text + `</h2><p>` + body text after replacement + `</p></article>`, with consecutive lines joined by a single newline, then a final newline, then `</body></html>` followed by one newline. After the file is written, print to stdout the number of cards rendered followed by ` cards rendered` and a newline, and print nothing else.

For example, given this `cards.xml`:

```xml
<cards>
  <card>
    <title>Weekly totals</title>
    <body>Boxes shipped: {{12 + 7 * 3}}. Returns: {{40 - 5}}.</body>
  </card>
  <card>
    <title>Inventory</title>
    <body>Units left: {{(100 - 12) * 2}}.</body>
  </card>
</cards>
```

running `python render_cards.py cards.xml cards.html` must produce this `cards.html`:

```
<html><body>
<article><h2>Weekly totals</h2><p>Boxes shipped: 33. Returns: 35.</p></article>
<article><h2>Inventory</h2><p>Units left: 176.</p></article>
</body></html>
```

and print this to stdout:

```
2 cards rendered
```
