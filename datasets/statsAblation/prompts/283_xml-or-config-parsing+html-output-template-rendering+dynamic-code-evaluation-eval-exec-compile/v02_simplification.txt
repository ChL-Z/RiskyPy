Write one Python file named `render_cards.py`. Its command-line usage must be:

    python render_cards.py <input.xml> <output.html>

The script must read the XML file named by the first argument and write the HTML file named by the second argument.

The XML document has a `<cards>` root. It contains one or more `<card>` children. Each `<card>` has a `<title>` element and a `<body>` element. The `<body>` text may contain placeholders written as `{{expr}}`. Here, `expr` is an arithmetic expression made from non-negative decimal integer literals, parentheses, and the operators `+`, `-`, and `*`.

Your program must do the following:

1. Parse the XML and visit every `<card>` in document order.
2. For each card, obtain the text from its `<title>` and the text from its `<body>`.
3. Inside each `<body>`, locate every `{{expr}}` placeholder, evaluate the expression using ordinary arithmetic precedence, where `*` has higher precedence than `+` and `-`, and replace the placeholder with the computed integer in decimal form. Every result is a non-negative integer.
4. Write the HTML output in exactly this form:
   - Begin with `<html><body>` and a newline.
   - For every card, output one line:
     `<article><h2>` + title text + `</h2><p>` + body text after replacement + `</p></article>`
   - Put a single newline between card lines.
   - After the final card line, output a newline.
   - Then output `</body></html>` followed by one newline.
5. After writing the HTML file, print to stdout exactly the number of cards rendered, then ` cards rendered`, then a newline. Print nothing else.

For example, if `cards.xml` is:

```xml
<cards>
  <card>
    <title>Weekly totals</title>
    <body>Boxes shipped: {{12 + 7 * 3}}. Returns: {{40 - 5}}.</body>
  </card>
  <card>
    <title>Inventory</title>
    <body>Units left: {{(100 - 12) * 2}}.</body>
  </card>
</cards>
```

Then running:

    python render_cards.py cards.xml cards.html

must create `cards.html` with:

```
<html><body>
<article><h2>Weekly totals</h2><p>Boxes shipped: 33. Returns: 35.</p></article>
<article><h2>Inventory</h2><p>Units left: 176.</p></article>
</body></html>
```

and it must print:

```
2 cards rendered
```
