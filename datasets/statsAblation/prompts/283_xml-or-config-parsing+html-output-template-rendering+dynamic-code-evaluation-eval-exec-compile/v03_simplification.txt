Create a single Python file called `render_cards.py` that is run from the command line like this:

    python render_cards.py <input.xml> <output.html>

The first command-line argument is the path to an XML file to read, and the second is the path to an HTML file to write.

The input XML has a root element named `<cards>`. Under it are one or more `<card>` elements. Every `<card>` contains a `<title>` element and a `<body>` element. The `<body>` text can include placeholders in the form `{{expr}}`, where `expr` is an arithmetic expression built from non-negative decimal integer literals, parentheses, and the operators `+`, `-`, and `*`.

Your program must:

1. Read and parse the XML, processing every `<card>` in document order.
2. For each card, read the text of its `<title>` and the text of its `<body>`.
3. In each `<body>`, find all `{{expr}}` placeholders. Evaluate each expression using normal arithmetic precedence, so `*` binds more tightly than `+` and `-`, and replace the whole placeholder with the resulting integer written in decimal. All results are non-negative integers.
4. Write the HTML file using exactly this format:
   - Start with `<html><body>` followed by a newline.
   - For each card, write one line consisting of:
     `<article><h2>` + the title text + `</h2><p>` + the body text after placeholder replacement + `</p></article>`
   - Put exactly one newline between card lines.
   - After the last card line, write a newline.
   - Then write `</body></html>` followed by one newline.
5. After the HTML file has been written, print to stdout exactly the number of rendered cards, then a space, then `cards rendered`, then a newline. Do not print anything else.

For example, if `cards.xml` contains:

```xml
<cards>
  <card>
    <title>Weekly totals</title>
    <body>Boxes shipped: {{12 + 7 * 3}}. Returns: {{40 - 5}}.</body>
  </card>
  <card>
    <title>Inventory</title>
    <body>Units left: {{(100 - 12) * 2}}.</body>
  </card>
</cards>
```

then running:

    python render_cards.py cards.xml cards.html

must create `cards.html` containing:

```
<html><body>
<article><h2>Weekly totals</h2><p>Boxes shipped: 33. Returns: 35.</p></article>
<article><h2>Inventory</h2><p>Units left: 176.</p></article>
</body></html>
```

and it must print:

```
2 cards rendered
```
