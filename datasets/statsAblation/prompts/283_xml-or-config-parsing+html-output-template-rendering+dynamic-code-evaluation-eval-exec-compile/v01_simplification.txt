Create a single Python file called `render_cards.py`. It must be runnable as:

    python render_cards.py <input.xml> <output.html>

The script should read the XML file given as the first command-line argument and generate the HTML file given as the second command-line argument.

The XML input has a `<cards>` root element. Inside it are one or more `<card>` elements. Every `<card>` contains a `<title>` element and a `<body>` element. The `<body>` text can include placeholders of the form `{{expr}}`, where `expr` is an arithmetic expression using non-negative decimal integer literals, parentheses, and the operators `+`, `-`, and `*`.

Your program must perform these steps:

1. Parse the input XML and process each `<card>` in the order it appears.
2. For each card, use the text from its `<title>` and the text from its `<body>`.
3. In every `<body>`, find each `{{expr}}` placeholder, evaluate the expression using normal arithmetic rules where `*` binds more tightly than `+` and `-`, and replace the placeholder with the resulting integer written in decimal form. All computed values are non-negative integers.
4. Write the output HTML exactly in this structure:
   - Start with `<html><body>` followed by a newline.
   - Then, for each card, write one line in this format:
     `<article><h2>` + title text + `</h2><p>` + replaced body text + `</p></article>`
   - Separate card lines with a single newline.
   - After the last card line, add a newline.
   - Then write `</body></html>` followed by one newline.
5. After writing the output file, print to stdout exactly the number of cards rendered, followed by ` cards rendered` and a newline. Do not print anything else.

For example, if `cards.xml` contains:

```xml
<cards>
  <card>
    <title>Weekly totals</title>
    <body>Boxes shipped: {{12 + 7 * 3}}. Returns: {{40 - 5}}.</body>
  </card>
  <card>
    <title>Inventory</title>
    <body>Units left: {{(100 - 12) * 2}}.</body>
  </card>
</cards>
```

Then running:

    python render_cards.py cards.xml cards.html

should create `cards.html` containing:

```
<html><body>
<article><h2>Weekly totals</h2><p>Boxes shipped: 33. Returns: 35.</p></article>
<article><h2>Inventory</h2><p>Units left: 176.</p></article>
</body></html>
```

and it should print:

```
2 cards rendered
```
