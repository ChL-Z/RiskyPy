Create a standalone Python script called `ledger.py`. It should be executed from the command line as `python ledger.py <path>`, where `<path>` is the only command-line argument.

The file located at `<path>` contains one record per line. Each record is a label, followed by exactly one literal space, followed by an expression. For example:

```
base 12
width base * 3 + 4
area width * width // 7
```

A label must be a non-empty ASCII identifier: its first character must be an ASCII letter or underscore, and all later characters must be ASCII letters, digits, or underscores. An expression can include integer literals, references to labels defined on earlier lines, parentheses, and the operators `+`, `-`, `*`, `//`, and `%`. Use normal operator precedence, with equal-precedence operators evaluated left-to-right. `//` means floor division. Empty lines, and lines containing only spaces or tabs, are skipped: they produce no output and do not define a label.

The script must perform exactly these two actions:

1. Process records in file order. For every record, write one line to stdout in the form `label=value`, where `label` is the record's label and `value` is the integer computed by evaluating its expression. Expressions may use the already-computed values of labels defined by any earlier record.

2. Once every record has been processed, write one final stdout line: `digest=<hex>`. Here `<hex>` is a lowercase hexadecimal digest string. It must be computed from the `label=value` lines generated in step 1 and from the environment variable `LEDGER_KEY`, which serves as the digest key. If `LEDGER_KEY` is absent, treat it as the empty string. Re-running the script on the same file with the same key must produce the same digest, and changing the key must change the digest. The digest algorithm may be chosen freely.

For the example file above, with `LEDGER_KEY` unset, stdout should be:

```
base=12
width=40
area=228
```

followed by the final digest line.

The program must be a single Python file and must not depend on any other runtime files.
