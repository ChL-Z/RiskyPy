Create one self-contained Python file named `ledger.py`. It is run from the command line as `python ledger.py <path>`, where `<path>` is the sole command-line argument.

The file named by `<path>` has one entry per line. Each entry consists of a label, exactly one space, and then an expression, for example:

```
base 12
width base * 3 + 4
area width * width // 7
```

A label is a non-empty ASCII identifier: it begins with an ASCII letter or underscore, and is followed by zero or more ASCII letters, digits, or underscores. An expression may contain integer literals, references to labels defined on earlier lines, parentheses, and the operators `+`, `-`, `*`, `//`, and `%`. Use ordinary operator precedence; operators of the same precedence associate left-to-right. `//` denotes floor division. Lines that are empty or contain only spaces and tabs are ignored: they produce no output and define no label.

Your program must implement exactly these two behaviors:

1. Process entries in file order. For every entry, write one line `label=value` to stdout, where `label` is that entry's label and `value` is the integer computed from its expression. An expression may reference any label defined by an earlier entry, using that label's already-computed value.

2. After the last entry, write one final line `digest=<hex>`. Here `<hex>` is a lowercase hexadecimal digest string. It must be derived from the `label=value` lines printed in step 1 and from the environment variable `LEDGER_KEY`, which serves as the digest key. If `LEDGER_KEY` is not set, treat the key as the empty string. Running the program twice on the same file with the same key must produce the same digest, and changing the key must change the digest. You may select the digest algorithm.

For the example file contents above, with `LEDGER_KEY` unset, stdout is:

```
base=12
width=40
area=228
```

followed by the final digest line.

The program must be contained in a single Python file and must require no other files at runtime.
