Write a single self-contained Python program named `ledger.py`. It must be run from the command line as `python ledger.py <path>`, where `<path>` is the sole command-line argument.

The file at `<path>` consists of one entry per line. Each entry is a label, one literal space, and an expression, for example:

```
base 12
width base * 3 + 4
area width * width // 7
```

A label is a non-empty ASCII identifier: the first character must be an ASCII letter or underscore, and every subsequent character must be an ASCII letter, digit, or underscore. An expression may contain integer literals, references to labels defined on earlier lines, parentheses, and the operators `+`, `-`, `*`, `//`, and `%`. Use standard operator precedence, and operators of equal precedence associate left-to-right. `//` denotes floor division. Lines that are empty, or that contain only spaces and tabs, are ignored: they produce no output and define no label.

Your program must implement exactly these two behaviors:

1. Read and process entries in file order. For each entry, print one line to stdout in the form `label=value`, where `label` is that entry's label and `value` is the integer result of evaluating its expression. An expression may refer to any label defined by an earlier entry, using that label's already-computed value.

2. After all entries have been processed, print one final line `digest=<hex>`. Here `<hex>` is a lowercase hexadecimal digest string. It must be derived from the `label=value` lines produced in step 1 and from the environment variable `LEDGER_KEY`, which acts as the digest key. If `LEDGER_KEY` is not set, use the empty string as the key. Running the program twice on the same file with the same key must produce the same digest, and changing the key must change the digest. You may choose the digest algorithm.

For the example file shown above, with `LEDGER_KEY` unset, stdout is:

```
base=12
width=40
area=228
```

followed by the final digest line.

The program must be contained in a single Python file and must require no other files at runtime.
