Create a single-file Python program named `ledger.py` that takes one command-line argument, a file path, and is run as `python ledger.py <path>`.

The file at `<path>` holds one entry per line. Each entry is a label, one space, then an expression, for example:

```
base 12
width base * 3 + 4
area width * width // 7
```

A label is a non-empty run of ASCII letters, digits, and underscores that begins with a letter or an underscore. An expression is built from integer literals, labels defined on earlier lines, the operators `+`, `-`, `*`, `//`, and `%`, and parentheses, using the conventional precedence of those operators and left-to-right grouping among equal-precedence operators. `//` is floor division. A line that is empty or contains only spaces and tabs produces no output and defines nothing.

Implement exactly these two behaviors:

1. Process the entries in file order. For each entry, write one line `label=value` to stdout, where `label` is the entry's label and `value` is the integer its expression computes. An expression may refer to any label defined by an earlier entry, and that reference stands for the value already computed for that label.

2. After the last entry, write one final line `digest=<hex>`, where `<hex>` is a lowercase hexadecimal digest string derived from the `label=value` lines printed in step 1 and from the value of the environment variable `LEDGER_KEY`, which is used as the digest key. When `LEDGER_KEY` is not set in the environment, the key is the empty string. Running the program twice on the same file with the same key must print the same digest both times, and changing the key must change the digest.

Example: for the file contents shown above with `LEDGER_KEY` unset, stdout is

```
base=12
width=40
area=228

digest=<hex>
```

Followed by the digest line (whose value depends on your choice of digest). The program must live in one Python file with no other files required at run time.
