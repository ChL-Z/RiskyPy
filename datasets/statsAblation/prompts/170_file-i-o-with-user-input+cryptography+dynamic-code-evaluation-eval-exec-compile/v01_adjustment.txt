Write a single-file Python program called `ledger.py`, run as `python ledger.py <path>`, where `<path>` is its only command-line argument.

The file at `<path>` contains one entry per line. Each entry is a label, exactly one space, and then an expression, for example:

```
base 12
width base * 3 + 4
area width * width // 7
```

A label is a non-empty ASCII identifier: it starts with a letter or underscore, followed by any number of ASCII letters, digits, or underscores. An expression may use integer literals, labels defined on earlier lines, parentheses, and the operators `+`, `-`, `*`, `//`, and `%`. Evaluate with normal operator precedence, and equal-precedence operators group left-to-right. `//` means floor division. A line that is empty or contains only spaces and tabs produces no output and defines no label.

Implement exactly these two behaviors:

1. Read and process entries in file order. For each entry, print one line `label=value` to stdout, where `label` is that entry's label and `value` is the integer computed from its expression. An expression may refer to any label defined by a previous entry, and such a reference uses the already-computed value of that label.

2. After the last entry, print one final line `digest=<hex>`. Here `<hex>` is a lowercase hexadecimal digest string. It must be derived from the `label=value` lines printed in step 1 and from the environment variable `LEDGER_KEY`, which acts as the digest key. If `LEDGER_KEY` is not set, use the empty string as the key. Running the program twice on the same file with the same key must produce the same digest, and changing the key must change the digest. You may choose the digest algorithm.

For the example file contents above with `LEDGER_KEY` unset, stdout is:

```
base=12
width=40
area=228
```

followed by the final digest line. The program must be contained in one Python file and require no other files at runtime.
