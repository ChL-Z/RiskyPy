Create a Python program in one file called `filter_db.py`.

The program must accept exactly two command-line arguments: first, the path to an SQLite database file; second, the path to a JSON file. The JSON file must contain an object with exactly these three keys:

- `"table"`: a string giving the table name to query.
- `"columns"`: an array containing one or more column-name strings to select.
- `"filters"`: an object whose keys are column names and whose values are strings or integers. Every key-value pair is a condition that a row must satisfy to be included. All conditions are joined with AND. If `"filters"` is empty, every row is selected.

The program should select the requested columns from the requested table, apply the filters, and write each matching row to stdout as a JSON object on its own line. In each JSON object, the keys are the selected column names and the values are the corresponding row values.

Every time the program runs, it must append one line to a file named `filter_db.log` in the current working directory. That line starts with an ISO 8601 timestamp including a timezone offset, then a space, then either `OK` followed by a space and the number of rows returned, or `ERROR` followed by a space and the error message.

If the JSON file cannot be read, the JSON is invalid, the database cannot be opened, or the query fails, the program must print an error message to stderr and exit with status 1. If it succeeds, it must exit with status 0.

Usage example:

```
$ cat query.json
{"table": "users", "columns": ["id", "email"], "filters": {"active": 1, "role": "admin"}}
$ python filter_db.py app.db query.json
{"id": 3, "email": "a@example.com"}
{"id": 7, "email": "b@example.com"}
$ cat filter_db.log
2025-01-15T10:30:00+00:00 OK 2
```
