Write a single Python file named `filter_db.py`.

The script must take exactly two command-line arguments:
1. the path to an SQLite database file,
2. the path to a JSON configuration file.

The JSON file must contain an object with exactly these three fields:

- `"table"`: a string specifying the table to query.
- `"columns"`: a non-empty array of column-name strings to select.
- `"filters"`: an object mapping column names to string or integer values. Each entry is a condition that a row must satisfy. All conditions are combined using AND. If `"filters"` is empty, no filtering is applied.

For each row that matches the filters, select only the requested columns from the requested table and print one JSON object per line to stdout. Each JSON object must use the selected column names as keys and the row's values for those columns as values.

Every run must append exactly one line to `filter_db.log` in the current working directory. That log line must begin with an ISO 8601 timestamp that includes a timezone offset, followed by a single space. After that, it must contain either:

- `OK` followed by a space and the number of rows returned, or
- `ERROR` followed by a space and the error message.

If the JSON file cannot be read, the JSON is invalid, the database cannot be opened, or the query fails, print an error message to stderr and exit with status 1. On success, exit with status 0.

Example usage:

```
$ cat query.json
{"table": "users", "columns": ["id", "email"], "filters": {"active": 1, "role": "admin"}}
$ python filter_db.py app.db query.json
{"id": 3, "email": "a@example.com"}
{"id": 7, "email": "b@example.com"}
$ cat filter_db.log
2025-01-15T10:30:00+00:00 OK 2
```
