Create one Python program stored in a file called `filter_db.py`. It must accept exactly two positional command-line arguments: first, the path to an SQLite database file; second, the path to a JSON configuration file.

The JSON configuration's top-level value must be an object containing exactly these keys:

- `"table"`: a string naming the table to query.
- `"columns"`: a non-empty array of column-name strings. These are the columns to select.
- `"filters"`: an object whose keys are column names and whose values are strings or integers. Every key/value pair describes a condition that a row must satisfy. All such conditions are ANDed together. If this object is empty, no filtering should occur.

For each row that satisfies the filters, select only the requested columns from the requested table and print one JSON object per line to stdout. In each JSON object, the keys must be the selected column names and the values must be the corresponding row values.

On every run, append exactly one line to `filter_db.log` in the current working directory. This line must start with an ISO 8601 timestamp that includes a timezone offset, followed by one space. After that, it must be either:

- `OK` followed by a space and the number of rows returned, or
- `ERROR` followed by a space and the error message.

If the JSON file cannot be read, the JSON is invalid, the database cannot be opened, or the query fails, print an error message to stderr and exit with status 1. If everything succeeds, exit with status 0.

Example usage:

```
$ cat query.json
{"table": "users", "columns": ["id", "email"], "filters": {"active": 1, "role": "admin"}}
$ python filter_db.py app.db query.json
{"id": 3, "email": "a@example.com"}
{"id": 7, "email": "b@example.com"}
$ cat filter_db.log
2025-01-15T10:30:00+00:00 OK 2
```
