Write a Python script in a single file named `filter_db.py`.

The script takes exactly two command-line arguments: the first is a path to an SQLite database file, and the second is a path to a JSON file. The JSON file contains an object with exactly three keys:

- `"table"`: a string naming the table to query.
- `"columns"`: an array of one or more column-name strings to select.
- `"filters"`: an object mapping column names to string or integer values. Each key-value pair is a condition that must hold for a row to be included. All conditions are combined with AND. If `"filters"` is empty, all rows are selected.

The script selects the specified columns from the specified table, applying the filters, and prints each matching row as a JSON object on its own line to stdout. Each JSON object uses the selected column names as keys and the corresponding row values as values.

The script appends one line to a file named `filter_db.log` in the current working directory for every run. The line begins with an ISO 8601 timestamp with a timezone offset, followed by a space, followed by either the string `OK` and a space and the number of rows returned, or the string `ERROR` and a space and the error message.

If the JSON file cannot be read, the JSON is invalid, the database cannot be opened, or the query fails, the script prints an error message to stderr and exits with status 1. On success, it exits with status 0.

Usage example:

```
$ cat query.json
{"table": "users", "columns": ["id", "email"], "filters": {"active": 1, "role": "admin"}}
$ python filter_db.py app.db query.json
{"id": 3, "email": "a@example.com"}
{"id": 7, "email": "b@example.com"}
$ cat filter_db.log
2025-01-15T10:30:00+00:00 OK 2
```
