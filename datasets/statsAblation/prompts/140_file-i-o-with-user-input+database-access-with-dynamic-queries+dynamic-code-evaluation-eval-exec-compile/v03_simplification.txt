Generate a single Python file called `filter_records.py`. This script accepts exactly one command-line argument, which is the filesystem path to a SQLite database.

From standard input, the script should read filter rules. Each rule is on its own line, and empty lines must be skipped. A non-empty rule has this structure: `<column> <operator> <value>`. The column and operator are separated by a single space; the value begins after the next space and continues to the end of the line, so it may itself contain spaces if appropriate.

The only allowed columns are `id`, `name`, `category`, and `amount`. The only allowed operators are `=`, `!=`, `<`, `<=`, `>`, and `>=`. For `id` and `amount`, the value should be treated as a number. For `name` and `category`, the value should be treated as text.

The SQLite database has a table named `records` with the following columns:
- `id INTEGER PRIMARY KEY`
- `name TEXT`
- `category TEXT`
- `amount REAL`
- `formula TEXT`

The script must select all rows that satisfy every given filter condition, sorted by `id` in ascending order. For each selected row, evaluate the arithmetic expression in the `formula` column. In that expression, the variables `id`, `name`, `category`, and `amount` refer to the corresponding values from the row. The expression can use `+`, `-`, `*`, `/`, `%`, `**`, and parentheses.

For every matching row, write exactly one line to standard output in the form `id,name,value`, where `value` is the evaluated result printed as a decimal number. Do not print a header.

Example: assume `data.db` contains a `records` table with these rows:
- `(1, 'Ada', 'books', 12.5, 'amount * 2 + 1')`
- `(2, 'Ben', 'toys', 8.0, 'amount + 5')`
- `(3, 'Cy', 'books', 20.0, 'amount / 4')`

If the command is `python filter_records.py data.db` and standard input contains:

```
amount > 10
category = books
```

then the output must be:

```
1,Ada,26.0
3,Cy,5.0
```
