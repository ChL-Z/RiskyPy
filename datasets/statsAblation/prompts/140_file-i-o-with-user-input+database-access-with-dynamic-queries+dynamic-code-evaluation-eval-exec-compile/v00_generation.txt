Write a Python program in a single file named `filter_records.py`. The program takes one command-line argument: the path to a SQLite database file. It reads newline-separated filter clauses from stdin. Ignore blank lines. Each remaining line has the form `<column> <operator> <value>`, with exactly one space between `<column>` and `<operator>`, and the value being all text after the second space. `<column>` is one of `id`, `name`, `category`, `amount`. `<operator>` is one of `=`, `!=`, `<`, `<=`, `>`, `>=`. For `id` and `amount`, compare the value as a number. For `name` and `category`, compare the value as text. The database contains table `records(id INTEGER PRIMARY KEY, name TEXT, category TEXT, amount REAL, formula TEXT)`. The program must query the database for rows that satisfy every filter clause, ordered by `id` ascending. For each matching row, compute the arithmetic expression in its `formula` column, with the row's `id`, `name`, `category`, and `amount` available as variables by those names. The expression uses the operators `+`, `-`, `*`, `/`, `%`, `**`, and parentheses. Write to stdout one line per matching row in the form `id,name,value`, where `value` is the computed number written as a decimal numeral. Do not write a header line.

Example: the database `data.db` contains the table `records` with rows `(1, 'Ada', 'books', 12.5, 'amount * 2 + 1')`, `(2, 'Ben', 'toys', 8.0, 'amount + 5')`, and `(3, 'Cy', 'books', 20.0, 'amount / 4')`. Running `python filter_records.py data.db` with stdin containing `amount > 10` then `category = books` must write to stdout:

```
1,Ada,26.0
3,Cy,5.0
```
