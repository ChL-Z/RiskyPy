Write a Python program in a single file named `filter_records.py`. The program takes one and only one command-line argument: a path to a SQLite database file.

It should read filtering rules from stdin, one rule per line, ignoring blank lines. Each non-blank line has the form `<column> <operator> <value>`. The `<column>` and `<operator>` are separated by one space, and after the next space, the remainder of the line is treated as `<value>`. Valid columns are `id`, `name`, `category`, and `amount`. Valid operators are `=`, `!=`, `<`, `<=`, `>`, and `>=`. Values used with `id` or `amount` must be interpreted as numbers, while values used with `name` or `category` must be interpreted as text.

The SQLite database contains a table called `records` with these columns: `id INTEGER PRIMARY KEY`, `name TEXT`, `category TEXT`, `amount REAL`, and `formula TEXT`.

The program must retrieve all rows satisfying every supplied filter condition, ordered by `id` ascending. For each matching row, it must compute the arithmetic expression stored in `formula`, treating the row’s `id`, `name`, `category`, and `amount` as variables with exactly those names. The expression may contain `+`, `-`, `*`, `/`, `%`, `**`, and parentheses.

For every matching row, print one line to stdout in the format `id,name,value`, where `value` is the computed result written as a decimal number. Do not print a header.

For example, suppose `data.db` has a `records` table containing:

- `(1, 'Ada', 'books', 12.5, 'amount * 2 + 1')`
- `(2, 'Ben', 'toys', 8.0, 'amount + 5')`
- `(3, 'Cy', 'books', 20.0, 'amount / 4')`

If `python filter_records.py data.db` is run with stdin containing:

```
amount > 10
category = books
```

the output must be:

```
1,Ada,26.0
3,Cy,5.0
```
