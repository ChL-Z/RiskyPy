Create a single-file Python script called `filter_records.py`. It accepts exactly one command-line argument: the filesystem path of a SQLite database. The script should read filter expressions from standard input, one per line, and skip any empty lines. Every non-empty line must follow the format `<column> <operator> <value>`, where a single space separates `<column>` from `<operator>`, and everything after the following space is the `<value>`. The allowed `<column>` names are `id`, `name`, `category`, and `amount`. The allowed `<operator>` values are `=`, `!=`, `<`, `<=`, `>`, and `>=`. When filtering on `id` or `amount`, treat the supplied value as a number; when filtering on `name` or `category`, treat it as text. The SQLite database has a table named `records` with columns `id INTEGER PRIMARY KEY`, `name TEXT`, `category TEXT`, `amount REAL`, and `formula TEXT`. The script must select all rows matching all given filter conditions, sorted by `id` in ascending order. For every matching row, evaluate the arithmetic expression stored in `formula`, using the row’s `id`, `name`, `category`, and `amount` as variables with those exact names. The expression may use `+`, `-`, `*`, `/`, `%`, `**`, and parentheses. For each matching row, print to standard output a single line formatted as `id,name,value`, where `value` is the evaluated result written as a decimal numeral. Do not print any header. For example, if `data.db` contains the `records` table with rows `(1, 'Ada', 'books', 12.5, 'amount * 2 + 1')`, `(2, 'Ben', 'toys', 8.0, 'amount + 5')`, and `(3, 'Cy', 'books', 20.0, 'amount / 4')`, then running `python filter_records.py data.db` with standard input containing the lines `amount > 10` and `category = books` must output:

```
1,Ada,26.0
3,Cy,5.0
```
