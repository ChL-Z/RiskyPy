Create a standalone Python program named `manifest_reader.py` that a build tool can execute before each build to download and validate a remotely hosted, signed settings manifest.

The program must accept exactly two command-line arguments:

1. The URL of the manifest service
2. The filesystem path to a PEM-encoded public key

Example command:

```
python manifest_reader.py https://manifests.example.com/latest.json ./public.pem
```

Required behavior:

1. Fetch the JSON document from the supplied URL over HTTPS. The JSON document is an object containing exactly two string fields:
   - `payload`: base64-encoded bytes representing a serialized Python dictionary. Every key and every value in that dictionary is a string.
   - `signature`: base64-encoded signature over the decoded `payload` bytes.

   Use the public key from the second command-line argument to verify the signature. If verification fails, print exactly `signature invalid` to standard error and terminate with exit status 2.

2. If verification succeeds, deserialize the dictionary from the `payload` bytes and print its entries to standard output, one entry per line, as `key=value`, with keys ordered alphabetically. If the dictionary is empty, print nothing.

Standard output must contain nothing except those `key=value` lines.
