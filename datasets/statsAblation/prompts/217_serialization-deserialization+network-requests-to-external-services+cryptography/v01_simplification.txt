Create a single-file Python program named `manifest_reader.py` for a build tool that loads a signed, remotely published settings manifest before each build.

The program accepts exactly two command-line arguments: the manifest service URL and the path to a PEM-encoded public key file. It should be run like this:

```
python manifest_reader.py https://manifests.example.com/latest.json ./public.pem
```

Requirements:

1. Fetch the JSON document from the given URL over HTTPS. The document is a JSON object with two string fields:
   - `payload`: base64-encoded bytes of a serialized Python dictionary whose keys and values are all strings.
   - `signature`: base64-encoded signature over the decoded `payload` bytes.

   Verify the signature using the public key read from the second argument. If verification fails, write exactly `signature invalid` to standard error and exit with status code 2.

2. Rebuild the dictionary from the `payload` bytes and print its items to standard output, one per line, formatted as `key=value`, with the keys sorted alphabetically. If the dictionary is empty, print nothing.

Do not print anything else to standard output.
