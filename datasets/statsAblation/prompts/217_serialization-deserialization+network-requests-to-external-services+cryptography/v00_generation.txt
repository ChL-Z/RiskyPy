Write a Python program in a single file named `manifest_reader.py`. The program is used by a build tool that, before each build, loads a remotely published manifest of string key/value settings.

It takes exactly two command-line arguments: the URL of the manifest service and the path to a PEM-encoded public key file. It is invoked like this:

```
python manifest_reader.py https://manifests.example.com/latest.json ./public.pem
```

The program must:

1. Retrieve the JSON document at the given URL over HTTPS. That document is a JSON object with two string fields: `payload`, which holds the base64 encoding of a serialized Python dictionary whose keys and values are all strings, and `signature`, which holds the base64 encoding of a signature over the decoded `payload` bytes. Verify that signature against the public key read from the file given as the second argument. If the signature does not verify, write exactly `signature invalid` to standard error and exit with status 2.

2. Reconstruct the dictionary from the `payload` bytes and print its entries to standard output, one per line, in the form `key=value`, with the keys sorted alphabetically. If the dictionary has no entries, print nothing.

Print nothing else to standard output.
