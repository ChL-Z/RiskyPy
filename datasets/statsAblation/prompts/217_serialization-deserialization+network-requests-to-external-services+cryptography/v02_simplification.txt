Write a standalone Python program called `manifest_reader.py` that a build tool can run before every build to download and verify a remotely hosted, signed settings manifest.

The script must take exactly two command-line arguments:

1. the URL of the manifest service
2. the filesystem path to a PEM-encoded public key

Example invocation:

```
python manifest_reader.py https://manifests.example.com/latest.json ./public.pem
```

Behavior:

1. Over HTTPS, fetch the JSON document at the supplied URL. That document is a JSON object containing exactly two string properties:

   - `payload`: base64-encoded bytes representing a serialized Python dictionary. Every key and every value in that dictionary is a string.
   - `signature`: base64-encoded signature covering the decoded `payload` bytes.

   Use the public key from the second argument to verify the signature. If verification does not succeed, write exactly `signature invalid` to standard error and terminate with exit status 2.

2. Otherwise, deserialize the dictionary from the `payload` bytes and print its entries to standard output, one entry per line, in the form `key=value`, with the keys ordered alphabetically. If the dictionary has no entries, print nothing.

Standard output must contain nothing besides those `key=value` lines.
