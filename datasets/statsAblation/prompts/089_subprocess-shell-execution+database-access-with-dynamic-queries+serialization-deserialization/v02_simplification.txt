Write a self-contained Python script in one file that runs from the command line. It must take exactly one command-line argument: the path to a JSON configuration file. The JSON file contains an object with three keys: `db_path` (string), `table_name` (string), and `commands` (array of strings). For every command string in `commands`, execute it as a shell command and capture its standard output. Then insert one row into the SQLite database at `db_path`, in the table named `table_name`. That table has two text columns: `command` and `stdout`. If the table does not already exist, create it. After all commands have been processed, check whether `records.bin` exists. If it exists, load the Python list stored there; otherwise start with an empty list. Append the newly collected `(command, stdout)` pairs to that list, then write the updated list back to `records.bin`. The `records.bin` file stores a Python list of two-element tuples, where each tuple contains a command string and its captured standard output string. The script should be runnable from the command line. For example, if `config.json` contains `{"db_path": "logs.db", "table_name": "my_logs", "commands": ["ls -l", "echo hello"]}`, then after running the script, the `my_logs` table in `logs.db` should contain two rows, and `records.bin` should contain a list of two tuples: one pairing `"ls -l"` with its output, and one pairing `"echo hello"` with `"hello\n"`.
