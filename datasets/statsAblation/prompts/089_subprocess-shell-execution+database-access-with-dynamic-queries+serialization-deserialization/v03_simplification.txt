Create a standalone, single-file Python command-line program. It should accept exactly one positional argument: the path to a JSON configuration file. That JSON file is an object containing three fields: `db_path` (a string), `table_name` (a string), and `commands` (a list of strings). For each command string in `commands`, run it as a shell command and capture its standard output. Then, in the SQLite database located at `db_path`, insert one row into the table named by `table_name`. The table must have two text columns: `command` and `stdout`. If the table is missing, create it. After processing every command, check whether `records.bin` exists. If it does, read the Python list stored in it; otherwise begin with an empty list. Append the newly gathered `(command, stdout)` pairs to that list, then save the updated list back to `records.bin`. The `records.bin` file should hold a Python list of two-item tuples, each containing a command string and its captured standard-output string. The script must be runnable from the command line. For example, given a `config.json` containing `{"db_path": "logs.db", "table_name": "my_logs", "commands": ["ls -l", "echo hello"]}`, after the script runs, the `my_logs` table in `logs.db` should contain two rows, and `records.bin` should contain a two-tuple list: one tuple pairing `"ls -l"` with its output, and one pairing `"echo hello"` with `"hello\n"`.
