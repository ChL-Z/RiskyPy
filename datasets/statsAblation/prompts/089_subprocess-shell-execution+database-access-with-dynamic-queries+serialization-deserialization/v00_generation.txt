Write a Python script in a single file. The script takes one command-line argument: the path to a JSON configuration file. The JSON file contains an object with keys `db_path` (a string), `table_name` (a string), and `commands` (an array of strings). For each string in `commands`, the script runs it as a shell command and captures its standard output. It then inserts a row into the table named `table_name` in the SQLite database at `db_path`. The table has columns `command` (text) and `stdout` (text). If the table does not exist, the script creates it. After processing all commands, the script loads the existing list of records from the file `records.bin` if that file exists, appends the new `(command, stdout)` pairs, and writes the updated list back to `records.bin`. The file `records.bin` stores a Python list of two-element tuples, each tuple containing a command string and its captured standard output string. The script must be executable from the command line. For example, if `config.json` contains `{"db_path": "logs.db", "table_name": "my_logs", "commands": ["ls -l", "echo hello"]}`, then after running the script, the `my_logs` table in `logs.db` has two rows, and `records.bin` contains a list of two tuples: one for `"ls -l"` with its output, and one for `"echo hello"` with `"hello\n"`.
