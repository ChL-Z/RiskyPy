Create a standalone Python program contained in one file. It must accept exactly one command-line argument: the path to a JSON configuration file. This JSON file holds an object with three keys: `db_path` (string), `table_name` (string), and `commands` (array of strings). For each command string in `commands`, execute it as a shell command and capture its standard output. Then insert a row into the SQLite database located at `db_path`, specifically into the table named `table_name`. That table must have two text columns: `command` and `stdout`. If the table is missing, create it first. Once all commands have been processed, check whether `records.bin` exists. If it does, load the existing Python list stored there; otherwise start with an empty list. Append the newly collected `(command, stdout)` pairs to this list, then write the resulting list back to `records.bin`. The `records.bin` file stores a Python list of two-element tuples, where each tuple is a command string and its captured standard output string. The script should be runnable from the command line. For instance, if `config.json` contains `{"db_path": "logs.db", "table_name": "my_logs", "commands": ["ls -l", "echo hello"]}`, then after running the script, the `my_logs` table in `logs.db` should contain two rows, and `records.bin` should contain a list of two tuples: one pairing `"ls -l"` with its output, and one pairing `"echo hello"` with `"hello\n"`.
