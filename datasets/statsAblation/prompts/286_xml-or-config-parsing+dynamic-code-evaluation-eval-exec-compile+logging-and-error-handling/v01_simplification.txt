Implement a single-file Python script named `calc_metrics.py` that evaluates metric formulas stored in an XML file.

The XML file path is provided as the first command-line argument. The XML document has a root `<metrics>` element and may contain any number of `<metric>` child elements. Each `<metric>` element has exactly two attributes:
- `name`: a string that begins with a letter and then contains only letters, digits, and underscores.
- `formula`: an arithmetic expression that may include integer literals, floating-point literals, the operators `+`, `-`, `*`, `/`, parentheses, and names of metrics defined earlier in the document.

Process the `<metric>` elements in the order they appear. For each one, compute its numeric value from its `formula`, using previously computed metrics as variables if their names appear in the expression.

For every metric, after attempting to compute it, append exactly one line to `run.log` in the current working directory:
- If successful: `OK <name>=<value>`, where `<value>` is the result formatted using `repr()`.
- If unsuccessful: `ERROR <name>: <message>`.

The possible error messages are:
- `unknown name: <name>` if the formula refers to a name that is not an earlier-defined metric.
- `invalid syntax` if the formula is not a valid arithmetic expression.
- `division by zero` if the formula divides by zero.

Also print every `OK` line to stdout and every `ERROR` line to stderr. The program should exit with code `0` if all metrics are computed successfully, and with code `1` if any metric fails.

Example: for `config.xml` containing:
```xml
<metrics>
  <metric name="a" formula="10" />
  <metric name="b" formula="a * 2 + 3" />
  <metric name="c" formula="b / 0" />
</metrics>
```
Running `python calc_metrics.py config.xml` should print `OK a=10` and `OK b=23` to stdout, print `ERROR c: division by zero` to stderr, write these three lines to `run.log`:
```
OK a=10
OK b=23
ERROR c: division by zero
```
and exit with status code `1`.
