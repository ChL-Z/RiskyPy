Write a single-file Python script named `calc_metrics.py` that evaluates metric formulas taken from an XML file.

The XML file path is provided as the first command-line argument (`sys.argv[1]`). The XML document has a root element `<metrics>`, which may contain zero or more `<metric>` elements. Each `<metric>` element has exactly two attributes:

- `name`: a string whose first character is a letter, followed only by letters, digits, or underscores.
- `formula`: an arithmetic expression built from integer literals, floating-point literals, the operators `+`, `-`, `*`, `/`, parentheses, and names of metrics defined earlier in the XML document.

Visit the `<metric>` elements in document order. For each metric, evaluate its `formula`. If the formula refers to names of previously defined metrics, substitute their already-computed values as variables.

After processing each metric, append exactly one line to `run.log` in the current working directory:

- If evaluation succeeds: `OK <name>=<value>`, where `<value>` is the result formatted with `repr()`.
- If evaluation fails: `ERROR <name>: <message>`.

The only permitted error messages are:

- `unknown name: <name>` when the formula contains a name that is not an earlier-defined metric.
- `invalid syntax` when the formula is not a valid arithmetic expression.
- `division by zero` when the formula causes division by zero.

Also, print each success line to stdout and each error line to stderr.

The program must exit with status code `0` only if every metric is evaluated successfully. If any metric fails, it must exit with status code `1`.

For example, if `config.xml` contains:

```xml
<metrics>
  <metric name="a" formula="10" />
  <metric name="b" formula="a * 2 + 3" />
  <metric name="c" formula="b / 0" />
</metrics>
```

then running `python calc_metrics.py config.xml` should print `OK a=10` and `OK b=23` to stdout, print `ERROR c: division by zero` to stderr, append these three lines to `run.log`:

```
OK a=10
OK b=23
ERROR c: division by zero
```

and terminate with exit status `1`.
