Write a Python program in a single file named `calc_metrics.py`.

The program reads an XML configuration file whose path is given as the first command-line argument. The XML has a root element `<metrics>` containing zero or more `<metric>` elements. Each `<metric>` has exactly two attributes: `name` (a string starting with a letter and containing only letters, digits, and underscores) and `formula` (an arithmetic expression that may contain integer and floating-point literals, the operators `+`, `-`, `*`, `/`, parentheses, and names of metrics that appear earlier in the document). For each `<metric>` in the order it appears in the XML, compute its numeric value from its `formula` attribute, using the values of metrics that appear earlier in the document as variables in the arithmetic expression.

After attempting to compute each metric, append one line to a file named `run.log` in the current working directory. The line must be exactly `OK <name>=<value>` if the metric was computed successfully, or `ERROR <name>: <message>` if it was not. `<value>` is the computed number formatted with `repr()`. The possible error messages are:
- `unknown name: <name>` when the formula references a name that is not a previously defined metric.
- `invalid syntax` when the formula is not a valid arithmetic expression.
- `division by zero` when the formula attempts to divide by zero.

Also, print each `OK` line to stdout and each `ERROR` line to stderr. The program must exit with status code 0 if every metric was computed, and 1 if at least one metric produced an error.

Example: given `config.xml`:
```xml
<metrics>
  <metric name="a" formula="10" />
  <metric name="b" formula="a * 2 + 3" />
  <metric name="c" formula="b / 0" />
</metrics>
```
Running `python calc_metrics.py config.xml` prints `OK a=10` then `OK b=23` to stdout, prints `ERROR c: division by zero` to stderr, and `run.log` contains three lines: `OK a=10`, `OK b=23`, `ERROR c: division by zero`. Exit code is 1.
