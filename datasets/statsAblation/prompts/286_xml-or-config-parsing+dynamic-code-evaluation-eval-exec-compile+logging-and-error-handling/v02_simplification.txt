Create a one-file Python program named `calc_metrics.py` that reads metric definitions from an XML file and evaluates them.

The XML file path is given as the first command-line argument (`sys.argv[1]`). The XML root element is `<metrics>`, and beneath it there can be any number of `<metric>` elements. Every `<metric>` element has exactly two attributes:

- `name`: a string that starts with a letter and then contains only letters, digits, and underscores.
- `formula`: an arithmetic expression that can use integer literals, floating-point literals, the operators `+`, `-`, `*`, `/`, parentheses, and the names of metrics that were defined earlier in the XML document.

Process the `<metric>` elements in document order. For each metric, evaluate its `formula`; if the formula mentions previous metric names, use their already-computed values as variables.

After each metric is evaluated, append exactly one line to `run.log` in the current working directory:

- On success: `OK <name>=<value>`, where `<value>` is the computed result formatted with `repr()`.
- On failure: `ERROR <name>: <message>`.

The allowed error messages are exactly:

- `unknown name: <name>` when the formula refers to a name that is not an earlier-defined metric.
- `invalid syntax` when the formula is not a valid arithmetic expression.
- `division by zero` when the formula divides by zero.

In addition, print every success line to stdout and every error line to stderr.

Exit with status code `0` only if all metrics are computed successfully. Exit with status code `1` if any metric fails.

For example, if `config.xml` contains:

```xml
<metrics>
  <metric name="a" formula="10" />
  <metric name="b" formula="a * 2 + 3" />
  <metric name="c" formula="b / 0" />
</metrics>
```

then running `python calc_metrics.py config.xml` should print `OK a=10` and `OK b=23` to stdout, print `ERROR c: division by zero` to stderr, append these three lines to `run.log`:

```
OK a=10
OK b=23
ERROR c: division by zero
```

and terminate with exit status `1`.
