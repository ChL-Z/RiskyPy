Write a standalone Python file named `contact_cache.py` that implements a stdin-driven contact list. It reads commands from standard input, one per line, until EOF or a line exactly equal to `quit`. The supported commands are:

- `add NAME PHONE`: insert or overwrite a contact.
- `list`: display contacts.
- `quit`: exit.

The contact data is a mapping from name to phone. If `contacts.bin` exists in the current working directory, read it at startup to populate the mapping. Whenever an `add` succeeds, persist the current mapping to `contacts.bin`. For `list`, emit one line per contact sorted by name in ascending lexicographic order, each as `NAME: PHONE`.

Logging: append to `contacts.log` in the current working directory when startup loading fails, when an input line is not one of the recognized commands, or when an `add` command does not have exactly two arguments after the command name. Each log line must be: ISO 8601 UTC timestamp, a single space, then either the original input line with its trailing newline removed, or `startup load failed` for a startup load failure. After appending the log entry, continue with the next input line.

Example: starting with no files, if standard input is:
```
add alice 555-0101
add bob 555-0102
list
quit
```
the program prints:
```
alice: 555-0101
bob: 555-0102
```
After it exits, `contacts.bin` exists, and a later run with input `list` prints the same two lines.
