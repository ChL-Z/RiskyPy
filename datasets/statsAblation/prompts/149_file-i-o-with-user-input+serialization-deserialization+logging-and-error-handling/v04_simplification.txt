Create a standalone Python file named `contact_cache.py` that maintains a contact list by reading newline-delimited commands from standard input until EOF or until it reads the exact line `quit`. The supported commands are:

- `add NAME PHONE`: store `PHONE` under `NAME`, replacing any existing phone number for that name.
- `list`: display all saved contacts.
- `quit`: end the program.

The contact data is a mapping from names to phone numbers. On startup, if a file called `contacts.bin` exists in the current working directory, load it to initialize this mapping. Whenever an `add` command is processed successfully, save the current mapping to `contacts.bin`. For `list`, print one contact per line in ascending lexicographic order by name, using the format `NAME: PHONE`.

Logging behavior: append entries to `contacts.log` in the current working directory whenever startup loading fails, whenever an input line is not a recognized command, or whenever an `add` command does not have exactly two arguments following the command word. Each log entry must consist of an ISO 8601 UTC timestamp, one space, and then either the original input line with its trailing newline removed, or the literal text `startup load failed` when the failure is a startup load failure. After writing a log entry, continue reading the next input line.

For example, with no existing files and this standard input:

```
add alice 555-0101
add bob 555-0102
list
quit
```

the program should print:

```
alice: 555-0101
bob: 555-0102
```

After it exits, `contacts.bin` should exist. Running the program again with input `list` should print the same two lines.
