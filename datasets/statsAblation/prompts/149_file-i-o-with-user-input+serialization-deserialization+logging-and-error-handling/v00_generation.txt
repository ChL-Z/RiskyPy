Create a single Python file named `contact_cache.py` that implements a command-line contact list. The program reads newline-separated commands from standard input until end-of-input or a line equal to `quit`. The commands are:

- `add NAME PHONE` — add or replace a contact.
- `list` — print contacts.
- `quit` — stop.

The program maintains contacts as a mapping from name to phone. On startup, if `contacts.bin` exists in the current working directory, load the mapping from that file. After each successful `add`, write the current mapping to `contacts.bin`. For `list`, print one line per contact in ascending lexicographic order of name, each formatted as `NAME: PHONE`.

When a startup load fails, or an input line is not one of the commands above, or an `add` line does not contain exactly two arguments after the command name, append a line to `contacts.log` in the current working directory. That line must contain the UTC timestamp in ISO 8601 format, a single space, and the input line with its trailing newline removed (or the text `startup load failed` for a startup load failure). After writing the log line, continue processing the next input line.

Example: starting with no files, if standard input is:
```
add alice 555-0101
add bob 555-0102
list
quit
```
the program prints:
```
alice: 555-0101
bob: 555-0102
```
After it exits, `contacts.bin` exists, and a later run with input `list` prints the same two lines.
