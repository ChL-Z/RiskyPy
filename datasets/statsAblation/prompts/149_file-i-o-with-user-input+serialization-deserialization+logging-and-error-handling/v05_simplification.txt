Write a standalone Python program saved as `contact_cache.py`. It should act as a simple contact cache driven by newline-delimited commands read from standard input. It keeps reading until EOF or until the line `quit` is encountered. The commands are:

- `add NAME PHONE`: save `PHONE` for `NAME`, overwriting any previous number for that name.
- `list`: print every stored contact.
- `quit`: stop the program.

The stored contacts are represented as a name-to-phone-number mapping. When the program starts, if `contacts.bin` exists in the current working directory, use it to initialize the mapping. Each time an `add` command succeeds, write the current mapping back to `contacts.bin`. For `list`, output contacts one per line, sorted by name in ascending lexicographic order, using exactly `NAME: PHONE`.

For logging, append records to `contacts.log` in the current working directory when any of these happens:
- startup loading fails;
- an input line is not a valid recognized command;
- an `add` command does not contain exactly two arguments after the command word.

Each log record must contain an ISO 8601 UTC timestamp, followed by one space, followed by either the original input line with its trailing newline removed, or the exact text `startup load failed` if the issue was a startup loading failure. After logging any such issue, continue reading the next input line.

For example, given no pre-existing files and this standard input:

```
add alice 555-0101
add bob 555-0102
list
quit
```

the program should print:

```
alice: 555-0101
bob: 555-0102
```

After it exits, `contacts.bin` should exist. If the program is run again with input `list`, it should print the same two lines.
