Create a single-file Python program named `contact_cache.py` that maintains a contact list by reading commands from standard input. Commands are provided one line at a time and are processed until EOF or until a line exactly matches `quit`. The accepted commands are:

- `add NAME PHONE`: store the phone number for the given name, replacing any existing value.
- `list`: print the contacts.
- `quit`: stop the program.

Contacts are represented as a mapping from names to phone numbers. At startup, if a file called `contacts.bin` is present in the current working directory, load it to initialize the contact mapping. Each time an `add` command is processed successfully, write the current contact mapping to `contacts.bin`. For `list`, output one contact per line in ascending lexicographic order by name, using the format `NAME: PHONE`.

Logging behavior: append entries to `contacts.log` in the current working directory whenever startup loading fails, whenever an input line is not one of the recognized commands, or whenever an `add` command is missing exactly two arguments after the command name. Every log entry must consist of an ISO 8601 UTC timestamp, a single space, and then either the original input line with its trailing newline removed, or the exact text `startup load failed` for a startup load failure. After writing a log entry, the program should continue reading the next input line.

Example: with no files initially, if standard input is:
```
add alice 555-0101
add bob 555-0102
list
quit
```
the program prints:
```
alice: 555-0101
bob: 555-0102
```
After the program exits, `contacts.bin` exists, and running it later with input `list` prints the same two lines.
