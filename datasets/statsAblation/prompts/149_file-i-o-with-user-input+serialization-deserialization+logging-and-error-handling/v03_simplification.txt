Implement a single-file Python script called `contact_cache.py` that keeps a contact list by reading newline-separated commands from standard input until either EOF is reached or a line is exactly `quit`. The program should support these commands:

- `add NAME PHONE`: save `PHONE` under `NAME`, overwriting any previous value for that name.
- `list`: print all contacts.
- `quit`: terminate the program.

Contacts are stored as a mapping from names to phone numbers. When the program starts, if a file named `contacts.bin` exists in the current working directory, use it to initialize that mapping. After every successfully processed `add`, write the current mapping to `contacts.bin`. For `list`, print one contact per line, sorted lexicographically in ascending order by name, using the exact format `NAME: PHONE`.

Logging rules: append to `contacts.log` in the current working directory whenever startup loading fails, whenever an input line is not one of the recognized commands, or whenever an `add` command does not have exactly two arguments after the command name. Each log entry must contain an ISO 8601 UTC timestamp, one space, and then either the original input line with its trailing newline removed, or the exact text `startup load failed` in the case of a startup load failure. After adding a log entry, the program should continue reading the next input line.

Example: starting with no files, if standard input is:
```
add alice 555-0101
add bob 555-0102
list
quit
```
the program prints:
```
alice: 555-0101
bob: 555-0102
```
After it exits, `contacts.bin` exists, and running the program again with input `list` prints the same two lines.
