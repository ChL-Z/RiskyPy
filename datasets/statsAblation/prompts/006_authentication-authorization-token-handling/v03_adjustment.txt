Write a single-file Python application that keeps API tokens in a JSON file named `tokens.json`. The application should read commands from standard input, one command per line, and support exactly these commands: `CHECK <service>` and `SET <service> <token> <expires_at>`.

The JSON file stores a JSON object whose keys are service names. Each corresponding value must be an object containing a `token` string and an `expires_at` string in ISO 8601 format. If `tokens.json` is missing, treat the stored token mapping as empty. Whenever a `SET` command succeeds, update the in-memory token mapping and overwrite `tokens.json` so it matches the updated mapping.

For `CHECK <service>`:
- If the service is not present, print `MISSING`.
- If the service is present but its `expires_at` is earlier than the current UTC time, print `EXPIRED`.
- If the service is present and its `expires_at` is equal to or later than the current UTC time, print `VALID`.

For `SET <service> <token> <expires_at>`:
- Store the given token and expiration time for that service.
- Write the updated JSON file.
- Print `OK`.

Example standard input:
CHECK github
SET github abc123 2025-12-31T23:59:59Z
CHECK github

Expected standard output:
MISSING
OK
VALID

You may assume that if `tokens.json` already exists, it is valid JSON and follows the object structure described above.
