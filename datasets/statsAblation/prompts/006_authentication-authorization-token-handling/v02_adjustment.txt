Create a one-file Python program that manages API tokens stored in a JSON file named `tokens.json`. Read commands from standard input, one per line. The program must support these commands: `CHECK <service>` and `SET <service> <token> <expires_at>`.

The JSON file must contain a JSON object whose keys are service names. Each value must be an object with a `token` string and an `expires_at` string in ISO 8601 format. If `tokens.json` does not exist, treat the stored token mapping as empty. Whenever a `SET` command succeeds, update the in-memory token mapping and overwrite `tokens.json` so it reflects the updated mapping.

When handling `CHECK <service>`:
- If the service is absent, print `MISSING`.
- If the service exists but its `expires_at` is earlier than the current UTC time, print `EXPIRED`.
- If the service exists and its `expires_at` is equal to or later than the current UTC time, print `VALID`.

When handling `SET <service> <token> <expires_at>`:
- Save the given token and expiration time for that service.
- Write the updated JSON file.
- Print `OK`.

Example standard input:
CHECK github
SET github abc123 2025-12-31T23:59:59Z
CHECK github

Expected standard output:
MISSING
OK
VALID

You may assume that if `tokens.json` already exists, it is valid JSON and follows the object structure described above.
