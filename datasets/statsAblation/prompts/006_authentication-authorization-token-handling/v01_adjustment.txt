Write a single-file Python script that maintains API tokens in a JSON file called `tokens.json`. The script should process commands from standard input, one command per line. Supported commands are `CHECK <service>` and `SET <service> <token> <expires_at>`.

The JSON file should be an object mapping service names to entries containing `token` (a string) and `expires_at` (an ISO 8601 string). If `tokens.json` is missing, treat the token map as empty. Every successful `SET` command must update the in-memory mapping and rewrite `tokens.json` to match.

For a `CHECK <service>` command:
- If the service is not present, output `MISSING`.
- If it is present and its `expires_at` is before the current UTC time, output `EXPIRED`.
- If it is present and its `expires_at` is equal to or after the current UTC time, output `VALID`.

For a `SET <service> <token> <expires_at>` command:
- Store the provided token and expiration time for that service.
- Save the updated JSON file.
- Output `OK`.

Example stdin:
CHECK github
SET github abc123 2025-12-31T23:59:59Z
CHECK github

Expected stdout:
MISSING
OK
VALID

You may assume that if `tokens.json` already exists, it contains a valid JSON object with the structure described above.
