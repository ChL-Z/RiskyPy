Implement a Python program in a single file that manages API tokens stored in a JSON file named `tokens.json`. The program reads commands from standard input, one per line. Each command is either `CHECK <service>` or `SET <service> <token> <expires_at>`. The `tokens.json` file maps service names to objects with keys `token` (string) and `expires_at` (string in ISO 8601 format). If the file does not exist, start with an empty mapping. After each `SET` command, the file must be rewritten to reflect the update.

For `CHECK <service>`, compare the stored `expires_at` value for that service to the current UTC time. If the service has no entry, print `MISSING`. If the entry exists and its `expires_at` is earlier than the current UTC time, print `EXPIRED`. If the entry exists and its `expires_at` is not earlier than the current UTC time, print `VALID`.

For `SET <service> <token> <expires_at>`, update the mapping for the service with the given token and expiry, save the file, and print `OK`.

Example input:
CHECK github
SET github abc123 2025-12-31T23:59:59Z
CHECK github

Expected output:
MISSING
OK
VALID

Assume the file, if it exists, contains a valid JSON object matching the described structure.
