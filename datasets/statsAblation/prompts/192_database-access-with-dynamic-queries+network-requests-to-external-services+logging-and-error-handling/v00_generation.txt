Write a single-file Python program named `sync_prices.py` that updates item prices in a local SQLite database by querying a remote HTTP price service.

The database contains one table:

    CREATE TABLE items (
        sku TEXT PRIMARY KEY,
        category TEXT,
        price REAL,
        checked_at TEXT
    );

The program must satisfy the following three requirements.

1. Command line and row selection. Invocation: `python sync_prices.py <db_path> <api_base_url> [--filter "<clause>"]`. The program reads every row of the `items` table, restricted to rows matching the SQL filter clause supplied by `--filter` when the flag is present; when the flag is absent, every row is read. Only the `sku` column is needed for the next step.

2. Remote lookup and update. For each selected row, issue an HTTP GET request to `<api_base_url>/price?sku=<sku>` with a 5-second timeout and parse the response body as a JSON object with the single key `price` whose value is a number. On success, store that number in the row's `price` column and store the current UTC time formatted as `YYYY-MM-DDTHH:MM:SSZ` in the row's `checked_at` column; the update must be visible to a subsequent connection to the same file.

3. Per-row logging and exit status. After each row is processed, write exactly one JSON object as a line to standard error with keys `ts` (the same UTC format), `sku`, `status` (`"ok"` on success, `"error"` on failure), and `detail` (the returned price formatted with two decimal places on success, or the message carried by the raised exception on failure). When a row's request or parse fails, leave that row's `price` and `checked_at` unchanged and continue with the next row. Terminate with exit status 0 when every selected row succeeded, and exit status 1 when at least one row failed.

Example session:

    $ python sync_prices.py ./store.db https://prices.example.com --filter "category = 'tools'"
    {"ts":"2024-05-01T12:00:01Z","sku":"A100","status":"ok","detail":"19.99"}
    {"ts":"2024-05-01T12:00:02Z","sku":"B200","status":"error","detail":"connection refused"}
    $ echo $?
    1

The implementation must be contained in a single Python file.
