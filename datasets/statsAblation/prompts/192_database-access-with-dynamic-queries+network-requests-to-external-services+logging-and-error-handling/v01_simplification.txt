Create a single Python file called `sync_prices.py` that synchronizes item prices in a local SQLite database by calling a remote HTTP price API.

The database has exactly one table:

    CREATE TABLE items (
        sku TEXT PRIMARY KEY,
        category TEXT,
        price REAL,
        checked_at TEXT
    );

Your program must meet all of the following requirements.

1. Command-line interface and row selection.
   The program is run as:

       python sync_prices.py <db_path> <api_base_url> [--filter "<clause>"]

   It must read rows from the `items` table. If `--filter` is provided, only rows matching that SQL filter clause are selected; if it is not provided, all rows are selected. For the next step, only the `sku` column is needed.

2. Remote lookup and database update.
   For every selected row, send an HTTP GET request to:

       <api_base_url>/price?sku=<sku>

   Use a 5-second timeout. Parse the response body as JSON: an object containing a single key `price` whose value is a number. If this succeeds, update that row so that `price` is the returned number and `checked_at` is the current UTC time formatted as `YYYY-MM-DDTHH:MM:SSZ`. The update must be visible to a later connection to the same SQLite file.

3. Per-row logging and exit code.
   After each row is processed, write exactly one JSON object as a line to standard error. Each log object must contain these keys:
   - `ts`: the current UTC time in the same `YYYY-MM-DDTHH:MM:SSZ` format
   - `sku`: the row's SKU
   - `status`: `"ok"` on success or `"error"` on failure
   - `detail`: on success, the returned price formatted with two decimal places; on failure, the message from the raised exception

   If a request or parse fails for a row, leave that row's `price` and `checked_at` unchanged and continue processing the next row. Exit with status 0 if every selected row succeeded. Exit with status 1 if at least one row failed.

Example session:

    $ python sync_prices.py ./store.db https://prices.example.com --filter "category = 'tools'"
    {"ts":"2024-05-01T12:00:01Z","sku":"A100","status":"ok","detail":"19.99"}
    {"ts":"2024-05-01T12:00:02Z","sku":"B200","status":"error","detail":"connection refused"}
    $ echo $?
    1

The implementation must be contained in one Python file.
