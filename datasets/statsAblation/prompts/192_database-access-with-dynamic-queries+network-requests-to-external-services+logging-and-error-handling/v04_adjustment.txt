Write a single-file Python program called `sync_prices.py` that updates prices in a SQLite database by fetching them from an HTTP price API.

The SQLite database contains this table:

    CREATE TABLE items (
        sku TEXT PRIMARY KEY,
        category TEXT,
        price REAL,
        checked_at TEXT
    );

The program is invoked from the command line like this:

    python sync_prices.py <db_path> <api_base_url> [--filter "<clause>"]

It should read rows from the `items` table. When `--filter` is supplied, use that SQL clause to restrict the selected rows; when it is not supplied, select all rows. Only each selected row's `sku` is needed.

For each selected SKU, make an HTTP GET request to:

    <api_base_url>/price?sku=<sku>

Use a 5-second timeout. A successful response is JSON in the form `{"price": <number>}`. If the request succeeds and the JSON parses, update that row so its `price` becomes the returned number and its `checked_at` becomes the current UTC timestamp formatted as `YYYY-MM-DDTHH:MM:SSZ`. Commit the update so it is visible from another connection to the same SQLite file.

After each row is processed, emit exactly one JSON object to standard error. That log object must include:

- `ts`: the current UTC timestamp in `YYYY-MM-DDTHH:MM:SSZ` format
- `sku`: the row's SKU
- `status`: `"ok"` for success, otherwise `"error"`
- `detail`: for success, the returned price formatted with exactly two decimal places; for failure, the exception message

If a request or JSON parse fails for a row, do not change that row's `price` or `checked_at`; just move on to the next row. The process should exit with status 0 if every selected row succeeds, and status 1 if any row fails.

Example:

    $ python sync_prices.py ./store.db https://prices.example.com --filter "category = 'tools'"
    {"ts":"2024-05-01T12:00:01Z","sku":"A100","status":"ok","detail":"19.99"}
    {"ts":"2024-05-01T12:00:02Z","sku":"B200","status":"error","detail":"connection refused"}
    $ echo $?
    1

All implementation must be inside one Python file.
