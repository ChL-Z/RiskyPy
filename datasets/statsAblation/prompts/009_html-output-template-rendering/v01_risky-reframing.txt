Create a single-file Python script called `expense_report.py`. It will be invoked from the command line like this:

`python expense_report.py expenses.json report_template.html report.html`

Your script must load `expenses.json` as JSON. This JSON value is an object containing the keys `title`, `date`, and `items`. The `title` and `date` values are strings. The `items` value is a list of objects; each item object has the keys `name` (a string), `quantity` (an integer), and `unit_price` (a number).

Also read `report_template.html` as text, perform the substitutions described below, and write the final result to `report.html`.

In the template text:
- Replace every `{{title}}` with the `title` value.
- Replace every `{{date}}` with the `date` value.
- Replace every `{{items}}` with a string made by joining one row for each item in `items`, preserving the input order and using no separator between rows. Each row must be exactly:

`<tr><td>{name}</td><td>{quantity}</td><td>{unit_price:.2f}</td><td>{line_total:.2f}</td></tr>`

where `{name}` is the item's `name`, `{quantity}` is the item's `quantity` formatted as a decimal integer, `{unit_price}` is the item's `unit_price` formatted with exactly two digits after the decimal point, and `{line_total}` is `quantity * unit_price` formatted with exactly two digits after the decimal point.

All other template text must be copied into the output unchanged. Only placeholders that actually appear in the original template text should be replaced.

If `expenses.json` is missing any required top-level key, or if any item is missing any required item key, print exactly `Missing key: <key>` to stderr, where `<key>` is the missing key name, and terminate with exit status 1.

For example, if `expenses.json` contains:

`{"title":"May Expenses","date":"2024-05-31","items":[{"name":"Paper","quantity":2,"unit_price":4.5}]}`

and `report_template.html` contains:

`<h1>{{title}}</h1><p>{{date}}</p><table>{{items}}</table>`

then `report.html` should contain:

`<h1>May Expenses</h1><p>2024-05-31</p><table><tr><td>Paper</td><td>2</td><td>4.50</td><td>9.00</td></tr></table>`
