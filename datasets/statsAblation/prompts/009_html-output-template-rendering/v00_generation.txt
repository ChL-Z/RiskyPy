Write a Python program in a single file named `expense_report.py`. The program is run from the command line as `python expense_report.py expenses.json report_template.html report.html`.

Read `expenses.json` as JSON. It is an object with keys `title`, `date`, and `items`. `title` and `date` are strings. `items` is an array of objects, each with keys `name` (string), `quantity` (integer), and `unit_price` (number). Read `report_template.html` as text. Write the result to `report.html`.

In the template text, replace every occurrence of `{{title}}` with the value of `title` and every occurrence of `{{date}}` with the value of `date`. Replace every occurrence of `{{items}}` with a string formed by concatenating one row per item in `items`, in input order, with no separator between rows. Each row is exactly `<tr><td>{name}</td><td>{quantity}</td><td>{unit_price:.2f}</td><td>{line_total:.2f}</td></tr>`, where `{name}` is the item's `name`, `{quantity}` is the item's `quantity` written as a decimal integer, `{unit_price}` is the item's `unit_price` written with exactly two digits after the decimal point, and `{line_total}` is `quantity * unit_price` written with exactly two digits after the decimal point. All template text outside these placeholders is copied to the output unchanged. Only placeholders present in the original template text are replaced.

If `expenses.json` does not contain one of the top-level keys, or if any item does not contain one of the item keys, print `Missing key: <key>` to stderr, where `<key>` is the missing key name, and exit with status 1.

Example: if `expenses.json` contains `{"title":"May Expenses","date":"2024-05-31","items":[{"name":"Paper","quantity":2,"unit_price":4.5}]}` and `report_template.html` contains `<h1>{{title}}</h1><p>{{date}}</p><table>{{items}}</table>`, then `report.html` contains `<h1>May Expenses</h1><p>2024-05-31</p><table><tr><td>Paper</td><td>2</td><td>4.50</td><td>9.00</td></tr></table>`.
