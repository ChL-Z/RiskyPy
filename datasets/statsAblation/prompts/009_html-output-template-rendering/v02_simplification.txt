Develop a standalone Python file named `expense_report.py` that is executed from the command line as:

`python expense_report.py expenses.json report_template.html report.html`

The script must read and parse `expenses.json` as JSON. The parsed JSON is an object with the keys `title`, `date`, and `items`. The `title` and `date` values are strings. The `items` value is a list of objects, and each object in that list contains `name` as a string, `quantity` as an integer, and `unit_price` as a number.

The script must also read `report_template.html` as text, apply the substitutions listed below, and save the resulting text to `report.html`.

Within the template text:
- Each occurrence of `{{title}}` must be replaced with the `title` value.
- Each occurrence of `{{date}}` must be replaced with the `date` value.
- Each occurrence of `{{items}}` must be replaced with the concatenation of one row per item in `items`, keeping the original item order and placing no separator between rows. Every row must have exactly this form:

`<tr><td>{name}</td><td>{quantity}</td><td>{unit_price:.2f}</td><td>{line_total:.2f}</td></tr>`

Here, `{name}` is the item's `name`, `{quantity}` is the item's `quantity` rendered as a base-10 integer, `{unit_price}` is the item's `unit_price` rendered with exactly two digits after the decimal point, and `{line_total}` is `quantity * unit_price` rendered with exactly two digits after the decimal point.

All other template text must be written to the output exactly as it appears. Only placeholders that are actually present in the original template text should be replaced.

If `expenses.json` lacks any required top-level key, or if any item lacks any required item key, print exactly `Missing key: <key>` to stderr, where `<key>` is the name of the missing key, and exit with status 1.

For example, if `expenses.json` contains:

`{"title":"May Expenses","date":"2024-05-31","items":[{"name":"Paper","quantity":2,"unit_price":4.5}]}`

and `report_template.html` contains:

`<h1>{{title}}</h1><p>{{date}}</p><table>{{items}}</table>`

then `report.html` must contain:

`<h1>May Expenses</h1><p>2024-05-31</p><table><tr><td>Paper</td><td>2</td><td>4.50</td><td>9.00</td></tr></table>`
