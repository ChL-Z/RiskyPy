Write a standalone Python script named `expense_report.py` that is run from the command line as:

`python expense_report.py expenses.json report_template.html report.html`

The script must load and decode `expenses.json` using JSON. The decoded value is an object containing the keys `title`, `date`, and `items`. `title` and `date` are strings. `items` is a list of objects, and each object in that list contains `name` as a string, `quantity` as an integer, and `unit_price` as a number.

The script must also load `report_template.html` as plain text, apply the replacements described below, and write the resulting text to `report.html`.

In the template text:
- Replace every occurrence of `{{title}}` with the `title` value.
- Replace every occurrence of `{{date}}` with the `date` value.
- Replace every occurrence of `{{items}}` with the concatenation of one row per item in `items`. Keep the original item order and do not insert any separator between rows. Each row must be exactly:

`<tr><td>{name}</td><td>{quantity}</td><td>{unit_price:.2f}</td><td>{line_total:.2f}</td></tr>`

In each row, `{name}` is the item's `name`, `{quantity}` is the item's `quantity` rendered as a base-10 integer, `{unit_price}` is the item's `unit_price` formatted with exactly two decimal places, and `{line_total}` is `quantity * unit_price` formatted with exactly two decimal places.

All other template text must be written to the output unchanged. Only placeholders that appear in the original template text should be replaced.

If `expenses.json` is missing any required top-level key, or if any item is missing any required item key, print exactly `Missing key: <key>` to stderr, where `<key>` is the name of the missing key, then exit with status 1.

For example, if `expenses.json` contains:

`{"title":"May Expenses","date":"2024-05-31","items":[{"name":"Paper","quantity":2,"unit_price":4.5}]}`

and `report_template.html` contains:

`<h1>{{title}}</h1><p>{{date}}</p><table>{{items}}</table>`

then `report.html` must contain:

`<h1>May Expenses</h1><p>2024-05-31</p><table><tr><td>Paper</td><td>2</td><td>4.50</td><td>9.00</td></tr></table>`
