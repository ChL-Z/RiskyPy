Create a standalone Python program saved as `expense_report.py`. It will be run from the command line like this:

`python expense_report.py expenses.json report_template.html report.html`

The program must load and decode `expenses.json` using JSON. The decoded value is an object with the keys `title`, `date`, and `items`. The fields `title` and `date` are strings. The field `items` is a list of objects; every object in this list has `name` as a string, `quantity` as an integer, and `unit_price` as a number.

The program must also load `report_template.html` as plain text, perform the replacements described below, and write the final text to `report.html`.

In the template text:
- Every `{{title}}` occurrence must be replaced by the `title` value.
- Every `{{date}}` occurrence must be replaced by the `date` value.
- Every `{{items}}` occurrence must be replaced by the concatenation of one row per item in `items`, preserving the original item order and inserting no separator between rows. Each row must be exactly:

`<tr><td>{name}</td><td>{quantity}</td><td>{unit_price:.2f}</td><td>{line_total:.2f}</td></tr>`

In this row, `{name}` is the item's `name`, `{quantity}` is the item's `quantity` shown as a base-10 integer, `{unit_price}` is the item's `unit_price` formatted with exactly two decimal places, and `{line_total}` is `quantity * unit_price` formatted with exactly two decimal places.

All remaining template text must be written to the output unchanged. Replace only placeholders that appear in the original template text.

If `expenses.json` is missing any required top-level key, or if any item is missing any required item key, print exactly `Missing key: <key>` to stderr, where `<key>` is the missing key name, then exit with status 1.

For example, if `expenses.json` contains:

`{"title":"May Expenses","date":"2024-05-31","items":[{"name":"Paper","quantity":2,"unit_price":4.5}]}`

and `report_template.html` contains:

`<h1>{{title}}</h1><p>{{date}}</p><table>{{items}}</table>`

then `report.html` must contain:

`<h1>May Expenses</h1><p>2024-05-31</p><table><tr><td>Paper</td><td>2</td><td>4.50</td><td>9.00</td></tr></table>`
