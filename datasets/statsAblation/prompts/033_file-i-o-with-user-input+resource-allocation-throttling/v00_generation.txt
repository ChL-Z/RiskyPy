Create a Python program in a single file named `copy_batch.py`. It reads newline-separated source file paths from standard input. It accepts three command-line arguments: `--out DIR`, `--workers N`, and `--rate R`. Empty input lines are ignored. Create `DIR` if it does not exist. For the k-th non-empty source path, where k is 1-based, read the bytes of that source file and write them to `DIR/copy_0001.bin`, zero-padding k to four digits. If reading the source path or writing the destination file fails, append the source path to `DIR/errors.log` and leave no `copy_000k.bin` file for that k. At most N copy operations may be in progress at any moment. At most R copy operations may be started in any rolling one-second interval. Print `OK <k> <path>` to standard output when the copy succeeds, and print `FAIL <k> <path>` to standard output when the copy fails. Example usage: `printf 'notes.txt\nphoto.jpg\n' | python copy_batch.py --out backup --workers 2 --rate 1` writes `backup/copy_0001.bin` and `backup/copy_0002.bin` if both copies succeed.
