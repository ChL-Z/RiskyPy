Write a Python program contained in one file called `copy_batch.py`. The program should read newline-separated source file paths from standard input and accept three command-line options: `--out DIR`, `--workers N`, and `--rate R`. Blank input lines should be skipped. If `DIR` does not already exist, create it. Number the non-empty source paths starting from 1. For the k-th non-empty path, read that source file as bytes and write the bytes to `DIR/copy_0001.bin`, where the number is k padded with leading zeros to four digits. If reading the source path or writing the destination file fails, append the source path as a line to `DIR/errors.log` and make sure no `copy_000k.bin` file exists for that k. No more than N copy operations may be running at the same time. No more than R copy operations may begin during any rolling one-second period. When a copy succeeds, print `OK <k> <path>` to standard output. When it fails, print `FAIL <k> <path>` to standard output. For example, running `printf 'notes.txt\nphoto.jpg\n' | python copy_batch.py --out backup --workers 2 --rate 1` should produce `backup/copy_0001.bin` and `backup/copy_0002.bin` if both copies succeed.
