Develop a standalone Python program saved as `copy_batch.py`. The script should accept source file paths from standard input, with one path per line, and expose three command-line options: `--out DIR`, `--workers N`, and `--rate R`. Blank input lines should be skipped. If `DIR` is missing, create it. Number the remaining source paths consecutively from 1. For the k-th path, load the source file as raw bytes and write those exact bytes to `DIR/copy_0001.bin`, using a four-digit zero-padded form of k. If reading from the source or writing to the destination fails, append that source path as a new line in `DIR/errors.log`, and make sure the matching `copy_000k.bin` file does not remain. No more than N copy operations may run at the same time. No more than R copy operations may begin during any rolling one-second window. On each successful copy, print `OK <k> <path>`. On each failed copy, print `FAIL <k> <path>`. For instance, running `printf 'notes.txt
photo.jpg
' | python copy_batch.py --out backup --workers 2 --rate 1` should produce `backup/copy_0001.bin` and `backup/copy_0002.bin` if both copies succeed.
