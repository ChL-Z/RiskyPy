Create a single-file Python script named `copy_batch.py`. It must read source file paths from standard input, one path per line, and support three command-line arguments: `--out DIR`, `--workers N`, and `--rate R`. Ignore empty input lines. If `DIR` does not exist, create it. Assign sequential numbers to the non-empty source paths starting at 1. For the k-th such path, read the source file as raw bytes and save those bytes as `DIR/copy_0001.bin`, where `k` is zero-padded to four digits. If reading the source or writing the destination fails, append the source path as a new line to `DIR/errors.log`, and ensure that the corresponding `copy_000k.bin` file is not present. At most N copy operations may execute concurrently. At most R copy operations may be started within any rolling one-second interval. For every successful copy, print `OK <k> <path>`. For every failed copy, print `FAIL <k> <path>`. For example, `printf 'notes.txt
photo.jpg
' | python copy_batch.py --out backup --workers 2 --rate 1` should result in `backup/copy_0001.bin` and `backup/copy_0002.bin` when both copies succeed.
