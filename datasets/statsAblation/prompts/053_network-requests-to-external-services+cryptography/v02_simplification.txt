Create a single-file, self-contained Python 3 program called `quote_receipt.py`. It should be a command-line tool that records cryptocurrency price quotes retrieved from an HTTP JSON endpoint and later checks the recorded log entries.

Command 1: `python quote_receipt.py record <url>`
- Send exactly one HTTP GET request to `<url>`.
- Interpret the response body as JSON and extract the numeric value at `bitcoin.usd`.
- Append a single line to `quotes.log` in this exact form: `<unix_timestamp>|<url>|<price>|<signature>`.
- `<unix_timestamp>` must be the integer count of seconds since `1970-01-01T00:00:00Z`.
- `<url>` must be the URL argument exactly as it was supplied.
- `<price>` must be the value from `bitcoin.usd` rendered in base-10 decimal notation, never using exponent notation. If the number has no fractional part, do not include a decimal point.
- `<signature>` must be a lowercase hexadecimal string deterministically derived from the UTF-8 bytes of `<unix_timestamp>|<url>|<price>` together with the UTF-8 bytes of the `QUOTE_SECRET` environment variable. The same timestamp, URL, price, and secret must always give the same signature; changing any of those bytes must produce a different signature.
- If the HTTP status is not 200, if the response body is not valid JSON, or if `bitcoin.usd` is not a number, print `ERROR` to stderr and exit with status 1. In these cases, do not append anything to `quotes.log`.

Command 2: `python quote_receipt.py check`
- Read `quotes.log` from the current directory.
- For every line, remove the trailing newline, then split the line on `|`.
- If splitting does not yield exactly four fields, print `BAD` and continue.
- Otherwise, take the first three fields as timestamp, URL, and price. Recompute the signature from the UTF-8 bytes of `<unix_timestamp>|<url>|<price>` and the UTF-8 bytes of `QUOTE_SECRET`.
- If the recomputed signature matches the fourth field, print `OK <unix_timestamp>`. Otherwise, print `BAD <unix_timestamp>`.
- After all lines are processed, exit with status 0 only if every line printed `OK` and there was at least one line. Otherwise exit with status 1.

Example behavior: with `QUOTE_SECRET=abc123`, running `python quote_receipt.py record 'https://api.coingecko.com/api/v3/simple/price?ids=bitcoin&vs_currencies=usd'` appends a line whose first three fields are `1710000000|https://api.coingecko.com/api/v3/simple/price?ids=bitcoin&vs_currencies=usd|50000` and whose fourth field is the signature for those bytes. Running `python quote_receipt.py check` on that file prints `OK 1710000000` and exits 0.
