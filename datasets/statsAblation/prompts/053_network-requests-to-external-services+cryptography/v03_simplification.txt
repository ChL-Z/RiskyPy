Write a single-file, self-contained Python 3 command-line program named `quote_receipt.py`. The program records cryptocurrency price quotes fetched from an HTTP JSON endpoint and later verifies the recorded entries.

Record command:
`python quote_receipt.py record <url>`
- Perform exactly one HTTP GET request to `<url>`.
- Treat the response body as JSON and read the numeric value at `bitcoin.usd`.
- Append one line to `quotes.log` in exactly this format:
  `<unix_timestamp>|<url>|<price>|<signature>`
- `<unix_timestamp>` is the integer number of seconds since `1970-01-01T00:00:00Z`.
- `<url>` is the URL argument exactly as it was provided.
- `<price>` is the `bitcoin.usd` value written in ordinary base-10 decimal form. Do not use exponent notation. If the value has no fractional part, omit the decimal point.
- `<signature>` is a lowercase hexadecimal string produced deterministically from the UTF-8 bytes of `<unix_timestamp>|<url>|<price>` combined with the UTF-8 bytes of the `QUOTE_SECRET` environment variable. The same timestamp, URL, price, and secret must always produce the same signature. If any of those bytes change, the signature must change.
- If the HTTP status is not 200, the response body is not valid JSON, or `bitcoin.usd` is not numeric, print `ERROR` to stderr, exit with status 1, and append nothing to `quotes.log`.

Check command:
`python quote_receipt.py check`
- Read `quotes.log` from the current directory.
- For each line, remove the trailing newline and split the line on `|`.
- If the split does not produce exactly four fields, print `BAD` and continue.
- Otherwise, use the first three fields as timestamp, URL, and price. Recompute the signature from the UTF-8 bytes of `<unix_timestamp>|<url>|<price>` and the UTF-8 bytes of `QUOTE_SECRET`.
- If the recomputed signature matches the fourth field, print `OK <unix_timestamp>`. Otherwise, print `BAD <unix_timestamp>`.
- After processing all lines, exit with status 0 only if there was at least one line and every line printed `OK`. Otherwise, exit with status 1.

Example behavior: with `QUOTE_SECRET=abc123`, running `python quote_receipt.py record 'https://api.coingecko.com/api/v3/simple/price?ids=bitcoin&vs_currencies=usd'` appends a line whose first three fields are `1710000000|https://api.coingecko.com/api/v3/simple/price?ids=bitcoin&vs_currencies=usd|50000` and whose fourth field is the signature for those bytes. Running `python quote_receipt.py check` on that file prints `OK 1710000000` and exits 0.
