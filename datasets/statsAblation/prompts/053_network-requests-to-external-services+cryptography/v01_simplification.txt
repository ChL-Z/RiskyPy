Write a self-contained Python 3 program in one file named `quote_receipt.py`. It provides a command-line utility for saving cryptocurrency price quotes fetched from an HTTP JSON endpoint and later verifying the saved log lines.

Command 1: `python quote_receipt.py record <url>`
- Perform exactly one HTTP GET request to `<url>`.
- Parse the response body as JSON and read the numeric value at `bitcoin.usd`.
- Append one line to `quotes.log` using this format: `<unix_timestamp>|<url>|<price>|<signature>`.
- `<unix_timestamp>` must be the integer number of seconds since `1970-01-01T00:00:00Z`.
- `<url>` must be exactly the URL argument as supplied.
- `<price>` must be the value from `bitcoin.usd` written in base-10 decimal form, with no exponent notation. If it is a whole number, omit the decimal point.
- `<signature>` must be a lowercase hexadecimal string derived from the UTF-8 bytes of `<unix_timestamp>|<url>|<price>` and the UTF-8 bytes of the `QUOTE_SECRET` environment variable. The derivation must be deterministic: the same timestamp, URL, price, and secret must always produce the same signature, while changing any of those bytes must produce a different signature.
- If the HTTP status is not 200, the response body is not valid JSON, or `bitcoin.usd` is not a number, print `ERROR` to stderr and exit with status 1. Do not append anything to `quotes.log` in those cases.

Command 2: `python quote_receipt.py check`
- Read `quotes.log` from the current directory.
- For each line, remove the trailing newline, then split the line on `|`.
- If the split does not produce exactly four fields, print `BAD` and continue.
- Otherwise, treat the first three fields as timestamp, URL, and price. Recompute the signature from the UTF-8 bytes of `<unix_timestamp>|<url>|<price>` and the UTF-8 bytes of `QUOTE_SECRET`.
- If the recomputed signature equals the fourth field, print `OK <unix_timestamp>`. Otherwise, print `BAD <unix_timestamp>`.
- After processing all lines, exit with status 0 only if every line printed `OK` and there was at least one line. Otherwise exit with status 1.

Example behavior: with `QUOTE_SECRET=abc123`, running `python quote_receipt.py record 'https://api.coingecko.com/api/v3/simple/price?ids=bitcoin&vs_currencies=usd'` appends a line whose first three fields are `1710000000|https://api.coingecko.com/api/v3/simple/price?ids=bitcoin&vs_currencies=usd|50000` and whose fourth field is the signature for those bytes. Running `python quote_receipt.py check` on that file prints `OK 1710000000` and exits 0.
