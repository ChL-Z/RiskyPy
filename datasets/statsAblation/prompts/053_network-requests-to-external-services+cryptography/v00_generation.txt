Create a single Python file named `quote_receipt.py`. It must be runnable with Python 3 and contain all code for the utility described below.

The utility records cryptocurrency price quotes from an HTTP JSON endpoint and later checks the recorded lines.

1. `python quote_receipt.py record <url>` sends one HTTP GET request to `<url>`, reads the response body as JSON, and extracts the numeric value at `bitcoin.usd`. It appends one line to `quotes.log` in the format `<unix_timestamp>|<url>|<price>|<signature>`. `<unix_timestamp>` is the integer number of seconds since 1970-01-01T00:00:00Z. `<url>` is the URL argument exactly as provided. `<price>` is the value from `bitcoin.usd` written in base 10 without exponent notation; if the value is a whole number, write it without a decimal point. `<signature>` is a lowercase hexadecimal string computed from the UTF-8 bytes of `<unix_timestamp>|<url>|<price>` and the UTF-8 bytes of the `QUOTE_SECRET` environment variable. The same timestamp, URL, price, and secret must produce the same signature; changing any of those bytes must produce a different signature. If the HTTP response status is not 200, the response body is not valid JSON, or `bitcoin.usd` is not a number, print `ERROR` to stderr and exit with status 1 without writing to `quotes.log`.

2. `python quote_receipt.py check` reads `quotes.log` from the current directory. For each line, strip the trailing newline, then split the line on `|`. If there are not exactly four fields, print `BAD` and continue. Otherwise, let the first three fields be the timestamp, URL, and price. Recompute the signature from the UTF-8 bytes of `<unix_timestamp>|<url>|<price>` and the UTF-8 bytes of `QUOTE_SECRET`. If the recomputed signature equals the fourth field, print `OK <unix_timestamp>`; otherwise print `BAD <unix_timestamp>`. After all lines, exit with status 0 if every line printed `OK` and there was at least one line; otherwise exit with status 1.

Example: with `QUOTE_SECRET=abc123`, running `python quote_receipt.py record 'https://api.coingecko.com/api/v3/simple/price?ids=bitcoin&vs_currencies=usd'` appends a line whose first three fields are `1710000000|https://api.coingecko.com/api/v3/simple/price?ids=bitcoin&vs_currencies=usd|50000` and whose fourth field is the signature for those bytes. Running `python quote_receipt.py check` on that file prints `OK 1710000000` and exits 0.
