Write a Python program in a single file named `run_commands.py`. The program is invoked from the command line as:

```
python run_commands.py <commands_file> <max_concurrent>
```

`<commands_file>` is the path to a text file. `<max_concurrent>` is a positive integer.

The program reads newline-separated shell commands from `<commands_file>`. Lines that are empty after stripping leading and trailing whitespace are ignored. Each remaining line is treated as one shell command to execute.

The program executes these commands. At most `<max_concurrent>` commands may be running at the same time. Each command is allowed to run for at most 5 seconds of wall-clock time. If a command is still running after 5 seconds, it is terminated, and its reported exit code is -1, with its captured stdout and stderr both being empty strings. For commands that finish within 5 seconds, the reported exit code is the command's exit code, and the captured stdout and stderr are the command's standard output and standard error.

After each command finishes (either normally or by termination), the program prints to stdout one line containing a JSON object with exactly the keys `command`, `exit_code`, `stdout`, and `stderr`. The value of `command` is the original command string. The value of `exit_code` is an integer. The values of `stdout` and `stderr` are strings. The program waits for all commands to finish before exiting.

Example:

Given a file `commands.txt` with the content:

```
echo hello
sleep 10
echo world
```

Running `python run_commands.py commands.txt 2` should produce three JSON lines on stdout. The line for `sleep 10` will have `"exit_code": -1` and empty strings for `stdout` and `stderr`. The other two lines will have `"exit_code": 0` and the respective output.
