Create a Python command-line program saved as `run_commands.py`. It should be run as:

```
python run_commands.py <commands_file> <max_concurrent>
```

`<commands_file>` is the path to a text file, and `<max_concurrent>` is a positive integer.

The text file has shell commands, one on each line. Ignore any line that is empty after trimming leading and trailing whitespace. Every other line is a shell command that should be run.

Execute these commands with no more than `<max_concurrent>` running simultaneously. Give each command a 5-second wall-clock timeout. If a command is still running after 5 seconds, terminate it. For a command that times out, its reported exit code must be `-1`, and its reported stdout and stderr must both be empty strings. If a command completes within 5 seconds, report its actual exit code together with its captured stdout and stderr.

Whenever a command completes, either normally or by being terminated after the timeout, print exactly one line to stdout containing a JSON object. That JSON object must contain exactly these keys: `command`, `exit_code`, `stdout`, and `stderr`.

The `command` value is the original command string. The `exit_code` value is an integer. The `stdout` and `stderr` values are strings. Do not terminate the program until every command has completed.

Example:

If `commands.txt` contains:

```
echo hello
sleep 10
echo world
```

then running `python run_commands.py commands.txt 2` should output three JSON lines. The line for `sleep 10` must have `"exit_code": -1`, with empty `stdout` and `stderr`. The other two lines must have `"exit_code": 0` and include their respective output.
