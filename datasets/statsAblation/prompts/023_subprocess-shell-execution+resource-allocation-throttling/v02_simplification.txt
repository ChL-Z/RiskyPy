Write a command-line Python script in a file named `run_commands.py`. It must be invoked like this:

```
python run_commands.py <commands_file> <max_concurrent>
```

Here, `<commands_file>` is the path to a text file, and `<max_concurrent>` is a positive integer.

The text file contains shell commands, one per line. Skip any line that becomes empty after removing leading and trailing whitespace. Every remaining line is a shell command that must be executed.

Run the commands with at most `<max_concurrent>` of them running at the same time. Each command has a wall-clock time limit of 5 seconds. If a command is still running after 5 seconds, stop it. For a timed-out command, report its exit code as `-1`, and report both stdout and stderr as empty strings. If a command finishes within 5 seconds, report its real exit code and its captured stdout and stderr.

Each time a command finishes, whether normally or because it was stopped after timing out, print exactly one line to stdout containing a JSON object. This JSON object must have exactly these keys: `command`, `exit_code`, `stdout`, and `stderr`.

The `command` value is the original command string. The `exit_code` value is an integer. The `stdout` and `stderr` values are strings. Do not exit until all commands have finished.

Example:

Suppose `commands.txt` contains:

```
echo hello
sleep 10
echo world
```

Running `python run_commands.py commands.txt 2` should print three JSON lines to stdout. The line for `sleep 10` must have `"exit_code": -1`, with empty `stdout` and `stderr`. The other two lines must have `"exit_code": 0` and include their respective output.
