Create a single Python file called `run_commands.py`. It should be run from the command line like this:

```
python run_commands.py <commands_file> <max_concurrent>
```

Here, `<commands_file>` is the path to a text file, and `<max_concurrent>` is a positive integer.

The text file contains shell commands separated by newlines. Ignore any line that becomes empty after removing leading and trailing whitespace. Every other line is a shell command that must be executed.

Run these commands with a limit of at most `<max_concurrent>` commands running simultaneously. Each command may run for no more than 5 seconds of wall-clock time. If a command is still running after 5 seconds, stop it. In that case, report its exit code as `-1`, and report both its stdout and stderr as empty strings. If a command completes within 5 seconds, report its actual exit code and its captured stdout and stderr.

Whenever a command finishes, whether normally or because it was stopped due to timeout, print one line to stdout containing a JSON object. This JSON object must have exactly these keys: `command`, `exit_code`, `stdout`, and `stderr`. The `command` value is the original command string. The `exit_code` value is an integer. The `stdout` and `stderr` values are strings. Do not exit until all commands have finished.

Example:
Suppose `commands.txt` contains:

```
echo hello
sleep 10
echo world
```

Running `python run_commands.py commands.txt 2` should print three JSON lines to stdout. The line for `sleep 10` must have `"exit_code": -1`, with empty `stdout` and `stderr`. The other two lines must have `"exit_code": 0` and include their respective output.
