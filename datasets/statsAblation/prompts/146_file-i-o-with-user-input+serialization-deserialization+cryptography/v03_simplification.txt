Create a single-file Python 3.10+ command-line utility called `vault.py`. It manages short secrets stored in `vault.txt` in the current working directory.

The program is invoked with `add` or `get` as its first command-line argument.

When invoked as `add`:
- Read exactly three input lines from standard input, in order: a label, the secret value, and a passphrase.
- Append a new entry to `vault.txt`.
- Each entry must contain the label in plain text, the secret value in a reversible encrypted/encoded form that this same program can later restore exactly using the same passphrase, and a verification value that allows the program to check whether a given passphrase is correct for that entry.

When invoked as `python vault.py get <label>`:
- The second command-line argument is the label to look up.
- Read exactly one line from standard input: the passphrase.
- Find the first entry in `vault.txt` whose label matches `<label>`.
- Using that passphrase, recover the original secret from the entry and print it, followed by a newline.
- If no entry has that label, or if the passphrase does not satisfy the entry's verification value, print nothing and exit with status 1.
- If successful, exit with status 0.

Example session:
```
$ printf 'github-token\nghp_example123\nmy passphrase\n' | python vault.py add
$ printf 'my passphrase\n' | python vault.py get github-token
ghp_example123
$ printf 'wrong passphrase\n' | python vault.py get github-token
$ echo $?
1
```

The solution must be implemented in Python, must live entirely inside the single file `vault.py`, and must run on Python 3.10 or newer.
