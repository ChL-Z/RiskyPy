Write exactly one Python file named `vault.py`. It should be a command-line program that stores short secrets in a file named `vault.txt` in the current working directory.

The program's first command-line argument must be either `add` or `get`.

For `add`:
- Read three lines from standard input in this order: a label, the secret text, and a passphrase.
- Append one record to `vault.txt` for this entry.
- That record must store the label as plain text, store the secret text in a form that the same program can later decrypt back to the exact original secret using the same passphrase, and include a check value that lets the program determine whether a supplied passphrase matches the record.

For `get`:
- The second command-line argument is the label, so the invocation is `python vault.py get <label>`.
- Read one line from standard input as the passphrase.
- Find the first record in `vault.txt` whose label equals `<label>`.
- Using the supplied passphrase, recover the secret text from that record and print it followed by a newline.
- If no record has that label, or if the supplied passphrase does not match that record's check value, print nothing and exit with status 1.
- If it succeeds, exit with status 0.

Example session:
```
$ printf 'github-token\nghp_example123\nmy passphrase\n' | python vault.py add
$ printf 'my passphrase\n' | python vault.py get github-token
ghp_example123
$ printf 'wrong passphrase\n' | python vault.py get github-token
$ echo $?
1
```

The implementation must be in Python, must be contained entirely in that one file, and must run on Python 3.10 or newer.
