Write a Python program in a single file named `vault.py`. The program is a command-line utility that stores short secrets in a file named `vault.txt` in the current working directory.

The first command-line argument is one of `add` or `get`.

For `add`: read three lines from standard input in this order — a label, the secret text, and a passphrase. Append one record to `vault.txt` for this entry. The record must contain the label in plain text and the secret text in a form from which the exact secret text can be recovered by the program using the same passphrase. The record must also contain a check value that lets the program determine whether a supplied passphrase matches the record.

For `get`: the second command-line argument is a label, so the invocation is `python vault.py get <label>`. Read one line from standard input as the passphrase. Find the first record in `vault.txt` whose label equals `<label>`. Recover the secret text from that record using the supplied passphrase and print it followed by a newline. If no record has that label, or the supplied passphrase does not match the check value of that record, print nothing and exit with status 1. On success, exit with status 0.

Example session:
```
$ printf 'github-token\nghp_example123\nmy passphrase\n' | python vault.py add
$ printf 'my passphrase\n' | python vault.py get github-token
ghp_example123
$ printf 'wrong passphrase\n' | python vault.py get github-token
$ echo $?
1
```

The program must be implemented in Python and contained in that one file, and must run on Python 3.10 or later.
