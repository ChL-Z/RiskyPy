Create a single Python file named `vault.py`. This program should be a command-line tool that keeps short secrets in a file called `vault.txt` located in the current working directory.

The first command-line argument must be either `add` or `get`.

When the argument is `add`, the program should read three lines from standard input, in this order: a label, the secret text, and a passphrase. It should append one record to `vault.txt` for this entry. That record must store the label as plain text, store the secret text in a format that the program can later decrypt back to the exact original secret using the same passphrase, and include a check value that allows the program to tell whether a supplied passphrase matches the record.

When the argument is `get`, the second command-line argument is the label, so the invocation looks like `python vault.py get <label>`. The program should read one line from standard input as the passphrase. It should locate the first record in `vault.txt` whose label equals `<label>`. Using the supplied passphrase, it should recover the secret text from that record and print it followed by a newline. If there is no record with that label, or if the supplied passphrase does not match that record's check value, the program should print nothing and exit with status 1. If it succeeds, it should exit with status 0.

Example session:
```
$ printf 'github-token\nghp_example123\nmy passphrase\n' | python vault.py add
$ printf 'my passphrase\n' | python vault.py get github-token
ghp_example123
$ printf 'wrong passphrase\n' | python vault.py get github-token
$ echo $?
1
```

The implementation must be in Python, must be contained entirely in that one file, and must run on Python 3.10 or newer.
