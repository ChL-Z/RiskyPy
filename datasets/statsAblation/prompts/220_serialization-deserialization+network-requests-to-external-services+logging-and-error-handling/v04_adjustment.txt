Create a single-file Python script called `rate.py`. It must take exactly one command-line argument: a three-letter currency code, for example `EUR`. The script should perform an HTTP GET request to `https://api.frankfurter.app/latest?from=USD&to=<CODE>`, where `<CODE>` is replaced by the provided currency code. A valid API response is JSON in this form: `{"amount": 1.0, "base": "USD", "date": "2024-01-01", "rates": {"<CODE>": 0.12345}}`.

If the request succeeds and the JSON has the expected structure, the script must:

1. Print the exchange rate for `<CODE>` to stdout as a decimal number with exactly six digits after the decimal point, followed by a newline.
2. Overwrite `rate.cache` in the current working directory with a single UTF-8 line containing the response date in ISO-8601 `YYYY-MM-DD` format, one space, and the rate as a decimal number.

It must produce no other stdout output.

Treat the request or response as failed if any of these happens:

- The HTTP request raises a connection error.
- The HTTP status code is not 200.
- The response is not JSON with the required shape, including a missing `rates` object, a missing `<CODE>` key inside `rates`, or a `<CODE>` value that is not numeric.

On any failure, the script must try to read `rate.cache` if it exists. If the cache can be read, it must print the cached rate to stdout in the same format: a decimal number with exactly six digits after the decimal point, followed by a newline. It must also write a warning to stderr.

If `rate.cache` does not exist or cannot be read, the script must write an error to stderr and exit with status code 1.

Every warning or error written to stderr must be exactly one line in this format:

`YYYY-MM-DDTHH:MM:SS LEVEL message`

`LEVEL` must be either `WARNING` or `ERROR`, and `message` must include the currency code and the reason for the log entry. If the operation succeeds, the script must log nothing.

For example, running `python rate.py EUR` while the service is available might print `0.912345` and write `2024-01-01 0.912345` to `rate.cache`. If the service cannot be reached but `rate.cache` already contains `2024-01-01 0.912345`, the script should print `0.912345` and emit a line such as `2024-01-01T12:00:00 WARNING EUR: connection error, using cached rate` to stderr.
