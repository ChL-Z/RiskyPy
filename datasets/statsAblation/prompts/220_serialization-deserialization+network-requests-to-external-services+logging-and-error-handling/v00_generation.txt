Write a Python program in a single file named `rate.py`. The program accepts exactly one command-line argument: a three-letter currency code (for example, `EUR`). It sends an HTTP GET request to `https://api.frankfurter.app/latest?from=USD&to=<CODE>` where `<CODE>` is the argument. The service returns a JSON document with this shape: `{"amount": 1.0, "base": "USD", "date": "2024-01-01", "rates": {"<CODE>": 0.12345}}`. On a successful response, print the rate for `<CODE>` to stdout as a decimal number with exactly six digits after the decimal point, followed by a newline. Then overwrite a file named `rate.cache` in the current working directory with a single UTF-8 line: the ISO-8601 date from the response (`YYYY-MM-DD`), a single space, and the rate as a decimal number. Do not print anything else to stdout.

If the HTTP request fails (connection error or HTTP status other than 200), or if the response is not a JSON document with the shape above (missing `rates` key, missing the `<CODE>` key under `rates`, or the value under that key is not a number), then read `rate.cache` if it exists, print the cached rate to stdout in the same format (six digits after the decimal point), and log a warning to stderr. If `rate.cache` does not exist or cannot be read, log an error to stderr and exit with status code 1.

Log every warning and error to stderr as a single line in the format `YYYY-MM-DDTHH:MM:SS LEVEL message`, where `LEVEL` is `WARNING` or `ERROR`, and `message` includes the currency code and the reason for the log entry. On success, do not log anything. For example, running `python rate.py EUR` when the service is reachable prints `0.912345` and writes `2024-01-01 0.912345` to `rate.cache`. If the service is unreachable and `rate.cache` already contains `2024-01-01 0.912345`, the program prints `0.912345` and emits a line like `2024-01-01T12:00:00 WARNING EUR: connection error, using cached rate` to stderr.
