Create a single Python file called `rate.py` that behaves as follows.

The script must take exactly one command-line argument: a currency code consisting of three letters, such as `EUR`. It should issue an HTTP GET request to:

`https://api.frankfurter.app/latest?from=USD&to=<CODE>`

where `<CODE>` is the supplied currency code. A successful API response is a JSON object shaped like:

`{"amount": 1.0, "base": "USD", "date": "2024-01-01", "rates": {"<CODE>": 0.12345}}`

When the request succeeds and the response has the expected structure, the program must:

1. Print the exchange rate for `<CODE>` to stdout as a decimal number with exactly six digits after the decimal point, followed by a newline.
2. Overwrite a file named `rate.cache` in the current working directory with one UTF-8 line containing the ISO-8601 date from the response in `YYYY-MM-DD` format, one space, and the rate as a decimal number.

Nothing else may be printed to stdout.

The request or response should be treated as failed if any of these occur:

- The HTTP request fails because of a connection error.
- The HTTP status code is anything other than 200.
- The response is not JSON with the required shape, including if `rates` is missing, the `<CODE>` key is missing from `rates`, or the value for `<CODE>` is not numeric.

In any failure case, the program must try to read `rate.cache` if it exists. If the cache is readable, it must print the cached rate to stdout using the same format as above: a decimal number with exactly six digits after the decimal point, followed by a newline. It must also write a warning to stderr.

If `rate.cache` does not exist or cannot be read, the program must write an error to stderr and exit with status code 1.

Every warning and error written to stderr must be a single line in this exact format:

`YYYY-MM-DDTHH:MM:SS LEVEL message`

Here `LEVEL` is either `WARNING` or `ERROR`, and `message` must include the currency code and the reason for the log entry. If the operation succeeds, the program must not log anything.

For example, running `python rate.py EUR` while the service is available might print `0.912345` and write `2024-01-01 0.912345` to `rate.cache`. If the service cannot be reached but `rate.cache` already contains `2024-01-01 0.912345`, the program should print `0.912345` and emit a line such as `2024-01-01T12:00:00 WARNING EUR: connection error, using cached rate` to stderr.
