Write a Python program in a single file named `rate.py` that does the following.

The program accepts exactly one command-line argument: a three-letter currency code, for example `EUR`. It should send an HTTP GET request to:

`https://api.frankfurter.app/latest?from=USD&to=<CODE>`

Replace `<CODE>` with the provided currency code. A valid API response is a JSON object like:

`{"amount": 1.0, "base": "USD", "date": "2024-01-01", "rates": {"<CODE>": 0.12345}}`

If the request succeeds and the JSON has the expected structure, the program must:

1. Write the exchange rate for `<CODE>` to stdout as a decimal number with exactly six digits after the decimal point, followed by a newline.
2. Replace the file `rate.cache` in the current working directory with a single UTF-8 line containing the response's ISO-8601 date in `YYYY-MM-DD` format, one space, and the rate as a decimal number.

No other output may be written to stdout.

Treat the request or response as failed if any of these happen:

- The HTTP request raises a connection error.
- The HTTP status code is not 200.
- The response is not JSON with the required shape. This includes a missing `rates` object, a missing `<CODE>` key inside `rates`, or a `<CODE>` value that is not numeric.

On any failure, the program must try to read `rate.cache` if it exists. If the cache can be read, it must print the cached rate to stdout using the same format as above: a decimal number with exactly six digits after the decimal point, followed by a newline. It must also write a warning to stderr.

If `rate.cache` does not exist or cannot be read, the program must write an error to stderr and exit with status code 1.

Every warning or error written to stderr must be one line in exactly this format:

`YYYY-MM-DDTHH:MM:SS LEVEL message`

`LEVEL` must be either `WARNING` or `ERROR`, and `message` must include the currency code and the reason for the log entry. If the operation succeeds, the program must not log anything.

Example: running `python rate.py EUR` while the service is available might print `0.912345` and write `2024-01-01 0.912345` to `rate.cache`. If the service cannot be reached but `rate.cache` already contains `2024-01-01 0.912345`, the program should print `0.912345` and emit a line such as `2024-01-01T12:00:00 WARNING EUR: connection error, using cached rate` to stderr.
