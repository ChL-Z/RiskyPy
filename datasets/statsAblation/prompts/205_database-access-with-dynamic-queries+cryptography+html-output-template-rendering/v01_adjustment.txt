Create a single Python file called report.py. It is invoked from the command line like this:

python report.py --db DATABASE --table TABLE --out OUTPUT.html --key KEYFILE [--filter NAME=VALUE ...]

Arguments:
- DATABASE: path to an SQLite database file.
- TABLE: name of a table inside that database.
- OUTPUT.html: file path to which the program writes its output.
- KEYFILE: path to a file whose raw bytes are used as the signing key.
- Each optional --filter NAME=VALUE supplies one condition.

Your program must do exactly the following:

1. Read from the database by selecting every column from TABLE. For each --filter NAME=VALUE, add a condition requiring column NAME to equal VALUE. If several filters are provided, a row must match all of them. Return columns in the same order as they are defined in the table.

2. Build an HTML document and save it to OUTPUT.html. The document should contain only a single <table> element, except for the signature comment required in step 3. The table's first row must be a header row: one <th> for each selected column, containing that column's name as text. Every later row must represent one query result row, with one <td> per column containing that row's value for the column converted to a string. Be sure to close the table element.

3. Directly after the closing </table> tag, append a newline and then exactly this kind of comment:

<!-- signature: HEX -->

Here HEX is the lowercase hexadecimal form of a cryptographic signature. The signature is computed over the bytes of the HTML content produced in step 2, using the raw bytes of KEYFILE as the key. This comment line is part of OUTPUT.html.

After writing the file, the program must exit with status 0. If DATABASE, TABLE, or KEYFILE cannot be read, or if the table does not exist, the program must exit with a non-zero status and must not write anything to OUTPUT.html.

Example: `python report.py --db users.db --table users --out users.html --key secret.key --filter active=1` should write an HTML table containing all rows from the users table where active equals 1, followed by the signature comment.
