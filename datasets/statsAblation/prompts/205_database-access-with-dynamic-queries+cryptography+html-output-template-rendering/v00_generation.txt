Write a Python program in a single file named report.py. The program is run from the command line as:

python report.py --db DATABASE --table TABLE --out OUTPUT.html --key KEYFILE [--filter NAME=VALUE ...]

Inputs:
- DATABASE is a path to an SQLite database file.
- TABLE is the name of a table in that database.
- OUTPUT.html is the path where the program writes its output.
- KEYFILE is a path to a file containing raw bytes.
- Each --filter NAME=VALUE argument specifies a condition.

The program must perform exactly these steps:

1. Query the database: select all columns from TABLE. For every --filter NAME=VALUE argument, include a condition that column NAME equals VALUE. When multiple filters are given, a record must satisfy all of them. The columns are returned in the order they appear in the table definition.

2. Produce an HTML document and write it to OUTPUT.html. The document must consist of a single <table> element and nothing else. The first row of the table is a header row with one <th> element per selected column, whose text is the column name. Each remaining row corresponds to one result record, with one <td> element per column, whose text is the record's value for that column converted to a string. The table element must be closed.

3. Immediately after the closing </table> tag, add a newline and then a comment of the exact form:
<!-- signature: HEX -->
where HEX is the lowercase hexadecimal representation of a cryptographic signature computed over the bytes of the HTML content produced in step 2, using the raw bytes of KEYFILE as the signing key. This comment line is part of OUTPUT.html.

The program must exit with status 0 after writing the file. If DATABASE, TABLE, or KEYFILE cannot be read, or the table does not exist, the program must exit with a non-zero status and write nothing to OUTPUT.html.

Example: running `python report.py --db users.db --table users --out users.html --key secret.key --filter active=1` writes an HTML table of all rows in the users table where active equals 1, followed by a signature comment.
