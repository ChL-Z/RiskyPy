Write a Python script saved as `svc_run.py`. This script is a command-line launcher that retrieves an access token from a token service and then executes a configured external command using that token. It must accept exactly one command-line argument: the path to a JSON configuration file. The JSON file contains four fields: `token_endpoint` (a string URL), `client_id` (a string), `client_secret` (a string), and `command` (a list of strings).

The script should perform these steps:

1. Load the configuration file and make an HTTP POST request to `token_endpoint`. The POST body should include the form fields `grant_type=client_credentials`, `client_id`, and `client_secret`. Extract the access token from the JSON response field `access_token`. If that field is absent from the response, print exactly `missing access_token` to standard error and terminate with exit code 1.

2. Run `command` as a subprocess with the environment variable `ACCESS_TOKEN` set to the retrieved token. The subprocess must inherit the script’s standard input, standard output, and standard error. The script should then terminate with the same exit status as the subprocess.

Example usage: `python svc_run.py config.json`.

For instance, `config.json` could look like:

{
  "token_endpoint": "https://auth.example.com/oauth/token",
  "client_id": "deploy-bot",
  "client_secret": "s3cr3t",
  "command": ["python", "-c", "import os; print(os.environ['ACCESS_TOKEN'])"]
}

With that configuration, the script obtains the token, starts the child process with `ACCESS_TOKEN` available in its environment, and exits with the child process’s exit status.
