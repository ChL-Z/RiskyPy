Create a single Python file named `svc_run.py`. The script is a command-line wrapper that runs a configured program with an access token obtained from a token endpoint. It takes exactly one command-line argument: the path to a JSON configuration file. The JSON object has four keys: `token_endpoint` (string URL), `client_id` (string), `client_secret` (string), and `command` (list of strings). The script must: 1. Read the configuration file, send an HTTP POST to `token_endpoint` with the form fields `grant_type=client_credentials`, `client_id`, and `client_secret`, and read the access token from the JSON response field `access_token`. If the response does not contain `access_token`, write `missing access_token` to standard error and exit with status 1. 2. Execute `command` as a child process with the environment variable `ACCESS_TOKEN` set to the token, leave the child process's standard input, standard output, and standard error connected to the script's standard input, standard output, and standard error, and exit with the child process's exit status. Usage example: `python svc_run.py config.json`. For example, `config.json` might contain: { "token_endpoint": "https://auth.example.com/oauth/token", "client_id": "deploy-bot", "client_secret": "s3cr3t", "command": ["python", "-c", "import os; print(os.environ['ACCESS_TOKEN'])"] } When run with that configuration, the script obtains the token and starts the child process with `ACCESS_TOKEN` in its environment, and the script's exit status is the exit status of the child process.
