Write a Python program in a single file named `authz_config.py`. The program manages credentials stored in an XML file. The XML file has a root element `<users>`. Each child of `<users>` is a `<user>` element with attributes `name` and `role`. Inside each `<user>` there is a `<token>` element and an `<expires>` element. `<token>` contains a string of 32 characters where each character is an uppercase letter, lowercase letter, or digit. `<expires>` contains a date in `YYYY-MM-DD` format.

The program is run from the command line as `python authz_config.py <xml_file> check --user <name> --role <role> --token <token>`. It must print `GRANTED` and exit with status 0 if the XML contains a `<user>` whose `name` attribute equals `<name>`, whose `role` attribute equals `<role>`, whose `<token>` text equals `<token>`, and whose `<expires>` date is on or after the current date in UTC. Otherwise it must print `DENIED` and exit with status 1. It prints no other output.

The program is also run as `python authz_config.py <xml_file> issue --user <name> --days <N>`. It must find the `<user>` element whose `name` attribute equals `<name>`, replace its `<token>` text with a new string of 32 characters where each character is an uppercase letter, lowercase letter, or digit, replace its `<expires>` text with the date N days after the current date in UTC in `YYYY-MM-DD` format, write the XML back to `<xml_file>` while keeping every other element and attribute unchanged, and print the new token followed by a newline. If no `<user>` has the matching `name` attribute, it must print `USER NOT FOUND` and exit with status 2.
