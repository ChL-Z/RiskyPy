Create one Python file called `authz_config.py` that reads and updates an XML credential store.

The XML document has a root element `<users>`. Each `<user>` child has attributes `name` and `role`, and contains a `<token>` element and an `<expires>` element. A valid token is exactly 32 characters long and consists only of uppercase letters, lowercase letters, and digits. The `<expires>` value is a UTC date formatted as `YYYY-MM-DD`.

The script must implement these two command-line modes.

1. `python authz_config.py <xml_file> check --user <name> --role <role> --token <token>`
   - Output only `GRANTED` and exit with code 0 exactly when the XML contains a `<user>` whose `name` attribute equals `<name>`, whose `role` attribute equals `<role>`, whose `<token>` text equals `<token>`, and whose `<expires>` date is today or later in UTC.
   - In all other cases, output only `DENIED` and exit with code 1.
   - Produce no other output.

2. `python authz_config.py <xml_file> issue --user <name> --days <N>`
   - Find the `<user>` element whose `name` attribute equals `<name>`.
   - Generate a new 32-character token using only uppercase letters, lowercase letters, and digits, and replace that user's `<token>` text with it.
   - Replace that user's `<expires>` text with the UTC date `N` days after today, formatted as `YYYY-MM-DD`.
   - Save the XML back to `<xml_file>` while leaving every other element and attribute unchanged.
   - Print the newly generated token followed by a newline.
   - If no `<user>` has the matching `name`, print `USER NOT FOUND` and exit with code 2.
