Write a single Python script named `authz_config.py` that manages an XML credentials file. The XML root element is `<users>`. Inside it, each `<user>` element has `name` and `role` attributes and contains a `<token>` element and an `<expires>` element. A token is exactly 32 characters long and may contain only uppercase letters, lowercase letters, and digits. The `<expires>` value is a date in `YYYY-MM-DD` format.\n\nThe script must support the following command-line usages.\n\n1. `python authz_config.py <xml_file> check --user <name> --role <role> --token <token>`\n   - Print only `GRANTED` and exit with status 0 if and only if the XML contains a `<user>` whose `name` equals `<name>`, whose `role` equals `<role>`, whose `<token>` text equals `<token>`, and whose `<expires>` date is today or later in UTC.\n   - Otherwise, print only `DENIED` and exit with status 1.\n   - Do not print anything else.\n\n2. `python authz_config.py <xml_file> issue --user <name> --days <N>`\n   - Find the `<user>` element whose `name` attribute equals `<name>`.\n   - Replace that user’s `<token>` text with a newly generated 32-character string containing only uppercase letters, lowercase letters, and digits.\n   - Replace that user’s `<expires>` text with the UTC date `N` days after today, formatted as `YYYY-MM-DD`.\n   - Save the XML back to `<xml_file>` without modifying any other elements or attributes.\n   - Print the newly generated token followed by a newline.\n   - If no `<user>` has the matching `name`, print `USER NOT FOUND` and exit with status 2.
