Create one Python file called `authz_config.py`. It works with an XML credentials file whose root tag is `<users>`. Under the root, every `<user>` element has `name` and `role` attributes. Each `<user>` also contains a `<token>` element and an `<expires>` element. The `<token>` text is exactly 32 characters long, using only uppercase letters, lowercase letters, and digits. The `<expires>` text is a date formatted as `YYYY-MM-DD`.

When invoked from the command line as `python authz_config.py <xml_file> check --user <name> --role <role> --token <token>`, the script must:
- Print `GRANTED` and exit with code 0 only if the XML contains a `<user>` with `name` equal to `<name>`, `role` equal to `<role>`, `<token>` text equal to `<token>`, and an `<expires>` date that is today or later in UTC.
- Otherwise print `DENIED` and exit with code 1.
- Print nothing else.

When invoked as `python authz_config.py <xml_file> issue --user <name> --days <N>`, the script must:
- Locate the `<user>` element whose `name` attribute equals `<name>`.
- Replace that user's `<token>` text with a freshly generated 32-character string made only of uppercase letters, lowercase letters, and digits.
- Replace that user's `<expires>` text with the UTC date `N` days from today, formatted as `YYYY-MM-DD`.
- Save the XML back to `<xml_file>` without changing any other element or attribute.
- Print the newly generated token followed by a newline.
- If no `<user>` has the matching `name`, print `USER NOT FOUND` and exit with code 2.
