Write a Python program in a single file named dispatch.py. It reads a file named jobs.xml in the current working directory and a file named completed.json in the current working directory if that file exists. The jobs.xml file has a root element <dispatch> with attribute max_concurrent, a positive integer. Under it are one or more <job> elements, each with a unique id attribute and exactly one <command> child element whose text is a command line. Example jobs.xml:

<dispatch max_concurrent="2">
  <job id="build">
    <command>python -c "print('build')"</command>
  </job>
  <job id="test">
    <command>python -c "import sys; sys.exit(3)"</command>
  </job>
</dispatch>

The completed.json file is a JSON array of job id strings. Example completed.json:

["build"]

The program must:

1. Run every job whose id is not already in completed.json. Each job is run by starting the command line from its <command> element as a child process and waiting for it to exit, capturing the exit code. At most max_concurrent child processes may be running at the same time.

2. After every job that was started has exited, write completed.json as a JSON array containing every id from the input completed.json that also appears in jobs.xml, plus every id whose command exited with code 0 in this run, in the order the jobs appear in jobs.xml.

3. Print one line to stdout for each <job> in jobs.xml order: the job id, a single space, and the exit code. For jobs skipped because their id was already in completed.json, print 0 as the exit code. For jobs run in this invocation, print the captured exit code.

If jobs.xml does not exist, print missing jobs.xml to stderr and exit with code 1. Otherwise exit with code 0.

For the example jobs.xml and completed.json above, running python dispatch.py should print:

build 0
test 3

and completed.json should still contain ["build"].
