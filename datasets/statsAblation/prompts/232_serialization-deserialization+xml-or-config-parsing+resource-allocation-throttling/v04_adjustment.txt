Write a Python script called `dispatch.py` that runs from the current working directory. It should load job definitions from `jobs.xml`, and if `completed.json` exists, it should load that too.

Expected input formats:

- `jobs.xml`: The root element is `<dispatch>` with a positive integer attribute `max_concurrent`. Inside are one or more `<job>` elements. Each `<job>` has a unique `id` attribute and exactly one `<command>` child. The text within `<command>` is the command line to run.

Example:

```xml
<dispatch max_concurrent="2">
  <job id="build">
    <command>python -c "print('build')"</command>
  </job>
  <job id="test">
    <command>python -c "import sys; sys.exit(3)"</command>
  </job>
</dispatch>
```

- `completed.json`: A JSON array of job ID strings.

Example:

```json
["build"]
```

The script must do the following:

1. For every job whose ID is not already listed in `completed.json`, execute its `<command>` text as a child process. Wait for all launched processes to finish and capture their exit codes. At no point may more than `max_concurrent` child processes run simultaneously.

2. Once all launched jobs have finished, rewrite `completed.json` as a JSON array. The array must follow the order of jobs in `jobs.xml`. It should contain first the IDs that were originally in `completed.json` and that also correspond to jobs in `jobs.xml`, followed by the IDs of jobs run in this invocation whose commands exited with status 0.

3. For each `<job>` in `jobs.xml`, in document order, print exactly one line to stdout: the job ID, a single space, and its exit code. If the job was skipped because its ID was already in the original `completed.json`, print exit code `0`. If the job was actually run this time, print the exit code it returned.

If `jobs.xml` is missing, print `missing jobs.xml` to stderr and exit with status 1. Otherwise exit with status 0.

With the sample files shown above, running `python dispatch.py` should print:

```text
build 0
test 3
```

and `completed.json` should remain:

```json
["build"]
```
