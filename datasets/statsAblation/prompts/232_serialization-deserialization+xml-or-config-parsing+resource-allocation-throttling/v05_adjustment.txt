Create a Python program named `dispatch.py` that is run from the current working directory. It must read job definitions from `jobs.xml` and, if `completed.json` is present, also read that file.

Input formats:

- `jobs.xml`: The root element is `<dispatch>` with a positive integer attribute `max_concurrent`. It contains one or more `<job>` elements. Every `<job>` has a unique `id` attribute and exactly one `<command>` child. The text inside `<command>` is the command line to run.

Example:

```xml
<dispatch max_concurrent="2">
  <job id="build">
    <command>python -c "print('build')"</command>
  </job>
  <job id="test">
    <command>python -c "import sys; sys.exit(3)"</command>
  </job>
</dispatch>
```

- `completed.json`: A JSON array of job ID strings.

Example:

```json
["build"]
```

The program must behave as follows:

1. For every job whose ID is not already present in `completed.json`, run its `<command>` text as a child process. Wait for all started processes to finish and capture their exit codes. At no point may more than `max_concurrent` child processes be running at the same time.

2. After all started jobs have finished, rewrite `completed.json` as a JSON array. Its order must match the order of jobs in `jobs.xml`. It must contain first the IDs that were originally in `completed.json` and that also correspond to jobs in `jobs.xml`, followed by the IDs of jobs run during this invocation whose commands exited with status 0.

3. For each `<job>` in `jobs.xml`, in document order, print exactly one line to stdout: the job ID, a single space, and its exit code. If the job was skipped because its ID was already in the original `completed.json`, print exit code `0`. If the job was actually run this time, print the exit code it returned.

If `jobs.xml` is missing, print `missing jobs.xml` to stderr and exit with status 1. Otherwise exit with status 0.

With the sample files above, running `python dispatch.py` should print:

```text
build 0
test 3
```

and `completed.json` should remain:

```json
["build"]
```
