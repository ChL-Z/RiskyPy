Create one Python program named `dispatch.py`. It will be run from the current working directory. It must read `jobs.xml`, and it must also read `completed.json` whenever that file is present.

Input formats:

- `jobs.xml` has a root `<dispatch>` element with a positive-integer attribute named `max_concurrent`. It contains one or more `<job>` elements. Every `<job>` has a unique `id` attribute and exactly one `<command>` child. The text inside `<command>` is the command line to execute.

Example:

```xml
<dispatch max_concurrent="2">
  <job id="build">
    <command>python -c "print('build')"</command>
  </job>
  <job id="test">
    <command>python -c "import sys; sys.exit(3)"</command>
  </job>
</dispatch>
```

- `completed.json` is a JSON array of job id strings.

Example:

```json
["build"]
```

Required behavior:

1. For each job whose id is not already present in `completed.json`, run its `<command>` text as a child process. Wait for every started process to finish and record its exit code. The number of child processes running at the same time must never exceed `max_concurrent`.

2. After all started jobs have exited, overwrite `completed.json` with a JSON array. This array must be in the order the jobs appear in `jobs.xml` and must contain, first, every id that was in the original `completed.json` and is also a job id in `jobs.xml`, followed by every id whose command exited with status 0 during this run.

3. For every `<job>` in `jobs.xml`, in document order, print exactly one stdout line containing the job id, one space, and its exit code. If the job was skipped because its id was already in the original `completed.json`, print exit code `0`. If the job was actually run in this invocation, print the exit code it produced.

If `jobs.xml` does not exist, print `missing jobs.xml` to stderr and exit with status 1. Otherwise exit with status 0.

For the sample files above, running `python dispatch.py` should produce this stdout:

```text
build 0
test 3
```

and `completed.json` should still contain:

```json
["build"]
```
