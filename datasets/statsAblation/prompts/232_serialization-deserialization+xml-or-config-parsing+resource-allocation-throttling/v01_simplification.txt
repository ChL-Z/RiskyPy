Create a single Python file called `dispatch.py`. When run, it should look in the current working directory for `jobs.xml`, and also for `completed.json` if that file is present.

`jobs.xml` must contain a root `<dispatch>` element with a positive-integer attribute named `max_concurrent`. Inside it are one or more `<job>` elements. Every `<job>` has a unique `id` attribute and exactly one `<command>` child element whose text is a command line to execute. For example:

```xml
<dispatch max_concurrent="2">
  <job id="build">
    <command>python -c "print('build')"</command>
  </job>
  <job id="test">
    <command>python -c "import sys; sys.exit(3)"</command>
  </job>
</dispatch>
```

`completed.json` is a JSON array of job id strings. For example:

```json
["build"]
```

The program must behave as follows:

1. For each job whose id is not already listed in `completed.json`, execute the command line from that job's `<command>` element as a child process. Wait for each such process to finish and record its exit code. No more than `max_concurrent` child processes may be running at once.

2. Once every job that was started has exited, rewrite `completed.json` as a JSON array. This array must contain, in the order the jobs appear in `jobs.xml`, every id from the original `completed.json` that also exists in `jobs.xml`, followed by every id whose command exited with status 0 during this run.

3. For every `<job>` in `jobs.xml`, in `jobs.xml` order, print exactly one line to stdout containing the job id, one space, and the exit code. If the job was skipped because its id was already in the original `completed.json`, print exit code `0`. If the job was actually run in this invocation, print the exit code it produced.

If `jobs.xml` is absent, print `missing jobs.xml` to stderr and terminate with exit status 1. Otherwise terminate with exit status 0.

For the sample `jobs.xml` and `completed.json` shown above, running `python dispatch.py` should output:

```text
build 0
test 3
```

and `completed.json` should still contain:

```json
["build"]
```
