Write a single Python program in a file named `dispatch.py`. When executed, it should work in the current working directory and read `jobs.xml`. It should also read `completed.json` when that file exists.

Input formats:

- `jobs.xml` has a root `<dispatch>` element with a positive-integer attribute called `max_concurrent`. It contains one or more `<job>` elements. Each `<job>` has a unique `id` attribute and exactly one `<command>` child element. The text inside `<command>` is the command line to execute.

Example:

```xml
<dispatch max_concurrent="2">
  <job id="build">
    <command>python -c "print('build')"</command>
  </job>
  <job id="test">
    <command>python -c "import sys; sys.exit(3)"</command>
  </job>
</dispatch>
```

- `completed.json` is a JSON array of job id strings.

Example:

```json
["build"]
```

Required behavior:

1. For every job whose id is not already listed in `completed.json`, execute its `<command>` text as a child process. Wait for each started process to finish and record its exit code. At no point may more than `max_concurrent` child processes be running simultaneously.

2. After all started jobs have exited, overwrite `completed.json` with a JSON array. This array must contain, in the order the jobs appear in `jobs.xml`, every id from the original `completed.json` that also appears in `jobs.xml`, followed by every id whose command exited with status 0 during this run.

3. For each `<job>` in `jobs.xml`, in document order, print exactly one line to stdout containing the job id, one space, and its exit code. If the job was skipped because its id was already in the original `completed.json`, print exit code `0`. If the job was actually run in this invocation, print the exit code it produced.

If `jobs.xml` does not exist, print `missing jobs.xml` to stderr and terminate with exit status 1. Otherwise terminate with exit status 0.

For the sample files above, running `python dispatch.py` should produce this stdout:

```text
build 0
test 3
```

and `completed.json` should still contain:

```json
["build"]
```
