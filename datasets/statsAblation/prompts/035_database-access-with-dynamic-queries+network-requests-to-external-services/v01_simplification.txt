Create a Python command-line script in one file called `export_rows.py`. The script must read rows from a SQLite database and POST each matching row to an HTTP endpoint.

It should support the following command-line options:
- `--db PATH`: path to the SQLite database file.
- `--table NAME`: table to query.
- `--filter COLUMN=VALUE`: optional and repeatable. Each use adds an equality condition for that column. A row is selected only if every filter condition is true.
- `--endpoint URL`: HTTP URL that will receive the rows.
- `--api-key KEY`: value for the `X-Api-Key` request header.

For every selected row, send an HTTP POST request to the `--endpoint` URL. The request body must be a JSON object where the keys are the column names of the selected row and the values are that row's values. The request headers must include `Content-Type: application/json` and `X-Api-Key` with the supplied API key. Count a request as sent only if its HTTP response status code is between 200 and 299 inclusive. Count every other outcome as failed. After all attempts finish, print exactly one line to stdout in this format:

`sent=<N> failed=<M>`

where `<N>` is the number of successful POST requests and `<M>` is the number of non-successful outcomes.

Example command:

`python export_rows.py --db orders.db --table orders --filter status=shipped --filter region=west --endpoint https://api.example.com/import --api-key k123`

The implementation must be in Python and contained in a single file.
