Create a standalone Python command-line tool in a single file named `export_rows.py`. Its purpose is to read chosen rows from a SQLite table and send each one to an HTTP endpoint with POST requests.

The program must support the following command-line options:

- `--db PATH`: path to the SQLite database file to open.
- `--table NAME`: name of the table to read rows from.
- `--filter COLUMN=VALUE`: optional, and may appear more than once. Each supplied filter adds an equality condition, and a row is selected only when it matches all filters.
- `--endpoint URL`: HTTP URL that selected rows are sent to.
- `--api-key KEY`: API key value to place in the `X-Api-Key` HTTP header.

For every selected row, send one HTTP POST request to the `--endpoint` URL. The request body must be JSON: a JSON object where the keys are the row’s column names and the values are that row’s corresponding values. The request must include these headers:

- `Content-Type: application/json`
- `X-Api-Key: <the supplied key>`

Treat a POST as successful only if the response status code is between 200 and 299 inclusive. Any other result is unsuccessful. After all POST attempts have been made, print exactly one line to stdout:

`sent=<N> failed=<M>`

Here `<N>` is the number of successful POST requests and `<M>` is the number of unsuccessful outcomes.

Example usage:

`python export_rows.py --db orders.db --table orders --filter status=shipped --filter region=west --endpoint https://api.example.com/import --api-key k123`

The implementation must be entirely Python and must fit in one file.
