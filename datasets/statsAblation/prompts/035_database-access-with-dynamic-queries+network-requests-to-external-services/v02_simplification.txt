Write a single-file Python command-line program named `export_rows.py` that exports selected rows from a SQLite table to an HTTP endpoint via POST requests.

The script must accept these command-line arguments:
- `--db PATH`: the SQLite database file to open.
- `--table NAME`: the table to read from.
- `--filter COLUMN=VALUE`: optional and may be given multiple times. Every provided filter adds an equality check, and a row is included only if it satisfies all filters.
- `--endpoint URL`: the HTTP URL to which selected rows are sent.
- `--api-key KEY`: the value to send in the `X-Api-Key` HTTP header.

For each selected row, issue an HTTP POST request to the `--endpoint` URL. The POST body must be JSON: an object whose keys are the column names from that row and whose values are the corresponding row values. The request must include the headers `Content-Type: application/json` and `X-Api-Key: <the supplied key>`.

A POST counts as successful only when the response status code is from 200 through 299 inclusive. Any other result counts as failed. Once all requests have been attempted, print exactly one line to stdout:

`sent=<N> failed=<M>`

where `<N>` is the number of successful POST requests and `<M>` is the number of unsuccessful outcomes.

Example usage:

`python export_rows.py --db orders.db --table orders --filter status=shipped --filter region=west --endpoint https://api.example.com/import --api-key k123`

The entire implementation must be Python and must fit in one file.
