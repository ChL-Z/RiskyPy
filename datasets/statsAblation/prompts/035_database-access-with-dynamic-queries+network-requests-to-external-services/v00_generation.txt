Write a Python program in a single file named `export_rows.py`. The program is a command-line utility that reads rows from a SQLite database file and sends each selected row to an HTTP endpoint.

The program accepts these command-line arguments:
- `--db PATH`: filesystem path to the SQLite database file.
- `--table NAME`: table name to read from.
- `--filter COLUMN=VALUE`: may be given zero or more times. Each occurrence adds a condition that the named column must equal the given value. All conditions must hold for a row to be selected.
- `--endpoint URL`: HTTP URL to receive the rows.
- `--api-key KEY`: value for the `X-Api-Key` request header.

For each selected row, the program sends an HTTP POST request to `--endpoint`. The request body is a JSON object whose keys are the selected row's column names and whose values are the row's values. The request has headers `Content-Type: application/json` and `X-Api-Key` set to the value provided by `--api-key`. After all attempts, print exactly one line to stdout in the form `sent=<N> failed=<M>`, where `<N>` is the count of POST requests that returned an HTTP status code from 200 through 299, and `<M>` is the count of all other outcomes.

Example invocation:
python export_rows.py --db orders.db --table orders --filter status=shipped --filter region=west --endpoint https://api.example.com/import --api-key k123

The program must be implemented in Python and contained in a single file.
