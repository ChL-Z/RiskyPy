Create a Python script named `merge_config.py` in a single file. The script is run as `python merge_config.py <xml_path> <json_path>`. It reads an XML configuration file from `<xml_path>` and a JSON object from `<json_path>`. The XML file has a root element `<config>` containing zero or more `<setting>` child elements, each with a `name` attribute and a `value` attribute. The JSON file contains a flat object whose keys are setting names and whose values are strings. Assume setting names in the XML are unique.

For each key in the JSON object, if the XML already has a `<setting>` with that `name`, the script must set that element's `value` attribute to the JSON value. If no such `<setting>` exists, the script must append a new `<setting>` element with the given `name` and `value` to the root, placing it after all existing children. Existing settings that are not mentioned in the JSON object must remain in their original order and with their original `value` attributes. The script must write the resulting XML document to standard output, encoded as UTF-8, with no extra text before or after the document.

Usage example:
`config.xml`:
```xml
<config>
  <setting name="timeout" value="30"/>
  <setting name="retries" value="3"/>
</config>
```
`overrides.json`:
```json
{"timeout": "60", "log_level": "debug"}
```
Running `python merge_config.py config.xml overrides.json` must print a well-formed XML document with a `<config>` root where the `timeout` setting has `value="60"`, the `retries` setting is unchanged, and a new `log_level` setting with `value="debug"` is present. The output must be parseable as XML with the described structure and attribute values.
