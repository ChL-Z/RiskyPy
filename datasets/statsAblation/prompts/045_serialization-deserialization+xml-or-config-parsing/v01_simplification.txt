Write a single-file Python program named `merge_config.py`. It will be executed as `python merge_config.py <xml_path> <json_path>`. The program should read an XML configuration document from `<xml_path>` and a JSON object from `<json_path>`.

The XML document has a root element named `<config>`. It may contain any number of `<setting>` child elements, including zero. Every `<setting>` element has a `name` attribute and a `value` attribute. The JSON document contains one flat object. Its keys are setting names, and each corresponding value is a string. You may assume that setting names within the XML are unique.

For every key in the JSON object:
- If the XML already contains a `<setting>` element with that `name`, update that element’s `value` attribute to the JSON value.
- If the XML does not contain such a `<setting>` element, append a new `<setting>` element with that `name` and `value` to the root `<config>` element. The new element must be placed after all existing child elements.

Any existing XML settings that are not present as keys in the JSON object must remain in their original order and keep their original `value` attributes.

After merging, write the resulting XML document to standard output. The output must be encoded as UTF-8 and must contain no extra text before or after the XML document.

Example usage:

`config.xml`:
```xml
<config>
  <setting name="timeout" value="30"/>
  <setting name="retries" value="3"/>
</config>
```

`overrides.json`:
```json
{"timeout": "60", "log_level": "debug"}
```

Running `python merge_config.py config.xml overrides.json` must print a well-formed XML document whose root is `<config>`. In that output, the `timeout` setting must have `value="60"`, the `retries` setting must be unchanged, and a new `log_level` setting with `value="debug"` must be present. The printed document must be parseable as XML and must have the structure and attribute values described above.
