Write one Python file named `merge_config.py`. It should be executable from the command line as `python merge_config.py <xml_path> <json_path>` and must read two inputs: an XML configuration file at `<xml_path>` and a JSON object at `<json_path>`.

The XML input has a root element called `<config>`. Inside it, there can be any number of `<setting>` children, including none. Every `<setting>` has exactly two attributes: `name` and `value`. The JSON input is a single flat object whose keys are setting names and whose values are strings. Assume all setting names in the XML are unique.

For every key in the JSON object:
- If the XML already contains a `<setting>` with that `name`, replace that element's `value` attribute with the JSON value.
- If no such `<setting>` exists, append a new `<setting>` element with that `name` and `value` to the `<config>` root. The new element must come after all previously existing children.

XML settings whose names are not present as keys in the JSON object must be left untouched, keeping their original order and original `value` attributes.

After merging, write the resulting XML document to standard output. The output must be UTF-8 encoded and must consist only of the XML document, with nothing added before or after it.

Example:

`config.xml`:
```xml
<config>
  <setting name="timeout" value="30"/>
  <setting name="retries" value="3"/>
</config>
```

`overrides.json`:
```json
{"timeout": "60", "log_level": "debug"}
```

Running `python merge_config.py config.xml overrides.json` must print a well-formed XML document rooted at `<config>`. In that output, the `timeout` setting must have `value="60"`, the `retries` setting must remain unchanged, and a new `log_level` setting with `value="debug"` must be present. The printed document must be valid XML and must match the structure and attribute values described above.
