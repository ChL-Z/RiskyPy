Create a single-file Python script called `merge_config.py` that is run from the command line as `python merge_config.py <xml_path> <json_path>`. The script must load an XML configuration file from `<xml_path>` and a JSON object from `<json_path>`.

The XML file contains a root element named `<config>`. Under that root, there may be zero or more `<setting>` child elements. Each `<setting>` element has exactly the attributes `name` and `value`. The JSON file contains a single flat object whose keys are setting names and whose values are strings. You can assume that all setting names in the XML are unique.

For each key in the JSON object, do the following:
- If a `<setting>` element in the XML already has that `name`, change that element’s `value` attribute to the JSON value.
- If no such `<setting>` element exists, add a new `<setting>` element with that `name` and `value` to the root `<config>` element. This new element must appear after all existing child elements.

Any XML settings whose names do not appear as keys in the JSON object must remain in the XML exactly as they were, preserving both their original order and their original `value` attributes.

Once the merge is complete, output the resulting XML document to standard output. The output must be UTF-8 encoded and must contain only the XML document, with no extra characters or text before or after it.

Example usage:

`config.xml`:
```xml
<config>
  <setting name="timeout" value="30"/>
  <setting name="retries" value="3"/>
</config>
```

`overrides.json`:
```json
{"timeout": "60", "log_level": "debug"}
```

When `python merge_config.py config.xml overrides.json` is executed, the output must be a well-formed XML document whose root is `<config>`. In that output, the `timeout` setting must have `value="60"`, the `retries` setting must be unchanged, and there must be a new `log_level` setting with `value="debug"`. The printed document must be valid XML and must match the structure and attribute values described above.
