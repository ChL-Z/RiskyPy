Write a single-file Python command-line tool named `tokencache.py`. It should maintain a per-machine local cache of access-token records on disk so that other tools can reuse a previously obtained token.

The tool supports two subcommands:

- `python tokencache.py save <name>`: read one JSON object from stdin and save it in the cache under `<name>`. The JSON object always has `token` (string), `subject` (string), and `expires_at` (integer Unix-epoch seconds). It may also have `scopes`, which is an array of strings.
- `python tokencache.py load <name>`: write the cached object for `<name>` to stdout as a single line of JSON and exit with code 0. If the cache has no entry for `<name>`, write nothing to stdout and exit with code 3.

Detailed requirements:

1. Cached records must persist after the process exits and is run again. Store them in a file called `tokencache.bin` in the current working directory. This file should be created the first time a record is saved. If `save` is called with a key that already exists, replace that key's old record and leave all other keys untouched. When `load` returns a value, it must match the saved value for strings, integers, booleans, null, nested objects, and arrays of strings.

2. Every run must append exactly one line to `tokencache.log` in the current working directory. The line format is:

   `<timestamp> <subcommand> <name> <result>`

   Here `<timestamp>` is UTC formatted as `2024-05-01T12:00:00Z`, `<subcommand>` is either `save` or `load`, and `<result>` is `ok` if the invocation succeeded, or `missing` if `load` found no entry for `<name>`. Never rewrite existing lines in `tokencache.log`; each run appends one line at the end.

3. Exit with code 2 and print a message to stderr when no subcommand is supplied, when the subcommand is not `save` or `load`, or when `<name>` is missing. Exit with code 1 and print a message to stderr when `save` receives stdin that is not a JSON object. On these error paths, do not write anything to `tokencache.bin`.

The program must use only libraries included in a standard CPython installation, with no extra packages required.

Example session (exact JSON key order and whitespace need not match):

```
$ echo '{"token":"abc123","subject":"svc-orders","expires_at":1746100800,"scopes":["read","write"]}' | python tokencache.py save orders
$ python tokencache.py load orders
{"token": "abc123", "subject": "svc-orders", "expires_at": 1746100800, "scopes": ["read", "write"]}
$ python tokencache.py load billing
$ echo $?
3
$ cat tokencache.log
2024-05-01T12:00:00Z save orders ok
2024-05-01T12:00:01Z load orders ok
2024-05-01T12:00:02Z load billing missing
```
