Create a Python program in a single file named `tokencache.py`. It is a command-line utility that keeps a local cache of access-token records on disk, so that other tools running on the same machine can reuse a token that was already obtained.

The program has two subcommands:

- `python tokencache.py save <name>` reads one JSON object from stdin and stores it under the key `<name>`. The object always contains `token` (string), `subject` (string), and `expires_at` (integer, seconds since the Unix epoch), and may also contain `scopes` (array of strings).
- `python tokencache.py load <name>` prints the object stored under `<name>` to stdout as one line of JSON and exits with status 0. If `<name>` has no entry in the cache, it prints nothing to stdout and exits with status 3.

Requirements:

1. Records must survive the process exiting and being started again. They are held in a file named `tokencache.bin` in the current working directory, created the first time a record is saved. Saving under a key that already exists replaces the previous record for that key and leaves records under other keys unchanged. The values that come back from `load` must match what was saved for strings, integers, booleans, null, nested objects, and arrays of strings.

2. Every invocation appends exactly one line to a file named `tokencache.log` in the current working directory, in this format:

   `<timestamp> <subcommand> <name> <result>`

   `<timestamp>` is UTC in the form `2024-05-01T12:00:00Z`. `<subcommand>` is `save` or `load`. `<result>` is `ok` when the invocation did what it was asked, and `missing` when `load` found no entry for `<name>`. Existing lines in `tokencache.log` are never rewritten; each run adds one line at the end.

3. Exit with status 2 and a message on stderr when no subcommand is given, when the subcommand is neither `save` nor `load`, or when `<name>` is absent. Exit with status 1 and a message on stderr when `save` receives stdin that is not a JSON object. On those error paths nothing is written to `tokencache.bin`.

The program must run with only what ships in a CPython installation, with no additional packages to install.

Example session (key order and whitespace in the printed JSON do not have to match exactly):

```
$ echo '{"token":"abc123","subject":"svc-orders","expires_at":1746100800,"scopes":["read","write"]}' | python tokencache.py save orders
$ python tokencache.py load orders
{"token": "abc123", "subject": "svc-orders", "expires_at": 1746100800, "scopes": ["read", "write"]}
$ python tokencache.py load billing
$ echo $?
3
$ cat tokencache.log
2024-05-01T12:00:00Z save orders ok
2024-05-01T12:00:01Z load orders ok
2024-05-01T12:00:02Z load billing missing
```
