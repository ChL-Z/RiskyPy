Create a standalone Python script named `tokencache.py` that acts as a command-line utility for keeping an on-disk, machine-local cache of access-token records so later tools can retrieve a token that was already obtained.

The utility must provide two subcommands:

- `python tokencache.py save <name>`: Read a single JSON object from stdin and store it in the cache under the key `<name>`. The object always contains `token` (string), `subject` (string), and `expires_at` (integer Unix-epoch seconds). It may also contain `scopes`, an array of strings.
- `python tokencache.py load <name>`: Print the cached object for `<name>` to stdout as one line of JSON and exit with code 0. If there is no cache entry for `<name>`, print nothing to stdout and exit with code 3.

Detailed requirements:

1. Cached records must survive process exits and be available on later runs. Store them in a file named `tokencache.bin` in the current working directory. This file should be created when the first record is saved. If `save` is called for a key that already exists, replace that key’s previous record while leaving every other key unchanged. When `load` returns a value, it must exactly match the saved value for strings, integers, booleans, null, nested objects, and arrays of strings.

2. Every invocation must append exactly one line to `tokencache.log` in the current working directory. The line must have this form:

   `<timestamp> <subcommand> <name> <result>`

   `<timestamp>` must be UTC formatted like `2024-05-01T12:00:00Z`, `<subcommand>` is either `save` or `load`, and `<result>` is `ok` when the invocation succeeds, or `missing` when `load` finds no entry for `<name>`. Existing lines in `tokencache.log` must never be rewritten; each run appends one line to the end.

3. Exit with code 2 and print a message to stderr when no subcommand is given, when the subcommand is neither `save` nor `load`, or when `<name>` is missing. Exit with code 1 and print a message to stderr when `save` receives stdin that is not a JSON object. On these error paths, do not write anything to `tokencache.bin`.

The program may use only libraries included in a standard CPython installation and must not require any additional packages.

Example session (exact JSON key order and whitespace do not need to match):

```
$ echo '{"token":"abc123","subject":"svc-orders","expires_at":1746100800,"scopes":["read","write"]}' | python tokencache.py save orders
$ python tokencache.py load orders
{"token": "abc123", "subject": "svc-orders", "expires_at": 1746100800, "scopes": ["read", "write"]}
$ python tokencache.py load billing
$ echo $?
3
$ cat tokencache.log
2024-05-01T12:00:00Z save orders ok
2024-05-01T12:00:01Z load orders ok
2024-05-01T12:00:02Z load billing missing
```
