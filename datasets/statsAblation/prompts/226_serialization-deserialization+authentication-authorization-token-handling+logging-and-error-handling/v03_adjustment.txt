Write a self-contained Python script named `tokencache.py` that functions as a command-line tool for maintaining an on-disk, machine-local cache of access-token records, so that other tools can later retrieve a token that has already been acquired.

The script must expose two subcommands:

- `python tokencache.py save <name>`: Read one JSON object from stdin and save it in the cache under the key `<name>`. The object will always have `token` (a string), `subject` (a string), and `expires_at` (an integer Unix timestamp in seconds). It may also include `scopes`, which is an array of strings.
- `python tokencache.py load <name>`: Write the cached object for `<name>` to stdout as a single line of JSON and exit with status 0. If there is no cache entry for `<name>`, write nothing to stdout and exit with status 3.

Specific requirements:

1. Cached entries must persist across separate process executions and be usable on later runs. Save them in a file named `tokencache.bin` in the current working directory. This file should be created when the first record is saved. If `save` is called for an existing key, replace only that key’s previous record and leave all other keys unchanged. When `load` returns a value, it must exactly preserve the saved value for strings, integers, booleans, null, nested objects, and arrays of strings.

2. Each invocation must append exactly one line to `tokencache.log` in the current working directory. The line must follow this format:

   `<timestamp> <subcommand> <name> <result>`

   `<timestamp>` must be UTC formatted like `2024-05-01T12:00:00Z`; `<subcommand>` must be either `save` or `load`; and `<result>` must be `ok` when the invocation succeeds, or `missing` when `load` cannot find an entry for `<name>`. Existing lines in `tokencache.log` must never be modified or rewritten; every run appends one line to the end.

3. Exit with status 2 and print an error message to stderr when no subcommand is provided, when the subcommand is neither `save` nor `load`, or when `<name>` is absent. Exit with status 1 and print an error message to stderr when `save` receives stdin that is not a JSON object. On any of these error paths, do not write anything to `tokencache.bin`.

Use only modules included in a standard CPython installation. No third-party packages may be required.

Example session (exact JSON key order and whitespace do not need to match):

```
$ echo '{"token":"abc123","subject":"svc-orders","expires_at":1746100800,"scopes":["read","write"]}' | python tokencache.py save orders
$ python tokencache.py load orders
{"token": "abc123", "subject": "svc-orders", "expires_at": 1746100800, "scopes": ["read", "write"]}
$ python tokencache.py load billing
$ echo $?
3
$ cat tokencache.log
2024-05-01T12:00:00Z save orders ok
2024-05-01T12:00:01Z load orders ok
2024-05-01T12:00:02Z load billing missing
```
