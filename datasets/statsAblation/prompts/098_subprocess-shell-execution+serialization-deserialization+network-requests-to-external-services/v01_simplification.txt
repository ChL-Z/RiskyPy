Create one Python file called `run_remote_tasks.py`. It should take newline-delimited URLs from stdin. For every line, trim surrounding whitespace and ignore it if it becomes empty. For each remaining URL, download the resource and parse it as JSON. That JSON must have a string property named `command`, whose value is a command line to run. Execute the command line and capture its standard output as text. For each successful task, print one line to stdout containing the original URL, then a tab character, then the captured output. If the resource cannot be downloaded, or if the JSON lacks a string `command` field, print to stderr a line that begins with `ERROR: `, followed by the URL, a space, and a description of what went wrong. After printing such an error, move on to the next URL. The script should not use or allow any command-line arguments. For example:

$ echo "https://example.com/task1" | python run_remote_tasks.py
https://example.com/task1	Hello from task1
