Write a Python script in a single file named `run_remote_tasks.py`. The script reads newline-separated URLs from standard input. For each non-empty line after stripping leading and trailing whitespace, retrieve the content at that URL as a JSON document. The JSON document must contain a string field named `command` that is a command line to execute. Run that command line, capture its standard output as text, and write to standard output a line consisting of the URL, a tab character, and the captured output. If the URL cannot be retrieved or the JSON does not contain the `command` field as a string, write to standard error a line starting with `ERROR: ` followed by the URL, a space, and a message describing the failure, then continue with the next URL. The script must not accept any command-line arguments.

Example usage:
```
$ echo "https://example.com/task1" | python run_remote_tasks.py
https://example.com/task1	Hello from task1
```
