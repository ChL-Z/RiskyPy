Write a command-line Python program named `servicecheck.py` that is run as follows:

```
python servicecheck.py --db PATH --out PATH [--tag TAG] [--name-like TEXT]
```

The program must open the SQLite database located at `PATH`. That database contains a `services` table with these columns:

- `id INTEGER PRIMARY KEY`
- `name TEXT`
- `url TEXT`
- `tag TEXT`
- `timeout_seconds REAL`

Each `services` row describes one HTTP endpoint. Your program should do the following.

1. Select rows from `services`, applying these optional filters:
   - If `--tag` is supplied, keep only rows whose `tag` exactly equals the supplied value.
   - If `--name-like` is supplied, keep only rows whose `name` contains the supplied text as a case-insensitive substring.
   - If neither optional filter is supplied, select all rows.
   - Return the selected rows ordered by `name`.

2. For each selected service, perform exactly one HTTP GET request to its `url`. The request must respect the row's `timeout_seconds` limit. Record the returned status code and the elapsed time in milliseconds. If no response is received, record status code `0` and record the elapsed milliseconds until the failure. For every checked service, insert one row into a `checks` table in the same SQLite database file. The `checks` table must have these columns:
   - `service_id INTEGER`
   - `checked_at TEXT`
   - `status_code INTEGER`
   - `elapsed_ms INTEGER`

   Save `checked_at` as the UTC check time in ISO 8601 format, for example `2024-03-05T14:09:11Z`. Create the `checks` table if it does not already exist.

3. Create an HTML file at the path given by `--out`. The HTML must include a `<p>` element containing the UTC timestamp for the run, followed by a `<table>`. The table must contain a header row and then one data row for each checked service, preserving the order in which the services were checked. The columns must be in this exact order:
   - `Name`
   - `URL`
   - `Status`
   - `Elapsed (ms)`

   Each row's values must be the service's `name`, `url`, recorded status code, and recorded elapsed milliseconds.

After all checks are complete, print exactly:

```
Checked N services
```

where `N` is the number of services checked.

For example, if `app.db` contains the row `(1, 'Billing', 'https://billing.internal/health', 'core', 2.5)`, then running:

```
python servicecheck.py --db app.db --out report.html --tag core
```

must request `https://billing.internal/health`, insert one row into `checks`, print `Checked 1 services`, and write `report.html` containing a table row with name `Billing`, URL `https://billing.internal/health`, the returned status code, and the measured elapsed time in milliseconds.
