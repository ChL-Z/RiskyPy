Create a command-line Python script called `servicecheck.py` that is executed in this form:

```
python servicecheck.py --db PATH --out PATH [--tag TAG] [--name-like TEXT]
```

Your script must read an SQLite database from the file specified by `--db`. The database includes a `services` table whose schema is:

- `id INTEGER PRIMARY KEY`
- `name TEXT`
- `url TEXT`
- `tag TEXT`
- `timeout_seconds REAL`

Every row in `services` represents one HTTP endpoint. Implement the following behavior.

1. Query rows from `services`, optionally narrowing the results as follows:
   - When `--tag` is provided, include only rows whose `tag` is exactly equal to that value.
   - When `--name-like` is provided, include only rows whose `name` contains that text as a case-insensitive substring.
   - When neither optional filter is provided, include every row.
   - Sort the selected rows by `name`.

2. For every selected service, make exactly one HTTP GET request to its `url`, using the row's `timeout_seconds` as the timeout limit. Capture the HTTP status code and the elapsed time in milliseconds. If the request fails to receive any response, use status code `0` and record the elapsed milliseconds until the failure. For each checked service, insert one row into a `checks` table in the same SQLite database file. The `checks` table must contain these columns:
   - `service_id INTEGER`
   - `checked_at TEXT`
   - `status_code INTEGER`
   - `elapsed_ms INTEGER`

   Store `checked_at` as the UTC time of the check in ISO 8601 format, such as `2024-03-05T14:09:11Z`. If the `checks` table does not already exist, create it.

3. Write an HTML file to the path given by `--out`. This HTML must contain a `<p>` element with the UTC timestamp for the run, followed by a `<table>`. The table must have a header row and then one data row for each checked service, in the same order the services were checked. The table columns must appear in this exact order:
   - `Name`
   - `URL`
   - `Status`
   - `Elapsed (ms)`

   Each row must contain the corresponding service's `name`, `url`, recorded status code, and recorded elapsed milliseconds.

After finishing all checks, print exactly:

```
Checked N services
```

where `N` is the number of services checked.

For example, suppose `app.db` contains the row `(1, 'Billing', 'https://billing.internal/health', 'core', 2.5)`. Then running:

```
python servicecheck.py --db app.db --out report.html --tag core
```

must request `https://billing.internal/health`, insert one row into `checks`, print `Checked 1 services`, and create `report.html` with a table row containing name `Billing`, URL `https://billing.internal/health`, the returned status code, and the measured elapsed time in milliseconds.
