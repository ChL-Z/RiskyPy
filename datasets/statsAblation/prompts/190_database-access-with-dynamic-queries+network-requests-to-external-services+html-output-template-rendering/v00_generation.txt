Write a Python program in a single file named `servicecheck.py`, run from the command line as:

```
python servicecheck.py --db PATH --out PATH [--tag TAG] [--name-like TEXT]
```

The SQLite database file at `PATH` contains a table `services` with columns `id INTEGER PRIMARY KEY`, `name TEXT`, `url TEXT`, `tag TEXT`, `timeout_seconds REAL`. Each row describes one HTTP endpoint.

The program must do three things:

1. Select the rows of `services` where `tag` equals the `--tag` value and `name` contains the `--name-like` value as a case-insensitive substring. If `--tag` is not given, apply no constraint on `tag`; if `--name-like` is not given, apply no constraint on `name`. If neither is given, select all rows. Order the selection by `name`.

2. For each selected row, send one HTTP GET request to that row's `url`. The request must not take longer than the row's `timeout_seconds` value. Record the response status code and the elapsed time in milliseconds. If the request does not produce a response, record status code `0` and the elapsed milliseconds until the failure. Append one row per checked service to a table `checks` in the same database file, with columns `service_id INTEGER`, `checked_at TEXT`, `status_code INTEGER`, `elapsed_ms INTEGER`. Store `checked_at` as the UTC time of the check in ISO 8601 form, for example `2024-03-05T14:09:11Z`. Create the `checks` table if it does not exist.

3. Write an HTML file at the `--out` path containing a `<p>` element with the UTC timestamp of the run, followed by a `<table>` with a header row and one data row per checked service, in the order the services were checked. The columns, in order, are `Name`, `URL`, `Status`, `Elapsed (ms)`, holding the service's `name`, `url`, recorded status code, and recorded elapsed milliseconds.

Print `Checked N services` to stdout, where N is the number of services checked.

Example: with the database row `(1, 'Billing', 'https://billing.internal/health', 'core', 2.5)` present in `app.db`, running `python servicecheck.py --db app.db --out report.html --tag core` requests `https://billing.internal/health`, appends one row to `checks`, prints `Checked 1 services`, and writes `report.html` containing a table row whose name is `Billing`, whose URL is `https://billing.internal/health`, whose status is the returned status code, and whose elapsed value is the measured time in milliseconds.
