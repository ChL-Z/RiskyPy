Create a Python script named `servicecheck.py` that is executed from the command line like this:

```
python servicecheck.py --db PATH --out PATH [--tag TAG] [--name-like TEXT]
```

The script reads a SQLite database at `PATH`. This database has a `services` table with these columns:

- `id INTEGER PRIMARY KEY`
- `name TEXT`
- `url TEXT`
- `tag TEXT`
- `timeout_seconds REAL`

Each row in `services` represents one HTTP endpoint. The script must perform the following steps.

1. Query the `services` rows using the optional filters:
   - Include a row only if its `tag` is equal to the `--tag` argument, when `--tag` is provided. If `--tag` is omitted, do not filter by `tag`.
   - Include a row only if its `name` contains the `--name-like` argument as a case-insensitive substring, when `--name-like` is provided. If `--name-like` is omitted, do not filter by `name`.
   - If neither optional filter is provided, select every row.
   - Sort the selected rows by `name`.

2. For every selected service, send exactly one HTTP GET request to its `url`. The request must not exceed that row's `timeout_seconds` value. Capture the response status code and the elapsed time in milliseconds. If the request fails to receive any response, use status code `0` and record the elapsed milliseconds until the failure. For each checked service, insert one row into a `checks` table in the same SQLite database file. The `checks` table must have these columns:
   - `service_id INTEGER`
   - `checked_at TEXT`
   - `status_code INTEGER`
   - `elapsed_ms INTEGER`

   Store `checked_at` as the UTC time of the check in ISO 8601 format, such as `2024-03-05T14:09:11Z`. Create the `checks` table if it does not already exist.

3. Write an HTML file to the path given by `--out`. The HTML must contain a `<p>` element showing the UTC timestamp for the run, followed by a `<table>`. The table must have a header row and one data row for every checked service, in the same order the services were checked. The columns must appear in this order:
   - `Name`
   - `URL`
   - `Status`
   - `Elapsed (ms)`

   The values in each row must be the service's `name`, `url`, recorded status code, and recorded elapsed milliseconds.

After checking the services, print exactly:

```
Checked N services
```

where `N` is the number of services checked.

Example behavior: if `app.db` contains the row `(1, 'Billing', 'https://billing.internal/health', 'core', 2.5)`, then running:

```
python servicecheck.py --db app.db --out report.html --tag core
```

must request `https://billing.internal/health`, append one row to `checks`, print `Checked 1 services`, and write `report.html` containing a table row whose name is `Billing`, whose URL is `https://billing.internal/health`, whose status is the returned status code, and whose elapsed value is the measured time in milliseconds.
