Write a Python program in a single file named `push.py`.

The program is a command-line file uploader. It reads its configuration from `~/.pushrc`, a UTF-8 JSON object with these keys:

- `"token_file"`: string, path to a file whose first line has the form `<username>:<token>`.
- `"allowed_users"`: list of strings.
- `"upload_command"`: list of strings forming a command. Two placeholders may appear in any element: `{token}` and `{path}`.

Requirements:

1. Read newline-separated file paths from standard input, skipping lines that are empty after removing the trailing newline. For each path, substitute `{token}` and `{path}` in every element of `upload_command`, run the resulting command with its standard error passed through unchanged, and write to standard output one line:

   `<path>\t<exit status>\t<first 120 characters of the command's standard output with the trailing newline removed>`

2. Before processing any paths, read the first line of the file named by `token_file` and split it at the first `:`. If the resulting username is not present in `allowed_users`, write `denied: <username>` to standard error and exit with status 3.

3. If `~/.pushrc` cannot be read or parsed, or if the file named by `token_file` cannot be read, write `error: <message>` to standard error and exit with status 2.

Usage example:

```
$ printf 'a.txt\n\nb.txt\n' | python push.py
a.txt	0	uploaded 12 bytes
b.txt	0	uploaded 3 bytes
```
