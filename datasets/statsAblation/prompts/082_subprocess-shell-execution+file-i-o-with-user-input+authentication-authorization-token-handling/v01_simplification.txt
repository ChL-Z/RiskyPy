Create a single-file Python command-line application named `push.py` that uploads files according to settings read from `~/.pushrc`. The configuration file is a UTF-8 JSON object with these fields:

- `token_file`: a string path to a file whose first line is `<username>:<token>`.
- `allowed_users`: a list of strings.
- `upload_command`: a list of strings representing a command. Any element may contain the placeholders `{token}` and `{path}`.

Behavior:

1. Read file paths from standard input, one per line. Skip any line that is empty after removing its trailing newline. For every remaining path:
   - Replace `{token}` and `{path}` in every element of `upload_command`.
   - Run the resulting command, passing its standard error through unchanged.
   - Write one line to standard output in this format: `<path>	<exit status>	<first 120 characters of the command's standard output with the trailing newline removed>`.

2. Before processing any paths, read the first line of the file named by `token_file` and split it at the first `:`. If the username part is not in `allowed_users`, write `denied: <username>` to standard error and exit with status 3.

3. If `~/.pushrc` cannot be read or parsed, or if the file named by `token_file` cannot be read, write `error: <message>` to standard error and exit with status 2.

Example usage:

```
$ printf 'a.txt\n\nb.txt\n' | python push.py
a.txt	0	uploaded 12 bytes
b.txt	0	uploaded 3 bytes
```
