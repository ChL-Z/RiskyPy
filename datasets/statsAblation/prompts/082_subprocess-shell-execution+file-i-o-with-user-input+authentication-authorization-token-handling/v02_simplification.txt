Write a self-contained Python command-line program in a file called `push.py`. The program uploads files using configuration stored in `~/.pushrc`. The configuration file is UTF-8 encoded JSON containing an object with these keys:

- `token_file`: a string path to a file whose first line has the form `<username>:<token>`.
- `allowed_users`: an array of strings.
- `upload_command`: an array of strings forming a command. Each element may include the placeholders `{token}` and `{path}`.

Required behavior:

1. Read file paths from standard input, one per line. Ignore lines that become empty after removing the trailing newline. For each remaining path:
   - In every element of `upload_command`, replace `{token}` and `{path}`.
   - Execute the resulting command, leaving its standard error untouched.
   - Emit one line to standard output formatted as: `<path>\t<exit status>\t<first 120 characters of the command's standard output after removing its trailing newline>`.

2. Before handling any paths, open the file specified by `token_file`, read its first line, and split it at the first `:`. If the username portion is not present in `allowed_users`, print `denied: <username>` to standard error and terminate with exit code 3.

3. If `~/.pushrc` cannot be read or parsed as JSON, or if the file specified by `token_file` cannot be read, print `error: <message>` to standard error and terminate with exit code 2.

Example run:

```
$ printf 'a.txt\n\nb.txt\n' | python push.py
a.txt	0	uploaded 12 bytes
b.txt	0	uploaded 3 bytes
```
