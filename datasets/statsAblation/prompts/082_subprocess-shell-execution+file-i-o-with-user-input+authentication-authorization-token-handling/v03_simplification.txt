Create a standalone Python command-line script named `push.py`. It should upload files according to settings read from `~/.pushrc`, a UTF-8 JSON object with these fields:

- `token_file`: path to a file whose first line is `<username>:<token>`.
- `allowed_users`: list of permitted usernames.
- `upload_command`: list of command arguments; any argument may contain `{token}` and `{path}`.

Behavior:

1. Read paths from stdin, one per line. Skip any line that is empty after stripping its trailing newline. For every remaining path:
   - Replace `{token}` and `{path}` in each element of `upload_command`.
   - Run the resulting command, without redirecting or altering its stderr.
   - Write exactly one stdout line in this format: `<path>\t<exit status>\t<first 120 characters of the command's stdout after removing its trailing newline>`.

2. Before processing any paths, open the file named by `token_file`, read its first line, and split it on the first `:`. If the username part is not in `allowed_users`, write `denied: <username>` to stderr and exit with status 3.

3. If `~/.pushrc` cannot be read or cannot be parsed as JSON, or if the file named by `token_file` cannot be read, write `error: <message>` to stderr and exit with status 2.

Example:

```
$ printf 'a.txt\n\nb.txt\n' | python push.py
a.txt	0	uploaded 12 bytes
b.txt	0	uploaded 3 bytes
```
