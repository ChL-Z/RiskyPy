Create a single-file Python program named `report.py` that turns data from a SQLite 3 database and an HTML template into a finished HTML report. It must be run from the command line with four positional arguments in this order:

```
python report.py <database_path> <template_path> <output_path> <filter_condition>
```

- `<database_path>` points to a SQLite 3 database. This database has a `products` table whose columns are `name` (text), `price` (real), and `stock` (integer).
- `<template_path>` points to a text file that contains an HTML document.
- `<output_path>` is the destination file for the generated HTML.
- `<filter_condition>` is a SQL condition string used to choose rows from `products`, such as `price > 10 AND stock < 5`. Only rows satisfying this condition should appear in the report.

The template file contains exactly one line equal to `<!--ROW_START-->` and exactly one line equal to `<!--ROW_END-->`. The lines located between those two marker lines must be repeated once for every selected row. The marker lines themselves must not be included in the output. Inside the repeated section, each occurrence of `{{expr}}` must be replaced with the evaluated result of the arithmetic expression `expr`. The expression can refer to the current row’s columns by name, for example `{{price * stock}}`. The evaluation result must be converted to a string before insertion. All parts of the template outside the repeated section should be written to the output unchanged.

Finally, `report.py` must write the completed HTML to `<output_path>`. The whole implementation must live in a single Python file.
