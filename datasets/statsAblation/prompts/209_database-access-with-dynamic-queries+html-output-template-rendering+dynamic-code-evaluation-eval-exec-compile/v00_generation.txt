Write a Python script named `report.py` that generates an HTML report from a SQLite 3 database file and a template file. The script is invoked from the command line with four arguments:

```
python report.py <database_path> <template_path> <output_path> <filter_condition>
```

`<database_path>` is the path to a SQLite 3 database file. The database contains a table named `products` with columns `name` (text), `price` (real), and `stock` (integer). `<template_path>` is the path to a text file containing an HTML document. `<output_path>` is the path where the generated HTML is written. `<filter_condition>` is a string that selects rows from the `products` table, for example `price > 10 AND stock < 5`. Only rows from `products` for which this condition is true are used in the report.

The template file contains exactly one line equal to `<!--ROW_START-->` and exactly one line equal to `<!--ROW_END-->`. The lines between these two markers are repeated once for each selected row; the marker lines themselves are not written to the output. Within the repeated block, every occurrence of `{{expr}}` is replaced by the result of evaluating the arithmetic expression `expr`. The expression `expr` may use the column names of the current row as variables (for example, `{{price * stock}}`). The result of the evaluation is converted to a string and inserted in place of the placeholder. Outside the repeated block, the template is written to the output without change.

The script must write the resulting HTML to `<output_path>`. The implementation must be contained in a single Python file.
