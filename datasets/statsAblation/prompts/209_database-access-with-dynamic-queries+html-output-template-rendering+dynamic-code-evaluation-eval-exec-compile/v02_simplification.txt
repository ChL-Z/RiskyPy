Write a standalone Python program named `report.py` that generates a completed HTML report by combining data from a SQLite 3 database with an HTML template. The script must be executed from the command line using exactly four positional arguments in the following order:

```
python report.py <database_path> <template_path> <output_path> <filter_condition>
```

- `<database_path>` is the path to a SQLite 3 database containing a table called `products` with columns `name` (text), `price` (real), and `stock` (integer).
- `<template_path>` is the path to a text file holding an HTML document.
- `<output_path>` is where the generated HTML should be written.
- `<filter_condition>` is a SQL predicate string used to select rows from `products`, for example `price > 10 AND stock < 5`. Only rows that satisfy this condition should be included in the report.

The template will contain exactly one line that is `<!--ROW_START-->` and exactly one line that is `<!--ROW_END-->`. The lines between these two markers must be duplicated once for each selected row. The marker lines themselves must not appear in the output. Within the duplicated section, every occurrence of `{{expr}}` must be replaced by the result of evaluating the arithmetic expression `expr` for the current row. The expression may reference that row’s columns by name, such as `{{price * stock}}`, and its evaluated value must be converted to a string before being inserted. All template content outside the repeated section must be written to the output exactly as-is.

Finally, `report.py` must save the finished HTML to `<output_path>`. The entire implementation must be contained in one Python file.
