Write a Python script in a single file. The script takes one command-line argument: the path to an XML configuration file. The XML file has a root element `<reports>`. Each child of `<reports>` is a `<report>` element with a `name` attribute. Each `<report>` contains one or more `<field>` elements. Each `<field>` has a `name` attribute and an `expr` attribute. The `expr` attribute contains an arithmetic expression composed of numbers, variable names, the operators `+`, `-`, `*`, `/`, and parentheses. All variable names referenced in expressions are defined either in the initial input or by a field computed earlier in the same or a previous report.

The script reads newline-separated lines from standard input until EOF. Each non-empty line has the form `key=value` with no spaces around the `=`, where `key` is a variable name and `value` is a number. These lines define the initial variable environment.

For each `<report>` in the order it appears in the XML file, and for each `<field>` in the order it appears within that report, the script computes the value of the `expr` attribute using the current variable environment. The variable environment initially contains the variables read from standard input. After computing a field, its `name` and computed value are added to the variable environment for subsequent fields. The script then prints one line to standard output for each field in the format `<report_name>.<field_name>=<value>`, where `<value>` is the computed number printed as an integer if it has no fractional part, otherwise as a decimal number.

Example:

XML file `config.xml`:
```xml
<reports>
  <report name="sales">
    <field name="units" expr="20"/>
    <field name="price" expr="7.5"/>
    <field name="revenue" expr="units * price"/>
  </report>
  <report name="inventory">
    <field name="start" expr="100"/>
    <field name="sold" expr="units"/>
    <field name="remaining" expr="start - sold"/>
  </report>
</reports>
```

Standard input:
```
discount=2
```

Command: `python script.py config.xml`

Output:
```
sales.units=20
sales.price=7.5
sales.revenue=150
inventory.start=100
inventory.sold=20
inventory.remaining=80
```
