Create one Python program, runnable as a single script, that accepts exactly one command-line argument: the path to an XML configuration file. The XML root is <reports>. Each <report> has a name attribute and contains one or more <field> children. Each <field> has a name attribute and an expr attribute. The expr value is an arithmetic expression using numeric literals, variable names, parentheses, and the operators +, -, *, and /. Any variable referenced in an expression must already exist at that point, either from the initial stdin data or from an earlier field that was already evaluated (in the same report or a previous report).

First, read stdin completely to EOF. Ignore blank lines. Every non-blank stdin line must be key=value, with no spaces around the equals sign. The key is a variable name and the value is numeric. These define the starting variables.

Then process the <report> elements in the exact order they appear in the XML, and process each report's <field> elements in order. For each field, evaluate its expression using the currently known variables, then store the field's name and computed value into the environment so later fields can use it. For every evaluated field, print one line to stdout in this format:

<report_name>.<field_name>=<value>

If the computed value is a whole number, print it without a decimal point. Otherwise, print it as a decimal number.

Example:

XML file config.xml:
<reports>
  <report name="sales">
    <field name="units" expr="20"/>
    <field name="price" expr="7.5"/>
    <field name="revenue" expr="units * price"/>
  </report>
  <report name="inventory">
    <field name="start" expr="100"/>
    <field name="sold" expr="units"/>
    <field name="remaining" expr="start - sold"/>
  </report>
</reports>

Standard input:
discount=2

Command:
python script.py config.xml

Output:
sales.units=20
sales.price=7.5
sales.revenue=150
inventory.start=100
inventory.sold=20
inventory.remaining=80
