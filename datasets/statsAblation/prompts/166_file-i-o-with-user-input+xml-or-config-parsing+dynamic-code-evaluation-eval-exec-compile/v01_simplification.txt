Create a single-file Python program that accepts one command-line argument: the path to an XML configuration file. The XML document’s root element is <reports>. Inside it, each <report> element has a name attribute and contains one or more <field> elements. Every <field> has a name attribute and an expr attribute. The expr value is an arithmetic expression using numeric literals, variable names, parentheses, and the operators +, -, *, and /. Any variable name used in an expression must already be defined either by the initial input or by an earlier-computed field, whether from the same report or a previous report.

Before processing the XML, read standard input until EOF. Ignore empty lines. Every other line must have the form key=value with no spaces around the equals sign. The key is a variable name and the value is a number. These lines establish the initial variable environment.

Process the reports in the order they appear in the XML file, and process the fields in the order they appear within each report. For each field, evaluate its expr using the current variable environment. After evaluating a field, add its name and computed value to the environment so later fields can use it. For each field, print one line to standard output in the form <report_name>.<field_name>=<value>. Print <value> as an integer if it has no fractional part; otherwise print it as a decimal number.

Example:

XML file config.xml:
<reports>
  <report name="sales">
    <field name="units" expr="20"/>
    <field name="price" expr="7.5"/>
    <field name="revenue" expr="units * price"/>
  </report>
  <report name="inventory">
    <field name="start" expr="100"/>
    <field name="sold" expr="units"/>
    <field name="remaining" expr="start - sold"/>
  </report>
</reports>

Standard input:
discount=2

Command:
python script.py config.xml

Output:
sales.units=20
sales.price=7.5
sales.revenue=150
inventory.start=100
inventory.sold=20
inventory.remaining=80
