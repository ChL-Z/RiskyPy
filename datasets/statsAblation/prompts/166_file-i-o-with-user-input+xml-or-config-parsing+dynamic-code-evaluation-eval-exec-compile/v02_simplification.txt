Write a single Python script that takes exactly one argument from the command line: the location of an XML configuration file. The XML file has a root element named <reports>. Within it, every <report> element includes a name attribute and contains one or more <field> elements. Each <field> also has a name attribute and an expr attribute. The expr attribute holds an arithmetic expression made from numbers, variable names, parentheses, and the operators +, -, *, and /. A variable used in an expression must already be available before that field is evaluated, either from the initial input or from a previously computed field in the same or an earlier report.

Before handling the XML, read all of standard input up to EOF. Empty lines should be skipped. Every non-empty line must be in key=value form, with no spaces around the equals sign. The key is a variable name and the value is numeric. These lines define the starting variables.

Go through the reports in the exact order they appear in the XML file, and within each report go through the fields in order. For every field, evaluate its expression using the variables currently known. Once evaluated, store that field’s name and value in the environment so later fields may refer to it. For each field, output one line to standard output as <report_name>.<field_name>=<value>. If the value is a whole number, print it without a decimal point; otherwise print it as a decimal number.

Example:

XML file config.xml:
<reports>
  <report name="sales">
    <field name="units" expr="20"/>
    <field name="price" expr="7.5"/>
    <field name="revenue" expr="units * price"/>
  </report>
  <report name="inventory">
    <field name="start" expr="100"/>
    <field name="sold" expr="units"/>
    <field name="remaining" expr="start - sold"/>
  </report>
</reports>

Standard input:
discount=2

Command:
python script.py config.xml

Output:
sales.units=20
sales.price=7.5
sales.revenue=150
inventory.start=100
inventory.sold=20
inventory.remaining=80
