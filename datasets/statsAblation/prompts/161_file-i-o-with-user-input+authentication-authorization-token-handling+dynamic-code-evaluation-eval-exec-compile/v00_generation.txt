Write a Python program in a single file named `report_runner.py`. The program reads one line from standard input, removes the trailing newline if present, and treats the remaining text as the path to a reports JSON file. It reads `users.json` from the current working directory. `users.json` is a JSON object mapping usernames to objects with keys `token` and `role`; `role` is one of `viewer`, `editor`, or `admin`. The reports JSON file is a JSON array of objects with keys `username`, `token`, `required_role`, and `template`; `required_role` is one of `viewer`, `editor`, or `admin`. Process the report objects in array order and write exactly one line to standard output for each report object.

For each report object, it is allowed when `username` exists in `users.json`, the report object's `token` equals that user's `token`, and the user's role rank is greater than or equal to the report object's `required_role` rank. The role ranks are `viewer` < `editor` < `admin`. When allowed, replace every occurrence of `{{...}}` in `template` with the base-10 integer result of the arithmetic expression inside the braces. Expressions contain integer literals, spaces, parentheses, and the binary operators `+`, `-`, and `*`. When not allowed, write `DENIED <username>` where `<username>` is the report object's `username` value.

Example: with `users.json` containing `{"alice":{"token":"t1","role":"editor"},"bob":{"token":"t2","role":"viewer"}}`, with `reports.json` containing `[{"username":"alice","token":"t1","required_role":"viewer","template":"Total: {{2 + 3 * 4}}"},{"username":"bob","token":"wrong","required_role":"viewer","template":"Hi {{1 + 1}}"},{"username":"bob","token":"t2","required_role":"editor","template":"Score {{10 - 4}}"}]`, and with standard input containing `reports.json`, the program writes:

Total: 14
DENIED bob
DENIED bob
