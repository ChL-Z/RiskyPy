Write a single Python source file that implements a command-line utility. The script will be invoked with three positional arguments, in this order: the path to a JSON file containing an array of book records, the path to a SQLite database file, and the path to a JSON file containing a query specification. Each book record is a JSON object with fields "title" (string), "author" (string), and "year" (integer). The query specification is a JSON object with fields "field" (string) and "value" (string or integer). The utility must satisfy all of the following requirements:

1. Read the book records from the first JSON file and insert each record into a table named "books" in the SQLite database. If the table does not already exist, create it with columns "title" (text), "author" (text), and "year" (integer). If a row with the same "title" and "author" already exists, replace it with the new record.

2. Read the query specification from the second JSON file. Query the "books" table for all rows where the column specified by "field" equals the value specified by "value". Print the matching rows to standard output as a JSON array. The matching rows must be returned in the same order in which they were inserted into the table.

3. Append one line to a file named "app.log" in the current working directory for each of the following events: reading the first JSON file, reading the second JSON file, inserting or replacing each book record, querying the database, and any error that occurs. Each log line must start with an ISO 8601 timestamp, followed by a space, then either "INFO" or "ERROR", followed by a space, then a message. If an error occurs, print a message to standard error and exit with a non-zero status code.

Example:
Assume books.json contains: [{"title": "The Hobbit", "author": "Tolkien", "year": 1937}, {"title": "1984", "author": "Orwell", "year": 1949}]
Assume query.json contains: {"field": "author", "value": "Tolkien"}
Executing `python utility.py books.json library.db query.json` must write to stdout: [{"title": "The Hobbit", "author": "Tolkien", "year": 1937}]
The app.log file must contain lines matching this pattern: <ISO 8601 timestamp> INFO <message>.
