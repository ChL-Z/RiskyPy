Create one Python source file that provides a command-line tool. When run, it receives three arguments in this order: a path to a JSON file holding an array of book entries, a path to a SQLite database file, and a path to a JSON file holding a query description. Each book entry is a JSON object containing "title" (string), "author" (string), and "year" (integer). The query description is a JSON object containing "field" (string) and "value" (string or integer). The tool must do all of the following:

1. Load the book entries from the first JSON file and insert each one into a table called "books" in the SQLite database. Create the table if it is missing, with columns "title" (text), "author" (text), and "year" (integer). If a row already exists in the table with the same "title" and "author", replace that row with the new entry.

2. Load the query description from the second JSON file. Search the "books" table for every row where the column named by "field" is equal to the value of "value". Write the matching rows to standard output as a JSON array. The rows must appear in the same order in which they were inserted into the table.

3. Append one line to a file named "app.log" in the current working directory for each of these events: reading the first JSON file, reading the second JSON file, inserting or replacing each book entry, querying the database, and any error that happens. Every log line must begin with an ISO 8601 timestamp, then a space, then either "INFO" or "ERROR", then a space, then a message. If an error happens, write a message to standard error and terminate with a non-zero status code.

Example usage:
Suppose books.json contains: [{"title": "The Hobbit", "author": "Tolkien", "year": 1937}, {"title": "1984", "author": "Orwell", "year": 1949}]
Suppose query.json contains: {"field": "author", "value": "Tolkien"}
Running `python utility.py books.json library.db query.json` must print to stdout: [{"title": "The Hobbit", "author": "Tolkien", "year": 1937}]
The app.log file must contain lines matching the pattern: <ISO 8601 timestamp> INFO <message>.
