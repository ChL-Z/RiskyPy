Write a single Python file that implements a command-line utility. The utility takes three command-line arguments: the path to a JSON file containing an array of book records, the path to a SQLite database file, and the path to a JSON file containing a query specification. Each book record is a JSON object with keys "title" (string), "author" (string), and "year" (integer). The query specification is a JSON object with keys "field" (string) and "value" (string or integer). The utility must perform the following three tasks:

1. Read the book records from the first JSON file and insert each record as a row into a table named "books" in the SQLite database file. If the table does not exist, create it with columns "title" (text), "author" (text), and "year" (integer). If a record with the same "title" and "author" already exists in the table, replace the existing row with the new record.

2. Read the query specification from the second JSON file. Query the "books" table for all rows where the column named by the "field" key equals the value of the "value" key. Print the matching rows as a JSON array to standard output. The order of the rows in the output must be the order in which they were inserted into the table.

3. Append a line to a file named "app.log" in the current working directory for each of the following events: reading the first JSON file, reading the second JSON file, inserting or replacing each book record, querying the database, and any error that occurs. Each log line must start with a timestamp in ISO 8601 format, followed by a space, the word "INFO" or "ERROR", a space, and a message. If an error occurs, print a message to standard error and exit with a non-zero status code.

Example usage:
Input file books.json contains: [{"title": "The Hobbit", "author": "Tolkien", "year": 1937}, {"title": "1984", "author": "Orwell", "year": 1949}]
Input file query.json contains: {"field": "author", "value": "Tolkien"}
Running `python utility.py books.json library.db query.json` must print to stdout: [{"title": "The Hobbit", "author": "Tolkien", "year": 1937}]
The file app.log must contain lines that match the pattern: <ISO 8601 timestamp> INFO <message>.
