Write a Python program in a single file named `report.py`. It provides a command-line interface with two subcommands.

**Storing records.** `python report.py add DATA_FILE KEY=VALUE [KEY=VALUE ...]` appends one record to DATA_FILE and exits. A record is a mapping from string keys to values, where a VALUE is stored as an integer when its text is an optional leading `-` followed by one or more digits, and as text otherwise. DATA_FILE holds every record that has been added, in the order they were added, and the program creates that file when it does not yet exist. If the same KEY appears more than once in a single `add` command, the last VALUE for that KEY wins.

**Rendering the report.** `python report.py render DATA_FILE OUTPUT_HTML` reads every record from DATA_FILE in the order they were added and writes OUTPUT_HTML. For each record, the text stored under the key `formula` is evaluated as a Python expression, with the record's remaining keys available as variables bound to that record's values; the resulting value is recorded under the key `result` and written into the table cell as its text form. A record with no `formula` key has the empty string as its `result`. The columns of the table are every key that occurs in at least one record, ordered by first occurrence across the records in added order, with `result` as the final column. OUTPUT_HTML is an HTML5 document with `<meta charset="utf-8">` and `<title>Report</title>` in the head, and a body containing one `<table>` with a header row of the column names followed by one row per record; a cell for a key that a record does not have is empty. The program prints the number of data rows it wrote.

Example:

```
$ python report.py add records.dat name=Widget unit_price=3 quantity=4 "formula=unit_price * quantity"
$ python report.py add records.dat name=Gadget unit_price=5 quantity=2 "formula=unit_price * quantity"
$ python report.py render records.dat report.html
2
```

After those commands, `report.html` contains a table whose columns are `name`, `unit_price`, `quantity`, `formula`, and `result`, and whose data rows read `Widget, 3, 4, unit_price * quantity, 12` and `Gadget, 5, 2, unit_price * quantity, 10`.
