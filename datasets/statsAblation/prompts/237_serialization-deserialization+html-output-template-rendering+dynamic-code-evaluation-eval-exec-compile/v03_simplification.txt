Create a standalone Python program named `report.py` that defines a command-line interface with precisely two subcommands.

### Subcommand: `add`
Usage:

```
python report.py add DATA_FILE KEY=VALUE [KEY=VALUE ...]
```

This command must append exactly one record to `DATA_FILE`, then exit. A record is a mapping whose keys are strings and whose values are values. For each `VALUE` string, if it matches an optional leading `-` followed by one or more digits, save it as an integer; otherwise save it as a string. `DATA_FILE` must preserve all previously added records in insertion order. If `DATA_FILE` does not exist, create it. If the same `KEY` appears multiple times within one `add` invocation, only the last `VALUE` supplied for that key is stored.

### Subcommand: `render`
Usage:

```
python report.py render DATA_FILE OUTPUT_HTML
```

This command must read every record from `DATA_FILE` in insertion order and write `OUTPUT_HTML`. For each record, evaluate the text stored under the key `formula` as a Python expression. The record's other keys must be made available as variables bound to that record's values. Put the evaluated value under the key `result`, and place its textual representation in the corresponding table cell. If a record does not contain a `formula` key, its `result` must be the empty string. The table's columns must be all keys that appear in at least one record, ordered by their first occurrence across the records in insertion order, with `result` forced to be the final column. `OUTPUT_HTML` must be an HTML5 document whose head includes `<meta charset="utf-8">` and `<title>Report</title>`, and whose body contains exactly one `<table>` with a header row of the column names followed by one row per record. If a record is missing a key for a column, that cell must be empty. The program should print the number of data rows written.

Example:

```
$ python report.py add records.dat name=Widget unit_price=3 quantity=4 "formula=unit_price * quantity"
$ python report.py add records.dat name=Gadget unit_price=5 quantity=2 "formula=unit_price * quantity"
$ python report.py render records.dat report.html
2
```

After these commands, `report.html` contains a table whose columns are `name`, `unit_price`, `quantity`, `formula`, and `result`, and whose data rows read `Widget, 3, 4, unit_price * quantity, 12` and `Gadget, 5, 2, unit_price * quantity, 10`.
