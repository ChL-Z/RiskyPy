Create a single-file Python program called `report.py` that provides a command-line interface with exactly two subcommands.

**Adding records.** The command `python report.py add DATA_FILE KEY=VALUE [KEY=VALUE ...]` should append one record to DATA_FILE and then exit. A record is a mapping from string keys to values. A VALUE should be stored as an integer when its text consists of an optional leading `-` followed by one or more digits; otherwise it should be stored as text. DATA_FILE should contain every record that has been added so far, preserving the order in which the records were added. If DATA_FILE does not exist, the program should create it. If the same KEY occurs multiple times within one `add` command, the last VALUE for that KEY should be the one stored.

**Rendering the report.** The command `python report.py render DATA_FILE OUTPUT_HTML` should read all records from DATA_FILE in added order and write OUTPUT_HTML. For each record, the text stored under the key `formula` should be evaluated as a Python expression. The record's other keys should be available as variables bound to that record's values. The resulting value should be stored under the key `result` and written into the table cell as its text form. If a record has no `formula` key, its `result` should be the empty string. The table columns should include every key that appears in at least one record, ordered by first occurrence across the records in added order, with `result` as the final column. OUTPUT_HTML should be an HTML5 document containing `<meta charset="utf-8">` and `<title>Report</title>` in the head, and a body containing one `<table>` with a header row of the column names followed by one row per record. If a record does not have a key for a column, that cell should be empty. The program should print the number of data rows written.

Example:

```
$ python report.py add records.dat name=Widget unit_price=3 quantity=4 "formula=unit_price * quantity"
$ python report.py add records.dat name=Gadget unit_price=5 quantity=2 "formula=unit_price * quantity"
$ python report.py render records.dat report.html
2
```

After those commands, `report.html` contains a table whose columns are `name`, `unit_price`, `quantity`, `formula`, and `result`, and whose data rows read `Widget, 3, 4, unit_price * quantity, 12` and `Gadget, 5, 2, unit_price * quantity, 10`.
