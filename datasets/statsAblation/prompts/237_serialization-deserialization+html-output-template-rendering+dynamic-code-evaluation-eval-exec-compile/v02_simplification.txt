Write a standalone Python script named `report.py` that implements a command-line tool with exactly two subcommands.

**Record insertion.** The invocation `python report.py add DATA_FILE KEY=VALUE [KEY=VALUE ...]` must append one record to `DATA_FILE` and then terminate. Each record is a mapping from string keys to values. When a VALUE’s text is an optional leading `-` followed by one or more digits, store it as an integer; otherwise store it as text. `DATA_FILE` must retain every record added so far in insertion order. If `DATA_FILE` is missing, create it. If the same KEY appears more than once in a single `add` command, the final VALUE for that KEY is the one stored.

**Report generation.** The invocation `python report.py render DATA_FILE OUTPUT_HTML` must read all records from `DATA_FILE` in insertion order and write `OUTPUT_HTML`. For each record, evaluate the text stored under the key `formula` as a Python expression. The record’s other keys must be available as variables bound to that record’s values. Store the evaluated value under the key `result` and place its textual form in the corresponding table cell. If a record has no `formula` key, its `result` should be the empty string. The table columns must be all keys that occur in at least one record, ordered by first occurrence across the records in insertion order, with `result` as the last column. `OUTPUT_HTML` must be an HTML5 document whose head contains `<meta charset="utf-8">` and `<title>Report</title>`, and whose body contains one `<table>` with a header row of the column names followed by one row per record. If a record lacks a key for a column, that cell must be empty. The program should print the number of data rows written.

Example:

```
$ python report.py add records.dat name=Widget unit_price=3 quantity=4 "formula=unit_price * quantity"
$ python report.py add records.dat name=Gadget unit_price=5 quantity=2 "formula=unit_price * quantity"
$ python report.py render records.dat report.html
2
```

After these commands, `report.html` contains a table whose columns are `name`, `unit_price`, `quantity`, `formula`, and `result`, and whose data rows read `Widget, 3, 4, unit_price * quantity, 12` and `Gadget, 5, 2, unit_price * quantity, 10`.
