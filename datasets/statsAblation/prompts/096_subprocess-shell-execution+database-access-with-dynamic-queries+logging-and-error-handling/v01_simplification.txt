Write a Python script saved as `job_runner.py`. It is run from the command line as `python job_runner.py config.json`, where the only positional argument is the path to a JSON configuration file.

The JSON file must contain exactly these keys: `database_path`, a string path to an SQLite database file; `jobs_table`, a string naming a table in that database; and `log_file`, a string path to a text file. The table specified by `jobs_table` has the columns `id INTEGER PRIMARY KEY`, `command TEXT`, `status TEXT`, and `output TEXT`.

The script should do the following:

1. Load the JSON config. From the indicated table, select every row whose `status` is `'pending'`, sorted by `id` in ascending order. For each selected row, execute the value in `command` as an external command, capturing both stdout and stderr together.

2. Once the command has completed, update that row so its `status` becomes `'done'` if the exit code is 0, or `'failed'` otherwise. Store the captured combined output in the row's `output` column. If the command cannot be launched at all, mark the row as `'failed'` and store the launch error text in `output`. Also append exactly one line to `log_file` using the format `id=<id> status=<status> output=<output>`, matching the values written to the database.

3. If the config file is absent, has invalid JSON, or is missing any required key, print `config error: <message>` to stderr and exit with status 1. If any database action raises an error, print `database error: <message>` to stderr and exit with status 1. If an individual job command fails, keep processing the remaining rows. After all rows are handled, exit with status 1 if at least one job failed; otherwise exit with status 0.
