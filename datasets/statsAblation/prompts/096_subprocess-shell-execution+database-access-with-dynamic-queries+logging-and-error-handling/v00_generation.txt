Create a Python file named `job_runner.py`. It is a command-line utility invoked as `python job_runner.py config.json`. The first argument is the path to a JSON file. The JSON file has exactly these keys: `database_path` (a string path to an SQLite database file), `jobs_table` (a string name of a table in that database), and `log_file` (a string path to a text file). The table named by `jobs_table` has columns `id INTEGER PRIMARY KEY`, `command TEXT`, `status TEXT`, and `output TEXT`.

The script must:

1. Read the JSON config. Query the table named by `jobs_table` for all rows where `status` is `'pending'`, ordered by `id` ascending. For each row, run the value of `command` as an external command and capture its combined stdout and stderr.

2. After the command finishes, set the row's `status` to `'done'` if the command exits with code 0, otherwise set it to `'failed'`. Set the row's `output` column to the captured combined output. If the command cannot be started, set `status` to `'failed'` and set `output` to the text of the start error. Append one line to `log_file` in the exact format `id=<id> status=<status> output=<output>`, using the same values written to the database.

3. If the config file is missing, contains invalid JSON, or lacks any required key, write `config error: <message>` to stderr and exit with code 1. If any database operation fails, write `database error: <message>` to stderr and exit with code 1. If a job command fails, continue processing the remaining rows and after all rows are processed exit with code 1 if at least one job failed, otherwise exit with code 0.
