Create a Python program called `job_runner.py`. It will be executed from the command line as `python job_runner.py config.json`, where the sole positional argument is the path to a JSON configuration file.

The JSON configuration must contain exactly the keys `database_path`, `jobs_table`, and `log_file`. `database_path` is a string giving the path to an SQLite database file. `jobs_table` is a string naming a table in that database. `log_file` is a string giving the path to a text file. The table named by `jobs_table` has columns `id INTEGER PRIMARY KEY`, `command TEXT`, `status TEXT`, and `output TEXT`.

The script must perform these actions:

1. Read the JSON config. From the specified table, fetch all rows whose `status` is `'pending'`, ordered by `id` ascending. For each such row, run the value of `command` as an external command, capturing stdout and stderr together as one combined output.

2. After the command finishes, update the row so that `status` is set to `'done'` when the command exit code is 0, and `'failed'` otherwise. Put the captured combined output into the row’s `output` column. If the command cannot be started at all, set the row’s `status` to `'failed'` and store the launch error text in `output`. For each processed row, append exactly one line to `log_file` in the format `id=<id> status=<status> output=<output>`, using the same values written to the database.

3. If the config file does not exist, contains invalid JSON, or is missing any required key, print `config error: <message>` to stderr and exit with status 1. If any database operation raises an error, print `database error: <message>` to stderr and exit with status 1. If an individual job command fails, continue processing the remaining rows. After all rows have been handled, exit with status 1 if at least one job failed; otherwise exit with status 0.
