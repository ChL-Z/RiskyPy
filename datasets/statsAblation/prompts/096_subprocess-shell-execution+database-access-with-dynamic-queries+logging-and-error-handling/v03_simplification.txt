Write a Python script named `job_runner.py` that is run from the shell as `python job_runner.py config.json`, where `config.json` is the only positional argument and points to a JSON configuration file.

The JSON config must be an object with exactly three keys: `database_path`, `jobs_table`, and `log_file`. Each value is a string. `database_path` is the SQLite database file path; `jobs_table` is the name of a table in that database; `log_file` is a text file path. The target table contains columns `id INTEGER PRIMARY KEY`, `command TEXT`, `status TEXT`, and `output TEXT`.

The script should:
- Load the JSON configuration.
- Query the configured table for every row with `status = 'pending'`, sorted by `id` in ascending order.
- For each row, execute the row's `command` as an external command and capture its stdout and stderr merged into a single output.
- Update the row after the command completes: set `status` to `'done'` when the exit code is 0, otherwise set it to `'failed'`; store the merged output in `output`. If the command cannot be launched at all, set `status` to `'failed'` and put the launch error text in `output`.
- For every processed row, append one line to `log_file` in exactly this format: `id=<id> status=<status> output=<output>`, using the same values that were written to the database.
- If the config file is absent, has invalid JSON, or does not contain exactly the required keys, print `config error: <message>` to stderr and exit with code 1.
- If any database operation fails, print `database error: <message>` to stderr and exit with code 1.
- If an individual job command fails, continue with the remaining rows. After all rows are processed, exit with code 1 if at least one job failed; otherwise exit with code 0.
