Create one Python source file called `spool.py` that provides a command-line, persistent, rate-limited job spool. Invoke it as:

`python spool.py --state STATE_FILE <subcommand> [options]`

The `--state` option is mandatory and specifies the spool state file. If that file does not already exist, create it.

Implement these subcommands:

1. `add`
   - Read command strings from standard input, one per line.
   - Every non-empty line becomes a pending job.
   - Assign jobs increasing integer ids beginning at 1, using the next unused id each time.
   - For each accepted job, print `added <id>`.
   - The spool must persist across process exits, so a later invocation using the same `--state` file sees the same pending jobs and continues with the next unused id.

2. `run --rate N`
   - Process pending jobs in ascending id order.
   - Run each job's command text as an external command.
   - Start no more than N jobs per second; `N` is a positive integer, and at most N jobs may be started in any 1000 ms window.
   - For every job that is started, print `ran <id> <exit_code>`.
   - Treat exit code 0 as successful and any non-zero exit code as failed.
   - Record successful jobs as done and failed jobs as failed in the spool.
   - Jobs that have not been started when the run stops remain pending.

3. `status`
   - Print exactly one line in this format:
     `pending=<p> done=<d> failed=<f>`
   - The values must be the current counts stored in the spool.

Example usage:

```
$ printf 'echo one\necho two\n' | python spool.py --state jobs.spool add
added 1
added 2
$ python spool.py --state jobs.spool run --rate 2
ran 1 0
ran 2 0
$ python spool.py --state jobs.spool status
pending=0 done=2 failed=0
```
