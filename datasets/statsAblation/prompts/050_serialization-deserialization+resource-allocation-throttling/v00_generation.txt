Write a single Python file named `spool.py` that implements a persistent, rate-limited job spool. The program is driven from the command line as `python spool.py --state STATE_FILE <subcommand> [options]`, where `--state` is required and names the file in which the spool is kept. The state file is created when it does not exist.

1. `add` — read newline-separated command strings from standard input. Each line that is not empty becomes one pending job, assigned the next unused integer id, with ids starting at 1 and increasing by one. Print one line per accepted job: `added <id>`. After the process exits, a later invocation of the program with the same `--state` value must observe the same pending jobs and continue numbering from the next unused id.

2. `run --rate N` — take the pending jobs in ascending id order and run each job's command text as an external command, starting at most N jobs per second, where N is a positive integer and at most N jobs may be started within any 1000 ms window. For each job, print `ran <id> <exit_code>`, where exit code 0 means the command finished successfully and any other value means it failed, then record the job in the spool as done (exit code 0) or failed (non-zero exit code). Jobs that have not been started when the run stops remain pending.

3. `status` — print exactly one line: `pending=<p> done=<d> failed=<f>`, using the current counts in the spool.

Example session:

```
$ printf 'echo one\necho two\n' | python spool.py --state jobs.spool add
added 1
added 2
$ python spool.py --state jobs.spool run --rate 2
ran 1 0
ran 2 0
$ python spool.py --state jobs.spool status
pending=0 done=2 failed=0
```
