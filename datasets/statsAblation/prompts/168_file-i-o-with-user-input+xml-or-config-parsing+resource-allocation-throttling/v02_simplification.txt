Develop a standalone Python script that acts as an XML-configured command dispatcher. The script must take exactly one command-line argument: the filesystem path of an XML configuration file. After starting, it reads task IDs from stdin, one per line, ignoring empty lines, until stdin reaches EOF. The XML configuration follows this structure:

```xml
<dispatcher max_parallel="3" min_interval_ms="200">
  <task id="alpha"><command>echo hello</command></task>
  <task id="beta"><command>sleep 1; echo done</command></task>
</dispatcher>
```

For each task ID read from stdin, look up the `<task>` element whose `id` attribute equals that ID. If a matching task exists, run the text contained in its `<command>` child as a command line, capture both stdout and stderr, and emit exactly one result line to stdout in this format:

`<task_id>\t<exit_code>\t<captured_stdout_with_newlines_replaced_by_spaces>\t<captured_stderr_with_newlines_replaced_by_spaces>`

If no matching task ID exists in the configuration, emit `<task_id>\tUNAVAILABLE` instead and do not execute any command.

Honor both root-level configuration settings:
- `max_parallel`: at most this many commands may be running at the same time. Whenever one finishes, another may begin.
- `min_interval_ms`: the start times of successive commands must be separated by at least this many milliseconds.

Result lines may be produced in any order, but all result lines must be printed before the program terminates. If the configuration file cannot be parsed, print `CONFIG_ERROR` to stderr and exit with status code 2.
