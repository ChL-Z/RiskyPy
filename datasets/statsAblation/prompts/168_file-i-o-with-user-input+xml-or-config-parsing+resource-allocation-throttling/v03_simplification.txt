Create a self-contained Python script that reads commands from an XML file and dispatches them based on task IDs entered on standard input.

The script must accept exactly one command-line argument: the path to the XML configuration file. Once started, it reads task IDs from stdin, one ID per line, skipping blank lines, until EOF.

The XML file has this form:

```xml
<dispatcher max_parallel="3" min_interval_ms="200">
  <task id="alpha"><command>echo hello</command></task>
  <task id="beta"><command>sleep 1; echo done</command></task>
</dispatcher>
```

For every task ID read from stdin, find the `<task>` element whose `id` attribute equals that ID. If such a task exists, execute the text inside its `<command>` child as a command line, capture both stdout and stderr, and print exactly one output line to stdout in this tab-separated format:

`<task_id>	<exit_code>	<captured_stdout_with_newlines_replaced_by_spaces>	<captured_stderr_with_newlines_replaced_by_spaces>`

If no task with that ID exists in the XML, instead print `<task_id>	UNAVAILABLE` and do not run any command.

The root `<dispatcher>` element also controls concurrency and timing:
- `max_parallel`: no more than this many commands may run simultaneously. As soon as one command finishes, another may start.
- `min_interval_ms`: the starts of consecutive commands must be separated by at least this many milliseconds.

Output lines may appear in any order, but every result line must be printed before the program exits.

If the configuration file cannot be parsed, write `CONFIG_ERROR` to stderr and terminate with exit status code 2.
