Write a Python program in a single file that acts as a task dispatcher. The program takes one command-line argument: the path to an XML configuration file. The program reads task IDs from standard input, one per line, ignoring empty lines, until end of input. The XML file has this structure:

```xml
<dispatcher max_parallel="3" min_interval_ms="200">
  <task id="alpha"><command>echo hello</command></task>
  <task id="beta"><command>sleep 1; echo done</command></task>
</dispatcher>
```

For each task ID read from stdin, the program finds the matching `<task>` element by its `id` attribute. It runs the text content of that element's `<command>` child as a command line, captures the command's standard output and standard error, and prints one result line to stdout in the format:

`<task_id>\t<exit_code>\t<captured_stdout_with_newlines_replaced_by_spaces>\t<captured_stderr_with_newlines_replaced_by_spaces>`

Task IDs not present in the configuration print `<task_id>\tUNAVAILABLE` and no command is run.

The program must respect two limits from the configuration root element:
- `max_parallel`: at most this many commands may be running at the same time. New commands start as soon as a slot is free.
- `min_interval_ms`: consecutive command starts must be separated by at least this many milliseconds.

Results may be printed in any order, but all result lines must be printed before the program exits. If the configuration file cannot be parsed, print `CONFIG_ERROR` to stderr and exit with status code 2.
