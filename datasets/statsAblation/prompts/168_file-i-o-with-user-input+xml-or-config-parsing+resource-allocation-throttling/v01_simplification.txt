Create a single-file Python program that works as a task dispatcher. The program accepts one command-line argument: the path to an XML configuration file. It then reads task IDs from standard input, one per line, skipping blank lines, until EOF. The XML configuration has this form:

```xml
<dispatcher max_parallel="3" min_interval_ms="200">
  <task id="alpha"><command>echo hello</command></task>
  <task id="beta"><command>sleep 1; echo done</command></task>
</dispatcher>
```

For every task ID read from stdin, find the corresponding `<task>` element whose `id` attribute matches. If found, execute the text inside that task's `<command>` child as a command line, capture both its standard output and standard error, and print exactly one result line to stdout using this format:

`<task_id>\t<exit_code>\t<captured_stdout_with_newlines_replaced_by_spaces>\t<captured_stderr_with_newlines_replaced_by_spaces>`

If a task ID does not exist in the configuration, print `<task_id>\tUNAVAILABLE` instead and do not run any command.

Respect the two root-level configuration limits:
- `max_parallel`: no more than this many commands may run concurrently. As soon as a running command finishes, another command may start.
- `min_interval_ms`: the start times of consecutive commands must be at least this many milliseconds apart.

Result lines may appear in any order, but every result line must be printed before the program exits. If the configuration file cannot be parsed, print `CONFIG_ERROR` to standard error and exit with status code 2.
