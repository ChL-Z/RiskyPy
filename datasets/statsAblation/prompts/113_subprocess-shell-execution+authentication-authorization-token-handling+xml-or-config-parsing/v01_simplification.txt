Develop a Python script saved as task_runner.py that reads and performs tasks from an XML file.

It accepts exactly one command-line argument: the XML file path. The document's root is <tasks>. Directly under this root there must be one <token> element and at least one <task> element. After stripping leading and trailing whitespace, the <token> element's text is the token value. For each <task>, after stripping leading and trailing whitespace, its text is an argument string whose components are separated by spaces. The first component names the external executable to launch, and the rest are arguments for it.

Process each <task> in document order:
1. In that task's argument text, replace every occurrence of {token} with the token value.
2. Split the modified text using single spaces as separators, yielding the executable name and its arguments.
3. Execute that program with those arguments.
4. Collect both its stdout and stderr together.
5. Print the collected output to stdout and append one newline.

When all tasks are complete, print DONE <N>, where <N> is how many <task> elements were handled.

Example: Suppose tasks.xml contains:

<tasks>
  <token>tok_abc123</token>
  <task>check --host db1 --auth {token}</task>
  <task>sync --dir /data --auth {token}</task>
</tasks>

Running `python task_runner.py tasks.xml` must run `check` with arguments `--host`, `db1`, `--auth`, `tok_abc123`, then run `sync` with arguments `--dir`, `/data`, `--auth`, `tok_abc123`, write the combined output of both programs to standard output, and finally write `DONE 2`.
