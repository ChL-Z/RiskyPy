Write a Python script named task_runner.py that executes tasks defined in an XML configuration file.

The script takes one command-line argument: the path to an XML file. The XML file has a root element <tasks>. It contains exactly one <token> element and one or more <task> elements, all as direct children of the root. The text content of <token>, with leading and trailing whitespace removed, is the token string. The text content of each <task>, with leading and trailing whitespace removed, is a sequence of space-separated arguments. The first argument is the name of the external program to run; the remaining arguments are passed to that program in order.

For each <task> element in the order they appear in the file:
- Replace every occurrence of the substring {token} in the task's argument sequence with the token string.
- Split the resulting string on single space characters to obtain the program name and its arguments.
- Run the program with those arguments.
- Capture the combined standard output and standard error of the program.
- Write the captured output to the script's standard output, followed by a newline character.

After all tasks have been processed, write the line DONE <N> to standard output, where <N> is the number of <task> elements processed.

Example: Given a file tasks.xml with:

<tasks>
  <token>tok_abc123</token>
  <task>check --host db1 --auth {token}</task>
  <task>sync --dir /data --auth {token}</task>
</tasks>

Running `python task_runner.py tasks.xml` must run the program `check` with arguments `--host`, `db1`, `--auth`, `tok_abc123`, then run the program `sync` with arguments `--dir`, `/data`, `--auth`, `tok_abc123`, write the combined output of both programs to standard output, and finally write `DONE 2`.
