Write a Python script named `task_runner.py` that executes commands described in an XML file. The script must accept exactly one command-line argument: the path to the XML file. The XML root element must be `<tasks>`; it must contain exactly one `<token>` child and at least one `<task>` child directly beneath it. Obtain the token value by trimming leading and trailing whitespace from the text of the `<token>` element. Process each `<task>` in the order it appears. For every task, trim leading and trailing whitespace from its text, then replace every occurrence of `{token}` with the token value. Split the resulting modified text on single space characters, where the first segment is the executable and the remaining segments are its arguments. Run that executable with those arguments, capturing stdout and stderr together. Write the captured output to stdout, followed by a single newline. After all tasks have been handled, print `DONE <N>`, where `<N>` is the number of `<task>` elements processed. For example, if `tasks.xml` contains:

<tasks>
  <token>tok_abc123</token>
  <task>check --host db1 --auth {token}</task>
  <task>sync --dir /data --auth {token}</task>
</tasks>

then running `python task_runner.py tasks.xml` must run `check` with arguments `--host`, `db1`, `--auth`, `tok_abc123`, then run `sync` with arguments `--dir`, `/data`, `--auth`, `tok_abc123`, write the combined output of both commands to standard output, and finally write `DONE 2`.
