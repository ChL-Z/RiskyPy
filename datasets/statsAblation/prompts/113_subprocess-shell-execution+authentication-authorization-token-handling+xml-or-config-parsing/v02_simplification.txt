Create a Python program named `task_runner.py` that runs commands specified in an XML file. The script must take exactly one command-line argument: the path to the XML file. The XML root must be `<tasks>`, with exactly one `<token>` child and at least one `<task>` child directly under it. Strip leading and trailing whitespace from the `<token>` text to obtain the token value. For each `<task>`, strip leading and trailing whitespace from its text to obtain a command string; split that string on the space character `' '`, where the first piece is the executable to run and the remaining pieces are its arguments. Process `<task>` elements in document order. For each task: replace every occurrence of `{token}` in the task text with the token value; split the modified text on single spaces to get the executable and arguments; run that executable with those arguments; capture stdout and stderr together; write the captured output to stdout followed by one newline. After all tasks are processed, print `DONE <N>`, where `<N>` is the number of `<task>` elements handled. For example, if `tasks.xml` contains:

<tasks>
  <token>tok_abc123</token>
  <task>check --host db1 --auth {token}</task>
  <task>sync --dir /data --auth {token}</task>
</tasks>

then running `python task_runner.py tasks.xml` must run `check` with arguments `--host`, `db1`, `--auth`, `tok_abc123`, then run `sync` with arguments `--dir`, `/data`, `--auth`, `tok_abc123`, write the combined output of both commands to standard output, and finally write `DONE 2`.
