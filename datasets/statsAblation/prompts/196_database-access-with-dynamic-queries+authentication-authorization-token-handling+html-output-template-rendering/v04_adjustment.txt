Write one Python file called `report.py` that is run like this:

`python report.py <database-path> <filter>`

The program should read a single line from standard input, strip the final newline, and treat the remaining text as an access token. The first command-line argument is the location of a SQLite database, and the second command-line argument is a filter string.

The SQLite database has the following schema:

- `users(token, username, role)`
- `records(owner_id, label, amount)`

The script must do the following:

1. Look up the row in `users` whose `token` matches the access token.
   - If there is no such row, write nothing to standard output and terminate with exit status `1`.
   - If such a row exists but its `role` is not exactly `admin`, write nothing to standard output and terminate with exit status `1`.
   - If such a row exists and its `role` is exactly `admin`, continue.

2. Write an HTML report to standard output using exactly this structure and ordering:
   - `<html><body>`
   - `<h1>Report for NAME</h1>`, where `NAME` is the matched user's `username`
   - `<table>`
   - `<tr><th>Label</th><th>Amount</th></tr>`
   - For each matching `records` row, one line of the form `<tr><td>LABEL</td><td>AMOUNT</td></tr>`, using that row's `label` and `amount`
   - `</table></body></html>`

A `records` row matches if its `label` contains the `<filter>` string as a case-sensitive substring. Matching records must be emitted in the same order they appear in the `records` table. After printing the report, terminate with exit status `0`.

Example:
If `data.db` contains a `users` row (`tok123`, `alice`, `admin`) and `records` rows (`1`, `alpha widget`, `10`) and (`1`, `beta widget`, `20`), then:

`echo tok123 | python report.py data.db widget`

should produce an HTML document whose heading is `Report for alice` and whose table contains two rows: `alpha widget` with amount `10`, followed by `beta widget` with amount `20`.
