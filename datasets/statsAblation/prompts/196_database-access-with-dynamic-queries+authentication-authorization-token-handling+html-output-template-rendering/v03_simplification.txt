Create a single Python script named `report.py` that is executed as:

`python report.py <database-path> <filter>`

The script must read one line from standard input, remove the trailing newline, and use the remaining text as an access token. The first command-line argument is the path to a SQLite database, and the second is a filter string.

The database contains these tables:

- `users(token, username, role)`
- `records(owner_id, label, amount)`

Implement the following behavior:

1. Find the `users` row whose `token` equals the access token.
   - If no such row exists, print nothing to standard output and exit with status 1.
   - If such a row exists but its `role` is not exactly `admin`, print nothing to standard output and exit with status 1.
   - If such a row exists and its `role` is exactly `admin`, continue.

2. Print an HTML report to standard output with exactly this structure, in this order:
   - `<html><body>`
   - `<h1>Report for NAME</h1>`, where `NAME` is the matched user's `username`
   - `<table>`
   - `<tr><th>Label</th><th>Amount</th></tr>`
   - For every matching `records` row, one line: `<tr><td>LABEL</td><td>AMOUNT</td></tr>`, using that row's `label` and `amount`
   - `</table></body></html>`

A matching `records` row is any row whose `label` contains the `<filter>` value as a case-sensitive substring. Matching rows must appear in the same order as they occur in the `records` table. After printing the report, exit with status 0.

Example:
If `data.db` contains a `users` row (`tok123`, `alice`, `admin`) and `records` rows (`1`, `alpha widget`, `10`) and (`1`, `beta widget`, `20`), then:

`echo tok123 | python report.py data.db widget`

should output an HTML document whose heading is `Report for alice` and whose table contains two rows: `alpha widget` with amount `10`, followed by `beta widget` with amount `20`.
