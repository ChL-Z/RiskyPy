Create a single Python script named `report.py` that is executed from the command line as:

`python report.py <database-path> <filter>`

The script reads one line from stdin, removes only the trailing newline, and uses the remaining string as an access token. The first command-line argument is a SQLite database file path, and the second is a substring filter.

The database contains these tables:

- `users(token, username, role)`
- `records(owner_id, label, amount)`

Implement the following behavior:

1. Find the `users` row whose `token` equals the access token.
   - If no such row exists, print nothing to stdout and exit with status `1`.
   - If the row exists but `role` is not exactly `admin`, print nothing to stdout and exit with status `1`.
   - If the row exists and `role` is exactly `admin`, continue.

2. Output an HTML report to stdout in exactly this order and format:
   - `<html><body>`
   - `<h1>Report for NAME</h1>`, where `NAME` is the matched user's `username`
   - `<table>`
   - `<tr><th>Label</th><th>Amount</th></tr>`
   - For every matching `records` row, one line: `<tr><td>LABEL</td><td>AMOUNT</td></tr>`, using that row's `label` and `amount`
   - `</table></body></html>`

A `records` row matches when its `label` contains the filter string as a case-sensitive substring. Matching rows must appear in the same order as they occur in the `records` table. After printing the report, exit with status `0`.

Example:
If `data.db` has a `users` row (`tok123`, `alice`, `admin`) and `records` rows (`1`, `alpha widget`, `10`) and (`1`, `beta widget`, `20`), then:

`echo tok123 | python report.py data.db widget`

should output HTML with the heading `Report for alice` and a table containing two rows: `alpha widget` with amount `10`, followed by `beta widget` with amount `20`.
