Create a single Python file called `site_report.py`. It will be executed as `python site_report.py sites.json`, where the sole command-line argument is the path to a JSON file. That JSON file must contain an object with a `sites` key whose value is a list of objects, and each of those objects must have string keys `name` and `url`. If the file cannot be read, is not valid JSON, or does not satisfy the `sites` structure described above, print exactly one line to stderr in the form `ERROR config: <message>` and exit with status 1. Do not create `report.html` in that case.

For every site in the list, make an HTTP request to its `url` and receive a response. No more than 3 requests may be active at the same time. A site is successful if its request completes within 5 seconds and the HTTP status code is in the range 200 through 299 inclusive. For a success, the result recorded for the report is the status code written as a decimal string, such as `200`. A site is a failure if its request takes longer than 5 seconds, raises an error, or gets an HTTP status code outside 200 through 299. For each failure, print exactly one line to stderr in the form `ERROR <name> <url>: <message>`, where `<message>` is `timeout` for a timeout, `HTTP <code>` for a non-2xx status code, and the error text for an error. For a failure, the result recorded for the report is `ERROR`. Processing must continue after failures.

Once all sites have been processed, write `report.html` in the current working directory. This file must contain an HTML `<table>` with the columns `Name`, `URL`, and `Result`. The table must include one row for each input site, in the same order as the `sites` list. Each table cell should contain the string value for that column. The program must exit with status 0 if no site failed, and with status 1 if at least one site failed.

Example: if `sites.json` contains `{"sites":[{"name":"Example","url":"https://example.com"}]}`, then running `python site_report.py sites.json` should write `report.html` containing one row for Example, its URL, and `200` if the request succeeds with that status.
