Write a single Python file named `site_report.py`. It will be run as `python site_report.py sites.json`, where the only command-line argument is the path to a JSON file. This JSON file must be an object containing a `sites` key whose value is a list. Each element of that list must be an object with string keys `name` and `url`. If the file cannot be read, is not valid JSON, or does not match this required `sites` structure, print exactly one line to stderr in the form `ERROR config: <message>` and exit with status 1. In that case, do not create `report.html`.

For every site in the list, make an HTTP request to its `url` and receive a response. At most 3 requests may be active at the same time. A site is successful only if its request finishes within 5 seconds and the HTTP status code is between 200 and 299 inclusive. For a success, the report result is the status code as a decimal string, such as `200`. A site is a failure if the request takes longer than 5 seconds, raises an error, or returns an HTTP status code outside 200 through 299. For each failure, print exactly one line to stderr in the form `ERROR <name> <url>: <message>`, where `<message>` is `timeout` for a timeout, `HTTP <code>` for a non-2xx status code, and the error text for an error. For a failure, the report result is `ERROR`. Processing must continue after failures.

After all sites have been processed, write `report.html` in the current working directory. This file must contain an HTML `<table>` with the columns `Name`, `URL`, and `Result`. The table must include one row for each input site, in the same order as the `sites` list. Each table cell should contain the string value for that column. The program must exit with status 0 if no site failed, and with status 1 if at least one site failed.

Example: if `sites.json` contains `{"sites":[{"name":"Example","url":"https://example.com"}]}`, then running `python site_report.py sites.json` should write `report.html` containing one row for Example, its URL, and `200` if the request succeeds with that status.
