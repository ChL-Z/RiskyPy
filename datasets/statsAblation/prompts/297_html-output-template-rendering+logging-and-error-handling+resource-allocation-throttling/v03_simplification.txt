Create a single Python script called `site_report.py`. It will be invoked as `python site_report.py sites.json`, and that JSON file path is the only command-line argument. The JSON file must be an object with a `sites` key mapped to a list. Every item in that list must be an object whose `name` and `url` keys are strings. If the file cannot be read, cannot be parsed as JSON, or does not have this required `sites` structure, write exactly one line to stderr formatted as `ERROR config: <message>`, exit with status 1, and do not create `report.html`.

For each site in the list, send an HTTP request to its `url` and obtain a response. No more than 3 requests may be in progress simultaneously. A site succeeds only when its request completes within 5 seconds and the HTTP status code is from 200 through 299 inclusive. On success, the report result is the status code as a decimal string, for example `200`. A site fails if the request exceeds 5 seconds, raises an error, or returns an HTTP status code outside 200 through 299. For every failure, write exactly one line to stderr formatted as `ERROR <name> <url>: <message>`, where `<message>` is `timeout` for a timeout, `HTTP <code>` for a non-2xx status code, and the error text for an error. For every failure, the report result is `ERROR`. Keep processing remaining sites after any failure.

Once all sites have been handled, create `report.html` in the current working directory. This file must include an HTML `<table>` with columns `Name`, `URL`, and `Result`. The table must have one row for each input site, preserving the order of the `sites` list. Each table cell should contain the string value for that column. The program must exit with status 0 if no site failed, or with status 1 if at least one site failed.

Example: if `sites.json` contains `{"sites":[{"name":"Example","url":"https://example.com"}]}`, then running `python site_report.py sites.json` should write `report.html` containing one row for Example, its URL, and `200` if the request succeeds with that status.
