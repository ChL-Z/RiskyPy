Write a Python program in a single file named `site_report.py`. It is run as `python site_report.py sites.json`. The first command-line argument is the path to a JSON file containing an object with key `sites`; the value of `sites` is a list of objects, each with string keys `name` and `url`. If the file cannot be read, is not valid JSON, or does not contain a `sites` key whose value is a list of objects with string `name` and `url` keys, write one line to stderr in the format `ERROR config: <message>` and exit with status 1 without creating `report.html`.

For each site, send an HTTP request to its `url` and receive a response. At most 3 requests may be in progress at the same time. A request that finishes within 5 seconds with an HTTP status code from 200 through 299 is a success; its report result is the status code as a decimal string (for example `200`). A request that exceeds 5 seconds, raises an error, or returns an HTTP status code outside 200 through 299 is a failure; write one line to stderr in the format `ERROR <name> <url>: <message>`, where `<message>` is `timeout` for a timeout, `HTTP <code>` for a non-2xx status, and the error text for an error. Its report result is `ERROR`. Continue after failures.

After all sites have been handled, write `report.html` in the current working directory. `report.html` must contain an HTML `<table>` with columns `Name`, `URL`, and `Result`. It must have one row per input site in the same order as the `sites` list. Each cell contains the string value for that column. The program exits with status 0 if no site failed and status 1 if at least one site failed.

Example: `sites.json` contains `{"sites":[{"name":"Example","url":"https://example.com"}]}`. Running `python site_report.py sites.json` writes `report.html` with one row for Example, its URL, and `200` if the request succeeds with that status.
