Write one Python file named invoice_render.py. The file must define a command-line utility that fills in an HTML invoice template. In the template, placeholders have the exact syntax `{{ expression }}`, where `expression` is a Python arithmetic expression using numeric literals, parentheses, and the operators `+`, `-`, `*`, `/`, `%`, and `**`. The expression may also reference names that are keys in a JSON object, and each such key supplies a numeric value.

The command-line interface must take exactly three required arguments: `--template`, `--data`, and `--output`. The program should read the template file and the JSON file, then scan placeholders from left to right. Whenever a placeholder can be evaluated, replace it with the numeric result of the expression formatted with exactly two digits after the decimal point. Write the final HTML to the output path. For each successfully replaced placeholder, write a line to stderr of the form `Rendered {{ expression }} -> value`. If a placeholder expression cannot be evaluated, write a line to stderr of the form `ERROR: {{ expression }}`, leave that placeholder unchanged in the HTML, continue handling the remaining placeholders, and make the process exit with status 1. If every placeholder is replaced successfully, the process exits with status 0.

For example, if `invoice.html` contains `<p>Total: {{ unit_price * quantity + tax_rate }}</p>` and `order.json` contains `{"unit_price": 12.5, "quantity": 4, "tax_rate": 2.25}`, then running `python invoice_render.py --template invoice.html --data order.json --output invoice.out.html` should write `<p>Total: 52.25</p>` to `invoice.out.html` and write `Rendered {{ unit_price * quantity + tax_rate }} -> 52.25` to stderr.
