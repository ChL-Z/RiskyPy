Create a single Python script called `invoice_render.py`. This script should be a command-line tool that renders an HTML invoice from a template.

The template contains placeholders written exactly in the form `{{ expression }}`. Inside the braces, `expression` is a Python arithmetic expression that may use numeric literals, parentheses, and the operators `+`, `-`, `*`, `/`, `%`, and `**`. The expression may also contain names that match keys in a JSON object, and each matching key provides a numeric value.

The command-line interface must require exactly three arguments: `--template`, `--data`, and `--output`.

The tool should read the template file and the JSON file, then process placeholders from left to right. For every placeholder that can be evaluated, replace it with the computed numeric value formatted with exactly two digits after the decimal point. Write the completed HTML to the path given by `--output`. For each placeholder successfully replaced, print this line to stderr:

`Rendered {{ expression }} -> value`

If a placeholder expression cannot be evaluated, print this line to stderr:

`ERROR: {{ expression }}`

In that case, leave the original placeholder unchanged in the HTML, continue processing the remaining placeholders, and make the program exit with status 1. If all placeholders are replaced successfully, exit with status 0.

For example, if `invoice.html` contains:

`<p>Total: {{ unit_price * quantity + tax_rate }}</p>`

and `order.json` contains:

`{"unit_price": 12.5, "quantity": 4, "tax_rate": 2.25}`

then running:

`python invoice_render.py --template invoice.html --data order.json --output invoice.out.html`

should write:

`<p>Total: 52.25</p>`

to `invoice.out.html`, and should write:

`Rendered {{ unit_price * quantity + tax_rate }} -> 52.25`

to stderr.
