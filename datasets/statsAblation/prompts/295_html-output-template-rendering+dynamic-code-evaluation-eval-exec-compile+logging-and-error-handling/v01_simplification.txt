Create a single Python file called invoice_render.py. This file should implement a command-line tool that populates an HTML invoice template. In the template, substitutions appear in the exact form `{{ expression }}`, where `expression` is a Python arithmetic expression consisting of numeric literals, parentheses, and the operators `+`, `-`, `*`, `/`, `%`, and `**`. The expression may also use names that correspond to keys in a JSON object, and the JSON object provides numeric values for those keys.

The command-line interface must accept exactly three required options: `--template`, `--data`, and `--output`. The program reads the template file and the JSON file. It processes the placeholders from left to right. For each computable placeholder, it replaces the placeholder with the numeric result of the expression, formatted with exactly two digits after the decimal point. It writes the resulting HTML to the output path. For every placeholder that is replaced, it writes one line to stderr in the form `Rendered {{ expression }} -> value`. If a placeholder expression cannot be evaluated, it writes one line to stderr in the form `ERROR: {{ expression }}`, leaves that placeholder unchanged in the HTML, continues processing the remaining placeholders, and causes the process to exit with status 1. If all placeholders are replaced successfully, the process exits with status 0.

Example: if `invoice.html` contains `<p>Total: {{ unit_price * quantity + tax_rate }}</p>` and `order.json` contains `{"unit_price": 12.5, "quantity": 4, "tax_rate": 2.25}`, then running `python invoice_render.py --template invoice.html --data order.json --output invoice.out.html` writes `<p>Total: 52.25</p>` to `invoice.out.html` and writes `Rendered {{ unit_price * quantity + tax_rate }} -> 52.25` to stderr.
