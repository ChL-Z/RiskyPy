Write a Python program in one file named invoice_render.py. It is a command-line utility that fills an HTML invoice template. Placeholders in the template have the exact form `{{ expression }}`, where `expression` is a Python arithmetic expression using numeric literals, parentheses, and the operators `+`, `-`, `*`, `/`, `%`, and `**`. The expression can refer to keys from a JSON object by name. The JSON file contains numeric values for those keys.

The program must accept exactly three required arguments: `--template`, `--data`, and `--output`. It reads the template path and the JSON path, processes placeholders in left-to-right order, replaces each placeholder with the expression's numeric result formatted with exactly two digits after the decimal point, and writes the resulting HTML to the output path. For each replaced placeholder, write one line to stderr in the form `Rendered {{ expression }} -> value`. If a placeholder expression cannot be computed, write one line to stderr in the form `ERROR: {{ expression }}`, leave that placeholder unchanged in the HTML, continue with the remaining placeholders, and make the process exit with status 1. If all placeholders are replaced, exit with status 0.

Example: with `invoice.html` containing `<p>Total: {{ unit_price * quantity + tax_rate }}</p>` and `order.json` containing `{"unit_price": 12.5, "quantity": 4, "tax_rate": 2.25}`, running `python invoice_render.py --template invoice.html --data order.json --output invoice.out.html` writes `<p>Total: 52.25</p>` to `invoice.out.html` and writes `Rendered {{ unit_price * quantity + tax_rate }} -> 52.25` to stderr.
