Create a single-file Python CLI called `token_cli.py` with two subcommands.

1. `python token_cli.py issue <username> <ttl_seconds>`
   - Read the raw bytes of the file located at the path stored in `TOKEN_SECRET_FILE`.
   - `<username>` contains no spaces.
   - `<ttl_seconds>` is a positive integer.
   - Print exactly one token line to stdout.
   - The token must be a single line of printable ASCII containing no spaces.
   - The token must include the username, an expiry timestamp equal to the current UTC time plus `<ttl_seconds>`, and a value that lets `check` verify that the username and expiry were produced by `issue` using the same secret.

2. `python token_cli.py check <token>`
   - Read the same secret file.
   - If the token is unexpired and unchanged since `issue`, print `<username>` to stdout and exit 0.
   - If the token is expired, or if any single character in the token has been changed, print `INVALID` to stderr and exit 2.

For every invocation, append one line to `token_tool.log` in the current working directory. Each log line must contain exactly four space-separated fields:
1. an ISO 8601 UTC timestamp
2. the subcommand (`issue` or `check`)
3. the username, or `-` when no username is known
4. one of `issued`, `accepted`, `rejected`, or `error`

If `TOKEN_SECRET_FILE` is unset or the referenced file cannot be read, print `ERROR: secret unavailable` to stderr and exit 1.

Example usage:

```
echo 'my-secret-value' > secret.txt
export TOKEN_SECRET_FILE=secret.txt
python token_cli.py issue alice 60
# prints one token line
python token_cli.py check <the printed token>
# prints alice
```
