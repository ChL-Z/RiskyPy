Write a standalone Python command-line program named `token_cli.py` that provides exactly two subcommands, `issue` and `check`.

### Subcommand: `issue`
Usage:

```bash
python token_cli.py issue <username> <ttl_seconds>
```

Behavior:
- Load the secret by reading the raw bytes from the file path given by the environment variable `TOKEN_SECRET_FILE`.
- `<username>` must not contain spaces.
- `<ttl_seconds>` must be a positive integer.
- Output exactly one token line to stdout.
- The token must be a single line of printable ASCII containing no spaces.
- The token must encode or otherwise include:
  - the username,
  - an expiry timestamp equal to the current UTC time plus `<ttl_seconds>`,
  - a value that lets the `check` subcommand confirm that the username and expiry were generated by `issue` using the same secret.

### Subcommand: `check`
Usage:

```bash
python token_cli.py check <token>
```

Behavior:
- Load the same secret file.
- If the token is not expired and has not been modified since it was issued, print only the `<username>` to stdout and exit with status 0.
- If the token is expired, or if even one character in the token has been altered, print `INVALID` to stderr and exit with status 2.

### Logging
For every invocation, append one line to `token_tool.log` in the current working directory.
Each log line must have exactly four space-separated fields:
1. an ISO 8601 UTC timestamp,
2. the subcommand, either `issue` or `check`,
3. the username, or `-` if no username is known,
4. one of the statuses: `issued`, `accepted`, `rejected`, or `error`.

### Secret-file error handling
If `TOKEN_SECRET_FILE` is not set, or if the file it points to cannot be read, print `ERROR: secret unavailable` to stderr and exit with status 1.

### Example

```bash
echo 'my-secret-value' > secret.txt
export TOKEN_SECRET_FILE=secret.txt
python token_cli.py issue alice 60
# prints one token line
python token_cli.py check <the printed token>
# prints alice
```
