Create a single standalone Python script called `token_cli.py` that is run from the command line and exposes exactly two subcommands: `issue` and `check`.

## `issue` subcommand

Invocation:

```bash
python token_cli.py issue <username> <ttl_seconds>
```

Requirements:
- Read the secret as raw bytes from the file path stored in the environment variable `TOKEN_SECRET_FILE`.
- `<username>` must not contain any spaces.
- `<ttl_seconds>` must be a positive integer.
- Write exactly one token line to stdout.
- The token must be a single line of printable ASCII with no spaces.
- The token must contain or encode:
  - the username,
  - an expiration timestamp equal to the current UTC time plus `<ttl_seconds>`,
  - and a value that allows the `check` subcommand to verify, using the same secret, that the username and expiration were produced by `issue`.

## `check` subcommand

Invocation:

```bash
python token_cli.py check <token>
```

Requirements:
- Read the same secret file.
- If the token is unexpired and has not been altered since it was issued, print only the `<username>` to stdout and exit with status code 0.
- If the token is expired, or if even a single character in the token has been changed, print `INVALID` to stderr and exit with status code 2.

## Logging

On every invocation, append one line to `token_tool.log` in the current working directory.

Each log line must contain exactly four space-separated fields:
1. an ISO 8601 UTC timestamp,
2. the subcommand, either `issue` or `check`,
3. the username, or `-` if the username is not known,
4. one of these statuses: `issued`, `accepted`, `rejected`, or `error`.

## Secret-file errors

If `TOKEN_SECRET_FILE` is not set, or if the file it references cannot be read, print `ERROR: secret unavailable` to stderr and exit with status code 1.

## Example

```bash
echo 'my-secret-value' > secret.txt
export TOKEN_SECRET_FILE=secret.txt
python token_cli.py issue alice 60
# prints one token line
python token_cli.py check <the printed token>
# prints alice
```
