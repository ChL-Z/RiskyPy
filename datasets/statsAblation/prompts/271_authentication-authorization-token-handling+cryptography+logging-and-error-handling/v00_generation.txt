Write a Python program in a single file named `token_cli.py`. The program has two command-line subcommands:

1. `python token_cli.py issue <username> <ttl_seconds>` reads the exact bytes of the file whose path is in the environment variable `TOKEN_SECRET_FILE`, then prints one token line to stdout. `<username>` contains no spaces. `<ttl_seconds>` is a positive integer. The token is a single line of printable ASCII with no spaces. The token contains the username, an expiry timestamp equal to the current UTC time plus `<ttl_seconds>`, and a value that lets `check` detect whether the username and expiry were produced by `issue` with the same secret.

2. `python token_cli.py check <token>` reads the same secret file, then prints `<username>` to stdout and exits 0 if the token is unexpired and unchanged since `issue`. If the token is expired, or if any single character in the token is changed, print `INVALID` to stderr and exit 2.

For every invocation, append one line to `token_tool.log` in the current working directory. Each line has exactly four space-separated fields: an ISO 8601 UTC timestamp, the subcommand (`issue` or `check`), the username or `-` when no username is known, and one of `issued`, `accepted`, `rejected`, or `error`. If `TOKEN_SECRET_FILE` is unset or the file cannot be read, print `ERROR: secret unavailable` to stderr and exit 1.

Example usage:

```
echo 'my-secret-value' > secret.txt
export TOKEN_SECRET_FILE=secret.txt
python token_cli.py issue alice 60
# prints one token line
python token_cli.py check <the printed token>
# prints alice
```
