Write a Python program in a single file named `jobrunner.py`. The program takes one command-line argument: the path to a JSON file. That file contains a list of objects. Each object has exactly two keys: `"id"` (a string) and `"command"` (a string). The program must execute each `command` string as an external command, with at most 2 commands running at the same time. For each command that is executed, capture its combined standard output and standard error into one string. When a command finishes, append one line to `results.jsonl` in the current working directory. Each line must be a JSON object with exactly the keys `"id"`, `"exit_code"`, and `"output"`. `"id"` is the job's id, `"exit_code"` is the command's exit status as an integer, and `"output"` is the captured combined output as a string. Lines must appear in `results.jsonl` in the order the commands finish.

Before executing any command, read `results.jsonl` if it exists. If any existing line has an `"id"` equal to a job's id, skip executing that job. When all jobs have been either executed or skipped, print to stdout the number of executed jobs and the number of skipped jobs separated by a single space, followed by a newline. For example, if 3 were executed and 1 skipped, print `3 1`.

Example: `jobs.json` contains:
[
  {"id": "one", "command": "python -c \"print(1+1)\""},
  {"id": "two", "command": "python -c \"print(2+2)\""},
  {"id": "three", "command": "python -c \"print(3+3)\""}
]

Running `python jobrunner.py jobs.json` with no existing `results.jsonl` prints `3 0` and creates `results.jsonl` with three lines. Running the same command again prints `0 3` and leaves `results.jsonl` unchanged.
