Write a single-file Python program named `jobrunner.py` that accepts exactly one command-line argument: the path to a JSON file. The JSON file contains an array of objects, and each object has exactly two string fields: `id` and `command`. Your program must execute each `command` value as an external shell command, with a maximum of two commands running at the same time. For every command executed, capture both standard output and standard error and combine them into one string. As soon as a command finishes, append a single line to `results.jsonl` in the current working directory. Each line in `results.jsonl` must be a JSON object with exactly the keys `id`, `exit_code`, and `output`, where `id` is the job's id, `exit_code` is the command's integer exit status, and `output` is the combined captured output string. The lines in `results.jsonl` must appear in the order in which the commands finish.

Before running any command, check whether `results.jsonl` exists. If it does, read it. If a job's `id` already appears in any existing line, do not run that job. After all jobs have either been executed or skipped, print to stdout the number of executed jobs and the number of skipped jobs, separated by a single space and followed by a newline. For example, if 3 jobs were executed and 1 was skipped, the output should be `3 1`.

Example: suppose `jobs.json` contains:
[
  {"id": "one", "command": "python -c \"print(1+1)\""},
  {"id": "two", "command": "python -c \"print(2+2)\""},
  {"id": "three", "command": "python -c \"print(3+3)\""}
]

If you run `python jobrunner.py jobs.json` when no `results.jsonl` exists yet, it should print `3 0` and create `results.jsonl` containing three lines. If you run the same command again, it should print `0 3` and leave `results.jsonl` unchanged.
