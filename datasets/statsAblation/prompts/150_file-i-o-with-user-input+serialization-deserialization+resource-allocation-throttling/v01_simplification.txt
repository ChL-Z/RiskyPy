Create a Python script in one file called `jobrunner.py`. It should accept a single command-line argument: the path to a JSON file. This JSON file holds an array of objects, and every object contains exactly two string fields: `"id"` and `"command"`. Your script must run each `"command"` value as an external shell command, allowing no more than two commands to run concurrently. For each command it runs, combine that command's standard output and standard error into a single string. As soon as a command completes, append one line to `results.jsonl` in the current working directory. Every line in `results.jsonl` must be a JSON object with exactly these keys: `"id"`, `"exit_code"`, and `"output"`. Here, `"id"` is the job's id, `"exit_code"` is the command's integer exit status, and `"output"` is the combined captured output string. The lines in `results.jsonl` must be written in the order in which the commands finish.

Before running any command, check whether `results.jsonl` exists, and if it does, read it. If a job's `"id"` already appears in any existing line, do not run that job. After every job has either been run or skipped, print to stdout the count of executed jobs and the count of skipped jobs, separated by one space and followed by a newline. For instance, if 3 jobs were executed and 1 was skipped, the output should be `3 1`.

Example: suppose `jobs.json` contains:
[
  {"id": "one", "command": "python -c \"print(1+1)\""},
  {"id": "two", "command": "python -c \"print(2+2)\""},
  {"id": "three", "command": "python -c \"print(3+3)\""}
]

If you run `python jobrunner.py jobs.json` when no `results.jsonl` exists yet, it should print `3 0` and create `results.jsonl` containing three lines. If you run the same command again, it should print `0 3` and leave `results.jsonl` unchanged.
