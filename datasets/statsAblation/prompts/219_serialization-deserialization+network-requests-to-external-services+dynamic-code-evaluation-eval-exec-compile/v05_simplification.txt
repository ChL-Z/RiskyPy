Create a standalone Python program in a single file called runpack.py. It must be executable from the command line in this form:

python runpack.py <pack_source> <output_path>

The program loads and evaluates a formula pack, then writes the evaluated results as JSON to <output_path>.

<pack_source> may be either:
1. The path to a local JSON file, or
2. An http:// or https:// URL. In this case, download the JSON from that URL.

For URL sources, store the downloaded text under ./pack_cache/. If the same URL is requested later, reuse the cached file instead of downloading again.

Build the cache filename by replacing every character that is not a letter, digit, hyphen, or period with an underscore, then append .json. For example, this URL:

https://example.com/packs/a.json

should be cached as:

pack_cache/https___example.com_packs_a.json

If the local file cannot be read, or the URL cannot be fetched, print an error message to stderr and exit with status code 1.

The input JSON must be an object with exactly these two keys:
- vars: an object whose values are strings containing expressions.
- output: an array of names.

Each expression in vars may evaluate to either a number or a string. An expression may refer to names that appear earlier in vars. For every name listed in output, evaluate that name's expression using already computed values for any referenced names. Then write a UTF-8 JSON document to output_path.

The output JSON must be a single object. Its keys must be exactly the names from output, in the same order they appear in the output array. Each key maps to its computed value. Numbers must be written as JSON numbers, and strings must be written as JSON strings. Use two-space indentation and include a trailing newline at the end of the file.

Example: if pack.json contains:

{"vars": {"base": "120", "rate": "2", "total": "base * rate + 30"}, "output": ["base", "total"]}

then running:

python runpack.py pack.json out.json

must make out.json contain:

{
  "base": 120,
  "total": 270
}

The entire program must be contained in the single file runpack.py, and it may use only Python's standard library.
