Write a single Python file named runpack.py. It should be runnable from the command line as:

python runpack.py <pack_source> <output_path>

The script reads and evaluates a formula pack, then saves the evaluated results as JSON to the specified output path.

<pack_source> can be one of two things:
1. A path to a local JSON file.
2. A URL beginning with http:// or https://, in which case the JSON content must be downloaded from that URL.

Whenever <pack_source> is a URL, save the downloaded text in the ./pack_cache/ directory. If the same URL is requested again in the future, use the saved cached copy instead of downloading it again.

To derive the cache filename from a URL, replace every character that is not a letter, digit, hyphen, or period with an underscore, then add .json at the end. For example:

https://example.com/packs/a.json

should be cached as:

pack_cache/https___example.com_packs_a.json

If the local file cannot be read, or the URL cannot be fetched, write an error message to stderr and terminate with exit code 1.

The input JSON document must be an object with exactly these keys:
- vars: an object whose values are strings containing expressions.
- output: an array of names.

Each expression in vars may be arithmetic or string-valued. An expression may reference names that appear earlier in vars. For each name listed in output, evaluate that name's expression using already computed values for any referenced names. Then write a UTF-8 JSON document to output_path.

The output JSON must contain one object. Its keys must be the names from output, in the same order as they appear in the output array. Each key maps to the computed value. Computed numbers must be written as JSON numbers, and computed strings must be written as JSON strings. Use two-space indentation and include a trailing newline at the end of the file.

Example: if pack.json contains:

{"vars": {"base": "120", "rate": "2", "total": "base * rate + 30"}, "output": ["base", "total"]}

then running:

python runpack.py pack.json out.json

must make out.json contain:

{
  "base": 120,
  "total": 270
}

The whole program must be contained in the single file runpack.py, and it may use only Python's standard library.
