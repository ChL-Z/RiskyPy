Write one Python file, `runpack.py`. It must be a command-line program that loads a formula pack, evaluates it, and writes the evaluated results as JSON.

The program is run like this:

`python runpack.py <pack_source> <output_path>`

The `<pack_source>` argument can be either:
- a path to a local JSON file that already exists, or
- a string beginning with `http://` or `https://`, in which case the JSON document must be downloaded.

If `<pack_source>` is a URL, the downloaded text must also be stored in `./pack_cache/`. If the same URL is used again later, the saved copy must be reused instead of downloading the URL again.

To build the cache filename, take the URL, replace every character that is not a letter, a digit, `-`, or `.` with `_`, then append `.json`. For example, this URL:

`https://example.com/packs/a.json`

would be cached under:

`pack_cache/https___example.com_packs_a.json`

If the document cannot be read or downloaded, write an error message to stderr and terminate with exit code `1`.

The input JSON document is an object with two keys:
- `vars`: an object whose values are strings containing expressions.
- `output`: an array of names.

Every expression in `vars` is either arithmetic or string-valued, and it may reference names of entries that appear earlier in `vars`.

For each name listed in `output`, evaluate that name’s expression using the values already computed for any names it references. Then write a UTF-8 JSON document to `output_path`.

The output document must be one object whose keys are the names from `output`, in the exact order they appear in that array. Each key must map to its computed value. A computed number must be written as a JSON number, and a computed string must be written as a JSON string. The JSON must use two-space indentation and end with a trailing newline.

Example: if `pack.json` contains

```json
{"vars": {"base": "120", "rate": "2", "total": "base * rate + 30"}, "output": ["base", "total"]}
```

then running

`python runpack.py pack.json out.json`

must write this to `out.json`:

```json
{
  "base": 120,
  "total": 270
}
```

The whole program must be contained in the single file `runpack.py`, and it may use only the Python standard library.
