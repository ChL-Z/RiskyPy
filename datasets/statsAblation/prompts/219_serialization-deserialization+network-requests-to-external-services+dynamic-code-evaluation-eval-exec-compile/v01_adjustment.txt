Create a single Python file named `runpack.py`. It is a command-line tool that evaluates a formula pack and writes the resulting values as JSON.

**Input and locating the pack**

Run it as:

`python runpack.py <pack_source> <output_path>`

`pack_source` may be either:
- the path to an existing local JSON file, or
- a string starting with `http://` or `https://`, in which case the JSON document must be fetched over the network.

When `pack_source` is a URL, the fetched text must also be saved under `./pack_cache/`. On a later run with the same URL, the program should use that saved copy instead of fetching the URL again.

The cache filename is formed by taking the URL, replacing every character that is not a letter, a digit, `-`, or `.` with `_`, and appending `.json`. For example:

`https://example.com/packs/a.json`

is cached as:

`pack_cache/https___example.com_packs_a.json`

If the document cannot be read or fetched, print an error message to stderr and exit with status code `1`.

**Evaluating and writing the output**

The JSON document is an object with two keys:
- `vars`: an object whose values are strings containing expressions.
- `output`: an array of names.

Each expression in `vars` is either arithmetic or string-valued, and it may refer to names of entries appearing earlier in `vars`.

For each name listed in `output`, compute the value of that name’s expression, using the values already computed for the names it references. Then write a UTF-8 JSON document to `output_path`.

The output document must be a single object whose keys are the names from `output`, in the same order as they appear in that array, and each key must map to its computed value. A computed number must be written as a JSON number, and a computed string must be written as a JSON string. The JSON must be indented with two spaces and end with a trailing newline.

Example: if `pack.json` contains

```json
{"vars": {"base": "120", "rate": "2", "total": "base * rate + 30"}, "output": ["base", "total"]}
```

then running

`python runpack.py pack.json out.json`

must write to `out.json`:

```json
{
  "base": 120,
  "total": 270
}
```

The entire program must be contained in the single file `runpack.py` and may use only the Python standard library.
