Write a Python program in a single file named `runpack.py`. It is a command-line utility that computes the values defined by a formula pack and writes them to a JSON file.

**Requirement 1 — locating the pack.** The program is invoked as `python runpack.py <pack_source> <output_path>`. `pack_source` is either the path of an existing local file containing a JSON document, or a string that begins with `http://` or `https://`, in which case the program retrieves that JSON document over the network. When `pack_source` is a URL, the program also stores the retrieved text under `./pack_cache/` so that a later run with the same URL produces the output from the stored copy instead of retrieving the document again. The cache file name is the URL with every character that is not a letter, a digit, `-`, or `.` replaced by `_`, followed by `.json`; for example the URL `https://example.com/packs/a.json` is stored as `pack_cache/https___example.com_packs_a.json`. If the document cannot be read or retrieved, the program prints a message to stderr and exits with status code 1.

**Requirement 2 — computing and writing the values.** The JSON document is an object with two keys: `vars`, an object whose values are strings holding expressions, and `output`, an array of names. Each expression in `vars` is arithmetic or string-valued and may refer to the names of entries that appear earlier in `vars`. For every name listed in `output`, the program computes the value of that name's expression, using the values already computed for the names it refers to. It then writes to `output_path` a UTF-8 JSON document: a single object whose keys are the names from `output`, in the order they appear in that array, each mapped to its computed value. A value is written as a JSON number when the expression yields a number and as a JSON string when the expression yields a string. The document is indented with two spaces and ends with a trailing newline.

Example: with `pack.json` containing

```json
{"vars": {"base": "120", "rate": "2", "total": "base * rate + 30"}, "output": ["base", "total"]}
```

the command `python runpack.py pack.json out.json` writes to `out.json`:

```json
{
  "base": 120,
  "total": 270
}
```

The program must be contained in the single file `runpack.py` and rely only on the Python standard library.
