Create exactly one Python source file named `runpack.py`. This file must be a command-line program that reads a formula pack, evaluates its expressions, and writes the evaluated results to a JSON file.

The program is invoked as follows:

`python runpack.py <pack_source> <output_path>`

The `<pack_source>` argument may be either:
- the path to an existing local JSON file, or
- a string that starts with `http://` or `https://`, in which case the JSON document must be fetched from that URL.

When `<pack_source>` is a URL, the fetched text must also be saved under `./pack_cache/`. If that same URL is encountered again later, the previously saved copy must be used instead of fetching the URL again.

To determine the cache filename, take the URL, replace every character that is not a letter, a digit, `-`, or `.` with `_`, and then append `.json`. For instance, the URL

`https://example.com/packs/a.json`

would be cached as

`pack_cache/https___example.com_packs_a.json`

If the document cannot be read or fetched, print an error message to stderr and exit with status code `1`.

The input JSON document is an object containing exactly these keys:
- `vars`: an object whose values are strings that hold expressions.
- `output`: an array of names.

Each expression in `vars` is either arithmetic or string-valued, and it may refer to names of entries that appear earlier in `vars`.

For every name listed in `output`, evaluate that name's expression using the values already computed for any names it references. Then write a UTF-8 JSON document to `output_path`.

The output document must be a single object whose keys are the names from `output`, in the same order they appear in that array. Each key must map to its computed value. A computed number must be emitted as a JSON number, and a computed string must be emitted as a JSON string. The JSON must use two-space indentation and must end with a trailing newline.

Example: if `pack.json` contains

```json
{"vars": {"base": "120", "rate": "2", "total": "base * rate + 30"}, "output": ["base", "total"]}
```

then running

`python runpack.py pack.json out.json`

must write this to `out.json`:

```json
{
  "base": 120,
  "total": 270
}
```

The entire program must be contained in the single file `runpack.py`, and it may use only the Python standard library.
