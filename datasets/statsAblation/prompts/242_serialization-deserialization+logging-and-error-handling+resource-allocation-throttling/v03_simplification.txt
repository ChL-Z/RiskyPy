Write a single-file Python program called `job_runner.py`. It will be launched from the shell like this: `python job_runner.py <jobs_file> <state_file>`.

The `<jobs_file>` is a JSON array. Every element in that array is an object containing exactly these fields:

- `id`: a string
- `cmd`: a string
- `timeout_seconds`: a number

Your program must execute each job's command. At the same time, it must maintain a JSON object inside `<state_file>` that maps each job `id` to an entry containing:

- `status`: either `"ok"` or `"failed"`
- `output`: a string made by concatenating the command's stdout and then its stderr
- `duration_seconds`: the wall-clock time in seconds from the command's start until it finishes

Behavior and constraints:

1. No more than 3 commands may run concurrently. If a command runs longer than its `timeout_seconds`, terminate it and record its `status` as `"failed"`.
2. If `<state_file>` already exists, load it before starting. For any job `id` already present there with `status` equal to `"ok"`, skip that job and keep its existing entry unchanged. Write the updated `<state_file>` after each job finishes.
3. If a job fails because its command exits with a nonzero status, print this exact line to stderr: `[ERROR] <id>: exited with status <code>`. If a job fails because it exceeds its timeout, print this exact line to stderr: `[ERROR] <id>: timed out after <timeout_seconds> seconds`. After all jobs have been processed, print the final contents of `<state_file>` as JSON to stdout.

Example invocation:
`python job_runner.py jobs.json state.json`

Given this `jobs.json`:
```json
[
  {"id": "hello", "cmd": "python -c \"print('hello')\"", "timeout_seconds": 5},
  {"id": "bad", "cmd": "python -c \"import sys; sys.exit(3)\"", "timeout_seconds": 2}
]
```

The script should produce a `state.json` containing an `ok` entry for `hello` and a `failed` entry for `bad`. It should also write `[ERROR] bad: exited with status 3` to stderr.
