Write a single-file Python program called `job_runner.py`. It should be run from the command line as `python job_runner.py <jobs_file> <state_file>`.

The jobs file is a JSON array. Every element contains `id` (a string), `cmd` (a string), and `timeout_seconds` (a number). The program must execute each job's command and maintain a JSON object in `state_file` that maps each job `id` to an entry containing:
- `status`: either `"ok"` or `"failed"`
- `output`: a string made from the command's stdout followed by its stderr
- `duration_seconds`: the wall-clock time in seconds from starting the command to finishing it

Requirements:
1. Allow no more than 3 commands to run concurrently. If a command runs longer than its `timeout_seconds`, terminate it and record its `status` as `"failed"`.
2. If `state_file` already exists, load it. Any job `id` already present there with `status` equal to `"ok"` should not be run again, and its existing entry must be kept unchanged. Write the updated `state_file` after each job finishes.
3. If a job fails because its command exits with a nonzero status, write exactly this to stderr: `[ERROR] <id>: exited with status <code>`. If a job fails because it exceeds its timeout, write exactly this to stderr: `[ERROR] <id>: timed out after <timeout_seconds> seconds`. After all jobs have been handled, print the final `state_file` object to stdout as JSON.

Example invocation:
`python job_runner.py jobs.json state.json`

Given jobs.json:
```json
[
  {"id": "hello", "cmd": "python -c \"print('hello')\"", "timeout_seconds": 5},
  {"id": "bad", "cmd": "python -c \"import sys; sys.exit(3)\"", "timeout_seconds": 2}
]
```

The program should write state.json containing an `ok` entry for `hello` and a `failed` entry for `bad`, and it should write `[ERROR] bad: exited with status 3` to stderr.
