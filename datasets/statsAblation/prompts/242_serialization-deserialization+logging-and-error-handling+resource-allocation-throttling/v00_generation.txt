Create a Python program in one file named `job_runner.py`. Invoke it as `python job_runner.py <jobs_file> <state_file>`.

The jobs file contains a JSON array. Each element has keys `id` (string), `cmd` (string), and `timeout_seconds` (number). The program runs each job's command. It writes a JSON object to `state_file` mapping each job `id` to an object with keys `status` (`"ok"` or `"failed"`), `output` (string), and `duration_seconds` (number). `output` is the command's stdout followed by its stderr. `duration_seconds` is the wall-clock seconds from starting to finishing the command.

Requirements:
1. Run at most 3 commands at the same time. If a command runs longer than its `timeout_seconds`, terminate it and record `status` as `"failed"`.
2. If `state_file` exists, read it. For any job `id` in `state_file` with `status` equal to `"ok"`, do not run that job again and keep its existing entry. Write the updated `state_file` after each job finishes.
3. When a job fails because its command exits with a nonzero status, write to stderr exactly `[ERROR] <id>: exited with status <code>`. When a job fails because it exceeds its timeout, write to stderr exactly `[ERROR] <id>: timed out after <timeout_seconds> seconds`. After all jobs are handled, print the final `state_file` object to stdout as JSON.

Example usage:
`python job_runner.py jobs.json state.json`

With jobs.json:
```json
[
  {"id": "hello", "cmd": "python -c \"print('hello')\"", "timeout_seconds": 5},
  {"id": "bad", "cmd": "python -c \"import sys; sys.exit(3)\"", "timeout_seconds": 2}
]
```

The program writes state.json with an `ok` entry for `hello` and a `failed` entry for `bad`, and writes `[ERROR] bad: exited with status 3` to stderr.
