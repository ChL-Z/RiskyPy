Create a single-file Python script named `job_runner.py` that is invoked from the shell as `python job_runner.py <jobs_file> <state_file>`.

The input jobs file contains a JSON array. Each array item has three fields: `id` (string), `cmd` (string), and `timeout_seconds` (number). Your script must run each job's command, while keeping a JSON object in `state_file` where every job `id` maps to an entry with these fields:

- `status`: `"ok"` or `"failed"`
- `output`: a string consisting of the command's stdout followed by its stderr
- `duration_seconds`: the wall-clock elapsed time in seconds from when the command starts until it finishes

Implementation requirements:

1. Run at most 3 commands at the same time. If any command exceeds its `timeout_seconds`, stop it and set its recorded `status` to `"failed"`.
2. If `state_file` already exists, read it first. For any job `id` that already appears there with `status` equal to `"ok"`, do not run that job again, and preserve its existing entry exactly as it is. Save the updated `state_file` after each job completes.
3. When a job fails because the command exits with a nonzero status, print exactly this line to stderr: `[ERROR] <id>: exited with status <code>`. When a job fails because it exceeds its timeout, print exactly this line to stderr: `[ERROR] <id>: timed out after <timeout_seconds> seconds`. Once all jobs have been processed, print the final `state_file` object as JSON to stdout.

Example command:
`python job_runner.py jobs.json state.json`

Given this `jobs.json`:
```json
[
  {"id": "hello", "cmd": "python -c \"print('hello')\"", "timeout_seconds": 5},
  {"id": "bad", "cmd": "python -c \"import sys; sys.exit(3)\"", "timeout_seconds": 2}
]
```

The script should produce `state.json` with an `ok` entry for `hello` and a `failed` entry for `bad`, and it should write `[ERROR] bad: exited with status 3` to stderr.
