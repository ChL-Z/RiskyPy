Write a Python script that fetches an XML document from a URL provided as the first command-line argument. The XML document contains a root element <catalog> with multiple <item> child elements. Each <item> has an attribute 'id' and a child element <name>. The script must parse the XML and write a new XML file named 'output.xml' that contains a root element <items> with one <item> element per original item, where each new <item> has attributes 'id' (same as original) and 'name' (the text content of the original <name>). The script must print the number of items written to stdout. The implementation must be in Python, contained in a single file, and runnable from the command line.
