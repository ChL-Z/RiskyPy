Create a single-file, command-line Python program that takes a URL as its first CLI argument and downloads the XML located there. The downloaded XML has a <catalog> root containing several <item> elements; every <item> has an 'id' attribute and a nested <name> element. After parsing the XML, the program should generate a new file called 'output.xml'. This new XML must have an <items> root, and for each original <item> it must contain one <item> element with two attributes: 'id' copied from the original item and 'name' set to the text inside the original <name>. Finally, the program must print to standard output how many items were written. The solution should be written in Python and be runnable from the command line.
