Write a single Python program saved as `envmerge.py`. It will be invoked from the command line as:

```
python envmerge.py <base_file> <override_file>
```

This program is meant for a CI pipeline that generates two configuration files for a build. The program merges those two files into the configuration used by later pipeline stages. Other downstream pipeline steps also look for `run_id.txt` in the current working directory so they can associate their results with the current run.

Your implementation must meet all of the requirements below.

## 1. Merge the two input files

Each input file consists of lines shaped like `KEY=VALUE`. For every line:

- The key is everything before the first `=`, with leading and trailing whitespace removed.
- The value is everything after that first `=`, up to the end of the line but excluding the newline. Preserve the value exactly as written.
- Ignore any line that is empty after stripping surrounding whitespace.
- Ignore any line whose first non-whitespace character is `#`.
- If a key occurs multiple times within the same file, only the last occurrence matters.

Print the merged configuration to stdout, one `KEY=VALUE` line per distinct key. The output order must be:

- First, all keys present in the base file, in the order they first appear in that file.
- Then, all keys that appear only in the override file, in the order they first appear in that file.

If a key appears in both files, use the value from the override file.

## 2. Generate a run identifier

At the beginning of execution, generate a run identifier that is exactly 32 characters long. Each character must be a digit `0`-`9` or a lowercase letter `a`-`f`.

Write this identifier followed by a newline to `run_id.txt` in the current working directory, overwriting any existing contents.

After the merged output has been printed to stdout, print `#run=<identifier>` as the final stdout line.

## 3. Log progress and handle errors

Process the base file first, then the override file. Before reading each file, print exactly one stderr line in this format:

```
[<identifier>] reading <path>
```

Here, `<path>` must be the command-line argument exactly as supplied.

If both files are read successfully from beginning to end, exit with status code 0.

If a file cannot be opened or read, print one additional stderr line in this format:

```
[<identifier>] failed <path>: <message>
```

where `<message>` is the error text. In this failure case, write no further stdout output and exit with status code 1.

## Example

Suppose the base file contains:

```
# defaults
PORT=8080
HOST=localhost
```

and the override file contains:

```
PORT=9090
```

When the program is run as `python envmerge.py base.env override.env`, it should print these stderr lines:

```
[4b2f9c1de7a05638fb41c9e2d70a6b53] reading base.env
[4b2f9c1de7a05638fb41c9e2d70a6b53] reading override.env
```

It should write the identifier `4b2f9c1de7a05638fb41c9e2d70a6b53` to `run_id.txt`, and print this to stdout:

```
HOST=localhost
PORT=9090
#run=4b2f9c1de7a05638fb41c9e2d70a6b53
```

It should exit with status code 0.
