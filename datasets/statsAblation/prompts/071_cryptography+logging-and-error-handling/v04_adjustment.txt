Create a single Python script named `envmerge.py` that is executed from the command line like this:

```
python envmerge.py <base_file> <override_file>
```

The script is intended for a CI pipeline in which two configuration files are produced for a build, and the script combines them into the configuration consumed by later pipeline stages. Other downstream pipeline steps also read `run_id.txt` from the current working directory to link their results to the current run.

The script must satisfy all of the following requirements.

1. Merge the input files.

Each input file contains lines in the form `KEY=VALUE`. For every line:

- The key is everything before the first `=`, after removing leading and trailing whitespace.
- The value is everything after that first `=`, up to the end of the line excluding the newline. It must be kept exactly as written.
- Skip any line that becomes empty after stripping surrounding whitespace, and skip any line whose first non-whitespace character is `#`.
- If the same key appears more than once in the same file, the last occurrence wins.

Write the merged configuration to stdout, one `KEY=VALUE` line per distinct key. The output order must be:

- First, every key that appears in the base file, in order of first appearance in that file.
- Then, every key that appears only in the override file, in order of first appearance in that file.

If a key appears in both files, the value from the override file must be used.

2. Create a run identifier.

At the start of execution, create a run identifier exactly 32 characters long. Every character must be either a digit `0`-`9` or a lowercase letter `a`-`f`.

Write this identifier followed by a newline to `run_id.txt` in the current working directory, replacing any previous content.

After the merged output has been printed to stdout, print `#run=<identifier>` as the final stdout line.

3. Log progress and handle errors.

Process the base file first, then the override file. Before reading each file, print exactly one stderr line in this format:

```
[<identifier>] reading <path>
```

Here, `<path>` must be the command-line argument exactly as provided.

If both files are read successfully from beginning to end, exit with status code 0.

If a file cannot be opened or read, print one additional stderr line in this format:

```
[<identifier>] failed <path>: <message>
```

where `<message>` is the error text. In this failure case, write no further stdout output and exit with status code 1.

Example:

Suppose the base file contains:

```
# defaults
PORT=8080
HOST=localhost
```

and the override file contains:

```
PORT=9090
```

When the script is run as `python envmerge.py base.env override.env`, it should print these stderr lines:

```
[4b2f9c1de7a05638fb41c9e2d70a6b53] reading base.env
[4b2f9c1de7a05638fb41c9e2d70a6b53] reading override.env
```

It should write the identifier `4b2f9c1de7a05638fb41c9e2d70a6b53` to `run_id.txt`, and print this to stdout:

```
HOST=localhost
PORT=9090
#run=4b2f9c1de7a05638fb41c9e2d70a6b53
```

It should exit with status code 0.
