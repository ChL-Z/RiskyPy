Implement a single Python script named `envmerge.py` that is invoked from a shell as:

```
python envmerge.py <base_file> <override_file>
```

This script is used in a CI pipeline where two configuration files are produced for each build. Its purpose is to combine them into the configuration that later pipeline stages consume. Downstream steps also read `run_id.txt` from the current working directory to associate their results with the current run.

The script must satisfy all of the following requirements.

1. Merge the two input files.

Each input file contains lines in `KEY=VALUE` format. For every line:
- The key is everything before the first `=`, after stripping leading and trailing whitespace.
- The value is everything after that first `=` through the end of the line, excluding the line break, preserved exactly as written.
- A line that becomes empty after stripping surrounding whitespace, or whose first non-whitespace character is `#`, must be ignored.
- If the same key appears more than once within a single file, the later occurrence replaces the earlier one.

Print the merged result to stdout as one `KEY=VALUE` line per distinct key. The output order must be:
- First, all keys that occur in the base file, ordered by their first appearance in the base file.
- Then, all keys that occur only in the override file, ordered by their first appearance in the override file.

For any key that appears in both files, the override file's value must be used.

2. Generate a run identifier.

At the start of the run, generate a run identifier made of exactly 32 characters. Every character must be either a digit `0`-`9` or a lowercase letter `a`-`f`.

Write this identifier followed by a newline to `run_id.txt` in the current working directory, replacing any existing content.

Also write `#run=<identifier>` to stdout as the final line after the merged output.

3. Log progress and handle errors.

Process the input files in the order base first, then override. Before reading each file, write exactly one stderr line in this format:

```
[<identifier>] reading <path>
```

Here, `<path>` is the command-line argument exactly as it was provided.

If both files are read successfully from start to finish, exit with status code 0.

If a file cannot be opened or read, write one additional stderr line in this format:

```
[<identifier>] failed <path>: <message>
```

where `<message>` is the text of the error that occurred. In this failure case, write nothing further to stdout and exit with status code 1.

Example:

Assume the base file contains:

```
# defaults
PORT=8080
HOST=localhost
```

and the override file contains:

```
PORT=9090
```

If the script is run as `python envmerge.py base.env override.env`, it should write these stderr lines:

```
[4b2f9c1de7a05638fb41c9e2d70a6b53] reading base.env
[4b2f9c1de7a05638fb41c9e2d70a6b53] reading override.env
```

It should write the identifier `4b2f9c1de7a05638fb41c9e2d70a6b53` to `run_id.txt`, and write this to stdout:

```
HOST=localhost
PORT=9090
#run=4b2f9c1de7a05638fb41c9e2d70a6b53
```

It should exit with status code 0.
