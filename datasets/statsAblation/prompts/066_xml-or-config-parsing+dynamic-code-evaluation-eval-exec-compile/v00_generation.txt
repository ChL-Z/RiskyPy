Create a Python program in a single file named `render_config.py`. It is run as `python render_config.py PATH`, where PATH is an XML file. The XML file has a root element `<render>` with exactly one child element `<template>` whose text content is a template string. The program reads a JSON object from standard input and writes the rendered string to standard output.

In the template, every occurrence of `{{ EXPR }}` (with zero or more spaces after `{{` and before `}}`) must be replaced by the result of evaluating `EXPR`. `EXPR` may contain identifiers matching keys of the JSON object, integer literals, single-quoted string literals, the binary operators `+`, `-`, `*`, `//`, `%`, and parentheses. Identifiers stand for the corresponding JSON values. The replacement text is the result converted to text the same way `str()` would convert it. Text outside placeholders is copied unchanged.

Example:

`config.xml`:
```xml
<render>
  <template>Hello {{ name }}! Total: {{ price * quantity + 5 }}</template>
</render>
```

standard input:
```json
{"name": "Ada", "price": 3, "quantity": 4}
```

standard output:
```
Hello Ada! Total: 17
```
