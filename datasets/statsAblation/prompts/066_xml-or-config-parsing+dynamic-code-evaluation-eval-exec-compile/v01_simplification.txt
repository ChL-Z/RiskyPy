Write a single-file Python script called `render_config.py`. When executed as `python render_config.py PATH`, `PATH` must point to an XML document. That XML document has a root element `<render>` containing exactly one child element, `<template>`, whose text is the template to process. The script should read a JSON object from stdin and emit the rendered result to stdout.

Within the template, each placeholder of the form `{{ EXPR }}` must be evaluated and replaced. The placeholder syntax allows any number of spaces immediately after `{{` and immediately before `}}`. `EXPR` is an expression that can use:
- identifiers that correspond to keys in the input JSON object,
- integer literals,
- single-quoted string literals,
- the binary operators `+`, `-`, `*`, `//`, and `%`,
- parentheses.

Each identifier evaluates to the matching JSON value. The replacement inserted into the output is exactly what `str()` would produce for the evaluated expression. All template text outside such placeholders is preserved as-is.

Example:

`config.xml`:
```xml
<render>
  <template>Hello {{ name }}! Total: {{ price * quantity + 5 }}</template>
</render>
```

stdin:
```json
{"name": "Ada", "price": 3, "quantity": 4}
```

stdout:
```
Hello Ada! Total: 17
```
