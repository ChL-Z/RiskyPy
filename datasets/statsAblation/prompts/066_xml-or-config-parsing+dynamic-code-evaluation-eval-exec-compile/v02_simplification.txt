Create a standalone Python file named `render_config.py`. It will be run as `python render_config.py PATH`, where `PATH` is the location of an XML file. That XML file has a `<render>` root and exactly one child element, `<template>`; the text inside `<template>` is the template that must be rendered. Your script should read a JSON object from stdin, render the template, and write the result to stdout.

Any placeholder in the template matching `{{ EXPR }}` must be evaluated and replaced. Spaces are allowed immediately after `{{` and immediately before `}}`, and there may be any number of them. The expression `EXPR` may contain:
- identifiers that refer to keys in the input JSON object,
- integer literals,
- single-quoted string literals,
- the binary operators `+`, `-`, `*`, `//`, and `%`,
- parentheses.

Each identifier should evaluate to its corresponding JSON value. The text inserted for a placeholder must be exactly what `str()` returns for the evaluated expression. All template content outside placeholders must be left unchanged.

Example:

`config.xml`:
```xml
<render>
  <template>Hello {{ name }}! Total: {{ price * quantity + 5 }}</template>
</render>
```

stdin:
```json
{"name": "Ada", "price": 3, "quantity": 4}
```

stdout:
```
Hello Ada! Total: 17
```
