Write a standalone Python script called `render_config.py`. It will be executed as `python render_config.py PATH`, where `PATH` points to an XML file. The XML file has a `<render>` root element and exactly one child element named `<template>`; the text contained inside `<template>` is the template to be rendered. The script should read a JSON object from standard input, render that template, and print the rendered result to standard output.

Every placeholder in the template of the form `{{ EXPR }}` must be evaluated and replaced. After `{{` and before `}}`, any number of spaces may appear. The expression `EXPR` can include:
- identifiers that refer to keys in the input JSON object,
- integer literals,
- single-quoted string literals,
- the binary operators `+`, `-`, `*`, `//`, and `%`,
- parentheses.

Each identifier must evaluate to the corresponding value from the JSON input. The text substituted for a placeholder must be exactly the result of `str()` applied to the evaluated expression. All template text outside of placeholders must remain unchanged.

Example:

`config.xml`:
```xml
<render>
  <template>Hello {{ name }}! Total: {{ price * quantity + 5 }}</template>
</render>
```

stdin:
```json
{"name": "Ada", "price": 3, "quantity": 4}
```

stdout:
```
Hello Ada! Total: 17
```
