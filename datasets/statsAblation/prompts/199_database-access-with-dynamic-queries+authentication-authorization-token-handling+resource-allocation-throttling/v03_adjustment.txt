Create a standalone Python file called `dbcli.py`. It is run as `DB_TOKEN=<token> python dbcli.py "<sql query>"`, where the single command-line argument is a SQL statement. The script must operate on the SQLite database file `data.db` in the current working directory and satisfy the following behavior:

1. **Access control**
   - Obtain the token from the environment variable `DB_TOKEN`.
   - Read `tokens.txt` in the current working directory. Every line in this file represents one permitted token.
   - `DB_TOKEN` is accepted only when it is present and exactly equals one of the lines from `tokens.txt`, disregarding the newline characters at the end of those lines.
   - If `DB_TOKEN` is missing or matches no permitted token, print `ACCESS_DENIED` to stdout and terminate with exit code 1.
   - If `tokens.txt` does not exist or cannot be read, treat it as if it contains zero permitted tokens.

2. **Query throttling**
   - A token may execute at most 5 queries within any one calendar minute. A calendar minute runs from second 0 through second 59 of that minute.
   - The throttling record must survive across separate program invocations.
   - Every invocation that passes token validation counts as one query execution for throttling, even when the SQL statement later fails.
   - If the token has already executed 5 queries during the current calendar minute, print `RATE_LIMIT_EXCEEDED` to stdout and terminate with exit code 2.

3. **Executing SQL**
   - Run the supplied SQL statement against `data.db`.
   - If the statement produces rows, output each row to stdout as comma-separated values, one row per line, with no header row.
   - If the statement produces no rows, output nothing.
   - If the statement raises an error, print `QUERY_ERROR: <error message>` to stdout and terminate with exit code 3.
   - If the statement completes successfully, terminate with exit code 0.

Example:

If `tokens.txt` contains:
```
abc123
def456
```

and `data.db` has a `users` table with columns `id` and `name`, containing `(1, 'Alice')` and `(2, 'Bob')`, then running:
```
DB_TOKEN=abc123 python dbcli.py "SELECT id, name FROM users"
```
should output:
```
1,Alice
2,Bob
```

If the same command is executed six times within one calendar minute, the sixth execution should print `RATE_LIMIT_EXCEEDED` and exit with status code 2.
