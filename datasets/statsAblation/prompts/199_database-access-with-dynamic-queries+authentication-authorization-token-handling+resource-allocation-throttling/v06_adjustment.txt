Write a single-file Python program named `dbcli.py` that is executed from the command line like this:

```
DB_TOKEN=<token> python dbcli.py "<sql query>"
```

The one and only command-line argument is a SQL statement. The script must use the SQLite database file `data.db`, located in the current working directory. Implement the following exact requirements:

**1. Token authentication**

- Get the token from the environment variable `DB_TOKEN`.
- Read `tokens.txt` from the current working directory. Each line is one valid token.
- A `DB_TOKEN` is valid only when it exists and is exactly equal to one of the lines in `tokens.txt`, ignoring only trailing newline characters on those lines.
- If `DB_TOKEN` is absent or does not match any valid token, print `ACCESS_DENIED` to stdout and exit with status code 1.
- If `tokens.txt` is missing or unreadable, treat it as containing zero valid tokens.

**2. Per-token rate limiting**

- Each token may run no more than 5 queries during a single calendar minute, where a calendar minute is seconds 0 through 59 of that minute.
- This rate-limit information must persist between separate executions of the script.
- Any invocation that successfully validates its token counts as one query execution for rate limiting, even if the SQL execution later fails.
- If the token has already performed 5 queries during the current calendar minute, print `RATE_LIMIT_EXCEEDED` to stdout and exit with status code 2.

**3. SQL execution**

- Run the provided SQL statement against `data.db`.
- If the statement returns rows, print them to stdout as comma-separated values, one row per line, with no header row.
- If the statement returns no rows, print nothing.
- If the statement raises an error, print `QUERY_ERROR: <error message>` to stdout and exit with status code 3.
- If the statement succeeds, exit with status code 0.

Example:

Suppose `tokens.txt` contains:

```
abc123
def456
```

Suppose `data.db` has a `users` table with columns `id` and `name`, containing `(1, 'Alice')` and `(2, 'Bob')`. Then this command:

```
DB_TOKEN=abc123 python dbcli.py "SELECT id, name FROM users"
```

should print:

```
1,Alice
2,Bob
```

If the same command is run six times within one calendar minute, the sixth run should print `RATE_LIMIT_EXCEEDED` and exit with status code 2.
