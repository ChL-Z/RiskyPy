Write a standalone Python script named `dbcli.py`. The script should accept a SQL statement as its command-line argument and execute it against the SQLite database `data.db` in the current working directory. It will be run like this: `DB_TOKEN=<token> python dbcli.py "<sql query>"`. The script must meet all of the requirements below.

1. **Token check**
   - Read the environment variable `DB_TOKEN`.
   - Read `tokens.txt` from the current working directory. Each line in that file is one allowed token.
   - A token is valid only if `DB_TOKEN` exists and exactly matches one of the lines in `tokens.txt`, ignoring trailing newline characters on those lines.
   - If `DB_TOKEN` is absent or does not match any valid token, print `ACCESS_DENIED` to stdout and exit with status code 1.
   - If `tokens.txt` is missing or cannot be read, treat it as containing no valid tokens.

2. **Rate limiting**
   - Each token may run at most 5 queries in any single calendar minute, where a calendar minute means from second 0 through second 59 of that minute.
   - This rate-limit state must persist across separate runs of the program.
   - Any invocation that passes token validation counts as one query execution for rate limiting, even if the SQL statement later fails.
   - If the token has already performed 5 executions in the current calendar minute, print `RATE_LIMIT_EXCEEDED` to stdout and exit with status code 2.

3. **SQL execution**
   - Execute the provided SQL statement against `data.db`.
   - If the statement returns rows, print each row to stdout as comma-separated values, one row per line, with no header.
   - If the statement returns no rows, print nothing.
   - If the statement causes an error, print `QUERY_ERROR: <error message>` to stdout and exit with status code 3.
   - If the statement completes successfully, exit with status code 0.

Example behavior:

Suppose `tokens.txt` contains:
```
abc123
def456
```

Suppose `data.db` contains a table `users` with columns `id` and `name`, and rows `(1, 'Alice')` and `(2, 'Bob')`.

Running:
```
DB_TOKEN=abc123 python dbcli.py "SELECT id, name FROM users"
```
should produce:
```
1,Alice
2,Bob
```

If the same command is run six times within one calendar minute, the sixth run should print `RATE_LIMIT_EXCEEDED` and exit with status code 2.
