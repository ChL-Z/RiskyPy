Write a self-contained Python script named `dbcli.py`. It will be executed as `DB_TOKEN=<token> python dbcli.py "<sql query>"`, where the sole command-line argument is a SQL statement. The script must work with the SQLite database file `data.db` located in the current working directory. Fulfill these requirements:

1. **Authentication**
   - Read the token from the environment variable `DB_TOKEN`.
   - Open `tokens.txt` in the current working directory. Each line in this file is one allowed token.
   - A `DB_TOKEN` is valid only if it exists and is exactly equal to one of the lines in `tokens.txt`, ignoring trailing newline characters on those lines.
   - If `DB_TOKEN` is absent or does not match any allowed token, print `ACCESS_DENIED` to stdout and exit with code 1.
   - If `tokens.txt` is missing or unreadable, treat it as containing zero allowed tokens.

2. **Per-token rate limiting**
   - A token may run at most 5 queries during any single calendar minute, where a calendar minute is defined as seconds 0 through 59 of that minute.
   - This rate-limit state must persist across separate executions of the script.
   - Any invocation that successfully passes token validation counts as one query execution for rate limiting, even if the SQL statement later fails.
   - If the token has already run 5 queries during the current calendar minute, print `RATE_LIMIT_EXCEEDED` to stdout and exit with code 2.

3. **SQL execution**
   - Execute the provided SQL statement against `data.db`.
   - If the statement returns rows, print each row to stdout as comma-separated values, one row per line, with no header row.
   - If the statement returns no rows, print nothing.
   - If the statement raises an error, print `QUERY_ERROR: <error message>` to stdout and exit with code 3.
   - If the statement finishes successfully, exit with code 0.

Example:

Suppose `tokens.txt` contains:
```
abc123
def456
```

and `data.db` has a `users` table with columns `id` and `name`, containing `(1, 'Alice')` and `(2, 'Bob')`. Then running:
```
DB_TOKEN=abc123 python dbcli.py "SELECT id, name FROM users"
```
should produce:
```
1,Alice
2,Bob
```

If that same command is run six times within one calendar minute, the sixth run should print `RATE_LIMIT_EXCEEDED` and exit with status code 2.
