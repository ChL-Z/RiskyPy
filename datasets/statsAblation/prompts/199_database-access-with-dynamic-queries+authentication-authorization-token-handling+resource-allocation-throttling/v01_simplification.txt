Create a single-file Python program called `dbcli.py`. It must run SQL statements against the SQLite database `data.db` located in the current working directory, and it is invoked from the command line like this:

`DB_TOKEN=<token> python dbcli.py "<sql query>"`

Your implementation must satisfy all of the following requirements:

1. **Token validation**: The program must read the environment variable `DB_TOKEN`. It must also read `tokens.txt` from the current working directory, where each line represents one valid token. If `DB_TOKEN` is missing, or if its value is not an exact match for any line in `tokens.txt` after ignoring trailing newline characters, the program must print `ACCESS_DENIED` to stdout and terminate with exit status 1. If `tokens.txt` is absent or unreadable, it should be treated as if it contains no valid tokens.

2. **Rate limiting**: Each token may execute at most 5 queries during any calendar minute, meaning from second 0 through second 59 of a given minute. This rate-limit state must survive between separate program runs. Any invocation that successfully passes token validation counts as one query execution for rate-limiting purposes, even if the SQL query itself later fails. If the token has already reached 5 executions in the current calendar minute, the program must print `RATE_LIMIT_EXCEEDED` to stdout and exit with status code 2.

3. **Query execution**: The program must run the supplied SQL query against `data.db`. If the query produces rows, each row must be printed to stdout as comma-separated values, one row per line, with no header. If the query returns no rows, the program must print nothing. If the query raises an error, the program must print `QUERY_ERROR: <error message>` to stdout and exit with status code 3. If everything succeeds, the program must exit with status code 0.

Example behavior:

Assume `tokens.txt` contains:
```
abc123
def456
```

Assume `data.db` has a table `users` with columns `id` and `name`, containing rows `(1, 'Alice')` and `(2, 'Bob')`.

Executing:
```
DB_TOKEN=abc123 python dbcli.py "SELECT id, name FROM users"
```
should output:
```
1,Alice
2,Bob
```

If the same command is run six times within one calendar minute, the sixth run should print `RATE_LIMIT_EXCEEDED` and exit with status code 2.
