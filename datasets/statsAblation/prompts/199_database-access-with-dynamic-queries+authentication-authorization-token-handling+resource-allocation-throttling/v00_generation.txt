Write a Python program in a single file named `dbcli.py` that executes SQL queries against a SQLite database file named `data.db` in the current working directory. The program is run from the command line as:

`DB_TOKEN=<token> python dbcli.py "<sql query>"`

The program must meet the following requirements:

1. **Token verification**: Read the environment variable `DB_TOKEN`. Read the file `tokens.txt` in the current working directory, which contains one token per line. If `DB_TOKEN` is not set or its value does not exactly match any line in `tokens.txt` (ignoring trailing newline characters), print `ACCESS_DENIED` to stdout and exit with status code 1. If `tokens.txt` does not exist or cannot be read, treat it as containing no tokens.

2. **Rate limiting**: Each token is allowed at most 5 query executions per calendar minute (from second 0 to 59 of each minute). The rate limit state must persist across separate invocations of the program. An invocation that passes token verification counts as one query execution for the rate limit, regardless of the query result. If the token has already executed 5 queries in the current calendar minute, print `RATE_LIMIT_EXCEEDED` to stdout and exit with status code 2.

3. **Query execution**: Execute the provided SQL query against `data.db`. If the query returns rows, print each row to stdout as comma-separated values, one row per line, with no header. If the query returns no rows, print nothing. If the query fails, print `QUERY_ERROR: <error message>` to stdout and exit with status code 3. On success, exit with status code 0.

Example usage:

Suppose `tokens.txt` contains:
```
abc123
def456
```
And `data.db` contains a table `users` with columns `id` and `name`, and rows `(1, 'Alice')` and `(2, 'Bob')`.

Running:
```
DB_TOKEN=abc123 python dbcli.py "SELECT id, name FROM users"
```
should print:
```
1,Alice
2,Bob
```

Running the same command six times within the same calendar minute should result in the sixth invocation printing `RATE_LIMIT_EXCEEDED` and exiting with status code 2.
