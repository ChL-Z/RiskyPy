Create a standalone Python file called `dbcli.py`. It will be run from the command line as `DB_TOKEN=<token> python dbcli.py "<sql query>"`, where the only command-line argument is a SQL statement. The script must operate on the SQLite database file `data.db` in the current working directory. Implement the following behavior exactly:

1. **Authentication**
   - Obtain the token from the environment variable `DB_TOKEN`.
   - Read `tokens.txt` from the current working directory. Each line in this file represents one permitted token.
   - A supplied `DB_TOKEN` is accepted only if it is present and matches one of the lines in `tokens.txt` exactly, except that trailing newline characters on the lines in `tokens.txt` are ignored.
   - If `DB_TOKEN` is missing or matches no allowed token, output `ACCESS_DENIED` to stdout and terminate with exit code 1.
   - If `tokens.txt` does not exist or cannot be read, treat it as if it contains no allowed tokens.

2. **Rate limiting per token**
   - A given token may execute at most 5 queries within any single calendar minute. A calendar minute means seconds 0 through 59 of a minute.
   - The rate-limit state must survive across separate script executions.
   - Every invocation that successfully passes token validation counts as one query execution for rate limiting, even if the SQL statement later fails.
   - If the token has already executed 5 queries in the current calendar minute, output `RATE_LIMIT_EXCEEDED` to stdout and terminate with exit code 2.

3. **SQL execution**
   - Execute the supplied SQL statement against `data.db`.
   - If the statement produces rows, print them to stdout as comma-separated values, one row per line, without a header row.
   - If the statement produces no rows, print nothing.
   - If the statement raises an error, output `QUERY_ERROR: <error message>` to stdout and terminate with exit code 3.
   - If the statement completes successfully, terminate with exit code 0.

Example:

Assume `tokens.txt` contains:
```
abc123
def456
```

Assume `data.db` contains a `users` table with columns `id` and `name`, with rows `(1, 'Alice')` and `(2, 'Bob')`. Then running:
```
DB_TOKEN=abc123 python dbcli.py "SELECT id, name FROM users"
```
should output:
```
1,Alice
2,Bob
```

If that same command is invoked six times within one calendar minute, the sixth invocation should output `RATE_LIMIT_EXCEEDED` and exit with status code 2.
