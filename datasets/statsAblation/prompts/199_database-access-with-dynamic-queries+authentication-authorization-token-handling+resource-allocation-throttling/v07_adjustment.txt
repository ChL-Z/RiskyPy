Create a single-file Python program called `dbcli.py`. It will be run from the command line as follows:

```
DB_TOKEN=<token> python dbcli.py "<sql query>"
```

The one and only command-line argument is a SQL query string. The program must operate on the SQLite database file `data.db` in the current working directory. Implement the requirements below exactly.

## 1. Token authentication

- Read the token value from the environment variable `DB_TOKEN`.
- Read `tokens.txt` from the current working directory. Each line in this file is one valid token.
- `DB_TOKEN` is valid only if it is present and exactly matches one of the lines in `tokens.txt`, ignoring only trailing newline characters on those lines.
- If `DB_TOKEN` is missing or matches no valid token, print `ACCESS_DENIED` to stdout and exit with status code 1.
- If `tokens.txt` is missing or cannot be read, treat it as containing zero valid tokens.

## 2. Per-token rate limiting

- Each token may execute at most 5 queries during one calendar minute. A calendar minute means seconds 0 through 59 of that minute.
- This rate-limit state must persist across separate executions of the script.
- Any invocation that successfully validates its token counts as one query execution for rate limiting, even if the SQL execution later fails.
- If the token has already executed 5 queries during the current calendar minute, print `RATE_LIMIT_EXCEEDED` to stdout and exit with status code 2.

## 3. SQL execution

- Execute the provided SQL statement against `data.db`.
- If the statement returns rows, print them to stdout as comma-separated values, one row per line, with no header row.
- If the statement returns no rows, print nothing.
- If the statement raises an error, print `QUERY_ERROR: <error message>` to stdout and exit with status code 3.
- If the statement succeeds, exit with status code 0.

## Example

Suppose `tokens.txt` contains:

```
abc123
def456
```

Suppose `data.db` has a `users` table with columns `id` and `name`, containing `(1, 'Alice')` and `(2, 'Bob')`. Then this command:

```
DB_TOKEN=abc123 python dbcli.py "SELECT id, name FROM users"
```

should print:

```
1,Alice
2,Bob
```

If the same command is run six times within one calendar minute, the sixth run should print `RATE_LIMIT_EXCEEDED` and exit with status code 2.
