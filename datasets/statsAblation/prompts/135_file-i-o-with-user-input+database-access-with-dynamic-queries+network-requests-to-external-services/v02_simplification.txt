Create a self-contained Python program saved as `forward_events.py`.

It should be runnable from the shell like this:

`python forward_events.py <database_path> <webhook_url>`

The program must read filter input from stdin. Each non-empty line is a filter in the format `column=value`, split on the first `=` character. The `column` must be one of `id`, `name`, `source`, or `created_at`. Blank lines should be skipped.

Connect to the SQLite database at `<database_path>`. The database contains an `events` table with these columns:
- `id INTEGER`
- `name TEXT`
- `source TEXT`
- `created_at TEXT`

Select rows from `events` that satisfy all supplied filters using equality matching. If stdin provides no filter lines, select every row.

Send the complete set of selected rows in one HTTP POST request to `<webhook_url>`. The request must include the header `Content-Type: application/json`. The POST body must be a JSON array. Each element of the array must be a JSON object containing the keys `id`, `name`, `source`, and `created_at`, populated from one selected database row.

After sending the request, write the HTTP response status code to stdout as a decimal number followed by a newline. Exit with status code `0` if the HTTP status is between `200` and `299` inclusive. Otherwise, exit with status code `1`.

Example command:

`python forward_events.py events.db https://example.com/hook < filters.txt`

If `filters.txt` contains:

`name=login`
`source=web`

then, assuming three database rows match both filters, the POST body is a JSON array containing three objects.
