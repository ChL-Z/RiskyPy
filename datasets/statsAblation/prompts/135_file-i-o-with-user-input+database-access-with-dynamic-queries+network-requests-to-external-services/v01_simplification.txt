Write a standalone Python script named `forward_events.py`.

Run it from the command line as:

`python forward_events.py <database_path> <webhook_url>`

The script should read filter rules from standard input. Every non-empty input line is a filter of the form `column=value`, where the split happens at the first `=`. The `column` part must be one of: `id`, `name`, `source`, or `created_at`. Ignore blank lines.

Open the SQLite database located at `<database_path>`. This database has an `events` table with the columns `id INTEGER`, `name TEXT`, `source TEXT`, and `created_at TEXT`. Query the `events` table for rows that match every provided filter by equality. If no filter lines are provided, select all rows.

Send all selected rows in a single HTTP POST request to `<webhook_url>`. Use the request header `Content-Type: application/json`. The request body must be a JSON array, where each array element is a JSON object with the keys `id`, `name`, `source`, and `created_at`, containing the values from one selected database row.

After the request, print the HTTP response status code as a decimal number followed by a newline to standard output. Exit with status code 0 if the HTTP status is from 200 through 299 inclusive; otherwise exit with status code 1.

Example invocation:

`python forward_events.py events.db https://example.com/hook < filters.txt`

If `filters.txt` contains:

`name=login`
`source=web`

then, assuming three rows satisfy both filters, the POST body is a JSON array containing three objects.
