Write a standalone Python script named `forward_events.py` that can be executed from the command line as:

`python forward_events.py <database_path> <webhook_url>`

The script should read filter expressions from standard input. Each non-blank input line is a filter of the form `column=value`; split the line on the first `=` only. The `column` part must be one of `id`, `name`, `source`, or `created_at`. Ignore empty lines.

Use the SQLite database located at `<database_path>`. The database has an `events` table with the following schema:

- `id INTEGER`
- `name TEXT`
- `source TEXT`
- `created_at TEXT`

Query the `events` table for all rows that match every provided filter using equality comparisons. If no filter lines were provided on stdin, query all rows instead.

Send all selected rows together in a single HTTP POST request to `<webhook_url>`. The request must have the header `Content-Type: application/json`. The POST body must be a JSON array, where each element is a JSON object with exactly the keys `id`, `name`, `source`, and `created_at`, populated from a selected database row.

After the HTTP request has been sent, print the HTTP response status code to stdout as a decimal integer followed by a newline. If the status code is in the range 200 through 299 inclusive, exit with status code `0`. Otherwise, exit with status code `1`.

For example, the script might be run as:

`python forward_events.py events.db https://example.com/hook < filters.txt`

If `filters.txt` contains:

`name=login`
`source=web`

then, assuming three database rows match both filters, the POST body will be a JSON array containing three objects.
