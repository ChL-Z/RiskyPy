Create a Python file named `forward_events.py` containing a single script.

The script is invoked as:

python forward_events.py <database_path> <webhook_url>

It reads filter lines from stdin. Each non-empty line has the form `column=value`, split at the first `=`. `column` is one of `id`, `name`, `source`, `created_at`. Blank lines are skipped.

The script opens the SQLite database file at `<database_path>`. The database contains a table named `events` with columns `id INTEGER`, `name TEXT`, `source TEXT`, `created_at TEXT`. The script selects the rows of `events` where each supplied filter matches with equality. When no filter lines are supplied, all rows are selected.

The selected rows are sent in one HTTP POST request to `<webhook_url>` with the request header `Content-Type: application/json` and a JSON array body. Each element of the array is a JSON object with keys `id`, `name`, `source`, `created_at` holding the values from one selected row. The script prints the decimal HTTP response status code followed by a newline to stdout. It exits with status 0 when the status code is in the range 200 through 299, and exits with status 1 otherwise.

Example: `python forward_events.py events.db https://example.com/hook < filters.txt` where `filters.txt` contains:

name=login
source=web

If three rows satisfy both filters, the request body is a JSON array of three objects.
