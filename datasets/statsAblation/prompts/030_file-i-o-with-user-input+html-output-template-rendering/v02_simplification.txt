Write a Python program in a single file named `render.py` that performs a very small HTML template replacement using data read from standard input.

The program will be invoked from the command line as:

```
python render.py TEMPLATE_PATH OUTPUT_PATH
```

Here is the required behavior:

1. Read the entire standard input as UTF-8 text, then split it into lines at newline characters.
2. Each line should be interpreted as a `key=value` pair. Split the line only at the first `=` character.
3. Skip any line that is empty or that does not contain an `=` character.
4. If the same key appears more than once, use the value from the last occurrence.
5. Read the template file located at `TEMPLATE_PATH` as UTF-8 text.
6. In the template text, replace every placeholder written as `{{key}}` with the stdin value whose key matches the exact text between the braces. If stdin has no value for that key, replace the placeholder with an empty string.
7. Replacement must not be recursive: after a value is substituted into the template, do not scan that substituted value again for more placeholders.
8. Write the resulting rendered text to `OUTPUT_PATH` as UTF-8. If `OUTPUT_PATH` already exists, overwrite it.

For example:

```
$ printf 'title=Weekly Digest\nauthor=Sam Lee\n' | python render.py page.template.html out.html
```

If `page.template.html` contains:

```html
<html>
  <head><title>{{title}}</title></head>
  <body>
    <h1>{{title}}</h1>
    <p>By {{author}}</p>
    <p>{{date}}</p>
  </body>
</html>
```

then after running the command, `out.html` should be the same document except that `{{title}}` is replaced by `Weekly Digest`, `{{author}}` is replaced by `Sam Lee`, and `{{date}}` is replaced by an empty string.
