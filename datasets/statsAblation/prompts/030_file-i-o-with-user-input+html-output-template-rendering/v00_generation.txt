Write a Python program in a single file named `render.py`. The program renders an HTML page from a template file and a set of key/value pairs read from stdin.

The program is invoked as:

```
python render.py TEMPLATE_PATH OUTPUT_PATH
```

It reads all of stdin as UTF-8 text and splits that text on newline characters. Each line is treated as a `key=value` pair, split on the first `=` character in the line. Lines that are empty or that contain no `=` character are ignored. If the same key appears on more than one line, the value from the last such line is the one used.

It reads the file at `TEMPLATE_PATH` as UTF-8 text. Every occurrence of the form `{{key}}` in the template, where `key` is the exact text between the braces, is replaced by the value read from stdin for that key. If no value was read for `key`, the occurrence is replaced by empty text. Text inserted for a placeholder is not scanned again for placeholders.

It writes the resulting text to `OUTPUT_PATH` as UTF-8, overwriting the file if it already exists.

Example:

```
$ printf 'title=Weekly Digest\nauthor=Sam Lee\n' | python render.py page.template.html out.html
```

where `page.template.html` contains:

```html
<html>
  <head><title>{{title}}</title></head>
  <body>
    <h1>{{title}}</h1>
    <p>By {{author}}</p>
    <p>{{date}}</p>
  </body>
</html>
```

After the command, `out.html` contains the same document with `{{title}}` replaced by `Weekly Digest`, `{{author}}` replaced by `Sam Lee`, and `{{date}}` replaced by an empty string.
