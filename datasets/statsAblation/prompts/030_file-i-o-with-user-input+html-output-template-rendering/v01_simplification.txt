Create a single Python file called `render.py` that performs simple HTML template rendering using values supplied through standard input.

The script is run like this:

```
python render.py TEMPLATE_PATH OUTPUT_PATH
```

Behavior:

1. Read all of stdin as UTF-8 text, then split it into lines using newline characters.
2. Treat each line as a `key=value` entry, splitting at the first `=` character. Ignore any line that is empty or does not contain `=`.
3. If a key occurs multiple times, the value from its last occurrence is the one that takes effect.
4. Read the template file at `TEMPLATE_PATH` as UTF-8 text.
5. In that template text, replace every placeholder of the form `{{key}}` with the stdin value associated with `key`. The key is exactly the text between the braces. If stdin supplied no value for that key, replace the placeholder with an empty string.
6. Do not scan substituted values again for further placeholders.
7. Write the final rendered text to `OUTPUT_PATH` as UTF-8, overwriting that file if it already exists.

Example:

```
$ printf 'title=Weekly Digest\nauthor=Sam Lee\n' | python render.py page.template.html out.html
```

Suppose `page.template.html` contains:

```html
<html>
  <head><title>{{title}}</title></head>
  <body>
    <h1>{{title}}</h1>
    <p>By {{author}}</p>
    <p>{{date}}</p>
  </body>
</html>
```

After running the command, `out.html` should contain the same document except that `{{title}}` becomes `Weekly Digest`, `{{author}}` becomes `Sam Lee`, and `{{date}}` becomes an empty string.
