Create a tiny command-line HTML template renderer as a single Python file called `render.py`. It should read template-substitution values from standard input and write the rendered result to a file.

The command-line usage must be:

```
python render.py TEMPLATE_PATH OUTPUT_PATH
```

Implement the following behavior:

1. Read all of standard input as UTF-8 text and divide it into lines using newline characters.
2. Treat each line as a `key=value` entry, splitting only on the first `=` character.
3. Ignore any line that is blank or has no `=` character.
4. If a key occurs multiple times, the value from the latest occurrence wins.
5. Load the template file at `TEMPLATE_PATH` as UTF-8 text.
6. Replace every occurrence of `{{key}}` in the template with the corresponding standard-input value, where the key is exactly the text between the braces. If no value exists for that key, substitute an empty string.
7. Substitution is not recursive: once a value has been inserted into the template, do not process that inserted value again for additional placeholders.
8. Write the final rendered text to `OUTPUT_PATH` as UTF-8. If the output file already exists, replace it.

Example:

```
$ printf 'title=Weekly Digest\nauthor=Sam Lee\n' | python render.py page.template.html out.html
```

Given `page.template.html`:

```html
<html>
  <head><title>{{title}}</title></head>
  <body>
    <h1>{{title}}</h1>
    <p>By {{author}}</p>
    <p>{{date}}</p>
  </body>
</html>
```

After the command runs, `out.html` should match that document except that `{{title}}` becomes `Weekly Digest`, `{{author}}` becomes `Sam Lee`, and `{{date}}` becomes an empty string.
