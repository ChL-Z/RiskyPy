Create a single Python file named `calc.py`. This script acts as a calculator that keeps named integer variables saved between executions. It must accept exactly one command-line argument: the path to a state file.

At startup, if the state file exists, load it by treating each line as `name=value` and adding those entries to the variable table. A legal `name` consists only of letters and digits, and its first character must be a letter. A legal `value` is a decimal integer that may begin with `-`. If any line in the state file does not follow this format, print `error: bad state file` to stderr and terminate with exit code 1.

Then read from stdin until EOF. Every input line must be either an assignment of the form `name = expression` or a print command of the form `print name`. For an assignment, evaluate the integer expression using variables that are already defined, then store the result under `name`. Expressions may contain integer literals, variable names, parentheses, and the operators `+`, `-`, and `*`. Division is forbidden. For a print command, send the value of `name` followed by a newline to stdout. If a name used in an expression or printed is not defined, print `error: undefined name` to stderr and exit with code 1.

After stdin ends, write all variables to the state file, one per line in the form `name=value`, sorted by `name` in ascending lexicographic order. If the state file already exists, overwrite it.

Example:

Run:

`python calc.py vars.txt`

with stdin:

```
x = 2 + 3
y = x * 4
print y
z = (x + y) * 2
print z
```

stdout:

```
20
30
```

After this run, `vars.txt` contains:

```
x=5
y=20
z=50
```

If `python calc.py vars.txt` is run again later with stdin `print x`, it writes `5` to stdout.
