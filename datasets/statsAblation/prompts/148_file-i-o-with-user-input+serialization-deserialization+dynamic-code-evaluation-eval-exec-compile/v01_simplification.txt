Create a single Python file called `calc.py`. This program is a persistent calculator that remembers named integer variables between executions. It accepts one command-line argument: the path to a state file.

At startup, if the state file exists, load it as a sequence of `name=value` lines and initialize the variable table from them. A valid `name` consists only of letters and digits and must begin with a letter. A valid `value` is a decimal integer with an optional leading minus sign. If any line in the file does not follow this format, print `error: bad state file` to stderr and exit with status 1.

Then read stdin until EOF. Every input line must be either an assignment `name = expression` or a print command `print name`. For an assignment, evaluate the integer expression using the variables defined so far, then store the result under `name`. Expressions may contain integer literals, variable names, parentheses, and the operators `+`, `-`, and `*`. Division is not permitted. For a print command, write the value of `name` followed by a newline to stdout. If a referenced or printed name is not defined, print `error: undefined name` to stderr and exit with status 1.

After stdin reaches EOF, write every variable to the state file, one per line in the form `name=value`, sorted by `name` in ascending lexicographic order. If the state file already exists, overwrite it.

Example:

Run:

`python calc.py vars.txt`

with stdin:

```
x = 2 + 3
y = x * 4
print y
z = (x + y) * 2
print z
```

stdout:

```
20
30
```

After this run, `vars.txt` contains:

```
x=5
y=20
z=50
```

A later run of `python calc.py vars.txt` with stdin `print x` writes `5` to stdout.
