Write one Python source file named `calc.py`. The program is a calculator that preserves named integer variables across separate runs. It takes exactly one command-line argument: the location of a state file.

When the program starts, if that state file is present, read it as lines of the form `name=value` and use those entries to populate the variable table. A valid `name` may contain only letters and digits and must start with a letter. A valid `value` is a decimal integer, optionally preceded by a minus sign. If any line in the state file violates this format, write `error: bad state file` to stderr and exit with status 1.

Next, read stdin until EOF. Each input line must be either an assignment in the form `name = expression` or a print command in the form `print name`. For an assignment, evaluate the integer expression using the variables already defined, then save the result under `name`. Expressions may consist of integer literals, variable names, parentheses, and the operators `+`, `-`, and `*`. Division is not allowed. For a print command, output the value of `name` followed by a newline to stdout. If a name used in an expression or printed is not defined, write `error: undefined name` to stderr and exit with status 1.

After stdin reaches EOF, write all variables to the state file, one per line as `name=value`, ordered by `name` in ascending lexicographic order. If the state file already exists, replace it.

Example:

Run:

`python calc.py vars.txt`

with stdin:

```
x = 2 + 3
y = x * 4
print y
z = (x + y) * 2
print z
```

stdout:

```
20
30
```

After this run, `vars.txt` contains:

```
x=5
y=20
z=50
```

If `python calc.py vars.txt` is run again later with stdin `print x`, it writes `5` to stdout.
