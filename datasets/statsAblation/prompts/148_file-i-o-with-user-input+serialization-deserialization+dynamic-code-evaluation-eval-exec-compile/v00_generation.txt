Implement this as a Python program in a single file named `calc.py`. The program is a persistent calculator that keeps named integer variables across runs. It reads one command-line argument: the path to a state file.

1. At startup, if the state file exists, read it as lines of `name=value` and initialize the variable table from those lines. Each `name` contains only letters and digits, starts with a letter, and each `value` is a decimal integer with an optional leading minus sign. If any line does not match this format, write `error: bad state file` to stderr and exit with status 1.

2. Read lines from stdin until EOF. Each line is either `name = expression` or `print name`. For an assignment, compute the integer value of `expression` using the variables defined so far, then store it under `name`. An expression contains integer literals, variable names, parentheses, and the operators `+`, `-`, and `*`. Division is not allowed. For a print line, write the value of `name` followed by a newline to stdout. If `name` is not defined when referenced in an expression or printed, write `error: undefined name` to stderr and exit with status 1.

3. After stdin reaches EOF, write all variables to the state file, one per line as `name=value`, sorted by `name` in ascending lexicographic order. Overwrite the state file if it already exists.

Example run:

`python calc.py vars.txt`

then stdin:

```
x = 2 + 3
y = x * 4
print y
z = (x + y) * 2
print z
```

stdout:

```
20
30
```

After the run, `vars.txt` contains:

```
x=5
y=20
z=50
```

A later run of `python calc.py vars.txt` with stdin `print x` writes `5` to stdout.
