Create one Python file called `taskcache.py`. It should be a command-line utility run like this:

```
python taskcache.py <cache_dir> <key_file>
```

Here, `<cache_dir>` is an already-existing directory, and `<key_file>` points to a file that contains a secret key.

The program reads task names from standard input, one name per line. Ignore blank lines. Process task names in the order they arrive on standard input.

For each task name `<name>`, do one of the following:

- If `<cache_dir>/<name>.cache` already exists, read the cached value from it, then print that value to standard output followed by exactly one newline.
- Otherwise, execute the command specified by the single-line contents of `<cache_dir>/<name>.cmd`. Capture that command's standard output. If the captured output ends with a newline, remove exactly one trailing newline. Print the resulting value to standard output followed by exactly one newline, and store that value in `<cache_dir>/<name>.cache`.

Requirements:

1. Every file the program creates under `<cache_dir>` must end in `.cache` and must contain both the task name and the value. Each such file must also contain a tag computed from the file's contents together with the key read from `<key_file>`. When reading a `.cache` file later, recompute the tag from the file's contents and the key, and accept the file only if the recomputed tag matches the stored tag. If they do not match, print `TAMPERED <name>` to standard output and exit with status 2.

2. The program may begin at most 3 tasks within any 1.0-second window. In other words, for every task after the third task, its start time must be at least 1.0 second after the start time of the task three positions earlier. If starting the next task would break this rule, wait until it is allowed before starting it.

Example usage:

```
printf 'build\nlint\nbuild\n' | python taskcache.py ./cache ./secret.key
```

On the first run, this executes `./cache/build.cmd` once and `./cache/lint.cmd` once, writes the two corresponding `.cache` files, and prints each captured value. The second occurrence of `build` reads the cached value instead of running the command again.
