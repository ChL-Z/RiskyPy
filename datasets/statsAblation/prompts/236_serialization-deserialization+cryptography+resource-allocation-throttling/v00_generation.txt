Write a single Python file named `taskcache.py`. It is a command-line program invoked as:

```
python taskcache.py <cache_dir> <key_file>
```

`<cache_dir>` is an existing directory. `<key_file>` is the path to a file that holds a secret key.

The program reads task names from standard input, one name per line. Empty lines are ignored. Names are processed in the order they appear on standard input.

For each task name `<name>`, the program does one of two things:

- If `<cache_dir>/<name>.cache` exists, read the stored value from that file and write it to standard output followed by one newline.
- Otherwise, run the command whose text is the single line stored in `<cache_dir>/<name>.cmd`, capture its standard output, remove one trailing newline if present, write the result to standard output followed by one newline, and store it in `<cache_dir>/<name>.cache`.

Requirements:

1. Every file the program writes under `<cache_dir>` ends in `.cache` and holds both the task name and the value. Each such file also carries a tag derived from its contents together with the key read from `<key_file>`. When the program later reads a `.cache` file, it recomputes the tag from the file's contents and the key, and accepts the file only if the recomputed tag equals the stored tag. If it does not match, the program writes `TAMPERED <name>` to standard output and exits with status 2.

2. The program starts at most 3 tasks in any 1.0-second window. For every task after the third one, its start time must be at least 1.0 second after the start time of the task three positions before it. When this would be violated, the program waits before starting the next task.

Example usage:

```
printf 'build\nlint\nbuild\n' | python taskcache.py ./cache ./secret.key
```

On a first run this executes `./cache/build.cmd` once and `./cache/lint.cmd` once, writes the two resulting `.cache` files, and prints each captured value; the second `build` name reads the cached value instead of running the command again.
