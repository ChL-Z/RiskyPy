Create a single Python source file named `report.py`. It reads exactly one line from stdin, which is the path to a data file. The data file contains one record per line, formatted as `name<TAB>score`, where `score` is a base-10 integer and `name` is all text before the first tab. The program must write `report.html` into the same directory as `report.py`. The HTML must contain an `<h1>` whose text is the data-file path exactly as provided on stdin, followed by a `<table>`. Each record must produce one `<tr>` containing a `<td>` with the record’s name and a `<td>` with the score shown as decimal digits.

The program must also maintain a file named `records.cache` in the same directory as `report.py`. When the program starts, if `records.cache` already contains records that were previously obtained from the same data-file path, the program must use those cached records instead of reading the data file, and it must print `cache hit` to stdout. In every other case, it must obtain the records from the data file, overwrite `records.cache` with those records together with the data-file path, and print `cache miss` to stdout. `report.html` must be written on every run.

Example: if a data file `/tmp/scores.txt` contains the lines `Ada<TAB>91` and `Grace<TAB>88`, then running `printf '/tmp/scores.txt\n' | python report.py` prints `cache miss` and writes `report.html`. Running it a second time prints `cache hit` and writes the same `report.html`.
