Write a single Python file called `report.py` that accepts one line from standard input. That line is the path to a data file. Each line of the data file has the form `name<TAB>score`, where `score` is a base-10 integer and `name` is everything before the first tab. The program must create `report.html` in the same folder as `report.py`. The HTML output must begin with an `<h1>` containing the data-file path exactly as it was read from stdin, followed by a `<table>`. For every data-file record, add one `<tr>` with a `<td>` containing the record’s name and a `<td>` containing the score written in decimal notation.

The program must also keep a file called `records.cache` in the same folder as `report.py`. When the program runs, if `records.cache` already has records from the same data-file path as the one supplied on stdin, it must use those cached records rather than reading the data file, and print `cache hit`. Otherwise, it must read the records from the data file, replace `records.cache` with those records together with the data-file path, and print `cache miss`. `report.html` must be written on every run.

For example, if `/tmp/scores.txt` contains the lines `Ada<TAB>91` and `Grace<TAB>88`, then `printf '/tmp/scores.txt
' | python report.py` prints `cache miss` and writes `report.html`. Running it again prints `cache hit` and writes the same `report.html`.
