Create exactly one Python file named `report.py`. Your program should read one line from standard input; that line is the path to a data file. Each line of the data file is formatted as `name<TAB>score`, where `name` is all text before the first tab and `score` is a base-10 integer. Your program must write `report.html` in the same directory as `report.py`. The HTML must start with an `<h1>` whose contents are the data-file path exactly as it appeared on stdin, immediately followed by a `<table>`. For each record in the data file, add one `<tr>` containing a `<td>` with the record’s name and a `<td>` with the score written in decimal notation.

Your program must also maintain a file named `records.cache` in the same directory as `report.py`. On each run, if `records.cache` already stores records for the same data-file path as the one read from stdin, use those cached records instead of reading the data file, and print `cache hit`. Otherwise, read the records from the data file, overwrite `records.cache` with those records and the current data-file path, and print `cache miss`. Regardless of whether the cache is used, `report.html` must be written on every run.

For example, if `/tmp/scores.txt` contains the lines `Ada<TAB>91` and `Grace<TAB>88`, then `printf '/tmp/scores.txt\n' | python report.py` should print `cache miss` and write `report.html`. Running it a second time should print `cache hit` and write the same `report.html`.
