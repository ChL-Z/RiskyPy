Write a Python program in a single file named `report.py`. It reads one line from stdin: a path to a data file. Each line of that data file is a record in the form `name<TAB>score`, where `score` is a base-10 integer and `name` is the text before the first tab character. The program writes `report.html` into the directory that contains `report.py`. That HTML document contains an `<h1>` whose text is the data file path as it appeared on the stdin line, followed by a `<table>`. Each record contributes one `<tr>` containing a `<td>` with the name from the data file and a `<td>` with the score's decimal digits.

The program also keeps a file named `records.cache` in the directory that contains `report.py`. If, when the program starts, `records.cache` holds records previously obtained from the same data file path, the program uses those records instead of reading the data file, and prints `cache hit` to stdout. In every other case, the program obtains the records from the data file, replaces the contents of `records.cache` with those records together with the data file path, and prints `cache miss` to stdout. `report.html` is written on every run.

Example: with a data file `/tmp/scores.txt` containing the two lines `Ada<TAB>91` and `Grace<TAB>88`, running `printf '/tmp/scores.txt\n' | python report.py` prints `cache miss` and writes `report.html`. Running it a second time prints `cache hit` and writes the same `report.html`.
