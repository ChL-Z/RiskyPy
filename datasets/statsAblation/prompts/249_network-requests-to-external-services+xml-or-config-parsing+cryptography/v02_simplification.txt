Create a standalone Python script called `provision_codes.py`.

Run it from a folder that contains an `endpoint.xml` file, passing the customer ID as a command-line argument:

```
python provision_codes.py <customer-id>
```

The `endpoint.xml` file has this structure:

```xml
<endpoint>
  <url>https://provisioning.example.com/api</url>
</endpoint>
```

The script must perform these tasks:

1. Read `endpoint.xml`, extract the text inside its `<url>` element, and treat that as the provisioning service base URL. Then send a request to `<base-url>/profile/<customer-id>` and parse the XML response. The response XML has this form:

```xml
<profile>
  <customer id="acme"/>
  <codes count="8" length="10" alphabet="ABCDEFGHJKLMNPQRSTUVWXYZ23456789"/>
</profile>
```

2. Generate one code for each unit of `count`. Write them to a file in the current directory named `codes-<customer-id>.txt`. The file must contain one code per line, and it must end with a newline after the last code. Every code must have exactly `length` characters. Every character in every code must come from the `alphabet` attribute. No two generated codes may be the same.

3. Print the number of generated codes to stdout as a base-10 integer followed by a newline.

For example, if `endpoint.xml` contains the URL shown above and the script is run as `python provision_codes.py acme`, it should request `https://provisioning.example.com/api/profile/acme`, create `codes-acme.txt` with eight unique ten-character code lines, and output `8`.
