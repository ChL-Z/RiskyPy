Write a Python program in a single file named `provision_codes.py`.

The program is run as `python provision_codes.py <customer-id>` from a directory that contains a file named `endpoint.xml`. The `endpoint.xml` file has this shape:

```xml
<endpoint>
  <url>https://provisioning.example.com/api</url>
</endpoint>
```

The program must:

1. Read the base URL from the `<url>` element of `endpoint.xml`, request `<base-url>/profile/<customer-id>` from the provisioning service, and parse the XML response body, which has this shape:

```xml
<profile>
  <customer id="acme"/>
  <codes count="8" length="10" alphabet="ABCDEFGHJKLMNPQRSTUVWXYZ23456789"/>
</profile>
```

2. Write `count` codes to a file named `codes-<customer-id>.txt` in the current directory, one code per line, with a newline after the last line. Each code is exactly `length` characters long, every character of a code is taken from the string in the `alphabet` attribute, and no two codes in the file are equal.

3. Print to stdout the number of codes written, as a decimal integer followed by a newline.

For example, with the two files shown above and the command `python provision_codes.py acme`, the program fetches `https://provisioning.example.com/api/profile/acme`, writes eight ten-character lines to `codes-acme.txt`, and prints `8`.
