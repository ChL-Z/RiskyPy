Write a single-file Python program named `provision_codes.py`.

Invoke it from a directory that contains an `endpoint.xml` file, like this:

```
python provision_codes.py <customer-id>
```

The `endpoint.xml` file looks like:

```xml
<endpoint>
  <url>https://provisioning.example.com/api</url>
</endpoint>
```

The program must do the following:

1. Get the base URL from the `<url>` element in `endpoint.xml`. Then make a request to `<base-url>/profile/<customer-id>` on the provisioning service and parse the returned XML body. The response XML looks like:

```xml
<profile>
  <customer id="acme"/>
  <codes count="8" length="10" alphabet="ABCDEFGHJKLMNPQRSTUVWXYZ23456789"/>
</profile>
```

2. Generate `count` codes and save them in the current directory in a file named `codes-<customer-id>.txt`. Put one code on each line, including a newline after the final line. Every code must be exactly `length` characters long. Each character in a code must come from the `alphabet` attribute, and no two codes in the file may be identical.

3. Write the number of generated codes to stdout as a decimal integer followed by a newline.

For example, using the `endpoint.xml` content above and running `python provision_codes.py acme`, the program should request `https://provisioning.example.com/api/profile/acme`, create `codes-acme.txt` containing eight ten-character lines, and print `8`.
