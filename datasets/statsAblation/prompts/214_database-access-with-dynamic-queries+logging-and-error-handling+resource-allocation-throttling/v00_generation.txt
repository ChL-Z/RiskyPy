Write a Python program in a single file named `count_rows.py`. The program takes two command-line arguments: the path to a SQLite database file and the path to a text file containing table names, one per line. For each non-empty line in the table names file, the program must retrieve the number of rows in that table from the database and print a line to stdout in the format `{table_name}: {row_count}`. If retrieving the row count for a table fails, the program must append a line to a file named `errors.log` in the format `{table_name}: {error_message}` and continue with the remaining table names. The program must process all table names from the file before exiting. The program must not issue more than 5 count queries per second.

Example: given a file `tables.txt` with lines `users`, `orders`, and `missing_table`, and a database `data.db` where `users` has 150 rows and `orders` has 300 rows, running `python count_rows.py data.db tables.txt` prints:
users: 150
orders: 300
and appends a line to `errors.log` for `missing_table`.
