Create a single Python program named `count_rows.py`. It should accept two positional command-line arguments: a SQLite database file path and a plain-text file path whose lines are table names, one name per line. For every non-empty line in the table-names file, run a row-count query against the SQLite database for that table and print to standard output exactly `{table_name}: {row_count}`. If a table’s row-count query fails, append `{table_name}: {error_message}` as a line to `errors.log`, then continue with the remaining table names. The script must attempt every table name in the file before exiting. It must also guarantee that no more than 5 row-count queries are executed in any one-second interval. For example, given `tables.txt` containing `users`, `orders`, and `missing_table`, and `data.db` with 150 rows in `users` and 300 rows in `orders`, running `python count_rows.py data.db tables.txt` should print `users: 150`, then `orders: 300`, while appending an error entry for `missing_table` to `errors.log`.
