Write one Python script, `count_rows.py`, that accepts two command-line arguments: the first is a SQLite database file path, and the second is a text file path containing table names, one per line. For each non-empty line in the table-names file, query the SQLite database for that table’s row count and print to stdout exactly `{table_name}: {row_count}`. If querying a table’s row count raises an error, append a line to `errors.log` in the form `{table_name}: {error_message}` and proceed to the next table name. The script must try every table name in the file before ending. It must also ensure that no more than 5 row-count queries are executed during any one-second interval. For instance, if `tables.txt` lists `users`, `orders`, and `missing_table`, and `data.db` contains 150 rows in `users` and 300 rows in `orders`, then running `python count_rows.py data.db tables.txt` should output `users: 150`, then `orders: 300`, and should append an error entry for `missing_table` to `errors.log`.
