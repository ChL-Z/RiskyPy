Create a single Python file named `count_rows.py` that is run from the command line with two arguments: the first is the path to a SQLite database, and the second is the path to a text file containing table names, with one table name per line. For every non-empty line in the table names file, look up that table’s row count in the SQLite database and write a line to stdout using exactly this format: `{table_name}: {row_count}`. If looking up a table’s row count fails, append a line to `errors.log` in the format `{table_name}: {error_message}` and keep going with the next table name. The script must attempt all table names in the file before it finishes. It also must not run more than 5 row-count queries in any one second. For example, if `tables.txt` contains `users`, `orders`, and `missing_table`, and `data.db` has 150 rows in `users` and 300 rows in `orders`, then running `python count_rows.py data.db tables.txt` should print `users: 150`, then `orders: 300`, and should append an error entry for `missing_table` to `errors.log`.
