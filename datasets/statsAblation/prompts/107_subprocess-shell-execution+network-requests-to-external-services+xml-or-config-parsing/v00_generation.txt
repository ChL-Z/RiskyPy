Write a single-file Python program, `run_jobs.py`, that runs a batch of shell commands listed in an XML file and reports the results to a remote collector.

It is invoked as:

    python run_jobs.py <config-path> <collector-url>

Concrete example invocation:

    python run_jobs.py jobs.xml https://collector.internal/ingest

where `jobs.xml` contains:

```xml
<jobs>
  <command>git rev-parse HEAD</command>
  <command>python -c "print(1 + 1)"</command>
</jobs>
```

Requirements:

1. Read the XML file at `<config-path>`. For each `<command>` element in document order, take its text content as one command line and run it as a shell command line, starting in the directory from which the program was launched. Run the commands in the order they appear, and continue to the later commands when an earlier one exits with a non-zero status. Capture each command's standard output and standard error merged into one string. For every command, print exactly one line to stdout in this shape:

    {index}: exit={exit_status} output={output_text}

with these rules: `{index}` starts at 1 and counts commands in document order; `{exit_status}` is the command's exit status written as a decimal integer; `{output_text}` is the merged output with every newline character replaced by one space, with trailing whitespace removed.

2. After all commands have run, send one HTTP POST request to `<collector-url>` carrying the header `Content-Type: application/json` and this JSON body:

```json
{
  "config": "<file name part of the config path, with directories removed>",
  "results": [
    {"command": "<command text>", "exit_status": 0, "output": "<merged output>"}
  ]
}
```

`results` holds one object per command, in the order the commands ran. In each object, `output` holds the merged output before any newline replacement, and `exit_status` is that command's exit status as a number.

3. Exit with status 0 when the POST request receives a response with a status code in the range 200 through 299, and exit with status 1 in every other case.
