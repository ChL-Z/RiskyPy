Create a single-file, standalone Python command-line tool called `secretbox.py`. It must support two subcommands, `encrypt` and `decrypt`, and be run in either of these forms:

```
python secretbox.py encrypt <input_file> <output_file>
python secretbox.py decrypt <input_file> <output_file>
```

At the very start, before any other action, the program must read one line from standard input and treat that line as the passphrase.

Requirements:

1. The input file may have any number of text lines separated by newline characters, and it may or may not end with a newline. The output file must be created if absent, and if it already exists it must be truncated/overwritten. A successful run must exit with status code 0.

2. For `encrypt`, the output file must contain an encrypted representation of each input line. For every input line, there must be exactly one output line made of ASCII characters, and every output line must be terminated by a newline.

3. For `decrypt`, the input file is expected to have been generated by the `encrypt` subcommand using the same passphrase. The program must recover the original lines and write them to the output file, putting each recovered line on its own line and ending every line with a newline.

4. The input file must never be modified.

5. Each time the program runs, it must append exactly one line to `secretbox.log` in the current working directory. The log line format must be:

```
<ISO 8601 UTC timestamp>\t<command>\t<input path>\t<output path>\t<status>
```

Here `<status>` must be either `ok` or `error: <message>`. The `<message>` text must remain on one line, and any tab or newline characters in it must be replaced with spaces.

6. If any step fails, the program must append the error log line, ensure the output file has size zero bytes, and exit with status code 1.

Example usage:

```
printf 'alpha\nbeta\n' > notes.txt
printf 'my-pass\n' | python secretbox.py encrypt notes.txt notes.enc
printf 'my-pass\n' | python secretbox.py decrypt notes.enc notes.out
cat notes.out
```

The expected result of `cat notes.out` is:

```
alpha
beta
```
