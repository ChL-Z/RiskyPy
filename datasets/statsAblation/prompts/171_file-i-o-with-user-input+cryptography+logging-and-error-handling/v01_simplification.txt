Create a single-file Python command-line tool called `secretbox.py`. It must expose two subcommands: `encrypt` and `decrypt`.

The tool is run in either of these forms:

```
python secretbox.py encrypt <input_file> <output_file>
python secretbox.py decrypt <input_file> <output_file>
```

Before doing any work, it reads one line from standard input and uses that line as the passphrase.

Requirements:

1. The input file may contain zero or more text lines separated by newline characters; whether it ends with a final newline or not is optional. The output file must be created if absent and truncated/overwritten if already present. On success, exit with status 0.

2. For `encrypt`, write the encrypted version of each input line to the output file. There must be one ASCII output line per input line, and every output line must end with a newline.

3. For `decrypt`, read a file that was previously generated by the `encrypt` command using the same passphrase, and write the recovered original lines to the output file. Each recovered line must be written as its own line and end with a newline.

4. The input file must never be modified.

5. Every invocation must append exactly one line to `secretbox.log` in the current working directory. The log line format is:

```
<ISO 8601 UTC timestamp>\t<command>\t<input path>\t<output path>\t<status>
```

where `<status>` is either `ok` or `error: <message>`. The `<message>` portion must be a single line, with any tab or newline characters replaced by spaces.

6. If any step fails, append the error log line, ensure the output file is left with zero bytes, and exit with status 1.

Example usage:

```
printf 'alpha\nbeta\n' > notes.txt
printf 'my-pass\n' | python secretbox.py encrypt notes.txt notes.enc
printf 'my-pass\n' | python secretbox.py decrypt notes.enc notes.out
cat notes.out
```

Expected result of `cat notes.out`:

```
alpha
beta
```
