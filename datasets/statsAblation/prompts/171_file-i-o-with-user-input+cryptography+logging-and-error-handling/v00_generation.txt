Write a Python program in a single file named `secretbox.py`. It provides a command-line utility with two commands: `encrypt` and `decrypt`.

1. The program is invoked as `python secretbox.py encrypt <input_file> <output_file>` or `python secretbox.py decrypt <input_file> <output_file>`. Before processing, it reads one line from stdin as the passphrase. The input file contains zero or more text lines separated by newline characters; a final newline is optional. The output file is created if it does not exist and overwritten if it does. On success, the exit status is 0.

2. For `encrypt`, write to the output file one ASCII line for each input line. Each output line is the encrypted form of the corresponding input line using the passphrase, and each output line ends with a newline. For `decrypt`, read a file previously produced by the `encrypt` command with the same passphrase and write the original lines to the output file, one per line, with each line ending in a newline. The input file is not modified.

3. For every invocation, append one line to `secretbox.log` in the current working directory. The log line starts with an ISO 8601 UTC timestamp, followed by a tab, then the command name, a tab, the input path, a tab, the output path, a tab, and either `ok` or `error: <message>`. The `<message>` part is a single line with any tab or newline characters replaced by spaces. If any step fails, append the error line, leave the output file with zero bytes, and exit with status 1.

Usage example:

```
printf 'alpha\nbeta\n' > notes.txt
printf 'my-pass\n' | python secretbox.py encrypt notes.txt notes.enc
printf 'my-pass\n' | python secretbox.py decrypt notes.enc notes.out
cat notes.out
```

Expected output of `cat notes.out`:

```
alpha
beta
```
