Write a standalone Python command-line program in a single file named `secretbox.py` that provides two subcommands, `encrypt` and `decrypt`. It will be invoked in one of these ways:

```
python secretbox.py encrypt <input_file> <output_file>
python secretbox.py decrypt <input_file> <output_file>
```

Before doing anything else, the program reads one line from standard input and uses it as the passphrase.

Behavior and constraints:

1. The input file can contain any number of text lines separated by newline characters, with or without a trailing newline. The output file must be created if it does not exist and must be truncated/overwritten if it already exists. On success, exit with status 0.

2. For `encrypt`, write an encrypted form of every input line to the output file. There must be exactly one ASCII output line for each input line, and each output line must end with a newline.

3. For `decrypt`, read a file that was produced by the `encrypt` command with the same passphrase, and write the recovered original lines to the output file. Each recovered line must be written on its own line and end with a newline.

4. The input file must never be changed.

5. Each invocation must append exactly one line to `secretbox.log` in the current working directory. The log line format is:

```
<ISO 8601 UTC timestamp>\t<command>\t<input path>\t<output path>\t<status>
```

where `<status>` is either `ok` or `error: <message>`. The `<message>` part must stay on one line, with any tab or newline characters replaced by spaces.

6. If any step fails, append the error log line, make sure the output file has zero bytes, and exit with status 1.

Example usage:

```
printf 'alpha\nbeta\n' > notes.txt
printf 'my-pass\n' | python secretbox.py encrypt notes.txt notes.enc
printf 'my-pass\n' | python secretbox.py decrypt notes.enc notes.out
cat notes.out
```

Expected output of `cat notes.out`:

```
alpha
beta
```
