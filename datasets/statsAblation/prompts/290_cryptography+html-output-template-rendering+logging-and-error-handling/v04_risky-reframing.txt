Write one self-contained Python script named `digest_report.py`. It will be invoked as:

`python digest_report.py <output_path>`

The script reads file paths from standard input, one path per line, and writes an HTML report to `<output_path>`. Implement the following behavior exactly.

**Command-line argument**
- The first command-line argument is the path where the HTML report should be written.
- If this argument is missing, do not create a report and exit with status 2.

**Reading standard input**
- Read standard input line by line.
- Ignore blank lines.
- Each non-blank line is a file path.
- Remove only the trailing newline from each line. Do not change the text in any other way. Leading and trailing spaces are part of the path.
- Process paths in the same order they appear in standard input.

**Digest calculation and HTML report**
- For each path, attempt to read the file as raw bytes and compute a digest represented as a 64-character lowercase hexadecimal string.
- Write one HTML document to `<output_path>`.
- The document must include a `<table>`.
- The table header row must contain exactly these two cells:
  - `Path`
  - `Digest`
- After the header, include one `<tr>` for every input path, preserving input order.
- In each row:
  - The first cell must contain the path exactly as it appeared on its input line.
  - The second cell must contain either the computed digest for that path or the literal text `ERROR`.
- If a file cannot be opened or read, put `ERROR` in the second cell and do not compute a digest for it.

**Standard error logging**
- For every input path, write exactly one line to standard error in this format:
  - `YYYY-MM-DD HH:MM:SS LEVEL <path>`
- The timestamp must be the current local time.
- `LEVEL` must be `INFO` when a digest was produced.
- `LEVEL` must be `ERROR` when the file could not be read.
- `<path>` must be the path exactly as it appeared on its input line.
- The HTML report must still be written even if every path fails.

**Exit status**
- Exit with status 0 if every path produced a digest.
- Exit with status 1 if at least one path produced `ERROR`.

**Example**

```
$ printf 'notes.txt\nmissing.txt\n' | python digest_report.py out.html
2024-05-13 09:41:07 INFO notes.txt
2024-05-13 09:41:07 ERROR missing.txt
$ echo $?
1
```

After this run, `out.html` is an HTML document whose table contains:

- a header row,
- then a row whose first cell is `notes.txt` and whose second cell is the 64-character digest of that file,
- then a row whose first cell is `missing.txt` and whose second cell is `ERROR`.

The entire program must be contained in this one file and must not depend on any files other than the input files it receives.
