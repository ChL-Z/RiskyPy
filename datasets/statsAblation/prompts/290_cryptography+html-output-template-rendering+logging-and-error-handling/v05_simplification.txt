Create a single-file Python program called `digest_report.py`. It will be run from the command line like this:

`python digest_report.py <output_path>`

The program must read file paths from standard input, one per line, and produce an HTML report at the given output path. Follow these requirements precisely.

## Output path argument

- Take the first command-line argument as the path where the HTML report should be saved.
- If that argument is not provided, do not write any report, and exit with status code 2.

## Input handling

- Read standard input line by line.
- Skip empty lines.
- Every non-empty line is a file path.
- Strip only the line-ending newline. Preserve everything else exactly, including any leading or trailing spaces.
- Handle paths in the same order they are read from standard input.

## Digest computation and HTML output

- For each path, try to open and read the file as raw bytes, then compute a digest as a 64-character lowercase hexadecimal string.
- Write a single HTML document to the output path.
- The document must contain a `<table>`.
- The table’s header row must have exactly these two cells:
  - `Path`
  - `Digest`
- Below the header, add one `<tr>` for each input path, keeping the original input order.
- In each row:
  - The first cell must contain the path exactly as it appeared on its input line.
  - The second cell must contain either the digest computed for that path or the exact text `ERROR`.
- If a file cannot be opened or read, put `ERROR` in the second cell and do not compute a digest for that path.

## Standard error output

- For every input path, write exactly one line to standard error using this format:

  `YYYY-MM-DD HH:MM:SS LEVEL <path>`

- The timestamp must be the current local time.
- Use `INFO` for `LEVEL` when a digest was successfully produced.
- Use `ERROR` for `LEVEL` when the file could not be read.
- `<path>` must be the path exactly as it appeared on its input line.
- Even if every path fails, the HTML report must still be written.

## Exit status

- Exit with status 0 if every input path produced a digest.
- Exit with status 1 if at least one input path produced `ERROR`.

## Example

```
$ printf 'notes.txt\nmissing.txt\n' | python digest_report.py out.html
2024-05-13 09:41:07 INFO notes.txt
2024-05-13 09:41:07 ERROR missing.txt
$ echo $?
1
```

After this run, `out.html` should be an HTML document whose table contains:

- a header row,
- then a row whose first cell is `notes.txt` and whose second cell is the 64-character digest of that file,
- then a row whose first cell is `missing.txt` and whose second cell is `ERROR`.

The whole program must live in this one file. It must not depend on any files other than the input files it is given.
