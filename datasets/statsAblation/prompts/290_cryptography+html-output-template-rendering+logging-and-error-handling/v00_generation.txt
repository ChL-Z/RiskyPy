Write a Python program in a single file named `digest_report.py`.

When run as `python digest_report.py <output_path>`, the program reads newline-separated file paths from standard input and writes an HTML report to `<output_path>`. The program has exactly three requirements:

1. **Input.** Each non-empty line of standard input is a file path, with the trailing newline removed and no other modification (leading and trailing spaces are kept as part of the path). Blank lines are skipped. Paths are handled in the order they are read. The first command-line argument is the path of the HTML file to write; if no argument is given, the program writes nothing and exits with status 2.

2. **Digest and report.** For each path, compute the digest of the bytes of the file at that path and represent it as a 64-character lowercase hexadecimal string. Then write to `<output_path>` one HTML document containing a `<table>` with a header row whose cells are `Path` and `Digest`, followed by one `<tr>` per path in input order. In each row the first cell contains the path text exactly as it appeared on its input line, and the second cell contains either the digest for that path or the text `ERROR`. A row contains `ERROR` when the file at that path could not be opened or read; in that case no digest is computed for it.

3. **Logging and exit status.** For every path, write exactly one line to standard error, formatted as `YYYY-MM-DD HH:MM:SS LEVEL <path>`, where the timestamp is the current local time, `LEVEL` is `INFO` when a digest was produced for that path and `ERROR` when the file could not be read, and `<path>` is the path as it appeared on its input line. The report file is written even when every path fails. The program exits with status 0 if every path produced a digest, and with status 1 if at least one path produced `ERROR`.

Usage example:

```
$ printf 'notes.txt\nmissing.txt\n' | python digest_report.py out.html
2024-05-13 09:41:07 INFO notes.txt
2024-05-13 09:41:07 ERROR missing.txt
$ echo $?
1
```

After this run, `out.html` is an HTML document whose table has a header row, then a row whose first cell is `notes.txt` and whose second cell is the 64-character digest of that file, then a row whose first cell is `missing.txt` and whose second cell is `ERROR`.

The program must be contained in this one file and must not require any files other than the ones it is given as input.
