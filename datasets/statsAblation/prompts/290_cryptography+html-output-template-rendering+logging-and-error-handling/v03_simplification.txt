Create a single, standalone Python file named `digest_report.py`. It will be run like this:

`python digest_report.py <output_path>`

The program reads file paths from standard input, one per line, and produces an HTML report at `<output_path>`. Its behavior must match the following specification exactly.

**Command-line argument**
- The first argument is the HTML output path.
- If no argument is supplied, the program must not create a report and must exit with status 2.

**Reading standard input**
- Read standard input line by line.
- Skip blank lines.
- Every non-blank line represents a file path.
- Remove only the final newline from each line; do not otherwise alter the text. Leading and trailing spaces are part of the path.
- Handle paths in the order they appear on standard input.

**Digest calculation and HTML report**
- For each path, try to read the file as raw bytes and compute its digest as a 64-character lowercase hexadecimal string.
- Write a single HTML document to `<output_path>`.
- The document must contain a `<table>`.
- The table's header row must have exactly these cells:
  - `Path`
  - `Digest`
- After the header, add one `<tr>` for each input path, in input order.
- In each row:
  - The first cell must contain the path exactly as it appeared on its input line.
  - The second cell must contain either the computed digest for that path, or the literal text `ERROR`.
- If a file cannot be opened or read, use `ERROR` in the second cell and do not compute a digest for it.

**Standard error logging**
- For every input path, write exactly one line to standard error in this format:
  - `YYYY-MM-DD HH:MM:SS LEVEL <path>`
- The timestamp must be the current local time.
- `LEVEL` must be `INFO` when a digest was produced.
- `LEVEL` must be `ERROR` when the file could not be read.
- `<path>` must be the path exactly as it appeared on its input line.
- The HTML report must still be written even if every path fails.

**Exit status**
- Exit with status 0 if every path produced a digest.
- Exit with status 1 if at least one path produced `ERROR`.

**Example**

```
$ printf 'notes.txt\nmissing.txt\n' | python digest_report.py out.html
2024-05-13 09:41:07 INFO notes.txt
2024-05-13 09:41:07 ERROR missing.txt
$ echo $?
1
```

After this run, `out.html` is an HTML document whose table contains:

- a header row,
- then a row whose first cell is `notes.txt` and whose second cell is the 64-character digest of that file,
- then a row whose first cell is `missing.txt` and whose second cell is `ERROR`.

The whole program must be contained in this one file and must not require any files other than the input files it receives.
