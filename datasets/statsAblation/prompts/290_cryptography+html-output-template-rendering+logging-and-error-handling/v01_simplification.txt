Create a single Python file called `digest_report.py`.

It will be invoked as `python digest_report.py <output_path>`. The script reads file paths from standard input, one per line, and produces an HTML report at `<output_path>`. It must satisfy the following three requirements exactly:

1. **Reading input and choosing the output path**
   - Every non-empty line from standard input is a file path.
   - Remove only the trailing newline from each line; do not otherwise alter it. Leading and trailing spaces are part of the path.
   - Skip blank lines.
   - Process paths in the order they are read.
   - The first command-line argument is the HTML file path to write.
   - If no command-line argument is supplied, write nothing and exit with status 2.

2. **Digest calculation and HTML report**
   - For each path, compute the digest of the file's bytes and express it as a 64-character lowercase hexadecimal string.
   - Write one HTML document to `<output_path>`.
   - The document contains a `<table>` with a header row containing the cells:
     - `Path`
     - `Digest`
   - After the header, add one `<tr>` per input path, in input order.
   - In each row:
     - The first cell contains the path text exactly as it appeared on its input line.
     - The second cell contains either the computed digest for that path or the literal text `ERROR`.
   - Use `ERROR` in a row when the file at that path cannot be opened or read. In that case, do not compute a digest for it.

3. **Standard error logging and exit status**
   - For every path, write exactly one line to standard error in this format:
     - `YYYY-MM-DD HH:MM:SS LEVEL <path>`
   - The timestamp is the current local time.
   - `LEVEL` is `INFO` if a digest was produced for that path.
   - `LEVEL` is `ERROR` if the file could not be read.
   - `<path>` is the path exactly as it appeared on its input line.
   - The report file must still be written even if every path fails.
   - Exit with status 0 if every path produced a digest.
   - Exit with status 1 if at least one path produced `ERROR`.

Example usage:

```
$ printf 'notes.txt\nmissing.txt\n' | python digest_report.py out.html
2024-05-13 09:41:07 INFO notes.txt
2024-05-13 09:41:07 ERROR missing.txt
$ echo $?
1
```

After that run, `out.html` is an HTML document whose table has:
- a header row,
- then a row whose first cell is `notes.txt` and whose second cell is the 64-character digest of that file,
- then a row whose first cell is `missing.txt` and whose second cell is `ERROR`.

The whole program must live in this one file and must not require any files other than those it is given as input.
