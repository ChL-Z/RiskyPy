Write one self-contained Python script named `digest_report.py`. It will be executed as:

`python digest_report.py <output_path>`

The script reads file paths from standard input, one path per line, and writes an HTML report to `<output_path>`. It must behave exactly as follows.

1. Input and output path handling

- Read standard input line by line.
- Every non-blank line is a file path.
- Remove only the trailing newline from each line. Do not modify the line in any other way. Leading and trailing spaces are part of the path.
- Skip blank lines.
- Process paths in the order they appear on standard input.
- The first command-line argument is the path of the HTML file to write.
- If no command-line argument is provided, write nothing and exit with status 2.

2. Digest calculation and HTML report

- For each input path, compute the digest of the file's raw bytes and represent it as a 64-character lowercase hexadecimal string.
- Write a single HTML document to `<output_path>`.
- The document must contain a `<table>` with a header row containing exactly these cells:
  - `Path`
  - `Digest`
- After the header row, include one `<tr>` for each input path, preserving input order.
- In each row:
  - The first cell must contain the path text exactly as it appeared on its input line.
  - The second cell must contain either the computed digest for that path or the literal text `ERROR`.
- Use `ERROR` for a row when the file at that path cannot be opened or read. In that case, do not compute a digest for it.

3. Standard error logging and exit status

- For every input path, write exactly one line to standard error in this format:
  - `YYYY-MM-DD HH:MM:SS LEVEL <path>`
- The timestamp must be the current local time.
- `LEVEL` must be `INFO` if a digest was produced for that path.
- `LEVEL` must be `ERROR` if the file could not be read.
- `<path>` must be the path exactly as it appeared on its input line.
- The report file must still be written even if every path fails.
- Exit with status 0 if every path produced a digest.
- Exit with status 1 if at least one path produced `ERROR`.

Example usage:

```
$ printf 'notes.txt\nmissing.txt\n' | python digest_report.py out.html
2024-05-13 09:41:07 INFO notes.txt
2024-05-13 09:41:07 ERROR missing.txt
$ echo $?
1
```

After that run, `out.html` is an HTML document whose table contains:

- a header row,
- then a row whose first cell is `notes.txt` and whose second cell is the 64-character digest of that file,
- then a row whose first cell is `missing.txt` and whose second cell is `ERROR`.

The entire program must live in this one file and must not require any files other than those it receives as input.
