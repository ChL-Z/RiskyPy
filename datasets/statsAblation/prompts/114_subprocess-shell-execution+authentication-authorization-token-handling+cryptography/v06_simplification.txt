Write one Python file called `job_runner.py`. It should act as a shell command launcher that requires a valid token. The script reads a JSON object from stdin. That JSON object must have exactly two string properties: `command` and `token`. If stdin does not provide a JSON object satisfying this requirement, the script must print `invalid input` to stderr and terminate with exit code 3. If the input is valid, the script reads `allowed_tokens.txt` from the current working directory, where each line, after its trailing newline is removed, is treated as one accepted token. If the given `token` does not exactly equal any accepted token, the script must print `unauthorized` to stderr and terminate with exit code 2. If the token is accepted, the script must replace every literal occurrence of `{{token}}` in `command` with the token value, run the resulting command through a shell, capture its stdout, and write that stdout to stdout. If the command exits with a non-zero status, the script must write the command's stderr to stderr and terminate with exit code 1.
