Create a single Python program named `job_runner.py` that implements a token-gated shell command executor. The program should: read a JSON object from standard input; this object must contain exactly the members `command` and `token`, and both values must be strings. If standard input does not contain such a JSON object, write `invalid input` to stderr and terminate with exit code 3. Otherwise, read `allowed_tokens.txt` from the current working directory, where every line after stripping its trailing newline is considered an allowed token. If the provided `token` is not exactly equal to at least one allowed line, write `unauthorized` to stderr and terminate with exit code 2. If the token is allowed, replace every literal occurrence of `{{token}}` in `command` with the token value, run the resulting command through a shell, capture its stdout, and write that stdout to stdout. If the command exits with a non-zero status, write its stderr to stderr and terminate with exit code 1.
