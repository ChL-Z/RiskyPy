Create a single Python script named `job_runner.py` that functions as a token-authorized shell command launcher with the following behavior. It should read a JSON object from stdin. The JSON object must contain exactly two string fields: `command` and `token`. If stdin does not supply a JSON object that meets this condition, print `invalid input` to stderr and exit with status 3. If the input is valid, read `allowed_tokens.txt` from the current working directory, treating each line with its trailing newline removed as one accepted token. If the provided `token` does not precisely match any accepted line, print `unauthorized` to stderr and exit with status 2. If the token is accepted, replace every literal occurrence of `{{token}}` inside `command` with the token value, execute the modified command through a shell, capture its stdout, and write that stdout to stdout. If the command exits with a non-zero status, write its stderr to stderr and exit with status 1.
