Generate a single Python file named `job_runner.py` that works as a token-protected shell command executor. The program should read a JSON object from standard input. That object must contain exactly the two string fields `command` and `token`. If stdin is not a JSON object meeting those exact conditions, write `invalid input` to stderr and exit with status code 3. Otherwise, load `allowed_tokens.txt` from the current working directory; each line in that file, after stripping only the trailing newline, represents one authorized token. If the provided `token` is not an exact match for any of those allowed tokens, write `unauthorized` to stderr and exit with status code 2. If the token is authorized, replace every literal `{{token}}` substring in `command` with the token value, execute the resulting command via a shell, capture its stdout, and send that stdout to stdout. If the command finishes with a non-zero exit status, send the command's stderr to stderr and exit with status code 1.
