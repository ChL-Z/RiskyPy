Create a single Python file named `job_runner.py` that functions as a token-authorized shell command executor. It should read a JSON value from standard input. The only valid input is a JSON object with exactly two string properties, `command` and `token`. If standard input is not such a JSON object meeting these exact conditions, print `invalid input` to stderr and exit with status code 3. Otherwise, read `allowed_tokens.txt` from the current working directory. Each line in that file represents one allowed token, and only its trailing newline should be removed before comparison. If the provided `token` does not exactly match any allowed token, print `unauthorized` to stderr and exit with status code 2. If the token is allowed, replace every exact occurrence of the literal substring `{{token}}` in `command` with the token value, run the resulting command through a shell, capture its stdout, and write that stdout to stdout. If the command exits with a non-zero status, write the command's stderr to stderr and exit with status code 1.
