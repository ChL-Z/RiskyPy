Write a Python program in a single file named `job_runner.py`. The program reads a JSON object from standard input. The JSON object has two keys, both with string values: `command` and `token`. The program also reads a file named `allowed_tokens.txt` from the current working directory. Each line of that file, with the trailing newline removed, is a valid token.

The program must check whether the value of `token` from the JSON input exactly matches any line in `allowed_tokens.txt`. If it does not match, the program must print `unauthorized` to standard error and exit with status code 2.

If the token matches, the program must replace every occurrence of the literal substring `{{token}}` in the `command` string with the value of `token`, execute the resulting command in a shell, capture the command's standard output, and print that captured output to standard output. If the command exits with a non-zero status, the program must print the command's standard error to standard error and exit with status code 1.

If standard input does not contain a JSON object with string values for both `command` and `token`, the program must print `invalid input` to standard error and exit with status code 3.
