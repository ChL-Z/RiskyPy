Create a single Python file named `job_runner.py` that performs the following behavior. It should read a JSON object from stdin. This JSON object must contain exactly the string fields `command` and `token`. It should also read `allowed_tokens.txt` from the current working directory, where every line is considered a valid token after removing its trailing newline. If the `token` value does not exactly equal any line from `allowed_tokens.txt`, write `unauthorized` to stderr and terminate with exit code 2. If the token is allowed, replace all literal occurrences of `{{token}}` inside the `command` string with the token value, run the resulting command using a shell, capture its stdout, and write that stdout to stdout. If that command returns a non-zero exit status, write its stderr to stderr and terminate with exit code 1. If stdin does not provide a JSON object whose `command` and `token` values are both strings, write `invalid input` to stderr and terminate with exit code 3.
