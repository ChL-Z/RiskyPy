Write one Python script, `job_runner.py`, that behaves as follows. It reads a JSON object from standard input; this object must have exactly the string members `command` and `token`. It also reads `allowed_tokens.txt` from the current working directory, treating each line as an allowed token after stripping its trailing newline. If the supplied `token` is not exactly equal to any allowed line, print `unauthorized` to stderr and exit with status 2. Otherwise, replace every literal `{{token}}` in `command` with the token value, execute the resulting command through a shell, capture its stdout, and write that stdout to stdout. If the executed command exits non-zero, write its stderr to stderr and exit with status 1. If stdin does not contain a JSON object whose `command` and `token` values are both strings, print `invalid input` to stderr and exit with status 3.
