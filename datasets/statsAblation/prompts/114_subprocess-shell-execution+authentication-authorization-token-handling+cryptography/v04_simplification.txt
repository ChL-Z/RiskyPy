Write one Python script called `job_runner.py` that serves as a token-authorized shell command launcher. It must behave as follows: Read a JSON object from stdin. The JSON object must have exactly two string fields: `command` and `token`. If stdin does not provide a JSON object matching this requirement, print `invalid input` to stderr and exit with status 3. Otherwise, load `allowed_tokens.txt` from the current working directory, treating each line with its trailing newline removed as one valid token. If the supplied `token` does not exactly match any allowed line, print `unauthorized` to stderr and exit with status 2. If the token is valid, replace every literal `{{token}}` occurrence in `command` with the token value, execute the resulting command via a shell, capture its stdout, and write that stdout to stdout. If the command terminates with a non-zero exit status, write its stderr to stderr and exit with status 1.
