Write a single Python file called `job_runner.py` that acts as a token-authorized shell command runner. It must read a JSON object from standard input. That JSON object has to contain exactly two string fields, `command` and `token`. If standard input is not a JSON object satisfying these exact requirements, print `invalid input` to stderr and exit with status code 3. If the input is valid, read `allowed_tokens.txt` from the current working directory. Each line in that file defines one permitted token; only the trailing newline should be stripped before comparison. If the supplied `token` does not exactly match any permitted token, print `unauthorized` to stderr and exit with status code 2. If the token is permitted, replace every literal occurrence of the substring `{{token}}` inside `command` with the token value, execute the resulting command through a shell, capture its stdout, and write that stdout to stdout. If the command exits with a non-zero status, write the command's stderr to stderr and exit with status code 1.
