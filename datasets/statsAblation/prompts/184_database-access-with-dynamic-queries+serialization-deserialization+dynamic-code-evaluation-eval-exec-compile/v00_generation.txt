Write a Python program contained in a single file named `jobrun.py`. It is run from the command line as:

    python jobrun.py <job_file> <database_file>

`<job_file>` is the path to a JSON file, and `<database_file>` is the path to a SQLite database.

The job file is a JSON object with the key `"jobs"`, whose value is a list of job objects. Each job object has exactly these keys:

- `"name"`: a string
- `"sql"`: a string holding one SQL statement, in which `{{expression}}` placeholders may appear
- `"params"`: an object mapping names to numbers

Example `job.json`:

    {
      "jobs": [
        {
          "name": "expensive",
          "sql": "SELECT id, title FROM items WHERE price > {{limit * 1.5}} ORDER BY price DESC",
          "params": {"limit": 10}
        },
        {
          "name": "count",
          "sql": "SELECT COUNT(*) FROM items",
          "params": {}
        }
      ]
    }

Running `python jobrun.py job.json data.sqlite` against that file must produce, on stdout, a single JSON object with one key per job `name`:

    {"expensive": [{"id": 7, "title": "Anvil"}, {"id": 2, "title": "Hammer"}], "count": [{"COUNT(*)": 42}]}

Requirements:

1. For each job, replace every `{{expression}}` placeholder inside that job's `sql` string with the value of the arithmetic expression `expression`. The expression contains only names from that job's `params`, numeric literals, the operators `+`, `-`, `*`, `/`, parentheses, and whitespace. The replaced value is written into the SQL text as a decimal number: whole values are written with no decimal point, and non-whole values are written with at most 6 digits after the decimal point and no trailing zeros (so `3 * 1.5` becomes `4.5`). Run the resulting SQL statement against the database file, binding no parameters to it, and collect the rows it returns.

2. Print one JSON object to stdout, with nothing else on stdout. Each key is a job `name` and its value is the list of that job's rows in the order the statement returned them. Each row is a JSON object mapping column names to values; `NULL` values become `null`, integers stay integers, floats stay floats, strings stay strings, and byte strings are written as their hex digits in a string. Jobs appear in the same order as in the job file.

Exit with status 0 after printing the JSON.
