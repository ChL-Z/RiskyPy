Create a single-file Python script named `jobrun.py` that is executed from the command line like this:

    python jobrun.py <job_file> <database_file>

Here, `<job_file>` is a JSON file path and `<database_file>` is a SQLite database path.

The JSON file must contain an object with a `"jobs"` key. Its value is a list of job objects. Every job object has exactly these keys:

- `"name"`: a string
- `"sql"`: a string containing one SQL statement, possibly including `{{expression}}` placeholders
- `"params"`: an object whose keys map to numeric values

Example job file `job.json`:

    {
      "jobs": [
        {
          "name": "expensive",
          "sql": "SELECT id, title FROM items WHERE price > {{limit * 1.5}} ORDER BY price DESC",
          "params": {"limit": 10}
        },
        {
          "name": "count",
          "sql": "SELECT COUNT(*) FROM items",
          "params": {}
        }
      ]
    }

If you run `python jobrun.py job.json data.sqlite` with that file, stdout must contain exactly one JSON object with one key per job `name`:

    {"expensive": [{"id": 7, "title": "Anvil"}, {"id": 2, "title": "Hammer"}], "count": [{"COUNT(*)": 42}]}

Requirements:

1. For each job, replace every `{{expression}}` occurrence in that job's `sql` string with the value of the arithmetic expression `expression`. The expression may contain only names from that job's `params`, numeric literals, the operators `+`, `-`, `*`, `/`, parentheses, and whitespace. Insert the computed value into the SQL text as a decimal number. Whole numbers must have no decimal point. Non-whole numbers must be written with at most 6 digits after the decimal point, with trailing zeros removed, so `3 * 1.5` becomes `4.5`. Then execute the resulting SQL statement against the database file without binding any parameters, and collect the returned rows.

2. Print exactly one JSON object to stdout, and print nothing else to stdout. Each key is a job `name`; its value is the list of rows returned by that job's statement, in the order the statement returned them. Each row is a JSON object mapping column names to values. `NULL` values become `null`, integers remain integers, floats remain floats, strings remain strings, and byte strings are represented as a string containing their hex digits. Jobs must appear in the same order as in the job file.

After printing the JSON, exit with status 0.
