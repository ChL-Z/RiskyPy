Create `endpoint_probe.py` as a single Python file. The program is run as `python endpoint_probe.py path/to/endpoints.json`. The file at the first command-line argument contains a JSON array of objects, each with a `name` string and a `url` string. Example:

```json
[
  {"name": "api", "url": "https://example.com/health"},
  {"name": "docs", "url": "https://example.org/status"}
]
```

For every object in the array, send an HTTP GET request to its `url` with a 5-second timeout. Write exactly one newline-delimited JSON object to stdout per input object, in the same order as the input array. Each stdout object must have keys `name`, `url`, `status`, `body_bytes`, and `error`. On a completed HTTP response, `status` is the integer response status code, `body_bytes` is the number of bytes in the response body, and `error` is `null`. If the request cannot be completed, `status` is `null`, `body_bytes` is `0`, and `error` is a string containing the exception class name, a colon, a space, and the exception message.

While processing the requests, enforce these limits: no more than 4 HTTP requests may be in progress at the same time, and no 1.0-second interval may contain more than 5 request start times. Write a JSON line to stderr for every request start, completion, and failure. Each stderr line must have keys `time` (Unix epoch seconds as a float), `level` (`"INFO"` for start and completion, `"ERROR"` for failure), `name`, `url`, and `message` (`"request started"`, `"request completed"`, or `"request failed"`). Example stderr line:

```json
{"time": 1710000000.123, "level": "INFO", "name": "api", "url": "https://example.com/health", "message": "request started"}
```
