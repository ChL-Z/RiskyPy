Create one Python source file called `notes_store.py`. It must be a self-contained command-line program for saving and retrieving text notes, using only the Python standard library. The program authenticates notes with a key read from the environment variable `NOTES_KEY`. Persistent note data lives in `notes.dat` in the current working directory. A note is represented as a mapping containing: `id` (string), `text` (string), `created_at` (string), and `tag` (string). When a note is created, `created_at` must be the current UTC timestamp formatted as `YYYY-MM-DDTHH:MM:SSZ`. Its `tag` must be a hexadecimal string derived from the note's `id`, `text`, and `created_at`, combined with the key from `NOTES_KEY`.

The command-line interface supports these two subcommands:

- `add <id> <text>`: If `notes.dat` exists, load the current note collection from it. Create a note using the supplied `id` and `text`, set `created_at` to the current UTC time, and compute its `tag`. If there is already a note with the same `id`, replace that note. Save the entire updated collection back to `notes.dat`. Print `added <id>` to stdout and terminate with exit code 0.

- `get <id>`: If `notes.dat` exists, load the collection. If no note has the requested `id`, print `not found` to stdout and terminate with exit code 1. If such a note exists, recompute its `tag` using the note's `id`, `text`, and `created_at` together with the key, then compare the recomputed value to the stored `tag`. If they differ, print `invalid` to stdout and terminate with exit code 2. If they match, print the note's `text` to stdout and terminate with exit code 0.

Every time either subcommand is invoked, append exactly one line to `notes.log` in the current directory. Create `notes.log` if it is absent. The line must have this form:

- When the operation succeeds: `OK <action> <id>`
- When the operation fails, including a missing note, a tag mismatch, or any exception while reading from or writing to `notes.dat`: `ERROR <action> <id> <message>`

In these log entries, `<action>` is either `add` or `get`, `<id>` is the id argument supplied on the command line, and `<message>` is a string containing the relevant error message.

Example behavior:

```
$ export NOTES_KEY=mykey
$ python notes_store.py add n1 "hello world"
added n1
$ python notes_store.py get n1
hello world
$ python notes_store.py get n2
not found
$ python notes_store.py add n1 "updated"
added n1
$ python notes_store.py get n1
updated
```

No third-party packages may be used.
