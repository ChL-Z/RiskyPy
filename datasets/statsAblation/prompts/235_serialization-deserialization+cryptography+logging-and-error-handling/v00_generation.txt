Write a single Python file named `notes_store.py` that implements a command-line tool for storing text notes. The tool reads a key from the environment variable `NOTES_KEY`. It uses the file `notes.dat` in the current directory to hold a collection of notes. Each note is a mapping with keys `id` (string), `text` (string), `created_at` (string), and `tag` (string). The `created_at` value is the current UTC time in the format `YYYY-MM-DDTHH:MM:SSZ`. The `tag` value is a hexadecimal string computed from the note's `id`, `text`, and `created_at` together with the key.

The tool supports two subcommands:

- `add <id> <text>`: Read the existing collection from `notes.dat` if the file exists. Add a new note with the given `id` and `text`, and the current UTC time for `created_at`. If a note with the same `id` already exists, replace it with the new note. Write the whole collection back to `notes.dat`. Print `added <id>` to stdout and exit with status 0.
- `get <id>`: Read the collection from `notes.dat` if it exists. If no note with the given `id` exists, print `not found` to stdout and exit with status 1. Otherwise, recompute the `tag` value for the note using the key and compare it with the stored `tag`. If they do not match, print `invalid` to stdout and exit with status 2. If they match, print the note's `text` to stdout and exit with status 0.

For every invocation of `add` or `get`, append one line to `notes.log` in the current directory. The line format is:
- On success: `OK <action> <id>`
- On any failure (missing note, tag mismatch, or an exception while reading or writing `notes.dat`): `ERROR <action> <id> <message>`
where `<action>` is either `add` or `get`, `<id>` is the id argument, and `<message>` is a string containing the error message. The log file is created if it does not exist.

Example usage:

```
$ export NOTES_KEY=mykey
$ python notes_store.py add n1 "hello world"
added n1
$ python notes_store.py get n1
hello world
$ python notes_store.py get n2
not found
$ python notes_store.py add n1 "updated"
added n1
$ python notes_store.py get n1
updated
```

The tool must not use any third-party packages.
