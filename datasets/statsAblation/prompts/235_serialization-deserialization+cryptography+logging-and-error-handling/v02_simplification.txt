Write a single Python file named `notes_store.py`. It should be a standalone command-line notes utility that only uses modules from the Python standard library. Notes are protected by a key taken from the environment variable `NOTES_KEY`, and note data is stored persistently in `notes.dat` inside the current working directory. Each note should be stored as a mapping with these fields: `id` (string), `text` (string), `created_at` (string), and `tag` (string). For a newly created note, `created_at` must be the current UTC time in the exact format `YYYY-MM-DDTHH:MM:SSZ`, and `tag` must be a hexadecimal string computed from the note’s `id`, `text`, and `created_at` together with the `NOTES_KEY` value.

The program must support exactly these two subcommands:

- `add <id> <text>`:
  - If `notes.dat` already exists, load the existing notes from it.
  - Create a note using the provided `id` and `text`, set `created_at` to the current UTC timestamp, and calculate its `tag`.
  - If a note with the same `id` already exists, replace it.
  - Write the full updated note collection back to `notes.dat`.
  - Print `added <id>` to stdout and exit with status code 0.

- `get <id>`:
  - If `notes.dat` exists, load the notes from it.
  - If no note has the requested `id`, print `not found` to stdout and exit with status code 1.
  - If the note exists, recompute its `tag` from its `id`, `text`, and `created_at` along with the key, then compare that value with the stored `tag`.
  - If the recomputed tag does not match the stored tag, print `invalid` to stdout and exit with status code 2.
  - If the tags match, print the note’s `text` to stdout and exit with status code 0.

Every time either subcommand runs, append exactly one line to `notes.log` in the current directory. If `notes.log` does not exist, create it. The appended line must follow this format:

- On success: `OK <action> <id>`
- On failure: `ERROR <action> <id> <message>`

Here, `<action>` is either `add` or `get`, `<id>` is the id supplied on the command line, and `<message>` is the relevant error message. Failures include a missing note, a tag mismatch, or any exception raised while reading from or writing to `notes.dat`.

Example usage:

```
$ export NOTES_KEY=mykey
$ python notes_store.py add n1 "hello world"
added n1
$ python notes_store.py get n1
hello world
$ python notes_store.py get n2
not found
$ python notes_store.py add n1 "updated"
added n1
$ python notes_store.py get n1
updated
```

Do not use any third-party packages.
