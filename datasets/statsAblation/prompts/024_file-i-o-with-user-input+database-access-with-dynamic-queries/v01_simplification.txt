Create a single-file Python program named `csv_to_sqlite.py`. The program should read exactly three lines from standard input, removing the trailing newline from each line: the path to a SQLite database file, the name of a table, and the path to a CSV file. If the database file does not exist, create a new empty SQLite database there.

The CSV file contains a header line `name,quantity` followed by data rows using those same two columns. Ensure the named table exists, creating it if needed with columns `name TEXT` and `quantity INTEGER`. For each data row, treat `name` as the key: if a row with that `name` already exists in the table, update its `quantity` to the new value; otherwise insert a new row. Count how many rows are inserted and how many are updated.

After processing all CSV data rows, print exactly two lines to standard output:

```
inserted: <N>
updated: <M>
```

Here `<N>` is the number of inserted rows and `<M>` is the number of updated rows. If the CSV file does not exist, print `error: csv file not found` to standard error and exit with status 1.

Example: A user runs `python csv_to_sqlite.py`, then enters:

```
/tmp/measurements.db
readings
/tmp/march.csv
```

The program creates or opens `/tmp/measurements.db`, creates the `readings` table if it does not exist, reads `/tmp/march.csv`, and prints the inserted and updated row counts.
