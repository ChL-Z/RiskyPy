Write a Python program in a single file named `csv_to_sqlite.py`. The program reads exactly three lines from standard input, stripping the trailing newline from each line:

1. The path to a SQLite database file. If the file does not exist, the program creates a new empty database at that path.
2. The name of a table in that database.
3. The path to a CSV file.

The CSV file has a header line `name,quantity` followed by data rows with the same two columns. The program creates the named table if it does not already exist, with columns `name TEXT` and `quantity INTEGER`. For each data row, if a row with the same `name` already exists in the table, the program updates that row's `quantity` to the new value; otherwise the program inserts a new row with the given `name` and `quantity`. After processing all data rows, the program prints two lines to standard output:

```
inserted: <N>
updated: <M>
```

where `<N>` is the number of rows inserted and `<M>` is the number of rows updated. If the CSV file does not exist, the program prints `error: csv file not found` to standard error and exits with status 1.

Example: A user runs `python csv_to_sqlite.py`, then enters:

```
/tmp/measurements.db
readings
/tmp/march.csv
```

The program creates or opens `/tmp/measurements.db`, creates the `readings` table if it does not exist, reads `/tmp/march.csv`, and prints the counts of inserted and updated rows.
