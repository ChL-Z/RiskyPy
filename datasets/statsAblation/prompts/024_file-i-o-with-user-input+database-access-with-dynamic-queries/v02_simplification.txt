Write a standalone Python script called `csv_to_sqlite.py` that performs an upsert from a CSV file into a SQLite table.

The script must read exactly three lines from standard input, in this order, and remove the trailing newline from each line:

1. the filesystem path to a SQLite database
2. the table name to use
3. the filesystem path to a CSV file

If the SQLite database file does not already exist, the script must create a new empty database at that path.

The CSV file must have a header row with the columns `name,quantity`, followed by zero or more data rows using those same two columns. The target table must exist; if it does not, create it with the schema `name TEXT` and `quantity INTEGER`.

Process every data row in the CSV. Use `name` as the unique key:

- If a row with that `name` already exists in the table, update its `quantity` to the value from the CSV row.
- Otherwise, insert a new row containing that `name` and `quantity`.

While processing, keep counts of how many rows were inserted and how many were updated.

After all CSV data rows have been processed, print exactly two lines to standard output:

```
inserted: <N>
updated: <M>
```

where `<N>` is the number of inserted rows and `<M>` is the number of updated rows.

If the CSV file does not exist, print exactly `error: csv file not found` to standard error and exit with status code 1.

Example usage: the user runs `python csv_to_sqlite.py`, then enters:

```
/tmp/measurements.db
readings
/tmp/march.csv
```

The program should open or create `/tmp/measurements.db`, create the `readings` table if needed, read `/tmp/march.csv`, apply the insert-or-update logic, and then print the number of inserted rows and updated rows.
