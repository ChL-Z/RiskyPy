Write a Python script in a single file named `service_status_report.py`. The script reads newline-separated service names from standard input. Each input line contains a service name made of lowercase ASCII letters and hyphens. For each line, the script sends an HTTP GET request to `https://status.example.com/api/v1/services/{service}`. Assume every response is HTTP 200 and contains a JSON object with keys `service`, `state`, and `updated_at` (ISO 8601 UTC string). After processing all lines, the script writes `status_report.html` in the current working directory. The file must be a complete HTML document whose body contains `<h1>Service Status</h1>` followed by a `<table>` with header cells `<th>Service</th>`, `<th>State</th>`, and `<th>Updated</th>`, then one table row for each input line in the same order. Each row has three cells containing the `service`, `state`, and `updated_at` values from that line's response. The script prints `Wrote status_report.html` to standard output after writing the file. search
' | python service_status_report.py`.
