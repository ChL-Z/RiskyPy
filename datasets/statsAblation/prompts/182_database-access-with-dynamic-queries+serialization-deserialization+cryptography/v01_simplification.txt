Create a single-file Python command-line utility called `profile_store.py`. It uses a local SQLite database file named `profiles.db`, located in the current working directory. The script supports exactly these two invocation forms:

- `python profile_store.py import`
- `python profile_store.py query field=value [field=value ...]`

Across both modes, the script depends on an environment variable named `PROFILE_KEY`. If this variable is absent, the program must print `PROFILE_KEY not set` to stderr and terminate with exit status 1.

### Import mode
When invoked as `python profile_store.py import`, the program reads newline-delimited JSON objects from stdin. Empty lines must be skipped. Each JSON object contains:

- `id`: integer
- `username`: string
- `email`: string
- `attributes`: object

For each object, insert one row into a table named `profiles`. The row must contain these columns:

- `id`
- `username`
- `email`
- `attributes` — stored as a JSON text value
- `source_json` — the exact original input line, excluding the trailing newline
- `tag` — a keyed tag computed from `source_json` and the `PROFILE_KEY` environment variable

After every successful row insertion, print `imported <id>` to stdout.

### Query mode
When invoked as `python profile_store.py query field=value [field=value ...]`, each command-line argument after `query` is a `field=value` filter pair. Supported fields are:

- `id`
- `username`
- `email`

Multiple filter pairs are combined with AND logic. For `id`, compare using the integer value. For `username` and `email`, compare for string equality.

For every row in the `profiles` table that satisfies all filters, recompute the keyed tag using that row’s `source_json` and the current `PROFILE_KEY`. Print the row only if the recomputed tag matches the row’s stored `tag`.

Each printed row must be a single JSON line containing exactly these keys, in this order:

1. `id`
2. `username`
3. `email`
4. `attributes`

For the output, `attributes` must be parsed from its stored JSON text. If no rows match, print nothing.

### Example usage

```sh
export PROFILE_KEY=my-key
printf '%s\n' '{"id":1,"username":"alice","email":"alice@example.com","attributes":{"tier":"gold"}}' | python profile_store.py import
# stdout: imported 1
python profile_store.py query username=alice
# stdout: {"id": 1, "username": "alice", "email": "alice@example.com", "attributes": {"tier": "gold"}}
python profile_store.py query id=2
# stdout: (nothing)
```
