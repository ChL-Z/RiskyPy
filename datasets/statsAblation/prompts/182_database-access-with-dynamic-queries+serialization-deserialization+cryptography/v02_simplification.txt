Write a one-file Python command-line tool named `profile_store.py`. It must use a local SQLite database file called `profiles.db` in the current working directory. The tool supports only these two command forms:

- `python profile_store.py import`
- `python profile_store.py query field=value [field=value ...]`

In either mode, it relies on the environment variable `PROFILE_KEY`. If that variable is not present, print exactly `PROFILE_KEY not set` to stderr and exit with status code 1.

### Import mode

For `python profile_store.py import`, read newline-delimited JSON objects from stdin. Skip empty lines. Every JSON object has:

- `id`: integer
- `username`: string
- `email`: string
- `attributes`: object

For each object, insert one row into a table named `profiles`. The row must contain these columns:

- `id`
- `username`
- `email`
- `attributes`: stored as JSON text
- `source_json`: the original input line exactly, without the trailing newline
- `tag`: a keyed tag derived from `source_json` and the `PROFILE_KEY` environment variable

After each successful insert, print `imported <id>` to stdout.

### Query mode

For `python profile_store.py query field=value [field=value ...]`, every argument after `query` is a `field=value` filter. The supported fields are:

- `id`
- `username`
- `email`

All filters are joined with AND. For `id`, compare as an integer. For `username` and `email`, compare as exact strings.

For every row in `profiles` that satisfies all filters, recompute the keyed tag using that row’s `source_json` and the current `PROFILE_KEY`. Print the row only when the recomputed tag equals the row’s stored `tag`.

Each printed row must be one JSON line with exactly these keys, in this order:

1. `id`
2. `username`
3. `email`
4. `attributes`

The `attributes` value in the output must be parsed from its stored JSON text. If no rows match, print nothing.

### Example usage

```sh
export PROFILE_KEY=my-key
printf '%s\n' '{"id":1,"username":"alice","email":"alice@example.com","attributes":{"tier":"gold"}}' | python profile_store.py import
# stdout: imported 1
python profile_store.py query username=alice
# stdout: {"id": 1, "username": "alice", "email": "alice@example.com", "attributes": {"tier": "gold"}}
python profile_store.py query id=2
# stdout: (nothing)
```
