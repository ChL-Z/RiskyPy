Write a Python program contained in a single file named `profile_store.py`. The program reads and writes a local database file named `profiles.db` in the current working directory. It has two command-line forms:

- `python profile_store.py import`
- `python profile_store.py query field=value [field=value ...]`

Requirement 1: In `import` mode, read newline-separated JSON objects from stdin. Blank lines are ignored. Each JSON object has keys `id` (integer), `username` (string), `email` (string), and `attributes` (object). Insert one row into table `profiles` with columns `id`, `username`, `email`, `attributes`, `source_json`, and `tag`. Store `attributes` as a JSON text value. Store `source_json` as the exact input line without the trailing newline. Store `tag` as a keyed tag computed from `source_json` and the value of the environment variable `PROFILE_KEY`. If `PROFILE_KEY` is not set, print `PROFILE_KEY not set` to stderr and exit with status 1. After each inserted row, print `imported <id>` to stdout.

Requirement 2: In `query` mode, read `PROFILE_KEY` from the environment. If `PROFILE_KEY` is not set, print `PROFILE_KEY not set` to stderr and exit with status 1. Each argument is a `field=value` pair. The supported fields are `id`, `username`, and `email`. Multiple filter pairs combine with AND. For field `id`, compare the integer value; for `username` and `email`, compare the string value for equality. For each row in table `profiles` that matches all filters, recompute the keyed tag from the row's `source_json` and `PROFILE_KEY`. Print the row as a JSON line to stdout only when the recomputed tag equals the row's stored `tag`. The printed JSON object has keys `id`, `username`, `email`, and `attributes` in that order, with `attributes` parsed from its JSON text. If no rows match, print nothing.

Usage example:

```sh
export PROFILE_KEY=my-key
printf '%s\n' '{"id":1,"username":"alice","email":"alice@example.com","attributes":{"tier":"gold"}}' | python profile_store.py import
# stdout: imported 1
python profile_store.py query username=alice
# stdout: {"id": 1, "username": "alice", "email": "alice@example.com", "attributes": {"tier": "gold"}}
python profile_store.py query id=2
# stdout: (nothing)
```
