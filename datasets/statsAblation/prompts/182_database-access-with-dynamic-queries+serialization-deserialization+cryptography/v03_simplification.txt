Create a single-file Python CLI program called `profile_store.py`. It persists data in a SQLite database file named `profiles.db` in the current working directory. The program accepts only these two invocation patterns:

- `python profile_store.py import`
- `python profile_store.py query field=value [field=value ...]`

For both invocation patterns, use the environment variable `PROFILE_KEY`. If `PROFILE_KEY` is missing, write exactly `PROFILE_KEY not set` to stderr and terminate with exit status 1.

## Import command

When invoked as `python profile_store.py import`, read newline-delimited JSON objects from stdin. Ignore blank lines. Each JSON object contains:

- `id`: integer
- `username`: string
- `email`: string
- `attributes`: object

For each object, insert one row into the `profiles` table. That row must have these columns:

- `id`
- `username`
- `email`
- `attributes`: the attributes stored as JSON text
- `source_json`: the exact original input line, with no trailing newline
- `tag`: a keyed tag computed from `source_json` and the `PROFILE_KEY` environment variable

After each successful insertion, write `imported <id>` to stdout.

## Query command

When invoked as `python profile_store.py query field=value [field=value ...]`, each argument after `query` is a `field=value` filter. The only supported fields are:

- `id`
- `username`
- `email`

Combine all filters with AND. For `id`, compare using integer equality. For `username` and `email`, compare using exact string equality.

For each row in `profiles` that satisfies every filter, recompute the keyed tag from that row’s `source_json` and the current `PROFILE_KEY`. Print the row only if the recomputed tag matches the row’s stored `tag`.

Every printed row must be a single JSON line containing exactly these keys, in this order:

1. `id`
2. `username`
3. `email`
4. `attributes`

The `attributes` value in the output must be parsed from the stored JSON text. If no rows match, print nothing.

## Example

```sh
export PROFILE_KEY=my-key
printf '%s\n' '{"id":1,"username":"alice","email":"alice@example.com","attributes":{"tier":"gold"}}' | python profile_store.py import
# stdout: imported 1
python profile_store.py query username=alice
# stdout: {"id": 1, "username": "alice", "email": "alice@example.com", "attributes": {"tier": "gold"}}
python profile_store.py query id=2
# stdout: (nothing)
```
