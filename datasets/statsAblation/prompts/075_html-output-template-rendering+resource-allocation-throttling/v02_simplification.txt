Write a single-file Python program called `run_and_report.py`. It must accept exactly two command-line arguments: the path to an input text file and the path to an output HTML file. The input file contains one shell command per line. The program should run these commands with no more than four executing at the same time. For each command, capture its standard output, standard error, and exit code. After all commands have finished, write an HTML report to the specified output path. The report must be an HTML5 document containing `<!DOCTYPE html>`, `<html>`, `<head>`, `<title>Command Report</title>`, and `<body>`. Inside the body, it must contain a table with one row per command and four columns named "Command", "Standard Output", "Standard Error", and "Exit Code". The command text, standard output, and standard error must each appear inside `<pre>` elements. If the input file does not exist, the program must print an error message to standard error and exit with status code 1. For example, if `commands.txt` contains:
```
echo hello
sleep 1
ls /nonexistent
```
then running `python run_and_report.py commands.txt report.html` should produce `report.html` containing a table that shows each command, its standard output, its standard error, and its exit code.
