Write a Python script in a single file named `run_and_report.py`. The script reads a text file containing one shell command per line. It runs up to 4 of those commands at the same time. For each command, it captures the command's standard output, standard error, and exit code. After all commands finish, the script writes an HTML file containing a table with one row per command and columns labeled "Command", "Standard Output", "Standard Error", and "Exit Code". The command text, standard output, and standard error must each be displayed inside `<pre>` elements. The HTML file must be an HTML5 document that includes `<!DOCTYPE html>`, `<html>`, `<head>`, `<title>Command Report</title>`, and `<body>`. The script accepts exactly two command-line arguments: the path to the input file and the path to the output HTML file. If the input file does not exist, the script prints an error message to standard error and exits with status code 1.

For example, if `commands.txt` contains:
```
echo hello
sleep 1
ls /nonexistent
```
then running `python run_and_report.py commands.txt report.html` should create `report.html` with a table showing each command, its standard output, standard error, and exit code.
