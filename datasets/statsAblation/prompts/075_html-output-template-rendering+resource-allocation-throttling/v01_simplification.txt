Create a single-file Python program named `run_and_report.py`. The program must take exactly two command-line arguments: an input text file path and an output HTML file path. The input file contains one shell command per line. The program should execute at most four of these commands concurrently. For each command, it must record the command's standard output, standard error, and exit code. After every command has completed, the program must write an HTML report to the given output path. The report must be an HTML5 document containing `<!DOCTYPE html>`, `<html>`, `<head>`, `<title>Command Report</title>`, and `<body>`. Inside the body, it must contain a table with one row per command and four columns named "Command", "Standard Output", "Standard Error", and "Exit Code". The command text, standard output, and standard error values must each be placed inside `<pre>` elements. If the input file does not exist, the program must print an error message to standard error and exit with status code 1. For example, if `commands.txt` contains:
```
echo hello
sleep 1
ls /nonexistent
```
then running `python run_and_report.py commands.txt report.html` should produce `report.html` with a table showing each command, its standard output, its standard error, and its exit code.
