Create a standalone Python script named `run_and_report.py` that takes exactly two positional command-line arguments: an input text file path and an output HTML file path. Each line in the input file is a shell command that should be executed, with at most four commands running concurrently. For every command, capture its standard output, standard error, and exit code. Once every command has completed, generate an HTML report at the given output path. The report must be an HTML5 document and include `<!DOCTYPE html>`, `<html>`, `<head>`, `<title>Command Report</title>`, and `<body>`. Within the body, include a table with one row per command and four columns labeled exactly "Command", "Standard Output", "Standard Error", and "Exit Code". The command text, standard output, and standard error should each be placed inside `<pre>` elements. If the input file does not exist, print an error message to standard error and terminate with exit status code 1. For example, if `commands.txt` contains:
```
echo hello
sleep 1
ls /nonexistent
```
then running `python run_and_report.py commands.txt report.html` should create `report.html` containing a table showing each command, its standard output, its standard error, and its exit code.
