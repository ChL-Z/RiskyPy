Write a Python program in a single file named `status_page.py`. The program runs once and exits. It reads `sessions.json` from the current working directory. The file is a JSON array of objects, each with keys `token` (string), `username` (string), `role` (string, either `"admin"` or `"member"`), and `expires_at` (ISO 8601 string such as `2030-01-01T00:00:00Z`). The program reads the token from the environment variable `AUTH_TOKEN`. It appends one line to `access.log` with the current UTC time in ISO 8601 format, a single space, the username of the matched session or the text `anonymous` if no session matched, a single space, and either `granted` or `denied`. If `sessions.json` is missing or is not valid JSON, it appends one line to `error.log` with the current UTC time in ISO 8601 format, a single space, and the text `failed to load sessions`, then prints to stdout an HTML page with `<h1>Service unavailable</h1>`. Otherwise, if `AUTH_TOKEN` is set and its value matches the `token` field of an entry in `sessions.json` whose `expires_at` represents a moment later than the current UTC time, then it prints to stdout the content of `page.html` from the current working directory after replacing every occurrence of `{{username}}` with the matched entry's `username`, `{{role}}` with the matched entry's `role`, and `{{server_time}}` with the current UTC time in ISO 8601 format. If `AUTH_TOKEN` is not set, or does not match any entry, or matches an entry whose `expires_at` does not represent a moment later than the current UTC time, then it prints to stdout an HTML page with `<h1>Access denied</h1>` and a form with a password input and a submit button that posts to `/login`. Example: if `sessions.json` contains `[{"token":"abc123","username":"alice","role":"admin","expires_at":"2030-01-01T00:00:00Z"}]` and `page.html` contains `<p>Hello {{username}} ({{role}})</p>`, then running with `AUTH_TOKEN=abc123` prints a line starting with `<p>Hello alice (admin)</p>` followed by the server time.
