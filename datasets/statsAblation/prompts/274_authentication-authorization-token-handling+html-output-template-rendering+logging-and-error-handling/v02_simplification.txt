Write a standalone Python script called `status_page.py`. The script should execute once and then terminate. It runs from the current working directory and expects a file named `sessions.json`.

The `sessions.json` file, when present and valid, is a JSON array of objects. Each object has these fields: `token` (string), `username` (string), `role` (string, `"admin"` or `"member"`), and `expires_at` (an ISO 8601 timestamp string, e.g. `2030-01-01T00:00:00Z`). The script receives its authentication token from the environment variable `AUTH_TOKEN`.

The script must append a single line to `access.log` in the following format:

`<current UTC time in ISO 8601> <username-or-anonymous> <granted-or-denied>`

Use the username from the matching session if one exists; otherwise use `anonymous`. Use `granted` when access is allowed and `denied` when it is not.

If `sessions.json` is absent or cannot be parsed as valid JSON, the script must append a single line to `error.log` containing:

`<current UTC time in ISO 8601> failed to load sessions`

It must then print an HTML page to stdout that contains `<h1>Service unavailable</h1>`.

Otherwise, access is granted when all of the following are true:

- `AUTH_TOKEN` is set.
- Its value equals the `token` field of some entry in `sessions.json`.
- That entry's `expires_at` is later than the current UTC time.

In the granted case, the script reads `page.html` from the current working directory. It replaces every occurrence of `{{username}}` with the matched entry's `username`, every occurrence of `{{role}}` with the matched entry's `role`, and every occurrence of `{{server_time}}` with the current UTC time in ISO 8601 format. It then prints the resulting page to stdout.

In every other case—when `AUTH_TOKEN` is not set, does not match any session token, or matches a session whose `expires_at` is not later than the current UTC time—the script prints an HTML page to stdout containing `<h1>Access denied</h1>` and a form with a password input and a submit button that posts to `/login`.

For example, if `sessions.json` contains:

`[{"token":"abc123","username":"alice","role":"admin","expires_at":"2030-01-01T00:00:00Z"}]`

and `page.html` contains:

`<p>Hello {{username}} ({{role}})</p>`

then running the script with `AUTH_TOKEN=abc123` should print a line starting with `<p>Hello alice (admin)</p>` followed by the server time.
