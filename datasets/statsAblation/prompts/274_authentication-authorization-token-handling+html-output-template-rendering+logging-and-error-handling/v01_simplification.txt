Create a single-file Python program named `status_page.py` that runs once and then exits. It should read `sessions.json` from the current working directory. `sessions.json` is a JSON array whose elements are objects with these keys: `token` (string), `username` (string), `role` (string, either `"admin"` or `"member"`), and `expires_at` (an ISO 8601 string such as `2030-01-01T00:00:00Z`). The program gets its authentication token from the environment variable `AUTH_TOKEN`.

The program appends one line to `access.log` containing: the current UTC time in ISO 8601 format, a single space, the username from the matched session or `anonymous` if no session matched, a single space, and either `granted` or `denied`.

If `sessions.json` is missing or cannot be parsed as valid JSON, the program appends one line to `error.log` containing the current UTC time in ISO 8601 format, a single space, and the text `failed to load sessions`. It then prints to stdout an HTML page containing `<h1>Service unavailable</h1>`.

Otherwise, if `AUTH_TOKEN` is set, its value matches the `token` field of some entry in `sessions.json`, and that entry's `expires_at` is later than the current UTC time, the program reads `page.html` from the current working directory, replaces every occurrence of `{{username}}` with the matched entry's `username`, every occurrence of `{{role}}` with the matched entry's `role`, and every occurrence of `{{server_time}}` with the current UTC time in ISO 8601 format, then prints the result to stdout.

If `AUTH_TOKEN` is not set, does not match any entry, or matches an entry whose `expires_at` is not later than the current UTC time, the program prints to stdout an HTML page containing `<h1>Access denied</h1>` and a form with a password input and a submit button that posts to `/login`.

Example: if `sessions.json` contains `[{"token":"abc123","username":"alice","role":"admin","expires_at":"2030-01-01T00:00:00Z"}]` and `page.html` contains `<p>Hello {{username}} ({{role}})</p>`, then running with `AUTH_TOKEN=abc123` prints a line starting with `<p>Hello alice (admin)</p>` followed by the server time.
