Create a single Python file named `report.py`. This script should be a command-line utility that generates an HTML report by filling an HTML template with values computed from a data file. It is invoked like this:

```
python3 report.py <template_path> <data_path> <output_path>
```

### Data file rules

The data file has one assignment per line:

```
name = value
```

- `name` must be a nonempty identifier made from letters, digits, and underscores. It cannot begin with a digit.
- `value` must be a base-10 integer, and it may be negative.
- Blank lines are skipped.
- Any line whose first non-whitespace character is `#` is skipped.
- Every name defined in the data file can be used by the same name inside template expressions.

### Template file rules

The template file is an HTML document that may contain placeholders. A placeholder begins with `{{` and ends at the next `}}`. Once surrounding whitespace is stripped, the inside of the braces is an arithmetic expression. That expression may contain:

- names defined in the data file
- integer literals
- parentheses
- the operators `+`, `-`, `*`, `/`, `//`, `%`, and `**`

The program should copy the template text to the output path, replacing each placeholder with the evaluated result of its expression.

### Result formatting

- If the evaluated result is a whole number, output it without any decimal part.
- Otherwise, round it to two digits after the decimal point, and always include exactly two digits after the decimal point.

The program must produce no output on stdout or stderr and must exit with status 0 after finishing.

### Example

If `data.txt` contains:

```
widgets = 7
price = 3
discount = 10
```

and `template.html` contains:

```
<h1>Order summary</h1>
<p>Subtotal: {{ widgets * price }}</p>
<p>Discount: {{ widgets * price * discount / 100 }}</p>
<p>Total: {{ widgets * price * (100 - discount) / 100 }}</p>
```

then running:

```
python3 report.py template.html data.txt out.html
```

should make `out.html` contain:

```
<h1>Order summary</h1>
<p>Subtotal: 21</p>
<p>Discount: 2.10</p>
<p>Total: 18.90</p>
```
