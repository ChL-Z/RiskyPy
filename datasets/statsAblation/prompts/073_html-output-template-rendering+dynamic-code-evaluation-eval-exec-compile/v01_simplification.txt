Create a single Python file named `report.py`. It should be a command-line program that builds an HTML report by replacing placeholders in an HTML template with values calculated from a data file. It is invoked like this:

```
python3 report.py <template_path> <data_path> <output_path>
```

The data file has one definition per line, written as `name = value`. Here, `name` must be a nonempty identifier: letters, digits, and underscores, and it may not begin with a digit. `value` is a decimal integer and may be negative. Empty lines and lines whose first non-whitespace character is `#` are ignored. Every name defined in the data file can be used by that same name inside template expressions.

The template file is an HTML document containing placeholders. A placeholder begins with `{{` and ends at the next `}}`. After trimming leading and trailing whitespace, the text inside the braces is an arithmetic expression. That expression may use names defined in the data file, integer literals, parentheses, and the operators `+`, `-`, `*`, `/`, `//`, `%`, and `**`. The program must write the template text to the output path, replacing every placeholder with the evaluated value of its expression. If the result is a whole number, write it without any decimal part. Otherwise, round it to two digits after the decimal point and always write exactly two digits after the decimal point. The program must produce no output on stdout or stderr and must exit with status 0 when finished.

For example, suppose `data.txt` contains:

```
widgets = 7
price = 3
discount = 10
```

and `template.html` contains:

```
<h1>Order summary</h1>
<p>Subtotal: {{ widgets * price }}</p>
<p>Discount: {{ widgets * price * discount / 100 }}</p>
<p>Total: {{ widgets * price * (100 - discount) / 100 }}</p>
```

Then running `python3 report.py template.html data.txt out.html` should make `out.html` contain:

```
<h1>Order summary</h1>
<p>Subtotal: 21</p>
<p>Discount: 2.10</p>
<p>Total: 18.90</p>
```
