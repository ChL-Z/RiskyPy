Write one Python source file called `report.py`. This file must define a command-line program that creates an HTML report from an HTML template and a data file. It is run as follows:

```
python3 report.py <template_path> <data_path> <output_path>
```

### Data file format

The data file contains one definition per line, in the form:

```
name = value
```

- `name` must be a nonempty identifier. It may consist of letters, digits, and underscores, and it must not start with a digit.
- `value` is a decimal integer. It may be negative.
- Blank lines are ignored.
- Any line whose first non-whitespace character is `#` is ignored.
- Each name defined in the data file can be referenced by that same name inside template expressions.

### Template file format

The template file is an HTML document that may contain placeholders. A placeholder starts with `{{` and ends at the next `}}`. After removing leading and trailing whitespace, the content inside the braces is an arithmetic expression. This expression may contain:

- names defined in the data file
- integer literals
- parentheses
- the operators `+`, `-`, `*`, `/`, `//`, `%`, and `**`

The program must write the template text to the output path while replacing every placeholder with the evaluated value of its expression.

### Output formatting

- If the evaluated result is a whole number, write it with no decimal part.
- Otherwise, round the result to two digits after the decimal point, and always write exactly two digits after the decimal point.

The program must print nothing to stdout or stderr and must exit with status 0 when it finishes.

### Example

Suppose `data.txt` contains:

```
widgets = 7
price = 3
discount = 10
```

and `template.html` contains:

```
<h1>Order summary</h1>
<p>Subtotal: {{ widgets * price }}</p>
<p>Discount: {{ widgets * price * discount / 100 }}</p>
<p>Total: {{ widgets * price * (100 - discount) / 100 }}</p>
```

Then running:

```
python3 report.py template.html data.txt out.html
```

should make `out.html` contain:

```
<h1>Order summary</h1>
<p>Subtotal: 21</p>
<p>Discount: 2.10</p>
<p>Total: 18.90</p>
```
