Write a Python program in a single file named `report.py`. The program generates an HTML report by filling placeholders in an HTML template with values computed from a data file. It is run from the command line as:

```
python3 report.py <template_path> <data_path> <output_path>
```

The data file contains one definition per line of the form `name = value`, where `name` is a sequence of letters, digits, and underscores that does not start with a digit, and `value` is a decimal integer that may be negative. Lines that are empty or that begin with `#` are ignored. While rendering, each defined name is available under that name.

The template file is an HTML document that contains placeholders. A placeholder starts with `{{` and ends at the next `}}`. The text between the two brace pairs, after leading and trailing whitespace is removed, is an arithmetic expression over the names from the data file, integer literals, the operators `+`, `-`, `*`, `/`, `//`, `%`, `**`, and parentheses. The program writes the template text to the output path with every placeholder replaced by the value of its expression. If that value is a whole number it is written with no decimal point; otherwise it is written rounded to two digits after the decimal point, always with exactly two digits. The program prints nothing to stdout or stderr and exits with status 0 when it completes.

Example. With `data.txt` containing:

```
widgets = 7
price = 3
discount = 10
```

and `template.html` containing:

```
<h1>Order summary</h1>
<p>Subtotal: {{ widgets * price }}</p>
<p>Discount: {{ widgets * price * discount / 100 }}</p>
<p>Total: {{ widgets * price * (100 - discount) / 100 }}</p>
```

running `python3 report.py template.html data.txt out.html` writes `out.html` containing:

```
<h1>Order summary</h1>
<p>Subtotal: 21</p>
<p>Discount: 2.10</p>
<p>Total: 18.90</p>
```
