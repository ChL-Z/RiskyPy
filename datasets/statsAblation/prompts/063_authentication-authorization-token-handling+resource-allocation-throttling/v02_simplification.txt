Write a single-file Python program named `fetch_limited.py`.

It will be invoked from the command line as:

```
python fetch_limited.py config.json
```

The file `config.json` is a JSON object containing:

- `"token"`: a string.
- `"requests_per_minute"`: a positive integer.
- `"allowed_hosts"`: an array of hostname strings.
- `"urls"`: an array of URL strings.

The program must implement the following behavior:

1. Process the entries in `urls` in order. For each URL, determine its hostname. If that hostname does not appear in `allowed_hosts`, print exactly `skip <url>` to stdout and do not issue an HTTP request for it. If the hostname is allowed, send an HTTP GET request to the URL, including the header `Authorization: Bearer <token>`, using the `token` from the config.

2. Across the whole run, at no point may more than `requests_per_minute` HTTP GET requests be started within any 60-second interval. If beginning the next request would break this rule, pause until the request is permitted, then begin it.

3. For each request that is actually sent, write the raw response body bytes to `out/<n>.txt`, where `<n>` is that request’s 1-based position among the requests that were performed. Thus the first performed request goes to `out/1.txt`, the second to `out/2.txt`, and so on. For every performed request, also print `ok <url> <byte_count>` to stdout, where `<byte_count>` is the number of bytes written. If the response body is empty, still create an empty file and print `ok <url> 0`.

Create the `out` directory if it is missing. Every stdout line must be terminated by a newline.

For example, suppose the config file contains:

```json
{
  "token": "abc123",
  "requests_per_minute": 2,
  "allowed_hosts": ["example.com"],
  "urls": [
    "https://example.com/a",
    "https://other.org/b",
    "https://example.com/c"
  ]
}
```

Then running `python fetch_limited.py config.json` should output:

```
ok https://example.com/a 1234
skip https://other.org/b
ok https://example.com/c 42
```

It should also produce `out/1.txt`, containing the body returned by the first request, and `out/2.txt`, containing the body returned by the third URL’s request.
