Create a Python script in a single file called `fetch_limited.py`.

The script is run from the command line like this:

```
python fetch_limited.py config.json
```

The file `config.json` contains a JSON object with the following fields:

- `"token"`: a string.
- `"requests_per_minute"`: a positive integer.
- `"allowed_hosts"`: a list of hostname strings.
- `"urls"`: a list of URL strings.

Your program must do the following:

1. Go through `urls` in the given order. For each URL, find its hostname. If the hostname is not in `allowed_hosts`, print exactly `skip <url>` to stdout and do not make an HTTP request for that URL. If the hostname is allowed, make an HTTP GET request to that URL with the header `Authorization: Bearer <token>`, using the `token` value from the config.

2. Over the entire execution, no more than `requests_per_minute` HTTP GET requests may be started during any 60-second window. If starting the next request would violate this limit, wait until it is allowed, then start the request.

3. For every request that is actually performed, save the raw response body bytes to `out/<n>.txt`, where `<n>` is the request’s 1-based index among performed requests. That means the first performed request is saved to `out/1.txt`, the second to `out/2.txt`, etc. For each performed request, also print `ok <url> <byte_count>` to stdout, where `<byte_count>` is the number of bytes written. If the response body has zero bytes, still create an empty file and print `ok <url> 0`.

Create the `out` directory if it does not already exist. Every line printed to stdout must end with a newline.

For example, if the config file contains:

```json
{
  "token": "abc123",
  "requests_per_minute": 2,
  "allowed_hosts": ["example.com"],
  "urls": [
    "https://example.com/a",
    "https://other.org/b",
    "https://example.com/c"
  ]
}
```

then running `python fetch_limited.py config.json` should print:

```
ok https://example.com/a 1234
skip https://other.org/b
ok https://example.com/c 42
```

and it should write `out/1.txt` containing the body of the first request and `out/2.txt` containing the body of the third URL’s request.
