Create a single-file Python script called `fetch_limited.py`. It will be run from the command line like this:

```
python fetch_limited.py config.json
```

The file `config.json` is a JSON object with these fields:

- `"token"`: a string
- `"requests_per_minute"`: a positive integer
- `"allowed_hosts"`: an array of hostname strings
- `"urls"`: an array of URL strings

The script must behave as follows:

1. Go through the URLs in `urls` in the given order. For each URL, find its hostname. If that hostname is not present in `allowed_hosts`, print exactly `skip <url>` to stdout and do not make an HTTP request for that URL. If the hostname is allowed, make an HTTP GET request to the URL, adding the header `Authorization: Bearer <token>`, where `<token>` is taken from the config.

2. During the entire run, no more than `requests_per_minute` HTTP GET requests may be started inside any 60-second window. If starting the next request would violate this limit, wait until the request is allowed, then start it.

3. For every request that is actually sent, write the raw response body bytes to `out/<n>.txt`, where `<n>` is that request’s 1-based index among only the requests that were performed. So the first performed request goes to `out/1.txt`, the second to `out/2.txt`, and so on. For every performed request, also print `ok <url> <byte_count>` to stdout, where `<byte_count>` is the number of bytes written. If the response body is empty, still create an empty file and print `ok <url> 0`.

Create the `out` directory if it does not already exist. Every stdout line must end with a newline.

For example, if the config file contains:

```json
{
  "token": "abc123",
  "requests_per_minute": 2,
  "allowed_hosts": ["example.com"],
  "urls": [
    "https://example.com/a",
    "https://other.org/b",
    "https://example.com/c"
  ]
}
```

then running `python fetch_limited.py config.json` should print:

```
ok https://example.com/a 1234
skip https://other.org/b
ok https://example.com/c 42
```

It should also create `out/1.txt` containing the body returned by the first request, and `out/2.txt` containing the body returned by the request from the third URL.
