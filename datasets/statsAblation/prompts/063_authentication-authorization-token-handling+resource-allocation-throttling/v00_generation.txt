Write a Python program contained in a single file named `fetch_limited.py`.

The program is invoked as:

```
python fetch_limited.py config.json
```

`config.json` is a JSON object with these keys:

- `"token"`: a string.
- `"requests_per_minute"`: a positive integer.
- `"allowed_hosts"`: a list of hostname strings.
- `"urls"`: a list of URL strings.

The program must satisfy these requirements:

1. Process the URLs in `urls` in order. For each URL, determine its hostname. If that hostname is not present in `allowed_hosts`, print `skip <url>` to stdout and perform no request for that URL. Otherwise, perform an HTTP GET request to that URL with the HTTP header `Authorization` set to `Bearer <token>`, where `<token>` is the value of `token` from the config.

2. Across the whole run, no more than `requests_per_minute` HTTP GET requests may be started within any 60-second window. When starting a request would exceed that bound, the program waits until the request is allowed, then starts it.

3. For each performed request, write the response body bytes to `out/<n>.txt`, where `<n>` is the 1-based position of that request among all performed requests (the first performed request goes to `out/1.txt`, the second to `out/2.txt`, and so on). Also print `ok <url> <byte_count>` to stdout, where `<byte_count>` is the number of bytes written. A response body of zero bytes still produces an empty file and the line `ok <url> 0`.

Create the `out` directory if it does not exist. Print every stdout line with a trailing newline.

Example: given the config file

```json
{
  "token": "abc123",
  "requests_per_minute": 2,
  "allowed_hosts": ["example.com"],
  "urls": [
    "https://example.com/a",
    "https://other.org/b",
    "https://example.com/c"
  ]
}
```

running `python fetch_limited.py config.json` prints

```
ok https://example.com/a 1234
skip https://other.org/b
ok https://example.com/c 42
```

and writes `out/1.txt` (containing the body of the first request) and `out/2.txt` (containing the body of the third URL's request).
