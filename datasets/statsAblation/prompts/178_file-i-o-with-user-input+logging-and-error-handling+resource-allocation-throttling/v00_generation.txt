Create a Python program in a single file named `throttled_copy.py`. The program reads newline-separated source file paths from standard input and copies each file to a destination directory passed as the first command-line argument. The destination directory must already exist. For each source path, copy the file to a file inside the destination directory with the same basename as the source file, replacing any existing file with that name. The program must enforce two limits at the same time: at most 3 copy operations may be in progress at any moment, and no more than 10 copy operations may begin in any 1-second window. For each source path, append one line to `copy_log.txt` inside the destination directory using this exact format: `<UTC timestamp in ISO 8601 format YYYY-MM-DDTHH:MM:SSZ> <source path> <OK|FAIL> <bytes copied or error message>`. The fields are separated by single spaces. If a copy succeeds, the third field is `OK` and the fourth field is the number of bytes copied. If a copy fails, the third field is `FAIL` and the fourth field is all remaining characters of the exception message on that line. Each line ends with a newline character. After all source paths have been processed, print exactly one line to standard output: `copied=<n> failed=<m>`.

Example invocation:
`printf 'data/a.txt\ndata/b.txt\n' | python throttled_copy.py outdir`
