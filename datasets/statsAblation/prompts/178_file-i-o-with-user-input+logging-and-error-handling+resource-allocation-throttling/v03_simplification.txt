Write a standalone Python program called `throttled_copy.py`. It takes exactly one command-line argument: a destination directory that can be assumed to already exist. The program reads source file paths from standard input, one per line. For each source path, copy that file into the destination directory using the original basename, overwriting any existing file with the same name.

While copying, enforce both throttling rules simultaneously:
- no more than 3 copy operations may be running concurrently;
- no more than 10 copy operations may be started within any 1-second interval.

For every source path processed, append exactly one line to `copy_log.txt` inside the destination directory. Each line must have this exact format, with fields separated by single spaces and ending with a newline:

`<UTC timestamp as ISO 8601 YYYY-MM-DDTHH:MM:SSZ> <source path> <OK|FAIL> <bytes copied or error message>`

On success, the third field is `OK` and the fourth field is the number of bytes copied. On failure, the third field is `FAIL` and the fourth field is the complete remaining exception message.

After all input paths have been handled, print exactly one line to standard output:

`copied=<n> failed=<m>`

Example invocation:
`printf 'data/a.txt
data/b.txt
' | python throttled_copy.py outdir`
