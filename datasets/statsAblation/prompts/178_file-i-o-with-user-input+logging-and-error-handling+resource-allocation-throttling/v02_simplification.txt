Create a single-file Python program named `throttled_copy.py`. It should accept one command-line argument: a destination directory. Assume this destination directory already exists. The program reads source file paths from standard input, one path per line. For each source path, copy the file into the destination directory using the same basename, replacing any existing file with that name.

While doing this, enforce both limits at the same time:
- at most 3 copy operations may be active concurrently;
- at most 10 copy operations may begin during any 1-second interval.

For each source path processed, append exactly one line to `copy_log.txt` inside the destination directory. Each line must use this exact format:

`<UTC timestamp as ISO 8601 YYYY-MM-DDTHH:MM:SSZ> <source path> <OK|FAIL> <bytes copied or error message>`

Fields must be separated by single spaces. For a successful copy, write `OK` as the third field and the number of bytes copied as the fourth field. For a failed copy, write `FAIL` as the third field and the full remaining exception message as the fourth field. Each log line must end with a newline.

Once all input paths have been processed, print exactly one line to standard output:

`copied=<n> failed=<m>`

Example invocation:
`printf 'data/a.txt\ndata/b.txt\n' | python throttled_copy.py outdir`
