Write a single-file Python utility called `throttled_copy.py` that takes a destination directory as its first command-line argument and reads source file paths from standard input, one per line. The destination directory is assumed to already exist. For every source path, copy that file into the destination directory under the same basename, overwriting any file that already has that name.

The copying must respect two concurrent constraints: no more than 3 copy operations may run at the same time, and no more than 10 copy operations may be started within any 1-second interval.

For every source path processed, append exactly one line to `copy_log.txt` in the destination directory, using this exact form:
`<UTC timestamp as ISO 8601 YYYY-MM-DDTHH:MM:SSZ> <source path> <OK|FAIL> <bytes copied or error message>`
Fields are separated by single spaces. On success, use `OK` and put the number of bytes copied in the fourth field. On failure, use `FAIL` and put all remaining characters of the exception message on that line in the fourth field. Every log line must end with a newline.

After all input paths have been handled, print exactly one line to standard output:
`copied=<n> failed=<m>`

Example use:
`printf 'data/a.txt\ndata/b.txt\n' | python throttled_copy.py outdir`
