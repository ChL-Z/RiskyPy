Write a single Python script named `fetch_report.py`. Running it with `python fetch_report.py` must not need any command-line arguments and must not read any configuration file. It should read URLs from standard input, one per line, and write a report to standard output.

Input handling:
- Standard input contains one URL per line.
- Each line may end with a newline or with end-of-file.
- A line should be ignored only if it is empty after removing trailing `\n` and `\r` characters.
- Every non-ignored line is treated as the URL exactly as entered, including any query string.

Output requirement:
For each URL, in the same order as the input, print exactly one line to standard output. Each output line must contain three fields separated by a single tab character:
1. the URL exactly as it appeared on the input line,
2. a status field,
3. a byte-count field.

The status field must be:
- the HTTP response status code as a decimal integer whenever an HTTP GET request was made,
- `CACHED` when the response body came from a local cache file instead of from a request,
- `ERROR` when the request did not produce a response.

The byte-count field must be:
- the number of bytes in the response body as a decimal integer, or
- `0` for an `ERROR` line.

Each HTTP request must use a connect-and-read timeout of 10 seconds.

Caching requirement:
After a request returns a response, store the response body in a file inside a directory named `body_cache` in the current working directory. Create `body_cache` if it does not already exist.

The cache file name must be derived from the URL as follows:
- replace every character that is not an ASCII letter, an ASCII digit, a hyphen, or an underscore with a single underscore,
- append `.body` to the result.

When processing a URL:
- If the corresponding cache file already exists and its last modification time is less than 600 seconds before the current time, do not make a request for that URL. Instead, print the `CACHED` status line for it, using the size of that cache file as the byte count.
- If the cache file exists but is 600 seconds old or older, make the request as described above and overwrite the cache file with the new response body.

Example session: the second command is run within 600 seconds of the first.

```
$ printf 'https://example.com/\nhttps://example.invalid/x\n' | python fetch_report.py
https://example.com/	200	1256
https://example.invalid/x	ERROR	0

$ printf 'https://example.com/\n' | python fetch_report.py
https://example.com/	CACHED	1256
```
