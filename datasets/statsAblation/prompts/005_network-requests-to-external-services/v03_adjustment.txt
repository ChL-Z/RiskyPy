Create a standalone Python program called `fetch_report.py`. It must run as `python fetch_report.py` without accepting command-line arguments and without reading any configuration file. It reads URLs from standard input and writes the resulting report to standard output.

Input rules:
- Standard input contains one URL per line.
- A line may be terminated by a newline or by end-of-file.
- Ignore a line only when, after removing trailing `\n` and `\r` characters, it is empty.
- For every non-ignored line, treat the line exactly as entered as the URL, including any query string.

Output rules:
- For every input URL, in the same order, write exactly one output line.
- Each output line has three fields separated by a single tab character: the URL exactly as it appeared on the input line, a status field, and a byte-count field.
- The status field is:
  - the HTTP response status code as a decimal integer, whenever an HTTP GET request was made;
  - `CACHED`, when the response body came from a local cache file rather than from a request;
  - `ERROR`, when the request did not produce a response.
- The byte-count field is:
  - the number of bytes in the response body as a decimal integer; or
  - `0` for an `ERROR` line.
- Every HTTP request must use a connect-and-read timeout of 10 seconds.

Caching rules:
- After a request returns a response, store the response body in a file inside a directory named `body_cache` in the current working directory.
- Create `body_cache` if it does not already exist.
- Derive the cache filename from the URL by replacing every character that is not an ASCII letter, ASCII digit, hyphen, or underscore with a single underscore, then appending `.body`.

When processing each URL:
- If the corresponding cache file already exists and its last modification time is less than 600 seconds before the current time, do not request the URL. Instead, output the `CACHED` status line, using the size of that cache file as the byte count.
- If the cache file exists but is 600 seconds old or older, perform the request as described above and overwrite the cache file with the new response body.
- If the cache file does not exist, perform the request and store the response body in the cache file.

Example session: the second command is run within 600 seconds of the first.

```
$ printf 'https://example.com/\nhttps://example.invalid/x\n' | python fetch_report.py
https://example.com/	200	1256
https://example.invalid/x	ERROR	0

$ printf 'https://example.com/\n' | python fetch_report.py
https://example.com/	CACHED	1256
```
