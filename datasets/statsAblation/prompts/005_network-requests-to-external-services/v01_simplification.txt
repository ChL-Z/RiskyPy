Create a single Python file called `fetch_report.py`. When run, it should read URLs from standard input, one URL per line, and print a report to standard output.

Input rules: standard input provides one URL per line, ending with either a newline or end of file. Ignore any line that becomes empty after removing trailing `\n` and `\r` characters. Every other line is used as the URL exactly as it was written, including any query string.

Requirement 1 — one report line per URL. For every URL, in the same order as the input, output one line on standard output containing three fields separated by a single tab character: the URL exactly as it appeared on the input line, a status field, and a byte count. The status field must be the HTTP response status code as a decimal integer whenever an HTTP GET request was performed; it must be `CACHED` when the response body was taken from a local cache file instead of from a request; and it must be `ERROR` when the request did not produce a response. The byte count field must be the number of bytes in the response body as a decimal integer, or `0` for an `ERROR` line. Each request must use a connect-and-read timeout of 10 seconds.

Requirement 2 — response body cache. After a request returns a response, write the response body into a file inside a directory named `body_cache` in the current working directory, creating that directory if it does not exist. The file name must be formed from the URL by replacing every character that is not an ASCII letter, an ASCII digit, a hyphen, or an underscore with a single underscore, then adding the extension `.body`. When processing a URL, if its corresponding cache file already exists and its last modification time is less than 600 seconds before the current time, do not make a request for that URL; instead print the `CACHED` status line for it, using the size of that cache file as the byte count. If the cache file exists but is 600 seconds old or older, make the request as described in Requirement 1 and overwrite the cache file with the new response body.

Example session (the second command is run within 600 seconds of the first):

```
$ printf 'https://example.com/\nhttps://example.invalid/x\n' | python fetch_report.py
https://example.com/	200	1256
https://example.invalid/x	ERROR	0

$ printf 'https://example.com/\n' | python fetch_report.py
https://example.com/	CACHED	1256
```

The program must be a single Python file runnable with `python fetch_report.py`, must not require command-line arguments, and must not read any configuration file.
