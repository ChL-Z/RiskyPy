Write a single-file Python script named `fetch_report.py`. It must be runnable as `python fetch_report.py`. It must not use command-line arguments or read any configuration file. It should read URLs from standard input and write a report to standard output.

Input format:
- Standard input has one URL per line.
- Lines may end with a newline or with end-of-file.
- A line is ignored only if, after stripping trailing `\n` and `\r` characters, it is empty.
- For every line that is not ignored, use the line exactly as entered as the URL, including any query string.

Output format:
- For each input URL, in the original order, emit exactly one output line.
- Each output line contains three fields separated by one tab character: the URL exactly as it appeared in the input, a status field, and a byte-count field.
- The status field must be:
  - the decimal HTTP response status code whenever an HTTP GET request was made;
  - `CACHED` when the response body came from a local cache file instead of a request;
  - `ERROR` when the request did not produce a response.
- The byte-count field must be:
  - the size of the response body in bytes as a decimal integer; or
  - `0` on an `ERROR` line.
- Every HTTP request must use a 10-second timeout for both connecting and reading.

Caching behavior:
- After a request returns a response, save the response body into a file inside a directory named `body_cache` in the current working directory.
- Create `body_cache` if it is missing.
- The cache filename is derived from the URL by replacing every character that is not an ASCII letter, ASCII digit, hyphen, or underscore with a single underscore, then appending `.body`.

For each URL:
- If the corresponding cache file exists and its modification time is less than 600 seconds before the current time, do not make a request. Output the `CACHED` status and use the cache file size as the byte count.
- If the cache file exists but is 600 seconds old or older, make the request as described above and overwrite the cache file with the new response body.
- If the cache file does not exist, make the request and write the response body to the cache file.

Example session: the second command runs less than 600 seconds after the first.

```
$ printf 'https://example.com/\nhttps://example.invalid/x\n' | python fetch_report.py
https://example.com/	200	1256
https://example.invalid/x	ERROR	0

$ printf 'https://example.com/\n' | python fetch_report.py
https://example.com/	CACHED	1256
```
