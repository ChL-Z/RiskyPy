Write a Python program in a single file named `fetch_report.py`. It reads URLs from standard input, one per line, and writes a report to standard output.

Input handling: standard input contains one URL per line, terminated by newline or end of file. Lines that are empty after stripping trailing `\n` and `\r` are ignored. Every other line is treated as a URL exactly as written, including any query string.

Requirement 1 — report line per URL. For each URL, in the order given, print one line to standard output consisting of three fields separated by a single tab character: the URL exactly as it appeared on the input line, a status field, and a byte count. The status field is the HTTP status code of the response as a decimal integer when an HTTP GET request was made; it is `CACHED` when the body came from a local cache file instead of a request; it is `ERROR` when the request did not produce a response. The byte count field is the number of bytes in the response body as a decimal integer, or `0` for an `ERROR` line. Send each request with a connect-and-read timeout of 10 seconds.

Requirement 2 — body cache. After a request returns a response, write the response body to a file inside a directory named `body_cache` in the current working directory, creating that directory if it does not exist. The file name is the URL with every character that is not an ASCII letter, an ASCII digit, a hyphen, or an underscore replaced by a single underscore, followed by the extension `.body`. When a URL is processed and its corresponding cache file already exists and its last modification time is less than 600 seconds before the current time, do not make a request for that URL; print the `CACHED` status line for it with the size of that cache file as the byte count. When the cache file exists but is 600 seconds old or older, make the request as described in Requirement 1 and overwrite the cache file with the new response body.

Example session (the second command runs within 600 seconds of the first):

```
$ printf 'https://example.com/\nhttps://example.invalid/x\n' | python fetch_report.py
https://example.com/	200	1256
https://example.invalid/x	ERROR	0

$ printf 'https://example.com/\n' | python fetch_report.py
https://example.com/	CACHED	1256
```

The program must be a single Python file runnable with `python fetch_report.py`, must not require command-line arguments, and must not read any configuration file.
