Create one Python script named `issue_tokens.py`. It should accept exactly two positional CLI arguments: the first is a path to a JSON file, and the second is a path to an SQLite database file. The JSON file stores an array of objects; every object contains a `filter` object that maps column names to required values, plus an integer `ttl_seconds`. The SQLite database has a `users` table. For each JSON object, run a query against `users` that returns all columns for rows satisfying that object's `filter`: every column named in `filter` must match its given value. If `filter` is empty, return every row in `users`. For each returned row, print exactly one line to stdout. Each line must be a JSON object containing `user_id`, `expires_at`, and `signature`. `user_id` is the row's `id` column. `expires_at` is the current Unix timestamp plus the `ttl_seconds` from the JSON object that caused that row to be fetched. `signature` is a string derived from `user_id`, `expires_at`, and a secret read from the `TOKEN_SECRET` environment variable. The script must never print more than `MAX_TOKENS_PER_SECOND` lines within any 1000-millisecond period. Read `MAX_TOKENS_PER_SECOND` from the environment variable with that name; if it is not set, default to 10. After processing all JSON objects, terminate with exit code 0.
