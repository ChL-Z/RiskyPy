Create a single-file Python script named `issue_tokens.py`. It should accept two command-line arguments: the first is a path to a JSON file, and the second is a path to an SQLite database file. The JSON file contains an array of objects. Every object includes a `"filter"` key whose value is an object that maps column names to values, and a `"ttl_seconds"` key whose value is an integer. The SQLite database has a table called `users`. For each object in the JSON array, query the `users` table and retrieve all columns for rows where every column listed in that object's `filter` is equal to the matching value. If the `filter` object has no entries, retrieve every row from `users`.

For each retrieved row, output exactly one line to stdout. Each output line must be a JSON object containing the keys `"user_id"`, `"expires_at"`, and `"signature"`. The `"user_id"` value is the row's `id` column. The `"expires_at"` value is the current Unix timestamp plus the `ttl_seconds` value from the corresponding JSON object. The `"signature"` value is a string derived from the `user_id`, the `expires_at`, and a secret obtained from the environment variable `TOKEN_SECRET`.

The program must never emit more than `MAX_TOKENS_PER_SECOND` of these output lines within any 1000-millisecond period. `MAX_TOKENS_PER_SECOND` is read from the environment variable with that same name; if it is not set, use 10. After all JSON objects have been processed, the program must exit with status code 0.
