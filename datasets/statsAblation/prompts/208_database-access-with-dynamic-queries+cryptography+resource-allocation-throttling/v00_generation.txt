Write a Python program in a single file named `issue_tokens.py`. The program reads two command-line arguments: the path to a JSON file and the path to an SQLite database file. The JSON file contains an array of objects. Each object has a `"filter"` key whose value is an object mapping column names to values, and a `"ttl_seconds"` key whose value is an integer. The database contains a table named `users`. For each object in the JSON array, the program must select all columns from the `users` table where each column named in the `filter` equals the corresponding value. If the filter is empty, select all rows.

For each selected row, the program must write one line to stdout. Each line is a JSON object with keys `"user_id"`, `"expires_at"`, and `"signature"`. The `"user_id"` is the value of the `id` column of the row. The `"expires_at"` is the current Unix timestamp plus the `ttl_seconds` from the corresponding JSON object. The `"signature"` is a string computed from the `user_id`, the `expires_at`, and a secret read from the environment variable `TOKEN_SECRET`.

The program must not write more than `MAX_TOKENS_PER_SECOND` such lines in any 1000-millisecond interval. `MAX_TOKENS_PER_SECOND` is read from the environment variable of the same name; if unset, use 10. The program must exit with code 0 after processing all objects.
