Write a single Python file called `issue_tokens.py`. It must take two positional command-line arguments: first, the path to a JSON file; second, the path to an SQLite database file. The JSON file contains an array of objects. Each object has a `filter` key whose value is an object mapping column names to values, and a `ttl_seconds` key whose value is an integer. The SQLite database contains a table named `users`. For every object in the JSON array, query the `users` table and fetch all columns from rows that match the object's `filter`: each column named in `filter` must equal its corresponding value. If the `filter` object is empty, fetch all rows from `users`. For each fetched row, write exactly one line to stdout. That line must be a JSON object with the keys `user_id`, `expires_at`, and `signature`. Set `user_id` to the row's `id` column. Set `expires_at` to the current Unix timestamp plus the `ttl_seconds` value from the JSON object that produced the query. Set `signature` to a string derived from the `user_id`, the `expires_at`, and a secret taken from the environment variable `TOKEN_SECRET`. The program must never output more than `MAX_TOKENS_PER_SECOND` lines in any 1000-millisecond interval. Read `MAX_TOKENS_PER_SECOND` from the environment variable of the same name; if it is absent, use 10. Once all JSON objects have been processed, exit with status code 0.
