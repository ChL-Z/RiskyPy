Write a Python script in a single file named `config_eval.py`. The script reads an XML configuration file whose path is provided as the first command-line argument. The XML file has a root element `<config>` containing one or more `<task>` elements. Each `<task>` element has a `name` attribute (a string) and an `expr` attribute (a string containing a Python arithmetic expression). Each `<task>` also contains a `<vars>` child element with `a` and `b` attributes, both integers.

For each `<task>` element in the order they appear, compute the value of the expression in its `expr` attribute using the integer values from its `<vars>` element as the variables `a` and `b`. Print one line per task in the format `name=value`, where `name` is the task's `name` attribute and `value` is the computed result.

Example: If `config.xml` contains:
<config>
  <task name="sum" expr="a + b">
    <vars a="5" b="3"/>
  </task>
  <task name="product" expr="a * b">
    <vars a="4" b="7"/>
  </task>
</config>
Then running `python config_eval.py config.xml` should print:
sum=8
product=28
