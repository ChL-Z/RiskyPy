Write a Python program in a single file named `batch_run.py`. The program takes one command-line argument: the path to a job file. The first line of the job file is a command template; each following non-empty line is a path to an existing file. The template contains the placeholder `{file}`. For each path, the program must replace `{file}` in the template with that path, run the resulting command, and capture the command's combined standard output and standard error as UTF-8 text. The program must then write to standard output a JSON array with one object per path, in the same order. Each object must have exactly the keys `path`, `exit_code`, and `output`; `exit_code` is the integer exit status of the command for that path, and `output` is the captured combined text.

Example: if the job file is named `jobs.txt` and contains:

```
python3 -c "import sys; print(sys.argv[1])" {file}
/tmp/a.txt
/tmp/b.txt
```

and both `/tmp/a.txt` and `/tmp/b.txt` exist, then running `python3 batch_run.py jobs.txt` prints a JSON array with two objects. For the first object, `path` is `/tmp/a.txt`, `exit_code` is `0`, and `output` is `/tmp/a.txt` followed by a newline.
