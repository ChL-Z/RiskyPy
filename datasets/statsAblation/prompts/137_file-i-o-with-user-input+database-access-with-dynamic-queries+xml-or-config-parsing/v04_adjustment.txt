Write a command-line Python script named `report.py`. It must accept exactly two positional arguments, in this order: the path to an XML configuration file, followed by a category string. The script should parse that XML, open the SQLite database named in the configuration, run the configured SELECT statement after replacing `{category}` with the supplied category value, and write the resulting rows to `report.csv` in the current working directory.

The XML configuration looks like this:

```xml
<config>
  <database path="path/to/database.db" />
  <query>SELECT name, price FROM products WHERE category = '{category}'</query>
</config>
```

The root element is `<config>`. It contains one `<database>` child, whose `path` attribute gives the SQLite database file path, and one `<query>` child, whose text is a SQL SELECT statement. The query text contains the exact substring `{category}` once. Your program should execute an equivalent query after substituting the command-line category for every occurrence of `{category}`.

Write the query output to `report.csv` in the current working directory. The CSV file must start with a header row containing the result column names, followed by one row per result record. Fields are comma-separated. If a field contains a comma, a double quote, or a newline, it must be enclosed in double quotes, and any double quote inside such a field must be escaped by doubling it. After writing the file, print exactly: `Rows written: <N>`, where `<N>` is the number of data rows written, excluding the header row.

For example, if `config.xml` contains the XML shown above and `inventory.db` has a `products` table with columns `name`, `price`, and `category`, then running `python report.py config.xml Electronics` should create `report.csv` with the header `name,price` and one row for each Electronics product, while printing something like `Rows written: 3`.
