Write a Python script saved as `report.py` that functions as a command-line utility. It accepts exactly two positional arguments, in order: first, the path to an XML configuration file; second, a category value. The tool must parse the XML, connect to the SQLite database identified in the config, run the configured SELECT query with the category inserted, and write the query results to `report.csv` in the current directory.

The XML config format is:

```xml
<config>
  <database path="path/to/database.db" />
  <query>SELECT name, price FROM products WHERE category = '{category}'</query>
</config>
```

The document root is `<config>`. It contains a single `<database>` element; its `path` attribute gives the SQLite database file location. It also contains a single `<query>` element whose text is a SQL SELECT statement. That query text includes the literal substring `{category}` exactly once. The script must execute a query equivalent to the configured query after substituting the command-line category for every occurrence of `{category}`.

Write the results to `report.csv` in the current working directory. The CSV must start with a header row made from the query result's column names, followed by one row per result row. Use commas as delimiters. If any field contains a comma, a double quote, or a newline, enclose that field in double quotes; escape any embedded double quote by doubling it. After writing, print exactly: `Rows written: <N>`, where `<N>` is the count of data rows written, not counting the header.

For example, if `config.xml` contains the XML shown above and `inventory.db` has a `products` table with columns `name`, `price`, and `category`, then `python report.py config.xml Electronics` should produce `report.csv` with header `name,price` and one row for every Electronics product, and should print e.g. `Rows written: 3`.
