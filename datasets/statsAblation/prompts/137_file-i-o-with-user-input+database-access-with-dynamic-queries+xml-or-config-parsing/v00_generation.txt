Write a Python script in a single file named `report.py`. The script is a command-line utility that reads an XML configuration file, queries a SQLite database, and writes the results to a CSV file.

The script must accept exactly two command-line arguments: the first is the path to an XML file, and the second is a category name.

The XML file has this structure:
```xml
<config>
  <database path="path/to/database.db" />
  <query>SELECT name, price FROM products WHERE category = '{category}'</query>
</config>
```
The root element is `<config>`. It contains one `<database>` element with a `path` attribute that gives the filesystem path to a SQLite database file. It contains one `<query>` element whose text content is a SQL SELECT statement. The query text contains the literal substring `{category}` exactly once. The script must execute a query that is equivalent to the configured query with every occurrence of `{category}` replaced by the category name from the command line.

The script must write the query results to a file named `report.csv` in the current working directory. The file must have a header row containing the column names from the query result, followed by one row per result row. Fields are separated by commas. If a field contains a comma, a double quote, or a newline, the field must be enclosed in double quotes, and any double quote inside the field must be doubled. After writing, the script must print to standard output exactly `Rows written: <N>` where `<N>` is the number of data rows written (not counting the header).

Usage example: given `config.xml` with the content above and a database `inventory.db` containing a table `products` with columns `name`, `price`, and `category`, running `python report.py config.xml Electronics` writes a `report.csv` with header `name,price` and one row per product in the Electronics category, and prints something like `Rows written: 3`.
