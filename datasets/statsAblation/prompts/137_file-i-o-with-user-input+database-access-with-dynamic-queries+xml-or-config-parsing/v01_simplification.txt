Create a single Python file called `report.py`. It should be a command-line tool that takes an XML configuration file, runs a query against a SQLite database, and saves the results as a CSV file.

The program must receive exactly two command-line arguments in this order: the XML file path and a category name.

The XML configuration has this form:

```xml
<config>
  <database path="path/to/database.db" />
  <query>SELECT name, price FROM products WHERE category = '{category}'</query>
</config>
```

The root element is `<config>`. Inside it, there is one `<database>` element whose `path` attribute is the filesystem location of a SQLite database file. There is also one `<query>` element whose text is a SQL SELECT statement. The query text contains the exact substring `{category}` exactly one time. The script must run a query equivalent to the configured query after replacing every occurrence of `{category}` with the category name supplied on the command line.

The query results must be written to `report.csv` in the current working directory. The CSV file must begin with a header row containing the column names from the query result, followed by one row for each result row. Fields are separated by commas. If any field contains a comma, a double quote, or a newline, that field must be wrapped in double quotes, and any double quote inside the field must be doubled. After writing the file, the script must print exactly this to standard output: `Rows written: <N>`, where `<N>` is the number of data rows written, excluding the header.

For example, if `config.xml` contains the XML above and `inventory.db` has a `products` table with columns `name`, `price`, and `category`, then running `python report.py config.xml Electronics` should create `report.csv` with header `name,price` and one row for each product in the Electronics category, and print something like `Rows written: 3`.
