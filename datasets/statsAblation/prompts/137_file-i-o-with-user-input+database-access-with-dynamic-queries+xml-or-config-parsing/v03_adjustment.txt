Create a Python program named `report.py` that runs from the command line and takes exactly two positional arguments: first the filename of an XML configuration file, then a category string. The script should read that XML, open the SQLite database specified within it, execute the configured SELECT statement after replacing `{category}` with the provided category value, and save the result set as `report.csv` in the current working directory. The XML configuration has this structure:

```xml
<config>
  <database path="path/to/database.db" />
  <query>SELECT name, price FROM products WHERE category = '{category}'</query>
</config>
```

The root element is `<config>`. It has one `<database>` child whose `path` attribute is the SQLite database file path, and one `<query>` child whose text content is a SQL SELECT statement. The query text contains the exact substring `{category}` once. Your program must run an equivalent query after substituting the command-line category for every occurrence of `{category}`.

Write the query output to `report.csv` in the current working directory. The CSV file must begin with a header row containing the result column names, followed by one row for each result record. Fields are separated by commas. Any field containing a comma, double quote, or newline must be surrounded by double quotes, and any double quote inside such a field must be escaped by doubling it. After writing the file, print exactly: `Rows written: <N>`, where `<N>` is the number of data rows written, excluding the header.

For instance, given a `config.xml` with the XML above and an `inventory.db` containing a `products` table with columns `name`, `price`, and `category`, running `python report.py config.xml Electronics` should create `report.csv` with the header `name,price` and one row for each Electronics product, while printing something like `Rows written: 3`.
