Write a Python 3 script named `run_jobs.py` that is contained in a single file.

The script must accept exactly two command-line arguments: a path to a SQLite database file and a table name.

The specified table contains columns `id` (integer), `command` (text), `status` (text), and `exit_code` (integer). Rows with `status` equal to `'pending'` are to be processed.

For each row in the specified table where `status` is `'pending'`, the script must:
- Run the command string stored in the `command` column as an external shell command.
- After the command finishes, update the row so that `status` becomes `'done'` and `exit_code` is set to the exit code of the command.
- Print a line to stdout in the format `job {id}: {exit_code}`, where `{id}` is the value of the `id` column and `{exit_code}` is the integer exit code.

The script must process all such rows in the order they are returned from reading the table.

Usage example:
Given a SQLite database file `jobs.db` containing a table `tasks` with one row: `id=1`, `command='echo hello'`, `status='pending'`, `exit_code=NULL`, running `python run_jobs.py jobs.db tasks` must print `job 1: 0` and update that row to `status='done'` and `exit_code=0`.
