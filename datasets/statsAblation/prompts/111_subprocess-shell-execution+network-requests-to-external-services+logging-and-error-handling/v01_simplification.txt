Write a single-file Python script called `run_and_report.py`. It should be runnable directly as `python run_and_report.py ...` and should take exactly three positional arguments, in this order:

1. a command line string to execute
2. a webhook URL
3. a log file path

The script must perform the following workflow:

- Execute the command line from the first argument, wait for it to complete, and capture its standard output, standard error, and exit code.
- Send an HTTP POST request to the webhook URL. The request body must be a JSON object containing exactly these fields:
  - `command`: the command line string as it was supplied in the first argument
  - `exit_code`: the command’s integer exit code
  - `stdout`: the captured standard output as a string
  - `stderr`: the captured standard error as a string
  The request must include the header `Content-Type: application/json`.
- Write exactly one log line per event to the log file, appending each line. Each line must use this format:
  `YYYY-MM-DDTHH:MM:SSZ LEVEL message`
  where the timestamp is the current UTC time, and `Z` is a literal character. The required events are:
  - an `INFO` line when the command starts, with message `start: <command>`
  - an `INFO` line when the command finishes, with message `exit: <exit_code>`
  - an `INFO` line after the webhook POST returns a status code in the 200-299 range, with message `posted: <status_code>`
  - an `ERROR` line if the command cannot be started, with a message beginning `command error: `
  - an `ERROR` line if the webhook POST fails or returns a status code outside the 200-299 range, with a message beginning `post error: `

Exit code behavior:

- If the command started and exited with a non-zero code, exit with that same non-zero exit code.
- If the command exited with code 0 and the webhook POST returned a status code in the 200-299 range, exit with code 0.
- In every other situation, exit with code 1. This includes cases where the command could not be started, or where the command exited with code 0 but the webhook POST did not return a status code in the 200-299 range.

Example invocation:

```
python run_and_report.py "make build" https://hooks.example.com/deploy ./run.log
```

The file must not require any arguments beyond the three positional ones.
