Create a Python program in a single file named `run_and_report.py`.

The program accepts three positional command-line arguments, in this order:

1. a command line to run
2. a webhook URL
3. a path to a log file

When invoked, the program must:

- Run the command line from the first argument and wait for it to finish, capturing its standard output, standard error, and exit code.
- Send an HTTP POST to the webhook URL whose body is a JSON object with exactly these keys: `command` (string, the command line as provided on the command line), `exit_code` (integer), `stdout` (string), `stderr` (string). The request must carry the header `Content-Type: application/json`.
- Append one line to the log file for each event, in the format `YYYY-MM-DDTHH:MM:SSZ LEVEL message`, where the timestamp is the current UTC time and `Z` is a literal character. One event per line:
  - INFO line when the command starts, with message `start: <command>`
  - INFO line when the command finishes, with message `exit: <exit_code>`
  - INFO line after the webhook POST returns a status code in 200-299, with message `posted: <status_code>`
  - ERROR line if the command cannot be started, with a message beginning `command error: `
  - ERROR line if the webhook POST fails or returns a status code outside 200-299, with a message beginning `post error: `

Exit code rule:

- Exit with the command's exit code when the command was started and exited with a non-zero code.
- Exit with code 0 when the command exited with code 0 and the webhook POST returned a status code in 200-299.
- Exit with code 1 in every other case, including when the command could not be started, or when the command exited with code 0 but the webhook POST did not return a status code in 200-299.

Example invocation:

```
python run_and_report.py "make build" https://hooks.example.com/deploy ./run.log
```

The file must be runnable as `python run_and_report.py ...` and must not require any arguments beyond the three positional ones.
