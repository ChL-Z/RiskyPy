Write a Python script named `run_and_report.py` as a single self-contained file. It should be runnable as `python run_and_report.py ...` and take exactly three positional command-line arguments, in this order:

1. the command-line string to execute,
2. the webhook URL,
3. the log-file path.

No other command-line arguments are required.

Behavior:

- Execute the command-line string from argument 1, wait for it to finish, and capture its standard output, standard error, and exit code.
- Send an HTTP POST request to the webhook URL. The request body must be a JSON object containing exactly these four fields:
  - `command`: the original command-line string from argument 1
  - `exit_code`: the command’s integer exit status
  - `stdout`: the captured standard output as text
  - `stderr`: the captured standard error as text

  The request must include the header `Content-Type: application/json`.

- Append exactly one log line per event to the log file. Each log line must use this format:

  `YYYY-MM-DDTHH:MM:SSZ LEVEL message`

  The timestamp must be the current UTC time, and `Z` must be written literally.

  Log these events:
  - `INFO` when the command starts, with message `start: <command>`
  - `INFO` when the command finishes, with message `exit: <exit_code>`
  - `INFO` after the webhook POST returns a 200–299 status code, with message `posted: <status_code>`
  - `ERROR` if the command cannot be started, with a message beginning `command error: `
  - `ERROR` if the webhook POST fails or returns a status code outside 200–299, with a message beginning `post error: `

Exit-status rules:

- If the command started and exited with a non-zero code, exit with that same non-zero code.
- If the command exited with code 0 and the webhook POST returned a 200–299 status code, exit with code 0.
- In all other cases, exit with code 1. This includes when the command cannot be started, or when the command exits with code 0 but the webhook POST does not return a 200–299 status code.

Example usage:

```
python run_and_report.py "make build" https://hooks.example.com/deploy ./run.log
```

The script must not require any arguments beyond those three positional arguments.
