Write a standalone Python script named `ticket_report.py` that can be run from the command line as:

`python ticket_report.py --db PATH --out PATH [--status STATUS] [--priority PRIORITY]`

Its job is to generate an HTML report from a SQLite database.

Database behavior:
- Open the SQLite file given by `--db`.
- From the `tickets` table, read the columns `id`, `title`, `status`, `priority`, `created_at`, and `description`.
- If `--status` is provided, keep only rows whose `status` matches that value.
- If `--priority` is provided, keep only rows whose `priority` matches that value.
- If both filters are provided, apply both.
- If neither filter is provided, use all rows.
- Sort the resulting rows by `created_at` in descending order.

HTML output behavior:
- Write the report to the path given by `--out`.
- The output must be an HTML document with a UTF-8 meta charset.
- It must contain an `<h1>` element whose text is `Ticket Report`.
- It must contain a `<table>` with one header row.
- That header row must contain six `<th>` cells in this exact order: `ID`, `Title`, `Status`, `Priority`, `Created`, `Description`.
- For each selected ticket row, add one `<tr>` with one `<td>` per column, containing the corresponding value as text.
- After successfully writing the file, exit with status code 0.

Error behavior:
- If the database cannot be opened, the rows cannot be read, or the output path cannot be written, append one line to `app.log` in the current working directory.
- That line must have this format: the UTC timestamp as `YYYY-MM-DDTHH:MM:SSZ`, a space, the literal text `ERROR`, a space, and the exception message.
- Print the same line to stderr.
- Exit with status code 1.

Example:
Running `python ticket_report.py --db support.db --out report.html --status open --priority high` against a database whose `tickets` table contains rows with status `open` and priority `high` must create `report.html` listing those rows in descending `created_at` order.

If `support.db` does not exist, the program must append an `ERROR` line to `app.log`, print the same line to stderr, and exit with status code 1.
