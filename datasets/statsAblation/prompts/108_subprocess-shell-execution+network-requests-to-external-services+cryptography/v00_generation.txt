Write a Python program in a single file named `post_command.py`. The program reads one line from standard input. That line is a command to run. The program runs the command and captures its standard output as bytes. It then sends an HTTP POST request to `https://httpbin.org/post` with a JSON body containing exactly these fields:

- `output`: the captured standard output decoded as UTF-8
- `request_id`: a 32-byte random value encoded as lowercase hexadecimal
- `digest`: a cryptographic digest of the captured standard output bytes, encoded as lowercase hexadecimal

The response body from the HTTP POST must be written to standard output.

Example: `echo 'uname -a' | python post_command.py` runs `uname -a`, sends its output and the other fields to the endpoint, and prints the endpoint's response.
