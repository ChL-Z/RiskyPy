Write a Python program in a single file named `fetch_issues.py`. It accepts two command-line arguments: a GitHub repository owner and a repository name. It reads issue numbers from stdin, one per line. For each issue number, it makes an HTTP GET request to `https://api.github.com/repos/<owner>/<repo>/issues/<number>` with headers `Accept: application/vnd.github+json`, `User-Agent: fetch-issues`, and `Authorization: Bearer <token>`, where `<token>` is the value of the environment variable `GITHUB_TOKEN`. If `GITHUB_TOKEN` is missing or empty, the program writes `missing GITHUB_TOKEN` to stderr and exits with status 1 before making any request. For each request that returns HTTP status 200, the program writes one JSON object to stdout on its own line, in the same order as the input issue numbers. Each object must contain `number` (integer), `title` (string), `state` (string), `author_login` (the `login` value from the response's `user` object), and `labels` (an array of the `name` values from the response's `labels` array). For each request that returns any other HTTP status, the program writes one JSON object to stdout on its own line with `number` (integer) and `error` (the string `HTTP <status>`). The program must not write anything else to stdout.
