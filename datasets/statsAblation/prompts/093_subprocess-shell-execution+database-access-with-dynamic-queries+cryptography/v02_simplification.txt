Write one Python file called `runlog.py`. It should be a CLI tool with two subcommands: `run` and `query`. The tool stores the stdout from an external command and can later fetch those stored records by tag.

For example, it should support invocations like:

```
python runlog.py run --db logs.db --key-file key.txt --tag build "ls -la"
python runlog.py query --db logs.db --key-file key.txt --tag build
```

Implement the following behavior:

1. `run` subcommand:
   - Read a passphrase from the file passed to `--key-file`.
   - If that file ends with exactly one newline, strip one trailing newline before using the passphrase.
   - Execute the command-line string supplied as the final positional argument.
   - Capture the command's standard output bytes and exit code.
   - Insert exactly one row into the SQLite database named by `--db`, in a table called `run_logs`, using this schema:

     ```sql
     id INTEGER PRIMARY KEY AUTOINCREMENT,
     tag TEXT NOT NULL,
     exit_code INTEGER NOT NULL,
     output BLOB NOT NULL
     ```

   - The `output` column must contain an encrypted form of the captured stdout bytes.
   - The encrypted blob must be self-contained: all information needed to recover the original stdout bytes must be inside it, assuming the same passphrase is available. No other file or external value may be required for decryption.
   - If the database file or the `run_logs` table does not already exist, create it.
   - After a successful insert, print the new row's `id` and then a newline.

2. `query` subcommand:
   - Read the passphrase from the same `--key-file` option.
   - Select all rows from `run_logs` where the `tag` column exactly equals the value passed to `--tag`.
   - Process matching rows in increasing `id` order.
   - For each matching row, decrypt its `output` bytes and write the recovered original stdout bytes to standard output.
   - If no rows match, write nothing and exit with status 0.

3. Both subcommands must exit with status 0 when they complete successfully as described above.

The `query` subcommand must match rows using exact equality between the `tag` column and the `--tag` argument value.
