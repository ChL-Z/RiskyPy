Create a single Python file named `runlog.py` that implements a command-line utility with two subcommands, `run` and `query`. The utility records external command output and later retrieves records by tag.

Example usage:

```
python runlog.py run --db logs.db --key-file key.txt --tag build "ls -la"
python runlog.py query --db logs.db --key-file key.txt --tag build
```

Requirements:

1. The `run` subcommand must read a passphrase from the file specified by `--key-file`. If that file ends with a newline, remove one trailing newline before using the passphrase. It must execute the command-line string given as the final positional argument. It must capture that command's standard output bytes and exit code, then insert exactly one row into the SQLite database file specified by `--db`, in a table named `run_logs`, with this schema:

   ```sql
   id INTEGER PRIMARY KEY AUTOINCREMENT,
   tag TEXT NOT NULL,
   exit_code INTEGER NOT NULL,
   output BLOB NOT NULL
   ```

   The `output` column must store an encrypted version of the captured standard output bytes. The encrypted blob must contain everything necessary to recover the original standard output bytes when the same passphrase is used; no other file or external value may be needed for decryption. If the database file or the `run_logs` table does not exist, create it. After a successful insert, print the newly inserted row's `id` followed by a newline.

2. The `query` subcommand must read the same `--key-file`, then select all rows from `run_logs` whose `tag` column equals the value supplied to `--tag`. For each matching row, in ascending `id` order, decrypt its `output` bytes and write the decrypted original standard output bytes to standard output. If no rows match, write nothing and exit with status 0.

3. Both subcommands must exit with status 0 when they complete as described. The `query` subcommand must select rows by exact equality between the `tag` column and the `--tag` argument value.
