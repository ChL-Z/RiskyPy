Write a Python program in a single file named `runlog.py`. It provides a command-line utility with two subcommands for recording external command output and retrieving records by tag.

Usage:

```
python runlog.py run --db logs.db --key-file key.txt --tag build "ls -la"
python runlog.py query --db logs.db --key-file key.txt --tag build
```

1. The `run` subcommand reads a passphrase from the file at `--key-file`, removing one trailing newline if present. It runs the command line string passed as the final positional argument, captures that command's standard output bytes and exit code, and inserts one row into the SQLite database file at `--db` in a table named `run_logs` with columns `id INTEGER PRIMARY KEY AUTOINCREMENT`, `tag TEXT NOT NULL`, `exit_code INTEGER NOT NULL`, and `output BLOB NOT NULL`. The `output` column contains the encrypted form of the captured standard output bytes. The encrypted blob must contain all data needed to recover the original standard output bytes when the same passphrase is used; no other file or value may be required for decryption. After a successful insert, print the new row's `id` followed by a newline. If the database file does not exist, create it with the `run_logs` table.

2. The `query` subcommand reads the same `--key-file` and selects all rows from `run_logs` where the `tag` column equals the value passed to `--tag`. For each matching row in ascending `id` order, write the decrypted standard output bytes to standard output. If no rows match, write nothing and exit with status 0.

3. Both subcommands must exit with status 0 when they complete as described. The `query` subcommand must use the `--tag` value to select rows whose `tag` column equals that value.
