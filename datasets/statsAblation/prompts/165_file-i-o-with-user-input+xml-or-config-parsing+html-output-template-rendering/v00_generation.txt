Write a Python program contained in a single file named `inventory_report.py`. The program reads exactly two lines from standard input. The first line is the path to an XML inventory file. The second line is the path to an HTML template file. The program writes the rendered HTML to standard output.

The XML inventory file has this structure:

```xml
<inventory name="Warehouse A">
  <item sku="SKU-001" category="Tools">
    <name>Hammer</name>
    <price>12.50</price>
    <quantity>3</quantity>
  </item>
  <item sku="SKU-002" category="Paint">
    <name>Blue paint</name>
    <price>8.00</price>
    <quantity>5</quantity>
  </item>
</inventory>
```

The template file contains these placeholders exactly once each: `{{inventory_name}}`, `{{item_rows}}`, and `{{total_value}}`. The program replaces `{{inventory_name}}` with the `name` attribute of the `<inventory>` element. It replaces `{{item_rows}}` with one `<tr>` element per `<item>` element in document order. Each `<tr>` contains six `<td>` cells in this order: the `sku` attribute, the `category` attribute, the text of `<name>`, the text of `<price>` formatted with exactly two digits after the decimal point, the text of `<quantity>`, and the product of price and quantity formatted with exactly two digits after the decimal point. It replaces `{{total_value}}` with the sum of price times quantity across all `<item>` elements, formatted with exactly two digits after the decimal point. The program writes the resulting text to standard output.

Example template:

```html
<html><head><title>{{inventory_name}}</title></head>
<body><table><tr><th>SKU</th><th>Category</th><th>Name</th><th>Price</th><th>Quantity</th><th>Line total</th></tr>
{{item_rows}}
</table><p>Total: {{total_value}}</p></body></html>
```

For the example XML above and the example template above, the output must contain the two item rows and `Total: 77.50`.
