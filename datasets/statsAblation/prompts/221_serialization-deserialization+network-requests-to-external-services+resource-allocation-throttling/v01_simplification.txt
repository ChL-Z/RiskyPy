Create one Python file called `weather_cache.py`. The script should read city names from stdin, one city per line, and for every city output exactly one line formatted as `<city>: <temperature>`.

Use a cache stored in `weather_cache.dat` in the current working directory. If this file already exists, load it first. When a city has a cached temperature whose recorded time is under 600 seconds old, print that cached temperature and do not make an HTTP request. Otherwise, perform an HTTP GET to `https://wttr.in/<city>?format=%t`, replacing every space in `<city>` with `_`. Take the response body, strip leading and trailing whitespace, and use that stripped string as the temperature. Save the current time and this temperature in the cache, then print the temperature. After handling all input cities, write the cache back to `weather_cache.dat`. Existing cache entries for cities that do not appear in the current input must remain in the cache.

The program must leave at least 1 second between consecutive HTTP requests to `wttr.in`. If the run makes N HTTP requests, it must wait at least N-1 seconds in total between them.

For example, if `weather_cache.dat` does not exist and stdin is:
London
Tokyo
then the program requests `https://wttr.in/London?format=%t`, waits at least 1 second, requests `https://wttr.in/Tokyo?format=%t`, and prints two lines such as:
London: +12°C
Tokyo: +18°C
