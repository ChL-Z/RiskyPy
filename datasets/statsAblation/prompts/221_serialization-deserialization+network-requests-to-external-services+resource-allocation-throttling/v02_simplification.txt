Write exactly one Python file named `weather_cache.py`. Its job is to process city names from standard input, where each line contains one city name, and for each city it must print a single line in the form `<city>: <temperature>`.

Use a persistent cache in the current working directory named `weather_cache.dat`. If that file is present, load its contents before processing. For a city whose cached temperature has a timestamp less than 600 seconds old, simply print the cached temperature and do not issue an HTTP request. Otherwise, send an HTTP GET request to `https://wttr.in/<city>?format=%t`, after replacing all spaces in `<city>` with underscores. The response body, with leading and trailing whitespace removed, becomes the temperature string. Then store the current time together with that temperature in the cache and print the temperature. Once all input cities have been handled, save the updated cache back to `weather_cache.dat`. Any cache entries for cities not present in the current input must be preserved.

The program must ensure that consecutive HTTP requests to `wttr.in` are separated by at least 1 second. In other words, if it performs N HTTP requests, the total waiting time between those requests must be at least N-1 seconds.

For instance, if `weather_cache.dat` does not exist and stdin is:
London
Tokyo
then the program should request `https://wttr.in/London?format=%t`, wait at least 1 second, request `https://wttr.in/Tokyo?format=%t`, and produce two lines such as:
London: +12°C
Tokyo: +18°C
