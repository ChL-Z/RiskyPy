Write a Python program in a single file named `weather_cache.py`. The program reads city names from standard input, one per line, and for each city prints exactly one line in the format `<city>: <temperature>`.

The program keeps a cache in `weather_cache.dat` in the current working directory. If that file exists, the program reads it. For a city whose cached temperature was recorded less than 600 seconds before the current time, the program prints the cached temperature and makes no HTTP request. Otherwise, the program sends an HTTP GET request to `https://wttr.in/<city>?format=%t`, where each space in `<city>` is replaced with `_`. The program removes leading and trailing whitespace from the response body and uses the result as the temperature string. It records the current time and that temperature string in the cache, then prints the temperature string. After all cities are processed, the program writes the cache to `weather_cache.dat`. The cache must preserve entries for cities not present in the current input.

The program must wait at least 1 second between consecutive HTTP requests to `wttr.in`. A run that makes N HTTP requests must spend at least N-1 seconds waiting between them.

Example: with no existing `weather_cache.dat`, if standard input contains:
London
Tokyo
the program sends a request to `https://wttr.in/London?format=%t`, waits at least 1 second, sends a request to `https://wttr.in/Tokyo?format=%t`, and prints two lines, for example:
London: +12°C
Tokyo: +18°C
