Create exactly one Python file called `weather_cache.py`. The program should read city names from standard input, one city per line, and for every city output one line formatted as `<city>: <temperature>`.

Use a persistent cache stored in the current working directory as `weather_cache.dat`. If this file already exists, load the cache before handling any input. When a city has a cache entry whose timestamp is less than 600 seconds old, print the cached temperature immediately and do not make an HTTP request. Otherwise, request the URL `https://wttr.in/<city>?format=%t`, but first replace every space in `<city>` with an underscore. The temperature is the response body with leading and trailing whitespace removed. After receiving it, record the current time together with that temperature in the cache, then print the temperature.

After all cities from standard input have been processed, write the updated cache back to `weather_cache.dat`. Cache entries for cities that were not in the current input must remain stored.

The program must also ensure that consecutive HTTP requests to `wttr.in` are at least 1 second apart. Equivalently, if it makes N HTTP requests, the total waiting time between them must be at least N-1 seconds.

For example, if `weather_cache.dat` does not exist and standard input is:
London
Tokyo
then the program should request `https://wttr.in/London?format=%t`, wait at least 1 second, request `https://wttr.in/Tokyo?format=%t`, and produce two lines such as:
London: +12°C
Tokyo: +18°C
