Write a single Python file named `render.py` that can be executed from the shell as:

```
python render.py <data.json> <template.txt> <output.txt>
```

The script must implement a template renderer with the following behavior.

## 1. Load the input files

- Read `<data.json>` using UTF-8 encoding and decode it as a JSON object.
- The JSON object maps string names to numeric values.
- Read `<template.txt>` using UTF-8 encoding as plain text.

## 2. Process the template

Placeholders in the template are any spans delimited by `{{` and `}}`.

Inside each placeholder is an arithmetic expression. Allowed expression components are:

- decimal number literals
- `+`, `-`, `*`, `/`
- parentheses
- names that are keys in the JSON data object

A name evaluates to the numeric value associated with that key in the JSON object.

Each placeholder must be replaced by the evaluated result of its expression, formatted in this specific way:

1. Round half away from zero to at most 6 digits after the decimal point.
2. Remove trailing zeros after the decimal point.
3. Remove a trailing decimal point if one remains.

Examples:

- `10` becomes `10`
- `0.5` becomes `0.5`
- `1/3` becomes `0.333333`

All characters outside placeholders must be copied exactly unchanged.

Write the final rendered text to `<output.txt>` using UTF-8 encoding.

## 3. Create a manifest

Also create a manifest file by appending `.manifest.json` to the full `<output.txt>` path string. For example, if `<output.txt>` is `out/report.txt`, the manifest path must be `out/report.txt.manifest.json`.

The manifest must be a JSON object with exactly these three keys:

- `"template"`: the exact `<template.txt>` argument string as it appeared on the command line.
- `"byte_count"`: the number of bytes written to `<output.txt>`.
- `"digest"`: a hexadecimal string derived from the bytes written to `<output.txt>`, such that identical output bytes always produce the same digest and different output bytes produce different digests.

## Example

If `data.json` contains:

```json
{"width": 4, "height": 2.5}
```

and `template.txt` contains:

```
area={{width * height}}
```

with a trailing newline, then running:

```
python render.py data.json template.txt output.txt
```

must produce `output.txt` containing:

```
area=10
```

with a trailing newline. The file `output.txt.manifest.json` must contain a JSON object whose `"template"` is `"template.txt"`, whose `"byte_count"` is `7`, and whose `"digest"` is a hexadecimal digest value.
