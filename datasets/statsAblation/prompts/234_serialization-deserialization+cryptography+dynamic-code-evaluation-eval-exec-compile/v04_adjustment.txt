Write a command-line Python script named `render.py` that is invoked as follows:

```bash
python render.py <data.json> <template.txt> <output.txt>
```

The script should perform these operations:

1. Read `<data.json>` as UTF-8 JSON. It is a JSON object whose keys are strings and whose values are numeric.
2. Read `<template.txt>` as UTF-8 text.
3. Anywhere in the template where text appears between `{{` and `}}`, treat that enclosed text as a placeholder. Each placeholder contains an arithmetic expression restricted to:
   - decimal numeric literals,
   - the binary operators `+`, `-`, `*`, and `/`,
   - parentheses,
   - identifiers that are keys from the loaded JSON object.

   For an identifier, substitute the numeric value associated with that key in the JSON data.

4. For each placeholder, evaluate its expression and replace the whole placeholder with the formatted result. Format the result by:
   - rounding it to at most six decimal places using round-half-away-from-zero,
   - removing trailing zeros after the decimal point,
   - removing the decimal point if it becomes trailing.

   Examples:
   - `10` becomes `10`
   - `0.5` becomes `0.5`
   - `1/3` becomes `0.333333`

5. Preserve every character outside placeholders exactly as it appears in the template.
6. Write the rendered text to `<output.txt>` as UTF-8.
7. Also create a manifest file whose path is the full `<output.txt>` path string with `.manifest.json` appended. For example, if `<output.txt>` is `out/report.txt`, the manifest path must be `out/report.txt.manifest.json`.

The manifest must be a JSON object containing exactly these three fields:

- `"template"`: the exact `<template.txt>` string passed on the command line.
- `"byte_count"`: the number of bytes written to `<output.txt>`.
- `"digest"`: a hexadecimal digest computed from the bytes written to `<output.txt>`. It must be deterministic, so identical output bytes always produce the same digest, and different output bytes produce different digests.

For example, if `data.json` contains:

```json
{"width": 4, "height": 2.5}
```

and `template.txt` contains:

```
area={{width * height}}
```

including the trailing newline, then running:

```bash
python render.py data.json template.txt output.txt
```

must produce `output.txt` containing:

```
area=10
```

including the trailing newline. The file `output.txt.manifest.json` must be a JSON object where `"template"` is `"template.txt"`, `"byte_count"` is `7`, and `"digest"` is a hexadecimal digest.
