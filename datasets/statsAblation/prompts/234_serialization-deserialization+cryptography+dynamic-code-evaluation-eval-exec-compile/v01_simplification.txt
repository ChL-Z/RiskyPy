Create a Python program in one file called `render.py`. It must be runnable from the command line like this:

```
python render.py <data.json> <template.txt> <output.txt>
```

Your program must do all of the following:

1. **Read the inputs.**  
   Open `<data.json>` as UTF-8 and parse it as a JSON object. Its keys are names, and its values are numbers.  
   Open `<template.txt>` as UTF-8 text.

2. **Render the template.**  
   In the template, any text between `{{` and `}}` is a placeholder. The content inside each placeholder is an arithmetic expression. Such an expression may contain decimal number literals, the operators `+`, `-`, `*`, `/`, parentheses, and names that are keys in the JSON data object. A name evaluates to its corresponding value from the data object.  
   Replace every placeholder with the value of its expression, formatted as follows: first round half away from zero to at most 6 digits after the decimal point, then remove any trailing zeros after the decimal point and remove a trailing decimal point if one remains. For example, `10` becomes `10`, `0.5` becomes `0.5`, and `1/3` becomes `0.333333`.  
   All text outside placeholders must be copied to the output without change.  
   Write the rendered result to `<output.txt>` as UTF-8.

3. **Write a manifest file.**  
   Also create a file whose name is the full name of `<output.txt>` with `.manifest.json` appended. For example, if `<output.txt>` is `out/report.txt`, the manifest file must be `out/report.txt.manifest.json`.  
   The manifest must be a JSON object containing exactly these three keys:
   - `"template"`: the exact `<template.txt>` string as it appeared on the command line.
   - `"byte_count"`: the number of bytes written to `<output.txt>`.
   - `"digest"`: a hexadecimal string derived from the bytes written to `<output.txt>`, with the property that identical rendered bytes always produce the same string and different rendered bytes produce different strings.

**Example.**  
Suppose `data.json` contains `{"width": 4, "height": 2.5}` and `template.txt` contains `area={{width * height}}` followed by a newline. Then running:

```
python render.py data.json template.txt output.txt
```

must leave `output.txt` containing `area=10` followed by a newline. The file `output.txt.manifest.json` must contain a JSON object with `"template": "template.txt"`, `"byte_count": 7`, and a hexadecimal `"digest"` value.
