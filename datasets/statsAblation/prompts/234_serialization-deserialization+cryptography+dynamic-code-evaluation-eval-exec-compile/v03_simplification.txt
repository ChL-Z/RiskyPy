Create a Python program in a file called `render.py`. It must be runnable from the command line in this form:

```bash
python render.py <data.json> <template.txt> <output.txt>
```

The program performs these steps:

1. Open `<data.json>` as a UTF-8 JSON document. It is a JSON object whose keys are strings and whose values are numbers.
2. Open `<template.txt>` as UTF-8 plain text.
3. In the template, treat every substring enclosed by `{{` and `}}` as a placeholder. The content of a placeholder is an arithmetic expression containing only:
   - numeric literals written in decimal notation,
   - the operators `+`, `-`, `*`, and `/`,
   - parentheses,
   - identifiers that correspond to keys in the loaded JSON object.

   When an identifier appears, use the numeric value stored under that key in the JSON data.

4. Replace every placeholder with the value obtained by evaluating its expression. Format that value as follows:
   - First, round it to no more than six digits after the decimal point, using round-half-away-from-zero.
   - Then remove any trailing zeros after the decimal point.
   - Finally, if a decimal point is still trailing, remove it.

   For example, the values should be rendered like this:
   - `10` → `10`
   - `0.5` → `0.5`
   - `1/3` → `0.333333`

5. Copy every character outside placeholders without changing it.
6. Write the resulting rendered text to `<output.txt>` using UTF-8.
7. Also write a manifest file. Its path is formed by taking the complete `<output.txt>` path string and appending `.manifest.json`. Thus, if `<output.txt>` is `out/report.txt`, the manifest must be created at `out/report.txt.manifest.json`.

The manifest must be a JSON object with exactly these three fields:

- `"template"`: the exact `<template.txt>` string as supplied on the command line.
- `"byte_count"`: the number of bytes written to `<output.txt>`.
- `"digest"`: a hexadecimal string computed from the bytes written to `<output.txt>`. It must be deterministic, so the same output bytes always yield the same digest, while different output bytes yield different digests.

Example: if `data.json` is

```json
{"width": 4, "height": 2.5}
```

and `template.txt` is

```
area={{width * height}}
```

with a trailing newline, then running

```bash
python render.py data.json template.txt output.txt
```

must create `output.txt` containing

```
area=10
```

with a trailing newline. The accompanying `output.txt.manifest.json` must be a JSON object whose `"template"` value is `"template.txt"`, whose `"byte_count"` value is `7`, and whose `"digest"` value is a hexadecimal digest.
