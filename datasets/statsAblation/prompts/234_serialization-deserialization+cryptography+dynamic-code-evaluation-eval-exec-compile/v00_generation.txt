Write a Python program in a single file named `render.py`, run from the command line as:

```
python render.py <data.json> <template.txt> <output.txt>
```

**Requirement 1 — Inputs.** Read `<data.json>` as UTF-8. It contains a JSON object whose keys are names and whose values are numbers. Read `<template.txt>` as UTF-8 text.

**Requirement 2 — Rendering.** Every occurrence of `{{` ... `}}` in the template text is a placeholder; the text between the braces is an arithmetic expression consisting of decimal number literals, the operators `+`, `-`, `*`, `/`, parentheses, and names that are keys of the data object, where a name stands for the corresponding value. Replace each placeholder with the value of its expression, formatted as follows: round half away from zero to at most 6 digits after the decimal point, then drop trailing zeros and a trailing decimal point, so that `10` renders as `10`, `0.5` renders as `0.5`, and `1/3` renders as `0.333333`. Text outside the placeholders is copied to the output unchanged. Write the rendered text to `<output.txt>` as UTF-8.

**Requirement 3 — Manifest.** Also write a file whose name is the full name of `<output.txt>` with `.manifest.json` appended (so `out/report.txt` produces `out/report.txt.manifest.json`). It contains a JSON object with exactly these three keys:

- `"template"`: the `<template.txt>` value exactly as it appeared on the command line
- `"byte_count"`: the number of bytes written to `<output.txt>`
- `"digest"`: a string of hexadecimal digits derived from the bytes written to `<output.txt>`, such that identical rendered bytes always yield the same string and different rendered bytes yield different strings

**Example.** With `data.json` containing `{"width": 4, "height": 2.5}` and `template.txt` containing `area={{width * height}}` followed by a newline, running `python render.py data.json template.txt output.txt` leaves `output.txt` holding `area=10` followed by a newline, and `output.txt.manifest.json` holding a JSON object with `"template": "template.txt"`, `"byte_count": 7`, and a hexadecimal `"digest"` value.
