Create a single Python file called `batch_runner.py`. It should be executed from the command line as `python batch_runner.py CONFIG_PATH`, where `CONFIG_PATH` points to a JSON configuration file. The configuration file has this structure:

```json
{
  "max_concurrent": 2,
  "requests": [
    {
      "url": "https://httpbin.org/post",
      "body": "{\"total\": \"{{2 + 3 * 4}}\"}"
    },
    {
      "url": "https://example.com/echo",
      "body": "value={{10 * (1 + 2)}}"
    }
  ]
}
```

Your program must do the following:

1. Load the configuration file. For every request entry, find all `{{expr}}` placeholders inside its `body` and replace each one with the decimal integer result of evaluating `expr`. An `expr` may contain non-negative integer literals, spaces, parentheses, and the binary operators `+`, `-`, and `*`. Multiplication has higher precedence than addition and subtraction, and parentheses can override the usual precedence. For example, `{{2 + 3 * 4}}` should become `14`, and `{{10 * (1 + 2)}}` should become `30`.

2. For each request, make an HTTP POST to the given `url`, using the rendered body as the request payload and including the header `Content-Type: application/json`. Every request will receive an HTTP response. Capture the numeric HTTP status code and the response body as text.

3. Never allow more than `max_concurrent` HTTP requests to be in progress simultaneously. After all requests have finished, print exactly one JSON object per line to stdout, preserving the same order as the `requests` array. Each JSON object must contain exactly the keys `url`, `status`, and `body`. Here, `url` is the request URL, `status` is the integer HTTP status code, and `body` is the response body text.

Example stdout for the configuration above, assuming typical service responses:

```json
{"url": "https://httpbin.org/post", "status": 200, "body": "{\"total\": \"14\"}"}
{"url": "https://example.com/echo", "status": 200, "body": "value=30"}
```
