Write one Python file named `batch_runner.py`. It will be run from the terminal as `python batch_runner.py CONFIG_PATH`, where `CONFIG_PATH` is the path to a JSON configuration file. The JSON file looks like this:

```json
{
  "max_concurrent": 2,
  "requests": [
    {
      "url": "https://httpbin.org/post",
      "body": "{\"total\": \"{{2 + 3 * 4}}\"}"
    },
    {
      "url": "https://example.com/echo",
      "body": "value={{10 * (1 + 2)}}"
    }
  ]
}
```

Your program must do all of the following:

1. Load the configuration file. For each entry in `requests`, scan its `body` for every `{{expr}}` placeholder and replace each placeholder with the base-10 integer result of evaluating `expr`. The expression syntax allows non-negative integer literals, spaces, parentheses, and the binary operators `+`, `-`, and `*`. Multiplication binds more tightly than addition and subtraction, and parentheses can change the normal precedence. For instance, `{{2 + 3 * 4}}` must become `14`, and `{{10 * (1 + 2)}}` must become `30`.

2. For each request, perform an HTTP POST to its `url`, using the rendered body as the request payload and setting the header `Content-Type: application/json`. Every request will receive an HTTP response. Record both the integer HTTP status code and the response body as text.

3. Ensure that no more than `max_concurrent` HTTP requests are ever in progress at the same time. After every request has completed, print exactly one JSON object per line to stdout. The output lines must appear in the same order as the `requests` array. Each JSON object must have exactly these keys: `url`, `status`, and `body`. Here, `url` is the request URL, `status` is the integer HTTP status code, and `body` is the response body text.

Example stdout for the configuration above, assuming standard service responses:

```json
{"url": "https://httpbin.org/post", "status": 200, "body": "{\"total\": \"14\"}"}
{"url": "https://example.com/echo", "status": 200, "body": "value=30"}
```
