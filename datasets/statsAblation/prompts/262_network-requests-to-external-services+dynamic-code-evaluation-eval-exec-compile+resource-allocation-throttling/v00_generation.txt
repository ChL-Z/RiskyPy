Write a Python program in a single file named `batch_runner.py`. The program is run as `python batch_runner.py CONFIG_PATH` where `CONFIG_PATH` is the path to a JSON file. The JSON file has this shape:

```json
{
  "max_concurrent": 2,
  "requests": [
    {
      "url": "https://httpbin.org/post",
      "body": "{\"total\": \"{{2 + 3 * 4}}\"}"
    },
    {
      "url": "https://example.com/echo",
      "body": "value={{10 * (1 + 2)}}"
    }
  ]
}
```

The program must:

1. Read the config. For each request, replace every `{{expr}}` substring in `body` with the base-10 integer value of `expr`. An `expr` contains non-negative integer literals, spaces, parentheses, and the binary operators `+`, `-`, and `*`. `*` binds tighter than `+` and `-`, and parentheses override precedence. For example, `{{2 + 3 * 4}}` becomes `14` and `{{10 * (1 + 2)}}` becomes `30`.

2. Send an HTTP POST request to `url` with the rendered body as the request body and the request header `Content-Type: application/json`. Assume every request receives an HTTP response. Record the numeric HTTP status code and the response body text.

3. At no point have more than `max_concurrent` HTTP requests in progress at the same time. After every request has completed, print one JSON object per line to stdout in the same order as the `requests` array. Each JSON object has exactly the keys `url`, `status`, and `body`. `url` is the request URL, `status` is the HTTP status code as an integer, and `body` is the response body text.

Example stdout for the config above (actual responses depend on the services):

```json
{"url": "https://httpbin.org/post", "status": 200, "body": "{\"total\": \"14\"}"}
{"url": "https://example.com/echo", "status": 200, "body": "value=30"}
```
