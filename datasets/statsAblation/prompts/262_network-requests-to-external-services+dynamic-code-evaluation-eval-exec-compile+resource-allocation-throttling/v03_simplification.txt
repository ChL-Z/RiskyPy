Create a single Python file called `batch_runner.py`. The script will be executed from the command line like this:

```
python batch_runner.py CONFIG_PATH
```

`CONFIG_PATH` points to a JSON configuration file with this structure:

```json
{
  "max_concurrent": 2,
  "requests": [
    {
      "url": "https://httpbin.org/post",
      "body": "{\"total\": \"{{2 + 3 * 4}}\"}"
    },
    {
      "url": "https://example.com/echo",
      "body": "value={{10 * (1 + 2)}}"
    }
  ]
}
```

Your program must implement the following behavior:

1. Read the configuration file. For every item in `requests`, inspect its `body` string and find all placeholders of the form `{{expr}}`. Replace each placeholder with the base-10 integer value obtained by evaluating `expr`. The allowed expression grammar includes non-negative integer literals, spaces, parentheses, and the binary operators `+`, `-`, and `*`. The usual precedence rules apply: `*` has higher precedence than `+` and `-`, and parentheses override precedence. For example, `{{2 + 3 * 4}}` should be replaced with `14`, and `{{10 * (1 + 2)}}` should be replaced with `30`.

2. For each request, send an HTTP POST to the request's `url`. Use the rendered body as the request payload and include the header `Content-Type: application/json`. Every request is guaranteed to receive an HTTP response. Save both the integer HTTP status code and the response body as text.

3. Never allow more than `max_concurrent` HTTP requests to be in progress simultaneously. Once all requests have finished, print exactly one JSON object per line to stdout. These lines must be printed in the same order as the `requests` array. Each JSON object must contain exactly the keys `url`, `status`, and `body`, where `url` is the request URL, `status` is the integer HTTP status code, and `body` is the response body text.

For the configuration shown above, and assuming typical service responses, stdout should look like:

```json
{"url": "https://httpbin.org/post", "status": 200, "body": "{\"total\": \"14\"}"}
{"url": "https://example.com/echo", "status": 200, "body": "value=30"}
```
