Write one Python source file called `expand.py`. It must be usable from the command line in this form:

```
python expand.py TEMPLATE_FILE VARS_FILE
```

The script opens both `TEMPLATE_FILE` and `VARS_FILE` as UTF-8 text, expands the template, and writes the result to standard output.

`VARS_FILE` stores one variable definition per line, using `name=value` syntax.

- Blank lines, lines containing only whitespace, and lines whose first character is `#` are skipped.
- A name consists of one or more letters, digits, or underscores.
- The value is everything after the first `=` on that line, preserved exactly as written.
- If the same name is defined multiple times, the last definition wins.

When expanding `TEMPLATE_FILE`, copy its contents to standard output, except that placeholders must be replaced. A placeholder begins with `{{` and ends with the first `}}` after it. A placeholder never spans multiple lines.

There are three placeholder forms:

1. `{{name}}` — replace with the value of `name` from `VARS_FILE`.
2. `{{= expression }}` — replace with the integer value produced by evaluating `expression`. Identifiers in the expression are looked up in `VARS_FILE`; if the corresponding value contains only digit characters, it is interpreted as an integer, otherwise the placeholder fails. Allowed operators are `+`, `-`, `*`, `/`, `//`, `%`, and parentheses. The text after `{{=` and before `}}` is used as written except for identifier lookup, and is not expanded recursively.
3. `{{$ command }}` — replace with the standard output of executing `command` as an external command. If that output ends with a newline, remove exactly one trailing newline. The text after `{{$` and before `}}` is used exactly as written and is not expanded recursively.

If any placeholder cannot be resolved, print that placeholder's text to standard error and exit with status 1.

If a `{{$ ... }}` command exits with a nonzero status or cannot be started, print the command text to standard error and exit with status 2.

In either error case, stop processing and ensure nothing has been written to standard output.

For example, if `vars.txt` contains:

```
count=3
greeting=hello
```

and `template.txt` contains:

```
count is {{count}}
double is {{= count * 2 }}
today is {{$ date +%Y-%m-%d }}
```

then:

```
python expand.py template.txt vars.txt
```

should print the template with `{{count}}` replaced by `3`, `{{= count * 2 }}` replaced by `6`, and the third placeholder replaced by the output of the `date` command.
