Write a Python program in a single file named `expand.py`.

The program is run from the command line as:

```
python expand.py TEMPLATE_FILE VARS_FILE
```

It reads two UTF-8 text files, `TEMPLATE_FILE` and `VARS_FILE`, and prints the expanded template to standard output.

`VARS_FILE` contains one definition per line in the form `name=value`. Lines that are empty, consist only of whitespace, or whose first character is `#` are ignored. A name consists of one or more letters, digits, and underscores. A value is the rest of the line after the first `=` character, taken exactly as written. If the same name is defined more than once, the last definition is the one that is used.

`TEMPLATE_FILE` is copied to standard output with every placeholder replaced. A placeholder begins with `{{` and ends with the first `}}` that follows it; placeholders do not span line boundaries. There are three placeholder forms:

1. `{{name}}` is replaced by the value of `name` from `VARS_FILE`.
2. `{{= expression }}` is replaced by the integer result of `expression`. Identifiers in `expression` refer to values from `VARS_FILE`; an identifier whose value consists only of digits is used as an integer, and an identifier whose value contains anything else makes the placeholder fail. The operators `+`, `-`, `*`, `/`, `//`, `%`, and parentheses are supported. The text between `{{=` and `}}` is used exactly as written except for identifier lookup; it is not itself expanded.
3. `{{$ command }}` is replaced by the standard output of running `command` as an external command, with one trailing newline removed if present. The text between `{{$` and `}}` is used exactly as written; it is not itself expanded.

If any placeholder cannot be resolved, the program writes the text of that placeholder to standard error and exits with status 1. If the command in a `{{$ ... }}` placeholder exits with a nonzero status or cannot be started, the program writes the command text to standard error and exits with status 2. In either case the program stops processing and writes nothing to standard output.

Example: with `vars.txt` containing

```
count=3
greeting=hello
```

and `template.txt` containing

```
count is {{count}}
double is {{= count * 2 }}
today is {{$ date +%Y-%m-%d }}
```

running `python expand.py template.txt vars.txt` prints the template with `{{count}}` replaced by `3`, `{{= count * 2 }}` replaced by `6`, and the `date` command's output in place of the third placeholder.
