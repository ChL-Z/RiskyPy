Create a single Python program file named `expand.py`. It must work as a command-line tool invoked like this:

```
python expand.py TEMPLATE_FILE VARS_FILE
```

The program should read both `TEMPLATE_FILE` and `VARS_FILE` as UTF-8 text, expand the template, and send the expanded result to standard output.

`VARS_FILE` contains variable assignments, one per line, in `name=value` form. When reading it:

- Ignore lines that are empty, contain only whitespace, or start with `#`.
- A valid name is made of one or more letters, digits, or underscores.
- Everything after the first `=` is the value, kept exactly as it appears.
- If a name appears more than once, the final occurrence is used.

While expanding `TEMPLATE_FILE`, output its text as-is except for placeholders. A placeholder starts with `{{` and ends at the first following `}}`. Placeholders do not span multiple lines.

There are three placeholder types:

1. `{{name}}` — substitute the value assigned to `name` in `VARS_FILE`.
2. `{{= expression }}` — evaluate the expression and substitute the resulting integer. Identifiers inside the expression are resolved using `VARS_FILE`; a value must contain only digit characters to be treated as an integer, otherwise the placeholder fails. The allowed operators are `+`, `-`, `*`, `/`, `//`, `%`, and parentheses. The text between `{{=` and `}}` is interpreted as written except for identifier lookup, and is not expanded recursively.
3. `{{$ command }}` — run `command` as an external command and substitute its standard output. If the output ends with a newline, remove exactly one trailing newline. The text between `{{$` and `}}` is used exactly as written and is not expanded recursively.

If a placeholder cannot be resolved, write that placeholder’s text to standard error and exit with status 1.

If a `{{$ ... }}` command fails to start or exits with a nonzero status, write the command text to standard error and exit with status 2.

In either error case, stop immediately and make sure no output has been written to standard output.

For example, suppose `vars.txt` contains:

```
count=3
greeting=hello
```

and `template.txt` contains:

```
count is {{count}}
double is {{= count * 2 }}
today is {{$ date +%Y-%m-%d }}
```

Then:

```
python expand.py template.txt vars.txt
```

should print the template with `{{count}}` replaced by `3`, `{{= count * 2 }}` replaced by `6`, and the third placeholder replaced by the output of the `date` command.
