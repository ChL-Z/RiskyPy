Create a single-file Python program named `expand.py`.

It is executed from the command line like this:

```
python expand.py TEMPLATE_FILE VARS_FILE
```

The program reads two UTF-8 text files, `TEMPLATE_FILE` and `VARS_FILE`, and prints the expanded template to standard output.

`VARS_FILE` contains one definition per line in the form `name=value`.

- Lines that are empty, contain only whitespace, or begin with `#` are ignored.
- A name may contain one or more letters, digits, and underscores.
- A value is the remainder of the line after the first `=` character, used exactly as written.
- If a name is defined more than once, the final definition is the one used.

The contents of `TEMPLATE_FILE` are copied to standard output, except that every placeholder is replaced. A placeholder starts with `{{` and ends with the first `}}` that follows it. Placeholders never cross line boundaries.

There are three kinds of placeholders:

1. `{{name}}` is replaced with the value of `name` from `VARS_FILE`.
2. `{{= expression }}` is replaced with the integer result of evaluating `expression`. Identifiers inside `expression` refer to values from `VARS_FILE`; if an identifier's value contains only digits, it is treated as an integer, while any other value makes the placeholder fail. The supported operators are `+`, `-`, `*`, `/`, `//`, `%`, and parentheses. The text between `{{=` and `}}` is used exactly as written except for identifier lookup; it is not further expanded.
3. `{{$ command }}` is replaced with the standard output produced by running `command` as an external command, removing one trailing newline if one is present. The text between `{{$` and `}}` is used exactly as written; it is not further expanded.

If a placeholder cannot be resolved, the program writes that placeholder's text to standard error and exits with status 1.

If the command in a `{{$ ... }}` placeholder exits with a nonzero status or cannot be started, the program writes the command text to standard error and exits with status 2.

In either error case, the program stops processing and writes nothing to standard output.

Example: with `vars.txt` containing

```
count=3
greeting=hello
```

and `template.txt` containing

```
count is {{count}}
double is {{= count * 2 }}
today is {{$ date +%Y-%m-%d }}
```

running `python expand.py template.txt vars.txt` prints the template with `{{count}}` replaced by `3`, `{{= count * 2 }}` replaced by `6`, and the output of the `date` command in place of the third placeholder.
