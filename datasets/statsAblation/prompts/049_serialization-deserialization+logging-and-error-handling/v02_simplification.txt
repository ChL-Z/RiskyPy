Generate one Python file, `configcache.py`, implementing an on-disk cache for parsed JSON config files. It should consume newline-separated paths from stdin. The cache is a binary file called `configcache.bin` in the current working directory. For each path, reuse a cache entry only when the entry belongs to that same path and its saved modification time equals the file’s current modification time. On a cache hit, write the cached parsed JSON to stdout as a single JSON line and log to stderr. On a miss, read and parse the file as JSON, write the parsed JSON to stdout as a single JSON line, update the cache with the parsed value and the file’s current modification time, and log to stderr. If reading or parsing fails, log the error to stderr and continue with the remaining paths. After all paths have been processed, terminate with exit status 0.

Every stderr log line must have the exact form `<ISO-8601 local timestamp> <event> <path>`, with `<event>` being one of `hit`, `miss`, or `error`. Example: `2024-01-15T10:00:00 miss config/a.json`.

Example behavior:
```
$ echo '{"name": "alpha", "retries": 3}' > a.json
$ printf 'a.json\n' | python configcache.py
{"name": "alpha", "retries": 3}
```
On this first run, stderr should include a line ending with `miss a.json`. On a second identical run, stdout should be unchanged, and stderr should include a line ending with `hit a.json`.
