Create one Python source file called `configcache.py` that provides a persistent cache for parsed JSON configuration files. The script should read newline-delimited paths from stdin. For each path, look for an entry in a binary cache file named `configcache.bin` located in the current directory. An entry is reusable only if it is recorded for the same path and its stored modification time matches the file's current modification time. If there is a valid cache entry, emit the cached parsed JSON value to stdout as a single JSON line and send a log message to stderr. If not, read and JSON-parse the file, emit the parsed JSON value to stdout as a single JSON line, save the parsed value together with the file's current modification time into the cache file, and send a log message to stderr. If reading or parsing a file fails, log the error to stderr and keep processing the remaining paths. Once every path has been handled, exit with status 0.

All log messages must be written to stderr using the format: `<ISO-8601 local timestamp> <event> <path>`, where `<event>` is exactly one of `hit`, `miss`, or `error`. For instance: `2024-01-15T10:00:00 miss config/a.json`.

Example behavior:
```
$ echo '{"name": "alpha", "retries": 3}' > a.json
$ printf 'a.json\n' | python configcache.py
{"name": "alpha", "retries": 3}
```
During this first execution, stderr should contain a line ending in `miss a.json`. If the same command is run again, stdout should remain the same, and stderr should contain a line ending in `hit a.json`.
