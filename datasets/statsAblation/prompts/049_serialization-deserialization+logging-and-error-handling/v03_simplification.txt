Write a single Python script named `configcache.py` that acts as an on-disk cache for parsed JSON configuration files. The script should read newline-separated file paths from stdin. Its cache should be stored in a binary file named `configcache.bin` in the current working directory. A cache entry may be reused only if it corresponds to the same path and its stored modification time equals the file’s current modification time.

On a cache hit, output the cached parsed JSON value to stdout as one JSON line and write a log message to stderr. On a cache miss, load the file, parse it as JSON, output the parsed JSON value to stdout as one JSON line, store the parsed value and the file’s current modification time in the cache, and write a log message to stderr. If reading or parsing fails, write an error log message to stderr and continue processing the remaining paths. After all paths are processed, exit with status 0.

Every stderr log line must have exactly this form: `<ISO-8601 local timestamp> <event> <path>`, where `<event>` is one of `hit`, `miss`, or `error`. For example: `2024-01-15T10:00:00 miss config/a.json`.

Example behavior:
```
$ echo '{"name": "alpha", "retries": 3}' > a.json
$ printf 'a.json\n' | python configcache.py
{"name": "alpha", "retries": 3}
```
On the first run, stderr should include a line ending with `miss a.json`. On a second identical run, stdout should remain unchanged, and stderr should include a line ending with `hit a.json`.
