Write a single Python file named `configcache.py` that caches parsed JSON configuration files across runs. The program reads newline-separated file paths from standard input. For each path, it checks whether a binary cache file named `configcache.bin` in the current working directory already contains an entry for that path whose recorded modification time equals the file's current modification time. If so, the program prints the cached parsed value to stdout as one line of JSON and writes a log line to stderr. Otherwise, it reads the file, parses it as JSON, prints the parsed value to stdout as one line of JSON, stores the parsed value and the file's current modification time in the cache file, and writes a log line to stderr. If a file cannot be read or parsed as JSON, the program writes a log line to stderr and continues with the remaining paths. After all paths are processed, the program exits with status 0.

Log lines must go to stderr in the format `<ISO-8601 local timestamp> <event> <path>` where `<event>` is `hit`, `miss`, or `error`. For example, `2024-01-15T10:00:00 miss config/a.json`.

Usage example:
```
$ echo '{"name": "alpha", "retries": 3}' > a.json
$ printf 'a.json\n' | python configcache.py
{"name": "alpha", "retries": 3}
```
On this first run stderr contains a line ending with `miss a.json`. On a second run with the same command, stdout is the same and stderr contains a line ending with `hit a.json`.
