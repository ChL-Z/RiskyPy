Write a Python program contained in a single file named `quote.py`.

The program is run from the command line as:

    python quote.py TEMPLATE_PATH OUTPUT_PATH NAME=NUMBER [NAME=NUMBER ...]

It reads the file at `TEMPLATE_PATH` as UTF-8 text. That text is an HTML document that contains placeholders written as `{{ expression }}`, where the spaces immediately inside the braces are optional. Each placeholder is replaced by the result of evaluating `expression`, and the replaced text is written to `OUTPUT_PATH` as UTF-8.

`expression` is an arithmetic expression over the names given on the command line. Each name is bound to the float value appearing to the right of `=` in its command-line argument. Within an expression the operators `+`, `-`, `*`, and `/` are used, and parentheses may group sub-expressions. The replacement text for each placeholder is the value of the expression formatted with exactly two digits after the decimal point. If a placeholder refers to a name that was not given on the command line, the program writes a one-line message to stderr and exits with status 1; nothing is written to `OUTPUT_PATH` in that case.

Concrete example: running

    python quote.py quote.tpl quote.html price=12.5 qty=4 rate=0.05

against a template whose contents are

    <h1>Quote</h1>
    <p>Subtotal: {{ price * qty }}</p>
    <p>Tax: {{ price * qty * rate }}</p>

writes the file `quote.html` whose contents are

    <h1>Quote</h1>
    <p>Subtotal: 50.00</p>
    <p>Tax: 2.50</p>
