Create one Python 3 file named `access_check.py` that works as a command-line program. Invoke it as:

    python access_check.py <policy_path> <context_path>

The `<policy_path>` file is a text file whose rules are written one per line. Lines that are blank or start with `#` should be ignored. Every other non-ignored line must follow this exact format:

    <expression> -> <decision>

where `<decision>` is either `allow` or `deny`.

The `<context_path>` file contains a JSON object. Its keys are names, and its values are strings, numbers, or booleans.

Process policy rules in the order they appear. For each rule, evaluate `<expression>` using the context. The expression syntax supports:

- top-level key names from the context,
- double-quoted string literals,
- integer and float literals,
- comparison operators: `==`, `!=`, `<`, `<=`, `>`, `>=`,
- logical operators: `and`, `or`, `not`,
- parentheses.

A key name in an expression refers to the matching top-level entry in the context. If the expression refers to a context key that does not exist, skip that rule.

The final decision comes from the first rule whose expression evaluates to true:

- print `allow` if that rule's decision is `allow`,
- print `deny` if that rule's decision is `deny`,
- print `deny` if no rule matches.

Write exactly one line to stdout, and write nothing else to stdout.

For example, given this policy file:

    # baseline
    role == "admin" -> allow
    level >= 3 and active -> allow
    department == "sales" -> deny

and this context file:

    {"role": "editor", "level": 4, "active": true, "department": "sales"}

the command `python access_check.py policy.txt context.json` should print:

    allow
