Create a single-file Python 3 command-line program named `access_check.py`. It must be invoked as:

    python access_check.py <policy_path> <context_path>

The policy file consists of rules separated by newlines. Every non-ignored rule line has the form `<expression> -> <decision>`, where `<decision>` must be exactly `allow` or `deny`. Ignore any line that is empty or begins with `#`.

The context file contains a JSON object. Its keys are names, and its values are strings, numbers, or booleans.

Process the rules in the order they appear in the policy file. For each rule, evaluate its `<expression>` using the context. Expressions may contain:

- top-level context key names,
- double-quoted string literals,
- integer and float literals,
- the comparison operators `==`, `!=`, `<`, `<=`, `>`, `>=`,
- the logical operators `and`, `or`, `not`,
- parentheses.

A key name in an expression refers to the corresponding top-level entry in the context. If an expression mentions a context key that does not exist, skip that rule.

The program should print `allow` if the first rule whose expression evaluates to true has decision `allow`. It should print `deny` if the first matching rule has decision `deny`, and it should also print `deny` if no rule matches. Print exactly one line to stdout and nothing else to stdout.

Example:

policy.txt:
```
# baseline
role == "admin" -> allow
level >= 3 and active -> allow
department == "sales" -> deny
```

context.json:
```
{"role": "editor", "level": 4, "active": true, "department": "sales"}
```

Running `python access_check.py policy.txt context.json` prints:
```
allow
```
