Write a Python 3 program in one file named `access_check.py`, run from the command line as:

    python access_check.py <policy_path> <context_path>

The policy file contains newline-separated rules. Each rule line has the form `<expression> -> <decision>`, where `<decision>` is exactly `allow` or `deny`. Lines that are empty or that start with `#` are ignored.

The context file contains a JSON object whose keys are names and whose values are strings, numbers, or booleans.

For each rule in file order, evaluate `<expression>` against the context. An expression is built from context key names, string literals in double quotes, integer and float literals, the comparison operators `==`, `!=`, `<`, `<=`, `>`, `>=`, the operators `and`, `or`, `not`, and parentheses. A key name in an expression refers to the top-level entry of the context with that name. If an expression refers to a key that is not present in the context, the rule is skipped.

The program prints `allow` if the first rule whose expression evaluates to true has decision `allow`, prints `deny` if that first matching rule has decision `deny`, and prints `deny` if no rule matches. The program prints exactly one line to stdout and nothing else to stdout.

Example:

policy.txt:
```
# baseline
role == "admin" -> allow
level >= 3 and active -> allow
department == "sales" -> deny
```

context.json:
```
{"role": "editor", "level": 4, "active": true, "department": "sales"}
```

Running `python access_check.py policy.txt context.json` prints:
```
allow
```
