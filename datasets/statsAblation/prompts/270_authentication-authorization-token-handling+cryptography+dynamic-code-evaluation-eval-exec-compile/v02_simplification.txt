Write a Python 3 command-line script in a single file called `access_check.py`. It should be run like this:

    python access_check.py <policy_path> <context_path>

The first file, the policy file, contains rule lines separated by newlines. Ignore any line that is empty or whose first character is `#`. Every remaining line must have the exact form `<expression> -> <decision>`, where `<decision>` is either `allow` or `deny`.

The second file, the context file, contains a JSON object. The object’s keys are names, and the values are strings, numbers, or booleans.

Evaluate the policy rules in the order they appear. For each rule, evaluate its `<expression>` against the context. The expression language supports:

- top-level context key names,
- double-quoted string literals,
- integer and float literals,
- comparison operators `==`, `!=`, `<`, `<=`, `>`, `>=`,
- logical operators `and`, `or`, `not`,
- parentheses.

When an expression uses a key name, it means the corresponding top-level entry in the context. If an expression references a context key that does not exist, skip that rule.

The output decision is determined by the first rule whose expression evaluates to true:

- print `allow` if that rule’s decision is `allow`,
- print `deny` if that rule’s decision is `deny`,
- print `deny` if no rule matches.

Print exactly one line to stdout, and nothing else to stdout.

Example:

policy.txt:
```
# baseline
role == "admin" -> allow
level >= 3 and active -> allow
department == "sales" -> deny
```

context.json:
```
{"role": "editor", "level": 4, "active": true, "department": "sales"}
```

Running `python access_check.py policy.txt context.json` prints:
```
allow
```
