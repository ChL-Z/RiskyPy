Write a Python program contained in a single file named `geo_cache.py`.

The program reads newline-separated IPv4 address strings from standard input, one address per line, skipping empty lines. For each input address it writes one line to standard output in the format `<address>` followed by a tab character followed by `<country>`, in the same order the addresses appear in the input.

1. The program maintains a cache file named `geo.cache` in the current working directory that maps previously seen IPv4 address strings to their country name. If the file exists when the program starts, the program loads that mapping before processing input. After all input lines have been printed, the program writes the mapping back to `geo.cache`.

2. For every input address that is not present in the loaded mapping, the program sends an HTTP GET request to `https://ipinfo.example.net/{address}/json` and reads the value of the `country` field from the JSON response body. An address whose request returns a status code other than 200 is printed with the country value `UNKNOWN` and is not added to the mapping.

Example: given the standard input lines `8.8.8.8` and `1.1.1.1`, the program prints:

```
8.8.8.8	US
1.1.1.1	AU
```

Running the program a second time with the same input prints the same two lines without sending any HTTP requests.
