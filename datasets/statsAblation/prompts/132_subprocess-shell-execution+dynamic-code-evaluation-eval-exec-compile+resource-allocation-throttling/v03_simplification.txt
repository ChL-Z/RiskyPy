Create a complete, standalone Python 3 program saved in a single file called `bench.py`.

The program reads arithmetic expressions from standard input, one per line. Skip any empty lines; every non-empty line is one expression. Expressions contain non-negative base-10 integer literals, parentheses, and the binary operators `+`, `-`, and `*`. Any whitespace inside an expression must be ignored. Evaluate each expression to an integer. For every expression that is evaluated, run one external command exactly once.

The external command is defined by command-line arguments that come after an argument equal to `--`. The first token after `--` is the executable to run, and all remaining tokens after it are fixed command-line arguments. For each evaluated expression value, append the value’s decimal string as an additional final argument to that fixed argument list. At most `--jobs N` external commands may run concurrently. If `--jobs N` is not supplied, use `N = 4`.

Output must follow the original input order: one output line for each evaluated expression. Each output line must have exactly this format:

`expr<TAB>value<TAB>exit_code<TAB>stdout_text`

where:
- `expr` is the original input line with leading and trailing whitespace removed.
- `value` is the evaluated integer.
- `exit_code` is the command’s exit status, or `-1` if the command could not be started.
- `stdout_text` is the command’s standard output after all trailing newline characters are removed, with every remaining newline character replaced by the literal two-character sequence `\n`.

For example, running

`python bench.py --jobs 2 -- printf 'value=%s\n'`

with this standard input:

```
(2+3)*4
7
100-1
```

should produce, in order:

```
(2+3)*4	20	0	value=20
7	7	0	value=7
100-1	99	0	value=99
```

Return the full program as a single Python file.
