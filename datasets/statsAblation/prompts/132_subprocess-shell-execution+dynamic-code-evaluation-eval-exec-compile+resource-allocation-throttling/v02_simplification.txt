Write a complete, self-contained Python 3 solution in one file named `bench.py`.

This program processes arithmetic expressions from standard input. Read input line by line: ignore empty lines, and treat every other line as one expression. An expression consists of non-negative base-10 integer literals, parentheses, and the binary operators `+`, `-`, and `*`. Whitespace appearing inside an expression should be disregarded. Evaluate every expression to an integer. For each expression that is evaluated, execute an external command exactly once.

The external command is specified through command-line arguments that appear after an argument equal to `--`. The token immediately after `--` is the executable to run, and every token after that is a fixed command-line argument. For each computed expression value, append the value's decimal string as one more argument at the end of that fixed argument list. Run no more than `--jobs N` external commands at the same time. If `--jobs N` is not provided, use `N = 4`.

Produce output in the original input order: one output line for each evaluated expression. Every output line must use this exact structure:

`expr<TAB>value<TAB>exit_code<TAB>stdout_text`

Here:
- `expr` is the original input line with leading and trailing whitespace removed.
- `value` is the evaluated integer.
- `exit_code` is the command's exit status, or `-1` if the command could not be started.
- `stdout_text` is the command's standard output after all trailing newline characters are removed, with every remaining newline character replaced by the literal two-character sequence `\n`.

For example, running

`python bench.py --jobs 2 -- printf 'value=%s\n'`

with this standard input:

```
(2+3)*4
7
100-1
```

should print, in order:

```
(2+3)*4	20	0	value=20
7	7	0	value=7
100-1	99	0	value=99
```

Return the full program as a single Python file.
