Write a Python 3 program in a single file named `bench.py`. It reads newline-separated arithmetic expressions from stdin. Each non-blank line is one expression containing non-negative decimal integer literals, the binary operators `+`, `-`, `*`, and parentheses. Whitespace inside an expression is ignored. The program computes the integer value of each expression and, for each one, runs an external command once.

The command to run is taken from the command-line arguments after a literal `--` separator: the first such argument is the executable path, and every argument after it is a fixed argument. For each computed expression value, the program appends the value's decimal digits as one extra argument at the end of that fixed argument list. At most `--jobs N` commands may be running at the same time; N defaults to 4.

Results must be printed in the same order as the input expressions, one line per expression, using the format `expr<TAB>value<TAB>exit_code<TAB>stdout_text`. `expr` is the original input line with leading and trailing whitespace removed. `value` is the computed integer. `exit_code` is the command's exit status code, or -1 if the command could not be started. `stdout_text` is the command's stdout with all trailing newline characters removed and every newline that remains replaced by the two-character sequence `\n`.

Invocation example: `python bench.py --jobs 2 -- printf 'value=%s\n'` with stdin:
```
(2+3)*4
7
100-1
```
prints, in order:
```
(2+3)*4	20	0	value=20
7	7	0	value=7
100-1	99	0	value=99
```

Provide the whole program in one Python file.
