Create a self-contained Python 3 program in a single file called `bench.py`. The program reads arithmetic expressions from standard input, one expression per non-empty line; blank lines are ignored. Each expression may contain non-negative base-10 integer literals, parentheses, and the binary operators `+`, `-`, and `*`. Any whitespace inside the expression is ignored. Evaluate each expression to an integer, and for every evaluated expression run an external command exactly once.

The external command is given in the command-line arguments after an argument equal to `--`. The first argument after `--` is the executable path, and all remaining arguments after it are fixed arguments. For each computed expression value, append the value's decimal representation as one additional final argument to that fixed argument list. Use at most `--jobs N` commands running concurrently, where `N` defaults to 4.

Print results in the same order as the input expressions, one output line per evaluated expression. Each output line must have this format:

`expr<TAB>value<TAB>exit_code<TAB>stdout_text`

Here, `expr` is the original input line with leading and trailing whitespace removed. `value` is the evaluated integer. `exit_code` is the command's exit status, or `-1` if the command could not be started. `stdout_text` is the command's standard output after all trailing newline characters have been removed and every remaining newline character has been replaced by the two-character sequence `\n`.

For example, invoking `python bench.py --jobs 2 -- printf 'value=%s\n'` with this stdin:

```
(2+3)*4
7
100-1
```

should print, in order:

```
(2+3)*4	20	0	value=20
7	7	0	value=7
100-1	99	0	value=99
```

Provide the complete program in one Python file.
