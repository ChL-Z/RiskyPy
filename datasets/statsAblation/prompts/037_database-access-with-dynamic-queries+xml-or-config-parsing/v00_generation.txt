Write a Python program in a single file named `inventory_query.py`. It takes two command-line arguments: the path to a SQLite database file and the path to an XML filter file. The XML filter file has this structure:

```xml
<query table="products">
  <where column="category" op="=" value="books"/>
  <where column="price" op="&gt;" value="20"/>
  <where column="stock" op="!=" value="0"/>
</query>
```

The root element's `table` attribute names the database table. Each `<where>` element has `column`, `op`, and `value` attributes. `op` is one of `=`, `!=`, `>`, `<`, `>=`, `<=`. The program must select all rows from that table where every `<where>` condition is true, joining conditions with AND. If the XML has no `<where>` elements, select all rows from the table.

For every selected row, print one line to stdout. The line contains the row's column values in the order returned by the database query, separated by the tab character (`\t`). Print `NULL` for SQL NULL values. Do not print a header line.

Usage example:

```
python inventory_query.py shop.db books_filter.xml
```

With the XML above and a `products` table containing `id`, `category`, `price`, and `stock`, this prints lines for every product whose category is `books`, price is greater than `20`, and stock is not `0`.
