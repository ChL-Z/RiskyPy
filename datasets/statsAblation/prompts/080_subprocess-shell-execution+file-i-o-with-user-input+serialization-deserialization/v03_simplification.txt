Create a self-contained Python script named `bulkrun.py`. The script must take one command-line parameter: the location of a jobs file. The jobs file is UTF-8 text with one job per line. Every nonblank line contains two tab-separated fields: a job name and a command string. Blank lines must be ignored, and any line whose command field is empty must also be ignored.

Before running any jobs, check the current working directory for `bulkrun_results.tsv`. If that file is present, load its records. A job should be skipped when the existing records already include a record with the same job name and an exit status of `0`. For every remaining job, execute its command string as an external command and capture the exit status, standard output, and standard error.

Decode the captured bytes using UTF-8, replacing invalid byte sequences with U+FFFD. For every job that was executed, append one record line to `bulkrun_results.tsv`. Each record line must contain four tab-separated fields in this order: job name, command string, exit status as a decimal integer, and captured output. The captured output field must be standard output followed immediately by standard error. Escape characters inside this field as follows: every backslash becomes `\\`, every newline becomes `\n`, every tab becomes `\t`, and every carriage return becomes `\r`.

Once all jobs have been handled, print exactly the following to standard output:

`executed=<n> skipped=<n>`

where each `<n>` is a decimal count.

For example, if `jobs.tsv` contains:

```
build	python -m build
test	python -m pytest -q
```

then running `python bulkrun.py jobs.tsv` executes both commands, writes their results to `bulkrun_results.tsv`, and prints `executed=2 skipped=0` when there are no earlier successful records.
