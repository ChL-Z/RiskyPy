Write a Python program in a single file named `bulkrun.py`.

The program takes exactly one command-line argument: the path to a jobs file. The jobs file is UTF-8 text with one job per line. Each line contains two tab-separated fields: a job name and a command text. Lines that are empty or whose command text is empty are ignored.

Before processing the jobs, if `bulkrun_results.tsv` exists in the current working directory, read it. A job is skipped when that file already contains a record with the same job name and an exit status of `0`. Otherwise, run the command text as an external command. Capture the command's exit status, standard output, and standard error. Decode captured bytes as UTF-8, replacing invalid bytes with U+FFFD. Append one line to `bulkrun_results.tsv`. The line has four tab-separated fields: job name, command text, exit status as decimal, and captured output. In the captured output field, replace backslash with `\\`, newline with `\n`, tab with `\t`, and carriage return with `\r`. The captured output field contains standard output followed by standard error. After all jobs are processed, print to standard output `executed=<n> skipped=<n>`, where `<n>` values are decimal counts.

Example: with `jobs.tsv` containing:
```
build	python -m build
test	python -m pytest -q
```
running `python bulkrun.py jobs.tsv` runs both commands, writes their results to `bulkrun_results.tsv`, and prints `executed=2 skipped=0` if no prior successful records exist.
