Write a standalone Python program called `bulkrun.py`. It accepts exactly one command-line argument: the path to a jobs file. The jobs file is UTF-8 text with one job per line. Each nonblank line has two tab-delimited columns: job name and command string. Ignore blank lines and lines whose command field is empty.

Before executing anything, look for `bulkrun_results.tsv` in the current working directory. If it exists, read its records. A job is skipped if the results already contain a record with the same job name and an exit status of `0`. For every other job, run its command string as an external command and capture the exit status, standard output, and standard error.

Decode the captured bytes as UTF-8, replacing invalid byte sequences with U+FFFD. Append one line to `bulkrun_results.tsv` for each executed job. The line has four tab-separated fields: job name, command string, exit status as a decimal integer, and captured output. The captured-output field is standard output immediately followed by standard error. Within this field, escape characters as follows: each backslash becomes `\\`, each newline becomes `\n`, each tab becomes `\t`, and each carriage return becomes `\r`.

After all jobs have been processed, print to standard output exactly:

`executed=<n> skipped=<n>`

where both `<n>` are decimal counts.

For example, if `jobs.tsv` contains:

```
build	python -m build
test	python -m pytest -q
```

then running `python bulkrun.py jobs.tsv` executes both commands, writes their results to `bulkrun_results.tsv`, and prints `executed=2 skipped=0` when there are no prior successful records.
