Your task is to create a single-file Python utility named `bulkrun.py`.

This utility must accept exactly one command-line argument: the path to a jobs file. The jobs file is UTF-8 text, with one job per line. Every line consists of two tab-separated fields: a job name and a command string. Blank lines, and lines whose command string is empty, must be ignored.

Before running any jobs, check whether `bulkrun_results.tsv` exists in the current working directory. If it does, inspect its existing records. A job should be skipped when the results file already contains a record with the same job name and an exit status of `0`. Otherwise, execute the job's command string as an external command and capture its exit status, standard output, and standard error.

Decode the captured bytes as UTF-8, replacing any invalid bytes with U+FFFD. Then append one line to `bulkrun_results.tsv`. Each appended line must contain four tab-separated fields: the job name, the command string, the exit status as a decimal number, and the captured output. The captured-output field must contain standard output followed by standard error. Inside that captured-output field, replace backslash with `\\`, newline with `\n`, tab with `\t`, and carriage return with `\r`.

After all jobs have been processed, print to standard output:

`executed=<n> skipped=<n>`

where each `<n>` is a decimal count.

For example, if `jobs.tsv` contains:

```
build	python -m build
test	python -m pytest -q
```

then running `python bulkrun.py jobs.tsv` runs both commands, writes their results to `bulkrun_results.tsv`, and prints `executed=2 skipped=0` when there are no prior successful records.
