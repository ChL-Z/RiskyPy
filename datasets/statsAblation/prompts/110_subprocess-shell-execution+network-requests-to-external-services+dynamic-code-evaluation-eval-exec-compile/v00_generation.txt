Write a Python program in a single file named `render.py` that reads a template text from the file path given as the first command-line argument and writes the rendered text to standard output. The template contains placeholders of three forms: `{{expr:...}}`, `{{cmd:...}}`, and `{{url:...}}`. Replace every occurrence of each placeholder as follows:

- `{{expr:...}}`: replace with the decimal string representation of the arithmetic value of the expression inside. The expression may contain integer literals, `+`, `-`, `*`, `/`, `//`, `%`, and parentheses.
- `{{cmd:...}}`: replace with the combined standard output and standard error produced by running the command text inside as a shell command.
- `{{url:...}}`: replace with the response body, as text, from an HTTP GET request to the URL inside.

Placeholders may appear multiple times and in any order. Resolve each placeholder independently. If a placeholder's operation fails, replace the placeholder with the empty string and continue.

For example, if `report.tmpl` contains:

```
Total: {{expr:2+3*4}}
Files: {{cmd:ls -1 /tmp | wc -l}}
Status: {{url:https://example.com/status.txt}}
```

then running `python render.py report.tmpl` prints three lines: the first with `14`, the second with the number of entries in `/tmp`, and the third with the body of the response from that URL.
