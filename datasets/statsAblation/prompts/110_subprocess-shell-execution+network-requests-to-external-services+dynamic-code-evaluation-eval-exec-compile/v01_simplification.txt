Create a single Python file called `render.py`. When executed, it takes one command-line argument: the path to a template file. It should read that template and print the rendered result to stdout.

The template may contain three kinds of placeholders:

- `{{expr:...}}` — replace with the decimal string form of the arithmetic value of the expression inside. The expression can use integer literals, parentheses, and the operators `+`, `-`, `*`, `/`, `//`, and `%`.
- `{{cmd:...}}` — replace with everything printed to both stdout and stderr when the text inside is run as a shell command.
- `{{url:...}}` — replace with the body of the HTTP GET response for the URL inside, treated as text.

Placeholders can occur any number of times and in any order. Each one should be resolved on its own. If resolving a placeholder fails for any reason, replace that placeholder with an empty string and continue processing the rest.

For instance, if `report.tmpl` contains:

```
Total: {{expr:2+3*4}}
Files: {{cmd:ls -1 /tmp | wc -l}}
Status: {{url:https://example.com/status.txt}}
```

then `python render.py report.tmpl` should output three lines: the first showing `14`, the second showing the number of entries under `/tmp`, and the third showing the response body from that URL.
