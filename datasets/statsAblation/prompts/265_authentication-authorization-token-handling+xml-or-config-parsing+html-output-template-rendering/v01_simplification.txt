Create one Python file named `auth_config_renderer.py`. It is run from the command line as `python auth_config_renderer.py CONFIG.xml TOKEN`. The first argument is the path to an XML configuration file, and the second argument is a token. The XML has this form:

```xml
<config>
  <users>
    <user name="alice" token="t0ken1"/>
    <user name="bob" token="t0ken2"/>
  </users>
  <resources>
    <resource id="r1" owner="alice" label="Quarterly Report"/>
    <resource id="r2" owner="bob" label="Budget"/>
    <resource id="r3" owner="alice" label="Roadmap"/>
  </resources>
</config>
```

The program must implement the following behavior:

1. Argument and configuration validation:
   - If fewer than two arguments are supplied, print `Usage: auth_config_renderer.py CONFIG.xml TOKEN` to stdout and exit with code 2.
   - If the configuration file cannot be read, or the XML does not contain a `<config>` element with `<users>` and `<resources>` children, print `ConfigError` to stdout and exit with code 2.

2. Authorization:
   - Locate the first `<user>` in document order whose `token` attribute equals TOKEN.
   - If such a user does not exist, print `Unauthorized` to stdout and exit with code 1.
   - If such a user exists, store that user's `name` attribute as NAME.

3. HTML output:
   - Print a complete HTML document to stdout.
   - The `<title>` and `<h1>` must both contain the text `Resources for NAME`.
   - The body must contain a `<ul>` with one `<li>` for each `<resource>` whose `owner` attribute equals NAME, preserving document order.
   - Each `<li>` must contain the resource's `label` attribute, then a space, then an opening parenthesis, then the resource's `id` attribute, then a closing parenthesis.
   - If no resources match, the `<ul>` must contain no `<li>` elements.
   - The document must begin with `<!DOCTYPE html>` and must use the tags `<html>`, `<head>`, `<body>`, `<title>`, `<h1>`, `<ul>`, and `<li>`.

For example, running `python auth_config_renderer.py config.xml t0ken1` with the configuration above must produce an HTML document whose title and heading are `Resources for alice` and whose list contains `Quarterly Report (r1)` followed by `Roadmap (r3)`.
