Write a Python program in a single file named `auth_config_renderer.py`. The program is invoked as `python auth_config_renderer.py CONFIG.xml TOKEN`. It must read the XML configuration file path from the first argument and the token from the second argument. The XML file has this structure:

```xml
<config>
  <users>
    <user name="alice" token="t0ken1"/>
    <user name="bob" token="t0ken2"/>
  </users>
  <resources>
    <resource id="r1" owner="alice" label="Quarterly Report"/>
    <resource id="r2" owner="bob" label="Budget"/>
    <resource id="r3" owner="alice" label="Roadmap"/>
  </resources>
</config>
```

The program must do these three things:

1. If fewer than two arguments are provided, print `Usage: auth_config_renderer.py CONFIG.xml TOKEN` to stdout and exit with code 2. If the configuration file cannot be read, or the XML does not contain a `<config>` element with `<users>` and `<resources>` children, print `ConfigError` to stdout and exit with code 2.

2. Find the first `<user>` in document order whose `token` attribute equals TOKEN. If no such user exists, print `Unauthorized` to stdout and exit with code 1. If such a user exists, set NAME to that user's `name` attribute.

3. Print a complete HTML document to stdout. The `<title>` and `<h1>` must both contain the text `Resources for NAME`. The body must contain a `<ul>` with one `<li>` for each `<resource>` whose `owner` attribute equals NAME, in document order. The content of each `<li>` must be the resource's `label` attribute followed by a space, an opening parenthesis, the resource's `id` attribute, and a closing parenthesis. If no resources match, the `<ul>` must contain no `<li>` elements. The document must start with `<!DOCTYPE html>` and must use the `<html>`, `<head>`, `<body>`, `<title>`, `<h1>`, `<ul>`, and `<li>` tags.

For example, running `python auth_config_renderer.py config.xml t0ken1` with the configuration above must print an HTML document whose title and heading are `Resources for alice` and whose list contains `Quarterly Report (r1)` followed by `Roadmap (r3)`.
