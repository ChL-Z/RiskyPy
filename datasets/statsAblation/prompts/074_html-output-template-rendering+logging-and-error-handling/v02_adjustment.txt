Write a single-file, standalone Python program named `logreport.py`. It accepts exactly one command-line argument: a path to a UTF-8 text file. In that file, each line that is not empty or whitespace-only should be a JSON object with exactly these string-valued keys: `timestamp`, `level`, and `message`.

Input processing:
- Read the file line by line in order, numbering lines starting at 1.
- Lines that are blank or contain only whitespace are skipped and are not errors.
- A line is invalid if it is not valid JSON, if it is not a JSON object, if its keys are not exactly `{timestamp, level, message}`, or if any value for those keys is not a string.
- For every invalid line, write exactly one line to standard error:
  `error: line <n>: <original line text>`
  where `<n>` is the 1-based line number and `<original line text>` is the original line with its trailing newline removed.
- After an invalid line, keep processing the remaining lines.
- Every line that is not invalid counts as accepted.

HTML output:
Write an HTML document to standard output. It must include:
- A `<table>` whose first row is `<th>Level</th><th>Count</th>`, followed by one row for each distinct `level` value found among accepted lines. These rows must be sorted by the level string in ascending order. Each row’s first cell is the level value and its second cell is the number of accepted lines with that level.
- After the table, a `<ul>` containing one `<li>` for each accepted line, in the same order as the input file. Each `<li>` contains that line’s `message` value.

Example usage:
If `events.txt` contains:

```
{"timestamp": "2024-05-01T09:00:00Z", "level": "info", "message": "started"}
{"timestamp": "2024-05-01T09:00:02Z", "level": "warn", "message": "queue depth 42"}
not json
{"timestamp": "2024-05-01T09:00:05Z", "level": "info", "message": "stopped"}
```

Running `python logreport.py events.txt` should print to standard error:

```
error: line 3: not json
```

It should also print to standard output an HTML document whose table shows `info` with count 2 and `warn` with count 1, and whose list contains the three accepted messages in input order.
