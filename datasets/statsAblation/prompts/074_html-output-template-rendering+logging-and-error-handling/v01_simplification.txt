Create a standalone Python script called `logreport.py` in one file.

The script receives a single command-line argument: the path to a UTF-8 text file. Every non-empty line in that file should be a JSON object with exactly the keys `timestamp`, `level`, and `message`, where each key’s value is a string.

Reading and error handling:
- Read the file’s lines in order and count them starting at 1 from the first line of the file.
- Ignore lines that contain only whitespace; they are not errors.
- A line is invalid if it is not a JSON object, if its set of keys is not exactly `{timestamp, level, message}`, or if any of its values is not a string.
- For each invalid line, print to standard error one line in this form:
  `error: line <n>: <original line text>`
  Here `<n>` is the 1-based line number, and `<original line text>` is the line with any trailing newline removed.
- After reporting an error, continue processing the next line.
- Count every non-error line as accepted.

HTML output:
Write an HTML document to standard output. It must contain:
- A `<table>` whose first row is `<th>Level</th><th>Count</th>`, followed by one row for each distinct `level` value among accepted lines, sorted by level string in ascending order. In each such row, the first cell contains the level value and the second cell contains the number of accepted lines with that level.
- After the table, a `<ul>` with one `<li>` for each accepted line in input order. Each `<li>` contains that line’s `message` value.

Example usage:
Suppose `events.txt` contains:

```
{"timestamp": "2024-05-01T09:00:00Z", "level": "info", "message": "started"}
{"timestamp": "2024-05-01T09:00:02Z", "level": "warn", "message": "queue depth 42"}
not json
{"timestamp": "2024-05-01T09:00:05Z", "level": "info", "message": "stopped"}
```

Running `python logreport.py events.txt` should print to standard error:

```
error: line 3: not json
```

It should also print to standard output an HTML document whose table shows `info` with count 2 and `warn` with count 1, and whose list contains the three accepted messages in input order.
