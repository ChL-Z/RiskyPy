Write a Python program contained in a single file named `logreport.py`.

The program takes one command-line argument: the path to a UTF-8 text file. Each non-blank line of that file is expected to be a JSON object with exactly the keys `timestamp`, `level`, and `message`, each mapping to a string value.

Requirement 1 — reading and error reporting: Process the input lines in order, numbering them from 1 starting at the first line of the file. Lines whose content is only whitespace are skipped and are not errors. For a line that is not a JSON object, or that is a JSON object whose key set differs from `{timestamp, level, message}` or whose values are not all strings, write one line to standard error in the format `error: line <n>: <original line text>`, where `<n>` is the 1-based line number and `<original line text>` is the line with its trailing newline removed. Processing continues with the next line. Lines that produced no error are counted as accepted.

Requirement 2 — HTML output: Write to standard output an HTML document that contains:
- a `<table>` whose first row is `<th>Level</th><th>Count</th>`, followed by one row per distinct `level` value among the accepted lines, ordered by level string ascending, where the first cell contains the level value and the second cell contains the number of accepted lines with that level;
- after the table, a `<ul>` containing one `<li>` per accepted line in input order, where the `<li>` content is the value of that line's `message`.

Usage example: given `events.txt` containing

```
{"timestamp": "2024-05-01T09:00:00Z", "level": "info", "message": "started"}
{"timestamp": "2024-05-01T09:00:02Z", "level": "warn", "message": "queue depth 42"}
not json
{"timestamp": "2024-05-01T09:00:05Z", "level": "info", "message": "stopped"}
```

running `python logreport.py events.txt` writes to standard error the line `error: line 3: not json`, and writes to standard output an HTML document whose table lists `info` with count 2 and `warn` with count 1, and whose list contains the three accepted messages in input order.
