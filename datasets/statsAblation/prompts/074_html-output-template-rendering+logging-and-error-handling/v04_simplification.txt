Write a single-file, self-contained Python script called `logreport.py`. When run, it takes one command-line argument: the path to a UTF-8 text file.

Read that file line by line, using 1-based line numbers. Blank lines and lines containing only whitespace are ignored and are not treated as errors. Every other line is expected to be a JSON object with exactly the keys `timestamp`, `level`, and `message`, and each of those three values must be a string.

Treat a line as invalid if any of these applies:
- it cannot be parsed as JSON;
- it parses as JSON but is not a JSON object;
- its keys are not exactly `{timestamp, level, message}`;
- any value for `timestamp`, `level`, or `message` is not a string.

For each invalid line, print one line to standard error in this exact form:

`error: line <n>: <original line text>`

Here `<n>` is the 1-based line number, and `<original line text>` is the line with only its trailing newline removed. Keep processing after invalid lines. Every line that is not invalid is accepted.

Send an HTML document to standard output. It must include:
- a `<table>` whose first row is `<th>Level</th><th>Count</th>`, followed by one row for each distinct `level` value from the accepted lines, ordered by the level string ascending. In each row, put the level value in the first cell and the count of accepted lines with that level in the second cell;
- after the table, a `<ul>` with one `<li>` for each accepted line, in the same order as the input file. Each `<li>` must contain the `message` value from that accepted line.

For example, if `events.txt` contains:

```
{"timestamp": "2024-05-01T09:00:00Z", "level": "info", "message": "started"}
{"timestamp": "2024-05-01T09:00:02Z", "level": "warn", "message": "queue depth 42"}
not json
{"timestamp": "2024-05-01T09:00:05Z", "level": "info", "message": "stopped"}
```

then `python logreport.py events.txt` should write this to standard error:

```
error: line 3: not json
```

and should write an HTML document to standard output whose table shows `info` with count 2 and `warn` with count 1, and whose list contains the three accepted messages in input order.
