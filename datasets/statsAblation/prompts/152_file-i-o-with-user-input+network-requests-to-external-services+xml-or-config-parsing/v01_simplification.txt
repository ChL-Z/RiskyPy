Create a single Python file named `fetch_status.py`. The script must accept exactly one command-line argument: the path to an XML configuration file. The configuration XML has a root element `<endpoints>`, which contains zero or more `<endpoint>` elements. Each `<endpoint>` has a `url` attribute and a child `<name>` element whose text is the endpoint name. Your script should:

1. Parse the XML configuration file given as the first command-line argument.
2. For every `<endpoint>`, make an HTTP GET request to its URL and measure the elapsed time in milliseconds from when the request begins until the response body has been fully received. If the HTTP request does not complete successfully—meaning an exception is raised or the response status code is not in the 200–299 range—record the elapsed time as -1.
3. Write a file named `status.xml` in the same directory as the input configuration file. The output XML must have a root element `<results>` containing one `<result>` element for each input endpoint, preserving the original order. Each `<result>` must have three attributes: `name` (the text from the `<name>` element), `url` (the endpoint URL), and `time_ms` (the measured time as an integer, or -1 for failures).

For example, if the input file is `/path/to/config.xml` with content `<endpoints><endpoint url="http://example.com"><name>Example</name></endpoint></endpoints>`, then the script should create `/path/to/status.xml` with content like `<results><result name="Example" url="http://example.com" time_ms="123"/></results>`. The script must be runnable as `python fetch_status.py config.xml`.
