Create a Python script named `fetch_status.py` that accepts exactly one command-line argument: the path to an XML configuration file. The XML document has a root element `<endpoints>` and can contain zero or more `<endpoint>` elements. Each `<endpoint>` has a `url` attribute and includes a `<name>` child element whose text is the endpoint’s name. The script must do the following:

1. Open, read, and parse the XML configuration file given as the first command-line argument.
2. For every `<endpoint>`, issue an HTTP GET request to its URL. Record the elapsed time in milliseconds from the moment the request starts until the complete response body has been received. If the request fails for any reason—either an exception is raised or the HTTP status code is not in the 200–299 range—record the elapsed time as -1.
3. Write an output file called `status.xml` in the same directory as the input configuration file. The output XML must use `<results>` as its root element and must contain one `<result>` child for each input endpoint, preserving the original order. Each `<result>` must have three attributes: `name` taken from the endpoint’s `<name>` element, `url` taken from the endpoint’s `url` attribute, and `time_ms` as an integer containing the measured time or -1 if the request failed.

For example, if the input file is `/path/to/config.xml` and contains `<endpoints><endpoint url="http://example.com"><name>Example</name></endpoint></endpoints>`, the script should create `/path/to/status.xml` with content similar to `<results><result name="Example" url="http://example.com" time_ms="123"/></results>`. The script should be runnable as `python fetch_status.py config.xml`.
