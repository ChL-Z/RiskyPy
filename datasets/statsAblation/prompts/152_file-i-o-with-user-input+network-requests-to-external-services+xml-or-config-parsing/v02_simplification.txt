Write a Python program saved as `fetch_status.py`. It should take exactly one command-line argument: the file path of an XML configuration file. The XML root is `<endpoints>`, and it may contain any number of `<endpoint>` entries. Every `<endpoint>` has a `url` attribute and contains a `<name>` child element whose text value is the endpoint's name. The script must perform the following tasks:

1. Read and parse the XML configuration file supplied as the first command-line argument.
2. For each `<endpoint>`, send an HTTP GET request to its URL. Measure the time in milliseconds starting when the request is initiated and ending after the entire response body has been received. If the request fails—either because an exception occurs or because the HTTP status code is outside the 200–299 range—set the measured time to -1.
3. Create an output file named `status.xml` in the same folder as the input configuration file. This output XML must have a `<results>` root element with one `<result>` child for each endpoint from the input, in the same order. Each `<result>` must include three attributes: `name` from the endpoint's `<name>` element, `url` from the endpoint's `url` attribute, and `time_ms` as an integer representing the measured time, or -1 for a failed request.

For instance, if the input file is `/path/to/config.xml` and contains `<endpoints><endpoint url="http://example.com"><name>Example</name></endpoint></endpoints>`, the script should produce `/path/to/status.xml` with content similar to `<results><result name="Example" url="http://example.com" time_ms="123"/></results>`. The script should be executable with `python fetch_status.py config.xml`.
