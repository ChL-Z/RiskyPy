Write a Python script in a single file named `fetch_status.py`. The script takes one command-line argument: the path to an XML configuration file. The XML file has a root element `<endpoints>` containing zero or more `<endpoint>` elements. Each `<endpoint>` element has a `url` attribute and a child `<name>` element containing text. The script must: (1) parse the XML configuration file specified by the first command-line argument; (2) for each `<endpoint>`, send an HTTP GET request to the URL and measure the elapsed time in milliseconds from the start of the request until the response body is fully received—if the HTTP request does not complete successfully (i.e., an exception is raised or the response status code is not in the range 200–299), record the elapsed time as -1; (3) write a file named `status.xml` in the same directory as the input configuration file. The output XML must have a root element `<results>` containing one `<result>` element for each input endpoint, in the same order as they appeared in the input. Each `<result>` element must have three attributes: `name` (the text content of the `<name>` element), `url` (the URL), and `time_ms` (the measured time as an integer, or -1 for failures). Example: If the input file is `/path/to/config.xml` with content `<endpoints><endpoint url="http://example.com"><name>Example</name></endpoint></endpoints>`, then the script should create `/path/to/status.xml` with content like `<results><result name="Example" url="http://example.com" time_ms="123"/></results>`. The script must be runnable as `python fetch_status.py config.xml`.
