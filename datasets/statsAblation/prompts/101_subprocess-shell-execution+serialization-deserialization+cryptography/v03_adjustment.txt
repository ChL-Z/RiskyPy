Create one self-contained Python program. It must accept exactly one positional command-line argument: the filename of a task file. Each line in that file represents one task and has this form: a shell command, then the last `|` character on the line, then a hexadecimal digest string. That digest string is the cryptographic hash of the command’s stdout. Run the shell commands one after another in the same order as the file lines. For each line, execute the command, capture its stdout as raw bytes, compute a cryptographic hash of those bytes, and print exactly one result line. If the computed hash equals the hexadecimal digest from the file, print `<line_number>: MATCH`; otherwise print `<line_number>: MISMATCH`, with line numbering starting at 1. Exit with code 0 only if every task matches, code 1 if any task does not match, and code 2 if the task file cannot be read. In the unreadable-file case, also print an error message to stderr. For example, if the task file contains only `echo hello|a1b2c3d4e5f6`, the program should run `echo hello`, hash its stdout `hello
`, compare that hash with `a1b2c3d4e5f6`, and print `1: MATCH` or `1: MISMATCH` depending on whether they match.
