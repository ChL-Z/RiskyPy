Write a single-file Python program that takes exactly one command-line argument: the path to a task file. The task file has one task per line. Each task consists of a shell command, then a `|` character, then a hexadecimal string. This hexadecimal string is the cryptographic hash of that command’s standard output. The `|` that separates the command from the hash is the final pipe character on the line. The program must execute the shell commands sequentially, preserving the order in which they appear in the file. For every command, it should capture standard output as bytes, compute a cryptographic hash of those bytes, and print one result line per task: `<line_number>: MATCH` if the computed hash equals the hexadecimal string from the task file, otherwise `<line_number>: MISMATCH`. Line numbering starts at `1`. The program must exit with status code `0` if every task matched, status code `1` if any task did not match, and status code `2` if the task file cannot be read; in the unreadable-file case, it must also print an error message to standard error. For example, if the task file contains only `echo hello|a1b2c3d4e5f6`, the program should run `echo hello`, compute the cryptographic hash of its output `hello
`, compare that hash with `a1b2c3d4e5f6`, and print `1: MATCH` or `1: MISMATCH` depending on whether they match.
