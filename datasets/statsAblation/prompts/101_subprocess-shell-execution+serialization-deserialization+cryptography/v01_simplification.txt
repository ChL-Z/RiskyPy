Create a single-file Python program that accepts exactly one command-line argument: the path to a task file. Each line of the task file describes one task as a shell command, followed by a pipe character `|`, followed by a hexadecimal string that is the cryptographic hash of that command’s standard output. The `|` separating the command from the hash is the last pipe character on the line. The program should run the shell commands sequentially, in the same order as they appear in the file. For each command, it must capture standard output as bytes, compute a cryptographic hash of those bytes, and print one result line per task: `<line_number>: MATCH` if the computed hash equals the hexadecimal string from the task file, or `<line_number>: MISMATCH` otherwise. The first line is line number `1`. The program must exit with status code `0` if every task matched, status code `1` if any task did not match, and status code `2` if the task file cannot be read, in which case it must print an error message to standard error. For example, if the task file contains only `echo hello|a1b2c3d4e5f6`, the program should execute `echo hello`, compute the cryptographic hash of its output `hello
`, compare it with `a1b2c3d4e5f6`, and print `1: MATCH` or `1: MISMATCH` depending on whether they match.
