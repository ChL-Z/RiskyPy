Write a single self-contained Python script that takes exactly one positional command-line argument: the path to a task file. The task file contains one task per line. On each line, the final `|` character separates a shell command from a hexadecimal digest string. That digest is the cryptographic hash of the command’s stdout. Execute the shell commands in the same order as the lines in the file. For every line, run the command, capture its stdout as raw bytes, compute a cryptographic hash of those bytes, and print exactly one result line. If the computed hash equals the digest from the file, print `<line_number>: MATCH`; otherwise print `<line_number>: MISMATCH`, numbering lines from 1. Exit with status 0 only if all tasks match, status 1 if any task does not match, and status 2 if the task file cannot be read. In the unreadable-file case, also write an error message to stderr. For example, if the task file contains only `echo hello|a1b2c3d4e5f6`, the script should run `echo hello`, hash its stdout `hello
`, compare that hash to `a1b2c3d4e5f6`, and print `1: MATCH` or `1: MISMATCH` depending on whether they match.
