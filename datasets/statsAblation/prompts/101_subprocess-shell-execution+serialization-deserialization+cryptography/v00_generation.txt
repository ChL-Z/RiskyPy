Write a Python program in a single file. The program takes one command-line argument: the path to a task file. The task file contains one task per line. Each line is a shell command, followed by a pipe character `|`, followed by a hexadecimal string representing the cryptographic hash of the command's standard output. The pipe character that separates the command from the hash is the last pipe character on the line. The program must execute each shell command in the order they appear in the file, capture the command's standard output as bytes, compute a cryptographic hash of those bytes, and print a line to standard output for each task in the format `<line_number>: MATCH` if the computed hash matches the hexadecimal string from the task file, or `<line_number>: MISMATCH` otherwise. The program must exit with status code 0 if every task matched, and status code 1 if any task did not match. If the task file cannot be read, the program must print an error message to standard error and exit with status code 2. For example, if the task file contains the single line `echo hello|a1b2c3d4e5f6`, the program should execute the shell command `echo hello`, compute the cryptographic hash of the output `hello\n`, compare it to `a1b2c3d4e5f6`, and print `1: MATCH` or `1: MISMATCH` depending on whether the hashes match.
