Write a complete Python program in a single file named `quota_tokens.py`. The program provides two command-line modes: `issue` and `check`.

In `issue` mode, it is invoked as `python quota_tokens.py issue <client_id> <expiry>`, where `<expiry>` is an integer Unix timestamp. It prints one line to stdout containing a token string. The token string contains no whitespace and encodes both `<client_id>` and `<expiry>`. The token is produced using the value of the environment variable `QUOTA_SECRET`; a token issued with one value of `QUOTA_SECRET` must not be accepted by `check` when the environment variable has a different value.

In `check` mode, it reads newline-separated JSON objects from stdin. Each non-empty line has the form `{"client_id": "alice", "token": "...", "timestamp": 1700000000}`. For each input line, it prints exactly one line to stdout: `ALLOW` or `DENY`. The program also reads `limits.json` from the current directory. `limits.json` is a JSON object whose keys are client IDs and whose values are positive integers, for example `{"alice": 3, "bob": 1}`. A request is permitted only when all of these are true: the token was issued with the same `QUOTA_SECRET`; the token encodes the same `client_id` as the request; the token's expiry is greater than the request's `timestamp`; and the number of requests already permitted for that client ID in the same 60-second window is less than that client's limit. The 60-second window for a timestamp is the integer `timestamp // 60`. When a request is permitted, it counts toward its window. When a request is denied, it does not count. A request for a client ID absent from `limits.json` is denied.

Example:
```
export QUOTA_SECRET=abc123
python quota_tokens.py issue alice 1700000060
# prints a token such as Xy7...
printf '%s\n' '{"client_id":"alice","token":"Xy7...","timestamp":1700000000}' '{"client_id":"alice","token":"Xy7...","timestamp":1700000010}' '{"client_id":"alice","token":"Xy7...","timestamp":1700000020}' '{"client_id":"alice","token":"Xy7...","timestamp":1700000030}' | python quota_tokens.py check
```
With `limits.json` containing `{"alice": 3}`, the four requests print `ALLOW`, `ALLOW`, `ALLOW`, `DENY`.
