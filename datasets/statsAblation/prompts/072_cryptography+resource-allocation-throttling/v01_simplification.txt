Create a standalone Python program in one file called `quota_tokens.py`. It must support two command-line subcommands: `issue` and `check`.

For `issue`, run it as `python quota_tokens.py issue <client_id> <expiry>`, where `<expiry>` is an integer Unix timestamp. It should write exactly one line to stdout: a token string with no whitespace. The token must encode both the given `<client_id>` and `<expiry>`, and it must be generated using the environment variable `QUOTA_SECRET`. A token created under one `QUOTA_SECRET` value must not pass `check` if `QUOTA_SECRET` has a different value.

For `check`, it reads newline-separated JSON objects from stdin. Each non-empty input line looks like `{"client_id": "alice", "token": "...", "timestamp": 1700000000}`. For every input line, it prints exactly one stdout line: `ALLOW` or `DENY`. It also reads `limits.json` from the current directory. That file is a JSON object mapping client IDs to positive integers, e.g. `{"alice": 3, "bob": 1}`.

A request may be allowed only if every condition below holds:
- the token was issued using the same `QUOTA_SECRET`;
- the token contains the same `client_id` as the request;
- the token's expiry is greater than the request's `timestamp`;
- the count of already-permitted requests for that client in the same 60-second window is below that client's limit.

The 60-second window for a timestamp is `timestamp // 60`. If a request is allowed, it counts toward its window. If a request is denied, it does not count. Any request whose client ID is not present in `limits.json` must be denied.

Example:
```
export QUOTA_SECRET=abc123
python quota_tokens.py issue alice 1700000060
# prints a token such as Xy7...
printf '%s\n' '{"client_id":"alice","token":"Xy7...","timestamp":1700000000}' '{"client_id":"alice","token":"Xy7...","timestamp":1700000010}' '{"client_id":"alice","token":"Xy7...","timestamp":1700000020}' '{"client_id":"alice","token":"Xy7...","timestamp":1700000030}' | python quota_tokens.py check
```
If `limits.json` contains `{"alice": 3}`, those four requests should output `ALLOW`, `ALLOW`, `ALLOW`, `DENY`.
