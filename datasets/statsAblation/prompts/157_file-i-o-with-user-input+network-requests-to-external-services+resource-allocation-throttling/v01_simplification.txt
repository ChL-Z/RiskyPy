Write a Python program in a single file called `pkg_info.py`. It should take two command-line arguments: the path to an input file and the path to an output file. The input file has one package name per line. Remove the trailing newline from each line, and ignore any line that becomes empty after that removal. For every remaining package name, perform an HTTP GET to `https://pypi.org/pypi/<package>/json`, substituting the package name directly into the URL path. The endpoint responds with a JSON object whose top-level `info` field contains `version` and `summary` string values. The output must be written as JSON Lines: one JSON object per line. Preserve the input order. For each package, if the HTTP response status is 200, write `{"package": "<name>", "version": "<version>", "summary": "<summary>"}`. For any non-200 HTTP status, write `{"package": "<name>", "error": "HTTP <status>"}`. At no point may the script have more than 3 HTTP requests in progress simultaneously. Once all packages are handled and the output file is written, terminate with exit code 0. For example, if `input.txt` contains `requests` and `flask`, then running `python pkg_info.py input.txt results.jsonl` should create `results.jsonl` with two lines, first for `requests` and second for `flask`, in that order.
