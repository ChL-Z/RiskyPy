Create a single Python file named `pkg_info.py`. The script accepts two command-line arguments: an input file path and an output file path. The input file contains one package name per line. Strip the trailing newline from each line; skip any line that is empty after stripping. For each remaining package name, send an HTTP GET request to `https://pypi.org/pypi/<package>/json`, where `<package>` is the package name inserted directly into the URL path. The service returns a JSON object with a top-level `info` object containing `version` and `summary` string fields. Write the output file as JSON Lines: one JSON object per line. For each package, in the same order as the input, write either `{"package": "<name>", "version": "<version>", "summary": "<summary>"}` when the HTTP status is 200, or `{"package": "<name>", "error": "HTTP <status>"}` for any other HTTP status. The script must keep no more than 3 HTTP requests in progress at any moment. After all packages have been processed and the output file has been written, exit with code 0.

Example: given `input.txt` containing `requests` and `flask`, running `python pkg_info.py input.txt results.jsonl` should produce two lines in `results.jsonl`, one for `requests` and one for `flask`, in that order.
