Create a standalone Python program in a single file called `pkg_info.py`. It should require exactly two command-line arguments: the first is an input file path, and the second is an output file path. The input file holds package names, one per line. For each line, remove the trailing newline; if the line is then empty, ignore it. For every remaining package name, send an HTTP GET request to `https://pypi.org/pypi/<package>/json`, with `<package>` placed directly into the URL path. The returned JSON has a top-level `info` object whose `version` and `summary` fields are strings. Save results as JSON Lines, one JSON object per line, preserving the original input order. For an HTTP 200 response, write `{"package": "<name>", "version": "<version>", "summary": "<summary>"}`. For any other HTTP status, write `{"package": "<name>", "error": "HTTP <status>"}`. At no point may more than 3 HTTP requests be active concurrently. Once all packages have been processed and the output file has been written, terminate with exit code 0. For instance, if `input.txt` contains `requests` followed by `flask`, then running `python pkg_info.py input.txt results.jsonl` should create `results.jsonl` with two lines: the first for `requests` and the second for `flask`, in that order.
