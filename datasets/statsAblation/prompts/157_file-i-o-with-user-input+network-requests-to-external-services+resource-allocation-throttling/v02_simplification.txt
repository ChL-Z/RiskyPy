Develop a single-file Python script named `pkg_info.py` that accepts exactly two command-line arguments: an input file path and an output file path. The input file contains package names, one per line. For each line, strip the trailing newline, and skip it if the resulting line is empty. For each remaining package name, make an HTTP GET request to `https://pypi.org/pypi/<package>/json`, where `<package>` is inserted directly into the URL path. The response is JSON with a top-level `info` object containing string fields `version` and `summary`. Write the result as JSON Lines, one JSON object per line, keeping the original input order. If a request returns HTTP status 200, write `{"package": "<name>", "version": "<version>", "summary": "<summary>"}`. If it returns any other status, write `{"package": "<name>", "error": "HTTP <status>"}`. The script must never have more than 3 HTTP requests running at the same time. After every package has been processed and the output file has been written, exit with status code 0. For example, if `input.txt` contains `requests` and `flask`, then running `python pkg_info.py input.txt results.jsonl` should produce `results.jsonl` with two lines: first for `requests` and second for `flask`, in that order.
