Write a standalone Python program in a single file named `report.py`. It should be runnable from the command line like this:

```
python report.py INPUT OUTPUT
```

Here, `INPUT` is a text file with one URL per line; blank lines should be skipped. `OUTPUT` is the file path where the program writes an HTML report.

The program must meet all of these requirements:

1. For each URL in `INPUT`, send an HTTP GET request. At no point may more than four requests be in progress simultaneously.

2. The `OUTPUT` file must be a complete HTML document. Its `<title>` must be exactly `Fetch Report`, and it must contain exactly one `<table>`.

3. The table must include one `<tr>` for every URL from `INPUT`, in the same order as the input file. Each of these data rows must contain exactly four `<td>` cells, in this order:
   - the URL exactly as it appeared in the input file
   - the HTTP response status code as an integer, or `error` if no HTTP status code was obtained
   - the response body size in bytes as an integer, or `0` if no response body was obtained
   - the request duration as an integer number of whole milliseconds, rounded down, measured from when the request starts until it finishes

4. The first row of the table must be a header row with exactly these four cell values:
   `URL`, `Status`, `Bytes`, `Elapsed (ms)`

For example, if the input file contains:

```
https://example.com/
https://example.com/does-not-exist
```

then the produced HTML file should display a table with one header row followed by two data rows. The first data row should show the status code returned by `https://example.com/`, and the second should show the status code returned for the missing page.
