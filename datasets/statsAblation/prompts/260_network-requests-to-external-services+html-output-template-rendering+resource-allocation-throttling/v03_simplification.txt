Create a self-contained Python program in one file called `report.py`. It should be executable from the command line as:

```
python report.py INPUT OUTPUT
```

`INPUT` is a plain text file containing one URL per line, and any blank lines should be ignored. `OUTPUT` is the path where the program should write an HTML report.

The program must satisfy all of the following conditions:

1. It must issue an HTTP GET request for every URL in `INPUT`. The number of requests being processed at the same time must never be greater than four.

2. The file written to `OUTPUT` must be a full HTML document. Its `<title>` must be exactly `Fetch Report`, and it must include exactly one `<table>`.

3. The table must contain one `<tr>` for each URL from `INPUT`, preserving the input order. Each such data row must have exactly four `<td>` cells, in this order:
   - the URL exactly as it appeared in the input file
   - the HTTP response status code as an integer, or `error` if no HTTP status code was received
   - the response body size in bytes as an integer, or `0` if no response body was received
   - the request duration as an integer number of whole milliseconds, rounded down, measured from the start of the request until it finishes

4. The table's first row must be a header row containing exactly these four cell values:
   `URL`, `Status`, `Bytes`, `Elapsed (ms)`

For example, suppose the input file contains:

```
https://example.com/
https://example.com/does-not-exist
```

Then the generated HTML should display a table with one header row followed by two data rows. The first data row should show the status code returned for `https://example.com/`, and the second should show the status code returned for the missing page.
