Create a single-file Python script called `report.py`.

It must be usable from the command line as:

```
python report.py INPUT OUTPUT
```

`INPUT` is a text file containing URLs, one per line. Ignore any blank lines. `OUTPUT` is the path where the script will write an HTML report.

Your script must satisfy these requirements:

1. For every URL in `INPUT`, perform an HTTP GET request. The script must never have more than 4 requests running concurrently at any moment.

2. Write `OUTPUT` as a full HTML document. Its `<title>` must be exactly `Fetch Report`, and it must contain exactly one `<table>`.

3. The table must have one `<tr>` for each URL from `INPUT`, preserving the original input order. Every such data row must contain exactly four `<td>` cells, in this order:
   - the URL exactly as it appeared in the input file
   - the HTTP response status code as an integer, or `error` if no HTTP status code was produced
   - the response body size in bytes as an integer, or `0` if no response body was produced
   - the request duration in whole milliseconds, rounded down to an integer, measured from starting the request to finishing it

4. The first row of the table must be a header row with these four cell values:
   `URL`, `Status`, `Bytes`, `Elapsed (ms)`

For example, if the input file contains:

```
https://example.com/
https://example.com/does-not-exist
```

then the generated HTML file should render as a table with a header row followed by two data rows. The first data row should show the status code returned by `https://example.com/`, and the second should show the status code returned for the missing page.
