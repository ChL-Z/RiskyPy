Write a Python program contained in a single file named `report.py`.

The program is run from the command line as `python report.py INPUT OUTPUT`, where `INPUT` is the path to a text file holding one URL per line (blank lines are ignored) and `OUTPUT` is the path where the program writes an HTML report.

Requirements:

1. The program sends an HTTP GET request to every URL from `INPUT`. At no point may more than 4 requests be in progress at the same time.

2. The program writes `OUTPUT` as a complete HTML document whose `<title>` is `Fetch Report` and which contains a single `<table>`. The table has one `<tr>` per URL from `INPUT`, in the same order the URLs appear in the input file, and each such row contains four `<td>` cells in this order:
   - the URL exactly as it appeared in the input file
   - the integer HTTP status code of the response, or the text `error` if the request did not produce an HTTP status code
   - the number of bytes in the response body, or `0` if the request did not produce a response body
   - the whole number of milliseconds elapsed between starting the request and finishing it, rounded down to an integer

3. The first row of the table is a header row containing the four cell values `URL`, `Status`, `Bytes`, and `Elapsed (ms)`.

Example: given an input file containing

```
https://example.com/
https://example.com/does-not-exist
```

the program writes an HTML file that renders as a table with a header row followed by two data rows, the first showing the status code returned by `https://example.com/`, and the second showing the status code returned for the missing page.
