Create a single-file Python script that takes two command-line arguments: the first is the path to a JSON configuration file, and the second is the path where a JSON report should be written. The configuration file contains a JSON object with a string field named "token" and a field named "commands", which is a list of shell command strings. The script should run those shell commands sequentially, in the given order, while making the token available to every command through the environment variable AUTH_TOKEN. For each command, capture its standard output. If every command completes successfully, write a JSON report whose top-level object has a "results" field. This field should contain a list with one object per command, where each object has "command" set to the original command string and "stdout" set to the captured standard output as a string. If any command returns a non-zero exit status, stop running any further commands, and write the report using only the results collected up to that point, plus a top-level "error" field whose value is exactly "command failed: <command>", where <command> is the command that failed. The script should terminate with exit code 0 when all commands succeed and exit code 1 when any command fails. For instance, given a configuration file containing {"token": "abc123", "commands": ["echo hello", "ls -l"]}, the script should execute both commands with AUTH_TOKEN set to abc123, capture their outputs, and produce the corresponding JSON report.
