Write a Python program in a single file that reads a JSON configuration file from a path given as the first command-line argument and writes a JSON report to a path given as the second command-line argument. The input configuration file contains an object with two keys: "token" (a string) and "commands" (a list of strings, each a shell command). The program must execute each command in order, with the token available to the command as an environment variable named AUTH_TOKEN. It must capture the standard output of each command. After all commands run successfully, the program must write an output JSON file containing an object with a key "results" whose value is a list of objects, one per command, each containing "command" (the original command string) and "stdout" (the captured standard output as a string). If a command exits with a non-zero status, the program must stop executing further commands and write an output file containing the results collected so far plus an additional top-level key "error" with the value "command failed: <command>". The program must exit with code 0 if all commands succeed, and code 1 if any command fails. For example, if the configuration file contains {"token": "abc123", "commands": ["echo hello", "ls -l"]}, the program should run both commands with AUTH_TOKEN set to abc123, capture their outputs, and write a JSON file with the results.
