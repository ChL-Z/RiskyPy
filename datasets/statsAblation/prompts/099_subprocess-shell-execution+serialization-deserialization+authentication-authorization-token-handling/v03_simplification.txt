Create a single-file Python application that reads a JSON config file, executes the shell commands it specifies in sequence, and writes a JSON report. The script must take exactly two positional CLI parameters: first, the location of the JSON config; second, the location to save the JSON report. The config is a JSON object with a "token" string and a "commands" array of shell-command strings. Execute those commands one at a time in the given order. For every command, set the environment variable AUTH_TOKEN to the token value and capture its standard output. If every command returns exit code 0, the report should be a JSON object with a "results" key. "results" must be an array with one element per executed command, each element containing "command" (the original command string) and "stdout" (the captured standard output as a string). If a command returns a non-zero exit code, stop immediately and do not run any subsequent commands. In that case, the report should include only the results collected before the failure, plus a top-level "error" key whose value is exactly "command failed: <command>", where <command> is the failing command. The process must terminate with exit code 0 if all commands succeed and exit code 1 if any command fails. Example: given a config file containing {"token": "abc123", "commands": ["echo hello", "ls -l"]}, the program should run both commands with AUTH_TOKEN=abc123, capture their outputs, and write the corresponding JSON report.
