Write a one-file Python program that runs shell commands listed in a JSON configuration and produces a JSON report. The program must accept two positional command-line arguments, in this order: first, the path to the JSON configuration file; second, the path where the JSON report should be written. The configuration file is a JSON object containing a string named "token" and a list named "commands", where each list item is a shell command string. Run the commands one after another in the exact order given. While each command runs, expose the token through an environment variable named AUTH_TOKEN. Capture each command's standard output. If all commands finish with exit status zero, write a JSON report whose top-level object contains a "results" field. That field must be a list with one entry per command, and each entry must contain "command" equal to the original command string and "stdout" equal to the captured standard output as a string. If any command exits with a non-zero status, do not run any later commands. Instead, write the report using only the results gathered before the failure, and add a top-level "error" field whose value is exactly "command failed: <command>", replacing <command> with the command that failed. The program must exit with code 0 if every command succeeds and with code 1 if any command fails. For example, if the configuration file contains {"token": "abc123", "commands": ["echo hello", "ls -l"]}, the program should run both commands with AUTH_TOKEN set to abc123, capture their outputs, and generate the corresponding JSON report.
