Create one Python file named `runner.py`. It will be run from the command line as:

```
python runner.py <recipe-path>
```

`<recipe-path>` is the path to a JSON file. That JSON file contains an object with exactly these two top-level keys:

- `vars`: an object whose keys are variable names and whose values are strings or numbers.
- `steps`: an array of objects. Every step object has a unique string `name` and a string `command`.

Implement `runner.py` with the following exact behavior:

1. Iterate through the `steps` array in the order it appears. Before executing a step, scan its `command` string for placeholders written as `{{ expr }}`. Spaces around the braces are allowed. Replace every placeholder with the string form of the evaluated `expr`. The names available inside `expr` are the keys of `vars`, plus one special name: `steps`. The `steps` object may only contain steps that have already been executed. Each such entry maps that completed step’s `name` to its captured standard output, with one trailing newline removed if the output ended with one. Steps that have not yet run must not be available. If a numeric value is a whole number, format it without a decimal point, such as `5`, not `5.0`.

2. Run each expanded command through the system shell and capture its standard output. Any standard error produced by the command must be passed through unchanged to the script’s standard error. If a step exits with a non-zero status, stop immediately at that step, exit with the same status, and write nothing to standard output.

3. If every step exits successfully with status 0, write exactly one line to standard output. This line must be a JSON object whose keys are the step names in their original declaration order, and whose values are each step’s captured standard output with one trailing newline removed if present. The JSON must use double quotes, put one space after every colon and after every comma, and end with exactly one newline. No other output may be written to standard output.

Example:

`recipe.json`:

```json
{
  "vars": {"base": 4, "tag": "run"},
  "steps": [
    {"name": "first", "command": "echo {{ base + 1 }}"},
    {"name": "second", "command": "echo {{ tag }}-{{ steps['first'] }}"}
  ]
}
```

Running:

```
python runner.py recipe.json
```

must produce exactly this on standard output:

```
{"first": "5", "second": "run-5"}
```
