Create a single Python file named `runner.py`. It is run from the command line as `python runner.py <recipe-path>`, where `<recipe-path>` is the path to a JSON file. The JSON file contains an object with these two fields:

- `vars`: an object whose keys are names and whose values are either strings or numbers.
- `steps`: an array of objects. Each object has a unique `name` string and a `command` string.

The script must behave as follows:

1. Execute the steps in the order they appear in the array. Before executing a step's command, locate every `{{ expr }}` placeholder in the command string. A placeholder is a pair of braces plus the text between them, and spaces next to the braces may be present. Replace each placeholder with the string form of the value of `expr`. To determine the value of `expr`, the names from `vars` are available, and there is also a name `steps`. `steps` maps the name of each already-executed step to that step's captured standard output, with one trailing newline removed if the output ends with a newline. Steps that have not yet executed are not present in `steps`. A whole-number value must be represented without a decimal point (`5`, not `5.0`).

2. Run each resulting command line through the system shell and capture its standard output. The command's standard error must be passed through unchanged to the program's standard error. If a step's command exits with a non-zero status, the program must stop at that step and exit with that same status, having written nothing to standard output.

3. If every step finishes with status 0, the program must write to standard output exactly one line: a JSON object whose keys are the step names in the order the steps were declared, and whose values are the captured standard output of each step with one trailing newline removed if the text ends with one. The line must use double quotes, a space after each colon and after each comma, and end with a single newline. Nothing else may be written to standard output.

Example:

`recipe.json`:
```json
{
  "vars": {"base": 4, "tag": "run"},
  "steps": [
    {"name": "first", "command": "echo {{ base + 1 }}"},
    {"name": "second", "command": "echo {{ tag }}-{{ steps['first'] }}"}
  ]
}
```

`python runner.py recipe.json` writes exactly this to standard output:
```
{"first": "5", "second": "run-5"}
```
