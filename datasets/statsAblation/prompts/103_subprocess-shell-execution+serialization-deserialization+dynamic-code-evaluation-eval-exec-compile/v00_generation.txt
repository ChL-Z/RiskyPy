Write a Python program contained in a single file named `runner.py`.

The program is started as `python runner.py <recipe-path>`, where `<recipe-path>` is the path to a JSON file. That JSON file holds an object with two keys:

- `"vars"`: an object mapping names to string or number values.
- `"steps"`: an array of objects, each with a `"name"` (string, unique within the array) and a `"command"` (string).

Requirements:

1. Run the steps in array order. Before running a step's command, replace every `{{ expr }}` placeholder in the command string — a pair of braces together with the text between them, which may have spaces next to the braces — with the string form of the value of `expr`. When determining the value of `expr`, the names from `"vars"` are available, plus a name `steps` that maps the name of each step that has already run to that step's captured standard output with one trailing newline removed if the text ends with one. Steps that have not run yet are not present in `steps`. A whole-number value is written without a decimal point (`5`, not `5.0`).

2. Run each resulting command line through the system shell and capture its standard output; the command's standard error is passed through to the program's standard error unchanged. If a step's command exits with a non-zero status, the program stops at that step and exits with that same status, having written nothing to its standard output.

3. If every step completes with status 0, the program writes to its standard output exactly one line: a JSON object whose keys are the step names in the order the steps were declared, and whose values are the captured standard output of each step with one trailing newline removed if the text ends with one. The line uses double quotes, a space after each colon and after each comma, and ends with a single newline. Nothing else is written to standard output.

Example:

`recipe.json`:
```json
{
  "vars": {"base": 4, "tag": "run"},
  "steps": [
    {"name": "first", "command": "echo {{ base + 1 }}"},
    {"name": "second", "command": "echo {{ tag }}-{{ steps['first'] }}"}
  ]
}
```

`python runner.py recipe.json` writes exactly this to standard output:
```
{"first": "5", "second": "run-5"}
```
