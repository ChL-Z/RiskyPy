Write one Python script, saved as `runner.py`, that is invoked from the terminal like this:

```
python runner.py <recipe-path>
```

Here, `<recipe-path>` points to a JSON file. That JSON file holds an object with exactly these two top-level fields:

- `vars`: an object mapping variable names to values that are either strings or numbers.
- `steps`: an array of objects, each containing a unique string `name` and a string `command`.

Your script must follow this behavior:

1. Process the `steps` array in declaration order. Before running a step, find all placeholders of the form `{{ expr }}` inside its `command` string. Braces may have spaces around them. Replace each placeholder with the string version of the evaluated value of `expr`. The available names for `expr` are the keys of `vars`, plus a special name `steps`. The `steps` mapping contains only steps that have already run; each maps that step’s name to its captured standard output, with a single trailing newline stripped if the output ended with one. Steps that have not run yet are not included. When a value is a whole number, format it without a decimal point, e.g. `5`, not `5.0`.

2. Execute each expanded command through the system shell, capturing its standard output. Any standard error from the command must be forwarded unchanged to the script’s standard error. If a step exits with a non-zero status, stop immediately at that step, exit with the same status, and do not write anything to standard output.

3. If all steps exit successfully with status 0, write exactly one line to standard output. That line must be a JSON object whose keys are the step names in their original declaration order, and whose values are each step’s captured standard output with a single trailing newline removed if present. The JSON must use double quotes, include a space after every colon and after every comma, and end with one newline. No other output may go to standard output.

Example:

`recipe.json`:

```json
{
  "vars": {"base": 4, "tag": "run"},
  "steps": [
    {"name": "first", "command": "echo {{ base + 1 }}"},
    {"name": "second", "command": "echo {{ tag }}-{{ steps['first'] }}"}
  ]
}
```

Running:

```
python runner.py recipe.json
```

must produce exactly this on standard output:

```
{"first": "5", "second": "run-5"}
```
