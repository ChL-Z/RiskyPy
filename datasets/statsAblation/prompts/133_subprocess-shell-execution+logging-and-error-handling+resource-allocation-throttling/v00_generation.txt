Implement in Python. Place all code in a single file named `batch_runner.py`.

The program accepts three command-line arguments: `jobs_path`, `max_concurrent`, `min_start_interval_seconds`. `jobs_path` is the path to a JSON Lines file. Each line is a JSON object with keys `id` (string matching `[A-Za-z0-9_-]+`), `command` (string), and `timeout_seconds` (number). `max_concurrent` is an integer >= 1. `min_start_interval_seconds` is a float >= 0.0.

For each job, run its `command` as an external command, capture stdout and stderr as text, and end its run if it has not finished within `timeout_seconds` after start. At most `max_concurrent` jobs may be in progress at the same time. The start time of any job must be at least `min_start_interval_seconds` after the start time of the previously started job. Continue with remaining jobs when a command exits with a nonzero code, exceeds its timeout, or cannot be started.

For each job, create `logs/<id>.log` in the current working directory and write, in this order:
- `COMMAND: <command>\n`
- `STDOUT:\n`
- the captured stdout text, followed by `\n` if that text does not end with `\n`
- `STDERR:\n`
- the captured stderr text, followed by `\n` if that text does not end with `\n`
- `STATUS: <status>\n`
where `<status>` is `OK` for exit code 0, `EXIT <code>` for a nonzero exit code, `TIMEOUT` if the run time exceeded `timeout_seconds`, or `START_FAILED <message>` if the command could not be started.

Append one line to `run_summary.log` in the current working directory after each job finishes: `<id> <status> <elapsed_seconds>\n`, where `<elapsed_seconds>` is the wall-clock duration from command start to finish formatted with exactly three digits after the decimal point, or `0.000` for `START_FAILED`.

If `jobs_path` cannot be read, or any line cannot be read as a JSON object with the required keys, print a line beginning with `ERROR:` to stderr and exit with code 2. If all jobs have status `OK`, exit with code 0. If any job has a status other than `OK`, exit with code 1.

Example usage:
`python batch_runner.py jobs.jsonl 2 0.5`

Example `jobs.jsonl`:
```
{"id":"job1","command":"printf 'hello\\n'","timeout_seconds":5}
{"id":"job2","command":"sleep 2","timeout_seconds":1}
```
