Write a Python script in a single file named `batch_runner.py`.

It must be runnable as:

`python batch_runner.py jobs.jsonl 2 0.5`

It takes three command-line arguments:

1. `jobs_path`: path to a JSON Lines file.
   - Each line must be a JSON object with keys:
     - `id`: string matching `[A-Za-z0-9_-]+`
     - `command`: string
     - `timeout_seconds`: number
2. `max_concurrent`: integer >= 1
3. `min_start_interval_seconds`: float >= 0.0

For every job:

- Run its `command` as an external command.
- Capture stdout and stderr as text.
- If the command has not finished within `timeout_seconds` after it starts, end its run.
- At most `max_concurrent` jobs may be in progress at the same time.
- The start time of any job must be at least `min_start_interval_seconds` after the start time of the previously started job.
- If a command exits with a nonzero code, exceeds its timeout, or cannot be started, continue processing the remaining jobs.

For each job, create `logs/<id>.log` in the current working directory and write the following, exactly in this order:

- `COMMAND: <command>\n`
- `STDOUT:\n`
- the captured stdout text, followed by `\n` if that text does not already end with `\n`
- `STDERR:\n`
- the captured stderr text, followed by `\n` if that text does not already end with `\n`
- `STATUS: <status>\n`

`<status>` must be one of:

- `OK` if the exit code is 0
- `EXIT <code>` if the exit code is nonzero
- `TIMEOUT` if the run time exceeded `timeout_seconds`
- `START_FAILED <message>` if the command could not be started

After each job finishes, append one line to `run_summary.log` in the current working directory:

`<id> <status> <elapsed_seconds>\n`

where `<elapsed_seconds>` is the wall-clock duration from command start to finish, formatted with exactly three digits after the decimal point. For `START_FAILED`, use `0.000`.

If `jobs_path` cannot be read, or if any line cannot be read as a JSON object with the required keys, print a line beginning with `ERROR:` to stderr and exit with code 2.

If all jobs have status `OK`, exit with code 0. If any job has a status other than `OK`, exit with code 1.

Example `jobs.jsonl`:

```
{"id":"job1","command":"printf 'hello\\n'","timeout_seconds":5}
{"id":"job2","command":"sleep 2","timeout_seconds":1}
```
