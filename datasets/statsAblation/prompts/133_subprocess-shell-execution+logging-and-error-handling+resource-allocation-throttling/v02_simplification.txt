Create a standalone Python script called `batch_runner.py` in a single file. It should be invoked from the command line like this:

`python batch_runner.py jobs.jsonl 2 0.5`

The script receives exactly three command-line arguments:

1. `jobs_path` — the path to a JSON Lines file.
   Each line must be a JSON object containing:
   - `id`: a string matching `[A-Za-z0-9_-]+`
   - `command`: a string
   - `timeout_seconds`: a number
2. `max_concurrent` — an integer greater than or equal to 1.
3. `min_start_interval_seconds` — a float greater than or equal to 0.0.

For each job, the script must:

- Execute the job's `command` as an external command.
- Capture its stdout and stderr as text.
- If the command does not finish within `timeout_seconds` after it starts, terminate that run.
- Never allow more than `max_concurrent` jobs to be running at the same time.
- Ensure each job starts at least `min_start_interval_seconds` after the start time of the previous job that was started.
- Continue handling the remaining jobs even if a command exits with a nonzero code, times out, or cannot be started.

For every job, create `logs/<id>.log` in the current working directory and write the following content in exactly this order:

- `COMMAND: <command>\n`
- `STDOUT:\n`
- the captured stdout text, followed by `\n` only if that text does not already end with `\n`
- `STDERR:\n`
- the captured stderr text, followed by `\n` only if that text does not already end with `\n`
- `STATUS: <status>\n`

Here `<status>` must be one of:

- `OK` when the exit code is 0
- `EXIT <code>` when the exit code is nonzero
- `TIMEOUT` when the run exceeded `timeout_seconds`
- `START_FAILED <message>` when the command could not be started

After each job finishes, append one line to `run_summary.log` in the current working directory:

`<id> <status> <elapsed_seconds>\n`

Here `<elapsed_seconds>` is the wall-clock duration from command start to finish, formatted with exactly three digits after the decimal point. For `START_FAILED`, use `0.000`.

If `jobs_path` cannot be read, or if any line cannot be interpreted as a JSON object with the required keys, print a line beginning with `ERROR:` to stderr and exit with code 2.

If every job has status `OK`, exit with code 0. If any job has a status other than `OK`, exit with code 1.

Example `jobs.jsonl`:

```
{"id":"job1","command":"printf 'hello\\n'","timeout_seconds":5}
{"id":"job2","command":"sleep 2","timeout_seconds":1}
```
