Write a single-file, self-contained Python script named `batch_runner.py`. It must be runnable from the command line exactly like this:

`python batch_runner.py jobs.jsonl 2 0.5`

The script takes exactly three command-line arguments:

1. `jobs_path`: path to a JSON Lines file. Each line must be a JSON object with these keys:
   - `id`: a string matching `[A-Za-z0-9_-]+`
   - `command`: a string
   - `timeout_seconds`: a number
2. `max_concurrent`: an integer at least 1.
3. `min_start_interval_seconds`: a float at least 0.0.

For every job, the script must:

- Run the job’s `command` as an external command.
- Capture stdout and stderr as text.
- If the command is still running after `timeout_seconds` from its start, terminate it.
- Never run more than `max_concurrent` jobs simultaneously.
- Make each job start no sooner than `min_start_interval_seconds` after the previous job’s start time.
- Keep processing later jobs even if a command exits nonzero, times out, or fails to start.

For each job, write `logs/<id>.log` relative to the current working directory. The file content must appear in exactly this order:

- `COMMAND: <command>\n`
- `STDOUT:\n`
- the captured stdout, adding `\n` only if that text does not already end with `\n`
- `STDERR:\n`
- the captured stderr, adding `\n` only if that text does not already end with `\n`
- `STATUS: <status>\n`

`<status>` must be exactly one of:

- `OK` if exit code is 0
- `EXIT <code>` if exit code is nonzero
- `TIMEOUT` if the run exceeded `timeout_seconds`
- `START_FAILED <message>` if the command could not be started

After each job completes, append one line to `run_summary.log` in the current working directory:

`<id> <status> <elapsed_seconds>\n`

`<elapsed_seconds>` is the wall-clock time from command start to finish, formatted with exactly three digits after the decimal point. For `START_FAILED`, use `0.000`.

If `jobs_path` cannot be read, or if any line is not a JSON object with the required keys, print a line beginning with `ERROR:` to stderr and exit with code 2.

Exit with code 0 only if every job has status `OK`. If any job has a non-`OK` status, exit with code 1.

Example `jobs.jsonl`:

```
{"id":"job1","command":"printf 'hello\\n'","timeout_seconds":5}
{"id":"job2","command":"sleep 2","timeout_seconds":1}
```
