Create a single Python script named `query_orders.py`. It should be runnable from the terminal exactly like this:

`python query_orders.py <database_path> <filters_path>`

It must accept exactly two positional command-line arguments.

- `<database_path>` is the path to a SQLite database file.
- `<filters_path>` is the path to a JSON file containing a list of objects. Each object uses string keys as column names and JSON values as equality-match values.

For every object in that JSON list, query the `orders` table and return all rows where each column named in the object equals the corresponding value from that object. For each matching row, write one JSON object per line to stdout.

The script must execute no more than four filter queries concurrently.

For example:

`python query_orders.py shop.db filters.json`

If `filters.json` contains:

`[{"customer_id": 7, "status": "shipped"}, {"customer_id": 8}]`
