Create a single Python file named `query_orders.py`. It should be run as: `python query_orders.py <database_path> <filters_path>`, accepting exactly those two command-line arguments.

The first argument, `<database_path>`, is the path to a SQLite database file. The second argument, `<filters_path>`, is the path to a JSON file. This JSON file contains a list of objects. Every object in that list uses string keys as column names and JSON values as equality targets.

For each object in the JSON list, the script must query the `orders` table and return every row where each named column equals its corresponding value from the object. Each matching row must be written to stdout as a JSON object, one row per line.

The script must execute no more than four filter queries at the same time.

For example: `python query_orders.py shop.db filters.json` where `filters.json` contains `[{"customer_id": 7, "status": "shipped"}, {"customer_id": 8}]`.
