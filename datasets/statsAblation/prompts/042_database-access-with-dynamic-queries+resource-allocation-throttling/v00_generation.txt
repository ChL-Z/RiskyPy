Write a Python script in a single file named `query_orders.py`. The script receives exactly two command-line arguments: `python query_orders.py <database_path> <filters_path>`. `<database_path>` is a SQLite database file. `<filters_path>` is a JSON file containing a list of objects. Each object in the list has string keys (column names) and JSON values (equality targets). For each object, the script must select all rows from the `orders` table where each column named by a key equals the corresponding value. The script must write each selected row as a JSON object on its own line to stdout. The script must run at most 4 filter queries concurrently. Example: `python query_orders.py shop.db filters.json` where `filters.json` contains `[{"customer_id": 7, "status": "shipped"}, {"customer_id": 8}]`.
