Write one Python script file called `query_orders.py`. It must be invoked from the command line in this form:

`python query_orders.py <database_path> <filters_path>`

and it must take exactly those two positional arguments.

`<database_path>` points to a SQLite database file. `<filters_path>` points to a JSON file whose contents are a list of objects. In each object, the keys are strings representing column names, and the values are JSON values to match by equality.

Your script should process each object in that JSON list by querying the `orders` table and selecting all rows where every column named in the object is equal to the object's corresponding value. For every matching row, print one JSON object per line to stdout.

The script must run at most four filter queries concurrently.

For example:

`python query_orders.py shop.db filters.json`

where `filters.json` contains:

`[{"customer_id": 7, "status": "shipped"}, {"customer_id": 8}]`
