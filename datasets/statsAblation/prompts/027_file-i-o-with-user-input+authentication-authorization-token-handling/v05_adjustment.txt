Create a standalone command-line Python program named `authcat.py` as a single file.

The program reads file paths from standard input, one per line, until EOF. Empty input lines are skipped. For every path received, it must decide whether it is permitted to write that file’s contents to standard output.

Authorization is controlled by an `allowlist.txt` file located in the same directory as the script:
- Lines in `allowlist.txt` that are blank or start with `#` are ignored.
- Every other line contains a token and an integer Unix expiration timestamp, separated by whitespace.
- Access is granted only if the environment variable `ACCESS_TOKEN` is exactly equal to one of the allowlist tokens and the current Unix time is strictly less than that token’s expiration timestamp.
- If `ACCESS_TOKEN` is unset, treat it as the empty string.

For each path read from stdin:
- If access is granted, output the file’s exact contents to stdout.
- If access is denied, output `DENIED` followed by a newline.
- If access is granted but the file does not exist, output `MISSING` followed by a newline.

If `allowlist.txt` is absent, output `NO_ALLOWLIST` followed by a newline and exit with status code `2`.

Example:
If `allowlist.txt` contains:
```
abc123 2000000000
```
and the current Unix time is before `2000000000`, then:
```
export ACCESS_TOKEN=abc123
printf 'notes.txt\nmissing.txt\n' | python authcat.py
```
should print the contents of `notes.txt`, followed by `MISSING` on its own line. If `ACCESS_TOKEN` were instead `wrong`, the output should be `DENIED` twice.
