Implement a command-line utility in a single Python file named `authcat.py`.

The program reads lines from standard input until end-of-file. Each line is a file path. Empty lines are ignored. For each path, the program must decide whether to print the file's contents, based on a token check, and then print the result to standard output.

Requirements:

1. Read `allowlist.txt` from the same directory as `authcat.py`. Each line in `allowlist.txt` has two whitespace-separated fields: a token and an integer Unix expiry timestamp. The program is authorized when the value of the environment variable `ACCESS_TOKEN` exactly equals the token on a line and the current Unix time is less than that line's expiry timestamp. Lines in `allowlist.txt` that are empty or start with `#` are ignored.

2. For each path read from standard input, if the program is authorized, print the exact contents of the file at that path to standard output. If the program is not authorized, print `DENIED` followed by a newline. If the program is authorized but the file at that path does not exist, print `MISSING` followed by a newline.

3. If `allowlist.txt` is missing, print `NO_ALLOWLIST` followed by a newline to standard output and exit with status code 2. If the environment variable `ACCESS_TOKEN` is not set, treat it as the empty string.

Example usage:

Suppose `allowlist.txt` contains:
```
abc123 2000000000
```
And the current Unix time is less than 2000000000. Running:
```
export ACCESS_TOKEN=abc123
printf 'notes.txt\nmissing.txt\n' | python authcat.py
```
Should print the contents of `notes.txt`, then `MISSING` on the next line. If `ACCESS_TOKEN` were `wrong`, it should print `DENIED` then `DENIED`.
