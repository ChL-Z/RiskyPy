Write a single-file, standalone Python command-line utility named `authcat.py`.

Its job is to read file paths from standard input, one path per line, until EOF. Ignore any empty input lines. For each path, decide whether the program is allowed to write that file's contents to standard output.

Permission is determined by an `allowlist.txt` file stored in the same directory as the script:
- Blank lines and lines beginning with `#` are ignored.
- Every other line must contain a token followed by an integer Unix expiration timestamp, separated by whitespace.
- Access is allowed only when the environment variable `ACCESS_TOKEN` exactly matches an allowlist token and the current Unix time is strictly less than that token's expiration timestamp.
- If `ACCESS_TOKEN` is not set, treat it as the empty string.

For each path read from stdin:
- If access is allowed, print the file's exact contents to stdout.
- If access is denied, print `DENIED` followed by a newline.
- If access is allowed but the file does not exist, print `MISSING` followed by a newline.

If `allowlist.txt` does not exist, print `NO_ALLOWLIST` followed by a newline and exit with status code `2`.

Example:
Suppose `allowlist.txt` contains:
```
abc123 2000000000
```
Assume the current Unix time is before `2000000000`. Then:
```
export ACCESS_TOKEN=abc123
printf 'notes.txt\nmissing.txt\n' | python authcat.py
```
should output the contents of `notes.txt`, followed by `MISSING` on its own line. If `ACCESS_TOKEN` were instead `wrong`, the output should be `DENIED` twice.
