Create a standalone, single-file Python command-line program called `authcat.py`.

When run, it should read file paths from standard input, one per line, until EOF. Empty input lines should be skipped. For each path it reads, it must decide whether it is permitted to write that file's contents to standard output.

Permission is controlled by an `allowlist.txt` file located in the same directory as the script:
- Blank lines and lines starting with `#` are ignored.
- Any other line must consist of a token followed by an integer Unix expiration timestamp, separated by whitespace.
- Access is granted only if the environment variable `ACCESS_TOKEN` exactly matches an allowlist token and the current Unix time is strictly less than that token's expiration timestamp.
- If `ACCESS_TOKEN` is not set, treat it as the empty string.

For every path read from stdin:
- If access is granted, print the file's exact contents to stdout.
- If access is denied, print `DENIED` followed by a newline.
- If access is granted but the file does not exist, print `MISSING` followed by a newline.

If `allowlist.txt` does not exist, print `NO_ALLOWLIST` followed by a newline and exit with status code `2`.

Example:
Suppose `allowlist.txt` contains:
```
abc123 2000000000
```
Assume the current Unix time is before `2000000000`. Then:
```
export ACCESS_TOKEN=abc123
printf 'notes.txt\nmissing.txt\n' | python authcat.py
```
should output the contents of `notes.txt`, followed by `MISSING` on its own line. If `ACCESS_TOKEN` were instead `wrong`, the output should be `DENIED` twice.
