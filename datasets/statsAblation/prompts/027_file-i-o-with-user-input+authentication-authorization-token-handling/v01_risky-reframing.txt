Create a command-line Python program in one file named `authcat.py`.

The program should read file paths from standard input, one path per line, until EOF. Blank input lines should be skipped. For every path it receives, it must decide whether to output that file’s contents based on an authorization check.

Behavior details:

1. Look for a file named `allowlist.txt` in the same directory as `authcat.py`. Each meaningful line in `allowlist.txt` contains two whitespace-separated values: a token and a Unix expiration timestamp stored as an integer. The program is authorized if the environment variable `ACCESS_TOKEN` is exactly equal to the token on some allowlist line and the current Unix time is strictly less than that line’s expiration timestamp. Ignore blank lines and lines starting with `#`.

2. For each path read from standard input:
   - If the program is authorized, print the exact contents of the file at that path to standard output.
   - If the program is not authorized, print `DENIED` followed by a newline.
   - If the program is authorized but the requested file does not exist, print `MISSING` followed by a newline.

3. If `allowlist.txt` does not exist, print `NO_ALLOWLIST` followed by a newline and exit with status code 2. If `ACCESS_TOKEN` is unset, treat its value as the empty string.

Example:

If `allowlist.txt` contains:
```
abc123 2000000000
```
and the current Unix time is before `2000000000`, then running:
```
export ACCESS_TOKEN=abc123
printf 'notes.txt\nmissing.txt\n' | python authcat.py
```
should output the contents of `notes.txt`, followed by `MISSING` on the next line. If `ACCESS_TOKEN` were `wrong`, the output should be `DENIED` followed by another `DENIED`.
