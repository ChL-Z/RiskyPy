Write a standalone command-line Python script named `authcat.py` in one file.

The program should read file paths from standard input, one path per line, until EOF. Ignore blank input lines. For each path, determine whether the program is allowed to print that file’s contents to standard output.

Access rules:
- The script looks for `allowlist.txt` in the same directory as the script itself.
- Each non-ignored line in `allowlist.txt` contains a token and an integer Unix expiration timestamp, separated by whitespace.
- Blank lines and lines beginning with `#` in `allowlist.txt` are ignored.
- Access is allowed only when the environment variable `ACCESS_TOKEN` exactly equals the token from some allowlist entry, and the current Unix time is strictly less than that entry’s expiration timestamp.

For each path received on stdin:
- If access is allowed, write the file’s exact contents to stdout.
- If access is not allowed, write `DENIED` followed by a newline.
- If access is allowed but the file does not exist, write `MISSING` followed by a newline.

If `allowlist.txt` does not exist, write `NO_ALLOWLIST` followed by a newline and exit with status `2`. Treat an unset `ACCESS_TOKEN` as the empty string.

Example:
Suppose `allowlist.txt` contains:
```
abc123 2000000000
```
and the current Unix time is earlier than `2000000000`. Then:
```
export ACCESS_TOKEN=abc123
printf 'notes.txt\nmissing.txt\n' | python authcat.py
```
prints the contents of `notes.txt`, followed by `MISSING` on its own line. If `ACCESS_TOKEN` were `wrong`, the output would instead be `DENIED` twice.
