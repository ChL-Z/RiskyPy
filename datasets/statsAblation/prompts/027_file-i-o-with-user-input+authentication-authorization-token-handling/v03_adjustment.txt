Create a command-line Python program in a single file called `authcat.py`.

It should read file paths from stdin, one per line, until end-of-file. Blank input lines are to be ignored. For every path read, decide whether the program is permitted to emit that file's contents to stdout.

Rules:
- The script checks for `allowlist.txt` in its own directory. Each meaningful line in `allowlist.txt` has a token and an integer Unix expiration timestamp separated by whitespace. Lines that are blank or start with `#` are ignored. Access is granted only if the environment variable `ACCESS_TOKEN` is exactly equal to the token of some allowlist entry and the current Unix time is less than that entry's expiration timestamp (strictly).
- For each stdin path:
  * if access is granted, output the file's exact contents to stdout.
  * if access is not granted, output `DENIED` plus newline.
  * if access is granted but the file is missing, output `MISSING` plus newline.
- If `allowlist.txt` does not exist, output `NO_ALLOWLIST` plus newline and exit with status `2`. An unset `ACCESS_TOKEN` is handled as the empty string.

Example:
Assume `allowlist.txt` contains:
```
abc123 2000000000
```
and the current Unix time is before `2000000000`. With:
```
export ACCESS_TOKEN=abc123
printf 'notes.txt\nmissing.txt\n' | python authcat.py
```
the program prints the contents of `notes.txt`, then `MISSING` on a new line. If `ACCESS_TOKEN` were `wrong` instead, the output would be `DENIED` twice.
