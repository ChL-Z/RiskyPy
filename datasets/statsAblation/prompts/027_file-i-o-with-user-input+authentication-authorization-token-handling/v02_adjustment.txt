Write a single-file Python command-line utility named `authcat.py`.

The script reads file paths from standard input, one path per line, until EOF. Lines that are blank should be ignored. For each path, the script must determine whether it is allowed to write that file's contents to standard output.

Requirements:

1. In the same directory as `authcat.py`, look for `allowlist.txt`. Each non-empty, non-comment line in this file contains a token and an integer Unix expiration timestamp, separated by whitespace. Comment lines begin with `#` and should be skipped, as should blank lines. Authorization succeeds only when the environment variable `ACCESS_TOKEN` exactly matches the token from some allowlist entry and the current Unix time is strictly less than that entry's expiration timestamp.

2. For each path received on standard input:
   - If authorized, print the exact contents of the file at that path to standard output.
   - If not authorized, print `DENIED` followed by a newline.
   - If authorized but the file does not exist, print `MISSING` followed by a newline.

3. If `allowlist.txt` is absent, print `NO_ALLOWLIST` followed by a newline and terminate with exit status `2`. If `ACCESS_TOKEN` is not set, treat it as an empty string.

Example:

Given an `allowlist.txt` containing:
```
abc123 2000000000
```
and assuming the current Unix time is earlier than `2000000000`, running:
```
export ACCESS_TOKEN=abc123
printf 'notes.txt\nmissing.txt\n' | python authcat.py
```
should print the contents of `notes.txt`, then print `MISSING` on the following line. If `ACCESS_TOKEN` were instead `wrong`, the output should be `DENIED` followed by another `DENIED`.
