Write a single Python file called `run_checks.py`. It accepts exactly one command-line argument: the path to an XML checks file, and is run like `python run_checks.py path/to/checks.xml`. The XML has a root `<checks>` element with a `db` attribute giving the SQLite database path. Its `<check>` children each have `name`, `command`, and `table` attributes. For example:

```xml
<checks db="results.db">
  <check name="disk" command="df -h" table="disk_runs"/>
  <check name="math" command="python -c 'print(1+2)'" table="math_runs"/>
</checks>
```

Your program should do the following:

1. Process every `<check>` in the order it appears in the XML. Execute its `command` attribute as a shell command line.
2. Capture both standard output and standard error, with stdout first and stderr second, plus the command's exit code. After each command completes, print a single line to stdout in the format `name=exit_code`.
3. For the SQLite database specified by the `db` attribute, resolve relative paths against the directory containing the XML file. Make sure the table named by the check's `table` attribute exists, with these columns: `check_name TEXT`, `exit_code INTEGER`, `output TEXT`, `started_at TEXT`. Insert one row for each check. The `started_at` value must be the UTC timestamp of when the command starts, formatted as `YYYY-MM-DDTHH:MM:SSZ`.

If the XML cannot be read, or the database cannot be opened or written, print a line to stderr that begins with `error: ` and exit with status 1. In all other cases, exit with status 0.
