Create one Python file named `run_checks.py`. It must accept exactly one command-line argument: the path to an XML checks file, and be run like `python run_checks.py path/to/checks.xml`. The XML root is `<checks>` with a `db` attribute that specifies the SQLite database path. Each child `<check>` has `name`, `command`, and `table` attributes. For example:

```xml
<checks db="results.db">
  <check name="disk" command="df -h" table="disk_runs"/>
  <check name="math" command="python -c 'print(1+2)'" table="math_runs"/>
</checks>
```

The program must do the following:

1. Walk through every `<check>` in the exact order it appears in the XML. Run the value of its `command` attribute as a shell command line.
2. Capture standard output and standard error, keeping stdout before stderr, and also capture the command's exit code. After the command finishes, print one line to stdout in the form `name=exit_code`.
3. For the SQLite database named by the root `db` attribute, resolve relative paths against the directory containing the XML file. For each check, ensure that the table specified by its `table` attribute exists with these columns: `check_name TEXT`, `exit_code INTEGER`, `output TEXT`, `started_at TEXT`. Insert one row per check. The `output` value must be the captured stdout followed by the captured stderr. The `started_at` value must be the UTC timestamp for when the command starts, formatted as `YYYY-MM-DDTHH:MM:SSZ`.

If the XML cannot be read, or the database cannot be opened or written, print a line to stderr beginning with `error: ` and exit with status 1. In every other case, exit with status 0.
