Create a Python program in a single file named `run_checks.py`. The program takes one command-line argument: the path to an XML checks file. Run it as `python run_checks.py path/to/checks.xml`. The XML file has a root element `<checks>` with a `db` attribute holding a path to a SQLite database file. Each child element `<check>` has `name`, `command`, and `table` attributes. For example:

```xml
<checks db="results.db">
  <check name="disk" command="df -h" table="disk_runs"/>
  <check name="math" command="python -c 'print(1+2)'" table="math_runs"/>
</checks>
```

The program must:

1. For each `<check>` in the order it appears, run the `command` attribute as a shell command line.
2. Capture the command's standard output followed by its standard error, and its exit code. After each check finishes, print one line to standard output in the form `name=exit_code`.
3. In the SQLite database at the path from the `db` attribute, resolve relative paths against the directory containing the XML file, ensure a table named by the `table` attribute exists with columns `check_name TEXT`, `exit_code INTEGER`, `output TEXT`, `started_at TEXT`, and insert one row per check. `started_at` must be the UTC timestamp when the command starts, in the format `YYYY-MM-DDTHH:MM:SSZ`.

If the XML file cannot be read or the database cannot be opened or written, print a line starting with `error: ` to standard error and exit with code 1. Otherwise exit with code 0.
