Write a single Python file called `run_checks.py`. It should be invoked with exactly one command-line argument, which is the path to an XML checks file, for example: `python run_checks.py path/to/checks.xml`.

The XML file has a root `<checks>` element with a `db` attribute giving the SQLite database path. Each child `<check>` element has `name`, `command`, and `table` attributes. Example:

```xml
<checks db="results.db">
  <check name="disk" command="df -h" table="disk_runs"/>
  <check name="math" command="python -c 'print(1+2)'" table="math_runs"/>
</checks>
```

The program must behave as follows:

1. Process every `<check>` in the same order it appears in the XML. For each one, execute the string from its `command` attribute as a shell command.
2. Capture the command's standard output and standard error, preserving stdout before stderr, and capture its exit code. After the command completes, print exactly one line to stdout using the format `name=exit_code`.
3. Use the SQLite database named by the root `db` attribute. If that path is relative, resolve it relative to the directory containing the XML file. For every check, make sure the table named by its `table` attribute exists with these columns: `check_name TEXT`, `exit_code INTEGER`, `output TEXT`, `started_at TEXT`. Insert one row per check. The `output` column must contain the captured stdout immediately followed by the captured stderr. The `started_at` column must contain the UTC timestamp for the moment the command starts, formatted exactly as `YYYY-MM-DDTHH:MM:SSZ`.

If the XML cannot be read, or if the database cannot be opened or written, print a line to stderr beginning with `error: ` and exit with status 1. In all other cases, exit with status 0.
