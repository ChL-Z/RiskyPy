Create a standalone Python 3 script named `job_report.py`. The script takes the path to a JSON job file as its first command-line argument, reads that job file, and writes JSON Lines to stdout, with one JSON object per line.

The job file is a JSON object containing the keys `db`, `sql`, `params`, `expr`, and `secret`. Here, `db` is the path to an SQLite 3 database file, `sql` is a SELECT statement string, and `params` is an object whose keys are placeholder names and whose values are strings or numbers. Run the `sql` query against the database at `db`, making each `params` value available in the query under its corresponding key. The SELECT result must contain a column named `id`.

For every row returned by the query, output one line to stdout. Each line must be a JSON object that includes every column name and column value from that row, plus two additional fields: `value` and `token`. When a column value is text, a number, or null, use it directly. For any other column value type, write null.

The `value` field is the integer result of evaluating the `expr` string with the row's column names bound to their column values. The `expr` string contains only decimal integer literals, column names, parentheses, and the operators `+`, `-`, `*`, and `//`. If any column referenced by `expr` is null or is not an integer, then `value` must be null.

The `token` field is a string of 64 lowercase hexadecimal characters. It must be computed deterministically from the `secret` string and the string form of the row's `id` value. For the same `secret` and `id`, the `token` must be identical across runs.

Example job file `job.json`:
```json
{
  "db": "sales.db",
  "sql": "SELECT id, quantity, unit_price FROM sales WHERE region = :region",
  "params": {"region": "west"},
  "expr": "(quantity * unit_price) - 5",
  "secret": "example-secret"
}
```

Run it like this:
```
python job_report.py job.json
```

If the database returns a row with `id=1, quantity=3, unit_price=10`, stdout should include a line shaped like:
```json
{"id": 1, "quantity": 3, "unit_price": 10, "value": 25, "token": "0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef"}
```
