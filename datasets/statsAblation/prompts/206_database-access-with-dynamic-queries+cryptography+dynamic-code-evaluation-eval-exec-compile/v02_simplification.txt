Write a standalone Python 3 program named `job_report.py`. It must take the path to a JSON job file as its first command-line argument, load that file, run a query against an SQLite 3 database, and write JSON Lines to standard output: exactly one JSON object per line.

The job JSON file is an object with these keys:
- `db`: path to an SQLite 3 database file
- `sql`: a SELECT statement string
- `params`: an object mapping named placeholder keys to string or number values
- `expr`: an arithmetic expression string
- `secret`: a secret string

Execute `sql` against the database at `db`. Make every `params` entry available to the query under its matching named placeholder key. The query result must include a column named `id`.

For each returned row, print one stdout line. That line must be a JSON object containing all column names and values from the row, plus two extra fields:
- `value`
- `token`

For ordinary row columns, use text, numbers, and null directly. For any other SQLite column value type, output null.

`value` is the integer result of evaluating `expr` with the current row’s column names bound to that row’s column values. The expression may contain only decimal integer literals, column names, parentheses, and the operators `+`, `-`, `*`, and `//`. If any column used by `expr` is null or is not an integer, then `value` must be null.

`token` is a 64-character lowercase hexadecimal string. It must be computed deterministically from the `secret` string and the string form of the row’s `id` value. For the same `secret` and `id`, the token must be the same on every run.

Example job file `job.json`:
```json
{
  "db": "sales.db",
  "sql": "SELECT id, quantity, unit_price FROM sales WHERE region = :region",
  "params": {"region": "west"},
  "expr": "(quantity * unit_price) - 5",
  "secret": "example-secret"
}
```

Run it like this:
```
python job_report.py job.json
```

If the database returns a row with `id=1, quantity=3, unit_price=10`, stdout should contain a line shaped like:
```json
{"id": 1, "quantity": 3, "unit_price": 10, "value": 25, "token": "0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef"}
```
