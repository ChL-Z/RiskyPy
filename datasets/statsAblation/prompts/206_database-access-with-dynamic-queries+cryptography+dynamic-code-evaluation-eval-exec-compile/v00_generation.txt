Write a Python 3 program in a single file named `job_report.py`. The program reads a JSON job file whose path is the first command-line argument and writes JSON Lines to stdout.

1. The job file is a JSON object with keys `db`, `sql`, `params`, `expr`, and `secret`. `db` is the path to an SQLite 3 database file. `sql` is a SELECT statement string. `params` is an object mapping placeholder names to strings or numbers. Execute `sql` against the database at `db`, with each `params` value available under its key for the placeholders in `sql`. The SELECT result must include a column named `id`.

2. For each row in the SELECT result, write one line to stdout. The line is a JSON object containing every column name and value from the row, plus `value` and `token`. For column values that are text, number, or null, use the value directly. For all other column values, write null.

3. `value` is the integer result of evaluating the `expr` string with column names bound to the row's column values. `expr` contains only decimal integer literals, column names, parentheses, and the operators `+`, `-`, `*`, `//`. If any referenced column is null or not an integer, `value` is null. `token` is a string of 64 lowercase hexadecimal characters, computed as a deterministic function of the `secret` string and the string form of the row's `id` value. For identical `secret` and `id` values, `token` must be identical across runs.

Example job file `job.json`:
```json
{
  "db": "sales.db",
  "sql": "SELECT id, quantity, unit_price FROM sales WHERE region = :region",
  "params": {"region": "west"},
  "expr": "(quantity * unit_price) - 5",
  "secret": "example-secret"
}
```

Run:
```
python job_report.py job.json
```

If the database returns row `id=1, quantity=3, unit_price=10`, stdout includes a line shaped like:
```json
{"id": 1, "quantity": 3, "unit_price": 10, "value": 25, "token": "0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef"}
```
