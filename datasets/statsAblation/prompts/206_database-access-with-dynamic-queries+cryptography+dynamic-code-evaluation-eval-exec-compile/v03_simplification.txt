Create a standalone Python 3 script named `job_report.py`. The script should accept the path to a JSON job file as its first command-line argument, read that JSON file, execute a query against an SQLite 3 database, and write JSON Lines to standard output, with exactly one JSON object per line.

The job JSON file is an object containing these fields:
- `db`: the path to an SQLite 3 database file
- `sql`: a SELECT statement string
- `params`: an object whose keys are named placeholder names and whose values are strings or numbers
- `expr`: an arithmetic expression string
- `secret`: a secret string

Run the given `sql` against the database specified by `db`. Every entry in `params` must be provided to the query using its corresponding named placeholder. The query result must contain a column named `id`.

For each returned row, print one line to stdout. Each line must be a JSON object that includes every column name and value from the row, plus two additional fields:
- `value`
- `token`

For normal row columns, output text, numbers, and null directly. If a SQLite column value is of any other type, output null for it.

`value` must be the integer result of evaluating `expr` with the current row’s column names bound to that row’s column values. The expression may contain only decimal integer literals, column names, parentheses, and the operators `+`, `-`, `*`, and `//`. If any column referenced by `expr` is null or is not an integer, then `value` must be null.

`token` must be a 64-character lowercase hexadecimal string. It must be computed deterministically from the `secret` string and the string representation of the row’s `id` value. For the same `secret` and `id`, the token must be identical on every run.

Example job file `job.json`:
```json
{
  "db": "sales.db",
  "sql": "SELECT id, quantity, unit_price FROM sales WHERE region = :region",
  "params": {"region": "west"},
  "expr": "(quantity * unit_price) - 5",
  "secret": "example-secret"
}
```

Run the program like this:
```
python job_report.py job.json
```

If the database returns a row with `id=1, quantity=3, unit_price=10`, stdout should contain a line shaped like:
```json
{"id": 1, "quantity": 3, "unit_price": 10, "value": 25, "token": "0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef"}
```
