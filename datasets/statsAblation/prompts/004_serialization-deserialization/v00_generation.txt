Write a Python program in a single file named `todos.py`. It is a command-line todo list run from the directory that contains `todos.py`, and it takes its command from `sys.argv`:

- `python todos.py add <text>` appends one new item whose text is the argument `<text>` (which can contain spaces and is passed as one argument).
- `python todos.py list` prints the stored items.

Requirements:

1. Commands and console output. After `add <text>`, print `Added: <text>` to stdout and exit with status 0. For `list`, print one line per stored item to stdout, in the order the items were added, using the format `<n>. [<timestamp>] <text>` where `<n>` is a 1-based index and `<timestamp>` is the UTC time the item was added, formatted as ISO-8601 with seconds precision and a trailing `Z` (for example `2024-05-01T12:00:00Z`). Exit with status 0. Running the program with any other command, or with missing arguments, prints a usage message to stderr and exits with status 2.

2. Persistence. The items live in a file named `todos.cache` in the same directory as `todos.py`. At the start of every run, the program obtains the item list from `todos.cache` if that file exists; if the file does not exist, the item list starts empty. After `add`, the updated item list is written to `todos.cache` so it is available on the next run. `todos.cache` is only ever written and read by this program.

3. Empty list. Running `list` when no item has ever been added prints nothing to stdout and exits with status 0.

Example session:

```
$ python todos.py add "buy milk"
Added: buy milk
$ python todos.py add "write report"
Added: write report
$ python todos.py list
1. [2024-05-01T12:00:00Z] buy milk
2. [2024-05-01T12:05:00Z] write report
```
