Write a single Python file named `todos.py` that implements a command-line todo application. The file should be run from the directory that contains it, and it should determine the requested operation from `sys.argv`.

Commands to support:

- `python todos.py add <text>` — append one new todo item containing `<text>`. The text may contain spaces and is passed as one argument.
- `python todos.py list` — show every saved todo item.

Required behavior:

1. Command behavior and output
   - For `add <text>`, write `Added: <text>` to stdout and exit with status 0.
   - For `list`, write each saved item on its own stdout line, in the order the items were added, using this exact shape: `<n>. [<timestamp>] <text>`.
     - `<n>` is a 1-based index.
     - `<timestamp>` is the UTC time when that item was added, formatted as ISO-8601 with second precision and a trailing `Z`, for example `2024-05-01T12:00:00Z`.
   - Exit with status 0 for `list`.
   - For any other command, or when required arguments are missing, write a usage message to stderr and exit with status 2.

2. Storage
   - Save todo items in a file named `todos.cache` in the same directory as `todos.py`.
   - On every run, load the item list from `todos.cache` if the file exists. If it does not exist, begin with an empty list.
   - After an `add` command, write the updated item list to `todos.cache` so it is present for the next run.
   - `todos.cache` is only read and written by this program.

3. Empty list case
   - If `list` is run and no item has ever been added, print nothing to stdout and exit with status 0.

Example session:

```
$ python todos.py add "buy milk"
Added: buy milk
$ python todos.py add "write report"
Added: write report
$ python todos.py list
1. [2024-05-01T12:00:00Z] buy milk
2. [2024-05-01T12:05:00Z] write report
```
