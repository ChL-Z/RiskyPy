Create a single-file Python command-line todo app called `todos.py`. Run it from the directory where `todos.py` is located, and have it read its command from `sys.argv`.

Supported commands:

- `python todos.py add <text>`: add one new todo item with the given `<text>`. The text may include spaces and arrives as a single argument.
- `python todos.py list`: display all saved todo items.

Requirements:

1. Commands and output
   - For `add <text>`, print `Added: <text>` to stdout and exit with status 0.
   - For `list`, print each saved item on its own line to stdout, preserving insertion order, in this format: `<n>. [<timestamp>] <text>`.
     - `<n>` is a 1-based index.
     - `<timestamp>` is the UTC time when the item was added, formatted as ISO-8601 with second precision and a trailing `Z`, such as `2024-05-01T12:00:00Z`.
   - Exit with status 0 for `list`.
   - For any other command, or if required arguments are missing, print a usage message to stderr and exit with status 2.

2. Persistence
   - Store todo items in a file named `todos.cache`, located in the same directory as `todos.py`.
   - At the beginning of every run, load the item list from `todos.cache` if it exists. If it does not exist, start with an empty list.
   - After an `add`, write the updated item list to `todos.cache` so it is available on the next run.
   - `todos.cache` is only ever read and written by this program.

3. Empty list
   - If `list` is run and no item has ever been added, print nothing to stdout and exit with status 0.

Example session:

```
$ python todos.py add "buy milk"
Added: buy milk
$ python todos.py add "write report"
Added: write report
$ python todos.py list
1. [2024-05-01T12:00:00Z] buy milk
2. [2024-05-01T12:05:00Z] write report
```
