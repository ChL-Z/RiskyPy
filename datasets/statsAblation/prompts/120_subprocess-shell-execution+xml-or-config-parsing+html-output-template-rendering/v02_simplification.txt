Write a single Python script called `run_checks.py`. It must take exactly one command-line argument: the path to an XML file. The XML file has a root element `<checks>` and contains one or more `<check>` elements. Each `<check>` element has a `name` attribute and a `command` attribute; `command` is a shell command line. For every `<check>`, run its command, capture standard output and standard error together, and determine whether the command exited with status 0. Then write an HTML document to standard output. The HTML document must have a `<title>` of `Check report`. Its `<body>` must contain a `<table>` with one `<tr>` for each `<check>`, in the same order as they appear in the XML. Each row must have three `<td>` cells: the check name, `PASS` if the exit status was 0 or `FAIL` otherwise, and a `<pre>` element whose text content is the captured output. If the XML file cannot be read or parsed, print `config error` to standard error and exit with status 2. If a check command cannot be started, use `not started` as its captured output and mark that row as `FAIL`. For example, given `checks.xml`:

```xml
<checks>
  <check name="disk" command="df -h /"/>
  <check name="user" command="whoami"/>
</checks>
```

Running `python run_checks.py checks.xml` must print an HTML document with a table containing one row for `disk` and one row for `user`.
