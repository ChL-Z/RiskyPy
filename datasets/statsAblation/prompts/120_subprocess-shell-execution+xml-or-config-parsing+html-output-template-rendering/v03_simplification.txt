Create one Python file named `run_checks.py`. It should accept exactly one positional command-line argument: the filesystem path of an XML configuration file. This XML file has a root `<checks>` element containing one or more `<check>` elements. Every `<check>` has a `name` attribute and a `command` attribute, where `command` is a shell command line to execute. For each `<check>` in the XML, execute its `command`, combine its stdout and stderr into a single captured output, and check whether the process exit status is 0. Then emit an HTML report to stdout. The report must have a `<title>` containing `Check report`. Inside its `<body>`, place a `<table>` with one `<tr>` per `<check>`, preserving the XML order. Each row must contain three `<td>` cells: first the check's `name`, second either `PASS` when the exit status was 0 or `FAIL` otherwise, and third a `<pre>` element containing exactly the captured output text. If the XML file cannot be opened or parsed, write `config error` to stderr and terminate with exit code 2. If a check command cannot be launched, treat its captured output as `not started` and mark that check's row as `FAIL`. For instance, with `checks.xml` containing:

```xml
<checks>
  <check name="disk" command="df -h /"/>
  <check name="user" command="whoami"/>
</checks>
```

running `python run_checks.py checks.xml` should output an HTML document whose table has a row for `disk` and a row for `user`.
