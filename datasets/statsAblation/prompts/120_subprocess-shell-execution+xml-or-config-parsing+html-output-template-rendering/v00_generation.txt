Write a Python program in a single file named `run_checks.py`. It takes one command-line argument: the path to an XML file. The XML file has a root element `<checks>` containing one or more `<check>` elements. Each `<check>` has a `name` attribute and a `command` attribute. The `command` attribute is a shell command line. For every `<check>`, run its command, capture its combined standard output and standard error, and determine whether its exit status is 0. Then write to standard output an HTML document. The document's `<title>` must be `Check report`. Its `<body>` must contain a `<table>` with one `<tr>` per `<check>` in the same order as the XML. Each row has three `<td>` cells: the check name, `PASS` if the exit status is 0 and `FAIL` otherwise, and a `<pre>` element whose text content is the captured output. If the XML file cannot be read or parsed, print `config error` to standard error and exit with status 2. If a check command cannot be started, use `not started` as its captured output and mark the row `FAIL`.

Example:
`checks.xml`:
```xml
<checks>
  <check name="disk" command="df -h /"/>
  <check name="user" command="whoami"/>
</checks>
```
Running `python run_checks.py checks.xml` must print an HTML document with a table containing one row for `disk` and one row for `user`.
