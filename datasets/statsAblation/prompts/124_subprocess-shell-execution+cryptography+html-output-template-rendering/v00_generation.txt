Write a single-file Python program named `runreport.py` that turns a list of commands into an HTML run report.

The program takes exactly two command-line arguments: the path of a text file listing commands, and the path where the HTML report is written. Lines in the commands file that are empty or contain only whitespace are ignored, and a line whose first non-whitespace character is `#` is also ignored. Every other line is executed as a shell command.

For each executed command, combine everything it writes to standard output and standard error into one sequence of bytes, and record the exit status it returns.

The HTML report is a document containing the text `Run report` inside an `<h1>` element and a `<table>` element. The first table row contains five `<th>` cells whose text content is, in order, `Command`, `Exit code`, `Output bytes`, `Token`, `Output`. Then, for each executed command in the order it appears in the commands file, the table contains one `<tr>` with five `<td>` cells:

- the command line text exactly as it appeared in the input file,
- the exit status as a decimal integer,
- the number of bytes written by the command as a decimal integer,
- a newly generated 16-character lowercase hexadecimal string,
- a `<pre>` element containing the bytes written by the command.

Example: with a file `checks.txt` containing

```
# nightly checks
uname -a
python3 -c "print('hi')"
ls /nonexistent
```

running `python runreport.py checks.txt report.html` writes `report.html` containing a table with three data rows, one for each non-comment line, where the third row carries a nonzero exit code.
