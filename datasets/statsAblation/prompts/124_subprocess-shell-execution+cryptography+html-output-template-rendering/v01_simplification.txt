Create a single-file Python program called `runreport.py` that converts a commands file into an HTML run report.

The script must accept exactly two command-line arguments: the first is the path to a text file containing commands, and the second is the path where the HTML report should be written. When reading the commands file, ignore any line that is blank or contains only whitespace. Also ignore any line whose first non-whitespace character is `#`. Any other line must be run as a shell command.

For every command that is run, capture both standard output and standard error together as one combined byte sequence, and record the command's exit status.

The generated HTML document must contain an `<h1>` element with the text `Run report` and a `<table>` element. The table's first row must have five `<th>` cells whose text content is, in this order: `Command`, `Exit code`, `Output bytes`, `Token`, `Output`. After that, for each executed command in the same order as it appeared in the commands file, add one `<tr>` containing five `<td>` cells:

- the command-line text exactly as it appeared in the input file,
- the exit status as a decimal integer,
- the number of output bytes as a decimal integer,
- a newly generated 16-character lowercase hexadecimal string,
- a `<pre>` element containing the combined bytes written by the command.

For example, if `checks.txt` contains:

```
# nightly checks
uname -a
python3 -c "print('hi')"
ls /nonexistent
```

then running `python runreport.py checks.txt report.html` should write `report.html` with a table containing three data rows, one for each non-comment line, where the third row has a nonzero exit code.
