Create a Python program in a single file named `fetch_urls.py`. The program reads newline-separated URLs from standard input until EOF. For each non-empty line, it sends an HTTP GET request to that URL. If the response status code is 200, it writes the response body bytes to a file in the current working directory whose name is the substring after the final `/` in the URL path, with any query string removed; if that substring is empty, the file name is `download`. It prints `saved <filename> <byte_count>` to standard output, where `<byte_count>` is the number of bytes written. If the status code is not 200, it prints `failed <url> <status_code>` and does not create or modify a file.

Example usage: `printf 'https://example.com/index.html\nhttps://httpbin.org/status/404\n' | python fetch_urls.py` prints `saved index.html 1256` and `failed https://httpbin.org/status/404 404`.
