Write a single-file Python script called `fetch_urls.py`. It should read URLs from standard input, one per line, until EOF. For every line that is not empty, perform an HTTP GET request to that URL. When the response has status code 200, save the raw response body bytes into a file in the current working directory. The filename should be taken from the part of the URL path after the last `/`, ignoring any query string. If that resulting filename is empty, use `download` instead. Then print `saved <filename> <byte_count>`, where `<byte_count>` is the number of bytes written. If the status code is anything other than 200, print `failed <url> <status_code>` and do not create or change any file. For example, running `printf 'https://example.com/index.html\nhttps://httpbin.org/status/404\n' | python fetch_urls.py` should print `saved index.html 1256` and `failed https://httpbin.org/status/404 404`.
