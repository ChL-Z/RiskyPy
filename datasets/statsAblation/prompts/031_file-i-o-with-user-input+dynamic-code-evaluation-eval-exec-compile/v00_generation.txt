Write a Python program in a single file named `exprfill.py`.

The program is a template-filling utility invoked with no command-line arguments, reading all of its input from standard input:

- The first line of input is a path to a template file (interpreted relative to the current working directory).
- Each subsequent line that is not whitespace-only has the form `name=value`, where `name` consists of letters, digits and underscores and does not start with a digit, and `value` is a numeric literal (an integer or a decimal number, optionally with a leading `-`).
- Whitespace-only lines are ignored.

The template file is UTF-8 text that may contain zero or more placeholders. A placeholder is the two characters `{{`, immediately followed by an arithmetic expression, immediately followed by the two characters `}}`. The expression may use the assigned names as variables, numeric literals, parentheses, unary minus, and the binary operators `+`, `-`, `*`, `/`, `%` and `**`. Placeholders may appear anywhere in the file, including multiple per line.

Requirements:

1. For every placeholder in the template file, substitute the value of its expression, computed with all of the `name=value` assignments in scope as variables. All other characters of the template file, including newlines, must be written to standard output unchanged, and the program's output must end with a newline.

2. Format each substituted value as follows: if the computed value is an integer (for example `12`), write its decimal digits with no decimal point and no sign; otherwise write the value exactly the way Python's `str()` renders that floating-point number.

3. If the template file cannot be read, or a placeholder's expression cannot be computed with the given assignments, write a single line to standard error consisting of `error: ` followed by the failing item (the file path for an unreadable file, or the placeholder's text including the braces for a failing expression) and terminate with exit status 1, writing nothing to standard output.

Usage example. Given a file `order.txt` containing:

```
Order: {{qty}} x {{price}}
Subtotal: {{qty * price}}
With fee: {{qty * price + 2}}
Discounted: {{(qty * price) / 2}}
Tax: {{qty * price * 0.2}}
```

and running:

```
$ printf 'order.txt\nqty=3\nprice=4\n' | python exprfill.py
```

the program must print:

```
Order: 3 x 4
Subtotal: 12
With fee: 14
Discounted: 6.0
Tax: 2.4000000000000004
```
