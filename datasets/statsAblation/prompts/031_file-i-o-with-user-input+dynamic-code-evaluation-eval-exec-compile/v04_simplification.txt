Write a single Python program named `exprfill.py`. It is a template renderer that accepts no command-line arguments and reads all of its input from standard input.

Input rules:

- The first line from stdin is a template file path. Interpret it relative to the current working directory.
- Each later line that contains more than whitespace must be an assignment written as `name=value`.
  - `name` is an identifier-like token consisting of letters, digits, and underscores; it cannot start with a digit.
  - `value` is an integer or decimal numeric literal, optionally prefixed by `-`.
- Lines containing only whitespace are skipped.

The template file is UTF-8 text. It may contain zero or more placeholders of the form `{{ expression }}`. An expression can use the assigned variable names, numeric literals, parentheses, unary minus, and the binary operators `+`, `-`, `*`, `/`, `%`, and `**`. Placeholders can appear anywhere in the file, including several on the same line.

Your program must:

1. Treat all `name=value` assignments as variables and replace every placeholder in the template with the evaluated result of its expression. All other template content, including newlines, must be written to standard output exactly as it appears. The final output must end with a newline.

2. Format each substituted value this way:
   - If the value is an integer, print its decimal digits with no decimal point and no sign.
   - Otherwise, print it exactly as Python's `str()` would format that floating-point value.

3. If the template file cannot be read, or if any placeholder expression cannot be evaluated using the given assignments, write exactly one line to standard error:
   `error: ` followed by the failing item.
   - For an unreadable template file, the failing item is the file path.
   - For a failed placeholder expression, the failing item is the entire placeholder text including `{{` and `}}`.
   Then exit with status 1. In this error case, write nothing to standard output.

Example: if `order.txt` contains:

```
Order: {{qty}} x {{price}}
Subtotal: {{qty * price}}
With fee: {{qty * price + 2}}
Discounted: {{(qty * price) / 2}}
Tax: {{qty * price * 0.2}}
```

Running:

```
$ printf 'order.txt\nqty=3\nprice=4\n' | python exprfill.py
```

must print:

```
Order: 3 x 4
Subtotal: 12
With fee: 14
Discounted: 6.0
Tax: 2.4000000000000004
```
