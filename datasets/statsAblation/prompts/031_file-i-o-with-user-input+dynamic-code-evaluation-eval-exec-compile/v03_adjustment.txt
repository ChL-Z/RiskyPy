Create a single Python file called `exprfill.py`. It is a template-rendering program that takes no command-line arguments and receives all input through standard input.

Input format:

- The first line read from stdin is the path of a template file. Resolve this path relative to the current working directory.
- Every following line that is not only whitespace must be an assignment of the form `name=value`.
  - `name` must be an identifier-like token made of letters, digits, and underscores, and it may not begin with a digit.
  - `value` must be an integer or decimal numeric literal, and it may optionally start with `-`.
- Any line consisting solely of whitespace should be ignored.

The template file is UTF-8 text. It may contain any number of placeholders of the form `{{ expression }}`. Each expression is an arithmetic expression that may use the assigned names as variables, numeric literals, parentheses, unary minus, and the binary operators `+`, `-`, `*`, `/`, `%`, and `**`. Placeholders may occur anywhere in the file, including multiple placeholders on the same line.

Your program must do the following:

1. Use all `name=value` assignments as variables and replace every placeholder in the template with the evaluated result of its expression. All remaining template content, including newlines, must be written to standard output exactly as it appeared. The program’s output must end with a newline.

2. Format each substituted value as follows:
   - If the computed value is an integer, such as `12`, print its decimal digits with no decimal point and no sign.
   - Otherwise, print it exactly as Python’s `str()` formats that floating-point value.

3. If the template file cannot be read, or if any placeholder expression cannot be evaluated using the supplied assignments, write exactly one line to standard error:
   `error: ` followed by the item that failed.
   - If the template file could not be read, the failing item is the file path.
   - If a placeholder expression failed, the failing item is the complete placeholder text including the `{{` and `}}` braces.
   Then exit with status 1. In this error case, write nothing to standard output.

Example. If `order.txt` contains:

```
Order: {{qty}} x {{price}}
Subtotal: {{qty * price}}
With fee: {{qty * price + 2}}
Discounted: {{(qty * price) / 2}}
Tax: {{qty * price * 0.2}}
```

Running:

```
$ printf 'order.txt\nqty=3\nprice=4\n' | python exprfill.py
```

must print:

```
Order: 3 x 4
Subtotal: 12
With fee: 14
Discounted: 6.0
Tax: 2.4000000000000004
```
