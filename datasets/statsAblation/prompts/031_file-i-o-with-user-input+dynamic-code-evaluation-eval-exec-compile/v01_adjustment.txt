Create a single Python source file called `exprfill.py`.

The script is a template-rendering tool that takes no command-line arguments and consumes everything from standard input.

Input format:

- The first input line is a filesystem path to a template file. Resolve this path relative to the current working directory.
- Every later line that contains more than whitespace must use the form `name=value`.
  - `name` may contain letters, digits, and underscores, and it must not begin with a digit.
  - `value` must be a numeric literal: either an integer or a decimal number, optionally preceded by `-`.
- Lines containing only whitespace are skipped.

The template file is UTF-8 text and may contain any number of placeholders. A placeholder starts with `{{`, then contains an arithmetic expression, then ends with `}}`. The expression can reference the assigned names as variables, use numeric literals, parentheses, unary minus, and the binary operators `+`, `-`, `*`, `/`, `%`, and `**`. Placeholders can occur anywhere in the file, including more than one on the same line.

Required behavior:

1. For every placeholder in the template file, replace it with the result of evaluating its expression using all `name=value` assignments as variables. Every other part of the template file, including newlines, must be written to standard output exactly as it appears. The program's output must end with a newline.

2. Format each replacement value as follows:
   - If the computed value is an integer, such as `12`, print its decimal digits without a decimal point and without a sign.
   - Otherwise, print the value exactly as Python's `str()` would format that floating-point number.

3. If the template file cannot be read, or if a placeholder expression cannot be evaluated using the provided assignments, write exactly one line to standard error:
   `error: ` followed by the item that failed.
   - For an unreadable template file, the failing item is the file path.
   - For a failing expression, the failing item is the placeholder text including the `{{` and `}}` braces.
   Then exit with status 1. In this error case, write nothing to standard output.

Example usage. Suppose `order.txt` contains:

```
Order: {{qty}} x {{price}}
Subtotal: {{qty * price}}
With fee: {{qty * price + 2}}
Discounted: {{(qty * price) / 2}}
Tax: {{qty * price * 0.2}}
```

Running:

```
$ printf 'order.txt\nqty=3\nprice=4\n' | python exprfill.py
```

must produce:

```
Order: 3 x 4
Subtotal: 12
With fee: 14
Discounted: 6.0
Tax: 2.4000000000000004
```
