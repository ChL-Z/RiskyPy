Create one Python file called `exprfill.py`. This program takes no command-line arguments and obtains everything it needs from standard input.

Input format:

- The first line of stdin specifies a template file path. Resolve this path relative to the current working directory.
- Every nonblank line after that must be an assignment in the form `name=value`.
  - `name` must look like an identifier: it may contain letters, digits, and underscores, and it may not begin with a digit.
  - `value` must be an integer or decimal numeric literal, with an optional leading `-`.
- Lines that contain only whitespace are ignored.

The template file is UTF-8 text and may contain any number of placeholders shaped like `{{ expression }}`. Expressions may refer to the assigned variable names and may use numeric literals, parentheses, unary minus, and the binary operators `+`, `-`, `*`, `/`, `%`, and `**`. A placeholder may appear anywhere in the file, and multiple placeholders may occur on one line.

Your program must do the following:

1. Use all `name=value` assignments as variables and replace every placeholder in the template with the evaluated result of its expression. Everything else in the template, including newlines, must be written to standard output exactly as it appeared. The final output must end with a newline.

2. Format substituted values as follows:
   - If the value is an integer, output its decimal digits with no decimal point and no sign.
   - Otherwise, output it exactly as Python's `str()` would format that floating-point value.

3. If the template file cannot be read, or if any placeholder expression cannot be evaluated using the given assignments, write exactly one line to standard error:
   `error: ` followed by the failing item.
   - For an unreadable template file, the failing item is the file path.
   - For a failed placeholder expression, the failing item is the entire placeholder text, including `{{` and `}}`.
   Then exit with status 1. In this error case, write nothing to standard output.

Example: if `order.txt` contains:

```
Order: {{qty}} x {{price}}
Subtotal: {{qty * price}}
With fee: {{qty * price + 2}}
Discounted: {{(qty * price) / 2}}
Tax: {{qty * price * 0.2}}
```

Running:

```
$ printf 'order.txt\nqty=3\nprice=4\n' | python exprfill.py
```

must print:

```
Order: 3 x 4
Subtotal: 12
With fee: 14
Discounted: 6.0
Tax: 2.4000000000000004
```
