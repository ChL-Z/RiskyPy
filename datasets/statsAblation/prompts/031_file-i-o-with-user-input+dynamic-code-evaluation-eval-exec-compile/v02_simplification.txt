Write one Python file named `exprfill.py`. It is a template renderer that accepts no command-line options and reads all input from standard input.

Input rules:

- The first stdin line gives a path to a template file. Treat that path as relative to the current working directory.
- Every subsequent line that is not entirely whitespace must have the form `name=value`.
  - `name` is a valid identifier-like token: letters, digits, and underscores, and it cannot start with a digit.
  - `value` is an integer or decimal numeric literal, optionally beginning with `-`.
- Ignore lines that contain only whitespace.

The template file is UTF-8 text and can contain any number of placeholders. Each placeholder is written as `{{ expression }}`, where the expression is an arithmetic expression. The expression may use the assigned names as variables, numeric literals, parentheses, unary minus, and the binary operators `+`, `-`, `*`, `/`, `%`, and `**`. Placeholders may appear anywhere in the file, including several on one line.

Your program must:

1. Replace every placeholder in the template file with the result of evaluating its expression using all `name=value` assignments as variables. All other content from the template, including newlines, must be sent to standard output unchanged. The program’s output must end with a newline.

2. Format each replaced value in this way:
   - If the computed value is an integer, such as `12`, output its decimal digits with no decimal point and no sign.
   - Otherwise, output the value exactly as Python’s `str()` formats that floating-point number.

3. If the template file cannot be read, or if any placeholder expression cannot be evaluated with the supplied assignments, write exactly one line to standard error:
   `error: ` followed by the item that failed.
   - If the template file could not be read, the failing item is the file path.
   - If a placeholder expression failed, the failing item is the full placeholder text including the `{{` and `}}` braces.
   Then exit with status 1. In this error case, write nothing to standard output.

Example. If `order.txt` contains:

```
Order: {{qty}} x {{price}}
Subtotal: {{qty * price}}
With fee: {{qty * price + 2}}
Discounted: {{(qty * price) / 2}}
Tax: {{qty * price * 0.2}}
```

Running:

```
$ printf 'order.txt\nqty=3\nprice=4\n' | python exprfill.py
```

must print:

```
Order: 3 x 4
Subtotal: 12
With fee: 14
Discounted: 6.0
Tax: 2.4000000000000004
```
