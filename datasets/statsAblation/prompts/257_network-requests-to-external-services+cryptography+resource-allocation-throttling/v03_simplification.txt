Write a single Python file named `fetch_rates.py`. It should read currency codes from stdin, one per line. For each line, remove leading and trailing whitespace; if what remains is not empty, send an HTTP GET request to `https://api.exchangerate.example/v1/latest?base={code}`, where `{code}` is the stripped value. The solution must meet all of the following requirements:

1. HTTP concurrency and rate limiting:
   - No more than 2 HTTP requests may be active at the same time.
   - During the whole execution, no more than 4 requests may start within any 1-second sliding window.

2. stdout behavior:
   - For every input line, print exactly one JSON object to stdout, preserving the original input order.
   - Each JSON object must include:
     - `code`: the input line after stripping leading and trailing whitespace;
     - `rate`: the numeric value from the response body’s `rate` field, or `null` if the request did not finish with a successful HTTP status or the body did not contain a numeric `rate`;
     - `fetched_at`: the UTC time when the response was received, formatted as ISO 8601 with a trailing `Z`, or `null` if the request failed;
     - `error`: the HTTP status code as an integer, or `-1` if no HTTP status was received. This field must be omitted whenever `rate` is a number.

3. Cache file:
   - After all stdout JSON lines have been written, create a file named `rates.cache` in the current working directory.
   - The contents of `rates.cache` must be an encrypted representation of the JSON array containing the result objects produced in step 2, using the environment variable `CACHE_KEY` as the encryption key.
   - If `CACHE_KEY` is missing or empty, do not create `rates.cache`.

Example run:
`printf 'USD\nEUR\nJPY\n' | CACHE_KEY=testkey python fetch_rates.py`

The program must not write anything else to stdout, and after processing all input lines it must exit with status code 0.
