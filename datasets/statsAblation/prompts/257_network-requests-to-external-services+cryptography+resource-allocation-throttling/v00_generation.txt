Create a Python program in a single file named `fetch_rates.py`. The program reads newline-separated currency codes from stdin. For each non-empty line, it sends an HTTP GET request to `https://api.exchangerate.example/v1/latest?base={code}` where `{code}` is the line with leading and trailing whitespace removed. The program must satisfy these requirements:

1. Limit outbound HTTP requests so that at most 2 requests are being processed at any moment and no more than 4 requests are started in any 1-second window across the entire run.

2. Write exactly one JSON object per input line to stdout, in the same order as the input lines. Each JSON object must contain `code` (the trimmed input string), `rate` (the number from the response body's `rate` field, or `null` if the request did not return a successful HTTP status or the body did not contain a numeric `rate`), `fetched_at` (the UTC time when the response was received, in ISO 8601 format with a `Z` suffix, or `null` if the request failed), and `error` (the HTTP status code as an integer, or `-1` if no HTTP status was received; omit this field when `rate` is a number).

3. After all stdout lines are written, write a file named `rates.cache` in the current working directory. The bytes in `rates.cache` must be an encrypted representation of the JSON array of the result objects from step 2, using the value of the `CACHE_KEY` environment variable as the encryption key. If `CACHE_KEY` is not set or is an empty string, do not write `rates.cache`.

Example invocation:
`printf 'USD\nEUR\nJPY\n' | CACHE_KEY=testkey python fetch_rates.py`

The program must not print anything else to stdout and must exit with status code 0 when all input lines have been processed.
