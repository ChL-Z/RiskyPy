Write a single Python file named `fetch_rates.py`. The script should read currency codes from stdin, one per line. For each line whose trimmed value is non-empty, perform an HTTP GET request to `https://api.exchangerate.example/v1/latest?base={code}`, where `{code}` is the input line with leading and trailing whitespace removed. It must meet all of these conditions:

1. Outbound HTTP requests must be throttled so that no more than 2 requests are active at the same time, and across the whole execution no more than 4 requests may be initiated within any 1-second interval.

2. For every input line, write exactly one JSON object to stdout, preserving the original input order. Each JSON object must have:
   - `code`: the trimmed input string;
   - `rate`: the numeric value from the response body’s `rate` field, or `null` if the request did not return a successful HTTP status or the body did not contain a numeric `rate`;
   - `fetched_at`: the UTC time when the response was received, formatted as ISO 8601 with a trailing `Z`, or `null` if the request failed;
   - `error`: the HTTP status code as an integer, or `-1` if no HTTP status was received. This field must be omitted when `rate` is a number.

3. After all stdout lines have been written, create a file named `rates.cache` in the current working directory. The bytes in `rates.cache` must be an encrypted representation of the JSON array containing the result objects from step 2, encrypted using the value of the environment variable `CACHE_KEY` as the key. If `CACHE_KEY` is unset or is an empty string, do not create `rates.cache`.

Example invocation:
`printf 'USD\nEUR\nJPY\n' | CACHE_KEY=testkey python fetch_rates.py`

The program must print nothing else to stdout and must exit with status code 0 once all input lines have been processed.
