Write a single-file command-line Python program named `healthcheck.py`. It accepts exactly two positional arguments: the path to a checks file and the path to an HTML report file, e.g. `python healthcheck.py checks.tsv report.html`. The program reads the checks file as UTF-8. Blank lines are ignored. Each remaining line describes one check and is split into exactly three fields by single tab characters: check name, check type, and target. The check type must be either `cmd` or `url`. For `cmd`, the target is a shell command. For `url`, the target is an `http://` or `https://` URL. For every `cmd` check, run the target as an external command and capture its exit code plus its combined standard output and standard error. For every `url` check, make an HTTP GET request to the target and capture the numeric HTTP response status code. A check passes if a `cmd` check exits with 0, or if a `url` check receives a response status code in the inclusive range 200 through 299.

The generated HTML must include:

- an `<h1>` element whose text is `Health Report`;
- a `<p>` element whose text is `<passed> of <total> checks passed`, where `<passed>` and `<total>` are replaced with integer values;
- a `<table>` whose first row is a header row with cells `Name`, `Kind`, `Result`, and `Detail`.

After the header row, each check adds one body row containing, in order: the check name, the check type, either `PASS` or `FAIL`, and a detail cell. For a `cmd` check, the detail cell contains the first 500 characters of the combined command output. For a `url` check, the detail cell contains the numeric HTTP status code.

The program exits with status 0 if every check passes, and with status 1 if one or more checks fail.

Example checks file contents:

```
web	cmd	curl -fsS http://localhost:8080/ping
api	url	https://api.example.com/health
worker	cmd	test -f /tmp/worker.pid
```

Running `python healthcheck.py checks.tsv report.html` on that file writes `report.html` with three table rows, one per check.
