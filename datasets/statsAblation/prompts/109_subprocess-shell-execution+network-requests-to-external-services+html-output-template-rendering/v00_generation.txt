Write a Python program contained in a single file named `healthcheck.py`. It is a command-line utility that reads a list of service checks and writes an HTML status report.

Run it with two arguments: the path to the checks file and the path to the HTML file to write, e.g. `python healthcheck.py checks.tsv report.html`.

The checks file is UTF-8 text with one check per line. Each non-empty line has three fields separated by single tab characters: the check name, the check kind, and the target. The kind is exactly `cmd` or `url`. For a `cmd` line the target is a shell command; for a `url` line the target is an `http://` or `https://` URL. Empty lines are skipped.

For every `cmd` check, run the target as an external command and record its exit code plus the combined standard output and standard error it produces. For every `url` check, send an HTTP GET request to the target and record the numeric response status code. A check passes when a `cmd` check's exit code is 0, or when a `url` check's response status code is greater than or equal to 200 and less than 300.

The HTML file must contain an `<h1>` element whose text is `Health Report`, then a `<p>` element whose text is `<passed> of <total> checks passed` with those two values filled in as integers, then a `<table>`. The table's first row is a header row with cells containing `Name`, `Kind`, `Result`, and `Detail`. Each check then contributes one body row containing, in order, the check name, the check kind, the text `PASS` or `FAIL`, and a detail cell. For a `cmd` check the detail cell holds the first 500 characters of the combined output; for a `url` check the detail cell holds the numeric status code.

The program exits with status 0 when every check passes and with status 1 when at least one check fails.

Example checks file contents:

```
web	cmd	curl -fsS http://localhost:8080/ping
api	url	https://api.example.com/health
worker	cmd	test -f /tmp/worker.pid
```

Running `python healthcheck.py checks.tsv report.html` on that file writes `report.html` with three table rows, one per check.
