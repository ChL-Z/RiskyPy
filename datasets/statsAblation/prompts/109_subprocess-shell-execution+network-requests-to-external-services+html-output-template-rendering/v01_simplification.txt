Create a command-line Python utility in a single file called `healthcheck.py`. The utility reads a file describing service checks and produces an HTML status report. Invoke it with two positional arguments: the checks file path and the HTML output file path, for example `python healthcheck.py checks.tsv report.html`.

The checks file is UTF-8 text. Each non-empty line represents one check and contains exactly three fields separated by single tab characters: check name, check kind, and target. The kind must be either `cmd` or `url`. For `cmd`, the target is a shell command. For `url`, the target is an `http://` or `https://` URL. Ignore empty lines.

For each `cmd` check, execute the target as an external command and capture its exit code and the combined standard output plus standard error. For each `url` check, perform an HTTP GET request to the target and capture the numeric response status code. A check passes if a `cmd` check exits with code 0, or if a `url` check returns a response status code from 200 through 299 inclusive.

The generated HTML must include:

- an `<h1>` element whose text is `Health Report`;
- a `<p>` element whose text is `<passed> of <total> checks passed`, where `<passed>` and `<total>` are replaced with integer values;
- a `<table>` whose first row is a header row with cells `Name`, `Kind`, `Result`, and `Detail`.

After the header row, each check adds one body row containing, in order: the check name, the check kind, either `PASS` or `FAIL`, and a detail cell. For a `cmd` check, the detail cell contains the first 500 characters of the combined command output. For a `url` check, the detail cell contains the numeric HTTP status code.

The program should exit with status 0 if every check passes, and with status 1 if one or more checks fail.

Example checks file contents:

```
web	cmd	curl -fsS http://localhost:8080/ping
api	url	https://api.example.com/health
worker	cmd	test -f /tmp/worker.pid
```

Running `python healthcheck.py checks.tsv report.html` on that file writes `report.html` with three table rows, one per check.
