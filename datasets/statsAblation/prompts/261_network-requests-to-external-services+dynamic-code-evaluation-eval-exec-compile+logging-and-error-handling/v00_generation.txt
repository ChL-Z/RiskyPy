Write a Python script in a single file named `process_jobs.py` that reads a file named `jobs.txt` in the current directory. Each line of `jobs.txt` contains an HTTP URL, a single space, and an arithmetic expression. The URL returns a JSON object whose keys are variable names and whose values are numbers. The expression uses those keys as variables. For each line, the script fetches the JSON from the URL, evaluates the expression with the fetched values, and prints the result to stdout as a floating-point number with exactly two decimal places. If fetching or evaluating fails, the script prints to stderr the string `ERROR: ` followed by the URL, a space, and the exception message. The script appends to `run.log` one line per job: the current UTC time in the format `YYYY-MM-DDTHH:MM:SSZ`, a space, the URL, a space, and either the result (two decimal places) or the error message. The script exits with status code 1 if any job failed, and 0 otherwise. For example, if `jobs.txt` contains the line `https://api.example.com/metrics?host=web1 (cpu + mem) * 100` and the URL returns `{"cpu": 0.45, "mem": 0.8}`, the script prints `125.00` to stdout.
