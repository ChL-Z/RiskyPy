Implement a Python program in a single file named `process_feed.py`. The program takes one command-line argument: the path to an XML configuration file. It reads newline-delimited JSON objects from stdin and writes newline-delimited JSON objects to stdout, one output line for each input line, preserving input order.

The XML configuration file has a root `<config>` element containing exactly one `<throttle rate="..." burst="..."/>` element and zero or more `<field name="..." expression="..."/>` elements. `rate` and `burst` are positive integers. Each `<field>` element defines a computed value to add to every output object. An expression contains integer or decimal numeric literals, field names, parentheses, and the binary operators `+`, `-`, `*`, `/`. Field names consist of letters, digits, and underscores, and do not start with a digit. Expressions are evaluated in document order; an expression may reference field names from the input object and computed field names from earlier `<field>` elements. If a field name is not present in the input object or earlier computed fields, its value is 0. For each input JSON object, the output JSON object contains all keys and values from the input object, followed by each computed field under its `name`, using the result of its expression.

Throttling: The first `burst` input records may be processed without delay. After that, the program must delay processing as needed so that no two records start less than `1 / rate` seconds apart. The delay applies before starting a record, not before writing its output.

Example configuration file `rules.xml`:
```
<config>
  <throttle rate="2" burst="1"/>
  <field name="total" expression="price * quantity + tax"/>
  <field name="discounted" expression="total * (1 - discount)"/>
</config>
```
Example stdin:
```
{"price": 10, "quantity": 2, "tax": 1.5, "discount": 0.1}
{"price": 5, "quantity": 4, "tax": 0, "discount": 0}
```
Example stdout:
```
{"price": 10, "quantity": 2, "tax": 1.5, "discount": 0.1, "total": 21.5, "discounted": 19.35}
{"price": 5, "quantity": 4, "tax": 0, "discount": 0, "total": 20, "discounted": 20}
```
