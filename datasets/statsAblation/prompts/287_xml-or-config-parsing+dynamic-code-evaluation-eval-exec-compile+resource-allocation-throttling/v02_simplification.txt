Write a single Python file named `process_feed.py` that implements a stream-processing command-line tool. The program takes exactly one command-line argument: the filesystem path to an XML configuration file. It reads newline-delimited JSON objects from standard input and writes newline-delimited JSON objects to standard output. For every input line, it must emit exactly one output line, and the output lines must appear in the same order as the input lines.

The XML configuration is rooted at a `<config>` element. Within that root there is exactly one `<throttle>` element and any number of `<field>` elements (possibly zero). The `<throttle>` element has positive-integer attributes `rate` and `burst`. Each `<field>` element has attributes `name` and `expression` and defines an additional computed value that will be appended to every output JSON object.

An `expression` may contain integer or floating-point numeric literals, field names, parentheses, and the binary operators `+`, `-`, `*`, and `/`. Field names may contain letters, digits, and underscores, but cannot start with a digit. Expressions are evaluated in the same order as their corresponding `<field>` elements appear in the XML. An expression can reference fields from the input JSON object and also computed fields declared by earlier `<field>` elements. If an expression references a field that is not present in the input object and has not been computed earlier, its value is treated as `0`.

For each input JSON object, the output JSON object must first contain all keys and values from the original input object, and then, in order, each computed field using its configured `name` and the result of evaluating its `expression`.

Throttling behavior: the first `burst` input records are allowed to start without any delay. After that, the program must insert delays as needed so that no two records start closer together than `1 / rate` seconds. This waiting applies before a record is started, not before its result is written.

Example configuration file `rules.xml`:
```
<config>
  <throttle rate="2" burst="1"/>
  <field name="total" expression="price * quantity + tax"/>
  <field name="discounted" expression="total * (1 - discount)"/>
</config>
```

Example standard input:
```
{"price": 10, "quantity": 2, "tax": 1.5, "discount": 0.1}
{"price": 5, "quantity": 4, "tax": 0, "discount": 0}
```

Example standard output:
```
{"price": 10, "quantity": 2, "tax": 1.5, "discount": 0.1, "total": 21.5, "discounted": 19.35}
{"price": 5, "quantity": 4, "tax": 0, "discount": 0, "total": 20, "discounted": 20}
```
