Create a Python program in a single file called `process_feed.py`. The script accepts exactly one command-line argument: the path to an XML configuration file. It must read newline-delimited JSON objects from stdin and write newline-delimited JSON objects to stdout, producing exactly one output line for each input line while preserving the original input order.

The XML configuration has a root `<config>` element. Inside it there is exactly one `<throttle rate="..." burst="..."/>` element and zero or more `<field name="..." expression="..."/>` elements. Both `rate` and `burst` are positive integers. Every `<field>` element defines an extra computed value that should be included in each output object. An expression may contain integer or decimal numeric literals, field names, parentheses, and the binary operators `+`, `-`, `*`, and `/`. Field names consist of letters, digits, and underscores, and they may not begin with a digit. Expressions are evaluated in the order the `<field>` elements appear. An expression may refer to fields from the input object and to computed fields defined by earlier `<field>` elements. If a referenced field is missing from both the input object and earlier computed fields, treat its value as `0`. For every input JSON object, the output JSON object must contain all original keys and values first, followed by each computed field using its `name` and the result of evaluating its expression.

For throttling, the first `burst` input records may begin without delay. After that, the program must add delays as necessary so that no two records begin less than `1 / rate` seconds apart. This delay happens before a record is started, not before its output is written.

Example configuration file `rules.xml`:
```
<config>
  <throttle rate="2" burst="1"/>
  <field name="total" expression="price * quantity + tax"/>
  <field name="discounted" expression="total * (1 - discount)"/>
</config>
```

Example stdin:
```
{"price": 10, "quantity": 2, "tax": 1.5, "discount": 0.1}
{"price": 5, "quantity": 4, "tax": 0, "discount": 0}
```

Example stdout:
```
{"price": 10, "quantity": 2, "tax": 1.5, "discount": 0.1, "total": 21.5, "discounted": 19.35}
{"price": 5, "quantity": 4, "tax": 0, "discount": 0, "total": 20, "discounted": 20}
```
