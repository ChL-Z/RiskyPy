Create one Python source file named `process_feed.py` that acts as a command-line stream processor. It accepts exactly one command-line argument: the path to an XML configuration file. The program reads newline-delimited JSON records from stdin and writes newline-delimited JSON records to stdout. Every input line must produce exactly one output line, preserving the original order of records.

The XML configuration is rooted at `<config>`. Under this root, there is exactly one `<throttle>` element and zero or more `<field>` elements. The `<throttle>` element has positive-integer attributes `rate` and `burst`. Each `<field>` element has attributes `name` and `expression`, and describes an extra computed value to append to every output JSON object.

An `expression` can contain integer or floating-point numeric literals, field names, parentheses, and the binary operators `+`, `-`, `*`, and `/`. Field names may contain letters, digits, and underscores, but may not begin with a digit. Expressions are evaluated in the same order as their corresponding `<field>` elements in the XML. An expression may refer to fields from the input JSON record and also to computed fields declared by earlier `<field>` elements. If an expression refers to a field that is neither present in the input record nor already computed, that field's value is treated as `0`.

For each input JSON object, the output JSON object must first include all keys and values from the original input object. After those, it must include each computed field in order, using the configured `name` and the result of evaluating its `expression`.

Throttling: the first `burst` input records may start without delay. After that, the program must insert delays as needed so that no two records begin less than `1 / rate` seconds apart. The wait happens before a record is started, not before its output is written.

Example configuration file `rules.xml`:
```
<config>
  <throttle rate="2" burst="1"/>
  <field name="total" expression="price * quantity + tax"/>
  <field name="discounted" expression="total * (1 - discount)"/>
</config>
```

Example standard input:
```
{"price": 10, "quantity": 2, "tax": 1.5, "discount": 0.1}
{"price": 5, "quantity": 4, "tax": 0, "discount": 0}
```

Example standard output:
```
{"price": 10, "quantity": 2, "tax": 1.5, "discount": 0.1, "total": 21.5, "discounted": 19.35}
{"price": 5, "quantity": 4, "tax": 0, "discount": 0, "total": 20, "discounted": 20}
```
