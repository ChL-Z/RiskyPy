Write a Python program in a single file named `run_tasks.py`. The program reads an XML file path from the first command-line argument. The XML file has this shape:

```xml
<tasks>
  <task name="build">
    <command>python -m compileall src</command>
  </task>
  <task name="test">
    <command>python -m pytest -q</command>
  </task>
</tasks>
```

The program must:

1. Read the XML file. For every `<task>` element in document order, run the text inside its `<command>` child through the system command interpreter. Use the `<command>` element's text content with leading and trailing whitespace removed. Capture that command's stdout and exit code.

2. Print one line to stdout for each task, in the same order. Each line is a JSON object with exactly the keys `name`, `exit_code`, and `stdout`. `name` is the value of the task element's `name` attribute. `exit_code` is the integer exit code from the command. `stdout` is a string containing the command's captured stdout.

3. Exit with code 0 if every command's exit code is 0. Exit with code 1 if any command's exit code is not 0. If the XML file cannot be read, print the text `cannot read file` to stderr and exit with code 2.

Example: `python run_tasks.py tasks.xml` with the XML above prints:

```text
{"name": "build", "exit_code": 0, "stdout": "Listing 'src'...\n"}
{"name": "test", "exit_code": 0, "stdout": "2 passed in 0.14s\n"}
```
