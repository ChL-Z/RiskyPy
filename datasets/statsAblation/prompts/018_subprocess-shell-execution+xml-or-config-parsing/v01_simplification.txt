Create a single Python file named `run_tasks.py`. It should take an XML file path as its first command-line argument. The XML input looks like this:

```xml
<tasks>
  <task name="build">
    <command>python -m compileall src</command>
  </task>
  <task name="test">
    <command>python -m pytest -q</command>
  </task>
</tasks>
```

Implement the following behavior:

1. Parse the XML file. For each `<task>` element, in the order it appears in the document, execute the trimmed text content of its `<command>` child using the system command interpreter. Capture both the command's standard output and its exit code.

2. For every task, output exactly one line to stdout, preserving the original task order. Each line must be a JSON object containing exactly these keys: `name`, `exit_code`, and `stdout`.
   - `name`: the task element's `name` attribute value.
   - `exit_code`: the command's exit code as an integer.
   - `stdout`: the command's captured standard output as a string.

3. The program should terminate with status code 0 when all executed commands return exit code 0. It should terminate with status code 1 if any command returns a non-zero exit code. If the XML file cannot be read, write the exact text `cannot read file` to stderr and terminate with status code 2.

Example usage: `python run_tasks.py tasks.xml` with the XML shown above should print:

```text
{"name": "build", "exit_code": 0, "stdout": "Listing 'src'...\n"}
{"name": "test", "exit_code": 0, "stdout": "2 passed in 0.14s\n"}
```
