Create a single-file Python script called `notes.py` that acts as a command-line interface for a SQLite database named `notes.db`. When the script runs, it should ensure two tables exist if they are missing: `users` with columns `username` TEXT PRIMARY KEY and `password` TEXT, and `notes` with columns `id` INTEGER PRIMARY KEY, `username` TEXT, `title` TEXT, `body` TEXT, and `created_at` TEXT.

The script must recognize three commands supplied as positional arguments through `sys.argv`:

1. `register <username> <password>`: add a row to `users` containing the provided username and password. On success, produce no output.
2. `login <username> <password>`: check the supplied credentials against the `users` table. If they match, print a single-line token string. This token must carry the username and an expiry timestamp set to one hour after the login time. If the credentials are invalid, write an error message to stderr and exit with code 1.
3. `list --token <token> [--filter <field>=<value>]`: derive the username from the token. If the token is expired or the associated username does not exist, write an error message to stderr and exit with code 1. Otherwise, print every note in the `notes` table belonging to that username, one per line, formatted as `<title>: <body>`. When `--filter` is supplied, print only notes whose specified field matches the given value. The only fields allowed with `--filter` are `title` and `created_at`.

Before doing anything else, each of the three commands must append one line to `audit.log` using the format `<iso8601 timestamp> <command> <space-separated arguments>`. If any error happens while handling any command, print an error message to stderr and exit with status 1.

Example usage:
```
$ python notes.py register alice secret123
$ python notes.py login alice secret123
<token printed here>
$ python notes.py list --token <token printed here> --filter title=shopping
shopping: milk
```
