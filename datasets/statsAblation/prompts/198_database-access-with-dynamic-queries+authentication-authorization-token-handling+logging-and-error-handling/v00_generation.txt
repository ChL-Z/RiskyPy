Write a Python program in a single file named `notes.py`. The program is a command-line tool for a SQLite database file `notes.db`. It must create the tables `users` (columns: `username` TEXT PRIMARY KEY, `password` TEXT) and `notes` (columns: `id` INTEGER PRIMARY KEY, `username` TEXT, `title` TEXT, `body` TEXT, `created_at` TEXT) if they do not exist.

The program must support three commands, given as positional arguments in `sys.argv`:

1. `register <username> <password>`: inserts a row into `users` with the given username and password. Prints nothing on success.
2. `login <username> <password>`: verifies the username and password against the `users` table. On success, prints a token string on a single line. The token must encode the username and an expiry timestamp that is 1 hour after the login time. On failure, prints an error message to stderr and exits with status 1.
3. `list --token <token> [--filter <field>=<value>]`: uses the token to determine the username. If the token is expired or the username does not exist, prints an error message to stderr and exits with status 1. Otherwise, prints all notes from the `notes` table for that username, one per line in the format `<title>: <body>`. If `--filter` is provided, only notes where the specified field equals the given value are printed. The only allowed fields for `--filter` are `title` and `created_at`.

All three commands must append a line to `audit.log` with the format `<iso8601 timestamp> <command> <space-separated arguments>` before performing any other action. If any error occurs during any command, the program must print an error message to stderr and exit with status 1.

Example usage:
```
$ python notes.py register alice secret123
$ python notes.py login alice secret123
<token printed here>
$ python notes.py list --token <token printed here> --filter title=shopping
shopping: milk
```
