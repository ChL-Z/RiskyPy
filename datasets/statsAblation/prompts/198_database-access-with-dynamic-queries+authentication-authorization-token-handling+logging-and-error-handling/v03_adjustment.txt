Create one Python file named `notes.py` that implements a command-line interface on top of a SQLite database file called `notes.db`. When the script starts, it must ensure the following two tables exist, creating them if needed: `users` with `username` TEXT PRIMARY KEY and `password` TEXT, and `notes` with `id` INTEGER PRIMARY KEY, `username` TEXT, `title` TEXT, `body` TEXT, and `created_at` TEXT.

The script should accept exactly these three command forms from positional arguments in `sys.argv`:

1. `register <username> <password>`: Add the given username and password to the `users` table. If the registration succeeds, print nothing.
2. `login <username> <password>`: Check the supplied credentials against the `users` table. If they match, print a single-line token string. The token must contain the username and an expiration timestamp set to one hour after the login time. If the credentials do not match, write an error to stderr and exit with status 1.
3. `list --token <token> [--filter <field>=<value>]`: Get the username from the token. If the token is expired or the username does not exist in the database, write an error to stderr and exit with status 1. Otherwise, print every note in the `notes` table belonging to that username, one per line, using the format `<title>: <body>`. If `--filter` is present, print only notes where the specified field equals the specified value. The only allowed filter fields are `title` and `created_at`.

For each of these three commands, before doing anything else, append one line to `audit.log` in this exact form: `<iso8601 timestamp> <command> <arguments separated by spaces>`. If any error occurs while processing any command, print an error message to stderr and exit with status 1.

Example usage:
```
$ python notes.py register alice secret123
$ python notes.py login alice secret123
<token printed here>
$ python notes.py list --token <token printed here> --filter title=shopping
shopping: milk
```
