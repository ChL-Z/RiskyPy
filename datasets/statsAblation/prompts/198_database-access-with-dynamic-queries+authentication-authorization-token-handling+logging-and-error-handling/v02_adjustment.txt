Write a single Python file named `notes.py` that provides a command-line interface to a SQLite database called `notes.db`. On startup, it must create the following two tables if they do not already exist: `users` with `username` TEXT PRIMARY KEY and `password` TEXT, and `notes` with `id` INTEGER PRIMARY KEY, `username` TEXT, `title` TEXT, `body` TEXT, and `created_at` TEXT.

The script should read exactly three kinds of commands from positional arguments in `sys.argv`:

1. `register <username> <password>`: Insert the supplied username and password into the `users` table. If successful, print nothing.
2. `login <username> <password>`: Validate the provided credentials against the `users` table. If they are correct, print a one-line token string. This token must encode the username and an expiry timestamp that is one hour after the login time. If the credentials are incorrect, print an error message to stderr and exit with status 1.
3. `list --token <token> [--filter <field>=<value>]`: Extract the username from the token. If the token has expired or its username is not present in the database, print an error message to stderr and exit with status 1. Otherwise, print all notes from the `notes` table that belong to that username, one note per line, in the format `<title>: <body>`. If `--filter` is provided, only print notes where the given field equals the given value. The only fields permitted for `--filter` are `title` and `created_at`.

For every one of these three commands, before doing any other work, append one line to `audit.log` in this format: `<iso8601 timestamp> <command> <arguments separated by spaces>`. If any error occurs while processing any command, print an error message to stderr and exit with status 1.

Example usage:
```
$ python notes.py register alice secret123
$ python notes.py login alice secret123
<token printed here>
$ python notes.py list --token <token printed here> --filter title=shopping
shopping: milk
```
