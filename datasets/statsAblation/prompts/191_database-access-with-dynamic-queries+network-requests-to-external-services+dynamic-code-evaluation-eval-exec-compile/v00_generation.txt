Write a Python script `process_data.py` that takes three command-line arguments in this order: `url`, `db_path`, and `table_name`. The script must be contained in a single file.

1. Fetch a JSON array from `url`. Each element is a JSON object with exactly two keys: `"id"` (an integer) and `"expression"` (a string containing an arithmetic expression). The expression uses only non-negative integers and the operators `+`, `-`, `*`, `//`, and parentheses for grouping. For example: `"((12 + 3) * 4) // 5"`.

2. Insert each object into a table named `table_name` in the SQLite database file at `db_path`. The table has two columns: `id` (INTEGER) and `expression` (TEXT). If the table does not exist, create it. If a row with the same `id` already exists, replace it with the new row.

3. After all rows are inserted, query the table and for each row, compute the integer value of the arithmetic expression in the `expression` column. Print one line per row to stdout in the format `id: value`, where `value` is the result of the expression. The rows must be printed in ascending order of `id`.

Example:
```
$ python process_data.py "https://example.com/data.json" "mydata.db" "results"
1: 12
2: 7
```
Assume the URL returns `[{"id": 1, "expression": "10 + 2"}, {"id": 2, "expression": "9 - 2"}]`.
