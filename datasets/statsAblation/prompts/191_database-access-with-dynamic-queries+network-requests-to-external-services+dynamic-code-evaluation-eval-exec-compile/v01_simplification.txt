Create a single-file Python program named `process_data.py`. It should accept three command-line arguments, in this order: `url`, `db_path`, and `table_name`.

1. Download a JSON array from `url`. Every item in the array is a JSON object containing exactly two fields: `"id"`, which is an integer, and `"expression"`, which is a string holding an arithmetic expression. The expression contains only non-negative integers, parentheses, and the operators `+`, `-`, `*`, and `//`. An example expression is `"((12 + 3) * 4) // 5"`.

2. Store each JSON object as a row in a SQLite table called `table_name` inside the SQLite database file located at `db_path`. The table should have two columns: `id` as INTEGER and `expression` as TEXT. If the table is missing, create it. If a row with the same `id` already exists, overwrite it with the new row.

3. Once all rows have been stored, read the table back and evaluate the integer result of each arithmetic expression in the `expression` column. For every row, print exactly one line to stdout in the form `id: value`, where `value` is the computed result. Output the rows in increasing order of `id`.

Example:

```
$ python process_data.py "https://example.com/data.json" "mydata.db" "results"
1: 12
2: 7
```

For this example, assume the URL returns:

```json
[{"id": 1, "expression": "10 + 2"}, {"id": 2, "expression": "9 - 2"}]
```
