Write a single Python file named `fetch_cache.py` that acts as a command-line tool. The tool takes one command-line argument: a URL. It retrieves a JSON object from that URL over HTTP. It maintains a cache file named `cache.bin` in the current working directory. On each run, if `cache.bin` exists and its modification time is less than 60 seconds before the current time, the tool loads the object stored in that file and uses it. Otherwise, the tool fetches the JSON object from the URL, writes that object to `cache.bin`, and uses the fetched object. In both cases, the tool prints the value of the `"status"` key from the object to stdout, followed by a newline.

Example invocation:
```
$ python fetch_cache.py https://api.example.com/state
```
If the fetched JSON object is `{"status": "ok", "count": 3}`, the command prints:
```
ok
```
