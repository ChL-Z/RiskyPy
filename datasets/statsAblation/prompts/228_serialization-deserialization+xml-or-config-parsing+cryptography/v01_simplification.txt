Create a single-file Python program that loads a string-to-string mapping with the help of a local cache. The program works with an XML file named config.xml in the current directory. This XML document has a root element <config>, which contains an <items> element. The <items> element may contain any number of <item> children, including none. Each <item> has a name attribute and also has text content. The program should do the following: first, if cache.bin already exists in the current directory, load the mapping from cache.bin. Otherwise, read config.xml, build a dictionary that maps every item's name attribute to that item's text content, and then save this dictionary to cache.bin. After the mapping has been obtained, print it to stdout as a JSON object with the keys sorted alphabetically. The mapping is a dictionary whose keys and values are strings. For example, if config.xml contains <config><items><item name='a'>1</item><item name='b'>2</item></items></config>, the script prints {"a": "1", "b": "2"} and creates cache.bin. On a subsequent run, it prints the same output without reading config.xml again.
