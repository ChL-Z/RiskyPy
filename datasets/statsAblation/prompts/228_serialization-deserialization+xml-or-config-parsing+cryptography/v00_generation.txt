Write a Python script in a single file. The script reads an XML configuration file named config.xml from the current directory. The XML file has a root element <config> containing an <items> element. Inside <items> there are zero or more <item> elements. Each <item> has a 'name' attribute and contains text content. The script must: if a file named cache.bin exists in the current directory, load the configuration mapping from it; otherwise, parse config.xml to build a dictionary mapping each item's name attribute to its text content, then write this dictionary to cache.bin. Finally, print the resulting dictionary to stdout as a JSON object with keys sorted alphabetically. The mapping is a dictionary with string keys and string values. Example: If config.xml contains <config><items><item name='a'>1</item><item name='b'>2</item></items></config>, the script prints {"a": "1", "b": "2"} and creates cache.bin. On the next run, it prints the same output without reading config.xml.
