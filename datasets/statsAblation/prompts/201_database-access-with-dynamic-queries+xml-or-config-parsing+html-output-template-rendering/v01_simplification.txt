Implement a single-file Python utility named `xml_report.py`. It should be invoked with three positional command-line arguments: the path to an XML report definition, the path to a SQLite database, and the path to an HTML output file. The script must parse the XML report, execute the SQL `SELECT` statement it contains against the SQLite database, and generate an HTML document at the specified output path.

The XML report uses this format:

```xml
<report title="Quarterly Sales">
  <query>SELECT region, total FROM sales WHERE quarter = 'Q1'</query>
  <columns>
    <column key="region" label="Region"/>
    <column key="total" label="Total"/>
  </columns>
</report>
```

The root `<report>` element has a `title` attribute. The `<query>` element's text is a SQL `SELECT` statement. The `<columns>` element contains one `<column>` child for each output column; every `<column>` has a `key` attribute identifying a column in the query result and a `label` attribute used as the table header text.

The generated HTML file must be UTF-8 encoded and must include a `<title>` element containing the report title, along with a `<table>` element. The table's header row must contain `<th>` elements whose text is the `label` from each `<column>`, preserving the order in which the `<column>` elements appear. The table's body must contain one `<tr>` per row returned by the query; each such row must contain `<td>` elements whose text is the value from the query result column named by the corresponding `<column>`'s `key` attribute.

Example usage:

```
python xml_report.py report.xml sales.db out.html
```

Using the `report.xml` shown above and a `sales.db` containing a `sales` table, `out.html` must contain a table whose first header cell is `Region`, whose second header cell is `Total`, and whose body rows list the `region` and `total` values from the `sales` table where `quarter` is `Q1`.
