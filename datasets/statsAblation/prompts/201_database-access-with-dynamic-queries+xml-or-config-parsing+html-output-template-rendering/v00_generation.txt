Create a Python script in a single file named `xml_report.py`. The script accepts three command-line arguments: an XML report file, a SQLite database file, and an output HTML file. It reads the XML report file, runs the SQL SELECT statement found in it against the SQLite database, and writes an HTML document to the output path.

The XML report file has this structure:
```xml
<report title="Quarterly Sales">
  <query>SELECT region, total FROM sales WHERE quarter = 'Q1'</query>
  <columns>
    <column key="region" label="Region"/>
    <column key="total" label="Total"/>
  </columns>
</report>
```
The root `<report>` element has a `title` attribute. The `<query>` element's text is a SQL SELECT statement. The `<columns>` element contains one `<column>` child per output column; each `<column>` has a `key` attribute naming a query result column and a `label` attribute for the table header.

The output HTML file must be a UTF-8 encoded document containing a `<title>` element with the report title, and a `<table>` element. The table's header row contains `<th>` elements whose text is each column's `label`, in the order the `<column>` elements appear. The table's body contains one `<tr>` per row returned by the query; each row contains `<td>` elements whose text is the value from the query result column named by the corresponding `<column>`'s `key` attribute.

Usage example:
```
python xml_report.py report.xml sales.db out.html
```
With the `report.xml` above and a `sales.db` containing a `sales` table, `out.html` must contain a table whose first header cell is `Region`, second header cell is `Total`, and whose body rows list the `region` and `total` values from the `sales` table where `quarter` is `Q1`.
