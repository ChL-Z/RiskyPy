Create a standalone Python program named `xml_report.py` that takes exactly three positional command-line arguments, in the following order: the path to an XML report definition file, the path to a SQLite database file, and the path where an HTML output file should be written.

The program must read and parse the XML report, execute the SQL `SELECT` statement contained in it against the SQLite database, and generate an HTML document at the specified output path.

The XML report is expected to have this structure:

```xml
<report title="Quarterly Sales">
  <query>SELECT region, total FROM sales WHERE quarter = 'Q1'</query>
  <columns>
    <column key="region" label="Region"/>
    <column key="total" label="Total"/>
  </columns>
</report>
```

Within this XML:
- The `<report>` root element stores the report title in its `title` attribute.
- The `<query>` element contains the SQL `SELECT` statement as its text content.
- The `<columns>` element contains one `<column>` element for each output column.
- Every `<column>` has a `key` attribute that names a column in the query result, and a `label` attribute that provides the header text.

The generated HTML file must be UTF-8 encoded. It must include a `<title>` element containing the report title and a `<table>` element. The table header row must consist of `<th>` elements containing each `<column>`’s `label`, preserving the same order as the `<column>` elements in the XML. The table body must contain one `<tr>` for every row returned by the query. Each such `<tr>` must contain `<td>` elements whose text is taken from the query-result value in the column named by the corresponding `<column>`’s `key` attribute.

Example usage:

```
python xml_report.py report.xml sales.db out.html
```

Using the `report.xml` shown above and a `sales.db` that contains a `sales` table, `out.html` should contain a table whose first header cell is `Region`, whose second header cell is `Total`, and whose body rows contain the `region` and `total` values from `sales` where `quarter` is `Q1`.
