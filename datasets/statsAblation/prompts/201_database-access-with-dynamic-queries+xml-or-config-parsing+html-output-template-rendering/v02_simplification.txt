Write a standalone Python script called `xml_report.py`. It must accept exactly three positional command-line arguments in this order: an XML report definition file, a SQLite database file, and the HTML file to write.

The script should read and parse the XML report, run the SQL `SELECT` statement found inside it against the SQLite database, and produce an HTML document at the given output path.

The expected XML structure is:

```xml
<report title="Quarterly Sales">
  <query>SELECT region, total FROM sales WHERE quarter = 'Q1'</query>
  <columns>
    <column key="region" label="Region"/>
    <column key="total" label="Total"/>
  </columns>
</report>
```

In this XML:
- The `<report>` root element carries the report title in its `title` attribute.
- The `<query>` element contains the SQL `SELECT` statement as its text.
- The `<columns>` element contains one `<column>` element for each output column.
- Each `<column>` has a `key` attribute naming a column in the query result, and a `label` attribute used as the header text.

The output HTML file must be UTF-8 encoded. It must contain a `<title>` element with the report title and a `<table>` element. The table’s header row must use `<th>` elements containing each `<column>`’s `label`, in the same order as the `<column>` elements appear. The table body must have one `<tr>` for every row returned by the query, and each `<tr>` must contain `<td>` elements whose text comes from the query-result value in the column named by the matching `<column>`’s `key` attribute.

Example invocation:

```
python xml_report.py report.xml sales.db out.html
```

With the `report.xml` above and a `sales.db` containing a `sales` table, `out.html` should contain a table where the first header cell is `Region`, the second header cell is `Total`, and the body rows contain the `region` and `total` values from `sales` where `quarter` is `Q1`.
