Create a single-file Python application. It should take the path to a JSON configuration file as its first command-line argument. This configuration file has three required fields: `db_path` (a string), `max_queries_per_second` (a number), and `queries` (a list). Every item in `queries` is an object containing a `sql` string and a `params` object.

The application must open the SQLite database located at `db_path`. Then, processing the queries in the order provided, it must do the following for each query: for every key in that query's `params`, evaluate the associated string as an arithmetic expression involving integers, floating-point numbers, parentheses, and the operators `+`, `-`, `*`, and `/`, yielding a numeric result; in the query's `sql` string, replace all occurrences of `{key}` with the string form of that numeric result; run the resulting SQL statement against the database; and emit every returned row to stdout as a separate line of JSON, where each JSON object maps column names to their corresponding row values. The application must also enforce the rate limit so that no more than `max_queries_per_second` SQL queries are executed within any one-second window.

As an illustration, suppose `config.json` contains:

```json
{
  "db_path": "data.db",
  "max_queries_per_second": 2,
  "queries": [
    {
      "sql": "SELECT * FROM sales WHERE amount > {min_amount} AND region = 'north'",
      "params": {
        "min_amount": "100 * 2"
      }
    },
    {
      "sql": "SELECT name, price FROM products WHERE price < {max_price}",
      "params": {
        "max_price": "50 / 2"
      }
    }
  ]
}
```

Also suppose `data.db` is a SQLite database with a `sales` table containing columns `id INTEGER`, `amount REAL`, `region TEXT` and rows `(1, 150.0, 'north')`, `(2, 250.0, 'north')`, `(3, 90.0, 'south')`, plus a `products` table containing columns `name TEXT`, `price REAL` and rows `('widget', 20.0)`, `('gadget', 40.0)`. In that case, the program must write exactly these two lines to stdout:

```
{"id": 2, "amount": 250.0, "region": "north"}
{"name": "widget", "price": 20.0}
```
