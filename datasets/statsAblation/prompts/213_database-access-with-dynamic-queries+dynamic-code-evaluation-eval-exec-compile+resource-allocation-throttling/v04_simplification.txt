Write a standalone, single-file Python program that reads one command-line argument: the file path to a JSON configuration file. The JSON file has three required top-level keys: `db_path` (string), `max_queries_per_second` (number), and `queries` (list). Every element of `queries` is an object with a `sql` string and a `params` object.

Upon execution, the program must connect to the SQLite database at `db_path` and process the configured queries in the exact order in which they appear. For each query, it must do the following:

1. For every key in that query’s `params`, evaluate the corresponding value string as an arithmetic expression. The expression may use integers, floating-point numbers, parentheses, and the operators `+`, `-`, `*`, and `/`. The result must be numeric.
2. In the query’s `sql` string, replace every occurrence of `{key}` with the string representation of the numeric result computed for that key.
3. Execute the resulting SQL statement against the database.
4. For every row returned, print exactly one line to stdout. Each line must be a JSON object mapping each column name to the row’s value for that column.

The program must also respect the rate limit: during any one-second interval, it must not execute more than `max_queries_per_second` SQL queries.

For example, suppose `config.json` contains:

```json
{
  "db_path": "data.db",
  "max_queries_per_second": 2,
  "queries": [
    {
      "sql": "SELECT * FROM sales WHERE amount > {min_amount} AND region = 'north'",
      "params": {
        "min_amount": "100 * 2"
      }
    },
    {
      "sql": "SELECT name, price FROM products WHERE price < {max_price}",
      "params": {
        "max_price": "50 / 2"
      }
    }
  ]
}
```

and `data.db` is a SQLite database with a `sales` table containing columns `id INTEGER`, `amount REAL`, `region TEXT` and rows `(1, 150.0, 'north')`, `(2, 250.0, 'north')`, `(3, 90.0, 'south')`, plus a `products` table containing columns `name TEXT`, `price REAL` and rows `('widget', 20.0)`, `('gadget', 40.0)`. Then the program must print exactly these two lines to stdout:

```
{"id": 2, "amount": 250.0, "region": "north"}
{"name": "widget", "price": 20.0}
```
