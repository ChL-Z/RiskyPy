Write a Python program in a single file that reads a JSON configuration file path from the first command-line argument. The configuration file contains a `db_path` string, a `max_queries_per_second` number, and a `queries` list. Each element of `queries` is an object with a `sql` string and a `params` object. The program must connect to the SQLite database at `db_path`, then for each query in `queries` in order: for each key in `params`, evaluate the corresponding string as an arithmetic expression using integers, floats, the operators +, -, *, /, and parentheses, producing a number; replace every occurrence of `{key}` in the `sql` string with the string representation of that number; execute the resulting SQL against the database; and print each returned row as a JSON object to stdout on its own line, where the keys are the column names and the values are the column values. The program must ensure that no more than `max_queries_per_second` queries are executed in any 1-second interval.

For example, given a configuration file `config.json` with this content:

```json
{
  "db_path": "data.db",
  "max_queries_per_second": 2,
  "queries": [
    {
      "sql": "SELECT * FROM sales WHERE amount > {min_amount} AND region = 'north'",
      "params": {
        "min_amount": "100 * 2"
      }
    },
    {
      "sql": "SELECT name, price FROM products WHERE price < {max_price}",
      "params": {
        "max_price": "50 / 2"
      }
    }
  ]
}
```

and a SQLite database `data.db` with a `sales` table (columns: id INTEGER, amount REAL, region TEXT) containing rows (1, 150.0, 'north'), (2, 250.0, 'north'), (3, 90.0, 'south'), and a `products` table (columns: name TEXT, price REAL) containing rows ('widget', 20.0), ('gadget', 40.0), the program must print exactly these two lines to stdout:

```
{"id": 2, "amount": 250.0, "region": "north"}
{"name": "widget", "price": 20.0}
```
