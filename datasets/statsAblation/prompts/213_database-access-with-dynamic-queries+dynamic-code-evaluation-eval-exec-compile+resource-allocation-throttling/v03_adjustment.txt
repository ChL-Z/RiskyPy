Create a self-contained Python script in a single file. When executed, it should take exactly one command-line argument: a path to a JSON configuration file. The JSON configuration will include these required fields: `db_path` (a string), `max_queries_per_second` (a number), and `queries` (a list). Each item in `queries` is an object containing a `sql` string and a `params` object.

The script must open/connect to the SQLite database located at `db_path`. It must process the queries in the same order they appear in the configuration. For each query, perform all of the following steps:

1. For each key in that query's `params`, treat the corresponding string as an arithmetic expression and evaluate it. The expression can contain integers, floating-point numbers, parentheses, and the operators `+`, `-`, `*`, and `/`. The evaluation must yield a numeric value.
2. In the query's `sql` string, replace every occurrence of `{key}` with the string form of the numeric value calculated for that key.
3. Run the resulting SQL statement against the database.
4. For every row produced, print one line to stdout containing a JSON object. The JSON object must map each column name to that row's value for the column.

The script must also enforce the rate limit: within any one-second window, it must not run more than `max_queries_per_second` SQL queries.

For example, if `config.json` contains:

```json
{
  "db_path": "data.db",
  "max_queries_per_second": 2,
  "queries": [
    {
      "sql": "SELECT * FROM sales WHERE amount > {min_amount} AND region = 'north'",
      "params": {
        "min_amount": "100 * 2"
      }
    },
    {
      "sql": "SELECT name, price FROM products WHERE price < {max_price}",
      "params": {
        "max_price": "50 / 2"
      }
    }
  ]
}
```

and `data.db` is a SQLite database with a `sales` table containing columns `id INTEGER`, `amount REAL`, `region TEXT` and rows `(1, 150.0, 'north')`, `(2, 250.0, 'north')`, `(3, 90.0, 'south')`, plus a `products` table containing columns `name TEXT`, `price REAL` and rows `('widget', 20.0)`, `('gadget', 40.0)`, then the script must output exactly these two lines to stdout:

```
{"id": 2, "amount": 250.0, "region": "north"}
{"name": "widget", "price": 20.0}
```
