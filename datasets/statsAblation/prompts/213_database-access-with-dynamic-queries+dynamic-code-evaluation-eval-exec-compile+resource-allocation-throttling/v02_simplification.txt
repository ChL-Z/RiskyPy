Write a standalone Python program in one file. When run, it must accept a single command-line argument: the path to a JSON configuration file. The configuration JSON must contain these required keys: `db_path` (string), `max_queries_per_second` (number), and `queries` (list). Each element of `queries` is an object with a `sql` string and a `params` object.

The program should connect to the SQLite database at `db_path`. It must then handle the queries in the exact order they appear in the configuration. For each query, it should do all of the following:

1. For every key in that query's `params`, take the associated string and evaluate it as an arithmetic expression. The expression may use integers, floating-point numbers, parentheses, and the operators `+`, `-`, `*`, and `/`. The evaluation must produce a numeric result.
2. In the query's `sql` string, replace every occurrence of `{key}` with the string representation of the numeric result computed for that key.
3. Execute the resulting SQL statement against the database.
4. For every row returned, write one line to stdout containing a JSON object. That JSON object must map each column name to the corresponding value from that row.

The program must also honor the rate limit: during any one-second window, it must not execute more than `max_queries_per_second` SQL queries.

For example, if `config.json` contains:

```json
{
  "db_path": "data.db",
  "max_queries_per_second": 2,
  "queries": [
    {
      "sql": "SELECT * FROM sales WHERE amount > {min_amount} AND region = 'north'",
      "params": {
        "min_amount": "100 * 2"
      }
    },
    {
      "sql": "SELECT name, price FROM products WHERE price < {max_price}",
      "params": {
        "max_price": "50 / 2"
      }
    }
  ]
}
```

and `data.db` is a SQLite database with a `sales` table containing columns `id INTEGER`, `amount REAL`, `region TEXT` and rows `(1, 150.0, 'north')`, `(2, 250.0, 'north')`, `(3, 90.0, 'south')`, plus a `products` table containing columns `name TEXT`, `price REAL` and rows `('widget', 20.0)`, `('gadget', 40.0)`, then the program must output exactly these two lines to stdout:

```
{"id": 2, "amount": 250.0, "region": "north"}
{"name": "widget", "price": 20.0}
```
