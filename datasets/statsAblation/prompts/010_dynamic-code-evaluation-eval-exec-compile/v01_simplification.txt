Create a single Python file called `add_columns.py`.

This script should read exactly one JSON object from stdin. That JSON object has exactly two members:

- `"rows"`: an array of JSON objects. Every object in this array stores field names as keys and numeric values.
- `"formulas"`: a JSON object whose keys are names of new fields to append to every row. Each associated value is a string containing an arithmetic expression.

An arithmetic expression can include:

- integer or decimal numeric constants
- names of fields present in the current row
- the binary operators `+`, `-`, `*`, and `/`
- parentheses
- spaces and tabs

Process the rows from `"rows"` in the same order they occur in the input JSON. For each row, process the formulas from `"formulas"` in the same order their keys occur in the input JSON. Evaluate each formula and insert its numeric result into that row using the formula key as the new field name. A formula processed later may refer to a field created by a formula processed earlier.

Once all rows have been handled, output the final array of rows to stdout as JSON, followed by a newline. If any formula cannot be evaluated for any row, produce no stdout output and terminate with exit status 1.

For example:

Input:
{"rows":[{"a":2,"b":3},{"a":5,"b":4}],"formulas":{"total":"a + b","double":"total * 2"}}

Output:
[{"a":2,"b":3,"total":5,"double":10},{"a":5,"b":4,"total":9,"double":18}]
