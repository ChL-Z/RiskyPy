Write a Python program in a single file named `add_columns.py`.

The program reads one JSON object from stdin. The JSON object has exactly two keys:
- `"rows"`: a list of JSON objects. Each object maps field names to numbers.
- `"formulas"`: a JSON object. Each key is a new field name to add to every row. Each value is a string containing an arithmetic expression.

The arithmetic expression may contain:
- integer and decimal numeric literals
- field names that appear in the current row
- the binary operators `+`, `-`, `*`, `/`
- parentheses
- spaces and tabs

For each row in `"rows"`, in the order they appear in the input JSON text, evaluate each formula from `"formulas"` in the order the formula keys appear in the input JSON text. Add the resulting numeric value to the row under the formula's key. A later formula may use a field added by an earlier formula. After processing all rows, print the resulting list of rows to stdout as a JSON array followed by a newline. If any formula cannot be evaluated for a row, write nothing to stdout and exit with status 1.

Example:
Input:
{"rows":[{"a":2,"b":3},{"a":5,"b":4}],"formulas":{"total":"a + b","double":"total * 2"}}
Output:
[{"a":2,"b":3,"total":5,"double":10},{"a":5,"b":4,"total":9,"double":18}]
