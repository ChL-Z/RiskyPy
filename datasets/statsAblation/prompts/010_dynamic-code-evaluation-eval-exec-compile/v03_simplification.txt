Create a single Python file called `add_columns.py`. It must read one JSON object from standard input. That JSON object has exactly two keys: `rows`, which is a list of JSON objects mapping field names to numeric values, and `formulas`, which is a JSON object mapping new field names to arithmetic expressions. Each expression may include integer or decimal literals, names of fields from the current row, the operators `+`, `-`, `*`, `/`, parentheses, and spaces or tabs. For each row, in the original order of `rows`, evaluate every formula in the original key order of `formulas`, adding the resulting number to that row under the corresponding formula key. Formulas evaluated later may use fields added by earlier formulas. After all rows have been processed, print the resulting list of rows to stdout as JSON followed by a newline. If any formula cannot be evaluated for any row, print nothing to stdout and exit with status code 1. Example: input `{"rows":[{"a":2,"b":3},{"a":5,"b":4}],"formulas":{"total":"a + b","double":"total * 2"}}` should produce output `[{"a":2,"b":3,"total":5,"double":10},{"a":5,"b":4,"total":9,"double":18}]`.
