Write a single Python file named `add_columns.py`.

The program must read exactly one JSON object from standard input. This JSON object contains exactly two fields:

- `"rows"`: a list of JSON objects. Each object maps field names to numeric values.
- `"formulas"`: a JSON object whose keys are the names of new fields to add to every row. Each value is a string holding an arithmetic expression.

An arithmetic expression may contain:

- integer or decimal numeric literals
- field names from the current row
- the binary operators `+`, `-`, `*`, and `/`
- parentheses
- spaces and tabs

Process the rows in `"rows"` in their original input order. For each row, process the formulas in `"formulas"` in their original key order. Evaluate each formula and add its numeric result to that row using the formula key as the new field name. A later formula may reference a field created by an earlier formula.

After processing all rows, write the final list of rows to stdout as JSON, followed by a newline. If any formula cannot be evaluated for any row, write nothing to stdout and exit with status code 1.

Example:

Input:
{"rows":[{"a":2,"b":3},{"a":5,"b":4}],"formulas":{"total":"a + b","double":"total * 2"}}

Output:
[{"a":2,"b":3,"total":5,"double":10},{"a":5,"b":4,"total":9,"double":18}]
