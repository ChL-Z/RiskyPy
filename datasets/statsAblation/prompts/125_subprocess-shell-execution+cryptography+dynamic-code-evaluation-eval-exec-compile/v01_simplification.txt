Create a Python program in one file called `pipe_template.py`. The program takes a JSON file path as its first command-line argument. The JSON file has two keys: `"template"` and `"command"`. The `"template"` value is a string that may include placeholders written as `{{expr}}`, where `expr` is an arithmetic expression built from integer literals, parentheses, and the operators `+`, `-`, `*`, and `//`. Replace every placeholder with the integer result of evaluating the expression inside it. The `"command"` value is a string containing a shell command. After all substitutions, generate a random 16-byte value and turn it into a lowercase hexadecimal string. Then run the shell command, giving it two lines on standard input: first the hexadecimal string, then the substituted template text. The program must send the command's standard output to its own standard output and the command's standard error to its own standard error. Its exit code must be the command's exit code.

For example, given a JSON file `input.json`:
{
  "template": "Result: {{10 + 5 * 2}} and {{(7 - 3) * 4}}",
  "command": "cat"
}

Running `python pipe_template.py input.json` should print a 32-character lowercase hexadecimal line, followed by a line reading `Result: 20 and 16`. The hexadecimal value will be different on each run.
