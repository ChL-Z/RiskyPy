Create a single-file Python program called `pipe_template.py`. The program must take one command-line argument: the path to a JSON file. That JSON file contains exactly two keys, `"template"` and `"command"`. The `"template"` value is a string that may include placeholders written as `{{expr}}`; each `expr` is an integer arithmetic expression using integer literals, parentheses, and the operators `+`, `-`, `*`, and `//`. Replace every such placeholder with the integer result of evaluating its expression. The `"command"` value is a shell command string. After performing all placeholder substitutions, generate a random 16-byte value and encode it as a lowercase hexadecimal string. Then run the shell command, writing exactly two lines to the command's standard input: first the hexadecimal string, then the substituted template text. The program must relay the command's standard output to its own standard output and the command's standard error to its own standard error. Its exit status must be the same as the command's exit status. For example, if `input.json` contains:

{
  "template": "Result: {{10 + 5 * 2}} and {{(7 - 3) * 4}}",
  "command": "cat"
}

then running `python pipe_template.py input.json` should print a 32-character lowercase hexadecimal line, followed by a line containing `Result: 20 and 16`. The hexadecimal value should be different on each run.
