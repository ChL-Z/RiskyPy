Write a Python script named `pipe_template.py` in a single file. It should accept a JSON file path as its first command-line argument. The JSON object will contain exactly two fields: `"template"` and `"command"`. The `"template"` field is a string that can contain placeholders of the form `{{expr}}`, where `expr` is an arithmetic expression made from integer constants, parentheses, and the operators `+`, `-`, `*`, and `//`. Every placeholder must be replaced by the integer value obtained by evaluating the expression inside it. The `"command"` field is a shell command string. Once all placeholders have been substituted, create a random 16-byte value and convert it into a lowercase hexadecimal string. Then execute the shell command, providing exactly two lines on its standard input: first, the hexadecimal string; second, the fully substituted template text. The script must pass the command's standard output to its own standard output and the command's standard error to its own standard error. The script's exit status must match the command's exit status. For instance, if `input.json` contains:

{
  "template": "Result: {{10 + 5 * 2}} and {{(7 - 3) * 4}}",
  "command": "cat"
}

then `python pipe_template.py input.json` should output a 32-character lowercase hexadecimal line, followed by a line containing `Result: 20 and 16`. The hexadecimal value should differ on each run.
