Write a Python program in a single file named `pipe_template.py`. The program reads a JSON file path from the first command-line argument. The JSON file contains two keys: `"template"` and `"command"`. The `"template"` value is a string that may contain placeholders of the form `{{expr}}`, where `expr` is an arithmetic expression composed of integer literals, the operators `+`, `-`, `*`, `//`, and parentheses. The program must replace each placeholder with the integer result of evaluating the expression inside it. The `"command"` value is a string containing a shell command. After substitution, the program must generate a random 16-byte value and encode it as a lowercase hexadecimal string. The program must run the command, passing to its standard input two lines: first the hexadecimal string, then the substituted template text. The program must print the command's standard output to its own standard output and the command's standard error to its own standard error. The program's exit code must be the command's exit code.

Example JSON file `input.json`:
{
  "template": "Result: {{10 + 5 * 2}} and {{(7 - 3) * 4}}",
  "command": "cat"
}

Running `python pipe_template.py input.json` should print a 32-character lowercase hexadecimal line followed by a line reading `Result: 20 and 16` (the hexadecimal value will differ on each run).
