Create a single-file Python script named `schedule_report.py`. It takes two command-line arguments: the first is the path to an XML file, and the second is an integer called `max_parallel`. The XML document has a root `<build>` element containing one or more `<step>` elements. Every `<step>` has the attributes `name` (a string), `group` (a string), and `duration` (a positive integer number of seconds). The steps must be handled in the same order they appear in the XML.

Your script must calculate a schedule satisfying these rules:
1. At no moment may more than `max_parallel` steps be running.
2. At no moment may two running steps share the same `group` value.

A step that starts at integer time `s` and has duration `d` occupies the half-open interval `[s, s + d)`.

For each step, in XML order, choose the smallest integer start time `t` such that all of the following hold:
- `t` is at least the start time of every step already processed before it.
- At time `t`, fewer than `max_parallel` previously scheduled steps have intervals containing `t`.
- At time `t`, no previously scheduled step with the same `group` has an interval containing `t`.

The step’s end time is then `t + duration`.

After scheduling all steps, write an HTML file named `schedule.html` into the current working directory. This file must be a complete HTML document containing `<html>`, `<head><title>Schedule</title></head>`, and `<body>`. Inside the body, there must be exactly one `<table>` element. The table must begin with a header row containing four `<th>` cells with the exact texts `Step`, `Group`, `Start`, and `End`. After the header row, add one row per step, preserving XML order. Each row must contain four `<td>` cells with the step’s `name`, `group`, `start` time, and `end` time, all as text.

The script must not print anything to standard output or standard error.

Example invocation:
```
python schedule_report.py build.xml 2
```
If `build.xml` contains:
```xml
<build>
  <step name="fetch" group="net" duration="3"/>
  <step name="compile" group="cpu" duration="5"/>
  <step name="test" group="cpu" duration="4"/>
  <step name="package" group="io" duration="2"/>
</build>
```
then the script writes `schedule.html`, whose table contains one row for each of the four steps with the computed start and end times.
