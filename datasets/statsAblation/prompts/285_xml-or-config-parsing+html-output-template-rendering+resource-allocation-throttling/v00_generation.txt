Write a Python program in a single file named `schedule_report.py`. The program reads an XML file whose path is given as the first command-line argument and an integer `max_parallel` given as the second command-line argument. The XML file has a root element `<build>` containing one or more `<step>` elements. Each `<step>` has three attributes: `name` (string), `group` (string), and `duration` (positive integer, in seconds). Steps are ordered by their appearance in the XML file.

The program computes a schedule for the steps subject to two constraints: (1) at any time, the number of steps that are running is at most `max_parallel`; (2) at any time, no two steps with the same `group` value are running. A step with start time `s` and duration `d` runs during the half-open interval `[s, s+d)`.

Process the steps in the order they appear in the XML file. For each step, assign the smallest integer start time `t` such that:
- `t` is greater than or equal to the start time of every step processed before it,
- at time `t`, the number of previously scheduled steps whose intervals contain `t` is strictly less than `max_parallel`,
- at time `t`, no previously scheduled step with the same `group` value has an interval that contains `t`.

The end time of the step is `t + duration`.

After computing the schedule, write an HTML file named `schedule.html` in the current working directory. The file must be a complete HTML document with `<html>`, `<head><title>Schedule</title></head>`, and `<body>`. Inside the body, include exactly one `<table>` element. The table must have a header row with four `<th>` cells containing the text `Step`, `Group`, `Start`, and `End`. After the header row, include one row for each step in the order they appear in the XML. Each row must have four `<td>` cells containing the step's `name`, `group`, `start` time, and `end` time as text. The program must not write to standard output or standard error.

Example usage:
```
python schedule_report.py build.xml 2
```
Given `build.xml`:
```xml
<build>
  <step name="fetch" group="net" duration="3"/>
  <step name="compile" group="cpu" duration="5"/>
  <step name="test" group="cpu" duration="4"/>
  <step name="package" group="io" duration="2"/>
</build>
```
The program writes `schedule.html` and the table contains rows for the four steps with their computed start and end times.
