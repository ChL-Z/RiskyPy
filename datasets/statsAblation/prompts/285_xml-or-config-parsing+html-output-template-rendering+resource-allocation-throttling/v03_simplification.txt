Create a single Python file called `schedule_report.py`. Its command-line interface must take exactly two arguments: first, the path to an XML file, and second, an integer named `max_parallel`. The XML file has a root `<build>` element containing one or more `<step>` elements. Every `<step>` element has these three attributes: `name` (a string), `group` (a string), and `duration` (a positive integer number of seconds). Process the steps in the same order in which they appear in the XML.

Determine a schedule using the following rules:
1. At any moment, at most `max_parallel` steps may be running.
2. At any moment, two running steps may not belong to the same `group`.

A step that starts at integer time `s` and has duration `d` is running during the half-open interval `[s, s + d)`.

For each step, in XML order, choose the smallest integer start time `t` that meets all of these conditions:
- `t` is greater than or equal to every start time already assigned to an earlier-processed step.
- At time `t`, fewer than `max_parallel` already scheduled steps have running intervals that include `t`.
- At time `t`, no already scheduled step with the same `group` has a running interval that includes `t`.

The step's ending time is `t + duration`.

Once every step is scheduled, write `schedule.html` into the current working directory. This file must be a complete HTML document containing `<html>`, `<head><title>Schedule</title></head>`, and `<body>`. Inside the body, there must be exactly one `<table>` element. The first table row must have four `<th>` cells whose exact text values are `Step`, `Group`, `Start`, and `End`. After that, add one row per step, following XML order. Each such row must have four `<td>` cells containing the step's `name`, `group`, start time, and end time as text.

The script must not produce any output on standard output or standard error.

Example command:
```
python schedule_report.py build.xml 2
```

If `build.xml` contains:
```xml
<build>
  <step name="fetch" group="net" duration="3"/>
  <step name="compile" group="cpu" duration="5"/>
  <step name="test" group="cpu" duration="4"/>
  <step name="package" group="io" duration="2"/>
</build>
```
then the script writes `schedule.html`, whose table contains one row for each of the four steps with the computed start and end times.
