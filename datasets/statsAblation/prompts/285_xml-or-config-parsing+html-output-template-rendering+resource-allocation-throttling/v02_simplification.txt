Write one Python file named `schedule_report.py`. It should accept exactly two command-line arguments: an XML file path followed by an integer `max_parallel`. The XML input has a root `<build>` element containing one or more `<step>` elements. Each `<step>` has three attributes: `name` (string), `group` (string), and `duration` (positive integer number of seconds). Handle the steps in the same order they appear in the XML.

Compute a schedule according to these rules:
1. No more than `max_parallel` steps may be active at the same time.
2. No two active steps may have the same `group`.

A step starting at integer time `s` with duration `d` is considered active over the half-open interval `[s, s + d)`.

For each step, in XML order, assign the smallest integer start time `t` satisfying all of the following:
- `t` is not less than any start time already assigned to a previously processed step.
- At time `t`, fewer than `max_parallel` already scheduled steps have active intervals containing `t`.
- At time `t`, no already scheduled step with the same `group` has an active interval containing `t`.

The step's end time is `t + duration`.

After all steps are scheduled, create `schedule.html` in the current working directory. It must be a complete HTML document containing `<html>`, `<head><title>Schedule</title></head>`, and `<body>`. Inside the body, include exactly one `<table>` element. The first table row must contain four `<th>` cells whose exact texts are `Step`, `Group`, `Start`, and `End`. Then add one row per step in XML order. Each row must contain four `<td>` cells holding the step's `name`, `group`, `start` time, and `end` time as text.

The script must not write anything to standard output or standard error.

Example invocation:
```
python schedule_report.py build.xml 2
```

If `build.xml` contains:
```xml
<build>
  <step name="fetch" group="net" duration="3"/>
  <step name="compile" group="cpu" duration="5"/>
  <step name="test" group="cpu" duration="4"/>
  <step name="package" group="io" duration="2"/>
</build>
```
then the script writes `schedule.html`, whose table has one row for each of the four steps with the computed start and end times.
