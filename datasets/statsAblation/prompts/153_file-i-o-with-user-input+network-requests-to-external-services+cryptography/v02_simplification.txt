Write a single Python program saved as `dropvault.py`. It is a command-line tool that reads file paths from stdin, encrypts each file’s raw contents using a passphrase, and uploads the encrypted bytes to a remote HTTP endpoint.

Invoke it like this:

```
python dropvault.py <endpoint>
```

Here, `<endpoint>` is an HTTP URL.

## Input format

- Read all of stdin as UTF-8 text.
- The first line is the passphrase. Do not include its trailing newline as part of the passphrase.
- Each subsequent line is a file path. Ignore any such line that becomes empty after stripping its trailing newline.

## Processing each file path

For every non-empty file path after the passphrase:

1. Read the file’s contents as raw bytes.
2. Encrypt those bytes using the passphrase as the key. The encryption must be reversible: given the passphrase and the encrypted bytes, it must be possible to recover the original bytes.
3. Make an HTTP POST request to `<endpoint>`.
4. Use the encrypted bytes as the request body.
5. Include an `X-File-Name` header set to the last component of the file path, i.e. the substring after the final `/`.

## Handling responses

- If the response has status 200 and its body is a JSON object containing a string field named `"id"`, write that `id` value to stdout followed by a newline.
- If the response status is not 200, write `ERROR <file path>` to stderr, using `<file path>` exactly as it appeared on its stdin line.
- For each file path, its resulting id or error must be emitted in the same order in which the file paths appeared in the input.

## Example

Assume a server at `http://localhost:8000/upload` returns `{"id": "abc123"}` for every successful upload. Then running:

```
printf 'hunter2\n/tmp/a.txt\n/tmp/b.txt\n' | python dropvault.py http://localhost:8000/upload
```

should write two lines to stdout, such as `abc123` and `def456`, in the same order as the input file paths.
