Create a single Python file named `dropvault.py`. It should be a command-line backup uploader that encrypts file contents and sends the encrypted bytes to a remote HTTP service.

Run it as:

```
python dropvault.py <endpoint>
```

`<endpoint>` is an HTTP URL.

Input handling:

- Read all of standard input as UTF-8 text.
- The first line is the passphrase, but its trailing newline is not part of the passphrase.
- Every following line is a file path. Skip any line that is empty after removing a trailing newline.

For each file path:

1. Read the file as raw bytes.
2. Encrypt those bytes using the passphrase as the key. The encryption must be reversible, meaning the original bytes can be recovered from the passphrase and encrypted bytes.
3. Send an HTTP POST request to `<endpoint>`.
4. The request body must be the encrypted bytes.
5. The request must include an `X-File-Name` header whose value is the final component of the file path, i.e. the text after the last `/`.

Response handling:

- If the response status is 200 and the response body is a JSON object with a string field named `"id"`, write that id to standard output followed by a newline.
- If the response status is anything other than 200, write `ERROR <file path>` to standard error, where `<file path>` is exactly the line read from stdin.
- The id or error for each file path must appear in the same order as the file paths appeared in the input.

Example: suppose a server at `http://localhost:8000/upload` returns `{"id": "abc123"}` for each successful upload. Running

```
printf 'hunter2\n/tmp/a.txt\n/tmp/b.txt\n' | python dropvault.py http://localhost:8000/upload
```

should write two lines to stdout, such as `abc123` and `def456`, in the same order as the input paths.
