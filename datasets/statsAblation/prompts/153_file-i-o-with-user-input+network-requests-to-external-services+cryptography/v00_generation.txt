Write a Python program in a single file named `dropvault.py`. The program is a command-line utility that uploads encrypted file contents to a remote backup service.

Invocation:

```
python dropvault.py <endpoint>
```

`<endpoint>` is an HTTP URL.

Input: the program reads all of standard input as UTF-8 text. The first line is the passphrase; the trailing newline is not part of the passphrase. Every subsequent line is a file path. Lines that are empty after removing a trailing newline are skipped.

For each file path, read the file's contents as raw bytes, encrypt those bytes using the passphrase as the key, and send an HTTP POST request to `<endpoint>` whose body is the encrypted bytes and whose `X-File-Name` header is the final component of the file path (the text after the last `/`). The encryption must be reversible: given the passphrase and the encrypted bytes, the original bytes can be recovered.

For each request, if the response status is 200 and the response body is a JSON object with a string field named `"id"`, write that id to standard output followed by a newline. If the response status is anything other than 200, write the line `ERROR <file path>` to standard error, where `<file path>` is the exact line read from stdin. The id or error for each file path must appear in the same order as the file paths appear in the input.

Example: with a server at `http://localhost:8000/upload` that returns `{"id": "abc123"}` for each successful upload, running

```
printf 'hunter2\n/tmp/a.txt\n/tmp/b.txt\n' | python dropvault.py http://localhost:8000/upload
```

writes two lines to stdout, such as `abc123` and `def456`, in the order of the input paths.
