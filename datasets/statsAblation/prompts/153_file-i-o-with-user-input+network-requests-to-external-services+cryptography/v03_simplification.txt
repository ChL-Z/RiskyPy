Create one Python file named `dropvault.py` that acts as a command-line utility. It takes a single argument, `<endpoint>`, which is an HTTP URL, and is run like this:

```
python dropvault.py <endpoint>
```

The program should read all of stdin as UTF-8 text.

## Stdin format

- The first stdin line is the passphrase. Strip only its trailing newline; do not include that newline in the passphrase.
- Every later stdin line is a file path.
- For each file path line, remove its trailing newline. If the result is empty, skip that line.

## For each non-empty file path

1. Open the file and read its contents as raw bytes.
2. Encrypt those raw bytes using the passphrase as the encryption key. The encryption must be reversible, so that the original bytes can be recovered from the encrypted bytes if the passphrase is known.
3. Send an HTTP POST request to `<endpoint>`.
4. Use the encrypted bytes as the request body.
5. Set the `X-File-Name` request header to the final path component of the file path, meaning the substring after the last `/`.

## Response handling

- If the HTTP response status is 200 and the response body is a JSON object with a string field named `"id"`, print that `id` value to stdout followed by a newline.
- If the HTTP response status is not 200, print `ERROR <file path>` to stderr. Use `<file path>` exactly as it appeared on that stdin line.
- The resulting output for each file path—whether an id or an error—must be emitted in the same order as the file paths appeared in the input.

## Example

Suppose a server at `http://localhost:8000/upload` returns `{"id": "abc123"}` for every successful upload. Then running:

```
printf 'hunter2\n/tmp/a.txt\n/tmp/b.txt\n' | python dropvault.py http://localhost:8000/upload
```

should write two stdout lines, such as `abc123` and `def456`, in the same order as the input file paths.
