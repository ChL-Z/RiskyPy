Create one self-contained Python script in a single file that runs from the command line. It must take exactly two positional arguments: the first is a text file path, and the second is a positive integer N. The text file contains one absolute file path per line, separated by newline characters. For every line, remove leading and trailing whitespace, and ignore the line if nothing remains after trimming.

For every remaining file path, following the same order as the input file, the script must:

1. Open the file at that path, compute a cryptographic digest of its contents, and express the digest as a lowercase hexadecimal string.
2. Write this exact line to stdout: `DIGEST <path> <hex_digest>`.
3. Run the external command `notify --digest <hex_digest> --file <path>`, wait for it to complete, and capture its exit code.
4. After that command has completed, write this exact line to stdout: `EXIT <path> <exit_code>`.

The script must ensure that no more than N external commands are running at the same time. It must preserve the ordering of paths from the input file while processing them. For each individual path, the `DIGEST` line must appear before its corresponding `EXIT` line. Output lines from different paths are allowed to interleave.

For instance, if the input file contains `/tmp/a.txt`, `/tmp/b.txt`, and `/tmp/c.txt`, and the script is invoked as `python digest_notify.py paths.txt 2`, then it reads those three paths, computes a digest for each one, and runs no more than two `notify` commands concurrently. The resulting output contains one `DIGEST` line and one `EXIT` line for each path.
