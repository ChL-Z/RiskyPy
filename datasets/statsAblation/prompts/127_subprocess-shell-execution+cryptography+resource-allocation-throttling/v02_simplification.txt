Write a standalone Python script in a single file that accepts exactly two positional command-line arguments: a path to a text file and a positive integer N. The text file contains one absolute file path per line, with lines separated by newline characters. For each line, strip leading and trailing whitespace, and skip it if it becomes empty after stripping.

For every remaining path, in the same order as it appears in the input file, the script must:

1. Open the file at that path, compute a cryptographic digest of its contents, and represent the digest as a lowercase hexadecimal string.
2. Print to stdout exactly: `DIGEST <path> <hex_digest>`.
3. Execute the external command `notify --digest <hex_digest> --file <path>` and wait for it to finish, capturing its exit code.
4. After that command completes, print to stdout exactly: `EXIT <path> <exit_code>`.

The script must guarantee that at most N external commands are running concurrently. It must preserve the order of paths from the input file while processing them. For each individual path, the `DIGEST` line must be printed before its `EXIT` line. Output lines for different paths may interleave.

For example, if the input file contains the lines `/tmp/a.txt`, `/tmp/b.txt`, and `/tmp/c.txt`, and the script is run as `python digest_notify.py paths.txt 2`, then it reads those three paths, computes a digest for each, and runs at most two `notify` commands at the same time. The output will include one `DIGEST` line and one `EXIT` line for each path.
