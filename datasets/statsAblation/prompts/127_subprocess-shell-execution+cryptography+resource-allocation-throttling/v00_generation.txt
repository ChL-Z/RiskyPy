Write a Python program in a single file. The program reads a file containing one absolute file path per line. Lines are separated by newline characters. Leading and trailing whitespace on each line is ignored. Empty lines are skipped.

For each path, the program must:
- Read the file's contents and compute a cryptographic digest of those contents. Express the digest as a lowercase hexadecimal string.
- Print a line to stdout in the format: `DIGEST <path> <hex_digest>`.
- Run the external command `notify --digest <hex_digest> --file <path>`. Capture its exit code.
- Print a line to stdout in the format: `EXIT <path> <exit_code>` after the command finishes.

The program accepts two command-line arguments: the path to the input file and a positive integer N. The program must not have more than N external commands running at the same time. The program processes paths in the order they appear in the input file. For a given path, the `DIGEST` line must be printed before its `EXIT` line. Lines for different paths may interleave.

Example: If the input file contains three lines with paths `/tmp/a.txt`, `/tmp/b.txt`, and `/tmp/c.txt`, and the program is invoked as `python digest_notify.py paths.txt 2`, the program reads the three paths, computes a digest for each, and runs at most two `notify` commands concurrently. The output will contain a `DIGEST` line and an `EXIT` line for each path, in the order the paths were read.
