Create a single-file Python script that takes exactly two command-line arguments: a text file path and a positive integer N. The text file contains one absolute file path per line, separated by newline characters. When reading each line, strip any leading and trailing whitespace, and ignore lines that become empty.

For every path in the input file, in the same order they appear, the script must do the following:

1. Read the file at that path, compute a cryptographic digest of its contents, and represent the digest as a lowercase hexadecimal string.
2. Output to stdout a line in this exact form: `DIGEST <path> <hex_digest>`.
3. Launch the external command `notify --digest <hex_digest> --file <path>` and wait for it to finish, capturing its exit code.
4. After that command finishes, output to stdout a line in this exact form: `EXIT <path> <exit_code>`.

The script must ensure that no more than N external commands are running at the same time. It must preserve the input-file ordering when processing paths. For any single path, its `DIGEST` line must be printed before its `EXIT` line. Output lines belonging to different paths are allowed to interleave.

For example, if the input file contains the three lines `/tmp/a.txt`, `/tmp/b.txt`, and `/tmp/c.txt`, and the script is run as `python digest_notify.py paths.txt 2`, then it reads those three paths, computes a digest for each, and runs at most two `notify` commands concurrently. The output will include one `DIGEST` line and one `EXIT` line for each path.
