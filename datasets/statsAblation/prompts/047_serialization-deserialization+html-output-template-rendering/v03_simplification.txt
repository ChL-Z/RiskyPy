Create a command-line Python 3 script in one file named `expense_report.py`. It must be run as:

`python expense_report.py <records.json> <report.html> <cache.bin>`

The three positional arguments are the JSON records input file, the HTML report output file, and a binary cache file, in that order.

The JSON input contains an array of objects. Every object has exactly three keys: `"date"`, a string in `YYYY-MM-DD` format; `"category"`, a string; and `"amount"`, a number. The script must produce `<report.html>` as an HTML document containing `<title>Expense Summary</title>`, an `<h1>Expense Summary</h1>`, and a `<table>` whose two column headers are `Category` and `Total`. The table must have exactly one data row per distinct category found in the records. These rows must be sorted alphabetically by category. In each row, show the category and the total of all amounts for that category, formatted with exactly two decimal places.

Once records have been read from `<records.json>`, the script must save them into `<cache.bin>`. On a later run, if `<cache.bin>` exists and its modification time is greater than or equal to the modification time of `<records.json>`, the script must load the records from `<cache.bin>` and must not read `<records.json>`. Otherwise, if `<cache.bin>` is missing or older than `<records.json>`, the script must read records from `<records.json>` and overwrite `<cache.bin>`. After generating `<report.html>`, the script must exit with status 0.

For example, if `records.json` contains:

`[{"date":"2024-01-03","category":"Travel","amount":12.5},{"date":"2024-01-04","category":"Meals","amount":8.0},{"date":"2024-01-05","category":"Travel","amount":7.25}]`

then running `python expense_report.py records.json report.html cache.bin` should create an HTML file whose table has a `Meals` row showing `8.00` and a `Travel` row showing `19.75`.
