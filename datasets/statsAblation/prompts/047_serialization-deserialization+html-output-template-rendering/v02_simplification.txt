Write a single-file Python 3 script called `expense_report.py` that is executed from the command line in this form:

`python expense_report.py <records.json> <report.html> <cache.bin>`

The three positional arguments are, respectively, the JSON input file containing records, the HTML report file to generate, and the binary cache file.

The JSON input file holds an array of objects. Each object has exactly these three keys: `"date"`, whose value is a `YYYY-MM-DD` string; `"category"`, whose value is a string; and `"amount"`, whose value is a number. The script must write `<report.html>` as an HTML document that includes `<title>Expense Summary</title>`, an `<h1>Expense Summary</h1>`, and a `<table>` with two column headers: `Category` and `Total`. For each distinct category present in the records, the table must contain exactly one data row. These rows must be ordered alphabetically by category. Each row must display the category and the sum of all amounts belonging to that category, formatted to exactly two decimal places.

After the records have been read from `<records.json>`, the script must save those records to `<cache.bin>`. On a later execution, if `<cache.bin>` exists and its modification time is greater than or equal to the modification time of `<records.json>`, then the script must load the records from `<cache.bin>` and must not read `<records.json>`. If `<cache.bin>` does not exist or is older than `<records.json>`, then the script must read records from `<records.json>` and overwrite `<cache.bin>`. After writing `<report.html>`, the script must terminate with exit status 0.

For instance, suppose `records.json` contains:

`[{"date":"2024-01-03","category":"Travel","amount":12.5},{"date":"2024-01-04","category":"Meals","amount":8.0},{"date":"2024-01-05","category":"Travel","amount":7.25}]`

Then running `python expense_report.py records.json report.html cache.bin` should generate an HTML file whose table includes a `Meals` row with `8.00` and a `Travel` row with `19.75`.
