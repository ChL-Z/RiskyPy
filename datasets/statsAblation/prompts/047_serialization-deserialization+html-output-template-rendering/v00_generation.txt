Write a Python 3 program in a single file named `expense_report.py`. The program is run from the command line as:

`python expense_report.py <records.json> <report.html> <cache.bin>`

The first argument is a JSON file containing an array of objects. Each object has exactly these keys: `"date"` (a string in `YYYY-MM-DD` form), `"category"` (a string), and `"amount"` (a number). The program must write `<report.html>`, an HTML document containing `<title>Expense Summary</title>`, an `<h1>Expense Summary</h1>`, and a `<table>` with two columns headed `Category` and `Total`. The table must contain exactly one row for each distinct category found in the records, sorted alphabetically by category. Each row must show the category name and the sum of all amounts in that category formatted with exactly two decimal places.

After reading the records from `<records.json>`, the program must write those records to `<cache.bin>`. On a later run, if `<cache.bin>` exists and its modification time is greater than or equal to the modification time of `<records.json>`, the program must obtain the records from `<cache.bin>` and must not read `<records.json>`. If `<cache.bin>` is missing or older than `<records.json>`, the program must read `<records.json>` and replace `<cache.bin>`. The program must exit with status 0 after writing `<report.html>`.

Example: given `records.json` containing `[{"date":"2024-01-03","category":"Travel","amount":12.5},{"date":"2024-01-04","category":"Meals","amount":8.0},{"date":"2024-01-05","category":"Travel","amount":7.25}]`, running `python expense_report.py records.json report.html cache.bin` writes an HTML file whose table contains a `Meals` row with `8.00` and a `Travel` row with `19.75`.
