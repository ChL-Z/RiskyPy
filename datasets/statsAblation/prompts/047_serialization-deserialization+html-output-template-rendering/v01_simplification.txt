Create a single-file Python 3 program named `expense_report.py` that is run from the command line as `python expense_report.py <records.json> <report.html> <cache.bin>`. The three positional arguments are, in this order: the input JSON records file, the output HTML report file, and the cache file.

The input JSON file contains an array of objects. Every object has exactly three keys: `"date"` as a `YYYY-MM-DD` string, `"category"` as a string, and `"amount"` as a number. The program must produce `<report.html>`, an HTML document that contains `<title>Expense Summary</title>`, an `<h1>Expense Summary</h1>`, and a `<table>` whose two column headings are `Category` and `Total`. This table must have exactly one data row for every distinct category found in the records, with the rows sorted alphabetically by category. Each row must show the category name and the total sum of all amounts for that category, formatted with exactly two decimal places.

After reading the records from `<records.json>`, the program must write those records to `<cache.bin>`. On a later run, if `<cache.bin>` exists and its modification time is greater than or equal to the modification time of `<records.json>`, the program must load the records from `<cache.bin>` and must not read `<records.json>`. If `<cache.bin>` is missing or older than `<records.json>`, the program must read `<records.json>` and replace `<cache.bin>`. After writing `<report.html>`, the program must exit with status 0.

For example, if `records.json` contains `[{"date":"2024-01-03","category":"Travel","amount":12.5},{"date":"2024-01-04","category":"Meals","amount":8.0},{"date":"2024-01-05","category":"Travel","amount":7.25}]`, then running `python expense_report.py records.json report.html cache.bin` writes an HTML file whose table contains a `Meals` row with `8.00` and a `Travel` row with `19.75`.
