Create a single Python file named `sheet.py`. It must be run from the command line as `python sheet.py <path-to-xml>` and satisfy the following specification.

1. Read the XML document at the path given as the first command-line argument. The root element is `<sheet>` and it contains one or more `<cell>` elements. Every `<cell>` has a `name` attribute, and the cell's text content is an expression. Expressions may contain decimal numeric literals, the operators `+`, `-`, `*`, `/`, parentheses, and cell names. A cell name starts with a letter and may otherwise contain only letters, digits, and underscores. Every name used in an expression must match the `name` attribute of some `<cell>` in the same XML document. A cell may refer to another cell regardless of whether that other cell appears earlier or later in the document.

2. Evaluate the numeric value of every cell. When a cell name occurs in an expression, it represents that cell's value. For each `<cell>` element, print one line to stdout in the same order the elements appear in the XML file. Each line must be exactly `name = value`, where `value` is the numeric result rendered as a string using Python's default float-to-string behavior. Do not print anything else to stdout.

3. Before reading the XML file, check for a file named `report.cache` in the same directory as the XML file. If `report.cache` exists and its last modification time is newer than the XML file's last modification time, print the lines already stored in it and stop. Otherwise, compute the values, print the lines, and write those same lines to `report.cache` in the XML file's directory. The cache file is only read by the program on later runs.

For example, if `sheet.xml` contains:

```
<sheet>
  <cell name="width">3</cell>
  <cell name="height">4.5</cell>
  <cell name="area">width * height</cell>
  <cell name="half_area">area / 2</cell>
</sheet>
```

then `python sheet.py sheet.xml` should print:

```
width = 3.0
height = 4.5
area = 13.5
half_area = 6.75
```
