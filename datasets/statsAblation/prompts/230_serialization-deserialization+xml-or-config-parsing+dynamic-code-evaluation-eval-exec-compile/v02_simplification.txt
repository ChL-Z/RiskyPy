Write one Python file called `sheet.py`. It will be invoked from the command line as `python sheet.py <path-to-xml>` and must behave as follows.

1. Load the XML document whose path is supplied as the first command-line argument. The document's root element is `<sheet>`, and it contains one or more `<cell>` elements. Every `<cell>` has a `name` attribute, and the text content of the cell is an expression. Expressions may contain decimal numeric literals, the operators `+`, `-`, `*`, `/`, parentheses, and cell names. A cell name begins with a letter and may otherwise contain only letters, digits, and underscores. Any name that appears in an expression must equal the `name` attribute of a `<cell>` somewhere in the same XML document. A cell is allowed to reference another cell whether that other cell occurs earlier or later in the document.

2. Compute the numeric value of each cell. When a cell name appears inside an expression, it stands for that cell's value. For every `<cell>` element, output one line to stdout in the same order the elements appear in the XML file. Each line must be exactly `name = value`, where `value` is the numeric result converted to a string using Python's default float-to-string behavior. Write nothing else to stdout.

3. Before reading the XML file, check for a file named `report.cache` in the same directory as the XML file. If `report.cache` exists and its last modification time is newer than the XML file's last modification time, then print the lines already stored in it and terminate. Otherwise, compute the values, print the lines, and write those same lines to `report.cache` in the XML file's directory. This cache file is only ever read by the program on a later run.

For example, if `sheet.xml` contains:

```
<sheet>
  <cell name="width">3</cell>
  <cell name="height">4.5</cell>
  <cell name="area">width * height</cell>
  <cell name="half_area">area / 2</cell>
</sheet>
```

then `python sheet.py sheet.xml` should print:

```
width = 3.0
height = 4.5
area = 13.5
half_area = 6.75
```
