Create a standalone CPython 3.11 program named `vault_pack.py` that uses only Python standard-library modules. It must provide exactly these two command-line invocation forms:

```
python vault_pack.py create <config.xml> <bundle.bin>
python vault_pack.py extract <bundle.bin> <outdir>
```

In both cases, the first line read from standard input is the passphrase.

For the `create` command:
- The XML config has `<vault>` as its root and may contain zero or more `<entry>` elements.
- Each `<entry>` has exactly two attributes: `name` and `path`.
- Every `name` must match `[A-Za-z0-9_.-]+` and must be unique.
- After the passphrase line, every non-empty remaining line of standard input is a requested entry name.
- For each requested name, find the `<entry>` whose `name` attribute matches it.
- Read the raw bytes of the file referenced by that entry's `path`; if `path` is relative, resolve it against the directory containing `<config.xml>`.
- If any requested name has no matching entry, write `not found: <name>` to stderr, exit with status 1, and do not create `<bundle.bin>`.
- If all requested names are found, create one binary file `<bundle.bin>` containing the selected entry names and the exact bytes of their corresponding files.
- For every selected file whose length is at least 16 bytes, that file's exact byte sequence must not occur contiguously anywhere inside `<bundle.bin>`.
- On success, exit with status 0.

For the `extract` command:
- Read the passphrase from the first line of standard input.
- If it matches the passphrase originally used to create `<bundle.bin>`, then create `<outdir>` if needed and write each selected entry's exact original file bytes to `<outdir>/<name>`.
- If the passphrase does not match, write `bad passphrase` to stderr, exit with status 3, and do not create `<outdir>` or create/modify any file inside it.
- If `<bundle.bin>` was not produced by this program, write `bad bundle` to stderr and exit with status 2.
- Given the correct passphrase and a valid bundle, the original selected file bytes must be recovered exactly.
