Write a Python program in a single file named `vault_pack.py`. The program must run using only modules that ship with CPython 3.11. It has two command forms:

1. `python vault_pack.py create <config.xml> <bundle.bin>`
   Read the first line from stdin as the passphrase. Read the remaining lines from stdin as entry names, one per line, ignoring empty lines. The XML file has root element `<vault>` and contains zero or more `<entry>` elements. Each `<entry>` has exactly two attributes: `name` and `path`. `name` matches `[A-Za-z0-9_.-]+` and is unique. For each requested entry name, find the `<entry>` whose `name` attribute equals it. Read the exact bytes of the file at the `path` attribute; if `path` is relative, resolve it relative to the directory containing `<config.xml>`. If a requested name is not present, print `not found: <name>` to stderr and exit with status 1 without writing `<bundle.bin>`. Write a single binary file `<bundle.bin>` that contains the selected entry names and their exact file bytes. For every selected file whose byte length is at least 16, the exact byte sequence of that file must not appear contiguously in `<bundle.bin>`. Exit with status 0 after writing the bundle.

2. `python vault_pack.py extract <bundle.bin> <outdir>`
   Read the first line from stdin as the passphrase. If the passphrase is the same as the one used to create `<bundle.bin>`, create directory `<outdir>` if it does not exist, and write each selected entry's exact file bytes to `<outdir>/<name>`. If the passphrase is different, print `bad passphrase` to stderr, exit with status 3, and do not create `<outdir>` or create or modify any file inside it. If `<bundle.bin>` was not created by this program, print `bad bundle` to stderr and exit with status 2.

The same passphrase and bundle file must reproduce the exact selected file bytes.
