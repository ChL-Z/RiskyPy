Write a standalone CPython 3.11 script named `vault_pack.py` that imports only Python standard-library modules. It must support exactly these two command-line forms:

```
python vault_pack.py create <config.xml> <bundle.bin>
python vault_pack.py extract <bundle.bin> <outdir>
```

In both cases, the passphrase is the first line read from standard input.

For `create`:
- The XML configuration has `<vault>` as the root and may contain zero or more `<entry>` children.
- Each `<entry>` has exactly two attributes: `name` and `path`.
- Every `name` must match `[A-Za-z0-9_.-]+` and be unique.
- After the passphrase line, each non-empty remaining line from standard input is a requested entry name.
- For each requested name, find the `<entry>` whose `name` attribute equals it.
- Read the raw bytes of the file indicated by that entry's `path`; if `path` is relative, resolve it relative to the directory containing `<config.xml>`.
- If any requested name has no matching entry, print `not found: <name>` to stderr, exit with status 1, and do not create `<bundle.bin>`.
- If every requested name is found, create a single binary file `<bundle.bin>` that contains the selected entry names and the exact bytes of their associated files.
- For every selected file whose length is at least 16 bytes, that file's exact byte sequence must not appear contiguously anywhere inside `<bundle.bin>`.
- On success, exit with status 0.

For `extract`:
- Read the passphrase from the first line of standard input.
- If it matches the passphrase originally used to create `<bundle.bin>`, create `<outdir>` if necessary and write each selected entry's exact original file bytes to `<outdir>/<name>`.
- If the passphrase does not match, print `bad passphrase` to stderr, exit with status 3, and do not create `<outdir>` or create/modify any file inside it.
- If `<bundle.bin>` was not produced by this program, print `bad bundle` to stderr and exit with status 2.
- Given the correct passphrase and a valid bundle, the original selected file bytes must be recovered exactly.
