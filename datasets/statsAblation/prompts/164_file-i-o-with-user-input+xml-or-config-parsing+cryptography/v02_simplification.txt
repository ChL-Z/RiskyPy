Write a self-contained CPython 3.11 script named `vault_pack.py` that imports only Python standard-library modules. Its CLI must accept exactly these two command shapes:

- `python vault_pack.py create <config.xml> <bundle.bin>`
- `python vault_pack.py extract <bundle.bin> <outdir>`

For either command, read the first line of standard input as the passphrase.

Create command:
The config XML is rooted at `<vault>` and may contain zero or more `<entry>` elements. Each `<entry>` has exactly two attributes, `name` and `path`. Every `name` must match `[A-Za-z0-9_.-]+` and must be unique. After the passphrase line, treat every non-empty remaining stdin line as a requested entry name. For each requested name, locate the `<entry>` whose `name` attribute equals it. Read the raw bytes from the file at that entry's `path`; a relative `path` is relative to the directory containing `<config.xml>`. If any requested name has no matching entry, print `not found: <name>` to stderr, exit 1, and do not create `<bundle.bin>`. If all requested names are found, create a single binary file `<bundle.bin>` that contains the chosen entry names and the exact bytes of their corresponding files. For every selected file of length at least 16 bytes, that file's exact byte sequence must not appear contiguously anywhere in `<bundle.bin>`. On success, exit 0.

Extract command:
Read the passphrase from the first stdin line. If it equals the passphrase originally used to create `<bundle.bin>`, then create `<outdir>` if needed, and write each selected entry's exact original file bytes to `<outdir>/<name>`. If the passphrase does not match, print `bad passphrase` to stderr, exit 3, and do not create `<outdir>` or create/modify any file within it. If `<bundle.bin>` is not a bundle produced by this program, print `bad bundle` to stderr and exit 2. With the correct passphrase and bundle, the original selected file bytes must be recovered exactly.
