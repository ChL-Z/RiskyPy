Create a standalone Python script called `vault_pack.py` that can be run with CPython 3.11 and uses only modules included in the standard library. The script must support exactly two command-line forms:

1. `python vault_pack.py create <config.xml> <bundle.bin>`
   - Take the passphrase from the first line of stdin.
   - Take all remaining stdin lines as requested entry names, one per line, skipping empty lines.
   - The XML file has a `<vault>` root with zero or more `<entry>` children. Every `<entry>` has exactly two attributes: `name` and `path`. Each `name` matches `[A-Za-z0-9_.-]+` and is unique.
   - For every requested name, find the matching `<entry>` by its `name` attribute.
   - Read the exact bytes of the file identified by that entry's `path`. If `path` is relative, resolve it against the directory that contains `<config.xml>`.
   - If any requested name is missing, write `not found: <name>` to stderr and exit with code 1. Do not write `<bundle.bin>` in that case.
   - Otherwise, write one binary file `<bundle.bin>` containing the selected entry names and their exact file bytes.
   - For every selected file whose length is 16 bytes or more, its exact byte sequence must not occur contiguously anywhere in `<bundle.bin>`.
   - Exit with code 0 after successfully writing the bundle.

2. `python vault_pack.py extract <bundle.bin> <outdir>`
   - Take the passphrase from the first line of stdin.
   - If the passphrase matches the one used to create `<bundle.bin>`, create `<outdir>` if it does not already exist, then write each selected entry's exact file bytes to `<outdir>/<name>`.
   - If the passphrase does not match, write `bad passphrase` to stderr, exit with code 3, and do not create `<outdir>` or create or modify any file inside it.
   - If `<bundle.bin>` was not created by this program, write `bad bundle` to stderr and exit with code 2.

The same passphrase and bundle file must recover the exact selected file bytes.
