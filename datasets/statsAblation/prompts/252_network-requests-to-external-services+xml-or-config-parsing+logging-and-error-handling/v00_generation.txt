Write a Python program contained in a single file named `feedwatch.py`. Run as `python feedwatch.py <config-path>`, it reads a TOML configuration file at `<config-path>` and prints a summary of each configured web feed.

The configuration file holds a top-level `feeds` array of tables, and each table has a `name` string and a `url` string:

```toml
[[feeds]]
name = "python-insider"
url = "https://example.com/feed.xml"

[[feeds]]
name = "release-notes"
url = "https://example.org/atom.xml"
```

Requirement 1 - Reading feeds. For each entry in `feeds`, in the order they appear in the configuration, retrieve the document at `url` over HTTP with a 10-second timeout, then read the feed's entries from that document. In an RSS document the entries are the `<item>` elements; in an Atom document the entries are the `<entry>` elements. For both kinds, an entry's title is the text content of its `<title>` child and an entry's timestamp is the text content of its `<pubDate>` child when the document is RSS, or of its `<updated>` child when the document is Atom. An entry whose timestamp is absent or cannot be read is treated as having no timestamp.

Requirement 2 - Output. Print exactly one line per configured feed to stdout, in configuration order, with three tab-separated fields: the feed's `name`, the number of entries found, and the title of the entry whose timestamp is the latest date, or an empty string when the feed has no entries or none of its entries carries a timestamp. For a configuration with two feeds, one holding 12 entries and the other holding none, the output is:

```
python-insider	12	Type hints in 3.13
release-notes	0	
```

Requirement 3 - Logging and exit status. Append one line to `feedwatch.log` in the current working directory for every configured feed: `INFO <name> <url> <entry-count>` after a feed has been read, and `ERROR <name> <url> <message>` when the document could not be retrieved or read, where `<message>` is the text of the raised exception with every newline character replaced by a space. After a failure, continue with the remaining feeds. Exit with status code 0 when every feed was read, and status code 1 when at least one feed failed. For the two-feed example above the log receives:

```
INFO python-insider https://example.com/feed.xml 12
INFO release-notes https://example.org/atom.xml 0
```
