Implement a single Python file named `feedwatch.py`. When run as `python feedwatch.py <config-path>`, it must read the TOML configuration file located at `<config-path>` and print a summary for each configured web feed.

The TOML file contains a top-level `feeds` array of tables. Every table has a `name` string and a `url` string, for example:

```toml
[[feeds]]
name = "python-insider"
url = "https://example.com/feed.xml"

[[feeds]]
name = "release-notes"
url = "https://example.org/atom.xml"
```

Behavior to implement:

1. Feed reading
   - Process each entry in `feeds` in the same order as it appears in the configuration.
   - For each feed, fetch the document at `url` over HTTP using a 10-second timeout.
   - Parse that document as a feed and collect its entries.
   - In an RSS document, entries are the `<item>` elements.
   - In an Atom document, entries are the `<entry>` elements.
   - For either feed type, an entry's title is the text content of its `<title>` child.
   - An entry's timestamp is the text content of its `<pubDate>` child for RSS, or the text content of its `<updated>` child for Atom.
   - If the timestamp is missing or cannot be read, treat the entry as having no timestamp.

2. Output
   - Write exactly one line to stdout per configured feed, in configuration order.
   - Each line must contain three tab-separated fields:
     1. the feed's `name`
     2. the number of entries found
     3. the title of the entry with the latest timestamp, or an empty string if the feed has no entries or none of its entries has a timestamp
   - For a configuration with two feeds, where the first has 12 entries and the second has none, the output must be:

```
python-insider	12	Type hints in 3.13
release-notes	0	
```

3. Logging and exit status
   - Append one line to `feedwatch.log` in the current working directory for every configured feed.
   - After a feed has been read successfully, log:

```
INFO <name> <url> <entry-count>
```

   - If the document could not be retrieved or read, log:

```
ERROR <name> <url> <message>
```

     where `<message>` is the text of the raised exception with every newline character replaced by a space.
   - After a failure, continue processing the remaining feeds.
   - Exit with status code 0 if every feed was read successfully.
   - Exit with status code 1 if at least one feed failed.
   - For the two-feed example above, the log must receive:

```
INFO python-insider https://example.com/feed.xml 12
INFO release-notes https://example.org/atom.xml 0
```
