Create a Python program in a file called `feedwatch.py`. It should be executed from the command line as `python feedwatch.py <config-path>`, where `<config-path>` points to a TOML configuration file. The program must read that TOML file and display a summary for every web feed defined in it.

The TOML file uses a top-level `feeds` array of tables. Each feed table contains a `name` string and a `url` string, for example:

```toml
[[feeds]]
name = "python-insider"
url = "https://example.com/feed.xml"

[[feeds]]
name = "release-notes"
url = "https://example.org/atom.xml"
```

Required behavior:

1. Reading feeds
   - Visit each entry in `feeds` in the exact order it appears in the configuration.
   - For every feed, perform an HTTP request to its `url` with a timeout of 10 seconds.
   - Parse the returned document as a feed and gather its entries.
   - For RSS documents, the entries are the `<item>` elements.
   - For Atom documents, the entries are the `<entry>` elements.
   - For any entry, the title is the text inside its `<title>` child.
   - The entry timestamp is the text inside `<pubDate>` for RSS, or the text inside `<updated>` for Atom.
   - If no timestamp can be found or read, the entry is considered to have no timestamp.

2. Output
   - Print exactly one line to stdout for each configured feed, preserving configuration order.
   - Each line must consist of three fields separated by tab characters:
     1. the feed’s `name`
     2. the number of entries found
     3. the title of the entry with the newest timestamp, or an empty string if the feed has no entries or no entry has a timestamp
   - For example, if the first feed has 12 entries and the second has none, the output must be:

```
python-insider	12	Type hints in 3.13
release-notes	0	
```

3. Logging and exit code
   - Append one line to `feedwatch.log` in the current working directory for every configured feed.
   - When a feed is read successfully, write:

```
INFO <name> <url> <entry-count>
```

   - If the document cannot be retrieved or read, write:

```
ERROR <name> <url> <message>
```

     Here `<message>` is the exception’s text, with every newline character replaced by a space.
   - After a failure, keep processing the remaining feeds.
   - Exit with status code 0 if all feeds were read successfully.
   - Exit with status code 1 if at least one feed failed.
   - For the two-feed example above, the log must contain:

```
INFO python-insider https://example.com/feed.xml 12
INFO release-notes https://example.org/atom.xml 0
```
