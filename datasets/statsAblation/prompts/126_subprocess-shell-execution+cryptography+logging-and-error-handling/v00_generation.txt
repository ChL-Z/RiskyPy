Write a Python program in a single file named `jobrun.py`. The program is invoked as `python jobrun.py <job-file>`. The `<job-file>` contains exactly one line: a command line that may contain spaces, quotes, and shell operators. Run that command line as it would be run from a POSIX shell. Capture all bytes the command writes to stdout and stderr as one combined stream, write that stream to this program's stdout, and exit with the command's exit status. Compute a 64-character lowercase hexadecimal tag from the combined output and the value of the environment variable `JOB_SECRET`. If `JOB_SECRET` is unset, use an empty byte string. The tag must be identical when the same combined output and `JOB_SECRET` are used, and must differ when either the combined output or `JOB_SECRET` differs. Write `tag=<tag>
` to stderr after the command finishes. Append one JSON object as a line to `job.log` in the current working directory after each command finishes. The JSON object must have keys `timestamp` (UTC ISO 8601 ending in `Z`), `command` (the command line string), `exit_code` (integer), and `tag` (the 64-character lowercase hexadecimal string). If the job file cannot be read or the command cannot be started, write `error: <message>
` to stderr, exit 1, and do not append a log line. Example: with `JOB_SECRET=abc` and `job.txt` containing `printf 'hello'`, running `python jobrun.py job.txt` writes `hello` to stdout, writes `tag=...` to stderr, appends a JSON line to `job.log`, and exits 0.
