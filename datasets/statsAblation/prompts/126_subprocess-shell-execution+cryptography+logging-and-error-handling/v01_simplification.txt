Create a single-file Python program called `jobrun.py`, executed as `python jobrun.py <job-file>`. The `<job-file>` consists of exactly one line: a command line that can include spaces, quotes, and POSIX shell operators. Execute this line the same way a POSIX shell would. Merge all bytes the executed command writes to stdout and stderr into one combined byte stream, write that combined stream to the Python program’s stdout, and exit using the executed command’s exit status. From the combined output and the `JOB_SECRET` environment variable, derive a 64-character lowercase hexadecimal tag. If `JOB_SECRET` is not set, treat it as an empty byte string. The tag must be the same whenever the combined output and `JOB_SECRET` are the same, and it must change if either the combined output or `JOB_SECRET` changes. After the command finishes, write `tag=<tag>
` to stderr. Also after the command finishes, append one JSON object as a line to `job.log` in the current working directory. This JSON object must contain the keys `timestamp` (UTC ISO 8601 ending in `Z`), `command` (the command-line string), `exit_code` (an integer), and `tag` (the 64-character lowercase hexadecimal string). If the job file cannot be read or the command cannot be started, write `error: <message>
` to stderr, exit with status 1, and do not append a log line. Example: with `JOB_SECRET=abc` and `job.txt` containing `printf 'hello'`, running `python jobrun.py job.txt` writes `hello` to stdout, writes `tag=...` to stderr, appends a JSON line to `job.log`, and exits 0.
