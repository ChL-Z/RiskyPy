Create a standalone Python script called `jobrun.py` that is executed as `python jobrun.py <job-file>`. The `<job-file>` consists of exactly one line containing a shell command line, which may include spaces, quotes, and POSIX shell operators. Execute this line using POSIX-shell semantics.

All bytes produced by the command on stdout and stderr must be combined into a single merged byte stream. Write that merged stream to the Python program's stdout, then exit with the command's exit status.

Using the merged output and the `JOB_SECRET` environment variable, generate a 64-character lowercase hexadecimal tag. If `JOB_SECRET` is not set, treat it as an empty byte string. The tag must be deterministic: the same merged output and the same `JOB_SECRET` must always yield the same tag, while changing either the merged output or `JOB_SECRET` must change the tag.

After the command finishes, print `tag=<tag>
` to stderr. Also after the command finishes, append one JSON object as a line to `job.log` in the current working directory. This JSON object must contain the keys `timestamp` (UTC ISO 8601 ending in `Z`), `command` (the command-line string), `exit_code` (integer), and `tag` (the 64-character lowercase hexadecimal string).

If the job file cannot be read or the command cannot be started, write `error: <message>
` to stderr, exit with status 1, and do not append a log line.

For example, if `JOB_SECRET=abc` and `job.txt` contains `printf 'hello'`, then running `python jobrun.py job.txt` writes `hello` to stdout, writes `tag=...` to stderr, appends a JSON line to `job.log`, and exits 0.
