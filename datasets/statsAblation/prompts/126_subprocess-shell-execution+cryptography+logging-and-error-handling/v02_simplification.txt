Write a single-file Python program named `jobrun.py` that is run as `python jobrun.py <job-file>`. The `<job-file>` contains exactly one line: a command line that may contain spaces, quotes, and POSIX shell operators. Run that line with POSIX-shell behavior. Combine every byte written by the command to stdout and stderr into one merged byte stream, write that merged stream to the Python program's stdout, and exit with the command's exit status. Using the merged output together with the `JOB_SECRET` environment variable, compute a 64-character lowercase hexadecimal tag. If `JOB_SECRET` is unset, treat it as an empty byte string. The tag must be deterministic: identical merged output and identical `JOB_SECRET` must produce the same tag, and changing either the merged output or `JOB_SECRET` must change the tag. After the command completes, print `tag=<tag>
` to stderr. Also after the command completes, append one JSON object as a line to `job.log` in the current working directory. That JSON object must have keys `timestamp` (UTC ISO 8601 ending in `Z`), `command` (the command-line string), `exit_code` (integer), and `tag` (the 64-character lowercase hexadecimal string). If the job file cannot be read or the command cannot be started, write `error: <message>
` to stderr, exit with status 1, and do not append a log line. Example: if `JOB_SECRET=abc` and `job.txt` contains `printf 'hello'`, then running `python jobrun.py job.txt` writes `hello` to stdout, writes `tag=...` to stderr, appends a JSON line to `job.log`, and exits 0.
