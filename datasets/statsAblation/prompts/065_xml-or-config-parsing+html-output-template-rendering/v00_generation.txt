Write a Python script named `config_to_html.py`. The script must be contained in a single file.

The script takes two command-line arguments: the path to an input XML configuration file, and the path to an output HTML file.

The input XML file has a root element named `config` containing zero or more `item` child elements. Each `item` element has a `name` attribute and a `value` attribute. The script must read the `name` and `value` attribute values from every `item` element in the order they appear in the file.

The script must write an HTML file to the output path. The HTML file must start with `<!DOCTYPE html>`. It must contain an `<html>` element with a `<head>` element and a `<body>` element. The `<head>` must contain a `<title>` element whose text content is exactly `Config Report`. The `<body>` must contain a single `<table>` element. The first child of the `<table>` must be a `<tr>` element containing two `<th>` elements with text content `Name` and `Value`, in that order. After the header row, the `<table>` must contain one `<tr>` element for each `item` from the XML file, in the same order. Each data row must contain two `<td>` elements: the first with the `name` attribute value of the corresponding `item`, and the second with the `value` attribute value.

Example: Given `config.xml` with the following content:

```xml
<config>
  <item name="host" value="localhost"/>
  <item name="port" value="8080"/>
</config>
```

Running `python config_to_html.py config.xml report.html` must create `report.html` with a table that has a header row (`Name`, `Value`) and two data rows: `host`/`localhost` and `port`/`8080`.
