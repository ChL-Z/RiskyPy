Create a single-file Python program called config_to_html.py. When run, it should accept exactly two command-line arguments: the first is the path to an XML configuration file to read, and the second is the path to an HTML file to write.

The XML input has a root element named config. Inside config, there can be any number of item elements, including none. Every item element has a name attribute and a value attribute. Your program should process all item elements in document order and collect each item's name and value attributes.

The program must write an HTML document to the given output path. This HTML document must begin with <!DOCTYPE html>. It must have an <html> element containing a <head> and a <body>.

Inside <head>, include a <title> element whose text is exactly Config Report.

Inside <body>, include exactly one <table> element. The table's first child must be a <tr> containing two <th> elements. The first <th> must contain the text Name, and the second must contain Value, in that order.

After that header row, the table must contain one data row per item from the XML file, preserving the original order. Each data row must be a <tr> with two <td> elements: the first <td> contains that item's name attribute value, and the second <td> contains that item's value attribute value.

For example, if config.xml contains:

<config>
  <item name="host" value="localhost"/>
  <item name="port" value="8080"/>
</config>

then running python config_to_html.py config.xml report.html should produce report.html containing a table with a header row Name, Value and two data rows: host, localhost and port, 8080.
