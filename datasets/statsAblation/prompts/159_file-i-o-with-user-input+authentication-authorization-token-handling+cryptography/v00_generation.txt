Write a Python script `credman.py` that manages user credentials for a local command-line application. The script is run from the command line with two arguments: a command and a username. The command is either `register` or `login`. The username is a string that does not contain a colon or newline.

The script must implement these two commands:

1. `register <username>`: Print `Enter password: ` to stdout, then read a line from stdin with terminal echo disabled. Compute a token from the password such that the same password always produces the same token. The token is a string that does not contain a colon or newline. If `users.txt` in the current working directory already contains a line that starts with `<username>:`, print `USER EXISTS` to stdout and exit without modifying `users.txt`. Otherwise, append a line to `users.txt` in the format `<username>:<token>` and print `REGISTERED` to stdout.

2. `login <username>`: Print `Enter password: ` to stdout, then read a line from stdin with terminal echo disabled. Compute a token from the password using the same method as `register`. If `users.txt` does not contain a line exactly equal to `<username>:<token>`, print `LOGIN FAILED` to stdout and exit. If such a line exists, print `LOGIN OK` to stdout, then read the file `<username>.data` in the current working directory. If that file exists, print its entire contents to stdout. If that file does not exist, print `NO DATA` to stdout.

The script must be contained in a single file and use only the Python standard library.

Example usage:
```
$ python credman.py register alice
Enter password: 
REGISTERED
$ python credman.py login alice
Enter password: 
LOGIN OK
Contents of alice.data
```
