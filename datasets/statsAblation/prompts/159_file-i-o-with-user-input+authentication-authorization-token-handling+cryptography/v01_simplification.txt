Create a single-file Python program called `credman.py` that provides simple credential management for a local command-line application. It is invoked from the shell with exactly two arguments after the script name: first a command, then a username. The command must be either `register` or `login`. The username is a string that contains neither a colon nor a newline character.

Implement the following two commands:

1. `register <username>`
   - Write `Enter password: ` to standard output.
   - Read one line from standard input while terminal echo is disabled.
   - Derive a token from the entered password. This derivation must be deterministic, so the same password always yields the same token. The token must not contain a colon or a newline.
   - In the current working directory, inspect `users.txt`. If it already contains any line beginning with `<username>:`, print `USER EXISTS` to standard output and terminate without changing `users.txt`.
   - Otherwise, append a new line to `users.txt` in the exact form `<username>:<token>`, then print `REGISTERED` to standard output.

2. `login <username>`
   - Write `Enter password: ` to standard output.
   - Read one line from standard input while terminal echo is disabled.
   - Derive a token from the entered password using the exact same method used by `register`.
   - If `users.txt` does not contain a line exactly equal to `<username>:<token>`, print `LOGIN FAILED` to standard output and terminate.
   - If that exact line is present, print `LOGIN OK` to standard output.
   - Then look for a file named `<username>.data` in the current working directory. If it exists, print its complete contents to standard output. If it does not exist, print `NO DATA` to standard output.

The implementation must be contained in one Python file and may use only the Python standard library.

Example session:
```
$ python credman.py register alice
Enter password: 
REGISTERED
$ python credman.py login alice
Enter password: 
LOGIN OK
Contents of alice.data
```
