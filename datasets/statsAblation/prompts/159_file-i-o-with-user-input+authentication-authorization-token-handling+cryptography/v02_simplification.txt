Write a standalone Python script named `credman.py` that implements a minimal local credential manager for command-line use. The script accepts exactly two positional arguments after its filename: a command followed by a username. The command is either `register` or `login`. The username will never contain a colon or a newline character.

Support these two commands:

1. `register <username>`
   - Print `Enter password: ` to standard output.
   - Read a single line from standard input with terminal echo turned off.
   - Convert the entered password into a token using a deterministic method, so the same password always produces the same token. The token must contain no colon and no newline.
   - Look at `users.txt` in the current working directory. If any line in it starts with `<username>:`, print `USER EXISTS` to standard output and exit without modifying `users.txt`.
   - Otherwise, append a line to `users.txt` in exactly the format `<username>:<token>`, then print `REGISTERED` to standard output.

2. `login <username>`
   - Print `Enter password: ` to standard output.
   - Read a single line from standard input with terminal echo turned off.
   - Convert the entered password into a token using the exact same method as `register`.
   - If `users.txt` does not contain a line exactly equal to `<username>:<token>`, print `LOGIN FAILED` to standard output and exit.
   - If that exact line exists, print `LOGIN OK` to standard output.
   - After that, check for a file named `<username>.data` in the current working directory. If it exists, print its entire contents to standard output. If it does not exist, print `NO DATA` to standard output.

The whole program must be contained in one Python file and may use only the Python standard library.

Example run:
```
$ python credman.py register alice
Enter password: 
REGISTERED
$ python credman.py login alice
Enter password: 
LOGIN OK
Contents of alice.data
```
