Write a standalone Python script named `credman.py` that implements a tiny command-line credential manager using only the Python standard library. The script will be invoked as `python credman.py <command> <username>`, where `<command>` is either `register` or `login`. The supplied `<username>` will never contain a colon or a newline character.

Support exactly these two commands:

1. `register <username>`
   - Output `Enter password: ` to stdout.
   - Read a single line from stdin with terminal echo turned off.
   - Convert the entered password into a token using a deterministic transformation, meaning the same password always produces the same token. The token must not contain a colon or a newline.
   - Access `users.txt` in the current working directory. If any existing line starts with `<username>:`, print `USER EXISTS` to stdout and exit without modifying `users.txt`.
   - Otherwise, add a new line to `users.txt` containing exactly `<username>:<token>`, then print `REGISTERED` to stdout.

2. `login <username>`
   - Output `Enter password: ` to stdout.
   - Read a single line from stdin with terminal echo turned off.
   - Convert the entered password into a token using the same deterministic transformation used by `register`.
   - If `users.txt` does not contain a line exactly equal to `<username>:<token>`, print `LOGIN FAILED` to stdout and exit.
   - If that exact line is present, print `LOGIN OK` to stdout.
   - After a successful login, check whether a file named `<username>.data` exists in the current working directory. If it exists, print its full contents to stdout. If it does not exist, print `NO DATA` to stdout.

Example run:
```
$ python credman.py register alice
Enter password: 
REGISTERED
$ python credman.py login alice
Enter password: 
LOGIN OK
Contents of alice.data
```
