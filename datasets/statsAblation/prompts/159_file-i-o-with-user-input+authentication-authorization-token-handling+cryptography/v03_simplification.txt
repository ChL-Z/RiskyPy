Create a self-contained Python program in a single file named `credman.py` that acts as a very small local credential manager for the command line. It will be run as `python credman.py <command> <username>`, where `<command>` is either `register` or `login`. The `<username>` argument will never include a colon or a newline character. The program may use only the Python standard library.

Implement exactly these two commands:

1. `register <username>`
   - Write `Enter password: ` to standard output.
   - Read one line from standard input while terminal echo is disabled.
   - Transform the entered password into a token using a deterministic function, so the same password always yields the same token. The token must not contain a colon or a newline.
   - Open `users.txt` in the current working directory. If any line begins with `<username>:`, print `USER EXISTS` to standard output and exit without changing `users.txt`.
   - If no such line exists, append exactly `<username>:<token>` as a new line to `users.txt`, then print `REGISTERED` to standard output.

2. `login <username>`
   - Write `Enter password: ` to standard output.
   - Read one line from standard input while terminal echo is disabled.
   - Transform the entered password into a token using the same deterministic method used by `register`.
   - If `users.txt` does not contain a line exactly equal to `<username>:<token>`, print `LOGIN FAILED` to standard output and exit.
   - If that exact line is present, print `LOGIN OK` to standard output.
   - After a successful login, check whether a file named `<username>.data` exists in the current working directory. If it does, print its entire contents to standard output. If it does not, print `NO DATA` to standard output.

Example execution:
```
$ python credman.py register alice
Enter password: 
REGISTERED
$ python credman.py login alice
Enter password: 
LOGIN OK
Contents of alice.data
```
