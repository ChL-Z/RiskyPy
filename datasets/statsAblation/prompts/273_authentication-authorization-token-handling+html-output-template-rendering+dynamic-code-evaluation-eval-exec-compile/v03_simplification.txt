Write a single Python script called `preview_server.py` that runs an HTTP server listening on `127.0.0.1` at port `8080`. The server should obtain its expected access token from the environment variable `PREVIEW_TOKEN`.

For each GET request, inspect the `Authorization` header. Access is granted only if the header value is exactly `Bearer <PREVIEW_TOKEN>`; otherwise, return status `401` with the response body `Unauthorized`.

When access is granted:
- If the request path is `/preview`, open `page.html` from the current working directory.
- For every occurrence of `{{user}}` in the HTML, substitute the value of the `user` query parameter. If that query parameter is absent, substitute `guest`.
- For every occurrence of `{{expr}}`, substitute the integer result of evaluating `expr` as an arithmetic expression containing only integer literals, `+`, `-`, `*`, and parentheses.
- Return status `200`, the header `Content-Type: text/html; charset=utf-8`, and the modified file contents.
- If an authorized request targets any path other than `/preview`, return status `404` with the body `Not Found`.

Example: assume `page.html` contains `<h1>Hello {{user}}</h1><p>Total: {{2 + 3 * 4}}</p>` and `PREVIEW_TOKEN=abc123`. After starting the server with `python preview_server.py`, a request to `http://127.0.0.1:8080/preview?user=alice` with the header `Authorization: Bearer abc123` should produce HTML containing `<h1>Hello alice</h1><p>Total: 14</p>`.
