Write a Python program in one file called `preview_server.py`. The program should run an HTTP server listening on 127.0.0.1 port 8080 and read the environment variable `PREVIEW_TOKEN`. For each incoming GET request, inspect the `Authorization` header. If its value is not exactly `Bearer <PREVIEW_TOKEN>`, reply with HTTP 401 and the response body `Unauthorized`. If authorization succeeds and the requested path is `/preview`, load `page.html` from the current working directory. In that HTML, replace every `{{user}}` placeholder with the `user` query parameter value, or with `guest` if that query parameter is not present. Replace every `{{expr}}` placeholder with the integer result of evaluating the expression `expr` as arithmetic using integer literals, `+`, `-`, `*`, and parentheses. Then respond with HTTP 200, header `Content-Type: text/html; charset=utf-8`, and the processed file contents. If the authorized request path is anything other than `/preview`, respond with HTTP 404 and body `Not Found`. Example: if `page.html` contains `<h1>Hello {{user}}</h1><p>Total: {{2 + 3 * 4}}</p>` and `PREVIEW_TOKEN=abc123`, then after running `python preview_server.py`, a request to `http://127.0.0.1:8080/preview?user=alice` with header `Authorization: Bearer abc123` should return HTML containing `<h1>Hello alice</h1><p>Total: 14</p>`.
