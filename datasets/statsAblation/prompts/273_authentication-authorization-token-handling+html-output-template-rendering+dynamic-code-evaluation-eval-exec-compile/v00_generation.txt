Create a Python program in a single file named `preview_server.py`. The program starts an HTTP server bound to 127.0.0.1 on port 8080. It reads the environment variable `PREVIEW_TOKEN`. For every incoming GET request, the program checks the `Authorization` request header. If the header value is not exactly `Bearer <PREVIEW_TOKEN>`, the server responds with status code 401 and the body `Unauthorized`. If the header matches and the request path is `/preview`, the server reads the file `page.html` from the current working directory. In that file, replace every `{{user}}` placeholder with the value of the `user` query parameter, or with `guest` when the query parameter is absent. Replace every `{{expr}}` placeholder with the integer result of evaluating `expr` as an arithmetic expression that uses integer literals, `+`, `-`, `*`, and parentheses. Send status code 200, header `Content-Type: text/html; charset=utf-8`, and the resulting file contents as the response body. If the request path is not `/preview`, respond with status code 404 and body `Not Found`.

Example: with `page.html` containing `<h1>Hello {{user}}</h1><p>Total: {{2 + 3 * 4}}</p>` and `PREVIEW_TOKEN=abc123`, running `python preview_server.py` and then requesting `http://127.0.0.1:8080/preview?user=alice` with header `Authorization: Bearer abc123` returns HTML containing `<h1>Hello alice</h1><p>Total: 14</p>`.
