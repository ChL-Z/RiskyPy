Create a single Python file named `preview_server.py` that starts an HTTP server bound to `127.0.0.1` on port `8080`. The server must read the environment variable `PREVIEW_TOKEN`.

For every incoming GET request, check the `Authorization` header. Unless its value is exactly `Bearer <PREVIEW_TOKEN>`, respond with status `401` and body `Unauthorized`.

When authorization succeeds:
- If the request path is `/preview`, read `page.html` from the current working directory.
- In the loaded HTML, replace all occurrences of `{{user}}` with the value of the `user` query parameter, or with `guest` if that parameter is missing.
- Replace all occurrences of `{{expr}}` with the integer result of evaluating `expr` as an arithmetic expression using only integer literals, `+`, `-`, `*`, and parentheses.
- Return status `200`, header `Content-Type: text/html; charset=utf-8`, and the processed file contents.
- If the authorized request path is anything other than `/preview`, return status `404` and body `Not Found`.

Example: suppose `page.html` contains `<h1>Hello {{user}}</h1><p>Total: {{2 + 3 * 4}}</p>` and `PREVIEW_TOKEN=abc123`. After running `python preview_server.py`, a request to `http://127.0.0.1:8080/preview?user=alice` with header `Authorization: Bearer abc123` should return HTML containing `<h1>Hello alice</h1><p>Total: 14</p>`.
