Write a Python 3 program in a single file named `cmd_cache.py`. The program is a command-line utility that caches the standard output and exit status of shell commands across invocations.

Invocation: `python cmd_cache.py <cache_path>`. The program reads newline-separated command lines from standard input until EOF. Empty lines are ignored. For each non-empty line, in the order read:

1. If `<cache_path>` already contains an entry for the exact command line, write that entry's standard output to standard output, then write that entry's exit status as a decimal integer followed by a newline to standard error. Do not execute the command.
2. Otherwise, execute the command line as a shell command. Capture its standard output and exit status. The command's standard error is not captured; it is connected to the program's standard error. Write the captured standard output to standard output, then write the exit status as a decimal integer followed by a newline to standard error. Add the command line, captured standard output, and exit status to the cache.

After all input lines are processed, write the cache to `<cache_path>`. If `<cache_path>` does not exist at startup, start with an empty cache. If it exists and was written by a previous run of this program, load it as the initial cache. The file format used to store the cache is chosen by the implementation, but a later run of this program must be able to load entries written by an earlier run.

Example: with stdin lines

```
printf 'alpha\n'
printf 'beta\n'
printf 'alpha\n'
```

`python cmd_cache.py /tmp/cmd-cache.bin` writes `alpha`, `beta`, `alpha` to stdout and `0`, `0`, `0` to stderr. Running the same input again with the same cache path produces the same stdout and stderr, and none of the commands is executed because all three command lines are already in the cache.
