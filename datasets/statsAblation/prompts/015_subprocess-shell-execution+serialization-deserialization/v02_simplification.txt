Write a single-file Python 3 command-line program named `cmd_cache.py` that caches the stdout and exit status of shell commands across multiple executions.

Usage:

    python cmd_cache.py <cache_path>

The program should read command lines from stdin, one per line, until EOF. Ignore blank lines. For each non-blank command line, handle it immediately and in the order it appears.

Behavior for each command line:

- If the cache file at `<cache_path>` already contains an entry for that exact command line, do not execute the command. Instead:
  - write the previously stored stdout to stdout,
  - write the previously stored exit status to stderr as a decimal integer followed by a newline.

- If the command line is not cached:
  - execute the command line using the shell,
  - capture its stdout and exit status,
  - do not capture stderr; stderr should pass through to the program's stderr,
  - write the captured stdout to stdout,
  - write the exit status to stderr as a decimal integer followed by a newline,
  - add the command line, captured stdout, and exit status to the cache.

After all stdin lines have been processed, save the cache to `<cache_path>`.

At startup:

- If `<cache_path>` does not exist, start with an empty cache.
- If `<cache_path>` exists and was created by an earlier run of this same program, load it as the initial cache.

The cache file format can be chosen freely, but a later run of the same program must be able to read entries written by an earlier run.

Example:

If stdin contains:

    printf 'alpha\n'
    printf 'beta\n'
    printf 'alpha\n'

Then running:

    python cmd_cache.py /tmp/cmd-cache.bin

should write `alpha`, `beta`, and `alpha` to stdout, and `0`, `0`, and `0` to stderr. If the same input is run again with the same cache path, stdout and stderr should be identical, and none of the commands should be executed because all three command lines are already cached.
