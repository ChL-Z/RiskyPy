Create a single-file Python 3 command-line tool called `cmd_cache.py` that remembers the standard output and exit code of shell commands between separate runs.

Run it as `python cmd_cache.py <cache_path>`. The script should read command lines from standard input, one per line, until EOF. Blank lines should be skipped. For every non-blank line, process it in the order it appears:

1. If the cache at `<cache_path>` already has an entry for that exact command line, print the cached standard output to standard output, then print the cached exit status as a decimal integer followed by a newline to standard error. The command must not be run.
2. If there is no cached entry, run the command line through the shell. Capture its standard output and exit status. Do not capture standard error; let it go to the program's standard error. Print the captured standard output to standard output, then print the exit status as a decimal integer followed by a newline to standard error. Save the command line, captured standard output, and exit status in the cache.

After all input lines have been handled, write the cache to `<cache_path>`. If `<cache_path>` does not exist when the program starts, begin with an empty cache. If it exists and was produced by an earlier run of this program, load it as the initial cache. The cache file format is up to you, but a future run of the same program must be able to load entries written by a previous run.

For example, given these standard input lines:

```
printf 'alpha\n'
printf 'beta\n'
printf 'alpha\n'
```

running `python cmd_cache.py /tmp/cmd-cache.bin` should write `alpha`, `beta`, `alpha` to standard output and `0`, `0`, `0` to standard error. If the same input is run again with the same cache path, the standard output and standard error should be the same, and none of the commands should be executed because all three command lines are already cached.
