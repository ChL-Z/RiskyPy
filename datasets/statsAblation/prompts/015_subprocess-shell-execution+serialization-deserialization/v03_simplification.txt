Create a single-file Python 3 command-line program called `cmd_cache.py` that remembers the stdout and exit status of shell commands between separate runs.

Invocation:

    python cmd_cache.py <cache_path>

The program reads command lines from standard input, one line at a time, until EOF. Empty lines are ignored. Each non-empty command line must be processed immediately and in the order it appears.

For every non-empty command line, do the following:

- If the cache file at `<cache_path>` already has an entry for the exact command line, do not run the command. Instead:
  - send the saved stdout to stdout,
  - send the saved exit status to stderr as a base-10 integer followed by a newline.

- If the command line is not in the cache:
  - run the command line through the shell,
  - capture its stdout and exit status,
  - leave stderr uncaptured so it passes through to the program's stderr,
  - send the captured stdout to stdout,
  - send the exit status to stderr as a base-10 integer followed by a newline,
  - store the command line, captured stdout, and exit status in the cache.

Once all stdin lines have been handled, write the cache to `<cache_path>`.

At startup:

- If `<cache_path>` does not exist, begin with an empty cache.
- If `<cache_path>` exists and was produced by a previous run of this same program, load it as the initial cache.

You may choose any cache file format, but a later run of the same program must be able to read entries written by an earlier run.

Example:

If stdin contains:

    printf 'alpha\n'
    printf 'beta\n'
    printf 'alpha\n'

Then running:

    python cmd_cache.py /tmp/cmd-cache.bin

should write `alpha`, `beta`, and `alpha` to stdout, and `0`, `0`, and `0` to stderr. Running the same input again with the same cache path should produce identical stdout and stderr, and none of the commands should be executed because all three command lines are already cached.
