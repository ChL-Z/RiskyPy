Create a standalone Python script called `batchrun.py` that acts as a batch command runner.

The script takes a file path as its first command-line argument. That file contains command lines separated by newlines. For every non-empty line, the script launches the line as a command in a separate child process. Each child inherits the parent's environment, with one extra environment variable added: `API_TOKEN`, whose value is an access token.

Command-line options:
- `--credentials PATH`: points to a JSON file that has string fields `client_id` and `client_secret`.
- `--token-url URL`: the HTTPS URL of a token endpoint.

Before executing any command lines, the script must fetch an access token. It does this by making an HTTP POST to the `--token-url` endpoint, using `Content-Type: application/x-www-form-urlencoded`, with form fields `grant_type=client_credentials`, `client_id`, and `client_secret`. The response body is a JSON object with a string field named `access_token`; that value becomes `API_TOKEN`. If the token request's HTTP status is anything other than 200, the script writes `TOKEN_ERROR` to stderr and exits with status 2.

No more than 4 command processes may run concurrently. The stdout and stderr of each command process must be passed through to the script's own stdout and stderr. When a command process exits, if its exit status is 0, the script writes `OK: <command line>` to stdout; if its exit status is non-zero, it writes `FAILED: <command line>` to stderr. It then continues with the remaining command lines. Once all command lines have completed, the script exits with status 0 only if every command process exited with status 0; otherwise it exits with status 1.

Example usage:

```
$ cat creds.json
{"client_id": "abc", "client_secret": "shh"}
$ cat jobs.txt
echo hello
python -c "import os; print(os.environ['API_TOKEN'])"
$ python batchrun.py jobs.txt --credentials creds.json --token-url https://example.test/oauth/token
hello
OK: echo hello
<token>
OK: python -c "import os; print(os.environ['API_TOKEN'])"
```
