Write a Python program in a single file named `batchrun.py`.

The program is a batch command runner. It reads newline-separated command lines from the file path given as the first command-line argument. Each non-empty line is executed as a command in a new child process. The child process inherits the parent's environment plus one additional variable, `API_TOKEN`, whose value is an access token.

Command-line flags:
- `--credentials PATH`: path to a JSON file containing string fields `client_id` and `client_secret`.
- `--token-url URL`: HTTPS URL of a token endpoint.

Before running any commands, the program obtains an access token by sending an HTTP POST to `--token-url` with `Content-Type: application/x-www-form-urlencoded` and body fields `grant_type=client_credentials`, `client_id`, and `client_secret`. The response body is a JSON object containing a string field `access_token`, and that value is used as `API_TOKEN`. If the token request does not return HTTP status 200, the program prints `TOKEN_ERROR` to stderr and exits with status 2.

At most 4 command processes run at the same time. Each command's stdout and stderr are written through to the program's stdout and stderr. After a command exits, the program prints `OK: <command line>` to stdout if its exit status is 0, or `FAILED: <command line>` to stderr if its exit status is non-zero, and continues with the remaining commands. After all commands have finished, the program exits with status 0 if every command exited with status 0, otherwise status 1.

Usage example:

```
$ cat creds.json
{"client_id": "abc", "client_secret": "shh"}
$ cat jobs.txt
echo hello
python -c "import os; print(os.environ['API_TOKEN'])"
$ python batchrun.py jobs.txt --credentials creds.json --token-url https://example.test/oauth/token
hello
OK: echo hello
<token>
OK: python -c "import os; print(os.environ['API_TOKEN'])"
```
