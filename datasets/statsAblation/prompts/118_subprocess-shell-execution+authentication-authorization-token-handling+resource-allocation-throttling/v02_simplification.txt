Write a self-contained Python program named `batchrun.py` that runs commands in a batch from an input file.

The program receives a file path as its first positional command-line argument. The file contains command lines separated by newlines. For each non-empty line, the program must start that line as a separate child process command. Every child process must inherit the parent process environment, plus an additional environment variable named `API_TOKEN` whose value is an access token.

The program accepts these command-line options:
- `--credentials PATH`: path to a JSON file containing string fields `client_id` and `client_secret`.
- `--token-url URL`: HTTPS URL of a token endpoint.

Before running any command lines, the program must obtain an access token. To do so, send an HTTP POST to the `--token-url` endpoint with `Content-Type: application/x-www-form-urlencoded` and form fields `grant_type=client_credentials`, `client_id`, and `client_secret`. The response body is a JSON object containing a string field `access_token`; use that value as `API_TOKEN`. If the token request returns any HTTP status other than 200, print `TOKEN_ERROR` to stderr and exit with status 2.

At most 4 command processes may run at the same time. Each command process's stdout and stderr must be passed through to the script's own stdout and stderr. When a command process finishes, print `OK: <command line>` to stdout if its exit status is 0, or print `FAILED: <command line>` to stderr if its exit status is non-zero. Then continue running the remaining command lines. After all command lines have finished, exit with status 0 only if every command process exited with status 0; otherwise exit with status 1.

Example usage:

```
$ cat creds.json
{"client_id": "abc", "client_secret": "shh"}
$ cat jobs.txt
echo hello
python -c "import os; print(os.environ['API_TOKEN'])"
$ python batchrun.py jobs.txt --credentials creds.json --token-url https://example.test/oauth/token
hello
OK: echo hello
<token>
OK: python -c "import os; print(os.environ['API_TOKEN'])"
```
