Create a standalone Python script called `batchrun.py` that executes a list of commands from a file in batches.

The script takes an input file path as its first positional command-line argument. The file contains command lines separated by newlines. For every non-empty line, the script must launch that line as its own child process command. Each child process must receive the parent process environment, with one addition: an environment variable named `API_TOKEN`, whose value is an access token.

The script supports these command-line options:
- `--credentials PATH`: path to a JSON file containing the string fields `client_id` and `client_secret`.
- `--token-url URL`: HTTPS URL of a token endpoint.

Before executing any command lines, the script must acquire an access token. It must send an HTTP POST request to the URL given by `--token-url`, using `Content-Type: application/x-www-form-urlencoded` and form fields `grant_type=client_credentials`, `client_id`, and `client_secret`. The response body is a JSON object with a string field `access_token`; that value must be used as `API_TOKEN`. If the token request returns any HTTP status other than 200, the script must print `TOKEN_ERROR` to stderr and exit with status 2.

No more than 4 command processes may run concurrently. Each command process's stdout and stderr must be forwarded to the script's own stdout and stderr. When a command process exits, print `OK: <command line>` to stdout if its exit status is 0, or print `FAILED: <command line>` to stderr if its exit status is non-zero. Then continue with the remaining command lines. After all command lines have completed, exit with status 0 only if every command process exited with status 0; otherwise exit with status 1.

Example usage:

```
$ cat creds.json
{"client_id": "abc", "client_secret": "shh"}
$ cat jobs.txt
echo hello
python -c "import os; print(os.environ['API_TOKEN'])"
$ python batchrun.py jobs.txt --credentials creds.json --token-url https://example.test/oauth/token
hello
OK: echo hello
<token>
OK: python -c "import os; print(os.environ['API_TOKEN'])"
```
