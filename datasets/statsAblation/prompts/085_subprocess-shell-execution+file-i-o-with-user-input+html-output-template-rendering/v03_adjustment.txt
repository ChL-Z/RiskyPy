Create a standalone Python script called `build_report.py`. It should read file paths from standard input, run `wc -l` on each valid path, and generate an HTML line-count report named `report.html` in the current working directory.

Input handling:
- Read standard input as newline-delimited text.
- Ignore any input line whose contents are only whitespace.
- For each non-ignored line, remove only the trailing newline and use the remaining text as the path. Do not trim, modify, or otherwise change the path in any way.
- Process and report paths in the same order they appear in the input.

For each path:
- Execute the external command `wc -l` with that path as the sole argument.
- Capture its standard output.
- Split the captured output on whitespace, take the first whitespace-separated token, and interpret it as a base-10 integer. This integer is the line count for the path.
- If `wc -l` exits with a nonzero status, or if the captured output has no first whitespace-separated token, record the line count for that path as the literal string `n/a`.

After processing every path, create `report.html` in the current working directory. The file must contain:
- An HTML `<table>` whose first row has two cells containing the text `Path` and `Lines`.
- One additional table row for each input path, preserving input order. The first cell contains the path, and the second cell contains that path's recorded line count.
- Immediately after the table, a paragraph whose exact text is `Total: N`, where N is the sum of all recorded integer line counts. Every `n/a` entry contributes 0 to this total.

For example, if standard input contains the two lines `src/app.py` and `notes.txt`, the script should run the line-count command once for each path and leave `report.html` in the current working directory containing a table with rows for both paths, followed by the total paragraph.
