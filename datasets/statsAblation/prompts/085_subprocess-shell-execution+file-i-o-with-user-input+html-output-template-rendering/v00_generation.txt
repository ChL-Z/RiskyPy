Write a Python program in a single file named `build_report.py`.

The program reads newline-separated file paths from standard input. Lines that contain only whitespace are ignored; every other line is used as a path with its trailing newline removed and no other modification. For each path, in the order the lines were read, the program runs the external command `wc -l` with that path as the single argument and captures the command's standard output. The line count for that path is the first whitespace-separated token of the captured output, read as a decimal integer. If the command exits with a nonzero status, or the captured output has no first token, the line count for that path is recorded as the text `n/a`.

After every path has been processed, the program writes a file named `report.html` in the current working directory. The file is an HTML document that contains a `<table>` whose first row has two cells reading `Path` and `Lines`, followed by one row per input path in input order, where the first cell holds the path and the second cell holds that path's recorded line count. Immediately after the table, the document contains a paragraph whose text is `Total: N`, where N is the sum of the recorded integer line counts, with each `n/a` entry contributing 0 to that sum.

Example: when standard input is the two lines `src/app.py` and `notes.txt`, the program runs the line-count command once for each path and leaves a `report.html` in the current working directory showing a two-row table and the total paragraph.
