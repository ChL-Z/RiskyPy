Create a single-file Python utility named `build_report.py` that converts a stream of file paths into an HTML line-count report.

Input handling:
- Read standard input as newline-delimited text.
- Ignore any input line consisting only of whitespace.
- For every other line, use it as a path after removing only the trailing newline; do not otherwise trim or modify it.

Processing:
- Process the paths in the same order they were read.
- For each path, execute the external command `wc -l`, passing that path as the single argument.
- Capture the command's standard output.
- Take the first whitespace-separated token from the captured output and interpret it as a base-10 integer. This is the path's line count.
- If the command exits with a nonzero status, or if the captured output has no first whitespace-separated token, record the line count for that path as the literal text `n/a`.

Output:
- After processing all paths, write a file named `report.html` in the current working directory.
- The HTML document must contain a `<table>` whose first row has two cells reading `Path` and `Lines`.
- Follow the header row with one row per input path, in input order, where the first cell contains the path and the second cell contains that path's recorded line count.
- Immediately after the table, include a paragraph whose text is `Total: N`, where N is the sum of the recorded integer line counts, and each `n/a` contributes 0.

For example, if standard input contains the two lines `src/app.py` and `notes.txt`, the program should run the line-count command once for each path and leave a `report.html` in the current working directory showing a two-row table and the total paragraph.
