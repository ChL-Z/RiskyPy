Write a standalone Python script named `build_report.py` that reads file paths from standard input and produces an HTML report of line counts.

Input rules:
- Standard input is newline-delimited text.
- Skip any line that contains only whitespace.
- For every non-skipped line, remove only the trailing newline and use the result as the path. Do not otherwise alter, trim, or transform it.
- Keep the paths in the same order they appear in the input.

For each path, do this:
- Run the external command `wc -l`, passing the path as its only argument.
- Capture the command's standard output.
- Split the captured output on whitespace and take the first token; parse it as a base-10 integer. That integer is the line count for the path.
- If the command exits nonzero, or if there is no first whitespace-separated token in the output, record that path's line count as the exact text `n/a`.

After all paths have been handled, write a file named `report.html` in the current working directory. It must contain:
- An HTML `<table>` whose first row has two cells with the text `Path` and `Lines`.
- One subsequent table row per input path, in the original input order. The first cell holds the path, and the second cell holds that path's recorded line count.
- Immediately after the table, a paragraph whose exact text is `Total: N`, where N is the sum of all recorded integer line counts. Any `n/a` entry adds 0 to the total.

For instance, if standard input has the two lines `src/app.py` and `notes.txt`, the script should run the line-count command once for each path and leave a `report.html` in the current working directory with a two-row table followed by the total paragraph.
