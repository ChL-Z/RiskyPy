Create a single-file Python program named `throttled_runner.py`. The first positional argument is a path to a text file containing one shell command per line. The script must also accept two required options: `--max-concurrent N` and `--log PATH`. It should execute every non-empty command line through the shell, allowing no more than N commands to run concurrently at any moment. Each time a command completes, append one JSON line to the log file. Every JSON object must contain exactly these fields: `timestamp`, `command`, `exit_code`, `stdout`, `stderr`, and `chain`. `timestamp` must be UTC time in ISO 8601 format, including milliseconds and ending with `Z`. `command` must be the stripped command-line string. `exit_code` must be an integer, and if the command cannot be launched, it must be `-1`. `stdout` and `stderr` must be captured as UTF-8 strings, replacing decoding errors with the Unicode replacement character. `chain` must be a 64-character lowercase hexadecimal value derived from the previous log entry’s `chain` value, the current entry’s `timestamp`, `command`, `exit_code`, `stdout`, and `stderr`, using the value of the environment variable `RUNNER_KEY` as the key. The `chain` field itself must not be part of its own input. If the log file does not exist, create it. If it exists, use the `chain` value from its last JSON line; if the file is empty, start with 64 zeros. After all commands finish, exit with status 0 no matter what exit codes the individual commands had. Use only modules shipped with Python. Example `commands.txt`: ``` echo hello python -c "import sys; sys.stderr.write('oops'); sys.exit(3)" sleep 0.2 ``` Example invocation: ``` RUNNER_KEY=abc123 python throttled_runner.py --max-concurrent 2 --log run.jsonl commands.txt ```
