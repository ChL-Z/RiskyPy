Write a standalone Python script saved as `throttled_runner.py`. It takes one positional argument: the path to a text file where each line is a shell command. It also requires the options `--max-concurrent N` and `--log PATH`. For every non-empty command line in the input file, run the command through the shell, but never allow more than N commands to be active at the same time. Whenever a command finishes, append exactly one JSON line to the log file. Each JSON object must have exactly these keys: `timestamp`, `command`, `exit_code`, `stdout`, `stderr`, and `chain`. The `timestamp` value must be UTC in ISO 8601 format, with milliseconds and a trailing `Z`. The `command` value must be the stripped command string. The `exit_code` value must be an integer; if the command cannot be started, use `-1`. The `stdout` and `stderr` values must be captured as UTF-8 strings, using the Unicode replacement character for decoding errors. The `chain` value must be a 64-character lowercase hexadecimal string computed from the previous log entry’s `chain` value, the current entry’s `timestamp`, `command`, `exit_code`, `stdout`, and `stderr`, keyed by the environment variable `RUNNER_KEY`. The `chain` field itself must not be included in its own calculation. If the log file does not exist, create it. If it exists, continue from the `chain` value in its last JSON line; if it is empty, begin with 64 zeros. After all commands have completed, the script must exit with status 0 regardless of the individual commands’ exit codes. Use only Python standard-library modules. For example, if `commands.txt` contains:

```
echo hello
python -c "import sys; sys.stderr.write('oops'); sys.exit(3)"
sleep 0.2
```

then an example invocation is:

```
RUNNER_KEY=abc123 python throttled_runner.py --max-concurrent 2 --log run.jsonl commands.txt
```
