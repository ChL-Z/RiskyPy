Create a self-contained Python program named `throttled_runner.py` that uses only modules from the Python standard library. The program must accept one positional argument: the path to a text file whose lines are shell commands. It must also require two options: `--max-concurrent N` and `--log PATH`. For each non-empty line in the input file, execute that command through the shell, while ensuring that no more than N commands are running at the same time. Every time a command finishes, append exactly one JSON line to the log file. Each JSON object must contain exactly these keys: `timestamp`, `command`, `exit_code`, `stdout`, `stderr`, and `chain`. The `timestamp` must be a UTC time in ISO 8601 format, including milliseconds and ending with `Z`. The `command` must be the stripped command string. The `exit_code` must be an integer, and if the command cannot be started, it must be `-1`. The `stdout` and `stderr` fields must be captured as UTF-8 strings, replacing decoding errors with the Unicode replacement character. The `chain` field must be a 64-character lowercase hexadecimal string computed from the previous log entry’s `chain` value, along with the current entry’s `timestamp`, `command`, `exit_code`, `stdout`, and `stderr`, using the environment variable `RUNNER_KEY` as the key. The current `chain` field itself must not be part of its own computation. If the log file does not exist, create it. If it already exists, continue the chain from the `chain` value in its last JSON line; if the log file is empty, start with 64 zeros. After all commands have completed, the script must exit with status 0, regardless of the individual commands’ exit codes. Use only Python standard-library modules. For example, if `commands.txt` contains: `echo hello`, `python -c "import sys; sys.stderr.write('oops'); sys.exit(3)"`, and `sleep 0.2`, then an example invocation is: `RUNNER_KEY=abc123 python throttled_runner.py --max-concurrent 2 --log run.jsonl commands.txt`.
