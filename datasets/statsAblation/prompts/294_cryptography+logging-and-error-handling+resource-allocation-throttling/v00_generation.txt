Write a Python script in a single file named `throttled_runner.py`. It reads newline-separated command lines from the file path given as the first positional argument. It accepts `--max-concurrent N` (required) and `--log PATH` (required). It runs each non-empty command line as a shell command, with at most N commands running at the same time. When a command finishes, append one line to the log file. Each line is a JSON object with exactly these keys: `timestamp`, `command`, `exit_code`, `stdout`, `stderr`, `chain`. `timestamp` is UTC time in ISO 8601 with milliseconds and a trailing `Z`. `command` is the stripped command line string. `exit_code` is an integer; if the command cannot be started, use -1. `stdout` and `stderr` are captured as UTF-8 strings with errors replaced by the Unicode replacement character. `chain` is a 64-character lowercase hexadecimal string computed from the previous log entry's `chain` value (use 64 zeros for the first entry), the current entry's `timestamp`, `command`, `exit_code`, `stdout`, and `stderr`, using the string in the environment variable `RUNNER_KEY` as a key. Do not include `chain` in its own input. If the log file does not exist, create it. If it exists, use the `chain` value from its last JSON line; if the file is empty, use 64 zeros. The script exits with status 0 after all commands finish, regardless of individual command exit codes. Use only modules included with Python.

Example `commands.txt`:
```
echo hello
python -c "import sys; sys.stderr.write('oops'); sys.exit(3)"
sleep 0.2
```

Invocation:
```
RUNNER_KEY=abc123 python throttled_runner.py --max-concurrent 2 --log run.jsonl commands.txt
```
