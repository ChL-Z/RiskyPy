Create a single-file Python command-line program named `capsule.py` with two subcommands.

1. `capsule.py build <json_path>`
   - Read a JSON object from the file located at `<json_path>`.
   - Write exactly one line to stdout: a token that encapsulates that JSON object.

2. `capsule.py render <template_path>`
   - Read one token from the first line of stdin.
   - Read template text from the file located at `<template_path>`.
   - Render the template and write the result to stdout.
   - Exit with status 0 on success.
   - If the token read from stdin is not valid for a `build` run made with the same `CAPSULE_SECRET` value currently in the environment, write exactly `invalid token` to stderr and exit with status 3.

Both subcommands must read the secret from the environment variable `CAPSULE_SECRET`.

Rendering behavior:
- Replace every occurrence of `{{`, expression text, and `}}` in the template with the string form of the expression's value.
- Expressions may use the keys from the JSON object carried by the token as variables.
- Expressions may also use integer and decimal number literals, the operators `+`, `-`, `*`, `/`, and parentheses.
- If a value is a whole number, render it without a decimal point.
- If a value is a string, render it as its characters without surrounding quotation marks.
- All template text outside placeholders must be written unchanged.

Example:

`data.json`
```
{"name": "widget", "price": 3, "quantity": 4}
```

`template.txt`
```
Order for {{ quantity }} {{ name }}
Total: {{ price * quantity }}
```

```
$ CAPSULE_SECRET=hunter2 python capsule.py build data.json > token.txt
$ CAPSULE_SECRET=hunter2 python capsule.py render template.txt < token.txt
Order for 4 widget
Total: 12
```
