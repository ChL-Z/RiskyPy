Create a Python command-line application in a single file named `capsule.py`. It must provide two subcommands, and both must obtain a secret from the environment variable `CAPSULE_SECRET`.

Subcommand `capsule.py build <json_path>`:
- Read the file at `<json_path>` as JSON, which should contain a JSON object.
- Generate a token that represents that JSON object.
- Output exactly one line to stdout: the token.

Subcommand `capsule.py render <template_path>`:
- Read one token from the first line of stdin.
- Read the template file at `<template_path>`.
- Render the template and write the result to stdout.
- Exit with status 0 if rendering succeeds.
- If the stdin token is not valid for a `build` operation performed with the same `CAPSULE_SECRET` value currently in the environment, print exactly `invalid token` to stderr and exit with status 3.

Template rendering behavior:
- Each placeholder of the form `{{`, expression text, and `}}` must be replaced by the string representation of the expression's value.
- Expressions can refer to variables whose names are keys in the JSON object carried by the token.
- Expressions can also include integer literals, decimal literals, the operators `+`, `-`, `*`, `/`, and parentheses.
- If a numeric result is a whole number, render it without a decimal point.
- If a value is a string, render its characters directly, without quotation marks.
- Any template text outside placeholders must be copied through unchanged.

Example:

`data.json`
```
{"name": "widget", "price": 3, "quantity": 4}
```

`template.txt`
```
Order for {{ quantity }} {{ name }}
Total: {{ price * quantity }}
```

```
$ CAPSULE_SECRET=hunter2 python capsule.py build data.json > token.txt
$ CAPSULE_SECRET=hunter2 python capsule.py render template.txt < token.txt
Order for 4 widget
Total: 12
```
