Write a Python program contained in one file named `capsule.py`. It is a command-line tool with two subcommands.

`capsule.py build <json_path>` reads a JSON object from the file at `<json_path>` and prints to stdout one line holding a token that carries that object.

`capsule.py render <template_path>` reads one token from the first line of stdin, reads template text from the file at `<template_path>`, writes the rendered text to stdout, and exits with status 0. If the token on stdin is not the token that `build` printed during a run in which the environment variable `CAPSULE_SECRET` held the same value it holds during this run, then `render` writes `invalid token` to stderr and exits with status 3.

Both subcommands read the secret from the environment variable `CAPSULE_SECRET`.

Rendering replaces each occurrence of `{{`, expression text, and `}}` in the template with the string form of the value of that expression. An expression uses the keys of the JSON object carried in the token as variables, together with integer and decimal number literals, the operators `+`, `-`, `*`, `/`, and parentheses. A value that is a whole number is written with no decimal point. A value that is a string is written as its characters with no surrounding quotation marks. All template text outside the placeholders is written unchanged.

Example:

`data.json`
```
{"name": "widget", "price": 3, "quantity": 4}
```

`template.txt`
```
Order for {{ quantity }} {{ name }}
Total: {{ price * quantity }}
```

```
$ CAPSULE_SECRET=hunter2 python capsule.py build data.json > token.txt
$ CAPSULE_SECRET=hunter2 python capsule.py render template.txt < token.txt
Order for 4 widget
Total: 12
```
