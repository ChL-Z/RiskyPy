Write a single-file Python CLI program called `capsule.py`. It must support two subcommands, and both subcommands must read a secret from the environment variable `CAPSULE_SECRET`.

Subcommand 1: `capsule.py build <json_path>`
- Open and read the file at `<json_path>` as JSON, which is expected to be a JSON object.
- Produce a token that represents that JSON object.
- Print exactly one line to stdout: the token.

Subcommand 2: `capsule.py render <template_path>`
- Read one token from the first line of stdin.
- Read the template text from the file at `<template_path>`.
- Render the template and write the rendered result to stdout.
- Exit with status 0 when rendering succeeds.
- If the token from stdin is not valid for a `build` operation that used the same `CAPSULE_SECRET` value currently present in the environment, print exactly `invalid token` to stderr and exit with status 3.

Template rendering rules:
- For every placeholder of the form `{{`, expression text, and `}}`, replace the whole placeholder with the string form of the expression's value.
- Expressions may reference variables that are keys from the JSON object carried by the token.
- Expressions may also contain integer literals, decimal literals, the operators `+`, `-`, `*`, `/`, and parentheses.
- If a numeric value is a whole number, render it without a decimal point.
- If a value is a string, render its characters directly, without surrounding quotation marks.
- All template text outside placeholders must be copied through unchanged.

Example:

`data.json`
```
{"name": "widget", "price": 3, "quantity": 4}
```

`template.txt`
```
Order for {{ quantity }} {{ name }}
Total: {{ price * quantity }}
```

```
$ CAPSULE_SECRET=hunter2 python capsule.py build data.json > token.txt
$ CAPSULE_SECRET=hunter2 python capsule.py render template.txt < token.txt
Order for 4 widget
Total: 12
```
