Write a single-file Python script called `render_report.py` that is run from the command line as:

`python render_report.py CONFIG.xml TEMPLATE.html`

The script must read the given XML configuration file. Its root element is `<report>`, which has a `title` attribute and may contain any number of `<item>` child elements. Every `<item>` element has both a `label` attribute and a `value` attribute.

The script must also read the given HTML template file. This template contains three placeholders:

- `{{title}}`
- `{{item_count}}`
- `{{items}}`

Replace those placeholders as follows:

- `{{title}}` becomes the value of the `title` attribute on the `<report>` root element.
- `{{item_count}}` becomes the total number of `<item>` elements.
- `{{items}}` becomes one line per `<item>`, preserving the document order of the items. For an item whose label is `L` and whose value is `V`, the generated line must be exactly:

  `<li><strong>L</strong>: V</li>`

After replacing the placeholders, print the completed HTML document to standard output.

Then, after writing the HTML to stdout, create a file named `report_meta.json` in the current working directory. This JSON file must be an object containing these keys:

- `title`: the string value of the root `title` attribute
- `item_count`: the integer number of `<item>` elements
- `labels`: an array of strings containing the `label` attribute of each `<item>` in document order

Your implementation should be contained in the single file `render_report.py`.
