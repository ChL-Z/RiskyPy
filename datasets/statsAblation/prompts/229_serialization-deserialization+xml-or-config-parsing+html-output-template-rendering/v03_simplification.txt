Write a self-contained Python program saved as `render_report.py` that is meant to be executed from the shell as:

`python render_report.py CONFIG.xml TEMPLATE.html`

It should read the two files supplied on the command line:

1. An XML configuration file. Its root element must be `<report>`. The root has a `title` attribute and can have any number of `<item>` children, including none. Every `<item>` has a `label` attribute and a `value` attribute.

2. An HTML template file that includes the placeholders:
   - `{{title}}`
   - `{{item_count}}`
   - `{{items}}`

The program must substitute these placeholders as follows:

- `{{title}}` becomes the string value of the `title` attribute from the `<report>` root element.
- `{{item_count}}` becomes the total number of `<item>` elements.
- `{{items}}` becomes one generated line for each `<item>`, preserving the order in which the `<item>` elements appear in the XML document. For an item whose label is `L` and whose value is `V`, the exact generated line must be:

  `<li><strong>L</strong>: V</li>`

Once every placeholder has been replaced, output the finished HTML document to standard output.

After the HTML has been printed to stdout, create a file called `report_meta.json` in the current working directory. This JSON file must contain an object with these keys:

- `title`: the string value of the root `title` attribute
- `item_count`: the integer count of `<item>` elements
- `labels`: a list of strings containing the `label` attribute of each `<item>`, in document order

All implementation code must be contained in the single file `render_report.py`.
