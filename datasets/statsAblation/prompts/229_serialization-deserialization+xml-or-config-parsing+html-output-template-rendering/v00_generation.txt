Create a Python program in a single file named `render_report.py`. The program is invoked as `python render_report.py CONFIG.xml TEMPLATE.html`. The XML file has a root `<report>` with a `title` attribute and zero or more `<item>` children. Each `<item>` has `label` and `value` attributes. The template file is an HTML document that contains the placeholders `{{title}}`, `{{item_count}}`, and `{{items}}`. Replace `{{title}}` with the root `title` attribute, `{{item_count}}` with the number of `<item>` elements, and `{{items}}` with one line per item in document order. For an item with label L and value V, the line must be exactly `<li><strong>L</strong>: V</li>`. Write the resulting HTML document to stdout. After writing to stdout, write a file named `report_meta.json` in the current working directory. That file must contain a JSON object with keys `title` (string), `item_count` (integer), and `labels` (array of strings) where `labels` lists the `label` attribute of each `<item>` in document order.
