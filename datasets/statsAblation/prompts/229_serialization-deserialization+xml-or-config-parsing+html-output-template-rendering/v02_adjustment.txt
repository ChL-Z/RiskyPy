Create a standalone Python script named `render_report.py` that is intended to be run from the command line like this:

`python render_report.py CONFIG.xml TEMPLATE.html`

The script should process two input files:

1. An XML configuration file whose root element is `<report>`. This root has a `title` attribute and may contain zero or more `<item>` child elements. Each `<item>` has a `label` attribute and a `value` attribute.

2. An HTML template file containing these placeholders:
   - `{{title}}`
   - `{{item_count}}`
   - `{{items}}`

Your program must perform these replacements:

- Replace `{{title}}` with the value of the `title` attribute on the `<report>` root element.
- Replace `{{item_count}}` with the number of `<item>` elements.
- Replace `{{items}}` with one generated line per `<item>`, keeping the XML document order. For an item with label `L` and value `V`, the generated line must be exactly:

  `<li><strong>L</strong>: V</li>`

After all placeholders have been replaced, print the completed HTML document to standard output.

Then, after the HTML has been written to stdout, create a file named `report_meta.json` in the current working directory. This file must contain a JSON object with the following keys:

- `title`: the string value of the root `title` attribute
- `item_count`: the integer number of `<item>` elements
- `labels`: an array of strings containing the `label` attribute of every `<item>`, in document order

The entire implementation must be contained in the single file `render_report.py`.
