Create a single-file Python script called `render_dashboard.py`.

When run, it should take the first command-line argument as a token. This token is a URL-safe base64-encoded JSON object containing these keys:

- `username`: string
- `role`: string
- `expires_at`: integer Unix timestamp in seconds since 1970-01-01T00:00:00Z

The script must behave as follows:

1. Compare `expires_at` with the current Unix timestamp. If `expires_at` is less than or equal to the current time, write `EXPIRED` to stdout and terminate with exit code 2.
2. If `role` is not exactly `admin`, write `FORBIDDEN` to stdout and terminate with exit code 3.
3. Otherwise, write the HTML template below to stdout, replacing every `{{username}}` with the `username` value and every `{{role}}` with the `role` value. Then terminate with exit code 0.

Template:

```html
<!doctype html>
<html>
<head><title>Dashboard</title></head>
<body>
<h1>Dashboard</h1>
<p>User: <span id="username">{{username}}</span></p>
<p>Role: <span id="role">{{role}}</span></p>
</body>
</html>
```

Example: if the first argument encodes `{"username":"alice","role":"admin","expires_at":4070908800}` and the current Unix timestamp is `1700000000`, the script should output the template with `<span id="username">alice</span>` and `<span id="role">admin</span>`, and exit with status 0.
