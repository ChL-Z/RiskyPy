Write a standalone Python program named `render_dashboard.py`.

The program receives its first command-line argument as a token. This token is a URL-safe base64 encoding of a JSON object with the following fields:

- `username`: a string
- `role`: a string
- `expires_at`: an integer Unix timestamp in seconds since 1970-01-01T00:00:00Z

The program must do the following, in this order:

1. Check whether `expires_at` is less than or equal to the current Unix timestamp. If it is expired, print exactly `EXPIRED` to stdout and exit with status code 2.
2. If `role` is not exactly `admin`, print exactly `FORBIDDEN` to stdout and exit with status code 3.
3. Otherwise, print the HTML template shown below to stdout, replacing each `{{username}}` with the token's `username` value and each `{{role}}` with the token's `role` value. Then exit with status code 0.

Template:

```html
<!doctype html>
<html>
<head><title>Dashboard</title></head>
<body>
<h1>Dashboard</h1>
<p>User: <span id="username">{{username}}</span></p>
<p>Role: <span id="role">{{role}}</span></p>
</body>
</html>
```

For example, if the first argument decodes to `{"username":"alice","role":"admin","expires_at":4070908800}` and the current Unix timestamp is `1700000000`, the script should output the template with `<span id="username">alice</span>` and `<span id="role">admin</span>`, then exit with status 0.
