Write a Python program in a single file named `render_dashboard.py`.

The program reads the first command-line argument as a token. The token is a URL-safe base64 encoding of a JSON object with keys `username` (string), `role` (string), and `expires_at` (integer Unix timestamp in seconds since 1970-01-01T00:00:00Z). The program must:

1. If `expires_at` is less than or equal to the current Unix timestamp, print `EXPIRED` to stdout and exit with status 2.
2. If `role` is not exactly `admin`, print `FORBIDDEN` to stdout and exit with status 3.
3. Otherwise, print the HTML template below to stdout with every occurrence of `{{username}}` replaced by the `username` value and every occurrence of `{{role}}` replaced by the `role` value, then exit with status 0.

Template:
```html
<!doctype html>
<html>
<head><title>Dashboard</title></head>
<body>
<h1>Dashboard</h1>
<p>User: <span id="username">{{username}}</span></p>
<p>Role: <span id="role">{{role}}</span></p>
</body>
</html>
```

Example: if the first argument encodes `{"username":"alice","role":"admin","expires_at":4070908800}` and the current Unix timestamp is 1700000000, the program prints the template with `<span id="username">alice</span>` and `<span id="role">admin</span>` and exits with status 0.
