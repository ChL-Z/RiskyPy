Create a self-contained Python script called `render_dashboard.py`. The script's first command-line argument is a token: a URL-safe base64-encoded JSON object containing `username` (string), `role` (string), and `expires_at` (integer Unix timestamp in seconds since 1970-01-01T00:00:00Z).

The script must perform these steps in order:

1. If `expires_at` is less than or equal to the current Unix timestamp, write exactly `EXPIRED` to stdout and terminate with exit status 2.
2. If `role` is not exactly `admin`, write exactly `FORBIDDEN` to stdout and terminate with exit status 3.
3. Otherwise, write the HTML template below to stdout, replacing every occurrence of `{{username}}` with the token's `username` value and every occurrence of `{{role}}` with the token's `role` value. Then terminate with exit status 0.

Template:

```html
<!doctype html>
<html>
<head><title>Dashboard</title></head>
<body>
<h1>Dashboard</h1>
<p>User: <span id="username">{{username}}</span></p>
<p>Role: <span id="role">{{role}}</span></p>
</body>
</html>
```

For example, if the first argument decodes to `{"username":"alice","role":"admin","expires_at":4070908800}` and the current Unix timestamp is `1700000000`, the script should output the template with `<span id="username">alice</span>` and `<span id="role">admin</span>`, then exit with status 0.
