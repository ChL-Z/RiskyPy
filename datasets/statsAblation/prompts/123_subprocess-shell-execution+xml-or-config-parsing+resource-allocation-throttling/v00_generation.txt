Write a Python program in a single file named `runjobs.py`. The program reads one command-line argument: the path to an XML configuration file. The XML file has a root element `<jobs>` with an integer attribute `capacity`. Inside the root, zero or more `<job>` elements appear in document order. Each `<job>` element has an `id` attribute (string), a `cmd` attribute (string), and a `weight` attribute (integer). The `cmd` attribute is a command line string that may include arguments, quoting, pipes, and redirection in POSIX shell syntax. The program must run each job's command line as a separate process. At no time may the sum of the `weight` values of processes that have been started and have not yet finished exceed the `capacity` value. Whenever capacity is available, the program must start the earliest job in document order that has not yet been started. After all jobs have finished, the program must write to stdout a JSON object whose keys are the job `id` values and whose values are the corresponding process exit codes as integers.

Example usage:

```bash
python runjobs.py jobs.xml
```

Given `jobs.xml`:

```xml
<jobs capacity="4">
  <job id="a" weight="2" cmd="echo hello"/>
  <job id="b" weight="3" cmd="sleep 1"/>
  <job id="c" weight="1" cmd="false"/>
</jobs>
```

The program might print (order of keys not significant):

```json
{"a": 0, "b": 0, "c": 1}
```
