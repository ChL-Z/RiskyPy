Create a single Python file called `runjobs.py`. When executed, it must accept exactly one command-line argument: the path to an XML configuration file. This XML file uses a root `<jobs>` element that has an integer `capacity` attribute. Under the root, there can be zero or more `<job>` elements, and they must be considered in document order. Each `<job>` has three attributes: `id` (string), `cmd` (string), and `weight` (integer). The `cmd` value is a command line written in POSIX shell syntax, so it may contain arguments, quoting, pipes, and redirection. Your program must execute every job's command line as its own separate process. The combined `weight` of all processes that have been started but have not yet completed must never be greater than `capacity` at any moment. If there is enough available capacity, the program must start the earliest job in document order that has not yet been started. Once all jobs have completed, print a JSON object to stdout. In this JSON object, the keys are the job `id` values and each value is the integer exit code of that job's process.

Example usage:

```bash
python runjobs.py jobs.xml
```

Given `jobs.xml`:

```xml
<jobs capacity="4">
  <job id="a" weight="2" cmd="echo hello"/>
  <job id="b" weight="3" cmd="sleep 1"/>
  <job id="c" weight="1" cmd="false"/>
</jobs>
```

The program might print, with key order not guaranteed:

```json
{"a": 0, "b": 0, "c": 1}
```
