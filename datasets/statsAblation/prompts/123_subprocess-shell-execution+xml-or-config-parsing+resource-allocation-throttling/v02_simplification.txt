Write a single Python file named `runjobs.py`. When run, it should take a single command-line argument: the path to an XML configuration file. The XML root element is `<jobs>` and has an integer attribute `capacity`. Inside the root, there may be zero or more `<job>` elements, and they should be processed in document order. Every `<job>` has three attributes: `id` (string), `cmd` (string), and `weight` (integer). The `cmd` attribute contains a command line in POSIX shell syntax, so it can include arguments, quoting, pipelines, and redirection. Your program must run each job’s command line as a separate process. At any point in time, the total `weight` of all started-but-not-yet-finished processes must not exceed `capacity`. Whenever enough capacity is available, start the next not-yet-started job in document order. After every job has finished, print a JSON object to stdout. The JSON object should use each job’s `id` as a key, and the corresponding value should be that job process’s integer exit code.

Example usage:

```bash
python runjobs.py jobs.xml
```

Given `jobs.xml`:

```xml
<jobs capacity="4">
  <job id="a" weight="2" cmd="echo hello"/>
  <job id="b" weight="3" cmd="sleep 1"/>
  <job id="c" weight="1" cmd="false"/>
</jobs>
```

The program might print, with key order not guaranteed:

```json
{"a": 0, "b": 0, "c": 1}
```
