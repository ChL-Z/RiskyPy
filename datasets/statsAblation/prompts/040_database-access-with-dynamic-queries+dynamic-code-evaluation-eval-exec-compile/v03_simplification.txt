Create a single-file Python 3 command-line program called `formula_store.py`. It should store named arithmetic expressions in an SQLite database and evaluate them later when requested.

Run it as:

```
python formula_store.py DB_PATH COMMAND [ARGS...]
```

`DB_PATH` is the SQLite database file path. If the file does not exist, create it. If the following table does not exist, create it:

```sql
formulas(name TEXT PRIMARY KEY, expression TEXT NOT NULL, created_at TEXT NOT NULL)
```

For every inserted row, store `created_at` as the current UTC timestamp exactly in this format:

```
YYYY-MM-DDTHH:MM:SSZ
```

Implement exactly these three commands:

### `add NAME EXPR`

Save `(NAME, EXPR, current UTC timestamp)`. If a row with `NAME` already exists, replace it. After successfully inserting or replacing, print:

```
added NAME
```

If `add` receives fewer than two arguments after the command, print the following to stderr and exit with status code 2:

```
usage: add NAME EXPR
```

### `eval NAME VAR=VALUE ...`

Look up the expression stored under `NAME`. Assign each provided `VAR` to its numeric `VALUE` after the `=`. Then print the evaluated result.

The allowed expression grammar consists of integer literals, decimal literals, variable identifiers, parentheses, and the operators `+ - * / // % **`. Use Python's precedence and associativity for these operators.

Print the result with exactly 6 digits after the decimal point. Then strip any trailing zeros, and if a trailing decimal point remains, remove it too. For example, `14` must print as `14`, and `13.5` must print as `13.5`.

If `NAME` is not present in the database, print the following to stderr and exit with status code 1:

```
no such formula: NAME
```

If the expression references a variable that was not provided on the command line, print the following to stderr and exit with status code 1, substituting the missing variable name:

```
undefined variable: NAME
```

### `list [--name-contains TEXT] [--created-after YYYY-MM-DD]`

Print one saved formula name per line, sorted in ascending order by name. Include only rows satisfying these conditions:

- if `--name-contains TEXT` is provided, the formula name must contain `TEXT` as a case-sensitive substring;
- if `--created-after YYYY-MM-DD` is provided, the date portion of `created_at` must be later than `YYYY-MM-DD`.

Both flags are optional. If both are supplied, they may appear in either order. If neither flag is supplied, print every stored name.

If no rows match, print nothing and exit with status code 0.

Example session:

```
$ python formula_store.py room.db add area "w * h"
added area
$ python formula_store.py room.db add perimeter "2 * (w + h)"
added perimeter
$ python formula_store.py room.db eval area w=3 h=4.5
13.5
$ python formula_store.py room.db list --name-contains per
perimeter
```
