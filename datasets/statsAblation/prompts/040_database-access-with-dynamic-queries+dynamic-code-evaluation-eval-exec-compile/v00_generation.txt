Write a Python 3 program contained in a single file named `formula_store.py`. The program is a command-line tool that keeps named arithmetic expressions in a SQLite database file and evaluates them on request.

It is invoked as `python formula_store.py DB_PATH COMMAND [ARGS...]`, where DB_PATH is the path of the SQLite file. The program creates that file if it is missing and creates the table `formulas(name TEXT PRIMARY KEY, expression TEXT NOT NULL, created_at TEXT NOT NULL)` if it is missing. The `created_at` column holds the UTC time at which the row was written, formatted as `YYYY-MM-DDTHH:MM:SSZ`.

The program implements exactly these three commands:

`add NAME EXPR`
Writes the row (NAME, EXPR, current UTC time), replacing any existing row with the same NAME, then prints `added NAME`. If fewer than two arguments follow `add`, it prints `usage: add NAME EXPR` to stderr and exits with status 2.

`eval NAME VAR=VALUE ...`
Reads the expression stored under NAME and prints its value with each named variable bound to the number to the right of the `=` sign. The expression may contain integer and decimal literals, variable names, parentheses, and the operators `+ - * / // % **`, which follow Python's precedence and associativity. The printed value carries 6 digits after the decimal point, after which trailing zeros and a trailing decimal point are dropped: a value of 14 prints as `14`, and a value of 13.5 prints as `13.5`. If NAME is not in the database, it prints `no such formula: NAME` to stderr and exits with status 1. If the expression refers to a variable name that was not supplied on the command line, it prints `undefined variable: NAME` to stderr and exits with status 1.

`list [--name-contains TEXT] [--created-after YYYY-MM-DD]`
Prints, one per line, the name of every stored row whose name contains TEXT as a case-sensitive substring and whose `created_at` date portion is later than the given date, sorted ascending by name. Either flag may be omitted, both may be present in either order, and with no flags every stored name is printed. When nothing matches, it prints nothing and exits with status 0.

Example session:

```
$ python formula_store.py room.db add area "w * h"
added area
$ python formula_store.py room.db add perimeter "2 * (w + h)"
added perimeter
$ python formula_store.py room.db eval area w=3 h=4.5
13.5
$ python formula_store.py room.db list --name-contains per
perimeter
```
