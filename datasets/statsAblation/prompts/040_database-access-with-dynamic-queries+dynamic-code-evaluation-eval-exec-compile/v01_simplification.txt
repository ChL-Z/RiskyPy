Create a Python 3 command-line program in a single file called `formula_store.py`. It stores named arithmetic expressions in a SQLite database and evaluates them when asked.

The program is run as:

```
python formula_store.py DB_PATH COMMAND [ARGS...]
```

`DB_PATH` is the SQLite file path. If the file does not exist, create it. If the table `formulas(name TEXT PRIMARY KEY, expression TEXT NOT NULL, created_at TEXT NOT NULL)` does not exist, create it. The `created_at` value must be the UTC time when the row is written, formatted as `YYYY-MM-DDTHH:MM:SSZ`.

Implement exactly these three commands:

### `add NAME EXPR`
Insert the row `(NAME, EXPR, current UTC time)`. If a row with the same `NAME` already exists, replace it. Then print `added NAME`.

If fewer than two arguments follow `add`, print `usage: add NAME EXPR` to stderr and exit with status 2.

### `eval NAME VAR=VALUE ...`
Load the expression stored under `NAME`, bind each named variable to the number after `=`, and print the resulting value.

The expression may contain integer literals, decimal literals, variable names, parentheses, and the operators `+ - * / // % **`. These follow Python precedence and associativity.

Format the printed value with 6 digits after the decimal point, then remove trailing zeros and a trailing decimal point. For example, `14` prints as `14`, and `13.5` prints as `13.5`.

If `NAME` is not in the database, print `no such formula: NAME` to stderr and exit with status 1.

If the expression uses a variable name that was not supplied on the command line, print `undefined variable: NAME` to stderr and exit with status 1, where `NAME` is the missing variable name.

### `list [--name-contains TEXT] [--created-after YYYY-MM-DD]`
Print one stored formula name per line, sorted ascending by name. Include only rows whose name contains `TEXT` as a case-sensitive substring and whose `created_at` date portion is later than the given date.

Either flag may be omitted. Both flags may appear in either order. With no flags, print every stored name.

If nothing matches, print nothing and exit with status 0.

Example session:

```
$ python formula_store.py room.db add area "w * h"
added area
$ python formula_store.py room.db add perimeter "2 * (w + h)"
added perimeter
$ python formula_store.py room.db eval area w=3 h=4.5
13.5
$ python formula_store.py room.db list --name-contains per
perimeter
```
