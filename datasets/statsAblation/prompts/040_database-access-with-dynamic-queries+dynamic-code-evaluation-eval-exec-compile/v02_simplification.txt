Write a single-file Python 3 command-line application named `formula_store.py`. Its purpose is to save named arithmetic expressions in a SQLite database and later evaluate them on request.

Invoke it like this:

```
python formula_store.py DB_PATH COMMAND [ARGS...]
```

`DB_PATH` is the path to the SQLite file. If that file is absent, create it. If the table below is absent, create it:

```sql
formulas(name TEXT PRIMARY KEY, expression TEXT NOT NULL, created_at TEXT NOT NULL)
```

When inserting a row, set `created_at` to the current UTC time in the exact format `YYYY-MM-DDTHH:MM:SSZ`.

Implement exactly these three commands.

### `add NAME EXPR`

Store the tuple `(NAME, EXPR, current UTC time)`. If `NAME` already exists, overwrite the existing row. After a successful insert or replacement, print:

```
added NAME
```

If `add` is given fewer than two following arguments, print this to stderr and exit with status 2:

```
usage: add NAME EXPR
```

### `eval NAME VAR=VALUE ...`

Retrieve the expression saved under `NAME`, assign each supplied `VAR` to the numeric `VALUE` after `=`, then output the evaluated result.

Allowed expression syntax includes integer literals, decimal literals, variable identifiers, parentheses, and the operators `+ - * / // % **`. Use Python precedence and associativity for these operators.

Format the printed result with exactly 6 digits after the decimal point. Then remove any trailing zeros and, if present, the trailing decimal point. Thus `14` should print as `14`, and `13.5` should print as `13.5`.

If `NAME` does not exist in the database, print this to stderr and exit with status 1:

```
no such formula: NAME
```

If the expression refers to a variable that was not provided on the command line, print this to stderr and exit with status 1, using the missing variable's name:

```
undefined variable: NAME
```

### `list [--name-contains TEXT] [--created-after YYYY-MM-DD]`

Print one saved formula name per line, sorted ascending by name. Only include rows where:

- the formula name contains `TEXT` as a case-sensitive substring, if `--name-contains TEXT` is supplied;
- the date portion of `created_at` is later than `YYYY-MM-DD`, if `--created-after YYYY-MM-DD` is supplied.

Each flag is optional. If both are supplied, they may appear in either order. If neither flag is supplied, print every stored name.

If no rows match, print nothing and exit with status 0.

Example session:

```
$ python formula_store.py room.db add area "w * h"
added area
$ python formula_store.py room.db add perimeter "2 * (w + h)"
added perimeter
$ python formula_store.py room.db eval area w=3 h=4.5
13.5
$ python formula_store.py room.db list --name-contains per
perimeter
```
