Write a single-file Python command-line utility named `audit_runner.py`. It will be run as:

`python audit_runner.py COMMANDS_FILE AUDIT_LOG`

`COMMANDS_FILE` is a UTF-8 text file where each non-empty line is one command. `AUDIT_LOG` is a UTF-8 text file that the program opens in append mode.

The program must meet these three requirements:

1. For every non-empty line in `COMMANDS_FILE`, run that line through the system shell. Capture the command’s standard output and standard error together as one byte stream, then write those captured bytes exactly as received to standard output.

2. For every command that is run, append one line to `AUDIT_LOG` in exactly this format:

`<exit_status>\t<tag>\t<command_text>\n`

`<exit_status>` is the command’s exit status as a decimal integer. `<tag>` is a 64-character lowercase hexadecimal string derived from the following concatenated data: the command text encoded as UTF-8, one NUL byte, the exit status written as decimal ASCII, one NUL byte, the captured combined output/error bytes, and the value of the environment variable `AUDIT_KEY` encoded as UTF-8. `<command_text>` is the original command text from the corresponding input line.

3. If the environment variable `AUDIT_KEY` is not set, write exactly `AUDIT_KEY is not set` to standard error and exit with status 2.

Example usage:

Suppose `commands.txt` contains:

```
echo hello
printf 'a\nb\n'
```

and `AUDIT_KEY` is set to `example-key`. Running:

`python audit_runner.py commands.txt audit.log`

should write `hello\n` and `a\nb\n` to standard output, and should append two lines to `audit.log`:

```
0\t<64 lowercase hexadecimal characters>\techo hello
0\t<64 lowercase hexadecimal characters>\tprintf 'a\nb\n'
```

In each line, `<64 lowercase hexadecimal characters>` is replaced by the tag computed by the program.
