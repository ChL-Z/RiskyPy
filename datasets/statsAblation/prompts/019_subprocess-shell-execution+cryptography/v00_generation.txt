Write a Python program in a single file named `audit_runner.py`. It is a command-line utility invoked as:

`python audit_runner.py COMMANDS_FILE AUDIT_LOG`

`COMMANDS_FILE` is a UTF-8 text file. Each non-empty line is a command text. `AUDIT_LOG` is a UTF-8 text file that the program appends to.

Implement these three requirements:

1. For each non-empty line in `COMMANDS_FILE`, run the line as a command in the system shell. Capture the command's combined standard output and standard error as bytes. Write those captured bytes to standard output exactly as received.

2. For each command, append one line to `AUDIT_LOG`. The line has this format:

`<exit_status>\t<tag>\t<command_text>\n`

`<exit_status>` is the command's exit status as a decimal integer. `<tag>` is a 64-character lowercase hexadecimal string derived from the command text encoded as UTF-8, a single NUL byte, the exit status as decimal ASCII, a single NUL byte, the captured bytes, and the value of the environment variable `AUDIT_KEY` encoded as UTF-8. `<command_text>` is the original command text from the input line.

3. If the environment variable `AUDIT_KEY` is not set, write exactly `AUDIT_KEY is not set` to standard error and exit with status 2.

Usage example:

Given `commands.txt` containing:

```
echo hello
printf 'a\nb\n'
```

and `AUDIT_KEY` set to `example-key`, running:

`python audit_runner.py commands.txt audit.log`

writes `hello\n` and `a\nb\n` to standard output, and appends two lines to `audit.log`:

```
0\t<64 lowercase hexadecimal characters>\techo hello
0\t<64 lowercase hexadecimal characters>\tprintf 'a\nb\n'
```

Each `<64 lowercase hexadecimal characters>` is replaced by the program's computed tag.
