Create a single-file Python command-line program called `audit_runner.py`. It must be invoked like this:

`python audit_runner.py COMMANDS_FILE AUDIT_LOG`

`COMMANDS_FILE` is a UTF-8 text file containing commands, one per line. Ignore empty lines. `AUDIT_LOG` is a UTF-8 text file that should be opened in append mode by the program.

Your program must implement the following behavior:

1. For every non-empty line in `COMMANDS_FILE`, execute that line using the system shell. Combine the command’s standard output and standard error into a single byte stream. Then write those captured bytes unchanged to the program’s standard output.

2. For each executed command, append exactly one line to `AUDIT_LOG` using this format:

`<exit_status>\t<tag>\t<command_text>\n`

Where:

- `<exit_status>` is the command’s exit status written as a decimal integer.
- `<tag>` is a 64-character lowercase hexadecimal string derived from the concatenation of:
  - the command text encoded as UTF-8,
  - one NUL byte,
  - the exit status written as decimal ASCII,
  - one NUL byte,
  - the captured combined output/error bytes,
  - the value of the environment variable `AUDIT_KEY` encoded as UTF-8.
- `<command_text>` is the original command text from the corresponding input line.

3. If the environment variable `AUDIT_KEY` is not set, write exactly `AUDIT_KEY is not set` to standard error and exit with status 2.

Example:

If `commands.txt` contains:

```
echo hello
printf 'a\nb\n'
```

and `AUDIT_KEY` is set to `example-key`, then running:

`python audit_runner.py commands.txt audit.log`

should write `hello\n` and `a\nb\n` to standard output. It should also append two lines to `audit.log`:

```
0\t<64 lowercase hexadecimal characters>\techo hello
0\t<64 lowercase hexadecimal characters>\tprintf 'a\nb\n'
```

In each line, `<64 lowercase hexadecimal characters>` is replaced by the tag computed by the program.
