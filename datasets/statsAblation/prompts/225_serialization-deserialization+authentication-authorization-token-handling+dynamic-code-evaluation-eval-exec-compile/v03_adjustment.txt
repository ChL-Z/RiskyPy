Write a single Python file called `render.py`. It must accept exactly one command-line argument, which is the path to a JSON file. The JSON file contains an object with two fields: `items`, an array of integers, and `template`, a string.

The script must also read the environment variable `AUTH_TOKEN`, and it must read `tokens.txt` from the same directory as `render.py`. `tokens.txt` stores one token per line. For every line in `tokens.txt`, remove only the trailing newline from that line, then compare the remaining token text with `AUTH_TOKEN`. If no line produces a matching token, the script should print `UNAUTHORIZED` to stderr and exit with status code 1.

If a token matches, take the `template` string and replace each occurrence of `{{expr}}`. Here `expr` is an arithmetic expression built from integer literals, parentheses, the binary operators `+`, `-`, and `*`, and references of the form `items[i]`, where `i` is a non-negative integer literal. Whitespace is allowed around operators and parentheses. Evaluate these expressions using normal arithmetic precedence: `*` has higher precedence than `+` and `-`, and parentheses can override that precedence. Each `{{expr}}` must be replaced with the integer result of evaluating that expression. Print the final resulting string to stdout.

For example, suppose `tokens.txt` contains the single line `abc123`, `AUTH_TOKEN` is `abc123`, and `input.json` contains:
```json
{"items":[10,20,30],"template":"Total: {{items[0] + items[1] * 2}}"}
```
Then running `python render.py input.json` should output:
```
Total: 70
```
