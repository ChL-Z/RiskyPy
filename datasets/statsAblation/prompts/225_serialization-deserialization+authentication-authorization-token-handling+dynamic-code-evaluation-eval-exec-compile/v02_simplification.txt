Create a single-file Python script named `render.py` that takes exactly one command-line argument: the path to a JSON file. This JSON document must be an object containing `items`, an array of integers, and `template`, a string.

The script must also read the environment variable `AUTH_TOKEN` and the file `tokens.txt` in the same directory as `render.py`. `tokens.txt` contains one token per line. For each line, remove only the trailing newline, then compare the resulting token with `AUTH_TOKEN`. If none of the lines matches, print `UNAUTHORIZED` to stderr and exit with status code 1.

If a matching token is found, evaluate the `template` string by replacing every occurrence of `{{expr}}`. In this context, `expr` is an arithmetic expression consisting of integer literals, the binary operators `+`, `-`, and `*`, parentheses, and references written as `items[i]`, where `i` is a non-negative integer literal. Whitespace may appear around operators and parentheses. Expressions must be evaluated with standard precedence: `*` binds more tightly than `+` and `-`, while parentheses override that order. Each `{{expr}}` should be replaced by the integer result of evaluating its expression, and the resulting string should be printed to stdout.

For instance, if `tokens.txt` contains the line `abc123`, `AUTH_TOKEN` is `abc123`, and `input.json` contains:
```json
{"items":[10,20,30],"template":"Total: {{items[0] + items[1] * 2}}"}
```
then running `python render.py input.json` should output `Total: 70`.
