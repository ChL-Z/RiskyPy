Write a single-file Python program called `render.py`. It should accept exactly one command-line argument: a path to a JSON file. That JSON file must contain an object with two keys: `items` (an array of integers) and `template` (a string).

The program should also read the environment variable `AUTH_TOKEN` and the file `tokens.txt` located in the same directory as `render.py`. Each line in `tokens.txt` holds one token. Compare `AUTH_TOKEN` against every line after stripping only the trailing newline. If no line matches, write `UNAUTHORIZED` to stderr and terminate with exit code 1.

If the token does match, process the `template` string by replacing every `{{expr}}` occurrence. Here `expr` is an arithmetic expression that can include integer literals, the binary operators `+`, `-`, and `*`, parentheses, and references written as `items[i]`, where `i` is a non-negative integer literal. Whitespace may appear around operators and parentheses. Evaluate each expression using normal precedence: `*` before `+` and `-`, with parentheses overriding. Replace each `{{expr}}` with the integer result of its expression, then print the final string to stdout.

For example, suppose `tokens.txt` contains the line `abc123`, `AUTH_TOKEN` is set to `abc123`, and `input.json` contains:
```json
{"items":[10,20,30],"template":"Total: {{items[0] + items[1] * 2}}"}
```
Then running `python render.py input.json` should print `Total: 70`.
