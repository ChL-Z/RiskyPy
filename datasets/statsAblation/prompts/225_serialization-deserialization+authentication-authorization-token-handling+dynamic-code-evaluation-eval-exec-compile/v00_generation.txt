Create a Python script named `render.py`. The script must be a single file. It takes exactly one command-line argument: the path to a JSON file. The JSON file contains an object with two keys: `items`, which is an array of integers, and `template`, which is a string.

The script reads the environment variable `AUTH_TOKEN`. It also reads a file named `tokens.txt` located in the same directory as `render.py`. Each line of `tokens.txt` contains one token. The script compares the value of `AUTH_TOKEN` to each line in `tokens.txt` after removing the line's trailing newline. If no line matches, the script prints `UNAUTHORIZED` to stderr and exits with status code 1.

When the token matches, the script replaces every occurrence of a substring of the form `{{expr}}` in the `template` string. The `expr` is an arithmetic expression that may contain integer literals, the binary operators `+`, `-`, and `*`, parentheses, and references of the form `items[i]` where `i` is a non-negative integer literal. Whitespace around operators and parentheses is allowed. The expression is evaluated following the precedence rules where `*` binds tighter than `+` and `-`, and parentheses override precedence. The replacement for each `{{expr}}` is the integer value of `expr`. The script prints the resulting string to stdout.

Example: `tokens.txt` contains the line `abc123`, the environment variable `AUTH_TOKEN` is set to `abc123`, and `input.json` contains:
```json
{"items":[10,20,30],"template":"Total: {{items[0] + items[1] * 2}}"}
```
Running `python render.py input.json` prints `Total: 70`.
