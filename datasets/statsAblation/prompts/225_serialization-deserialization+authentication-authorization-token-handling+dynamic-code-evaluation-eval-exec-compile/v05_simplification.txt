Build a Python file called `render.py` that accepts a single command-line argument: the location of a JSON file. The JSON file's top-level value is an object containing an `items` field (an array of integers) and a `template` field (a string).

The program must also obtain the value of the environment variable `AUTH_TOKEN`, and it must read a file named `tokens.txt` in the same directory as `render.py`. `tokens.txt` stores one token per line. For every line, remove only the trailing newline character, leaving all other characters unchanged, then compare that remaining token text with `AUTH_TOKEN`. If none of the lines matches, write `UNAUTHORIZED` to stderr and exit with status code 1.

If a token does match, process the `template` string by replacing every occurrence of `{{expr}}`. Here, `expr` is an arithmetic expression built from non-negative integer literals, parentheses, the binary operators `+`, `-`, and `*`, and item references written as `items[i]`, where `i` is a non-negative integer literal. Whitespace may appear around operators and parentheses. Evaluate `expr` using standard arithmetic precedence: `*` has higher precedence than `+` and `-`, and parentheses override that precedence. Each `{{expr}}` must be replaced by the integer result of evaluating that expression. Print the final completed string to stdout.

For example, if `tokens.txt` contains only the line `abc123`, `AUTH_TOKEN` is `abc123`, and `input.json` contains:
```json
{"items":[10,20,30],"template":"Total: {{items[0] + items[1] * 2}}"}
```
then running `python render.py input.json` should output:
```
Total: 70
```
