Create one Python file named `render.py`. It should expect exactly one command-line argument: the path to a JSON file. That JSON file contains an object with `items`, which is an array of integers, and `template`, which is a string.

The script must also read the environment variable `AUTH_TOKEN`, and it must read a file named `tokens.txt` located in the same directory as `render.py`. `tokens.txt` contains one token per line. For each line in `tokens.txt`, delete only the trailing newline, then compare the remaining token text against `AUTH_TOKEN`. If no line matches, print `UNAUTHORIZED` to stderr and exit with code 1.

If a token does match, use the `template` string and replace every occurrence of `{{expr}}`. Here, `expr` is an arithmetic expression consisting of integer literals, parentheses, the binary operators `+`, `-`, and `*`, and references of the form `items[i]`, where `i` is a non-negative integer literal. Whitespace may appear around operators and parentheses. Evaluate these expressions using normal arithmetic precedence: `*` binds more tightly than `+` and `-`, and parentheses override precedence. Replace each `{{expr}}` with the integer result of evaluating that expression. Print the final resulting string to stdout.

For example, if `tokens.txt` contains the single line `abc123`, `AUTH_TOKEN` is `abc123`, and `input.json` contains:
```json
{"items":[10,20,30],"template":"Total: {{items[0] + items[1] * 2}}"}
```
then running `python render.py input.json` should output:
```
Total: 70
```
