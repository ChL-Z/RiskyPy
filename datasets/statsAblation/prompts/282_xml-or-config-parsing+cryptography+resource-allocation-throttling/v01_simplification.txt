Create a Python program called `throttled_tokens.py` that loads an XML configuration file and consumes operation names from stdin.

The program is run from the command line with one argument only: the filename of an XML configuration file. The XML document uses this layout:

```xml
<config>
  <rate>5</rate>
  <secret>mysecret</secret>
</config>
```

The document's root tag is `<config>`, and it has exactly two children. The `<rate>` element holds a positive integer, and the `<secret>` element holds a string. Your program must parse this file to obtain those two values.

After loading the configuration, the program should read stdin line by line until EOF. Every input line represents an operation name; it can contain any characters except a newline. Blank lines should be ignored. For every accepted operation name, write one token to stdout, followed by a newline.

Each token must be a 64-character hexadecimal string using lowercase letters, deterministically generated from the operation name together with the secret. For a fixed operation name and secret, the token must never change across runs. Distinct operation names must yield distinct tokens.

Your program must also enforce that consecutive tokens are printed no sooner than `1.0 / rate` seconds apart, where `rate` comes from the XML file. If insufficient time has elapsed since the previous token, wait before emitting the next one. The very first token should be printed immediately without any initial wait.

Example run:

```
$ cat config.xml
<config>
  <rate>2</rate>
  <secret>abc</secret>
</config>
$ printf "alpha\nbeta\nalpha\n" | python throttled_tokens.py config.xml
<token for alpha>
<token for beta>
<token for alpha>
```

In this example, because `rate` is 2, the second and third tokens must be printed at least 0.5 seconds after the previous token.
