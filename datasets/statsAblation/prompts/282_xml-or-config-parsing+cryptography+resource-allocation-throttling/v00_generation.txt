Write a Python script named `throttled_tokens.py` that reads an XML configuration file and processes operation names from standard input.

The script is invoked from the command line with exactly one argument: the path to an XML configuration file. The XML file has the following structure:

```xml
<config>
  <rate>5</rate>
  <secret>mysecret</secret>
</config>
```

The root element is `<config>`. It contains exactly two child elements: `<rate>` containing a positive integer, and `<secret>` containing a string. The script must read this file and extract the rate and secret.

The script then reads lines from standard input until EOF. Each line is an operation name (a string that may contain any characters except newline). Empty lines are skipped. For each operation name, the script prints one token to standard output followed by a newline.

The token must be a 64-character lowercase hexadecimal string that is derived from the operation name and the secret. The same operation name and secret must always produce the same token, regardless of when the script is run. Different operation names must produce different tokens.

The script must ensure that the time between printing consecutive tokens is at least 1.0 / rate seconds, where rate is the integer from the configuration file. If the script has not waited long enough since the previous token, it must delay before printing the next token. The first token is printed immediately (no initial delay).

Example usage:
```
$ cat config.xml
<config>
  <rate>2</rate>
  <secret>abc</secret>
</config>
$ printf "alpha\nbeta\nalpha\n" | python throttled_tokens.py config.xml
<token for alpha>
<token for beta>
<token for alpha>
```
The second and third tokens must be printed at least 0.5 seconds after the previous token.
