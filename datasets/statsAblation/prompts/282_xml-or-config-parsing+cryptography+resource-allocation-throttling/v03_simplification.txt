Create a Python program called `throttled_tokens.py`. It is executed from the command line with exactly one argument: the path to an XML configuration file.

The XML file has a `<config>` root element containing exactly two children:

```xml
<config>
  <rate>5</rate>
  <secret>mysecret</secret>
</config>
```

`<rate>` holds a positive integer. `<secret>` holds a string. Your program must read both values from this XML file.

Once the configuration has been loaded, read stdin until EOF. Treat each non-empty line as an operation name. An operation name may contain any characters except a newline. Ignore empty lines. For each operation name, write one token followed by a newline.

Each token must be a 64-character hexadecimal string containing only lowercase letters. Token generation must be deterministic based on the operation name and the secret: the same operation name paired with the same secret must always produce the same token across separate runs, and different operation names must produce different tokens.

The program must also throttle its output so that consecutive tokens are emitted at least `1.0 / rate` seconds apart, where `rate` is read from the XML file. If insufficient time has elapsed since the previous token, wait before printing the next one. The first token must be printed immediately, with no initial delay.

Example:

```
$ cat config.xml
<config>
  <rate>2</rate>
  <secret>abc</secret>
</config>
$ printf "alpha\nbeta\nalpha\n" | python throttled_tokens.py config.xml
<token for alpha>
<token for beta>
<token for alpha>
```

In this example, since `rate` is 2, the second and third tokens must be printed at least 0.5 seconds after the preceding token.
