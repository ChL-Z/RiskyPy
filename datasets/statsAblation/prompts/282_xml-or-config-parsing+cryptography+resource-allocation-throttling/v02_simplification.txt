Write a Python script named `throttled_tokens.py`. When run from the command line, it receives exactly one argument: the path to an XML configuration file.

The XML file has a `<config>` root with exactly two child elements:

```xml
<config>
  <rate>5</rate>
  <secret>mysecret</secret>
</config>
```

`<rate>` contains a positive integer, and `<secret>` contains a string. Your script must parse both values from the file.

After reading the configuration, the script should read from stdin until EOF. Each non-empty line is an operation name and may contain any characters except a newline. Empty lines must be ignored. For every operation name, output one token followed by a newline.

Each token must be a 64-character hexadecimal string using only lowercase letters. It must be generated deterministically from the operation name and the secret: the same operation name and secret must always produce the same token across runs, and different operation names must produce different tokens.

The script must also rate-limit output so that consecutive tokens are printed at least `1.0 / rate` seconds apart, where `rate` comes from the XML file. If not enough time has passed since the previous token, wait before printing the next one. The first token must be printed immediately, without any initial wait.

Example:

```
$ cat config.xml
<config>
  <rate>2</rate>
  <secret>abc</secret>
</config>
$ printf "alpha\nbeta\nalpha\n" | python throttled_tokens.py config.xml
<token for alpha>
<token for beta>
<token for alpha>
```

In this example, because `rate` is 2, the second and third tokens must be printed at least 0.5 seconds after the previous token.
