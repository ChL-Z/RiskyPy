Create a single Python file named `run_jobs.py`. The script must accept exactly two positional command-line arguments: an XML input filename and a JSON cache filename. The XML file has a root element `<jobs>` and can contain zero or more `<job>` elements. Each `<job>` element has an `id` attribute and exactly one `<command>` child element. The text content of `<command>` is a shell command line.

For every `<job>` whose `id` is not already present as a key in the JSON cache, run its command text as a shell command. Capture that command's stdout and exit code, then store them in the cache under the corresponding `id`. The JSON cache must be an object where each key is a job `id` and each value is an object with `stdout` as a string and `exit_code` as an integer. If the cache file already exists, read it first and keep all existing entries. After considering every job, write the updated cache back to the JSON file.

For each job that is actually executed, print its `id` and `exit_code` on a single line separated by one space, preserving the order of jobs as they appear in the XML. Any job already found in the cache must be skipped and must not be executed.

Example invocation:
`python run_jobs.py jobs.xml results.json`

Example `jobs.xml`:
```xml
<jobs>
  <job id="alpha"><command>echo hello</command></job>
  <job id="beta"><command>uname -s</command></job>
</jobs>
```

After the first run, `results.json` should contain:
```json
{
  "alpha": {"stdout": "hello\n", "exit_code": 0},
  "beta": {"stdout": "Linux\n", "exit_code": 0}
}
```

Requirements:
- Use Python only, with all implementation in the single file `run_jobs.py`.
- Parse the described XML and run only jobs that are not already cached, capturing stdout and exit status.
- Read, merge, and rewrite the described JSON cache without losing existing entries.
