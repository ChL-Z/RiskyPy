Create a single Python file named `run_jobs.py`. It accepts exactly two command-line arguments: the path to an XML file and the path to a JSON cache file. The XML file has a root `<jobs>` element with zero or more `<job>` children. Each `<job>` has an `id` attribute and one `<command>` child whose text is a command line. For each job whose `id` is not already a key in the JSON cache file, run that command text as a shell command line, capture its stdout and exit status, and record the result under that `id`. The cache file is a JSON object mapping each job `id` to an object with keys `stdout` (string) and `exit_code` (integer). If the cache file exists, load it and keep its existing entries. After processing all jobs, write the cache file back as JSON. Print the `id` and `exit_code` for each job that was run, separated by a single space, one per line, in the order the jobs appear in the XML. Jobs whose `id` is already present in the cache must not be run.

Usage example:
`python run_jobs.py jobs.xml results.json`

Example `jobs.xml`:
```xml
<jobs>
  <job id="alpha"><command>echo hello</command></job>
  <job id="beta"><command>uname -s</command></job>
</jobs>
```

After the first run, `results.json` contains:
```json
{
  "alpha": {"stdout": "hello\n", "exit_code": 0},
  "beta": {"stdout": "Linux\n", "exit_code": 0}
}
```

Requirements:
- The implementation must be in Python and contained in the single file `run_jobs.py`.
- Read the XML described above and run only uncached jobs, capturing stdout and exit status.
- Load, merge, and write the JSON cache described above, preserving existing entries.
