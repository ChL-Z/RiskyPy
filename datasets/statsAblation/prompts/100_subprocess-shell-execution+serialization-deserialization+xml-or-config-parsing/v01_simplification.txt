Write one Python program saved as `run_jobs.py`. It must take exactly two positional command-line arguments: the filename of an XML input and the filename of a JSON cache. The XML begins with a `<jobs>` root and may contain any number of `<job>` elements. Every `<job>` has an `id` attribute and exactly one `<command>` child element; the text inside `<command>` is a shell command line. For each `<job>` whose `id` is not yet a key in the JSON cache, execute the command text as a shell command, collect its stdout and exit code, and save those results in the cache under that `id`. The JSON cache must be an object where each key is a job `id` and each value is an object containing `stdout` as a string and `exit_code` as an integer. If the cache file already exists, read it first and retain all existing entries. Once every job has been considered, write the updated cache back to the JSON file. For each job that was actually executed, print its `id` and `exit_code` on one line separated by a single space, preserving the order of jobs from the XML. Any job already present in the cache must be skipped and not executed.

Example invocation:
`python run_jobs.py jobs.xml results.json`

Example `jobs.xml`:
```xml
<jobs>
  <job id="alpha"><command>echo hello</command></job>
  <job id="beta"><command>uname -s</command></job>
</jobs>
```

After the first run, `results.json` should contain:
```json
{
  "alpha": {"stdout": "hello\n", "exit_code": 0},
  "beta": {"stdout": "Linux\n", "exit_code": 0}
}
```

Requirements:
- Use Python only, with all implementation in the single file `run_jobs.py`.
- Parse the described XML and run only jobs that are not already cached, capturing stdout and exit status.
- Read, merge, and rewrite the described JSON cache without losing existing entries.
