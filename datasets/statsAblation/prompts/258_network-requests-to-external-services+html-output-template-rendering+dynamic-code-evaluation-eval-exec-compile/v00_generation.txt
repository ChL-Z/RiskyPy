Write a Python program in a single file named `rate_report.py`. It must do exactly this:

1. Read a three-letter base currency code from `sys.argv[1]`. Fetch the JSON document at `https://api.frankfurter.app/latest?from={base}`. The JSON contains a `rates` member, an object whose keys are three-letter currency codes and whose values are numbers.

2. Build an HTML document as a string. The document must start with `<!DOCTYPE html>` and contain a `<table>` with one row for each entry in `rates`. Use this exact row template for each entry:
   `<tr><td>{code}</td><td>{{rate}}</td><td>{{100 * rate}}</td><td>{{rate * rate}}</td></tr>`
   Replace `{code}` with the currency code. For each `{{expr}}` in the row template, replace it with `str(round(value, 4))`, where `value` is the arithmetic value of the expression `expr` with `rate` set to that entry's number.

3. Write the resulting HTML document to `report.html` in the current working directory, then print `Wrote report.html`.

Example: running `python rate_report.py USD` fetches the USD rates and writes `report.html`; for an entry `"EUR": 0.92`, the row starts `<tr><td>EUR</td><td>0.92</td><td>92.0</td><td>0.8464</td></tr>`.
