Write a Python script in a single file named `job_report.py`. The script generates an HTML report from a SQLite database of jobs.

Command-line usage:
`python job_report.py --db <database_path> --filter <sql_condition>`

The database contains a table named `jobs` with columns `id` (integer), `name` (text), `command` (text), and `status` (text). The `--filter` argument is a SQL condition string, such as `status = 'pending'` or `name LIKE 'build%'`. The script must select all rows from `jobs` where the condition evaluates to true.

For each selected row, execute the string in the `command` column in the system shell and capture its standard output and exit code.

Write an HTML file named `report.html` in the current working directory. The HTML must contain a `<table>` with a header row containing the column names `Name`, `Command`, `Exit Code`, and `Output`. Each selected job must produce one table row with the job's `name`, its `command` string, the integer exit code, and the captured standard output. If the command produces no standard output, the `Output` cell must be empty. The table must be preceded by an `<h1>` element with the text `Job Report`.

Example:
`python job_report.py --db jobs.db --filter "status = 'pending'"` reads `jobs.db`, selects pending jobs, runs their commands, and writes `report.html`.
