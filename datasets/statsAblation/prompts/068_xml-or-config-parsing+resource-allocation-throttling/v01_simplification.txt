Create a one-file Python script called `throttle_log.py`. The script must accept exactly one command-line argument: the path to an XML configuration file. The XML root is `<throttle>`, and it may contain zero or more `<limit>` child elements. Every `<limit>` has a `category` attribute (string), a `max_lines` attribute (positive integer), and a `window_seconds` attribute (positive integer). No category appears more than once. For example:

```xml
<throttle>
  <limit category="auth" max_lines="2" window_seconds="10"/>
  <limit category="search" max_lines="3" window_seconds="5"/>
</throttle>
```

The program reads standard input as UTF-8 text. Each non-empty input line is split once at the first tab character, producing a category and a message. Any line that has no tab is ignored. Processing must happen in input order. For each input line, the program writes the original line to standard output only if either the category has no corresponding `<limit>`, or the number of already-written standard-output lines for that category whose write time is later than `current_time - window_seconds` is smaller than `max_lines`. If neither condition holds, the line is discarded. Categories are handled separately. `current_time` means the current wall-clock time at the instant the line is read. When an allowed line is written, remove its trailing newline from the input line, then output the remaining original line text followed by one newline.

Once standard input ends, for every category that had at least one dropped line, write one line to standard error in the form `dropped <category> <count>`, sorted by category according to lexicographic Unicode code point order. If nothing was dropped, standard error must remain empty. Example usage:

```
python throttle_log.py limits.xml < input.tsv
```

where `input.tsv` might contain lines such as:

```
search	first query
auth	login a
search	second query
auth	login b
auth	login c
unknown	header
```
