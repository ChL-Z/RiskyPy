Write a single-file Python program named `throttle_log.py`. It takes one command-line argument: the path to an XML file. The XML file has a root element `<throttle>` containing zero or more `<limit>` elements. Each `<limit>` has attributes `category` (string), `max_lines` (positive integer), and `window_seconds` (positive integer). Each category appears at most once. Example XML:

```xml
<throttle>
  <limit category="auth" max_lines="2" window_seconds="10"/>
  <limit category="search" max_lines="3" window_seconds="5"/>
</throttle>
```

The program reads standard input as UTF-8 text. Each non-empty line is split once at the first tab character into a category and a message. Lines without a tab are ignored. For each line, in input order, the program writes the original line to standard output only if the category has no `<limit>` entry, or if the number of lines for that category already written to standard output with a write time greater than `current_time - window_seconds` is less than `max_lines`. Otherwise the line is dropped. Categories are independent. `current_time` is the current wall-clock time at the moment the line is read. When writing an allowed line, strip the trailing newline from the input line, then write the remaining original line text followed by one newline.

After standard input ends, for each category that had at least one dropped line, write one line to standard error in the form `dropped <category> <count>`, sorted by category in lexicographic Unicode code point order. If no lines were dropped, write nothing to standard error. Example invocation:

```
python throttle_log.py limits.xml < input.tsv
```

where `input.tsv` contains lines such as:

```
search	first query
auth	login a
search	second query
auth	login b
auth	login c
unknown	header
```
