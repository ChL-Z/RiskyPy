Create a single-file Python program named `throttle_log.py`. It must be invoked with exactly one command-line argument: the file path to an XML configuration file.

The configuration XML uses `<throttle>` as the root element. It can contain any number of `<limit>` child elements, including none. Each `<limit>` has:

- `category`: a string
- `max_lines`: a positive integer
- `window_seconds`: a positive integer

A `category` value never appears more than once. For example:

```xml
<throttle>
  <limit category="auth" max_lines="2" window_seconds="10"/>
  <limit category="search" max_lines="3" window_seconds="5"/>
</throttle>
```

The program reads UTF-8 text from standard input. For each non-empty input line, split the line exactly once at the first tab character to obtain a category and a message. Ignore any line that has no tab. Preserve the original input order.

For each input line, let `current_time` be the wall-clock time when that line is read. Output the line to standard output only when at least one of these conditions holds:

- The line’s category has no matching `<limit>` in the XML.
- Among previously written standard-output lines for the same category, fewer than `max_lines` have write times strictly later than `current_time - window_seconds`.

Otherwise, discard the line. Categories are handled independently.

When a line is allowed through, remove only its trailing newline from the original input line, then write the remaining original text followed by exactly one newline.

After standard input ends, for every category that had at least one discarded line, write one line to standard error in exactly this form:

```
dropped <category> <count>
```

These report lines must be sorted by category in lexicographic Unicode code point order. If no lines were dropped, standard error must remain empty.

Example usage:

```
python throttle_log.py limits.xml < input.tsv
```

where `input.tsv` might contain lines such as:

```
search	first query
auth	login a
search	second query
auth	login b
auth	login c
unknown	header
```
