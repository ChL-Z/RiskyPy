Write a single-file Python program named `throttle_log.py`. It must accept exactly one command-line argument: the path to an XML configuration file.

The XML file has `<throttle>` as its root element. It may contain zero or more `<limit>` child elements. Each `<limit>` has these attributes:

- `category`: a string
- `max_lines`: a positive integer
- `window_seconds`: a positive integer

No `category` value occurs more than once. Example XML:

```xml
<throttle>
  <limit category="auth" max_lines="2" window_seconds="10"/>
  <limit category="search" max_lines="3" window_seconds="5"/>
</throttle>
```

The program reads standard input as UTF-8 text. Each non-empty input line is split exactly once at the first tab character, yielding a category and a message. Any line without a tab is ignored. Input order must be preserved.

For each input line, let `current_time` be the current wall-clock time at the moment the line is read. The line is written to standard output only if one of these is true:

- The line’s category has no corresponding `<limit>`.
- The number of already-written standard-output lines for that same category whose write time is later than `current_time - window_seconds` is less than `max_lines`.

If neither condition holds, the line is discarded. Categories are processed independently.

Whenever an allowed line is written, remove its trailing newline from the input line, then write the remaining original line text followed by exactly one newline.

After standard input ends, for every category that had at least one dropped line, write one line to standard error in this form:

```
dropped <category> <count>
```

These report lines must be sorted by category using lexicographic Unicode code point order. If no lines were dropped, standard error must remain empty.

Example usage:

```
python throttle_log.py limits.xml < input.tsv
```

where `input.tsv` might contain lines such as:

```
search	first query
auth	login a
search	second query
auth	login b
auth	login c
unknown	header
```
