Write one Python program in a file named `report.py`. The program is run from the command line with exactly two positional arguments: first `input_path`, then `output_path`.

While it runs, it must keep appending entries to `report.log` in the current working directory. This log file must never be overwritten or truncated.

Required behavior:

1. First append the line `START <input_path>` to `report.log`.
2. Attempt to open `input_path` for reading. If this fails, append `ERROR <input_path>` to `report.log` and exit with code 1.
3. Process the input file one line at a time:
   - If the line has no colon (`:`), ignore it for the HTML output and append `SKIP <the original line text>` to `report.log`.
   - If the line contains a colon, split it only at the first colon. Remove leading and trailing whitespace from the part before the colon to get `name`. Remove leading and trailing whitespace from the part after the colon to get `value`. Append `LINE <name>` to `report.log`, and save the `(name, value)` pair for later use in the HTML table.
4. After all input lines have been processed, attempt to open `output_path` for writing. If this fails, append `ERROR <output_path>` to `report.log` and exit with code 1.
5. Write an HTML document to `output_path` that contains:
   - a `<title>` element with the text `Report`;
   - a `<table>` element whose header row contains `<th>Name</th>` and `<th>Value</th>`;
   - one table row for every saved `(name, value)` pair, with two `<td>` cells: the first containing `name` and the second containing `value`. The `name` and `value` strings must appear in the HTML exactly as they were after whitespace trimming.
6. After the HTML file has been written successfully, append `END <count>` to `report.log`, where `<count>` is the number of table rows written.

Example usage: `python report.py input.txt output.html`

If `input.txt` contains:
```
Alice: 42
Bob: 7
```
then `output.html` should contain a table with one row for `Alice` and `42` and another row for `Bob` and `7`. The file `report.log` should contain:
```
START input.txt
LINE Alice
LINE Bob
END 2
```
