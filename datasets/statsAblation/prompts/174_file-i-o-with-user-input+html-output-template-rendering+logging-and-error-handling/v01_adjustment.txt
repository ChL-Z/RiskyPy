Create a single Python source file named `report.py`. When executed, it must accept exactly two command-line arguments in this order: `input_path` and `output_path`. During execution, it appends log entries to `report.log` in the current working directory; it must not overwrite that file.

Execution requirements:

1. Append `START <input_path>` to `report.log`.
2. Try to open `input_path` for reading. If it cannot be opened, append `ERROR <input_path>` to `report.log` and exit with status 1.
3. Read the input line by line:
   - If a line does not contain a colon, skip it and append `SKIP <the original line text>` to `report.log`.
   - If a line contains a colon, split it at the first colon only. The text before that colon, with leading and trailing whitespace removed, is the `name`. The text after that colon, with leading and trailing whitespace removed, is the `value`. Append `LINE <name>` to `report.log` and remember the `(name, value)` pair for the HTML table.
4. After all input lines have been processed, try to write an HTML document to `output_path`. If `output_path` cannot be opened for writing, append `ERROR <output_path>` to `report.log` and exit with status 1.
5. The HTML document must contain:
   - a `<title>` element containing the text `Report`;
   - a `<table>` element with a header row containing `<th>Name</th>` and `<th>Value</th>`;
   - one table row for each remembered colon-containing input line, with two `<td>` cells: the first containing the `name` and the second containing the `value`.
   The name and value text must be placed into the HTML exactly as they were after whitespace removal.
6. After writing the HTML file, append `END <count>` to `report.log`, where `<count>` is the number of table rows written.

Example usage: `python report.py input.txt output.html`, where `input.txt` contains:
```
Alice: 42
Bob: 7
```
This produces `output.html` with a table containing a row for Alice and 42 and a row for Bob and 7, and `report.log` containing:
```
START input.txt
LINE Alice
LINE Bob
END 2
```
