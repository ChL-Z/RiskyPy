Write a Python program in a single file named `report.py`. The program takes exactly two command-line arguments: `input_path` and `output_path`. It appends lines to a file named `report.log` in the current working directory. It appends `START <input_path>` to `report.log`, then reads `input_path` line by line. Each line that contains a colon is split at the first colon into a name and a value. The name is the text before the colon with leading and trailing whitespace removed. The value is the text after the colon with leading and trailing whitespace removed. Lines that do not contain a colon are skipped. For each skipped line, append `SKIP <the original line text>` to `report.log`. For each line that contains a colon, append `LINE <name>` to `report.log`. After reading all lines, the program writes an HTML document to `output_path`. The HTML document has a `<title>` element containing the text `Report`, and a `<table>` element with a header row containing `<th>Name</th>` and `<th>Value</th>`. For each line that contained a colon, the table has one row with two `<td>` cells: the first cell contains the name text and the second cell contains the value text. The text is placed into the HTML exactly as read after the whitespace removal. After writing the HTML file, append `END <count>` to `report.log`, where `<count>` is the number of table rows written. If `input_path` cannot be opened for reading, append `ERROR <input_path>` to `report.log` and exit with status 1. If `output_path` cannot be opened for writing, append `ERROR <output_path>` to `report.log` and exit with status 1.

Usage example: `python report.py input.txt output.html` where `input.txt` contains:
```
Alice: 42
Bob: 7
```
produces `output.html` with a table containing a row for Alice and 42 and a row for Bob and 7, and `report.log` containing:
```
START input.txt
LINE Alice
LINE Bob
END 2
```
