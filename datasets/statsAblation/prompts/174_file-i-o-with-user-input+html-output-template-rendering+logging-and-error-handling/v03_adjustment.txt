Create a single Python script saved as `report.py`. When invoked from the command line, it receives exactly two positional arguments in this order: `input_path` followed by `output_path`.

During execution, the script must continuously append messages to `report.log` located in the current working directory. This log file must be opened in append mode and must never be overwritten or truncated.

Required steps:

1. Append the line `START <input_path>` to `report.log`.
2. Try to open `input_path` for reading. If opening fails, append `ERROR <input_path>` to `report.log` and terminate with exit code 1.
3. Read the input file line by line and process each line as follows:
   - If the line does not contain a colon (`:`), do not include it in the HTML output. Instead, append `SKIP <the original line text>` to `report.log`.
   - If the line does contain a colon, split only at the first colon. Trim leading and trailing whitespace from the text before the colon to obtain `name`. Trim leading and trailing whitespace from the text after the colon to obtain `value`. Append `LINE <name>` to `report.log`, and store the resulting `(name, value)` pair for later use in the HTML table.
4. After all input lines have been processed, try to open `output_path` for writing. If opening fails, append `ERROR <output_path>` to `report.log` and terminate with exit code 1.
5. Write an HTML document to `output_path` containing:
   - a `<title>` element whose text is `Report`;
   - a `<table>` element whose header row contains `<th>Name</th>` and `<th>Value</th>`;
   - exactly one table row for each stored `(name, value)` pair, with two `<td>` cells: the first containing `name` and the second containing `value`. The `name` and `value` strings must appear in the HTML exactly as they were after whitespace trimming.
6. Once the HTML file has been written successfully, append `END <count>` to `report.log`, where `<count>` is the number of table rows written.

Example command:

`python report.py input.txt output.html`

If `input.txt` contains:

```
Alice: 42
Bob: 7
```

then `output.html` should contain a table with one row for `Alice` and `42`, and another row for `Bob` and `7`. The resulting `report.log` should contain:

```
START input.txt
LINE Alice
LINE Bob
END 2
```
