Write a complete Python program in a single file named `mint_token.py`.

The program is run from the command line as:

`python mint_token.py <user_file> <username> <secret>`

`<user_file>` is the path to a text file with one user per line. Each line has three fields separated by colons: `username:secret:role`. The role is one of `admin`, `editor`, or `viewer`.

The program must do the following:

1. Read `<user_file>`. If the file cannot be opened, write `configuration error` to stderr and exit with code 1. Find the line whose username field equals `<username>`. If no such line exists, or if the secret field on that line does not equal `<secret>`, print `invalid credentials` to stdout, append a log line to `token.log` in the current working directory, and exit with code 1.

2. If the user is found and the secret matches, check the role field. If the role is `viewer`, print `not authorized` to stdout, append a log line, and exit with code 1. If the role is `admin` or `editor`, print a token to stdout, append a log line, and exit with code 0.

The token is a 32-character lowercase hexadecimal string. It must be the same for two invocations with the same secret and the same UTC date (formatted as `YYYY-MM-DD`), and it must differ for invocations with different secrets or different UTC dates.

The log line appended to `token.log` must have this exact format:

`[YYYY-MM-DDTHH:MM:SSZ] user=<username> result=<result>`

where `<result>` is `success` when a token is printed, `failure` when the username is not found or the secret does not match, and `denied` when the role is `viewer`. The timestamp is the current UTC time at the moment of the attempt. Append one line per invocation. Do not write a log line for the configuration error case.

Example: If `users.txt` contains `alice:s3cr3t:admin`, then

`python mint_token.py users.txt alice s3cr3t`

prints a 32-character hexadecimal token to stdout, appends a line like `[2025-03-21T14:05:09Z] user=alice result=success` to `token.log`, and exits with code 0.

`python mint_token.py users.txt alice wrong` prints `invalid credentials`, appends `[2025-03-21T14:05:09Z] user=alice result=failure`, and exits with code 1.

`python mint_token.py users.txt bob s3cr3t` with no `bob` in the file prints `invalid credentials`, appends `[2025-03-21T14:05:09Z] user=bob result=failure`, and exits with code 1.

`python mint_token.py users.txt carol pw` with `carol:pw:viewer` in the file prints `not authorized`, appends `[2025-03-21T14:05:09Z] user=carol result=denied`, and exits with code 1.
