Create a single Python file called `job_runner.py`. When run from the command line, it accepts two arguments: the path to an XML configuration file and the path to a SQLite database file. The script should parse the XML configuration, run the queries described there against the SQLite database, and write a JSON object to stdout.

The XML configuration has a root `<runner>` element with one attribute, `max_parallel`, which is a positive integer. Inside `<runner>` are one or more `<task>` child elements. Every `<task>` has these attributes: `name` (string), `sql` (string, possibly containing `{param}` placeholders), and `interval_ms` (non-negative integer). A `<task>` may also contain zero or more `<param>` child elements, each with `name` (string) and `value` (string) attributes. For each `{param}` placeholder in a task's `sql`, there is exactly one matching `<param>` child whose `name` equals the placeholder name.

Each task must be executed exactly three times. During one execution of a task, replace every `{param}` placeholder in the task's `sql` with the corresponding `<param>` value, execute the resulting SQL against the SQLite database, and collect all returned rows. Each row should be represented as a list of column values in the order returned by the query. Once every task has finished all three executions, output a JSON object. In this JSON object, each key is a task name, and its value is a list containing exactly three entries. Each of those three entries is the list of rows returned during one execution of that task.

Tasks must run concurrently, but at no point may more than `max_parallel` tasks be executing at the same time. A task is considered executing from the moment its SQL query starts until all rows from that query have been collected. For any single task, the time between the start of one execution and the start of the next execution of that same task must be at least `interval_ms` milliseconds.

For example, suppose `config.xml` contains:
```xml
<runner max_parallel="2">
  <task name="users" sql="SELECT id, name FROM users WHERE age > {min_age}" interval_ms="500">
    <param name="min_age" value="30"/>
  </task>
</runner>
```
and `data.db` is a SQLite database containing a `users` table. Running `python job_runner.py config.xml data.db` should print a JSON object such as `{"users": [[[1, "Alice"]], [[1, "Alice"]], [[1, "Alice"]]]}`.
