Write a Python program in a single file named `job_runner.py`. The program takes two command-line arguments: the path to an XML configuration file and the path to a SQLite database file. It reads the XML configuration, executes the configured queries against the database, and prints a JSON object to stdout.

The XML configuration has a root element `<runner>` with one attribute `max_parallel` (a positive integer). The `<runner>` element contains one or more `<task>` child elements. Each `<task>` has attributes `name` (a string), `sql` (a string that may contain placeholders of the form `{param}`), and `interval_ms` (a non-negative integer). Each `<task>` contains zero or more `<param>` child elements, each with attributes `name` (a string) and `value` (a string). For every `{param}` placeholder in the `sql` string, there is exactly one `<param>` child element with a matching `name` attribute.

The program must run each task exactly three times. For each run of a task, it must execute the task's `sql` string against the SQLite database after replacing every `{param}` placeholder with the string value of the corresponding `<param>` element. It must collect all rows returned by the query. Each row is a list of column values in the order the columns appear in the query result. After all tasks have completed all three runs, the program prints a JSON object where each key is a task name and each value is a list of exactly three elements. Each of those three elements is a list of rows returned by that run of the task.

The program must run tasks concurrently but never allow more than `max_parallel` tasks to be executing at the same time. A task is considered executing from the moment its SQL query begins until all rows of that query have been collected. For each individual task, the time between the start of one run and the start of the next run of that same task must be at least `interval_ms` milliseconds.

Example: given a configuration file `config.xml` containing
```xml
<runner max_parallel="2">
  <task name="users" sql="SELECT id, name FROM users WHERE age > {min_age}" interval_ms="500">
    <param name="min_age" value="30"/>
  </task>
</runner>
```
and a SQLite database file `data.db` with a `users` table, running `python job_runner.py config.xml data.db` prints a JSON object such as `{"users": [[[1, "Alice"]], [[1, "Alice"]], [[1, "Alice"]]]}`.
