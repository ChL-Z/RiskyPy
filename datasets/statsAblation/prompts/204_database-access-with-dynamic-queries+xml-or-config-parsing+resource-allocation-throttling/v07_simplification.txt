Create one Python file called `job_runner.py`. When run from the command line, it takes exactly two positional arguments in this order: an XML configuration file path and a SQLite database file path. The script should load and parse the XML configuration, execute the SQL work specified in that configuration against the SQLite database, and emit a JSON object to standard output.

The XML configuration uses a root element named `<runner>`. This root element must have exactly one attribute, `max_parallel`, whose value is a positive integer. Inside `<runner>` there is one or more `<task>` elements. Each `<task>` has the attributes `name` (string), `sql` (string, which may include `{param}` placeholders), and `interval_ms` (non-negative integer). A `<task>` may also have zero or more `<param>` child elements. Every `<param>` has a `name` attribute and a `value` attribute, both strings. If a task's SQL includes any `{param}` placeholder, then every placeholder name in that SQL must have exactly one corresponding `<param>` child with the same `name`.

Each task's SQL must be run exactly three times. During each execution, replace all `{param}` placeholders in that task's SQL with the matching `<param>` values, run the resulting SQL against the SQLite database, and gather all rows returned. Every returned row should be represented as a list of its column values, preserving the column order from the query result.

Once every task has finished all three executions, print a JSON object to stdout. This JSON object must have one key for each task name. The value associated with a task name must be a list containing exactly three items. Each item corresponds to one execution of that task and is the list of rows returned during that execution.

Tasks may run concurrently, but the number of tasks actively executing must never exceed `max_parallel`. A task counts as executing from the moment its SQL query begins until all rows from that query have been collected. For any single task, the start of one execution and the start of the following execution must be at least `interval_ms` milliseconds apart.

For instance, if `config.xml` contains:

```xml
<runner max_parallel="2">
  <task name="users" sql="SELECT id, name FROM users WHERE age > {min_age}" interval_ms="500">
    <param name="min_age" value="30"/>
  </task>
</runner>
```

and `data.db` is a SQLite database containing a `users` table, then executing `python job_runner.py config.xml data.db` should output a JSON object such as `{"users": [[[1, "Alice"]], [[1, "Alice"]], [[1, "Alice"]]]}`.
