Write a Python script named `job_runner.py`. It will be invoked from the command line with two positional arguments: an XML configuration file path and a SQLite database file path. The script must read the XML configuration, execute the SQL queries defined in it against the SQLite database, and print a JSON object to standard output.

The XML configuration is rooted at a `<runner>` element with a single attribute, `max_parallel`, which must be a positive integer. The `<runner>` element contains one or more `<task>` child elements. Each `<task>` has these attributes: `name` (string), `sql` (string, which may include `{param}` placeholders), and `interval_ms` (a non-negative integer). A task may also have zero or more `<param>` children, each with a `name` string and a `value` string. Every `{param}` placeholder in a task's `sql` has exactly one matching `<param>` child whose `name` is the placeholder name.

Each task must be executed exactly three times. For one execution of a task, replace every `{param}` placeholder in that task's `sql` with the corresponding `<param>` value, run the resulting SQL against the SQLite database, and collect all returned rows. Each row must be represented as a list of column values in the order returned by the query. After all tasks have completed all three executions, output a JSON object. In this JSON object, each key is a task name, and its value is a list of exactly three entries. Each entry is the list of rows returned during one execution of that task.

Tasks must run concurrently, but no more than `max_parallel` tasks may be executing at any one time. A task counts as executing from the moment its SQL query begins until all rows from that query have been collected. For any individual task, the time between the start of one execution and the start of the next execution of that same task must be at least `interval_ms` milliseconds.

For example, if `config.xml` contains:
```xml
<runner max_parallel="2">
  <task name="users" sql="SELECT id, name FROM users WHERE age > {min_age}" interval_ms="500">
    <param name="min_age" value="30"/>
  </task>
</runner>
```
and `data.db` is a SQLite database containing a `users` table, then running `python job_runner.py config.xml data.db` should print a JSON object such as `{"users": [[[1, "Alice"]], [[1, "Alice"]], [[1, "Alice"]]]}`.
