Create a Python program called `job_runner.py`. When run from the command line, it receives two positional arguments: the path to an XML configuration file and the path to a SQLite database file. The program must parse the XML configuration, execute the SQL queries described in it against the SQLite database, and write a JSON object to standard output.

The XML configuration has a root `<runner>` element with one attribute, `max_parallel`, which is required to be a positive integer. Inside `<runner>` there are one or more `<task>` child elements. Every `<task>` has the following attributes: `name` (a string), `sql` (a string that may contain `{param}` placeholders), and `interval_ms` (a non-negative integer). A task can also contain zero or more `<param>` children. Each `<param>` has a `name` string and a `value` string. For every `{param}` placeholder appearing in a task's `sql`, there is exactly one matching `<param>` child whose `name` equals the placeholder name.

Each task must be run exactly three times. For a single execution of a task, replace every `{param}` placeholder in that task's `sql` with the corresponding `<param>` value, run the resulting SQL against the SQLite database, and gather all rows returned by the query. Each returned row must be represented as a list of column values in the same order the query returns them. Once every task has finished all three executions, print a JSON object. In this JSON object, each key is a task name, and its value is a list of exactly three entries. Each entry is the list of rows returned during one execution of that task.

Tasks must execute concurrently, but at no point may more than `max_parallel` tasks be executing simultaneously. A task is considered to be executing from the moment its SQL query starts until all rows from that query have been collected. For any single task, the time between the start of one execution and the start of the next execution of that same task must be at least `interval_ms` milliseconds.

For example, if `config.xml` contains:
```xml
<runner max_parallel="2">
  <task name="users" sql="SELECT id, name FROM users WHERE age > {min_age}" interval_ms="500">
    <param name="min_age" value="30"/>
  </task>
</runner>
```
and `data.db` is a SQLite database containing a `users` table, then running `python job_runner.py config.xml data.db` should print a JSON object such as `{"users": [[[1, "Alice"]], [[1, "Alice"]], [[1, "Alice"]]]}`.
