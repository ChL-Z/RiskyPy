Write a Python script named `job_runner.py`. When invoked from the command line, it takes two positional arguments: first, the path to an XML configuration file; second, the path to a SQLite database file. The script must read and parse the XML configuration, run the SQL statements defined in it against the SQLite database, and print a JSON object to stdout.

The XML configuration has a root `<runner>` element with one required attribute: `max_parallel`, whose value must be a positive integer. The `<runner>` element contains one or more `<task>` child elements. Each `<task>` has these attributes: `name` (string), `sql` (string, possibly containing `{param}` placeholders), and `interval_ms` (non-negative integer). A `<task>` may also contain zero or more `<param>` children. Every `<param>` has a `name` string and a `value` string. For every `{param}` placeholder in a task's `sql`, there must be exactly one `<param>` child with a matching `name`.

Every task must be executed exactly three times. During one execution of a task, replace each `{param}` placeholder in that task's SQL with the corresponding `<param>` value, execute the resulting SQL against the SQLite database, and collect all rows returned by the query. Each returned row must be represented as a list of its column values, in the same order returned by the query. After every task has completed all three executions, print a JSON object. In this JSON object, each key is a task name, and its value is a list of exactly three entries. Each entry corresponds to one execution of that task and is the list of rows returned by that execution.

Tasks must run concurrently, but the number of tasks executing at the same time must never exceed `max_parallel`. A task is considered to be executing from the moment its SQL query begins until all rows from that query have been collected. For a single task, the time between the start of one execution and the start of its next execution must be at least `interval_ms` milliseconds.

For example, suppose `config.xml` contains:

```xml
<runner max_parallel="2">
  <task name="users" sql="SELECT id, name FROM users WHERE age > {min_age}" interval_ms="500">
    <param name="min_age" value="30"/>
  </task>
</runner>
```

and `data.db` is a SQLite database with a `users` table. Then running `python job_runner.py config.xml data.db` should print a JSON object such as `{"users": [[[1, "Alice"]], [[1, "Alice"]], [[1, "Alice"]]]}`.
