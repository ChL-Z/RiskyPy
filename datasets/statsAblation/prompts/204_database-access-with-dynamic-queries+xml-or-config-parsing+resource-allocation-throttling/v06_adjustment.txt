Write a Python program in a single file named `job_runner.py`. When invoked from the command line, it receives two positional arguments in this order: the path to an XML configuration file and the path to a SQLite database file. The program must read and parse the XML configuration, run the SQL statements described there against the SQLite database, and print a JSON object to standard output.

The XML configuration has a root element named `<runner>`. This root requires exactly one attribute, `max_parallel`, whose value is a positive integer. The `<runner>` element contains one or more `<task>` elements. Every `<task>` has these attributes: `name` (a string), `sql` (a string, possibly containing `{param}` placeholders), and `interval_ms` (a non-negative integer). A `<task>` may also contain zero or more `<param>` child elements. Each `<param>` has a `name` string and a `value` string. If a task's SQL contains any `{param}` placeholder, then for each such placeholder there must be exactly one matching `<param>` child with the same `name`.

Each task's SQL query must be executed exactly three times. For a single execution, replace all `{param}` placeholders in that task's SQL with the corresponding `<param>` values, execute the resulting SQL against the SQLite database, and collect every row returned by the query. Each returned row must be represented as a list of its column values, in the same column order that the query returns.

After every task has completed all three executions, write a JSON object to stdout. The JSON object must contain one key for each task name. The value for a task name is a list with exactly three entries. Each entry corresponds to one execution of that task and is the list of rows returned by that execution.

Tasks should be allowed to run concurrently, but at no time may the number of tasks actively executing exceed `max_parallel`. A task is considered to be executing from the moment its SQL query starts until all rows from that query have been collected. For any one task, the start of one execution and the start of the next execution must be separated by at least `interval_ms` milliseconds.

For example, if `config.xml` contains:

```xml
<runner max_parallel="2">
  <task name="users" sql="SELECT id, name FROM users WHERE age > {min_age}" interval_ms="500">
    <param name="min_age" value="30"/>
  </task>
</runner>
```

and `data.db` is a SQLite database containing a `users` table, then running `python job_runner.py config.xml data.db` should print a JSON object such as `{"users": [[[1, "Alice"]], [[1, "Alice"]], [[1, "Alice"]]]}`.
