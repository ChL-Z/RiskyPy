Create a single Python file called `job_runner.py`. It is run from the command line with two positional arguments: an XML configuration file path, followed by a SQLite database file path. The program must parse the XML configuration, execute the SQL statements it defines against the SQLite database, and write a JSON object to standard output.

The XML configuration starts with a root `<runner>` element. This root has one required attribute, `max_parallel`, whose value is a positive integer. Inside `<runner>` there are one or more `<task>` elements. Each `<task>` has the attributes `name` (string), `sql` (string, which may include `{param}` placeholders), and `interval_ms` (non-negative integer). A `<task>` may also have zero or more `<param>` child elements. Each `<param>` has a `name` string and a `value` string. For every `{param}` placeholder appearing in a task's SQL, there must be exactly one `<param>` child with the same `name`.

For each task, run its SQL query exactly three times. In one run, replace every `{param}` placeholder in that task's SQL with the corresponding `<param>` value, execute the resulting SQL against the SQLite database, and gather all rows returned by the query. Each row must be represented as a list of its column values, preserving the column order returned by the query.

Once every task has finished all three runs, output a JSON object to stdout. The JSON object should have one key per task name. The value for each task name is a list of exactly three entries. Each entry represents one execution of that task and is the list of rows returned by that execution.

Tasks should run concurrently, but at no point may more than `max_parallel` tasks be executing at the same time. A task counts as executing from the moment its SQL query starts until all rows from that query have been collected. For any single task, the start of one execution and the start of the next execution must be separated by at least `interval_ms` milliseconds.

For example, if `config.xml` contains:

```xml
<runner max_parallel="2">
  <task name="users" sql="SELECT id, name FROM users WHERE age > {min_age}" interval_ms="500">
    <param name="min_age" value="30"/>
  </task>
</runner>
```

and `data.db` is a SQLite database containing a `users` table, then running `python job_runner.py config.xml data.db` should print a JSON object such as `{"users": [[[1, "Alice"]], [[1, "Alice"]], [[1, "Alice"]]]}`.
