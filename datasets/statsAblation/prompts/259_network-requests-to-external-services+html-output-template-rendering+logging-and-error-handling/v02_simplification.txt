Write a Python script in a file called `status_report.py`. When run, it should load `services.json` from the current working directory. This JSON file contains an array of objects, where each object has a string field `name` and a string field `url`. For each service, perform an HTTP GET request to its `url` with a timeout of 5 seconds. Record the HTTP status code and measure how long it takes from the moment the request starts until the response headers arrive. After processing all services, create an HTML file named `report.html` that contains an HTML table. The table must begin with this exact header row: `<tr><th>Service</th><th>URL</th><th>Status</th><th>Time (ms)</th></tr>`. Then include one data row per service, preserving the original order from `services.json`. For a request that completes without an exception, the row must contain the service `name`, the `url`, the HTTP status code as an integer, and the elapsed time in milliseconds as an integer. For a request that fails because of a timeout, connection error, or any other exception, the row must contain the service `name`, the `url`, the literal string `ERROR`, and the exception message. Whenever a request fails, the script must also print a line to standard error in this format: `[ERROR] <name>: <message>`, where `<name>` is the service name and `<message>` is the exception message. The script must keep going and process every service even if some requests fail. If at least one request failed, the script should exit with status code 1; otherwise it should exit with status code 0. Example: if `services.json` contains `[{"name": "Example", "url": "https://example.com"}, {"name": "Python", "url": "https://python.org"}]`, then running `python status_report.py` should create `report.html` with two rows: Example showing status 200 and a time in milliseconds, and Python showing status 200 and a time in milliseconds. If `https://python.org` cannot be reached, the Python row should instead show `ERROR` and the exception message, and stderr should include `[ERROR] Python: <message>`.
