Create a Python program named `status_report.py`. When executed from a directory, it must read `services.json` from that current working directory. The JSON contains a list of records, each with string properties `name` and `url`. Iterate through every record in the original list order. For each one, send an HTTP GET request to its `url` with a 5-second timeout. Capture the returned HTTP status code and the elapsed time from starting the request until receiving the response headers. Once all records have been processed, generate an HTML file named `report.html` containing an HTML table. The table’s first row must be exactly: `<tr><th>Service</th><th>URL</th><th>Status</th><th>Time (ms)</th></tr>`. Then add one row for each service, in the same order as `services.json`. For a service whose request succeeds, the row must include the service `name`, its `url`, the HTTP status code as an integer, and the elapsed time in milliseconds as an integer. For a service whose request raises a timeout, connection error, or any other exception, the row must include the service `name`, its `url`, the literal text `ERROR`, and the exception message. Every failed request must also cause this exact line to be written to standard error: `[ERROR] <name>: <message>`, where `<name>` is the service name and `<message>` is the exception message. The script must not stop early; it must continue processing all remaining services even after failures. If at least one request failed, the program must terminate with exit code 1. If no request failed, it must terminate with exit code 0. For example, if `services.json` is `[{"name": "Example", "url": "https://example.com"}, {"name": "Python", "url": "https://python.org"}]`, then running `python status_report.py` should create `report.html` with two rows: Example with status 200 and a time in milliseconds, and Python with status 200 and a time in milliseconds. If `https://python.org` cannot be reached, the Python row should instead contain `ERROR` and the exception message, and standard error should include `[ERROR] Python: <message>`.
