Create a single-file Python script named `run_jobs.py` that works as an XML-based job runner.

The script takes exactly one command-line argument: the path to an XML file. This XML file must have a root element named `<jobs>`. Under the root, every child element should be a `<job>` element. Each `<job>` must have a `name` attribute and exactly one `<command>` child. The text inside `<command>` is a shell command line to execute.

Process the `<job>` elements in the order they appear. For each job, run its command line using the system shell. Before starting the command, append one line to `jobs.log` in the current working directory:

`[<ISO-8601 timestamp>] <name>: start`

After the command finishes, append one line:

`[<timestamp>] <name>: exit <code>`

where `<code>` is the process exit code.

After all jobs have been processed, print to stdout exactly:

`passed=<N>`

where `<N>` is how many jobs exited with code 0. The program should exit with status 0 if `<N>` equals the total number of jobs, otherwise exit with status 1.

Handle configuration errors as follows. If the XML file cannot be opened, if the root element is not `<jobs>`, or if any `<job>` element is missing either its `name` attribute or its `<command>` child, then write this line to `jobs.log`:

`[<timestamp>] config: error`

In that error case, write nothing to stdout and exit with status 2.

Example: given `jobs.xml` containing:

```xml
<jobs>
  <job name="build"><command>echo building</command></job>
  <job name="test"><command>false</command></job>
</jobs>
```

Running `python run_jobs.py jobs.xml` should print `passed=1` and exit with status 1. `jobs.log` should receive four new lines: a `start` line and an `exit 0` line for `build`, then a `start` line and an `exit 1` line for `test`.
