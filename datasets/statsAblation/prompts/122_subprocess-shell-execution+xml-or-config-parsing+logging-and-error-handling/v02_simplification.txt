Write a self-contained Python script called `run_jobs.py` that runs shell commands specified in an XML file.

It must accept exactly one argument from the command line: the XML file path. The XML document must be rooted at `<jobs>`, and all direct children of that root should be `<job>` elements. Every `<job>` has a `name` attribute and exactly one `<command>` child; the text content of `<command>` is a shell command line to run.

Visit the `<job>` elements in document order. For each job, execute its command line through the system shell. Just before launching the command, append this line to `jobs.log` in the current directory:

`[<ISO-8601 timestamp>] <name>: start`

When the command completes, append:

`[<timestamp>] <name>: exit <code>`

using the actual process exit code. After every job has been attempted, write exactly this to standard output:

`passed=<N>`

where `<N>` is the number of jobs whose exit code was 0. Exit with status 0 if `<N>` equals the total number of jobs; otherwise exit with status 1.

For configuration errors, cover these cases: the XML file cannot be opened; the root is not `<jobs>`; or any `<job>` lacks a `name` attribute or a `<command>` child. In any such case, append this line to `jobs.log`:

`[<timestamp>] config: error`

and produce no stdout output, exiting with status 2.

Example: if `jobs.xml` contains:

```xml
<jobs>
  <job name="build"><command>echo building</command></job>
  <job name="test"><command>false</command></job>
</jobs>
```

then `python run_jobs.py jobs.xml` should output `passed=1` and exit with code 1. The `jobs.log` file should gain four lines: the `start` and `exit 0` entries for `build`, followed by the `start` and `exit 1` entries for `test`.
