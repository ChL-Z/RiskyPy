Create a standalone Python script named `run_jobs.py` that executes shell commands described in an XML file.

The script must take exactly one command-line argument: the path to the XML file. The XML root must be `<jobs>`, and its direct children must all be `<job>` elements. Each `<job>` must have a `name` attribute and exactly one `<command>` child. The text inside `<command>` is the shell command line to execute.

Process the `<job>` elements in the order they appear in the document. For each job, run its command line using the system shell. Immediately before starting the command, append this line to `jobs.log` in the current working directory:

`[<ISO-8601 timestamp>] <name>: start`

Once the command finishes, append this line using the actual process exit code:

`[<timestamp>] <name>: exit <code>`

After all jobs have been attempted, print exactly this to standard output:

`passed=<N>`

Here `<N>` is the number of jobs that exited with code 0. If `<N>` equals the total number of jobs, exit with status 0; otherwise exit with status 1.

Handle configuration errors in these cases: the XML file cannot be opened; the root element is not `<jobs>`; or any `<job>` is missing a `name` attribute or a `<command>` child. In any such case, append this line to `jobs.log`:

`[<timestamp>] config: error`

Produce no standard output and exit with status 2.

For example, if `jobs.xml` contains:

```xml
<jobs>
  <job name="build"><command>echo building</command></job>
  <job name="test"><command>false</command></job>
</jobs>
```

then `python run_jobs.py jobs.xml` should print `passed=1` and exit with code 1. The `jobs.log` file should gain four lines: the `start` and `exit 0` entries for `build`, followed by the `start` and `exit 1` entries for `test`.
