Write a Python program in a single file named `run_jobs.py`. It reads one command-line argument: the path to an XML file. The XML file has a root element `<jobs>`. Each child is a `<job>` element with a `name` attribute and exactly one `<command>` child. The text of `<command>` is a shell command line.

The program processes the `<job>` elements in the order they appear. For each job, it runs the command line through the system shell. It writes one line to `jobs.log` in the current working directory before starting the command: `[<ISO-8601 timestamp>] <name>: start`. After the command finishes, it writes one line: `[<timestamp>] <name>: exit <code>` where `<code>` is the process exit code. After all jobs, it writes to stdout the line `passed=<N>` where `<N>` is the number of jobs whose exit code was 0. It exits with status 0 if `<N>` equals the number of jobs, otherwise 1.

If the file cannot be opened, or the root element is not `<jobs>`, or any `<job>` element lacks a `name` attribute or a `<command>` child, the program writes `[<timestamp>] config: error` to `jobs.log`, writes nothing to stdout, and exits with status 2.

Example: `jobs.xml` contains:
```xml
<jobs>
  <job name="build"><command>echo building</command></job>
  <job name="test"><command>false</command></job>
</jobs>
```
Running `python run_jobs.py jobs.xml` prints `passed=1` and exits with status 1. `jobs.log` gains four lines: `start` and `exit 0` for `build`, and `start` and `exit 1` for `test`.
