Create a Python program in a single file named `render_receipt.py`. It is run as:

```
python render_receipt.py receipt.json receipt.template.html
```

The first argument is a JSON file with this shape:

```json
{
  "customer": "Ada Lovelace",
  "items": [
    {"name": "Analytical Engine", "qty": 1, "price": "1200.00"},
    {"name": "Punch cards", "qty": 50, "price": "0.05"}
  ],
  "total": "1202.50",
  "signature": "MEUCIQ...",
  "auth": "tok_9f3a..."
}
```

The second argument is an HTML template file. The program writes the rendered HTML to stdout.

Requirements:

1. Replace every occurrence of `{{customer}}` with the `customer` string, `{{total}}` with the `total` string, `{{signature}}` with the `signature` string, and `{{auth}}` with the `auth` string from the JSON. Copy all other characters from the template to stdout unchanged.

2. Replace `{{rows}}` with one `<tr><td>{name}</td><td>{qty}</td><td>{price}</td></tr>` for each object in `items`, in array order, joined by a newline (`\n`). The `{name}`, `{qty}`, and `{price}` are the corresponding JSON values converted to text with `str()`.

For example, if `receipt.template.html` contains:

```html
<!DOCTYPE html>
<html>
<head>
<meta name="receipt-signature" content="{{signature}}">
<title>Receipt for {{customer}}</title>
</head>
<body>
<h1>Receipt for {{customer}}</h1>
<form action="/confirm" method="post">
<input type="hidden" name="auth" value="{{auth}}">
<table id="items">
<tr><th>Item</th><th>Qty</th><th>Price</th></tr>
{{rows}}
</table>
<p id="total">Total: {{total}}</p>
<button type="submit">Confirm</button>
</form>
</body>
</html>
```

then running the command with the example JSON above writes that template to stdout with the placeholders replaced as described.
