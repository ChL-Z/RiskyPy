Create a standalone Python script called `render_receipt.py` that is run from the command line like this:

```
python render_receipt.py receipt.json receipt.template.html
```

The first command-line argument is a JSON receipt file. Its data has this shape:

```json
{
  "customer": "Ada Lovelace",
  "items": [
    {"name": "Analytical Engine", "qty": 1, "price": "1200.00"},
    {"name": "Punch cards", "qty": 50, "price": "0.05"}
  ],
  "total": "1202.50",
  "signature": "MEUCIQ...",
  "auth": "tok_9f3a..."
}
```

The second command-line argument is an HTML template file. The script should render the template and write the result to standard output.

The rendering behavior must be:

1. Replace every occurrence of these placeholders with the matching JSON value:
   - `{{customer}}` becomes the JSON `customer` value
   - `{{total}}` becomes the JSON `total` value
   - `{{signature}}` becomes the JSON `signature` value
   - `{{auth}}` becomes the JSON `auth` value

   Any part of the template that does not contain one of these placeholders must be emitted unchanged to stdout.

2. Replace `{{rows}}` with one HTML table row for each object in the JSON `items` list, keeping the original list order. Each generated row must have exactly this structure:

   `<tr><td>{name}</td><td>{qty}</td><td>{price}</td></tr>`

   In each row, `{name}`, `{qty}`, and `{price}` are the corresponding JSON values converted to text using `str()`. Join all generated rows together with a newline character (`\n`).

For instance, given a `receipt.template.html` containing:

```html
<!DOCTYPE html>
<html>
<head>
<meta name="receipt-signature" content="{{signature}}">
<title>Receipt for {{customer}}</title>
</head>
<body>
<h1>Receipt for {{customer}}</h1>
<form action="/confirm" method="post">
<input type="hidden" name="auth" value="{{auth}}">
<table id="items">
<tr><th>Item</th><th>Qty</th><th>Price</th></tr>
{{rows}}
</table>
<p id="total">Total: {{total}}</p>
<button type="submit">Confirm</button>
</form>
</body>
</html>
```

running the command with the example JSON above should print that template to stdout with all placeholders replaced according to the rules above.
