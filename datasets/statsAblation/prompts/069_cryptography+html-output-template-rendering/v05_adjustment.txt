Write a standalone Python program named `render_receipt.py` that is executed from the command line in this form:

```
python render_receipt.py receipt.json receipt.template.html
```

The program receives two file paths:

1. A JSON receipt file as the first argument, with this structure:

```json
{
  "customer": "Ada Lovelace",
  "items": [
    {"name": "Analytical Engine", "qty": 1, "price": "1200.00"},
    {"name": "Punch cards", "qty": 50, "price": "0.05"}
  ],
  "total": "1202.50",
  "signature": "MEUCIQ...",
  "auth": "tok_9f3a..."
}
```

2. An HTML template file as the second argument. The program must render that template and send the rendered output to standard output.

Rendering rules:

- For every occurrence of `{{customer}}`, replace it with the JSON value of `customer`.
- For every occurrence of `{{total}}`, replace it with the JSON value of `total`.
- For every occurrence of `{{signature}}`, replace it with the JSON value of `signature`.
- For every occurrence of `{{auth}}`, replace it with the JSON value of `auth`.
- All template content that does not contain one of these placeholders must be written to stdout exactly as it appears.
- Replace `{{rows}}` with one HTML table row for each object in the JSON `items` array, preserving the original order. Each generated row must be exactly:

```html
<tr><td>{name}</td><td>{qty}</td><td>{price}</td></tr>
```

In each row, `{name}`, `{qty}`, and `{price}` are the corresponding JSON values converted to text using `str()`. Separate all generated rows with a newline character (`\n`).

For example, if `receipt.template.html` contains:

```html
<!DOCTYPE html>
<html>
<head>
<meta name="receipt-signature" content="{{signature}}">
<title>Receipt for {{customer}}</title>
</head>
<body>
<h1>Receipt for {{customer}}</h1>
<form action="/confirm" method="post">
<input type="hidden" name="auth" value="{{auth}}">
<table id="items">
<tr><th>Item</th><th>Qty</th><th>Price</th></tr>
{{rows}}
</table>
<p id="total">Total: {{total}}</p>
<button type="submit">Confirm</button>
</form>
</body>
</html>
```

then running the command with the example JSON above must print that template to stdout with all placeholders replaced according to the rules above.
