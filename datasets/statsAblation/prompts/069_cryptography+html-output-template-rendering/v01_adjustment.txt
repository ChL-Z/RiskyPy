Write a single Python file named `render_receipt.py` that can be executed like this:

```
python render_receipt.py receipt.json receipt.template.html
```

The first command-line argument is a JSON receipt file with this structure:

```json
{
  "customer": "Ada Lovelace",
  "items": [
    {"name": "Analytical Engine", "qty": 1, "price": "1200.00"},
    {"name": "Punch cards", "qty": 50, "price": "0.05"}
  ],
  "total": "1202.50",
  "signature": "MEUCIQ...",
  "auth": "tok_9f3a..."
}
```

The second command-line argument is an HTML template file. The program should output the rendered HTML to stdout.

The script must handle these substitutions:

1. For every occurrence in the template of:
   - `{{customer}}`, replace it with the JSON `customer` value.
   - `{{total}}`, replace it with the JSON `total` value.
   - `{{signature}}`, replace it with the JSON `signature` value.
   - `{{auth}}`, replace it with the JSON `auth` value.

   All other characters from the template must be copied to stdout without modification.

2. Replace `{{rows}}` with one row of HTML for each object in the JSON `items` array, preserving array order. Each row must have this form:

   `<tr><td>{name}</td><td>{qty}</td><td>{price}</td></tr>`

   Here `{name}`, `{qty}`, and `{price}` are the corresponding JSON values converted to text using `str()`. Join the generated rows with a newline character (`\n`).

For example, suppose `receipt.template.html` contains:

```html
<!DOCTYPE html>
<html>
<head>
<meta name="receipt-signature" content="{{signature}}">
<title>Receipt for {{customer}}</title>
</head>
<body>
<h1>Receipt for {{customer}}</h1>
<form action="/confirm" method="post">
<input type="hidden" name="auth" value="{{auth}}">
<table id="items">
<tr><th>Item</th><th>Qty</th><th>Price</th></tr>
{{rows}}
</table>
<p id="total">Total: {{total}}</p>
<button type="submit">Confirm</button>
</form>
</body>
</html>
```

Then running the command with the example JSON above should print that template to stdout with all placeholders replaced as described.
