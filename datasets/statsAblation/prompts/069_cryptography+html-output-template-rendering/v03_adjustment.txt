Write a self-contained Python script named `render_receipt.py` that is executed from the command line as:

```
python render_receipt.py receipt.json receipt.template.html
```

The first argument is a JSON receipt file with this structure:

```json
{
  "customer": "Ada Lovelace",
  "items": [
    {"name": "Analytical Engine", "qty": 1, "price": "1200.00"},
    {"name": "Punch cards", "qty": 50, "price": "0.05"}
  ],
  "total": "1202.50",
  "signature": "MEUCIQ...",
  "auth": "tok_9f3a..."
}
```

The second argument is an HTML template file. The script must print the rendered HTML to standard output.

The rendering rules are:

1. For every occurrence of these placeholders, substitute the corresponding JSON value:
   - `{{customer}}` -> the JSON `customer` value
   - `{{total}}` -> the JSON `total` value
   - `{{signature}}` -> the JSON `signature` value
   - `{{auth}}` -> the JSON `auth` value

   Template content that does not contain one of these placeholders must be passed through to stdout unchanged.

2. Replace `{{rows}}` with one HTML table row for each object in the JSON `items` array, preserving the array order. Each row must use exactly this form:

   `<tr><td>{name}</td><td>{qty}</td><td>{price}</td></tr>`

   For each row, `{name}`, `{qty}`, and `{price}` are the corresponding JSON values converted to text with `str()`. The generated rows must be joined together using a newline character (`\n`).

For example, if `receipt.template.html` contains:

```html
<!DOCTYPE html>
<html>
<head>
<meta name="receipt-signature" content="{{signature}}">
<title>Receipt for {{customer}}</title>
</head>
<body>
<h1>Receipt for {{customer}}</h1>
<form action="/confirm" method="post">
<input type="hidden" name="auth" value="{{auth}}">
<table id="items">
<tr><th>Item</th><th>Qty</th><th>Price</th></tr>
{{rows}}
</table>
<p id="total">Total: {{total}}</p>
<button type="submit">Confirm</button>
</form>
</body>
</html>
```

then running the command with the example JSON above should print that template to stdout with all placeholders replaced according to the rules above.
