Write a single-file Python program named `run_report.py` that reads report settings from an XML file, queries a SQLite database, and writes a CSV report to standard output.

The program is invoked as:

```
python run_report.py --config config.xml --token TOKEN [--filter FIELD=VALUE ...]
```

## XML input

The file passed with `--config` is XML with this shape:

```xml
<report>
  <database path="sales.db" />
  <table name="orders" />
  <columns>id, customer, total</columns>
  <token value="a1b2c3" />
</report>
```

Interpret the XML as follows:

- `<database path="...">` specifies the SQLite database file. If the path is relative, interpret it relative to the process's current working directory.
- `<table name="...">` specifies the table to query.
- The text content of `<columns>` is a comma-separated list of column names. These columns must appear in the CSV output in exactly the order given.
- `<token value="...">` specifies the token that the command-line `--token` argument must equal.

## Required behavior

1. Token check:
   - Compare the value supplied through `--token` with the XML `<token value="...">` attribute.
   - If they differ, write exactly `access denied` followed by a newline to stderr, then exit with status 1.
   - If they match, continue.

2. Filters:
   - Each `--filter FIELD=VALUE` keeps only rows where the column named `FIELD` has the textual value `VALUE`.
   - When multiple `--filter` arguments are provided, a row must satisfy all of them.
   - If no filters are provided, all rows are eligible.
   - Filter columns do not need to be part of the configured output columns.
   - Filter comparisons are textual.
   - If any `--filter` argument does not contain `=`, write exactly `bad filter: <argument>` followed by a newline to stderr, then exit with status 2.

3. CSV output:
   - Print the result to stdout as comma-separated values.
   - The first line must contain the configured column names in the configured order.
   - After that, print one line for each matching row, with values in the same column order.
   - Every line, including the final line, must end with a newline.
   - If a value contains a comma, a double quote, or a newline, wrap it in double quotes. Inside a quoted value, each double quote must be doubled.
   - A SQL NULL must be printed as an empty field.
   - After printing the report, exit with status 0.

## Example

Assume `config.xml` is exactly as shown above, and the `orders` table in `sales.db` contains these rows:

- `(1, 'Ann', 20)`
- `(2, 'Bo', 35)`
- `(3, 'Ann', 12)`

Running:

```
python run_report.py --config config.xml --token a1b2c3 --filter customer=Ann
```

must produce this stdout:

```
id,customer,total
1,Ann,20
3,Ann,12
```

A table column that is not listed in `<columns>` may still be used in a `--filter` option.

Everything must be implemented in one Python file only, with no additional companion files.
