Write a single Python file named `run_report.py` that prints a CSV report extracted from a SQLite database, where the report definition lives in an XML configuration file.

The tool is invoked as:

```
python run_report.py --config config.xml --token TOKEN [--filter FIELD=VALUE ...]
```

**Configuration file.** The `--config` file is an XML document in this shape:

```xml
<report>
  <database path="sales.db" />
  <table name="orders" />
  <columns>id, customer, total</columns>
  <token value="a1b2c3" />
</report>
```

`<database path>` is the path to the SQLite file (relative paths resolve against the current working directory). `<table name>` is the table to read. `<columns>` is a comma-separated list of column names, in the order they must appear in the output. `<token value>` is the accepted token string.

**Behavior.**

1. If the string passed to `--token` is not equal to the `value` attribute of `<token>`, print exactly `access denied` followed by a newline to stderr and exit with status 1. Otherwise continue.

2. Every `--filter FIELD=VALUE` argument restricts the output to rows where column FIELD equals VALUE. When multiple `--filter` arguments are given, a row is included only if all of them match. When no `--filter` argument is given, every row of the table is eligible. The field names in filters are not limited to the configured columns. Filter values are compared against the stored values as text. A `--filter` argument with no `=` character must cause the program to print exactly `bad filter: <argument>` followed by a newline to stderr and exit with status 2.

3. Write the result to stdout as comma-separated values: the first line is the configured column names in configured order, followed by one line per matching row with the column values in that same order. Terminate every line, including the last, with a newline. Enclose a value in double quotes if it contains a comma, a double quote, or a newline, and represent a double quote inside such a value by doubling it. A NULL value is written as an empty field. Exit with status 0 after writing the report.

**Example.** With `config.xml` as shown above and a `sales.db` whose `orders` table holds `(1, 'Ann', 20)`, `(2, 'Bo', 35)`, `(3, 'Ann', 12)`, running

```
python run_report.py --config config.xml --token a1b2c3 --filter customer=Ann
```

must write to stdout:

```
id,customer,total
1,Ann,20
3,Ann,12
```

Another column of the table that is not listed in `<columns>` may still be used in `--filter`.

The whole implementation must be a single Python file with no companion files.
