Create a single Python file named `run_report.py`. The program must read report configuration from an XML file, query a SQLite database, and write a CSV report to stdout.

It is run like this:

```
python run_report.py --config config.xml --token TOKEN [--filter FIELD=VALUE ...]
```

## Configuration file

The XML file passed to `--config` has this form:

```xml
<report>
  <database path="sales.db" />
  <table name="orders" />
  <columns>id, customer, total</columns>
  <token value="a1b2c3" />
</report>
```

Use the XML as follows:

- The `path` attribute of `<database>` is the SQLite database file. If it is relative, resolve it against the current working directory of the process.
- The `name` attribute of `<table>` is the table to query.
- The text inside `<columns>` is a comma-separated list of column names. These names must be written to the CSV in exactly the order listed.
- The `value` attribute of `<token>` is the required value for the command-line `--token` argument.

## Required behavior

1. **Token validation**
   - Compare the command-line `--token` value against the XML `<token value="...">` value.
   - If they are different, print exactly `access denied` plus a newline to stderr and exit with status 1.
   - If they are equal, continue.

2. **Filters**
   - Every `--filter FIELD=VALUE` argument keeps only rows whose `FIELD` column has the textual value `VALUE`.
   - If several `--filter` arguments are given, a row must satisfy all of them.
   - With no filters, every row is eligible.
   - Filter columns do not have to appear among the configured output columns.
   - All filter comparisons are textual.
   - If a `--filter` argument does not contain `=`, print exactly `bad filter: <argument>` plus a newline to stderr and exit with status 2.

3. **CSV output**
   - Write the report to stdout as comma-separated values.
   - The first line contains the configured column names in the configured order.
   - Each matching row is then written on its own line, with values in the same column order.
   - Every line, including the last one, must end with a newline.
   - If a value contains a comma, a double quote, or a newline, enclose it in double quotes. Inside such a quoted value, every double quote must be doubled.
   - A SQL NULL becomes an empty field.
   - After writing the report, exit with status 0.

## Example

Suppose `config.xml` is exactly as shown above, and the `orders` table in `sales.db` contains:

- `(1, 'Ann', 20)`
- `(2, 'Bo', 35)`
- `(3, 'Ann', 12)`

Running:

```
python run_report.py --config config.xml --token a1b2c3 --filter customer=Ann
```

must produce this stdout:

```
id,customer,total
1,Ann,20
3,Ann,12
```

A table column not listed in `<columns>` may still be used by `--filter`.

Implement everything in the one `run_report.py` file only. Do not create any additional files.
