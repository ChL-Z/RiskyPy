Create a self-contained Python script named `run_report.py` that emits a CSV report based on data read from a SQLite database, using an XML file to define the report.

The script is run like this:

```
python run_report.py --config config.xml --token TOKEN [--filter FIELD=VALUE ...]
```

### XML configuration

The file supplied via `--config` must be parsed as XML in the following form:

```xml
<report>
  <database path="sales.db" />
  <table name="orders" />
  <columns>id, customer, total</columns>
  <token value="a1b2c3" />
</report>
```

- The `path` attribute of `<database>` gives the SQLite database file. If it is relative, resolve it relative to the current working directory.
- The `name` attribute of `<table>` gives the table to query.
- The text inside `<columns>` is a comma-separated list of column names. These columns must appear in the output in exactly that order.
- The `value` attribute of `<token>` is the token that the command-line `--token` value must match.

### Required behavior

1. Compare the string passed to `--token` with the XML `<token value>` attribute. If they are not equal, write exactly `access denied` plus a newline to stderr, then exit with status 1. Otherwise, continue.

2. Each `--filter FIELD=VALUE` option keeps only rows where the column named `FIELD` has the text value `VALUE`. If multiple `--filter` options are supplied, only rows satisfying all of them are included. If none are supplied, all rows are eligible. Filter fields do not have to be among the configured output columns. Filter comparisons are textual. If any `--filter` argument does not contain `=`, write exactly `bad filter: <argument>` plus a newline to stderr, then exit with status 2.

3. Print the result to stdout as comma-separated values. The first line must contain the configured column names in the configured order. Then print one line for every matching row, with values in that same column order. Every line, including the final one, must end with a newline. If a value contains a comma, a double quote, or a newline, surround it with double quotes. Inside such a quoted value, represent each double quote by two double quotes. A SQL NULL must be printed as an empty field. After printing the report, exit with status 0.

### Example

Assume `config.xml` is exactly as shown above, and the `orders` table in `sales.db` contains:

- `(1, 'Ann', 20)`
- `(2, 'Bo', 35)`
- `(3, 'Ann', 12)`

Running:

```
python run_report.py --config config.xml --token a1b2c3 --filter customer=Ann
```

must produce this stdout:

```
id,customer,total
1,Ann,20
3,Ann,12
```

A table column that is not listed in `<columns>` may still be used in a `--filter` option.

Everything must be implemented in one Python file only, with no additional companion files.
