Create a single Python file called `auth_check.py`. When the script starts, it must read `config.json` from the current working directory. That JSON file will be an object containing exactly two keys: `users`, which is a list of username strings, and `secret`, which is a string. The script receives command-line arguments. The first argument is the operation and must be either `generate` or `verify`. The second argument is a username. For `generate`, print to stdout a token string for that username. For `verify`, a third command-line argument will be a token string; print `ACCEPT` if that token is valid for the given username, otherwise print `REJECT`. In both verification cases, the process must exit with status code 0. A token is valid for a username exactly when it matches the token that `generate` would produce for the same username using the same `config.json`. The token must be computed deterministically from the username and the `config.json` secret, and its final string representation must be safe to pass as a command-line argument. The program must not create or write any files. For example, if `config.json` is `{"users": ["alice", "bob"], "secret": "s3cr3t"}`, then running `python auth_check.py generate alice` should print a token, running `python auth_check.py verify alice <that token>` should print `ACCEPT`, and running `python auth_check.py verify alice wrongtoken` should print `REJECT`.
