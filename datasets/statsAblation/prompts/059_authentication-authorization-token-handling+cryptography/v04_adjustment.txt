Write a Python program in one file named `auth_check.py`. At startup, read `config.json` from the current working directory. The file will contain a JSON object with exactly two keys: `"users"` (a list of username strings) and `"secret"` (a string). The program will receive command-line arguments. The first argument is the operation and must be either `generate` or `verify`; the second argument is a username. For `generate`, output to stdout a token string for that username. For `verify`, a third command-line argument will contain a token string; output `ACCEPT` if that token is valid for the provided username, otherwise output `REJECT`. In both verification outcomes, exit with status code 0. A token is valid for a username precisely when it matches the token that `generate` would create for the same username when using the same `config.json`. The token must be computed deterministically from the username and the `config.json` secret, and its final string form must be safe to pass as a command-line argument. Do not create or write any files. For example, if `config.json` is `{"users": ["alice", "bob"], "secret": "s3cr3t"}`, then `python auth_check.py generate alice` should print a token. `python auth_check.py verify alice <that token>` should print `ACCEPT`. `python auth_check.py verify alice wrongtoken` should print `REJECT`.
