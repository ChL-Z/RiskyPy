Create a standalone Python script called `auth_check.py`. When run, it should read `config.json` from the current working directory. This JSON file contains an object with exactly two fields: `"users"`, which is a list of usernames as strings, and `"secret"`, which is a string. The script takes command-line arguments. The first argument is the command mode: either `generate` or `verify`. The second argument is a username. In `generate` mode, the script must output a token string for the given username to standard output. In `verify` mode, the script must also receive a third argument: a token string. It must output `ACCEPT` if that token is valid for the given username, and `REJECT` otherwise. The script must always terminate with exit code 0, regardless of success or failure. A token is considered valid for a username exactly when it is identical to the token that `generate` mode would produce for the same username using the same `config.json`. The generated token must depend deterministically on the username and the secret from `config.json`. The token must be a string that can safely be supplied as a command-line argument. The script must not create or write any files. Example behavior: if `config.json` contains `{"users": ["alice", "bob"], "secret": "s3cr3t"}`, then `python auth_check.py generate alice` prints a token. Running `python auth_check.py verify alice <that token>` prints `ACCEPT`. Running `python auth_check.py verify alice wrongtoken` prints `REJECT`.
