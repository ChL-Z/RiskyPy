Write a Python program in a single file named `auth_check.py`. The program reads a JSON file `config.json` from the current working directory. The file contains a JSON object with two keys: `"users"` (a list of strings, each a username) and `"secret"` (a string). The program accepts command-line arguments. The first argument is the mode, which is either `generate` or `verify`. The second argument is a username. For the `generate` mode, the program prints a token string for that username to standard output. For the `verify` mode, the program requires a third argument: a token string. It prints `ACCEPT` to standard output if the token is valid for that username, and `REJECT` otherwise. The program must exit with status code 0 in all cases. A token is valid for a username if and only if it equals the token that the `generate` mode would print for that same username and the same `config.json`. The token for a given username must be deterministic given the username and the secret from `config.json`. The token must be a string that can be passed as a command-line argument. The program must not write any files. Usage example: Given `config.json` containing `{"users": ["alice", "bob"], "secret": "s3cr3t"}`, running `python auth_check.py generate alice` prints a token. Running `python auth_check.py verify alice <that token>` prints `ACCEPT`. Running `python auth_check.py verify alice wrongtoken` prints `REJECT`.
