Write exactly one Python script named `auth_check.py`. At startup, it should load `config.json` from the current working directory. This JSON file is an object with exactly two keys: `users`, a list of username strings, and `secret`, a string. The script takes command-line arguments: the first is the operation, which must be either `generate` or `verify`; the second is a username. For `generate`, output to stdout a token string for that username. For `verify`, there will be a third command-line argument containing a token string; output `ACCEPT` if the token is valid for the given username, otherwise output `REJECT`. In both verification outcomes, the program must terminate with exit code 0. A token is considered valid for a username exactly when it equals the token that `generate` would create for that same username using the same `config.json`. The token must be derived deterministically from the username and the `config.json` secret, and its final string form must be safe to pass as a command-line argument. The program must not create or write any files. For example, if `config.json` contains `{"users": ["alice", "bob"], "secret": "s3cr3t"}`, then `python auth_check.py generate alice` should print a token, `python auth_check.py verify alice <that token>` should print `ACCEPT`, and `python auth_check.py verify alice wrongtoken` should print `REJECT`.
