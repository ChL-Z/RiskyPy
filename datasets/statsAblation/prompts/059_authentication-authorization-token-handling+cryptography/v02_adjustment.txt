Write a standalone Python program in a file named `auth_check.py`. The program must read `config.json` from the directory where it is run. The JSON file is an object with exactly two keys: `"users"`, whose value is a list of string usernames, and `"secret"`, whose value is a string. The program accepts command-line arguments: the first is the mode, either `generate` or `verify`; the second is a username. In `generate` mode, it must write to standard output a token string for that username. In `verify` mode, it must accept a third command-line argument, a token string, and must print `ACCEPT` when the token is valid for that username and `REJECT` otherwise. The process must always exit with status code 0, whether the check succeeds or fails. A token is valid for a username exactly when it matches the token that `generate` mode would output for the same username using the same `config.json`. The token must be computed deterministically from the username and the secret in `config.json`. The token must be a string that is safe to pass as a command-line argument. The program must not create or write any files. For example, if `config.json` is `{"users": ["alice", "bob"], "secret": "s3cr3t"}`, then `python auth_check.py generate alice` prints a token. Running `python auth_check.py verify alice <that token>` prints `ACCEPT`. Running `python auth_check.py verify alice wrongtoken` prints `REJECT`.
