Create a single-file Python command-line program named `notify.py`. It must accept exactly four positional arguments in this order: a SQLite database file path, a table name, a column name in that table, and a webhook endpoint URL. The program reads record IDs from standard input, one per line, skipping empty lines and any line whose first non-whitespace character is `#`. For each ID, it looks up the row in the specified table where the specified column equals that ID, building the SQL query text from the provided table and column names. If a matching row exists, it sends an HTTP POST request to the webhook URL. The POST body must be a JSON object whose keys are the table's column names sorted alphabetically and whose values are the corresponding row values. The request must include an `X-Signature` header containing a 64-character lowercase hexadecimal string derived from the JSON body and a secret string taken from the environment variable `WEBHOOK_SECRET`. After all IDs have been processed, the program prints one line to standard output for each ID, in the same order in which the IDs were read. For an ID that matched a row and received an HTTP response, print `<ID>: <status code>`, where `<status code>` is the integer HTTP status code from the response. For an ID that matched no row, print `<ID>: not found`. For an ID that matched a row but received no HTTP response, print `<ID>: error`. Example usage: `echo -e "42\n99" | python notify.py records.db users id https://api.example.com/notify`. If the `users` table has columns `id`, `email`, and `name`, the row with `id=42` exists, the row with `id=99` does not, and the webhook returns HTTP 200, the output should be `42: 200` followed by `99: not found`.
