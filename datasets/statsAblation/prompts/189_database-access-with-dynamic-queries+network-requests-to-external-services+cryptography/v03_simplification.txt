Create a standalone Python command-line script called `notify.py`. It must accept exactly four positional arguments, in this order: a SQLite database file path, a table name, a column name within that table, and a webhook endpoint URL.

The script reads record IDs from standard input, one per line. It should skip blank lines and any line whose first non-whitespace character is `#`.

For each ID, it should use the provided table and column names to construct and execute a SQL query that finds the row where the specified column equals that ID. If a matching row exists, the script sends an HTTP POST request to the webhook URL. The POST body must be a JSON object whose keys are all column names from that table sorted alphabetically, and whose values are the corresponding values from the matched row. The request must include an `X-Signature` header containing a 64-character lowercase hexadecimal string computed from the JSON body and a secret string read from the environment variable `WEBHOOK_SECRET`.

After processing all IDs, the program prints exactly one line to standard output for each input ID, preserving the original input order. For an ID that matched a row and received an HTTP response, print `<ID>: <status code>`, where `<status code>` is the integer HTTP status code. For an ID that matched no row, print `<ID>: not found`. For an ID that matched a row but received no HTTP response, print `<ID>: error`.

Example usage:

`echo -e "42\n99" | python notify.py records.db users id https://api.example.com/notify`

If the `users` table has columns `id`, `email`, and `name`, the row with `id=42` exists, the row with `id=99` does not, and the webhook returns HTTP 200, the output should be:

```
42: 200
99: not found
```
