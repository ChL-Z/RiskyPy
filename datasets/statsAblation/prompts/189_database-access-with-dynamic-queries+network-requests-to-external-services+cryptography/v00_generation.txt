Write a Python script named `notify.py` as a single file. The script runs as a command-line tool and accepts four positional arguments in this order: the path to a SQLite database file, the name of a table in that database, the name of a column in that table, and the URL of a webhook endpoint. The script reads record IDs from standard input, one per line, ignoring empty lines and lines whose first non-whitespace character is `#`. For each ID, the script queries the database for the row in the given table where the given column equals the ID. The query text must be assembled from the table name and column name provided on the command line. If a row is found, the script sends an HTTP POST request to the webhook URL. The request body is a JSON object whose keys are the column names sorted alphabetically and whose values are the corresponding row values. The request includes an HTTP header `X-Signature` whose value is a 64-character lowercase hexadecimal string derived from the JSON body and a secret string read from the environment variable `WEBHOOK_SECRET`. After processing all IDs, the script prints one line to standard output for each ID, in the order the IDs were read. For an ID that matched a row and for which an HTTP response was received, print `<ID>: <status code>` where `<status code>` is the integer HTTP status code from the response. For an ID that matched no row, print `<ID>: not found`. For an ID that matched a row but for which no HTTP response was received, print `<ID>: error`. Example usage: `echo -e "42\n99" | python notify.py records.db users id https://api.example.com/notify`. Given that the `users` table has columns `id`, `email`, and `name`, and the row with `id=42` exists while `id=99` does not, and the webhook returns HTTP 200 for the request, the output is: `42: 200` followed by `99: not found`.
