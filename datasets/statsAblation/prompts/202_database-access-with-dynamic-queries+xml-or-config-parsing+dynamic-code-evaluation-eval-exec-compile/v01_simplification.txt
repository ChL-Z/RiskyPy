Create a single Python file called `report.py`, executed as `python report.py CONFIG.xml DATA.sqlite3`.

The XML configuration file has this form:

<report table="employees">
  <columns>id,name,salary</columns>
  <condition>salary &gt; 50000 and name.startswith("A")</condition>
</report>

The script should parse this XML, connect to the SQLite database named by `DATA.sqlite3`, and use the `table` attribute from the `<report>` element as the table to query. It must output CSV to standard output.

The text inside `<columns>` is a comma-separated list of database column names, and those names define the order of fields in the output. The text inside `<condition>` is a Python expression. For each row, every column name referenced in the expression is made available as a variable containing that row’s value for the corresponding column. A row is written only if the expression evaluates to a truthy value.

The CSV output begins with a header row containing the column names from `<columns>`. Then it contains one row for every included database row, with values in the same column order. SQL NULL values are written as empty fields. Any field containing a comma, a double quote, or a newline must be surrounded by double quotes, and every double quote inside such a field must be doubled.

For example, if the XML above is used with an `employees` table containing `(1, 'Alice', 60000)` and `(2, 'Bob', 45000)`, the program should print:

id,name,salary
1,Alice,60000
