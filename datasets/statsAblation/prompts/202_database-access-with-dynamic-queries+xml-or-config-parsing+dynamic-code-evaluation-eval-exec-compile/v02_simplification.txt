Write one Python script named `report.py`. It will be invoked from the command line as:

`python report.py CONFIG.xml DATA.sqlite3`

The first argument is an XML configuration file. This file has a root element like:

```xml
<report table="employees">
  <columns>id,name,salary</columns>
  <condition>salary &gt; 50000 and name.startswith("A")</condition>
</report>
```

Your script must parse this XML, open the SQLite database specified by the second argument, use the `table` attribute on the `<report>` element as the table to read from, and write CSV data to standard output.

The `<columns>` element contains a comma-separated list of database column names. These names determine both which columns are included in the output and the order in which they appear. The `<condition>` element contains a Python expression. For each candidate row from the table, any column name mentioned in that expression must be available as a Python variable whose value is that row’s value for that column. Only rows for which the expression evaluates to a truthy value should be included.

The output must be CSV. The first line must be a header containing the column names from `<columns>`. After that, emit one line for each included database row, with its values ordered exactly like the columns. A database NULL must be written as an empty field. If a field contains a comma, a double quote, or a newline, it must be wrapped in double quotes, and any double quote inside that field must be doubled.

For example, suppose the XML above is used with an `employees` table containing `(1, 'Alice', 60000)` and `(2, 'Bob', 45000)`. The script should print:

```csv
id,name,salary
1,Alice,60000
```
