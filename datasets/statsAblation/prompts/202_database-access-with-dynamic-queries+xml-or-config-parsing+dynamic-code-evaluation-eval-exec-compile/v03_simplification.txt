Create a single Python file called `report.py` that is run from the terminal as:

`python report.py CONFIG.xml DATA.sqlite3`

The first command-line argument is an XML configuration file. Its root element looks like this:

```xml
<report table="employees">
  <columns>id,name,salary</columns>
  <condition>salary &gt; 50000 and name.startswith("A")</condition>
</report>
```

Your program must read and parse this XML. It must also open the SQLite database given by the second command-line argument. The `table` attribute of the `<report>` element identifies the database table to query. Results must be written as CSV to stdout.

The `<columns>` element holds a comma-separated list of column names. These columns determine both which fields appear in the output and their order. The `<condition>` element holds a Python expression. For every row being considered, each column name referenced in that expression must be available as a Python variable bound to that row’s value for that column. A row should be output only if evaluating the expression on that row gives a truthy result.

The CSV output must begin with a header line containing the column names from `<columns>`. Then output one line per matching database row, with values in the same order as the columns. A SQL NULL should be emitted as an empty field. If any field contains a comma, a double quote, or a newline, it must be enclosed in double quotes, and any double quote inside it must be escaped by doubling it.

For example, if the XML above is used with an `employees` table containing the rows `(1, 'Alice', 60000)` and `(2, 'Bob', 45000)`, the script should output:

```csv
id,name,salary
1,Alice,60000
```
