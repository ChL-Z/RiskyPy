Write a Python program in a single file named `report.py`. It is invoked as `python report.py CONFIG.xml DATA.sqlite3`.

`CONFIG.xml` is an XML file with this structure:

<report table="employees">
  <columns>id,name,salary</columns>
  <condition>salary &gt; 50000 and name.startswith("A")</condition>
</report>

The program must read the XML file, read rows from the SQLite database `DATA.sqlite3` using the table name from the `table` attribute, and write CSV to stdout. The `<columns>` text is a comma-separated list of column names to include in the output. The `<condition>` text uses Python expression syntax and references only those column names; for a row, each referenced name has the row's cell value for that column. A row is included when the condition expression produces a true value. The CSV output has a header line containing the column names from `<columns>`, followed by one line for each included row with values in that column order. Database NULL values appear as empty fields. Fields containing a comma, double quote, or newline are enclosed in double quotes, and each double quote inside such a field is written as two double quotes.

Example: with the XML above and a table `employees` containing `(1, 'Alice', 60000)`, `(2, 'Bob', 45000)`, the program prints:

id,name,salary
1,Alice,60000
