Create a Python program in a single file named `status_sync.py`. The program is run as `python status_sync.py < services.txt`, where `services.txt` contains newline-separated service names. It refreshes timestamps for those services in a cache file.

1. For each non-empty service name read from standard input, open the SQLite database file `services.db` and retrieve the `endpoint` and `last_sync` columns from the `services` table row whose `name` column equals that service name. If no row exists, write the service name and the text `missing` to standard error and continue.

2. For each service name that has a database row, send an HTTP GET request to `{endpoint}/status?since={last_sync}` and read the response body as a JSON object with keys `status` and `updated_at`. If the response body is not a JSON object with both keys, write `{name}: invalid response` to standard error and continue.

3. After processing all input names, write `status_cache.json` as a JSON object. The object maps each service name for which an `updated_at` value was obtained to that `updated_at` string. If `status_cache.json` already exists and contains a JSON object, preserve all existing key-value pairs and overwrite entries for service names processed in this run. Print the final cache object to standard output as JSON.
