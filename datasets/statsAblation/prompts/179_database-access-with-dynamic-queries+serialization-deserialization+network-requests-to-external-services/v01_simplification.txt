Build a single-file Python program called `status_sync.py`, intended to be executed as `python status_sync.py < services.txt`, where `services.txt` holds one service name per line. The script updates timestamp records for those services in a cache file.

1. Read non-empty service names from standard input. For each such name, open the SQLite database `services.db` and look up the row in the `services` table where `name` matches. Fetch its `endpoint` and `last_sync` columns. If the row is absent, output the service name followed by `missing` to standard error and move on.

2. For every service that was found in the database, issue an HTTP GET request to `{endpoint}/status?since={last_sync}`. The response body should be interpreted as a JSON object containing `status` and `updated_at`. If it is not a JSON object with both of those keys, output `{name}: invalid response` to standard error and skip to the next service.

3. Once all input names have been handled, write `status_cache.json` as a JSON object. It should associate each service name that yielded an `updated_at` value with that value. If `status_cache.json` already exists and holds a JSON object, keep all existing key-value pairs while replacing any entries for services handled in this execution. Finally, print the resulting cache object to standard output as JSON.
