Write a single-file Python program called `status_sync.py` that is executed as `python status_sync.py < services.txt`, where `services.txt` provides one service name per line. The program must refresh timestamp records for those services in a cache file.

1. Read service names from standard input, ignoring blank lines. For each non-empty service name, connect to the SQLite database `services.db`, find the row in the `services` table where `name` matches that service, and retrieve its `endpoint` and `last_sync` columns. If no matching row exists, write the service name followed by `missing` to standard error and continue.

2. For every service found in the database, send an HTTP GET request to `{endpoint}/status?since={last_sync}`. Parse the response body as JSON. If it is not a JSON object containing both `status` and `updated_at`, write `{name}: invalid response` to standard error and skip that service.

3. After all input names have been processed, write `status_cache.json` as a JSON object. It should map each service name that produced an `updated_at` value to that value. If `status_cache.json` already exists and contains a JSON object, preserve all existing key-value pairs while replacing entries for services handled in this execution. Finally, print the resulting cache object to standard output as JSON.
