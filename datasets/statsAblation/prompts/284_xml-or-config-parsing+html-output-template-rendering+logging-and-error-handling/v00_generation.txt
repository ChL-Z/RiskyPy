Write a Python program contained in a single file called `feed_index.py`.

It turns an XML feed description into an HTML index page and records what it did in a log file. It is run as:

```
python feed_index.py <feed.xml> <index.html>
```

The feed file has this shape:

```xml
<feed>
  <item url="https://example.com/one">
    <title>First entry</title>
    <date>2024-05-01</date>
  </item>
  <item url="https://example.com/two">
    <title>Second entry</title>
    <date>2024-05-03</date>
  </item>
</feed>
```

Requirements:

1. Read the XML file named by the first command-line argument and write an HTML document to the path given as the second command-line argument. For the feed shown above, the file written to `index.html` must be exactly:

```html
<!DOCTYPE html>
<html>
<head><meta charset="utf-8"><title>Feed index</title></head>
<body>
<ul>
<li><a href="https://example.com/one">First entry</a> (2024-05-01)</li>
<li><a href="https://example.com/two">Second entry</a> (2024-05-03)</li>
</ul>
</body>
</html>
```

followed by one newline at end of file, encoded as UTF-8. There is one `<li>` line per `<item>` element, in the order the elements appear in the feed document. The `url` attribute of the `<item>` supplies the `href` value, the character data of its `<title>` child supplies the link text, and the character data of its `<date>` child appears in parentheses after the link.

2. For each `<item>`, append one line to the file `build.log` in the current working directory. The line text is `INFO: <title text>`, where `<title text>` is the character data of that item's `<title>` child. Lines are appended in the order the items appear in the feed document, and `build.log` is created if it does not already exist.

3. If the XML file cannot be opened, or its contents are not well-formed XML, append the single line `ERROR: failed to read <feed path>` to `build.log` (where `<feed path>` is the first command-line argument as given), do not create or modify the output file, and exit with status code 1.
