Create a single Python file called `feed_index.py`. It must be executable from the command line as:

```
python feed_index.py <feed.xml> <index.html>
```

The input file is an XML feed with this structure:

```xml
<feed>
  <item url="https://example.com/one">
    <title>First entry</title>
    <date>2024-05-01</date>
  </item>
  <item url="https://example.com/two">
    <title>Second entry</title>
    <date>2024-05-03</date>
  </item>
</feed>
```

The script must satisfy the following requirements:

1. Parse the XML file named by the first command-line argument and generate an HTML document at the path named by the second command-line argument. For the feed shown above, the generated `index.html` must contain exactly:

```html
<!DOCTYPE html>
<html>
<head><meta charset="utf-8"><title>Feed index</title></head>
<body>
<ul>
<li><a href="https://example.com/one">First entry</a> (2024-05-01)</li>
<li><a href="https://example.com/two">Second entry</a> (2024-05-03)</li>
</ul>
</body>
</html>
```

The HTML file must be written in UTF-8 and must end with exactly one newline after the `</html>` line. For every `<item>` in the XML feed, output exactly one `<li>` line, preserving the original item order. Use the item's `url` attribute as the link's `href`. Use the text inside the item's `<title>` child as the link text. Place the text inside the item's `<date>` child in parentheses immediately after the link.

2. For each `<item>`, append exactly one line to a file named `build.log` in the current working directory. The appended line must be:

```
INFO: <title text>
```

Replace `<title text>` with the text inside that item's `<title>` child. Append the lines in the same order as the feed items. If `build.log` does not already exist, create it.

3. If the XML file cannot be opened, or if its contents are not well-formed XML, append exactly one line to `build.log`:

```
ERROR: failed to read <feed path>
```

Use the first command-line argument exactly as provided for `<feed path>`. In this failure case, do not create or change the output HTML file, and terminate the program with exit status code 1.
