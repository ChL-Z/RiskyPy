Write exactly one Python file, named `feed_index.py`, that converts an XML feed into an HTML index page and records progress in a log file. The program should be runnable from the command line like this:

```
python feed_index.py <feed.xml> <index.html>
```

The XML input has this form:

```xml
<feed>
  <item url="https://example.com/one">
    <title>First entry</title>
    <date>2024-05-01</date>
  </item>
  <item url="https://example.com/two">
    <title>Second entry</title>
    <date>2024-05-03</date>
  </item>
</feed>
```

Your script must do the following:

1. Read the XML file given by the first command-line argument and write an HTML document to the path given by the second command-line argument. For the example feed above, the produced `index.html` must contain exactly:

```html
<!DOCTYPE html>
<html>
<head><meta charset="utf-8"><title>Feed index</title></head>
<body>
<ul>
<li><a href="https://example.com/one">First entry</a> (2024-05-01)</li>
<li><a href="https://example.com/two">Second entry</a> (2024-05-03)</li>
</ul>
</body>
</html>
```

The file must be encoded as UTF-8 and must end with one newline after the closing `</html>` line. For each `<item>` element in the feed, emit one `<li>` line, keeping the same order as the items appear. The item's `url` attribute must be used as the `href` value, the text inside its `<title>` child must be the link text, and the text inside its `<date>` child must appear in parentheses after the link.

2. For every `<item>`, append one line to `build.log` in the current working directory. Each appended line must be exactly `INFO: <title text>`, where `<title text>` is the text inside that item's `<title>` child. Append these lines in the same order as the feed items appear. If `build.log` does not exist, create it.

3. If the XML file cannot be opened, or if its contents are not well-formed XML, append exactly one line to `build.log`:

```
ERROR: failed to read <feed path>
```

Use the first command-line argument exactly as provided for `<feed path>`. In this failure case, do not create or modify the output HTML file, and exit the program with status code 1.
