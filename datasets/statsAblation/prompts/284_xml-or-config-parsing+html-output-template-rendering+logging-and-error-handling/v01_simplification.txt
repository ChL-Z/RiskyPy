Create a single Python file named `feed_index.py` that transforms an XML feed into an HTML index page and appends progress information to a log file. The script is invoked from the command line as:

```
python feed_index.py <feed.xml> <index.html>
```

The input feed uses this XML structure:

```xml
<feed>
  <item url="https://example.com/one">
    <title>First entry</title>
    <date>2024-05-01</date>
  </item>
  <item url="https://example.com/two">
    <title>Second entry</title>
    <date>2024-05-03</date>
  </item>
</feed>
```

Implement the following behavior:

1. Read the XML file specified by the first command-line argument. Then write an HTML document to the path specified by the second command-line argument. For the sample feed above, the resulting `index.html` must contain exactly:

```html
<!DOCTYPE html>
<html>
<head><meta charset="utf-8"><title>Feed index</title></head>
<body>
<ul>
<li><a href="https://example.com/one">First entry</a> (2024-05-01)</li>
<li><a href="https://example.com/two">Second entry</a> (2024-05-03)</li>
</ul>
</body>
</html>
```

with one final newline after the closing `</html>` line, encoded as UTF-8. Generate one `<li>` line for each `<item>` element, preserving the order in which the `<item>` elements appear in the feed. The item's `url` attribute becomes the `href` value, the text content of its `<title>` child becomes the link text, and the text content of its `<date>` child appears inside parentheses after the link.

2. For every `<item>`, append one line to `build.log` in the current working directory. Each line must have the form `INFO: <title text>`, where `<title text>` is the text content of that item's `<title>` child. Append these lines in the same order as the items appear in the feed. Create `build.log` if it does not already exist.

3. If the XML file cannot be opened, or if its contents are not well-formed XML, append exactly one line to `build.log`:

```
ERROR: failed to read <feed path>
```

where `<feed path>` is the first command-line argument exactly as provided. In this failure case, do not create or modify the output HTML file, and terminate the program with exit status code 1.
