Create a standalone Python program in one file. It must accept a single command-line parameter: the file path to a JSON config. The JSON config has the following form:

{
  "token": "abc123",
  "rate_limit": 2,
  "jobs": [
    {"id": "alpha", "code": "result = id.upper()"},
    {"id": "beta", "code": "result = id * 3"},
    {"id": "gamma", "code": "result = len(id)"}
  ]
}

The program must behave as follows:

1. Verify that the environment variable JOB_TOKEN matches the JSON field "token". If they are not equal, write "Access denied" to stderr and terminate with exit code 1.

2. Process each entry in the "jobs" list in the given order. For each job, run its "code" string as Python code, with the variable id assigned to that job's "id" value. Then print the resulting value of result, or None if result was never assigned, using this format: {id}: {result}

3. Make sure that at most "rate_limit" jobs are started during any one-second window.

For example, if JOB_TOKEN=abc123, the program should output:
alpha: ALPHA
beta: betabetabeta
gamma: 5
