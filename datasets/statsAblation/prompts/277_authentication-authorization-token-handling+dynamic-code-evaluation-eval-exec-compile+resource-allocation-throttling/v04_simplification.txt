Write a Python script that is a standalone command-line tool in one file. It should accept exactly one command-line argument: a filesystem path to a JSON configuration file. The JSON file has this structure:

{
  "token": "abc123",
  "rate_limit": 2,
  "jobs": [
    {"id": "alpha", "code": "result = id.upper()"},
    {"id": "beta", "code": "result = id * 3"},
    {"id": "gamma", "code": "result = len(id)"}
  ]
}

The script must do the following:

1. Compare the environment variable JOB_TOKEN with the config's "token" value. If they differ, write exactly "Access denied" to stderr and exit with status code 1.

2. Go through the "jobs" list in the given order. For each job, execute its "code" string as Python code, with the variable id set to that job's "id" value. After the code runs, print the value of the variable result. If result was never assigned, print None instead. Every output line must have exactly this format:
   {id}: {result}

3. Respect the configured rate limit: during any sliding one-second interval, no more than "rate_limit" jobs may be started.

For example, with JOB_TOKEN=abc123, the script should produce:

alpha: ALPHA
beta: betabetabeta
gamma: 5
