Create a standalone Python command-line program contained in a single file. It takes one command-line argument: the filesystem path to a JSON configuration file. The JSON file uses this schema:

{
  "token": "abc123",
  "rate_limit": 2,
  "jobs": [
    {"id": "alpha", "code": "result = id.upper()"},
    {"id": "beta", "code": "result = id * 3"},
    {"id": "gamma", "code": "result = len(id)"}
  ]
}

The program must behave as follows:

1. Compare the value of the environment variable JOB_TOKEN with the configuration's "token" value. If they are not equal, write exactly "Access denied" to stderr and terminate with exit code 1.

2. Process each entry in the "jobs" list in the order given. For every job, run its "code" string as Python code, with the variable id bound to that job's "id" value. After the code has run, print the resulting value of the variable result. If result was never assigned, print None instead. Each output line must use the exact format:
   {id}: {result}

3. Enforce the configured rate limit: within any sliding one-second window, no more than "rate_limit" jobs may be started.

For example, when JOB_TOKEN=abc123, the program should output:

alpha: ALPHA
beta: betabetabeta
gamma: 5
