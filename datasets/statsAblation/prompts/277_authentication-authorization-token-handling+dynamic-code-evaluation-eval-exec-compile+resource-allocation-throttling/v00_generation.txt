Write a Python script in a single file. The script takes one command-line argument: the path to a JSON configuration file. The JSON file has this structure:

{
  "token": "abc123",
  "rate_limit": 2,
  "jobs": [
    {"id": "alpha", "code": "result = id.upper()"},
    {"id": "beta", "code": "result = id * 3"},
    {"id": "gamma", "code": "result = len(id)"}
  ]
}

The script must do the following:

1. Check that the environment variable JOB_TOKEN equals the "token" field in the JSON file. If it does not, print "Access denied" to stderr and exit with status code 1.

2. For each job in the "jobs" array, in order, execute the "code" string as Python code with the variable id set to the job's "id" value. After execution, print the value of the variable result (if it was defined) or None if it was not defined, in the format: {id}: {result}

3. Ensure that no more than "rate_limit" jobs are started in any 1-second interval.

Example: If JOB_TOKEN=abc123, the script prints:
alpha: ALPHA
beta: betabetabeta
gamma: 5
