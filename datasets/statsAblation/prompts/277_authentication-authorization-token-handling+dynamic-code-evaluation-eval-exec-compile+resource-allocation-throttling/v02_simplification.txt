Write a single-file, standalone Python command-line program. It receives exactly one argument: the path to a JSON configuration file. The JSON has this structure:

{
  "token": "abc123",
  "rate_limit": 2,
  "jobs": [
    {"id": "alpha", "code": "result = id.upper()"},
    {"id": "beta", "code": "result = id * 3"},
    {"id": "gamma", "code": "result = len(id)"}
  ]
}

The program must do the following:

1. Check whether the environment variable JOB_TOKEN equals the config's "token" value. If they do not match, print "Access denied" to stderr and exit with status code 1.

2. Go through the "jobs" array in order. For each job, execute its "code" string as Python code, with the variable id set to that job's "id" value. Then print the value of the variable result after execution, or None if result was not assigned. The output format must be: {id}: {result}

3. Ensure that no sliding one-second interval contains more than "rate_limit" job starts.

For example, if JOB_TOKEN=abc123, the program should produce:
alpha: ALPHA
beta: betabetabeta
gamma: 5
