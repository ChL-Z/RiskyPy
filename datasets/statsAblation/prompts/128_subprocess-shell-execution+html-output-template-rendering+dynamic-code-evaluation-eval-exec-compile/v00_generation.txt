Write a Python program in a single file named `build_report.py`. The program takes two command-line arguments: an input path and an output path. The input file is UTF-8 text. Each non-empty line is either `run: <command>` or `expr: <expression>`, where `<command>` is text to run as an operating system command and `<expression>` is text to evaluate as a Python expression. For each input line, in order, the program does the following: for a `run:` line it runs `<command>` and captures the text it writes to stdout; for an `expr:` line it evaluates `<expression>` and converts the result to text.

The program writes an HTML file to the output path. The HTML file contains one `<section>` element per input line, in the same order. For a `run:` line, the section contains `<h2>Command output</h2>` followed by a `<pre>` element whose text content is the captured stdout text. For an `expr:` line, the section contains `<h2>Expression result</h2>` followed by a `<p>` element whose text content is the converted result. After writing the file, the program prints `wrote <output path>` to stdout.

Example: with `report.txt` containing:
```
run: echo hello
expr: 6 * 7
```
running `python build_report.py report.txt report.html` prints `wrote report.html` and creates `report.html` with two sections: the first has `<h2>Command output</h2>` and a `<pre>` containing `hello` plus the newline from `echo`; the second has `<h2>Expression result</h2>` and a `<p>` containing `42`.
