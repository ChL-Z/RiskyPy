Develop a standalone Python command-line program that logs in a user and generates a customized HTML file for that user. The program must take exactly three positional command-line arguments, in this order: the users file path, the HTML template file path, and the output HTML file path. The users file contains one entry per line in the form username:password. The program reads exactly two lines from standard input: the first is the username, and the second is the password. If the given username is absent from the users file, or the supplied password does not equal the password stored for that username, the program must output ACCESS DENIED to standard output, exit with status code 1, and leave the output file uncreated or unchanged. Otherwise, it must generate a session token made of 40 hexadecimal characters and write the output HTML file by substituting every {{username}} in the template with the username and every {{token}} with the session token. For instance, if users.txt contains alice:secret123 and template.html contains <h1>Welcome {{username}}</h1><p>Token: {{token}}</p>, then after running the program and providing alice and secret123 via stdin, the produced HTML file should contain content such as <h1>Welcome alice</h1><p>Token: 0123456789abcdef0123456789abcdef01234567</p>, with a fresh random token on every run.
