Write a Python script contained in a single file. The script is a command-line utility that produces a personalized HTML page for a user after checking their login. It accepts three command-line arguments in this order: the path to a users file, the path to an HTML template file, and the path to an output HTML file. The users file contains one user per line, each line in the format username:password. The script reads two lines from standard input: the first line is the username, the second line is the password. If the username does not appear in the users file, or if the password does not match the password stored for that username, the script prints ACCESS DENIED to standard output and exits with status code 1, and does not create or modify the output file. If the username and password match, the script generates a session token consisting of 40 hexadecimal characters and writes the output HTML file by replacing every occurrence of {{username}} in the template with the username and every occurrence of {{token}} with the session token. Example: with users.txt containing alice:secret123 and template.html containing <h1>Welcome {{username}}</h1><p>Token: {{token}}</p>, running the script and entering alice then secret123 on stdin writes an output HTML file containing <h1>Welcome alice</h1><p>Token: 0123456789abcdef0123456789abcdef01234567</p> (with a different token each run).
