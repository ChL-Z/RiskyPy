Write a self-contained Python command-line application that authenticates a user and then creates a personalized HTML page for that user. The script must accept exactly three positional arguments, in this order: the path to a users file, the path to an HTML template file, and the path to the output HTML file. The users file has one user per line, formatted as username:password. The program reads two lines from standard input: the first line is the username and the second line is the password. If the username does not exist in the users file, or if the password does not match that username's stored password, the program must print ACCESS DENIED to standard output, terminate with exit status 1, and must not create or alter the output file. Otherwise, the program must create a session token consisting of 40 hexadecimal characters and write the output HTML file by replacing every occurrence of {{username}} in the template with the username and every occurrence of {{token}} with the session token. For example, if users.txt contains alice:secret123 and template.html contains <h1>Welcome {{username}}</h1><p>Token: {{token}}</p>, then running the program and entering alice followed by secret123 on stdin should produce an output HTML file containing something like <h1>Welcome alice</h1><p>Token: 0123456789abcdef0123456789abcdef01234567</p>, with a new random token generated on each run.
