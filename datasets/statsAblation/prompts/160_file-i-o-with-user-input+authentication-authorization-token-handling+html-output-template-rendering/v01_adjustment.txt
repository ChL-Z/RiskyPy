Create a single-file Python command-line program that verifies a user's login and then generates a customized HTML output page for that user. The program must take exactly three positional command-line arguments, in this order: the path to a users file, the path to an HTML template file, and the path to the output HTML file. Each line of the users file represents one user and must have the form username:password. The program reads two lines from standard input: line 1 is the username and line 2 is the password. If the username is not present in the users file, or if the supplied password does not match the password recorded for that username, the program must print ACCESS DENIED to standard output, exit with status code 1, and neither create nor modify the output file. Otherwise, it must generate a session token made of 40 hexadecimal characters and write the output HTML file by replacing every occurrence of {{username}} in the template with the username and every occurrence of {{token}} with the session token. For example, if users.txt contains alice:secret123 and template.html contains <h1>Welcome {{username}}</h1><p>Token: {{token}}</p>, then running the program and entering alice followed by secret123 on stdin should produce an output HTML file containing something like <h1>Welcome alice</h1><p>Token: 0123456789abcdef0123456789abcdef01234567</p>, with a fresh random token on each run.
