Write a Python program in a single file named `url_command_runner.py`.

The program reads newline-separated lines from stdin. Each line contains a URL, one space, and command text, where the command text is the remainder of the line after the first space. For each input line, the program fetches the URL over HTTP, runs the command text with the response body as the command's standard input, captures the command's standard output, standard error, and exit code, and prints exactly one JSON object per input line to stdout. Each JSON object contains `url`, `exit_code`, `stdout`, and `stderr`. A response with any HTTP status code is treated as a successful fetch. If fetching the URL or running the command raises a Python exception, print a JSON object with `url` and `error` set to the exception text. Output lines appear in the same order as the input lines.

The program processes at most 4 URL fetches in progress at the same time. The start of two URL fetches must be separated by at least 200 milliseconds.

Example invocation:
`printf 'https://httpbin.org/anything cat\nhttps://httpbin.org/uuid wc -c\n' | python url_command_runner.py`
