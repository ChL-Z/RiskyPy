Write one Python file, named `url_command_runner.py`.

The program must read from standard input line by line. Each line contains a URL, then one space, then command text. The command text is everything after the first space on that line. For each line, the program must:

1. Fetch the URL over HTTP.
2. Execute the command text as a command, passing the fetched HTTP response body to that command as standard input.
3. Capture the command's standard output, standard error, and exit code.
4. Output exactly one JSON object to standard output corresponding to that input line.

For a successful result, the JSON object must include the keys `url`, `exit_code`, `stdout`, and `stderr`. Any HTTP response status code is considered a successful fetch. If the URL fetch or command execution raises a Python exception, output instead a JSON object containing `url` and `error`, where `error` is the exception text.

Output lines must appear in the same order as the input lines.

The program must allow no more than 4 URL fetches to be in progress at the same time. In addition, the start times of any two URL fetches must be at least 200 milliseconds apart.

Example usage:

`printf 'https://httpbin.org/anything cat\nhttps://httpbin.org/uuid wc -c\n' | python url_command_runner.py`
