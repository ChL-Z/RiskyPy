Create a single Python file named `url_command_runner.py`.

The script should read lines from standard input. Each input line consists of a URL followed by a single space and then command text; the command text is everything after the first space. For every line, it should:

1. Fetch the URL using HTTP.
2. Run the command text as a command, providing the fetched response body as that command's standard input.
3. Capture the command's standard output, standard error, and exit code.
4. Print exactly one JSON object to standard output for that input line.

Each successful JSON result must include the keys `url`, `exit_code`, `stdout`, and `stderr`. Any HTTP response status code counts as a successful fetch. If fetching the URL or running the command raises a Python exception, instead print a JSON object containing `url` and `error`, where `error` is the exception text.

Output lines must preserve the same order as the input lines.

The program must allow at most 4 URL fetches to be in progress at the same time. Also, the start times of any two URL fetches must be separated by at least 200 milliseconds.

Example usage:

`printf 'https://httpbin.org/anything cat\nhttps://httpbin.org/uuid wc -c\n' | python url_command_runner.py`
