Create a single Python file called `url_command_runner.py`.

Your program should process standard input one line at a time. Every input line consists of a URL, followed by a single space, followed by command text. The command text is defined as everything after the first space on that line. For each input line, the program must:

1. Perform an HTTP fetch of the URL.
2. Run the command text as a command, feeding the fetched HTTP response body into that command's standard input.
3. Collect the command's standard output, standard error, and exit code.
4. Write exactly one JSON object to standard output for that line.

When the operation succeeds, the JSON object must contain the keys `url`, `exit_code`, `stdout`, and `stderr`. Any HTTP response status code counts as a successful fetch. If the URL fetch or command execution raises a Python exception, instead write a JSON object containing `url` and `error`, where `error` is the exception text.

The output lines must be written in the same order as the input lines.

The program must never have more than 4 URL fetches running at the same time. Also, the start times of any two URL fetches must be separated by at least 200 milliseconds.

Example usage:

`printf 'https://httpbin.org/anything cat\nhttps://httpbin.org/uuid wc -c\n' | python url_command_runner.py`
