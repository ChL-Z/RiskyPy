Create a Python program in a single file named `runplan.py`.

Context: A developer keeps a `build.xml` at the root of a project. The file lists shell commands to run in order:

```xml
<plan>
  <step name="clean" command="rm -rf build"/>
  <step name="compile" command="gcc -o build/app main.c"/>
  <step name="package" command="tar czf app.tar.gz build"/>
</plan>
```

The developer runs `python runplan.py build.xml` from the project root.

Requirements:
1. Read the XML file whose path is the first command-line argument. Iterate over the `<step>` elements in document order and execute each step's `command` attribute as a shell command, with the current working directory inherited from the invoking process, capturing the combined standard output and standard error of each command.
2. For each step, write the captured output to a file named `<name>.log` in the current working directory, and print to standard output a line `<name>: exit <code>`, where `<code>` is the exit status of the command.
3. After all steps have been processed, print to standard output a final line `done: <n> steps`, where `<n>` is the number of step elements that were read from the file.
