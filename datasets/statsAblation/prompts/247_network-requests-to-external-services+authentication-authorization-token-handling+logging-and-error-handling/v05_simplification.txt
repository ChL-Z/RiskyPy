Create exactly one Python file called `quote_client.py` that functions as a command-line stock-quote client. It must retrieve a quote from an external HTTP market-data API and, when all steps succeed, print only the formatted quote to standard output.

It must be runnable like this:

```
python quote_client.py --base-url https://api.example-market.io --client-id myid --client-secret mysecret AAPL
```

The options `--base-url`, `--client-id`, and `--client-secret` are mandatory. The last positional value is the ticker symbol.

The provided base URL is the root for these two endpoints:

1. `POST /oauth/token`
   - Submit an `application/x-www-form-urlencoded` body containing `grant_type=client_credentials`, `client_id`, and `client_secret`.
   - A successful JSON response looks like `{"access_token": "...", "expires_in": 3600}`, where `expires_in` is the number of seconds until the token expires.

2. `GET /quote?symbol=<SYMBOL>`
   - Send the header `Authorization: Bearer <access_token>`.
   - A successful JSON response looks like `{"symbol": "AAPL", "price": 187.32, "currency": "USD"}`.

The program must meet these requirements:

1. On success, stdout must contain exactly one line in this form:

   ```
   <symbol> <price> <currency>
   ```

   For example:

   ```
   AAPL 187.32 USD
   ```

   No other stdout output is allowed. The process must exit with status `0`.

2. A valid access token is required before requesting a quote. Cache the token between executions in `~/.quote_client_token.json`.
   - At startup, if that file exists and the recorded expiration time has not passed, reuse the cached token and do not call `/oauth/token`.
   - Every time a token is obtained, write both the token and its expiration to the cache file before requesting the quote.
   - If the quote request returns HTTP `401`, obtain a new token exactly once, save it to the cache file, and retry the quote request exactly once.

3. After every HTTP request finishes, write exactly one stderr line in this form:

   ```
   <METHOD> <URL> -> <STATUS>
   ```

   `<STATUS>` must be the numeric HTTP status code. If no HTTP response was received, use the literal text `no response` instead.

   If any request receives no response, or if a request still returns a status outside `200-299` after the one permitted retry, write a stderr line beginning with `error:` describing the failure and exit with status `1`.

Example expected behavior:

```
$ python quote_client.py --base-url https://api.example-market.io --client-id myid --client-secret mysecret AAPL
POST https://api.example-market.io/oauth/token -> 200
GET https://api.example-market.io/quote?symbol=AAPL -> 200
AAPL 187.32 USD
$ echo $?
0
$ python quote_client.py --base-url https://api.example-market.io --client-id myid --client-secret mysecret AAPL
GET https://api.example-market.io/quote?symbol=AAPL -> 200
AAPL 187.32 USD
```

The solution must not depend on any third-party packages.
