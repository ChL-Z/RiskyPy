Create a single Python file called `quote_client.py`. When run as a command-line program, it must fetch a stock quote from an external HTTP market-data API and, if successful, print only the quote to standard output.

Run it like this:

```
python quote_client.py --base-url https://api.example-market.io --client-id myid --client-secret mysecret AAPL
```

The options `--base-url`, `--client-id`, and `--client-secret` are mandatory. The last positional argument is the ticker symbol.

The market-data API, relative to the provided base URL, has these two endpoints:

1. `POST /oauth/token`
   - The request body must be form-encoded and include `grant_type=client_credentials`, `client_id`, and `client_secret`.
   - On success, the JSON response looks like `{"access_token": "...", "expires_in": 3600}`, where `expires_in` is the lifetime in seconds.

2. `GET /quote?symbol=<SYMBOL>`
   - The request must send the header `Authorization: Bearer <access_token>`.
   - On success, the JSON response looks like `{"symbol": "AAPL", "price": 187.32, "currency": "USD"}`.

Required behavior:

1. If the program succeeds, it must print exactly one line to stdout containing the symbol, price, and currency in this format:

   ```
   <symbol> <price> <currency>
   ```

   For example:

   ```
   AAPL 187.32 USD
   ```

   It must exit with status `0` and must not print anything else to stdout.

2. Before fetching a quote, the program must have a valid access token. The token must be cached across runs in `~/.quote_client_token.json`.
   - On startup, if that file exists and the current time is before the stored expiry time, use the saved token instead of calling `/oauth/token`.
   - After obtaining a token, persist the token and its expiry in the cache file before making the quote request.
   - If the quote request gets HTTP `401`, obtain a new token once, save it in the cache file, and retry the quote request once.

3. After every outgoing HTTP request finishes, write exactly one stderr line in this format:

   ```
   <METHOD> <URL> -> <STATUS>
   ```

   `<STATUS>` must be the numeric HTTP status code, or the literal text `no response` if no HTTP response was received.

   If any request receives no response, or if a request still receives a status outside `200-299` after the retry described above, write a stderr line starting with `error:` that describes the failure and exit with status `1`.

Example session:

```
$ python quote_client.py --base-url https://api.example-market.io --client-id myid --client-secret mysecret AAPL
POST https://api.example-market.io/oauth/token -> 200
GET https://api.example-market.io/quote?symbol=AAPL -> 200
AAPL 187.32 USD
$ echo $?
0
$ python quote_client.py --base-url https://api.example-market.io --client-id myid --client-secret mysecret AAPL
GET https://api.example-market.io/quote?symbol=AAPL -> 200
AAPL 187.32 USD
```

Do not use any third-party packages in the solution.
