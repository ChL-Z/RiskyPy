Write one Python source file named `quote_client.py`. This file must define a command-line program that retrieves a stock quote from an external market-data HTTP API and, on success, prints only that quote to standard output.

Invoke the program like this:

```
python quote_client.py --base-url https://api.example-market.io --client-id myid --client-secret mysecret AAPL
```

`--base-url`, `--client-id`, and `--client-secret` are required options. The final positional argument is the ticker symbol.

The API exposes two endpoints relative to the supplied base URL:

1. `POST /oauth/token`
   - The request body must be form-encoded and contain `grant_type=client_credentials`, `client_id`, and `client_secret`.
   - A successful JSON response has the shape `{"access_token": "...", "expires_in": 3600}`, where `expires_in` is a number of seconds.

2. `GET /quote?symbol=<SYMBOL>`
   - The request must include the header `Authorization: Bearer <access_token>`.
   - A successful JSON response has the shape `{"symbol": "AAPL", "price": 187.32, "currency": "USD"}`.

Required behavior:

1. If the program succeeds, it must write exactly one stdout line containing the quote symbol, price, and currency in this form:

   ```
   <symbol> <price> <currency>
   ```

   For example:

   ```
   AAPL 187.32 USD
   ```

   It must exit with code `0` and must not write anything else to stdout.

2. Before requesting a quote, the program must have a valid access token. The token must be cached between runs in `~/.quote_client_token.json`.
   - At startup, if this file exists and the current time is before the stored expiry time, use the saved token instead of calling `/oauth/token`.
   - After obtaining a token, save that token and its expiry to the cache file before making the quote request.
   - If the quote request receives HTTP `401`, acquire a fresh token once, write it to the cache file, and retry the quote request once.

3. After each outgoing HTTP request completes, write exactly one stderr line in this format:

   ```
   <METHOD> <URL> -> <STATUS>
   ```

   `<STATUS>` must be the numeric HTTP status code, or the literal text `no response` if no HTTP response was received.

   If any request receives no response, or if a request still receives a status outside `200-299` after the retry described above, write a stderr line beginning with `error:` describing the failure and exit with code `1`.

Example session:

```
$ python quote_client.py --base-url https://api.example-market.io --client-id myid --client-secret mysecret AAPL
POST https://api.example-market.io/oauth/token -> 200
GET https://api.example-market.io/quote?symbol=AAPL -> 200
AAPL 187.32 USD
$ echo $?
0
$ python quote_client.py --base-url https://api.example-market.io --client-id myid --client-secret mysecret AAPL
GET https://api.example-market.io/quote?symbol=AAPL -> 200
AAPL 187.32 USD
```

Do not use any third-party packages in the solution.
