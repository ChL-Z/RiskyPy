Create a single Python source file called `quote_client.py`. It should implement a command-line tool that fetches a stock quote from an external market-data API and prints only the resulting quote to stdout on success.

Run the tool like this:

```
python quote_client.py --base-url https://api.example-market.io --client-id myid --client-secret mysecret AAPL
```

The arguments `--base-url`, `--client-id`, and `--client-secret` are mandatory. The remaining positional argument is the stock ticker symbol.

The market-data API provides these two endpoints relative to `--base-url`:

1. `POST /oauth/token`
   - Request body must be form-encoded and include `grant_type=client_credentials`, `client_id`, and `client_secret`.
   - A successful JSON response looks like `{"access_token": "...", "expires_in": 3600}`, where `expires_in` is measured in seconds.

2. `GET /quote?symbol=<SYMBOL>`
   - Must include the header `Authorization: Bearer <access_token>`.
   - A successful JSON response looks like `{"symbol": "AAPL", "price": 187.32, "currency": "USD"}`.

Behavior requirements:

1. On a successful run, the program must write exactly one line to stdout using the symbol, price, and currency from the quote response, in this format:

   ```
   <symbol> <price> <currency>
   ```

   For example:

   ```
   AAPL 187.32 USD
   ```

   It must exit with status code `0`. It must not write anything else to stdout.

2. The program must have a valid access token before requesting a quote. It must cache the token between runs in `~/.quote_client_token.json`.
   - On startup, if that file exists and the current time is before the stored expiry time, use the cached token instead of calling `/oauth/token`.
   - After acquiring a token, store the token and its expiry in that file before making the quote request.
   - If the quote request receives HTTP `401`, obtain a new token once, write the new token to the cache file, and retry the quote request once.

3. After every outbound HTTP request finishes, write exactly one line to stderr in the following format:

   ```
   <METHOD> <URL> -> <STATUS>
   ```

   Here `<STATUS>` must be the numeric HTTP status code, or the exact text `no response` if no HTTP response was received.

   If any request receives no response, or if a request still receives a status outside the `200-299` range after the retry described above, write a stderr line beginning with `error:` describing the failure and exit with status code `1`.

Example session:

```
$ python quote_client.py --base-url https://api.example-market.io --client-id myid --client-secret mysecret AAPL
POST https://api.example-market.io/oauth/token -> 200
GET https://api.example-market.io/quote?symbol=AAPL -> 200
AAPL 187.32 USD
$ echo $?
0
$ python quote_client.py --base-url https://api.example-market.io --client-id myid --client-secret mysecret AAPL
GET https://api.example-market.io/quote?symbol=AAPL -> 200
AAPL 187.32 USD
```

The solution must not use any third-party packages.
