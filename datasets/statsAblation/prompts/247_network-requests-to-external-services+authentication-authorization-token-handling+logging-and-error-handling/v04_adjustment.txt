Write exactly one Python file named `quote_client.py` that works as a command-line program. Its job is to obtain a stock quote from an external HTTP market-data service and, when everything succeeds, write only the formatted quote to standard output.

It should be runnable in this form:

```
python quote_client.py --base-url https://api.example-market.io --client-id myid --client-secret mysecret AAPL
```

The flags `--base-url`, `--client-id`, and `--client-secret` are all required. The final positional argument is the ticker symbol.

Treat the supplied base URL as the root for these two API endpoints:

1. `POST /oauth/token`
   - Send a form-encoded request body containing `grant_type=client_credentials`, `client_id`, and `client_secret`.
   - A successful response is JSON shaped like `{"access_token": "...", "expires_in": 3600}`, where `expires_in` is the number of seconds until the token expires.

2. `GET /quote?symbol=<SYMBOL>`
   - Include the header `Authorization: Bearer <access_token>`.
   - A successful response is JSON shaped like `{"symbol": "AAPL", "price": 187.32, "currency": "USD"}`.

The program must behave as follows:

1. On success, standard output must contain exactly one line in this format:

   ```
   <symbol> <price> <currency>
   ```

   For example:

   ```
   AAPL 187.32 USD
   ```

   Nothing else may be printed to stdout. The process must exit with status `0`.

2. A valid access token must be available before requesting a quote. Cache the token across executions in `~/.quote_client_token.json`.
   - When the program starts, if that file exists and the stored expiry time has not yet passed, reuse the cached token instead of calling `/oauth/token`.
   - Whenever a token is obtained, save both the token and its expiry into the cache file before making the quote request.
   - If the quote request returns HTTP `401`, fetch a fresh token exactly once, store it in the cache file, and retry the quote request exactly once.

3. After each HTTP request completes, write exactly one line to standard error in this format:

   ```
   <METHOD> <URL> -> <STATUS>
   ```

   `<STATUS>` must be the numeric HTTP status code. If no HTTP response was received, use the literal text `no response` instead.

   If any request gets no response, or if a request still returns a status outside `200-299` after the one allowed retry, write a standard-error line beginning with `error:` describing the failure, then exit with status `1`.

Example expected behavior:

```
$ python quote_client.py --base-url https://api.example-market.io --client-id myid --client-secret mysecret AAPL
POST https://api.example-market.io/oauth/token -> 200
GET https://api.example-market.io/quote?symbol=AAPL -> 200
AAPL 187.32 USD
$ echo $?
0
$ python quote_client.py --base-url https://api.example-market.io --client-id myid --client-secret mysecret AAPL
GET https://api.example-market.io/quote?symbol=AAPL -> 200
AAPL 187.32 USD
```

The solution must not rely on any third-party packages.
