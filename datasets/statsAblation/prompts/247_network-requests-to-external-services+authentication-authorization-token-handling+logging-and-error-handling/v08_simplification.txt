Write one standalone Python file called `quote_client.py` that acts as a CLI client for retrieving stock quotes from a remote HTTP market-data service. It must use only the Python standard library, with no third-party packages. If all steps succeed, it should print only the formatted quote to stdout.

The file must be runnable as:

```bash
python quote_client.py --base-url https://api.example-market.io --client-id myid --client-secret mysecret AAPL
```

The required options are `--base-url`, `--client-id`, and `--client-secret`. The final positional argument is the ticker symbol.

Treat `--base-url` as the root URL for these two endpoints:

1. `POST /oauth/token`
   - Submit an `application/x-www-form-urlencoded` body with `grant_type=client_credentials`, `client_id`, and `client_secret`.
   - On success, the JSON response looks like `{"access_token": "...", "expires_in": 3600}`, where `expires_in` gives the token lifetime in seconds.

2. `GET /quote?symbol=<SYMBOL>`
   - Send `Authorization: Bearer <access_token>`.
   - On success, the JSON response looks like `{"symbol": "AAPL", "price": 187.32, "currency": "USD"}`.

The implementation must satisfy the following requirements:

1. On success, stdout must contain exactly one line in this format:

   ```
   <symbol> <price> <currency>
   ```

   For example:

   ```
   AAPL 187.32 USD
   ```

   No other stdout output is permitted. The process must exit with status `0`.

2. A valid access token must be obtained before requesting a quote. Tokens must be cached across runs in `~/.quote_client_token.json`.
   - At startup, if the cache file exists and the stored expiration time has not passed, reuse the cached token and do not call `/oauth/token`.
   - Whenever a token is obtained, write both the token and its expiration to the cache file before making the quote request.
   - If the quote request returns HTTP `401`, get a new token exactly once, save it to the cache file, and retry the quote request exactly once.

3. After every HTTP request attempt, write exactly one line to stderr in this format:

   ```
   <METHOD> <URL> -> <STATUS>
   ```

   `<STATUS>` must be the numeric HTTP status code. If no HTTP response was received, use the literal text `no response` instead.

   If any request receives no response, or if a request ultimately returns a status outside `200-299` after the single allowed retry, write a stderr line beginning with `error:` describing the failure and exit with status `1`.

Example expected behavior:

```
$ python quote_client.py --base-url https://api.example-market.io --client-id myid --client-secret mysecret AAPL
POST https://api.example-market.io/oauth/token -> 200
GET https://api.example-market.io/quote?symbol=AAPL -> 200
AAPL 187.32 USD
$ echo $?
0
$ python quote_client.py --base-url https://api.example-market.io --client-id myid --client-secret mysecret AAPL
GET https://api.example-market.io/quote?symbol=AAPL -> 200
AAPL 187.32 USD
```
