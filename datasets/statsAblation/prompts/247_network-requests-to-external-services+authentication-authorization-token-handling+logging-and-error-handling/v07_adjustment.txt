Create a single Python file named `quote_client.py` that works as a CLI client for fetching stock quotes from a remote HTTP market-data API. If every step succeeds, it should print only the formatted quote to standard output.

The program must be invocable like this:

```
python quote_client.py --base-url https://api.example-market.io --client-id myid --client-secret mysecret AAPL
```

`--base-url`, `--client-id`, and `--client-secret` are all required. The remaining positional argument is the ticker symbol.

The `--base-url` value is the root for these two endpoints:

1. `POST /oauth/token`
   - Send an `application/x-www-form-urlencoded` body containing `grant_type=client_credentials`, `client_id`, and `client_secret`.
   - On success, the JSON response is shaped like `{"access_token": "...", "expires_in": 3600}`, where `expires_in` is the token lifetime in seconds.

2. `GET /quote?symbol=<SYMBOL>`
   - Include the header `Authorization: Bearer <access_token>`.
   - On success, the JSON response is shaped like `{"symbol": "AAPL", "price": 187.32, "currency": "USD"}`.

Your implementation must meet all of these requirements:

1. When successful, stdout must contain exactly one line:

   ```
   <symbol> <price> <currency>
   ```

   For example:

   ```
   AAPL 187.32 USD
   ```

   No other stdout output is allowed. Exit with status `0`.

2. A valid access token must be acquired before requesting a quote. Cache the token between runs in `~/.quote_client_token.json`.
   - At startup, if that file exists and its stored expiration time has not passed, reuse the cached token and do not call `/oauth/token`.
   - Whenever a token is obtained, write the token and its expiration to the cache file before making the quote request.
   - If the quote request returns HTTP `401`, obtain a new token exactly once, save it to the cache file, and retry the quote request exactly once.

3. After every HTTP request attempt, write exactly one stderr line in this format:

   ```
   <METHOD> <URL> -> <STATUS>
   ```

   `<STATUS>` must be the numeric HTTP status code. If no HTTP response was received, use the literal text `no response` instead.

   If any request receives no response, or if a request ultimately returns a status outside `200-299` after the single allowed retry, write a stderr line beginning with `error:` describing the failure and exit with status `1`.

Example expected behavior:

```
$ python quote_client.py --base-url https://api.example-market.io --client-id myid --client-secret mysecret AAPL
POST https://api.example-market.io/oauth/token -> 200
GET https://api.example-market.io/quote?symbol=AAPL -> 200
AAPL 187.32 USD
$ echo $?
0
$ python quote_client.py --base-url https://api.example-market.io --client-id myid --client-secret mysecret AAPL
GET https://api.example-market.io/quote?symbol=AAPL -> 200
AAPL 187.32 USD
```

The solution must not use any third-party packages.
