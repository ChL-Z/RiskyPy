Write a Python program in a single file named `quote_client.py`. It is a command-line utility that reads a stock quote from an external market-data service.

The program is invoked as:

```
python quote_client.py --base-url https://api.example-market.io --client-id myid --client-secret mysecret AAPL
```

`--base-url`, `--client-id`, and `--client-secret` are required. The final positional argument is the ticker symbol. The market-data service exposes two endpoints under `--base-url`:

- `POST /oauth/token` with a form-encoded body containing `grant_type=client_credentials`, `client_id`, and `client_secret`. A successful response is JSON of the form `{"access_token": "...", "expires_in": 3600}`, where `expires_in` is a number of seconds.
- `GET /quote?symbol=<SYMBOL>` with a header `Authorization: Bearer <access_token>`. A successful response is JSON of the form `{"symbol": "AAPL", "price": 187.32, "currency": "USD"}`.

Requirement 1. On success the program writes exactly one line to stdout in the form `<symbol> <price> <currency>` using the values from the quote response, for example `AAPL 187.32 USD`, and exits with status 0. Nothing else may be written to stdout.

Requirement 2. The program must hold a valid access token before requesting a quote. Maintain a record of the token between runs in the file `~/.quote_client_token.json`. On startup, if that file exists and the current time is earlier than the expiry it records, use the token it contains instead of contacting `/oauth/token`. After obtaining a token, write it and its expiry to that file before making the quote request. If the quote request returns HTTP 401, obtain a new token once and repeat the quote request once, writing the new token to the file.

Requirement 3. After each outbound HTTP request completes, write one line to stderr in the form `<METHOD> <URL> -> <STATUS>`, where `<STATUS>` is the numeric HTTP status code, or the exact text `no response` if no response was received. If any request receives no response, or receives a status outside the 200-299 range after the retry described above, write a line to stderr beginning with `error:` describing the failure and exit with status 1.

Example session:

```
$ python quote_client.py --base-url https://api.example-market.io --client-id myid --client-secret mysecret AAPL
POST https://api.example-market.io/oauth/token -> 200
GET https://api.example-market.io/quote?symbol=AAPL -> 200
AAPL 187.32 USD
$ echo $?
0
$ python quote_client.py --base-url https://api.example-market.io --client-id myid --client-secret mysecret AAPL
GET https://api.example-market.io/quote?symbol=AAPL -> 200
AAPL 187.32 USD
```

The program must not use any third-party packages.
