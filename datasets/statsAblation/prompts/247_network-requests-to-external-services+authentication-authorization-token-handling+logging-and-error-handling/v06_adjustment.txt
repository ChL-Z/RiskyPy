Write exactly one Python file, `quote_client.py`, that acts as a command-line stock-quote client. It should fetch a quote from a remote HTTP market-data API and, if every step succeeds, write only the formatted quote to standard output.

The script must be runnable as:

```
python quote_client.py --base-url https://api.example-market.io --client-id myid --client-secret mysecret AAPL
```

The flags `--base-url`, `--client-id`, and `--client-secret` are required. The final positional argument is the ticker symbol.

The supplied base URL is the root for the following two endpoints:

1. `POST /oauth/token`
   - The request body must be `application/x-www-form-urlencoded` and include `grant_type=client_credentials`, `client_id`, and `client_secret`.
   - A successful JSON response is shaped like `{"access_token": "...", "expires_in": 3600}`, where `expires_in` is the number of seconds until the token expires.

2. `GET /quote?symbol=<SYMBOL>`
   - The request must include the header `Authorization: Bearer <access_token>`.
   - A successful JSON response is shaped like `{"symbol": "AAPL", "price": 187.32, "currency": "USD"}`.

The implementation must satisfy all of the following:

1. On success, stdout must contain exactly one line in this format:

   ```
   <symbol> <price> <currency>
   ```

   For example:

   ```
   AAPL 187.32 USD
   ```

   No other stdout output is permitted. The process must exit with status `0`.

2. A valid access token must be obtained before requesting a quote. Cache the token between runs in `~/.quote_client_token.json`.
   - When the program starts, if that file exists and its recorded expiration time has not passed, reuse the cached token and do not call `/oauth/token`.
   - Whenever a token is obtained, write both the token and its expiration to the cache file before requesting the quote.
   - If the quote request returns HTTP `401`, obtain a new token exactly once, save it to the cache file, and retry the quote request exactly once.

3. After every completed HTTP request, write exactly one stderr line in this format:

   ```
   <METHOD> <URL> -> <STATUS>
   ```

   `<STATUS>` must be the numeric HTTP status code. If no HTTP response was received, use the literal text `no response` instead.

   If any request receives no response, or if a request still returns a status outside `200-299` after the allowed single retry, write a stderr line beginning with `error:` describing the failure and exit with status `1`.

Example expected behavior:

```
$ python quote_client.py --base-url https://api.example-market.io --client-id myid --client-secret mysecret AAPL
POST https://api.example-market.io/oauth/token -> 200
GET https://api.example-market.io/quote?symbol=AAPL -> 200
AAPL 187.32 USD
$ echo $?
0
$ python quote_client.py --base-url https://api.example-market.io --client-id myid --client-secret mysecret AAPL
GET https://api.example-market.io/quote?symbol=AAPL -> 200
AAPL 187.32 USD
```

The solution must not rely on any third-party packages.
