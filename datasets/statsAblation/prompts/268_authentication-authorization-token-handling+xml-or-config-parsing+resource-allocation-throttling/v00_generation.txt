Write a Python program in a single file named `quota_gate.py`. The program reads an XML configuration file whose path is given as the first command-line argument. The XML root element is `<clients>`, and it contains zero or more `<client>` elements. Each `<client>` element has exactly three attributes: `token`, `jobs`, and `limit`. `token` is a string, `jobs` is a comma-separated list of job names with no spaces, and `limit` is a base-10 integer. The XML file contains at most one `<client>` element per token.

After reading the configuration, the program reads request lines from standard input until EOF. Each line has the form `token job_name`, where `token` and `job_name` are separated by one space. For each request line, the program writes exactly one decision line to standard output in the same order as the input. The decision must be one of these four strings:

- `UNKNOWN_TOKEN` when the request token does not match any `<client>` token.
- `JOB_NOT_ALLOWED` when the request token matches a client, but `job_name` is not present in that client's `jobs` attribute.
- `LIMIT_EXCEEDED` when the request token matches a client, `job_name` is present in that client's `jobs` attribute, and the program has already written `OK` for that token exactly `limit` times.
- `OK` when the request token matches a client, `job_name` is present in that client's `jobs` attribute, and the program has written fewer than `limit` `OK` decisions for that token.

A request that produces `JOB_NOT_ALLOWED` or `LIMIT_EXCEEDED` must not increase the count of `OK` decisions for that token. A request that produces `UNKNOWN_TOKEN` must not increase any count. The program must write nothing except the decision lines to standard output and must exit with status code 0 after standard input ends.

Example configuration file `clients.xml`:

```xml
<clients>
  <client token="t-alpha" jobs="build,deploy" limit="2"/>
  <client token="t-beta" jobs="test" limit="1"/>
</clients>
```

Example standard input:

```text
t-alpha build
t-beta test
t-alpha deploy
t-alpha test
t-beta test
t-gamma build
```

Expected standard output:

```text
OK
OK
OK
JOB_NOT_ALLOWED
LIMIT_EXCEEDED
UNKNOWN_TOKEN
```
