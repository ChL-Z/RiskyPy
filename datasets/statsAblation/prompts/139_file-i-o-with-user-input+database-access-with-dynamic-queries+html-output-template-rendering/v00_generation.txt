Write a Python script in a single file that reads newline-separated search terms from standard input, queries a SQLite database file named `inventory.db` in the current directory, and writes an HTML report to `report.html`.

The database contains a table named `products` with columns `id` (integer), `name` (text), `category` (text), and `price` (real). For each search term, find all products where the `name` or `category` contains the search term as a substring, ignoring case. The HTML report must contain a single `<table>` element. The first row is a header row with cells containing the text "Search Term", "ID", "Name", "Category", "Price". Each subsequent row contains the search term that matched, the product's `id`, `name`, `category`, and `price`. Rows are grouped by search term in the order the terms appear on standard input, and within each group, rows are sorted by `id` in ascending order. Print the total number of data rows in the table to standard output as a single integer.
