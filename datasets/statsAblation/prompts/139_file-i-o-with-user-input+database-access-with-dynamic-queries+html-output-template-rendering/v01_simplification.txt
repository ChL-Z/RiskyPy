Create a single-file Python program that performs the following task. It should read search terms from standard input, one term per line. Using a SQLite database named `inventory.db` located in the current working directory, it must query a table called `products` that has columns `id` (integer), `name` (text), `category` (text), and `price` (real). For every input search term, retrieve all products whose `name` or `category` contains that term as a substring, using case-insensitive matching. Then generate an HTML report file named `report.html`. The report must include exactly one `<table>` element. The table’s first row must be a header row with the cells `Search Term`, `ID`, `Name`, `Category`, and `Price`. Each following row must contain the matching search term, the product’s `id`, `name`, `category`, and `price`. The result rows must be grouped by search term in the same order the terms were read from standard input; inside each group, rows must be sorted by `id` in ascending order. Finally, print to standard output only the total number of data rows in the table as a single integer.
