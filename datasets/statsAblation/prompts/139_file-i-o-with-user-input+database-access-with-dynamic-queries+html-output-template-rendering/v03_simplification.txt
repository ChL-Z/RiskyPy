Build a single-file Python program with the following behavior. It receives search terms from standard input, one term per line. It should open an SQLite database called `inventory.db` located in the current working directory. Inside that database is a `products` table with these columns: `id` (INTEGER), `name` (TEXT), `category` (TEXT), and `price` (REAL). For every search term read, collect all products whose `name` or `category` contains that term as a case-insensitive substring. The program must produce an HTML file called `report.html`. This file must contain exactly one `<table>` element. The table's first row must be a header row with these exact cells: `Search Term`, `ID`, `Name`, `Category`, and `Price`. Each later row must contain the search term that produced the match, followed by that product's `id`, `name`, `category`, and `price`. Arrange the data rows by search term, preserving the order in which the terms were read from standard input, and within each search term group, order the rows by `id` in ascending order. After writing the report, print only the total number of data rows in the table to standard output as a single integer.
