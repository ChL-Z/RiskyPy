Write a one-file Python script that does the following. It should read search queries from standard input, with one query per line. Connect to an SQLite database file named `inventory.db` in the current working directory. This database contains a table called `products` with columns `id` (INTEGER), `name` (TEXT), `category` (TEXT), and `price` (REAL). For each input query, find all products where the query string appears as a case-insensitive substring in either the `name` or `category` column. Then create an HTML report file named `report.html`. The report must contain exactly one `<table>` element. The first row of this table must be a header row with the cells: `Search Term`, `ID`, `Name`, `Category`, and `Price`. Every subsequent row must contain the matching search term, followed by the product's `id`, `name`, `category`, and `price`. The data rows must be grouped by search term in the same order the terms were read from standard input, and within each group the rows must be sorted by `id` in ascending order. Finally, print to standard output only the total number of data rows in the table as a single integer.
