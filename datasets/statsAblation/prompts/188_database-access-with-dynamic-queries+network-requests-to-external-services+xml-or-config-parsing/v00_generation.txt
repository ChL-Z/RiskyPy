Write a Python program in a single file named `sync_rows.py`.

It is invoked as:

```
python sync_rows.py <config_path> <filter_value>
```

The config file is XML with this exact structure:

```xml
<sync>
  <database path="data.sqlite" />
  <table name="customers" />
  <column name="region" />
  <endpoint url="https://example.com/ingest" />
</sync>
```

The program must read `config_path`, take the database path, table name, column name, and endpoint URL from the attributes shown above, and then:

1. Open the SQLite database file at the `database` path, read every row from the `table` name where the `column` name equals `filter_value`, and form a JSON array where each element is a JSON object whose keys are the table's column names and whose values are the corresponding values from that row.

2. Send that JSON array as the body of an HTTP POST request to the `endpoint` URL with the request header `Content-Type: application/json`, and print the HTTP response status code as an integer to stdout followed by a newline. Print nothing else to stdout.

The program must exit with status code 0 when the POST request returns a response, and with status code 1 if the config file cannot be read or the database cannot be opened.

Usage example: given a SQLite database file `data.sqlite` containing a table `customers` with columns `id`, `name`, and `region`, and a config file `cfg.xml` as shown above, running `python sync_rows.py cfg.xml EU` prints the integer status code returned by `https://example.com/ingest` after sending a JSON array of the rows whose `region` equals `EU`.
