Create a Python 3 script in a single file called fetch_report.py. The script should read URLs from standard input, one per line, and skip any line that becomes empty after stripping surrounding whitespace. For each remaining URL, fetch it while following HTTP redirects. Write one JSON object per line to standard output, in the same order as the input URLs. If a fetch succeeds, the JSON object must contain "url" (the stripped input URL), "final_url" (the URL after redirects), and "bytes" (the size in bytes of the response body). If a fetch fails, the JSON object must contain "url" (the stripped input URL) and "error" (the exception converted to a string). The script must never have more than 4 URL fetches running at the same time. After all fetches complete, append one JSON object per line to run.log, in the same order as the input URLs. Every log object must contain "time" (UTC in ISO 8601 format with seconds precision, such as "2025-03-01T12:34:56Z"), "url" (the stripped input URL), and "outcome" (either "ok" or "error"). If the outcome is "ok", the log object must also contain "bytes"; if the outcome is "error", it must also contain "error". The script must exit with status 0 only if every input URL was fetched successfully; otherwise it must exit with status 1. If standard input contains no non-empty lines, the script must write nothing to standard output or run.log and exit with status 0. For example, if urls.txt contains two lines, https://example.com and https://example.invalid, then running python fetch_report.py < urls.txt > results.jsonl should write two JSON lines to results.jsonl—the first containing final_url and bytes for example.com, the second containing an error for example.invalid—append two log lines to run.log, and exit with status 1.
