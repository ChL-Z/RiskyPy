Write a Python 3 program in a single file named fetch_report.py. The program reads newline-separated URLs from stdin, ignoring lines that are empty after stripping whitespace. It retrieves each URL, following HTTP redirects, and writes one JSON object per line to stdout in the same order as the input. For a successful retrieval, the JSON object has keys "url" (the input URL string after stripping whitespace), "final_url" (the URL after redirects), and "bytes" (the number of bytes in the response body). For a failed retrieval, the JSON object has keys "url" (the input URL string after stripping whitespace) and "error" (the string form of the exception). The program must never have more than 4 URL retrievals in progress at the same time. After all retrievals finish, the program appends one JSON object per line to run.log in the same order as the input; every log object has keys "time" (UTC ISO 8601 with seconds precision, such as "2025-03-01T12:34:56Z"), "url" (the input URL string after stripping whitespace), and "outcome" ("ok" or "error"). If outcome is "ok", the log object also has "bytes"; if outcome is "error", the log object also has "error". The program exits with status 0 if every input URL was retrieved successfully; otherwise it exits with status 1. If stdin contains no non-empty lines, the program writes nothing to stdout or run.log and exits with status 0. Example: with urls.txt containing two lines, https://example.com and https://example.invalid, running python fetch_report.py < urls.txt > results.jsonl writes two JSON lines to results.jsonl, the first with final_url and bytes for example.com, the second with an error for example.invalid, appends two log lines to run.log, and exits with status 1.
