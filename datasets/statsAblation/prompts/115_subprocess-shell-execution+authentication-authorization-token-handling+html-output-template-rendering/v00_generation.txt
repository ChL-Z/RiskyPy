Write a Python program in a single file named `audit_report.py`.

The program reads `jobs.txt` and `users.txt` from the current directory. Each non-empty line of `jobs.txt` has the form `<token> <command>`, where `<token>` is a sequence of 16 characters from `0-9a-f` and `<command>` is the remainder of the line after the single space that follows the token. Each non-empty line of `users.txt` has the form `<token> <display name>`, where `<display name>` is the remainder of the line after the single space that follows the token.

The program executes each `<command>` string as a command line and captures its exit status and the combined standard output and standard error. It then writes `report.html`, an HTML document containing one `<section>` element per line of `jobs.txt`, in the same order. Each `<section>` contains the display name associated with that line's token (or the text `unknown` if the token does not appear in `users.txt`), the command text, the exit status, and the captured output inside a `<pre>` element. The program exits with status 0 after writing `report.html`.

Usage example: with `jobs.txt` containing `a1b2c3d4e5f60718 echo hello` and `users.txt` containing `a1b2c3d4e5f60718 alice`, running `python audit_report.py` writes `report.html` with a section showing `alice`, `echo hello`, exit status `0`, and `hello`.
