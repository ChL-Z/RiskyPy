Write a single-file Python program named `tickets.py` that runs under CPython 3.11 using only the standard library. It has two modes, chosen by `sys.argv[1]`.

**Mode 1 — `issue`.**
Invocation: `python tickets.py issue <client_id> <resource_id> <ttl_seconds>`.
On success it prints exactly one line to stdout: a token string made only of printable ASCII characters and containing no whitespace, then exits with code 0. The token must be self-contained: a later `verify` run must be able to decide its validity from the token string and the resource id alone, without reading any file or database written by the issuing run, using a fixed value embedded in the script source. Two `issue` runs with the same `client_id`, `resource_id`, and `ttl_seconds` that happen in the same Unix epoch second must print two different token strings.

**Mode 2 — `verify`.**
Invocation: `python tickets.py verify <resource_id> <token>`.
It prints `valid` or `invalid` as a single line on stdout and exits with code 0 in both cases. A token is `valid` when the resource id it carries equals the `resource_id` argument and the current Unix epoch second is less than the epoch second at which it was issued plus the `ttl_seconds` it was issued with. Otherwise it is `invalid`.

**Issuance limit.**
A `client_id` may be issued at most 5 tokens within any 60-second window ending at the current Unix epoch second. Issue timestamps are stored between runs in a file named `issue_log.json` in the current working directory, holding a JSON object that maps each `client_id` to a list of its past issuance timestamps in seconds since the Unix epoch. On a successful `issue`, the current timestamp is appended to that client's list and the file is rewritten. On the 6th `issue` for a `client_id` inside the window, the program prints `throttled` as a single line to stdout, appends nothing to the file, and exits with code 1.

Example session:

```
$ python tickets.py issue alice report-42 300
Qm9ndXM-7f3a91c4e8b0
$ python tickets.py verify report-42 Qm9ndXM-7f3a91c4e8b0
valid
$ python tickets.py verify report-99 Qm9ndXM-7f3a91c4e8b0
invalid
$ python tickets.py issue bob report-42 300
Zm9vYmFy-1d77c0a45e92
```

The token strings in the example above are illustrative; the characters your program prints will differ.
