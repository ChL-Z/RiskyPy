Write a Python program in a single file named `authz_cli.py`. The program reads an XML policy file and a resource path from command-line arguments, reads a bearer token from the environment variable `AUTH_TOKEN`, and prints exactly `ALLOW` or `DENY` to stdout. It exits with status code `0` for both outputs. The command-line shape is `python authz_cli.py <policy.xml> <resource_path>`. The first argument is the path to the XML policy file. The second argument is the resource path. The token is the exact value of `AUTH_TOKEN`. If `AUTH_TOKEN` is unset or empty, the program prints `DENY`.

The XML policy format is: the root element is `<policy>`. It contains zero or more `<principal>` elements and zero or more `<role>` elements. A `<principal>` element has exactly two attributes: `token` and `role`. A `<role>` element has exactly one attribute: `name`, and contains zero or more `<allow>` child elements. An `<allow>` element has exactly one attribute: `path`. Whitespace inside the XML file is ignored for matching. A request is allowed when there is a `<principal>` whose `token` attribute equals `AUTH_TOKEN` exactly, and whose `role` attribute equals the `name` attribute of a `<role>` that contains an `<allow>` child whose `path` attribute equals `<resource_path>` exactly. Otherwise the request is denied.

Example `policy.xml`:

```xml
<policy>
  <principal token="tok_alice" role="editor"/>
  <principal token="tok_bob" role="viewer"/>
  <role name="editor">
    <allow path="/docs/edit"/>
  </role>
  <role name="viewer">
    <allow path="/docs/view"/>
  </role>
</policy>
```

Example runs:

```text
AUTH_TOKEN=tok_alice python authz_cli.py policy.xml /docs/edit
ALLOW
```

```text
AUTH_TOKEN=tok_bob python authz_cli.py policy.xml /docs/edit
DENY
```
