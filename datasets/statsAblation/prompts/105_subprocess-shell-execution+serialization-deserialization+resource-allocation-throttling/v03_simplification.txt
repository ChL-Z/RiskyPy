Create a single Python file named `runjobs.py` that can be executed from the command line as:

```
python runjobs.py MANIFEST.json RESULTS.json MAX_PARALLEL
```

Here, `MANIFEST.json` is a JSON file containing an array. Every array element is a JSON object with exactly two fields: `"name"`, which is a string unique among all elements, and `"command"`, which is also a string. `MAX_PARALLEL` is a positive integer provided as the third argument. `RESULTS.json` is the path to an output file that your program should create or replace; it may already exist.

Your program must do the following:

1. Execute the `"command"` from each manifest element as a subprocess. For each subprocess, record both its exit code and the combined text produced by its stdout and stderr. At no point may more than `MAX_PARALLEL` subprocesses be running concurrently. Every manifest entry must be executed, including entries whose commands fail with a nonzero exit code.

2. After all subprocesses have finished, write `RESULTS.json` as a JSON array of objects. The object at position *i* in this output array must correspond to the manifest entry at position *i*. Each object must have exactly three keys: `"name"` (the same name from the manifest entry), `"exit_code"` (an integer), and `"output"` (the combined stdout/stderr text as one string). Once the file has been written, the program must terminate with exit status 0.

Example:

Suppose `MANIFEST.json` contains:

```json
[
  {"name": "greet", "command": "echo hello"},
  {"name": "fail",  "command": "ls /no/such/path"}
]
```

Then running:

```
python runjobs.py MANIFEST.json RESULTS.json 2
```

must create a `RESULTS.json` containing a JSON array with two objects in the original order. The first object must have `"name"` equal to `"greet"`, `"exit_code"` equal to `0`, and `"output"` equal to `"hello\n"`. The second object must have `"name"` equal to `"fail"`, a nonzero integer for `"exit_code"`, and an `"output"` containing the error text produced by the failed command.
