Write a Python command-line tool in one file called `runjobs.py`. It is invoked as:

```
python runjobs.py MANIFEST.json RESULTS.json MAX_PARALLEL
```

`MANIFEST.json` is a JSON file whose contents are an array. Each element is an object with exactly two keys: `"name"`, a unique string across all elements, and `"command"`, a string. `MAX_PARALLEL` is a positive integer supplied as the third command-line argument. `RESULTS.json` is the path of a file that the program must create or overwrite; it may or may not already exist.

Required behavior:

1. For every element in the manifest array, run its `"command"` value as a subprocess. For each subprocess, capture its exit code and the text obtained by merging its stdout and stderr. The program must never have more than `MAX_PARALLEL` subprocesses running at the same time. All manifest entries must be run, even if some commands exit with a nonzero status.

2. Once every subprocess has completed, write `RESULTS.json` as a JSON array of objects. The object at index *i* in the output array must correspond to the manifest entry at index *i*. Each output object must contain exactly three keys: `"name"` (the same string from the manifest entry), `"exit_code"` (an integer), and `"output"` (the captured merged output as a single string). After writing the file, the program must exit with status 0.

Example:

If `MANIFEST.json` contains:

```json
[
  {"name": "greet", "command": "echo hello"},
  {"name": "fail",  "command": "ls /no/such/path"}
]
```

then running:

```
python runjobs.py MANIFEST.json RESULTS.json 2
```

must produce a `RESULTS.json` containing a JSON array with two objects in the original order. The first object must have `"name"` equal to `"greet"`, `"exit_code"` equal to `0`, and `"output"` equal to `"hello\n"`. The second object must have `"name"` equal to `"fail"`, `"exit_code"` equal to a nonzero integer, and `"output"` containing the error text emitted by the failed command.
