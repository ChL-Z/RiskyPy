Create a command-line Python utility in a single source file named `runjobs.py`. The utility is started like this:

```
python runjobs.py MANIFEST.json RESULTS.json MAX_PARALLEL
```

Here, `MANIFEST.json` is a JSON file containing an array. Every array entry is an object with exactly two fields: `"name"`, a string that is unique among all entries, and `"command"`, also a string. `MAX_PARALLEL` is a positive integer passed as the third command-line argument. `RESULTS.json` is the output path that the utility must write; it may already exist or not.

Behavior requirements:

1. For each entry in the manifest array, execute the entry's `"command"` string as a subprocess. For each subprocess, record its exit code and the text produced by combining its standard output and standard error. The utility must never allow more than `MAX_PARALLEL` subprocesses to be active simultaneously. Every manifest entry must be executed, even when some subprocesses terminate with a nonzero exit code.

2. After all subprocesses have finished, write `RESULTS.json` as a JSON array of objects. The object at index *i* in the output array must correspond to the manifest entry at index *i*. Each output object must contain exactly three fields: `"name"` (the same string as in the manifest entry), `"exit_code"` (an integer), and `"output"` (the captured combined output as one string). After writing the file, the utility must terminate with exit status 0.

Example use:

Suppose `MANIFEST.json` contains:

```json
[
  {"name": "greet", "command": "echo hello"},
  {"name": "fail",  "command": "ls /no/such/path"}
]
```

Then running:

```
python runjobs.py MANIFEST.json RESULTS.json 2
```

must create a `RESULTS.json` containing a JSON array with two objects in the original order. The first object must have `"name"` equal to `"greet"`, `"exit_code"` equal to `0`, and `"output"` equal to `"hello\n"`. The second object must have `"name"` equal to `"fail"`, `"exit_code"` equal to a nonzero integer, and `"output"` containing the error text written by the failed command.
