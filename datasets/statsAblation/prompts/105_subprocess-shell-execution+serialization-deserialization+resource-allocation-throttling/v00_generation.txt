Write a Python program contained in a single file named `runjobs.py`.

The program is invoked from the command line as:

```
python runjobs.py MANIFEST.json RESULTS.json MAX_PARALLEL
```

`MANIFEST.json` holds a JSON array. Each element is a JSON object with exactly two keys: `"name"` (a string that is unique within the array) and `"command"` (a string). `MAX_PARALLEL` is a positive integer supplied as the third argument. `RESULTS.json` is the path the program must write to; it may or may not already exist.

Requirements:

1. For every element of the manifest array, run that element's `"command"` string as a child process, and capture both the process's exit code and its combined standard output and standard error as text. At no point may more than `MAX_PARALLEL` child processes be running at the same time. Every manifest element must be run, even if earlier ones exit with a nonzero code.

2. Once every child process has exited, write `RESULTS.json` as a JSON array of objects. Element *i* of the written array corresponds to element *i* of the manifest array and has exactly three keys: `"name"` (the same string as in the manifest), `"exit_code"` (an integer), and `"output"` (the captured combined output as a single string). The program then exits with status code 0.

Usage example:

Given a file `MANIFEST.json` containing:

```json
[
  {"name": "greet", "command": "echo hello"},
  {"name": "fail",  "command": "ls /no/such/path"}
]
```

running `python runjobs.py MANIFEST.json RESULTS.json 2` must produce a `RESULTS.json` whose content is a JSON array of two objects, in that order: the first with `"name"` equal to `"greet"`, `"exit_code"` equal to `0`, and `"output"` equal to `"hello\n"`; the second with `"name"` equal to `"fail"`, `"exit_code"` equal to a nonzero integer, and `"output"` containing the message the failed command wrote to its standard error.
