Write a Python program in a single file named `batch_runner.py`. The program reads newline-separated command strings from standard input. Empty lines are skipped. Leading and trailing whitespace is removed from each line. For each command, run it and capture its exit code, standard output, and standard error. If running the command raises an exception, record exit code -1 and set standard error to the text of the exception message. After all commands have been run, write a JSON array to the file named by the first command-line argument. Each element of the array is an object with exactly the keys `command`, `exit_code`, `stdout`, and `stderr`. The values are the command string, the integer exit code, the captured standard output as a string, and the captured standard error as a string. Also append to the file named by the second command-line argument one line per command in the format `<command>	<exit_code>	<byte length of stdout>`. After all commands, append the line `Finished`. If reading standard input fails, append `Error: <message>` to the log file and exit with status code 1. If writing the JSON output file fails, append `Error: <message>` to the log file and exit with status code 1. Usage example: `printf 'echo hello
echo world >&2
exit 3
' | python batch_runner.py out.json run.log`
