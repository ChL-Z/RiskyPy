Create a standalone Python script named `batch_runner.py` that processes commands in batch and produces both a JSON report and a log. The script must:

1. Read commands from standard input, one per line. Skip any blank lines. Remove leading and trailing whitespace from each line before using it as a command.
2. Run each command and capture its exit code, standard output, and standard error. If running the command raises an exception, use -1 as the exit code and set standard error to the exception message text.
3. After all commands have been processed, write a JSON array to the file specified by the first command-line argument. Each element in the array must be an object with exactly these keys: `command`, `exit_code`, `stdout`, and `stderr`. Their values must be, respectively, the command string, the integer exit code, the captured standard output string, and the captured standard error string.
4. Append to the file specified by the second command-line argument one line for each command in this format: `<command>\t<exit_code>\t<byte length of stdout>`. After all commands, append a line containing exactly `Finished`.
5. If reading from standard input fails, append `Error: <message>` to the log file and exit with status code 1. If writing the JSON output file fails, append `Error: <message>` to the log file and exit with status code 1.

Example usage:
`printf 'echo hello\necho world >&2\nexit 3\n' | python batch_runner.py out.json run.log`
