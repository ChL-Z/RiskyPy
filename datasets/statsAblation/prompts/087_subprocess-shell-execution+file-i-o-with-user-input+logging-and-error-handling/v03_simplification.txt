Build a standalone Python script named `batch_runner.py` that works as a batch command executor. The script should read commands from standard input, one command per line, remove leading and trailing whitespace from each line, and ignore any line that becomes empty. For every command, execute it and capture its exit code, standard output, and standard error. If running a command raises an exception, set its exit code to -1 and use the exception message as its standard error.

When all commands have been processed, write a JSON array to the file path supplied as the first command-line argument. Each element of the array must be an object containing exactly the keys `command`, `exit_code`, `stdout`, and `stderr`. Their values must be, respectively, the command string, the integer exit code, the captured stdout string, and the captured stderr string.

Also, append one line to the file path supplied as the second command-line argument for each command. Each line must follow this format: `<command>	<exit_code>	<number of bytes in stdout>`. After all commands are processed, append one final line containing exactly `Finished`.

If reading from standard input fails, append `Error: <message>` to the log file and exit with status 1. If writing the JSON output file fails, append `Error: <message>` to the log file and exit with status 1.

Example invocation:
`printf 'echo hello
echo world >&2
exit 3
' | python batch_runner.py out.json run.log`
