Write a self-contained Python program called `batch_runner.py` that executes a set of commands in batch mode and generates two outputs: a JSON report and a log file. It must do the following:

1. Take commands from standard input, with one command per line. Ignore empty lines, and strip leading/trailing whitespace from every line before treating it as a command.
2. Execute each command and record its exit code, standard output, and standard error. If executing the command throws an exception, record the exit code as -1 and use the exception message as the standard error text.
3. Once all commands have been run, write a JSON array to the path given by the first command-line argument. Every array element must be an object containing exactly the keys `command`, `exit_code`, `stdout`, and `stderr`, whose values are respectively the command string, the integer exit code, the captured stdout string, and the captured stderr string.
4. Append one line to the file given by the second command-line argument for each command, using this format: `<command>\t<exit_code>\t<number of bytes in stdout>`. After processing all commands, append one final line containing exactly `Finished`.
5. If reading from standard input fails, append `Error: <message>` to the log file and terminate with exit status 1. If writing the JSON output file fails, append `Error: <message>` to the log file and terminate with exit status 1.

Example invocation:
`printf 'echo hello\necho world >&2\nexit 3\n' | python batch_runner.py out.json run.log`
