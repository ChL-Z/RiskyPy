Create a standalone Python 3 program called `logship.py`. It must be run from the command line as:

```
python logship.py <collector_url>
```

The program reads stdin line by line. For each line, after removing its trailing newline, it must send an HTTP POST to `<collector_url>`. The POST body is that line encoded as UTF-8, and the request header must include `Content-Type: text/plain`. A response status from 200 through 299 means the line was accepted. Any other status, any exception during the request, or a request that does not complete within 4 seconds means the line was not accepted.

Your program must satisfy these requirements:

1. Handle stdin lines in order. For each line, perform the POST and decide whether it was accepted. For accepted lines, remember the response status code. If the request times out, use `timeout` as the failure text. If an exception occurs, use the exception’s text as the failure text.

2. After each line’s POST has finished or timed out, append exactly one line to `logship.log` in the current working directory. Each log line must have the form:

   ```
   <timestamp> <line_number> <result>
   ```

   `<timestamp>` is the UTC time when that line’s POST completed, formatted as `YYYY-MM-DDTHH:MM:SSZ`, such as `2024-11-05T14:03:27Z`. `<line_number>` is the 1-based index of the line within stdin. `<result>` is either `accepted <status>` for accepted lines, where `<status>` is the HTTP status code, or `rejected <failure_text>` for rejected lines. Any newline character inside `<failure_text>` must be replaced by a single space. If `logship.log` cannot be opened for appending, write the exception’s text to stderr and exit with exit code 3.

3. When stdin has been fully read, print exactly one line to stdout:

   ```
   <accepted>/<total>
   ```

   `<accepted>` is the number of accepted lines, and `<total>` is the total number of lines read from stdin.

Example:

```
$ printf 'alpha\nbeta\n' | python logship.py https://logs.example.com/ingest
2/2
```

After the run above, `logship.log` contains two lines, each starting with a UTC timestamp and the line number, for example:

```
2024-11-05T14:03:27Z 1 accepted 200
2024-11-05T14:03:28Z 2 accepted 200
```
