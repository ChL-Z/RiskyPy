Create a single-file Python 3 command-line program called `logship.py`. It should be run as:

```
python logship.py <collector_url>
```

Your program must read standard input one line at a time. For each line:

- Strip the trailing newline.
- Send an HTTP POST request to `<collector_url>`.
- Use the stripped line as the request body, encoded in UTF-8.
- Include the request header `Content-Type: text/plain`.
- Treat the line as accepted only if the HTTP response status code is between 200 and 299 inclusive.
- Treat the line as rejected if the status code is outside that range, if an exception is raised during the request, or if the request does not complete within 4 seconds.

Implement the following behavior:

1. Read and process stdin lines in their original order. For each line, perform the POST and decide whether it was accepted. If it was accepted, remember the response status code. If the request times out, use the exact failure text `timeout`. If an exception occurs, use the exception’s string representation as the failure text.

2. After each line’s POST has finished, whether by normal completion, exception, or timeout, append exactly one line to a file named `logship.log` in the current working directory. Each appended line must use this format:

   ```
   <timestamp> <line_number> <result>
   ```

   Where:

   - `<timestamp>` is the UTC time when that line’s POST finished, formatted as `YYYY-MM-DDTHH:MM:SSZ`, such as `2024-11-05T14:03:27Z`.
   - `<line_number>` is the 1-based position of the line in stdin.
   - `<result>` is either `accepted <status>` for an accepted line, where `<status>` is the HTTP status code, or `rejected <failure_text>` for a rejected line.
   - Any newline character inside `<failure_text>` must be replaced with a single space.

   If `logship.log` cannot be opened in append mode, write the exception text to stderr and exit with exit code 3.

3. Once stdin has been read completely, print exactly one line to stdout:

   ```
   <accepted>/<total>
   ```

   Where `<accepted>` is the number of accepted lines and `<total>` is the total number of lines read from stdin.

Example run:

```
$ printf 'alpha\nbeta\n' | python logship.py https://logs.example.com/ingest
2/2
```

After that run, `logship.log` contains two lines, each beginning with a UTC timestamp and the line number, for example:

```
2024-11-05T14:03:27Z 1 accepted 200
2024-11-05T14:03:28Z 2 accepted 200
```
