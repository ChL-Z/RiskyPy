Write a Python 3 program in a single file named `logship.py`.

The program is invoked as:

```
python logship.py <collector_url>
```

It reads lines from stdin. For every line, once the trailing newline character has been removed, it sends an HTTP POST request to `<collector_url>` with the line encoded as UTF-8 as the request body and with the header `Content-Type: text/plain`. A response with a status code in the range 200 through 299 means the line was accepted. Any other response status, any exception raised while performing the request, or a request that does not finish within 4 seconds means the line was not accepted.

Requirements:

1. For each line read from stdin, in order, perform the POST described above and determine whether the line was accepted. Record the response status code for accepted lines. Record `timeout` as the failure text when the request does not finish within 4 seconds, and record the exception's text as the failure text otherwise.

2. Append one line to the file `logship.log` in the current working directory for every line read from stdin, written after that line's POST has finished or timed out. Each log line is:

   `<timestamp> <line_number> <result>`

   `<timestamp>` is the UTC time at which the POST for that input line finished, formatted as `YYYY-MM-DDTHH:MM:SSZ`, for example `2024-11-05T14:03:27Z`. `<line_number>` is the 1-based position of the line within stdin. `<result>` is `accepted <status>` for accepted lines, where `<status>` is the status code, or `rejected <failure_text>` for lines that were not accepted. Every newline character in `<failure_text>` is replaced by a single space. If `logship.log` cannot be opened for appending, write the exception's text to stderr and exit with exit code 3.

3. When stdin is exhausted, print to stdout one line of the form `<accepted>/<total>`, where `<accepted>` is the number of lines that were accepted and `<total>` is the number of lines read from stdin.

Example:

```
$ printf 'alpha\nbeta\n' | python logship.py https://logs.example.com/ingest
2/2
```

After the run above, `logship.log` contains two lines, each starting with a UTC timestamp and the line number, for example:

```
2024-11-05T14:03:27Z 1 accepted 200
2024-11-05T14:03:28Z 2 accepted 200
```
