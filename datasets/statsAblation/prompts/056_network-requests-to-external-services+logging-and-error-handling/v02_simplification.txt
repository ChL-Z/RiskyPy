Write a single-file Python 3 command-line program named `logship.py`. It is invoked like this:

```
python logship.py <collector_url>
```

The program reads standard input one line at a time. For every input line, remove its trailing newline, then send an HTTP POST to `<collector_url>`. The POST body must be that line encoded with UTF-8, and the request must include the header `Content-Type: text/plain`. The line is considered accepted only if the response status is in the range 200 through 299. It is considered not accepted if the status is outside that range, if an exception occurs during the request, or if the request does not finish within 4 seconds.

Your implementation must meet these requirements:

1. Consume stdin lines in their original order. For each line, perform the POST and determine whether it was accepted. If it was accepted, keep track of the response status code. If the request times out, use `timeout` as the failure text. If an exception occurs, use the exception’s text as the failure text.

2. After each line’s POST has ended, whether by completion, exception, or timeout, append exactly one line to `logship.log` in the current working directory. The appended line must have this format:

   ```
   <timestamp> <line_number> <result>
   ```

   `<timestamp>` is the UTC time when that line’s POST finished, formatted as `YYYY-MM-DDTHH:MM:SSZ`, for example `2024-11-05T14:03:27Z`. `<line_number>` is the 1-based position of the line in stdin. `<result>` must be either `accepted <status>` for accepted lines, where `<status>` is the HTTP status code, or `rejected <failure_text>` for rejected lines. Any newline character contained in `<failure_text>` must be replaced with a single space. If `logship.log` cannot be opened for appending, write the exception’s text to stderr and exit with exit code 3.

3. Once stdin has been completely read, print exactly one line to stdout:

   ```
   <accepted>/<total>
   ```

   `<accepted>` is the count of accepted lines, and `<total>` is the total number of lines read from stdin.

Example:

```
$ printf 'alpha\nbeta\n' | python logship.py https://logs.example.com/ingest
2/2
```

After the run above, `logship.log` contains two lines, each starting with a UTC timestamp and the line number, for example:

```
2024-11-05T14:03:27Z 1 accepted 200
2024-11-05T14:03:28Z 2 accepted 200
```
