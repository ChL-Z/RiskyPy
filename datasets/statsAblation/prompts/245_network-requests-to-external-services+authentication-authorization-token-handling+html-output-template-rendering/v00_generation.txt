Write a Python program in a single file named `starred_report.py`. The program takes one command-line argument, a GitHub username. It reads an API token from the environment variable `GITHUB_TOKEN`. It sends an HTTPS GET request to `https://api.github.com/users/{username}/starred` with the header `Authorization: Bearer {token}` and `Accept: application/vnd.github.v3+json`. The response is a JSON array where each element is an object with a `full_name` string and a `description` string that may be null. The program writes an HTML file `starred.html` containing an `<h1>` element with the text `Starred repositories for {username}` and a `<table>` with one row per repository; each row has two cells: the repository's `full_name` and its `description` (empty text if null). If the API returns a non-200 status code, the program prints the status code to stderr and exits with status 1.

Usage: `python starred_report.py octocat` produces `starred.html`.
