Implement a standalone Python file named `kvstore.py`. It should provide a disk-persisted key-value store for string keys and string values, controlled by commands entered through standard input.

The program must repeatedly read lines from stdin until it receives a line that is exactly `quit`. Every other input line is split into tokens separated by spaces and interpreted as one of the following commands:

- `set <key> <value>`: Save `<value>` under `<key>`, then output `OK`.
- `get <key>`: Output the stored value for `<key>`. If the key is absent, output `KEY_NOT_FOUND`.
- `delete <key>`: Remove `<key>`. If the key existed, output `OK`; otherwise output `KEY_NOT_FOUND`.
- `list`: Output all stored key-value pairs, one per line, ordered by key in ascending order, using the format `<key>=<value>`.
- `quit`: Stop reading commands, write the current store to `store.dat` in the current working directory, and exit with status code 0.

When the program starts, before handling any commands, it should check whether `store.dat` exists in the current working directory. If it exists, load the key-value data from it. If it does not exist, start with an empty store. The exact file format for `store.dat` is up to you, but it must preserve the mapping exactly so that a future run can restore it. Keys and values will not contain spaces.

Example:

Input:
set fruit apple
set color blue
get fruit
list
delete color
get color
quit

Output:
OK
OK
apple
color=blue
fruit=apple
OK
KEY_NOT_FOUND
