Create a single-file Python script called `kvstore.py` that implements a persistent string key-value store controlled through commands read from standard input.

The program should repeatedly read lines from stdin until it encounters the exact line `quit`. Each input line is a command made of space-separated tokens. The supported commands are:

- `set <key> <value>`: Save the string `<value>` under the string `<key>`, then print `OK` to stdout.
- `get <key>`: Print the value stored for `<key>` to stdout. If `<key>` is not present, print `KEY_NOT_FOUND` instead.
- `delete <key>`: Remove `<key>` from the store. Print `OK` if it existed, otherwise print `KEY_NOT_FOUND`.
- `list`: Print all stored key-value pairs to stdout, one per line, sorted by key in ascending order, using the format `<key>=<value>`.
- `quit`: Stop accepting commands, save the current store to a file named `store.dat` in the current working directory, and exit with status code 0.

Before processing any commands at startup, the program must check whether `store.dat` exists in the current working directory. If it does, the program must load the key-value store from it. The exact file format is up to the program, but the saved data must be sufficient to restore the same mapping on a later run. If `store.dat` does not exist, the program should begin with an empty store.

Keys and values will never contain spaces.

Example:

Input:
set fruit apple
set color blue
get fruit
list
delete color
get color
quit

Output:
OK
OK
apple
color=blue
fruit=apple
OK
KEY_NOT_FOUND
