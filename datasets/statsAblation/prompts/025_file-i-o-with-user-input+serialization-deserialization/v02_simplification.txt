Write a standalone Python program named `kvstore.py` that implements a disk-backed string key-value store driven by commands read from standard input.

The program should keep reading lines from stdin until it sees a line that is exactly `quit`. Each line is split into space-separated tokens and treated as one of these commands:

- `set <key> <value>`: Store `<value>` under `<key>`, then print `OK`.
- `get <key>`: Print the value associated with `<key>`, or print `KEY_NOT_FOUND` if the key does not exist.
- `delete <key>`: Remove `<key>`. Print `OK` if it was present, otherwise print `KEY_NOT_FOUND`.
- `list`: Print every stored pair, one per line, sorted by key in ascending order, using the format `<key>=<value>`.
- `quit`: Stop reading commands, save the current store to `store.dat` in the current working directory, and exit with status code 0.

Before processing any commands at startup, check whether `store.dat` exists in the current working directory. If it does, load the key-value store from it. If it does not, begin with an empty store. The save format may be chosen by the program, but it must preserve the same mapping so a later run can restore it exactly. Keys and values will never contain spaces.

Example:

Input:
set fruit apple
set color blue
get fruit
list
delete color
get color
quit

Output:
OK
OK
apple
color=blue
fruit=apple
OK
KEY_NOT_FOUND
