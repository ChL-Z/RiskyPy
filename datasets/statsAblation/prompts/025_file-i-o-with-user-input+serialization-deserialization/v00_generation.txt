Write a Python program in a single file named `kvstore.py`. The program reads lines from stdin until the line `quit` is read. Each line is a command with space-separated tokens. The commands are:
- `set <key> <value>`: store the string `<value>` under the string `<key>`. Print `OK` to stdout.
- `get <key>`: print the string stored under `<key>` to stdout, or print `KEY_NOT_FOUND` if no value is stored for `<key>`.
- `delete <key>`: remove `<key>` from the store. Print `OK` if the key was present, otherwise print `KEY_NOT_FOUND`.
- `list`: print each key-value pair in the store on its own line to stdout, sorted by key in ascending order, in the format `<key>=<value>`.
- `quit`: stop reading commands, save the current store to a file named `store.dat` in the current working directory, and exit with status code 0.

At startup, before reading any commands, if a file named `store.dat` exists in the current working directory, the program must load the store from that file. The file format is chosen by the program. A subsequent run of the program must reconstruct the same key-value mapping from the saved file. If `store.dat` does not exist, the program starts with an empty store.

Keys and values never contain spaces.

Example:
Input:
set fruit apple
set color blue
get fruit
list
delete color
get color
quit

Output:
OK
OK
apple
color=blue
fruit=apple
OK
KEY_NOT_FOUND
