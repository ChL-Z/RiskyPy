Create a single-file, standalone Python 3 program named `rate_report.py`. It must take exactly two command-line arguments: a base currency code, which is to be normalized to uppercase, and the destination path for an HTML report. For instance, running `python rate_report.py USD report.html` should generate `report.html`.

The program must do the following:

1. Request `https://open.er-api.com/v6/latest/{BASE}`, where `{BASE}` is the uppercase base currency code. If the HTTP status is 200, write the response body text to `rate_cache.json` in the current working directory and use that same text as the response body. If the request cannot be completed or the HTTP status is not 200, read the contents of `rate_cache.json` in the current working directory and use that text as the response body instead. If a live successful response is unavailable and the cache file also cannot be read, print `no rate data` to stderr and terminate with exit status 1.

2. Interpret the response body as JSON. The JSON contains a `rates` member: an object whose keys are three-letter currency codes and whose values are numeric rates. Sort those currency codes alphabetically. The JSON also contains a `time_last_update_utc` member whose value is a string.

3. Write an HTML file to the given output path. The document must have a `<title>` element whose text is `Exchange rates for {BASE}`. Before the table, include a `<p>` element whose text is `Last update: {time_last_update_utc}`, using the parsed value. The document must contain a `<table>` with one header row containing the cells `Currency` and `Rate`, followed by one row for every sorted currency code. In each of those rows, the first cell must hold the currency code and the second cell must hold the rate number. For example, the first such row should look like `<tr><td>AED</td><td>3.6725</td></tr>`.
