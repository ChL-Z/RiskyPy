Write a standalone Python 3 script in a single file called `rate_report.py`. The script accepts exactly two command-line arguments: a base currency code, which should be converted to uppercase, and the path where an HTML report should be written. For example, `python rate_report.py USD report.html` should produce `report.html`.

The script must behave as follows:

1. Send a request to `https://open.er-api.com/v6/latest/{BASE}`, replacing `{BASE}` with the uppercase currency code. If the response has HTTP status 200, save the response body text to `rate_cache.json` in the current working directory and use that same text as the response body. If the request fails or the status is anything other than 200, read the text from `rate_cache.json` in the current working directory and use that as the response body instead. If there is neither a successful request nor a readable cache file, write `no rate data` to stderr and exit with status code 1.

2. Parse the response body as JSON. The JSON object contains a `rates` member, whose value is an object mapping three-letter currency codes to numeric rates. Sort the currency codes alphabetically. The JSON object also contains a `time_last_update_utc` member whose value is a string.

3. Create an HTML file at the given output path. The document must include a `<title>` element containing the text `Exchange rates for {BASE}`. Before the table, include a `<p>` element containing the text `Last update: {time_last_update_utc}`, using the parsed value. The document must include a `<table>` with one header row containing the cells `Currency` and `Rate`, followed by one row for each sorted currency code. In each such row, the first cell contains the currency code and the second cell contains the rate number. For example, an initial row should look like `<tr><td>AED</td><td>3.6725</td></tr>`.
