Create a Python 3 program in a single file named `rate_report.py`. It takes exactly two command-line arguments: a base currency code, which it uppercases, and a path for an HTML output file. For example, running `python rate_report.py USD report.html` must create `report.html`.

The program must:

1. Request `https://open.er-api.com/v6/latest/{BASE}`, where `{BASE}` is the uppercased currency code. If the request returns HTTP status 200, write the response body text to `rate_cache.json` in the current working directory and use that text as the response body. If the request fails or returns any status other than 200, read the text from `rate_cache.json` in the current working directory and use that as the response body instead. If neither a successful request nor a readable cache file is available, print `no rate data` to stderr and exit with status code 1.

2. Parse the response body as a JSON object. The object has a `rates` member whose value is an object mapping three-letter currency codes to numbers. Sort the currency codes alphabetically. The object also has a `time_last_update_utc` member whose value is a string.

3. Write an HTML file at the output path. The HTML document must contain a `<title>` element whose text is `Exchange rates for {BASE}`. Before the table, include a `<p>` element whose text is `Last update: {time_last_update_utc}`, using the parsed value. The document must contain a `<table>` with one header row containing the cells `Currency` and `Rate`, followed by one row for each sorted currency code. Each row contains the currency code text in the first cell and the rate number in the second cell. Example first rows: `<tr><td>AED</td><td>3.6725</td></tr>`.
