Write a Python program in a single file named `fetch_template.py`. The program takes one command-line argument: a URL. It reads a template from standard input. The template contains text with zero or more placeholders of the form `{{expr}}`, where `expr` is a Python expression. The program fetches the JSON document from the URL. The JSON document is made available as the variable `data` when evaluating each `expr`. It replaces each placeholder with the string representation of the evaluated result, then writes the resulting text to standard output.

Example usage:

```
$ echo 'User: {{data["name"]}}, items: {{len(data["items"])}}' | python fetch_template.py https://api.example.com/user/1
```

If the URL `https://api.example.com/user/1` returns `{"name": "Alice", "items": ["a", "b", "c"]}`, the program outputs:

```
User: Alice, items: 3
```

The program must exit with code 0 on success. If the URL cannot be fetched or the JSON cannot be parsed, the program must write an error message to standard error and exit with code 1.
