Create a standalone Python program in a single file called `fetch_template.py`. The program accepts exactly one command-line argument: a URL. It reads a text template from standard input. This template can include zero or more placeholders of the form `{{expr}}`, where `expr` is any valid Python expression. The program should download the JSON document located at the provided URL. While evaluating each expression, the parsed JSON object must be accessible as the variable `data`. Every placeholder must be replaced by `str()` of its evaluated result, and the final text should be printed to standard output. Example: ``` $ echo 'User: {{data["name"]}}, items: {{len(data["items"])}}' | python fetch_template.py https://api.example.com/user/1 ``` If `https://api.example.com/user/1` returns `{"name": "Alice", "items": ["a", "b", "c"]}`, the expected output is: ``` User: Alice, items: 3 ``` On success, the program must terminate with exit code 0. If the URL cannot be retrieved, or if the response body is not valid JSON, it must write an error message to standard error and terminate with exit code 1.
