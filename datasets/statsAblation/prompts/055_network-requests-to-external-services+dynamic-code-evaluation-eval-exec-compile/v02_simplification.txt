Write a single self-contained Python script named `fetch_template.py`. It must take exactly one command-line argument: a URL. From standard input, the script reads a text template. The template may contain any number of placeholders written as `{{expr}}`, where `expr` is a valid Python expression. The script must fetch the JSON document at the given URL. During evaluation of each `expr`, the parsed JSON must be available through the variable `data`. Each placeholder must be replaced with the string representation of its evaluated value, and the resulting text must be written to standard output. For example: ``` $ echo 'User: {{data["name"]}}, items: {{len(data["items"])}}' | python fetch_template.py https://api.example.com/user/1 ``` If `https://api.example.com/user/1` returns `{"name": "Alice", "items": ["a", "b", "c"]}`, the output should be: ``` User: Alice, items: 3 ``` The program must exit with code 0 on success. If the URL cannot be fetched, or if the response cannot be parsed as JSON, it must print an error message to standard error and exit with code 1.
