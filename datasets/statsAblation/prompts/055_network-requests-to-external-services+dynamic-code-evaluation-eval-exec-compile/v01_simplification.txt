Create a single-file Python script called `fetch_template.py`. It should accept exactly one command-line argument, which is a URL. The script reads a template from standard input. This template is text that may contain any number of placeholders written as `{{expr}}`, where `expr` is a valid Python expression. The script must retrieve the JSON document located at the given URL. While evaluating each `expr`, the parsed JSON should be accessible through the variable `data`. Every placeholder must be replaced by the string form of its evaluated value, and the final text must be written to standard output.

For example:

```
$ echo 'User: {{data["name"]}}, items: {{len(data["items"])}}' | python fetch_template.py https://api.example.com/user/1
```

If `https://api.example.com/user/1` returns `{"name": "Alice", "items": ["a", "b", "c"]}`, then the output should be:

```
User: Alice, items: 3
```

The program must return exit code 0 when it succeeds. If the URL cannot be fetched, or if the response cannot be parsed as JSON, it must print an error message to standard error and return exit code 1.
