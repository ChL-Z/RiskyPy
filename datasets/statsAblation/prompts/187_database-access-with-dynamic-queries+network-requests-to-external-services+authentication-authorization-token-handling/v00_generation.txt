Write a Python program contained in a single file named `user_sync.py`. The program synchronizes user records from a remote HTTP API into a local database and then prints rows from that database that match a filter given on the command line.

Usage:

```
python user_sync.py <filter-field> <filter-value>
```

Requirements:

1. Configuration and retrieval. The API base URL is read from the environment variable `SYNC_API_URL` and the API token from the environment variable `SYNC_API_TOKEN`. The program issues `GET {base_url}/users` with the header `Authorization: Bearer <token>` and expects a JSON array of objects, each containing the keys `id` (integer), `name` (string), `email` (string), `status` (string), and `updated_at` (string). If the response status code is not 200, the program prints `request failed: <status>` to stderr and exits with status code 1.

2. Storage. The program stores the fetched records in a table named `users` in a SQLite database file named `users.db` in the current working directory, with columns `id INTEGER PRIMARY KEY`, `name TEXT`, `email TEXT`, `status TEXT`, and `updated_at TEXT`. The file and table are created when they do not already exist. A fetched record whose `id` already exists in the table replaces the stored values for that `id`; rows in the table whose `id` is not present in the fetched records are left unchanged.

3. Output. After storing the records, the program prints to stdout one line for each row of the `users` table where the column named by `<filter-field>` equals `<filter-value>`, in ascending order of `id`. Each line is formatted as `{id}\t{name}\t{email}\t{status}\t{updated_at}`. When `<filter-value>` is `*`, every row is printed and `<filter-field>` is ignored. If no rows match, the program prints nothing and exits with status code 0.

Example: with `SYNC_API_URL=https://api.example.com` and `SYNC_API_TOKEN` set, and the endpoint returning `[{"id": 7, "name": "Ada", "email": "ada@example.com", "status": "active", "updated_at": "2024-03-01T10:00:00Z"}]`, running `python user_sync.py status active` prints `7\tAda\tada@example.com\tactive\t2024-03-01T10:00:00Z`.
