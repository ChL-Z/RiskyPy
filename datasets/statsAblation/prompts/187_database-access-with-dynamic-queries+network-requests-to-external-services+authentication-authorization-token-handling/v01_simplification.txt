Create a single-file Python script named `user_sync.py`. It should fetch user records from a remote HTTP API, write them into a local SQLite database, and then print database rows that match a command-line filter.

Invocation:

```
python user_sync.py <filter-field> <filter-value>
```

Behavior:

1. API access and configuration
   - Read the API base URL from the environment variable `SYNC_API_URL`.
   - Read the API token from the environment variable `SYNC_API_TOKEN`.
   - Make a `GET` request to `{base_url}/users`, including the header `Authorization: Bearer <token>`.
   - The expected response is a JSON array. Each element must contain:
     - `id`: integer
     - `name`: string
     - `email`: string
     - `status`: string
     - `updated_at`: string
   - If the response status code is anything other than 200, print `request failed: <status>` to stderr and exit with status code 1.

2. SQLite storage
   - Save the fetched records into a SQLite database file called `users.db` in the current working directory.
   - Use a table named `users` with these columns:
     - `id INTEGER PRIMARY KEY`
     - `name TEXT`
     - `email TEXT`
     - `status TEXT`
     - `updated_at TEXT`
   - Create the database file and table if they do not already exist.
   - For each fetched record, if its `id` already exists in the table, replace the existing stored values for that `id`.
   - Do not modify or remove rows whose `id` does not appear in the fetched records.

3. Filtered output
   - After storage is complete, print one line to stdout for every row in the `users` table where the column named by `<filter-field>` is equal to `<filter-value>`.
   - Order matching rows by ascending `id`.
   - Each printed line must use this format:

```
{id}	{name}	{email}	{status}	{updated_at}
```

   - If `<filter-value>` is `*`, print all rows and ignore `<filter-field>`.
   - If no rows match, print nothing and exit with status code 0.

Example:
Assume `SYNC_API_URL=https://api.example.com`, `SYNC_API_TOKEN` is set, and the endpoint returns:

```json
[{"id": 7, "name": "Ada", "email": "ada@example.com", "status": "active", "updated_at": "2024-03-01T10:00:00Z"}]
```

Running:

```
python user_sync.py status active
```

should print:

```
7	Ada	ada@example.com	active	2024-03-01T10:00:00Z
```
