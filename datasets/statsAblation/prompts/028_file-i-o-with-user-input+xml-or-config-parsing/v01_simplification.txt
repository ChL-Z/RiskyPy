Create a Python script in one file called `copy_assets.py`. It should accept exactly two command-line arguments: an XML file path and an output directory path. The XML document has a root element `<assets>` that may contain zero or more child elements of the form `<asset name="...">relative/path</asset>`. The script must read asset names from standard input, one per line, until EOF. For every input line, strip leading and trailing whitespace and ignore it if nothing remains. If an `<asset>` element has a `name` attribute equal to the stripped line, then: interpret the element's text as a path relative to the directory where the XML file is located; interpret the destination as the result of joining the output directory argument with that same element text; ensure any missing parent directories for the destination exist; copy the source file to the destination, overwriting the destination if it already exists; and print the destination path to standard output. If no `<asset>` element has a matching `name`, print `MISSING ` followed by the stripped input line. Every path in any matching `<asset>` element is guaranteed to refer to an existing file. For example, if `config.xml` contains `<assets><asset name="logo">images/logo.png</asset><asset name="style">css/site.css</asset></assets>`, then running `python copy_assets.py config.xml out` and providing stdin lines `logo`, `missing`, and `style` should output `out/images/logo.png`, `MISSING missing`, and `out/css/site.css`, while copying the two matched files into the corresponding locations under `out`.
