Write a Python program in a single file named `copy_assets.py`. The program takes two command-line arguments: the path to an XML file and an output directory path. The XML file has a root `<assets>` element containing zero or more `<asset name="...">relative/path</asset>` children. The program reads newline-separated asset names from stdin until end of input. For each input line, remove leading and trailing whitespace and skip lines that are empty after trimming. If an `<asset>` element has a `name` attribute equal to the trimmed line, treat the element's text as a path relative to the directory containing the XML file, treat the destination path as the path formed by joining the output directory argument and the element's text, create any missing directories in the destination path, write a copy of the source file at the destination path, and print the destination path to stdout. If the destination file already exists, replace it. If no `<asset>` element matches the trimmed line, print `MISSING ` followed by the trimmed line. All paths listed in matching `<asset>` elements refer to existing files. Example: `config.xml` contains `<assets><asset name="logo">images/logo.png</asset><asset name="style">css/site.css</asset></assets>`. Running `python copy_assets.py config.xml out` with stdin lines `logo`, `missing`, `style` prints `out/images/logo.png`, `MISSING missing`, `out/css/site.css` and writes copies of the two matched files under `out`.
