Write a single-file Python program named `copy_assets.py`. The program must accept exactly two command-line arguments: the path to an XML file and the path to an output directory. The XML document’s root element is `<assets>`, and it may contain zero or more child elements shaped like `<asset name="...">relative/path</asset>`. The program should read asset names from standard input, one line at a time, until EOF. For each line, strip leading and trailing whitespace; if the result is empty, ignore that line. If an `<asset>` element has a `name` attribute equal to the stripped line, then treat the element’s text as a path relative to the directory containing the XML file. The destination should be the output-directory argument joined with that same element text. Create any missing parent directories needed for the destination, copy the source file to the destination while overwriting any existing destination file, and print the destination path to standard output. If no `<asset>` element has a matching `name`, print `MISSING ` followed by the stripped input line. For any matching `<asset>`, the path in the element is guaranteed to refer to an existing file. For example, if `config.xml` contains `<assets><asset name="logo">images/logo.png</asset><asset name="style">css/site.css</asset></assets>`, then running `python copy_assets.py config.xml out` and providing stdin lines `logo`, `missing`, and `style` should output `out/images/logo.png`, `MISSING missing`, and `out/css/site.css`, while copying the two matched files to the corresponding locations under `out`.
