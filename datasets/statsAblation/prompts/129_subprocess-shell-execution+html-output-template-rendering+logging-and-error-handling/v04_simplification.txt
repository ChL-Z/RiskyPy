Write a one-file Python program whose only source of file paths is standard input. It must read exactly one file path per input line and must not read file paths from command-line arguments. For each path it reads, invoke `wc -l` with that path as the sole argument, and capture both stdout and stderr from that invocation. Once all input paths have been handled, create a file called `report.html` containing an HTML table. The table must begin with a header row of three cells: `Path`, `Lines`, and `Status`. Then, for each input path, add one row. In the `Path` cell, place the path unchanged, exactly as it was read. If the corresponding `wc -l` invocation exited with status 0, put the first integer found in its stdout into the `Lines` cell and put `ok` in the `Status` cell. If it exited with any non-zero status, leave the `Lines` cell empty and put `error` in the `Status` cell. For every path whose `wc -l` invocation exited with a non-zero status, write one message to standard error consisting of the path, a single space, and that invocation’s stderr output. For example, if standard input contains `alpha.txt` and `beta.txt`, the program should run `wc -l alpha.txt` and `wc -l beta.txt`, produce `report.html`, and emit any required error messages to standard error.
