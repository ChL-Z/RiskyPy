Create a single-file Python program that takes a list of file paths from standard input, one path per line. It must not accept file paths through command-line arguments. For each path, execute the command `wc -l` using that path as the sole argument, and collect both the command’s standard output and standard error. Once every path has been handled, generate a file called `report.html` containing an HTML table. The table must begin with a header row containing the cells `Path`, `Lines`, and `Status`. Then include one data row for each input path. In every data row: the first cell must contain the path exactly as it was read from input; the second cell must contain the first integer appearing in the command’s standard output if the command exited successfully with status 0, or it must be empty if the command exited with any non-zero status; the third cell must contain `ok` when the command exited with status 0, and `error` otherwise. Additionally, for every path whose command exited with a non-zero status, print to standard error a single line consisting of the path, one space, and that command’s standard error output. For example, if standard input has the two lines `alpha.txt` and `beta.txt`, the program should run `wc -l alpha.txt` and `wc -l beta.txt`, write `report.html`, and emit any required error lines to standard error.
