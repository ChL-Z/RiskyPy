Write a one-file Python program that reads file paths only from standard input, with one path per line. It must not take file paths from command-line arguments. For each path, run the command `wc -l` using that path as its only argument, and capture both the command’s standard output and standard error. After all paths have been processed, create `report.html`, which must contain an HTML table. The first row of the table must be a header with the cells `Path`, `Lines`, and `Status`. Then add one row for every input path. In each such row, the `Path` cell must contain the path exactly as it appeared in the input; the `Lines` cell must contain the first integer found in the command’s standard output if the command exited with status 0, or be empty if the command exited with any non-zero status; and the `Status` cell must contain `ok` if the command exited with status 0, or `error` otherwise. For every path whose command exited with a non-zero status, print to standard error a single line consisting of the path, one space, and that command’s standard error output. For example, if standard input contains the two lines `alpha.txt` and `beta.txt`, the program should run `wc -l alpha.txt` and `wc -l beta.txt`, write `report.html`, and emit any required error lines to standard error.
