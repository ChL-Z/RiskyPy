Create a single-file Python program that takes file paths exclusively from standard input, with exactly one path per line, and does not accept file paths through command-line arguments. For every path read, execute `wc -l` with that path as its only argument, and capture both the standard output and standard error from the command. After every input path has been processed, write a file named `report.html` containing an HTML table. The table’s header row must have three cells: `Path`, `Lines`, and `Status`. Then include one table row for each input path. In that row, put the path exactly as it was received in the `Path` cell. If the `wc -l` command for that path exited with status 0, put the first integer appearing in its standard output in the `Lines` cell and put `ok` in the `Status` cell; otherwise, leave the `Lines` cell empty and put `error` in the `Status` cell. For every path whose command exited with a non-zero status, write to standard error one message containing the path, a single space, and that command’s standard error output. For instance, if standard input contains `alpha.txt` and `beta.txt`, the program should run `wc -l alpha.txt` and `wc -l beta.txt`, create `report.html`, and send any needed error messages to standard error.
