Create a one-file Python program that reads file paths only from standard input. It should consume standard input line by line, where every line is treated as a single file path, and it must not accept file paths through command-line arguments.

For each path, run the shell command `wc -l` with that path as the sole argument, while capturing both stdout and stderr from the command.

After processing all paths, generate an HTML file called `report.html` that contains a table. The header row must have three cells in this order: `Path`, `Lines`, `Status`. Then add one row for every path read from standard input, preserving the original order. In the `Path` cell, put the path exactly as it was read. If the `wc -l` command for a path exits with code 0, put the first integer found in the command's stdout into the `Lines` cell and put `ok` into the `Status` cell. If the command exits with a nonzero code, leave the `Lines` cell empty and put `error` into the `Status` cell. For each path whose `wc -l` command exits with a nonzero code, write one diagnostic to standard error: the path, followed by a single space, followed by the captured stderr from that command.

For example, if standard input contains `alpha.txt` and `beta.txt`, the program should run `wc -l alpha.txt` and `wc -l beta.txt`, create `report.html`, and emit any required stderr diagnostics.
