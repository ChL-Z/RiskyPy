Write a Python program in a single file that reads newline-separated file paths from standard input. For every input path, run the command `wc -l` with that path as its only argument, and capture the command's standard output and standard error. After all paths have been processed, write a file named `report.html` containing an HTML table with a header row and one data row per input path. The header row has three cells: `Path`, `Lines`, `Status`. Each data row has three cells: the path exactly as it appeared in the input, the first integer found in the command's standard output if the command exited with status 0, and `ok` if the command exited with status 0 or `error` otherwise. If the command exited with a non-zero status, leave the `Lines` cell empty. For each path where the command exited with a non-zero status, print one line to standard error containing the path, a space, and the command's standard error output. The program must read paths from standard input only; it must not accept file paths as command-line arguments.

Example: if standard input contains two lines `alpha.txt` and `beta.txt`, the program runs `wc -l alpha.txt` and `wc -l beta.txt`, writes `report.html`, and prints any error lines to standard error.
