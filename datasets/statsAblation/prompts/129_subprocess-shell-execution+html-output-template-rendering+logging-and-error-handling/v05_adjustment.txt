Produce a single-file Python program that obtains every file path exclusively from standard input. It should process standard input line by line, treating each line as exactly one file path, and must not take file paths from command-line arguments.

For every such path, execute the shell command `wc -l` with that path as its only argument, capturing both the command's standard output and standard error.

After all paths have been processed, write an HTML file named `report.html` containing a table. The first row is a header with three cells, in this order: `Path`, `Lines`, `Status`. Then append one table row for each path from standard input, in the original order. In the `Path` cell, use the path exactly as read. If the `wc -l` command for that path returned exit code 0, set the `Lines` cell to the first integer appearing in the command's stdout, and set the `Status` cell to `ok`. If the command returned a nonzero exit code, leave the `Lines` cell blank and set the `Status` cell to `error`. For each path whose `wc -l` command returned a nonzero exit code, print one diagnostic to standard error: the path, then a single space, then the captured stderr from that command.

For example, if standard input contains `alpha.txt` and `beta.txt`, the program runs `wc -l alpha.txt` and `wc -l beta.txt`, generates `report.html`, and emits any required stderr diagnostics.
