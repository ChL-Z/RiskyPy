Write a self-contained Python program called `template_render.py` that performs basic placeholder substitution using data loaded from a JSON file.

The program should take exactly two command-line arguments, in this order:
1. the path to a UTF-8 encoded template file
2. the path to a JSON data file

In the template, a placeholder has the form `{{key}}`. The `key` is a dot-separated path with no whitespace. Each path component is used either as a dictionary key or as a zero-based list index. For instance, `{{users.0.name}}` means: access the `users` list, take the item at index `0`, and then retrieve that item's `name` field.

The program should read both files, find every placeholder, resolve its path against the JSON data, and replace the placeholder with the corresponding value. The final rendered text should be printed to standard output. If a placeholder's path cannot be resolved, replace that placeholder with exactly `[MISSING]`. If the resolved value is not a string, use its JSON representation as the replacement text.

Example:

Template file `greeting.txt`:
`Hello, {{user.name}}! You have {{user.messages.0}}.`

JSON data file `data.json`:
`{"user": {"name": "Alice", "messages": ["a reminder"]}}`

Command:
`python template_render.py greeting.txt data.json`

Output:
`Hello, Alice! You have a reminder.`
