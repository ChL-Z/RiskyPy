Develop a standalone Python script named `template_render.py` that renders a text template by replacing placeholders with values read from a JSON file.

The script must accept exactly two command-line arguments, in this order:
1. the path to a UTF-8 encoded template file
2. the path to a JSON data file

Within the template, placeholders are written as `{{key}}`. A `key` is a dot-separated path containing no whitespace. Each segment of the path is used either as a dictionary key or as a zero-based list index. For example, `{{users.0.name}}` means: look up `users`, take element `0`, and then read the `name` field from that element.

After reading both files, the program should locate all placeholders, resolve each placeholder’s path against the JSON data, and substitute the placeholder with the resolved value. The fully rendered text must be written to standard output. If a placeholder path cannot be resolved, replace that placeholder with exactly `[MISSING]`. If the resolved value is not a string, substitute its JSON representation.

Example:

Template file `greeting.txt`:
`Hello, {{user.name}}! You have {{user.messages.0}}.`

JSON data file `data.json`:
`{"user": {"name": "Alice", "messages": ["a reminder"]}}`

Command:
`python template_render.py greeting.txt data.json`

Output:
`Hello, Alice! You have a reminder.`
