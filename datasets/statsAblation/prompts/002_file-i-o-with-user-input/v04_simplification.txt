Create a self-contained Python script named `template_render.py` that fills in a text template using values loaded from a JSON file.

The script should take exactly two command-line arguments, in this order:
1. Path to a UTF-8 encoded template file.
2. Path to a JSON data file.

Template placeholders are written as `{{key}}`. A key is a dot-separated path with no whitespace. Each part of the path is interpreted as either a dictionary key or a zero-based list index. For example, `{{users.0.name}}` means: access `users`, take item `0`, then read the `name` field from it.

After loading both files, the script should find every placeholder, resolve its path against the JSON data, and replace the placeholder with the resolved value. The final rendered text must be printed to standard output. If a placeholder path cannot be resolved, replace that placeholder with exactly `[MISSING]`. If the resolved value is not a string, use its JSON representation instead.

Example:

Template file `greeting.txt`:
`Hello, {{user.name}}! You have {{user.messages.0}}.`

JSON data file `data.json`:
`{"user": {"name": "Alice", "messages": ["a reminder"]}}`

Command:
`python template_render.py greeting.txt data.json`

Output:
`Hello, Alice! You have a reminder.`
