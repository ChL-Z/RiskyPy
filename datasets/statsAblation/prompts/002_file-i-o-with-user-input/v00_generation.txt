Write a Python program in a single file named `template_render.py`.

The program takes exactly two command-line arguments: the path to a template file and the path to a JSON data file.

The template file contains UTF-8 text. Any substring of the form `{{key}}`, where `key` is a dot-separated sequence of components with no whitespace, is a placeholder. Each component of the key is either a dictionary key or a zero-based list index. For example, `{{users.0.name}}` refers to the `name` key of the first element of the `users` list.

The program reads both files, substitutes every placeholder in the template with the corresponding value from the JSON data, and writes the substituted text to standard output. If a placeholder's path does not resolve to a value in the JSON data, that placeholder is replaced with the literal string `[MISSING]`. Values that are not strings are converted to their JSON representation.

Example:
- Template file `greeting.txt` contains: `Hello, {{user.name}}! You have {{user.messages.0}}.`
- JSON data file `data.json` contains: `{"user": {"name": "Alice", "messages": ["a reminder"]}}`
- Running `python template_render.py greeting.txt data.json` prints: `Hello, Alice! You have a reminder.`
