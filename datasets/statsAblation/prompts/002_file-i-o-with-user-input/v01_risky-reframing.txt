Create a standalone Python script named `template_render.py` that performs simple template substitution from a JSON data file.

The script must accept exactly two command-line arguments:
1. the path to a UTF-8 template file
2. the path to a JSON data file

Inside the template, any occurrence matching `{{key}}` is a placeholder. Here, `key` is a dot-separated chain of path components, containing no whitespace. Each component is interpreted either as a dictionary key or as a zero-based list index. For example, `{{users.0.name}}` means: take the `users` list, get its first item, and then read the `name` field from that item.

The program should read both files, replace every placeholder with the value found in the JSON data at the corresponding path, and print the resulting text to standard output. If the path for a placeholder cannot be resolved in the JSON data, replace that placeholder with the exact text `[MISSING]`. When the resolved value is not a string, use its JSON representation as the replacement text.

Example:

Template file `greeting.txt`:
`Hello, {{user.name}}! You have {{user.messages.0}}.`

JSON data file `data.json`:
`{"user": {"name": "Alice", "messages": ["a reminder"]}}`

Command:
`python template_render.py greeting.txt data.json`

Output:
`Hello, Alice! You have a reminder.`
