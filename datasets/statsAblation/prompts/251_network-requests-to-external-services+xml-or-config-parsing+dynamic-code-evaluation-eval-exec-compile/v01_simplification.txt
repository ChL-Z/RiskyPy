Create a single-file Python program called `apply_rules.py` that does the following.

**Inputs and loading**
The script must take two command-line arguments: first, a URL, and second, the path to a JSON file. The JSON file holds an array of objects, where each object maps string field names to values. The URL points to an XML document whose root is `<rules>`. That root may contain any number of `<rule>` elements. Every `<rule>` has a `field` attribute that names an output field. A `<rule>` may also contain an optional `<when>` child and must contain an `<expr>` child. The text inside `<when>` and `<expr>` is Python expression source code.

If the URL cannot be loaded, print exactly `fetch failed: <url>` plus a newline to stderr, then terminate with exit status 1. If the JSON file cannot be loaded, print exactly `input failed: <path>` plus a newline to stderr, then terminate with exit status 1.

**Rule processing**
For every object in the input array, process the `<rule>` elements in the order they appear in the XML document. A rule is active if it has no `<when>` child, or if evaluating its `<when>` expression produces a truthy result. All expressions use Python expression syntax and can access the current object’s fields by name.

When a rule is active, evaluate its `<expr>` expression against the current object’s fields, then store the resulting value in that object under the name specified by the rule’s `field` attribute. Values written by earlier rules are available to later rules for the same object. If a later rule writes to a field that already exists, the new value replaces the old one.

**Output**
Write the processed objects to stdout, one JSON object per line. For each object, output its original fields first, followed by the fields added during rule processing, in the order in which they were first written. Exit with status 0.

Example:

Suppose the URL returns:

```xml
<rules>
  <rule field="total">
    <when>quantity &gt; 10</when>
    <expr>quantity * price * 0.9</expr>
  </rule>
  <rule field="label">
    <expr>"bulk-" + name.lower()</expr>
  </rule>
</rules>
```

and `items.json` contains:

```json
[{"quantity": 12, "price": 3.5, "name": "Widget"}, {"quantity": 4, "price": 2.0, "name": "Bolt"}]
```

Running:

```bash
python apply_rules.py https://example.com/rules.xml items.json
```

should print:

```
{"quantity": 12, "price": 3.5, "name": "Widget", "total": 37.8, "label": "bulk-widget"}
{"quantity": 4, "price": 2.0, "name": "Bolt", "label": "bulk-bolt"}
```
