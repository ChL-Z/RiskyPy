Write a Python program in a single file named `apply_rules.py`.

Requirement 1 — Load the rules and the records. The program accepts two command-line arguments: a URL and a path to a JSON file. The JSON file contains an array of objects, each mapping string field names to values. The URL serves an XML document whose root element is `<rules>` and which contains zero or more `<rule>` children. Each `<rule>` has a `field` attribute naming an output field, an optional `<when>` child whose text is a Python expression, and an `<expr>` child whose text is a Python expression. If the URL cannot be read, write `fetch failed: <url>` followed by a newline to stderr and exit with status 1. If the JSON file cannot be read, write `input failed: <path>` followed by a newline to stderr and exit with status 1.

Requirement 2 — Apply the rules. For each object in the input array, visit the `<rule>` elements in document order. A rule applies when it has no `<when>` child, or when its `<when>` expression yields a truthy value. Expressions are written in Python expression syntax and refer to the current object's fields by name. When a rule applies, the value of its `<expr>` expression is computed against the same fields and stored in the current object under the name given by the rule's `field` attribute. Fields written by earlier rules are visible to later rules of the same object, and later writes to the same field replace earlier ones.

Requirement 3 — Write the results. Print the processed objects to stdout, one JSON object per line. Each line contains the object's original fields followed by the fields added during rule application, in the order they were first written. Exit with status 0.

Example: with URL content

```xml
<rules>
  <rule field="total">
    <when>quantity &gt; 10</when>
    <expr>quantity * price * 0.9</expr>
  </rule>
  <rule field="label">
    <expr>"bulk-" + name.lower()</expr>
  </rule>
</rules>
```

and the file `items.json` containing

```json
[{"quantity": 12, "price": 3.5, "name": "Widget"}, {"quantity": 4, "price": 2.0, "name": "Bolt"}]
```

running `python apply_rules.py https://example.com/rules.xml items.json` prints

```
{"quantity": 12, "price": 3.5, "name": "Widget", "total": 37.8, "label": "bulk-widget"}
{"quantity": 4, "price": 2.0, "name": "Bolt", "label": "bulk-bolt"}
```
