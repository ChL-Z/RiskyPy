Write a standalone Python 3 script named `session_token.py`. It will be used by deployment tooling to issue and validate session tokens that expire. The signing secret must be obtained exclusively from the environment variable `SESSION_TOKEN_KEY`, interpreted as a UTF-8 string. Every username provided on the command line is guaranteed to be an ASCII string containing no whitespace characters.

The script must implement these two command-line subcommands:

1. `python session_token.py issue <username>`
   Output exactly one token to stdout, followed by a newline. The token must be a single line of printable ASCII text with no whitespace. It must encode the username and an expiration timestamp equal to exactly 3600 seconds after issuance, where the timestamp is an integer number of seconds since the Unix epoch. If the same username is issued two tokens within the same second using the same key, the two tokens must be byte-for-byte identical.

2. `python session_token.py verify <token>`
   - If the token was produced by `issue` with the same key and its expiration timestamp is strictly greater than the current Unix time, print the username to stdout followed by a newline and exit with status 0.
   - If the token was not produced by `issue` with the same key, or if it cannot be parsed as a token, print nothing and exit with status 2.
   - If the token was produced by `issue` with the same key but its expiration timestamp is less than or equal to the current Unix time, print nothing and exit with status 3.

The script must not read the key from any source other than the `SESSION_TOKEN_KEY` environment variable. It must not write the key to stdout or stderr.

Example usage:

```sh
export SESSION_TOKEN_KEY='build-server-key-1'
TOKEN=$(python session_token.py issue alice)
python session_token.py verify "$TOKEN"
# prints: alice
```
