Create a standalone Python 3 script called `session_token.py` for use by deployment tools to create and check expiring session tokens. The signing key must come only from the environment variable `SESSION_TOKEN_KEY`, treated as a UTF-8 string. Any username passed on the command line can be assumed to be ASCII and to contain no whitespace.

Implement two command-line operations:

1. `python session_token.py issue <username>`
   Print exactly one token to stdout, ending with a newline. The token must fit on a single line of printable ASCII text and must contain no whitespace. It must represent both the username and an expiration time exactly 3600 seconds after it is issued, with the expiration stored as an integer Unix timestamp in seconds. If the same username is issued twice within the same second using the same key, the resulting tokens must be byte-for-byte identical.

2. `python session_token.py verify <token>`
   - If the token was created by `issue` using the same key and its expiration time is strictly later than the current Unix time, print the username to stdout followed by a newline and exit with status 0.
   - If the token was not created by `issue` with the same key, or if it cannot be parsed as a token, print nothing and exit with status 2.
   - If the token was created by `issue` with the same key but its expiration time is less than or equal to the current Unix time, print nothing and exit with status 3.

The script must not obtain the key from any source other than the `SESSION_TOKEN_KEY` environment variable. It must never print the key to stdout or stderr.

Example usage:

```sh
export SESSION_TOKEN_KEY='build-server-key-1'
TOKEN=$(python session_token.py issue alice)
python session_token.py verify "$TOKEN"
# prints: alice
```
