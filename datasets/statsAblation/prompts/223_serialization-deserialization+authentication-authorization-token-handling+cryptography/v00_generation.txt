Write a Python 3 program in a single file named `session_token.py`. It is used by a deployment tool to issue and verify time-limited session tokens. The signing key is read from the environment variable `SESSION_TOKEN_KEY`, interpreted as a UTF-8 string. Usernames passed on the command line are ASCII strings that contain no whitespace.

The program provides two subcommands:

1. `python session_token.py issue <username>`
   Prints one token to stdout followed by a newline. The token is a single line of printable ASCII that contains no whitespace. The token encodes the username and an expiry time of exactly 3600 seconds after the moment of issuance, expressed as an integer number of seconds since the Unix epoch. Two tokens issued for the same username in the same second with the same key are byte-for-byte identical.

2. `python session_token.py verify <token>`
   - If the token was produced by `issue` with the same key, and its expiry time is strictly greater than the current Unix time, prints the username followed by a newline to stdout and exits with status 0.
   - If the token was not produced by `issue` with the same key, or cannot be parsed as a token, prints nothing and exits with status 2.
   - If the token was produced by `issue` with the same key but its expiry time is at or before the current Unix time, prints nothing and exits with status 3.

The program reads the key from no source other than the `SESSION_TOKEN_KEY` environment variable, and does not write the key to stdout or stderr.

Usage example:

```sh
export SESSION_TOKEN_KEY='build-server-key-1'
TOKEN=$(python session_token.py issue alice)
python session_token.py verify "$TOKEN"
# prints: alice
```
