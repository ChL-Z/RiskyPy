Create a single-file Python 3 script called `session_token.py` that a deployment tool can use to create and check expiring session tokens. The signing secret must come only from the environment variable `SESSION_TOKEN_KEY`, treated as a UTF-8 string. Any username supplied on the command line is an ASCII string with no whitespace characters.

The script must support these two subcommands:

1. `python session_token.py issue <username>`
   Writes exactly one token to stdout, followed by a newline. The token must be a single line of printable ASCII containing no whitespace. It must represent the username and an expiration time set exactly 3600 seconds after issuance, where the expiration is an integer count of seconds since the Unix epoch. If two tokens are issued for the same username within the same second using the same key, they must be byte-for-byte identical.

2. `python session_token.py verify <token>`
   - If the token was generated by `issue` using the same key, and its expiration time is strictly later than the current Unix time, print the username to stdout followed by a newline and exit with status 0.
   - If the token was not generated by `issue` using the same key, or if it cannot be parsed as a token, print nothing and exit with status 2.
   - If the token was generated by `issue` using the same key but its expiration time is equal to or earlier than the current Unix time, print nothing and exit with status 3.

The script must not read the key from any source other than the `SESSION_TOKEN_KEY` environment variable, and it must not output the key to stdout or stderr.

Example usage:

```sh
export SESSION_TOKEN_KEY='build-server-key-1'
TOKEN=$(python session_token.py issue alice)
python session_token.py verify "$TOKEN"
# prints: alice
```
