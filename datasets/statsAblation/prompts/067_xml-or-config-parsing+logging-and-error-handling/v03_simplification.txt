Write a standalone Python program named `summarize.py` that accepts exactly two positional command-line arguments: a path to an XML configuration file and a path to a newline-delimited log file.

The XML configuration must match this exact structure:

```xml
<config>
  <counters>
    <counter name="ERROR"/>
    <counter name="INFO"/>
  </counters>
</config>
```

Specifically, the root element must be `<config>`, it must contain exactly one `<counters>` child, and `<counters>` must contain one or more `<counter>` children. Every `<counter>` must have a `name` attribute. If either input file cannot be read, or if the XML does not satisfy this required structure, the program must write exactly one line to stderr beginning with `ERROR:` and then exit with status `2`.

For each line in the log file:

- Remove the trailing newline.
- If the resulting string is empty, skip that line.
- Otherwise, split the string on runs of whitespace and use the first token as the category name.
- If that category exactly matches a counter name from the XML, increment that counter by `1`.
- If it does not match any counter name, write exactly one line to stderr beginning with `WARN:` and skip that log line.

After all log lines have been processed, print to stdout one line per counter, sorted lexicographically by counter name, in the format `name=count`. Do not print anything else to stdout. All counters start at `0`.

Example usage:

Given `config.xml`:

```xml
<config>
  <counters>
    <counter name="ERROR"/>
    <counter name="INFO"/>
  </counters>
</config>
```

and `app.log`:

```
INFO started
INFO ready
DEBUG checking
ERROR failed
INFO done
```

Running:

```
python summarize.py config.xml app.log
```

should print to stdout:

```
ERROR=1
INFO=3
```

and should write one stderr line beginning with `WARN:` for the `DEBUG` line.
