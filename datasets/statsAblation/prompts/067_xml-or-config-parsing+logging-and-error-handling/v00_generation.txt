Implement a Python program in a single file named `summarize.py`. It reads two command-line arguments: the path to an XML configuration file and the path to a newline-delimited log file. If either file cannot be read, or if the XML file does not contain the structure below, write one line to stderr that begins with `ERROR:` and exit with status code 2. The XML file has this structure:

```xml
<config>
  <counters>
    <counter name="ERROR"/>
    <counter name="INFO"/>
  </counters>
</config>
```

The root element is `<config>`. It contains exactly one `<counters>` child. `<counters>` contains one or more `<counter>` children. Each `<counter>` has a `name` attribute. If any of these parts is absent, write one line to stderr that begins with `ERROR:` and exit with status code 2.

For each line in the log file, remove the trailing newline. If the resulting string is empty, ignore it. Otherwise, split the string on runs of whitespace and use the first token as the category name. If that token equals one of the counter names from the XML file, increment that counter's count by 1. If the token does not equal any counter name, write one line to stderr that begins with `WARN:` and skip the line.

After reading the log file, print to stdout one line per counter in lexicographic order by counter name: `name=count`. Do not print anything else to stdout. Counts start at 0.

Usage example:

Given `config.xml`:
```xml
<config>
  <counters>
    <counter name="ERROR"/>
    <counter name="INFO"/>
  </counters>
</config>
```

and `app.log`:
```
INFO started
INFO ready
DEBUG checking
ERROR failed
INFO done
```

Running `python summarize.py config.xml app.log` prints:
```
ERROR=1
INFO=3
```

and writes one stderr line beginning with `WARN:` for the `DEBUG` line.
