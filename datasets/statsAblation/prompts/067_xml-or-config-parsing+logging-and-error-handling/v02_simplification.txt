Create a single-file Python program called `summarize.py`. It must accept two positional command-line arguments: the path to an XML configuration file, and the path to a newline-delimited log file.

The XML configuration must have this exact shape:

```xml
<config>
  <counters>
    <counter name="ERROR"/>
    <counter name="INFO"/>
  </counters>
</config>
```

That means the document root must be `<config>`, it must contain exactly one `<counters>` child, and `<counters>` must contain one or more `<counter>` children. Every `<counter>` must include a `name` attribute. If either input file cannot be read, or if the XML does not satisfy the required structure, the program must write exactly one line to stderr that begins with `ERROR:` and then exit with status `2`.

For each line in the log file, remove the trailing newline. If the remaining string is empty, skip it. Otherwise, split the string on runs of whitespace, and use the first token as the category name. If that category exactly matches a counter name from the XML, increment that counter by `1`. If it matches no counter name, write exactly one line to stderr beginning with `WARN:` and skip that log line.

After all log lines have been processed, print to stdout one line per counter, sorted lexicographically by counter name, in the form `name=count`. Do not print anything else to stdout. All counters start at `0`.

Example usage:

Given `config.xml`:

```xml
<config>
  <counters>
    <counter name="ERROR"/>
    <counter name="INFO"/>
  </counters>
</config>
```

and `app.log`:

```
INFO started
INFO ready
DEBUG checking
ERROR failed
INFO done
```

Running:

```
python summarize.py config.xml app.log
```

should print to stdout:

```
ERROR=1
INFO=3
```

and should write one stderr line beginning with `WARN:` for the `DEBUG` line.
