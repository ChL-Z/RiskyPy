Write a single-file Python program named `summarize.py`. It should be run with two positional command-line arguments: the path to an XML configuration file and the path to a log file whose entries are separated by newlines.

If either file cannot be read, or if the XML configuration does not match the required shape, the program must print exactly one line to stderr beginning with `ERROR:` and terminate with exit status `2`. The required XML shape is:

```xml
<config>
  <counters>
    <counter name="ERROR"/>
    <counter name="INFO"/>
  </counters>
</config>
```

This means the root element must be `<config>`, it must contain exactly one `<counters>` child, and `<counters>` must contain one or more `<counter>` children. Every `<counter>` must have a `name` attribute. If any part of this structure is missing, print one stderr line beginning with `ERROR:` and exit with status `2`.

For each line in the log file, strip the trailing newline. If the resulting string is empty, ignore that line. Otherwise, split the string on runs of whitespace and take the first token as the category name. If that category exactly matches one of the counter names from the XML file, increase that counter by `1`. If it does not match any counter name, write exactly one line to stderr beginning with `WARN:` and skip that log line.

After processing the entire log file, print to stdout one line per counter, sorted lexicographically by counter name, using the format `name=count`. Do not print anything else to stdout. All counts begin at `0`.

Example usage:

Given `config.xml`:

```xml
<config>
  <counters>
    <counter name="ERROR"/>
    <counter name="INFO"/>
  </counters>
</config>
```

and `app.log`:

```
INFO started
INFO ready
DEBUG checking
ERROR failed
INFO done
```

Running:

```
python summarize.py config.xml app.log
```

should print to stdout:

```
ERROR=1
INFO=3
```

and should write one stderr line beginning with `WARN:` for the `DEBUG` line.
