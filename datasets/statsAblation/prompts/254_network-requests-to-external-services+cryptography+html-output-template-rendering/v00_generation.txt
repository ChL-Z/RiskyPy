Write a Python program in a single file named `profile.py`. The program is run from the command line as `python profile.py <email>`, where `<email>` is an email address. It must do the following:

1. Send an HTTP GET request to `https://api.example.com/users?email=<email>` (substituting the command-line value for `<email>`). Read the response body and parse it as JSON. The JSON object has the string keys `"name"` and `"bio"`.
2. Compute a 32-character lowercase hexadecimal string from the email address string.
3. Write a file named `profile.html` in the current directory. The file must be an HTML document whose body contains: an `<img>` tag with its `src` attribute set to the string `https://www.gravatar.com/avatar/` followed immediately by the 32-character lowercase hexadecimal string; an `<h1>` element whose text content is the `"name"` value; and a `<p>` element whose text content is the `"bio"` value.

For example, `python profile.py alice@example.com` must produce a `profile.html` file for the user with that email.
