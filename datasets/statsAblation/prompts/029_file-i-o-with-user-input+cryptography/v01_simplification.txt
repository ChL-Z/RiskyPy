Write a Python program in a file called `secret_store.py`. It manages a persistent mapping from string keys to string values, stored in a single file named `store.dat` located in the current working directory. When the program starts, it reads exactly one line from standard input. That line is either `set <key> <value>` or `get <key>`, where `<key>` and `<value>` are non-empty strings containing no spaces. For a `set` command, update the stored mapping and rewrite the full mapping to `store.dat`; produce no output and exit with status 0. For a `get` command, print the corresponding value followed by a newline, or print `NOT FOUND` followed by a newline if the key is not present. The contents of `store.dat` must be encrypted using the passphrase provided in the environment variable `STORE_PASSPHRASE`; the mapping must not be stored as plain text. If `store.dat` does not exist, start with an empty mapping. Example: running `echo 'set user alice' | STORE_PASSPHRASE=hunter2 python secret_store.py` and then `echo 'get user' | STORE_PASSPHRASE=hunter2 python secret_store.py` should output `alice`.
