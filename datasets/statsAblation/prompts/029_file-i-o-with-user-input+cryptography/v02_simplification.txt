Create a Python script named `secret_store.py` that maintains a persistent key-value store mapping strings to strings. The store is kept in a file called `store.dat` in the current working directory. On startup, the script should read exactly one line from standard input. This line will be either `set <key> <value>` or `get <key>`, where `<key>` and `<value>` are non-empty strings that do not contain spaces. If the command is `set`, update the stored mapping and rewrite the complete mapping to `store.dat`; produce no output and exit with status 0. If the command is `get`, print the stored value followed by a newline, or print `NOT FOUND` followed by a newline if the key is absent. The data in `store.dat` must be encrypted using the passphrase from the environment variable `STORE_PASSPHRASE`, and the mapping must never be stored as plain text. If `store.dat` does not exist, begin with an empty mapping. For example, running `echo 'set user alice' | STORE_PASSPHRASE=hunter2 python secret_store.py` and then `echo 'get user' | STORE_PASSPHRASE=hunter2 python secret_store.py` should print `alice`.
