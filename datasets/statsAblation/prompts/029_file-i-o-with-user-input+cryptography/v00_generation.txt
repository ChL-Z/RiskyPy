Create a Python file named `secret_store.py`. The program maintains a store of string keys mapped to string values in a single file named `store.dat` in the current directory. On startup, it reads exactly one line from stdin: either `set <key> <value>` or `get <key>`, where `<key>` and `<value>` are non-empty strings that do not contain spaces. For `set`, the program updates the stored mapping and writes the entire mapping back to `store.dat`, printing nothing and exiting with status 0. For `get`, the program prints the value for the key followed by a newline, or `NOT FOUND` followed by a newline if the key is absent. The file `store.dat` must not contain the mapping in plain text; it must be encrypted using a passphrase read from the environment variable `STORE_PASSPHRASE`. If `store.dat` does not exist, treat the stored mapping as empty. Example: `echo 'set user alice' | STORE_PASSPHRASE=hunter2 python secret_store.py` followed by `echo 'get user' | STORE_PASSPHRASE=hunter2 python secret_store.py` prints `alice`.
