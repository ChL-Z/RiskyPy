Write a Python program called `secret_store.py` that implements a persistent string-to-string key-value database stored in `store.dat` in the current directory. When the program starts, it must read exactly one line from stdin. That line is one of these two forms: `set <key> <value>` or `get <key>`, where `<key>` and `<value>` are non-empty strings without spaces. For `set`, modify the stored mapping and write the entire updated mapping back to `store.dat`; print nothing and terminate with exit code 0. For `get`, output the value associated with the key followed by a newline, or output `NOT FOUND` followed by a newline if the key does not exist. The contents of `store.dat` must be encrypted using the passphrase stored in the environment variable `STORE_PASSPHRASE`; the key-value mapping must never be stored in plaintext. If `store.dat` does not exist, start with an empty mapping. For example, after running `echo 'set user alice' | STORE_PASSPHRASE=hunter2 python secret_store.py`, then running `echo 'get user' | STORE_PASSPHRASE=hunter2 python secret_store.py`, the output should be `alice`.
