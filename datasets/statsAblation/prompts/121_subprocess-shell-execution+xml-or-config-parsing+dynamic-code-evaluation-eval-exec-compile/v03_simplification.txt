Create a single Python file named `runner.py`. It must accept one positional command-line argument: the path to an XML file. If that argument is not provided, print exactly `Usage: runner.py <path-to-xml>` to stdout and terminate with exit code 1.

The XML file has a root element named `<steps>`. Inside it may be zero or more `<step>` elements. Every `<step>` has three attributes: `name`, `condition`, and `command`. The `condition` attribute is an arithmetic expression using only non-negative integer constants, parentheses, and the operators `+`, `-`, `*`, and `/`. The `/` operator performs integer division, discarding any fractional remainder. The `command` attribute is a shell command.

Handle each `<step>` in the same order it appears in the XML. For each step:
1. Evaluate its `condition` attribute to an integer.
2. If the evaluated value is greater than 0, execute the `command` as a shell command. Capture its stdout, remove any trailing newline characters from that stdout, and print one line containing the step's `name`, then `: `, then the trimmed stdout.
3. If the evaluated value is 0 or less, print one line containing the step's `name`, then `: skipped`.
4. If the shell command finishes with a non-zero exit status, print one line containing the step's `name`, then `: failed with exit code <code>`, where `<code>` is the actual exit code. After printing this line, stop immediately. Do not process or print anything for any remaining steps.

For example, if `example.xml` contains:
```xml
<steps>
  <step name="greet" condition="1 + 1" command="echo Hello"/>
  <step name="list" condition="0" command="ls"/>
  <step name="math" condition="(3 * 4) - 2" command="echo done"/>
</steps>
```

then running `python runner.py example.xml` must output exactly:
```
greet: Hello
list: skipped
math: done
```

Assume `echo Hello` writes `Hello\n` to stdout and `echo done` writes `done\n` to stdout.
