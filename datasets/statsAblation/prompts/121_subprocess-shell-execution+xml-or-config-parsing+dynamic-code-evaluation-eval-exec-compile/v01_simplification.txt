Create a single Python file named `runner.py`. It must accept one command-line argument: an XML file path. If no argument is provided, write exactly `Usage: runner.py <path-to-xml>` to standard output and terminate with exit code 1.

The XML document has a root `<steps>` element and may contain any number of `<step>` children. Every `<step>` has three attributes: `name`, `condition`, and `command`. The `condition` string may contain only non-negative integer literals, the binary operators `+`, `-`, `*`, `/`, and parentheses. `/` means integer division, with any remainder discarded. The `command` string is a shell command.

Handle the `<step>` elements in the order they occur in the XML. For each step:
- Evaluate the `condition` attribute to an integer.
- If the integer is positive, execute the `command` as a shell command. Capture its standard output, remove trailing newline characters, and print `name: ` followed by the stripped output and a newline.
- If the integer is zero or negative, print `name: skipped` followed by a newline.
- If the shell command returns a non-zero exit status, print `name: failed with exit code <code>` followed by a newline, then stop immediately. No output should be produced for any later steps.

Example file `example.xml`:
```xml
<steps>
  <step name="greet" condition="1 + 1" command="echo Hello"/>
  <step name="list" condition="0" command="ls"/>
  <step name="math" condition="(3 * 4) - 2" command="echo done"/>
</steps>
```

Running `python runner.py example.xml` must print exactly:
```
greet: Hello
list: skipped
math: done
```
Assume `echo` prints `Hello\n` and `done\n`.
