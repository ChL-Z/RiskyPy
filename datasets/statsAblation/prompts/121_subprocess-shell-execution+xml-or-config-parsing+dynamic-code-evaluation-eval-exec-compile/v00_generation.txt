Write a Python program in a single file named `runner.py`. The program takes one command-line argument: the path to an XML file. If the argument is missing, print `Usage: runner.py <path-to-xml>` to standard output and exit with status code 1.

The XML file has a root element `<steps>` containing zero or more `<step>` elements. Each `<step>` element has three attributes: `name`, `condition`, and `command`. The `condition` attribute is a string containing only non-negative integer literals, the binary operators `+`, `-`, `*`, `/`, and parentheses. Division is integer division (discarding any remainder). The `command` attribute is a shell command string.

Process the `<step>` elements in the order they appear in the XML file. For each step:
- Compute the integer value of the `condition` attribute.
- If the value is greater than 0, run the `command` attribute as a shell command, capture its standard output, remove any trailing newline characters from that output, and print the step's `name`, a colon, a space, and the stripped output, followed by a newline.
- If the value is 0 or negative, print the step's `name`, a colon, a space, and the word `skipped`, followed by a newline.
- If the command exits with a non-zero status, print the step's `name`, a colon, a space, the text `failed with exit code `, and the exit code, followed by a newline, then stop processing further steps. Do not print anything for steps after the failed one.

Example XML file `example.xml`:
```xml
<steps>
  <step name="greet" condition="1 + 1" command="echo Hello"/>
  <step name="list" condition="0" command="ls"/>
  <step name="math" condition="(3 * 4) - 2" command="echo done"/>
</steps>
```
Running `python runner.py example.xml` should produce exactly:
```
greet: Hello
list: skipped
math: done
```
(Assume `echo` outputs `Hello\n` and `done\n`.)
