Write one Python program saved as `runner.py`. The program takes exactly one command-line parameter, which is the location of an XML file. If this parameter is missing, it must output exactly `Usage: runner.py <path-to-xml>` to stdout and then exit with status code 1.

The XML input has a `<steps>` root element. Under it, there can be zero or more `<step>` elements. Each `<step>` element has the attributes `name`, `condition`, and `command`. The value of `condition` is an arithmetic expression containing only non-negative integer constants, the operators `+`, `-`, `*`, `/`, and parentheses. Division with `/` is integer division, so any fractional part is discarded. The value of `command` is a shell command.

Process every `<step>` in the order it appears in the XML. For each one:
1. Compute the integer value of its `condition` attribute.
2. If that value is greater than zero, run the `command` as a shell command. Capture its stdout, strip trailing newline characters from it, and print a line consisting of the step's `name`, followed by `: `, followed by the stripped stdout.
3. If that value is zero or less, print a line consisting of the step's `name`, followed by `: skipped`.
4. If executing the shell command exits with a non-zero status, print a line consisting of the step's `name`, followed by `: failed with exit code <code>`, where `<code>` is the exit code. After printing that line, stop immediately. Do not process or output anything for later steps.

For example, given `example.xml`:
```xml
<steps>
  <step name="greet" condition="1 + 1" command="echo Hello"/>
  <step name="list" condition="0" command="ls"/>
  <step name="math" condition="(3 * 4) - 2" command="echo done"/>
</steps>
```

Running `python runner.py example.xml` must produce exactly:
```
greet: Hello
list: skipped
math: done
```
Assume `echo` writes `Hello\n` and `done\n` to stdout.
