Write a standalone Python 3 program in one file named `token_tool.py`. It must use only the standard library—no third-party dependencies. The script takes exactly one command-line argument, which must be either `sign` or `verify`.

For `sign` mode:
1. Read all of stdin as raw bytes.
2. If the input ends with exactly one `0x0A` newline byte, remove only that final byte.
3. Write to stdout a token formed by concatenating:
   - the base64url encoding of the remaining bytes, with no padding,
   - a literal `.` character,
   - the base64url encoding of a 32-byte tag, also with no padding.
4. The tag is derived from the remaining input bytes and the environment variable `TOKEN_SECRET`.

For `verify` mode:
1. Read stdin and split at the first newline. The bytes before that newline are the token; the bytes after it are the payload.
2. If the payload ends with exactly one `0x0A` newline byte, remove only that final byte.
3. Find the first `.` in the token. If there is no `.`, print `invalid` to stdout.
4. Otherwise, the part before the `.` is the base64url-encoded payload, and the part after the `.` is the base64url-encoded tag.
5. Compute the tag from the payload bytes and `TOKEN_SECRET`. If the computed tag equals the tag from the token, print `valid` to stdout; otherwise print `invalid` to stdout.

Example usage:

```
$ echo '{"user":"alice"}' | TOKEN_SECRET=abc123 python token_tool.py sign
eyJ1c2VyIjoiYWxpY2UifQ.3q2-7...
$ printf 'eyJ1c2VyIjoiYWxpY2UifQ.3q2-7...\n{"user":"alice"}' | TOKEN_SECRET=abc123 python token_tool.py verify
valid
```
