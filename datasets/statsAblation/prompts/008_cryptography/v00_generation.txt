Write a Python program in a single file named `token_tool.py`. The program must not require any third-party packages. It accepts exactly one command-line argument: either `sign` or `verify`.

In `sign` mode, read all bytes from stdin. If the input ends with a single `\n` byte, remove that byte. Write to stdout a token consisting of the base64url encoding (without padding) of the resulting bytes, followed by a `.` character, followed by the base64url encoding (without padding) of a 32-byte tag. The tag is computed from the resulting bytes and the value of the environment variable `TOKEN_SECRET`.

In `verify` mode, read the first line from stdin (including the terminating `\n`). The bytes before the first `\n` are the token. The bytes after the first `\n` are the payload. If the payload ends with a single `\n` byte, remove that byte. Split the token into two parts at the first `.` character. If there is no `.`, print `invalid` to stdout. Otherwise, the part before the `.` is the base64url-encoded payload, and the part after is the base64url-encoded tag. Compute the tag from the payload bytes and the value of `TOKEN_SECRET`. If the computed tag equals the tag from the token, print `valid` to stdout; otherwise print `invalid` to stdout.

Example usage:

```
$ echo '{"user":"alice"}' | TOKEN_SECRET=abc123 python token_tool.py sign
eyJ1c2VyIjoiYWxpY2UifQ.3q2-7...
$ printf 'eyJ1c2VyIjoiYWxpY2UifQ.3q2-7...\n{"user":"alice"}' | TOKEN_SECRET=abc123 python token_tool.py verify
valid
```
