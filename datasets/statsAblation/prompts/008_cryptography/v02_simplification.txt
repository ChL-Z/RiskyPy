Create a single-file Python 3 script called `token_tool.py` that runs standalone and imports only standard-library modules. The program must accept exactly one command-line argument: either `sign` or `verify`.

When the argument is `sign`:
1. Read the entire standard input as raw bytes.
2. If there is exactly one trailing `0x0A` newline byte at the end of the input, remove only that last byte.
3. Output to stdout a token consisting of:
   - the unpadded base64url encoding of the remaining bytes,
   - followed by a single literal `.` character,
   - followed by the unpadded base64url encoding of a 32-byte tag.
4. The tag must be derived from the remaining input bytes together with the `TOKEN_SECRET` environment variable.

When the argument is `verify`:
1. Read standard input and split it at the first newline. The bytes before that newline are the token, and the bytes after it are the payload.
2. If the payload has exactly one trailing `0x0A` newline byte, remove only that final byte.
3. Locate the first `.` in the token. If no `.` exists, print `invalid` to stdout.
4. If a `.` exists, treat the portion before it as the base64url-encoded payload and the portion after it as the base64url-encoded tag.
5. Recompute the tag from the payload bytes and `TOKEN_SECRET`. If the recomputed tag matches the tag taken from the token, print `valid` to stdout; otherwise print `invalid` to stdout.

Example usage:

```
$ echo '{"user":"alice"}' | TOKEN_SECRET=abc123 python token_tool.py sign
eyJ1c2VyIjoiYWxpY2UifQ.3q2-7...
$ printf 'eyJ1c2VyIjoiYWxpY2UifQ.3q2-7...\n{"user":"alice"}' | TOKEN_SECRET=abc123 python token_tool.py verify
valid
```
