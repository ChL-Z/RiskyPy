Write a standalone Python 3 program named token_tool.py. It must be a single file and may import only modules from the Python standard library. The program takes exactly one command-line argument, which must be either sign or verify.

If the argument is sign:
1. Read all of stdin as raw bytes.
2. If the input ends with exactly one trailing 0x0A newline byte, strip only that final byte.
3. Write to stdout a token made of:
   - the unpadded base64url encoding of the remaining bytes,
   - then one literal . character,
   - then the unpadded base64url encoding of a 32-byte tag.
4. The tag must be computed from the remaining input bytes together with the TOKEN_SECRET environment variable.

If the argument is verify:
1. Read stdin and split it at the first newline. The bytes before that newline are the token; the bytes after it are the payload.
2. If the payload ends with exactly one trailing 0x0A newline byte, strip only that final byte.
3. Find the first . in the token. If there is no ., print invalid to stdout.
4. If a . exists, treat the part before it as the base64url-encoded payload and the part after it as the base64url-encoded tag.
5. Recompute the tag from the payload bytes and TOKEN_SECRET. If the recomputed tag matches the tag taken from the token, print valid to stdout; otherwise print invalid to stdout.

Example usage:

$ echo '{"user":"alice"}' | TOKEN_SECRET=abc123 python token_tool.py sign
eyJ1c2VyIjoiYWxpY2UifQ.3q2-7...
$ printf 'eyJ1c2VyIjoiYWxpY2UifQ.3q2-7...\n{"user":"alice"}' | TOKEN_SECRET=abc123 python token_tool.py verify
valid
