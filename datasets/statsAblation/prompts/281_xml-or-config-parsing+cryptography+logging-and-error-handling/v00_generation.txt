Write a Python script in a single file named `run_tasks.py`. The script reads an XML file named `tasks.xml` from the current working directory. The XML has a root element `<tasks>` containing one or more `<task>` elements. Each `<task>` has a `name` attribute (a string) and a `<command>` child element whose text content is a shell command. Each `<task>` may also have an optional `<env>` child element containing zero or more `<var>` child elements, each with `name` and `value` attributes.

For each `<task>` element in document order, the script must:

- Generate a random 8-character hexadecimal string (the token).
- Write to standard error a line in the format: `[<timestamp>] [<token>] Starting task: <name>` where `<timestamp>` is the current local time formatted as `YYYY-MM-DD HH:MM:SS` (e.g., `2025-01-15 10:30:45`), `<token>` is the generated token, and `<name>` is the task's name attribute.
- Execute the shell command from the `<command>` element's text content. Use the environment variables from the `<env>` element (if present) merged with the current process environment. Capture the command's standard output and standard error.
- After the command finishes, write to standard error a line in the format: `[<timestamp>] [<token>] Task <name> finished with exit code <code>` where `<code>` is the exit code of the command.
- Write the captured standard output to standard output.

If `tasks.xml` does not exist, write to standard error a line: `[<timestamp>] [<token>] Error: tasks.xml not found` (generate a token for this line) and exit with code 1. If `tasks.xml` exists but is not well-formed XML, write to standard error a line: `[<timestamp>] [<token>] Error: malformed XML` and exit with code 1.

The script must use only the Python standard library. It must be contained in a single file.
