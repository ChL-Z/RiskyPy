Create a single-file standalone Python script called `inventory_export.py`. The script reads item names from standard input, one per line, and skips blank lines. It must access the SQLite database at `./stock.db`, which has an `items` table with columns `name TEXT`, `quantity INTEGER`, and `unit TEXT`. For each non-blank input name, look up the database row whose `name` is exactly equal to that input. Write all matched rows to `./export.csv` with no header. Each output row must have the form `name,quantity,unit`. The output rows must appear in the same order as the matching input names from standard input. If an input name has no matching database row, do not write anything for it. You can assume that neither `name` nor `unit` contains commas. If none of the input names match, `./export.csv` must still be created, but it should be empty. During the lookups, at most 4 lookups may be active at once, and every lookup must first wait 0.2 seconds before starting. For example, if `stock.db` contains `('gear', 12, 'box')` and `('bolt', 80, 'pack')`, then running `printf 'gear
widget
bolt
' | python inventory_export.py` should make `export.csv` contain `gear,12,box` followed by `bolt,80,pack`, in that order.
