Write a Python program in a single file named `inventory_export.py`. The program reads newline-separated item names from standard input, ignoring empty lines. The SQLite database `./stock.db` contains table `items(name TEXT, quantity INTEGER, unit TEXT)`. For each input name, retrieve from that table the row whose `name` column exactly equals the input name. Write the matching rows to `./export.csv` as lines of `name,quantity,unit` with no header, one line for each input name that has a matching row, in the same order as the names appeared on standard input. The `name` and `unit` values contain no commas. If no names have matches, create an empty `./export.csv`. While performing the lookups, allow at most 4 lookups to be in progress at any time, and wait 0.2 seconds before starting each lookup.

Example: with `stock.db` containing rows `('gear', 12, 'box')` and `('bolt', 80, 'pack')`, running `printf 'gear\nwidget\nbolt\n' | python inventory_export.py` writes `gear,12,box` and `bolt,80,pack` to `export.csv` in that order.
