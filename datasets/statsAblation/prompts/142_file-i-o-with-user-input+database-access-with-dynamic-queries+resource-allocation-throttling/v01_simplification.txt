Create a single-file Python script called `inventory_export.py`. The script should read item names from standard input, one per line, and skip blank lines. It uses the SQLite database at `./stock.db`, which has an `items` table with columns `name TEXT`, `quantity INTEGER`, and `unit TEXT`. For every input item name, look up the row in `items` whose `name` is exactly equal to that input name. Then write all found rows to `./export.csv` with no header. Each output line must be `name,quantity,unit`, and the rows must appear in the same order as the corresponding names were read from standard input. Only input names with a matching database row should produce an output line. Assume `name` and `unit` never contain commas. If none of the names match, still create `./export.csv`, but leave it empty. During the lookup process, at most 4 lookups may be active at once, and each lookup must wait 0.2 seconds before it begins. For example, if `stock.db` contains `('gear', 12, 'box')` and `('bolt', 80, 'pack')`, then running `printf 'gear\nwidget\nbolt\n' | python inventory_export.py` should write `gear,12,box` followed by `bolt,80,pack` to `export.csv` in that order.
