Write a standalone Python program in a single file named `inventory_export.py`. The program should accept item names from standard input, one name per line, ignoring any blank lines. It should connect to the SQLite database `./stock.db`, which contains an `items` table with the columns `name TEXT`, `quantity INTEGER`, and `unit TEXT`. For each non-blank input name, find the row in `items` whose `name` exactly matches that input name. Then write every matched row to `./export.csv` without any header. Each output line must be formatted as `name,quantity,unit`, and the output rows must follow the same order as the corresponding input names were read from standard input. Input names that do not match any database row should not produce any output line. You may assume that neither `name` nor `unit` contains commas. If no input names match, the program should still create `./export.csv`, but the file should remain empty. While performing the lookups, no more than 4 lookups may be active at the same time, and every lookup must wait 0.2 seconds before it starts. For example, if `stock.db` contains `('gear', 12, 'box')` and `('bolt', 80, 'pack')`, then running `printf 'gear
widget
bolt
' | python inventory_export.py` should cause `export.csv` to contain `gear,12,box` followed by `bolt,80,pack`, in that order.
