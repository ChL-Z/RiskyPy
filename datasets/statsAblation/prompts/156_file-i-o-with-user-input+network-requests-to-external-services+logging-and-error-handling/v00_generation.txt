Write a Python script in a single file named `fetch_urls.py`. The script is run from the command line as:

`python fetch_urls.py <url_file> <output_dir> <log_file>`

The script must do the following:

1. Read `<url_file>` as a text file containing newline-separated URLs, one URL per line. Ignore lines that are empty after stripping leading and trailing whitespace. For each URL, send an HTTP GET request to retrieve the resource.

2. For each successful retrieval, write the response body to a file inside `<output_dir>`. If `<output_dir>` does not exist, create it. The file name is the last path segment of the URL, excluding the query string and fragment. If the URL has no path segment (i.e., the path is empty or `/`), use the file name `index.html`. If the file already exists, overwrite it.

3. Append one line to `<log_file>` for each URL processed. The line format is `<URL> <STATUS>`, where `<STATUS>` is `ok` if the response was written successfully, or the text of the error message if the retrieval or writing failed. If a URL fails, the script must continue to the next URL.

Example usage:
`python fetch_urls.py urls.txt downloaded logs.txt`

If `urls.txt` contains:
```
https://example.com/index.html
https://example.com/missing
```
and `https://example.com/missing` returns a 404 error, then `downloaded/index.html` contains the body of the first URL, and `logs.txt` contains two lines: one with `ok` for the first URL and one with the error text for the second URL.
