Create a single-file Python program called `bootstrap.py` that serves as a simple remote bootstrap runner. It is run from the command line as:

    python bootstrap.py <script_url> <target_dir>

Requirements:

1. Retrieve the text content located at `<script_url>`. If `<target_dir>` is missing, create it, including any parent directories that do not yet exist. Store the retrieved text in `<target_dir>/bootstrap.sh`.

2. Execute `<target_dir>/bootstrap.sh` as a command with `<target_dir>` set as the working directory. Capture both its standard output and standard error together. Print the captured combined output to standard output exactly as captured, without adding any prefix or extra text. After that, append one line to `<target_dir>/install.log` containing the UTC timestamp formatted as `YYYY-MM-DDTHH:MM:SS`, followed by a single space, then the command's exit code as a decimal integer, and finally a newline. If `<target_dir>/install.log` does not exist, create it.

3. `bootstrap.py` must terminate with the same exit status code as the command executed in step 2.

Example usage:

    $ python bootstrap.py https://scripts.internal.example/setup.sh ./node-a
    reading package lists...
    installing dependencies...
    done
    $ cat ./node-a/install.log
    2024-05-01T09:14:22 0
