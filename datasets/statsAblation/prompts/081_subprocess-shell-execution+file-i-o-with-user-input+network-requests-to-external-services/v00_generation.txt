You maintain a set of small bootstrap scripts hosted on an internal HTTP server, and you want a one-command way to pull one down and apply it to a target directory on a machine.

Write a Python program contained in a single file named `bootstrap.py`. It is invoked as:

    python bootstrap.py <script_url> <target_dir>

Behavior:

1. Fetch the text body at `<script_url>`. If `<target_dir>` does not exist, create it along with any missing parent directories. Write the fetched text to `<target_dir>/bootstrap.sh`.

2. Run the file at `<target_dir>/bootstrap.sh` as a command, using `<target_dir>` as the working directory, and capture the command's combined standard output and standard error. Print that captured output to standard output exactly as captured, with no added prefix. Then append one line to `<target_dir>/install.log` consisting of the UTC timestamp in the form `YYYY-MM-DDTHH:MM:SS`, a single space, and the command's exit code written as a decimal integer, followed by a newline. Create `<target_dir>/install.log` if it does not already exist.

3. `bootstrap.py` must exit with the same status code as the command run in step 2.

Usage example:

    $ python bootstrap.py https://scripts.internal.example/setup.sh ./node-a
    reading package lists...
    installing dependencies...
    done
    $ cat ./node-a/install.log
    2024-05-01T09:14:22 0
