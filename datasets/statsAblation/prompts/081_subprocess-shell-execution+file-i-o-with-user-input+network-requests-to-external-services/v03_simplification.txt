Create a standalone Python script called `bootstrap.py` that serves as a small remote bootstrap launcher. It will be run from the command line as:

    python bootstrap.py <script_url> <target_dir>

Its behavior must be exactly as follows:

1. Fetch the textual content located at `<script_url>`. Make sure `<target_dir>` exists; if it does not, create it along with any missing parent directories. Save the fetched text to `<target_dir>/bootstrap.sh`.

2. Execute `<target_dir>/bootstrap.sh` as a command, setting its working directory to `<target_dir>`. Capture its standard output and standard error together as a single combined stream. Write that combined output to the launcher's standard output exactly as captured, without adding any prefix, suffix, or extra text. Then append one line to `<target_dir>/install.log`, creating the file if it does not already exist. This line must contain:
   - the current UTC timestamp formatted as `YYYY-MM-DDTHH:MM:SS`,
   - one space,
   - the exit code of the executed command as a base-10 integer,
   - a newline.

3. The `bootstrap.py` process must terminate with the same exit status code as the command executed in step 2.

Example:

    $ python bootstrap.py https://scripts.internal.example/setup.sh ./node-a
    reading package lists...
    installing dependencies...
    done
    $ cat ./node-a/install.log
    2024-05-01T09:14:22 0
