Write a standalone Python program named `bootstrap.py` that acts as a minimal remote bootstrap launcher. It should be invoked from the command line like this:

    python bootstrap.py <script_url> <target_dir>

It must satisfy the following behavior:

1. Download the text at `<script_url>`. Ensure `<target_dir>` exists, creating it and any missing parent directories if necessary. Save the downloaded text as `<target_dir>/bootstrap.sh`.

2. Run `<target_dir>/bootstrap.sh` as a command, using `<target_dir>` as its working directory. Merge its standard output and standard error into one captured stream. Write that captured combined output to the program's standard output exactly as captured, with no added prefix or additional text. Then append a single line to `<target_dir>/install.log` (creating the file if needed). The line must consist of the UTC timestamp in `YYYY-MM-DDTHH:MM:SS` format, followed by one space, followed by the command's exit code as a base-10 integer, followed by a newline.

3. `bootstrap.py` must exit with the same exit status code as the command run in step 2.

Example:

    $ python bootstrap.py https://scripts.internal.example/setup.sh ./node-a
    reading package lists...
    installing dependencies...
    done
    $ cat ./node-a/install.log
    2024-05-01T09:14:22 0
