Write a Python script in a single file named `run_commands.py`. The script takes two command-line arguments: the path to a text file containing commands, and the path to a log file.

The command file contains one command per line. Lines that are empty or start with `#` are ignored. For every other line, execute the command and capture its standard output and standard error. Wait for the command to finish and obtain its exit code. If an error occurs while starting the command, record exit code 127 and place the error message in the captured output.

Append one line to the log file for each executed command. The line must contain four fields separated by a single tab character:
1. The current UTC time in ISO 8601 format, e.g. `2025-01-15T10:30:00`.
2. The exact command string from the input file.
3. The exit code as an integer.
4. The captured standard output and standard error, concatenated in that order, with every newline character replaced by the two-character sequence `\n`.

After all commands have been processed, print exactly one line to standard output in the format:
`Executed: X, Succeeded: Y, Failed: Z`
where X is the number of commands executed, Y is the number of commands with exit code 0, and Z is the number of commands with a non-zero exit code. Exit with code 0 if Z is 0, otherwise exit with code 1.

If the command file does not exist, print an error message to standard error and exit with code 1.

Example usage:
```
$ cat commands.txt
echo hello
# this is a comment
false
$ python run_commands.py commands.txt run.log
Executed: 2, Succeeded: 1, Failed: 1
$ cat run.log
2025-01-15T10:30:00	echo hello	0	hello\n
2025-01-15T10:30:01	false	1	
```
(The actual timestamps will vary.)
