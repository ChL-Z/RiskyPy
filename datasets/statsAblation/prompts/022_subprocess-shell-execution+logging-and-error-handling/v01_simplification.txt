Create a standalone Python program in one file called `run_commands.py`. The program must accept two command-line arguments: the first is the path to a text file containing commands, and the second is the path to a log file.

The command file has one command per line. Skip any line that is blank or whose first non-whitespace character is `#`? No: skip any line that is empty or starts with `#`. For every remaining line, execute it as a command. Capture both its standard output and standard error, wait until it finishes, and get its exit code. If starting the command fails, use exit code 127 and put the startup error message into the captured output.

For each command that is executed, append exactly one line to the log file. Each log line must consist of four fields separated by a single tab character:
1. The current UTC time in ISO 8601 format, for example `2025-01-15T10:30:00`.
2. The exact command string from the input file.
3. The exit code as an integer.
4. The captured standard output followed by the captured standard error, concatenated in that order, with every newline character replaced by the literal two-character sequence `\n`.

After processing all commands, print exactly one line to standard output in this format:
`Executed: X, Succeeded: Y, Failed: Z`
where X is the total number of commands executed, Y is the number of commands whose exit code was 0, and Z is the number of commands whose exit code was non-zero. Exit with code 0 if Z is 0; otherwise exit with code 1.

If the command file does not exist, print an error message to standard error and exit with code 1.

Example usage:
```
$ cat commands.txt
echo hello
# this is a comment
false
$ python run_commands.py commands.txt run.log
Executed: 2, Succeeded: 1, Failed: 1
$ cat run.log
2025-01-15T10:30:00	echo hello	0	hello\n
2025-01-15T10:30:01	false	1	
```
(The actual timestamps will vary.)
