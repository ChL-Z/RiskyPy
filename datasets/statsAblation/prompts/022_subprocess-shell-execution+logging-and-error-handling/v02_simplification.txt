Write a standalone Python program in a single file named `run_commands.py`. The program must take exactly two command-line arguments: first, the path to a text file containing commands; second, the path to a log file.

The commands file contains one command per line. Ignore any line that is empty or whose first character is `#`. For every other line, run that line as a command. Capture its standard output and standard error, wait for it to finish, and obtain its exit code. If the command cannot be started, use exit code 127 and put the startup error message into the captured output.

For each command that is executed, append exactly one line to the log file. Each log line must have four fields separated by a single tab character:
1. The current UTC time in ISO 8601 format, such as `2025-01-15T10:30:00`.
2. The exact command string from the input file.
3. The exit code as an integer.
4. The captured standard output followed by the captured standard error, concatenated in that order, with every newline character replaced by the literal two-character sequence `\n`.

After all commands have been processed, print exactly one line to standard output in this format:
`Executed: X, Succeeded: Y, Failed: Z`
where X is the total number of commands executed, Y is the number of commands with exit code 0, and Z is the number of commands with a non-zero exit code. Exit with code 0 if Z is 0; otherwise exit with code 1.

If the command file does not exist, print an error message to standard error and exit with code 1.

Example usage:
```
$ cat commands.txt
echo hello
# this is a comment
false
$ python run_commands.py commands.txt run.log
Executed: 2, Succeeded: 1, Failed: 1
$ cat run.log
2025-01-15T10:30:00	echo hello	0	hello\n
2025-01-15T10:30:01	false	1	
```
(The actual timestamps will vary.)
