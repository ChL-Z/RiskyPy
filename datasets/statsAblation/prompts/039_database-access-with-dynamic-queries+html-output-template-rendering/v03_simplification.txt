Create a self-contained Python script called `report.py` that is run from the command line like this:

    python report.py <db_path> <table_name> [--where <column>=<value>] ... --out <output_path>

Here:
- `<db_path>` points to an SQLite database file.
- `<table_name>` names a table inside that database.
- Every optional `--where` argument has the form `COLUMN=VALUE`. Parse it by splitting on the first `=` only; the text before that `=` is the column, and the text after it is the value. Any number of `--where` arguments may be present, including zero.
- `--out` specifies the path of an HTML file that must be generated.

The script must satisfy these requirements:

1. Select all columns from all rows of `<table_name>` that satisfy every supplied `--where` condition, combined using AND. If no `--where` conditions are given, select every row.

2. Write an HTML file to `<output_path>` with exactly this structure: `<!DOCTYPE html>`, then `<html>`, then `<body>`, then one `<table>`, then `</body>`, then `</html>`. Inside the table:
   - The first `<tr>` must have one `<th>` for each column, in the same column order returned by the database. Each `<th>` must contain the column name as its text.
   - Every following `<tr>` must have one `<td>` for each value in the selected row, using the same column order.
   - If a value is NULL, its `<td>` must contain no text. For any other value, the `<td>` text must be `str(value)`.

For example, if `shop.db` has a table called `orders` with columns `id`, `customer`, and `total`, then running:

    python report.py shop.db orders --where customer=Acme --out acme.html

should produce `acme.html` containing a table whose header cells are `id`, `customer`, and `total`, and whose body rows are the rows from `orders` where `customer` equals `Acme`.
