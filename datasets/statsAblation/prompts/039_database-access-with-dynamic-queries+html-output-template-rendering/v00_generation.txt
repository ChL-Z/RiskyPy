Write a Python program contained in a single file named `report.py`.

The program is invoked as:

    python report.py <db_path> <table_name> [--where <column>=<value>] ... --out <output_path>

`<db_path>` is the path to an SQLite database file. `<table_name>` is the name of a table in that database. Each `--where` argument has the form `COLUMN=VALUE`; the first `=` separates the column name from the value. Zero or more `--where` arguments may be given. `--out` gives the path where the program writes an HTML file.

Requirement 1: The program reads all columns of every row of `<table_name>` whose values satisfy every given `--where` condition (conditions are combined with AND). If no `--where` arguments are given, all rows are selected.

Requirement 2: The program writes an HTML file at `<output_path>` with this content: it starts with `<!DOCTYPE html>`, then `<html>`, then `<body>`, then a single `<table>` element, then `</body>`, then `</html>`. Inside the table, the first `<tr>` contains one `<th>` element per column, in the order the database returns the columns, and the text inside each `<th>` is the column name. Each following `<tr>` contains one `<td>` element per column value of a matching row, in the same order. A `<td>` for NULL is empty; otherwise its text is the result of converting the cell value to text with Python's `str`.

Usage example: given a database file `shop.db` containing a table `orders` with columns `id`, `customer`, and `total`, running

    python report.py shop.db orders --where customer=Acme --out acme.html

writes `acme.html` containing a table whose header cells are `id`, `customer`, `total`, and whose data rows are the rows of `orders` where `customer` equals `Acme`.
