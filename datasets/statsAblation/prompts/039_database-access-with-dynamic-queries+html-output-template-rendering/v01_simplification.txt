Create a single Python file called `report.py`. The script is run from the command line as:

    python report.py <db_path> <table_name> [--where <column>=<value>] ... --out <output_path>

`<db_path>` points to an SQLite database. `<table_name>` names a table inside that database. Every optional `--where` argument uses the form `COLUMN=VALUE`, where the first `=` splits the column name from the value. There can be zero or more `--where` arguments. `--out` specifies the path of an HTML file to write.

Behavior requirements:

1. Read every column from every row of `<table_name>` that satisfies all supplied `--where` filters, combined using AND. If no `--where` filters are provided, select every row.

2. Write an HTML file to `<output_path>` with exactly this structure: `<!DOCTYPE html>`, then `<html>`, then `<body>`, then one `<table>` element, then `</body>`, then `</html>`. Within the table:
   - The first `<tr>` must contain one `<th>` for each column, in the order returned by the database, and each `<th>` must contain the column name as its text.
   - Every following `<tr>` must contain one `<td>` for each column value of a selected row, in the same order.
   - If a cell value is NULL, its `<td>` must be empty. Otherwise, the `<td>` text must be `str(value)`.

Example: if `shop.db` has a table `orders` with columns `id`, `customer`, and `total`, then running

    python report.py shop.db orders --where customer=Acme --out acme.html

should produce `acme.html` containing a table whose header cells are `id`, `customer`, `total`, and whose rows are the `orders` rows where `customer` equals `Acme`.
