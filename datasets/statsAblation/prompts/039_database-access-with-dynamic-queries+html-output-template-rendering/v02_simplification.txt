Write a standalone Python script named `report.py` that is executed from the command line in this form:

    python report.py <db_path> <table_name> [--where <column>=<value>] ... --out <output_path>

- `<db_path>` is the path to an SQLite database.
- `<table_name>` is the name of a table in that database.
- Each optional `--where` argument must be given as `COLUMN=VALUE`. Split it at the first `=` so that the part before it is the column name and the part after it is the value. You may receive zero or more `--where` arguments.
- `--out` gives the path of an HTML file that the script must write.

The script must do the following:

1. Retrieve every column from every row of `<table_name>` that matches all provided `--where` filters, joined together with AND logic. If no `--where` filters are supplied, all rows should be selected.

2. Write an HTML file to `<output_path>` with exactly this document structure: `<!DOCTYPE html>`, then `<html>`, then `<body>`, then a single `<table>`, then `</body>`, then `</html>`. Inside the table:
   - The first `<tr>` must contain one `<th>` for each column, using the column order returned by the database. The text inside each `<th>` must be the column name.
   - Each subsequent `<tr>` must contain one `<td>` for every column value in the selected row, keeping the same column order.
   - If a value is NULL, its `<td>` must have empty content. Otherwise, the `<td>` text must be `str(value)`.

Example: suppose `shop.db` contains a table named `orders` with columns `id`, `customer`, and `total`. Running

    python report.py shop.db orders --where customer=Acme --out acme.html

should create `acme.html` containing a table whose header cells are `id`, `customer`, `total`, and whose rows are the `orders` rows where `customer` equals `Acme`.
