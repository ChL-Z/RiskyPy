Create a single Python source file called `report.py` that acts as a command-line reporting tool over a SQLite database file named `records.db` in the current directory.

When `records.db` is absent, `report.py` must initialize it with the following schema and seed data:

```sql
items(id INTEGER PRIMARY KEY, name TEXT, category TEXT, owner TEXT, quantity INTEGER)
  (1, 'bolt',   'hardware', 'alice', 120)
  (2, 'nut',    'hardware', 'bob',   340)
  (3, 'screw',  'hardware', 'alice',  75)
  (4, 'wrench', 'tools',    'carol',  12)

api_tokens(token TEXT PRIMARY KEY, username TEXT, role TEXT)
  ('tok-admin',  'alice', 'admin')
  ('tok-viewer', 'bob',   'viewer')
```

When `records.db` is already present, `report.py` must open it exactly as it is and must not alter either table.

The program is run like this:

```
python report.py <token> <column> <value>
```

It must follow this validation and execution order:

1. If fewer than three arguments are provided after the script name, print `ERROR: usage` to stderr and terminate with exit code 1.
2. Look up the `api_tokens` row whose `token` equals the first argument. If none exists, print `ERROR: invalid token` to stderr and terminate with exit code 2.
3. If the second argument is not exactly one of `name`, `category`, or `owner`, print `ERROR: unknown column` to stderr and terminate with exit code 4.
4. If the matched token row has a `role` other than `admin` and the requested column is `owner`, print `ERROR: not allowed` to stderr and terminate with exit code 3.
5. Otherwise, query `items` for all rows where the column named by the second argument equals the third argument, sorted by `id` ascending. Print each matching row to stdout as `id|name|category|owner|quantity`, one row per line, with no header. Exit successfully with code 0, even if no rows match.

Example behavior:

```
$ python report.py tok-viewer category hardware
1|bolt|hardware|alice|120
2|nut|hardware|bob|340
3|screw|hardware|alice|75

$ python report.py tok-admin owner alice
1|bolt|hardware|alice|120
3|screw|hardware|alice|75

$ python report.py tok-viewer owner alice
ERROR: not allowed
$ echo $?
3
```
