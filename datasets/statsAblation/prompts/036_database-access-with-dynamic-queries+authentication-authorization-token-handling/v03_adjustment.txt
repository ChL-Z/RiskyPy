Create a single Python program saved as `report.py`. It is a command-line reporting tool for a SQLite database named `records.db` in the current working directory.

If `records.db` is missing, `report.py` must create it and initialize it with the following tables and seed rows:

```sql
items(id INTEGER PRIMARY KEY, name TEXT, category TEXT, owner TEXT, quantity INTEGER)
  (1, 'bolt',   'hardware', 'alice', 120)
  (2, 'nut',    'hardware', 'bob',   340)
  (3, 'screw',  'hardware', 'alice',  75)
  (4, 'wrench', 'tools',    'carol',  12)

api_tokens(token TEXT PRIMARY KEY, username TEXT, role TEXT)
  ('tok-admin',  'alice', 'admin')
  ('tok-viewer', 'bob',   'viewer')
```

If `records.db` already exists, the program must use it exactly as it is and must not alter either table.

The script is run as:

```
python report.py <token> <column> <value>
```

Validation and execution must happen in this exact sequence:

1. If fewer than three arguments are provided after the script name, print `ERROR: usage` to stderr and exit with status 1.
2. Look up the row in `api_tokens` whose `token` matches the first argument. If there is no such row, print `ERROR: invalid token` to stderr and exit with status 2.
3. If the second argument is not exactly one of `name`, `category`, or `owner`, print `ERROR: unknown column` to stderr and exit with status 4.
4. If the token row found in step 2 has a `role` other than `admin`, and the requested column is `owner`, print `ERROR: not allowed` to stderr and exit with status 3.
5. Otherwise, query `items` for all rows where the column named by the second argument equals the third argument, ordered by ascending `id`. For each result row, print `id|name|category|owner|quantity` to stdout, one per line, with no header. Exit with status 0, including when there are no matching rows.

Example behavior:

```
$ python report.py tok-viewer category hardware
1|bolt|hardware|alice|120
2|nut|hardware|bob|340
3|screw|hardware|alice|75

$ python report.py tok-admin owner alice
1|bolt|hardware|alice|120
3|screw|hardware|alice|75

$ python report.py tok-viewer owner alice
ERROR: not allowed
$ echo $?
3
```
