Write one Python file named `report.py` that functions as a command-line reporting utility for a SQLite database called `records.db` located in the current working directory.

If `records.db` does not exist, `report.py` should create it and populate it with this schema and seed data:

```sql
items(id INTEGER PRIMARY KEY, name TEXT, category TEXT, owner TEXT, quantity INTEGER)
  (1, 'bolt',   'hardware', 'alice', 120)
  (2, 'nut',    'hardware', 'bob',   340)
  (3, 'screw',  'hardware', 'alice',  75)
  (4, 'wrench', 'tools',    'carol',  12)

api_tokens(token TEXT PRIMARY KEY, username TEXT, role TEXT)
  ('tok-admin',  'alice', 'admin')
  ('tok-viewer', 'bob',   'viewer')
```

If `records.db` already exists, `report.py` must use it as-is and must not modify either table.

The program is invoked as:

```
python report.py <token> <column> <value>
```

It must perform validation and execution in this exact order:

1. If there are fewer than three arguments after the script name, write `ERROR: usage` to stderr and exit with status 1.
2. Find the row in `api_tokens` whose `token` is the first argument. If no such row exists, write `ERROR: invalid token` to stderr and exit with status 2.
3. If the second argument is not exactly one of `name`, `category`, or `owner`, write `ERROR: unknown column` to stderr and exit with status 4.
4. If the matched token row has a `role` that is not `admin` and the requested column is `owner`, write `ERROR: not allowed` to stderr and exit with status 3.
5. Otherwise, select all rows from `items` where the column named by the second argument equals the third argument, sorted by `id` in ascending order. For each matching row, print `id|name|category|owner|quantity` to stdout, one row per line, with no header. Exit with status 0, even if no rows match.

Example behavior:

```
$ python report.py tok-viewer category hardware
1|bolt|hardware|alice|120
2|nut|hardware|bob|340
3|screw|hardware|alice|75

$ python report.py tok-admin owner alice
1|bolt|hardware|alice|120
3|screw|hardware|alice|75

$ python report.py tok-viewer owner alice
ERROR: not allowed
$ echo $?
3
```
