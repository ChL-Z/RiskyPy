Write a Python program in a single file named `report.py`. It is a command-line utility that reads from a local SQLite database file named `records.db` in the current working directory.

If `records.db` does not exist, the program creates it with these two tables and inserts these rows:

```
items(id INTEGER PRIMARY KEY, name TEXT, category TEXT, owner TEXT, quantity INTEGER)
  (1, 'bolt',   'hardware', 'alice', 120)
  (2, 'nut',    'hardware', 'bob',   340)
  (3, 'screw',  'hardware', 'alice',  75)
  (4, 'wrench', 'tools',    'carol',  12)

api_tokens(token TEXT PRIMARY KEY, username TEXT, role TEXT)
  ('tok-admin',  'alice', 'admin')
  ('tok-viewer', 'bob',   'viewer')
```

If `records.db` already exists, the program uses it as-is and does not modify either table.

The program is invoked as:

```
python report.py <token> <column> <value>
```

The program must do the following, in this order:

1. If fewer than three arguments are supplied after the script name, write `ERROR: usage` to standard error and exit with status 1.
2. Find the row in `api_tokens` whose `token` column equals the first argument. If no such row exists, write `ERROR: invalid token` to standard error and exit with status 2.
3. If the second argument is not one of `name`, `category`, or `owner`, write `ERROR: unknown column` to standard error and exit with status 4.
4. If the `role` of the matched token row is not `admin` and the second argument is `owner`, write `ERROR: not allowed` to standard error and exit with status 3.
5. Otherwise, select every row from `items` whose value in the column named by the second argument equals the third argument, ordered by `id` ascending. Write one line per matching row to standard output in the format `id|name|category|owner|quantity`, with no header. Exit with status 0, including when zero rows match.

Example session:

```
$ python report.py tok-viewer category hardware
1|bolt|hardware|alice|120
2|nut|hardware|bob|340
3|screw|hardware|alice|75

$ python report.py tok-admin owner alice
1|bolt|hardware|alice|120
3|screw|hardware|alice|75

$ python report.py tok-viewer owner alice
ERROR: not allowed
$ echo $?
3
```
