Create a one-file Python program called `line_runner.py`. It accepts exactly one command-line argument: the path to a text file. Read and process that file in order, one line at a time. Ignore any line that is empty or contains only whitespace. For each remaining line, check its exact prefix:

- If it starts with the literal prefix `run ` (including the trailing space), treat everything after that prefix as a shell command and execute it. Pass the command’s standard output, followed immediately by its standard error, straight to the program’s own standard output. Do not add any characters before, between, or after those outputs.

- If it starts with the literal prefix `calc ` (including the trailing space), treat everything after that prefix as an arithmetic expression and evaluate it. The expression may use integer literals, parentheses, and the binary operators `+`, `-`, `*`, `/`, `//`, `%`, and `**`. If the evaluated result is an integer, output it as a normal base-10 integer. If it is not an integer, output it with exactly six digits after the decimal point.

- If a non-skipped line starts with neither `run ` nor `calc `, or if evaluating a `calc ` expression fails, output `ERROR: ` and then the original entire line.

If a command execution or arithmetic evaluation fails, move on to the next line. After finishing the entire file, terminate with exit status 0.

For example, if `tasks.txt` contains `run echo hello` followed by `calc 2 + 3 * 4`, then running `python line_runner.py tasks.txt` should output `hello` and then `14`.
