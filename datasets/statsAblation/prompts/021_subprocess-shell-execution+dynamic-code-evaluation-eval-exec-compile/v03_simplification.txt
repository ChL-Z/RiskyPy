Write a single-file Python script named `line_runner.py`. It must take exactly one command-line argument: the path to a text file. Open and process the file from top to bottom, one line at a time. Skip any line that is empty or consists only of whitespace. For every other line, inspect its exact prefix:

- If the line begins with the exact prefix `run ` (including the space), take the rest of the line as a shell command and run it. Send the command’s standard output first, then its standard error, directly to the script’s standard output. Add nothing before, between, or after these outputs.

- If the line begins with the exact prefix `calc ` (including the space), take the rest of the line as an arithmetic expression and evaluate it. The expression can contain integer literals, parentheses, and the binary operators `+`, `-`, `*`, `/`, `//`, `%`, and `**`. If the evaluated value is an integer, print it as a normal base-10 integer. If it is not an integer, print it with exactly six digits after the decimal point.

- If a non-skipped line starts with neither `run ` nor `calc `, or if evaluating a `calc ` expression fails, print `ERROR: ` followed by the original full line.

If running a command or evaluating an arithmetic expression fails, continue with the next line. After reaching the end of the file, exit with status 0.

For example, if `tasks.txt` contains `run echo hello` and then `calc 2 + 3 * 4`, running `python line_runner.py tasks.txt` should print `hello` followed by `14`.
