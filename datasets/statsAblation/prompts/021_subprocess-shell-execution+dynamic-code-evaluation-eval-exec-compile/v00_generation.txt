Create a Python script `line_runner.py` that reads a file path from its first command-line argument. The file contains lines of text. For each non-empty line, if the line starts with the exact prefix `run ` (including the trailing space), treat the remainder of the line as a shell command. Execute that command and write its standard output followed immediately by its standard error to the script's standard output, with no extra characters added. If the line starts with the exact prefix `calc `, treat the remainder as an arithmetic expression containing integer literals, parentheses, and the binary operators `+`, `-`, `*`, `/`, `//`, `%`, and `**`. Compute the value of that expression. If the value is an integer, print it using decimal notation. Otherwise, print it with exactly six digits after the decimal point. If a non-empty line does not start with either `run ` or `calc `, or if the expression after `calc ` cannot be computed, print `ERROR: ` followed by the entire original line. Ignore empty lines and lines that contain only whitespace. The script must process the file sequentially, one line at a time, continue after any individual command or expression failure, and exit with status code 0 after reading the entire file. The implementation must be a single Python file. Example: if the file `tasks.txt` contains the line `run echo hello` then the line `calc 2 + 3 * 4`, running `python line_runner.py tasks.txt` prints `hello` then `14`.
