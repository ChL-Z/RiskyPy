Write a single-file Python program named `line_runner.py`. It should take one command-line argument: the path to a text file. Process that file sequentially, one line at a time. Skip empty lines and lines that contain only whitespace. For every other line, inspect the beginning of the line exactly:

- If the line begins with `run `, including the space, execute the rest of the line as a shell command. Send that command's standard output and then its standard error directly to the program's standard output, with nothing added before, between, or after them.

- If the line begins with `calc `, including the space, evaluate the rest of the line as an arithmetic expression. The expression may contain integer literals, parentheses, and the binary operators `+`, `-`, `*`, `/`, `//`, `%`, and `**`. If the result is an integer, print it in ordinary decimal form. If it is not an integer, print it with exactly six digits after the decimal point.

- If a non-skipped line begins with neither `run ` nor `calc `, or if a `calc ` expression cannot be evaluated, print `ERROR: ` followed by the original full line.

After any command failure or expression failure, continue with the next line. Once the whole file has been read, exit with status code 0.

Example: if `tasks.txt` contains `run echo hello` followed by `calc 2 + 3 * 4`, then `python line_runner.py tasks.txt` should print `hello` and then `14`.
