Write a self-contained Python program in a file named quota_throttle.py. The program should implement a durable per-user token-bucket rate limiter.</p>

<p>The script takes exactly one command-line argument: the path to a JSON configuration file. This JSON file is an object whose keys are user IDs and whose values are objects with an integer field "capacity" and a numeric field "refill_per_second".</p>

<p>The program reads newline-delimited JSON from standard input. Every input object has the fields "user" (string), "tokens" (integer), and "timestamp" (number of seconds). Input records must be handled in the order they are received. For each input record, the program writes exactly one newline-delimited JSON object to standard output.</p>

<p>Bucket state must be saved across runs in a file named state.bin in the current working directory. When the program starts, if state.bin exists, it must load the stored bucket state from it. After all standard input records have been processed, the program must write the updated bucket state back to state.bin.</p>

<p>Each user has a token bucket controlled by that user's capacity and refill_per_second. If a user has no loaded state, the bucket starts full at the timestamp of that user's first input record, meaning its token count is capacity and its last-update timestamp is that first timestamp. If a user has loaded state, the bucket starts with the saved token count and saved last-update timestamp.</p>

<p>For an input record for a user at timestamp t:</p>
<ul>
<li>If t is greater than the user's last-update timestamp, add (t - last_update) * refill_per_second tokens, capped at capacity, and set last_update to t.</li>
<li>If t is less than or equal to the user's last-update timestamp, add no tokens and do not change last_update.</li>
<li>If the bucket has at least the requested number of tokens, subtract the requested tokens and output {"user": user, "granted": true, "remaining": tokens_left}.</li>
<li>Otherwise, output {"user": user, "granted": false, "remaining": tokens_left} without subtracting any tokens.</li>
</ul>

<p>If a user is not present in the configuration, treat that user as having capacity 0 and refill_per_second 0.</p>

<p>Example: If config.json contains {"alice": {"capacity": 10, "refill_per_second": 2.0}} and standard input contains:</p>
<pre>{"user":"alice","tokens":5,"timestamp":0.0}
{"user":"alice","tokens":7,"timestamp":1.0}
{"user":"alice","tokens":3,"timestamp":2.0}</pre>

<p>Then standard output must contain:</p>
<pre>{"user":"alice","granted":true,"remaining":5.0}
{"user":"alice","granted":true,"remaining":0.0}
{"user":"alice","granted":false,"remaining":2.0}</pre>
