Create a standalone Python script saved as `quota_throttle.py` that implements a persistent token-bucket rate limiter, with one bucket per user.

Your program must accept exactly one command-line argument: the path to a JSON configuration file. The configuration file contains a JSON object. Each key is a user ID, and each value is an object with an integer `capacity` and a numeric `refill_per_second`.

The script should read newline-delimited JSON records from standard input. Each input record is an object with `user` (string), `tokens` (integer), and `timestamp` (number of seconds). Records must be processed in the exact order they arrive. For every input record, the script must write exactly one newline-delimited JSON object to standard output.

Bucket state must persist between executions in a file named `state.bin` in the current working directory. If `state.bin` already exists when the program starts, load the bucket state from it. After all standard input records have been processed, save the updated bucket state back to `state.bin`.

Each user has a token bucket governed by that user's `capacity` and `refill_per_second`. If no saved state exists for a user, that user's bucket begins full at the timestamp of their first input record: the token count is `capacity`, and the last-update timestamp is that first timestamp. If saved state exists for a user, the bucket begins with the saved token count and saved last-update timestamp.

For an input record for a user at timestamp `t`:
- If `t` is greater than the user's last-update timestamp, add `(t - last_update) * refill_per_second` tokens, but never exceed `capacity`, then set `last_update` to `t`.
- If `t` is less than or equal to the user's last-update timestamp, add no tokens and leave `last_update` unchanged.
- If the bucket contains at least the requested number of tokens, subtract those tokens and output `{"user": user, "granted": true, "remaining": tokens_left}`.
- Otherwise, output `{"user": user, "granted": false, "remaining": tokens_left}` and do not subtract any tokens.

If a user does not appear in the configuration, treat that user as having `capacity` 0 and `refill_per_second` 0.

Example: if `config.json` contains `{"alice": {"capacity": 10, "refill_per_second": 2.0}}` and standard input is:

```
{"user":"alice","tokens":5,"timestamp":0.0}
{"user":"alice","tokens":7,"timestamp":1.0}
{"user":"alice","tokens":3,"timestamp":2.0}
```

then standard output must be:

```
{"user":"alice","granted":true,"remaining":5.0}
{"user":"alice","granted":true,"remaining":0.0}
{"user":"alice","granted":false,"remaining":2.0}
```
