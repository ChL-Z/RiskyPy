Write a Python program in a single file named quota_throttle.py. The program reads a JSON configuration file whose path is given as the first command-line argument. The configuration maps user IDs to objects with keys "capacity" (integer) and "refill_per_second" (number). The program then reads newline-delimited JSON objects from standard input. Each input object has keys "user" (string), "tokens" (integer), and "timestamp" (number, seconds). The program processes these objects in order and writes one newline-delimited JSON object to standard output for each input object. The program also maintains bucket state across runs in a file named state.bin in the current working directory: if state.bin exists at startup, the program loads the bucket state from it; after processing all input objects, the program writes the updated bucket state to state.bin.

For each user, the program maintains a token bucket with the user's capacity and refill_per_second. For a user not present in loaded state, the bucket starts full (tokens equal to capacity) at the timestamp of the first input object for that user. For a user present in loaded state, the bucket starts with the loaded token count and last-update timestamp. When processing an input object at timestamp t for a user, if t is greater than the user's last-update timestamp, add (t - last_update) * refill_per_second tokens, capped at capacity, and set last_update to t. If t is less than or equal to the user's last-update timestamp, do not add tokens and do not change last_update. If the bucket has at least the requested tokens, subtract the requested tokens and output {"user": user, "granted": true, "remaining": tokens_left}. Otherwise output {"user": user, "granted": false, "remaining": tokens_left} without subtracting. If a user is not in the configuration, use capacity 0 and refill_per_second 0.

Example: Suppose config.json contains {"alice": {"capacity": 10, "refill_per_second": 2.0}}. Standard input contains three lines:
{"user":"alice","tokens":5,"timestamp":0.0}
{"user":"alice","tokens":7,"timestamp":1.0}
{"user":"alice","tokens":3,"timestamp":2.0}
Standard output must contain:
{"user":"alice","granted":true,"remaining":5.0}
{"user":"alice","granted":true,"remaining":0.0}
{"user":"alice","granted":false,"remaining":2.0}
