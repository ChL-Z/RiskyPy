Create a single-file Python program called quota_throttle.py that implements a persistent per-user token-bucket throttle.

The script must accept one command-line argument: the path to a JSON configuration file. This config is a JSON object mapping user IDs to objects containing an integer "capacity" and a numeric "refill_per_second".

The program must read newline-delimited JSON records from standard input. Each record has the keys "user" (string), "tokens" (integer), and "timestamp" (number, in seconds). Records are processed in the order they appear. For every input record, the program must write exactly one newline-delimited JSON object to standard output.

Bucket state must persist between runs in a file named state.bin in the current working directory. If state.bin exists when the program starts, load the saved bucket state from it. After all input records have been processed, write the updated bucket state back to state.bin.

Each user has a token bucket defined by that user's capacity and refill_per_second. For a user with no loaded state, the bucket begins full at the timestamp of that user's first input record, so its token count equals capacity and its last-update timestamp equals that first timestamp. For a user with loaded state, the bucket begins with the saved token count and last-update timestamp.

When processing an input record for a user at timestamp t:
- If t is greater than the user's last-update timestamp, add (t - last_update) * refill_per_second tokens, but never exceed capacity, and set last_update to t.
- If t is less than or equal to the user's last-update timestamp, add no tokens and leave last_update unchanged.
- If the bucket contains at least the requested number of tokens, subtract the requested tokens and output {"user": user, "granted": true, "remaining": tokens_left}.
- Otherwise, output {"user": user, "granted": false, "remaining": tokens_left} without subtracting any tokens.

If a user is not present in the configuration, treat that user as having capacity 0 and refill_per_second 0.

Example:
If config.json contains {"alice": {"capacity": 10, "refill_per_second": 2.0}} and standard input contains:
{"user":"alice","tokens":5,"timestamp":0.0}
{"user":"alice","tokens":7,"timestamp":1.0}
{"user":"alice","tokens":3,"timestamp":2.0}

Then standard output must contain:
{"user":"alice","granted":true,"remaining":5.0}
{"user":"alice","granted":true,"remaining":0.0}
{"user":"alice","granted":false,"remaining":2.0}
