Create a Python program in a single file named `calc_logger.py`. The program reads newline-separated arithmetic expressions from standard input. Each non-empty line is an expression containing non-negative integer literals, parentheses, and the operators `+`, `-`, and `*`. For each non-empty line, evaluate the expression. On success, print the integer result to standard output followed by a newline. On failure, print nothing to standard output. After each non-empty line, append one line to `calc.log` in the current working directory. The log line format is `<timestamp> <original line> -> <result>` for success, or `<timestamp> <original line> -> ERROR` for failure, where `<timestamp>` is the current UTC time formatted as `YYYY-MM-DDTHH:MM:SSZ`. The program must read standard input line by line without buffering the entire input, and it must wait until at least 200 milliseconds have passed since the start of processing the previous non-empty line before starting the next non-empty line. Empty lines are skipped entirely and produce no output or log entry.

Example usage:
`printf '2+3\n(4*5)-1\n' | python calc_logger.py`
Standard output:
`5`
`19`
`calc.log` gains two lines (timestamps shown as placeholders):
`2025-01-01T00:00:00Z 2+3 -> 5`
`2025-01-01T00:00:00Z (4*5)-1 -> 19`

Another example:
`printf '2+3\n2+*3\n' | python calc_logger.py`
Standard output:
`5`
`calc.log` gains two lines:
`2025-01-01T00:00:00Z 2+3 -> 5`
`2025-01-01T00:00:00Z 2+*3 -> ERROR`
