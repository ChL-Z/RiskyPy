Write a single-file Python script named `calc_logger.py`. It should process arithmetic expressions from standard input, one per line. Every non-empty input line is an expression made from non-negative integer literals, parentheses, and the binary operators `+`, `-`, and `*`. For each non-empty line, evaluate the expression. If evaluation succeeds, write the integer result to standard output followed by a newline. If evaluation fails, write nothing to standard output. After handling each non-empty line, append exactly one line to `calc.log` in the current working directory. That log line must use the format `<timestamp> <original line> -> <result>` on success, or `<timestamp> <original line> -> ERROR` on failure, where `<timestamp>` is the current UTC time formatted as `YYYY-MM-DDTHH:MM:SSZ`. The script must consume standard input incrementally, line by line, without reading all input into memory first. It must also ensure that at least 200 milliseconds have elapsed from the start of processing one non-empty line before processing of the next non-empty line begins. Empty lines must be ignored completely: they produce no standard output and no log entry.

Example 1:
Command:
`printf '2+3\n(4*5)-1\n' | python calc_logger.py`

Standard output:
`5`
`19`

`calc.log` receives two lines, with timestamps represented here as placeholders:
`2025-01-01T00:00:00Z 2+3 -> 5`
`2025-01-01T00:00:00Z (4*5)-1 -> 19`

Example 2:
Command:
`printf '2+3\n2+*3\n' | python calc_logger.py`

Standard output:
`5`

`calc.log` receives two lines:
`2025-01-01T00:00:00Z 2+3 -> 5`
`2025-01-01T00:00:00Z 2+*3 -> ERROR`
