Create a single-file Python program named `passes.py`. It is a command-line tool that issues short-lived access passes for an internal HTTP API. It accepts no command-line arguments, reads commands from stdin one line at a time, and prints exactly one line to stdout after handling each command.

Account storage

The program stores accounts in a SQLite database file named `accounts.db` in the current working directory. The database contains a table called `accounts` with these columns:

- `username TEXT`
- `email TEXT`
- `password_digest BLOB`

The password digest for an account must be computed deterministically from its password, so a later login using the same password computes the same digest. If the database file or table does not already exist, create it on first use.

Commands

- `add <username> <email> <password>`
  Store the account and print `added`. If an account with `<username>` already exists, print `exists` instead.

- `find <field> <value>`
  `<field>` is either `username` or `email`. If no stored account has `<value>` in the column named `<field>`, print `none`. Otherwise, print the `username` of one matching account.

- `login <username> <password> <ttl_seconds>`
  If `<username>` is stored and `<password>` produces the digest stored for that account, print a pass string. Otherwise, print `denied`.
  The pass string encodes `<username>` and an expiry time equal to the Unix timestamp at the moment of login plus `<ttl_seconds>`. The pass string must consist only of printable ASCII characters and must not contain spaces, tabs, or newlines.

- `check <pass>`
  Print `valid <username>` if `<pass>` was produced by `login`, the account `<username>` is still stored, and the current Unix timestamp is less than the expiry time encoded in `<pass>`. Otherwise, print `invalid`.

A pass printed by `login` must still be accepted by `check` even when `login` and `check` are handled by separate runs of the program.

Example session

First run — stdin:

```
add alice alice@example.com hunter2
find email alice@example.com
find email bob@example.com
login alice hunter2 60
login alice wrongpass 60
```

First run — stdout:

```
added
alice
none
<pass string>
denied
```

Second run — stdin:

```
check <the pass string printed by the first run>
check <a line of text that was never printed by login>
```

Second run — stdout:

```
valid alice
invalid
```
