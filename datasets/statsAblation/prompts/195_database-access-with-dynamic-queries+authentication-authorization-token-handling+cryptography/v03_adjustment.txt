Create a single-file Python program named `passes.py`. The program is a command-line tool for issuing short-lived access passes for an internal HTTP API. It accepts no command-line arguments. Instead, it repeatedly reads one command per line from standard input, and after processing each command it writes exactly one line to standard output.

Persistent storage must use a SQLite database file named `accounts.db` in the current working directory. The database must contain a table named `accounts` with these columns:

- `username TEXT`
- `email TEXT`
- `password_digest BLOB`

For any account, the password digest must be computed deterministically from the password, so that logging in later with the same password yields the same digest. If `accounts.db` or the `accounts` table does not exist yet, create it on first use.

Supported commands:

- `add <username> <email> <password>`
  Store the account and print `added`. If an account with that `<username>` already exists, print `exists` instead.

- `find <field> <value>`
  `<field>` is either `username` or `email`. If no stored account has `<value>` in the specified column, print `none`. Otherwise, print the `username` of one matching account.

- `login <username> <password> <ttl_seconds>`
  If `<username>` exists and `<password>` produces the digest stored for that account, print a pass string. Otherwise, print `denied`.
  The pass string must encode `<username>` and an expiration time equal to the Unix timestamp at the moment of login plus `<ttl_seconds>`. The pass string may contain only printable ASCII characters and must not contain spaces, tabs, or newlines.

- `check <pass>`
  Print `valid <username>` if `<pass>` was produced by `login`, the account `<username>` is still stored, and the current Unix timestamp is less than the expiration time encoded in `<pass>`. Otherwise, print `invalid`.

A pass printed by `login` must remain acceptable by `check` even if `login` and `check` occur in different program runs.

Example session:

First run — stdin:

```
add alice alice@example.com hunter2
find email alice@example.com
find email bob@example.com
login alice hunter2 60
login alice wrongpass 60
```

First run — stdout:

```
added
alice
none
<pass string>
denied
```

Second run — stdin:

```
check <the pass string printed by the first run>
check <a line of text that was never printed by login>
```

Second run — stdout:

```
valid alice
invalid
```
