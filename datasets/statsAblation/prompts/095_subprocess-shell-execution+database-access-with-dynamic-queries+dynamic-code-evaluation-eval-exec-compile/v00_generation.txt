Write a Python program in one file called `collect.py`. It is run from a shell as

    python collect.py <spec-file> <database-file>

`<spec-file>` is a UTF-8 text file. Blank lines are skipped; every other line is a table name, one tab character, and a shell command line, in that order. `<database-file>` is the path to a SQLite database; the program creates the file when it is absent.

For each specification line, in the order the lines appear in the file:

- Run that line's command and capture its standard output as text.
- That captured output consists of one header line followed by zero or more data lines. Each line is comma-separated with no quoting and no embedded commas. The header line gives the column names; each data line gives the values of one row.
- In the database, replace any table bearing that line's table name with a table whose columns carry the header names in order, all of type TEXT, holding the data rows. Create the table when no table of that name exists.
- Write to standard output one line per specification line, containing the table name, a tab character, and the number of data rows inserted.

Example: with `sources.txt` containing

    people	cat people.csv
    cities	cat cities.csv

and `people.csv` containing

    name,age
    Alice,30
    Bob,25

the first line printed by `python collect.py sources.txt data.db` is `people`, a tab, and `2`.
