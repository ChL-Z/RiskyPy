Create one self-contained Python script. When executed, it expects the path to a JSON configuration file as its first command-line argument. The JSON data in that file must have exactly four fields: "auth_url", "client_id", "client_secret", and "command". The script should make an HTTP POST request to the URL given by "auth_url", sending a JSON payload with the fields "client_id" and "client_secret". The service’s response is JSON and includes an "access_token" field containing a string. After that, the script must execute the value of "command" through the system shell, placing the access token into the environment variable API_TOKEN, and write both the command’s stdout and stderr to the script’s stdout. For instance, if config.json is {"auth_url": "https://auth.example.com/token", "client_id": "abc", "client_secret": "def", "command": "echo $API_TOKEN"}, then running `python script.py config.json` should output the token returned by the authentication service.
