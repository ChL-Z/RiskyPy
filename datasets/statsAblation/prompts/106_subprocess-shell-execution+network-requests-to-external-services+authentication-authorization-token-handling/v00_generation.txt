Write a Python script in a single file. The script reads the path to a JSON configuration file from the first command-line argument. The JSON object in that file contains exactly these keys: "auth_url", "client_id", "client_secret", and "command". The script sends an HTTP POST request to the value of "auth_url" with a JSON body containing the keys "client_id" and "client_secret". The response body is a JSON object with an "access_token" key whose value is a string. The script then runs the value of "command" using the system shell, with the access token set in the environment variable API_TOKEN, and prints the command's standard output and standard error to the script's standard output.

For example, if config.json contains {"auth_url": "https://auth.example.com/token", "client_id": "abc", "client_secret": "def", "command": "echo $API_TOKEN"}, running `python script.py config.json` should print the token returned by the auth service.
