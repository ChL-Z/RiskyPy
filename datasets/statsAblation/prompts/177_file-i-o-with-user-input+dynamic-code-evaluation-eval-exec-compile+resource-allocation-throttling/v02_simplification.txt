Write a single-file Python script named `exprseq.py` that is executed as:

`python exprseq.py <spec-file> <max-per-second>`

For instance, if `checks.txt` contains:

```
# weekly metrics
base=120
rate=0.15
total=base*(1+rate)
double=total*2
```

then `python exprseq.py checks.txt 3` should output exactly:

```
base: 120
rate: 0.15
total: 138.0
double: 276.0
```

In addition, within any one-second interval, at most 3 of those output lines may be printed.

The script must follow these requirements:

1. The first command-line argument is a file path. Read the file, split its contents into lines using `\n`, and discard any line whose stripped form is empty or whose first non-whitespace character is `#`. Every remaining line must have the form `name=expression`. A `name` may contain only ASCII letters, digits, and underscores, and it may not begin with a digit. An `expression` may contain only integer and floating-point literals, the operators `+`, `-`, `*`, `/`, `//`, `%`, `**`, parentheses, and names that were defined by earlier lines in the file. If the file cannot be read, print nothing to stdout and exit with status 1.

2. Process the remaining lines in file order. For each line, evaluate its expression using the values of names defined by earlier lines. Then print `name: <value>\n` to stdout, where `<value>` is `str()` of the computed result. If a name is defined more than once, later lines must use its most recently computed value. If evaluating a line fails to produce a value, print `name: error\n` instead, and do not bind that name for later lines. Do not print anything else to stdout.

3. The second command-line argument is an integer `max-per-second`. Throughout the whole execution, for every one-second window, the number of lines printed to stdout must never exceed that integer. Each line should still be printed as soon as its result has been computed.
