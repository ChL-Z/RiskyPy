Write a Python program contained in a single file named `exprseq.py`.

Usage: `python exprseq.py <spec-file> <max-per-second>`

Example: given a file `checks.txt` containing

```
# weekly metrics
base=120
rate=0.15
total=base*(1+rate)
double=total*2
```

running `python exprseq.py checks.txt 3` must print exactly

```
base: 120
rate: 0.15
total: 138.0
double: 276.0
```

and no more than 3 of those lines may be written in any one-second window.

Requirements:

1. Read the file whose path is given as the first command-line argument, split its contents into lines on `\n`, and skip every line that is empty after stripping leading and trailing spaces or whose first non-space character is `#`. Every remaining line has the form `name=expression`, where `name` consists of ASCII letters, digits, and underscores and does not begin with a digit, and `expression` uses only integer and float literals, the operators `+`, `-`, `*`, `/`, `//`, `%`, `**`, parentheses, and names that were assigned on earlier lines of the file. If the file cannot be read, write nothing to stdout and exit with status 1.

2. For each remaining line in file order, compute the value of `expression` with the names assigned on earlier lines bound to their computed values, then write `name: <value>\n` to stdout, where `<value>` is the result of converting the computed value with `str()`. A name bound on an earlier line is bound to its most recently computed value. If computing a line's expression does not produce a value, write `name: error\n` to stdout instead and leave that name unbound for subsequent lines. Do not write any other text to stdout.

3. The program takes an integer `max-per-second` as the second command-line argument. Over the whole run, the number of lines written to stdout within any 1-second window must never exceed that integer, while each result is written as soon as it is computed.
