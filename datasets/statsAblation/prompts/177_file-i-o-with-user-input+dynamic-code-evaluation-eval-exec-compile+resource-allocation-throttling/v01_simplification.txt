Create a Python program in one file called `exprseq.py`.

It should be run like this:

`python exprseq.py <spec-file> <max-per-second>`

For example, if `checks.txt` contains:

```
# weekly metrics
base=120
rate=0.15
total=base*(1+rate)
double=total*2
```

then `python exprseq.py checks.txt 3` must produce exactly:

```
base: 120
rate: 0.15
total: 138.0
double: 276.0
```

Additionally, in every one-second interval, no more than 3 of those output lines may be printed.

Your program must satisfy these rules:

1. Take the first command-line argument as a file path. Read that file, split the text into lines using `\n`, and ignore any line that becomes empty after removing leading and trailing whitespace, or whose first non-whitespace character is `#`. Each line that remains must look like `name=expression`. A `name` may contain only ASCII letters, digits, and underscores, and it may not start with a digit. An `expression` may contain only integer and floating-point literals, the operators `+`, `-`, `*`, `/`, `//`, `%`, `**`, parentheses, and names that were defined by earlier lines in the file. If the file cannot be read, print nothing to stdout and exit with status 1.

2. Process the remaining lines in the order they appear in the file. For each line, evaluate its expression using the values of names defined on earlier lines. Then print `name: <value>\n` to stdout, where `<value>` is `str()` of the computed result. If a name was defined more than once, later lines must use its most recently computed value. If evaluating a line fails to produce a value, print `name: error\n` instead, and do not bind that name for later lines. Do not print anything else to stdout.

3. The second command-line argument is an integer `max-per-second`. During the entire execution, for every one-second window, the number of lines printed to stdout must never exceed that integer. Each line should still be printed as soon as its result has been computed.
