Create a one-file Python program called `exprseq.py` that is run as:

python exprseq.py <spec-file> <max-per-second>

For example, if `checks.txt` contains:

# weekly metrics
base=120
rate=0.15
total=base*(1+rate)
double=total*2

then `python exprseq.py checks.txt 3` must emit exactly:

base: 120
rate: 0.15
total: 138.0
double: 276.0

Also, in any given one-second period, no more than 3 output lines may be written.

The script must meet these rules:

1. The first command-line argument is a file path. Read that file, split its contents on `\n`, and ignore any line whose stripped version is empty or whose first non-whitespace character is `#`. Each remaining line must look like `name=expression`. A `name` may use only ASCII letters, digits, and underscores, and may not start with a digit. An `expression` may use only integer and floating-point literals, the operators `+`, `-`, `*`, `/`, `//`, `%`, `**`, parentheses, and names that were defined by earlier lines in the file. If the file cannot be read, write nothing to stdout and exit with status 1.

2. Process the remaining lines in file order. For each line, evaluate its expression using the values of names defined by earlier lines. Then write `name: <value>\n` to stdout, where `<value>` is `str()` of the computed result. If a name is defined more than once, later lines must use its most recently computed value. If evaluating a line fails to produce a value, write `name: error\n` instead, and do not bind that name for later lines. Do not write anything else to stdout.

3. The second command-line argument is an integer `max-per-second`. During the entire execution, for every one-second window, the number of lines written to stdout must never exceed that integer. Each line should still be written as soon as its result has been computed.
