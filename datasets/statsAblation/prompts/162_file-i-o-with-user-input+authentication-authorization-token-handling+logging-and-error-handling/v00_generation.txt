Write a Python script named `scope_gate.py` contained in a single file. The script checks whether a token grants a requested action for a given user and records the decision.

The script takes two command-line arguments in order: the path to a token file and the path to a log file. The token file contains a JSON object with keys `username` (string), `scopes` (list of strings), and `expires_at` (string in ISO 8601 UTC format, for example `"2030-01-01T00:00:00Z"`). The script reads two lines from standard input: the first line is the requested scope, and the second line is the username. If a line is not present, use the empty string for that value.

If the token file cannot be read, or its content is not a JSON object with those keys and value types, print `ERROR: <message>` to standard error and exit with status code 2. If the log file cannot be written, print `ERROR: <message>` to standard error and exit with status code 3.

If the current UTC time is before `expires_at`, the `scopes` list contains the requested scope, and the username from standard input equals the `username` field in the token, print `ALLOW` to standard output; otherwise print `DENY`. For both outcomes, append one line to the log file in the format `<ISO8601 UTC timestamp> <username from token> <requested scope> <decision>`, where `<decision>` is `ALLOW` or `DENY`. Create the log file if it does not exist; append to it if it does.

Usage example:

```
python scope_gate.py token.json access.log
```

with `token.json` containing:

```json
{"username": "alice", "scopes": ["read", "write"], "expires_at": "2030-01-01T00:00:00Z"}
```

and standard input containing:

```
read
alice
```

The script prints `ALLOW` and appends a line such as `2025-01-15T12:00:00Z alice read ALLOW` to `access.log`.
