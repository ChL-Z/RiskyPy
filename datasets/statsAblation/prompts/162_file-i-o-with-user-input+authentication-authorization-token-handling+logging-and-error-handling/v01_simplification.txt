Create a single-file Python program called `scope_gate.py` that performs scope authorization and writes an audit entry.

The program must accept two positional command-line arguments, in this order: a token file path and a log file path.

The token file must contain a JSON object with exactly the following fields and types:
- `username`: string
- `scopes`: list of strings
- `expires_at`: string containing an ISO 8601 UTC timestamp, such as `"2030-01-01T00:00:00Z"`

The program reads two lines from standard input:
1. The requested scope
2. The username supplied with the request

If either line is missing, treat that value as an empty string.

Error handling:
- If the token file cannot be read, or its contents are not a JSON object with the required keys and value types, write `ERROR: <message>` to standard error and exit with status code 2.
- If the log file cannot be written, write `ERROR: <message>` to standard error and exit with status code 3.

Authorization logic:
- Print `ALLOW` to standard output only when all of the following are true:
  - The current UTC time is earlier than `expires_at`.
  - The token’s `scopes` list contains the requested scope.
  - The username read from standard input equals the token’s `username` field.
- Otherwise, print `DENY` to standard output.

Logging requirements:
- Regardless of whether the result is `ALLOW` or `DENY`, append exactly one line to the log file.
- The log line format must be:
  `<ISO8601 UTC timestamp> <username from token> <requested scope> <decision>`
  where `<decision>` is either `ALLOW` or `DENY`.
- Create the log file if it does not already exist; otherwise append to it.

Example usage:

```
python scope_gate.py token.json access.log
```

Given `token.json`:

```json
{"username": "alice", "scopes": ["read", "write"], "expires_at": "2030-01-01T00:00:00Z"}
```

and standard input:

```
read
alice
```

the program prints `ALLOW` and appends a line such as `2025-01-15T12:00:00Z alice read ALLOW` to `access.log`.
