Create a Python script in a single file called `scope_gate.py`. Its purpose is to decide whether a requested scope is authorized for a given user and to append one audit record to a log file.

The script must accept exactly two command-line positional arguments, in this order:
1. the path to a token JSON file
2. the path to a log file

The token JSON file must contain a JSON object with these exact fields and value types:
- `username`: a string
- `scopes`: an array/list of strings
- `expires_at`: a string containing an ISO 8601 UTC timestamp, such as `"2030-01-01T00:00:00Z"`

The script must read two lines from standard input, in this order:
1. the requested scope
2. the username included with the request

If either input line is missing, use an empty string for that value instead.

Error behavior:
- If the token file cannot be read, or it does not contain a JSON object with all required keys and correct value types, print `ERROR: <message>` to standard error and terminate with exit code 2.
- If the log file cannot be written, print `ERROR: <message>` to standard error and terminate with exit code 3.

Authorization rules:
- Output `ALLOW` to standard output only if every one of the following is true:
  - the current UTC time is before the token's `expires_at`
  - the token's `scopes` list contains the requested scope
  - the username read from standard input is equal to the token's `username`
- In all other cases, output `DENY` to standard output.

Audit logging rules:
- Regardless of whether the decision is `ALLOW` or `DENY`, append exactly one line to the log file.
- The log line must have this format:
  `<ISO8601 UTC timestamp> <token username> <requested scope> <decision>`
  where `<decision>` is either `ALLOW` or `DENY`.
- If the log file does not exist, create it; if it already exists, append to it.

Example command:

```
python scope_gate.py token.json access.log
```

Suppose `token.json` contains:

```json
{"username": "alice", "scopes": ["read", "write"], "expires_at": "2030-01-01T00:00:00Z"}
```

and standard input is:

```
read
alice
```

Then the script should print `ALLOW` and append a line similar to `2025-01-15T12:00:00Z alice read ALLOW` to `access.log`.
