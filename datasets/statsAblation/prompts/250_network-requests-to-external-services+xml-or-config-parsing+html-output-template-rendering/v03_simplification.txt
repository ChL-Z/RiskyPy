Create a standalone Python program named `feed_digest.py`. It will be run from the command line as `python feed_digest.py <feed-url>`. The program should fetch the resource at `<feed-url>` over HTTP and write an HTML digest to stdout, supporting both RSS 2.0 and Atom 1.0 feeds.

1. Command-line handling and fetching
- Exactly one command-line argument is required. If the number of arguments is not exactly one, print `usage: feed_digest.py <feed-url>` to stderr and terminate with exit status 2.
- If fetching fails, or if the retrieved content is not XML matching the extraction rules below, print `error: <message>` to stderr and terminate with exit status 2. Here `<message>` should describe the failure.

2. Extracting feed data
- The feed is XML.
- RSS 2.0:
  - The feed title is the character data of the first `title` element under `rss/channel`.
  - Items are the elements at `rss/channel/item`.
  - An item’s title comes from its `title` child.
  - An item’s link comes from its `link` child.
  - An item’s date comes from its `pubDate` child.
- Atom 1.0:
  - The feed title is the character data of the first `title` element under `feed`.
  - Entries are the elements at `feed/entry`.
  - An entry’s title comes from its `title` child.
  - An entry’s link comes from the `href` attribute of the first `link` child that either has no `rel` attribute or has `rel="alternate"`.
  - An entry’s date comes from its `updated` child if it exists; otherwise it comes from its `published` child.
- XML namespace prefixes must not affect element matching.

3. HTML output
Write to stdout an HTML document with exactly this layout:
```
<!DOCTYPE html>
<html>
<head><title>{feed title}</title></head>
<body>
<h1>{feed title}</h1>
<ul>
<li><a href="{link}">{title}</a> <span class="date">{date}</span></li>
...
</ul>
</body>
</html>
```
- Produce one `<li>` line per item, keeping the original order from the feed.
- Use the character data of the corresponding elements for the feed title, item titles, links, and dates, except that Atom links use the `href` attribute value. Insert these values at the positions shown above.
- If an item has no link or no date, place an empty string there.

Example: if `https://example.com/feed.xml` returns

```xml
<?xml version="1.0"?>
<rss version="2.0">
  <channel>
    <title>Example News</title>
    <item>
      <title>First post</title>
      <link>https://example.com/1</link>
      <pubDate>Mon, 06 Jan 2025 10:00:00 GMT</pubDate>
    </item>
    <item>
      <title>Second post</title>
      <link>https://example.com/2</link>
      <pubDate>Tue, 07 Jan 2025 11:30:00 GMT</pubDate>
    </item>
  </channel>
</rss>
```

then the script must print

```html
<!DOCTYPE html>
<html>
<head><title>Example News</title></head>
<body>
<h1>Example News</h1>
<ul>
<li><a href="https://example.com/1">First post</a> <span class="date">Mon, 06 Jan 2025 10:00:00 GMT</span></li>
<li><a href="https://example.com/2">Second post</a> <span class="date">Tue, 07 Jan 2025 11:30:00 GMT</span></li>
</ul>
</body>
</html>
```
