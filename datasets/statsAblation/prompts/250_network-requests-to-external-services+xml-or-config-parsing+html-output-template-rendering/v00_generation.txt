Write a Python program in a single file named `feed_digest.py`. It prints an HTML digest document for an RSS 2.0 or Atom 1.0 feed.

Entry point: the program is run as `python feed_digest.py <feed-url>`. It retrieves the document at `<feed-url>` over HTTP and prints the resulting HTML document to stdout.

1. Retrieval and input handling. If the program is run without exactly one command-line argument, print `usage: feed_digest.py <feed-url>` to stderr and exit with status 2. If the document cannot be retrieved, or its contents do not match the element structure described in requirement 2, print `error: <message>` to stderr and exit with status 2, where `<message>` describes what failed.

2. Feed element extraction. The feed document is XML. For an RSS 2.0 document, the feed title is the text of the first `title` element inside `rss/channel`, and each item is an element at `rss/channel/item`, with its title from the `title` child, its link from the `link` child, and its date from the `pubDate` child. For an Atom 1.0 document, the feed title is the text of the first `title` element inside `feed`, and each entry is at `feed/entry`, with its title from the `title` child, its link from the `href` attribute of the first `link` child that has no `rel` attribute or has `rel="alternate"`, and its date from the `updated` child when present, otherwise the `published` child. Namespace prefixes in element names do not affect matching.

3. HTML output. Print an HTML document to stdout in this shape:
```
<!DOCTYPE html>
<html>
<head><title>{feed title}</title></head>
<body>
<h1>{feed title}</h1>
<ul>
<li><a href="{link}">{title}</a> <span class="date">{date}</span></li>
...
</ul>
</body>
</html>
```
One `<li>` line per item, in the order the items appear in the feed. The feed title, item titles, links, and dates are taken from the character data of the corresponding elements (and from the `href` attribute value for Atom links) and placed in the output at those positions. For an item whose link or date is missing, insert an empty string in that position.

Example: for input `https://example.com/feed.xml` returning

```xml
<?xml version="1.0"?>
<rss version="2.0">
  <channel>
    <title>Example News</title>
    <item>
      <title>First post</title>
      <link>https://example.com/1</link>
      <pubDate>Mon, 06 Jan 2025 10:00:00 GMT</pubDate>
    </item>
    <item>
      <title>Second post</title>
      <link>https://example.com/2</link>
      <pubDate>Tue, 07 Jan 2025 11:30:00 GMT</pubDate>
    </item>
  </channel>
</rss>
```

the program prints

```html
<!DOCTYPE html>
<html>
<head><title>Example News</title></head>
<body>
<h1>Example News</h1>
<ul>
<li><a href="https://example.com/1">First post</a> <span class="date">Mon, 06 Jan 2025 10:00:00 GMT</span></li>
<li><a href="https://example.com/2">Second post</a> <span class="date">Tue, 07 Jan 2025 11:30:00 GMT</span></li>
</ul>
</body>
</html>
```
