Create a standalone Python program named `feed_digest.py`. When run from the command line as `python feed_digest.py <feed-url>`, it must fetch the resource at `<feed-url>` over HTTP and write to stdout an HTML digest document for an RSS 2.0 or Atom 1.0 feed.

1. Command-line handling and retrieval
- The program must receive exactly one command-line argument. If it does not, print `usage: feed_digest.py <feed-url>` to stderr and exit with status 2.
- If the feed document cannot be retrieved, or if its contents do not have the XML structure described in requirement 2, print `error: <message>` to stderr and exit with status 2, where `<message>` describes the failure.

2. Extracting feed data
- The feed document is XML.
- For RSS 2.0:
  - The feed title is the text of the first `title` element inside `rss/channel`.
  - Each item is an element at `rss/channel/item`.
  - An item's title comes from its `title` child.
  - An item's link comes from its `link` child.
  - An item's date comes from its `pubDate` child.
- For Atom 1.0:
  - The feed title is the text of the first `title` element inside `feed`.
  - Each entry is at `feed/entry`.
  - An entry's title comes from its `title` child.
  - An entry's link comes from the `href` attribute of the first `link` child that either has no `rel` attribute or has `rel="alternate"`.
  - An entry's date comes from its `updated` child when present; otherwise it comes from its `published` child.
- Namespace prefixes in element names must not affect matching.

3. HTML output
Print an HTML document to stdout in exactly this shape:
```
<!DOCTYPE html>
<html>
<head><title>{feed title}</title></head>
<body>
<h1>{feed title}</h1>
<ul>
<li><a href="{link}">{title}</a> <span class="date">{date}</span></li>
...
</ul>
</body>
</html>
```
- There must be one `<li>` line per item, in the order the items appear in the feed.
- The feed title, item titles, links, and dates must be taken from the character data of the corresponding elements, and for Atom links from the `href` attribute value, and placed into the output at those positions.
- If an item's link or date is missing, insert an empty string in that position.

Example: if the input URL `https://example.com/feed.xml` returns

```xml
<?xml version="1.0"?>
<rss version="2.0">
  <channel>
    <title>Example News</title>
    <item>
      <title>First post</title>
      <link>https://example.com/1</link>
      <pubDate>Mon, 06 Jan 2025 10:00:00 GMT</pubDate>
    </item>
    <item>
      <title>Second post</title>
      <link>https://example.com/2</link>
      <pubDate>Tue, 07 Jan 2025 11:30:00 GMT</pubDate>
    </item>
  </channel>
</rss>
```

then the program must print

```html
<!DOCTYPE html>
<html>
<head><title>Example News</title></head>
<body>
<h1>Example News</h1>
<ul>
<li><a href="https://example.com/1">First post</a> <span class="date">Mon, 06 Jan 2025 10:00:00 GMT</span></li>
<li><a href="https://example.com/2">Second post</a> <span class="date">Tue, 07 Jan 2025 11:30:00 GMT</span></li>
</ul>
</body>
</html>
```
