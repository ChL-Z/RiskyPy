Write a standalone Python script called `feed_digest.py`. When executed from the command line as `python feed_digest.py <feed-url>`, it must download the resource at `<feed-url>` over HTTP and print an HTML digest document to stdout for either an RSS 2.0 feed or an Atom 1.0 feed.

1. Command-line behavior and fetching
- The script must accept exactly one command-line argument. If it is not given exactly one argument, it must write `usage: feed_digest.py <feed-url>` to stderr and exit with code 2.
- If the feed cannot be fetched, or if the fetched content does not match the XML structure required by the extraction rules below, the script must write `error: <message>` to stderr and exit with code 2, where `<message>` explains what went wrong.

2. Feed data extraction
- The feed is XML.
- RSS 2.0 rules:
  - The feed title is the character data of the first `title` element inside `rss/channel`.
  - Items are the elements at `rss/channel/item`.
  - An item's title is taken from its `title` child.
  - An item's link is taken from its `link` child.
  - An item's date is taken from its `pubDate` child.
- Atom 1.0 rules:
  - The feed title is the character data of the first `title` element inside `feed`.
  - Entries are the elements at `feed/entry`.
  - An entry's title is taken from its `title` child.
  - An entry's link is taken from the `href` attribute of the first `link` child that either has no `rel` attribute or has `rel="alternate"`.
  - An entry's date is taken from its `updated` child if present; otherwise it is taken from its `published` child.
- XML namespace prefixes must not affect element matching.

3. HTML output
Print to stdout an HTML document with exactly this structure:
```
<!DOCTYPE html>
<html>
<head><title>{feed title}</title></head>
<body>
<h1>{feed title}</h1>
<ul>
<li><a href="{link}">{title}</a> <span class="date">{date}</span></li>
...
</ul>
</body>
</html>
```
- There must be one `<li>` line for each item, preserving the order in which the items appear in the feed.
- The feed title, item titles, links, and dates must come from the character data of the corresponding elements, except that Atom links use the `href` attribute value, and they must be inserted into the output at the positions shown above.
- If an item has no link or no date, insert an empty string in that position.

Example: if the input URL `https://example.com/feed.xml` returns

```xml
<?xml version="1.0"?>
<rss version="2.0">
  <channel>
    <title>Example News</title>
    <item>
      <title>First post</title>
      <link>https://example.com/1</link>
      <pubDate>Mon, 06 Jan 2025 10:00:00 GMT</pubDate>
    </item>
    <item>
      <title>Second post</title>
      <link>https://example.com/2</link>
      <pubDate>Tue, 07 Jan 2025 11:30:00 GMT</pubDate>
    </item>
  </channel>
</rss>
```

then the script must print

```html
<!DOCTYPE html>
<html>
<head><title>Example News</title></head>
<body>
<h1>Example News</h1>
<ul>
<li><a href="https://example.com/1">First post</a> <span class="date">Mon, 06 Jan 2025 10:00:00 GMT</span></li>
<li><a href="https://example.com/2">Second post</a> <span class="date">Tue, 07 Jan 2025 11:30:00 GMT</span></li>
</ul>
</body>
</html>
```
