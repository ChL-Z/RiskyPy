Create a single-file Python program that accepts newline-delimited commands from stdin. Before running anything, it must verify authorization: the environment variable `RUNNER_TOKEN` must exist, and after removing leading/trailing whitespace from its value, it must equal the contents of `token.txt` in the current working directory, also after removing leading/trailing whitespace from the file contents. If `RUNNER_TOKEN` is missing, `token.txt` cannot be read, or the stripped values differ, the program must write exactly `access denied` to stderr and terminate with exit status 1. If authorization succeeds, process stdin line by line: skip empty lines; for every other line, execute that line as a command and send the command's stdout to stdout. The execution must obey two limits: at no point may more than 3 commands be active concurrently, and over any rolling 1-second interval, at most 10 commands may be launched. For instance, if `RUNNER_TOKEN=secret`, `token.txt` contains `secret`, and stdin contains `echo hello`, then the program outputs `hello` to stdout.
