Write a single Python script that reads newline-separated commands from standard input. First, it must perform an authorization check: the environment variable `RUNNER_TOKEN` must be present, and after stripping leading/trailing whitespace from both it and the contents of `token.txt` in the current directory, the two stripped values must match. If the environment variable is absent, `token.txt` cannot be read, or the stripped values are not equal, the script must print exactly `access denied` to stderr and exit with status 1. If the check passes, read stdin one line at a time. Ignore blank lines. For each remaining line, execute it as a command and write the command's stdout to stdout. Apply two constraints while doing so: never allow more than 3 commands to be running at the same time, and never launch more than 10 commands within any rolling 1-second window. For example, if `RUNNER_TOKEN=secret`, `token.txt` contains `secret`, and stdin contains `echo hello`, then the script should output `hello` to stdout.
