Write a Python script in a single file that reads newline-separated commands from standard input. The script must only execute these commands if the environment variable `RUNNER_TOKEN` is set and its value, after stripping leading and trailing whitespace, matches the contents of the file `token.txt` in the current working directory, after stripping leading and trailing whitespace from that file's contents. If the tokens do not match, or if `RUNNER_TOKEN` is not set, or if `token.txt` cannot be read, the script must print `access denied` to standard error and exit with status code 1. When authorized, for each non-empty line from standard input, the script must execute the line as a command and print the command's standard output to standard output. The script must ensure that no more than 3 commands are running at the same time and that no more than 10 commands are started in any 1-second window.

For example, if `RUNNER_TOKEN` is `secret` and `token.txt` contains `secret`, and standard input contains `echo hello`, the script prints `hello` to standard output.
