Create one Python script. It should accept newline-delimited commands from standard input. Before running any command, it must verify authorization: the environment variable RUNNER_TOKEN must exist, and its value after stripping leading and trailing whitespace must exactly match the contents of token.txt in the current directory after that file's contents are also stripped of leading and trailing whitespace. If RUNNER_TOKEN is missing, token.txt cannot be read, or the stripped values differ, the script must print exactly `access denied` to stderr and exit with status 1. If authorization succeeds, read stdin line by line, skip blank lines, and for every other line execute it as a command, forwarding the command's stdout to the script's stdout. While executing commands, enforce two limits: at most 3 commands may run concurrently, and no more than 10 commands may be started during any rolling 1-second interval. For example, if RUNNER_TOKEN=secret, token.txt contains secret, and stdin contains `echo hello`, then the script should write `hello` to stdout.
