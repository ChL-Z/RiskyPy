Write exactly one Python file, named `snippet_cli.py`. It must be executable as `python snippet_cli.py <command> ...`, and all persistent data must be saved in `snippets.db` in the current working directory. Implement the following CLI behavior.

1. `register <username> <password>`
   - If the username is not already stored, save the username/password and print `ok`.
   - If the username already exists, print `error: username exists` and exit with status code 1.

2. `login <username> <password>`
   - If the username/password matches a stored user, print a single token string and exit with status code 0.
   - Otherwise, print `error: login failed` and exit with status code 1.
   - Every successful login creates a token tied to that username. Tokens do not expire.

3. `add --token <token> [--tag <tag>] <text>`
   - If the token belongs to a user, save `<text>` for that user, optionally with a tag, print the new record id as an integer, and exit with status code 0.
   - If `--tag` is not present, store the tag as an empty string.
   - If the token does not belong to any user, print `error: invalid token` and exit with status code 1.

4. `list --token <token> [--tag <tag>] [--contains <substring>]`
   - If the token belongs to a user, print all records owned by that user, one per line, ordered by increasing record id, formatted as `<id>\t<text>`.
   - If `--tag` is given, include only records whose tag exactly equals the provided tag.
   - If `--contains` is given, include only records whose text contains the provided substring.
   - If both filters are given, include only records satisfying both.
   - If nothing matches, print nothing and exit with status code 0.
   - If the token does not belong to any user, print `error: invalid token` and exit with status code 1.

5. `render --token <token> <id>`
   - If the token belongs to the user who owns record `<id>`, print the record text after replacing every `{{expr}}` placeholder with the decimal integer result of evaluating `expr`.
   - Each `expr` may contain integer literals, spaces, `+`, `-`, `*`, and parentheses.
   - If the record id is missing or belongs to a different user, print `error: record not found` and exit with status code 1.
   - If the token does not belong to any user, print `error: invalid token` and exit with status code 1.

Record ids begin at 1 and increment by 1 for each newly created record. For all tested inputs, every expression inside `{{...}}` will be valid.

Example interaction:

```
$ python snippet_cli.py register alice secret
ok
$ python snippet_cli.py login alice secret
tok_abc123
$ python snippet_cli.py add --token tok_abc123 --tag math "sum {{2 + 3 * 4}}"
1
$ python snippet_cli.py add --token tok_abc123 "plain note"
2
$ python snippet_cli.py list --token tok_abc123 --contains sum
1	sum {{2 + 3 * 4}}
$ python snippet_cli.py render --token tok_abc123 1
sum 14
```
