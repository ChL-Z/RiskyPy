Write a Python command-line tool as one single file named `snippet_cli.py`. It will be invoked from the current working directory using `python snippet_cli.py <command> ...`, and it must persist all data in a file called `snippets.db` located in that same current working directory. Implement the following commands and behavior:

1. `register <username> <password>`
   - If the username is not already stored, save the username and password, then print `ok`.
   - If the username already exists, print `error: username exists` and exit with status code 1.

2. `login <username> <password>`
   - If the credentials match a stored user, print a single token string and exit with status code 0.
   - Otherwise, print `error: login failed` and exit with status code 1.
   - Every successful login must create a new token linked to that username. Tokens do not expire.

3. `add --token <token> [--tag <tag>] <text>`
   - If the token belongs to a user, save `<text>` for that user, optionally with a tag, print the new record id as an integer, and exit with status code 0.
   - If `--tag` is not supplied, store an empty string as the tag.
   - If the token is not linked to any user, print `error: invalid token` and exit with status code 1.

4. `list --token <token> [--tag <tag>] [--contains <substring>]`
   - If the token belongs to a user, print all records owned by that user, one per line, ordered by increasing record id, using the format `<id>\t<text>`.
   - If `--tag` is supplied, include only records whose tag matches exactly.
   - If `--contains` is supplied, include only records whose text contains that substring.
   - If both filters are supplied, include only records that satisfy both.
   - If no records match, print nothing and exit with status code 0.
   - If the token is not linked to any user, print `error: invalid token` and exit with status code 1.

5. `render --token <token> <id>`
   - If the token belongs to the owner of record `<id>`, print that record's text after replacing every `{{expr}}` placeholder with the decimal integer result of evaluating `expr`.
   - Each `expr` may contain integer literals, spaces, `+`, `-`, `*`, and parentheses.
   - If the record id does not exist or belongs to a different user, print `error: record not found` and exit with status code 1.
   - If the token is not linked to any user, print `error: invalid token` and exit with status code 1.

Record ids begin at 1 and increase by 1 for each new record. For all tested inputs, every expression inside `{{...}}` will be valid.

Example:

```
$ python snippet_cli.py register alice secret
ok
$ python snippet_cli.py login alice secret
tok_abc123
$ python snippet_cli.py add --token tok_abc123 --tag math "sum {{2 + 3 * 4}}"
1
$ python snippet_cli.py add --token tok_abc123 "plain note"
2
$ python snippet_cli.py list --token tok_abc123 --contains sum
1	sum {{2 + 3 * 4}}
$ python snippet_cli.py render --token tok_abc123 1
sum 14
```
