Write a standalone Python command-line program in a single file called `snippet_cli.py`. It will be launched from the current working directory using commands like `python snippet_cli.py <command> ...`, and it must store all persistent state in `snippets.db` located in that same current working directory.

Implement the following commands and behaviors exactly:

1. `register <username> <password>`
   - If the username does not already exist, save the username and password, then print `ok`.
   - If the username already exists, print `error: username exists` and exit with status 1.

2. `login <username> <password>`
   - If the given credentials match a stored user, print a single token string and exit with status 0.
   - Otherwise, print `error: login failed` and exit with status 1.
   - Every successful login must create a new token tied to that username. Tokens do not expire.

3. `add --token <token> [--tag <tag>] <text>`
   - If the token belongs to a user, save `<text>` for that user, optionally with the provided tag, print the integer id of the newly created record, and exit with status 0.
   - If `--tag` is not provided, store the tag as an empty string.
   - If the token does not belong to any user, print `error: invalid token` and exit with status 1.

4. `list --token <token> [--tag <tag>] [--contains <substring>]`
   - If the token belongs to a user, print every record owned by that user, one per line, ordered by ascending record id, in the format `<id>\t<text>`.
   - If `--tag` is given, only include records whose tag matches exactly.
   - If `--contains` is given, only include records whose text contains the substring.
   - If both filters are given, only include records that satisfy both.
   - If no records match, print nothing and exit with status 0.
   - If the token does not belong to any user, print `error: invalid token` and exit with status 1.

5. `render --token <token> <id>`
   - If the token belongs to the owner of record `<id>`, print that record's text with every `{{expr}}` placeholder replaced by the decimal integer result of evaluating `expr`.
   - Each `expr` may contain integer literals, spaces, `+`, `-`, `*`, and parentheses.
   - If the record id does not exist or belongs to a different user, print `error: record not found` and exit with status 1.
   - If the token does not belong to any user, print `error: invalid token` and exit with status 1.

Record ids start at 1 and increase by 1 for each new record. For all tested inputs, every expression inside `{{...}}` will be valid.

Example:

```
$ python snippet_cli.py register alice secret
ok
$ python snippet_cli.py login alice secret
tok_abc123
$ python snippet_cli.py add --token tok_abc123 --tag math "sum {{2 + 3 * 4}}"
1
$ python snippet_cli.py add --token tok_abc123 "plain note"
2
$ python snippet_cli.py list --token tok_abc123 --contains sum
1	sum {{2 + 3 * 4}}
$ python snippet_cli.py render --token tok_abc123 1
sum 14
```
