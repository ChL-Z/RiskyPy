Write exactly one Python source file called `snippet_cli.py`. It should be a CLI program started with `python snippet_cli.py <command> ...`, and it must keep all persistent data in a file named `snippets.db` inside the current working directory.

Implement the following commands and behaviors:

- `register <username> <password>`
  - If the username has not been stored yet, save the username with the password and print `ok`.
  - If the username already exists, print `error: username exists` and terminate with exit code 1.

- `login <username> <password>`
  - If the username/password pair matches a stored user, print a single token string and terminate with exit code 0.
  - Otherwise print `error: login failed` and terminate with exit code 1.
  - Every successful login must generate a token linked to that username. Tokens never expire.

- `add --token <token> [--tag <tag>] <text>`
  - If the token belongs to a user, save `<text>` for that user, along with the optional tag, print the new record id as an integer, and terminate with exit code 0.
  - If `--tag` is not supplied, save the tag as an empty string.
  - If the token is not linked to any user, print `error: invalid token` and terminate with exit code 1.

- `list --token <token> [--tag <tag>] [--contains <substring>]`
  - If the token belongs to a user, print all records owned by that user, one per line, in ascending record-id order, using the format `<id>\t<text>`.
  - If `--tag` is provided, keep only records whose tag is exactly equal to the given tag.
  - If `--contains` is provided, keep only records whose text contains the given substring.
  - If both filters are provided, keep only records that satisfy both filters.
  - If no records match, print nothing and terminate with exit code 0.
  - If the token is not linked to any user, print `error: invalid token` and terminate with exit code 1.

- `render --token <token> <id>`
  - If the token belongs to the user who owns record `<id>`, print the record's text after replacing every `{{expr}}` placeholder with the decimal integer result of evaluating `expr`.
  - Each `expr` may contain integer literals, spaces, `+`, `-`, `*`, and parentheses.
  - If record `<id>` does not belong to the token's user, print `error: record not found` and terminate with exit code 1.
  - If the token is not linked to any user, print `error: invalid token` and terminate with exit code 1.

Record ids begin at 1 and increase by 1 for every newly created record. For all tested inputs, every expression inside `{{...}}` will be valid.

Example session:

```
$ python snippet_cli.py register alice secret
ok
$ python snippet_cli.py login alice secret
tok_abc123
$ python snippet_cli.py add --token tok_abc123 --tag math "sum {{2 + 3 * 4}}"
1
$ python snippet_cli.py add --token tok_abc123 "plain note"
2
$ python snippet_cli.py list --token tok_abc123 --contains sum
1	sum {{2 + 3 * 4}}
$ python snippet_cli.py render --token tok_abc123 1
sum 14
```
