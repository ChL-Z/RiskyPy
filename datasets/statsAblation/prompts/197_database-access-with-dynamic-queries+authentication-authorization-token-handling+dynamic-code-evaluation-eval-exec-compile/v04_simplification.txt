Create a single Python program in exactly one file called `snippet_cli.py`. It will be run from the current working directory as `python snippet_cli.py <command> ...`, and it must keep all persistent data in a local file named `snippets.db` in that same working directory. Implement this command-line interface:

1. `register <username> <password>`
   - If the username has not been registered yet, store the username and password, then print `ok`.
   - If the username already exists, print `error: username exists` and terminate with exit code 1.

2. `login <username> <password>`
   - If the username and password match a stored user, print one token string and terminate with exit code 0.
   - Otherwise, print `error: login failed` and terminate with exit code 1.
   - Each successful login must create a token associated with that username. Tokens never expire.

3. `add --token <token> [--tag <tag>] <text>`
   - If the token is associated with a user, store `<text>` for that user, optionally with a tag, print the newly assigned record id as an integer, and terminate with exit code 0.
   - If `--tag` is omitted, store the tag as an empty string.
   - If the token is not associated with any user, print `error: invalid token` and terminate with exit code 1.

4. `list --token <token> [--tag <tag>] [--contains <substring>]`
   - If the token is associated with a user, print every record owned by that user, one per line, in ascending record-id order, in the format `<id>\t<text>`.
   - If `--tag` is provided, only include records whose tag is exactly that tag.
   - If `--contains` is provided, only include records whose text contains that substring.
   - If both filters are provided, only include records that satisfy both filters.
   - If no records match, print nothing and terminate with exit code 0.
   - If the token is not associated with any user, print `error: invalid token` and terminate with exit code 1.

5. `render --token <token> <id>`
   - If the token is associated with the user who owns record `<id>`, print the record text after replacing every `{{expr}}` placeholder with the decimal integer result of evaluating `expr`.
   - Each `expr` may contain integer literals, spaces, `+`, `-`, `*`, and parentheses.
   - If the record id does not exist or belongs to a different user, print `error: record not found` and terminate with exit code 1.
   - If the token is not associated with any user, print `error: invalid token` and terminate with exit code 1.

Record ids start at 1 and increase by 1 for every new record. For all tested inputs, every expression inside `{{...}}` will be valid.

Example interaction:

```
$ python snippet_cli.py register alice secret
ok
$ python snippet_cli.py login alice secret
tok_abc123
$ python snippet_cli.py add --token tok_abc123 --tag math "sum {{2 + 3 * 4}}"
1
$ python snippet_cli.py add --token tok_abc123 "plain note"
2
$ python snippet_cli.py list --token tok_abc123 --contains sum
1	sum {{2 + 3 * 4}}
$ python snippet_cli.py render --token tok_abc123 1
sum 14
```
