Create one Python file named `snippet_cli.py`. It is a command-line tool invoked as `python snippet_cli.py <command> ...`. All state persists in a file named `snippets.db` in the current working directory. The tool must support these commands:

- `register <username> <password>`: if `<username>` is not already stored, store it with the given password and print `ok`. If `<username>` is already stored, print `error: username exists` and exit with status 1.
- `login <username> <password>`: if the username and password match a stored user, print one token string and exit with status 0. Otherwise print `error: login failed` and exit with status 1. Each successful login creates a token associated with that username. Tokens do not expire.
- `add --token <token> [--tag <tag>] <text>`: if `<token>` is associated with a user, store `<text>` and the optional tag for that user, print the new record id as an integer, and exit with status 0. If `--tag` is omitted, store an empty string as the tag. If `<token>` is not associated with a user, print `error: invalid token` and exit with status 1.
- `list --token <token> [--tag <tag>] [--contains <substring>]`: if `<token>` is associated with a user, print all records belonging to that user, one per line as `<id>\t<text>`, ordered by record id ascending. If `--tag` is given, include only records whose tag equals the given tag. If `--contains` is given, include only records whose text contains the given substring. If both filters are given, include records that satisfy both. If no records match, print nothing and exit with status 0. If `<token>` is not associated with a user, print `error: invalid token` and exit with status 1.
- `render --token <token> <id>`: if `<token>` is associated with the user who owns record `<id>`, print that record's text after replacing every `{{expr}}` placeholder with the decimal integer result of evaluating `expr`. Each `expr` contains integer literals, spaces, `+`, `-`, `*`, and parentheses. If record `<id>` does not belong to the token's user, print `error: record not found` and exit with status 1. If `<token>` is not associated with a user, print `error: invalid token` and exit with status 1.

Record ids start at 1 and increase by 1 for each new record. For tested inputs, every `expr` inside `{{...}}` is valid.

Example session:

```
$ python snippet_cli.py register alice secret
ok
$ python snippet_cli.py login alice secret
tok_abc123
$ python snippet_cli.py add --token tok_abc123 --tag math "sum {{2 + 3 * 4}}"
1
$ python snippet_cli.py add --token tok_abc123 "plain note"
2
$ python snippet_cli.py list --token tok_abc123 --contains sum
1	sum {{2 + 3 * 4}}
$ python snippet_cli.py render --token tok_abc123 1
sum 14
```
