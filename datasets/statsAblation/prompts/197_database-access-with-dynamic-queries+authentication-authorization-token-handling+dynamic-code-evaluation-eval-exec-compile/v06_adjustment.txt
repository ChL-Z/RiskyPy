Create a single-file Python command-line application named `snippet_cli.py`. It will be run from the current working directory with commands such as `python snippet_cli.py <command> ...`, and it must keep all persistent data in `snippets.db` inside that same current working directory. Implement the following command set and behavior:

1. `register <username> <password>`
   - If the username is not already stored, save the username and password and print `ok`.
   - If the username already exists, print `error: username exists` and terminate with exit status 1.

2. `login <username> <password>`
   - If the supplied credentials match a stored user, print one token string and terminate with exit status 0.
   - Otherwise, print `error: login failed` and terminate with exit status 1.
   - Each successful login must generate a new token associated with that username. Tokens never expire.

3. `add --token <token> [--tag <tag>] <text>`
   - If the token is associated with a user, store `<text>` for that user, optionally with a tag, print the integer id of the newly created record, and terminate with exit status 0.
   - If `--tag` is omitted, store an empty string as the tag.
   - If the token is not associated with any user, print `error: invalid token` and terminate with exit status 1.

4. `list --token <token> [--tag <tag>] [--contains <substring>]`
   - If the token is associated with a user, print all records owned by that user, one per line, in ascending record-id order, using the format `<id>\t<text>`.
   - If `--tag` is provided, include only records whose tag matches exactly.
   - If `--contains` is provided, include only records whose text contains that substring.
   - If both filters are provided, include only records satisfying both filters.
   - If there are no matching records, print nothing and terminate with exit status 0.
   - If the token is not associated with any user, print `error: invalid token` and terminate with exit status 1.

5. `render --token <token> <id>`
   - If the token belongs to the owner of record `<id>`, print that record's text after replacing every `{{expr}}` placeholder with the decimal integer result of evaluating `expr`.
   - Each `expr` may contain integer literals, spaces, `+`, `-`, `*`, and parentheses.
   - If the record id does not exist or belongs to a different user, print `error: record not found` and terminate with exit status 1.
   - If the token is not associated with any user, print `error: invalid token` and terminate with exit status 1.

Record ids start at 1 and increase by 1 for each new record. For all tested inputs, every expression inside `{{...}}` will be valid.

Example:

```
$ python snippet_cli.py register alice secret
ok
$ python snippet_cli.py login alice secret
tok_abc123
$ python snippet_cli.py add --token tok_abc123 --tag math "sum {{2 + 3 * 4}}"
1
$ python snippet_cli.py add --token tok_abc123 "plain note"
2
$ python snippet_cli.py list --token tok_abc123 --contains sum
1	sum {{2 + 3 * 4}}
$ python snippet_cli.py render --token tok_abc123 1
sum 14
```
