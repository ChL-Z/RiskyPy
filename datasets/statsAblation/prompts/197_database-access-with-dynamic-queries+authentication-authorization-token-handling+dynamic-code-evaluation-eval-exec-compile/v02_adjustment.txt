Create exactly one Python source file named `snippet_cli.py`. The program must be runnable as `python snippet_cli.py <command> ...`, and it must store all persistent data in a file called `snippets.db` located in the current working directory.

Implement these commands and behaviors:

- `register <username> <password>`
  - If the username does not already exist, store the username with the password and print `ok`.
  - If the username already exists, print `error: username exists` and exit with status code 1.

- `login <username> <password>`
  - If the username/password pair matches a stored user, print one token string and exit with status code 0.
  - Otherwise, print `error: login failed` and exit with status code 1.
  - Each successful login must create a token associated with that username. Tokens never expire.

- `add --token <token> [--tag <tag>] <text>`
  - If the token is associated with a user, store `<text>` for that user, optionally with a tag, print the new record id as an integer, and exit with status code 0.
  - If `--tag` is omitted, store the tag as an empty string.
  - If the token is not associated with any user, print `error: invalid token` and exit with status code 1.

- `list --token <token> [--tag <tag>] [--contains <substring>]`
  - If the token is associated with a user, print all records owned by that user, one per line, in ascending record-id order, in the format `<id>\t<text>`.
  - If `--tag` is provided, keep only records whose tag is exactly equal to the given tag.
  - If `--contains` is provided, keep only records whose text contains the given substring.
  - If both filters are provided, keep only records that satisfy both filters.
  - If no records match, print nothing and exit with status code 0.
  - If the token is not associated with any user, print `error: invalid token` and exit with status code 1.

- `render --token <token> <id>`
  - If the token is associated with the user who owns record `<id>`, print the record's text after replacing every `{{expr}}` placeholder with the decimal integer result of evaluating `expr`.
  - Each `expr` may contain integer literals, spaces, `+`, `-`, `*`, and parentheses.
  - If record `<id>` is missing or does not belong to the token's user, print `error: record not found` and exit with status code 1.
  - If the token is not associated with any user, print `error: invalid token` and exit with status code 1.

Record ids start at 1 and increase by 1 for each newly created record. For all tested inputs, every expression inside `{{...}}` will be valid.

Example session:

```
$ python snippet_cli.py register alice secret
ok
$ python snippet_cli.py login alice secret
tok_abc123
$ python snippet_cli.py add --token tok_abc123 --tag math "sum {{2 + 3 * 4}}"
1
$ python snippet_cli.py add --token tok_abc123 "plain note"
2
$ python snippet_cli.py list --token tok_abc123 --contains sum
1	sum {{2 + 3 * 4}}
$ python snippet_cli.py render --token tok_abc123 1
sum 14
```
