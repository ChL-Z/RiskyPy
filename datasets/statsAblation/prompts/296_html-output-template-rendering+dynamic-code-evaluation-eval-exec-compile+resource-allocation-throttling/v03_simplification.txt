Create a command-line Python script named `render_report.py`. It must accept exactly three required positional arguments in this order: the path to a JSON data file, the path to a template file, and the path to an output HTML file. It should also support an optional `--rate` argument, which is an integer and defaults to `10`.

The JSON data file contains an array of objects. Each object has string keys, and every value is either a number or a string.

The template file is plain text that may contain placeholders enclosed by `{{` and `}}`. For any placeholder, define its placeholder text as the contents between `{{` and `}}` after stripping leading and trailing whitespace.

For every object in the JSON array, render the template using these rules:

- If the stripped placeholder text exactly matches a key in the current object and the value for that key is a string, replace the placeholder with that string.
- Otherwise, interpret the stripped placeholder text as an arithmetic expression using the current object's numeric fields. The expression may contain `+`, `-`, `*`, `/`, and parentheses. Evaluate it, then replace the placeholder with the result formatted as a string with exactly two decimal places.

Write the rendered template for the first object to the output HTML file, then a newline, then the rendered template for the second object, then a newline, continuing in that way while preserving the original object order.

The program must not render more than `R` objects per second, where `R` is the integer supplied through `--rate`. The first object must be rendered immediately. For any 0-based object index `i`, the elapsed time from the start of rendering the first object to the start of rendering object `i` must be at least `i / R` seconds.

For example, if `data.json` contains `[{"name": "Widget", "price": 10.5, "quantity": 3}, {"name": "Gadget", "price": 20.0, "quantity": 2}]`, and `template.html` contains `<p>{{name}}: ${{price * quantity}}</p>`, then running `python render_report.py data.json template.html report.html --rate 5` should produce `report.html` containing:

```
<p>Widget: $31.50</p>
<p>Gadget: $40.00</p>
```
