Write a Python script `render_report.py` that takes three positional command-line arguments: a path to a JSON data file, a path to a template file, and a path to an output HTML file, plus an optional `--rate` argument that takes an integer (default 10). The JSON data file contains an array of objects. Each object has string keys and values that are either numbers or strings. The template file contains text with placeholders delimited by `{{` and `}}`. The placeholder text is the substring between `{{` and `}}` with leading and trailing whitespace removed.

For each object in the data array, the script must render the template by replacing each placeholder with:
- If the placeholder text is exactly a field name present in the object and its value is a string, that string.
- Otherwise, the placeholder text is an arithmetic expression over the object's numeric fields, using operators `+`, `-`, `*`, `/`, and parentheses. Evaluate the expression and format the result as a string with exactly two decimal places.

The script writes the rendered template for the first object, then a newline, then the rendered template for the second object, and so on, to the output HTML file.

The script must render no more than `R` objects per second, where `R` is the integer from `--rate`. The first object must be rendered immediately. For any object index `i` (0-based), the time between the start of rendering the first object and the start of rendering object `i` must be at least `i / R` seconds.

Example: `data.json` contains `[{"name": "Widget", "price": 10.5, "quantity": 3}, {"name": "Gadget", "price": 20.0, "quantity": 2}]`. `template.html` contains `<p>{{name}}: ${{price * quantity}}</p>`. Running `python render_report.py data.json template.html report.html --rate 5` produces `report.html` with:
```
<p>Widget: $31.50</p>
<p>Gadget: $40.00</p>
```
