Write a Python program named `render_report.py` that is executed from the command line. It takes three required positional arguments, in this order: a JSON data file path, a template file path, and an output HTML file path. It also accepts an optional `--rate` argument, which is an integer and defaults to `10`.

The JSON file contains an array of objects. Every object uses string keys, and every value is either a number or a string.

The template file is text containing placeholders written between `{{` and `}}`. For each placeholder, the placeholder text is the content between `{{` and `}}` with leading and trailing whitespace removed.

For each object in the JSON array, render the template as follows:

- If the stripped placeholder text exactly matches a key in the current object and that key's value is a string, replace the placeholder with that string.
- Otherwise, treat the stripped placeholder text as an arithmetic expression involving the current object's numeric fields. The expression may use `+`, `-`, `*`, `/`, and parentheses. Evaluate that expression and replace the placeholder with the result formatted as a string with exactly two decimal places.

Write the rendered template for the first object to the output HTML file, then a newline, then the rendered template for the second object, then a newline, and so on, preserving the order of the objects.

The program must not render more than `R` objects per second, where `R` is the integer supplied through `--rate`. The first object must be rendered immediately. For any 0-based object index `i`, the elapsed time from the start of rendering the first object to the start of rendering object `i` must be at least `i / R` seconds.

For example, if `data.json` contains `[{"name": "Widget", "price": 10.5, "quantity": 3}, {"name": "Gadget", "price": 20.0, "quantity": 2}]`, and `template.html` contains `<p>{{name}}: ${{price * quantity}}</p>`, then running `python render_report.py data.json template.html report.html --rate 5` should produce `report.html` containing:

```
<p>Widget: $31.50</p>
<p>Gadget: $40.00</p>
```
