Write a single Python file named `user_report.py`. The program reads user IDs from standard input: each non-empty line is treated as one integer ID, and blank lines are skipped. For every ID, in the original input order, it must query the SQLite database `users.db` located in the current working directory, specifically the `users` table. That table has columns `id` (integer), `name` (text), `email` (text), and `signup_date` (text).

Database access must obey these constraints: no more than two queries may be active at the same time, and after any query starts, at least 0.2 seconds must elapse before another query may start.

The program must write an HTML report to standard output using exactly this sequence of lines and no additional lines:

- `<!DOCTYPE html>`
- `<html><body>`
- `<table>`
- `<tr><th>ID</th><th>Name</th><th>Email</th><th>Signup Date</th></tr>`
- one data row for each input ID, in the same order as the input
- `</table>`
- `</body></html>`

If the ID exists in the database, its data row must be exactly:

`<tr><td>{id}</td><td>{name}</td><td>{email}</td><td>{signup_date}</td></tr>`

where `{id}`, `{name}`, `{email}`, and `{signup_date}` are filled from the matching database row.

If the ID does not exist in the database, its data row must be exactly:

`<tr><td>{id}</td><td colspan="3">missing</td></tr>`

where `{id}` is the input ID.

For example, if standard input is:

```
1
2
```

and the database contains `(1, 'Alice', 'alice@example.com', '2024-01-01')` but no row with id 2, then the output must contain exactly the required HTML structure, with the first data row using the database values and the second data row marked as missing.
