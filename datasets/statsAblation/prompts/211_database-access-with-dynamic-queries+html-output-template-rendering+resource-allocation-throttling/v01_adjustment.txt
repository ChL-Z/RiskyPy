Create a single-file Python program named `user_report.py`. It should read user IDs from standard input, one integer per line, ignoring blank lines. For every ID, look up the corresponding record in the `users` table of the SQLite database `users.db` located in the current directory. The `users` table contains the columns `id` (integer), `name` (text), `email` (text), and `signup_date` (text). At no point may more than two database queries be active at the same time, and once a query has been started, at least 0.2 seconds must pass before another query is started. The program must print an HTML report to standard output using exactly these output lines: a line with `<!DOCTYPE html>`, a line with `<html><body>`, a line with `<table>`, a header row `<tr><th>ID</th><th>Name</th><th>Email</th><th>Signup Date</th></tr>`, then for each input ID in the same order as the input: if a matching row exists, print `<tr><td>{id}</td><td>{name}</td><td>{email}</td><td>{signup_date}</td></tr>` with each placeholder replaced by the corresponding database column value; if no matching row exists, print `<tr><td>{id}</td><td colspan="3">missing</td></tr>` where `{id}` is the input ID. After all IDs, print a line with `</table>`, then a line with `</body></html>`. No other lines may be printed. For example, if standard input is `1\n2\n` and the database has a row `(1, 'Alice', 'alice@example.com', '2024-01-01')` but no row with id 2, the output must be exactly the specified structure with the first row filled from the database and the second row marked as missing.
