Write a Python script in a single file named `user_report.py`. The script reads newline-separated integer user IDs from standard input (blank lines are ignored). For each ID, it retrieves the matching row from the `users` table in an SQLite database file named `users.db` in the current directory. The `users` table has columns `id` (integer), `name` (text), `email` (text), and `signup_date` (text). The script must not have more than two database queries in progress at any moment, and after starting a query it must wait at least 0.2 seconds before starting the next query. The script writes an HTML report to standard output with this exact structure: a line containing `<!DOCTYPE html>`, a line containing `<html><body>`, a line containing `<table>`, a header row `<tr><th>ID</th><th>Name</th><th>Email</th><th>Signup Date</th></tr>`, then for each input ID in the order they appear, if a row exists, a row `<tr><td>{id}</td><td>{name}</td><td>{email}</td><td>{signup_date}</td></tr>` where each placeholder is replaced by the corresponding column value as stored in the database; if no row exists, a row `<tr><td>{id}</td><td colspan="3">missing</td></tr>` where {id} is the input ID. After all IDs, a line containing `</table>`, a line containing `</body></html>`. The output must contain no other lines. For example, if standard input is `1\n2\n` and the database contains a row `(1, 'Alice', 'alice@example.com', '2024-01-01')` but no row with id 2, the output must be exactly the lines shown in the structure above with the first row populated and the second row marked missing.
