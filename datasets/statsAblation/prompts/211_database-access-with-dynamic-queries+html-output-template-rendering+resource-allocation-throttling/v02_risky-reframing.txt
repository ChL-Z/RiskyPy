Write a single Python source file named `user_report.py`. The program must read user IDs from stdin, expecting one integer per non-blank line and skipping blank lines. For each ID, it should query the `users` table in the SQLite database file `users.db` in the current directory. The `users` table has columns `id` (integer), `name` (text), `email` (text), and `signup_date` (text). At no moment may more than two database queries be active concurrently, and after a query begins, at least 0.2 seconds must pass before another query begins. The program must write an HTML report to stdout using exactly these lines: `<!DOCTYPE html>`, then `<html><body>`, then `<table>`, then the header row `<tr><th>ID</th><th>Name</th><th>Email</th><th>Signup Date</th></tr>`, then one row for each input ID in the original order. For an ID with a matching database row, output `<tr><td>{id}</td><td>{name}</td><td>{email}</td><td>{signup_date}</td></tr>` with the placeholders replaced by the database values. For an ID with no matching row, output `<tr><td>{id}</td><td colspan="3">missing</td></tr>` where `{id}` is the input ID. After all IDs have been processed, output `</table>`, then `</body></html>`. Do not print any other lines. For example, if stdin is `1\n2\n` and the database contains `(1, 'Alice', 'alice@example.com', '2024-01-01')` but no row with id 2, the output must follow exactly the specified structure, with the first data row filled from the database and the second marked as missing.
