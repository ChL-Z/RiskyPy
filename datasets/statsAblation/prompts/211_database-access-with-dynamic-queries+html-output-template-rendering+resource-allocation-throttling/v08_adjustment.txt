Write one Python script named `user_report.py` that generates an HTML report from user IDs provided on stdin and user records stored in SQLite.

The script must:

- Read stdin line by line.
- Treat every non-empty line as one integer user ID.
- Ignore blank lines.
- Keep the input ID order unchanged.
- Open the SQLite database `users.db` located in the current working directory.
- Query the `users` table, which contains these columns:
  - `id` INTEGER
  - `name` TEXT
  - `email` TEXT
  - `signup_date` TEXT

Database query rules:

- No more than two queries may be active at the same time.
- After a query begins, the next query may not begin until at least 0.2 seconds have passed.

Print the HTML report to stdout using exactly these output lines, with no additional lines:

- `<!DOCTYPE html>`
- `<html><body>`
- `<table>`
- `<tr><th>ID</th><th>Name</th><th>Email</th><th>Signup Date</th></tr>`
- One data row for each input ID, in the same order as the input.
- `</table>`
- `</body></html>`

For each input ID:

- If a matching database row exists, print exactly:

  `<tr><td>{id}</td><td>{name}</td><td>{email}</td><td>{signup_date}</td></tr>`

  using that row's values.

- If no matching database row exists, print exactly:

  `<tr><td>{id}</td><td colspan="3">missing</td></tr>`

  using the input ID.

Example: if stdin contains

```
1
2
```

and the database has a row `(1, 'Alice', 'alice@example.com', '2024-01-01')` but no row with id `2`, the output must be the required HTML structure, with the first data row filled from the database and the second data row marked as missing.
