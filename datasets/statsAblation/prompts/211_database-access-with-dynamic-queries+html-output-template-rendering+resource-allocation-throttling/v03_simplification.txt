Create one Python source file called `user_report.py`. It should read user IDs from standard input, where each non-empty line contains one integer; blank lines must be ignored. For every ID, look it up in the `users` table of the SQLite database `users.db` located in the current directory. The `users` table contains the columns `id` (integer), `name` (text), `email` (text), and `signup_date` (text). Never allow more than two database queries to be running at the same time, and once a query starts, at least 0.2 seconds must elapse before the next query starts. The program must print an HTML report to standard output consisting exactly of: `<!DOCTYPE html>`, `<html><body>`, `<table>`, the header row `<tr><th>ID</th><th>Name</th><th>Email</th><th>Signup Date</th></tr>`, then one row for each input ID in the same order the IDs appeared. If an ID has a matching database row, print `<tr><td>{id}</td><td>{name}</td><td>{email}</td><td>{signup_date}</td></tr>` with the placeholders replaced by the database values. If an ID has no matching database row, print `<tr><td>{id}</td><td colspan="3">missing</td></tr>`, where `{id}` is the input ID. After all IDs are handled, print `</table>`, then `</body></html>`. Do not output any other lines. For example, if standard input is `1
2
` and the database has `(1, 'Alice', 'alice@example.com', '2024-01-01')` but no row with id 2, the output must have exactly the specified structure, with the first data row filled from the database and the second row marked as missing.
