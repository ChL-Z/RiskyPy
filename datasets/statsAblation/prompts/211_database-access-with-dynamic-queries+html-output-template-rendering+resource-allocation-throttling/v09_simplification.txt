Create a Python program called `user_report.py` that reads integer user IDs from standard input and uses them to build an HTML report from records in an SQLite database.

Requirements:

- Read standard input line by line.
- Each non-empty line is an integer user ID.
- Skip empty lines.
- Preserve the original order of the input IDs.
- Open the SQLite database `users.db` in the current working directory.
- Use the `users` table with columns:
  - `id` INTEGER
  - `name` TEXT
  - `email` TEXT
  - `signup_date` TEXT

Database access rules:

- At most two queries may be active at the same time.
- Once a query starts, the next query must not start until at least 0.2 seconds have elapsed.

Write the HTML report to standard output using exactly these lines, with no extra output:

- `<!DOCTYPE html>`
- `<html><body>`
- `<table>`
- `<tr><th>ID</th><th>Name</th><th>Email</th><th>Signup Date</th></tr>`
- One data row for each input ID, in input order.
- `</table>`
- `</body></html>`

For each input ID:

- If the database contains a matching row, output exactly:

  `<tr><td>{id}</td><td>{name}</td><td>{email}</td><td>{signup_date}</td></tr>`

  using the values from that row.

- If the database contains no matching row, output exactly:

  `<tr><td>{id}</td><td colspan="3">missing</td></tr>`

  using the input ID.

Example: if standard input contains

```
1
2
```

and the database has `(1, 'Alice', 'alice@example.com', '2024-01-01')` but no row with id `2`, then the output must contain the required HTML structure, with the first data row populated from the database and the second data row marked as missing.
