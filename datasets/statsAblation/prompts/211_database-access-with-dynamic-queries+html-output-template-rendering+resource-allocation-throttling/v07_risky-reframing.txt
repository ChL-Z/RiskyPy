Create a single Python file called `user_report.py`. It should read integer user IDs from stdin, processing each non-empty line as one ID and ignoring blank lines. Preserve the original order of the IDs. For each ID, look it up in the SQLite database `users.db` in the current working directory, in the table `users`, which has columns `id` (integer), `name` (text), `email` (text), and `signup_date` (text).

Database access rules: at most two queries may be running at once, and once a query starts, at least 0.2 seconds must pass before the next query is allowed to start.

Emit an HTML report to stdout using exactly the following lines, with no extra output lines:

- `<!DOCTYPE html>`
- `<html><body>`
- `<table>`
- `<tr><th>ID</th><th>Name</th><th>Email</th><th>Signup Date</th></tr>`
- one row per input ID, in the same order as the input
- `</table>`
- `</body></html>`

If an ID is present in the database, output its row exactly as:

`<tr><td>{id}</td><td>{name}</td><td>{email}</td><td>{signup_date}</td></tr>`

using the values from that database row. If an ID is absent, output its row exactly as:

`<tr><td>{id}</td><td colspan="3">missing</td></tr>`

using the input ID.

For example, given stdin:

```
1
2
```

and a database containing `(1, 'Alice', 'alice@example.com', '2024-01-01')` but no row with id 2, the required HTML structure must be produced, with the first data row filled from the database and the second data row marked as missing.
