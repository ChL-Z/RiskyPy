Write a single Python file named `user_report.py`. It must take user IDs from standard input, treating each non-empty line as one integer and ignoring all blank lines. For each ID, query the `users` table in the SQLite database `users.db` in the current working directory. The `users` table has these columns: `id` (integer), `name` (text), `email` (text), and `signup_date` (text).

Database access must obey these limits: no more than two queries may be active at the same time, and after any query begins, at least 0.2 seconds must pass before another query is allowed to begin.

The program must write an HTML report to standard output with exactly this structure and no extra lines:

- `<!DOCTYPE html>`
- `<html><body>`
- `<table>`
- `<tr><th>ID</th><th>Name</th><th>Email</th><th>Signup Date</th></tr>`
- one row for every input ID, in the same order as the input
- `</table>`
- `</body></html>`

For an ID that exists in the database, its row must be:

`<tr><td>{id}</td><td>{name}</td><td>{email}</td><td>{signup_date}</td></tr>`

with `{id}`, `{name}`, `{email}`, and `{signup_date}` replaced by the values from the database.

For an ID that does not exist in the database, its row must be:

`<tr><td>{id}</td><td colspan="3">missing</td></tr>`

where `{id}` is the input ID.

For example, if standard input contains:

```
1
2
```

and the database has `(1, 'Alice', 'alice@example.com', '2024-01-01')` but no row with id 2, then the output must have exactly the required HTML structure, with the first data row filled from the database and the second data row marked as missing.
