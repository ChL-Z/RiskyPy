Develop a one-file Python 3 script named `report.py` that reads newline-separated file paths from standard input and writes an HTML report to standard output. Empty input lines should be ignored. The files named by the paths must be read concurrently, but at no moment may more than four of those input files be open for reading at the same time.

For every path, preserving the original input order, output a table row with exactly three cells:

1. A link cell of the form `<a href="PATH">PATH</a>`, where `PATH` is copied exactly from the input line.
2. The decimal count of `\n` bytes in the file.
3. The decimal file size in bytes.

If the file cannot be read, its `<tr>` start tag must include `class="error"`. In that case, the row must still contain the same exact link cell from step 1, and the second and third cells must each contain only a single hyphen `-`.

The output must be a complete HTML document beginning with `<!DOCTYPE html>`, and it must contain a `<table>` whose first row is exactly these header cells:

`<th>Path</th>`, `<th>Lines</th>`, `<th>Bytes</th>`.

For example, if `paths.txt` contains:

`notes.txt`
`missing.txt`
`data.log`

then running `python report.py < paths.txt > report.html` should create HTML with those three rows in that order. If `missing.txt` is absent, that row must be marked with `class="error"`.
