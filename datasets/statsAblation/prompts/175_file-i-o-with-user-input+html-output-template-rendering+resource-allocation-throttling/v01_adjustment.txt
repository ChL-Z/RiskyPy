Create a single-file Python 3 script called `report.py` that turns a list of file paths into an HTML report.

Input is read from standard input as newline-separated path strings, one per line. Ignore blank lines. Output is a complete HTML document printed to standard output. The script must read the files concurrently, but it must never have more than 4 of the input files open for reading at the same time.

For every input path, preserving the original input order, output one table row with three cells:

1. An anchor element `<a href="PATH">PATH</a>`, using the path text exactly as it appeared in the input.
2. The count of `\n` byte occurrences in that file, as decimal digits.
3. That file's size in bytes, as decimal digits.

If a path cannot be read, its `<tr>` must include `class="error"`; it must still contain the same link cell as requirement (1); and its other two cells must each contain only a hyphen `-`.

The generated document must start with `<!DOCTYPE html>` and must contain a `<table>` whose first row is exactly:

`<th>Path</th>`, `<th>Lines</th>`, `<th>Bytes</th>`.

Example usage: if `paths.txt` contains the lines `notes.txt`, `missing.txt`, and `data.log`, then running `python report.py < paths.txt > report.html` should create an HTML file with exactly those three rows in that order. If `missing.txt` does not exist on disk, that row must be marked with `class="error"`.
