Create a single Python file called `dynamic_query.py`. In it, implement a function named `run_query(db_path, table, filters, order_by=None, limit=None)`. The parameter `db_path` points to a SQLite database file. `table` is the name of a table in that database. `filters` is a dictionary mapping column names to values, where each value is a string, a number, or `None`. The function should select every column from `table` and return a list of dictionaries, one per matching row. Each dictionary must map every column name in the table to that row’s value for the column. A row is considered matching only when, for all keys in `filters`, the row’s value in that column is equal to the corresponding filter value. If `filters` is empty, every row in the table matches. If `order_by` is a tuple `(column, direction)`, sort the returned rows by that column, where `direction` is either `'ASC'` or `'DESC'`. If `limit` is an integer, return at most that many rows; if `limit` is `None`, return all matching rows. If `order_by` is `None`, do not include an ORDER BY clause, leaving row order up to the database. The script must also be executable from the command line in this form: `python dynamic_query.py <db_path> <table> [column=value ...] [--order-by column:ASC|DESC] [--limit N]`. After `<table>`, every positional argument is a filter written as `column=value`, and the filter value is the exact literal text after the first `=`. The `--order-by` option accepts one value shaped like `column:ASC` or `column:DESC`. The `--limit` option accepts an integer. For each row produced by the query, print a single JSON object to standard output, with column names as keys, one object per line. If there are no matching rows, print nothing.
