Write a Python script in a single file named `sync_services.py`. Run it as `python sync_services.py <config_path>`. The file at `<config_path>` is XML with this structure:

```xml
<sync>
  <endpoint url="https://api.example.com/v1/services"/>
  <token path="/tmp/service-token.txt"/>
  <output path="services.json"/>
</sync>
```

The script must perform these steps:

1. Read `<config_path>` and obtain the `url` attribute of the `<endpoint>` element, the `path` attribute of the `<token>` element, and the `path` attribute of the `<output>` element.

2. Send an HTTP GET request to the endpoint URL. Put the token in the request as the `Authorization` header with value `Bearer <token>`, where `<token>` is the first line of the token file with one trailing newline character removed if present. The response body is XML with this structure:

```xml
<services>
  <service id="svc-1"><name>Alpha</name><url>https://alpha.example.com</url></service>
  <service id="svc-2"><name>Beta</name><url>https://beta.example.com</url></service>
</services>
```

Read the `id` attribute and the text content of `<name>` and `<url>` for every `<service>` element.

3. Write to the output path a JSON array. Each object has string keys `id`, `name`, and `url`, using the values from the response. If the HTTP status code is 200, exit with status 0. If the HTTP status code is not 200, write the status code as a decimal integer followed by a newline to stderr and exit with status 1.

Example: with the config above, `/tmp/service-token.txt` containing `abc123\n`, and the example XML response, `services.json` must contain `[{"id":"svc-1","name":"Alpha","url":"https://alpha.example.com"},{"id":"svc-2","name":"Beta","url":"https://beta.example.com"}]`.
