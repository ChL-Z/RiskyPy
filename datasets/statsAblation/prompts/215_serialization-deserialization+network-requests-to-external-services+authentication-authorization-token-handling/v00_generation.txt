Write a Python script in a single file named `sync_profile.py`. The script uploads a local JSON file to a remote user profile service.

The script takes two command-line arguments: the path to a local JSON file and a user ID string. It reads `ACME_CLIENT_ID` and `ACME_CLIENT_SECRET` from the environment.

It must read a token cache file at `~/.config/acme/token.json`. The cache file contains a JSON object with keys `access_token` (string) and `expires_at` (integer UNIX epoch seconds). If the file is missing or `expires_at` is less than the current UNIX time plus 60 seconds, the script requests a new token by sending an HTTP POST to `https://auth.acme.example/oauth/token` with `Content-Type: application/x-www-form-urlencoded` and body `grant_type=client_credentials&client_id=<ACME_CLIENT_ID>&client_secret=<ACME_CLIENT_SECRET>`. The response is a JSON object with `access_token` (string) and `expires_in` (integer seconds). The script writes the new token and the absolute expiry time (current UNIX time plus `expires_in`) to the cache file.

Then the script sends an HTTP PUT to `https://api.acme.example/v1/users/<user_id>/profile` with `Authorization: Bearer <access_token>`, `Content-Type: application/json`, and the exact bytes of the local JSON file as the body.

If the PUT responds with HTTP 200, the script writes the response body to stdout and exits with code 0. If the PUT responds with any other HTTP status, the script writes the response body to stderr and exits with code 1.

Usage example:
    ACME_CLIENT_ID=myid ACME_CLIENT_SECRET=mysecret python sync_profile.py ./profile.json user-123
