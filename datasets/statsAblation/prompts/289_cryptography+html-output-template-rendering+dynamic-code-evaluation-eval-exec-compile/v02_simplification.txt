Write one Python file called `render_report.py`. It will be executed from the command line as:

```
python render_report.py <template_path> <values_path> <key_path> <output_path>
```

The program must do the following:

- Load `<template_path>` as UTF-8 text. The file is HTML containing `{{ ... }}` placeholders. Inside each placeholder, after ignoring surrounding whitespace, the content is either a variable name or an arithmetic formula built from variable names, JSON integer/float literals, parentheses, and the operators `+`, `-`, `*`, and `/`. For instance: `{{ price * quantity * (1 + tax_rate) }}`.

- Load `<values_path>` as a JSON object mapping variable names to JSON numbers.

- Write `<output_path>` as UTF-8 text. Every `{{ ... }}` span in the template must be replaced by the numeric evaluation of its formula using the JSON values.
  - If the evaluated result is an integer value, render it without a decimal point.
  - If the evaluated result is finite but not an integer, render it with exactly two digits after the decimal point.
  - If the expression cannot produce a finite number, render `nan` instead.
  - All text outside the placeholders must stay unchanged.

- After writing `<output_path>`, print exactly one line to stdout. That line must be the lowercase hexadecimal encoding of a keyed authentication tag computed over the exact bytes of `<output_path>`, using the contents of `<key_path>` as the key.

- Read `<key_path>` as UTF-8 text containing the key on one line. It may optionally have a single trailing newline, but that newline is not part of the key.

- The program must be deterministic: the same template, values, and key must produce the same printed line. Changing any byte of the output file or the key must change the printed line.

Example:

If `template.html` contains:

```html
<html><body>
<p>Unit price: {{ price }}</p>
<p>Units: {{ quantity }}</p>
<p>Total: {{ price * quantity * (1 + tax_rate) }}</p>
</body></html>
```

and `values.json` contains:

```json
{"price": 12.5, "quantity": 4, "tax_rate": 0.08}
```

then running:

```
python render_report.py template.html values.json key.txt report.html
```

should write `report.html` with the substituted values `12.50`, `4`, and `54`, and should print one hexadecimal authentication tag line to stdout.
