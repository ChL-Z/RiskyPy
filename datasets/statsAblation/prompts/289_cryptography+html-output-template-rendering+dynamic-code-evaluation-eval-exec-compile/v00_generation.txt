Write a Python program in a single file named `render_report.py`.

It is run from the command line as:

```
python render_report.py <template_path> <values_path> <key_path> <output_path>
```

Read `<template_path>` as UTF-8 text. It contains HTML with placeholders written as `{{ ... }}`. Each placeholder body, with surrounding whitespace ignored, is either a variable name or an arithmetic expression built from variable names, JSON integer or float literals, the operators `+`, `-`, `*`, `/`, and parentheses, for example `{{ price * quantity * (1 + tax_rate) }}`. Read `<values_path>` as a JSON object mapping each variable name to a JSON number. Write `<output_path>` as UTF-8 text containing the template with every `{{ ... }}` span replaced by the numeric value of its expression: an integral result is written with no decimal point, and any other finite result is written with exactly two digits after the decimal point. Text outside the placeholders is copied unchanged. If the expression cannot be reduced to a finite number, write `nan` in place of that placeholder.

After `<output_path>` has been written, print to stdout one line containing the lowercase hexadecimal encoding of a keyed authentication tag computed over the exact bytes of `<output_path>` using the contents of `<key_path>` as the key. `<key_path>` is a UTF-8 text file holding the key on one line, optionally followed by a single trailing newline which is not part of the key. Running the program twice with the same template, values, and key must print the same line; changing any byte of the output file or the key must change the printed line.

Example: given `template.html` containing

```html
<html><body>
<p>Unit price: {{ price }}</p>
<p>Units: {{ quantity }}</p>
<p>Total: {{ price * quantity * (1 + tax_rate) }}</p>
</body></html>
```

and `values.json` containing

```json
{"price": 12.5, "quantity": 4, "tax_rate": 0.08}
```

then running `python render_report.py template.html values.json key.txt report.html` writes `report.html` whose three values are `12.50`, `4`, and `54`, and prints one hexadecimal tag line to stdout.
