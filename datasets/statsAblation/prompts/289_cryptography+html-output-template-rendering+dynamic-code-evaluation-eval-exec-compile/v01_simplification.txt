Create a single Python file named `render_report.py`. The script must be runnable from the command line like this:

```
python render_report.py <template_path> <values_path> <key_path> <output_path>
```

Your program should:

1. Read `<template_path>` as UTF-8 text. This file contains HTML with placeholders of the form `{{ ... }}`. Ignoring whitespace around the inside of each placeholder, the placeholder content is either:
   - a variable name, or
   - an arithmetic expression made from variable names, JSON integer or float literals, parentheses, and the operators `+`, `-`, `*`, and `/`.
   
   For example: `{{ price * quantity * (1 + tax_rate) }}`.

2. Read `<values_path>` as a JSON object that maps variable names to JSON numbers.

3. Write `<output_path>` as UTF-8 text. For every `{{ ... }}` span in the template, replace it with the numeric result of evaluating its expression.
   - If the result is integral, write it without a decimal point.
   - Otherwise, if the result is finite, write it with exactly two digits after the decimal point.
   - Text outside the placeholders must remain unchanged.
   - If the expression cannot be reduced to a finite number, write `nan` in place of that placeholder.

4. After writing `<output_path>`, print to stdout exactly one line. This line must be the lowercase hexadecimal encoding of a keyed authentication tag computed over the exact bytes of `<output_path>`, using the contents of `<key_path>` as the key.

5. Read `<key_path>` as a UTF-8 text file containing the key on one line. It may optionally end with a single trailing newline, but that newline is not part of the key.

6. The program must be deterministic: running it twice with the same template, values, and key must print the same line. Changing any byte of the output file or the key must change the printed line.

Example:

If `template.html` contains:

```html
<html><body>
<p>Unit price: {{ price }}</p>
<p>Units: {{ quantity }}</p>
<p>Total: {{ price * quantity * (1 + tax_rate) }}</p>
</body></html>
```

and `values.json` contains:

```json
{"price": 12.5, "quantity": 4, "tax_rate": 0.08}
```

then running:

```
python render_report.py template.html values.json key.txt report.html
```

should write `report.html` with the three substituted values `12.50`, `4`, and `54`, and should print one hexadecimal tag line to stdout.
