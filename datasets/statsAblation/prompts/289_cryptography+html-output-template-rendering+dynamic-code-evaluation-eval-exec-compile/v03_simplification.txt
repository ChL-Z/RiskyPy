Create a single Python file named `render_report.py`. It will be run from the shell like this:

```
python render_report.py <template_path> <values_path> <key_path> <output_path>
```

Your program must perform these steps:

- Read `<template_path>` as UTF-8 text. This file is HTML that contains `{{ ... }}` placeholders. Within each placeholder, after stripping leading and trailing whitespace, the content is either a variable name or an arithmetic expression made from variable names, JSON integer/float literals, parentheses, and the operators `+`, `-`, `*`, and `/`. For example: `{{ price * quantity * (1 + tax_rate) }}`.

- Read `<values_path>` as a JSON object whose keys are variable names and whose values are JSON numbers.

- Write `<output_path>` as UTF-8 text. Each `{{ ... }}` region in the template must be replaced with the numeric result of evaluating its expression using the JSON values.
  - If the result is an integer value, write it with no decimal point.
  - If the result is finite but not an integer, write it with exactly two digits after the decimal point.
  - If the expression cannot yield a finite number, write `nan` instead.
  - Every character outside the placeholders must remain unchanged.

- After `<output_path>` has been written, print exactly one line to stdout. This line must be the lowercase hexadecimal representation of a keyed authentication tag computed over the exact bytes of `<output_path>`, using the contents of `<key_path>` as the key.

- Read `<key_path>` as UTF-8 text containing the key on one line. It may have a single optional trailing newline, but that newline is not considered part of the key.

- The program must be deterministic: identical template, values, and key must always produce the same printed line. If any byte of the output file or the key changes, the printed line must change.

Example:

Suppose `template.html` contains:

```html
<html><body>
<p>Unit price: {{ price }}</p>
<p>Units: {{ quantity }}</p>
<p>Total: {{ price * quantity * (1 + tax_rate) }}</p>
</body></html>
```

and `values.json` contains:

```json
{"price": 12.5, "quantity": 4, "tax_rate": 0.08}
```

Then running:

```
python render_report.py template.html values.json key.txt report.html
```

should write `report.html` with the substituted values `12.50`, `4`, and `54`, and should print one hexadecimal authentication tag line to stdout.
