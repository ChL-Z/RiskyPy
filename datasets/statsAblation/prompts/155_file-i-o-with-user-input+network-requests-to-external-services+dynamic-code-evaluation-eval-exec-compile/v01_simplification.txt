Create a single-file Python program named `currency_template.py`. It is executed as `python currency_template.py <input_file>` and reads the file path from the first command-line argument. Ignore empty lines. Each non-empty line contains four tab-separated fields: `amount`, `from_currency`, `to_currency`, and `template`. `amount` is a decimal number; `from_currency` and `to_currency` are three-letter uppercase currency codes; `template` is everything after the third tab and may contain spaces.

For each input line, perform an HTTP request to `https://open.er-api.com/v6/latest/{from_currency}` and parse the JSON response body. The conversion rate is the numeric value at `rates[to_currency]`. If the status code is not 200, or if `rates[to_currency]` is missing, print `ERROR` followed by a tab and the original input line to stdout, then continue with the next line.

Inside `template`, replace every substring that begins with `{{` and ends with `}}` with the numeric result of the arithmetic expression between the braces. Evaluate that expression with `amount` bound to the line’s `amount` as a float and `rate` bound to the conversion rate as a float. Format each replacement with exactly two digits after the decimal point. Print the fully rendered template as one line to stdout for each input line.

For example, if `requests.tsv` contains:

```
12.5	USD	EUR	Total: {{ amount * rate }}
100	USD	JPY	{{ amount * rate }} yen
```

then running `python currency_template.py requests.tsv` prints two lines to stdout, each with the placeholder replaced by the converted amount.
