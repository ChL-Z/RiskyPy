Write a Python program in a single file named `currency_template.py`. The program is run as `python currency_template.py <input_file>`. It reads the file named by the first command-line argument. Each non-empty line in that file has four tab-separated fields: `amount`, `from_currency`, `to_currency`, `template`. `amount` is a decimal number. `from_currency` and `to_currency` are three-letter uppercase currency codes. `template` is the remainder of the line after the third tab and may contain spaces.

For each input line, request `https://open.er-api.com/v6/latest/{from_currency}` and read the JSON object in the response body. The conversion rate is the number at `rates[to_currency]`. If the response status is not 200 or the JSON object does not contain `rates[to_currency]`, write `ERROR	` followed by the original input line to stdout and continue with the next line.

In `template`, replace every substring that starts with `{{` and ends with `}}` with the numeric result of the arithmetic expression between the braces, evaluated with `amount` bound to the line's `amount` as a float and `rate` bound to the conversion rate as a float. Format each result with exactly two digits after the decimal point. Write the resulting template as one line to stdout for each input line. For example, input file `requests.tsv` containing:

```
12.5	USD	EUR	Total: {{ amount * rate }}
100	USD	JPY	{{ amount * rate }} yen
```

running `python currency_template.py requests.tsv` prints two lines to stdout, each with the placeholder replaced by the converted amount.
