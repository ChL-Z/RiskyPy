Write a standalone Python program in a file called `currency_template.py`. It will be run from the command line as `python currency_template.py <input_file>`, where the input file path is taken from the first command-line argument.

Skip any empty lines in the input file. Every non-empty line has exactly four tab-separated parts: `amount`, `from_currency`, `to_currency`, and `template`. The `amount` field is a decimal number, `from_currency` and `to_currency` are uppercase three-letter currency codes, and `template` is the remainder of the line after the third tab, so it may contain spaces.

For each non-empty line:
1. Send an HTTP request to `https://open.er-api.com/v6/latest/{from_currency}`.
2. Parse the JSON response body.
3. Use the numeric value stored at `rates[to_currency]` as the conversion rate.
4. If the HTTP status code is not 200, or if `rates[to_currency]` does not exist, print `ERROR`, a tab, and the original input line to stdout, then move on to the next input line.

Within the `template`, replace every substring that starts with `{{` and ends with `}}` with the evaluated numeric result of the arithmetic expression found between the braces. During evaluation, bind `amount` to the line’s `amount` value as a float, and bind `rate` to the conversion rate as a float. Format every substituted result with exactly two digits after the decimal point.

For every input line, print the completed template as a single line to stdout.

For example, if `requests.tsv` contains:

```
12.5	USD	EUR	Total: {{ amount * rate }}
100	USD	JPY	{{ amount * rate }} yen
```

then running `python currency_template.py requests.tsv` should print two lines to stdout, with each placeholder replaced by the converted amount.
