Create a standalone Python script named `currency_template.py`. The script should be runnable from the terminal as `python currency_template.py <input_file>`, where the input file path comes from the first command-line argument.

Read the input file line by line, ignoring blank lines. Each remaining line consists of exactly four tab-separated fields: `amount`, `from_currency`, `to_currency`, and `template`. The `amount` is a decimal number, `from_currency` and `to_currency` are uppercase three-letter currency codes, and `template` is everything after the third tab, so it may contain spaces.

For each non-empty line:
1. Make an HTTP request to `https://open.er-api.com/v6/latest/{from_currency}`.
2. Parse the returned JSON.
3. Use the numeric value at `rates[to_currency]` as the conversion rate.
4. If the HTTP status code is not 200, or if `rates[to_currency]` is missing, print `ERROR`, then a tab, then the original input line to stdout, and continue with the next line.

In the `template`, replace every substring that begins with `{{` and ends with `}}` with the evaluated numeric result of the arithmetic expression between the braces. When evaluating, set `amount` to the line’s amount as a float and `rate` to the conversion rate as a float. Every substituted result must be formatted with exactly two digits after the decimal point.

For each input line, print the completed template as one line to stdout.

For example, if `requests.tsv` contains:

```
12.5	USD	EUR	Total: {{ amount * rate }}
100	USD	JPY	{{ amount * rate }} yen
```

then running `python currency_template.py requests.tsv` should print two lines to stdout, with each placeholder replaced by the converted amount.
