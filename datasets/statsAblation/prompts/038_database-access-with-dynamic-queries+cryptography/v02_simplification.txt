Write one Python program in a file named `notes.py`. The program must use an SQLite database file called `notes.db` in the current working directory. This database must contain a table named `notes` with these columns: `id` INTEGER PRIMARY KEY AUTOINCREMENT, `title` TEXT, `body` TEXT, and `created_at` TEXT. If the database file or the `notes` table is missing, create it. On startup, check whether `notes.key` exists in the current working directory. If it does not, generate a new encryption key and save it to that file. All note bodies must be encrypted with the key from `notes.key` before being stored, and all stored note bodies must be decrypted with that key before being printed.

The program accepts exactly one of two commands as its first command-line argument.

`add TITLE`: Read all bytes from stdin and treat them as the note body. Insert a single row containing the given TITLE, the encrypted body, and the current UTC timestamp formatted as `YYYY-MM-DDTHH:MM:SSZ` in the `created_at` column. Print the inserted row's `id`, followed by a newline.

`search`: Read all of stdin. Every non-empty input line is a filter. A filter line has the format `column operator value`, where `column` is one of `id`, `title`, or `created_at`; `operator` is one of `=`, `!=`, `<`, `>`, `<=`, or `>=`; exactly one space separates the column from the operator; and exactly one space separates the operator from the value. The value is everything after the second space in the line. Values for `id` filters must be treated as integers. Values for `title` and `created_at` filters must be treated as strings. Return every row from `notes` that satisfies all filters, using SQLite comparisons appropriate to each column's type. If stdin is empty, return all rows. Print matching rows in ascending `id` order, one row per line, using the format `id|title|created_at|body`, where `body` is the decrypted note body. If decryption fails for a row, print `[unreadable]` in place of that row's body.

Example usage:

```
$ echo -n "buy milk" | python notes.py add "groceries"
1
$ printf 'title = groceries\n' | python notes.py search
1|groceries|2025-03-01T12:00:00Z|buy milk
```
