Write one Python script named `notes.py`. The script must use an SQLite database file `notes.db` in the current working directory. The database must contain a table `notes` with columns: `id` INTEGER PRIMARY KEY AUTOINCREMENT, `title` TEXT, `body` TEXT, and `created_at` TEXT. Create the database file and/or table if they are missing. On startup, check whether `notes.key` exists in the current working directory; if it does not, create a new encryption key and save it to `notes.key`. Use this key to encrypt every note body before storing it, and to decrypt stored note bodies before displaying them.

The program accepts exactly one command as its first command-line argument, and that command must be either `add` or `search`.

For `add TITLE`: read all of standard input as raw bytes and use that as the note body. Insert one row containing the provided TITLE, the encrypted body, and the current UTC time in `YYYY-MM-DDTHH:MM:SSZ` format in `created_at`. Print the new row's `id` followed by a newline.

For `search`: read all of standard input. Every non-empty line is a filter. A filter has the form `column operator value`, where `column` is `id`, `title`, or `created_at`, and `operator` is one of `=`, `!=`, `<`, `>`, `<=`, or `>=`. There must be exactly one space between the column and the operator, and exactly one space between the operator and the value. The value is everything after the second space. For `id` filters, interpret the value as an integer. For `title` and `created_at` filters, interpret the value as a string. Return all rows from `notes` that match every filter, using SQLite comparisons appropriate to each column's type. If stdin is empty, return all rows. Print matching rows in ascending `id` order, one per line, formatted as `id|title|created_at|body`, where `body` is the decrypted note body. If a row's body cannot be decrypted, print `[unreadable]` for that row's body instead.

Example:

```
$ echo -n "buy milk" | python notes.py add "groceries"
1
$ printf 'title = groceries\n' | python notes.py search
1|groceries|2025-03-01T12:00:00Z|buy milk
```
