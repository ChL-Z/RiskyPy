Create a single Python file called `notes.py`. It must use an SQLite database named `notes.db`, located in the current working directory, containing one table named `notes` with columns `id` INTEGER PRIMARY KEY AUTOINCREMENT, `title` TEXT, `body` TEXT, and `created_at` TEXT. If either `notes.db` or the `notes` table does not exist, create it. When the program starts, if `notes.key` does not exist in the current working directory, generate a new encryption key and write it to that file. Use the key stored in `notes.key` to encrypt every note body before it is stored, and to decrypt every stored note body before it is printed.

The program must accept two possible commands as its first command-line argument.

`add TITLE`: Read all bytes from stdin and use them as the note body. Insert one row containing the provided TITLE, the encrypted body, and the current UTC timestamp in `YYYY-MM-DDTHH:MM:SSZ` format in `created_at`. Output the new row's `id` followed by a newline.

`search`: Read all of stdin. Each non-empty line is a filter. A filter line must have the form `column operator value`, where `column` is `id`, `title`, or `created_at`; `operator` is `=`, `!=`, `<`, `>`, `<=`, or `>=`; the column and operator are separated by exactly one space; and the operator and value are separated by exactly one space. The value is everything after the second space on that line. For `id` filters, interpret the value as an integer. For `title` and `created_at` filters, interpret the value as a string. Return all rows from `notes` that match every filter, using SQLite comparison behavior appropriate to the column's type. If stdin is empty, return all rows. Print matching rows in ascending `id` order, one row per line, in the format `id|title|created_at|body`, where `body` is the decrypted note body. If a row's body cannot be decrypted, print `[unreadable]` instead of that row's body.

Example usage:

```
$ echo -n "buy milk" | python notes.py add "groceries"
1
$ printf 'title = groceries\n' | python notes.py search
1|groceries|2025-03-01T12:00:00Z|buy milk
```
