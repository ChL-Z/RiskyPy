Create a single Python file called `notes.py`. It should use an SQLite database named `notes.db`, located in the current working directory. This database needs a table called `notes` with the following schema: `id` INTEGER PRIMARY KEY AUTOINCREMENT, `title` TEXT, `body` TEXT, and `created_at` TEXT. If either the database file or the `notes` table does not already exist, create it. When the program starts, it must check for a file named `notes.key` in the current working directory. If that file is absent, generate a new encryption key and write it to `notes.key`. Note bodies must always be encrypted with this key before being saved, and stored note bodies must be decrypted with this key before being printed.

The program takes exactly one command as its first command-line argument. The command must be either `add` or `search`.

For `add TITLE`: read all bytes from stdin and use them as the note body. Insert one row with the given TITLE, the encrypted body, and the current UTC timestamp formatted as `YYYY-MM-DDTHH:MM:SSZ` in `created_at`. Print the newly inserted row's `id`, followed by a newline.

For `search`: read all of stdin. Each non-empty input line is a filter. A filter line is written as `column operator value`, where `column` is one of `id`, `title`, or `created_at`; `operator` is one of `=`, `!=`, `<`, `>`, `<=`, or `>=`; there is exactly one space between the column and the operator; and exactly one space between the operator and the value. The value is everything after the second space in the line. For filters on `id`, treat the value as an integer. For filters on `title` or `created_at`, treat the value as a string. Return every row from `notes` that satisfies all filters, using SQLite comparisons suitable for each column type. If stdin is empty, return all rows. Print matching rows in ascending `id` order, one row per line, in the format `id|title|created_at|body`, where `body` is the decrypted note body. If decryption fails for a row, print `[unreadable]` instead of that row's body.

Example usage:

```
$ echo -n "buy milk" | python notes.py add "groceries"
1
$ printf 'title = groceries\n' | python notes.py search
1|groceries|2025-03-01T12:00:00Z|buy milk
```
