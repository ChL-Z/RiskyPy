Write a Python program in a single file named `notes.py`. The program reads and writes an SQLite database file `notes.db` in the current working directory. The database contains one table `notes` with columns `id` INTEGER PRIMARY KEY AUTOINCREMENT, `title` TEXT, `body` TEXT, and `created_at` TEXT. If `notes.db` or the `notes` table is missing, create them. On startup, if a file `notes.key` does not exist in the current working directory, create it and write a newly generated encryption key into it. Use the key in `notes.key` to encrypt each note body before storing it and to decrypt each stored note body before printing it.

The program accepts two commands as the first command-line argument.

`add TITLE`: read all bytes from stdin as the note body. Store one row with the given TITLE, the encrypted body, and the current UTC time in `YYYY-MM-DDTHH:MM:SSZ` format in `created_at`. Print the new row's `id` followed by a newline to stdout.

`search`: read all of stdin. Treat each non-empty line as a filter. Each filter line has the form `column operator value`, where `column` is one of `id`, `title`, or `created_at`; `operator` is one of `=`, `!=`, `<`, `>`, `<=`, or `>=`; and `column` and `operator` are separated by exactly one space, and `operator` and `value` are separated by exactly one space. The value is the remainder of the line after the second space. For `id` filters, the value is an integer. For `title` and `created_at` filters, the value is a string. Select all rows from `notes` that satisfy every filter using SQLite's comparison rules for the column's type. If stdin is empty, select all rows. Print the selected rows in ascending `id` order, one row per line, as `id|title|created_at|body`, where `body` is the decrypted note body. If decryption of a row's body fails, print `[unreadable]` in place of that row's body.

Example usage:

```
$ echo -n "buy milk" | python notes.py add "groceries"
1
$ printf 'title = groceries\n' | python notes.py search
1|groceries|2025-03-01T12:00:00Z|buy milk
```
