Create a standalone Python 3 script named `render_drafts.py`. It will be executed from a directory that already contains `users.json` and `drafts.json`. The script must not accept any command-line arguments. Instead, it should read an access token from the environment variable `SITE_TOKEN`, then write an HTML document to standard output listing the draft articles belonging to the user associated with that token.

`users.json` is a JSON array of user objects. Each user object has string fields named `token`, `display_name`, and `role`. For example:

```json
[
  {"token": "abc123", "display_name": "Alice", "role": "editor"},
  {"token": "def456", "display_name": "Bob", "role": "viewer"}
]
```

`drafts.json` is a JSON object. Its keys are user `display_name` values. Each key maps to a JSON array of article objects. Every article object has a string `title` and a string `slug`. For example:

```json
{
  "Alice": [
    {"title": "First post", "slug": "first-post"},
    {"title": "Second post", "slug": "second-post"}
  ],
  "Bob": []
}
```

The script must behave as follows:

1. Find the user record in `users.json` whose `token` equals `SITE_TOKEN`.
   - If no such user exists, write exactly `no authorized user` to stderr and exit with status code 1.
   - If such a user exists but the user's `role` is not `editor`, write exactly `role not permitted` to stderr and exit with status code 1.
   - Otherwise, continue.

2. Write a complete HTML document to stdout. The document must contain:
   - An `<h1>` element whose text is `Drafts for ` followed by the matched user's `display_name`.
   - A `<ul>` element.
   - For each article in the array stored in `drafts.json` under the matched user's `display_name`, insert one `<li>` element inside the `<ul>`.
   - Each `<li>` must contain exactly one `<a>` element. The link's `href` must be `/drafts/` plus the article's `slug` plus `.html`, and the link's text must be the article's `title`.
   - If the matched user's article array is empty, the `<ul>` element must still be present, but it must have no `<li>` children.

For example, if `SITE_TOKEN=abc123` and the files above are used, the output HTML should include `<h1>Drafts for Alice</h1>` and links to `/drafts/first-post.html` and `/drafts/second-post.html`.
