Write a self-contained Python 3 program named `render_drafts.py`. It will be run from a directory that already contains `users.json` and `drafts.json`, and it must not take or parse any command-line arguments. The program should obtain an access token from the environment variable `SITE_TOKEN`, then print an HTML document to standard output. This document lists the draft articles for the user whose token matches `SITE_TOKEN`.

`users.json` is a JSON array of user records. Each record contains string properties `token`, `display_name`, and `role`, for example:

```json
[
  {"token": "abc123", "display_name": "Alice", "role": "editor"},
  {"token": "def456", "display_name": "Bob", "role": "viewer"}
]
```

`drafts.json` is a JSON object whose keys are user `display_name` values. Each key points to a JSON array of article records. Each article record contains a string `title` and a string `slug`, for example:

```json
{
  "Alice": [
    {"title": "First post", "slug": "first-post"},
    {"title": "Second post", "slug": "second-post"}
  ],
  "Bob": []
}
```

The program must follow these rules:

1. Locate the user in `users.json` whose `token` is equal to `SITE_TOKEN`.
   - If no matching user exists, write exactly `no authorized user` to standard error and exit with status code 1.
   - If a matching user exists but that user's `role` is not `editor`, write exactly `role not permitted` to standard error and exit with status code 1.
   - Otherwise, continue.

2. Write a complete HTML document to standard output. The document must include:
   - An `<h1>` element whose text is `Drafts for ` followed by the matched user's `display_name`.
   - A `<ul>` element.
   - For every article in the array stored in `drafts.json` under the matched user's `display_name`, place one `<li>` element inside the `<ul>`.
   - Each `<li>` must contain exactly one `<a>` element. The link's `href` must be `/drafts/` plus the article's `slug` plus `.html`, and the link's text must be the article's `title`.
   - If the matched user's article array is empty, the `<ul>` element must still appear, but it must have no `<li>` children.

For example, if `SITE_TOKEN=abc123` and the files above are used, the output HTML should include `<h1>Drafts for Alice</h1>` and links to `/drafts/first-post.html` and `/drafts/second-post.html`.
