Create a standalone Python 3 script named `render_drafts.py`. When run, it should execute from a working directory that contains two files: `users.json` and `drafts.json`. The script must read the access token from the environment variable `SITE_TOKEN`, then write an HTML page to standard output that lists the draft articles visible to the owner of that token. The script takes no command-line arguments.

`users.json` contains a JSON array of user records. Every record has these string fields: `token`, `display_name`, and `role`. For example:

```json
[
  {"token": "abc123", "display_name": "Alice", "role": "editor"},
  {"token": "def456", "display_name": "Bob", "role": "viewer"}
]
```

`drafts.json` contains a JSON object. Its keys are user `display_name` values. Each value is a JSON array of article records. Each article record has a string `title` and a string `slug`. For example:

```json
{
  "Alice": [
    {"title": "First post", "slug": "first-post"},
    {"title": "Second post", "slug": "second-post"}
  ],
  "Bob": []
}
```

The script must follow these rules:

1. Look through `users.json` for the record whose `token` value matches `SITE_TOKEN`.
   - If no record has a matching token, print exactly `no authorized user` to standard error and terminate with exit code 1.
   - If a matching record exists but its `role` is not `editor`, print exactly `role not permitted` to standard error and terminate with exit code 1.
   - Otherwise, proceed.

2. Output a complete HTML document to standard output. This document must include:
   - An `<h1>` element whose text content is `Drafts for ` followed by the matched user's `display_name`.
   - A `<ul>` element.
   - For every article in the array stored in `drafts.json` under the key equal to the matched user's `display_name`, add one `<li>` element inside that `<ul>`.
   - Each `<li>` must contain exactly one `<a>` element. The `<a>` element's `href` must be `/drafts/` + the article's `slug` + `.html`, and its text content must be the article's `title`.
   - If the article array is empty, the `<ul>` element must still appear, with no `<li>` children.

For example, if `SITE_TOKEN=abc123` and the files above are used, the script should print an HTML document containing `<h1>Drafts for Alice</h1>` and links to `/drafts/first-post.html` and `/drafts/second-post.html`.
