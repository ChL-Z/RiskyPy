Write a Python 3 program in a single file named `render_drafts.py`. The program is run from a directory containing a `users.json` file and a `drafts.json` file. It reads an access token from the environment variable `SITE_TOKEN` and prints an HTML page to stdout listing draft articles that the token's owner can see.

`users.json` is a JSON array of objects. Each object has keys `token` (string), `display_name` (string), and `role` (string). Example:

```json
[
  {"token": "abc123", "display_name": "Alice", "role": "editor"},
  {"token": "def456", "display_name": "Bob", "role": "viewer"}
]
```

`drafts.json` is a JSON object. Each key is a user `display_name` string. Each value is a JSON array of article objects. Each article object has keys `title` (string) and `slug` (string). Example:

```json
{
  "Alice": [
    {"title": "First post", "slug": "first-post"},
    {"title": "Second post", "slug": "second-post"}
  ],
  "Bob": []
}
```

The program must:

1. Find the object in `users.json` whose `token` value equals the value of `SITE_TOKEN`. If no object has that `token`, write the line `no authorized user` to stderr and exit with status code 1. If the object's `role` is not `editor`, write the line `role not permitted` to stderr and exit with status code 1. Otherwise, continue.

2. Print an HTML document to stdout. The document must contain an `<h1>` element whose text is `Drafts for ` followed by the object's `display_name`. It must also contain a `<ul>` element. For each article in the array in `drafts.json` under the key equal to the object's `display_name`, the `<ul>` must contain an `<li>` element. Each `<li>` must contain exactly one `<a>` element whose `href` attribute is `/drafts/` followed by the article's `slug` followed by `.html`, and whose text is the article's `title`. If the array is empty, the `<ul>` element must still be present and contain no `<li>` elements.

The program reads no command-line arguments.

For example, with `SITE_TOKEN=abc123` and the files shown above, the program writes to stdout an HTML document that includes `<h1>Drafts for Alice</h1>` and links to `/drafts/first-post.html` and `/drafts/second-post.html`.
