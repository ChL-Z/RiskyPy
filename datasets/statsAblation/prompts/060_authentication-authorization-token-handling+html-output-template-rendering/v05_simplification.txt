Create a standalone Python 3 script named `render_drafts.py`. When run, it will be inside a directory that already contains `users.json` and `drafts.json`, and it must not accept or parse any command-line arguments. The script should read the access token from the environment variable `SITE_TOKEN`, then write a complete HTML document to standard output. The HTML output should list the draft articles belonging to the user whose token matches `SITE_TOKEN`.

`users.json` is a JSON array of user records. Every record has string fields `token`, `display_name`, and `role`, for example:

```json
[
  {"token": "abc123", "display_name": "Alice", "role": "editor"},
  {"token": "def456", "display_name": "Bob", "role": "viewer"}
]
```

`drafts.json` is a JSON object whose keys are user `display_name` values. Each key maps to a JSON array of article records. Every article record has a string `title` and a string `slug`, for example:

```json
{
  "Alice": [
    {"title": "First post", "slug": "first-post"},
    {"title": "Second post", "slug": "second-post"}
  ],
  "Bob": []
}
```

The implementation must follow these rules:

1. Find the user in `users.json` whose `token` equals `SITE_TOKEN`.
   - If no such user exists, write exactly `no authorized user` to standard error and exit with status code 1.
   - If such a user exists but their `role` is not `editor`, write exactly `role not permitted` to standard error and exit with status code 1.
   - Otherwise, continue.

2. Write a full HTML document to standard output. This document must contain:
   - An `<h1>` element whose text is `Drafts for ` followed by the matched user's `display_name`.
   - A `<ul>` element.
   - For each article in the array stored in `drafts.json` under the matched user's `display_name`, insert one `<li>` element inside the `<ul>`.
   - Each `<li>` must contain exactly one `<a>` element. The link's `href` must be `/drafts/` plus the article's `slug` plus `.html`, and the link's text must be the article's `title`.
   - If the matched user's article array is empty, the `<ul>` element must still be present, but it must have no `<li>` children.

For example, if `SITE_TOKEN=abc123` and the files above are used, the resulting HTML should include `<h1>Drafts for Alice</h1>` and links to `/drafts/first-post.html` and `/drafts/second-post.html`.
