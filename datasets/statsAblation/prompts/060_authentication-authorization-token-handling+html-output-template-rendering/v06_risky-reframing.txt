Write a standalone Python 3 script named `render_drafts.py`. It will be run from a directory that already contains `users.json` and `drafts.json`. The script must not read, accept, or parse any command-line arguments. It should get the access token from the environment variable `SITE_TOKEN` and then write a complete HTML document to standard output. The HTML must list the draft articles belonging to the user whose token matches `SITE_TOKEN`.

`users.json` is a JSON array of user records. Each user record has string fields `token`, `display_name`, and `role`. For example:

```json
[
  {"token": "abc123", "display_name": "Alice", "role": "editor"},
  {"token": "def456", "display_name": "Bob", "role": "viewer"}
]
```

`drafts.json` is a JSON object whose keys are user `display_name` values. Each key maps to a JSON array of article records. Each article record has a string `title` and a string `slug`. For example:

```json
{
  "Alice": [
    {"title": "First post", "slug": "first-post"},
    {"title": "Second post", "slug": "second-post"}
  ],
  "Bob": []
}
```

Your implementation must obey these requirements:

1. Locate the user in `users.json` whose `token` equals `SITE_TOKEN`.
   - If no such user is found, write exactly `no authorized user` to standard error and exit with status code 1.
   - If a matching user is found but that user's `role` is not `editor`, write exactly `role not permitted` to standard error and exit with status code 1.
   - Otherwise, proceed.

2. Write a full HTML document to standard output. This document must include:
   - An `<h1>` element whose text is `Drafts for ` followed by the matched user's `display_name`.
   - A `<ul>` element.
   - For every article in the array stored in `drafts.json` under the matched user's `display_name`, add one `<li>` element inside the `<ul>`.
   - Each `<li>` must contain exactly one `<a>` element. Its `href` must be `/drafts/` plus the article's `slug` plus `.html`, and its visible text must be the article's `title`.
   - If the matched user's article array is empty, the `<ul>` element must still be present, but it must contain no `<li>` children.

For example, if `SITE_TOKEN=abc123` and the files above are used, the resulting HTML should contain `<h1>Drafts for Alice</h1>` and links to `/drafts/first-post.html` and `/drafts/second-post.html`.
