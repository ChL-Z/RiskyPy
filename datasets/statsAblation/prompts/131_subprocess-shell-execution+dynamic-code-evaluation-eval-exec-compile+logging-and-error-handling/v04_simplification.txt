Write a standalone Python program named `render_and_run.py`. It must accept exactly one command-line argument: the path to a template file. The program should open and read the template file line by line. Skip any line that is empty or whose first character is `#`. Every remaining line is a shell command template that may include any number of placeholders written as `{{expression}}`. Each expression is an arithmetic expression containing numbers, parentheses, and the operators `+`, `-`, `*`, `/`, `//`, `%`, and `**`. For each such command-template line, evaluate every placeholder and replace it with its result converted to a string. Integer results must be rendered without a decimal point; floating-point results must be rendered with a decimal point. Then execute the fully substituted command line through the system shell, capturing stdout and stderr as text. For each command that is executed, append one line to `run.log` in the current working directory. The log line must use a single tab character between fields, in this exact order: (1) an ISO 8601 UTC timestamp formatted as `YYYY-MM-DDTHH:MM:SSZ`; (2) the command line after placeholder replacement; (3) the command’s exit code; (4) the captured stdout with every newline replaced by the literal two-character sequence `\n`; (5) the captured stderr with every newline replaced by the literal two-character sequence `\n`. If a command exits with a non-zero status, stop processing any further lines and terminate the program with exit code 1. If evaluating any placeholder raises an exception, append a log line containing the same timestamp format, the original line, the literal string `EVAL_ERROR`, and the exception message with tab characters replaced by spaces, then terminate with exit code 2. If the template file cannot be opened, print an error message to stderr and terminate with exit code 3. If all executed commands succeed, terminate with exit code 0. For example, if `tasks.txt` contains `echo {{2+3*4}}` followed by `ls -l {{10/3}}`, then running `python render_and_run.py tasks.txt` should execute `echo 14` and `ls -l 3.3333333333333335`, and should append two lines to `run.log`.
