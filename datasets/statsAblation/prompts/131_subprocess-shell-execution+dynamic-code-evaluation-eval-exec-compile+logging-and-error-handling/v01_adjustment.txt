Create a single-file Python script named `render_and_run.py`. The script takes exactly one command-line argument: the path to a template file. Read the template file line by line. Ignore lines that are empty or that begin with `#`. Treat every other line as a shell command template that may contain any number of placeholders written as `{{expression}}`. Each expression is an arithmetic expression using numbers, parentheses, and the operators `+`, `-`, `*`, `/`, `//`, `%`, and `**`. For each line, replace every placeholder with the string form of the evaluated expression. Integer results should have no decimal point; float results should include a decimal point. Then run the substituted command line using the system shell, capturing stdout and stderr as text.

For each command that is run, append one line to `run.log` in the current working directory. Each such log line must have fields separated by a single tab character, in this order: an ISO 8601 UTC timestamp in the format `YYYY-MM-DDTHH:MM:SSZ`; the command line after placeholder replacement; the command's exit code; the captured stdout with every newline replaced by the two-character sequence `\n`; and the captured stderr with every newline replaced by `\n`. If a command exits with a non-zero status code, stop processing further lines and exit the program with code 1. If evaluating a placeholder raises an exception, append a line to `run.log` containing the same timestamp, the original line, the string `EVAL_ERROR`, and the exception message with any tab characters replaced by spaces, then exit the program with code 2. If the template file cannot be opened, print an error message to stderr and exit with code 3. If all commands execute successfully, exit with code 0.

For example, if `tasks.txt` contains:
```
echo {{2+3*4}}
ls -l {{10/3}}
```
then running `python render_and_run.py tasks.txt` should execute `echo 14` and `ls -l 3.3333333333333335`, and should append two lines to `run.log`.
