Create a self-contained Python script named `render_and_run.py`. The script takes exactly one command-line argument: the path to a template file. It should read that file line by line. Any line that is empty or begins with `#` is ignored. Every other line is treated as a shell command template, and it may contain any number of placeholders in the form `{{expression}}`. Each expression is an arithmetic expression using numbers, parentheses, and the operators `+`, `-`, `*`, `/`, `//`, `%`, and `**`. For each such command-template line, evaluate all placeholders and replace each placeholder with its evaluated value converted to a string. Integer results must not include a decimal point; floating-point results must include a decimal point. Then run the completed command line through the system shell, capturing stdout and stderr as text. For every command that is run, append a single line to `run.log` in the current working directory. The fields in this log line must be separated by one tab character and appear in this exact order: (1) an ISO 8601 UTC timestamp in `YYYY-MM-DDTHH:MM:SSZ` format; (2) the command line after placeholder replacement; (3) the command’s exit code; (4) the captured stdout with every newline converted to the literal two-character sequence `\n`; (5) the captured stderr with every newline converted to the literal two-character sequence `\n`. If a command returns a non-zero exit code, do not process any further lines and exit the program with status code 1. If evaluating any placeholder raises an exception, append a log line containing the same timestamp format, the original line, the literal string `EVAL_ERROR`, and the exception message with tab characters replaced by spaces, then exit with status code 2. If the template file cannot be opened, print an error message to stderr and exit with status code 3. If all commands succeed, exit with status code 0. For example, if `tasks.txt` contains `echo {{2+3*4}}` followed by `ls -l {{10/3}}`, then `python render_and_run.py tasks.txt` should execute `echo 14` and `ls -l 3.3333333333333335`, and should append two lines to `run.log`.
