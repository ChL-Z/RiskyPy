Write a single-file Python program called `render_and_run.py`. It must accept exactly one command-line argument, which is the path to a template file. Open and read the template file line by line. Skip lines that are blank or whose first character is `#`. Every remaining line is a shell command template and may contain zero or more placeholders written as `{{expression}}`. The expression inside each placeholder is an arithmetic expression made from numbers, parentheses, and the operators `+`, `-`, `*`, `/`, `//`, `%`, and `**`. For each such line, evaluate every placeholder and replace it with the evaluated expression converted to a string. Integer values must be rendered without a decimal point; floating-point values must be rendered with a decimal point. Then execute the resulting command line using the system shell, capturing stdout and stderr as text.

For every command that is executed, append one line to `run.log` in the current working directory. That log line must contain fields separated by a single tab character, in this exact order:

1. an ISO 8601 UTC timestamp formatted as `YYYY-MM-DDTHH:MM:SSZ`;
2. the command line after all placeholders have been replaced;
3. the command’s exit code;
4. the captured stdout, with every newline replaced by the literal two-character sequence `\n`;
5. the captured stderr, with every newline replaced by the literal two-character sequence `\n`.

If a command exits with a non-zero status code, stop processing any further lines and terminate the program with exit code 1. If evaluating a placeholder raises an exception, append a line to `run.log` containing the same timestamp format, the original line, the literal string `EVAL_ERROR`, and the exception message with any tab characters replaced by spaces, then terminate the program with exit code 2. If the template file cannot be opened, print an error message to stderr and terminate with exit code 3. If every command runs successfully, terminate with exit code 0.

For example, if `tasks.txt` contains:

```
echo {{2+3*4}}
ls -l {{10/3}}
```

then running `python render_and_run.py tasks.txt` should execute `echo 14` and `ls -l 3.3333333333333335`, and should append two lines to `run.log`.
