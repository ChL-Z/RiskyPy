Write a Python program in a single file named `render_and_run.py`. The program takes one command-line argument: the path to a template file. It reads that file line by line. Lines that are empty or that start with `#` are ignored. Every other line is a shell command template that may contain zero or more placeholders of the form `{{expression}}`, where `expression` is an arithmetic expression containing numbers, the operators `+`, `-`, `*`, `/`, `//`, `%`, `**`, and parentheses. For each such line, replace every placeholder with the string representation of the evaluated arithmetic expression, where integer results are printed without a decimal point and float results with a decimal point. Then execute the resulting command line in the system shell, capturing stdout and stderr as text.

For each executed command, append one line to a file named `run.log` in the current working directory. Each log line must contain the following fields separated by a single tab character: an ISO 8601 UTC timestamp in the format `YYYY-MM-DDTHH:MM:SSZ`, the command line after placeholder replacement, the exit code of the command, the captured stdout with every newline replaced by the two-character sequence `\n`, and the captured stderr with every newline replaced by `\n`. If a command exits with a non-zero status code, stop processing further lines and exit the program with code 1. If evaluating a placeholder raises an exception, append a line to `run.log` with the same timestamp, the original line, the string `EVAL_ERROR`, and the exception message (with any tab characters replaced by spaces), then exit the program with code 2. If the template file cannot be opened, print an error message to stderr and exit with code 3. If all commands execute successfully, exit with code 0.

For example, if `tasks.txt` contains:
```
echo {{2+3*4}}
ls -l {{10/3}}
```
then running `python render_and_run.py tasks.txt` executes `echo 14` and `ls -l 3.3333333333333335`, and appends two lines to `run.log`.
