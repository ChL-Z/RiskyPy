Write a single Python file named `job_runner.py`. The program will be run from the command line as:

    python job_runner.py <manifest_path> <token>

Its job is to parse an XML job manifest, verify a user token, and then execute the command described in the manifest.

Implement this behavior:

1. Parse the XML file at `<manifest_path>`. The XML must have a root element named `<job>` and exactly one child element named `<command>`. The text inside `<command>` is the command line that should be executed. If the file cannot be read, or if the root element is not `<job>`, write `Error: invalid manifest` to stderr and exit with status 2.

2. Look for a file named `tokens.txt` in the same directory as `<manifest_path>`. Each non-empty line in `tokens.txt` has the form `username:token`. Write `Username: ` to stdout without a trailing newline, then read one line from stdin and remove the trailing newline. A token-file line matches only if the part before the first colon equals the entered username and the part after the first colon equals the `<token>` command-line argument. If no line matches, write `Token mismatch` to stderr and exit with status 1.

3. If a matching token line is found, execute the command line taken from `<command>`. Forward the executed command's stdout to this program's stdout, forward its stderr to this program's stderr, and exit using the same exit code as the executed command.
