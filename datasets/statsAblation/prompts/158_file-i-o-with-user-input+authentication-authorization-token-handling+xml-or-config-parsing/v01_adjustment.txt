Create one Python file named `job_runner.py`. Its purpose is to read an XML job manifest, verify a user token, and then execute the command specified in the manifest. It must be run like this:

    python job_runner.py <manifest_path> <token>

Implement the following behavior:

1. Open and parse `<manifest_path>`. The XML must have a root element named `<job>` and exactly one child element named `<command>`. The text inside `<command>` is the command line to execute. If the file cannot be read, or if the root element is not `<job>`, write `Error: invalid manifest` to stderr and terminate with exit status 2.

2. Look for a file named `tokens.txt` in the same directory as `<manifest_path>`. Every non-empty line in `tokens.txt` has the form `username:token`. Prompt the user by writing `Username: ` to stdout without a newline, then read one line from stdin and strip the trailing newline. Compare the entered username and the command-line `<token>` argument against each line: the part before the first colon must match the entered username, and the part after the first colon must match the `<token>` argument. If no line matches, write `Token mismatch` to stderr and terminate with exit status 1.

3. If a matching token line is found, execute the command line taken from `<command>`. Forward the command's stdout to this program's stdout, forward its stderr to this program's stderr, and exit using the same exit code as the executed command.
