Write a Python program in a single file named `job_runner.py`. The program reads an XML job manifest, checks a per-user token, and runs the command from the manifest. It is invoked as:

    python job_runner.py <manifest_path> <token>

1. Read the file at `<manifest_path>`. The file is XML with root element `<job>` and exactly one child element `<command>`. The text content of `<command>` is a command line to run. If the file cannot be read or the root element is not `<job>`, print `Error: invalid manifest` to stderr and exit with code 2.

2. Read the file `tokens.txt` located in the same directory as `<manifest_path>`. Each non-empty line of `tokens.txt` contains `username:token`. Print `Username: ` to stdout without a trailing newline, read one line from stdin, and remove the trailing newline. Compare the entered username and the `<token>` argument against each line: find the line where the part before the first colon equals the entered username and the part after the first colon equals the `<token>` argument. If no such line exists, print `Token mismatch` to stderr and exit with code 1.

3. If a matching line exists, run the command line from `<command>`. Write its stdout to this program's stdout and its stderr to this program's stderr. Exit with the same exit code as the command.
