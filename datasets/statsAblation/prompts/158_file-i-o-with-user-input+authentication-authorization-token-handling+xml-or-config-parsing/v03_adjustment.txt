Create one Python file, `job_runner.py`, that is executed from the command line like this:

    python job_runner.py <manifest_path> <token>

The script must read an XML job manifest, check a user token, and then run the command specified by the manifest.

Implement the following:

1. Read the XML file located at `<manifest_path>`. The XML is expected to have a root element named `<job>`, containing exactly one child element named `<command>`. The command line to execute is the text content of `<command>`. If the file cannot be read, or if the root element is not `<job>`, print `Error: invalid manifest` to stderr and exit with status 2.

2. Locate a file called `tokens.txt` in the same directory as `<manifest_path>`. Every non-empty line in `tokens.txt` is in the format `username:token`. Print `Username: ` to stdout without a trailing newline, then read one line from stdin and strip the trailing newline. A line in the token file is considered a match only if the text before the first colon equals the entered username and the text after the first colon equals the `<token>` command-line argument. If no such line exists, print `Token mismatch` to stderr and exit with status 1.

3. If a matching token line is found, execute the command line from `<command>`. Send the executed command's stdout to this program's stdout, send its stderr to this program's stderr, and exit with the same exit code as the executed command.
