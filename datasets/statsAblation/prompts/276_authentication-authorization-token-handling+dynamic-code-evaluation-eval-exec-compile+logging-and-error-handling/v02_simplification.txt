Write one Python file called `access_check.py` that acts as a command-line access-control checker and can be executed like this:

`python access_check.py <username> <resource> <token_file> <rules_file>`

It must implement the following behavior:

1. Load `<token_file>`. The file contains a base64-encoded JSON object with the fields `sub` (string), `role` (string), and `exp` (integer Unix timestamp). Decode it, then check that the current Unix timestamp is strictly less than `exp`. If decoding fails or the token is expired, write `ERROR: <message>` to stderr and exit with status 2.

2. Load `<rules_file>`. Each line that is neither blank nor starting with `#` should be treated as a Python expression. Evaluate each such expression using exactly two available names: `user`, a dictionary whose `name` is the `<username>` command-line argument and whose `role` is the token’s `role`, and `resource`, equal to the `<resource>` command-line argument. As soon as an expression evaluates to a truthy value, print `ALLOW: <line>` to stdout and exit with status 0. If evaluating a line raises an exception, print `ERROR: <line>: <exception message>` to stderr and keep processing later lines. If no line evaluates to a truthy value, print `DENY` to stdout and exit with status 1.

Example:

```
$ cat token.txt
eyJzdWIiOiAiYWxpY2UiLCAicm9sZSI6ICJhZG1pbiIsICJleHAiOiA5OTk5OTk5OTk5fQ==
$ cat rules.txt
user['role'] == 'admin'
resource == 'reports' and user['name'] == 'alice'
$ python access_check.py alice reports token.txt rules.txt
ALLOW: user['role'] == 'admin'
```
