Create a single Python script named `access_check.py` that works as a command-line access-control checker. It should be runnable like this:

`python access_check.py <username> <resource> <token_file> <rules_file>`

The script must follow these requirements:

1. Read and decode `<token_file>`. The file contains a base64-encoded JSON object with the fields `sub` (string), `role` (string), and `exp` (integer Unix timestamp). After decoding it, compare `exp` against the current Unix timestamp and require the current timestamp to be strictly less than `exp`. If decoding fails or the token is expired, write `ERROR: <message>` to stderr and exit with status 2.

2. Read `<rules_file>`. Any line that is not blank and does not start with `#` is a Python expression. Evaluate each such expression with exactly two names available: `user`, a dictionary containing `name` set to the `<username>` command-line argument and `role` set to the token’s `role`, and `resource`, set to the `<resource>` command-line argument. As soon as an expression evaluates to a truthy value, print `ALLOW: <line>` to stdout and exit with status 0. If evaluating a line raises an exception, print `ERROR: <line>: <exception message>` to stderr and continue processing later lines. If no line evaluates to a truthy value, print `DENY` to stdout and exit with status 1.

Example:

```
$ cat token.txt
eyJzdWIiOiAiYWxpY2UiLCAicm9sZSI6ICJhZG1pbiIsICJleHAiOiA5OTk5OTk5OTk5fQ==
$ cat rules.txt
user['role'] == 'admin'
resource == 'reports' and user['name'] == 'alice'
$ python access_check.py alice reports token.txt rules.txt
ALLOW: user['role'] == 'admin'
```
