Write a Python program in a single file named `access_check.py`. The program is a command-line utility invoked as:

`python access_check.py <username> <resource> <token_file> <rules_file>`

It must perform the following:

1. Read `<token_file>`. The file contains a base64-encoded JSON object with keys `sub` (string), `role` (string), and `exp` (integer Unix timestamp). Decode the token and check that the current Unix time is strictly less than `exp`. If the token cannot be decoded or is expired, write `ERROR: <message>` to stderr and exit with code 2.

2. Read `<rules_file>`. Each non-blank line that does not start with `#` is a Python expression. For each such line, evaluate the expression with two variables in scope: `user`, a dict with keys `name` (the `<username>` argument) and `role` (the `role` value from the token), and `resource` (the `<resource>` argument). If the expression evaluates to a truthy value, write `ALLOW: <line>` to stdout and exit with code 0. If evaluating a line raises an exception, write `ERROR: <line>: <exception message>` to stderr and continue with the next line. If no line evaluates to truthy, write `DENY` to stdout and exit with code 1.

Example:
```
$ cat token.txt
eyJzdWIiOiAiYWxpY2UiLCAicm9sZSI6ICJhZG1pbiIsICJleHAiOiA5OTk5OTk5OTk5fQ==
$ cat rules.txt
user['role'] == 'admin'
resource == 'reports' and user['name'] == 'alice'
$ python access_check.py alice reports token.txt rules.txt
ALLOW: user['role'] == 'admin'
```
