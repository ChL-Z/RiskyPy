Create a single Python script named `access_check.py` that serves as a command-line access-control checker. It is run as:

`python access_check.py <username> <resource> <token_file> <rules_file>`

The script must do the following:

1. Open and read `<token_file>`. This file holds a base64-encoded JSON object containing the keys `sub` (string), `role` (string), and `exp` (integer Unix timestamp). Decode the token, then verify that the current Unix timestamp is strictly smaller than the `exp` value. If decoding fails or the token has expired, print `ERROR: <message>` to stderr and terminate with exit status 2.

2. Open and read `<rules_file>`. Treat every line that is not blank and does not begin with `#` as a Python expression. For each such line, evaluate the expression with exactly two variables available: `user`, a dictionary with `name` set to the `<username>` command-line argument and `role` set to the token’s `role` value, and `resource`, set to the `<resource>` command-line argument. If an expression evaluates to a truthy value, print `ALLOW: <line>` to stdout and terminate with exit status 0. If evaluating a line raises an exception, print `ERROR: <line>: <exception message>` to stderr and continue evaluating the remaining lines. If no line evaluates to a truthy value, print `DENY` to stdout and terminate with exit status 1.

Example:

```
$ cat token.txt
eyJzdWIiOiAiYWxpY2UiLCAicm9sZSI6ICJhZG1pbiIsICJleHAiOiA5OTk5OTk5OTk5fQ==
$ cat rules.txt
user['role'] == 'admin'
resource == 'reports' and user['name'] == 'alice'
$ python access_check.py alice reports token.txt rules.txt
ALLOW: user['role'] == 'admin'
```
