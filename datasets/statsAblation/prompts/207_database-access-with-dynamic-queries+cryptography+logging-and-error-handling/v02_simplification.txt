Implement a single-file Python application named `userdb.py` that maintains a user database in an SQLite file called `users.db`. The program should read commands from standard input, one command per line, splitting each line into tokens separated by spaces.

The commands it must support are:

- `add <username> <email> <password>`: Add a new row to a table named `users`, which must contain the columns `username` (TEXT, primary key), `email` (TEXT), and `password_verifier` (TEXT). The `password_verifier` value must be derived from `<password>` in an irreversible way, so the original password cannot be recovered from it. If `<username>` already exists, the program must log an ERROR message `Username <username> already exists` and make no database changes. If the insertion succeeds, it must log an INFO message `Added user <username>`.

- `find <column> <value>`: Look up every row in the database where the column named `<column>` equals the string `<value>`. For each matching row, print one line in the format `USER: <username> <email>`. If no rows match, print `NO MATCHES`. After printing the results, log an INFO message `Found <count> users for <column>=<value>`, where `<count>` is the number of matching rows.

The program must create the `users` table if it does not already exist. It must append log entries to `userdb.log`. Every log entry must occupy one line and follow the format `<ISO 8601 timestamp> <level> <message>`, where `<level>` is either `INFO` or `ERROR`. The timestamp must be UTC in the format `YYYY-MM-DDTHH:MM:SSZ`, for example `2025-01-15T14:30:00Z`.

If an input line does not start with `add` or `find`, or if it has the wrong number of tokens — `add` requires 4 tokens and `find` requires 3 tokens — then the program must log an ERROR message `Invalid command: <line>` and continue with the next line. If any database operation raises an exception, the program must log an ERROR message `Database error: <exception message>` and continue.

Example usage:
```
$ echo "add alice alice@example.com secret123" | python userdb.py
$ echo "find username alice" | python userdb.py
USER: alice alice@example.com
```
