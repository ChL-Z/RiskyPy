Write a single-file Python application named `userdb.py` that implements a command-line user database using an SQLite file called `users.db`. The program should read from standard input, handle one command per line, and parse each line by splitting it on whitespace into tokens.

The program must implement two commands:

- `add <username> <email> <password>`
  Add a new record to a table named `users`. The table must contain the columns `username` (TEXT, primary key), `email` (TEXT), and `password_verifier` (TEXT). The `password_verifier` value must be derived from `<password>` using an irreversible method, so the original password cannot be recovered from it. If `<username>` already exists, append an ERROR log line `Username <username> already exists` and leave the database unchanged. If the insert succeeds, append an INFO log line `Added user <username>`.

- `find <column> <value>`
  Query all rows in the database where the column named `<column>` has the string value `<value>`. For each matching row, print exactly one line in this format: `USER: <username> <email>`. If no rows match, print `NO MATCHES`. After printing the results, append an INFO log line `Found <count> users for <column>=<value>`, where `<count>` is the number of matching rows.

The `users` table must be created automatically if it does not already exist.

Log messages must be appended to `userdb.log`. Each log entry must be a single line in the format `<ISO 8601 timestamp> <level> <message>`, where `<level>` is either `INFO` or `ERROR`. Timestamps must be UTC and use exactly the format `YYYY-MM-DDTHH:MM:SSZ`, for example `2025-01-15T14:30:00Z`.

If an input line does not start with `add` or `find`, or if the token count is wrong — `add` must have 4 tokens and `find` must have 3 tokens — append an ERROR log line `Invalid command: <line>` and continue to the next input line. If any database operation raises an exception, append an ERROR log line `Database error: <exception message>` and continue.

Example behavior:
```
$ echo "add alice alice@example.com secret123" | python userdb.py
$ echo "find username alice" | python userdb.py
USER: alice alice@example.com
```
