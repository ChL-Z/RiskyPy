Write a Python script in a single file named `userdb.py`. The script maintains a user database in an SQLite file named `users.db`. It reads commands from standard input, one command per line. Each line contains space-separated tokens.

There are two commands:
- `add <username> <email> <password>`: Adds a new user to the database. The database table is named `users` and has columns `username` (text, primary key), `email` (text), and `password_verifier` (text). The `password_verifier` column must store a value derived from the `<password>` token such that the original password cannot be recovered from it. If a user with the same `<username>` already exists, the command must log an ERROR message `Username <username> already exists` and not modify the database. On success, it must log an INFO message `Added user <username>`.
- `find <column> <value>`: Queries the database for all rows where the column named `<column>` equals the string `<value>`. Prints each matching row's username and email on a separate line in the format `USER: <username> <email>`. If no rows match, prints `NO MATCHES`. After printing, logs an INFO message `Found <count> users for <column>=<value>` where `<count>` is the number of matching rows.

The script must create the `users` table if it does not exist. It must append log entries to a file named `userdb.log`. Each log entry occupies one line and has the format `<ISO 8601 timestamp> <level> <message>`, where `<level>` is either `INFO` or `ERROR`. The timestamp must be in UTC and formatted as `YYYY-MM-DDTHH:MM:SSZ` (e.g., `2025-01-15T14:30:00Z`).

If a command line does not start with `add` or `find`, or has an incorrect number of tokens (4 tokens for `add`, 3 tokens for `find`), the script must log an ERROR message `Invalid command: <line>` and continue processing the next line. If any database operation raises an exception, the script must log an ERROR message `Database error: <exception message>` and continue.

Example usage:
```
$ echo "add alice alice@example.com secret123" | python userdb.py
$ echo "find username alice" | python userdb.py
USER: alice alice@example.com
```
