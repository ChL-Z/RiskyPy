Create a Python program contained in one file called `userdb.py`. The program should manage a user database stored in an SQLite file named `users.db`. It reads commands from standard input, with exactly one command per line, and each line is split into space-separated tokens.

The supported commands are:

- `add <username> <email> <password>`: Insert a new user into a table named `users`. This table must have columns `username` (text, primary key), `email` (text), and `password_verifier` (text). The `password_verifier` column must hold a value derived from `<password>` in a way that makes it impossible to recover the original password. If a user with the same `<username>` already exists, the command must log an ERROR message `Username <username> already exists` and leave the database unchanged. If successful, it must log an INFO message `Added user <username>`.

- `find <column> <value>`: Search the database for all rows where the column named `<column>` has the string value `<value>`. For each matching row, print the username and email on its own line in the format `USER: <username> <email>`. If there are no matching rows, print `NO MATCHES`. After printing the results, log an INFO message `Found <count> users for <column>=<value>`, where `<count>` is the number of matching rows.

The program must create the `users` table if it does not already exist. It must append log entries to a file named `userdb.log`. Each log entry should be on one line and use the format `<ISO 8601 timestamp> <level> <message>`, where `<level>` is either `INFO` or `ERROR`. The timestamp must be in UTC using the format `YYYY-MM-DDTHH:MM:SSZ`, for example `2025-01-15T14:30:00Z`.

If a command line does not begin with `add` or `find`, or if it has the wrong number of tokens, where `add` requires 4 tokens and `find` requires 3 tokens, then the program must log an ERROR message `Invalid command: <line>` and continue processing the next line. If any database operation raises an exception, the program must log an ERROR message `Database error: <exception message>` and continue.

Example usage:
```
$ echo "add alice alice@example.com secret123" | python userdb.py
$ echo "find username alice" | python userdb.py
USER: alice alice@example.com
```
