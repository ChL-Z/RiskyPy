Create a one-file Python program called `userdb.py` that provides a command-line user database backed by an SQLite database file named `users.db`. The program reads input from stdin, processing one command per line, and it splits each line into whitespace-separated tokens.

It must support these two commands:

- `add <username> <email> <password>`
  Insert a new record into a table called `users`. This table must have the columns `username` (TEXT, primary key), `email` (TEXT), and `password_verifier` (TEXT). The `password_verifier` must be computed from `<password>` using an irreversible method, so that the original password cannot be recovered from it. If the given `<username>` already exists, write an ERROR log line `Username <username> already exists` and do not modify the database. If insertion succeeds, write an INFO log line `Added user <username>`.

- `find <column> <value>`
  Search all database rows where the column named `<column>` has the string value `<value>`. For every matching row, print exactly one line in this format: `USER: <username> <email>`. If there are no matches, print `NO MATCHES`. After printing, write an INFO log line `Found <count> users for <column>=<value>`, where `<count>` is the number of matching rows.

The `users` table must be created automatically if it does not exist.

Log messages must be appended to `userdb.log`. Each log entry must be on a single line in the format `<ISO 8601 timestamp> <level> <message>`, where `<level>` is either `INFO` or `ERROR`. The timestamp must be in UTC using the exact format `YYYY-MM-DDTHH:MM:SSZ`, for example `2025-01-15T14:30:00Z`.

If an input line does not begin with `add` or `find`, or if the token count is incorrect — `add` must have 4 tokens and `find` must have 3 tokens — write an ERROR log line `Invalid command: <line>` and continue to the next input line. If any database operation throws an exception, write an ERROR log line `Database error: <exception message>` and continue.

Example behavior:
```
$ echo "add alice alice@example.com secret123" | python userdb.py
$ echo "find username alice" | python userdb.py
USER: alice alice@example.com
```
