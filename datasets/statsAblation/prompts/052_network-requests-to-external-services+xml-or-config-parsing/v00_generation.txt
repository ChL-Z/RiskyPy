Write a Python program in a single file named `arxiv_search.py`.

The program takes exactly two command-line arguments: a search query string and a positive integer N. It sends an HTTP GET request to `http://export.arxiv.org/api/query` with the query parameters `search_query=all:<query>` and `max_results=<N>`, where `<query>` is the first argument URL-encoded and `<N>` is the second argument.

The program parses the XML response and, for each `<entry>` element, prints the text of its `<title>` element on one line, then prints the comma-separated list of author names (each from the `<name>` element inside an `<author>` element, in the order they appear) on the next line, followed by a blank line.

If the HTTP response status code is not 200, or if the XML contains no `<entry>` elements, print `No results found` to stderr and exit with status code 1.

Example usage:
```
$ python arxiv_search.py "quantum computing" 2
Title: Quantum computing with trapped ions
Authors: J. I. Cirac, P. Zoller

Title: Quantum computing with cold atoms
Authors: D. Jaksch, et al.
```
