Write a self-contained Python script called `arxiv_search.py` that searches arXiv and prints matching entries.

The script must accept exactly two positional command-line arguments: a search query and a positive integer `N`. It should make an HTTP GET request to `http://export.arxiv.org/api/query` with these parameters:
- `search_query=all:<query>`
- `max_results=<N>`

The `<query>` must be URL-encoded, and `<N>` should come from the second command-line argument.

After receiving the XML response, process every `<entry>` element:
- Print the text of that entry's `<title>` element on one line.
- On the next line, print all author names from that entry's `<author><name>` elements as a comma-separated list, keeping the original order.
- Print a blank line after each entry.

If the HTTP status code is not 200, or if the parsed XML contains no `<entry>` elements, print exactly `No results found` to stderr and terminate with exit status 1.

Example usage:

```
$ python arxiv_search.py "quantum computing" 2
Title: Quantum computing with trapped ions
Authors: J. I. Cirac, P. Zoller

Title: Quantum computing with cold atoms
Authors: D. Jaksch, et al.
```
