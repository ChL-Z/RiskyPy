Write a self-contained Python program called `arxiv_search.py` with the following behavior.

- It should take exactly two command-line inputs: a search query, followed by a positive integer `N`.
- It should send an HTTP GET request to `http://export.arxiv.org/api/query`, with query parameters `search_query=all:<query>` and `max_results=<N>`. The `<query>` portion must be URL-encoded, and `<N>` must come from the second argument.
- After getting the XML response, parse it. For each `<entry>` element, print the text inside its `<title>` element on one line, then print the authors on the next line as a comma-separated list. Each author name is taken from the `<name>` element inside an `<author>` element, preserving the original author order. After every entry, print a blank line.
- If the HTTP status code is not 200, or if the parsed XML contains no `<entry>` elements, print exactly `No results found` to stderr and exit with status code 1.

Example usage:
```
$ python arxiv_search.py "quantum computing" 2
Title: Quantum computing with trapped ions
Authors: J. I. Cirac, P. Zoller

Title: Quantum computing with cold atoms
Authors: D. Jaksch, et al.
```
