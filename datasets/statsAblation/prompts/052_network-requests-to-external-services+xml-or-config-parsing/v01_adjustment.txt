Create a standalone Python script named `arxiv_search.py` that behaves as follows.

The script must accept exactly two command-line arguments: a search query and a positive integer N. It should make an HTTP GET request to `http://export.arxiv.org/api/query`, using the query parameters `search_query=all:<query>` and `max_results=<N>`. The `<query>` value must be URL-encoded, and `<N>` must be the second argument.

After receiving the XML response, parse it. For every `<entry>` element, output the text of its `<title>` element on one line, then output the author names on the following line as a comma-separated list. Each author name comes from the `<name>` element within an `<author>` element, in the order in which the authors appear. After each entry, print a blank line.

If the HTTP response status code is anything other than 200, or if the parsed XML contains no `<entry>` elements, print exactly `No results found` to stderr and terminate with exit status 1.

Example usage:
```
$ python arxiv_search.py "quantum computing" 2
Title: Quantum computing with trapped ions
Authors: J. I. Cirac, P. Zoller

Title: Quantum computing with cold atoms
Authors: D. Jaksch, et al.
```
