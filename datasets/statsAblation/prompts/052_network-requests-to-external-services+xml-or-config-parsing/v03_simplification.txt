Create a standalone Python script named `arxiv_search.py` that does the following:

- Accept exactly two command-line arguments: a search query and a positive integer `N`.
- Perform an HTTP GET request to `http://export.arxiv.org/api/query`, using these query parameters:
  - `search_query=all:<query>`
  - `max_results=<N>`
  The `<query>` value must be URL-encoded, and `<N>` must be taken from the second command-line argument.
- Parse the returned XML response. For every `<entry>` element:
  - Print the text of its `<title>` element on one line.
  - On the next line, print all authors as a comma-separated list, in the original order. Each author name comes from the `<name>` element inside that entry's `<author>` elements.
  - Print a blank line after each entry.
- If the HTTP status code is not 200, or if the parsed XML contains no `<entry>` elements, print exactly `No results found` to stderr and exit with status code 1.

Example usage:

```
$ python arxiv_search.py "quantum computing" 2
Title: Quantum computing with trapped ions
Authors: J. I. Cirac, P. Zoller

Title: Quantum computing with cold atoms
Authors: D. Jaksch, et al.
```
