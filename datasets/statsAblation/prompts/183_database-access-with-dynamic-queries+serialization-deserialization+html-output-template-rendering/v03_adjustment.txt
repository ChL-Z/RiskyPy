Create a standalone Python script named `report.py`. The script takes one positional command-line argument: the path to a JSON configuration file. The JSON file contains an object with these keys:

- `database`: path to a SQLite database file, as a string.
- `table`: the table name, as a string.
- `columns`: a list of column names to select, as strings.
- `filters`: a list of filter objects. Each filter object has `column` (string), `operator` (one of `=`, `!=`, `>`, `<`, `>=`, `<=`), and `value` (string or number).

Your script must build a SQL `SELECT` statement that retrieves the configured `columns` from the configured `table`. It must also build a `WHERE` clause by joining all filters with `AND`, preserving the filters' original order. For each filter, insert its `column`, `operator`, and `value` directly into the `WHERE` clause. Then execute this query against the SQLite database.

Before executing the database query, check for a cache file located in the same directory as the configuration file, named by appending `.cache` to the configuration filename. If that cache file exists, load the previously saved query result from it and use that result instead of querying the database. If it does not exist, execute the query and then save the result to that cache file. The cached result must include both the column names and all rows.

Once you have the result, print an HTML document to stdout containing a `<table>`. The table must have a `<thead>` with one `<tr>` containing a `<th>` for each selected column name. It must also have a `<tbody>` with one `<tr>` for each result row, and each row must contain a `<td>` for each column value, in the same order as the selected columns. If there are no result rows, the `<tbody>` must be empty. The HTML document must be printed exactly once.

For example, if `config.json` contains:

{
  "database": "sales.db",
  "table": "orders",
  "columns": ["id", "customer", "total"],
  "filters": [
    {"column": "total", "operator": ">", "value": 100},
    {"column": "customer", "operator": "=", "value": "Alice"}
  ]
}

then running `python report.py config.json` should print an HTML table whose header cells are `id`, `customer`, and `total`, with one body row for each order in `sales.db` where `total > 100` and `customer = 'Alice'`.
