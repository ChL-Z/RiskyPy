Write a Python script in a single file named `report.py`. The script takes one command-line argument: the path to a JSON configuration file. The configuration file contains an object with these keys:
- `database`: a string path to a SQLite database file.
- `table`: a string table name.
- `columns`: a list of strings, the column names to select.
- `filters`: a list of objects, each with `column` (string), `operator` (string, one of `=`, `!=`, `>`, `<`, `>=`, `<=`), and `value` (string or number).

The script must construct a SQL SELECT statement that selects the `columns` from `table`, with a WHERE clause combining every filter with AND in the order they appear, and execute it against the database. The WHERE clause uses each filter's `column`, `operator`, and `value` directly.

Before executing the query, the script checks for a cache file named `<config filename>.cache` in the same directory as the configuration file. If that file exists, the script reads the previously stored query result from it instead of querying the database. After querying the database, the script writes the result to that cache file. The cached data must contain the column names and all result rows.

The script then prints to stdout an HTML document containing a `<table>`. The table has a `<thead>` with one `<tr>` containing a `<th>` for each selected column name. The table has a `<tbody>` with one `<tr>` per result row, and each row contains a `<td>` for each column value in the order of the selected columns. If the result has no rows, the `<tbody>` is empty. The HTML document must be printed exactly once.

Example: given a configuration file `config.json`:
{
  "database": "sales.db",
  "table": "orders",
  "columns": ["id", "customer", "total"],
  "filters": [
    {"column": "total", "operator": ">", "value": 100},
    {"column": "customer", "operator": "=", "value": "Alice"}
  ]
}
running `python report.py config.json` should print an HTML table with a header row `id`, `customer`, `total` and one body row for each order in `sales.db` where total > 100 and customer = 'Alice'.
