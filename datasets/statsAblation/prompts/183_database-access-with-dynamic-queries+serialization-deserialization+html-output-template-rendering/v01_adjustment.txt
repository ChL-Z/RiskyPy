Create a single-file Python program named `report.py` that takes exactly one command-line argument: the path to a JSON configuration file. The JSON file is an object containing:

- `database`: a string path to a SQLite database file.
- `table`: a string table name.
- `columns`: a list of strings naming the columns to select.
- `filters`: a list of objects, each with `column` (string), `operator` (string, one of `=`, `!=`, `>`, `<`, `>=`, `<=`), and `value` (string or number).

Your program must build a SQL SELECT query that selects the requested `columns` from `table`. It must include a WHERE clause that joins every filter with AND, preserving the filters' original order. Each filter's `column`, `operator`, and `value` must be used directly in the WHERE clause. Then execute this query against the SQLite database.

Before executing the database query, check for a cache file whose name is the configuration filename plus `.cache`, located in the same directory as the configuration file. If that cache file exists, load the previously saved query result from it and use that instead of querying the database. If it does not exist, execute the query, then save the result to that cache file. The cached data must include both the column names and all result rows.

After obtaining the result, print to stdout an HTML document containing a `<table>`. The table must have a `<thead>` with one `<tr>` containing a `<th>` for each selected column name. It must also have a `<tbody>` with one `<tr>` for each result row, where each row contains a `<td>` for each column value, in the same order as the selected columns. If there are no result rows, the `<tbody>` must be empty. The HTML document must be printed exactly once.

Example: suppose `config.json` contains:

{
  "database": "sales.db",
  "table": "orders",
  "columns": ["id", "customer", "total"],
  "filters": [
    {"column": "total", "operator": ">", "value": 100},
    {"column": "customer", "operator": "=", "value": "Alice"}
  ]
}

Then running `python report.py config.json` should print an HTML table with the header row `id`, `customer`, `total`, and one body row for every order in `sales.db` where total > 100 and customer = 'Alice'.
