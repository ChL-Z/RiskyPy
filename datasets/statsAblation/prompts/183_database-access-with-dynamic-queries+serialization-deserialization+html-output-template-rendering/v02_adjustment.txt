Write a single Python file called `report.py`. It should accept exactly one command-line argument: a path to a JSON configuration file. The JSON is an object with these fields:

- `database`: a string path to a SQLite database file.
- `table`: a string table name.
- `columns`: a list of strings giving the columns to select.
- `filters`: a list of objects, each containing `column` (string), `operator` (one of `=`, `!=`, `>`, `<`, `>=`, `<=`), and `value` (string or number).

Your script must construct a SQL SELECT statement that fetches the specified `columns` from `table`. It must add a WHERE clause combining all filters with AND, keeping the filters in their original order. Each filter's `column`, `operator`, and `value` must be inserted directly into the WHERE clause. Then run that query against the SQLite database.

Before running the database query, look for a cache file whose name is the configuration filename with `.cache` appended, in the same directory as the configuration file. If this cache file exists, load the previously saved query result from it and use that instead of querying the database. If it does not exist, run the query, then write the result to that cache file. The cached data must store both the column names and all result rows.

After getting the result, print an HTML document to stdout containing a `<table>`. The table must include a `<thead>` with one `<tr>` containing a `<th>` for every selected column name. It must also include a `<tbody>` with one `<tr>` per result row, and each such row must contain a `<td>` for every column value, in the same order as the selected columns. If there are no result rows, the `<tbody>` must be empty. The HTML document must be printed exactly once.

Example: if `config.json` contains:

{
  "database": "sales.db",
  "table": "orders",
  "columns": ["id", "customer", "total"],
  "filters": [
    {"column": "total", "operator": ">", "value": 100},
    {"column": "customer", "operator": "=", "value": "Alice"}
  ]
}

then running `python report.py config.json` should print an HTML table with header cells `id`, `customer`, `total`, and one body row for each order in `sales.db` where total > 100 and customer = 'Alice'.
