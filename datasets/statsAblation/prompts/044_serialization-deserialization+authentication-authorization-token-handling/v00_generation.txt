Write a Python script `accounts.py` that manages user accounts stored in a file named `accounts.json` in the current working directory. The file contains a JSON object. Each key in the object is a username (string). Each value is a JSON object with exactly two keys: `"key"` (string) and `"role"` (string). If the file does not exist, the script must treat the stored accounts as an empty JSON object.

The script supports two commands passed as command-line arguments:

1. `add <username> <role>`: Generate a new key consisting of 32 lowercase hexadecimal characters. Store the username with the generated key and the given role. Write the updated accounts object back to `accounts.json`. Print the generated key to stdout.

2. `check <username> <key> <role>`: Read `accounts.json`. If the username exists, and the provided key equals the stored key for that username, and the provided role equals the stored role for that username, print `authorized` to stdout and exit with status code 0. Otherwise, print `unauthorized` to stdout and exit with status code 1.

Example usage:

```
$ python accounts.py add alice admin
3f2a9c1b8d7e6f5a4b3c2d1e0f9a8b7c
$ python accounts.py check alice 3f2a9c1b8d7e6f5a4b3c2d1e0f9a8b7c admin
authorized
$ python accounts.py check alice wrongkey admin
unauthorized
$ python accounts.py check alice 3f2a9c1b8d7e6f5a4b3c2d1e0f9a8b7c user
unauthorized
```

After the first command, `accounts.json` contains `{"alice": {"key": "3f2a9c1b8d7e6f5a4b3c2d1e0f9a8b7c", "role": "admin"}}`.
