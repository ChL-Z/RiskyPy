Create a Python program named `accounts.py` that maintains user accounts in a JSON file called `accounts.json`, located in the current working directory. The JSON file stores a single object. Every property name in that object is a username string. Every corresponding value is another JSON object containing exactly two string properties: `"key"` and `"role"`. If `accounts.json` is missing, the program should behave as though the account data is an empty JSON object.\n\nThe program must accept two possible command-line commands:\n\n1. `add <username> <role>`: Create a fresh key made of 32 lowercase hexadecimal characters. Save the username with that key and the supplied role. Then write the full updated accounts object back to `accounts.json`. Output the newly created key to stdout.\n\n2. `check <username> <key> <role>`: Load `accounts.json`. If the username is present, the supplied key matches the key saved for that username, and the supplied role matches the role saved for that username, print `authorized` to stdout and terminate with exit status 0. In every other case, print `unauthorized` to stdout and terminate with exit status 1.\n\nExample behavior:\n\n```\n$ python accounts.py add alice admin\n3f2a9c1b8d7e6f5a4b3c2d1e0f9a8b7c\n$ python accounts.py check alice 3f2a9c1b8d7e6f5a4b3c2d1e0f9a8b7c admin\nauthorized\n$ python accounts.py check alice wrongkey admin\nunauthorized\n$ python accounts.py check alice 3f2a9c1b8d7e6f5a4b3c2d1e0f9a8b7c user\nunauthorized\n```\n\nAfter the first command runs, `accounts.json` should contain `{"alice": {"key": "3f2a9c1b8d7e6f5a4b3c2d1e0f9a8b7c", "role": "admin"}}`.
