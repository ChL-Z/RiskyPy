Create a standalone Python script named `calc_recipe.py`. When run, it must take a recipe file path from `sys.argv[1]` and process the recipe definitions stored in that file.

Line handling rules:
- Skip blank lines.
- Skip any line whose first non-whitespace character is `#`.
- Every other line is expected to be a definition written as `name = expression`.
- A valid `name` may contain only lowercase ASCII letters and underscores.
- An `expression` may use non-negative integer constants, parentheses, the operators `+`, `-`, and `*`, and names that have already been defined earlier in the same file.
- Definitions must be evaluated in the exact order they appear.

For every definition that is successfully evaluated:
- Print `name=value` to stdout.
- Print exactly one line to stderr in this format:
  `YYYY-MM-DDTHH:MM:SSZ INFO computed name=value`
  using the current UTC time for the timestamp.

If evaluation fails because the expression uses a name that has not been defined earlier:
- Stop immediately.
- Print exactly this line to stderr:
  `YYYY-MM-DDTHH:MM:SSZ ERROR line N: unknown name 'missing'`
  where `N` is the 1-based line number and `missing` is the undefined name.
- Exit with status 1.

If a non-skipped line does not follow the required grammar:
- Stop immediately.
- Print exactly this line to stderr:
  `YYYY-MM-DDTHH:MM:SSZ ERROR line N: invalid expression`
  where `N` is the 1-based line number.
- Exit with status 1.
- Only the first such failure should be reported.

If every definition is processed successfully, exit with status 0.

Example recipe file `recipe.txt`:

```
# dimensions
width = 4
height = 3
area = width * height
perimeter = 2 * (width + height)
```

Running `python calc_recipe.py recipe.txt` should print this to stdout:

```
width=4
height=3
area=12
perimeter=14
```

It should also write four INFO lines to stderr, each with a matching UTC timestamp.
