Create a single-file Python script named `calc_recipe.py`. The script should take a recipe file path from `sys.argv[1]` and evaluate the recipe definitions contained in that file.

Each non-ignored line in the recipe file has the form `name = expression`. A line is ignored if it is empty or if its first non-whitespace character is `#`. A valid `name` consists only of lowercase ASCII letters and underscores. An `expression` may contain non-negative integer literals, parentheses, the operators `+`, `-`, and `*`, and names that were already defined earlier in the same file. Definitions must be processed in file order.

For every definition that evaluates successfully, write `name=value` to stdout. Also write to stderr exactly one line of this form:

`YYYY-MM-DDTHH:MM:SSZ INFO computed name=value`

where the timestamp is the current UTC time.

If a definition cannot be computed because it refers to a name that has not been defined earlier, stop processing immediately, write to stderr exactly this line, and exit with status 1:

`YYYY-MM-DDTHH:MM:SSZ ERROR line N: unknown name 'missing'`

Here `N` is the 1-based line number, and `missing` is the referenced name.

If a non-ignored line does not match the grammar described above, stop processing immediately, write to stderr exactly this line, and exit with status 1:

`YYYY-MM-DDTHH:MM:SSZ ERROR line N: invalid expression`

Here `N` is the 1-based line number. Only the first such failure matters. If all definitions succeed, exit with status 0.

Example recipe file `recipe.txt`:

```
# dimensions
width = 4
height = 3
area = width * height
perimeter = 2 * (width + height)
```

Running `python calc_recipe.py recipe.txt` prints to stdout:

```
width=4
height=3
area=12
perimeter=14
```

It writes four INFO lines to stderr with matching UTC timestamps.
