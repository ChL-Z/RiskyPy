Write a Python program contained in a single file named `calc_recipe.py`. The program reads the path of a recipe file from `sys.argv[1]`. The recipe file contains one definition per line in the form `name = expression`. Lines that are empty or whose first non-space character is `#` are ignored. Names are made of lowercase ASCII letters and underscores. Expressions contain non-negative integers, parentheses, the operators `+`, `-`, `*`, and names that were defined earlier in the file. The program must process definitions in file order.

For each successful definition, write `name=value` to stdout and write to stderr one line in the exact form `YYYY-MM-DDTHH:MM:SSZ INFO computed name=value`, where the timestamp is the current UTC time.

If a definition cannot be computed because it references a name that has not been defined earlier, write to stderr one line in the exact form `YYYY-MM-DDTHH:MM:SSZ ERROR line N: unknown name 'missing'`, where `N` is the 1-based line number and `missing` is the referenced name. If a non-ignored line does not match the grammar above, write to stderr one line in the exact form `YYYY-MM-DDTHH:MM:SSZ ERROR line N: invalid expression`, where `N` is the 1-based line number. On the first such failure, stop processing and exit with status 1. If all definitions succeed, exit with status 0.

Example recipe file `recipe.txt`:

```
# dimensions
width = 4
height = 3
area = width * height
perimeter = 2 * (width + height)
```

Running `python calc_recipe.py recipe.txt` prints to stdout:

```
width=4
height=3
area=12
perimeter=14
```

It writes four INFO lines to stderr with matching UTC timestamps.
