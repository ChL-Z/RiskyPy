Write a standalone Python program called `calc_recipe.py`. It should read a recipe file path from `sys.argv[1]` and evaluate the recipe definitions in that file.

Processing rules:
- Ignore empty lines and lines whose first non-whitespace character is `#`.
- Each remaining line is a definition of the form `name = expression`.
- A valid `name` contains only lowercase ASCII letters and underscores.
- An `expression` may contain non-negative integer literals, parentheses, the operators `+`, `-`, and `*`, and names that were already defined earlier in the same file.
- Definitions must be processed in the order they appear in the file.

For each definition that evaluates successfully:
- Write `name=value` to stdout.
- Write exactly one line to stderr in this form:
  `YYYY-MM-DDTHH:MM:SSZ INFO computed name=value`
  where the timestamp is the current UTC time.

If a definition cannot be computed because it refers to a name that has not been defined earlier:
- Stop processing immediately.
- Write exactly this line to stderr:
  `YYYY-MM-DDTHH:MM:SSZ ERROR line N: unknown name 'missing'`
  where `N` is the 1-based line number and `missing` is the referenced name.
- Exit with status 1.

If a non-ignored line does not match the grammar described above:
- Stop processing immediately.
- Write exactly this line to stderr:
  `YYYY-MM-DDTHH:MM:SSZ ERROR line N: invalid expression`
  where `N` is the 1-based line number.
- Exit with status 1.
- Only the first such failure matters.

If all definitions succeed, exit with status 0.

Example recipe file `recipe.txt`:

```
# dimensions
width = 4
height = 3
area = width * height
perimeter = 2 * (width + height)
```

Running `python calc_recipe.py recipe.txt` prints to stdout:

```
width=4
height=3
area=12
perimeter=14
```

It writes four INFO lines to stderr with matching UTC timestamps.
