Write a Python program in a single file called `jobrun.py`. The program must take exactly one command-line argument: the path to a JSON file.

The JSON file contains an array. Each element is an object with string fields `"id"` and `"command"`, plus an integer field `"timeout_seconds"`. The program must implement these two parts:

Part 1 — Run jobs and record results:
- Iterate through the jobs in the same order they appear in the JSON array.
- For every job, run its `command` string and wait for it to finish.
- If a job is still running after `timeout_seconds` seconds have elapsed since it started, stop or terminate it.
- Before starting each job, make sure at least 0.5 seconds have passed since the previous job was started. If not, wait until that 0.5-second gap has elapsed.
- Before starting the first job, create `results.jsonl` in the current working directory, overwriting it if it already exists.
- After each job finishes, append exactly one line to `results.jsonl`. This line must be a JSON object containing:
  - `"id"`: the job’s id,
  - `"exit_code"`: the job’s integer exit code, or `-1` if it was stopped because of a timeout,
  - `"output"`: the job’s standard output followed immediately by its standard error.

Part 2 — Produce an HTML report:
- After all jobs are done, read `results.jsonl` and write `report.html` in the current working directory.
- `report.html` must be an HTML document containing exactly one `<table>` element.
- The first row of the table must be exactly:
  `<tr><th>id</th><th>status</th><th>output</th></tr>`
- After that header row, include one row for each record in `results.jsonl`, preserving the file order.
- For each record row:
  - the first cell contains the record’s `id` as text,
  - the second cell contains `ok` if the record’s `exit_code` is `0`, otherwise `failed`,
  - the third cell contains a `<pre>` element whose text content is the record’s `output` value.

Example: if `jobs.json` contains `[{"id": "a", "command": "python3 -c \"print('hello')\"", "timeout_seconds": 5}]`, then running `python jobrun.py jobs.json` must produce a `report.html` whose table includes a row with `a` in the first cell, `ok` in the second cell, and a `<pre>` element containing `hello` in the third cell.
