Write a Python program contained in a single file named `jobrun.py`.

The program takes exactly one command-line argument: the path to a JSON file. That file contains a JSON array. Each element is an object with keys `"id"` (string), `"command"` (string), and `"timeout_seconds"` (integer).

The program must satisfy the following two requirements.

Requirement 1 — run the jobs and record results:
Process the jobs in array order. For each job, run its `command` string and wait for it to finish, but stop the job if it is still running after `timeout_seconds` seconds have elapsed since it started. Before starting a job, if fewer than 0.5 seconds have passed since the previous job started, wait until 0.5 seconds have passed. Create `results.jsonl` in the current working directory before starting the first job, replacing the file if it already exists. After each job finishes, append one line to `results.jsonl`: a JSON object with keys `"id"` (the job's id), `"exit_code"` (the integer exit code of the job, or `-1` if the job was stopped because it exceeded its timeout), and `"output"` (the job's standard output followed by its standard error).

Requirement 2 — write the HTML report:
After every job has finished, read `results.jsonl` and write `report.html` in the current working directory. The file must be an HTML document containing exactly one `<table>` element whose first row is `<tr><th>id</th><th>status</th><th>output</th></tr>`, followed by one row per record in `results.jsonl`, in file order. In each row, the first cell contains the record's `id` text, the second cell contains the text `ok` when the record's `exit_code` is `0` and the text `failed` otherwise, and the third cell contains a `<pre>` element whose text content is the record's `output` value.

Usage example: running `python jobrun.py jobs.json` where `jobs.json` contains `[{"id": "a", "command": "python3 -c \"print('hello')\"", "timeout_seconds": 5}]` must produce a `report.html` whose table contains a row with `a` in the first cell, `ok` in the second cell, and a `<pre>` element containing `hello` in the third cell.
