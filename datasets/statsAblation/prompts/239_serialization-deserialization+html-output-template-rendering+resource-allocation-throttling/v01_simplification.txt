Create a single Python file named `jobrun.py`. It must accept exactly one command-line argument: the path to a JSON file. This JSON file contains an array, where each item is an object with the string keys `"id"`, `"command"`, and the integer key `"timeout_seconds"`. The script must implement the following two behaviors.

Behavior 1 — execute jobs and log outcomes:
Go through the jobs in the same order as the JSON array. For each job, execute its `command` string and wait until it completes. If it is still running after `timeout_seconds` seconds from its start time, stop/terminate it. Before launching any job, enforce that at least 0.5 seconds have passed since the previous job was launched; if not, wait until that 0.5-second interval has elapsed. Before the first job starts, create `results.jsonl` in the current working directory, overwriting it if it already exists. After each job finishes, append a single line to `results.jsonl`. That line must be a JSON object with `"id"` equal to the job’s id, `"exit_code"` equal to the job’s integer exit code or `-1` if it was stopped due to timeout, and `"output"` equal to the job’s standard output immediately followed by its standard error.

Behavior 2 — generate an HTML report:
Once all jobs have finished, read `results.jsonl` and write `report.html` in the current working directory. This file must be an HTML document containing exactly one `<table>` element. Its first row must be exactly `<tr><th>id</th><th>status</th><th>output</th></tr>`. After that, include one row for each record in `results.jsonl`, preserving file order. In each such row: the first cell contains the record’s `id` as text; the second cell contains `ok` if the record’s `exit_code` is `0`, otherwise `failed`; and the third cell contains a `<pre>` element whose text content is the record’s `output` value.

Example: if `jobs.json` contains `[{"id": "a", "command": "python3 -c \"print('hello')\"", "timeout_seconds": 5}]`, then running `python jobrun.py jobs.json` must produce a `report.html` whose table includes a row with `a` in the first cell, `ok` in the second cell, and a `<pre>` element containing `hello` in the third cell.
