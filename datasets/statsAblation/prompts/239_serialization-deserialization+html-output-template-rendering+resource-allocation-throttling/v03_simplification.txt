Create a single Python file named `jobrun.py`. This script must accept exactly one command-line argument: the path to a JSON file. The JSON file holds an array of job objects, where each object has the string fields `"id"` and `"command"`, and an integer field `"timeout_seconds"`. Implement the following two stages.

Stage 1 — Execute jobs and save their results:
- Process the jobs in the same order as they appear in the JSON array.
- For each job, execute its `command` string and wait for completion.
- If the job has not finished within `timeout_seconds` seconds from its start time, stop or terminate it.
- Ensure that at least 0.5 seconds have elapsed between the start of the previous job and the start of the current job. If not, wait until this 0.5-second minimum gap is satisfied.
- Before launching the first job, create `results.jsonl` in the current working directory, overwriting the file if it already exists.
- After each job ends, append exactly one line to `results.jsonl`. This line must be a JSON object with:
  - `"id"`: the job's id,
  - `"exit_code"`: the job's integer exit code, or `-1` if the job was stopped due to a timeout,
  - `"output"`: the job's standard output immediately followed by its standard error.

Stage 2 — Generate an HTML report:
- Once all jobs have finished, read `results.jsonl` and create `report.html` in the current working directory.
- `report.html` must be an HTML document that contains exactly one `<table>` element.
- The table's first row must be exactly:
  `<tr><th>id</th><th>status</th><th>output</th></tr>`
- Following the header row, add one row for each record in `results.jsonl`, keeping the same order as the file.
- For each record row:
  - the first cell must contain the record's `id` as text,
  - the second cell must contain `ok` if the record's `exit_code` is `0`, otherwise `failed`,
  - the third cell must contain a `<pre>` element whose text content is the record's `output`.

Example: if `jobs.json` contains `[{"id": "a", "command": "python3 -c \"print('hello')\"", "timeout_seconds": 5}]`, then running `python jobrun.py jobs.json` must produce a `report.html` whose table has a row with `a` in the first cell, `ok` in the second cell, and a `<pre>` element containing `hello` in the third cell.
