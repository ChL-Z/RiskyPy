Write a Python program contained in a single file named `fill_tokens.py`. The program takes exactly one argument: the path to an XML configuration file. The file has a root element `<config>` and zero or more `<user>` child elements. Each `<user>` has an `id` attribute. A `<user>` may contain a `<token>` child element. The program prints a new XML document to stdout. In the output, there is exactly one `<user>` element for each input `<user>`, in the same order, with the same `id` attribute value. If an input `<user>` had a `<token>` child, the output `<user>` must contain that same `<token>` text, unchanged. If an input `<user>` had no `<token>` child, the output `<user>` must contain a new `<token>` child whose text is a token. A token is 32 bytes from a random source, encoded as URL-safe base64 with no `=` padding. The output must begin with `<?xml version="1.0" encoding="UTF-8"?>` followed by a newline, and must end with a newline. The original file must not be modified.

Example: for `config.xml` containing:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<config>
  <user id="alice"/>
  <user id="bob"><token>keep-this</token></user>
</config>
```

running `python fill_tokens.py config.xml` prints an XML document where the `alice` user has a 43-character token from the URL-safe base64 alphabet (`A-Z`, `a-z`, `0-9`, `-`, `_`) and the `bob` user still has text `keep-this`. The exact whitespace and indentation of the output do not need to match the input.
