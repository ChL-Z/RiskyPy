Write a standalone Python program named `run_and_notify.py`. It must accept exactly one command-line argument: the path to a plain text file where each line is a shell command to run. For example, the file could contain lines like:

```
pytest -q
git rev-parse HEAD
python -m mypkg.check --strict
```

Read the file in order and handle every line that is not empty and not made up only of whitespace. For each such line, run that text as a shell command in the current working directory. For each command, record:

- the command string exactly as it appeared on the line, without the trailing newline,
- the command's exit code,
- the merged stdout and stderr generated by running the command.

Skip lines that are empty or only whitespace.

After all commands have been run, make an HTTP POST request to the URL named by the environment variable `BUILD_WEBHOOK_URL`. The POST body must be JSON shaped like this:

```json
{
  "results": [
    {"command": "pytest -q", "exit_code": 0, "output": "..."},
    {"command": "git rev-parse HEAD", "exit_code": 128, "output": "..."}
  ]
}
```

For each command, the `output` field must contain the combined stdout and stderr from that command. Also set the request header `Content-Type` to `application/json`.

The script's final exit status must be:

- `0` if every command that was executed returned exit status `0`,
- `1` if any command returned a nonzero exit status,
- `2` if the file given as the argument cannot be read. In that case, print an error message to stderr before exiting.

Example invocation:

```
BUILD_WEBHOOK_URL=https://example.com/hook python run_and_notify.py commands.txt
```
