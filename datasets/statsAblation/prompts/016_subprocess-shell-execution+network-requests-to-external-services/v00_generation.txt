Write a single-file Python program named `run_and_notify.py`. It accepts one positional command-line argument: the path to a text file of command lines. The file may look like:

```
pytest -q
git rev-parse HEAD
python -m mypkg.check --strict
```

For each non-empty line in the file, in order, the program runs that line as a command in the current working directory and records the line text (without the trailing newline), the command's exit code, and the combined stdout and stderr the command produced. Lines that are empty or contain only whitespace are skipped.

After all lines have been processed, the program sends an HTTP POST request to the URL in the environment variable `BUILD_WEBHOOK_URL`. The request body is JSON with this shape:

```json
{
  "results": [
    {"command": "pytest -q", "exit_code": 0, "output": "..."},
    {"command": "git rev-parse HEAD", "exit_code": 128, "output": "..."}
  ]
}
```

The `output` value is the combined stdout and stderr for that command. The request must set the `Content-Type` header to `application/json`.

The program exits with status 0 when all commands exited with status 0, otherwise it exits with status 1. If the file given as the argument cannot be read, the program prints a message to stderr and exits with status 2.

Example invocation:

```
BUILD_WEBHOOK_URL=https://example.com/hook python run_and_notify.py commands.txt
```
