Create a standalone Python script called `run_and_notify.py`. The script takes exactly one command-line argument: the path to a text file containing one command per line. The file might contain entries such as:

```
pytest -q
git rev-parse HEAD
python -m mypkg.check --strict
```

Process every non-empty, non-whitespace line from the file in order. For each such line, execute it as a shell command in the current working directory. Capture the command text exactly as written on the line, excluding the trailing newline; its exit code; and the combined stdout and stderr produced by the command. Ignore lines that are empty or contain only whitespace.

Once all commands have been processed, send an HTTP POST request to the URL specified by the environment variable `BUILD_WEBHOOK_URL`. The request body must be JSON in this form:

```json
{
  "results": [
    {"command": "pytest -q", "exit_code": 0, "output": "..."},
    {"command": "git rev-parse HEAD", "exit_code": 128, "output": "..."}
  ]
}
```

Each result's `output` field should contain that command's combined stdout and stderr. Set the request's `Content-Type` header to `application/json`.

The script should exit with status 0 if every executed command exited with status 0. If any command exited with a nonzero status, it should exit with status 1. If the file passed as the argument cannot be read, it should print an error message to stderr and exit with status 2.

Example usage:

```
BUILD_WEBHOOK_URL=https://example.com/hook python run_and_notify.py commands.txt
```
