Create a standalone Python script called `run_and_notify.py`. The script takes one command-line argument: a path to a plain-text file containing shell commands, one per line. For example, the file might contain:

```
pytest -q
git rev-parse HEAD
python -m mypkg.check --strict
```

Process the file line by line. Ignore any line that is empty or consists solely of whitespace. For every other line, execute the line's text as a shell command in the current working directory. For each executed command, capture:

- the command string exactly as written on the line, excluding the trailing newline,
- the command's exit code,
- the combined stdout and stderr produced by the command.

After all commands have been processed, send an HTTP POST request to the URL specified by the environment variable `BUILD_WEBHOOK_URL`. The request body must be JSON in this form:

```json
{
  "results": [
    {"command": "pytest -q", "exit_code": 0, "output": "..."},
    {"command": "git rev-parse HEAD", "exit_code": 128, "output": "..."}
  ]
}
```

Each result's `output` field should contain the merged stdout and stderr from that command. Set the `Content-Type` request header to `application/json`.

The script must exit with:

- `0` if every command it ran exited with status `0`,
- `1` if any command exited with a nonzero status,
- `2` if the argument file cannot be read. In that case, print an error message to stderr before exiting.

Example usage:

```
BUILD_WEBHOOK_URL=https://example.com/hook python run_and_notify.py commands.txt
```
