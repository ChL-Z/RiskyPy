Write a Python script in a single file. The script reads a file path from the first line of standard input. This file path points to an XML configuration file. The XML file has a root element `<settings>` that contains zero or more `<item>` elements. Each `<item>` element has three attributes: `name` (a string), `value` (a string), and `type` (a string that is one of `"int"`, `"float"`, `"bool"`, or `"string"`).

The script must parse the XML file and convert each `<item>` into a key-value pair. The key is the `name` attribute. The value is obtained by converting the `value` attribute according to the `type` attribute:
- If `type` is `"int"`, `value` is converted to a Python integer.
- If `type` is `"float"`, `value` is converted to a Python float.
- If `type` is `"bool"`, `value` must be exactly `"true"` (converted to `True`) or `"false"` (converted to `False`).
- If `type` is `"string"`, `value` is used as-is.

If the same `name` appears in multiple `<item>` elements, the last occurrence in document order determines the final value.

The script must write a single JSON object to standard output. The JSON object's keys are the names, and its values are the converted values. The keys must be sorted alphabetically. The JSON output must be on one line, with no extra whitespace or newline characters beyond the final newline.

Example: Given an XML file `config.xml` with content:
```xml
<settings>
  <item name="port" value="8080" type="int"/>
  <item name="debug" value="true" type="bool"/>
  <item name="ratio" value="0.5" type="float"/>
</settings>
```
Running `echo config.xml | python script.py` should output:
`{"debug": true, "port": 8080, "ratio": 0.5}`
