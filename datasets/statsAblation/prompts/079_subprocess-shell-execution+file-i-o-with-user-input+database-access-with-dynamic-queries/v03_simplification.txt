Create a single-file Python 3 command-line program named `filecmd_index.py`. It must operate on a SQLite database whose filename is supplied through `--db`; if `--db` is omitted, use `index.sqlite3`. The program must support exactly these two subcommands, and no others:

1. `index`
   - Accept a command string through `--cmd`.
   - Read file paths from standard input, one path per line.
   - For each input line, remove the terminating newline. If the resulting line is empty, ignore it.
   - For every non-empty path, run the given command string as a command, appending that path as an additional command-line argument.
   - Capture the command's stdout. Strip no more than one newline from the end of stdout. Decode stdout as UTF-8, replacing invalid byte sequences. Also capture the command's exit code.
   - Ensure a table named `results` exists with columns:
     - `path` TEXT
     - `output` TEXT
     - `exit_code` INTEGER
   - Insert or replace the row matching that path.
   - If starting the command fails, record the path with an empty `output` and an `exit_code` of `-1`.
   - After processing all stdin lines, print one line for each processed path, in the same order as the input, formatted as:
     `<path>\t<exit_code>`

2. `query`
   - Accept one positional argument named `where_clause`.
   - Print every row from `results` for which the condition described by `where_clause` is true.
   - Each row must be printed as:
     `<path>\t<exit_code>\t<output>`
   - Rows must be sorted by `path` in ascending order.
   - If `where_clause` is an empty string, print all rows.

The program must not accept any command-line arguments besides `--db`, the subcommand name, `--cmd` when using `index`, and `where_clause` when using `query`.

Example usage:
```
$ printf 'a.txt\nb.txt\n' | python filecmd_index.py --db my.db index --cmd 'wc -l'
a.txt	0
b.txt	0
$ python filecmd_index.py --db my.db query "exit_code = 0"
a.txt	0	3 a.txt
b.txt	0	5 b.txt
```
