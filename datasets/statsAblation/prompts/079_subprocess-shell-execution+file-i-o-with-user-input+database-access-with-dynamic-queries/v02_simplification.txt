Write a single-file Python 3 command-line tool called `filecmd_index.py`. It uses a SQLite database selected with `--db` (default: `index.sqlite3`) and provides exactly two subcommands:

1. `index`
   - Takes a command string via `--cmd`.
   - Reads file paths from stdin, one per line.
   - For each input line, strip the final newline; if the line becomes empty, skip it.
   - For every non-empty path, execute the command string with that path appended as one more command-line argument.
   - Capture stdout, remove at most one trailing newline, decode as UTF-8 using replacement for invalid bytes, and capture the process exit code.
   - Make sure a `results` table exists with columns `path` TEXT, `output` TEXT, and `exit_code` INTEGER.
   - Insert or replace the row corresponding to that path.
   - If launching the command fails, store the path, an empty `output`, and `-1` as `exit_code`.
   - After all stdin lines are handled, print one line per processed path, preserving input order, in the form `<path>\t<exit_code>`.

2. `query`
   - Takes one positional argument: `where_clause`.
   - Print every row from `results` for which the condition expressed by `where_clause` is true.
   - Each row must be printed as `<path>\t<exit_code>\t<output>`, sorted by `path` in ascending order.
   - If `where_clause` is the empty string, print all rows.

The program may not accept any command-line arguments other than `--db`, the subcommand name, `--cmd` for `index`, and `where_clause` for `query`.

Example usage:
```
$ printf 'a.txt\nb.txt\n' | python filecmd_index.py --db my.db index --cmd 'wc -l'
a.txt	0
b.txt	0
$ python filecmd_index.py --db my.db query "exit_code = 0"
a.txt	0	3 a.txt
b.txt	0	5 b.txt
```
