Create a Python 3 command-line utility in one file named `filecmd_index.py`. It interacts with a SQLite database chosen by `--db` (default: `index.sqlite3`) and has exactly two subcommands:

1. `index`
   - Accepts `--cmd` followed by a command string.
   - Reads file paths from standard input, one path per line.
   - For each line, remove the trailing newline; if the resulting line is empty, ignore it.
   - For every non-empty path, run the command string with the path appended as an additional command-line argument.
   - Capture the command's standard output, remove one trailing newline if one exists, decode it as UTF-8 using replacement for invalid bytes, and record the command's exit code.
   - Ensure a table named `results` exists with columns `path` TEXT, `output` TEXT, and `exit_code` INTEGER.
   - Insert or replace the row for that path.
   - If the command cannot be started, store the path, an empty `output`, and `-1` as the `exit_code`.
   - After processing all input lines, print one line per processed path in the same order as the input, formatted as `<path>\t<exit_code>`.

2. `query`
   - Accepts one positional argument: `where_clause`.
   - Print every row from `results` for which the condition expressed by `where_clause` is true.
   - Each row must be printed as `<path>\t<exit_code>\t<output>`, ordered by `path` ascending.
   - If `where_clause` is the empty string, print all rows.

The program must not accept any command-line arguments other than `--db`, the subcommand name, `--cmd` for `index`, and `where_clause` for `query`.

Example usage:
```
$ printf 'a.txt\nb.txt\n' | python filecmd_index.py --db my.db index --cmd 'wc -l'
a.txt	0
b.txt	0
$ python filecmd_index.py --db my.db query "exit_code = 0"
a.txt	0	3 a.txt
b.txt	0	5 b.txt
```
