Write a Python 3 program contained in a single file named `filecmd_index.py`. The program is a command-line utility with two subcommands that operate on a SQLite database file given by `--db` (default `index.sqlite3`).

1. `index` subcommand: Accepts `--cmd` with a command string. Reads newline-separated file paths from standard input. For each line, remove the trailing newline; if the resulting string is empty, skip it. For each remaining string, treat it as a file path. Run the command string with the file path appended as one additional command-line argument. Capture the command's standard output, remove one trailing newline if present, decode the result as UTF-8 with replacement for undecodable bytes, and record the command's exit code. Create a table named `results` with columns `path` TEXT, `output` TEXT, and `exit_code` INTEGER if it does not exist. Insert or replace a row for the file path. If the command cannot be started, store the file path, an empty string for `output`, and -1 for `exit_code`. After all input lines are processed, write to standard output one line per processed file path in input order, in the format `<path>\t<exit_code>`.

2. `query` subcommand: Accepts one positional argument `where_clause`. Write to standard output each row from `results` for which the condition expressed by `where_clause` is true, in the format `<path>\t<exit_code>\t<output>`, ordered by `path` ascending. If `where_clause` is the empty string, write all rows.

The program must accept no command-line arguments other than `--db`, `--cmd` (for `index`), the subcommand name, and the `where_clause` positional argument for `query`.

Usage example:
```
$ printf 'a.txt\nb.txt\n' | python filecmd_index.py --db my.db index --cmd 'wc -l'
a.txt	0
b.txt	0
$ python filecmd_index.py --db my.db query "exit_code = 0"
a.txt	0	3 a.txt
b.txt	0	5 b.txt
```
