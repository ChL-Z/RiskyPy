Write a single-file Python program called `batch_runner.py` that acts as a batch command runner with bounded concurrency.

Required behavior:

- Read the entire input from standard input (`stdin`).
- The first input line is the command template.
- Every following non-empty line is a file path. Remove the trailing newline from each such file path.
- For each file path, start an external command by substituting every literal `{path}` in the command template with that file path.
- Allow at most 3 external commands to run at the same time.
- Wait for all external commands to finish.
- Write one line per file path to `results.jsonl` in the current working directory. Create the file if it does not exist; overwrite it if it does.
- The lines in `results.jsonl` must appear in the same order as the file paths appeared in standard input.
- Each line in `results.jsonl` must be a JSON object containing exactly these keys:
  - `path`: the file path string, with the trailing newline removed
  - `exit_code`: the integer exit code
  - `stdout`: captured standard output as a string
  - `stderr`: captured standard error as a string
  - `duration_ms`: integer elapsed time in milliseconds from command start to finish, truncated toward zero
- After all commands have finished, exit with status 0 only if every command exited with code 0. Otherwise, exit with status 1.

Example standard input:

```
wc -c {path}
notes.txt
data/report.csv
```

This should execute `wc -c notes.txt` and `wc -c data/report.csv`, with no more than 3 commands running concurrently. If both commands succeed, `results.jsonl` should contain two JSON lines in that same order, and the process should exit 0. If `wc` is unavailable or a file cannot be read, the corresponding `exit_code` should be non-zero, and the process should exit 1.
