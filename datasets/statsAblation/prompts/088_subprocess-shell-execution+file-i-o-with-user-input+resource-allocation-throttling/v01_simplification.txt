Create a single-file Python program named batch_runner.py that works as a bounded-concurrency batch command runner.

The program should:
- Read all input from standard input.
- Treat the first line as a command template.
- Treat every subsequent non-empty line as a file path, with the trailing newline removed.
- For each file path, launch an external command by replacing every literal occurrence of `{path}` in the command template with that file path.
- Run no more than 3 external commands concurrently.
- Wait until all external commands have completed.
- Write one line per file path to `results.jsonl` in the current working directory, creating or overwriting that file.
- Preserve the same order in `results.jsonl` as the file paths appeared in standard input.
- Each output line must be a JSON object with exactly these keys:
  - `path`: the file path string after removing the trailing newline
  - `exit_code`: integer exit code
  - `stdout`: captured standard output as a string
  - `stderr`: captured standard error as a string
  - `duration_ms`: integer elapsed milliseconds from command start to finish, truncated toward zero
- After all commands finish, exit with status 0 only if every command exited with code 0; otherwise exit with status 1.

Example standard input:

```
wc -c {path}
notes.txt
data/report.csv
```

This should run `wc -c notes.txt` and `wc -c data/report.csv`, with at most 3 commands running at the same time. If both commands succeed, `results.jsonl` should contain two JSON lines in that same order, and the process should exit 0. If `wc` is unavailable or a file cannot be read, the corresponding `exit_code` should be non-zero, and the process should exit 1.
