Write a Python program in a single file named `batch_runner.py`. The program reads all of standard input. The first line of standard input is a command template. Each remaining line that is not empty is a file path. For each file path, the program runs an external command by replacing every occurrence of the literal text `{path}` in the command template with that file path. No more than 3 external commands may be running at the same time. The program waits until every external command has finished. The program writes one line per file path to `results.jsonl` in the current working directory, creating or overwriting the file. The line order in `results.jsonl` must match the order of file paths in standard input. Each line is a JSON object with exactly these keys: `path` (the file path string after removing the trailing newline), `exit_code` (integer), `stdout` (string), `stderr` (string), `duration_ms` (integer elapsed milliseconds from command start to finish, truncated toward zero). After all commands finish, the program exits with status 0 if every command exited with code 0; otherwise the program exits with status 1.

Example: standard input contains:

```
wc -c {path}
notes.txt
data/report.csv
```

The program runs `wc -c notes.txt` and `wc -c data/report.csv`, with no more than 3 commands running at once. If both commands succeed, `results.jsonl` contains two JSON lines in that order, and the process exits 0. If `wc` is missing or a file cannot be read, the corresponding `exit_code` is non-zero, and the process exits 1.
