Create a single Python script named `batch_runner.py` that runs a batch of external commands with limited concurrency.

Specification:

- Read all of standard input (`stdin`).
- The first line is the command template.
- Each later non-empty line is a file path. Strip only the trailing newline from each such file path.
- For every file path, launch an external command by replacing every literal `{path}` occurrence in the command template with that file path.
- Never allow more than 3 external commands to be running simultaneously.
- Wait for all launched external commands to complete.
- Write `results.jsonl` in the current working directory. If it does not exist, create it; if it exists, overwrite it.
- `results.jsonl` must contain one line per file path, in the same order as the file paths appeared in the input.
- Each JSONL line must be a JSON object containing exactly these keys:
  - `path`: the file path string, without the trailing newline
  - `exit_code`: the integer exit code
  - `stdout`: captured standard output as a string
  - `stderr`: captured standard error as a string
  - `duration_ms`: integer elapsed time in milliseconds from command start to command finish, truncated toward zero
- After everything finishes, the program should exit with status 0 only if every external command exited with code 0. Otherwise, it should exit with status 1.

Example stdin:

```
wc -c {path}
notes.txt
data/report.csv
```

This should run `wc -c notes.txt` and `wc -c data/report.csv`, while keeping at most 3 commands running at once. If both succeed, `results.jsonl` should contain two JSON lines in that same order, and the process should exit 0. If `wc` is missing or a file cannot be read, the matching `exit_code` should be non-zero, and the process should exit 1.
