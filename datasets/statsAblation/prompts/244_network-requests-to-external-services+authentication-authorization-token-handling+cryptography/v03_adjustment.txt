Create a standalone Python script called `fetch_reports.py`. It should read a single JSON object from stdin. This object contains string fields `client_id`, `client_secret`, `auth_url`, and `api_base`, and a list of strings named `report_ids`.

Token acquisition and caching:
- Request an access token by HTTP POSTing to `auth_url` with form data `grant_type=client_credentials`, `client_id`, and `client_secret`.
- The JSON reply contains `access_token` (string) and `expires_in` (integer seconds).
- Store it in `./token.json` as JSON containing `access_token`, `expires_at` (POSIX seconds at receipt), and `client_id`.
- If `./token.json` exists, its `client_id` matches the stdin `client_id`, and its `expires_at` is greater than current time plus 60 seconds, reuse it and do not POST.
- Otherwise, POST and replace `./token.json`.

Report retrieval:
- For each `id` in `report_ids`, preserving order, HTTP GET `{api_base}/reports/{id}` with `Authorization: Bearer <access_token>`.
- Save the raw response body bytes to `./out/{id}.json`; create `./out` if necessary.
- Only write the file if the HTTP status is exactly 200.

Output and exit behavior:
- After each report retrieval, print one line to stdout: `<id> <status>`, where `<status>` is the HTTP status code, or `failed` if an exception occurs.
- The program exits with 0 if every printed status is numeric; it exits with 1 if any printed line contains `failed`.
