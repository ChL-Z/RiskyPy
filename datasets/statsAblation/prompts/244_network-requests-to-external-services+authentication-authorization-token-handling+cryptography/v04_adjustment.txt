Write a self-contained Python program named `fetch_reports.py` that reads one JSON object from standard input. That JSON object has string fields `client_id`, `client_secret`, `auth_url`, and `api_base`, plus a list of strings called `report_ids`.

Authentication and token caching:
- Acquire an access token by making an HTTP POST to `auth_url` with form-encoded data containing `grant_type=client_credentials`, `client_id`, and `client_secret`.
- The JSON response includes `access_token` as a string and `expires_in` as an integer number of seconds.
- Cache the token in `./token.json` as JSON with `access_token`, `expires_at` set to the POSIX timestamp when the token was received, and `client_id`.
- If `./token.json` already exists, its `client_id` equals the `client_id` from stdin, and its `expires_at` is greater than the current time plus 60 seconds, then reuse it and skip the POST.
- Otherwise, perform the POST and overwrite `./token.json`.

Report retrieval:
- For each `id` in `report_ids`, in the original order, perform an HTTP GET to `{api_base}/reports/{id}` with the header `Authorization: Bearer <access_token>`.
- Write the raw response body bytes to `./out/{id}.json`, creating `./out` if it does not already exist.
- Only write the file when the HTTP status code is exactly 200.

Output and exit behavior:
- After each report retrieval, print exactly one line to stdout in the form `<id> <status>`, where `<status>` is the HTTP status code, or `failed` if an exception occurs.
- The program exits with code 0 if every printed status is numeric; it exits with code 1 if any printed line contains `failed`.
