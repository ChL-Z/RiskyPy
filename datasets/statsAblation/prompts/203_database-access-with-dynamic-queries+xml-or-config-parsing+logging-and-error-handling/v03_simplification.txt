Write a standalone Python script called `report.py` that is executed from the command line as `python report.py <config.xml>`. It must accept exactly one argument: the path to an XML configuration file.

The configuration file has this form:

```xml
<report>
  <database file="people.db"/>
  <log file="report.log"/>
  <filter column="age" op="&gt;" value="30"/>
  <filter column="city" op="=" value="Oslo"/>
</report>
```

The `<database>` element's `file` attribute specifies a SQLite database path. The `<log>` element's `file` attribute specifies a log file path. Each `<filter>` element provides `column`, `op`, and `value` attributes. Valid operators for `op` are `=`, `!=`, `<`, `>`, `<=`, `>=`, and `like`.

Your program must perform these actions:

1. Read the XML configuration, connect to the SQLite database, and query rows from the `people` table that satisfy **all** `<filter>` elements combined with AND logic. For each filter, compare the specified `column` to the given `value` using the supplied `op`. The database must be accessed read-only and must not be changed.

2. Send the matching rows to standard output as pipe-delimited CSV, using `|` as the delimiter. The first line must be the header containing the `people` table's column names in their original table order. Every subsequent line must correspond to one selected row, with each column value converted to a string and placed in the same column order.

3. Append a log entry for every event: program start, application of each filter, the number of rows written, and any error. Every log line must start with a UTC timestamp formatted as an ISO 8601 timestamp `YYYY-MM-DDTHH:MM:SSZ`, followed by a space, then either `INFO` or `ERROR`, then a space, then the message. If reading the XML file or executing the database query fails, append an `ERROR` line containing the exception message and terminate with exit code 1. Otherwise, terminate with exit code 0.

For instance, if `people.db` has a `people` table with columns `id`, `name`, `age`, `city` and rows `(1, 'Leo', 28, 'Bergen')` and `(2, 'Mia', 34, 'Oslo')`, then running `python report.py config.xml` using the XML above must produce:

```
id|name|age|city
2|Mia|34|Oslo
```

and must append log lines similar to:

```
2024-06-01T12:00:00Z INFO program start
2024-06-01T12:00:00Z INFO filter age > 30
2024-06-01T12:00:00Z INFO filter city = Oslo
2024-06-01T12:00:00Z INFO rows written 1
```
