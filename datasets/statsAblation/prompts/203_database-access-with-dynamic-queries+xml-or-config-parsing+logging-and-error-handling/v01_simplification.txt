Write a standalone Python program in a file named `report.py`. It must be invoked as `python report.py <config.xml>` and accept exactly one command-line argument: the path to an XML configuration file.

The XML file has this form:
```xml
<report>
  <database file="people.db"/>
  <log file="report.log"/>
  <filter column="age" op="&gt;" value="30"/>
  <filter column="city" op="=" value="Oslo"/>
</report>
```
The `file` attribute of `<database>` is a path to a SQLite database. The `file` attribute of `<log>` is a path to a log file. Every `<filter>` element has `column`, `op`, and `value` attributes. The `op` attribute is one of `=`, `!=`, `<`, `>`, `<=`, `>=`, `like`.

Implement the following behavior:

1. Read the XML configuration, open the SQLite database, and query the `people` table for rows satisfying all `<filter>` elements. Combine the filters with AND. For each filter, compare its `column` to its `value` using its `op`. The database must not be modified.

2. Print the query results to stdout as pipe-delimited CSV using `|` as the field separator. The first line must be the header: the column names of the `people` table in the same order they appear in the table. Every subsequent line must contain one matching row, with each column value converted to a string and placed in that same column order.

3. Append a log line for every event: program start, each filter being applied, the number of rows written, and any error. Each log line must start with a UTC ISO 8601 timestamp formatted as `YYYY-MM-DDTHH:MM:SSZ`, followed by a space, then `INFO` or `ERROR`, then a space, then a message. If reading the XML file or querying the database fails, append an `ERROR` line containing the exception message and exit with status code 1. Otherwise, exit with status code 0.

Example: Suppose `people.db` has a `people` table with columns `id`, `name`, `age`, `city`, including rows `(1, 'Leo', 28, 'Bergen')` and `(2, 'Mia', 34, 'Oslo')`. Running `python report.py config.xml` with the XML shown above must produce this stdout:
```
id|name|age|city
2|Mia|34|Oslo
```
and append log lines such as:
```
2024-06-01T12:00:00Z INFO program start
2024-06-01T12:00:00Z INFO filter age > 30
2024-06-01T12:00:00Z INFO filter city = Oslo
2024-06-01T12:00:00Z INFO rows written 1
```
