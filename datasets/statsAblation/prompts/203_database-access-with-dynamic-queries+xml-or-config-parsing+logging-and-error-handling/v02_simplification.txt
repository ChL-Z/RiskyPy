Create a self-contained Python script named `report.py`. It is run from the command line as `python report.py <config.xml>` and must take exactly one argument: the path to an XML configuration file.

The XML configuration looks like this:

```xml
<report>
  <database file="people.db"/>
  <log file="report.log"/>
  <filter column="age" op="&gt;" value="30"/>
  <filter column="city" op="=" value="Oslo"/>
</report>
```

Here, `<database file="...">` gives the path to a SQLite database, and `<log file="...">` gives the path to a log file. Each `<filter>` has `column`, `op`, and `value` attributes. The allowed values for `op` are `=`, `!=`, `<`, `>`, `<=`, `>=`, and `like`.

Your program must do the following:

1. Parse the XML configuration, open the SQLite database, and select rows from the `people` table that satisfy **all** `<filter>` elements together using AND logic. For each filter, compare the named `column` against `value` using the given `op`. The database must be treated as read-only and must not be modified.

2. Write the matching rows to standard output as pipe-delimited CSV, using `|` as the separator. The first output line must be the header, containing the `people` table's column names in their original table order. Each following line must represent one selected row, converting every column value to a string and placing the values in that same column order.

3. Append a log entry for every event: when the program starts, when each filter is applied, how many rows were written, and any error. Every log line must begin with a UTC timestamp in ISO 8601 format `YYYY-MM-DDTHH:MM:SSZ`, followed by a space, then `INFO` or `ERROR`, then a space, then the message. If reading the XML file or running the database query fails, append an `ERROR` line containing the exception message and exit with status code 1. Otherwise, exit with status code 0.

For example, if `people.db` contains a `people` table with columns `id`, `name`, `age`, `city` and rows `(1, 'Leo', 28, 'Bergen')` and `(2, 'Mia', 34, 'Oslo')`, then running `python report.py config.xml` with the XML above must print:

```
id|name|age|city
2|Mia|34|Oslo
```

and must append log lines similar to:

```
2024-06-01T12:00:00Z INFO program start
2024-06-01T12:00:00Z INFO filter age > 30
2024-06-01T12:00:00Z INFO filter city = Oslo
2024-06-01T12:00:00Z INFO rows written 1
```
