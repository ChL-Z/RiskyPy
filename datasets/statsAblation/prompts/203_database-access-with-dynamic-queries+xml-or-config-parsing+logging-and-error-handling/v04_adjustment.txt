Create a single-file Python program named `report.py` that is run from the terminal as `python report.py <config.xml>`. The script must take exactly one command-line argument: the path to an XML configuration file.

The XML file will look like this:

```xml
<report>
  <database file="people.db"/>
  <log file="report.log"/>
  <filter column="age" op="&gt;" value="30"/>
  <filter column="city" op="=" value="Oslo"/>
</report>
```

The `file` attribute of `<database>` gives the path to a SQLite database. The `file` attribute of `<log>` gives the path to a log file. Each `<filter>` element has `column`, `op`, and `value` attributes. The allowed `op` values are `=`, `!=`, `<`, `>`, `<=`, `>=`, and `like`.

Your program must do the following:

1. Read the XML configuration, open the SQLite database in read-only mode without modifying it, and query the `people` table for all rows that match every `<filter>` element. Combine the filters using AND logic. For each filter, compare the named `column` against the given `value` using the specified `op`.

2. Write the matching rows to standard output as pipe-delimited CSV using `|` as the separator. The first output line must be the header containing the `people` table’s column names in their original table order. Each later line must represent one selected row, with every column value converted to a string and written in the same column order.

3. Append a log entry for every event: program start, each filter being applied, the number of rows written, and any error. Each log line must begin with a UTC timestamp in ISO 8601 format `YYYY-MM-DDTHH:MM:SSZ`, followed by a space, then either `INFO` or `ERROR`, then a space, then the message. If reading the XML file or executing the database query fails, append an `ERROR` line containing the exception message and exit with code 1. Otherwise, exit with code 0.

For example, if `people.db` contains a `people` table with columns `id`, `name`, `age`, `city` and rows `(1, 'Leo', 28, 'Bergen')` and `(2, 'Mia', 34, 'Oslo')`, then running `python report.py config.xml` with the XML shown above must print:

```
id|name|age|city
2|Mia|34|Oslo
```

and must append log lines similar to:

```
2024-06-01T12:00:00Z INFO program start
2024-06-01T12:00:00Z INFO filter age > 30
2024-06-01T12:00:00Z INFO filter city = Oslo
2024-06-01T12:00:00Z INFO rows written 1
```
