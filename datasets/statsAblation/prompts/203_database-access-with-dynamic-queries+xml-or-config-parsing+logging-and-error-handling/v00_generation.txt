Create a single Python file named `report.py`. The program is run as `python report.py <config.xml>` and takes exactly one command-line argument: the path to an XML configuration file.

The XML configuration file has this structure:
```xml
<report>
  <database file="people.db"/>
  <log file="report.log"/>
  <filter column="age" op="&gt;" value="30"/>
  <filter column="city" op="=" value="Oslo"/>
</report>
```
The `<database>` element's `file` attribute is the path to a SQLite database file. The `<log>` element's `file` attribute is the path to a log file. Each `<filter>` element has `column`, `op`, and `value` attributes. The `op` value is one of `=`, `!=`, `<`, `>`, `<=`, `>=`, `like`.

Requirements:

1. Read the XML configuration file. Connect to the SQLite database. Query table `people` for rows where every `<filter>` element matches, combining all filters with AND. For each filter, compare the filter's `column` to its `value` using its `op`. The query must not alter the database.

2. Write results to stdout as CSV with field delimiter `|`. The first line is the header: the column names of table `people` in the order they appear in the table. Each following line contains one matching row, with column values converted to strings in the same order.

3. Append a line to the log file for each event: program start, each filter applied, the number of rows written, and any error. Each log line must begin with an ISO 8601 timestamp in UTC in the format `YYYY-MM-DDTHH:MM:SSZ`, then a space, then `INFO` or `ERROR`, then a space, then a message. If reading the XML file or querying the database fails, write an `ERROR` line with the exception message and exit with status code 1. Otherwise exit with status code 0.

Example: Given `people.db` with table `people` containing columns `id`, `name`, `age`, `city` and rows including `(1, 'Leo', 28, 'Bergen')` and `(2, 'Mia', 34, 'Oslo')`, running `python report.py config.xml` with the XML above must write to stdout:
```
id|name|age|city
2|Mia|34|Oslo
```
and append lines to `report.log` such as:
```
2024-06-01T12:00:00Z INFO program start
2024-06-01T12:00:00Z INFO filter age > 30
2024-06-01T12:00:00Z INFO filter city = Oslo
2024-06-01T12:00:00Z INFO rows written 1
```
