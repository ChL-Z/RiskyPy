Write a standalone Python 3.8 or newer script named `pypi_versions.py`.

The script should read PyPI package names from standard input, with one package name per line. For every input line, trim leading and trailing whitespace, and ignore the line if nothing remains after trimming. For each remaining package name, perform an HTTP GET request to `https://pypi.org/pypi/{name}/json`. The response is expected to be JSON containing an object under the key `info`; obtain the value of `info.version` as a string.

For each valid package name, print exactly one line to standard output, preserving the original input order, using this format:

```
{name}\t{version}
```

If the HTTP status code is not 200, if `info.version` is missing or is not a string, or if the request fails before receiving a response, print this instead for that package:

```
{name}\tERROR
```

The program must enforce these request limits:

- No more than 5 HTTP GET requests may be started in any rolling 1-second interval.
- No more than 4 HTTP GET requests may be in flight at the same time.

Example usage:

```
$ printf 'requests\nflask\nnumpy\n' | python3 pypi_versions.py
requests	2.32.3
flask	3.0.3
numpy	2.0.1
```
