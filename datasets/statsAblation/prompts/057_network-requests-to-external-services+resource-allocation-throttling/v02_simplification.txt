Create a standalone Python program called `pypi_versions.py` that requires Python 3.8 or later.

Your program should read PyPI package names from standard input, with one package name per line. For each line, remove leading and trailing whitespace, and if the resulting line is empty, skip it. For each nonempty package name, send an HTTP GET request to `https://pypi.org/pypi/{name}/json`. The response should be JSON containing an object with an `info` key; read `info.version` as a string.

For each nonempty package name, print exactly one line to standard output, in the same order as the input, using this format:

```
{name}	{version}
```

If the HTTP response status is not 200, if `info.version` is missing or is not a string, or if the request fails before any response is received, print this line for that package instead:

```
{name}	ERROR
```

The program must obey these HTTP request limits:

- It must not start more than 5 HTTP GET requests in any rolling 1-second interval.
- It must not have more than 4 HTTP GET requests in flight at the same time.

Example usage:

```
$ printf 'requests\nflask\nnumpy\n' | python3 pypi_versions.py
requests	2.32.3
flask	3.0.3
numpy	2.0.1
```
