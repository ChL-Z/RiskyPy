Write a self-contained Python script named `pypi_versions.py` that runs on Python 3.8 or newer.

The script reads PyPI package names from stdin, one per line. For each input line:
- Strip leading and trailing whitespace.
- If the stripped line is empty, ignore it.
- Otherwise, treat it as a package name and make an HTTP GET request to `https://pypi.org/pypi/{name}/json`.

The response should be JSON for an object containing an `info` key. Read `info.version` as a string.

For every nonempty package name, output exactly one line to stdout, preserving the input order, in this format:

```
{name}	{version}
```

Use `{name}	ERROR` instead for that package if any of these occurs:
- the HTTP response status is not 200;
- `info.version` is missing or is not a string;
- the request fails before any response is received.

The script must enforce these HTTP request limits:
- No more than 5 HTTP GET requests may be started within any rolling 1-second period.
- No more than 4 HTTP GET requests may be in flight simultaneously.

Example:

```
$ printf 'requests\nflask\nnumpy\n' | python3 pypi_versions.py
requests	2.32.3
flask	3.0.3
numpy	2.0.1
```
