Create a Python 3.8+ program in a single file named `pypi_versions.py`.

The program reads package names from standard input, one per line. For each line, remove leading and trailing whitespace. Skip lines that are empty after trimming. For each remaining package name, retrieve the JSON document at `https://pypi.org/pypi/{name}/json`. The response body is a JSON object with an object at key `info`; read the string at `info.version`. Write one line to standard output for each remaining package name, in the same order as the input, formatted as `{name}\t{version}`. If the HTTP response status is not 200, if the JSON document has no `info.version` string, or if the request fails before a response arrives, write `{name}\tERROR` for that package.

The program must start at most 5 HTTP GET requests in any rolling 1-second interval and must have at most 4 HTTP GET requests in flight at the same time.

Usage example:

```
$ printf 'requests\nflask\nnumpy\n' | python3 pypi_versions.py
requests	2.32.3
flask	3.0.3
numpy	2.0.1
```
