Create a single Python script named `runplan.py`. When executed from a terminal using `python runplan.py <xml-path> <token>`, it must open the XML document located at `<xml-path>` and select only those jobs whose token matches the provided `<token>` string.

The XML document always consists of one root `<jobs>` element. Inside it may be any number of `<job>` children. Every `<job>` has both an `id` attribute and a `token` attribute. The body text of each `<job>` is a valid integer arithmetic expression using only nonnegative integer constants, `+`, `-`, `*`, parentheses, and ASCII whitespace.

For each `<job>` whose `token` attribute is exactly equal to the `<token>` command-line argument, evaluate the job’s expression as an integer and print one line to standard output in this exact format:

```
<id>=<integer result>
```

The matching jobs must be output in the same order in which they occur in the XML document. Any job whose token does not match exactly must not produce any output. You may assume the XML is well-formed and that every expression is valid.

For example, suppose `jobs.xml` contains:

```xml
<jobs>
  <job id="first" token="abc">2 + 3 * 4</job>
  <job id="second" token="xyz">10 - 2</job>
  <job id="third" token="abc">(1 + 2) * 3</job>
</jobs>
```

Then running `python runplan.py jobs.xml abc` should output:

```
first=14
third=9
```
