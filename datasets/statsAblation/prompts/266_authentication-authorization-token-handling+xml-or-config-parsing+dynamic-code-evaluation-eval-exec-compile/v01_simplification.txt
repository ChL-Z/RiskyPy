Create a single Python source file called `runplan.py`. When executed from the command line as `python runplan.py <xml-path> <token>`, it must load the XML document located at `<xml-path>` and use the given `<token>` string as a filter.

The XML document always has one root tag `<jobs>` and may contain any number of `<job>` children. Every `<job>` has attributes `id` and `token`, and the text inside it is a valid arithmetic expression using only nonnegative integer constants, `+`, `-`, `*`, parentheses, and ASCII whitespace.

For each `<job>` whose `token` attribute is exactly equal to the command-line `<token>`, evaluate its arithmetic expression to an integer and print one output line to stdout in the form:

```
<id>=<integer result>
```

Output must follow the original order of the matching `<job>` elements in the XML file. Do not print anything for `<job>` elements whose `token` does not match exactly. Assume the XML is well-formed and all expressions are valid.

For example, if `jobs.xml` is:

```xml
<jobs>
  <job id="first" token="abc">2 + 3 * 4</job>
  <job id="second" token="xyz">10 - 2</job>
  <job id="third" token="abc">(1 + 2) * 3</job>
</jobs>
```

then running `python runplan.py jobs.xml abc` should print:

```
first=14
third=9
```
