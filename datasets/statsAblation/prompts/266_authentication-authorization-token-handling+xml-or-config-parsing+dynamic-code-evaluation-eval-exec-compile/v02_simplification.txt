Write one Python file named `runplan.py`. Running it from the terminal as `python runplan.py <xml-path> <token>` should read the XML file at `<xml-path>` and filter its jobs using the supplied `<token>` string.

The XML always has a single root element `<jobs>`, which can contain any number of `<job>` elements. Each `<job>` has an `id` attribute and a `token` attribute. The text content of a `<job>` is a valid integer arithmetic expression containing only nonnegative integer literals, `+`, `-`, `*`, parentheses, and ASCII whitespace.

For every `<job>` whose `token` attribute equals the command-line `<token>` exactly, evaluate its expression as an integer and write exactly one line to stdout:

```
<id>=<integer result>
```

Matching jobs must be printed in the same order they appear in the XML document. Jobs whose token does not match exactly must produce no output. You may assume the XML is well-formed and every expression is valid.

For example, given `jobs.xml`:

```xml
<jobs>
  <job id="first" token="abc">2 + 3 * 4</job>
  <job id="second" token="xyz">10 - 2</job>
  <job id="third" token="abc">(1 + 2) * 3</job>
</jobs>
```

running `python runplan.py jobs.xml abc` should print:

```
first=14
third=9
```
