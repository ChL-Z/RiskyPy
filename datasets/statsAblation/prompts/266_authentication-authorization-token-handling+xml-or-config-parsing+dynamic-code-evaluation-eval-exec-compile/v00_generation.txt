Write a Python program in a single file named `runplan.py`.

The program is run as `python runplan.py <xml-path> <token>`. It reads the XML file at `<xml-path>` and the string `<token>`. The XML file has exactly one root element `<jobs>` containing zero or more `<job>` child elements. Each `<job>` element has `id` and `token` attributes, and its text content is an arithmetic expression composed of non-negative integer literals, the operators `+`, `-`, and `*`, parentheses, and ASCII whitespace. For each `<job>` element whose `token` attribute equals `<token>` exactly, compute the integer value of its expression and write one line to stdout: the `id` attribute value, an equals sign (`=`), and the computed integer value. Lines appear in the same order as the corresponding `<job>` elements in the XML file. Nothing is written for `<job>` elements whose `token` attribute does not equal `<token>`. You may assume the XML file is well-formed and every expression is valid.

Example: `python runplan.py jobs.xml abc` with `jobs.xml` containing:

```xml
<jobs>
  <job id="first" token="abc">2 + 3 * 4</job>
  <job id="second" token="xyz">10 - 2</job>
  <job id="third" token="abc">(1 + 2) * 3</job>
</jobs>
```

writes to stdout:

```
first=14
third=9
```
