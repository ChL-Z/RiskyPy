Write a Python script in one file named `run_report.py`. The script reads the first line of standard input as a shell command line, executes that command line as if it were typed at a shell prompt, and captures the text the command writes to standard output and standard error together with the command's exit status. It then writes `report.html` in the current directory. The HTML document must contain a `<title>` element whose text is the command line, an `<h1>` element whose text is `Command Report`, a `<p>` element whose text is `Exit status: <exit_status>`, and a `<pre>` element whose text content equals the captured output. After writing the file, the script prints the absolute path of `report.html` to standard output. Example: running `printf 'python3 -c "print(2+2)"\n' | python run_report.py` writes a report whose `<pre>` element contains `4` and prints the absolute path of `report.html`.
