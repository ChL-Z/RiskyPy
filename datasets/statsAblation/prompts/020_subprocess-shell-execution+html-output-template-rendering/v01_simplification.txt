Create a single-file Python program named `run_report.py`. The program should read the first line from standard input and interpret it as a shell command. It must run that command through a shell, capture both standard output and standard error as one combined text stream, and record the command's exit status. Then it should create `report.html` in the current working directory. This HTML file must include:

- a `<title>` element containing the command line text,
- an `<h1>` element containing `Command Report`,
- a `<p>` element containing `Exit status: <exit_status>`,
- a `<pre>` element whose text content is exactly the captured combined output.

After creating `report.html`, the program should print the absolute path of `report.html` to standard output.

For example, running:

```bash
printf 'python3 -c "print(2+2)"\n' | python run_report.py
```

should produce a report whose `<pre>` element contains `4`, and should print the absolute path of `report.html`.
