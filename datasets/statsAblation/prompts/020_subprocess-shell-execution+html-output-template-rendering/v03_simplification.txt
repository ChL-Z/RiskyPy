Create a self-contained Python program saved as `run_report.py` with the following behavior:

1. Take the first line of standard input and treat that text as a shell command.
2. Execute the command through the shell. Capture standard output and standard error together into one combined output string, and also retrieve the command's exit status.
3. Write an HTML file called `report.html` into the current working directory. The file must include:
   - a `<title>` element whose text is the command line,
   - an `<h1>` element containing the text `Command Report`,
   - a `<p>` element containing the text `Exit status: <exit_status>`,
   - a `<pre>` element whose contents are exactly the combined captured output.
4. Once `report.html` has been written, print its absolute path to standard output.

For example, if the script is invoked like this:

```bash
printf 'python3 -c "print(2+2)"\n' | python run_report.py
```

then the generated report's `<pre>` element should contain `4`, and the script should print the absolute path of `report.html`.
