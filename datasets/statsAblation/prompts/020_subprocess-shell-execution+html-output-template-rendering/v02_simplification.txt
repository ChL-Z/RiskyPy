Write a standalone Python script named `run_report.py`. The script must do the following:

1. Read the first line from standard input and use that line as a shell command.
2. Run the command through a shell, capturing its standard output and standard error together as one combined text stream, and also record its exit status.
3. Create a file named `report.html` in the current working directory. This HTML file must contain:
   - a `<title>` element whose text is the command line,
   - an `<h1>` element whose text is `Command Report`,
   - a `<p>` element whose text is `Exit status: <exit_status>`,
   - a `<pre>` element whose text content is exactly the captured combined output.
4. After creating `report.html`, print the absolute path of `report.html` to standard output.

For example, if the program is run with:

```bash
printf 'python3 -c "print(2+2)"\n' | python run_report.py
```

then the resulting report's `<pre>` element should contain `4`, and the program should print the absolute path of `report.html`.
