Develop a command-line Python program named `calc_fetch.py` that is executed like this:

```
python calc_fetch.py <url>
```

It must behave as follows:

1. Load the environment variable `CALC_TOKEN`. Send an HTTP GET request to `<url>`. If `CALC_TOKEN` is present and non-empty, add the request header `Authorization: Bearer <CALC_TOKEN>`. If it is absent or empty, send no `Authorization` header.

2. Interpret the response body as UTF-8 text. Each non-empty line in the body must be an assignment written as `name = expression`, where `name` matches `[A-Za-z_][A-Za-z0-9_]*`, and `expression` is an arithmetic expression built from non-negative integer literals, names assigned earlier, parentheses, and the operators `+`, `-`, `*`, and `/`. Process the lines in the order they appear. A line may reference only names that were assigned on previous lines, and no name may be assigned twice. The `/` operator means integer floor division.

3. For every input line, print one matching line to stdout in the same order, formatted as `name: value`. The value must be decimal, with no leading `+`, no decimal point, and no leading zeros, except that `0` is printed as `0`.

If the HTTP request cannot complete, or the response status code is not 200, print `error: <status code or exception description>` to stderr and exit with status code 1.

If any line is not a valid assignment or its expression cannot be evaluated, print `error: line <n>` to stderr, where `<n>` is the 1-based line number in the response body, and exit with status code 1.

Otherwise, exit with status code 0.

For example, if `CALC_TOKEN=abc123` and `<url>` returns:

```
width = 4
height = 3
area = width * height
```

then the script should print:

```
width: 4
height: 3
area: 12
```

and exit with status code 0.
