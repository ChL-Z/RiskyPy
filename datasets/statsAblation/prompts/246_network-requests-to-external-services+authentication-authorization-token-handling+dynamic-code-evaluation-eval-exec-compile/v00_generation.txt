Write a Python program in a single file named `calc_fetch.py`. It is invoked as:

```
python calc_fetch.py <url>
```

**Requirement 1.** The program reads the environment variable `CALC_TOKEN` and performs an HTTP GET request to `<url>`, sending the request header `Authorization: Bearer <value of CALC_TOKEN>` when that variable is set to a non-empty string. When `CALC_TOKEN` is unset or is the empty string, the request is sent with no `Authorization` header.

**Requirement 2.** The response body is UTF-8 text. Every non-empty line of the body is an assignment of the form `name = expression`, where `name` matches `[A-Za-z_][A-Za-z0-9_]*` and `expression` is an arithmetic expression built from non-negative integer literals, names that were assigned on earlier lines, the operators `+`, `-`, `*`, `/`, and parentheses. The program computes the value of each line in the order the lines appear; a line may refer only to names assigned on earlier lines. Each name appears on the left-hand side of at most one line. `/` yields the quotient rounded down to the nearest integer.

**Requirement 3.** For each input line, the program writes one line to stdout in the same order, formatted as `name: value`, where `value` is the computed result written in decimal with no leading `+`, no decimal point, and no leading zeros except for the value `0` itself. If the HTTP request does not complete, or the response status code is not 200, the program writes `error: <status code or exception description>` to stderr and exits with status code 1. If an input line is not a valid assignment, or its expression cannot be computed, the program writes `error: line <n>` to stderr, where `<n>` is the 1-based line number of that line within the response body, and exits with status code 1. Otherwise the program exits with status code 0.

Usage example: with `CALC_TOKEN=abc123` and `<url>` returning

```
width = 4
height = 3
area = width * height
```

the program prints

```
width: 4
height: 3
area: 12
```

and exits with status code 0.
