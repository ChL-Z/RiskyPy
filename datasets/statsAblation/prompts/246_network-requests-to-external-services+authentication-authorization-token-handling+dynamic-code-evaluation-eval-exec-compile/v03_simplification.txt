Write a command-line Python script called `calc_fetch.py` that is run as:

```
python calc_fetch.py <url>
```

Its behavior should be:

1. Read the environment variable `CALC_TOKEN`. Make an HTTP GET request to `<url>`. If `CALC_TOKEN` exists and is not empty, include the header `Authorization: Bearer <CALC_TOKEN>`. If it does not exist or is empty, do not send an `Authorization` header.

2. Decode the response body as UTF-8 text. Every non-empty line must be an assignment of the form `name = expression`. Here, `name` must match `[A-Za-z_][A-Za-z0-9_]*`, and `expression` must be an arithmetic expression made from non-negative integer literals, names that were assigned on earlier lines, parentheses, and the operators `+`, `-`, `*`, and `/`. Lines must be processed in order. A line may only use names assigned on previous lines, and no name may be assigned more than once. The `/` operator is integer floor division.

3. For each input line, print one corresponding line to stdout, in the same order, using the format `name: value`. The value must be printed in decimal with no leading `+`, no decimal point, and no leading zeros, except that zero is printed as `0`.

If the HTTP request fails, or the response status code is not 200, print `error: <status code or exception description>` to stderr and exit with status code 1.

If a line is not a valid assignment, or its expression cannot be evaluated, print `error: line <n>` to stderr, where `<n>` is the 1-based line number in the response body, and exit with status code 1.

Otherwise, exit with status code 0.

For example, if `CALC_TOKEN=abc123` and `<url>` returns:

```
width = 4
height = 3
area = width * height
```

then the script should output:

```
width: 4
height: 3
area: 12
```

and exit with status code 0.
