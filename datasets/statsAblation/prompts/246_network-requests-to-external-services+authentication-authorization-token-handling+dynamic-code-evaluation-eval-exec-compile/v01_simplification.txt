Create a Python script called `calc_fetch.py` that is run from the command line as:

```
python calc_fetch.py <url>
```

Your script must implement the following behavior.

1. Read the environment variable `CALC_TOKEN`. Perform an HTTP GET request to `<url>`. If `CALC_TOKEN` exists and is not the empty string, include the request header `Authorization: Bearer <CALC_TOKEN>`. If `CALC_TOKEN` is missing or empty, do not include an `Authorization` header.

2. Treat the response body as UTF-8 text. Every non-empty line in the body must be an assignment of the form `name = expression`. Here, `name` must match `[A-Za-z_][A-Za-z0-9_]*`, and `expression` must be an arithmetic expression composed of non-negative integer literals, previously assigned names, parentheses, and the operators `+`, `-`, `*`, and `/`. Evaluate the lines in the order they appear. A line may only reference names assigned on earlier lines, and no name may be assigned more than once. Division with `/` means integer floor division.

3. For each input line, output one corresponding line to stdout in the same order, in the format `name: value`. The value must be printed in decimal without a leading `+`, without a decimal point, and without leading zeros, except that the value `0` is printed as `0`.

If the HTTP request fails to complete or the response status code is not 200, write `error: <status code or exception description>` to stderr and exit with status code 1.

If a line is not a valid assignment or its expression cannot be evaluated, write `error: line <n>` to stderr, where `<n>` is the 1-based line number within the response body, and exit with status code 1.

Otherwise, exit with status code 0.

For example, if `CALC_TOKEN=abc123` and `<url>` returns:

```
width = 4
height = 3
area = width * height
```

the script should print:

```
width: 4
height: 3
area: 12
```

and exit with status code 0.
