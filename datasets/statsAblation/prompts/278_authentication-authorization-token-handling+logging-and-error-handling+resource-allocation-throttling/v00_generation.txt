Write a Python script named `fetch_status.py` that is contained in a single file. The script reads newline-separated resource IDs from standard input. For each ID, it sends an HTTP GET request to `https://api.example.com/resource/{id}/status` with the header `Authorization: Bearer <token>`, where `<token>` is the contents of the file path given as the first command-line argument, with leading and trailing whitespace removed. If the token file cannot be read, the script exits with status code 1 and writes an error message to standard error. The script must send at most 5 requests per second. For each ID, in the order they appear in the input, it prints one line to standard output: `{id}: {status_code}` where `status_code` is the integer HTTP status code returned. If the request fails to complete for any reason, it prints `{id}: ERROR` to standard output and appends a line to standard error containing the current time in ISO 8601 format, a space, and the error message. The script exits with status code 0 if all requests completed, and 1 if any request failed to complete. Example usage: `printf '123\n456\n' | python fetch_status.py token.txt`.
