Write a Python program in a single file named `configcache.py`. The program exposes a command-line interface with two subcommands.

The configuration file it works with is an XML document whose root element is `<app>` with a `name` attribute and a `token` attribute. Zero or more `<setting key="..." value="..."/>` elements appear as direct children of the root. Example:

```xml
<app name="billing" token="t-9f3a2b71">
  <setting key="region" value="eu-west-1"/>
  <setting key="retries" value="3"/>
</app>
```

**Requirement 1 — `load`.** Invoked as:

```
python configcache.py load --config <xml_path> --cache <bin_path>
```

Read the XML document at `<xml_path>`. Take the value of the root `name` attribute, the value of the root `token` attribute, and a mapping from each `<setting>` element's `key` attribute to that element's `value` attribute. Write those three items to the file at `<bin_path>` as one object, creating the file if it does not exist and replacing it if it does. Print exactly one line to stdout: `cached N settings for NAME`, where `N` is the number of `<setting>` elements in the document and `NAME` is the root `name` attribute value.

**Requirement 2 — `show`.** Invoked as:

```
python configcache.py show --cache <bin_path>
```

Read the object previously written by `load` back from the file at `<bin_path>`. Print one line `KEY=VALUE` for each setting, ordered by key in ascending lexicographic order, followed by one final line `token=TOKEN`, where `TOKEN` is the stored token value.

**Usage example.** With the XML above saved as `config.xml`:

```
$ python configcache.py load --config config.xml --cache cache.bin
cached 2 settings for billing
$ python configcache.py show --cache cache.bin
region=eu-west-1
retries=3
token=t-9f3a2b71
```
