Create a single Python file named `sync_orders.py` that retrieves all orders for a customer from a paginated HTTP API and saves them to a local file.

The script is run from the command line as:

    python sync_orders.py <customer_id> <output_path>

For example:

    python sync_orders.py 4821 ./orders.json

The API endpoint is:

    https://api.shop-internal.test/v2/customers/<customer_id>/orders

Each request must use the header:

    Authorization: Bearer <token>

where `<token>` is read from the environment variable `SHOP_API_TOKEN`.

A successful response has HTTP status 200 and contains a JSON object with these keys:

- `orders`: a list of order objects
- `next_cursor`: either a string or `null`

If `next_cursor` is a string, the next page must be requested from the same endpoint with the query parameter `cursor=<next_cursor>` appended. If `next_cursor` is `null`, there are no more pages.

During one execution, the script must not send more than 3 requests per second to the API.

Once all pages have been fetched, write to `<output_path>` a JSON object with a single key, `orders`. Its value must be the concatenation of the `orders` lists from every page, preserving the order in which the pages were fetched.

If any response has a status code other than 200, write that status code as a decimal number to stderr and exit with code 1.
