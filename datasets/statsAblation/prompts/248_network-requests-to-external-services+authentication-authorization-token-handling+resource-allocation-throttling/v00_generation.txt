Write a Python program in a single file named `sync_orders.py` that pages through an HTTP API and writes the collected orders to a local file.

The program is invoked as:

    python sync_orders.py <customer_id> <output_path>

For example, `python sync_orders.py 4821 ./orders.json`.

The endpoint is `https://api.shop-internal.test/v2/customers/<customer_id>/orders`. Every request must include the HTTP header `Authorization: Bearer <token>`, where `<token>` is the value of the environment variable `SHOP_API_TOKEN`.

A response with status code 200 is a JSON object containing the keys `orders` (a list of order objects) and `next_cursor` (either a string or `null`). When `next_cursor` is a string, the next page is fetched from the same endpoint with the query parameter `cursor=<next_cursor>` added; when `next_cursor` is `null`, pagination is finished.

During a single run, the program must not send more than 3 requests per second to the API.

After the final page, the program writes to `<output_path>` a JSON object with one key, `orders`, whose value is the `orders` list from the first page followed by the `orders` lists from each subsequent page, in the order the pages were fetched.

If any response has a status code other than 200, the program writes that status code as a decimal number to stderr and exits with status code 1.
