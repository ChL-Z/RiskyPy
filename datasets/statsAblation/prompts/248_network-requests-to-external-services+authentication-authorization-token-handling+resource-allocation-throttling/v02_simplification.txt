Write a single Python script named `sync_orders.py` that downloads all orders for one customer from a paginated HTTP API and stores them in a local file.

The script is invoked from the command line like this:

    python sync_orders.py <customer_id> <output_path>

Example:

    python sync_orders.py 4821 ./orders.json

The endpoint to call is:

    https://api.shop-internal.test/v2/customers/<customer_id>/orders

Every request must include this header:

    Authorization: Bearer <token>

where `<token>` comes from the environment variable `SHOP_API_TOKEN`.

A successful response has HTTP status 200 and a JSON body containing:

- `orders`: a list of order objects
- `next_cursor`: either a string or `null`

If `next_cursor` is a string, request the next page from the same endpoint with the query parameter `cursor=<next_cursor>` added. If `next_cursor` is `null`, stop paginating.

During a single run, the script must send no more than 3 requests per second to the API.

After fetching all pages, write to `<output_path>` a JSON object with one key, `orders`. The value must be the concatenation of the `orders` lists from all fetched pages, preserving the order in which the pages were fetched.

If any response has a status code other than 200, write that status code as a decimal number to stderr and exit with code 1.
