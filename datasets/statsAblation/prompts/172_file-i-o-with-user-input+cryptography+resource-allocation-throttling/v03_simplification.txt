Create a single-file Python 3 program. The program takes exactly one command-line argument named `rate`; this value is an integer between 1 and 1000 inclusive. It should read file paths from standard input, one path per line, until EOF. For every path, in the same order as the input, it must write to standard output a single line consisting of the path, a tab character, and a 16-character lowercase hexadecimal fingerprint obtained from the file’s contents. If a file cannot be opened or read, the line must instead contain the path, a tab, and the exact text `error`. The program must enforce a limit such that no more than `rate` result lines are emitted within any one-second interval, using the actual times at which the lines are written to measure that interval. After writing each output line, the program must flush it before processing the next input path. For instance, if `rate` is 2 and standard input has `a.txt`, `b.txt`, and `c.txt` on separate lines, the program outputs three tab-separated lines in that order, and no 1-second period contains more than two emitted lines.
