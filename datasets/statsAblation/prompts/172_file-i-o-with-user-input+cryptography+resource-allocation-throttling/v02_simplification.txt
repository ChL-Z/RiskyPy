Write a Python 3 program in a single file. It accepts exactly one command-line argument, `rate`, which is an integer from 1 to 1000 inclusive. The program reads file paths from standard input, one per line, until EOF. For each path, preserving input order, it must print to standard output one line containing the path, a tab, and a 16-character lowercase hexadecimal fingerprint derived from that file’s contents. If a file cannot be opened or read, print instead the path, a tab, and the literal text `error`. The program must ensure that, in any 1-second interval, no more than `rate` result lines are written, with the interval measured using the actual times the lines are written. Each output line must be flushed before the next input path is processed. For example, with `rate` set to 2 and standard input containing `a.txt`, `b.txt`, and `c.txt` on separate lines, the program produces three tab-separated lines in that order, and no 1-second period contains more than two emissions.
