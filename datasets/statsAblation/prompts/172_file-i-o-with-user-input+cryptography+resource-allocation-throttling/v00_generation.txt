Write a Python 3 program in a single file. The program accepts one command-line argument: an integer `rate` from 1 to 1000. It reads newline-separated file paths from standard input until EOF. For each path, in the order read, it writes one line to standard output containing the path, a tab character, and a 16-character lowercase hexadecimal fingerprint derived from the bytes of that file. If a path cannot be opened or read, it writes the path, a tab, and the literal text `error`. The program must write no more than `rate` result lines in any 1-second interval, measured by when each line is written, and it must flush each line before starting the next path. Example: with `rate` set to 2 and standard input `a.txt
b.txt
c.txt
`, the program writes three tab-separated lines in that order, and no 1-second window contains more than two of those writes.
