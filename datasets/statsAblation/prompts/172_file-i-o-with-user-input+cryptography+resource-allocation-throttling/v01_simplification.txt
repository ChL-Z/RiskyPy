Create a single-file Python 3 script that takes one command-line argument: an integer `rate` in the inclusive range 1 through 1000. The script should read file paths from standard input, one path per line, until EOF. For every path, in the same order as it was read, emit one line to standard output consisting of the path, a tab character, and a 16-character lowercase hexadecimal fingerprint computed from that file's contents. If the file cannot be opened or read, emit the path, a tab character, and the exact string `error` instead. The script must never emit more than `rate` result lines during any 1-second window, where the window is determined by the times the lines are written, and it must flush each output line before processing the next input path. For example, if `rate` is 2 and standard input is `a.txt
b.txt
c.txt
`, the script emits three tab-separated lines in that order, and no 1-second interval contains more than two of those emissions.
