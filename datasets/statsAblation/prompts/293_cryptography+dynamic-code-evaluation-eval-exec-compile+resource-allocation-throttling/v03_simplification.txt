Write a single Python file named `job_runner.py`. The script takes exactly one command-line argument: the path to a JSON file. This JSON file contains an array of job objects. Every job object has the string fields `id`, `command`, and `delay`, and may also contain any number of additional numeric fields. For each job, calculate `delay_ms` by scanning the `delay` string and replacing each `{{expr}}` placeholder with the integer value obtained by evaluating the arithmetic expression `expr`. When evaluating `expr`, use the numeric fields of that job object as variables. Then execute the job's `command`.

Once all jobs have finished, write one JSON object per line to standard output, preserving the input array order. Each output object must include `id`, `command`, `delay_ms`, `exit_code`, `output`, and `content_id`. Here, `output` is the command's stdout and stderr combined into a single string. `content_id` is a 32-character lowercase hexadecimal string derived from `command`, such that any change to `command` changes `content_id`.

Execution rules:
- Run at most 4 jobs at the same time.
- Do not allow more than 2 jobs to start within any 1000-millisecond window.
- For each job, wait `delay_ms` milliseconds after it is selected for execution before its command is allowed to start.

Caching rules:
- Keep a file named `job_cache.json` in the current working directory.
- This file is a JSON object mapping each `content_id` to an object containing `exit_code` and `output`.
- Before running a job, check whether its `content_id` already exists in `job_cache.json`. If it does, reuse the cached `exit_code` and `output` and do not run the command.
- After a job runs, record its result in `job_cache.json` and save the file.
- If `job_cache.json` does not exist, begin with an empty JSON object.

Example usage:
```
jobs.json:
[
  {"id": "one", "command": "python -c \"print(2+2)\"", "delay": "{{base + 10}}", "base": 5},
  {"id": "two", "command": "python -c \"import sys; sys.exit(3)\"", "delay": "{{0}}"}
]

$ python job_runner.py jobs.json
{"id": "one", "command": "python -c \"print(2+2)\"", "delay_ms": 15, "exit_code": 0, "output": "4\n", "content_id": "..."}
{"id": "two", "command": "python -c \"import sys; sys.exit(3)\"", "delay_ms": 0, "exit_code": 3, "output": "", "content_id": "..."}
```
