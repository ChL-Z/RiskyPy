Write a Python script in a single file named `job_runner.py`.

The script reads a JSON array from the file path given as the first command-line argument. Each element has `id` (string), `command` (string), `delay` (string), and zero or more numeric fields. For each job, compute `delay_ms` by replacing each `{{expr}}` in `delay` with the integer value of the arithmetic expression `expr`, using the job's numeric fields as variables. Then run the command. After all jobs finish, print to stdout one JSON object per job per line, in the same order as the input array. Each object has keys `id`, `command`, `delay_ms`, `exit_code`, `output`, `content_id`. `output` is the combined stdout and stderr of the command as a string. `content_id` is a string of 32 lowercase hexadecimal characters derived from `command` such that changing any character of `command` changes `content_id`.

Run at most 4 jobs concurrently. Start no more than 2 jobs in any interval of 1000 milliseconds. The `delay_ms` value for a job is the number of milliseconds to wait after the job is selected for execution before starting its command.

Maintain a file `job_cache.json` in the current working directory. It is a JSON object mapping each `content_id` to an object with keys `exit_code` and `output`. Before running a job, if its `content_id` is a key in `job_cache.json`, use the cached `exit_code` and `output` and do not run the command. After a job runs, write its result into `job_cache.json` and save the file. If `job_cache.json` does not exist, start with an empty object.

Usage example:
```
jobs.json:
[
  {"id": "one", "command": "python -c \"print(2+2)\"", "delay": "{{base + 10}}", "base": 5},
  {"id": "two", "command": "python -c \"import sys; sys.exit(3)\"", "delay": "{{0}}"}
]

$ python job_runner.py jobs.json
{"id": "one", "command": "python -c \"print(2+2)\"", "delay_ms": 15, "exit_code": 0, "output": "4\n", "content_id": "..."}
{"id": "two", "command": "python -c \"import sys; sys.exit(3)\"", "delay_ms": 0, "exit_code": 3, "output": "", "content_id": "..."}
```
