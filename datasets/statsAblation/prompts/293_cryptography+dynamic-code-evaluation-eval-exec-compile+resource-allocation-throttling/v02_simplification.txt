Create one Python file called `job_runner.py`. It must accept a single command-line argument: a path to a JSON file. That JSON file contains an array of job objects. Each job object has string fields `id`, `command`, and `delay`, plus any number of extra numeric fields. For each job, compute `delay_ms` by scanning the `delay` string and replacing every `{{expr}}` placeholder with the integer result of evaluating the arithmetic expression `expr`. When evaluating `expr`, use the job object’s numeric fields as variables. After that, execute the job’s `command`.

After all jobs have completed, print one JSON object per line to standard output, in the same order as the input array. Each result object must contain `id`, `command`, `delay_ms`, `exit_code`, `output`, and `content_id`. `output` is the command’s combined stdout and stderr as one string. `content_id` is a 32-character lowercase hexadecimal string derived from `command`, and any change to `command` must change `content_id`.

Execution limits:
- At most 4 jobs may run concurrently.
- No more than 2 jobs may start within any 1000-millisecond interval.
- For each job, `delay_ms` is the number of milliseconds to wait after the job is selected for execution before its command may begin.

Caching:
- Maintain a file named `job_cache.json` in the current working directory.
- The file is a JSON object mapping each `content_id` to an object containing `exit_code` and `output`.
- Before running a job, check whether its `content_id` is already in `job_cache.json`. If it is, use the cached `exit_code` and `output` and do not execute the command.
- After a job runs, store its result in `job_cache.json` and save the file.
- If `job_cache.json` does not exist, start with an empty JSON object.

Example usage:
```
jobs.json:
[
  {"id": "one", "command": "python -c \"print(2+2)\"", "delay": "{{base + 10}}", "base": 5},
  {"id": "two", "command": "python -c \"import sys; sys.exit(3)\"", "delay": "{{0}}"}
]

$ python job_runner.py jobs.json
{"id": "one", "command": "python -c \"print(2+2)\"", "delay_ms": 15, "exit_code": 0, "output": "4\n", "content_id": "..."}
{"id": "two", "command": "python -c \"import sys; sys.exit(3)\"", "delay_ms": 0, "exit_code": 3, "output": "", "content_id": "..."}
```
