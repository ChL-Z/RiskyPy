Develop a single-file Python program named `job_runner.py` with the following behavior.

The program takes one command-line argument: the path to a JSON file containing an array of job objects. Every job object contains `id` (string), `command` (string), `delay` (string), and any number of additional numeric fields. For each job, determine `delay_ms` by scanning the `delay` string and replacing every `{{expr}}` placeholder with the integer result of the arithmetic expression `expr`. When evaluating `expr`, use the job object’s numeric fields as variables. Then execute the job’s `command`.

Once all jobs have completed, print results to standard output: one JSON object per line, one line per job, preserving the input array order. Each result object must contain the keys `id`, `command`, `delay_ms`, `exit_code`, `output`, and `content_id`. The `output` value is the command’s combined stdout and stderr as a single string. The `content_id` value is a 32-character lowercase hexadecimal string derived from `command`; it must have the property that any change to `command` changes `content_id`.

Concurrency and rate limits:
- Run no more than 4 jobs at the same time.
- Do not start more than 2 jobs within any 1000-millisecond interval.
- For each job, `delay_ms` is the number of milliseconds to wait after the job has been selected for execution before its command may start.

Caching:
- Keep a file named `job_cache.json` in the current working directory.
- This file is a JSON object mapping each `content_id` to an object with keys `exit_code` and `output`.
- Before running a job, check whether its `content_id` is already present in `job_cache.json`. If it is, use the cached `exit_code` and `output` and do not run the command.
- After a job runs, store its result in `job_cache.json` and save the file.
- If `job_cache.json` does not exist, begin with an empty JSON object.

Example usage:
```
jobs.json:
[
  {"id": "one", "command": "python -c \"print(2+2)\"", "delay": "{{base + 10}}", "base": 5},
  {"id": "two", "command": "python -c \"import sys; sys.exit(3)\"", "delay": "{{0}}"}
]

$ python job_runner.py jobs.json
{"id": "one", "command": "python -c \"print(2+2)\"", "delay_ms": 15, "exit_code": 0, "output": "4\n", "content_id": "..."}
{"id": "two", "command": "python -c \"import sys; sys.exit(3)\"", "delay_ms": 0, "exit_code": 3, "output": "", "content_id": "..."}
```
