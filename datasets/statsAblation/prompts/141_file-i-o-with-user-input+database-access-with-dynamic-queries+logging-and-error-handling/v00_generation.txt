Write a Python script in a single file named `import_csv.py`. The script reads newline-separated file paths from standard input. For each path, it reads the CSV file at that path. A valid CSV file has a first line containing comma-separated column names, and each subsequent line contains the same number of comma-separated fields. The script creates or replaces a table in a database file named `data.db`. The table name is the CSV file's base name without its extension. The table columns are the column names from the CSV header. The script inserts all rows from the CSV into that table. For each file, the script appends a line to `import.log`: if the file is processed, `<filepath>: <row_count> rows`; if the file does not exist, or if the first line is missing, or if any row has a different number of comma-separated fields than the header, `<filepath>: <error description>`. After processing all paths, the script prints `Total rows inserted: <total>` to standard output, where `<total>` is the sum of row counts from all successfully processed files.

Example: if standard input contains:
```
users.csv
orders.csv
```
and `users.csv` contains:
```
id,name
1,Alice
2,Bob
```
and `orders.csv` contains:
```
order_id,user_id,total
100,1,25.50
```
then running `python import_csv.py < filelist.txt` creates `data.db` with a table `users` containing 2 rows and a table `orders` containing 1 row, appends `users.csv: 2 rows` and `orders.csv: 1 row` to `import.log`, and prints `Total rows inserted: 3` to standard output.
