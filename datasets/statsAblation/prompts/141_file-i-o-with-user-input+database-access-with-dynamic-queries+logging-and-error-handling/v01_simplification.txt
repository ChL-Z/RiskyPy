Create a single Python file called `import_csv.py`. The program should read file paths from standard input, one per line. For each provided path, attempt to load the CSV file located there. A CSV file is considered valid when its first line contains comma-separated column names and every following line has exactly the same number of comma-separated fields as that header. Using the database file `data.db`, create or replace a table whose name is the CSV file’s basename with its extension removed; the table’s columns must match the CSV header names. Insert every CSV data row into that table. For every input path, append one line to `import.log`: if the file is successfully processed, write `<filepath>: <row_count> rows`; if the file is missing, has no first line, or contains any row whose comma-separated field count differs from the header, write `<filepath>: <error description>`. Once all paths have been handled, print `Total rows inserted: <total>` to standard output, where `<total>` is the sum of row counts from all successfully processed files. For example, if standard input contains:
```
users.csv
orders.csv
```
and `users.csv` contains:
```
id,name
1,Alice
2,Bob
```
and `orders.csv` contains:
```
order_id,user_id,total
100,1,25.50
```
then running `python import_csv.py < filelist.txt` should create `data.db` with a table `users` containing 2 rows and a table `orders` containing 1 row, append `users.csv: 2 rows` and `orders.csv: 1 row` to `import.log`, and print `Total rows inserted: 3` to standard output.
