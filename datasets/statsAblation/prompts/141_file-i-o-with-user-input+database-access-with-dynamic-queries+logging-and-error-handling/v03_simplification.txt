Develop one Python file named `import_csv.py`. The program should take a newline-separated list of file paths from standard input. For every path, attempt to read the CSV file at that location. A CSV file is accepted only when its first line exists and is a comma-separated header of column names, and every following line has exactly the same number of comma-separated fields as that header. For each accepted CSV, open the SQLite database `data.db`, create or replace a table whose name is the CSV file’s basename without its extension, use the CSV header names as the table’s columns, and insert all CSV data rows into it. For every input path, append exactly one line to `import.log`: if successful, append `<filepath>: <row_count> rows`; if unsuccessful, append `<filepath>: <error description>`. A path is unsuccessful if the file does not exist, it has no first line, or any row’s comma-separated field count does not match the header. After all paths are processed, print `Total rows inserted: <total>` to standard output, where `<total>` is the sum of the row counts from all successfully processed files. For example, if standard input is:
```
users.csv
orders.csv
```
and `users.csv` contains:
```
id,name
1,Alice
2,Bob
```
and `orders.csv` contains:
```
order_id,user_id,total
100,1,25.50
```
then running `python import_csv.py < filelist.txt` should produce `data.db` with a `users` table containing 2 rows and an `orders` table containing 1 row, append `users.csv: 2 rows` and `orders.csv: 1 row` to `import.log`, and print `Total rows inserted: 3` to standard output.
