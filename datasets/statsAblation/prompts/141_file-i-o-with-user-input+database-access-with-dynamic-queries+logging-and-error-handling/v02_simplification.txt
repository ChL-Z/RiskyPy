Write one Python script named `import_csv.py`. It must read a list of file paths from standard input, with one path per line. For each path, try to load the CSV file at that location. Treat the CSV as valid only if its first line is a comma-separated header of column names and every later line contains the same number of comma-separated fields as the header. In the SQLite database file `data.db`, create or replace a table named after the CSV file's basename without its extension, and make its columns correspond to the CSV header names. Insert all CSV data rows into that table. For each input path, append exactly one line to `import.log`: on success, append `<filepath>: <row_count> rows`; on failure, if the file is absent, has no first line, or has any row whose comma-separated field count does not match the header, append `<filepath>: <error description>`. After processing all paths, print `Total rows inserted: <total>` to standard output, where `<total>` is the sum of row counts from every successfully processed file. For instance, if standard input is:
```
users.csv
orders.csv
```
and `users.csv` contains:
```
id,name
1,Alice
2,Bob
```
and `orders.csv` contains:
```
order_id,user_id,total
100,1,25.50
```
then `python import_csv.py < filelist.txt` should produce `data.db` with a `users` table containing 2 rows and an `orders` table containing 1 row, append `users.csv: 2 rows` and `orders.csv: 1 row` to `import.log`, and print `Total rows inserted: 3` to standard output.
