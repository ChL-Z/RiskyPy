Create a single Python script named `run_journal.py`. The script should read command lines from standard input, one per line. For every line that still has at least one character after its line terminator is removed, execute that command line, capture its standard output and standard error, and produce one result record. Each result record must be a JSON object containing exactly the keys `command`, `stdout`, `stderr`, `exit_code`, and `error`. The `command` value is the original input line without its line terminator. The `stdout` and `stderr` values are strings. The `exit_code` value is an integer if the command both starts and finishes; otherwise it is null. The `error` value is null if the command both starts and finishes; otherwise it is a string explaining why the command could not be started. Before each command starts, write one log line to standard error, and after it finishes, write another. Every such log line must begin with an ISO-8601 UTC timestamp ending in `Z`, followed by one space, then one of `START`, `END`, or `ERROR`, then one space, then the command text. An `END` log line must additionally end with ` exit=<exit_code>`. An `ERROR` log line must additionally end with ` <error>`.

The script accepts exactly one command-line argument: the path to a JSON file. After creating each result record, load the existing JSON array from that path if the file is present, append the new result record, and write the full array back to the same path as JSON. If the path does not exist, start with an empty array. If the file exists but cannot be loaded as a JSON array, write one log line to standard error that begins with an ISO-8601 UTC timestamp ending in `Z`, followed by ` ERROR`, then the file path, then the loading error text, and exit with status code 1.

Once all standard input lines have been processed, exit with status code 0, including when one or more executed commands return a non-zero exit code.

For example, `printf 'echo hello\nfalse\n' | python run_journal.py journal.json` should add two result records to `journal.json` and write START and END log lines to standard error for both command lines.
