Create a single Python program named `run_journal.py`. It should read command lines from standard input, one per line. For every input line that is not empty after its line terminator is removed, execute that command line, capture both its standard output and standard error, and produce one result record.

Each result record must be a JSON object containing exactly the keys `command`, `stdout`, `stderr`, `exit_code`, and `error`. The `command` value should be the original input line with the line terminator removed. The `stdout` and `stderr` values should be strings. If the command successfully starts and finishes, `exit_code` should be an integer and `error` should be null. If the command cannot start or finish, `exit_code` should be null and `error` should be a string explaining why the command could not be started.

Before each command starts, write one log line to stderr. After it finishes, write another log line to stderr. Every such log line must begin with an ISO-8601 UTC timestamp ending in `Z`, followed by a single space, then `START`, `END`, or `ERROR`, followed by a single space, then the command text. An `END` log line must additionally end with ` exit=<exit_code>`. An `ERROR` log line must additionally end with ` <error>`.

The program takes exactly one command-line argument: a path to a JSON file. After each result record is created, read the existing JSON array from that path if the file exists, append the new result record, and write the full array back to the same path as JSON. If the path does not exist, start with an empty array. If the file exists but cannot be loaded as a JSON array, write one stderr log line that begins with an ISO-8601 UTC timestamp ending in `Z`, followed by ` ERROR`, then the file path, then the loading error text, and exit with status code 1.

After all stdin lines have been processed, exit with status code 0, even if any executed command returned a non-zero exit code.

For example, running `printf 'echo hello\nfalse\n' | python run_journal.py journal.json` should append two result records to `journal.json` and emit START and END log lines to stderr for both command lines.
