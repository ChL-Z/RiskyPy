Write one Python file named `run_journal.py`. The program reads newline-separated command lines from stdin. For each line that contains at least one character after removing the line terminator, it runs that command line, captures stdout and stderr, and records one result object. A result object is a JSON object with keys `command`, `stdout`, `stderr`, `exit_code`, and `error`. `command` is the input line without its line terminator. `stdout` and `stderr` are strings. `exit_code` is an integer when the command starts and finishes, otherwise null. `error` is null when the command starts and finishes, otherwise a string describing why the command could not start. The program writes one log line to stderr before starting each command and one after finishing it. Each log line begins with an ISO-8601 UTC timestamp ending in `Z`, followed by a space, then `START`, `END`, or `ERROR`, then a space, then the command text. The `END` line also ends with ` exit=<exit_code>`. The `ERROR` line also ends with ` <error>`.

The program takes one command-line argument: the path to a JSON file. After each result object is created, the program loads the existing JSON array from that path if the file exists, appends the new result object, and writes the entire array back to the path as JSON. If the path does not exist, the program starts with an empty array. If the file exists but cannot be loaded as a JSON array, the program writes one log line to stderr that begins with an ISO-8601 UTC timestamp ending in `Z`, followed by ` ERROR`, then the file path, then the loading error text, and exits with code 1.

After all stdin lines have been processed, the program exits with code 0, including when one or more commands return a non-zero exit code.

Example: `printf 'echo hello\nfalse\n' | python run_journal.py journal.json` adds two result objects to `journal.json` and writes START and END lines to stderr for both command lines.
