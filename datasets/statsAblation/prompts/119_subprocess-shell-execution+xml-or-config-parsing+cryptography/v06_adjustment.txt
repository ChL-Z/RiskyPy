Write a standalone Python program named `run_checks.py`. When executed, it must read an XML file called `checks.xml` from the current working directory. The XML document’s root element is `<checks>`, and it contains one or more `<check>` children. Each `<check>` has a `name` attribute and a `cmd` attribute. The `cmd` value is a base64-encoded string whose decoded content is a shell command encrypted using the passphrase stored in `passphrase.txt`.

Process every `<check>` element in the exact order it appears in the XML. For each one, decrypt its `cmd` value using that passphrase, execute the resulting shell command, and capture its standard output as text. Then print exactly one line per check in the form `<name>: <output>`, where `<name>` is the check’s `name` attribute and `<output>` is the captured standard output after removing any trailing newline. If the command emits no output, still print the line as `<name>: ` — that is, the name, a colon, a space, and then nothing afterward.
