Create a self-contained Python script called `run_checks.py`. When run, the script should load an XML file named `checks.xml` from the current working directory. The XML root element is `<checks>`, and it has one or more `<check>` child elements. Every `<check>` element includes a `name` attribute and a `cmd` attribute. The `cmd` attribute holds a base64-encoded string that represents a shell command encrypted with the passphrase found in `passphrase.txt`. Iterate through all `<check>` elements in the same order they appear in the XML. For each check, use that passphrase to decrypt the `cmd` value, run the decrypted shell command, and capture its standard output as text. Then output exactly one line per check using the format `<name>: <output>`, where `<name>` is the value of the check’s `name` attribute and `<output>` is the captured standard output with any trailing newline removed. If the command produces no output, the line must still be printed as `<name>: ` — that is, the name, a colon, a space, and then nothing after it.
