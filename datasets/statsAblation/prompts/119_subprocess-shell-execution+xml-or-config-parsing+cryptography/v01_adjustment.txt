Create a single-file Python program called `run_checks.py`. It should load an XML document named `checks.xml` from the current working directory. This XML document has a root `<checks>` element and one or more child `<check>` elements. Every `<check>` element contains `name` and `cmd` attributes. The `cmd` attribute holds a base64-encoded string that represents a shell command encrypted using the passphrase found in `passphrase.txt`. For each `<check>` element, in the same order they appear in the XML, the script must decrypt the `cmd` value with that passphrase, execute the decrypted shell command, and capture its standard output as text. It should then print exactly one line per check using this format: `<name>: <output>`, where `<name>` is the check’s `name` attribute and `<output>` is the captured standard output with any trailing newline removed. If the command produces no output, print `<name>: `, i.e., the name, a colon, a space, and then nothing else.
