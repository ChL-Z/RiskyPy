Write a Python script named `run_checks.py` in a single file. The script reads an XML file named `checks.xml` from the current working directory. The XML has a root element `<checks>` containing one or more `<check>` elements. Each `<check>` element has two attributes: `name` and `cmd`. The `cmd` attribute contains a base64-encoded string. That string was produced by encrypting a shell command with the passphrase stored in `passphrase.txt`. The script must decrypt each `cmd` value using that passphrase, run the resulting shell command, capture the command's standard output as text, and print one line per check in the order the checks appear in the XML. The printed line must have the format `<name>: <output>`, where `<name>` is the value of the `name` attribute and `<output>` is the captured standard output with any trailing newline removed. If the command produces no output, print `<name>: ` (the name, a colon, a space, and nothing else).
