Write a standalone Python script named `run_checks.py`. The script should read an XML file named `checks.xml` from the current working directory. The XML has a root `<checks>` element containing one or more `<check>` children. Each `<check>` has a `name` attribute and a `cmd` attribute. The `cmd` attribute is a base64-encoded string representing a shell command encrypted with the passphrase stored in `passphrase.txt`. For every `<check>` element, in the exact order it appears in the XML, the program must decrypt the `cmd` value using that passphrase, run the decrypted shell command, and capture its standard output as text. Then it must print one line per check in the form `<name>: <output>`, where `<name>` is the check’s `name` attribute and `<output>` is the captured standard output with any trailing newline stripped. If the command produces no output, the printed line should be `<name>: ` — that is, the name, a colon, a space, and nothing after it.
