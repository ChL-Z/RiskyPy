Create a self-contained Python script named `run_checks.py`. When run, the script should load an XML document named `checks.xml` from the current working directory. The XML root element is `<checks>`, and under it there may be one or more `<check>` elements. Every `<check>` element has two attributes: `name` and `cmd`. The `cmd` attribute holds a base64-encoded string; once decoded, it is a shell command that has been encrypted with the passphrase found in `passphrase.txt`.

Iterate through all `<check>` elements in the same order they appear in the XML. For each check, use the passphrase to decrypt the `cmd` value, run the decrypted shell command, and capture its standard output as text. Then output exactly one line per check in this format: `<name>: <output>`, where `<name>` is the value of the check's `name` attribute and `<output>` is the captured standard output with any trailing newline removed. If a command produces no output, the line must still be printed as `<name>: ` — the name, a colon, a space, and then nothing else.
