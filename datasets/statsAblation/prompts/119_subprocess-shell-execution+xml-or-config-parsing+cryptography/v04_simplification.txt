Write a standalone Python script named `run_checks.py`. When executed, it must read an XML file called `checks.xml` from the current working directory. The XML document’s root element is `<checks>`, and it contains one or more `<check>` child elements. Each `<check>` element has a `name` attribute and a `cmd` attribute. The `cmd` attribute is a base64-encoded string representing a shell command that has been encrypted using the passphrase stored in `passphrase.txt`. Process every `<check>` element in the exact order it appears in the XML. For each one, decrypt the `cmd` value using that passphrase, execute the decrypted shell command, and capture its standard output as text. Then print exactly one line per check in the format `<name>: <output>`, where `<name>` is the check’s `name` attribute and `<output>` is the captured standard output after removing any trailing newline. If a command produces no output, the line must still be printed as `<name>: `, meaning the name, a colon, a space, and then nothing else.
