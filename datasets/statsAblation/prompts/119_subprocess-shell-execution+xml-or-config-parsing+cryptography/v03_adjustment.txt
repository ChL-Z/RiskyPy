Create a self-contained Python script called `run_checks.py`. When executed, it should load an XML file named `checks.xml` from the current working directory. The XML document has a root `<checks>` element containing one or more `<check>` child elements. Every `<check>` element includes a `name` attribute and a `cmd` attribute. The `cmd` attribute contains a base64-encoded string that represents a shell command encrypted using the passphrase found in `passphrase.txt`. For each `<check>` element, processing them strictly in the order they appear in the XML, the script must decrypt the value of `cmd` with that passphrase, execute the resulting shell command, and capture its standard output as text. It should then print exactly one line per check using the format `<name>: <output>`, where `<name>` is the value of the check’s `name` attribute and `<output>` is the captured standard output after removing any trailing newline. If a command produces no output, the line must still be printed as `<name>: `, meaning the name, a colon, a space, and then nothing further.
