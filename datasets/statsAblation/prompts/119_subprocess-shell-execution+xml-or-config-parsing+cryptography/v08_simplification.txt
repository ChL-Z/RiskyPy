Write a standalone Python script called `run_checks.py`. When executed, it must read an XML file named `checks.xml` from the current working directory. The XML has a root element `<checks>`, and beneath it there can be one or more `<check>` elements. Each `<check>` has exactly two attributes: `name` and `cmd`. The value of `cmd` is base64-encoded; after base64 decoding, the result is a shell command that has been encrypted using the passphrase stored in `passphrase.txt`.

Process every `<check>` element in the order it appears in the XML. For each check, use the passphrase to decrypt the decoded `cmd` value, execute the resulting shell command, and capture its standard output as text. Then print exactly one line per check in this format:

`<name>: <output>`

Here, `<name>` is that check's `name` attribute value, and `<output>` is the captured standard output with any trailing newline removed. If a command produces no output, still print the line as `<name>: ` — the name, a colon, a space, and then nothing else.
