Write a Python program in a single file named `expense_report.py`. It will be invoked from the command line as `python expense_report.py expenses.csv report.html`. The input CSV is a UTF-8 text file. Its first line is the header `date,category,amount,note`, and all following lines are data rows. Each data row is expected to contain four comma-separated fields. Implement all of the following behavior:

1. Read and validate `expenses.csv`.
   - A data row is invalid if any of these is true:
     - it does not have exactly four fields;
     - its first field is not in `YYYY-MM-DD` format;
     - its third field cannot be parsed as a floating-point number.
   - For each invalid row, print exactly `line {line_number}: invalid row` to standard error, where `{line_number}` is the 1-based line number in the file, and skip that row.
   - For each valid row, use the first seven characters of its date as the month key.

2. Maintain monthly cumulative totals in `expense_state.txt` in the current working directory.
   - Each line of `expense_state.txt` must be `YYYY-MM<TAB>total`, where `total` has exactly two digits after the decimal point.
   - At program startup, if `expense_state.txt` exists, load its existing month totals; otherwise start with no totals.
   - After processing the CSV, add each valid expense amount to the total for its month key.
   - Rewrite `expense_state.txt` with all month keys and totals, sorted ascending by month key, formatting every total to exactly two decimal places.

3. Write an HTML report to `report.html`.
   - The document must begin with `<!DOCTYPE html>` and then contain `<html><head><title>Expense Report</title></head><body>`.
   - After that, include `<h1>Expense Report</h1>`, then `<h2>Monthly Totals</h2>`, then a `<table>` whose header row is `<tr><th>Month</th><th>Total</th></tr>` and which has one data row for each month key and total written to the state file in step 2.
   - Then include `<h2>Expenses</h2>`, then a `<table>` whose header row is `<tr><th>Date</th><th>Category</th><th>Amount</th><th>Note</th></tr>` and which has one data row for each valid expense from the CSV.
   - Finally, end with `</body></html>`.
   - Every amount shown in the HTML must have exactly two decimal places.
   - Monthly total rows must be ordered ascending by month key.
   - Expense rows must preserve the same order as the input CSV.

For example, if `expenses.csv` contains:
```
date,category,amount,note
2024-01-05,travel,12.5,taxi
2024-01-06,food,8,breakfast
2024-02-01,travel,20, train
badline
```
then after the first run, `expense_state.txt` contains:
```
2024-01	20.50
2024-02	20.00
```
and `report.html` contains a monthly totals table with those two rows and an expenses table with three rows.
