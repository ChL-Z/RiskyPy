Create a single Python file called `expense_report.py`. It will be run from the command line as `python expense_report.py expenses.csv report.html`. The input CSV is a UTF-8 text file whose first line is the header `date,category,amount,note`, followed by data rows. Each data row is supposed to contain four comma-separated fields. Your program must implement the following behavior:

1. Read `expenses.csv`. For every data row, check it as follows:
   - If the row does not have exactly four fields, or
   - the first field is not in `YYYY-MM-DD` format, or
   - the third field cannot be parsed as a floating-point number,
   then print exactly `line {line_number}: invalid row` to standard error, where `{line_number}` is the 1-based line number in the file, and skip that row. For every valid row, use the first seven characters of the date as its month key.

2. Keep monthly cumulative totals in a file named `expense_state.txt` in the current working directory. Each line of this state file must have the form `YYYY-MM<TAB>total`, where `total` is written with exactly two digits after the decimal point. When the program starts, if `expense_state.txt` exists, read its existing month totals; if it does not exist, begin with no totals. After processing the CSV, add each valid expense amount to the total for its month key, then rewrite `expense_state.txt` containing all month keys and their totals, sorted ascending by month key, with every total formatted to exactly two decimal places.

3. Write an HTML report to `report.html`. The document must start with `<!DOCTYPE html>` and contain `<html><head><title>Expense Report</title></head><body>`, followed by `<h1>Expense Report</h1>`, followed by `<h2>Monthly Totals</h2>`, followed by a `<table>` whose header row is `<tr><th>Month</th><th>Total</th></tr>` and which has one data row for each month key and total written to the state file in step 2, followed by `<h2>Expenses</h2>`, followed by a `<table>` whose header row is `<tr><th>Date</th><th>Category</th><th>Amount</th><th>Note</th></tr>` and which has one data row for each valid expense from the CSV, followed finally by `</body></html>`. Every amount shown in the HTML must have exactly two decimal places. Monthly total rows must be ordered ascending by month key. Expense rows must preserve the same order as the input CSV.

For example, if `expenses.csv` contains:
```
date,category,amount,note
2024-01-05,travel,12.5,taxi
2024-01-06,food,8,breakfast
2024-02-01,travel,20, train
badline
```
then after the first run, `expense_state.txt` contains:
```
2024-01	20.50
2024-02	20.00
```
and `report.html` contains a monthly totals table with those two rows and an expenses table with three rows.
