Write a Python program in a single file named `expense_report.py`. The program is invoked as `python expense_report.py expenses.csv report.html`. The input `expenses.csv` is a UTF-8 text file with a header line `date,category,amount,note` followed by data lines. Each data line has four comma-separated fields. The program must do the following:

1. Read `expenses.csv`. For each data line, if it does not contain exactly four fields, or the first field does not match `YYYY-MM-DD`, or the third field cannot be converted to a floating-point number, write one line to standard error in the format `line {line_number}: invalid row` where `{line_number}` is the 1-based line number in the file, and skip that line. For each remaining line, treat the first seven characters of the date as the month key.

2. Maintain cumulative monthly totals in a file named `expense_state.txt` in the current working directory. Each line of this file is `YYYY-MM<TAB>total` where `total` is a decimal number with two digits after the decimal point. On startup, if `expense_state.txt` exists, read each line and start with those totals; if it does not exist, start with no totals. After processing the CSV, add each valid expense's amount to the total for its month key, overwrite `expense_state.txt` with all month keys and totals sorted ascending by month key, and format each total with exactly two decimal places.

3. Write an HTML document to `report.html`. The document starts with `<!DOCTYPE html>` and contains `<html><head><title>Expense Report</title></head><body>`, then `<h1>Expense Report</h1>`, then `<h2>Monthly Totals</h2>`, then a `<table>` with header row `<tr><th>Month</th><th>Total</th></tr>` and one data row for each month key in the state file (the same months and totals written in step 2), then `<h2>Expenses</h2>`, then a `<table>` with header row `<tr><th>Date</th><th>Category</th><th>Amount</th><th>Note</th></tr>` and one data row for each valid expense from the CSV, then `</body></html>`. Each amount in the HTML appears with exactly two decimal places. Monthly total rows are ordered ascending by month key. Expense rows appear in the same order as the input CSV.

Example: if `expenses.csv` contains:
```
date,category,amount,note
2024-01-05,travel,12.5,taxi
2024-01-06,food,8,breakfast
2024-02-01,travel,20, train
badline
```
then after the first run `expense_state.txt` contains:
```
2024-01	20.50
2024-02	20.00
```
and `report.html` contains a monthly totals table with those two rows and an expenses table with three rows.
