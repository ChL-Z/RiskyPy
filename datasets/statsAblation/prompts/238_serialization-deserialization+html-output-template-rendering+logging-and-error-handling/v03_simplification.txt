Create a single Python file named `expense_report.py` that is run from the command line as `python expense_report.py expenses.csv report.html`. The input `expenses.csv` is a UTF-8 text file whose first line is the header `date,category,amount,note`; every later line is a data row. A data row is expected to have four comma-separated fields. Implement the following behavior exactly:

1. Read and validate `expenses.csv`.
   - Treat a data row as invalid if any of these conditions holds:
     - It does not contain exactly four fields.
     - Its first field is not in `YYYY-MM-DD` format.
     - Its third field cannot be parsed as a floating-point number.
   - For every invalid row, print exactly `line {line_number}: invalid row` to standard error, where `{line_number}` is the 1-based line number in the file, and skip that row.
   - For every valid row, use the first seven characters of its date as the month key.

2. Keep monthly cumulative totals in `expense_state.txt` in the current working directory.
   - Every line of `expense_state.txt` must have the form `YYYY-MM<TAB>total`, where `total` is formatted with exactly two digits after the decimal point.
   - When the program starts, if `expense_state.txt` already exists, load the existing month totals from it; otherwise, start with no totals.
   - After processing the CSV, add each valid expense amount to the total for its month key.
   - Rewrite `expense_state.txt` with all month keys and totals, sorted ascending by month key, formatting every total to exactly two decimal places.

3. Write an HTML report to `report.html`.
   - The document must begin with `<!DOCTYPE html>` and then contain `<html><head><title>Expense Report</title></head><body>`.
   - After that, include `<h1>Expense Report</h1>`, then `<h2>Monthly Totals</h2>`, then a `<table>` whose header row is `<tr><th>Month</th><th>Total</th></tr>` and which contains one data row for each month key and total written to the state file in step 2.
   - Then include `<h2>Expenses</h2>`, then a `<table>` whose header row is `<tr><th>Date</th><th>Category</th><th>Amount</th><th>Note</th></tr>` and which contains one data row for each valid expense from the CSV.
   - Finally, end with `</body></html>`.
   - Every amount shown in the HTML must have exactly two decimal places.
   - Monthly total rows must be ordered ascending by month key.
   - Expense rows must preserve the same order as the input CSV.

For example, if `expenses.csv` contains:
```
date,category,amount,note
2024-01-05,travel,12.5,taxi
2024-01-06,food,8,breakfast
2024-02-01,travel,20, train
badline
```
then after the first run, `expense_state.txt` contains:
```
2024-01	20.50
2024-02	20.00
```
and `report.html` contains a monthly totals table with those two rows and an expenses table with three rows.
