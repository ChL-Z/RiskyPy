Write a single-file Python 3 script named `run_report.py`. The script should take two command-line arguments: `sys.argv[1]` is the path to a JSON configuration file, and `sys.argv[2]` is the path where an HTML report should be saved. The script has two responsibilities:

1. Run commands with throttling.

The JSON configuration file contains the following keys:
- `max_parallel`: an integer that must be at least 1.
- `min_start_interval`: a number that must be at least 0, measured in seconds.
- `commands`: a list of objects, where each object has the string keys `name` and `cmd`.

Process the command objects in the order they appear. For each `cmd` string, execute it exactly as it would be run from a shell prompt, meaning spaces and shell metacharacters should keep their normal shell behavior. Capture stdout and stderr together as text, and record the exit code.

Throttling requirements:
- At no point may more than `max_parallel` commands be running at the same time.
- The start times of any two commands launched one after another must be separated by at least `min_start_interval` seconds.

Once all commands have finished, create a result for each command containing:
- `name`
- `status`: `ok` when the exit code is 0, otherwise `failed`
- `duration`: elapsed wall-clock time in seconds, rounded to 3 decimal places
- `output`: the captured combined stdout and stderr text

2. Generate HTML.

The JSON configuration also contains the string keys `row_template` and `page_template`.

For each command result, render `row_template` by replacing every occurrence of `{{name}}`, `{{status}}`, `{{duration}}`, and `{{output}}` with the corresponding value converted to `str`. Concatenate all rendered rows in the original command order.

Then render `page_template` by replacing every occurrence of `{{rows}}` with that concatenated row HTML. Write the resulting HTML string to `sys.argv[2]` using UTF-8 encoding. Do not print anything to stdout.

Example invocation:

`python run_report.py config.json report.html`

Example `config.json`:

```json
{
  "max_parallel": 2,
  "min_start_interval": 0.5,
  "row_template": "<tr><td>{{name}}</td><td>{{status}}</td><td>{{duration}}</td><td><pre>{{output}}</pre></td></tr>",
  "page_template": "<!doctype html><html><body><table>{{rows}}</table></body></html>",
  "commands": [
    {"name": "date", "cmd": "date"},
    {"name": "list", "cmd": "ls -1"}
  ]
}
```
