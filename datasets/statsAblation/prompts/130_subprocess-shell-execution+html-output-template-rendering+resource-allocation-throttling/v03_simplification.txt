Create a single-file Python 3 program called `run_report.py`. It must accept exactly two command-line arguments: `sys.argv[1]` is the path to a JSON configuration file, and `sys.argv[2]` is the path where the program should write an HTML report. The program must perform two main jobs: run throttled shell commands, then generate an HTML report from their results.

The JSON configuration file contains these keys:

- `max_parallel`: an integer with a minimum value of 1.
- `min_start_interval`: a number with a minimum value of 0, expressed in seconds.
- `commands`: a list of objects. Each object must contain the string keys `name` and `cmd`.
- `row_template`: a string template.
- `page_template`: a string template.

Process the entries in `commands` in their original order. For each `cmd` value, run it exactly as it would be executed from a shell prompt, so spaces and shell metacharacters must retain their normal shell interpretation. Capture stdout and stderr together as text, and also record the command's exit code.

Throttling rules:

- More than `max_parallel` commands must never be running at the same time.
- The start times of two commands launched one after another must differ by at least `min_start_interval` seconds.

After every command has completed, produce one result object per command. Each result must include:

- `name`
- `status`: `"ok"` if the exit code is 0, otherwise `"failed"`
- `duration`: wall-clock elapsed time in seconds, rounded to 3 decimal places
- `output`: the combined captured stdout and stderr text

For HTML generation, use the `row_template` and `page_template` strings from the JSON configuration.

For each command result, render one row by replacing every occurrence of `{{name}}`, `{{status}}`, `{{duration}}`, and `{{output}}` in `row_template` with the corresponding value converted to `str`. Join all rendered rows together in the original command order.

Then render `page_template` by replacing every occurrence of `{{rows}}` with that combined row HTML. Write the final HTML string to `sys.argv[2]` using UTF-8 encoding. Do not print anything to stdout.

Example usage:

`python run_report.py config.json report.html`

Example `config.json`:

```json
{
  "max_parallel": 2,
  "min_start_interval": 0.5,
  "row_template": "<tr><td>{{name}}</td><td>{{status}}</td><td>{{duration}}</td><td><pre>{{output}}</pre></td></tr>",
  "page_template": "<!doctype html><html><body><table>{{rows}}</table></body></html>",
  "commands": [
    {"name": "date", "cmd": "date"},
    {"name": "list", "cmd": "ls -1"}
  ]
}
```
