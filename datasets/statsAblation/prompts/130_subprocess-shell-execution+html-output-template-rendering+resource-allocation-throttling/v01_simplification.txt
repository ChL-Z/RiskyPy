Create a single-file Python 3 script called `run_report.py`. It must accept two command-line arguments: `sys.argv[1]` is the path to a JSON configuration file, and `sys.argv[2]` is the path where an HTML report should be written. The script must satisfy two main parts.

Part 1: Execute commands with throttling.
The JSON configuration contains these keys:
- `max_parallel`: an integer at least 1.
- `min_start_interval`: a number at least 0, representing seconds.
- `commands`: a list of objects, each having string keys `name` and `cmd`.

Process each command object in the given order. For each one, execute the `cmd` string exactly as a user would enter it at a shell prompt, so spaces and shell metacharacters must retain their normal command-line behavior. Capture combined stdout and stderr as text, and record the exit code.

Throttling rules:
- Never have more than `max_parallel` commands running at the same time.
- The start times of any two commands started consecutively must differ by at least `min_start_interval` seconds.

After all commands have completed, build a result for each command containing:
- `name`
- `status`: `ok` if the exit code is 0, otherwise `failed`
- `duration`: elapsed wall-clock time in seconds, rounded to 3 decimal places
- `output`: the captured combined stdout and stderr text

Part 2: Generate HTML.
The JSON configuration also contains string keys `row_template` and `page_template`.

For each command result, render `row_template` by replacing every occurrence of `{{name}}`, `{{status}}`, `{{duration}}`, and `{{output}}` with the corresponding value converted to `str`. Concatenate all rendered rows in the original command order.

Then render `page_template` by replacing every occurrence of `{{rows}}` with that concatenated row HTML. Write the resulting HTML string to `sys.argv[2]` using UTF-8 encoding. Do not print anything to stdout.

Example invocation:

`python run_report.py config.json report.html`

Example `config.json`:

```json
{
  "max_parallel": 2,
  "min_start_interval": 0.5,
  "row_template": "<tr><td>{{name}}</td><td>{{status}}</td><td>{{duration}}</td><td><pre>{{output}}</pre></td></tr>",
  "page_template": "<!doctype html><html><body><table>{{rows}}</table></body></html>",
  "commands": [
    {"name": "date", "cmd": "date"},
    {"name": "list", "cmd": "ls -1"}
  ]
}
```
