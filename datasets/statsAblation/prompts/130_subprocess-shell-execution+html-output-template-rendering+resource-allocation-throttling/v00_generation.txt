Write a Python 3 program in a single file named `run_report.py`. The program reads a JSON configuration file path from `sys.argv[1]` and writes an HTML report to the path from `sys.argv[2]`. The program has two top-level requirements.

1. Run commands with throttling. The JSON configuration has keys `max_parallel` (integer >= 1), `min_start_interval` (number >= 0, seconds), and `commands` (list of objects with string keys `name` and `cmd`). For each command object in order, run the `cmd` string exactly as a user would type it at a shell prompt, allowing spaces and command-line metacharacters to have their command-line meanings. Capture the command's combined stdout and stderr as text. Record the exit code. Start no more than `max_parallel` commands at the same time. Ensure the difference between the start times of any two consecutively started commands is at least `min_start_interval` seconds. After all commands finish, produce for each command: `name`, `status` (`ok` if exit code is 0, otherwise `failed`), `duration` (elapsed wall-clock seconds rounded to 3 decimals), and `output` (the captured combined stdout and stderr text).

2. Render HTML. The JSON configuration also has string keys `row_template` and `page_template`. For each command, render `row_template` by replacing every occurrence of `{{name}}`, `{{status}}`, `{{duration}}`, and `{{output}}` with the corresponding value converted to `str`. Concatenate all rendered rows in the original command order. Render `page_template` by replacing every occurrence of `{{rows}}` with that concatenation. Write the final HTML string to `sys.argv[2]` as UTF-8. Print nothing to stdout.

Example usage:

`python run_report.py config.json report.html`

Example `config.json`:

```json
{
  "max_parallel": 2,
  "min_start_interval": 0.5,
  "row_template": "<tr><td>{{name}}</td><td>{{status}}</td><td>{{duration}}</td><td><pre>{{output}}</pre></td></tr>",
  "page_template": "<!doctype html><html><body><table>{{rows}}</table></body></html>",
  "commands": [
    {"name": "date", "cmd": "date"},
    {"name": "list", "cmd": "ls -1"}
  ]
}
```
