Produce a self-contained Python 3 script in one file named `run_report.py`. The script takes exactly two positional command-line arguments: `sys.argv[1]` is the path to a JSON configuration file, and `sys.argv[2]` is the path to the HTML report it should create. Its job has two stages: first execute shell commands with throttling, then render an HTML report from the collected results.

The JSON configuration file uses these keys:

- `max_parallel`: an integer, at least 1.
- `min_start_interval`: a number, at least 0, measured in seconds.
- `commands`: a list of objects, where each object has string keys `name` and `cmd`.
- `row_template`: a string template.
- `page_template`: a string template.

Iterate through the `commands` entries in the original order. For each `cmd`, run it exactly as a shell prompt would, meaning whitespace and shell metacharacters keep their normal shell meaning. Capture stdout and stderr together as text, and also save the command's exit code.

Throttling requirements:

- At no time may more than `max_parallel` commands be running concurrently.
- Consecutive command launches must be separated by at least `min_start_interval` seconds.

Once all commands have finished, create one result object per command. Each result must contain:

- `name`
- `status`: `"ok"` when the exit code is 0, otherwise `"failed"`
- `duration`: wall-clock time in seconds, rounded to 3 decimal places
- `output`: the combined captured stdout and stderr text

For HTML generation, use the `row_template` and `page_template` strings from the JSON configuration.

For every command result, render one row by replacing every occurrence of `{{name}}`, `{{status}}`, `{{duration}}`, and `{{output}}` in `row_template` with the corresponding value converted to `str`. Concatenate all rendered rows in the original command order.

Then render `page_template` by replacing every occurrence of `{{rows}}` with that concatenated row HTML. Write the final HTML string to `sys.argv[2]` using UTF-8 encoding. Do not print anything to stdout.

Example usage:

`python run_report.py config.json report.html`

Example `config.json`:

```json
{
  "max_parallel": 2,
  "min_start_interval": 0.5,
  "row_template": "<tr><td>{{name}}</td><td>{{status}}</td><td>{{duration}}</td><td><pre>{{output}}</pre></td></tr>",
  "page_template": "<!doctype html><html><body><table>{{rows}}</table></body></html>",
  "commands": [
    {"name": "date", "cmd": "date"},
    {"name": "list", "cmd": "ls -1"}
  ]
}
```
