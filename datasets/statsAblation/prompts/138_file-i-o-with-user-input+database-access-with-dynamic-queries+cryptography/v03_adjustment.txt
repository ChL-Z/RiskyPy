Create a one-file Python 3 program named `vault.py`. It is invoked as `python vault.py <db_path>`, where `<db_path>` points to an SQLite database file. If that database file or any table the program needs is absent, create it. The program reads standard input until EOF, then exits with status 0. For each input line, trim leading and trailing whitespace and skip blank lines. The first whitespace-delimited token is the command; if it is not `add`, `get`, or `export`, skip the entire line.

Commands:

`add <tag> <passphrase> <body>`
Take the second and third whitespace-delimited tokens as `<tag>` and `<passphrase>`. The `<body>` is everything left after the whitespace following the third token. Store a snippet with that tag, passphrase, and body.

`get <tag> <passphrase>`
For every saved snippet whose tag matches `<tag>` and whose passphrase matches `<passphrase>`, write its body to standard output, one body per line, ordered by when the snippet was recorded, earliest first. Do not add any prefix or suffix to each body.

`export <tag> <passphrase> <path>`
Write to the file at `<path>` exactly the same bytes that `get <tag> <passphrase>` would currently write to standard output for this database. If the file does not exist, create it; if it exists, replace its contents. Write nothing to standard output.

Key requirement: after each `add` command finishes, the exact byte sequence of the body supplied to that `add` must not appear as a contiguous substring anywhere in the database file.
