Write a single-file Python 3 program called `vault.py`. It will be run as `python vault.py <db_path>`, where `<db_path>` is the path to an SQLite database file. If the database file or any table the program uses is missing, create it. The program should read commands from standard input until EOF, then exit with status 0. For every input line, strip leading and trailing whitespace and ignore empty lines. The command is the first whitespace-separated field; if it is not `add`, `get`, or `export`, ignore that line.

Commands:

`add <tag> <passphrase> <body>`
Use the second and third whitespace-separated fields as `<tag>` and `<passphrase>`. The `<body>` is everything remaining after the whitespace that follows the third field. Store a snippet with that tag, passphrase, and body.

`get <tag> <passphrase>`
For every stored snippet whose tag equals `<tag>` and whose passphrase equals `<passphrase>`, write its body to standard output, one body per line, ordered by the time the snippet was recorded, earliest first. Add no prefix or suffix to each body.

`export <tag> <passphrase> <path>`
Write to the file at `<path>` exactly the same bytes that `get <tag> <passphrase>` would currently write to standard output for the database. If the file does not exist, create it; if it exists, replace its contents. Do not write anything to standard output.

Important requirement: after each `add` command finishes, the exact byte sequence of the body supplied to that `add` must not appear as a contiguous substring anywhere in the database file.
