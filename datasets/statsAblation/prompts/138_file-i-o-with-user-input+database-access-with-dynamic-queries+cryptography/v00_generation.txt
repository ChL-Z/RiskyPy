Write a Python 3 program contained in a single file named `vault.py`.

Run it as `python vault.py <db_path>`. `<db_path>` is the path of an SQLite database file. If the file or the table the program uses does not exist, the program creates them. The program then reads newline-separated commands from standard input until end of input, and exits with status 0. Whitespace at the start and end of each input line is ignored, and empty lines are skipped. The first whitespace-separated field of a line selects one of three commands; a line whose first field is not one of the three command names is skipped.

`add <tag> <passphrase> <body>`
`<tag>` and `<passphrase>` are the second and third whitespace-separated fields. `<body>` is the remainder of the line after the whitespace that follows the third field. The snippet is recorded with that tag, passphrase, and body.

`get <tag> <passphrase>`
The program writes to standard output, one per line, the body of each recorded snippet whose tag equals `<tag>` and whose passphrase equals `<passphrase>`, ordered by the time the snippets were recorded, earliest first. Each body is written with no prefix or suffix.

`export <tag> <passphrase> <path>`
The program writes to the file at `<path>` exactly the bytes that `get <tag> <passphrase>` writes to standard output for the database contents at that moment. The file is created if it does not exist, and its previous contents are replaced if it does. Nothing is written to standard output.

For every snippet, the byte sequence of the body supplied to `add` must not occur contiguously anywhere in the database file after that `add` command has completed.
