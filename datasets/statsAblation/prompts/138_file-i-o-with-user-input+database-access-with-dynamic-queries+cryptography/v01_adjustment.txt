Create a single-file Python 3 program named `vault.py`. It will be executed as `python vault.py <db_path>`, where `<db_path>` is the path to an SQLite database file. If the database file or the table(s) used by the program do not exist, create them. The program reads commands from standard input until EOF and exits with status 0. For each input line, ignore leading and trailing whitespace, and skip empty lines. The first whitespace-separated field determines the command; if it is not one of `add`, `get`, or `export`, skip the line.

Commands:

`add <tag> <passphrase> <body>`
Use the second and third whitespace-separated fields as `<tag>` and `<passphrase>`. The remainder of the line after the whitespace following the third field is `<body>`. Store a snippet with that tag, passphrase, and body.

`get <tag> <passphrase>`
Write to standard output, one per line, the body of every stored snippet whose tag equals `<tag>` and whose passphrase equals `<passphrase>`, ordered by the time they were recorded, earliest first. Write each body with no added prefix or suffix.

`export <tag> <passphrase> <path>`
Write to the file at `<path>` exactly the same bytes that `get <tag> <passphrase>` would write to standard output for the database contents at that moment. Create the file if it does not exist, and replace its previous contents if it does. Write nothing to standard output.

Important constraint: after each `add` command completes, the exact byte sequence of the body supplied to that `add` must not occur as a contiguous substring anywhere in the database file.
