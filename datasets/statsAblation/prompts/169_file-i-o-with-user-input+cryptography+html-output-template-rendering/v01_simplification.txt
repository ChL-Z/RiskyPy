Create a single-file Python 3 script named `asset_report.py` that does the following:

Read input from standard input. Ignore empty lines. Every non-empty input line is formatted as `label<TAB>path`, where exactly one tab separates a label from a file path.

For each such line, attempt to read the bytes of the file at `path`. For that file, determine two values:
- its size as a decimal integer number of bytes,
- a fingerprint of the file contents: a lowercase hexadecimal string of constant length that is deterministic for the same byte sequence.

If the file cannot be read, use `0` for the size and `unreadable` for the fingerprint, then continue processing the remaining input lines.

Generate an HTML file named `report.html` in the current working directory. The HTML must include:
- `<title>Asset Report</title>`,
- a `<table id="assets">`,
- a `<thead>` row containing the headers `Label`, `Size`, and `Fingerprint`,
- one `<tbody>` row for each input line, in the same order as the input, containing the label, byte count, and fingerprint.

After writing the HTML file, print exactly `rows: N` to standard output, where `N` is the number of `<tbody>` rows written to the table.

Example session:

```
$ cat inputs.txt
main.js\tsrc/app.js
styles.css\tsrc/site.css
$ python asset_report.py < inputs.txt
rows: 2
```

After that run, `report.html` contains two body rows in the same order as the input.
