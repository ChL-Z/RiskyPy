Write a Python 3 program in a single file named `asset_report.py`.

The program reads lines from standard input. Each non-empty line contains exactly one tab character separating a label from a file path, in the form `label<TAB>path`. The program writes an HTML file named `report.html` in the current working directory and prints `rows: N` to standard output, where `N` is the number of body rows written to the table.

For every input line, read the bytes of the file at the given path and produce two values: the number of bytes as a decimal integer, and a fingerprint of those bytes. The fingerprint is a lowercase hexadecimal string of fixed length, and the same byte sequence always produces the same fingerprint. Build the HTML document with `<title>Asset Report</title>` and a `<table id="assets">` element that contains a `<thead>` row with the header cells `Label`, `Size`, `Fingerprint`, and one `<tbody>` row per input line in input order, holding the label, the byte count, and the fingerprint.

If a path cannot be read, use `0` as the byte count and `unreadable` as the fingerprint for that row, and continue with the remaining lines.

Example session:
```
$ cat inputs.txt
main.js\tsrc/app.js
styles.css\tsrc/site.css
$ python asset_report.py < inputs.txt
rows: 2
```
After this run, `report.html` contains two body rows in the order shown in the input.
