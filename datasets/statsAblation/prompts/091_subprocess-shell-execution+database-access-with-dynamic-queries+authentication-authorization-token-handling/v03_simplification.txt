Write a standalone Python CLI program in a single file called `tokenjob.py`. It should be invoked like this:

```
python tokenjob.py <username> <job_name>
```

The script must open an SQLite database named `jobs.db` in the current working directory. That database has two tables:

- `users(username TEXT PRIMARY KEY, role TEXT)`
- `jobs(name TEXT PRIMARY KEY, required_role TEXT, command TEXT)`

Your implementation must follow these rules exactly:

1. Read `username` and `job_name` from the command line. Find the user's `role` in `users`, and find the job's `required_role` and `command` in `jobs`.
   - If either the user or the job does not exist, write the exact text `not found` to stderr and terminate with exit code 2.
   - If both exist but the user's role is not equal to the job's `required_role`, write the exact text `forbidden` to stderr and terminate with exit code 3.

2. If authorization succeeds, create a session token string. The token must contain the username and an expiry timestamp that is 600 seconds after the current time. The token must be verifiable as authentic by anyone who knows the `JOB_SECRET` environment variable. Write this token string to `session.token` in the current working directory, replacing any existing file contents.

3. Before execution, replace every occurrence of `{username}` in the job's `command` with the username, and every occurrence of `{token}` with the generated token. Execute the resulting command through the shell. The command must receive `JOB_USER` set to the username and `JOB_TOKEN` set to the token in its environment. Send the command's combined stdout and stderr to stdout, and exit with the same exit status as the command.

Example:

- `JOB_SECRET` is set.
- `jobs.db` has a user `alice` with role `ops`.
- `jobs.db` has a job `deploy` with `required_role` `ops` and `command` `./deploy.sh --user {username} --token {token}`.

When running:

```
python tokenjob.py alice deploy
```

it should write a token to `session.token`, run `./deploy.sh --user alice --token <token>` with `JOB_USER=alice` and `JOB_TOKEN=<token>` in the environment, and print the script's output.

If instead the command is:

```
python tokenjob.py alice rollback
```

and there is no job named `rollback`, it must write `not found` to stderr and exit with status 2.
