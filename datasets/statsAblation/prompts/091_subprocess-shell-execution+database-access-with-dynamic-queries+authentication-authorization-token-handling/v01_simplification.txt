Develop a single Python script called `tokenjob.py` that functions as a command-line job launcher. It should be run as:

```
python tokenjob.py <username> <job_name>
```

It expects an SQLite database named `jobs.db` in the current working directory, with these two tables:

- `users(username TEXT PRIMARY KEY, role TEXT)`
- `jobs(name TEXT PRIMARY KEY, required_role TEXT, command TEXT)`

Your implementation must satisfy the following behavior:

1. Parse the supplied `username` and `job_name` from the command line. Query the `users` table for the `role` associated with that username, and query the `jobs` table for the `required_role` and `command` associated with that job name. If either the user row or the job row is missing, print exactly `not found` to stderr and terminate with exit status 2. If both rows exist but the user's role is not equal to the job's `required_role`, print exactly `forbidden` to stderr and terminate with exit status 3.

2. If authorization succeeds, create a session token string that contains the username and an expiration time set to 600 seconds after the current time. The token must be verifiable as authentic by anyone who knows the value of the `JOB_SECRET` environment variable. Write this token string to `session.token` in the current working directory, replacing any existing contents of that file.

3. Run the job's `command` after substituting every occurrence of `{username}` with the username and every occurrence of `{token}` with the generated token. Execute the resulting command through the shell, with the environment variables `JOB_USER` set to the username and `JOB_TOKEN` set to the token. Send the command's combined stdout and stderr to stdout, and exit using the command's exit status.

Example scenario: Suppose `JOB_SECRET` is set, `jobs.db` contains a user `alice` with role `ops`, and a job `deploy` with `required_role` `ops` and `command` `./deploy.sh --user {username} --token {token}`. Then `python tokenjob.py alice deploy` should write a token to `session.token`, invoke `./deploy.sh --user alice --token <token>` with `JOB_USER=alice` and `JOB_TOKEN=<token>` in its environment, and print the script's output. If `python tokenjob.py alice rollback` is run and no job named `rollback` exists, it should print `not found` on stderr and exit with status 2.
