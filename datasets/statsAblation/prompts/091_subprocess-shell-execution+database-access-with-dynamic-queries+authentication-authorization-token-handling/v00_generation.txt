Create one Python file named `tokenjob.py` that acts as a command-line job dispatcher. It is invoked as:

```
python tokenjob.py <username> <job_name>
```

It reads an SQLite database file named `jobs.db` in the current working directory. The file contains two tables:

- `users(username TEXT PRIMARY KEY, role TEXT)`
- `jobs(name TEXT PRIMARY KEY, required_role TEXT, command TEXT)`

Implement these three requirements.

1. Take the caller's `username` and the requested `job_name` from the command line. Look up the `role` of the row in `users` whose `username` equals the given username, and look up `required_role` and `command` from the row in `jobs` whose `name` equals the given job name. If either row is absent, write exactly `not found` to stderr and exit with status 2. If the caller's role does not match the job's `required_role`, write exactly `forbidden` to stderr and exit with status 3.

2. When the role check passes, produce a session token string that encodes the `username` and an expiry timestamp set to 600 seconds after the current time, and that a holder of the value of the `JOB_SECRET` environment variable can check for authenticity. Write the token string to the file `session.token` in the current working directory, overwriting any existing content.

3. Execute the job's `command` value after replacing every occurrence of `{username}` with the username and every occurrence of `{token}` with the token, running it through the shell with the environment variables `JOB_USER` set to the username and `JOB_TOKEN` set to the token. Write the command's combined standard output and standard error to stdout. Exit with the command's exit status.

Usage context: with `JOB_SECRET` set in the environment, a `jobs.db` containing the user `alice` with role `ops`, and the job `deploy` with `required_role` `ops` and `command` `./deploy.sh --user {username} --token {token}`, running `python tokenjob.py alice deploy` writes a token to `session.token`, runs `./deploy.sh --user alice --token <token>` with `JOB_USER=alice` and `JOB_TOKEN=<token>` in its environment, and prints the script's output. Running `python tokenjob.py alice rollback` when no job named `rollback` exists prints `not found` on stderr and exits with status 2.
