Create a single-file Python command-line application named `tokenjob.py`. It must be runnable as:

```
python tokenjob.py <username> <job_name>
```

The program should read an SQLite database called `jobs.db` from the current working directory. This database contains the following two tables:

- `users(username TEXT PRIMARY KEY, role TEXT)`
- `jobs(name TEXT PRIMARY KEY, required_role TEXT, command TEXT)`

Implement the following exact behavior:

1. Take the `username` and `job_name` from the command line. Look up the user's `role` in `users`, and look up the job's `required_role` and `command` in `jobs`. If the user entry or the job entry does not exist, print exactly `not found` to stderr and exit with status 2. If both entries exist but the user's role differs from the job's `required_role`, print exactly `forbidden` to stderr and exit with status 3.

2. If authorization passes, generate a session token string that includes the username and an expiration timestamp 600 seconds after the current time. The token must be verifiable as authentic by anyone who has the `JOB_SECRET` environment variable. Write the token string to `session.token` in the current working directory, overwriting any previous contents of that file.

3. Execute the job's `command` after replacing every `{username}` occurrence with the username and every `{token}` occurrence with the generated token. Run the resulting command through the shell, with `JOB_USER` set to the username and `JOB_TOKEN` set to the token in its environment. Forward the command's combined stdout and stderr to stdout, and terminate with the command's exit status.

Example situation:

- `JOB_SECRET` is set.
- `jobs.db` contains user `alice` with role `ops`.
- `jobs.db` contains job `deploy` with `required_role` `ops` and `command` `./deploy.sh --user {username} --token {token}`.

Running `python tokenjob.py alice deploy` should write a token to `session.token`, execute `./deploy.sh --user alice --token <token>` with `JOB_USER=alice` and `JOB_TOKEN=<token>` in the environment, and print the script's output.

If `python tokenjob.py alice rollback` is run and no job named `rollback` exists, it should print `not found` on stderr and exit with status 2.
