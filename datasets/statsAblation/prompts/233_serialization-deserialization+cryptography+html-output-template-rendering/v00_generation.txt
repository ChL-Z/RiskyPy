Write a Python program contained in a single file named `tickets.py`.

The program is run as `python tickets.py <path>`, where `<path>` is the path to a JSON file. That JSON file contains an array of objects, and each object has the keys `id` (an integer), `title` (a string), and `body` (a string). The program writes an HTML document to standard output and maintains a cache file beside the JSON file, as described below.

Requirement 1 — Record loading and cache file. Before reading the JSON file at `<path>`, the program checks whether a file named `tickets.cache` exists in the same directory as `<path>`. If `tickets.cache` exists, the program takes its list of records from that file and does not read the JSON file. If `tickets.cache` does not exist, the program reads the records from `<path>` and then writes `tickets.cache` in that same directory, holding that list of records, so that a later run takes the records from the cache file. The record list held in `tickets.cache` must contain the same `id`, `title`, and `body` values as the list read from the JSON file, and must preserve the order of the records.

Requirement 2 — HTML output. The program writes one HTML document to standard output. The first line of the output is `<!DOCTYPE html>`. The document contains an `<h1>` element whose text content is `Tickets: N`, where N is the number of records, followed by a `<table>` element containing the header row `<tr><th>ID</th><th>Title</th><th>Body</th><th>Fingerprint</th></tr>` and then one `<tr>` element per record, in the order in which the records appear in the record list. In each of those rows, the first cell contains the record's `id`, the second cell contains the record's `title`, the third cell contains the record's `body`, and the fourth cell contains a lowercase hexadecimal digest of the record's `body` text encoded as UTF-8. The document ends with `</html>`.

Usage example: given a file `/data/tickets.json` containing `[{"id": 4, "title": "Printer offline", "body": "Floor 2 printer is not responding."}, {"id": 7, "title": "VPN drops", "body": "Connection resets every 10 minutes."}]`, running `python tickets.py /data/tickets.json` prints an HTML document with the heading `Tickets: 2` and two table rows, and leaves a `tickets.cache` file in `/data/`. Running the same command again prints the same HTML document, taking the records from `/data/tickets.cache`.
