Write a Python program in a single file named render_cache.py.

The program must satisfy these three requirements:

1. The program takes one command-line argument, a file path. If that path exists, it must be readable as a JSON object with exactly the keys "template" (a string) and "vars" (an object whose keys are variable names and whose values are integers). Variable names consist of letters, digits, and underscores, and do not start with a digit. The program uses the "template" string and the "vars" mapping. If the path does not exist, the program reads a template string from stdin and uses the variable mapping stored in a binary file named cache.bin in the current working directory. That cache.bin file is written by the program as described in requirement 3.

2. For every occurrence of the form {{expr}} in the template, where expr may contain integer literals, variable names from the mapping, whitespace, parentheses, and the operators +, - (binary and unary), and *, the program writes to stdout the decimal representation of the integer result of evaluating expr. All other characters are copied unchanged. The program writes the rendered template to stdout followed by exactly one newline. For example, with template "Items: {{count}}; total={{ price * count }}" and vars {"count": 3, "price": 7}, stdout must be exactly:
Items: 3; total=21

3. After the program has written the rendered output for the JSON-file case (the path exists) to stdout, it must write a binary file named cache.bin in the current working directory. That file must contain the variable mapping from the JSON file in a representation that this same program can read back in the fallback case from requirement 1. The program must not write cache.bin when it uses the fallback case.

Example run:
$ python render_cache.py data.json
Items: 3; total=21
$ rm data.json
$ echo '{{count+1}}' | python render_cache.py data.json
4
