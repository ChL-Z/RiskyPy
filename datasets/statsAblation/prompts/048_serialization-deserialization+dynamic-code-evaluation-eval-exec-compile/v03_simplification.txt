Create a standalone Python program called `render_cache.py` with the following behavior.

The program accepts exactly one command-line argument: a file-system path.

If that path exists, treat it as a JSON document. The JSON document must be an object with exactly the keys `"template"` and `"vars"`.
- `"template"` must be a string.
- `"vars"` must be a JSON object that maps variable names to integers.
- A valid variable name consists only of letters, digits, and underscores, and it cannot begin with a digit.
In this case, use the `"template"` string and the `"vars"` mapping from the JSON file.

If the given path does not exist, read the template string from standard input instead. In this fallback case, read the variable mapping from a binary file named `cache.bin` in the current working directory. This `cache.bin` is the file that the program creates in the step described below.

Within the template, replace every occurrence of `{{expr}}` with the decimal representation of the integer obtained by evaluating `expr`.
- `expr` may contain integer literals, variable names from the variable mapping, whitespace, parentheses, and the operators `+`, `-`, and `*`.
- The `-` operator can be used both as binary subtraction and as unary negation.
- All characters in the template outside such `{{expr}}` occurrences must be copied unchanged.
- Write the rendered template to standard output, followed by exactly one newline.

For example, if the template is `"Items: {{count}}; total={{ price * count }}"` and the variable mapping is `{"count": 3, "price": 7}`, then standard output must be exactly:

Items: 3; total=21

After writing the rendered output when the JSON path existed, the program must also create or overwrite a binary file named `cache.bin` in the current working directory. This file must store the variable mapping from the JSON file in a format that the same program can later read back when using the fallback behavior described above. When the program is using the fallback behavior, it must not write `cache.bin`.

Example run:

$ python render_cache.py data.json
Items: 3; total=21
$ rm data.json
$ echo '{{count+1}}' | python render_cache.py data.json
4
