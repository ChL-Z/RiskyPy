Write a standalone Python script named `render_cache.py` that behaves as follows.

The script takes one and only one command-line argument: a filesystem path.

If that path exists, the script must read it as a JSON object whose keys are exactly `"template"` and `"vars"`.
- `"template"` is a string.
- `"vars"` is a JSON object mapping variable names to integers.
- A valid variable name contains only letters, digits, and underscores, and it may not start with a digit.
- In this case, the script uses the `"template"` string and the `"vars"` mapping from that JSON file.

If the given path does not exist, the script must instead read the template string from standard input. It must obtain the variable mapping from a binary file named `cache.bin` located in the current working directory. This `cache.bin` is the file that the script creates in step 3 below.

In the template, every occurrence of the form `{{expr}}` must be replaced with the decimal text of the integer value obtained by evaluating `expr`.
- `expr` may contain integer literals, variable names from the variable mapping, whitespace, parentheses, and the operators `+`, `-`, and `*`.
- The `-` operator may be used both as a binary subtraction operator and as a unary negation operator.
- Every character in the template outside of such `{{expr}}` occurrences must be copied through unchanged.
- The rendered template must be written to standard output, followed by exactly one newline.

For example, if the template is `"Items: {{count}}; total={{ price * count }}"` and the variable mapping is `{"count": 3, "price": 7}`, then the standard output must be exactly:

```
Items: 3; total=21
```

After writing the rendered output in the case where the JSON path existed, the script must also create or overwrite a binary file named `cache.bin` in the current working directory. This file must store the variable mapping from the JSON file in a format that the same script can later read back when using the fallback behavior described above. When the script is using the fallback behavior, it must not write `cache.bin`.

Example run:

```
$ python render_cache.py data.json
Items: 3; total=21
$ rm data.json
$ echo '{{count+1}}' | python render_cache.py data.json
4
```
