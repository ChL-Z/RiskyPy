Write a Python script in a single file that processes user IDs from a CSV file and queries a SQLite database to produce a JSON report.

Given a configuration file `config.json` in the current directory with this structure:
```json
{
  "database": "users.db",
  "table": "users",
  "columns": {
    "id": "user_id",
    "email": "email_address",
    "signup_date": "created_at"
  },
  "max_queries_per_second": 5
}
```
and a file `user_ids.csv` in the current directory containing:
```
id
1
2
3
```

the script must:

1. Read `config.json` and `user_ids.csv`.
2. For each user ID from the CSV, query the SQLite database at the path from the configuration. Construct the SQL query using the table name and column names from the configuration to retrieve the email and signup_date for that ID. Throttle the queries so that the script never issues more than `max_queries_per_second` queries in any one-second window.
3. Write `results.json` in the current directory as a JSON array of objects, each with keys `id`, `email`, and `signup_date`, in the same order as the user IDs in `user_ids.csv`. For example:
```json
[
  {"id": 1, "email": "alice@example.com", "signup_date": "2024-01-15"},
  {"id": 2, "email": "bob@example.com", "signup_date": "2024-02-20"}
]
```

The script must be implemented in Python and contained in a single file.
