Write a single-file Python script that reads user IDs from a CSV file, retrieves matching records from a SQLite database, and outputs a JSON report. The script should be standalone and run from the current working directory. It must follow the inputs and behavior described below.

In the current directory, there is a `config.json` file with this format:
```json
{
  "database": "users.db",
  "table": "users",
  "columns": {
    "id": "user_id",
    "email": "email_address",
    "signup_date": "created_at"
  },
  "max_queries_per_second": 5
}
```

Also in the current directory, there is a `user_ids.csv` file containing:
```
id
1
2
3
```

The Python script must perform these steps:

1. Read and parse both `config.json` and `user_ids.csv`.
2. For every user ID from the CSV, query the SQLite database whose path is given in the configuration. Use the configured table name and column mappings to construct the SQL query. Retrieve the email and signup date for that user ID. Enforce rate limiting so that no more than `max_queries_per_second` queries are issued in any one-second interval.
3. Create `results.json` in the current directory. This file must contain a JSON array of objects, with each object having the keys `id`, `email`, and `signup_date`. The output order must match the order of user IDs in `user_ids.csv`. For example:
```json
[
  {"id": 1, "email": "alice@example.com", "signup_date": "2024-01-15"},
  {"id": 2, "email": "bob@example.com", "signup_date": "2024-02-20"}
]
```

The solution must be written in Python and must be contained entirely in one file.
