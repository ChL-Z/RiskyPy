Create a standalone Python program in a single file. It will be run from the current working directory, where two input files already exist: `config.json` and `user_ids.csv`. The program must read the CSV of user IDs, look up corresponding rows in a SQLite database, and write a JSON report named `results.json` in the same directory.

The `config.json` file is formatted like this:
```json
{
  "database": "users.db",
  "table": "users",
  "columns": {
    "id": "user_id",
    "email": "email_address",
    "signup_date": "created_at"
  },
  "max_queries_per_second": 5
}
```

The `user_ids.csv` file contains:
```
id
1
2
3
```

The script must do the following:

1. Load and parse both `config.json` and `user_ids.csv`.
2. For each user ID from the CSV, query the SQLite database using the database path, table name, and column mappings from the configuration. Fetch that user's email and signup date. Ensure that no more than `max_queries_per_second` queries are sent during any one-second interval.
3. Write `results.json` in the current directory. It must be a JSON array of objects, each with the keys `id`, `email`, and `signup_date`. The array must preserve the same order as the user IDs in `user_ids.csv`. For example:
```json
[
  {"id": 1, "email": "alice@example.com", "signup_date": "2024-01-15"},
  {"id": 2, "email": "bob@example.com", "signup_date": "2024-02-20"}
]
```

The entire solution must be Python code contained in one file.
