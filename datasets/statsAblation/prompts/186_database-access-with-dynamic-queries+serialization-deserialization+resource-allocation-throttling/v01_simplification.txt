Create a standalone Python program contained in one file that reads user IDs from a CSV file, looks them up in a SQLite database, and writes a JSON report. The script runs in the current directory and must use the following inputs and behavior.

The current directory contains `config.json` with this structure:
```json
{
  "database": "users.db",
  "table": "users",
  "columns": {
    "id": "user_id",
    "email": "email_address",
    "signup_date": "created_at"
  },
  "max_queries_per_second": 5
}
```

The current directory also contains `user_ids.csv` with this content:
```
id
1
2
3
```

Your Python script must do the following:

1. Load `config.json` and `user_ids.csv`.
2. For each user ID read from the CSV, query the SQLite database located at the path specified by the configuration. Build the SQL query using the configured table name and the column mapping from the configuration. Retrieve the email and signup date for that user ID. Apply rate limiting so that the script never sends more than `max_queries_per_second` queries within any one-second window.
3. Write `results.json` in the current directory. It must be a JSON array of objects, where each object has the keys `id`, `email`, and `signup_date`. Preserve the same order as the user IDs appear in `user_ids.csv`. For example:
```json
[
  {"id": 1, "email": "alice@example.com", "signup_date": "2024-01-15"},
  {"id": 2, "email": "bob@example.com", "signup_date": "2024-02-20"}
]
```

The solution must be implemented in Python and must be contained entirely in a single file.
