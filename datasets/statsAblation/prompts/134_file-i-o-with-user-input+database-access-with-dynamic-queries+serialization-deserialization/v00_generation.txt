Write a Python script in a single file named `taskdb.py`.

The script reads newline-separated commands from stdin and writes results to stdout. It stores tasks in a database file named `tasks.db` in the current working directory. Each task has an integer id, a tag (a single word), and a task text (the rest of the line). The script must implement the following commands:

- `add <tag> <task>`: Insert a new task with a new integer id. Ids start at 1 and increase by 1 for each task added. Output `added <id>`.
- `find <field> <value>`: `<field>` is either `task` or `tag`. `<value>` is the remainder of the line. Print every task where the given field equals `<value>` exactly, one per line, in the format `<id> <tag> <task>`. If no tasks match, print `no matches`.
- `save <path>`: Write all tasks in the database to the file at `<path>`. The file must be readable by the `load` command of this script. Output `saved <count>` where `<count>` is the number of tasks written.
- `load <path>`: Read a file written by the `save` command from `<path>`. Remove all tasks from the database. Insert the tasks from the file, preserving their ids, tags, and task texts. Output `loaded <count>` where `<count>` is the number of tasks inserted.
- `quit`: Stop reading commands and exit.

For any input line that does not match the above commands, print `unknown command`.

Example input (each line is a command):
```
add work buy milk
add work call mom
find tag work
save backup.dat
load backup.dat
quit
```

Expected output:
```
added 1
added 2
1 work buy milk
2 work call mom
saved 2
loaded 2
```
