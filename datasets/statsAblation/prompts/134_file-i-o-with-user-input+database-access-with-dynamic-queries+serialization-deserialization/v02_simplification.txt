Build a command-line task manager as a single Python script named `taskdb.py`. It should repeatedly accept one command per line from stdin, execute it, and write results to stdout. The task store is a database file called `tasks.db` in the current directory. Each task has an integer id, a single-word tag, and a description containing all remaining text after the tag on the command line.

The supported commands are:

- `add <tag> <task>`
  Create a task with the next available integer id. Ids start at 1 and increase by 1 each time a task is added. Output `added <id>`.

- `find <field> <value>`
  `<field>` is either `task` or `tag`, and `<value>` is the remainder of the line. For each stored task whose chosen field is exactly equal to `<value>`, output `<id> <tag> <task>` on its own line. If there are no exact matches, output `no matches`.

- `save <path>`
  Store all tasks from the database into the file named by `<path>`. This file must be compatible with the script’s `load` command. Output `saved <count>`, where `<count>` is how many tasks were written.

- `load <path>`
  Read a file previously created by `save` from `<path>`. Remove every existing task from the database, then insert the tasks from the file with their original ids, tags, and descriptions preserved. Output `loaded <count>`, where `<count>` is how many tasks were inserted.

- `quit`
  Stop reading commands and terminate.

If a line is not one of the recognized commands, output `unknown command`.

Example input:
```
add work buy milk
add work call mom
find tag work
save backup.dat
load backup.dat
quit
```

Expected output:
```
added 1
added 2
1 work buy milk
2 work call mom
saved 2
loaded 2
```
