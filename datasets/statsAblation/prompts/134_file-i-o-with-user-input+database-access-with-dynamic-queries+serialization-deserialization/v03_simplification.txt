Write a single Python script named `taskdb.py` that works as a command-line task manager. It should read one command per line from standard input in a loop, run each command, and print the result to standard output. Tasks are stored in a database file named `tasks.db` in the current working directory. Each task has an integer ID, a one-word tag, and a description consisting of everything left on the command line after the tag.

The commands are:

- `add <tag> <task>`
  Add a task using the next available integer ID. IDs begin at 1 and increment by 1 for each added task. Print `added <id>`.

- `find <field> <value>`
  `<field>` must be either `task` or `tag`, and `<value>` is the rest of the line. For every stored task whose selected field exactly matches `<value>`, print `<id> <tag> <task>` on its own line. If there are no exact matches, print `no matches`.

- `save <path>`
  Write all tasks from the database to the file specified by `<path>`. The file must be readable by the `load` command. Print `saved <count>`, where `<count>` is the number of tasks written.

- `load <path>`
  Read a file previously created by `save` from `<path>`. Delete all existing tasks from the database, then insert the tasks from the file with their original IDs, tags, and descriptions preserved. Print `loaded <count>`, where `<count>` is the number of tasks inserted.

- `quit`
  Stop reading commands and exit.

If a line is not one of the recognized commands, print `unknown command`.

Example input:
```
add work buy milk
add work call mom
find tag work
save backup.dat
load backup.dat
quit
```

Expected output:
```
added 1
added 2
1 work buy milk
2 work call mom
saved 2
loaded 2
```
