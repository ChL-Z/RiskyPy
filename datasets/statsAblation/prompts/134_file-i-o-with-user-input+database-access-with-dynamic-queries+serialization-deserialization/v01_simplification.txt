Create a single-file Python program called `taskdb.py`.

The program should continuously read commands from standard input, one per line, and print their results to standard output. It must keep tasks in a database file named `tasks.db` in the current working directory. Every task consists of an integer id, a one-word tag, and a task description (everything after the tag on the command line).

Implement these commands:

- `add <tag> <task>`
  Add a new task, assigning it the next integer id. Ids begin at 1 and increment by 1 for each added task. Print `added <id>`.

- `find <field> <value>`
  `<field>` must be either `task` or `tag`. `<value>` is the rest of the line. For every stored task whose selected field exactly equals `<value>`, print the task as `<id> <tag> <task>`, one per line. If nothing matches, print `no matches`.

- `save <path>`
  Write all tasks in the database to the file at `<path>`. The resulting file must be loadable by this same script's `load` command. Print `saved <count>`, where `<count>` is the number of tasks written.

- `load <path>`
  Read a file previously produced by the `save` command from `<path>`. Delete all existing tasks from the database, then insert the tasks from the file while keeping their original ids, tags, and task texts. Print `loaded <count>`, where `<count>` is the number of tasks inserted.

- `quit`
  Stop processing commands and exit.

If an input line does not match any of the above commands, print `unknown command`.

Example input:
```
add work buy milk
add work call mom
find tag work
save backup.dat
load backup.dat
quit
```

Expected output:
```
added 1
added 2
1 work buy milk
2 work call mom
saved 2
loaded 2
```
