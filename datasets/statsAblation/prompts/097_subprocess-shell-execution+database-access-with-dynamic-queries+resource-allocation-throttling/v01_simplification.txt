Create one Python file called `jobrunner.py`. It should be a command-line utility that runs jobs stored in a SQLite database named `jobs.db`, located in the current working directory. The database has a `jobs` table with these columns: `id` (integer), `command` (text), `status` (text), `output` (text), and `timeout_seconds` (integer).

The tool is run like this:

`python jobrunner.py --limit N [column=value ...]`

`--limit N` is mandatory. It sets the maximum number of commands allowed to run concurrently. Every other argument is a filter written as `column=value`; split each filter at the first `=` character.

Implement the following behavior:

1. Query the `jobs` table for rows that match all provided filters. If no filters are provided, select every row. The query must use the state of `jobs.db` as it exists when the program starts.

2. For every selected row, run the text in its `command` column as an external shell command line. No more than `--limit` commands may run at the same time. For each command, capture its exit code, stdout, and stderr. If a command exceeds its row's `timeout_seconds`, stop it and treat its result as a nonzero exit code.

3. Once a command has completed or been stopped, update that row in `jobs`: set `status` to `success` when the exit code is 0, otherwise set it to `failed`; set `output` to the captured stdout followed by the captured stderr. The program should terminate only after all selected rows have been updated.

Example: `python jobrunner.py --limit 2 status=pending` should find all rows whose `status` is `pending`, execute at most two of their commands concurrently, and write each command's result back into `jobs.db`.
