Write a Python program in a single file named `jobrunner.py`. The program is a command-line tool that executes jobs recorded in a SQLite database file named `jobs.db` in the current working directory. The database contains a table `jobs` with columns `id` (integer), `command` (text), `status` (text), `output` (text), and `timeout_seconds` (integer). The program is invoked as:

`python jobrunner.py --limit N [column=value ...]`

`--limit N` is required and specifies the maximum number of commands that may run at the same time. Each remaining argument is a filter of the form `column=value`, split at the first `=`.

The program must meet these requirements:

1. Select rows from `jobs` whose column values match every filter argument. When no filter arguments are given, select all rows. The selection must reflect the contents of `jobs.db` at the moment the program starts.

2. Execute the text in each selected row's `command` column as an external command line. Run at most `--limit` commands concurrently. Capture each command's exit code, stdout, and stderr. If a command does not finish within its row's `timeout_seconds`, stop that command and treat it as having a nonzero exit code.

3. After each command finishes or is stopped, update its row in `jobs`: set `status` to `success` if the exit code is 0, otherwise `failed`; set `output` to the captured stdout followed by the captured stderr. The program exits after all selected rows have been updated.

Example: `python jobrunner.py --limit 2 status=pending` selects all rows where `status` is `pending`, runs at most two of their commands at the same time, and writes each command's result back to `jobs.db`.
