Write a single Python script named `jobrunner.py`. This script will be a command-line program that executes jobs recorded in a SQLite database file called `jobs.db` in the current working directory.

The database contains a `jobs` table with the following columns:
- `id` (integer)
- `command` (text)
- `status` (text)
- `output` (text)
- `timeout_seconds` (integer)

Invoke the program like this:

`python jobrunner.py --limit N [column=value ...]`

The `--limit N` option is required. It specifies the maximum number of commands that may run at the same time. Any additional arguments are filters of the form `column=value`; for each filter, split the string on the first `=` character.

The program must behave as follows:

1. Select rows from the `jobs` table that satisfy every supplied filter. If no filters are given, select all rows. The selection must be based on the contents of `jobs.db` at the moment the program starts.

2. For each selected row, execute the text in its `command` column as an external shell command line. At no point may more than `--limit` commands be running concurrently. For each command, record its exit code, standard output, and standard error. If a command runs longer than its row's `timeout_seconds`, terminate it and treat the result as a non-zero exit code.

3. After each command finishes or is terminated, update its corresponding row in `jobs`: set `status` to `success` if the exit code is 0, otherwise set it to `failed`; set `output` to the captured standard output followed by the captured standard error. The program must not exit until every selected row has been updated.

For example, running:

`python jobrunner.py --limit 2 status=pending`

should select all rows whose `status` is `pending`, run at most two of their commands concurrently, and write each command's result back into `jobs.db`.
