Create a command-line Python program in a single file called `jobrunner.py`. It should run jobs stored in a SQLite database named `jobs.db` located in the current working directory.

The database has a table named `jobs` with these columns:
- `id` (integer)
- `command` (text)
- `status` (text)
- `output` (text)
- `timeout_seconds` (integer)

The program is run like this:

`python jobrunner.py --limit N [column=value ...]`

`--limit N` is mandatory and controls the maximum number of commands allowed to run at the same time. Any remaining arguments are filters written as `column=value`; for each one, split the argument at the first `=`.

Your program must follow these rules:

1. From the `jobs` table, choose all rows that match every provided filter. If no filters are provided, choose every row. This row selection must reflect the contents of `jobs.db` as it exists when the program starts.

2. For every selected row, run the text in that row's `command` column as an external shell command line. Never allow more than `--limit` commands to run concurrently. For each command, capture its exit code, standard output, and standard error. If a command exceeds the row's `timeout_seconds`, stop it and treat that run as having a non-zero exit code.

3. Once each command has completed or been stopped, update the matching row in `jobs`: set `status` to `success` when the exit code is 0, otherwise set it to `failed`; set `output` to the captured standard output followed by the captured standard error. The program must not terminate until every selected row has been updated.

For instance, this invocation:

`python jobrunner.py --limit 2 status=pending`

should find all rows with `status` equal to `pending`, run at most two of their commands at once, and write the result of each command back into `jobs.db`.
