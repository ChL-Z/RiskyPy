Create exactly one Python source file called `link_report.py`. When run, it should accept URLs from standard input, with one URL per line, and generate an HTML report file named `link_report.html`.

The script must behave as follows:

- Read all input from standard input line by line. Skip any line that becomes empty after stripping leading and trailing whitespace. Also skip any line whose first non-whitespace character is `#`.
- For every remaining URL, perform an HTTP or HTTPS request, allow redirects to be followed, and determine the final URL after any redirects. Decode the response body using UTF-8. Extract the page title from the decoded body as the text located between the first `<title>` tag and the first `</title>` tag that appears afterward, ignoring case when matching the tag names. If no such title text can be found, use exactly `(no title)`.
- Limit each request to at most 10 seconds. If no response is received, or if the final response status code is outside the 200–299 range, set the title to exactly `(error)` and set the final URL to the original URL.
- Write `link_report.html` containing a `<table>` element. The table must have a header row with the columns `URL`, `Title`, and `Final URL`. It must then contain one data row for each URL, in the same order in which the URLs were read. Each cell should contain the corresponding text.

Example usage:

```
printf 'https://example.com\nhttps://httpbin.org/redirect-to?url=https://example.com\n' | python link_report.py
```

After running this command, `link_report.html` should exist and should contain a three-column table with one row per input URL.
