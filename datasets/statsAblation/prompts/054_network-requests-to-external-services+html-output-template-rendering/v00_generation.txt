Write a single Python file named `link_report.py` that reads newline-separated URLs from standard input and writes an HTML report to `link_report.html`.

The program must:

- Read URLs from standard input, one per line. Ignore lines that are empty after removing leading and trailing spaces. Ignore lines whose first non-space character is `#`.
- For each URL, request it over HTTP or HTTPS, follow redirects, and record the final URL after redirects. Decode the response body as UTF-8. Determine the page title as the text between the first `<title>` and the first following `</title>` in the decoded body, matching the tag names without regard to letter case. If that text is absent, use the exact text `(no title)`. Wait at most 10 seconds for each request. If no response is received or the final response status code is not in the range 200 through 299, use `(error)` for the title and the original URL for the final URL.
- Write `link_report.html` containing a `<table>` element with a header row `URL`, `Title`, `Final URL`, and one data row for each URL in the order read. Each cell must contain the corresponding text.

Example usage:

```
printf 'https://example.com\nhttps://httpbin.org/redirect-to?url=https://example.com\n' | python link_report.py
```

After this command, `link_report.html` exists and contains a three-column table with one row for each input URL.
