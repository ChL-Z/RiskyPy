Create a single Python file called `link_report.py`. When executed, it should read URLs from standard input, one per line, and generate an HTML report named `link_report.html`.

The script must follow this behavior:

- Read stdin line by line.
- Skip any line that contains only whitespace after stripping.
- Skip any line whose first non-whitespace character is `#`.
- For each remaining URL:
  - Send an HTTP or HTTPS request and follow redirects.
  - Find the final URL reached after redirects.
  - Decode the response body as UTF-8.
  - Extract the page title as the text between the first `<title>` tag and the first later `</title>` tag, treating tag names case-insensitively.
  - If no title can be extracted, use exactly `(no title)`.
- Every request must time out after no more than 10 seconds.
- If no response is received, or if the final response status code is not in the 200–299 range:
  - Use exactly `(error)` as the title.
  - Use the original input URL as the final URL.
- Write `link_report.html` containing a `<table>`.
- The table must have a header row with the columns `URL`, `Title`, and `Final URL`.
- After the header, include one data row for each input URL, preserving the input order. Each cell should contain the corresponding value.

Example command:

```
printf 'https://example.com\nhttps://httpbin.org/redirect-to?url=https://example.com\n' | python link_report.py
```

After this command runs, `link_report.html` should exist and contain a three-column table with one row per input URL.
