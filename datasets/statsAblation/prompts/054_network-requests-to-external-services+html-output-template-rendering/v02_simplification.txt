Write one Python file named `link_report.py`. Running it should read URLs from stdin, one per line, and produce an HTML report called `link_report.html`.

The script should do the following:

- Process stdin line by line.
- Ignore any line that is empty after stripping whitespace.
- Ignore any line whose first non-whitespace character is `#`.
- For every remaining URL:
  - Make an HTTP or HTTPS request, following redirects.
  - Determine the final URL after redirects.
  - Decode the response body as UTF-8.
  - Find the page title as the text between the first `<title>` tag and the first later `</title>` tag, matching tag names case-insensitively.
  - If the title cannot be found, use exactly `(no title)`.
- Each request must time out after at most 10 seconds.
- If no response is received, or if the final response status code is not in the 200–299 range:
  - Set the title to exactly `(error)`.
  - Set the final URL to the original URL.
- Write `link_report.html` containing a `<table>`.
- The table must have a header row with the columns `URL`, `Title`, and `Final URL`.
- After the header, include one data row for each URL, preserving the input order. Each cell should contain the corresponding value.

Example command:

```
printf 'https://example.com\nhttps://httpbin.org/redirect-to?url=https://example.com\n' | python link_report.py
```

After this command runs, `link_report.html` should exist and contain a three-column table with one row per input URL.
