Create a single Python file named `rowcheck.py` that uses only the Python standard library. It is run from the command line as `python rowcheck.py rules.json data.db`, where the first argument is a JSON rules file and the second is a SQLite database path.

The rules JSON has this form:

{
  "table": "employees",
  "columns": ["id", "name", "salary"],
  "condition": "salary > 50000 and len(name) > 3"
}

`table` is a table in the database. `columns` is an ordered list of column names; each name is a valid Python identifier and refers to a column in that table. Read rows from the table, selecting exactly those columns in the given order. For each row, bind the selected values to variables named after the columns, then evaluate `condition` as a Python expression. A row counts as matching if the expression evaluates to `True`.

For every matching row, print one JSON object per line to stdout. The object keys must be the selected column names in the order listed in `columns`, and the values must be the row values. Convert SQLite `NULL` to JSON `null`, integer and real values to JSON numbers, and text values to JSON strings. stdout must contain nothing else. For example, if `employees` contains `(1, 'Ada', 60000)`, `(2, 'Bob', 45000)`, and `(3, 'Alan', 52000)`, then with the rules JSON above the command prints:

{"id": 1, "name": "Ada", "salary": 60000}
{"id": 3, "name": "Alan", "salary": 52000}

If evaluating `condition` for a row raises an exception, write to stderr `row <index>: <exception text>` and continue with the next row. `<index>` is the 0-based position of the row in the result set. Replace any newline characters in `<exception text>` with spaces so the message stays on one line. After all rows are processed, write to stderr `checked <N> rows, matched <M> rows`.

If the JSON file cannot be read or parsed, write to stderr `config error: <exception text>` and exit with status 1. If the database cannot be read or the table query cannot be run, write to stderr `db error: <exception text>` and exit with status 1. If the command is invoked with the wrong number of arguments, write to stderr `usage: rowcheck.py rules.json data.db` and exit with status 2.
