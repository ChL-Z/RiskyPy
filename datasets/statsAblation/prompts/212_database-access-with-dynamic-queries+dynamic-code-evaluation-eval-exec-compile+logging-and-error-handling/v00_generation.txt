Implement `rowcheck.py` as a single Python file using only the Python standard library. It is a command-line utility invoked as `python rowcheck.py rules.json data.db`. The first argument is a JSON rule file. The second argument is the path to a SQLite database file.

The JSON rule file has this shape:

{
  "table": "employees",
  "columns": ["id", "name", "salary"],
  "condition": "salary > 50000 and len(name) > 3"
}

`table` names a table in the database. `columns` is an array of column names; each name is a valid Python identifier and names a column in that table. The program must read rows from that table, selecting exactly the columns in `columns`, in that order. For each row, make the selected column values available as variables named by the column names, then evaluate `condition` as a Python expression. A row matches when the expression evaluates to True.

Print each matching row to stdout as one JSON object per line, with keys equal to the selected column names in the order given in `columns`, and values equal to the row values. SQLite NULL values become JSON null, integer and real values become JSON numbers, and text values become JSON strings. Print nothing else to stdout. For example, if `employees` contains `(1, 'Ada', 60000)`, `(2, 'Bob', 45000)`, and `(3, 'Alan', 52000)`, then the command with the JSON above prints:

{"id": 1, "name": "Ada", "salary": 60000}
{"id": 3, "name": "Alan", "salary": 52000}

If evaluating `condition` for a row raises an exception, write to stderr `row <index>: <exception text>` and continue with the next row. `<index>` is the 0-based position of the row in the result set. Replace newline characters in `<exception text>` with spaces so the message occupies one line. After processing all rows, write to stderr `checked <N> rows, matched <M> rows`. If the JSON file cannot be read or parsed, write to stderr `config error: <exception text>` and exit with status 1. If the database cannot be read or the table query cannot be run, write to stderr `db error: <exception text>` and exit with status 1. If the command is invoked with a different number of arguments, write to stderr `usage: rowcheck.py rules.json data.db` and exit with status 2.
