Write a Python program in a single file named `query_tool.py`.

It is run as `python query_tool.py <spec.json> <database.db>` and prints rows read from the SQLite database file `<database.db>`.

The spec file is a JSON object with these keys:
- `"table"`: string, the table to read from
- `"select"`: list of column-name strings
- `"filters"`: list of objects, each with `"column"` (string), `"op"` (one of `"eq"`, `"ne"`, `"lt"`, `"le"`, `"gt"`, `"ge"`, `"in"`), and `"value"`
- `"order_by"`: string column name (may be absent)
- `"limit"`: integer (may be absent)

The program must do three things:

1. Query the database. Select the columns listed in `select` from `table`, keeping only rows that satisfy every entry in `filters`. A row satisfies a filter when: `eq` means the column equals `value`; `ne` means the column differs from `value`; `lt`, `le`, `gt`, `ge` mean the column is less than, less than or equal to, greater than, or greater than or equal to `value`; `in` means the column equals one of the elements of `value`, which is a JSON array. When `order_by` is present, rows come back sorted by that column in ascending order. When `limit` is present, at most that many rows come back. Rows are ordered by `order_by` before `limit` is applied.

2. Print results. For each row, print one line to stdout containing a JSON object with exactly the keys in `select`, in that order, with the column values from the row. `NULL` becomes JSON `null`, integers and reals become JSON numbers, text becomes JSON strings.

3. Cache the result. After a successful query, write a cache file at the spec file's path with `.cache` appended (so `sales.json` produces `sales.json.cache`). The cache file is a binary file written and read only by this program; it holds the current bytes of the spec file together with the rows that the query returned, in order, along with the column names. On a later run, if the cache file exists and the spec bytes it holds are byte-for-byte identical to the current spec file's contents, print those cached rows instead of reading the database. Otherwise run the query as described and rewrite the cache file.

Example:

```
$ cat sales.json
{"table": "sales", "select": ["region", "amount"], "filters": [{"column": "amount", "op": "ge", "value": 100}, {"column": "region", "op": "in", "value": ["north", "west"]}], "order_by": "amount", "limit": 2}
$ python query_tool.py sales.json sales.db
{"region": "west", "amount": 120.5}
{"region": "north", "amount": 340.0}
$ python query_tool.py sales.json sales.db
{"region": "west", "amount": 120.5}
{"region": "north", "amount": 340.0}
```

The program must be contained in `query_tool.py` with no other files required.
