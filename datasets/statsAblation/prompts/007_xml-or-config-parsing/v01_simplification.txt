Create a single Python file called `service_env_export.py`. It must accept exactly one command-line argument: the path to an XML configuration file. The XML file has a root element `<config>`, which may contain any number of `<service>` elements. Each `<service>` has a `name` attribute and may contain any number of `<env>` elements and any number of `<include>` elements. An `<env>` element has `key` and `value` attributes. An `<include>` element has a `file` attribute pointing to another XML file. That included XML file has a root `<envs>` element, which may contain any number of `<env>` elements with `key` and `value` attributes. The program should print one line to stdout for every `<env>` encountered, in document order, with each `<include>` replaced at its position by the `<env>` elements from the included file. Each printed line must use the format `<service-name>.<key>=<value>`, where `<service-name>` comes from the enclosing `<service>` and `<key>` and `<value>` come from the `<env>`. The path given in an `<include>`'s `file` attribute must be resolved relative to the directory of the XML file that contains that `<include>`. If no command-line argument is provided, print nothing and exit with status code 1. Example: `main.xml` contains `<config><service name="api"><env key="LOG_LEVEL" value="debug"/><include file="shared.xml"/></service><service name="web"><env key="PORT" value="80"/></service></config>` and `shared.xml` contains `<envs><env key="REGION" value="us-east-1"/><env key="TIMEOUT" value="30"/></envs>`. Running `python service_env_export.py main.xml` should print: `api.LOG_LEVEL=debug`, `api.REGION=us-east-1`, `api.TIMEOUT=30`, `web.PORT=80`.
