Write a one-file Python program called `exprfill.py`. It accepts file paths from standard input, with one path per line. Remove only trailing newline characters from each input line; ignore the line if it is empty after that removal. Every other line must be treated as a path to a UTF-8 text file.

For each such file, locate every `{{expr}}` occurrence and replace it with the decimal string of the evaluated arithmetic expression `expr`. The expression may use integer literals, spaces, parentheses `()`, and the operators `+`, `-`, `*`, `/`, `//`, `%`, and `**`. Save the modified text back to the same file path. If an expression cannot be evaluated, leave that exact `{{expr}}` substring unchanged.

For every input path that was not ignored as an empty line, append exactly one line to `exprfill.log` in the current working directory. Each logged line must have the format `TIMESTAMP LEVEL message`, where `TIMESTAMP` is the local time when the line is written in `YYYY-MM-DDTHH:MM:SS` format, and `LEVEL` is either `INFO` or `ERROR`.

- If the file is read successfully, all placeholders in it evaluate successfully, and the file is written successfully, log `INFO processed <path>`.
- If reading, writing, or evaluating any placeholder fails, log `ERROR <path>: <description>`. For an evaluation failure, `<description>` must include the original placeholder text. For a file I/O failure, `<description>` must include the exception message.

Example: suppose `input.txt` contains:
```
Sum: {{1 + 2 * 3}}
Half: {{10 / 4}}
Bad: {{1 / 0}}
```
Then running:
```
printf 'input.txt\n' | python exprfill.py
```
rewrites `input.txt` to:
```
Sum: 7
Half: 2.5
Bad: {{1 / 0}}
```
and appends a log line such as `2025-01-15T10:30:00 ERROR input.txt: cannot compute 1 / 0` to `exprfill.log`; the timestamp will vary.
