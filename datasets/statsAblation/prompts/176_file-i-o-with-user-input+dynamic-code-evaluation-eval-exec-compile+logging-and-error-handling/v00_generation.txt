Write a Python program in a single file named `exprfill.py`. The program reads newline-separated file paths from standard input. For each line, if the line is empty after stripping trailing newline characters, skip it. Otherwise, treat the line as a path to a UTF-8 encoded text file.

For each such file, replace every occurrence of `{{expr}}` where `expr` consists of integer literals, the operators `+`, `-`, `*`, `/`, `//`, `%`, `**`, parentheses `()`, and spaces, with the decimal string of the computed result of that arithmetic expression. Write the resulting text back to the same file path. If an `expr` cannot be computed, leave the exact `{{expr}}` substring unchanged in the file.

Append one line to `exprfill.log` in the current working directory for each file path read from standard input (excluding empty lines). Each log line has the format `TIMESTAMP LEVEL message`, where `TIMESTAMP` is the local time when the line is written in `YYYY-MM-DDTHH:MM:SS` format, and `LEVEL` is `INFO` or `ERROR`. For a file path that is successfully read, has all its placeholders computed, and is successfully written, append `INFO processed <path>`. For a file path where reading, writing, or computing any placeholder fails, append `ERROR <path>: <description>` where `<description>` is a string that includes the original placeholder text for a computation failure, or the exception message for a file I/O failure.

Example: given `input.txt` containing:
```
Sum: {{1 + 2 * 3}}
Half: {{10 / 4}}
Bad: {{1 / 0}}
```
Running `printf 'input.txt\n' | python exprfill.py` rewrites `input.txt` to:
```
Sum: 7
Half: 2.5
Bad: {{1 / 0}}
```
and appends a log line such as `2025-01-15T10:30:00 ERROR input.txt: cannot compute 1 / 0` to `exprfill.log` (the timestamp varies).
