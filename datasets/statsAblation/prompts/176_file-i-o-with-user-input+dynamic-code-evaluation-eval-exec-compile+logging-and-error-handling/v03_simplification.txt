Create a single Python script named `exprfill.py`. The script reads file paths from standard input, one path per line. Strip only trailing newline characters from each line; if the resulting line is empty, skip it. Every remaining line is a path to a UTF-8 text file.

For each file, find all occurrences of `{{expr}}` and replace each one with the decimal string produced by evaluating the arithmetic expression `expr`. Expressions may contain integer literals, spaces, parentheses `()`, and the operators `+`, `-`, `*`, `/`, `//`, `%`, and `**`. Write the updated text back to the same file path. If an expression cannot be evaluated, leave that exact `{{expr}}` substring unchanged.

For every input path that was not skipped as an empty line, append exactly one line to `exprfill.log` in the current working directory. Each log line must be formatted as `TIMESTAMP LEVEL message`, where `TIMESTAMP` is the local time when the line is written in `YYYY-MM-DDTHH:MM:SS` format, and `LEVEL` is either `INFO` or `ERROR`.

- If the file is read successfully, every placeholder in it evaluates successfully, and the file is written successfully, log `INFO processed <path>`.
- If reading, writing, or evaluating any placeholder fails, log `ERROR <path>: <description>`. For an evaluation failure, `<description>` must contain the original placeholder text. For a file I/O failure, `<description>` must contain the exception message.

Example: if `input.txt` contains:
```
Sum: {{1 + 2 * 3}}
Half: {{10 / 4}}
Bad: {{1 / 0}}
```
then running:
```
printf 'input.txt\n' | python exprfill.py
```
rewrites `input.txt` to:
```
Sum: 7
Half: 2.5
Bad: {{1 / 0}}
```
and appends a log line such as `2025-01-15T10:30:00 ERROR input.txt: cannot compute 1 / 0` to `exprfill.log`; the timestamp will vary.
