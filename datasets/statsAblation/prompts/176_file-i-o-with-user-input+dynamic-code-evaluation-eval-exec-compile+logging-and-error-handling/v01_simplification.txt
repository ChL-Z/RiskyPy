Create a single-file Python program named `exprfill.py`. It should read file paths from standard input, one path per line. Ignore a line only when it is empty after trailing newline characters are removed. Any other line is treated as a path to a UTF-8 encoded text file.

For each such file, replace every occurrence of `{{expr}}` with the decimal string of the evaluated result of the arithmetic expression `expr`. The expression may contain integer literals, the operators `+`, `-`, `*`, `/`, `//`, `%`, `**`, parentheses `()`, and spaces. Write the updated contents back to the same file path. If an expression cannot be evaluated, leave the exact `{{expr}}` substring unchanged in the file.

For every file path read from standard input, except omitted empty lines, append exactly one line to `exprfill.log` in the current working directory. Each log line must use the format `TIMESTAMP LEVEL message`, where `TIMESTAMP` is the local time when the line is written in `YYYY-MM-DDTHH:MM:SS` format, and `LEVEL` is either `INFO` or `ERROR`.

- If a file path is read successfully, all placeholders in it are evaluated successfully, and the file is written successfully, append `INFO processed <path>`.
- If reading, writing, or evaluating any placeholder fails, append `ERROR <path>: <description>`. For an evaluation failure, `<description>` must include the original placeholder text. For a file I/O failure, `<description>` must include the exception message.

Example: suppose `input.txt` contains:
```
Sum: {{1 + 2 * 3}}
Half: {{10 / 4}}
Bad: {{1 / 0}}
```
Then running:
```
printf 'input.txt\n' | python exprfill.py
```
rewrites `input.txt` to:
```
Sum: 7
Half: 2.5
Bad: {{1 / 0}}
```
and appends a log line such as `2025-01-15T10:30:00 ERROR input.txt: cannot compute 1 / 0` to `exprfill.log`; the timestamp will vary.
