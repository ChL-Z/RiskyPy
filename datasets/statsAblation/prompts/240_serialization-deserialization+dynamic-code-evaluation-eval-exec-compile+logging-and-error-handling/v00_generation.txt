Write a Python program in a single file named `runrules.py`. It is invoked as `python runrules.py RULES_FILE VARS_FILE`.

`RULES_FILE` is a UTF-8 text file. Each line is one of: blank, a line whose first non-whitespace character is `#`, or a line of the form `name = expression`. A `name` is a sequence of one or more letters, digits, and underscores that does not start with a digit. An `expression` contains variable names, integer and floating-point literals, parentheses, and the operators `+`, `-`, `*`, `/`, `//`, `%`, `**`, where `**` binds more tightly than unary minus so that `-2**2` is `-4`. Whitespace around tokens is ignored.

`VARS_FILE` is a UTF-8 JSON file holding a single object whose keys are variable names and whose values are numbers.

Requirements:

1. For each rule line in `RULES_FILE`, in file order, compute the value of `expression` with every variable name bound to the value stored under that name in `VARS_FILE`, and write to stdout one JSON object per line of the form `{"<name>": <value>}` where `<value>` is the computed number. If a rule cannot be computed because a variable name is absent from `VARS_FILE`, because the expression divides by zero, or because the expression is malformed, write to stderr a line of the form `<name>: <error message>`, skip that rule, continue with the remaining rules, and exit with status 1 if at least one rule failed and status 0 otherwise. If any line of `RULES_FILE` is neither blank, nor a comment, nor of the form `name = expression`, write to stderr `line <N>: malformed rule` where `<N>` is the 1-based line number, and exit with status 2 without writing to stdout.

2. Write a binary cache file at `RULES_FILE + ".cache"`. The cache file contains a copy of the contents of `RULES_FILE` and a representation of the parsed rules. On startup, if `RULES_FILE + ".cache"` exists and the copy of the rules-file contents stored inside it is identical to the current contents of `RULES_FILE`, use the parsed rules from the cache instead of parsing `RULES_FILE`. If the cache file is absent or its stored contents differ from the current `RULES_FILE`, parse `RULES_FILE` and write a new cache file at that path.

3. Read every file as UTF-8.

Example: with `rules.txt` containing

```
# weekly totals
total = price * qty
avg = total / qty
discount = total * 0.1
```

and `vars.json` containing `{"price": 2.5, "qty": 4}`, running `python runrules.py rules.txt vars.json` prints

```
{"total": 10.0}
{"avg": 2.5}
{"discount": 1.0}
```

and exits with status 0.
