Create a single-file Python script called `runplan.py` that runs a series of shell commands defined by a JSON plan file.

Run it like this:

`python runplan.py PLAN.json`

The JSON plan is an object containing:

- `token_file`: a string path to a text file. The token is the complete contents of that file after stripping leading and trailing whitespace.
- `variables`: an object whose keys are names and whose values are integers.
- `steps`: an ordered list of step objects.

Each step object contains:

- `command`: a shell command string to execute.
- `env`: an object mapping environment variable names to string values.

For every step, perform these actions:

1. For each string value in `env`, substitute every occurrence of `{{ expr }}` with the evaluated result of `expr`. Within `{{ }}`, `expr` may contain integer literals, parentheses, the operators `+`, `-`, `*`, `/`, and names. A name may refer either to an entry in `variables` or to `token`. `token` is the token value read from `token_file`. Use integer division for `/`. Convert the evaluation result to a plain decimal string, with no leading or trailing whitespace.
2. Execute the step's `command` with the computed environment variables added on top of the current process environment.
3. Wait for the command to complete. Then print one line to stdout containing the 0-based step index, a single space, and the command's exit code as an integer. Even if the exit code is nonzero, continue with the next step.

Example plan file `plan.json`:

```
{
  "token_file": "secret.txt",
  "variables": {"build": 7, "impl": 2},
  "steps": [
    {"command": "echo starting", "env": {}},
    {"command": "sh -c 'echo token=$TOK; exit 3'", "env": {"TOK": "{{ token }}"}},
    {"command": "sh -c 'echo n=$N'", "env": {"N": "{{ build * impl + 1 }}"}}
  ]
}
```

If `secret.txt` contains `abc123`, then `python runplan.py plan.json` should print, in order:

```
starting
0 0
token=abc123
1 3
n=15
2 0
```

The solution must be contained in one file and may use only the Python standard library.
