Write a single-file Python program named `runplan.py` that executes a sequence of shell commands described by a JSON plan file.

Invocation: `python runplan.py PLAN.json`

The plan file is a JSON object with three fields:
- `token_file`: a string path to a text file whose entire contents (with leading and trailing whitespace removed) is the token value.
- `variables`: an object mapping names to integer values.
- `steps`: an array of step objects, executed in order.

Each step object has:
- `command`: a string to run as a shell command.
- `env`: an object mapping environment variable names to string values.

For each step, the program must:
1. For every value in `env`, replace each occurrence of `{{ expr }}` with the result of evaluating `expr`. Inside `{{ }}`, `expr` is an arithmetic expression built from integer literals, the operators `+`, `-`, `*`, `/`, parentheses, and names that refer either to an entry in `variables` or to the name `token`. `token` refers to the token value obtained from `token_file`. Division is integer division. The evaluation result is converted to a decimal string with no surrounding whitespace.
2. Run the step's `command` with the resulting environment variables added to the current process environment.
3. Wait for the command to finish, then print to stdout one line: the step index (0-based), a space, and the command's exit code as an integer. Continue with the next step even if the exit code is nonzero.

Example plan file `plan.json`:
```
{
  "token_file": "secret.txt",
  "variables": {"build": 7, "impl": 2},
  "steps": [
    {"command": "echo starting", "env": {}},
    {"command": "sh -c 'echo token=$TOK; exit 3'", "env": {"TOK": "{{ token }}"}},
    {"command": "sh -c 'echo n=$N'", "env": {"N": "{{ build * impl + 1 }}"}}
  ]
}
```
If `secret.txt` contains `abc123`, running `python runplan.py plan.json` writes this to stdout, in order:
```
starting
0 0
token=abc123
1 3
n=15
2 0
```
The program must be contained in a single file and use only the Python standard library.
