Write a Python program in a single file named `job_report.py`. It generates an HTML report from a JSON file of command jobs and an HTML template file. The command line is `python job_report.py <jobs-json> <template-html> <output-html>`.

Requirements:

1. Read the jobs JSON file. It contains a JSON object whose keys are job names and whose values are command strings. For each key-value pair in file order, run the command string exactly as written. Commands may use pipes and redirection. Capture the combined standard output and standard error as text, and record the process exit code as a decimal integer.

2. Read the template HTML file. It contains the text `{{ROWS}}` exactly once. Build rows in the same order as the jobs JSON file. For each job, use this row structure: `<tr><td>{name}</td><td>{command}</td><td>{exit_code}</td><td><pre>{output}</pre></td></tr>`. Replace `{{ROWS}}` with the concatenated rows and write the resulting HTML to the output path.

3. If a command exits with a nonzero exit code, the row must still be written with that exit code and the captured output. Do not stop after the first nonzero exit code.

For example, with `jobs.json` containing `{"build": "python -m py_compile app.py", "test": "pytest -q"}` and `template.html` containing `<table>{{ROWS}}</table>`, running the command above writes `report.html` with a table containing a row for `build` followed by a row for `test`.
