Create a single Python source file named `secrets.py` that implements a persistent, encrypted name-to-secret-string map stored in exactly one file. The file path is supplied as the first command-line argument. The encryption passphrase is read from the environment variable `SECRETS_PASSPHRASE`. The program reads newline-delimited commands from stdin and writes results to stdout.

The supported commands are:

- `set <name> <secret>` — Store `<secret>` under `<name>`, replacing any previous value for that name. The line begins with `set`, followed by a space, the name, another space, and then the remainder of the line is the secret. Produce no output.
- `get <name>` — Print the stored secret for `<name>` followed by a newline. If `<name>` has no stored value, print `ERROR: not found` followed by a newline. After all commands have been processed, exit with status 1 if any `get` failed this way.
- `list` — Print all stored names, one per line, ordered by Unicode code point.

The map must survive across runs by being stored in the target file. On startup, if the file exists, load the map using the passphrase. On shutdown, write the map back to the file. The file must allow recovery of the map only when the same passphrase is used. If the wrong passphrase is provided, print `ERROR: bad passphrase` to stdout and exit with status 2, without modifying the file. If the file has been changed after this program wrote it, print `ERROR: file modified` to stdout and exit with status 3.

Example:

```
$ export SECRETS_PASSPHRASE=open-sesame
$ printf 'set email alice@example.com\nset city Paris\nget email\nlist\n' | python secrets.py vault.bin
alice@example.com
city
email
```
