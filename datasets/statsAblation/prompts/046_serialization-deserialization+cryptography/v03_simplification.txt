Write exactly one Python source file called `secrets.py`. It should implement a persistent encrypted mapping from names to secret strings, with all persistent state kept in a single file whose path is given as the first command-line argument.

Read the encryption passphrase from the environment variable `SECRETS_PASSPHRASE`. The program should read newline-delimited commands from stdin and write any results to stdout.

Supported commands:

- `set <name> <secret>`
  Store `<secret>` under `<name>`, overwriting any existing value for that name. The line starts with `set`, then a space, then the name, then another space, and the rest of the line is the secret. Produce no output.

- `get <name>`
  Print the secret stored for `<name>` followed by a newline. If no value is stored for `<name>`, print `ERROR: not found` followed by a newline. After all commands are processed, exit with status 1 if any `get` failed in this way.

- `list`
  Print every stored name, one per line, sorted by Unicode code point.

The map must persist between runs by being stored in the target file. At startup, if the file exists, load the map using the passphrase. At shutdown, write the map back to the file. The file must make the map recoverable only when the same passphrase is used.

If the wrong passphrase is supplied, print `ERROR: bad passphrase` to stdout and exit with status 2, without modifying the file. If the file has been altered after this program wrote it, print `ERROR: file modified` to stdout and exit with status 3.

Example:

```
$ export SECRETS_PASSPHRASE=open-sesame
$ printf 'set email alice@example.com\nset city Paris\nget email\nlist\n' | python secrets.py vault.bin
alice@example.com
city
email
```
