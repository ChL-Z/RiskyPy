Write a Python program in a single file named `secrets.py`. It manages a persistent mapping from names to secret strings in one file. The file path is the first command-line argument. The passphrase is read from the environment variable `SECRETS_PASSPHRASE`. The program reads newline-separated commands from standard input and writes results to standard output.

Commands:
- `set <name> <secret>`: store `<secret>` under `<name>`, replacing any value already stored for that name. The line is the word `set`, one space, the name, one space, and the remainder of the line is the secret. Writes no output.
- `get <name>`: print the stored secret followed by a newline. If `<name>` has no stored value, print `ERROR: not found` followed by a newline and set the process exit status to 1 after all commands have been processed.
- `list`: print all stored names, one per line, sorted by Unicode code point.

The mapping persists in the file between runs. When the program starts, if the file exists, it loads the mapping using the passphrase. When the program exits, it writes the mapping back to the file. The file must only allow recovery of the mapping when the same passphrase is supplied. If a different passphrase is supplied, the program prints `ERROR: bad passphrase` to standard output and exits with status 2 without changing the file. If the file was modified after it was written by this program, the program prints `ERROR: file modified` to standard output and exits with status 3.

Example:

```
$ export SECRETS_PASSPHRASE=open-sesame
$ printf 'set email alice@example.com\nset city Paris\nget email\nlist\n' | python secrets.py vault.bin
alice@example.com
city
email
```
