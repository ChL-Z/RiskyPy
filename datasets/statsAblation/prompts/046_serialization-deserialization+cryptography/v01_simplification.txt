Create a single Python source file called `secrets.py` that maintains a durable encrypted mapping between names and secret strings, stored in one file. The target file is provided as the first command-line argument. The passphrase is taken from the environment variable `SECRETS_PASSPHRASE`. The program processes newline-delimited commands from stdin and sends output to stdout.

Supported commands:

- `set <name> <secret>` — Save `<secret>` under `<name>`, overwriting any existing value for that name. The input line starts with `set`, followed by a space, then the name, then a space, and the rest of the line is the secret. No output is produced.
- `get <name>` — Output the stored secret for `<name>` followed by a newline. If no value is stored for `<name>`, output `ERROR: not found` followed by a newline, and after all commands have been processed, make the process exit with status 1.
- `list` — Output every stored name, one per line, ordered by Unicode code point.

The mapping must persist in the file across runs. On startup, if the file already exists, load the mapping using the passphrase. On shutdown, write the mapping back to the file. The file must only permit recovery of the mapping when the same passphrase is used. If the wrong passphrase is supplied, output `ERROR: bad passphrase` to stdout and exit with status 2, leaving the file unchanged. If the file has been altered after it was written by this program, output `ERROR: file modified` to stdout and exit with status 3.

Example:

```
$ export SECRETS_PASSPHRASE=open-sesame
$ printf 'set email alice@example.com\nset city Paris\nget email\nlist\n' | python secrets.py vault.bin
alice@example.com
city
email
```
