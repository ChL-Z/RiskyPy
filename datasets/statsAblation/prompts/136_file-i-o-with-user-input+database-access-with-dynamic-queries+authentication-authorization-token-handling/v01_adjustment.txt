Write a Python 3 program in one file called `auth_cli.py`. It must read four newline-terminated lines from standard input, in this order:

1. a path to a SQLite database file
2. a username
3. a password
4. a command line

The SQLite database has a single table named `users`, with columns `username TEXT PRIMARY KEY`, `password TEXT NOT NULL`, and `role TEXT NOT NULL`. If the database file from line 1 is absent, create it and populate `users` with exactly these rows: `alice,pw1,admin`, `bob,pw2,user`, and `carol,pw3,user`. If the database file already exists, use its current `users` table and leave it unchanged.

After reading all four lines, find the row in `users` whose `username` matches line 2. If there is no such row, or if its stored `password` is not equal to line 3, print `DENIED` on a single line and terminate with exit status 1.

If the username and password match, handle the command line from line 4:

- For `list`: print every row in `users` as `username role`, one per line, sorted by `username`. This command is allowed only when the authenticated user's `role` is `admin`; otherwise print `FORBIDDEN` on one line and terminate with exit status 2.
- For `list PREFIX`: print every row in `users` whose `username` begins with `PREFIX`, formatted as `username role`, one per line, sorted by `username`. Any authenticated user may run this command.
- For `issue`: print a single token string for the authenticated username. The token must encode that username and an expiration time 600 seconds after the moment `issue` is executed. The same `auth_cli.py` program must later accept and validate this token in a `check` command.
- For `check TOKEN`: take `TOKEN` as the remainder of line 4 after the word `check` and one space. If `TOKEN` encodes the authenticated username, has not expired, and was produced by this program, print `OK username` on one line. Otherwise print `NO` on one line.

After printing the command result, exit with status 0. Do not print any extra lines.

Example: with a new database, `printf 'users.db\nalice\npw1\nlist b\n' | python3 auth_cli.py` prints:
```
bob user
```
