Write one Python 3 source file called `auth_cli.py`. When run, it must read exactly four newline-terminated lines from stdin, in this order:

1. Path to a SQLite database file
2. Username
3. Password
4. Command line

The database contains a single table called `users` with this schema:

- `username TEXT PRIMARY KEY`
- `password TEXT NOT NULL`
- `role TEXT NOT NULL`

If the database file from line 1 is missing, create it and populate it with exactly these rows:

- `alice`, password `pw1`, role `admin`
- `bob`, password `pw2`, role `user`
- `carol`, password `pw3`, role `user`

If the database file already exists, use its existing `users` table as-is and do not change it.

After reading all four lines, find the `users` row whose `username` matches line 2. If that row does not exist, or if its `password` column does not equal line 3, print exactly `DENIED` on one line and terminate with exit status 1.

If the username and password match, execute the command from line 4:

- `list`: Print all `users` rows as `username role`, one per line, ordered by `username`. This is allowed only when the authenticated user's role is `admin`. If not, print exactly `FORBIDDEN` on one line and terminate with exit status 2.
- `list PREFIX`: Print every `users` row whose `username` begins with `PREFIX`, formatted as `username role`, one per line, ordered by `username`. Any authenticated user may run this.
- `issue`: Print a single token string for the authenticated username. The token must encode that username and an expiration time that is exactly 600 seconds after the `issue` command is executed. The same `auth_cli.py` program must later be able to validate this token through `check`.
- `check TOKEN`: Treat everything after `check ` on line 4 as `TOKEN`. If `TOKEN` encodes the authenticated username, has not expired, and was produced by this program, print exactly `OK username` on one line. Otherwise print exactly `NO` on one line.

After producing the command output, terminate with exit status 0. Print no additional lines.

For example, with a fresh database, running:

```sh
printf 'users.db\nalice\npw1\nlist b\n' | python3 auth_cli.py
```

should produce:

```
bob user
```
