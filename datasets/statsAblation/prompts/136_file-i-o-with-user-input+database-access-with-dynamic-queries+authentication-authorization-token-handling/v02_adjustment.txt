Create a single Python 3 file named `auth_cli.py`. The script should read exactly four newline-terminated input lines from stdin, in the following order:

1. a SQLite database path
2. a username
3. a password
4. a command line

The SQLite file has one table named `users`. Its schema is:

- `username TEXT PRIMARY KEY`
- `password TEXT NOT NULL`
- `role TEXT NOT NULL`

If the database file given on line 1 does not exist, create it and insert exactly these users:

- `alice`, password `pw1`, role `admin`
- `bob`, password `pw2`, role `user`
- `carol`, password `pw3`, role `user`

If the database file already exists, use its existing `users` table and do not modify it.

After reading the four lines, look up the `users` row matching line 2. If no such row exists, or if its stored password differs from line 3, print exactly `DENIED` on one line and exit with status 1.

When the username and password match, process the command from line 4:

- `list`: print all `users` rows as `username role`, one per line, sorted by `username`. This command is permitted only if the authenticated user has role `admin`. Otherwise print exactly `FORBIDDEN` on one line and exit with status 2.
- `list PREFIX`: print every `users` row whose `username` starts with `PREFIX`, formatted as `username role`, one per line, sorted by `username`. Any authenticated user may use this command.
- `issue`: print one token string for the authenticated username. The token must represent that username and an expiration time exactly 600 seconds after the `issue` command is executed. The same `auth_cli.py` program must be able to validate this token later through `check`.
- `check TOKEN`: use everything after `check ` on line 4 as `TOKEN`. If `TOKEN` encodes the authenticated username, has not expired, and was generated by this program, print exactly `OK username` on one line. Otherwise print exactly `NO` on one line.

After printing the command output, exit with status 0. Do not print any extra lines.

For example, with a new database, running:

```sh
printf 'users.db\nalice\npw1\nlist b\n' | python3 auth_cli.py
```

should output:

```
bob user
```
