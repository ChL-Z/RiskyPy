Create a Python 3 program in a single file named `auth_cli.py`. It reads exactly four newline-terminated lines from standard input:
1. the path to a SQLite database file
2. a username
3. a password
4. a command line

The database contains one table named `users` with columns `username TEXT PRIMARY KEY`, `password TEXT NOT NULL`, and `role TEXT NOT NULL`. If the file in line 1 does not exist, create it and insert these three rows: `alice,pw1,admin`, `bob,pw2,user`, `carol,pw3,user`. If the file exists, use its existing `users` table without changing it.

After reading the four lines, look up the row in `users` whose `username` equals line 2. If no row exists or its `password` does not equal line 3, print `DENIED` on one line and exit with status 1.

If the username and password match, process the command line from line 4:
- `list` prints every row from `users` as `username role` on its own line, sorted by `username`. Only a matching user whose `role` is `admin` may run this command; otherwise print `FORBIDDEN` on one line and exit with status 2.
- `list PREFIX` prints every row from `users` whose `username` starts with `PREFIX` as `username role` on its own line, sorted by `username`. Any matching user may run this command.
- `issue` prints one token string for the matching username. The token string must encode the username and an expiration time 600 seconds after the moment `issue` runs. The same program must accept this token later in a `check` command.
- `check TOKEN` reads the token from the rest of line 4 after the word `check` and a single space. If `TOKEN` encodes the matching username, has not expired, and was produced by this program, print `OK username` on one line. Otherwise print `NO` on one line.

The program exits with status 0 after printing the command result. Do not print extra lines.

Example: with a new database, `printf 'users.db\nalice\npw1\nlist b\n' | python3 auth_cli.py` prints:
```
bob user
```
