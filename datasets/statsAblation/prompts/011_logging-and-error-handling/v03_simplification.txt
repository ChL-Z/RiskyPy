Create a Python script named `word_count_cache.py` that takes exactly one command-line argument: the path to a text file. The script should count how many times each word occurs, where a word is any token made up only of alphanumeric characters, and case should be ignored. It should then print the top 5 words and their counts to stdout, one per line, in the format `word count`. Results must be sorted by count from highest to lowest; if counts are equal, sort the words alphabetically. If there are fewer than 5 distinct words, print all of them.

The script must also keep a cache file named `word_count.cache` in the same directory as the script. This cache maps each input file's absolute path and last modification time to that file's word-frequency counts. Before counting, the script should check whether the cache already contains an entry matching the input file's absolute path and last modification time. If it does, use the cached counts for output and write exactly `Using cache` to stderr. If it does not, read the input file, compute the counts, add or replace the cache entry while leaving all other entries unchanged, write exactly `Cache updated` to stderr, and then produce the output.

If the input file cannot be read, write exactly `Error: cannot read <path>` to stderr and exit with status 1. If the cache file exists but cannot be read, or if its contents do not match the expected structure, write exactly `Warning: cache could not be used` to stderr, then continue as if the cache were empty: recompute the counts and update the cache.

Example: if `input.txt` contains `Apple banana apple`, then running `python word_count_cache.py input.txt` prints:
```
apple 2
banana 1
```
and writes `Cache updated` to stderr. Running the same command again prints the same output and writes `Using cache` to stderr.
