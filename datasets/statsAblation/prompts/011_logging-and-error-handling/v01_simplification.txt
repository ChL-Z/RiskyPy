Create a Python program named `word_count_cache.py` that takes exactly one command-line argument: the path to a text file. The program should count occurrences of each word made up only of alphanumeric characters, treating uppercase and lowercase letters as the same. It must print the top 5 words and their counts to stdout, one per line, using the format `word count`. The ordering should be by count descending; if counts are equal, order alphabetically. If there are fewer than 5 distinct words, print all of them.

The program must keep a cache file named `word_count.cache` in the same directory as the script. This cache maps each input file's absolute path and last modification time to that file's word frequency counts. Before counting, the program checks whether the cache contains an entry matching the input file's absolute path and last modification time. If it does, the program uses the cached counts for output and writes exactly `Using cache` to stderr. If it does not, the program reads the input file, computes the counts, adds or replaces the cache entry while preserving all other entries, writes exactly `Cache updated` to stderr, and then produces the output.

If the input file cannot be read, the program must write exactly `Error: cannot read <path>` to stderr and exit with status 1. If the cache file exists but cannot be read, or if its contents do not match the expected structure, the program must write exactly `Warning: cache could not be used` to stderr, then continue as though the cache were empty: recompute the counts and update the cache.

Example: if `input.txt` contains `Apple banana apple`, then running `python word_count_cache.py input.txt` prints:
```
apple 2
banana 1
```
and writes `Cache updated` to stderr. Running the same command again prints the same output and writes `Using cache` to stderr.
