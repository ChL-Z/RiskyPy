Write a Python script named `word_count_cache.py` that reads one command-line argument: the path to a text file. The script computes the frequency of each word consisting only of alphanumeric characters, treating uppercase and lowercase letters as equivalent. It prints the top 5 words and their counts to stdout, one per line, in the format `word count`, sorted by count descending, then alphabetically for equal counts. If fewer than 5 distinct words exist, print all of them.

The script maintains a cache file named `word_count.cache` in the same directory as the script. The cache associates each file's absolute path and last modification time with its word frequency counts. Before computing, the script checks the cache for an entry matching the input file's absolute path and last modification time. If found, it uses the cached counts to produce the output and writes exactly `Using cache` to stderr. If not found, it reads the input file, computes the counts, updates the cache with the new entry (keeping all existing entries), writes exactly `Cache updated` to stderr, and produces the output.

If the input file cannot be read, the script writes exactly `Error: cannot read <path>` to stderr and exits with status 1. If the cache file exists but cannot be read or its contents do not match the expected structure, the script writes exactly `Warning: cache could not be used` to stderr, then proceeds as if the cache was empty (i.e., recomputes and updates the cache).

Example: If `input.txt` contains `Apple banana apple`, running `python word_count_cache.py input.txt` prints:
```
apple 2
banana 1
```
and writes `Cache updated` to stderr. Running the same command again prints the same output and writes `Using cache` to stderr.
