Write a Python script named `word_count_cache.py` that accepts exactly one command-line argument: a path to a text file. The script must count how often each word appears, where a word is any token consisting only of alphanumeric characters, and letter case must be ignored. It should then print the top 5 words and their counts to stdout, one per line, in the form `word count`. Sort results by count from highest to lowest; when counts tie, sort the words alphabetically. If there are fewer than 5 distinct words, print all of them.

The script must also maintain a cache file named `word_count.cache` located in the same directory as the script. This cache maps each input file's absolute path together with its last modification time to that file's word-frequency counts. Before counting, the script should check whether the cache already has an entry matching the input file's absolute path and last modification time. If such an entry exists, use the cached counts for output and write exactly `Using cache` to stderr. If it does not exist, read the input file, compute the counts, add or replace the cache entry while keeping all other entries unchanged, write exactly `Cache updated` to stderr, and then produce the output.

If the input file cannot be read, write exactly `Error: cannot read <path>` to stderr and exit with status 1. If the cache file exists but cannot be read, or if its contents do not match the expected structure, write exactly `Warning: cache could not be used` to stderr, then proceed as if the cache were empty: recompute the counts and update the cache.

Example: if `input.txt` contains `Apple banana apple`, then running `python word_count_cache.py input.txt` prints:
```
apple 2
banana 1
```
and writes `Cache updated` to stderr. Running the same command again prints the same output and writes `Using cache` to stderr.
