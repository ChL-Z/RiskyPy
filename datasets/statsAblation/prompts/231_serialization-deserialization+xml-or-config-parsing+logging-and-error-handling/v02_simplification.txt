Create a Python script named `xml_config_to_json.py` that acts as a command-line XML-to-JSON converter. The script receives an XML configuration file path as its first command-line argument, parses that XML, converts it to a JSON object, and writes the JSON to stdout with 2-space indentation and alphabetically sorted keys.

Transformation rules:
- The root `<config>` element is not included in the JSON result.
- Each direct child of `<config>` becomes a top-level key in the JSON output, using the child element's tag name as the key.
- If a direct child has no nested elements, its JSON value is the element's text content with leading and trailing whitespace removed. If it has no text, use an empty string.
- If a direct child has nested elements, its JSON value is an object built recursively from those nested elements. Any text directly inside that child element should be ignored.
- You may assume that no parent element contains more than one child with the same tag name.

Behavior and error handling:
- On success, print exactly one line to stderr: `read <xml_path>`.
- If no command-line argument is provided, the file cannot be read, or the XML cannot be parsed, print `error: <message>` to stderr and exit with status 1. In all failure cases, stdout must remain empty.

Example:

`app.xml`:
```xml
<config>
  <server>
    <host>localhost</host>
    <port>8080</port>
  </server>
  <debug>true</debug>
</config>
```

Command:
```sh
python xml_config_to_json.py app.xml > app.json
```

`app.json`:
```json
{
  "debug": "true",
  "server": {
    "host": "localhost",
    "port": "8080"
  }
}
```

stderr on success:
```text
read app.xml
```
