Write a Python program in a file called `xml_config_to_json.py`. It should accept an XML configuration file path as its first command-line argument, parse that XML file, transform it into a JSON object, and output that JSON to stdout using 2-space indentation and alphabetically sorted object keys.

Conversion rules:
- Treat the root element `<config>` as external structure; do not include it in the JSON output.
- Every immediate child of `<config>` becomes a top-level property in the output JSON. The property name is the child element's tag name.
- If such a child has no nested elements, its value is the element's text content with surrounding whitespace stripped. If there is no text, use an empty string.
- If such a child has nested elements, its value is a JSON object created recursively from those nested elements. Ignore any text directly inside that child element.
- You may assume that each parent element has at most one child per tag name.

Logging and failures:
- On success, write exactly one line to stderr: `read <xml_path>`.
- If no command-line argument is supplied, the file cannot be read, or the XML cannot be parsed, write `error: <message>` to stderr and terminate with exit status 1. In any failure case, stdout must remain empty.

Example usage:

`app.xml`:
```xml
<config>
  <server>
    <host>localhost</host>
    <port>8080</port>
  </server>
  <debug>true</debug>
</config>
```

Command:
```sh
python xml_config_to_json.py app.xml > app.json
```

`app.json`:
```json
{
  "debug": "true",
  "server": {
    "host": "localhost",
    "port": "8080"
  }
}
```

stderr on success:
```text
read app.xml
```
