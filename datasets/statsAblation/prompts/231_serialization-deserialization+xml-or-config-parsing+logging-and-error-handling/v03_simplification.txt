Write a Python command-line utility called `xml_config_to_json.py` that converts an XML configuration file into JSON. The first command-line argument is the path to the XML file. The program should read and parse that XML file, transform it into a JSON-compatible object, and print the resulting JSON to stdout using 2-space indentation and alphabetically sorted object keys.

Conversion requirements:
- Do not include the top-level `<config>` element itself in the JSON output.
- Every direct child of `<config>` becomes a top-level key, using the child element’s tag name as the key.
- For a direct child element that contains no nested elements, use its text content as the JSON value, stripped of leading and trailing whitespace. If there is no text, use an empty string.
- For a direct child element that contains nested elements, recursively convert those nested elements into a JSON object as the value. Ignore any text directly inside that child element.
- You can assume that within any single parent element, no two child elements share the same tag name.

Command-line behavior and error handling:
- If conversion succeeds, print exactly one line to stderr in the form: `read <xml_path>`.
- If no command-line argument is supplied, the file cannot be read, or the XML cannot be parsed, print `error: <message>` to stderr and terminate with exit status 1.
- In every failure case, stdout must remain completely empty.

Example:

`app.xml`:
```xml
<config>
  <server>
    <host>localhost</host>
    <port>8080</port>
  </server>
  <debug>true</debug>
</config>
```

Command:
```sh
python xml_config_to_json.py app.xml > app.json
```

`app.json`:
```json
{
  "debug": "true",
  "server": {
    "host": "localhost",
    "port": "8080"
  }
}
```

stderr on success:
```text
read app.xml
```
