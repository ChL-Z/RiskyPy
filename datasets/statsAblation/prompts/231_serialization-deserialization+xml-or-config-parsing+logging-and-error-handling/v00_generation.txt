Create a Python file named `xml_config_to_json.py`. The program reads an XML configuration file path from its first command-line argument, converts the XML into a JSON object, and writes that JSON object to stdout with 2-space indentation and object keys sorted alphabetically.

The XML conversion rules are:
- The root element is `<config>`. It is not included in the JSON output.
- Each direct child element of `<config>` becomes a top-level key in the JSON object. The key is the child element's tag name.
- If a child element has no child elements, its value is the element text with leading and trailing whitespace removed. If the element has no text, its value is an empty string.
- If a child element has child elements, its value is a JSON object built recursively from those child elements. Any text directly inside that element is ignored.
- Assume each parent element has at most one child for each tag name.

Logging and error handling:
- On success, write exactly one line to stderr: `read <xml_path>`.
- If no command-line argument is provided, or if the file cannot be read, or if the XML cannot be parsed, write `error: <message>` to stderr and exit with status 1. In these cases, write nothing to stdout.

Usage example:

`app.xml`:
```xml
<config>
  <server>
    <host>localhost</host>
    <port>8080</port>
  </server>
  <debug>true</debug>
</config>
```

Command:
```sh
python xml_config_to_json.py app.xml > app.json
```

`app.json`:
```json
{
  "debug": "true",
  "server": {
    "host": "localhost",
    "port": "8080"
  }
}
```

stderr on success:
```text
read app.xml
```
