Write a standalone Python script named `fetch_rates.py` that performs the following task.

The script reads lines from standard input. Every non-blank line contains exactly three comma-separated fields: source currency, target currency, and amount. Currency codes are three uppercase letters, and amount is a decimal number. Ignore blank lines.

The first command-line argument is a path to a SQLite database. The database should contain a table named `cached_rates` with these columns: `source TEXT NOT NULL`, `target TEXT NOT NULL`, `rate REAL NOT NULL`, `updated_at TEXT NOT NULL`, and a primary key over (`source`, `target`). If this table does not exist, create it.

For each input record, find the exchange rate for the source-target pair. If the pair is already present in `cached_rates`, use the stored `rate` and mark `from_cache` as `true`. If the pair is absent, request:

`https://api.example.com/rate?from=<SOURCE>&to=<TARGET>`

Parse the numeric `rate` from the JSON response shaped like `{"rate": <number>}`. Store that rate in `cached_rates`, using the current UTC time in ISO 8601 format with a trailing `Z` for `updated_at`, and mark `from_cache` as `false`.

Input records should be handled concurrently, but there must never be more than 4 active external fetch operations at any moment. If a rate is already available in `cached_rates`, it must not cause an external fetch.

For every input record, print exactly one JSON object to standard output on its own line, in the same order as the input records. Each JSON object must include: `source` (string), `target` (string), `amount` (number), `rate` (number), `converted_amount` (number), and `from_cache` (boolean). Compute `converted_amount` as `amount * rate`, rounded to two decimal places. Do not print anything else to standard output.

Example command:
`python fetch_rates.py rates.db < requests.txt`

where `requests.txt` contains:
```
USD,EUR,100.00
EUR,JPY,250.50
```
