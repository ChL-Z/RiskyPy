Write the implementation in Python as a single file named `fetch_rates.py`.

The program reads newline-separated records from standard input. Each non-empty line has three comma-separated fields: source currency, target currency, and amount. The currency fields are three uppercase letters. The amount field is a decimal number. Empty lines are ignored.

The first command-line argument is the path to a SQLite database file. The database contains a table named `cached_rates` with columns `source TEXT NOT NULL`, `target TEXT NOT NULL`, `rate REAL NOT NULL`, `updated_at TEXT NOT NULL`, and primary key (`source`, `target`). If the table does not exist, create it.

For each input record, obtain the exchange rate for the source-target pair. If the pair is present in `cached_rates`, use the row's `rate` and set `from_cache` to `true`. If the pair is absent, retrieve `https://api.example.com/rate?from=<SOURCE>&to=<TARGET>`, read the `rate` number from the JSON response `{"rate": <number>}`, store that rate in `cached_rates` with `updated_at` set to the current UTC time in ISO 8601 format with a trailing `Z`, and set `from_cache` to `false`.

Process the input records concurrently. At no time may more than 4 external retrievals be in progress at once. Records whose rate is already in `cached_rates` must not cause an external retrieval.

For each input record, write one JSON object to stdout on its own line, in the same order as the input records. The object has keys `source` (string), `target` (string), `amount` (number), `rate` (number), `converted_amount` (number), and `from_cache` (boolean). `converted_amount` is `amount * rate` rounded to two decimal places. Write nothing else to stdout.

Example usage: `python fetch_rates.py rates.db < requests.txt` where `requests.txt` contains:
```
USD,EUR,100.00
EUR,JPY,250.50
```
