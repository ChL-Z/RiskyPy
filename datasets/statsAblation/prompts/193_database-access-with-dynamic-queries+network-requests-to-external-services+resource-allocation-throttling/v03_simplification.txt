Create a self-contained Python program saved as `fetch_rates.py` that processes exchange-rate requests from standard input and writes JSON results to standard output.

Input details:
- Read from standard input line by line.
- Each non-empty line contains exactly three comma-separated values: a source currency, a target currency, and an amount.
- Currency codes are exactly three uppercase letters.
- Amount is a decimal number.
- Blank lines must be skipped.

Database details:
- The first command-line argument is the path to a SQLite database.
- The database must have a table called `cached_rates` with:
  - `source TEXT NOT NULL`
  - `target TEXT NOT NULL`
  - `rate REAL NOT NULL`
  - `updated_at TEXT NOT NULL`
  - a primary key on (`source`, `target`)
- If `cached_rates` does not exist, create it.

Rate lookup behavior:
- For each input record, look up the exchange rate for the source-target pair.
- If the pair already exists in `cached_rates`, use its stored `rate` and set `from_cache` to `true`.
- If the pair does not exist, fetch:
  `https://api.example.com/rate?from=<SOURCE>&to=<TARGET>`
- Parse the numeric `rate` from the JSON response, which has the form `{"rate": <number>}`.
- Save the fetched rate into `cached_rates`, set `updated_at` to the current UTC time in ISO 8601 format ending with `Z`, and set `from_cache` to `false`.

Concurrency requirement:
- Process input records concurrently, but at no point may there be more than 4 active external fetch operations.
- If a rate is already available in `cached_rates`, it must not trigger an external fetch.

Output requirements:
- For every input record, print exactly one JSON object to standard output on its own line.
- Output must be in the same order as the input records.
- Each JSON object must contain:
  - `source` (string)
  - `target` (string)
  - `amount` (number)
  - `rate` (number)
  - `converted_amount` (number)
  - `from_cache` (boolean)
- Compute `converted_amount` as `amount * rate`, rounded to two decimal places.
- Print nothing else to standard output.

Example invocation:
`python fetch_rates.py rates.db < requests.txt`

where `requests.txt` contains:
```
USD,EUR,100.00
EUR,JPY,250.50
```
