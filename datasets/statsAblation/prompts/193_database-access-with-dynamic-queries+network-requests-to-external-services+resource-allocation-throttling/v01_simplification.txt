Create a Python implementation in a single file called `fetch_rates.py`.

The program should read records from standard input, one per line. Each non-empty line consists of three comma-separated values: a source currency, a target currency, and an amount. Currency codes are exactly three uppercase letters. The amount is a decimal number. Skip blank lines.

The first command-line argument is the path to a SQLite database. This database has a table called `cached_rates` with the columns `source TEXT NOT NULL`, `target TEXT NOT NULL`, `rate REAL NOT NULL`, `updated_at TEXT NOT NULL`, and a primary key on (`source`, `target`). If the table is missing, create it.

For every input record, look up the exchange rate for the source-target currency pair. If that pair already exists in `cached_rates`, use the stored `rate` and set `from_cache` to `true`. If it does not exist, fetch `https://api.example.com/rate?from=<SOURCE>&to=<TARGET>`, extract the numeric `rate` from the JSON response of the form `{"rate": <number>}`, save that rate into `cached_rates` with `updated_at` equal to the current UTC time formatted as ISO 8601 with a trailing `Z`, and set `from_cache` to `false`.

Process the input records concurrently, but never allow more than 4 external fetch operations to be active at the same time. Any record whose rate is already available in `cached_rates` must not trigger an external fetch.

For each input record, print exactly one JSON object to standard output on its own line, preserving the original input order. The JSON object must contain: `source` (string), `target` (string), `amount` (number), `rate` (number), `converted_amount` (number), and `from_cache` (boolean). `converted_amount` should be `amount * rate`, rounded to two decimal places. Do not write anything else to standard output.

Example usage: `python fetch_rates.py rates.db < requests.txt`, where `requests.txt` contains:
```
USD,EUR,100.00
EUR,JPY,250.50
```
