Create a standalone Python script named `batch_fetch.py`. The script must accept exactly two positional command-line arguments, in this order: first, the path to a credentials file; second, a token endpoint URL. The credentials file must be JSON, and its object must contain string fields named `client_id`, `client_secret`, and `refresh_token`.

The script should do only the following two jobs:

1. Retrieve an access token. Send an HTTP POST request to the token endpoint given as the second command-line argument. The request body must be encoded as `application/x-www-form-urlencoded` and include these form fields: `grant_type=refresh_token`, `refresh_token`, `client_id`, and `client_secret`, with the last three values read from the credentials file. Read the JSON response from the token endpoint and extract the string value of `access_token`.

2. Download a set of files. Continue reading lines from standard input until EOF. For each line that is not empty, treat the line as a URL. For every such URL, send an HTTP GET request with the header `Authorization: Bearer <access_token>`. Write the response body to a file in the current directory. The output filename must be built from the final path segment of the URL; if that segment is empty, use `index` instead, then append `.bin` as the extension. After the file has been successfully written, print that filename on a line by itself. If the HTTP request fails or the response status code is not 200, print the URL, followed by a single space, followed by `failed`, and do not create any file for that URL.

For example, suppose `creds.json` contains `{"client_id": "abc", "client_secret": "shh", "refresh_token": "r1"}` and the token endpoint is `https://auth.example.com/token`. Running:

    printf 'https://api.example.com/data/report1\nhttps://api.example.com/data/report2\n' | python batch_fetch.py creds.json https://auth.example.com/token

should print `report1.bin` followed by `report2.bin`, and create those two files in the working directory, each containing the body of the corresponding GET response.
