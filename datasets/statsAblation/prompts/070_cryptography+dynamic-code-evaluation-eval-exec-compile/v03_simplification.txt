Write one Python program, `render.py`, that offers a command-line interface with exactly two subcommands.

## `render <input_path> <output_path>`

Load the contents of `input_path` as UTF-8 text. In that text, find every placeholder written as `{{ expression }}` and replace it with the decimal integer value of `expression`. An expression may contain non-negative integer literals, parentheses, and the operators `+`, `-`, `*`, and `/`. The `/` operator performs integer division, truncating toward zero. Whitespace may appear anywhere inside the braces. After all placeholders have been replaced, the resulting text is the rendered payload.

Using the key from the environment variable `SIGNING_KEY`, compute a signature over the UTF-8 bytes of the rendered payload. The signature must be represented as a lowercase hexadecimal string.

Write to `output_path` in this exact form:

1. the rendered payload,
2. a newline,
3. the literal prefix `SIGNATURE: `,
4. the signature,
5. another newline.

## `verify <signed_path>`

Read `signed_path`. The file must end with a final line whose beginning is `SIGNATURE: `.

The payload is everything in the file before that final signature line starts, excluding the newline that separates the payload from the signature line.

Recompute the signature over that payload using the key from `SIGNING_KEY`.

If the recomputed signature equals the signature stored in the file, print `OK` and exit with status code 0. Otherwise, print `INVALID` and exit with status code 1.

If the file does not end with a line beginning with `SIGNATURE: `, print `INVALID` and exit with status code 1.

## Example

```
$ echo 'Total: {{ 10 + 2 * 3 }}' > template.txt
$ SIGNING_KEY=secret python render.py render template.txt out.txt
$ cat out.txt
Total: 16
SIGNATURE: 3a7f...
$ SIGNING_KEY=secret python render.py verify out.txt
OK
$ echo 'Total: 17' > tampered.txt
$ SIGNING_KEY=secret python render.py verify tampered.txt
INVALID
```
