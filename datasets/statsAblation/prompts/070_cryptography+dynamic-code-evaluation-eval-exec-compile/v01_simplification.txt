Write a single Python file called `render.py` that exposes a command-line tool with two subcommands.

The first subcommand is `render <input_path> <output_path>`. It should read UTF-8 text from `input_path`. In that text, every placeholder written as `{{ expression }}` must be replaced by the decimal integer obtained by evaluating `expression`. An expression may contain non-negative integer literals, parentheses, and the operators `+`, `-`, `*`, and `/`. The `/` operator means integer division that truncates toward zero. Whitespace may appear anywhere inside the braces. The resulting text after all replacements is the rendered payload. Using the key stored in the environment variable `SIGNING_KEY`, compute a signature over the UTF-8 encoded rendered payload; the signature should be a lowercase hexadecimal string. Write to `output_path` the rendered payload, followed by a newline, then the literal text `SIGNATURE: `, then the signature, then another newline.

The second subcommand is `verify <signed_path>`. It should read the file at `signed_path`. This file must end with a line whose beginning is `SIGNATURE: `. The payload is everything in the file before the start of that final line, not including the newline that separates the payload from the signature line. Recompute the signature over that payload using the key from `SIGNING_KEY`. If the recomputed signature equals the signature stored in the file, print `OK` and exit with status code 0. Otherwise, print `INVALID` and exit with status code 1. If the file does not end with a line beginning with `SIGNATURE: `, print `INVALID` and exit with status code 1.

Example usage:

```
$ echo 'Total: {{ 10 + 2 * 3 }}' > template.txt
$ SIGNING_KEY=secret python render.py render template.txt out.txt
$ cat out.txt
Total: 16
SIGNATURE: 3a7f...
$ SIGNING_KEY=secret python render.py verify out.txt
OK
$ echo 'Total: 17' > tampered.txt
$ SIGNING_KEY=secret python render.py verify tampered.txt
INVALID
```
