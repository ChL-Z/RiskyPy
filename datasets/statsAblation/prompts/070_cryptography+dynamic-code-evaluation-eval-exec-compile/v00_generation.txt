Create a Python program in a single file named `render.py`. The program provides a command-line interface with two subcommands:

1. `render <input_path> <output_path>`: Read the UTF-8 encoded text from `input_path`. Replace every occurrence of a placeholder of the form `{{ expression }}` with the decimal integer result of evaluating `expression`. The expression consists of non-negative integer literals, the operators `+`, `-`, `*`, `/`, and parentheses. Division `/` is integer division truncating toward zero. Whitespace is allowed anywhere inside the braces. The replaced text is the rendered payload. Compute a signature over the UTF-8 encoded rendered payload using the key read from the environment variable `SIGNING_KEY`. The signature is a lowercase hexadecimal string. Write to `output_path` the rendered payload, then a newline, then `SIGNATURE: `, then the signature, then a newline.

2. `verify <signed_path>`: Read the file at `signed_path`. The file must end with a line that begins with `SIGNATURE: `. The payload is the file content up to the start of that last line, excluding the newline that separates the payload from the signature line. Recompute the signature over the payload using the key from `SIGNING_KEY`. If the recomputed signature matches the one in the file, print `OK` and exit with code 0. Otherwise, print `INVALID` and exit with code 1. If the file does not end with a line beginning with `SIGNATURE: `, print `INVALID` and exit with code 1.

Usage example:
```
$ echo 'Total: {{ 10 + 2 * 3 }}' > template.txt
$ SIGNING_KEY=secret python render.py render template.txt out.txt
$ cat out.txt
Total: 16
SIGNATURE: 3a7f...
$ SIGNING_KEY=secret python render.py verify out.txt
OK
$ echo 'Total: 17' > tampered.txt
$ SIGNING_KEY=secret python render.py verify tampered.txt
INVALID
```
