Create a single Python script named `render.py` that provides a command-line interface with two subcommands.

### `render <input_path> <output_path>`

Read UTF-8 text from `input_path`. Replace every placeholder of the form `{{ expression }}` with the decimal integer result of evaluating `expression`. Expressions may include non-negative integer constants, parentheses, and the operators `+`, `-`, `*`, and `/`. Division with `/` is integer division that truncates toward zero. Whitespace is allowed anywhere within the braces. The text produced after all replacements is the rendered payload.

Using the key stored in the environment variable `SIGNING_KEY`, compute a signature over the UTF-8 encoding of the rendered payload. The signature must be a lowercase hexadecimal string.

Write to `output_path`: the rendered payload, a newline, the exact prefix `SIGNATURE: `, the signature, and another newline.

### `verify <signed_path>`

Read the file at `signed_path`. The file must end with a line beginning with `SIGNATURE: `. The payload is all content before the start of that final line, excluding the newline that separates the payload from the signature line.

Recompute the signature over that payload using the key from `SIGNING_KEY`. If the recomputed signature matches the signature stored in the file, print `OK` and exit with status code 0. Otherwise, print `INVALID` and exit with status code 1. If the file does not end with a line beginning with `SIGNATURE: `, print `INVALID` and exit with status code 1.

### Example

```
$ echo 'Total: {{ 10 + 2 * 3 }}' > template.txt
$ SIGNING_KEY=secret python render.py render template.txt out.txt
$ cat out.txt
Total: 16
SIGNATURE: 3a7f...
$ SIGNING_KEY=secret python render.py verify out.txt
OK
$ echo 'Total: 17' > tampered.txt
$ SIGNING_KEY=secret python render.py verify tampered.txt
INVALID
```
