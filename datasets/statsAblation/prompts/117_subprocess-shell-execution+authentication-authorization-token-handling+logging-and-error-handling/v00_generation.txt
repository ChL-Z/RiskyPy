Write a Python script in a single file named `fetch_urls.py`. The script reads URLs from standard input, one per line, and ignores lines that are empty after stripping whitespace. It obtains an access token by running the command stored in the `TOKEN_CMD` environment variable and capturing the command's standard output. If `TOKEN_CMD` is not set, the token is the empty string. The token is the captured output with the trailing newline removed. For each URL, the script sends an HTTP GET request with the header `Authorization: Bearer <token>`. For each response, the script writes one line to standard output and appends the same line to `fetch.log`. The line format is `{timestamp} {url} status={status_code} body={body_text}` where `timestamp` is the current UTC time in ISO 8601 format, `status_code` is the HTTP status code as an integer, and `body_text` is the first 100 characters of the response body after replacing every newline character with a space. If a request fails, the line format is `{timestamp} {url} status=ERROR body={error_text}` where `error_text` is the string representation of the error.

For example, if `TOKEN_CMD` is set to `echo abc123` and standard input contains `https://api.example.com/health`, the script sends a GET request to that URL with header `Authorization: Bearer abc123` and logs a line such as `2025-01-01T00:00:00Z https://api.example.com/health status=200 body={"status":"ok"}`.

The script must be implemented in Python and contained in the single file `fetch_urls.py`.
