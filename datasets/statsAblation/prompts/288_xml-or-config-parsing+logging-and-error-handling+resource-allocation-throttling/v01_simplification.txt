Create a single-file Python program named `run_tasks.py` that reads shell commands from an XML configuration file, executes them with a configurable concurrency limit, and logs the outcome of each command.

Program requirements:

1. The program must accept these command-line options:
   - `--config`: path to the XML configuration file; default is `tasks.xml`.
   - `--max-parallel`: integer specifying the maximum number of concurrent commands; default is `2`.

   The XML configuration has a root element `<tasks>` that contains zero or more `<task>` elements. Every `<task>` element has two attributes: `name` and `command`. If the XML file cannot be read or parsed, print an error message to stderr and exit with status code `1`.

2. Execute every command. No more than `--max-parallel` commands may run simultaneously. The program must wait until all commands have completed before exiting. For each command, record either its exit code if it finishes, or the error message if it cannot be started.

3. After each task finishes or fails to start, append one line to `run.log`. Each line must use this format:

   `<timestamp> <name> <status>`

   Here, `<timestamp>` is the local time formatted as `YYYY-MM-DDTHH:MM:SS`, `<name>` is the task name, and `<status>` is either `exit=<code>` for a completed command or `error: <message>` for a command that could not be started.

4. After all tasks have been processed, print exactly one summary line to stdout:

   `tasks: <total>, succeeded: <n>, failed: <n>`

Example usage:

Given `tasks.xml`:

```xml
<tasks>
  <task name="build" command="make -j4" />
  <task name="test" command="pytest -q" />
  <task name="lint" command="flake8 ." />
</tasks>
```

Running:

```bash
python run_tasks.py --config tasks.xml --max-parallel 2
```

should run no more than two commands at the same time, append three lines to `run.log` (one per task), and print a summary such as:

```text
tasks: 3, succeeded: 2, failed: 1
```

The implementation must be contained in a single Python file.
