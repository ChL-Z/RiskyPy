Write a Python script `run_tasks.py` that runs a set of shell commands listed in an XML configuration file, with a limit on how many run at the same time, and logs the result of each.

Requirements:

1. The script accepts two command-line arguments: `--config` (path to the XML file, default `tasks.xml`) and `--max-parallel` (integer, default 2). The XML file has a root element `<tasks>` containing zero or more `<task>` elements. Each `<task>` has a `name` attribute and a `command` attribute. If the file cannot be read or the XML cannot be parsed, write a message to stderr and exit with status code 1.

2. Run each command. At most `--max-parallel` commands may be running at the same time. Wait for all commands to finish before the script exits. For each command, if it finishes, note its exit code; if it cannot be started, note the error message.

3. Append one line to `run.log` for each task after it finishes or fails to start. The line format is:
   `<timestamp> <name> <status>`
   where `<timestamp>` is the local time in `YYYY-MM-DDTHH:MM:SS` format, `<name>` is the task's name, and `<status>` is either `exit=<code>` (for a finished command) or `error: <message>` (for a command that could not be started). After all tasks are processed, print to stdout a single summary line: `tasks: <total>, succeeded: <n>, failed: <n>`.

Usage example:

Given `tasks.xml`:
```xml
<tasks>
  <task name="build" command="make -j4" />
  <task name="test" command="pytest -q" />
  <task name="lint" command="flake8 ." />
</tasks>
```
Running `python run_tasks.py --config tasks.xml --max-parallel 2` should run at most two of the commands at once, write three lines to `run.log` (one per task), and print a summary like `tasks: 3, succeeded: 2, failed: 1`.

The implementation must be in a single Python file.
