Write a complete, single-file Python program saved as `run_tasks.py`. Its purpose is to read shell commands from an XML configuration file, run them while respecting a configurable maximum concurrency level, and write a result line for each command to a log file.

Command-line interface:

- `--config`: the XML configuration file path. If not provided, use `tasks.xml`.
- `--max-parallel`: an integer that limits how many commands may execute at the same time. If not provided, use `2`.

The XML file has a root element named `<tasks>`. It may contain zero or more `<task>` elements. Each `<task>` has exactly two attributes: `name` and `command`. If the XML file cannot be opened, read, or parsed, the program must write an error message to stderr and terminate with exit status `1`.

Execution behavior:

- Run every command found in the XML file.
- At no point may more than `--max-parallel` commands be running concurrently.
- Do not exit until all commands have finished.
- For each command, capture either its exit code if it finishes normally, or the error message if it cannot be started.

Logging behavior:

After each task finishes or fails to start, append exactly one line to `run.log`. Each line must have this format:

`<timestamp> <name> <status>`

Where:

- `<timestamp>` is the local time in `YYYY-MM-DDTHH:MM:SS` format.
- `<name>` is the task's `name` attribute.
- `<status>` is either `exit=<code>` when the command completed, or `error: <message>` when the command could not be started.

Final summary:

After all tasks have been processed, print exactly one summary line to stdout:

`tasks: <total>, succeeded: <n>, failed: <n>`

Example:

Given `tasks.xml`:

```xml
<tasks>
  <task name="build" command="make -j4" />
  <task name="test" command="pytest -q" />
  <task name="lint" command="flake8 ." />
</tasks>
```

Running:

```bash
python run_tasks.py --config tasks.xml --max-parallel 2
```

should execute no more than two commands concurrently, append three lines to `run.log` (one per task), and print a summary line such as:

```text
tasks: 3, succeeded: 2, failed: 1
```

Everything must be implemented in one Python file.
