Create a single-file Python program called `run_query.py`. It should take three command-line inputs: an XML configuration path at `sys.argv[1]`, a JSON parameters path at `sys.argv[2]`, and a query name at `sys.argv[3]`. The XML configuration uses this form:

```xml
<config>
  <database>users.sqlite</database>
  <query name="active">
    SELECT id, email, certificate FROM users WHERE active = :active
  </query>
</config>
```

The JSON file is an object whose keys correspond to named placeholders in the selected SQL query, such as `{"active": 1}`. The program should connect to the SQLite database named by the `<database>` element, locate the `<query>` element whose `name` attribute matches the third argument, execute that query’s SQL text, and bind every JSON key to its matching `:key` placeholder in the SQL. The query results must be written to stdout as CSV: first a header row containing the returned column names in query order, then one CSV row for each result row.

For any output column named `certificate`, if the cell value is a string containing a PEM-encoded X.509 certificate, replace that CSV cell with the certificate serial number written as a lowercase hexadecimal string with no leading zeros. If the serial number is zero, output `0`. If the cell value is NULL, is not a string, or does not contain a PEM-encoded X.509 certificate, leave the cell value unchanged.

If the third argument does not match the `name` attribute of any `<query>` element, write `query not found` to stderr and exit with status 2. In all other cases, exit with status 0.

Example usage:

```bash
python run_query.py config.xml params.json active
```

With `config.xml` as shown above and `params.json` containing `{"active": 1}`, the program should print:

```csv
id,email,certificate
1,alice@example.com,1a2b3c
```
