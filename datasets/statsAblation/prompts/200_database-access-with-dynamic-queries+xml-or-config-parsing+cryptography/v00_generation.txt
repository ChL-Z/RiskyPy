Write a Python program in a single file named `run_query.py`. The program reads an XML configuration file path from `sys.argv[1]`, a JSON parameters file path from `sys.argv[2]`, and a query name from `sys.argv[3]`. The XML file has this structure:

```xml
<config>
  <database>users.sqlite</database>
  <query name="active">
    SELECT id, email, certificate FROM users WHERE active = :active
  </query>
</config>
```

The JSON file contains an object whose keys match named placeholders in the SQL query, for example `{"active": 1}`. The program connects to the SQLite database file named by the `<database>` element, executes the SQL text of the `<query>` element whose `name` attribute equals the third argument, and binds each JSON key to the corresponding `:key` placeholder in the SQL text. It writes the query result to stdout as CSV with a header row containing the column names in the order returned by the query, followed by one row per result row.

For every output column named `certificate`, if the cell value is a string containing a PEM-encoded X.509 certificate, replace that cell in the CSV output with the certificate's serial number as a lowercase hexadecimal string with no leading zeros (use `0` when the serial number is zero). If the cell value is NULL, not a string, or does not contain a PEM-encoded X.509 certificate, write the original cell value unchanged.

If the third argument does not match the `name` attribute of any `<query>` element, write `query not found` to stderr and exit with status 2. Otherwise exit with status 0.

Usage example:

```bash
python run_query.py config.xml params.json active
```

With `config.xml` containing the structure above and `params.json` containing `{"active": 1}`, the program prints:

```csv
id,email,certificate
1,alice@example.com,1a2b3c
```
