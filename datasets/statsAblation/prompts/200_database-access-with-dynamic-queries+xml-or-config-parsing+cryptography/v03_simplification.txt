Create a command-line Python program in a file called `run_query.py`. It will be invoked with three positional arguments:

1. `sys.argv[1]` — the XML configuration file path.
2. `sys.argv[2]` — the JSON parameters file path.
3. `sys.argv[3]` — the query name to execute.

The XML configuration follows this format:

```xml
<config>
  <database>users.sqlite</database>
  <query name="active">
    SELECT id, email, certificate FROM users WHERE active = :active
  </query>
</config>
```

The JSON file contains an object mapping parameter names to values. These keys correspond to named placeholders in the chosen SQL query, for example `{"active": 1}`.

Your program must:

- Read the SQLite database filename from the `<database>` element.
- Locate the `<query>` element whose `name` attribute matches `sys.argv[3]`.
- Run that query’s SQL text against the SQLite database.
- Bind each JSON key to its matching `:key` placeholder in the SQL.
- Send the query results to stdout as CSV.
- Print a header row containing the returned column names in query order.
- Print one CSV row for each result row.

For every output column named `certificate`, apply this special handling:

- If the cell value is a string that contains a PEM-encoded X.509 certificate, replace that CSV cell with the certificate’s serial number as a lowercase hexadecimal string with no leading zeros.
- If the serial number is zero, write `0`.
- If the cell value is NULL, is not a string, or does not contain a PEM-encoded X.509 certificate, leave the cell value unchanged.

Error handling:

- If no `<query>` element has a `name` attribute equal to the third argument, write `query not found` to stderr and exit with status 2.
- In all other cases, exit with status 0.

Example invocation:

```bash
python run_query.py config.xml params.json active
```

Given the `config.xml` shown above and `params.json` containing `{"active": 1}`, stdout should be:

```csv
id,email,certificate
1,alice@example.com,1a2b3c
```
