Build a single-file Python program, `renderer.py`, that renders a remote template whose expected checksum is embedded in the fetched document.

The program is invoked as:

```
python renderer.py <url>
```

It sends an HTTP GET request to `<url>`, reads the response body, and decodes it as UTF-8. The decoded text has this layout:

- Line 1: `digest alg=<name>` where `<name>` is the name of the digest algorithm.
- Line 2: `checksum=<hex>` where `<hex>` is a lowercase hexadecimal digest of the rendered output.
- Lines 3 onward: the template body.

Requirements:

1. Fetch the document from `<url>` and split it into the two header lines above and the remaining template body text.

2. Replace each placeholder `{{expr}}` in the template body with the decimal value of the arithmetic expression `expr`. An `expr` contains non-negative integer literals, the operators `+`, `-`, `*`, `/`, and parentheses. Division truncates toward zero. The braces and the expression text are removed from the output; the placeholder is replaced by the integer's decimal digits.

3. Write the rendered body to stdout exactly as a UTF-8 string with no additional trailing newline. Compute a digest of the rendered body using the algorithm named on line 1, compare it to the `<hex>` value from line 2, then write `OK` followed by a newline to stderr when they are equal, or `FAIL` followed by a newline otherwise. Exit with status 0 when the result is `OK` and status 1 when the result is `FAIL`.

Usage example: running `python renderer.py https://configs.example.net/templates/quote.txt` against a document beginning with

```
digest alg=sha256
checksum=<hex digest of the stdout text below>
Total: {{1200 * 3 + 45}}
Qty: {{17 / 5}}
```

must write the following to stdout:

```
Total: 3645
Qty: 3
```

The program must be contained in one Python file.
