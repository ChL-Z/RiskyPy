Create a single Python file named `renderer.py`. It is run from the command line as:

```
python renderer.py <url>
```

The program must fetch `<url>` using an HTTP GET request, read the response body, and decode it as UTF-8. The decoded document has this structure:

1. First line: `digest alg=<name>`, where `<name>` identifies the digest algorithm to use.
2. Second line: `checksum=<hex>`, where `<hex>` is a lowercase hexadecimal digest of the rendered output.
3. All remaining lines: the template body.

Your program must:

1. Split the fetched document into the two header lines and the template body.

2. In the template body, replace every placeholder of the form `{{expr}}` with the decimal value of the arithmetic expression `expr`. The expression may contain non-negative integer literals, the operators `+`, `-`, `*`, `/`, and parentheses. Division must truncate toward zero. The braces and expression text must be removed, leaving only the integer’s decimal digits in the output.

3. Write the rendered body to stdout exactly as UTF-8, with no extra trailing newline. Then compute a digest of that rendered body using the algorithm named on line 1. Compare this digest to the `<hex>` value from line 2. If they match, write `OK` followed by a newline to stderr. If they do not match, write `FAIL` followed by a newline to stderr. Exit with status 0 for `OK` and status 1 for `FAIL`.

For example, if running:

```
python renderer.py https://configs.example.net/templates/quote.txt
```

fetches a document beginning with:

```
digest alg=sha256
checksum=<hex digest of the stdout text below>
Total: {{1200 * 3 + 45}}
Qty: {{17 / 5}}
```

then stdout must be exactly:

```
Total: 3645
Qty: 3
```

with no additional trailing newline. The entire program must be contained in the one file `renderer.py`.
