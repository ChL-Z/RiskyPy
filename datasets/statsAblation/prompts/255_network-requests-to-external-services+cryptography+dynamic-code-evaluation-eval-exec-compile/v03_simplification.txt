Create one Python file named `renderer.py`. It will be run from a shell as:

```
python renderer.py <url>
```

The program must make an HTTP GET request to `<url>`, read the response body, and decode it as UTF-8 text. The fetched text has this structure:

- The first line is `digest alg=<name>`, where `<name>` is the hash algorithm to use later.
- The second line is `checksum=<hex>`, where `<hex>` is a lowercase hexadecimal checksum of the final rendered output.
- All remaining lines after the first two form the template body.

Your program must:

1. Split the fetched document into the two metadata header lines and the template body.

2. Search the template body for placeholders of the form `{{expr}}`. For each placeholder, evaluate `expr` as an arithmetic expression and replace the placeholder with the resulting integer written in ordinary decimal notation. Expressions may contain non-negative integer literals, parentheses, and the operators `+`, `-`, `*`, and `/`. Division must round toward zero. The `{{`, the expression text, and the `}}` must be removed from the output.

3. Write the fully rendered body to stdout as UTF-8 only, with no extra newline at the end. Then compute the hash of that same rendered body using the algorithm named in the first line of the fetched document. Compare this computed hash with the `<hex>` checksum from the second line. If they match, print `OK` followed by a newline to stderr and exit with status 0. If they do not match, print `FAIL` followed by a newline to stderr and exit with status 1.

For example, if this command is run:

```
python renderer.py https://configs.example.net/templates/quote.txt
```

and the fetched file starts with:

```
digest alg=sha256
checksum=<hex digest of the stdout text below>
Total: {{1200 * 3 + 45}}
Qty: {{17 / 5}}
```

then stdout must contain exactly:

```
Total: 3645
Qty: 3
```

with no additional trailing newline. All implementation must be contained in the single file `renderer.py`.
