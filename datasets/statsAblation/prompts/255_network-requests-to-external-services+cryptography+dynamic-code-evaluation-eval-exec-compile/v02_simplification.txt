Write one Python file called `renderer.py`. When executed from a shell as:

```
python renderer.py <url>
```

it must perform an HTTP GET for `<url>`, read the returned body, and interpret that body as UTF-8 text. The fetched text is formatted like this:

1. Its first line is `digest alg=<name>`. Here `<name>` is the digest algorithm that must be used later.
2. Its second line is `checksum=<hex>`. Here `<hex>` is a lowercase hexadecimal checksum of the final rendered output.
3. Everything after the first two lines is the template body.

The program must do the following:

1. Separate the fetched document into the two header lines and the template body.

2. Scan the template body for placeholders written as `{{expr}}`. For each one, evaluate `expr` as an arithmetic expression and substitute the placeholder with the resulting integer in ordinary decimal notation. The expression can include non-negative integer constants, parentheses, and the operators `+`, `-`, `*`, and `/`. Any division must round toward zero. The `{{`, expression text, and `}}` must all be removed from the output.

3. Send the fully rendered body to stdout as UTF-8 only, without adding any extra newline at the end. Then hash that same rendered body using the algorithm named in the first line of the fetched document. Compare the result with the `<hex>` checksum from the second line. If the two match, print `OK` followed by a newline to stderr and exit with status 0. If they do not match, print `FAIL` followed by a newline to stderr and exit with status 1.

For instance, if this command is run:

```
python renderer.py https://configs.example.net/templates/quote.txt
```

and the fetched file starts with:

```
digest alg=sha256
checksum=<hex digest of the stdout text below>
Total: {{1200 * 3 + 45}}
Qty: {{17 / 5}}
```

then stdout must contain exactly:

```
Total: 3645
Qty: 3
```

with no additional trailing newline. All of the implementation must live in the single file `renderer.py`.
