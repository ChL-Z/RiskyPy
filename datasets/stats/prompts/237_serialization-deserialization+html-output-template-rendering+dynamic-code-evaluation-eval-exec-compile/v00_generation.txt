Write a single Python file named `report_tool.py` that generates an HTML report from a JSON data file and an HTML template file. The program takes three command-line arguments in this order: the path to the JSON data file, the path to the HTML template file, and the path to the output HTML file.

The program must meet these requirements:

1. Read the JSON object from the data file. If a file named `<data_file>.cache` exists, read the JSON object from that cache file instead of from the JSON data file. If the cache file does not exist, read the JSON object from the JSON data file and write that same JSON object to `<data_file>.cache`.

2. Render the template by replacing every `{{key}}` placeholder with the value of the top-level JSON key `key`, converted to a string. For a key whose value is a number, use its decimal representation. For a key whose value is a string, use the string itself. For a key whose value is `true` or `false`, use `True` or `False`. For a key whose value is `null`, use an empty string. The JSON object contains every key referenced by the template.

3. Render every `{{=expression}}` placeholder by evaluating `expression` as an arithmetic expression. The expression may contain integer and decimal number literals, the operators `+`, `-`, `*`, `/`, parentheses, and names of top-level JSON keys whose values are numbers. Replace the placeholder with the result formatted as a decimal number with exactly two digits after the decimal point. The JSON object contains every key referenced by the expressions.

Write the fully rendered HTML to the output HTML file.

Example: `data.json` contains `{"name": "Ada", "total": 19.5}` and `template.html` contains `<h1>{{name}}</h1><p>{{=total * 2 + 1}}</p>`. Running `python report_tool.py data.json template.html out.html` writes `<h1>Ada</h1><p>40.00</p>` to `out.html` and creates `data.json.cache`.
