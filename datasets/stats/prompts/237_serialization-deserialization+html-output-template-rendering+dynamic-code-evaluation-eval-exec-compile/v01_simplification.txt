Write a single Python file named `report_tool.py`. The program takes three command-line arguments in this order: the path to a JSON data file, the path to an HTML template file, and the path to an output HTML file.

1. Read the JSON object from the data file. Write that same JSON object to a file named `<data_file>.cache`. Use the object read from the data file as the data for rendering.

2. Read the template file as text. Replace every `{{key}}` placeholder with the value of the top-level JSON key `key`, converted to a string: strings are used as themselves, numbers are written in decimal form. Replace every `{{=expression}}` placeholder with the result of evaluating `expression` as an arithmetic expression. The expression may contain integer and decimal number literals, the operators `+`, `-`, `*`, `/`, parentheses, and names of top-level JSON keys whose values are numbers. Format the result with exactly two digits after the decimal point. The JSON object contains every key referenced by the template. Write the fully rendered text to the output HTML file.

Example: `data.json` contains `{"name": "Ada", "total": 19.5}` and `template.html` contains `<h1>{{name}}</h1><p>{{=total * 2 + 1}}</p>`. Running `python report_tool.py data.json template.html out.html` writes `<h1>Ada</h1><p>40.00</p>` to `out.html` and creates `data.json.cache`.
