Write a single Python file named `report_tool.py`. It takes three command-line arguments: a JSON data file path, an HTML template file path, and an output HTML file path.

1. Read the JSON object from the data file. Write that same object to `<data_file>.cache` as JSON. Use the object read from the data file for rendering.

2. Read the template file as text. Replace each `{{key}}` placeholder with the value of the top-level JSON key `key`, converted to a string: strings as themselves, numbers in decimal form. Replace each `{{=expression}}` placeholder with the result of evaluating `expression` as an arithmetic expression. The expression contains only integer and decimal number literals, the operators `+`, `-`, `*`, `/`, spaces, and names of top-level JSON keys whose values are numbers. Format the result with exactly two digits after the decimal point. The JSON object contains every key referenced by the template. Write the rendered text to the output HTML file.

Example: `data.json` contains `{"name": "Ada", "total": 19.5}` and `template.html` contains `<h1>{{name}}</h1><p>{{=total * 2 + 1}}</p>`. Running `python report_tool.py data.json template.html out.html` writes `<h1>Ada</h1><p>40.00</p>` to `out.html` and creates `data.json.cache`.
