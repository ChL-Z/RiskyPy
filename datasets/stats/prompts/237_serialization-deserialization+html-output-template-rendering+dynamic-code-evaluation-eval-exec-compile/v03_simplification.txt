Write a single Python file named `report_tool.py`. It takes three command-line arguments in order: a JSON data file path, an HTML template file path, and an output HTML file path.

1. Read the JSON object from the data file. Write that same object to a file named by appending `.cache` to the data file path, as JSON. Use the object read from the data file for the next step.

2. Read the template file as text. Replace every `{{=expression}}` placeholder with the value of `expression`, formatted with exactly two digits after the decimal point. The expression contains only integer and decimal number literals, the operators `+`, `-`, `*`, `/`, spaces, and names of top-level JSON keys whose values are numbers. Every key named in the template is present in the JSON object. Write the resulting text to the output HTML file.

Example: `data.json` contains `{"total": 19.5}` and `template.html` contains `<h1>Total</h1><p>{{=total * 2 + 1}}</p>`. Running `python report_tool.py data.json template.html out.html` writes `<h1>Total</h1><p>40.00</p>` to `out.html` and creates `data.json.cache`.
