Write a Python program in a single file named `check_stock.py`. The program takes exactly one command-line argument: the path to a configuration file.

The configuration file contains lines in the form `key = value`. Lines that are empty or start with `#` are ignored. The keys are `feed_url` and `threshold`.

The program must:
1. Read the configuration file and obtain the two values.
2. Fetch the XML document at `feed_url`. Parse the XML document and collect the text content of every element whose local name is `price`. Convert each collected text to a floating-point number and compute their sum.
3. Evaluate the `threshold` value as an arithmetic expression consisting of decimal numbers, the operators `+`, `-`, `*`, `/`, and parentheses. Compare the sum of prices to the evaluated threshold. If the sum is greater than the threshold, print `OK`; otherwise print `LOW`.

For example, given `prices.conf`:
```
feed_url = https://example.com/prices.xml
threshold = 100 + 25
```
and an XML document at that URL containing:
```xml
<items>
  <item><price>50</price></item>
  <item><price>80</price></item>
</items>
```
the sum of prices is 130, the threshold evaluates to 125, and the program prints:
```
OK
```
