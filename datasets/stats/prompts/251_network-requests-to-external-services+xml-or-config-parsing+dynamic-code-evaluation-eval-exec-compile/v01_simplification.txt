Write a Python program in a single file named `check_stock.py`. The program takes one command-line argument: the path to a configuration file.

The configuration file contains lines in the form `key = value`. Empty lines and lines starting with `#` are ignored. The keys are `feed_url` and `threshold`.

The program must:
1. Read `feed_url` and `threshold` from the configuration file.
2. Fetch the XML document at `feed_url`, parse it, collect the text content of every element whose element name is `price`, convert each collected text to a floating-point number, and compute their sum.
3. Evaluate `threshold` as an arithmetic expression containing decimal numbers, parentheses, and the operators `+`, `-`, `*`, `/`. Compare the sum of prices to the evaluated threshold. If the sum is greater than the threshold, print `OK`; otherwise print `LOW`.

For example, given `prices.conf`:
```
feed_url = https://example.com/prices.xml
threshold = 100 + 25
```
and an XML document at that URL containing:
```xml
<items>
  <item><price>50</price></item>
  <item><price>80</price></item>
</items>
```
the sum of prices is 130, the threshold evaluates to 125, and the program prints:
```
OK
```
