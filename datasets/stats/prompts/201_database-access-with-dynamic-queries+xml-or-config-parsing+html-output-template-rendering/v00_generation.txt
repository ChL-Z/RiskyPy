Write a Python program in one file named `report.py`. The program reads a report definition XML file and a SQLite database file, then writes an HTML report to stdout.

The command line is:

`python report.py --config reports.xml --db app.db --report <name> [--filter <column>=<value>]...`

`--config` defaults to `reports.xml`. `--db` defaults to `app.db`. `--report` is required. `--filter` may appear zero or more times.

The XML file has this structure:

```xml
<reports>
  <report name="sales" table="sales">
    <column name="region" label="Region"/>
    <column name="amount" label="Amount"/>
    <filter name="region"/>
    <filter name="year"/>
  </report>
  <report name="inventory" table="items">
    <column name="sku" label="SKU"/>
    <column name="quantity" label="Quantity"/>
    <filter name="warehouse"/>
  </report>
</reports>
```

Requirements:

1. Read the report definition from the XML file. If `--report` does not match a `<report>` element's `name` attribute, print `report not found` to stderr and exit with code 1. For the matching report, use its `table` attribute and its `<column>` child elements in document order.

2. Query the SQLite database with a SELECT over the report's table, selecting exactly the columns named by the `<column>` elements in that same order. Apply each `--filter` as an equality condition on the column named before the first `=` in that filter argument. If a `--filter` names a column that is not declared as a `<filter>` child element in the matching report, print `unknown filter: <name>` to stderr and exit with code 1.

3. Write one HTML document to stdout in this exact shape, with the report name in the title, one header cell per column using the column `label`, and one body row per query result row using the selected values in column order. NULL values from the database must render as the empty string.

```html
<!DOCTYPE html><html><head><meta charset="utf-8"><title>sales</title></head><body><table border="1"><thead><tr><th>Region</th><th>Amount</th></tr></thead><tbody><tr><td>West</td><td>12.5</td></tr><tr><td>West</td><td>8</td></tr></tbody></table></body></html>
```

Example command:

`python report.py --config reports.xml --db app.db --report sales --filter region=West --filter year=2024`
