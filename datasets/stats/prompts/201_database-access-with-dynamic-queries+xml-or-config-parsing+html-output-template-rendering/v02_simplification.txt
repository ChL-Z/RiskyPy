Write a Python program in one file named `report.py`. It reads one XML report definition file and one SQLite database file, and writes one HTML document to stdout.

Command line:
`python report.py --config <xml-path> --db <sqlite-path> [--filter <column>=<value>]...`

`--config` is the XML file path. `--db` is the SQLite database file path. `--filter` may appear zero or more times. Each `--filter` value is `column=value`; split on the first `=`.

1. Read the XML file. The root element is `<report table="...">`. Its `<column name="..." label="..."/>` child elements, in document order, define the selected columns and their labels.

2. Open the SQLite database file. Run one SELECT over the table named by the root `table` attribute. Select exactly the columns named by the `<column>` elements in document order. For each `--filter`, add an equality condition on the column named before the first `=` with the value after the first `=`. If there are no `--filter` options, select all rows.

3. Write one HTML document to stdout. The HTML `title` element text is the root `table` attribute. It contains an HTML `table` element with `border="1"`, a `thead` with one `th` per column using the column `label` in document order, and a `tbody` with one `tr` per query result row. Each `tr` has one `td` per selected column value in column order. A database NULL value renders as the empty string.
