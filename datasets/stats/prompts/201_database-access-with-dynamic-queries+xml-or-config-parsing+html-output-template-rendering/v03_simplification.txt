Write a Python program in one file named `report.py`. It reads one XML configuration file and one SQLite database file, then writes one HTML document to stdout.

Command line:
`python report.py --config <xml-path> --db <sqlite-path>`

1. The XML file has root `<report table="...">`. Its `<column name="..." label="..."/>` child elements, in document order, name the columns and labels to include.

2. Open the SQLite database file. Read from the table named by the root `table` attribute exactly the columns named by the `<column>` elements, in document order. Read all rows.

3. Write one HTML document to stdout. The HTML `title` element text is the root `table` attribute. The document contains an HTML `table` element with `border="1"`, a `thead` with one `th` per `<column>` using its `label` in document order, and a `tbody` with one `tr` per result row. Each `tr` has one `td` per selected column value in column order. A database NULL value renders as the empty string.
