Write a Python program in one file named `report.py`. It reads one report definition XML file and one SQLite database file, then writes one HTML report to stdout.

Command line:

`python report.py --config <xml-path> --db <sqlite-path> [--filter <column>=<value>]...`

`--config` is the path to the XML file. `--db` is the path to the SQLite database file. `--filter` may appear zero or more times. Each `--filter` value has the form `column=value`; split it on the first `=`.

The XML file has this structure:

```xml
<report table="sales">
  <column name="region" label="Region"/>
  <column name="amount" label="Amount"/>
  <filter name="region"/>
  <filter name="year"/>
</report>
```

1. Read the XML file. Use the root report element's `table` attribute and its `<column>` child elements in document order. The `<filter name="...">` child elements list the filter columns that are allowed.

2. Query the SQLite database file with a SELECT over the report table. Select exactly the columns named by the `<column>` elements in document order. Apply each `--filter` as an equality condition on the column named before the first `=`. If a `--filter` names a column that is not in the root report element's `<filter>` child elements, print `unknown filter: <name>` to stderr and exit with code 1.

3. Write one HTML document to stdout. The document title is the report table attribute. The document contains a table with `border="1"`, a `thead` with one `th` per column using the column `label` in document order, and a `tbody` with one `tr` per query result row. Each `tr` has one `td` per selected column value in column order. Database NULL values render as the empty string.
