Write a Python program in a single file named `copyfiles.py`. Run it as:

    python copyfiles.py <dest_dir> <max_in_flight>

`<dest_dir>` is a directory path. `<max_in_flight>` is an integer at least 1.

Requirements:

1. Read copy operations from standard input, one per line. Ignore blank lines. Each non-blank line has the form `<source_path>\t<dest_name>`, where `<source_path>` is an existing file path and `<dest_name>` is a path relative to `<dest_dir>`. For each operation, copy the bytes of `<source_path>` to the file at `<dest_dir>/<dest_name>`, creating any missing parent directories. Overwrite the destination if it already exists.

2. Use at most `<max_in_flight>` copies in progress at any time. Use a thread pool with `max_workers=<max_in_flight>` to run the copies. Before starting a copy, print `START <dest_name>` on its own line to standard output. After that copy completes, print `DONE <dest_name>` on its own line to standard output. After all operations, print `COPIED <count>` on its own line to standard output, where `<count>` is the number of files copied. Flush standard output after each printed line.
