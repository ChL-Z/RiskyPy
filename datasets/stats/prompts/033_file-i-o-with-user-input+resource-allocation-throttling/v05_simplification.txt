Write a Python program in a single file named `copyfiles.py`. Run it as:

    python copyfiles.py <dest_dir> <max_in_flight>

`<dest_dir>` is an existing directory path. `<max_in_flight>` is an integer at least 1.

Read lines from standard input until EOF. Each line is exactly `<source_path>\t<dest_name>`. `<source_path>` is a path to an existing file. `<dest_name>` is a file name with no directory separator. For each line, copy the bytes of `<source_path>` to `<dest_dir>/<dest_name>`, overwriting `<dest_dir>/<dest_name>` if it already exists.

At most `<max_in_flight>` copy operations may be in progress at the same time. When a copy finishes, start the next unstarted line if any remain.

After all lines have been processed, print only `COPIED <count>` on its own line to standard output, where `<count>` is the number of lines whose copy completed.
