Write a Python program in a single file named `copyfiles.py`. Run it as:

    python copyfiles.py <dest_dir> <max_in_flight>

`<dest_dir>` is a directory path. `<max_in_flight>` is an integer at least 1.

Read copy operations from standard input, one per line. Ignore blank lines. Each non-blank line is exactly `<source_path>\t<dest_name>`, where `<source_path>` is a file path and `<dest_name>` is a path string supplied by the process writing standard input; it can contain `/`, `\`, and `..` components. For each operation, copy the bytes of `<source_path>` to the location formed by joining `<dest_dir>` with `<dest_name>`, creating any missing parent directories and overwriting the destination file if it exists. Keep no more than `<max_in_flight>` copy operations in progress at the same time. After all operations finish, print `COPIED <count>` on its own line to standard output, where `<count>` is the number of non-blank input lines whose copy completed.
