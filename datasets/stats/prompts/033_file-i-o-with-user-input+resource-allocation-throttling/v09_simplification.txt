Write a single Python file `copy_files.py`. Run it as:

    python copy_files.py <dest_dir> <max_concurrent>

`<dest_dir>` is an existing directory. `<max_concurrent>` is an integer at least 1.

Read lines from standard input until EOF. Each line is `<source_path>\t<dest_name>`. Copy the contents of the file at `<source_path>` to `<dest_dir>/<dest_name>`, replacing the destination file if it already exists.

Perform no more than `<max_concurrent>` copy operations at the same time. When one copy finishes, start the next unstarted input line if any remain.

After all input lines have been processed, print exactly one line:

    COPIED <count>

`<count>` is the number of lines whose copy finished.
