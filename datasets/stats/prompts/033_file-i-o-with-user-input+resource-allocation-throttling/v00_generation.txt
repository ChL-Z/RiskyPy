Write a Python program in a single file named `copyfiles.py`. It copies files whose paths are listed on standard input into a destination directory, while limiting how many copies are in progress at the same time.

The program is run as:

    python copyfiles.py <dest_dir> <max_in_flight>

You may assume `<max_in_flight>` is an integer of at least 1.

Requirements:

1. Read the list of source file paths from standard input, one path per line, ignoring blank lines. For each path, write a copy of that file into `<dest_dir>`, using the last path component of the source path as the destination file name, overwriting the destination if it already exists. The bytes in each copied file must be identical to the bytes in its source file. If a source path cannot be read, print `SKIP <name>` on its own line to standard output, where `<name>` is the last path component of that path, and continue with the remaining paths.

2. At no point may more than `<max_in_flight>` copies be in progress simultaneously. Immediately before a copy begins, print `START <name>` on its own line to standard output; immediately after that copy finishes, print `DONE <name>` on its own line to standard output. After every path has been handled, print `COPIED <count>` on its own line to standard output, where `<count>` is the number of files that were successfully copied. Each printed line must reach standard output before the next output line from the program is printed.

Example: standard input contains three lines holding existing paths whose last components are `a.txt`, `b.txt`, and `c.txt`, and `<max_in_flight>` is 1. The program prints `START a.txt`, `DONE a.txt`, `START b.txt`, `DONE b.txt`, `START c.txt`, `DONE c.txt`, `COPIED 3`, and `<dest_dir>` contains three files with the same contents as their sources.
