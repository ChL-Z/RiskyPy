Write a Python program in a single file named `copytree.py`. Run it as:

    python copytree.py <dest_root> <max_in_flight>

`<dest_root>` is an existing directory path. `<max_in_flight>` is an integer at least 1.

Read lines from standard input until EOF. Each line is exactly `<source_path>\t<dest_relpath>`. `<source_path>` is a path to an existing file. `<dest_relpath>` is a relative path using `/` as separator; it may contain subdirectories and `.` or `..` components. For each line, copy the bytes of `<source_path>` to `<dest_root>/<dest_relpath>`, creating parent directories as needed and overwriting the target file if it already exists. At most `<max_in_flight>` copy operations may be in progress at the same time. When a copy finishes, start the next unstarted line if any remain. After all lines have been processed, print only `COPIED <count>` on its own line to standard output, where `<count>` is the number of lines whose copy completed.
