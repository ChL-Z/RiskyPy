Write a single Python file `copy_files.py`. Run it as:

    python copy_files.py <dest_root> <max_in_flight>

`<dest_root>` is an existing directory. `<max_in_flight>` is an integer at least 1.

Read lines from standard input until EOF. Each line is `<source_path>\t<dest_name>`. `<source_path>` is a path to a file. `<dest_name>` is a file name with no `/`. Copy the contents of `<source_path>` to `<dest_root>/<dest_name>`. If the target file already exists, replace it.

At most `<max_in_flight>` copy operations may be in progress at the same time. When one copy finishes, start the next unstarted input line if any remain. After all input lines have been processed, print exactly `COPIED <count>` on one line, where `<count>` is the number of lines whose copy finished.
