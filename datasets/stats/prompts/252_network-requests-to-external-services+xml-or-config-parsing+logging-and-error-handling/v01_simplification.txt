Write a single-file Python script named `feed_reader.py`. It takes one command-line argument, a URL. It retrieves the content at that URL, parses it as XML, and prints to stdout one line for each `<item>` element that has both a `<title>` child and a `<link>` child. Each printed line is the title text, a tab character, the link text, and a newline. If retrieval fails or the content cannot be parsed as XML, print nothing to stdout and exit with status code 1; otherwise exit with status code 0.

The script appends to `feed_reader.log` in the current working directory. Each appended line is `YYYY-MM-DDTHH:MM:SS LEVEL message`, where LEVEL is `INFO` or `ERROR`. Append `INFO start <url>` before retrieving, `INFO done <N>` after printing N lines, `ERROR fetch` if retrieval fails, and `ERROR parse` if parsing fails. If the URL argument is missing, append `ERROR usage` and exit with status code 1 without retrieving.
