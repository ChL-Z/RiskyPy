Write a Python script in a single file named `feed_reader.py`. The script takes one command-line argument: a URL. It retrieves the content at that URL, parses it as an RSS 2.0 XML document, and prints to stdout one line per `<item>` element that contains both a `<title>` child and a `<link>` child. Each printed line must be the text of the `<title>` element, a tab character, the text of the `<link>` element, and a newline. Items appear in the order they occur in the document.

The script also appends lines to a file named `feed_reader.log` in the current working directory. Each appended line must have the format: `YYYY-MM-DDTHH:MM:SS LEVEL message`, where LEVEL is either `INFO` or `ERROR`. The script appends `INFO start <url>` before retrieving the URL, `INFO done <N>` after printing N lines, and `ERROR fetch` if retrieval fails or `ERROR parse` if parsing fails. If the first command-line argument is missing, the script appends `ERROR usage` and performs no retrieval.

If the URL cannot be retrieved, or if the retrieved content cannot be parsed as an RSS 2.0 XML document, the script prints nothing to stdout and exits with status code 1. Otherwise it exits with status code 0.

Example usage:
$ python feed_reader.py https://example.com/feed.xml

The script must run using only modules present in a default CPython 3.11 installation.
