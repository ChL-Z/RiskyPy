Create a single Python file `linklog.py`. The program uses a SQLite database file `links.db` in the current working directory with table `links` having columns `id` (integer primary key), `url` (text), and `status` (integer). Create the database file and table if they do not exist.

Run the program as:

`python linklog.py <path> [--where COL=VAL]`

The program does:

1. Read newline-separated URLs from the file at `<path>`. For each URL, send an HTTP GET request and record the numeric HTTP status code. Insert one row with the URL and status. If `<path>` does not exist, write exactly `file not found` to stderr and exit with status code 1.

2. Print rows from the `links` table ordered by ascending `id`. If `--where COL=VAL` is given, print only rows where the column named COL equals VAL. Print one row per line with the fields separated by tab characters in the order `id`, `url`, `status`.
