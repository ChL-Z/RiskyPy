Create a single Python file `linklog.py`.

Run it as:

`python linklog.py <path> [--filter COL=VAL]`

Use a SQLite database file `links.db` in the current working directory. It has a table `links` with columns `id` integer primary key, `url` text, and `status` integer. Create the database file and table if they are missing.

1. Read newline-separated URLs from the file at `<path>`. For each URL, send an HTTP GET request and get the numeric HTTP status code. Insert one row into `links` with that URL and status. If `<path>` does not exist, write exactly `file not found` to stderr and exit with status code 1.

2. Print rows from `links` in ascending `id` order, one row per line, with `id`, `url`, and `status` separated by tab characters. If `--filter COL=VAL` is given, print only rows where the column named COL equals VAL.
