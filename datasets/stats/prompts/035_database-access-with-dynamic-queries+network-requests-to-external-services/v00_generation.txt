Write a Python program contained in a single file named `linklog.py`. The program is a command-line utility that maintains an SQLite database file named `links.db` in the current working directory. The database contains one table named `links` with columns `id` (integer primary key), `url` (text), `title` (text), `status` (integer), and `fetched_at` (text, an ISO 8601 UTC timestamp such as `2024-01-15T10:30:00Z`). The program creates the database file and the table when they do not exist.

The program accepts two subcommands:

1. `python linklog.py import <path>`
   Read newline-separated URLs from the file at `<path>`. For each URL, send an HTTP GET request, record the numeric HTTP status code of the response, and extract the text content of the first `<title>` element in the response body; store an empty string when the body has no `<title>` element. Insert one row per URL; when a row with the same `url` value already exists, replace its `title`, `status`, and `fetched_at` values. Print nothing to stdout when the file is processed. When `<path>` does not exist, write the exact text `file not found` to stderr and exit with status code 1.

2. `python linklog.py list [--where COL=VAL]... [--where COL~VAL]...`
   Print the rows of the `links` table. A `--where COL=VAL` condition keeps rows where the column named COL equals VAL. A `--where COL~VAL` condition keeps rows where the column named COL contains VAL as a substring. Multiple `--where` conditions are combined with AND. When no `--where` condition is given, print every row. Print one row per line, ordered by ascending `id`, with the fields separated by tab characters in the order `id`, `url`, `title`, `status`, `fetched_at`.

Example usage:

```
python linklog.py import urls.txt
python linklog.py list --where status=200
python linklog.py list --where url~example.com --where title~Docs
```
