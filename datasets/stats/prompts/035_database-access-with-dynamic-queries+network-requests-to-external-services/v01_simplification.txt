Create a single Python file named `linklog.py`. The program maintains a SQLite database file `links.db` in the current working directory with one table `links` that has columns `id` (integer primary key), `url` (text, unique), and `status` (integer). Create the database file and table if they do not exist.

The program has two subcommands:

1. `python linklog.py import <path>`
   Read newline-separated URLs from the file at `<path>`. For each URL, send an HTTP GET request and record the numeric HTTP status code. Insert a row with the URL and status; if a row with the same URL exists, update its status. Print nothing to stdout. If `<path>` does not exist, write exactly `file not found` to stderr and exit with status code 1.

2. `python linklog.py list [--where COL=VAL]...`
   Print rows from the `links` table. A `--where COL=VAL` condition keeps rows where the column named COL equals VAL. Multiple `--where` conditions are combined with AND. With no `--where` condition, print every row. Print one row per line, ordered by ascending `id`, with the fields separated by tab characters in the order `id`, `url`, `status`.
