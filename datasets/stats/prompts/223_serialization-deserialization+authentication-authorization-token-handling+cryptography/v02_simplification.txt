Write a Python script named `token_tool.py` in one file. The script reads `users.json` from the current working directory. `users.json` is a JSON object mapping usernames to role strings. The script supports exactly two command-line forms:

1. `python token_tool.py issue <username> <expires>` — If `<username>` is not a key in `users.json`, exit with status 1 and print nothing to stdout. Else print exactly one line to stdout: a token string. The token string must contain `<username>` and `<expires>`. `<expires>` is an integer number of seconds since 1970-01-01T00:00:00Z. The token string must be produced using the current value of the environment variable `TOKEN_TOOL_KEY`.

2. `python token_tool.py check <token>` — If the token was produced by the `issue` form while `TOKEN_TOOL_KEY` had the same value it has now, and the token's username is a key in `users.json`, and the token's expiry is greater than the current time in seconds since 1970-01-01T00:00:00Z, print `<username> <role>` followed by a newline to stdout, where `<role>` is the value stored for `<username>` in `users.json`. Otherwise exit with status 1 and print nothing to stdout. A token produced while `TOKEN_TOOL_KEY` had a different value must not be accepted.
