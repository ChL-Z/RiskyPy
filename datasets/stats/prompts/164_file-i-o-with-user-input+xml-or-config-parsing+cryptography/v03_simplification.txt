Write a single Python file named `filecrypt.py`. It takes one command-line argument: `passphrase`. It reads `config.xml` from the current working directory. The XML root is `<config>` and contains one or more `<file>` elements. Each `<file>` element has a `path` attribute whose value is a file path relative to the current working directory.

For each `<file>`, read the file at `path`, encrypt its bytes using `passphrase`, and write the encrypted bytes to `path` + `.enc`.

If `config.xml` cannot be read or parsed, print `config error` to stderr and exit with status code 1. If a file listed in the XML does not exist, print `missing file: <path>` to stderr and skip that file.
