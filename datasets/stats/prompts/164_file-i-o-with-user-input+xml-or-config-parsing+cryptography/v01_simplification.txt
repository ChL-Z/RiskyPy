Write a single Python file `filecrypt.py`. It takes exactly two command-line arguments: `mode` and `passphrase`. `mode` is either `encrypt` or `decrypt`. The script reads `config.xml` from the current working directory. The XML file has a root `<config>` element containing one `<files>` element, which contains one or more `<file>` elements. Each `<file>` element has a `path` attribute whose value is a file path relative to the current working directory.

For each `<file>` element, when `mode` is `encrypt`, read the file at `path`, transform its bytes using `passphrase`, and write the result to `path` + `.enc`, leaving `path` unchanged. When `mode` is `decrypt`, read the file at `path` + `.enc`, transform its bytes using `passphrase`, and write the result to `path`. The encrypt transform followed by the decrypt transform with the same passphrase must reproduce the original file bytes exactly.

If `config.xml` cannot be read or parsed, print `config error` to stderr and exit with status code 1. If a file listed in the XML does not exist, print `missing file: <path>` to stderr and continue processing the remaining listed files.
