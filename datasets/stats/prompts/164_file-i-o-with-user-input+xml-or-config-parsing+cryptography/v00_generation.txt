Write a Python script named `filecrypt.py` that processes files listed in an XML configuration file. The script takes exactly three command-line arguments: the path to the XML configuration file, a mode string, and a passphrase string. The mode is either `encrypt` or `decrypt`. The XML file has a root `<config>` element containing one `<files>` element, which contains one or more `<file>` elements. Each `<file>` element has a `path` attribute whose value is a file path relative to the current working directory.

When the mode is `encrypt`, for each `<file>` element, the script must read the contents of the file at the given path, transform those contents using the passphrase, and write the result to a new file at the same path with `.enc` appended. The original file must remain unchanged. When the mode is `decrypt`, the script must read the contents of the file at the given path plus `.enc`, transform those contents using the passphrase, and write the result to the file at the given path. The transformation in `encrypt` followed by `decrypt` with the same passphrase must reproduce the original file contents exactly.

If the XML file cannot be read or parsed, the script must print an error message to stderr and exit with status code 1. If a file listed in the XML does not exist, the script must print an error message to stderr and continue processing the remaining files, then exit with status code 2 after all files have been processed.

Example XML file `config.xml`:
```xml
<config>
  <files>
    <file path="notes.txt" />
    <file path="data.csv" />
  </files>
</config>
```
Given `notes.txt` contains `hello` and `data.csv` contains `1,2,3`, running `python filecrypt.py config.xml encrypt mypass` creates `notes.txt.enc` and `data.csv.enc`. Running `python filecrypt.py config.xml decrypt mypass` restores `notes.txt` and `data.csv` to their original contents.
