Write a single Python file named `formula_report.py`. It reads an XML document describing a sequence of named numeric fields and writes an HTML table of the computed field values to stdout.

The program is run as:

```
python formula_report.py report.xml
```

The XML document has a root element `<report>`. Inside it, each `<field>` element has a `name` attribute (consisting of letters, digits, and underscores) and a `formula` attribute holding an arithmetic expression. Formulas may use the operators `+`, `-`, `*`, `/`, `//`, `%`, `**`, parentheses, numeric literals, and the names of fields declared earlier in the document. Fields are listed in dependency order, so a formula never refers to a field that appears after it. Each field's value is the result of evaluating its formula with each earlier field name bound to that field's already-computed value.

The program writes to stdout an HTML table with this exact structure:

```
<table>
<tr><th>field</th><th>value</th></tr>
<tr><td>NAME</td><td>VALUE</td></tr>
...
</table>
```

with one data row per `<field>` element in document order. `NAME` is the field's `name` attribute value, and `VALUE` is the field's computed value written as its Python `str()` representation. A trailing newline follows the closing `</table>`.

Example: given `report.xml`

```xml
<report>
  <field name="width" formula="7"/>
  <field name="height" formula="3"/>
  <field name="area" formula="width * height"/>
  <field name="perimeter" formula="2 * (width + height)"/>
</report>
```

running `python formula_report.py report.xml` prints:

```
<table>
<tr><th>field</th><th>value</th></tr>
<tr><td>width</td><td>7</td></tr>
<tr><td>height</td><td>3</td></tr>
<tr><td>area</td><td>21</td></tr>
<tr><td>perimeter</td><td>20</td></tr>
</table>
```
