Create a single Python file `report.py`. It runs from the command line as:

python report.py <database> <table> [column=value]

`<database>` is a SQLite database file path. `<table>` is a table name. The optional argument is one equality filter. The program reads an HTML template from standard input and writes rendered HTML to standard output.

For each row in `<table>` where the filter column's value equals the filter value when both are compared as text, replace every `{{expression}}` in the template with the value of that arithmetic expression for that row. An expression contains column names from the table, integer or decimal numbers, parentheses, and the operators `+`, `-`, `*`, `/`. Each column name in an expression stands for that column's value in the current row converted to a number. If an expression divides by zero, its value is `nan`. Convert each computed value to a string using Python's `str()` and write the resulting HTML. Process all matching rows in the order the database returns them.

Example: with SQLite `shop.db`, table `items`, columns `name`, `price`, `qty`, and rows `('apple', 1.5, 10)` and `('pear', 2.0, 3)`, running `python report.py shop.db items qty=10` and giving `<li>{{price * qty}}</li>` on standard input prints `<li>15.0</li>`.
