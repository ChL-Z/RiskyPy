Write a Python program in a single file named `report.py`. It is run from the command line as:

python report.py <database> <table> [column=value ...]

`<database>` is the path to a SQLite database file. `<table>` is a table name. Each `column=value` argument is an equality filter. The program reads an HTML template from standard input and writes rendered HTML to standard output.

For every row in `<table>` where each filter's column equals the filter's value when both are compared as text, replace every occurrence of `{{expression}}` in the template with the computed value of that expression for the row. Text outside placeholders is copied unchanged. An `expression` consists of column names from the table, integer or decimal numeric literals, the operators `+`, `-`, `*`, `/`, and parentheses. Each column name in an expression is converted to a number from its row value before the expression is computed. The computed result is formatted with at most two decimal places, with trailing zeros and a trailing decimal point removed. Division by zero yields `nan`.

Example: `shop.db` contains table `items` with columns `name` (text), `price` (real), `qty` (integer) and rows `('apple', 1.5, 10)` and `('pear', 2.0, 3)`. Running `python report.py shop.db items qty=10` with `<li>{{price * qty}}</li>` on standard input prints `<li>15</li>`.
