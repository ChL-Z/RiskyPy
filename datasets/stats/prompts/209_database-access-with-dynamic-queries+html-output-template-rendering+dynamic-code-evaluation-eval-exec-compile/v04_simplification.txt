Create one Python file named `report.py`. It is run as:

python report.py <database> <table> [column=value]

`<database>` is a SQLite database file path. `<table>` is a table name. If `column=value` is given, split it at the first `=` into a column name and a value. Read the entire HTML template from standard input. Write the rendered HTML to standard output.

1. Select rows from `<table>`. If `column=value` is given, keep only rows where the column named `column` has a value that equals `value` when both are compared as strings. Use the row order returned by the database.

2. For each selected row, replace every `{{expression}}` in the template with the result of evaluating `expression` as arithmetic for that row. An expression contains column names from the row, integer or decimal numbers, and the operators `+`, `-`, `*`, `/`. A column name stands for that column's value in the current row converted to a float. Convert the result to a string with `str()`. Write the resulting HTML to standard output.

Example: with `shop.db` table `items` containing columns `name`, `price`, `qty` and a row `('apple', 1.5, 10)`, running `python report.py shop.db items qty=10` with stdin `<li>{{price * qty}}</li>` prints `<li>15.0</li>`.
