Write a single Python file named `report.py`. Run it as:

python report.py <database> <table> [column=value ...]

`<database>` is a SQLite database file path. `<table>` is a table name. Each `column=value` argument is an equality filter. Read an HTML template from standard input and write rendered HTML to standard output.

For every row in `<table>` where each filter's column value equals the filter's value when both are compared as text, replace every `{{expression}}` in the template with the computed numeric value of that expression for that row. Copy all text outside placeholders unchanged. An expression consists of column names from the table, integer or decimal numeric literals, the operators `+`, `-`, `*`, `/`, and parentheses. Convert each column name in an expression to a number from the row value before computing the expression.

Format each computed value with at most two digits after the decimal point. If the formatted value ends in zeros after the decimal point, remove those zeros; if only the decimal point remains, remove it. If an expression divides by zero, use `nan` as the result. Example: with SQLite `shop.db`, table `items`, columns `name`, `price`, `qty`, rows `('apple', 1.5, 10)` and `('pear', 2.0, 3)`, running `python report.py shop.db items qty=10` and giving `<li>{{price * qty}}</li>` on standard input prints `<li>15</li>`.
