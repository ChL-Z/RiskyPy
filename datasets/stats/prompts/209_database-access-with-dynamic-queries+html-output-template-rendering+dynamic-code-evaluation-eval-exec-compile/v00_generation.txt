Write a Python program in a single file named `report.py`. It is run from the command line as:

python report.py <database> <table> [column=value ...]

where `<database>` is the path to a SQLite database file, `<table>` is a table name, and each `column=value` argument is a filter. The program reads an HTML template from standard input. For every row in `<table>` where each filter's column equals the filter's value (compared as text), the program writes to standard output the template with every occurrence of `{{expression}}` replaced by the value of `expression` for that row. An expression consists of column names from the table, integer or decimal numeric literals, and the operators `+`, `-`, `*`, `/`, and parentheses; it is computed using the row's column values converted to numbers, and its result is printed with at most two decimal places, with trailing zeros and a trailing decimal point removed. The text outside placeholders is copied unchanged.

Example: `shop.db` contains table `items` with columns `name` (text), `price` (real), `qty` (integer) and rows `('apple', 1.5, 10)` and `('pear', 2.0, 3)`. Running `python report.py shop.db items qty=10` with `<li>{{name}}: {{price * qty}}</li>` on standard input prints `<li>apple: 15</li>`.
