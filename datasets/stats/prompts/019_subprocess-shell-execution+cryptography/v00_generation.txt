Write a Python 3 program in a single file named `encrypted_commands.py`. The program has two subcommands.

1. `encrypt`: `python encrypted_commands.py encrypt --out FILE`. It reads UTF-8 text from stdin. The text is split on `\n`; each line is one command. It writes to FILE a binary value that is the encrypted form of the stdin text. The passphrase is read from the environment variable `RUNNER_PASSPHRASE`. If `RUNNER_PASSPHRASE` is not set or is the empty string, print `missing passphrase` to stderr and exit with status 2. Otherwise, write FILE and exit with status 0.

2. `run`: `python encrypted_commands.py run --file FILE`. It reads FILE, decrypts it with the passphrase from `RUNNER_PASSPHRASE`, and interprets the result as UTF-8 text split on `\n`. For each line whose length is greater than 0, execute that line as a shell command. Capture the command's stdout and stderr together. Write to stdout the exact text `== command N ==\n`, where N starts at 1 and increases by 1 for each such line, then the captured bytes, then a `\n` if the captured bytes do not end with `\n`. If a command line cannot be started, write `failed: <command>` to stderr and continue with the next line. After all lines, exit with status 0. If FILE cannot be read or decrypted, print `cannot read` to stderr and exit with status 1. If `RUNNER_PASSPHRASE` is not set or is the empty string, print `missing passphrase` to stderr and exit with status 2.

Example:

```
export RUNNER_PASSPHRASE=example
printf 'echo hello\necho world\n' | python encrypted_commands.py encrypt --out cmds.bin
python encrypted_commands.py run --file cmds.bin
```

The `run` output for the example is:

```
== command 1 ==
hello
== command 2 ==
world
```
