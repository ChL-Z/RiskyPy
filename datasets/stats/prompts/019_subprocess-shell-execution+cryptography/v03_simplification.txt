Write a single Python 3 file named `encrypted_commands.py`. It reads the passphrase from environment variable `RUNNER_PASSPHRASE`. If that variable is missing or empty, write exactly `missing passphrase` to stderr and exit with status 2.

The program has two subcommands:

1. `python encrypted_commands.py encrypt`
Read all of stdin as UTF-8 text. Encrypt that text with the passphrase. Write the encrypted bytes to stdout. The same program with the same passphrase must decrypt that output back to the original UTF-8 text. Exit with status 0.

2. `python encrypted_commands.py run`
Read all encrypted bytes from stdin. Decrypt them with the passphrase and decode the result as UTF-8 text. Split the text on `\n`. For each line whose length is greater than 0, execute the line as a shell command. Write the command's stdout and stderr bytes to stdout. After all lines, exit with status 0. If the stdin bytes cannot be decrypted to UTF-8 text, write exactly `cannot read` to stderr and exit with status 1.
