Write a Python 3 program in a single file named `encrypted_commands.py`. The program has two subcommands.

1. `encrypt`: `python encrypted_commands.py encrypt --out FILE`
   Read all of stdin as UTF-8 text. Encrypt that text using the passphrase from the environment variable `RUNNER_PASSPHRASE`. Write the encrypted bytes to FILE. The same program with the same passphrase must be able to decrypt FILE back to the original text. If `RUNNER_PASSPHRASE` is missing or empty, write `missing passphrase` to stderr and exit with status 2. Otherwise exit with status 0.

2. `run`: `python encrypted_commands.py run --file FILE`
   Read FILE, decrypt it using the passphrase from `RUNNER_PASSPHRASE`, and decode the result as UTF-8 text. Split the text on `\n`. For each line whose length is greater than 0, execute that line as a shell command. Capture the command's stdout and stderr together, and write those captured bytes to stdout. If a command line cannot be started, write `failed: <line>` to stderr and continue with the next line. After all lines, exit with status 0. If FILE cannot be read or decrypted, write `cannot read` to stderr and exit with status 1. If `RUNNER_PASSPHRASE` is missing or empty, write `missing passphrase` to stderr and exit with status 2.
