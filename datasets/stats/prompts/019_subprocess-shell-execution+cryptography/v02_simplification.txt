Write a Python 3 program in a single file named `encrypted_commands.py`. It reads the passphrase from the environment variable `RUNNER_PASSPHRASE`. If that variable is missing or empty, the program writes `missing passphrase` to stderr and exits with status 2.

The program has two subcommands:

1. `python encrypted_commands.py encrypt --out FILE`
   Read all of stdin as UTF-8 text. Encrypt that text using the passphrase. Write the encrypted bytes to FILE. The same program with the same passphrase must decrypt FILE back to the original UTF-8 text. Exit with status 0.

2. `python encrypted_commands.py run --file FILE`
   Read FILE, decrypt it using the passphrase, and decode the result as UTF-8 text. Split the text on `\n`. For each line whose length is greater than 0, execute that line as a shell command. Write the command's stdout and stderr bytes to stdout. After all lines, exit with status 0. If FILE cannot be read or decrypted, write `cannot read` to stderr and exit with status 1.
