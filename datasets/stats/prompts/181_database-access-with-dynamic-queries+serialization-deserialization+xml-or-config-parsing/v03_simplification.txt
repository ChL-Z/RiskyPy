Write a Python program in a single file named `report.py`. It takes two command-line arguments: the path to an XML configuration file and the path to a cache file. It prints rows to stdout. Each printed row has its fields joined by one tab character followed by a newline. An empty database value prints as an empty string. Column order is the order returned by the database query.

1. If the cache file exists, read it. The cache file contains one row per line, with fields separated by one tab character. An empty field means NULL. Print each row in the same tab-separated format.

2. If the cache file does not exist, read the XML configuration, run a query against the SQLite database file named in it, write the resulting rows to the cache file in the format described in requirement 1, and print the rows.

The XML configuration has this shape:

```xml
<query>
  <database>sales.db</database>
  <table>orders</table>
</query>
```

`<database>` is the SQLite database file path relative to the XML file's directory. `<table>` is the table name. The query selects all columns from the table.
