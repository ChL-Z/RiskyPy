Write a Python program in a single file named `report.py`. The program takes exactly two command-line arguments: a path to an XML configuration file and a path to a cache file. It prints rows to stdout. Each row is printed by joining its values with one tab character and then writing a newline. A NULL database value prints as an empty string. Column order is the order returned by the database query.

1. If the cache file exists, read the rows from it as a list of tuples and print them.

2. If the cache file does not exist, read the XML configuration, query the SQLite database file named in it, write the resulting rows to the cache file so they can later be read as a list of tuples, and print the rows.

The XML configuration uses this shape:

```xml
<query>
  <database>sales.db</database>
  <table>orders</table>
  <filter column="amount" operator="gt" value="100"/>
</query>
```

`<database>` is the path to the SQLite database file relative to the XML file's directory. `<table>` is the table name. Zero or one `<filter>` element may appear after `<table>`. A filter has `column`, `operator`, and `value` attributes. `operator` is either `eq` or `gt`, meaning `=` or `>`. The query selects all columns from the table and includes a WHERE clause for the filter if one is present. If no filter is present, the query has no WHERE clause.
