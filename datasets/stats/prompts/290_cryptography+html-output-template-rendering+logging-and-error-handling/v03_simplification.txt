Write a single Python file `receipt_tool.py` that is run from the command line as:

python receipt_tool.py --records purchases.txt --key key.txt --out receipt.html

1. Read the file named by `--records` line by line. Skip lines that are empty or contain only whitespace. For every other line, split the line on commas. If the split produces exactly three fields, the first field is non-empty, and the second and third fields are integer strings, write `INFO <first> <second>` to stderr and keep that purchase as `<name>`, `<qty>`, `<price_cents>`. Otherwise write `ERROR line <n>` to stderr, where `<n>` is the 1-based line number, and continue with later lines. Keep the purchases in the order they appear in the file.

2. Read the file named by `--key` as a string. Compute a deterministic signature string from the key string and the kept purchases in order. The signature must consist only of lowercase hexadecimal digits and be at least 32 characters long. Running the program again with the same `--records` and `--key` inputs must produce the same signature.

3. Write the file named by `--out` as HTML. It contains a `<table>` with one `<tr>` per kept purchase, in the same order, each row having three `<td>` elements: the item name, the quantity, and `qty * price_cents / 100` formatted with exactly two digits after the decimal point. Directly below the table, include `<p>Signature: <code>HEX</code></p>` where `HEX` is the signature string.
