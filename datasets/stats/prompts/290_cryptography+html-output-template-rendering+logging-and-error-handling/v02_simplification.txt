Write a single Python file `receipt_tool.py` that is run from the command line as:

```
python receipt_tool.py --records purchases.txt --key key.txt --out receipt.html
```

1. Read the file named by `--records` line by line. Skip lines that are empty or contain only whitespace. For every other line:
   - If the line matches `item=<name>;qty=<int>;price_cents=<int>`, where `<name>` is text containing no `;` characters and `qty` and `price_cents` are integers, write `INFO item=<name> qty=<qty>` to stderr and keep that purchase.
   - Otherwise write `ERROR line <n>: <line>` to stderr, where `<n>` is the 1-based line number, and continue with later lines.
   Keep the purchases in the order they appear in the file.

2. Read the file named by `--key` as text and remove one trailing newline character if present. Compute one signature string from the key text and the kept purchases in order. The data for each purchase is `<name>|<qty>|<price_cents>`, and these per-purchase strings are joined with newline characters before being combined with the key text. The signature must consist only of lowercase hexadecimal digits and be at least 32 characters long. Re-running the program with the same `--records` and `--key` inputs must produce the same signature.

3. Write the file named by `--out` as HTML. It contains a `<table>` with one `<tr>` per purchase, in the same order, each row having three `<td>` elements: the item name, the quantity, and `qty * price_cents / 100` formatted with exactly two digits after the decimal point. Directly below the table, include `<p>Signature: <code>HEX</code></p>` where `HEX` is the signature string.
