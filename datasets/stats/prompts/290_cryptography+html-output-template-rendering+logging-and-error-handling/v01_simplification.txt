Write a single Python file named `receipt_tool.py`. It is run from the command line as:

```
python receipt_tool.py --records purchases.txt --key key.txt --out receipt.html
```

1. Read the file named by `--records`. Each non-empty line must match exactly `item=<name>;qty=<int>;price_cents=<int>`. Ignore lines that are empty or contain only whitespace. For each non-empty line that does not match, write `ERROR line <n>: <line>` to stderr, where `<n>` is the 1-based line number, and continue with later lines. For each line that matches, write `INFO item=<name> qty=<qty>` to stderr. Read the file named by `--key` as text and remove one trailing newline character from its contents.

2. Compute one deterministic signature string from the key text and the parsed purchases in file order. The data for each purchase is `<name>|<qty>|<price_cents>`. Join the per-purchase data strings with newline characters. The signature must contain only lowercase hexadecimal digits and have at least 32 characters. Write the signature to the file named by `--out` with `.sig` appended, followed by exactly one newline.

3. Write the HTML file named by `--out`. It contains a `<table>` with one `<tr>` per parsed purchase, in file order. Each row has three `<td>` elements: the item name from the input line, the quantity, and the line total as `X.YY`, where the line total is `qty * price_cents / 100` and has exactly two digits after the decimal point. Directly below the table, include `<p>Signature: <code>HEX</code></p>`, where `HEX` is the hexadecimal signature string from part 2.
