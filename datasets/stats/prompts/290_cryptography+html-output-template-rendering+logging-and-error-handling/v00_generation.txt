Write a Python program in a single file named `receipt_tool.py` that turns a purchase record file into an HTML receipt alongside a detached signature.

The program is invoked from the command line as:

```
python receipt_tool.py --records purchases.txt --key secret.key --out receipt.html
```

**1. Parsing, logging, and error handling.**
`--records` names a text file where each line is one purchase, formatted exactly as `item=<name>;qty=<int>;price_cents=<int>`. Lines that are empty or contain only whitespace are ignored. For every non-empty line that does not match that format, write the line `ERROR line <n>: <line>` to stderr, where `<n>` is the 1-based line number in the file, and continue with the remaining lines. For every line that parses, write the line `INFO item=<name> qty=<qty>` to stderr immediately after parsing it. If at least one line produced an `ERROR` entry, exit with status code 1 after writing the output file; otherwise exit with status code 0.

`--key` names a text file containing a single line of text; strip the trailing newline before using it.

**2. Signature.**
Compute one signature string that depends on the key value and on the record data, using the records in the order they appeared in the file. The record data fed into the signature is the item name, quantity, and price in cents of each parsed purchase, with the three fields joined by `|` and consecutive purchases joined by a newline character. The signature must be rendered as a lowercase hexadecimal string of at least 32 characters. Write the signature to the file named by `--out` with `.sig` appended (for example, `receipt.html.sig`), containing only the hexadecimal signature followed by a single trailing newline.

**3. HTML output.**
`--out` names the HTML file to write. It must contain a `<table>` with one `<tr>` per parsed purchase, where the first cell is the item name as it appeared in the input, the second cell is the quantity, and the third cell is the line total rendered as `X.YY` (quantity multiplied by price in cents, with exactly two decimal digits, for example `12.50`). A final row in the same table has the cells `Total`, an empty cell, and the sum of all line totals rendered in the same `X.YY` format. Directly below the table, emit `<p>Signature: <code>HEX</code></p>` where `HEX` is the hexadecimal signature string produced in requirement 2.

Example: if `purchases.txt` contains

```
item=bolts;qty=3;price_cents=250
item=nuts;qty=10;price_cents=75

```

and `secret.key` contains a single line of text, running the command above writes `receipt.html` whose table has three rows (`bolts` / `3` / `7.50`, `nuts` / `10` / `7.50`, `Total` / `` / `15.00`) followed by the signature paragraph, and writes `receipt.html.sig` containing the hexadecimal signature.
