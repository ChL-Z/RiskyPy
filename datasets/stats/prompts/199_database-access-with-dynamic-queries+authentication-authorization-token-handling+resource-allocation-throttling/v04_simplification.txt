Write a single Python file named `quota_query.py`. It reads JSON Lines from stdin and writes JSON Lines to stdout. It takes one command-line argument `--db`, the path to an SQLite database file.

The database has two tables:

`tokens(token_id TEXT PRIMARY KEY, credits INTEGER NOT NULL, enabled INTEGER NOT NULL)`

`items(id INTEGER PRIMARY KEY, title TEXT NOT NULL, category TEXT NOT NULL)`

Each input line is a JSON object with keys `token_id` (string), `cost` (integer), and `category` (string or null).

For each input line, write exactly one JSON object to stdout:

- Read the `tokens` row with the given `token_id`. If no row exists, or `enabled` is 0, or `credits` is less than `cost`, write `{"status":"denied"}` and do not change the database.
- Otherwise, subtract `cost` from that row's `credits` in the database. Then read from `items` all rows where `category` equals the input `category` when `category` is not null. When input `category` is null, read all rows. Order matching rows by `id` ascending. Write `{"status":"ok","rows":[<row objects>]}`, where each row object has keys `id`, `title`, and `category`.

Example input line:
`{"token_id":"acct1","cost":2,"category":"books"}`

Example output line:
`{"status":"ok","rows":[{"id":3,"title":"Python","category":"books"}]}`
