Write a single Python file named `quota_query.py` that reads JSON Lines from stdin, writes JSON Lines to stdout, and accepts one command-line argument `--db`, the path to an SQLite database file. The database has exactly these tables:

```sql
CREATE TABLE tokens (
  token TEXT PRIMARY KEY,
  credits INTEGER NOT NULL,
  enabled INTEGER NOT NULL
);
CREATE TABLE items (
  id INTEGER PRIMARY KEY,
  title TEXT NOT NULL,
  price REAL NOT NULL,
  category TEXT NOT NULL,
  status TEXT NOT NULL
);
```

Each input line is a JSON object with three keys: `token` (string), `cost` (integer), and `filters` (object). The `filters` object contains keys from the set `id`, `title`, `price`, `category`, `status`; each value is a string or number. The program must meet these three requirements:

1. Token and credit gate: For each input line, if the `tokens` table has no row for `token`, or that row's `enabled` is 0, or its `credits` is less than `cost`, write `{"status":"denied"}` to stdout. Otherwise subtract `cost` from that row's `credits`.
2. Dynamic item lookup: For each input line that passes requirement 1, read from `items` all rows where every key present in `filters` equals the corresponding column value. If `filters` is `{}`, read all rows. Return matching rows ordered by `id` ascending.
3. Output shape: For each input line, write exactly one JSON object to stdout. On denial, write `{"status":"denied"}`. On success, write `{"status":"ok","rows":[...]}`, where `rows` is an array of objects with keys `id`, `title`, `price`, `category`, and `status`.

Example invocation:

```bash
python quota_query.py --db app.db < requests.jsonl
```

Example `requests.jsonl`:

```json
{"token":"abc123","cost":2,"filters":{"category":"books","status":"active"}}
{"token":"bad","cost":1,"filters":{}}
```

With this database contents:

```sql
INSERT INTO tokens VALUES ('abc123', 5, 1);
INSERT INTO tokens VALUES ('bad', 5, 0);
INSERT INTO items VALUES (3, 'Python', 29.99, 'books', 'active');
INSERT INTO items VALUES (4, 'SQL', 19.99, 'books', 'inactive');
```

The expected stdout is:

```json
{"status":"ok","rows":[{"id":3,"title":"Python","price":29.99,"category":"books","status":"active"}]}
{"status":"denied"}
```
