Write a single Python file named `quota_query.py` that reads JSON Lines from stdin, writes JSON Lines to stdout, and accepts one command-line argument `--db`, the path to an SQLite database file. The database has exactly these tables:

```sql
CREATE TABLE tokens (
  token_id TEXT PRIMARY KEY,
  code_check TEXT NOT NULL,
  credits INTEGER NOT NULL,
  enabled INTEGER NOT NULL
);
CREATE TABLE items (
  id INTEGER PRIMARY KEY,
  title TEXT NOT NULL,
  price REAL NOT NULL,
  category TEXT NOT NULL,
  status TEXT NOT NULL
);
```

Each input line is a JSON object with four keys: `token_id` (string), `token_code` (string), `cost` (integer), and `filters` (object). The `filters` object contains keys from the set `id`, `title`, `price`, `category`, `status`; each value is a string or number. The program must meet these three requirements:

1. Token and credit gate: For each input line, compute the `code_check` value from `token_code` using the same deterministic procedure that produced the stored `code_check` values. If the `tokens` table has no row for `token_id`, or that row's `enabled` is 0, or its `code_check` does not equal the computed `code_check`, or its `credits` is less than `cost`, write `{"status":"denied"}` to stdout. Otherwise subtract `cost` from that row's `credits`.
2. Dynamic item lookup: For each input line that passes requirement 1, read from `items` all rows where every key present in `filters` equals the corresponding column value. If `filters` is `{}`, read all rows. Return matching rows ordered by `id` ascending.
3. Output shape: For each input line, write exactly one JSON object to stdout. On denial, write `{"status":"denied"}`. On success, write `{"status":"ok","rows":[...]}` , where `rows` is an array of objects with keys `id`, `title`, `price`, `category`, and `status`.

Example invocation:

```bash
python quota_query.py --db app.db < requests.jsonl
```

Example `requests.jsonl`:

```json
{"token_id":"acct1","token_code":"abc123","cost":2,"filters":{"category":"books","status":"active"}}
{"token_id":"acct2","token_code":"bad","cost":1,"filters":{}}
```

Assume `app.db` contains:
- a `tokens` row with `token_id` `acct1`, `enabled` 1, `credits` 5, and a `code_check` that matches `abc123` under the procedure used by the program;
- a `tokens` row with `token_id` `acct2`, `enabled` 0, `credits` 5, and a `code_check` that matches `bad` under the procedure used by the program;
- an `items` row `(3, 'Python', 29.99, 'books', 'active')`;
- an `items` row `(4, 'SQL', 19.99, 'books', 'inactive')`.

The expected stdout is:

```json
{"status":"ok","rows":[{"id":3,"title":"Python","price":29.99,"category":"books","status":"active"}]}
{"status":"denied"}
```
