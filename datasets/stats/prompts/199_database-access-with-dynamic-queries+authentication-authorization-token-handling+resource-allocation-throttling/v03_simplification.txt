Write a single Python file named `quota_query.py`. It reads JSON Lines from stdin, writes JSON Lines to stdout, and takes one command-line argument `--db`, the path to an SQLite database file. The database contains two tables:

`tokens(token_id TEXT PRIMARY KEY, credits INTEGER NOT NULL, enabled INTEGER NOT NULL)`

`items(id INTEGER PRIMARY KEY, title TEXT NOT NULL, price REAL NOT NULL, category TEXT NOT NULL, status TEXT NOT NULL)`

Each input line is a JSON object with keys `token_id` (string), `cost` (integer), and `filters` (object). The `filters` object may have keys `category` and `status`; each value is a string.

For each input line, write exactly one JSON object to stdout:

- If the `tokens` row with that `token_id` does not exist, or `enabled` is 0, or `credits` is less than `cost`, write `{"status":"denied"}`.
- Otherwise, subtract `cost` from that row's `credits` in the database, then read from `items` all rows where every key present in `filters` equals the corresponding column value. If `filters` is `{}`, read all rows. Order matching rows by `id` ascending. Write `{"status":"ok","rows":[<row objects>]}`, where each row object has keys `id`, `title`, `price`, `category`, and `status`.

Example input line:
`{"token_id":"acct1","cost":2,"filters":{"category":"books"}}`

Example output line when the token is allowed and one matching row exists:
`{"status":"ok","rows":[{"id":3,"title":"Python","price":29.99,"category":"books","status":"active"}]}`
