Write a single Python file named `quota_query.py`. It reads JSON Lines from stdin, writes JSON Lines to stdout, and takes one command-line argument `--db`, the path to an SQLite database file. The database has exactly these tables:

```sql
CREATE TABLE tokens (
  token_id TEXT PRIMARY KEY,
  credits INTEGER NOT NULL,
  enabled INTEGER NOT NULL
);
CREATE TABLE items (
  id INTEGER PRIMARY KEY,
  title TEXT NOT NULL,
  price REAL NOT NULL,
  category TEXT NOT NULL,
  status TEXT NOT NULL
);
```

Each input line is a JSON object with keys `token_id` (string), `cost` (integer), and `filters` (object). The `filters` object has keys from `id`, `title`, `price`, `category`, `status`; each value is a string or number.

1. Token gate and credits: For each input line, read the `tokens` row whose `token_id` equals the input `token_id`. If no row exists, or `enabled` is 0, or `credits` is less than `cost`, write `{"status":"denied"}` to stdout. Otherwise subtract `cost` from that row's `credits` in the database.

2. Item lookup: For each input line that passes step 1, read from `items` all rows where every key present in `filters` equals the corresponding column value. If `filters` is an empty object, read all rows. Order matching rows by `id` ascending.

3. Output: For each input line, write exactly one JSON object to stdout. On denial, write `{"status":"denied"}`. On success, write `{"status":"ok","rows":[...]}`, where `rows` is an array of objects with keys `id`, `title`, `price`, `category`, and `status`.

Example invocation:

```bash
python quota_query.py --db app.db < requests.jsonl
```

Example `requests.jsonl`:

```json
{"token_id":"acct1","cost":2,"filters":{"category":"books","status":"active"}}
{"token_id":"acct2","cost":1,"filters":{}}
```

Assume `app.db` contains:
- a `tokens` row with `token_id` `acct1`, `enabled` 1, `credits` 5;
- a `tokens` row with `token_id` `acct2`, `enabled` 0, `credits` 5;
- an `items` row `(3, 'Python', 29.99, 'books', 'active')`;
- an `items` row `(4, 'SQL', 19.99, 'books', 'inactive')`.

The expected stdout is:

```json
{"status":"ok","rows":[{"id":3,"title":"Python","price":29.99,"category":"books","status":"active"}]}
{"status":"denied"}
```
