Write a Python program in a single file named `invite.py`. It runs from the command line as:

```
python invite.py <users.json> <card.html> <out_dir>
```

`users.json` is a JSON array in file order. Each element is an object with string fields `name`, `email`, `token`, and a boolean field `allowed`. `name` contains only letters, digits, and underscores. `card.html` is a text file. `out_dir` is a directory path; create the directory when it does not exist.

Requirement 1 — render cards for allowed users.
Process the array in order. For each object, if `allowed` is true and `token` is not empty, write `<out_dir>/<name>.html`. Its contents are the full text of `card.html` with every occurrence of `{{name}}` replaced by `name`, every occurrence of `{{email}}` replaced by `email`, and every occurrence of `{{invite_url}}` replaced by `https://app.example.com/invite?user=<name>`. Print `<out_dir>/<name>.html` on its own line to stdout. Otherwise, print `unauthorized <name>` on its own line to stdout.

Requirement 2 — reuse processed names from a previous run.
`<out_dir>/cache.dat` is a file this program writes and reads. It stores the exact text of `card.html` from the run that wrote it and the `name` values from that run. At startup, if `cache.dat` exists and the `card.html` text it stores equals the current contents of `card.html`, then for each object in `users.json` whose `name` is one of the stored names, print `skipped <name>` on its own line to stdout instead of doing the work in requirement 1. Objects whose `name` is not stored are handled by requirement 1. At the end of every run, overwrite `cache.dat` so it stores the current text of `card.html` and the `name` values of all objects in `users.json`.
