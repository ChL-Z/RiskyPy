Write a Python program in a single file named `invite.py`. It runs from the command line as:

```
python invite.py <users.json> <card.html> <out_dir>
```

`users.json` is a JSON array. Each element is an object with string fields `name`, `email`, and `token`. `card.html` is a text file. `out_dir` is a directory path. If `out_dir` does not exist, create it.

Requirement 1 — render cards for users with non-empty tokens.
Process the array in order. For each object:
- If `token` is the empty string, print `denied <name>` on its own line to stdout.
- Otherwise, write `<out_dir>/<name>.html`. Its contents are the full text of `card.html` with every occurrence of `{{name}}` replaced by `name`, every occurrence of `{{email}}` replaced by `email`, and every occurrence of `{{invite_url}}` replaced by `https://app.example.com/invite?user=<name>`. Print `<out_dir>/<name>.html` on its own line to stdout.

Requirement 2 — cache names from a previous run.
`<out_dir>/cache.dat` is a file this program writes and reads. It stores the current text of `card.html` and the `name` values of users whose `token` was not empty in the run that wrote it. At startup, if `cache.dat` exists and the `card.html` text it stores equals the current contents of `card.html`, then for each object in `users.json` whose `token` is not empty and whose `name` is one of the stored names, print `skipped <name>` on its own line to stdout and do not write its HTML file. At the end of every run, overwrite `cache.dat` so it stores the current text of `card.html` and the `name` values of all users in `users.json` whose `token` was not empty.
