Write a Python program contained in a single file named `invite.py`.

It runs from the command line as:

```
python invite.py <users.json> <card.html> <out_dir>
```

`users.json` is a JSON array in file order. Each element is an object with the string fields `name`, `email`, and `token`. `card.html` is a text file. `out_dir` is a directory path; create the directory when it does not exist.

Requirement 1 — render one card per user.
Process the elements of the array in order. For each element, write the file `<out_dir>/<name>.html` whose contents are the full text of `card.html` with every occurrence of the literal substring `{{name}}` replaced by that element's `name`, every occurrence of `{{email}}` replaced by that element's `email`, and every occurrence of `{{invite_url}}` replaced by:

```
https://app.example.com/invite?user=<name>&token=<token>
```

where `<name>` and `<token>` are that element's values percent-encoded so that only the characters `A`-`Z`, `a`-`z`, `0`-`9`, `-`, `_`, `.`, and `~` appear as themselves and every other character is written as `%` followed by two uppercase hexadecimal digits of its UTF-8 byte. For each file written, print the path `<out_dir>/<name>.html` on its own line to stdout.

Requirement 2 — reuse the file list from a previous run.
`<out_dir>/cache.dat` is a file this program writes and reads. It holds the exact text of `card.html` from the run that produced it, together with the user names that run wrote card files for. At startup, if `cache.dat` exists and the `card.html` text it holds equals the current contents of `card.html`, then for each element of `users.json` whose `name` is one of the stored names, write no card file and instead print `skipped <name>` on its own line to stdout at that element's position in the order. Every runner remaining after that check is rendered as described in requirement 1. At the end of every run, whether or not the previous cache was reused, overwrite `cache.dat` so that it holds the current text of `card.html` and the names of all elements of `users.json` from that run.
