Write a Python 3 program in a single file named `jobrunner.py`.

The program takes one command-line argument: the path to an XML file. The XML root element is `<job>` with attributes `command` and `logfile`. Example:

<job command="ls -la" logfile="job.log"/>

Requirements:

1. Read the XML file. If the file cannot be read or parsed, or the root element is not `<job>`, print exactly `config failed: <message>` to stderr and exit with status 1.

2. Run the `command` attribute as an external command line. Write the command's stdout to the path in the `logfile` attribute, replacing the file if it already exists. The command's stderr must go to the program's stderr. After the command finishes, print exactly `job exited with code <code>` to stderr. If the command cannot be started or the logfile cannot be written, print exactly `job failed: <message>` to stderr and exit with status 1.

3. Exit with status 0 if the command finished with exit status 0 and the logfile was written. Otherwise exit with status 1.
