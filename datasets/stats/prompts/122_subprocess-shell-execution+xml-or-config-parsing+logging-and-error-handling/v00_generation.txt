Write a Python 3 program in a single file named `jobrunner.py`.

The program takes one command-line argument: the path to an XML configuration file. The XML file has a root element `<jobs>` containing one or more `<job>` elements. Each `<job>` element has three attributes: `name`, `command`, and `logfile`. Example:

<jobs>
  <job name="list" command="ls -la" logfile="list.log"/>
  <job name="date" command="date" logfile="date.log"/>
</jobs>

Run the program as:

python jobrunner.py jobs.xml

The program processes the `<job>` elements in the order they appear in the XML file. For each job, execute the `command` attribute as an external command. Capture the command's standard output. Write the captured standard output to the file path given by the `logfile` attribute, replacing the file if it already exists. Do not write the command's standard error to the log file; let it go to the program's standard error. After each job, print exactly one line to standard error:
- `job <name> exited with code <code>` when the command finishes, where `<name>` is the job's `name` attribute and `<code>` is the command's exit status.
- `job <name> failed: <reason>` when the command cannot be started or the log file cannot be written, where `<reason>` is the error message text.

If the XML file cannot be read or parsed, or its root element is not `<jobs>`, print `config failed: <reason>` to standard error and exit with status 1.

After all jobs, exit with status 0 if every command finished with exit status 0 and every log file was written. Otherwise exit with status 1.
