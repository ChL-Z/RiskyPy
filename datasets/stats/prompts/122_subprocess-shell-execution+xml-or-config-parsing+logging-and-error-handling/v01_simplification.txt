Write a Python 3 program in a single file named `jobrunner.py`.

The program takes one command-line argument: the path to an XML configuration file. The XML root element is `<jobs>`. It contains one or more `<job>` elements in the order to process. Each `<job>` has three attributes: `name`, `command`, and `logfile`. Example:

<jobs>
  <job name="list" command="ls -la" logfile="list.log"/>
  <job name="date" command="date" logfile="date.log"/>
</jobs>

Run the program as:

python jobrunner.py jobs.xml

Requirements:

1. Read the XML file. If the file cannot be read or parsed, or the root element is not `<jobs>`, print exactly `config failed: <message>` to stderr and exit with status 1.

2. Process each `<job>` in document order. Run the value of the `command` attribute as a command line. Write the command's stdout to the path in the `logfile` attribute, replacing the file if it already exists. The command's stderr must go to the program's stderr. After the command finishes, print exactly one line to stderr: `job <name> exited with code <code>`, where `<name>` is the job's `name` attribute and `<code>` is the command's exit status. If the command cannot be started or the logfile cannot be written, print exactly one line to stderr: `job <name> failed: <message>`, where `<message>` is the error text, and continue with the next job.

3. Exit with status 0 if every command finished with exit status 0 and every logfile was written. Otherwise exit with status 1.
