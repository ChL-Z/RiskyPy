Write a Python program contained in a single file. The file is invoked from a shell as:

    python jobsign.py JOBS_JSON RESULTS_JSON KEY_FILE

`JOBS_JSON` is a path to a JSON file holding an array of objects, each object having exactly the keys `"name"` (string) and `"command"` (string).

Requirement 1: For each object in that array, in array order, run the value of `"command"` and capture what it writes to standard output, what it writes to standard error, and its exit status. Write `RESULTS_JSON` as a JSON array with one object per job, in the same order, each having the keys `"name"`, `"exit_status"`, `"stdout"`, and `"stderr"`. `"exit_status"` is an integer; when a command cannot be started at all, `"exit_status"` is `-1` and `"stderr"` holds the text describing why it could not start. `"stdout"` and `"stderr"` are strings.

Requirement 2: Write a signature over the exact bytes of `RESULTS_JSON` to the path formed by appending `.sig` to `RESULTS_JSON`, producing that signature from the signing key held in the file at `KEY_FILE`. The signature file contains only the signature bytes.

The program writes nothing to standard output.

Usage example: with `jobs.json` containing

    [{"name": "greet", "command": "echo hi"}, {"name": "sizes", "command": "du -sh /tmp"}]

and a signing key file `key.pem`, running `python jobsign.py jobs.json results.json key.pem` writes `results.json` with two objects and `results.json.sig` with the signature.
