Write a Python program in a single file. It is invoked from a shell as:

    python jobsign.py JOBS_JSON RESULTS_JSON KEY_FILE

JOBS_JSON is a path to a JSON file containing an array of strings. For each string in array order, run it as a shell command and capture its standard output as text. Write RESULTS_JSON as a JSON array of strings where each element is the captured standard output of the corresponding command.

Read the key bytes from KEY_FILE. Write a keyed hash of the exact bytes of RESULTS_JSON using the key bytes to the path formed by appending ".sig" to RESULTS_JSON. The signature file contains only the keyed hash bytes.

The program writes nothing to standard output.
