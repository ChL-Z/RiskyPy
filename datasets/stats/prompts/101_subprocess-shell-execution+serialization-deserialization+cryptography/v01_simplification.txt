Write a Python program in a single file. It is invoked from a shell as:

    python jobsign.py JOBS_JSON RESULTS_JSON KEY_FILE

JOBS_JSON is a path to a JSON file. The file contains an array of objects. Each object has exactly the keys "name" (string) and "command" (string).

1. Read JOBS_JSON. For each object in array order, run the value of "command" as a shell command and capture its standard output and exit status. Write RESULTS_JSON as a JSON array. Each element has exactly the keys "name", "exit_status", and "stdout". "exit_status" is an integer. "stdout" is a string.

2. Read the signing key from KEY_FILE. Write a digital signature over the exact bytes of RESULTS_JSON to the path formed by appending ".sig" to RESULTS_JSON. The signature file contains only the signature bytes.

The program writes nothing to standard output.
