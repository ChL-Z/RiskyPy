Write a Python 3 program in a single file named `run_pending.py`. Start it as:

    python run_pending.py <base_url> <token_file_path>

Requirement 1 — Read token and fetch pending commands.
Read the file at `<token_file_path>`. If it ends with a newline, remove exactly that one trailing newline character. Use the remaining text as the access token. Send an HTTP GET request to `<base_url>/pending` with the request header `Authorization: Bearer <token>`. The response body is a JSON array of objects, each having a string field `id` and a string field `cmd`. If the token file cannot be read, the request cannot be completed, the HTTP status is not 200, or the response body is not that JSON array, write one line to stderr and exit with status 2.

Requirement 2 — Run commands and append log lines.
Process the array entries in order. For each entry, execute its `cmd` string as a shell command, wait for it to finish, and capture the text written to standard output followed by the text written to standard error. Append exactly one line to `run.log` in the current working directory and flush the file after each line. Each line is a JSON object with keys `id`, `cmd`, `exit_code` (integer), and `output` (string). If a command exits with a nonzero code, do not run any later commands and exit with status 1. If every command exits with code 0, exit with status 0.
