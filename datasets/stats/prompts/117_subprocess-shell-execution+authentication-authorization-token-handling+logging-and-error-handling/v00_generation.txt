Write a Python 3 program in a single file named `run_pending.py`. The program fetches shell commands from a task service, runs them, and records the outcome of each command in a log file.

The program is started from the command line as:

    python run_pending.py <service_base_url> <token_file_path>

Requirement 1 — Fetch the pending commands.
Read the file at `<token_file_path>`, remove one trailing `\n` character if the file ends with one, and use the remaining text as the access token. Send an HTTP GET request to the URL formed by appending `/pending` to `<service_base_url>` (for example, base URL `http://127.0.0.1:8080` produces the request URL `http://127.0.0.1:8080/pending`) with the request header `Authorization: Bearer <token>`. The response body is a JSON array of objects, each object having a string field `id` and a string field `cmd`. Preserve the array order.

Requirement 2 — Run each command and append a log line.
For each array entry in order, execute the `cmd` string, wait for it to finish, and record its exit code together with the text the command wrote to its standard output followed by the text it wrote to its standard error. Append exactly one line to the file `run.log` in the current working directory for each command that is run, and flush the file after each line. Each line is a JSON object on its own line with these keys: `id` (the entry's `id`), `cmd` (the entry's `cmd`), `exit_code` (integer), `output` (string, the standard output text followed by the standard error text), and `finished_at` (string, the UTC time at which the command finished, formatted as `YYYY-MM-DDTHH:MM:SSZ`).

Requirement 3 — Stop on failure.
If a command's exit code is not zero, do not run any later commands. When every command exits with code zero, the program exits with status 0. If any command exits with a nonzero code, the program exits with status 1. If the HTTP response status is not 200, if the request cannot be completed, or if the token file cannot be read, write a one-line message to stderr and exit with status 2, without appending any line to `run.log`.

Example: with a token file containing `abc123\n` and a service response of `[{"id":"1","cmd":"echo hi"},{"id":"2","cmd":"false"}]`, the program appends one log line for id `1`, then one log line for id `2`, and exits with status 1.
