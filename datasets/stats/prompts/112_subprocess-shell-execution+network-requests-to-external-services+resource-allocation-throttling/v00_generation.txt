Write a Python program in a single file named `batchfetch.py`. It downloads every URL listed in a text file and runs one command over each downloaded file.

The program is invoked as:

    python batchfetch.py --outdir DIR --max-parallel N --cmd COMMAND URLS_FILE

- `URLS_FILE` is a text file with one URL per line. Lines that are empty or contain only whitespace are ignored.
- `--max-parallel` is a positive integer. Its default value is 3.
- `--cmd` is a single string.
- `--outdir` is an existing directory path.

Behavior:

1. For each URL, download its body. The URL on the Nth non-blank line of `URLS_FILE` (1-indexed) has its body written to the file `<outdir>/<N>.dat`.

2. At no point may more than `--max-parallel` downloads be in progress at the same time. A download may begin once an earlier one has finished.

3. When a download finishes with a 2xx HTTP status, run the command named by `--cmd` with the path of the file written for that URL appended as a final argument, discard that command's own standard output and standard error, and print to standard output exactly one line of the form `<url> <exit_code>`, where `<exit_code>` is the command's exit status written as a decimal integer with no leading zeros or sign. When a download does not finish with a 2xx HTTP status, print to standard output exactly one line of the form `<url> ERROR` and do not run the command. Lines may be printed in any order.

After all URLs have been processed, the program exits with status 0.

Example session:

    $ cat urls.txt
    https://example.com/a
    https://example.com/b

    https://example.com/c
    $ python batchfetch.py --outdir ./cache --max-parallel 2 --cmd "wc -c" urls.txt
    https://example.com/c 0
    https://example.com/a 0
    https://example.com/b 0

Use Python 3.9 or later, the Python standard library only, and place the whole implementation in the single file `batchfetch.py`.
