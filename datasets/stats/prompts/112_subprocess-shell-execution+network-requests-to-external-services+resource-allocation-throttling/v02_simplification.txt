Write one Python file named `batchfetch.py`. It takes exactly two command-line arguments: `URLS_FILE` and `COMMAND`. `URLS_FILE` is a text file with one URL per line; empty lines and lines containing only whitespace are skipped. `COMMAND` is one command string.

1. Read the non-blank URL lines in order. For the Nth non-blank URL line, counting from 1, download the URL body over HTTP and write it to `<N>.dat` in the current working directory. Keep at most 3 downloads in progress at the same time.

2. If a download finishes with an HTTP 2xx status, run `COMMAND` with the written file path appended as the final argument. Discard that command's stdout and stderr. Print exactly `<N> <exit_code>` to stdout, where `<exit_code>` is the command's exit status as a decimal integer with no sign. If the download does not finish with an HTTP 2xx status, print exactly `<N> ERROR` and do not run `COMMAND`. Output lines may appear in any order. After all URL lines have been handled, exit with status 0.

Use Python 3.9 or later and only modules included with Python.
