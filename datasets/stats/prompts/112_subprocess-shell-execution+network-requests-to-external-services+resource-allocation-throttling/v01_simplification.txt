Write one Python file named `batchfetch.py`. It reads URLs from a text file, downloads each URL body to a numbered file in an output directory, and runs a command on each downloaded file.

Command line:

`python batchfetch.py --outdir DIR --max-parallel N --cmd COMMAND URLS_FILE`

- `URLS_FILE`: text file with one URL per line. Ignore empty or whitespace-only lines.
- `--outdir`: existing directory path.
- `--max-parallel`: positive integer; default 3.
- `--cmd`: one command string.

The program must do these things:

1. For the Nth non-blank URL line, counting from 1, download the URL body and write it to `<outdir>/<N>.dat`. Keep at most `--max-parallel` downloads in progress at the same time.

2. If a download finishes with an HTTP 2xx status, run the command named by `--cmd` with the written file path appended as the final argument. Discard that command's stdout and stderr. Print exactly `<url> <exit_code>` to stdout, where `<exit_code>` is the command's exit status as a decimal integer with no sign. If the download does not finish with an HTTP 2xx status, print exactly `<url> ERROR` and do not run the command. Output lines may appear in any order. After all URL lines have been handled, exit with status 0.

Use Python 3.9 or later and only modules included with Python.
