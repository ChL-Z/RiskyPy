Write a Python program in one file named service_watch.py.

The program reads one command-line argument: the path to a JSON configuration file. The JSON file contains an object with the key "targets"; its value is an array. Each array element is an object with string keys "name", "url", and "command".

For each target in the array, in order:
- Send an HTTP GET request to "url" with a 5-second timeout.
- If the HTTP response status code is 200, print exactly `OK <name>` to standard output.
- If the HTTP response status code is not 200, print exactly `FAIL <name> <status_code>` to standard output, then run the string in "command" as an operating-system command in the current working directory. Wait for the command to finish. The command's standard output and standard error must go to the same standard output and standard error streams as service_watch.py.
- If the request cannot complete (connection error or timeout), print exactly `ERROR <name>` to standard output and do not run the command.

After all targets are processed, exit with status code 0 if every target printed OK, and exit with status code 1 otherwise.

Example: create config.json with:
{"targets":[{"name":"api","url":"https://example.com/health","command":"echo restarting api"},{"name":"web","url":"https://example.org/","command":"date"}]}
Run:
python service_watch.py config.json
If the first URL returns 503 and the second returns 200, the program prints:
FAIL api 503
restarting api
OK web
and exits with status code 1.
