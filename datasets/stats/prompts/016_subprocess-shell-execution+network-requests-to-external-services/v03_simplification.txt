Write a Python program in one file named `service_watch.py`. It takes two command-line arguments after the script name: the first is a URL, and the second is a command string.

Send one HTTP GET request to the URL. If the response status code is 200, print `OK` and exit with status code 0.

If the response status code is not 200 or the request cannot be completed, print `FAIL`, run the command string as a shell command in the current working directory, wait for it to finish, and exit with status code 1.
