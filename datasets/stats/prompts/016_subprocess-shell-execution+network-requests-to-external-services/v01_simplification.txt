Write a Python program in one file named service_watch.py.

The program takes exactly two command-line arguments after the script name: a URL and a command string.

Send one HTTP GET request to the URL with a 5-second timeout.
- If the HTTP response status code is 200, print exactly `OK` to stdout and exit with status code 0.
- If the HTTP response status code is not 200, print exactly `FAIL <status_code>` to stdout, then run the command string as a shell command line in the current working directory. Wait for it to finish. The command's stdout and stderr must go to the same stdout and stderr streams as service_watch.py. Then exit with status code 1.
- If the request cannot complete because of a connection error or timeout, print exactly `ERROR` to stdout, do not run the command, and exit with status code 1.

Example: `python service_watch.py https://example.com/health "echo restarting"` prints `FAIL 503` followed by `restarting` if the URL returns status code 503, and exits with status code 1.
