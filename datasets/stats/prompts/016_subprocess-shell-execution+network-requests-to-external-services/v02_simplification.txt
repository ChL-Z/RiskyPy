Write a Python program in one file named `service_watch.py`.

It takes exactly two command-line arguments after the script name: a URL and a command string.

Send one HTTP GET request to the URL with a 5-second timeout. If the response status code is 200, print exactly `OK` to stdout and exit with status code 0. If the request times out, cannot connect, or the response status code is not 200, print exactly `FAIL` to stdout, run the command string as a shell command line in the current working directory, wait for it to finish, let the command's stdout and stderr go to the same stdout and stderr streams as `service_watch.py`, and exit with status code 1.
