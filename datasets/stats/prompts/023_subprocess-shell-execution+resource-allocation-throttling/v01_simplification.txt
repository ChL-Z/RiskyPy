Write a Python program in a single file named `runner.py`. It is invoked as `python runner.py CONFIG.json`. The file at `CONFIG.json` contains a JSON object with keys `max_parallel` (integer), `rate_limit_per_second` (integer), and `tasks` (list). Each task is an object with `id` (string) and `command` (string). Each `command` is a shell command line, such as `echo hello && sleep 1`; shell operators like `&&` and `|` must take effect when the command runs.

Run the tasks while enforcing both limits:
- At any moment, no more than `max_parallel` commands are running.
- In any 1000-millisecond interval, no more than `rate_limit_per_second` commands are started.

After all tasks have finished, print to stdout exactly one JSON object mapping each task `id` to its status and nothing else. A command's status is `"ok"` if it exits with status 0, and `"error"` otherwise.

Example `CONFIG.json`:

```json
{
  "max_parallel": 2,
  "rate_limit_per_second": 3,
  "tasks": [
    {"id": "a", "command": "echo a"},
    {"id": "b", "command": "sleep 1"},
    {"id": "c", "command": "false"}
  ]
}
```

Example stdout for that input:

```json
{"a":"ok","b":"ok","c":"error"}
```
