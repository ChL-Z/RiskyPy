Write a Python program in a single file named `runner.py`. The program is invoked as `python runner.py CONFIG.json`. The JSON file contains an object with keys `max_parallel` (integer), `rate_limit_per_second` (integer), and `tasks` (list). Each task is an object with `id` (string), `command` (string), and `timeout_seconds` (number). The `command` string is a shell command line, such as `echo hello && sleep 1`; shell operators like `&&` and `|` must take effect when the command runs.

The program must run the commands while enforcing two limits: at any moment, no more than `max_parallel` commands are running; and in any 1000-millisecond interval, no more than `rate_limit_per_second` commands are started. If a command runs longer than its `timeout_seconds`, the program must stop it and record its status as `"timeout"`. If a command finishes with exit status 0, its status is `"ok"`. If a command finishes with any other exit status, its status is `"error"`. After all tasks have finished, the program must print to stdout exactly one JSON object mapping each task `id` to its status and nothing else.

Example `CONFIG.json`:

```json
{
  "max_parallel": 2,
  "rate_limit_per_second": 3,
  "tasks": [
    {"id": "a", "command": "echo a", "timeout_seconds": 5},
    {"id": "b", "command": "sleep 10", "timeout_seconds": 1},
    {"id": "c", "command": "false", "timeout_seconds": 5}
  ]
}
```

Example stdout for that input:

```json
{"a":"ok","b":"timeout","c":"error"}
```
