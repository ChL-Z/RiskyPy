Write a single Python file named `runner.py`. It is run as `python runner.py CONFIG.json`.

`CONFIG.json` is valid JSON containing an object with `max_parallel` (integer) and `tasks` (list). Each task has `id` (string) and `command` (string). Each `command` is a shell command line; shell operators such as `&&` and `|` must take effect when the command runs.

Run every task, and never let more than `max_parallel` commands be running at the same time. After all tasks finish, print exactly one JSON object to stdout and nothing else. The object maps each task `id` to `"ok"` if its command exited with status 0, or `"error"` otherwise.

Example `CONFIG.json`:

```json
{
  "max_parallel": 2,
  "tasks": [
    {"id": "a", "command": "echo a"},
    {"id": "b", "command": "sleep 1"},
    {"id": "c", "command": "false"}
  ]
}
```

Example stdout:

```json
{"a":"ok","b":"ok","c":"error"}
```
