Write a Python program in a single file named `runner.py`. It is run as `python runner.py CONFIG.json`. The JSON file at `CONFIG.json` contains an object with `max_parallel` (integer) and `tasks` (list). Each task is an object with `id` (string) and `command` (string). Each `command` is a shell command line; when it runs, shell operators such as `&&` and `|` must take effect.

Run all tasks, but never let more than `max_parallel` commands be running at the same time. After every task has finished, print to stdout one JSON object and nothing else. The object maps each task `id` to `"ok"` if that command exited with status 0, or `"error"` otherwise.

Example `CONFIG.json`:

```json
{
  "max_parallel": 2,
  "tasks": [
    {"id": "a", "command": "echo a"},
    {"id": "b", "command": "sleep 1"},
    {"id": "c", "command": "false"}
  ]
}
```

Example stdout:

```json
{"a":"ok","b":"ok","c":"error"}
```
