Write a Python 3 program in a single file named `vault_cli.py`.

It reads newline-separated commands from stdin and writes results to stdout, one command per line in the order read. Each command line contains space-separated fields. Records persist in an SQLite database at the path in the `VAULT_DB` environment variable, or at `vault.db` when `VAULT_DB` is unset.

1. `put NAME KIND VALUE`: store the record for `NAME` with `KIND` and a cryptographic verifier derived from `VALUE`. If a record for `NAME` already exists, replace it. Print nothing. `check NAME CANDIDATE`: print `OK` on its own line when the verifier derived from `CANDIDATE` matches the stored verifier for `NAME`; print `NO` on its own line otherwise or when no record exists for `NAME`.

2. `find COLUMN VALUE`: `COLUMN` is `name` or `kind`. Print one line for each matching record in the form `NAME|KIND`, sorted by `NAME` in ascending Unicode code point order. A record matches when the chosen `COLUMN` equals `VALUE`. Print nothing when no record matches.

Lines that do not match these command forms are ignored.
