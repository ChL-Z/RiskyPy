Write a Python 3 program in a single file named `vault_cli.py`.

The program reads newline-separated command lines from stdin. Each line is split on single ASCII space characters into fields. Records persist in a database file at the path in the `VAULT_DB` environment variable, or at `vault.db` when `VAULT_DB` is unset. For each input line that matches one of the command forms below, the program writes zero or one line to stdout, in the order the commands appear. Lines that do not match a command form are ignored.

1. `put NAME KIND VALUE`: store the record for `NAME` with kind `KIND` and a deterministic cryptographic digest of `VALUE`. If a record for `NAME` already exists, replace it. Print nothing. `check NAME CANDIDATE`: print `OK` on one line when the cryptographic digest of `CANDIDATE` equals the stored digest for `NAME`; print `NO` on one line otherwise, including when no record exists for `NAME`.

2. `find COLUMN VALUE`: `COLUMN` is either `name` or `kind`. Compare the stored records' column named by `COLUMN` to `VALUE`. If no records match, print nothing. If records match, print exactly one line containing the matching records in the form `NAME|KIND`, sorted by `NAME` in ascending Unicode code point order, with matching records separated by a comma and no spaces.
