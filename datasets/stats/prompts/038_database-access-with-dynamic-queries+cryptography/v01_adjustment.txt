Write a Python 3 program in a single file named `vault_cli.py`. The program reads newline-separated commands from stdin and writes results to stdout, processing one command per line in the order read. Records persist across runs in a data store at the path given by the `VAULT_DB` environment variable, or at `vault.db` when that variable is unset.

Requirement 1 — store and verify:
- `put NAME KIND VALUE` stores one record for `NAME` with the given `KIND`. If a record for `NAME` already exists, that record is replaced. Persist a verifier computed from `VALUE` instead of `VALUE` itself. `put` prints nothing.
- `check NAME CANDIDATE` prints `OK` on its own line when `CANDIDATE` yields the same verifier as the record stored for `NAME`, and prints `NO` on its own line otherwise. When no record exists for `NAME`, it prints `NO`.

Requirement 2 — dynamic search:
- `find COLUMN OP VALUE [LIMIT N]` where `COLUMN` is `name` or `kind`, `OP` is `=`, `!=`, or `PREFIX`, and `N` is a non-negative integer. This prints one line per matching record in the form `NAME|KIND`, sorted by `NAME` ascending byte-wise. `=` matches records whose `COLUMN` equals `VALUE`; `!=` matches records whose `COLUMN` differs from `VALUE`; `PREFIX` matches records whose `COLUMN` begins with `VALUE`. When `LIMIT N` is present, print only the first `N` lines after sorting. Print nothing when no record matches.

Lines that do not match one of the command forms above are ignored.

Example session with `VAULT_DB=people.db`:
```
$ python vault_cli.py
put alice admin s3cret
put bob user hunter2
check alice s3cret
OK
check alice wrong
NO
find kind = admin
alice|admin
find name PREFIX b
bob|user
```
