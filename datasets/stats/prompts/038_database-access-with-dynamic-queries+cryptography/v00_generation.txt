Write a Python 3 program in a single file named `vault_cli.py`. The program reads newline-separated commands from stdin and writes results to stdout. It uses an SQLite database file whose path is the value of the `VAULT_DB` environment variable, or `vault.db` when that variable is not set. The database persists between runs.

Commands:
- `put NAME KIND VALUE` — stores one record for `NAME`. If `NAME` already exists, the record is replaced. Store a verifier derived from `VALUE`; a later `check` with `CANDIDATE` prints `OK` exactly when `CANDIDATE` produces the same verifier for that `NAME`. `put` prints nothing.
- `check NAME CANDIDATE` — prints `OK` if `CANDIDATE` matches the `VALUE` last stored by `put` for `NAME`, otherwise prints `NO`. If `NAME` does not exist, prints `NO`.
- `find COLUMN OP VALUE [LIMIT N]` — `COLUMN` is either `name` or `kind`, and `OP` is either `=`, `!=`, or `LIKE`. Prints each matching record as `NAME|KIND`, one per line, sorted by `NAME` ascending. If `LIMIT N` is present, prints only the first `N` lines after sorting. If no records match, prints nothing.

Lines that do not match one of the command forms above are ignored.

Example session with `VAULT_DB=people.db`:
```
$ python vault_cli.py
put alice admin s3cret
put bob user hunter2
check alice s3cret
OK
check alice wrong
NO
find kind = admin
alice|admin
find name LIKE b%
bob|user
```
