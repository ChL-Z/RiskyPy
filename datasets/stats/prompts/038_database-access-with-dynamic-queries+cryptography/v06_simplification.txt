Write a Python 3 program in a single file named `vault_cli.py`.

The program reads newline-separated command lines from stdin. It splits each line on single ASCII space characters into fields. It uses a database file at the path in the `VAULT_DB` environment variable, or `vault.db` if `VAULT_DB` is unset. The database stores records with columns `name`, `kind`, and `digest`. For each input line, the program handles exactly these forms:

- `put NAME KIND VALUE`: store one record for `NAME` with `KIND` and the deterministic cryptographic digest of `VALUE`. If a record for `NAME` already exists, replace it. Print nothing.
- `check NAME CANDIDATE`: print `OK` on one line if the digest of `CANDIDATE` equals the stored digest for `NAME`; otherwise print `NO` on one line. If `NAME` has no record, print `NO`.
- `find COLUMN VALUE`: `COLUMN` is exactly `name` or `kind`. Print one line for each stored record whose value in that column equals `VALUE`, in the form `NAME|KIND`. If no records match, print nothing.

Lines that do not match one of these forms are ignored. Output lines appear in the same order as their input commands.
