Write a Python 3 program in a single file named `vault_cli.py`. It reads newline-separated commands from stdin and writes results to stdout, one command per line in the order read. Records persist in an SQLite database at the path in the `VAULT_DB` environment variable, or at `vault.db` when `VAULT_DB` is unset.

1. `put NAME KIND VALUE`: store the record for `NAME` with `KIND` and a verifier computed from `VALUE`. If a record for `NAME` already exists, replace it. Print nothing. `check NAME CANDIDATE`: print `OK` on its own line when the verifier computed from `CANDIDATE` matches the stored verifier for `NAME`; print `NO` on its own line otherwise or when no record exists for `NAME`.

2. `find COLUMN OP VALUE`: `COLUMN` is `name` or `kind`; `OP` is `=` or `PREFIX`. Print one line for each matching record in the form `NAME|KIND`, sorted by `NAME` in ascending Unicode code point order. `=` matches records whose `COLUMN` equals `VALUE`. `PREFIX` matches records whose `COLUMN` begins with `VALUE`. Print nothing when no record matches.

Lines that do not match these command forms are ignored.
