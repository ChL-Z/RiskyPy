Write a Python program in a single file named `task_report.py`. The program is a command-line utility that prints task records from a local database.

The program takes one command-line argument: a path to a text file containing a token string. The program reads the entire contents of that file, removes leading and trailing whitespace, and uses the result as the token.

The program must open the SQLite database file `auth.db` and query the table `tokens` (columns: `token` TEXT, `username` TEXT, `role` TEXT). If the token is not present in the table, the program prints `ERROR: invalid token` to stderr and exits with status code 1. If the token is present but its `role` column is not exactly `admin`, the program prints `ERROR: forbidden` to stderr and exits with status code 1.

If the token is valid and the role is `admin`, the program opens the SQLite database file `tasks.db` and reads lines from standard input until EOF. Each input line has the form `column=value`, where `column` is one of `id`, `title`, `status`, or `owner`. The program collects all such filters and combines them with AND. It then queries the table `tasks` (columns: `id` INTEGER, `title` TEXT, `status` TEXT, `owner` TEXT) for all rows matching every filter. For each matching row, the program prints one line to standard output in the format `id|title|status|owner`. If there are no input lines, all rows from `tasks` are printed.

Example usage:
```
$ echo "status=open
owner=alice" | python task_report.py ./my_token.txt
1|Fix login|open|alice
5|Update docs|open|alice
```
