Write a Python program in a single file named `task_report.py`.

The program reads a path to a token file from command-line argument 1. It reads the entire file, strips leading and trailing whitespace, and uses the result as the token.

It opens the SQLite database file `app.db`. The database contains table `tokens` with columns `token` TEXT, `username` TEXT, `role` TEXT, and table `tasks` with columns `id` INTEGER, `title` TEXT, `status` TEXT, `owner` TEXT. If the token is not in `tokens`, print `ERROR: invalid token` to stderr and exit with status code 1. If the token exists and its `role` column is not exactly `admin`, print `ERROR: forbidden` to stderr and exit with status code 1.

After the token is accepted, read standard input until EOF. If standard input is empty, print every row from `tasks`. If standard input is not empty, use only the first line, which has the form `column=value`. The `column` is the text before the first `=` and is one of `id`, `title`, `status`, or `owner`. The `value` is the remaining text after that first `=`. Print only rows from `tasks` where `column` equals `value`. Print each matching row to stdout as `id|title|status|owner`, one row per line.
