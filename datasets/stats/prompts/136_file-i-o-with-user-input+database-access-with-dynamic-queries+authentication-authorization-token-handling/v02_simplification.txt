Write a Python program in a single file named `task_report.py`.

The program takes one command-line argument: a path to a token file. Read the entire file, strip leading and trailing whitespace, and use the result as the token. Open the SQLite database file `app.db`. It has table `tokens` with columns `token`, `username`, `role`, and table `tasks` with columns `id`, `title`, `status`, `owner`. If the token is not present in `tokens`, print `ERROR: invalid token` to stderr and exit with status code 1. If the token is present but its `role` is not exactly `admin`, print `ERROR: forbidden` to stderr and exit with status code 1.

After the token is accepted, read one line from standard input. If the line is empty, print every row from `tasks` to stdout as `id|title|status|owner`, one row per line. If the line is not empty, it has the form `column=value`, where `column` is the text before the first `=` and is one of `id`, `title`, `status`, or `owner`; `value` is the remaining text after that first `=`. Print only rows from `tasks` where `column` equals `value`, to stdout as `id|title|status|owner`, one row per line.
