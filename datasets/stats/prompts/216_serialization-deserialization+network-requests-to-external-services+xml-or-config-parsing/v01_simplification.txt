Write a Python program in a single file named feed_digest.py. It takes one command-line argument: the path to a JSON configuration file. The configuration file contains a JSON object with key "feeds"; its value is a list of objects, each with string keys "name" and "url".

1. Read the JSON configuration file. For each feed object in order, retrieve its "url" with an HTTP GET request. If the response status is 200, parse the response body as RSS 2.0 XML. RSS 2.0 has an <rss> root containing a <channel> element with <item> children. Read the text of the direct <title> and direct <link> children of the first <item> in document order. If the HTTP request fails, the status is not 200, the body cannot be parsed as RSS 2.0, there is no <item>, or the first <item> lacks a direct <title> or direct <link>, mark that feed as failed.

2. Print exactly one JSON object to stdout. It has key "feeds" whose value is a list with one entry per configuration feed, in the same order. For a successful feed, the entry is {"name": <feed name>, "title": <title text>, "link": <link text>}. For a failed feed, the entry is {"name": <feed name>, "error": "failed"}. No other text goes to stdout.

Example: config feeds.json:
{"feeds":[{"name":"Python Blog","url":"https://example.com/python.xml"},{"name":"Broken Feed","url":"https://example.com/missing.xml"}]}

If the first URL returns RSS with first item title Hello and link https://example.com/hello, and the second URL returns HTTP 404, stdout is:
{"feeds":[{"name":"Python Blog","title":"Hello","link":"https://example.com/hello"},{"name":"Broken Feed","error":"failed"}]}
