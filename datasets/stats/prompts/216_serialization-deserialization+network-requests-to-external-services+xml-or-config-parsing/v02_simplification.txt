Write a Python program in a single file named feed_digest.py. It takes one command-line argument: the path to a JSON configuration file. The JSON file contains an object with key "feeds". Its value is a list of objects, each with string keys "name" and "url".

For each feed object in order, retrieve its "url" with an HTTP GET request. If the response body is RSS 2.0 XML with a first <item> element that contains both a <title> element and a <link> element, record the feed name, the title text, and the link text. Otherwise record the feed name with the value "failed" for key "error".

Print one JSON object to stdout. It has key "feeds" whose value is a list with one object per configuration feed, in the same order. A successful feed object has keys "name", "title", and "link". A failed feed object has keys "name" and "error", where "error" is "failed". Print only this JSON object to stdout.
