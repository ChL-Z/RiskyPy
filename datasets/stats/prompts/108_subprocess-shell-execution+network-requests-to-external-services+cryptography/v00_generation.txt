Write a Python program in a single file named `remote_runner.py`. The program accepts exactly two command-line arguments: a URL and a 64-character lowercase hexadecimal checksum. It retrieves the content from the URL, writes it to a file named `remote_script` in the current working directory, and confirms that the file's checksum equals the checksum argument. If the checksum matches, the program executes the file `remote_script` with the system shell and prints the exit code to stdout. If the checksum does not match, it prints `checksum mismatch` to stderr and exits with code 1. Example usage: `python remote_runner.py https://example.com/setup.sh 0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef` where the URL serves a shell script and the checksum is the expected digest of that script.
