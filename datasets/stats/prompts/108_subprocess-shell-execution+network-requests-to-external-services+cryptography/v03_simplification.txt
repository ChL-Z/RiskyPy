Write `remote_runner.py`. The program reads two lines from stdin: a URL on the first line and a 64-character lowercase hexadecimal checksum on the second line.

1. Fetch the bytes at the URL. Compute a 64-character lowercase hexadecimal cryptographic hash of the fetched bytes. If the hash is not equal to the checksum, print `checksum mismatch` to stderr and exit with status 1.

2. If the hash is equal, decode the fetched bytes as UTF-8 and execute the decoded text as one shell command line. Print the command's exit code as a decimal integer to stdout.

Use only modules included with Python.
