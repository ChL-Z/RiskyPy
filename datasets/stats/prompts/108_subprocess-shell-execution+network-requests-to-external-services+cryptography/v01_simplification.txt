Write a Python program in a single file named `remote_runner.py`. The program accepts exactly two command-line arguments: a URL and a 64-character lowercase hexadecimal checksum. It retrieves the content at the URL and checks that the content's checksum equals the checksum argument. If the checksums match, the program runs the retrieved content as a shell command and prints the command's exit code to stdout. If they do not match, the program prints `checksum mismatch` to stderr and exits with status 1. Example usage: `python remote_runner.py https://example.com/setup.sh 0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef`.
