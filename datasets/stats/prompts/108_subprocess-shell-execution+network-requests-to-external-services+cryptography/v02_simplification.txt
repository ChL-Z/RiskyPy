Create a single Python file named `remote_runner.py`. The program takes exactly two command-line arguments: a URL and a 64-character lowercase hexadecimal checksum. Download the bytes at the URL. Compute the hexadecimal checksum of the downloaded bytes and compare it to the second argument. If the checksums are not equal, print `checksum mismatch` to stderr and exit with status 1. If the checksums are equal, decode the downloaded bytes as UTF-8 and execute that text as a shell command line, then print the command's exit code as a decimal integer to stdout. The program must not import third-party packages.
