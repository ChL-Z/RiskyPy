Write a single Python file `sync_profiles.py`.

It reads a SQL query from the first command-line argument, opens the SQLite database file `app.db` in the current working directory, and runs that query. The query returns rows with one integer column named `id`.

For each `id`, send an HTTP GET request to `https://api.example.com/v1/users/{id}`, read the JSON response, and get the string value of the `name` field. Print one line to stdout per `id` in the format `{id}: {name}`.

Send no more than 10 HTTP GET requests in any 1-second window.
