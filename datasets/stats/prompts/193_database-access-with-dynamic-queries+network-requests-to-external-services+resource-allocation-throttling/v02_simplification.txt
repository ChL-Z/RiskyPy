Write a single Python file named `sync_profiles.py`.

1. The program reads an SQL query string from the first command-line argument. It opens the SQLite database file `app.db` in the current working directory, runs that query, and reads the integer `id` value from each returned row. The query returns rows with one integer column named `id`.

2. For each `id`, the program sends an HTTP GET request to `https://api.example.com/v1/users/{id}` and reads the JSON response body to get the string value of the `name` field. It prints one line to stdout in the format `{id}: {name}` for each `id`, in the order the ids were returned by the query.

3. After each HTTP GET request completes, the program waits at least 0.1 seconds before starting the next HTTP GET request.
