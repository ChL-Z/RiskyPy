Write a Python script `sync_profiles.py` that reads a SQL query from the first command-line argument. The script must connect to a SQLite database file named `app.db` in the current working directory and execute that query. The query is expected to return rows each containing a single integer column named `id`. For each returned `id`, the script must send an HTTP GET request to `https://api.example.com/v1/users/{id}`, read the JSON response, and extract the string value of the `"name"` field. The script must print one line to stdout for each user in the format `{id}: {name}`. The script must not send more than 10 HTTP requests per second. The implementation must be in a single Python file. For example, running `python sync_profiles.py "SELECT id FROM users WHERE active = 1"` might print `1: Alice` and `2: Bob`.
