Write a Python program in one file.

Read lines from stdin until EOF. For each line:

- If the line starts with `cmd: `, execute the remainder of the line as a shell command, capture its stdout, and write that captured stdout to stdout exactly as produced.
- If the line starts with `expr: `, compute the value of the remainder of the line as an arithmetic expression using numbers and the operators `+`, `-`, `*`, `/`, and parentheses, then write the value to stdout followed by a newline.
- If the line does not start with either `cmd: ` or `expr: `, ignore it.

After all lines are processed, exit with status 0.

Example input:
```
# note
cmd: echo hello
expr: 3 * (4 + 2)
```

Expected stdout:
```
hello
18
```
