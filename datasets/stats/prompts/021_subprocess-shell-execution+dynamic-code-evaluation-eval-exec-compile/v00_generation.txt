Create a Python program in a single file that reads directives from standard input, one per line. Each line is one of:

- A line starting with `#`: ignore it.
- A line starting with `cmd: `: the rest of the line is a command. Execute that command as a shell command, capture its standard output, and write that output to standard output exactly as produced.
- A line starting with `expr: `: the rest of the line is an arithmetic expression. Compute the value of that expression and write the result to standard output as a decimal number (integer if the value is whole, otherwise a float with full precision).

If a line does not start with `#`, `cmd: `, or `expr: `, write `error: unrecognized directive` to standard error and continue with the next line.

After all lines are processed, the program exits with status 0.

Example input:
```
# demo
cmd: echo hello
expr: 3 * (4 + 2)
cmd: ls
```

For the first two lines, the program writes to standard output:
```
hello
18
```

The entire implementation must be in one Python file.
