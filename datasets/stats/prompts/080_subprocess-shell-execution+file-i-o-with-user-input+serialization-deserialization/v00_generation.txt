Write a Python program in a single file named `cmd_cache.py`. It must be run as `python cmd_cache.py <command_file> <cache_file>`.

1. Read `<command_file>` as UTF-8 text. For each line, remove the trailing newline and carriage return characters. Skip the line if the resulting string is empty. Treat each remaining line as one command string.

2. For each command string, if `<cache_file>` exists and contains a mapping from that exact command string to captured stdout bytes, write those bytes to stdout and do not run the command. Otherwise run the command string, capture its stdout and stderr as bytes, and write the captured stdout bytes to stdout. If the command exits with status 0, store the command string and its captured stdout bytes in the mapping. If the command exits with a nonzero status, write `ERROR <command>: ` followed by the captured stderr bytes to stderr, and do not store or update a mapping entry for that command.

3. After all lines are processed, write the mapping to `<cache_file>` as a binary file in a format the script can read back on a later invocation. If `<cache_file>` does not exist or cannot be read as that format, start with an empty mapping.

Example `commands.txt`:

```
uname -a
python --version
```

Running `python cmd_cache.py commands.txt .cache.bin` prints the output of each command. Running the same command again prints the same output without running the commands again, as long as `.cache.bin` has not been removed.
