Write a single Python file named `cmd_cache.py`. It is run as `python cmd_cache.py <command_file> <cache_file>`.

1. Read `<command_file>` as UTF-8 text. For each line, remove trailing newline and carriage return characters. Skip empty lines. Treat each remaining line as one command string.

2. For each command string, if `<cache_file>` exists and contains a mapping from that command string to stdout bytes, write those bytes to stdout and do not run the command. Otherwise run the command string, capture its stdout bytes and exit status, and write the captured stdout bytes to stdout. If the exit status is 0, store the command string and its stdout bytes in the mapping. If the exit status is nonzero, do not store or update a mapping entry for that command.

3. After all command strings are processed, write the mapping to `<cache_file>` as a binary file that this script can read back on a later run. If `<cache_file>` is missing or cannot be read as that binary mapping, start with an empty mapping.
