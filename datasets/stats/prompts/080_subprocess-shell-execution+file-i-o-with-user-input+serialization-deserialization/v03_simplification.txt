Write a single Python file `cmd_cache.py`. It is run as `python cmd_cache.py <command_file> <cache_file>`.

1. Read `<command_file>` as UTF-8 text. For each line, remove trailing newline and carriage return characters. Skip empty lines. Each remaining line is one command string.

2. If `<cache_file>` exists and can be read back as a mapping from command strings to stdout bytes, load that mapping. Otherwise use an empty mapping. For each command string in order: if the mapping has that command string, write its stored stdout bytes to stdout and do not run the command. Otherwise, run the command string as a shell command, capture its stdout bytes, write those bytes to stdout, and set the mapping entry for that command string to those bytes.

3. After all command strings are processed, write the mapping to `<cache_file>` as a binary file that this script can read back on a later run.
