Write a Python script in a single file named `tagger.py`. It reads newline-delimited JSON from standard input. Each input line is a JSON object with two string fields: `id` and `payload`. Process lines in the order they appear.

For each input line, write to standard output one JSON object on one line with two string fields: `id` (the same string from the input line) and `tag`. `tag` must be a 64-character lowercase hexadecimal string derived from the `payload` string. The same `payload` must always produce the same `tag`; changing the `payload` must produce a different `tag`.

Between writing any two consecutive output lines, wait at least 0.2 seconds. Exit after all input lines have been processed and all output lines have been written.

Example:
Input:
{"id":"a1","payload":"hello"}
{"id":"a2","payload":"world"}
Output:
{"id":"a1","tag":"<64 lowercase hex characters>"}
{"id":"a2","tag":"<64 lowercase hex characters>"}
with at least 0.2 seconds between the two output lines.
