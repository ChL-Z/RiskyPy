Write a Python program in a single file named `tagger.py`. It reads newline-delimited JSON objects from standard input, one line at a time. Each input object has one string field: `payload`. For each input object, in the order read, write to standard output one JSON object on one line with one string field: `tag`. `tag` is a 64-character lowercase hexadecimal string computed from `payload`; the same `payload` always yields the same `tag`. Between any two consecutive output lines, at least 0.2 seconds must pass. The program exits after all input lines are processed and all output lines are written.
