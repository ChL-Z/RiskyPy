Write a Python program in a single file named `tagger.py`. The program takes one command-line argument: a path to a text file. It reads the file line by line, one string per line. For each line, in the order read, it writes to standard output one 64-character lowercase hexadecimal string on its own line. The same input line always produces the same output string. At least 0.2 seconds must pass between writing any two consecutive output lines. The program exits after all input lines are processed and all output lines are written.
