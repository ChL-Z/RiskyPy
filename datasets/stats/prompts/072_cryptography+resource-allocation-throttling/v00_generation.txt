Write a Python script in a single file named `tagger.py`. The script reads newline-delimited JSON from standard input. Each input line is a JSON object with three string fields: `id`, `payload`, and `secret`. The script processes lines in the order they appear. For each input line, the script writes to standard output a single JSON object on one line with two string fields: `id` (the same string as the input line) and `tag`. The `tag` value must be a 64-character lowercase hexadecimal string computed from the `payload` and `secret` strings. The same `payload` and `secret` must produce the same `tag`; changing either the `payload` or the `secret` must produce a different `tag`. Between writing any two consecutive output lines, the script must wait at least 0.2 seconds. The script exits after all input lines have been processed and all output lines have been written.

For example, if standard input contains:
{"id":"a1","payload":"hello","secret":"k1"}
{"id":"a2","payload":"world","secret":"k2"}
then standard output is:
{"id":"a1","tag":"<64 lowercase hex characters>"}
{"id":"a2","tag":"<64 lowercase hex characters>"}
with at least 0.2 seconds between the two output lines.
