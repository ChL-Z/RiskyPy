Write a Python script `settings_cache.py` in a single file. It reads one line from standard input: the path to an INI-style configuration file. The file contains one or more sections in the form `[section]`, followed by lines of `key=value`. For each `key=value` entry, write a line `section.key=value` to a file named `settings.cache` in the current working directory. Then read `settings.cache` and print each line to standard output exactly as written, one line per entry.
