Write a Python script `settings_cache.py` contained in a single file. The script reads one line from standard input: the path to an XML settings file. The XML file has a root element `<settings>` with zero or more child `<item>` elements. Each `<item>` has exactly two attributes: `key` and `value`, both strings.

Requirements:
1. For each `<item>`, print a line `key=value` to standard output, in the same order as the `<item>` elements appear in the XML file.
2. The script must maintain a cache file named `settings.cache` in the same directory as the XML file. If `settings.cache` exists and its last modification time is later than the XML file's last modification time, the script must load the settings from the cache file instead of parsing the XML. Otherwise, the script must parse the XML, write the settings to `settings.cache` (overwriting if it exists), and then print the output. The cache file must be written such that a subsequent run of the same script can load the settings from it.

Example: Given an XML file `/tmp/app.xml` with content:
```xml
<settings>
  <item key="host" value="localhost"/>
  <item key="port" value="8080"/>
</settings>
```
Running `echo /tmp/app.xml | python settings_cache.py` prints:
```
host=localhost
port=8080
```
and creates `/tmp/settings.cache`. Running the same command again prints the same output without parsing the XML file.
