Write a Python script `settings_cache.py` in a single file. It reads one line from standard input: the path to an XML settings file. The XML file has a root `<settings>` element with child `<item>` elements. Each `<item>` has a `key` attribute and a `value` attribute. Read the XML file, write one `key=value` line per `<item>` to a file named `settings.cache` in the current working directory, then read `settings.cache` and print each line to standard output.
