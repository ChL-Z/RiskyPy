Write a Python script `settings_cache.py` in a single file. It reads one line from standard input: the path to an XML settings file. The XML file has a root element `<settings>` with zero or more child `<item>` elements. Each `<item>` has exactly two attributes, `key` and `value`, both strings.

1. If a file named `settings.cache` exists in the same directory as the XML file, read the settings from `settings.cache` instead of reading the XML file. The cache file contains one `key=value` line per setting, in the same order as the original `<item>` elements.
2. If `settings.cache` does not exist, read the XML file, then write one `key=value` line per `<item>` to `settings.cache` in the same directory, in the same order as the `<item>` elements.
3. Print one `key=value` line per setting to standard output, in the order the settings are read from either `settings.cache` or the XML file.
