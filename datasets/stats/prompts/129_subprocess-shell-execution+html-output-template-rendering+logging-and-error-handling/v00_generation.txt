Write a single Python file named `run_checks.py` that reads command lines from a file, executes them, and writes an HTML report and a log file. Invoke it as `python run_checks.py CHECKS_FILE REPORT_FILE LOG_FILE`.

1. Read `CHECKS_FILE` as text. Ignore lines that are empty after stripping trailing newline characters. For each remaining line, execute the line as an external command from the current working directory. Capture the command's standard output and standard error. Continue to the next command regardless of the exit status.

2. Write `REPORT_FILE` as an HTML document. The document must start with `<!DOCTYPE html>`, have `<title>Command Report</title>`, and contain one `<table>` with a header row `<tr><th>Command</th><th>Output</th></tr>`. For each input command, add a row where the first cell contains the command line and the second cell contains a `<pre>` element holding the command's standard output followed immediately by its standard error.

3. Append to `LOG_FILE` one line before executing each command in the form `START <command>`, and one line after it finishes in the form `END <command> exit=<code>`. If the command cannot be started, append `ERROR <command> <message>` instead of the `END` line and put `<message>` in the report row's `<pre>` element. If `CHECKS_FILE` cannot be read, print `ERROR: cannot read ` followed by the value of `CHECKS_FILE` to stderr and exit with status 1. When the report is written, print `Report written to ` followed by the value of `REPORT_FILE` to stdout.

Example: if `checks.txt` contains:
```
python -c "print('alpha')"
false
```
running `python run_checks.py checks.txt report.html run.log` writes `report.html` with two table rows and `run.log` with START/END lines for both commands.
