Create a single Python file named `run_report.py`. The program reads one command-line argument: a command string. It runs that command string through the system shell and captures its standard output as UTF-8 text. It computes a digest of the UTF-8 bytes of that standard output and writes the digest as 64 lowercase hexadecimal characters. It writes a UTF-8 HTML file named `report.html` in the current working directory. That file must contain an `<html>` element with a `<body>` element; inside the body, place exactly three `<pre>` elements in this order: the command string, the captured standard output, and the digest.
