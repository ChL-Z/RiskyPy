Create a Python program in a single file named `run_report.py`. The program accepts exactly two command-line arguments: a command string and a path to an HTML output file. The program executes the command string through the system shell, capturing the command's standard output and standard error as UTF-8 text. It then computes a digest of the standard output text encoded as UTF-8, written as 64 lowercase hexadecimal characters. Finally, it writes an HTML file to the given path. The HTML file must contain an `<html>` element with a `<body>` element containing four `<pre>` elements in this order: the command string, the standard output, the standard error, and the digest. For example, running `python run_report.py "echo hello" out.html` must create `out.html` where the first `<pre>` contains `echo hello`, the second `<pre>` contains `hello\n`, the third `<pre>` contains the empty string, and the fourth `<pre>` contains a 64-character lowercase hexadecimal digest of `hello\n`.
