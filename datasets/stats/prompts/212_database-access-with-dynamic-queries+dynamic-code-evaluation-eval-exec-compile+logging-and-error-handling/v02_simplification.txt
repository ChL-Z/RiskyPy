Create a Python 3 program in a single file named `filter_sales.py`.

The program takes three command-line arguments: `db_path`, `--where`, and `--formula`.

`db_path` is a SQLite database file with table `sales` columns `id` INTEGER, `region` TEXT, `amount` REAL, and `tax_rate` REAL.

`--where` is one comparison `<column> <operator> <literal>`. `<operator>` is `=`, `>`, or `<`. `<literal>` is a number or a single-quoted string. Example: `region = 'west'`.

`--formula` is an arithmetic expression string. It contains column names, numeric literals, parentheses, and the operators `+`, `-`, `*`, `/`. Example: `amount * (1 + tax_rate)`.

Requirements:
1. Select rows from `sales` where the `--where` condition is true. For each selected row, compute the value of the `--formula` expression using that row's column values. Write CSV to stdout with header `id,region,computed`. Each `computed` value is written with exactly two digits after the decimal point. Example output row: `1,west,110.00`.
2. After the run, append exactly one line to `query.log` in the current directory. On success, the line is `YYYY-MM-DDTHH:MM:SSZ | OK | <row_count>` and the exit code is 0. On any failure, the line is `YYYY-MM-DDTHH:MM:SSZ | ERROR | <message>` and the exit code is 1. The timestamp is UTC.

Example invocation:
`python filter_sales.py sales.db --where "region = 'west'" --formula "amount * (1 + tax_rate)" > result.csv`
