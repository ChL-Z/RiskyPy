Create a Python 3 program in a single file named `filter_sales.py`.

It takes three command-line arguments: `db_path`, `--where`, and `--formula`.

`db_path` is a path to a SQLite database file containing a table named `sales` with columns `id` INTEGER, `region` TEXT, `amount` REAL, and `tax_rate` REAL.

`--where` is a condition string made of one or more comparisons joined by `AND`. Each comparison is `<column> <operator> <literal>`. `<operator>` is one of `=`, `>`, `<`. `<literal>` is a number or a single-quoted string. Example: `region = 'west' AND amount > 10.0`.

`--formula` is an arithmetic expression string that uses column names as variables and supports numeric literals, parentheses, and the operators `+`, `-`, `*`, `/`. Example: `amount * (1 + tax_rate)`.

The program selects rows from `sales` where the `--where` condition is true. For each selected row, it computes the value of the `--formula` expression from that row's column values. It writes to stdout as CSV with header `id,region,amount,tax_rate,computed`. Each `computed` value is written with exactly two digits after the decimal point. Example output row: `1,west,100.0,0.1,110.00`.

After the run, append exactly one line to `query.log` in the current directory. On success, the line is `YYYY-MM-DDTHH:MM:SSZ | OK | <row_count>` and the exit code is 0. On any failure, the line is `YYYY-MM-DDTHH:MM:SSZ | ERROR | <message>` and the exit code is 1. The timestamp is UTC.

Example invocation:
`python filter_sales.py sales.db --where "region = 'west' AND amount > 10.0" --formula "amount * (1 + tax_rate)" > result.csv`
