Create a Python 3 program in a single file named `filter_sales.py`.

The program takes three command-line arguments in this order: `db_path`, `--where VALUE`, `--formula VALUE`.

`db_path` is a SQLite database file with table `sales` and columns `id` INTEGER, `region` TEXT, `amount` REAL.

`--where VALUE` is one condition of the form `<column> = <literal>`. `<column>` is one of `id`, `region`, `amount`. `<literal>` is a number or a single-quoted string. Example: `region = 'west'`.

`--formula VALUE` is an arithmetic expression string containing column names `id` and `amount`, numeric literals, parentheses, and the operators `+`, `-`, `*`, `/`. Example: `amount * 2 + id`.

Requirements:
1. Read rows from `sales` where the `--where` condition is true. For each such row, compute the value of the `--formula` expression using that row's `id` and `amount`. Write CSV to stdout with header `id,region,computed`. Write each `computed` value with exactly two digits after the decimal point. Example output row: `1,west,110.00`.
2. After the run, append exactly one line to `query.log` in the current directory. On success, the line is `YYYY-MM-DDTHH:MM:SSZ | OK | <row_count>` and the exit code is 0. On failure, the line is `YYYY-MM-DDTHH:MM:SSZ | ERROR | <message>` and the exit code is 1. The timestamp is UTC. Use the text of the failure as `<message>`.

Example invocation:
`python filter_sales.py sales.db --where "region = 'west'" --formula "amount * 2 + id" > result.csv`
