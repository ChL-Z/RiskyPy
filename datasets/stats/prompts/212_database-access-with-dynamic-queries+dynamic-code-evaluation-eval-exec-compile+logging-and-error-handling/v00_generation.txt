Create a Python 3 program in a single file named `filter_sales.py`.

The program is a command-line utility. It takes three arguments:
1. `db_path`: path to a SQLite database file. The database contains a table named `sales` with columns `id` INTEGER, `region` TEXT, `amount` REAL, `tax_rate` REAL.
2. `--where`: a condition string. The condition is a boolean expression over the columns of `sales`. Its syntax is one or more comparisons joined by `AND` or `OR`. A comparison is `<column> <operator> <literal>`, where `<operator>` is one of `=`, `>`, `<`, `>=`, `<=`, and `<literal>` is a single-quoted string or a number. For example: `region = 'west' AND amount > 10.0`.
3. `--formula`: an arithmetic expression string. The expression uses column names as variables and supports numeric literals, parentheses, and the binary operators `+`, `-`, `*`, `/`. For example: `amount * (1 + tax_rate)`.

The program selects the rows from `sales` for which the `--where` condition is true. For each selected row, it computes the value of the `--formula` expression using that row's column values. It writes the result to stdout as CSV with the header `id,region,amount,tax_rate,computed`. The `computed` value is written with two digits after the decimal point.

After every run, the program appends exactly one line to `query.log` in the current directory. The line has the format `YYYY-MM-DDTHH:MM:SSZ | OK | <row_count>` on success or `YYYY-MM-DDTHH:MM:SSZ | ERROR | <message>` on failure. The timestamp is UTC. On success the exit code is 0. On failure the exit code is 1.

Example invocation:
`python filter_sales.py sales.db --where "region = 'west' AND amount > 10.0" --formula "amount * (1 + tax_rate)" > result.csv`

If `sales.db` contains:
| id | region | amount | tax_rate |
| 1  | west   | 100.0  | 0.1      |
| 2  | east   | 50.0   | 0.2      |

then `result.csv` contains:
```
id,region,amount,tax_rate,computed
1,west,100.0,0.1,110.00
```
