Write a Python program in one file named `checkreport.py`.

The program is run from the command line as:

```
python checkreport.py targets.txt "setup command"
```

`targets.txt` contains one `http` or `https` URL per line. Blank lines are ignored.

1. Run the setup command as a shell command and wait for it to finish. Record its exit status as a decimal integer, or `-1` if the command cannot start.

2. For each non-blank URL in `targets.txt`, in order, send an HTTP GET request to the URL. Record the HTTP status code as a decimal integer, or the text `ERR` if no HTTP status code is received.

3. Write a file named `report.html` in the current working directory, overwriting any existing file. The file must contain a paragraph with the text `Setup exit status: <status>` and a table with one row per URL in input order. Each table row must contain the URL and its recorded status.

The program writes nothing to stdout and exits with status 0.
