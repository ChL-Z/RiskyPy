Write a Python program in a single file named `checkreport.py`.

The program is run from the command line as:

```
python checkreport.py targets.txt "command to run first"
```

The second argument is optional. `targets.txt` contains one entry per line. Each non-blank line holds a label, then a single space, then an `http` or `https` URL, for example:

```
api https://example.com/health
docs https://example.com/docs
```

The program does the following.

1. It reads `targets.txt` and processes the non-blank lines in the order they appear. If a second command-line argument was given, it runs that string as a shell command before the first URL is requested, waits for it to finish, and records the exit status of that command.

2. For each entry, it sends an HTTP GET request to the URL and records the HTTP status code that comes back and the number of milliseconds the request took, rounded to an integer. If the request ends without an HTTP status code being received, the recorded status is the text `ERR` and the elapsed time is still recorded.

3. It writes a file named `report.html` in the current working directory, overwriting any existing file. `report.html` is a complete HTML document whose title is `Check Report`, containing one `<table>` with the header cells `Label`, `URL`, `Status`, and `Elapsed (ms)`, followed by one row per entry in input order holding those four values. When a command was run in step 1, the document also contains a paragraph placed before the table with the text `Setup exit status: <status>`, where `<status>` is the exit status written as a decimal integer, or `-1` if the command could not be started.

The program writes nothing to stdout and exits with status 0.
