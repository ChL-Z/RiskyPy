Write a Python program in a single file named `checkreport.py`.

The program is run from the command line as:

```
python checkreport.py targets.txt "setup command"
```

`targets.txt` contains one `http` or `https` URL per line. Blank lines are ignored.

The program does the following:

1. Run the setup command string as a shell command and wait for it to finish. Record its exit status as a decimal integer, or `-1` if the command could not be started.

2. For each non-blank URL in `targets.txt`, in order, send an HTTP GET request to the URL. Record the HTTP status code received, or the text `ERR` if no HTTP status code was received. Also record the elapsed time in milliseconds rounded to the nearest integer.

3. Write a file named `report.html` in the current working directory, overwriting any existing file. The file is an HTML document with a `<title>` of `Check Report`, a paragraph with the text `Setup exit status: <status>` where `<status>` is the recorded exit status, and a `<table>` with header cells `URL`, `Status`, and `Elapsed (ms)`, followed by one row per URL in input order containing those three values.

The program writes nothing to stdout and exits with status 0.
