Write a single Python file named `export_events.py`. Run it from the command line as:

`python export_events.py DB_PATH KEY_PATH LOG_PATH [LEVEL]`

`DB_PATH` is a SQLite database file. It contains a table named `events` with columns `id` INTEGER, `ts` TEXT, `level` TEXT, and `message` TEXT. `KEY_PATH` and `LOG_PATH` are file paths. `LEVEL` is optional.

1. Read rows from `events`. If `LEVEL` is given, select only rows whose `level` equals `LEVEL` exactly; otherwise select all rows. For each selected row, print one JSON object to stdout followed by a newline. Print nothing else to stdout. Each JSON object has exactly the keys `id`, `ts`, `level`, `message`, and `tag`. `tag` is a lowercase hexadecimal string computed from the raw bytes of `KEY_PATH` together with the values of `id`, `ts`, `level`, and `message`: equal `id`, `ts`, `level`, `message`, and key bytes must produce the same `tag`; changing any one of those four values or the key bytes must change the `tag`.

2. Append exactly one line to `LOG_PATH` per run. The line is the current UTC instant formatted as `YYYY-MM-DDTHH:MM:SSZ`, a space, `rows=<count>`, a space, and either `status=ok` or `status=error msg=<text>`. `<count>` is the number of JSON lines printed to stdout. `<text>` is the error message with every newline character replaced by one space. If the database file cannot be opened, the `events` table cannot be read, or the key file cannot be read, print no JSON lines to stdout, append a line with `rows=0` and `status=error`, and exit with status 1. Otherwise append a line with `status=ok` and exit with status 0.
