Write a Python program in a single file named `taskcache.py`. Run it as `python taskcache.py` with no command-line arguments.

The program reads lines from stdin until EOF. It keeps an ordered list of task text strings. At startup, if `tasks.cache` exists in the current working directory, load the task list from the file this program previously wrote; otherwise start with an empty list. When stdin ends, write the current task list to `tasks.cache` in the current working directory, replacing its previous contents.

Each input line is one command:

- `add <text>`: append the text after the first space following `add`.
- `list`: print one line per task to stdout in list order, formatted as `<n> <text>`, where `<n>` is the 1-based position.
- Any other first word: print `error: unknown command <word>` to stderr.
- An `add` line with no text after `add`: print `error: add requires text` to stderr.
- An empty line or a line containing only whitespace: print nothing.

For every input line, append one line to `tasks.log` in the current working directory without truncating it. The appended line is `<command> <outcome>`, where `<command>` is the first whitespace-separated word of the input line or `-` if the line is empty or contains only whitespace, and `<outcome>` is `ok` if the command was carried out, or `error` if it could not be carried out.
