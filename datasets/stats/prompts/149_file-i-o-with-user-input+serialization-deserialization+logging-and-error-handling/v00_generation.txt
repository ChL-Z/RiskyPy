Write a Python program contained in a single file named `taskcache.py`. The program is run as `python taskcache.py` with no command-line arguments, and it reads commands from standard input, one command per line, until end of input.

Task list handling: The program keeps an ordered list of task records in memory. Each task record holds a text string and a completion flag. At startup, if a file named `tasks.cache` exists in the current working directory, the program loads the task list from it. When standard input ends, the program writes the current task list to `tasks.cache` in the current working directory, replacing any previous contents of that file. Each input line is one of:

- `add <text>` — append a task record whose text is everything on the line after the single space following `add`, with completion flag `False`.
- `done <n>` — set the completion flag of the task at 1-based position `n` to `True`.
- `list` — print one line per task to standard output, in list order, formatted as `<n> [x] <text>` for a completed task and `<n> [ ] <text>` for an incomplete task, where `<n>` is the 1-based position of the task.

Logging and errors: For every input line, append one line to `tasks.log` in the current working directory, without truncating existing contents of that file. Each appended line has the form `<timestamp> <command> <outcome>`, where `<timestamp>` is the current UTC time in ISO 8601 format, `<command>` is the first whitespace-separated word of the input line (or `-` if the line is empty), and `<outcome>` is `ok` when the command was carried out, `error` when it could not be carried out, or `unknown` when the first word is not one of the three command words above. When a `done` command names a position that is not an integer or that is outside the current list range, print `error: cannot complete task <n>` to standard error and continue reading the next line. An empty input line produces a log line with command `-` and outcome `unknown`, and prints nothing.

For example, starting in a directory that has no `tasks.cache` and no `tasks.log`, feeding this input on standard input:

```
add write report
done 1
list
done 5
```

writes to standard output:

```
1 [x] write report
```

writes to standard error:

```
error: cannot complete task 5
```

and then `tasks.log` contains four lines, one for each input line, ending with a line whose command is `done` and whose outcome is `error`.
