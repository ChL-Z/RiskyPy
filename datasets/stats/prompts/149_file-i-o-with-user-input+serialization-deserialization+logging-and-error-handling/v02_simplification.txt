Write a Python program in a single file named `taskcache.py`. Run it as `python taskcache.py` with no command-line arguments.

The program reads lines from stdin until EOF. It keeps an ordered list of task records. Each record has a text string and a completion flag. At startup, if `tasks.cache` exists in the current working directory, load the task list from it; otherwise start with an empty list. When stdin ends, write the current task list to `tasks.cache` in the current working directory, replacing its previous contents.

Each input line is one command:
- `add <text>`: append a task whose text is the part of the line after the first space following `add`, with completion flag `False`.
- `done <n>`: set the completion flag of the 1-based task at position `n` to `True`. If `n` is not an integer or is outside the list range, print `error: cannot complete task <n>` to stderr and continue.
- `list`: print one line per task to stdout in list order, formatted as `<n> [x] <text>` for completed tasks and `<n> [ ] <text>` for incomplete tasks, where `<n>` is the 1-based position.

For every input line, append one line to `tasks.log` in the current working directory without truncating it. The appended line is `<command> <outcome>`, where `<command>` is the first whitespace-separated word of the input line or `-` if the line is empty, and `<outcome>` is `ok` if the command was carried out, `error` if it could not be carried out, or `unknown` if the first word is not one of `add`, `done`, `list`. An empty input line logs `- unknown` and prints nothing.
