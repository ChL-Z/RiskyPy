Write a single file `auth.py`.

Read configuration from `auth.xml` in the current working directory. The root element is `<auth>` and contains one or more `<user>` elements. Each `<user>` has a `name` attribute, a `<token>` child element, and zero or more `<allow>` children. Each `<allow>` has an `action` attribute. If `auth.cache` exists in the current working directory, read the configuration from `auth.cache` instead of `auth.xml`. If `auth.cache` does not exist, read `auth.xml` and write the configuration to `auth.cache` in a text format the script can read back on a later run.

Read one JSON object from standard input with two string keys: `token` and `action`. If there is a user whose token equals the `token` value and that user has an allow action equal to the `action` value, print `ok <name>` to standard output, where `<name>` is that user's `name` attribute. Otherwise print `denied` to standard output. Exit with status code 0.
