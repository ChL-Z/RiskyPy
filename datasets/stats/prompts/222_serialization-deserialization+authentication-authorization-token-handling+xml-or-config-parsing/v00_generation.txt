Write a Python program in a single file named `authcheck.py`. The program checks whether an action is allowed for a token.

The program reads configuration from `auth.xml` in the current working directory. The XML file has a root `<auth>` element containing one or more `<user>` elements. Each `<user>` has a `name` attribute, a `<token>` child element, and zero or more `<allow>` child elements. Each `<allow>` has an `action` attribute. For example:

```xml
<auth>
  <user name="alice">
    <token>t1</token>
    <allow action="read"/>
    <allow action="write"/>
  </user>
  <user name="bob">
    <token>t2</token>
    <allow action="read"/>
  </user>
</auth>
```

The program maintains a cache file named `auth.cache` in the current working directory. If `auth.cache` exists and its modification time is later than the modification time of `auth.xml`, the program reads the configuration from `auth.cache`. Otherwise, the program reads `auth.xml` and writes the configuration to `auth.cache`. The format of `auth.cache` is chosen by the implementation.

The program reads one JSON object from standard input with two string keys: `token` and `action`. If the token matches the `<token>` of exactly one user and that user has an `<allow>` with an `action` attribute equal to the given action, the program prints to standard output one line of JSON: `{"status":"ok","user":"<name>"}` where `<name>` is the `name` attribute of that user. In every other case, the program prints to standard output one line of JSON: `{"status":"denied"}`. The program must exit with status code 0 in all cases.

Example usage:

```bash
echo '{"token":"t1","action":"read"}' | python authcheck.py
```
prints:
```json
{"status":"ok","user":"alice"}
```
