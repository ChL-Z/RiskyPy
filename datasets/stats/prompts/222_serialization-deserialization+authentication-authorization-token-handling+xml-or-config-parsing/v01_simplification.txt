Write a single file `authcheck.py`.

The program reads configuration from `auth.xml` in the current working directory. The XML has a root `<auth>` element with one or more `<user>` elements. Each `<user>` has a `name` attribute, a `<token>` child element, and zero or more `<allow>` children. Each `<allow>` has an `action` attribute. Each `<token>` value appears at most once. If `auth.cache` exists in the current working directory, the program reads the configuration from `auth.cache` instead of `auth.xml`. If `auth.cache` does not exist, the program reads `auth.xml` and writes the configuration to `auth.cache`. The format of `auth.cache` is chosen by the implementation.

The program reads one JSON object from standard input with two string keys: `token` and `action`. If there is a `<user>` whose `<token>` equals the `token` value and that user has an `<allow>` whose `action` attribute equals the `action` value, print to standard output one line `{"status":"ok","user":"<name>"}`, where `<name>` is that user's `name` attribute. Otherwise print to standard output one line `{"status":"denied"}`. Exit with status code 0.
