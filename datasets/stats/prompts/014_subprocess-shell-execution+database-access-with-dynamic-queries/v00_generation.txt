Write a Python script `row_runner.py` in a single file. The script reads one SQL query from stdin, executes it against the SQLite database file named by the first command-line argument, and for each result row runs the external program named by the second command-line argument with each column value converted to text and passed as a separate argument in the order the columns appear in the query result.

For each result row, the script must forward the external program's stdout and stderr to its own stdout and stderr respectively, then print the external program's exit status as a decimal integer followed by a newline to its own stdout. If any external program exits with a nonzero status, the script must exit with the status of the last such program after processing all rows; otherwise it must exit with 0. It must not print any other text to its stdout.

Usage example:

```
python row_runner.py ./orders.db /usr/bin/echo <<'SQL'
SELECT customer, total FROM orders WHERE total > 100;
SQL
```

If the query returns rows `("Ada", 120)` and `("Bob", 200)`, the script runs `/usr/bin/echo Ada 120` and `/usr/bin/echo Bob 200`, forwards their outputs, prints `0` after each row, and exits with 0.
