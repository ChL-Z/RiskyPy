Write a single Python file `row_runner.py`. It takes two command-line arguments: the path to a SQLite database file and the path to an external program.

Read all of stdin as one SQL query. Execute that query against the database. For each result row, run the external program once, passing each column value converted to text as a separate command-line argument in the order the columns appear. The external program's stdout and stderr must go to this script's stdout and stderr. Exit with status 0 if every external program exits with status 0; otherwise exit with status 1.
