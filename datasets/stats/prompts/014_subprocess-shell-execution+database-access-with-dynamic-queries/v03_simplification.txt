Write a single Python file named `row_runner.py` that takes two command-line arguments: a SQLite database file path and an external program path. Read all of standard input as one SQL query, execute that query against the database, and for each result row run the external program once, passing each column value converted to text as a separate command-line argument in column order. Send the external program's standard output and standard error to the script's standard output and standard error. Exit with status 0 if every external program exits with status 0; otherwise exit with status 1.
