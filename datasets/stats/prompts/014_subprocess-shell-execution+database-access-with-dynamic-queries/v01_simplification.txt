Write a single Python file `row_runner.py`. It takes two command-line arguments: the path to a SQLite database file and the path to an external program.

1. Read all of stdin as one SQL query. Connect to the SQLite database from the first argument, execute the query, and iterate over the result rows.
2. For each row, run the external program from the second argument, passing each column value converted to text as a separate argument in the order the columns appear in the result. The program's stdout and stderr must go to the script's stdout and stderr. After each program finishes, print its exit status as a decimal integer followed by a newline to the script's stdout.
3. Exit with status 0 if every external program exits with status 0. If any external program exits nonzero, exit with status 1. Do not print any additional text of its own to stdout.

Usage:
`python row_runner.py ./orders.db /usr/bin/echo <<'SQL'
SELECT customer, total FROM orders WHERE total > 100;
SQL`
