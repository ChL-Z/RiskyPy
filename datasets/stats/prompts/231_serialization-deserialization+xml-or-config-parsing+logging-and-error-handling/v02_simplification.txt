Write a Python program in a single file named `settings_viewer.py`.

The program is run as `python settings_viewer.py <config.xml>`. The XML file contains a `<settings>` root with `<entry>` elements. Each `<entry>` element has one `key` attribute and one `value` attribute. Build a mapping from each `key` attribute to its `value` attribute, preserving the order in which the entries appear in the XML file.

Requirements:

1. Cache. The cache path is `<config.xml>` with `.cache` appended. If that cache file exists, obtain the mapping by reading the cache file and do not read the XML file. Otherwise, obtain the mapping by parsing the XML file and write that same mapping to the cache file, replacing its contents.

2. Output and reporting. After obtaining the mapping, print it to standard output as a JSON object with 2-space indentation and a trailing newline. Write exactly one line to standard error: `source=xml` when the mapping came from the XML file, or `source=cache` when it came from the cache file.

3. Errors. If parsing the XML file or reading or writing the cache file fails, write exactly one line to standard error starting with `error: ` followed by the path of the file that caused the failure, exit with status code 1, and write nothing to standard output.
