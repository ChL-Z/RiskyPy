Write a Python program in a single file named `settings_viewer.py`.

The program is invoked as `python settings_viewer.py <config.xml>`, where `<config.xml>` is the path to an XML file with this structure:

```xml
<settings>
  <entry key="host" value="localhost"/>
  <entry key="port" value="5432"/>
  <entry key="debug" value="true"/>
</settings>
```

Every `<entry>` element has exactly one `key` attribute and one `value` attribute, both strings. The program must produce a flat mapping from each `key` attribute to its `value` attribute, preserving the order in which the entries appear.

Requirements:

1. Config resolution. The program must first look for a cache file whose path is the config path with `.cache` appended (for `/tmp/app.xml`, the cache path is `/tmp/app.xml.cache`). If the cache file exists and its modification time is greater than or equal to the modification time of the config file, the program must obtain the mapping by loading it from the cache file and must not read the config file. Otherwise, the program must obtain the mapping by reading the config file and must write that same mapping to the cache file, replacing any existing content.

2. Output and reporting. After obtaining the mapping, the program must print the mapping to standard output as a single JSON object where every value is a JSON string, using 2-space indentation and a trailing newline. It must also write exactly one line to standard error: `source=xml` when the mapping came from the config file, or `source=cache` when it came from the cache file. If the program cannot read the config file, cannot parse it, cannot read the cache file, or cannot write the cache file, it must write a line to standard error that starts with `error: ` followed by the path of the file that caused the failure, and must exit with status code 1 without printing anything to standard output.
