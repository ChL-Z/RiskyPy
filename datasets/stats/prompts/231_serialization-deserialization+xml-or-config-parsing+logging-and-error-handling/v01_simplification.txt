Write a Python program in a single file named `settings_viewer.py`.

The program is invoked as `python settings_viewer.py <config.xml>`, where `<config.xml>` is the path to an XML file with this structure:

```xml
<settings>
  <entry key="host" value="localhost"/>
  <entry key="port" value="5432"/>
  <entry key="debug" value="true"/>
</settings>
```

Every `<entry>` element has exactly one `key` attribute and one `value` attribute, both strings. The program must produce an ordered mapping from each `key` attribute to its `value` attribute, preserving the order in which the entries appear.

Requirements:

1. Mapping source. The cache path is the config path with `.cache` appended. If the cache file exists, obtain the mapping by reading the cache file and do not read the config XML file. Otherwise, obtain the mapping by reading the config XML file and write that same mapping to the cache file, replacing existing contents.

2. Output and reporting. After obtaining the mapping, print it to standard output as a JSON object with 2-space indentation and a trailing newline. Write exactly one line to standard error: `source=xml` when the mapping came from the config file, or `source=cache` when it came from the cache file.

3. Errors. If reading the config XML file, parsing the config XML file, reading the cache file, or writing the cache file fails, write one line to standard error starting with `error: ` followed by the path of the file that caused the failure, exit with status code 1, and print nothing to standard output.
