Write a Python program in a single file named `settings_viewer.py`.

The program is run as `python settings_viewer.py <config.xml>`. The XML file has a `<settings>` root containing `<entry>` elements. Each `<entry>` has a `key` attribute and a `value` attribute. Build a dictionary that maps each `key` attribute to its `value` attribute.

1. Load the dictionary. The cache path is the config path with `.cache` appended. If that cache file exists, read the dictionary from the cache file and do not read the XML file. Otherwise, parse the XML file to build the dictionary and write the dictionary to the cache file, replacing the cache file's contents. The cache file stores a JSON object.

2. Print and report. Print the dictionary to standard output as a JSON object with 2-space indentation and a trailing newline. Write exactly one line to standard error: `source=xml` if the dictionary came from the XML file, or `source=cache` if it came from the cache file.

3. Errors. If parsing the XML file or reading or writing the cache file fails, write exactly one line to standard error: `error: <path>`, where `<path>` is the path of the file that caused the failure. Exit with status code 1. Write nothing to standard output.
