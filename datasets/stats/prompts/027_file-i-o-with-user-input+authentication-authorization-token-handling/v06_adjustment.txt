Create a single Python file named `filegate.py`. The program accepts exactly two command-line arguments: `credentials_path` and `token`. Read the credentials file as newline-separated records. Each record is `token_id:directory`, where `token_id` is an identifier string and `directory` is a directory path. Read one line from stdin as `requested_path`; remove only the final newline character if present.

The `token` argument is an access identifier. Find the first credentials record whose `token_id` equals `token`. If no record matches, write `Denied` to stdout and exit with status 0. If a record matches, use its `directory` as the authorized base. Accept `requested_path` only when it is a relative path and, after treating `.` and `..` as path segments without following symbolic links, the resulting path stays within the authorized base directory. If it is not accepted, write `Denied` to stdout and exit with status 0. If it is accepted, write the bytes of the file at the resulting path to stdout and exit with status 0. If the file cannot be opened for reading, write `Denied` to stdout and exit with status 0.
