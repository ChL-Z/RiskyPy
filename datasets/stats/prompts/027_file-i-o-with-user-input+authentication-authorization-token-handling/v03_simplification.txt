Write a Python script named `filegate.py`.

The script accepts exactly two command-line arguments: a credentials file path and a token string. The credentials file contains one entry per line in the format `token:directory`, where `directory` is relative to the directory containing the credentials file. If a credentials entry has a token equal to the token argument, use that entry's directory to resolve the requested path.

Read the first line from stdin and remove the trailing newline if present. Treat that line as the requested path. If a matching token entry exists, write the contents of the requested file to stdout. Otherwise, write `Denied` to stdout. Exit with status code 0 after writing either output.
