Create a Python file named `filegate.py`. It takes two command-line arguments: a credentials file path and a token. Each line of the credentials file is `token:directory`. Read the first line from stdin, ignoring the line-ending newline, as `requested_path`. If the token argument equals the token part of a credentials line, write to stdout the contents of the file at `requested_path` joined to that line's directory. If no credentials line has that token, write `Denied` to stdout. Exit with status code 0 in both cases.
