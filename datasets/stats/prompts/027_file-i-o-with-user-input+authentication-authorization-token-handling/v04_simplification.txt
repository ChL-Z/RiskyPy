Write a Python script named `filegate.py`. It accepts exactly two command-line arguments: a credentials file path and a token string. Each line of the credentials file is `token:directory`. Read the first line from stdin, remove one trailing newline if present, and treat it as a requested path. If the token argument equals a line's token, write the contents of the file at that requested path relative to that line's directory to stdout. If no line has that token, write `Denied` to stdout. Exit with status code 0 after either output.
