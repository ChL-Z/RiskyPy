Write a Python script named `filegate.py`. It takes exactly two command-line arguments: the path to a credentials file and a token string. The credentials file contains one line per entry in the format `token:directory`, where a token contains no colon and `directory` is a path relative to the directory containing the credentials file. Read one line from stdin and remove the trailing newline if present; this line is the requested path. If the credentials file contains a line whose token equals the token argument, write the contents of the file at the requested path resolved against that entry's directory to stdout. Otherwise write `Denied` to stdout. Exit with status code 0 after writing either output.
