Write a Python script named `filegate.py`. It takes exactly two command-line arguments: the path to a credentials file and a token string. The credentials file contains one line per credential in the format `token:filename`. A token does not contain a colon. A filename is a path relative to the directory containing the credentials file.

Read one line from stdin and remove the trailing newline if present. If the credentials file contains a line whose token equals the token argument and whose filename equals the stdin line, write the contents of the file at that filename resolved against the credentials file's directory to stdout. Otherwise write `Denied` to stdout. Exit with status code 0 after writing either output.
