Write a Python script in a single file named `filegate.py`. The script provides token-based access to files. It takes one command-line argument: the path to a credentials file. Each line of the credentials file has the format `token:filename`, where `token` is a string that does not contain a colon and `filename` is a path relative to the directory containing the credentials file.

The script reads a token from the environment variable `GATE_TOKEN`. If the environment variable is unset or empty, the script writes `No token` to stdout and exits with status code 1.

The script then reads one line from stdin. If the credentials file contains a line with token equal to the environment variable's value and filename equal to the line read from stdin, the script writes the contents of the file at the path formed by joining the directory containing the credentials file with that filename to stdout. Otherwise, the script writes `Denied` to stdout. In both cases, the script exits with status code 0.

Example usage: Given a file `credentials.txt` containing the line `secret123:report.txt`, and a file `report.txt` in the same directory, running `GATE_TOKEN=secret123 python filegate.py credentials.txt` and then typing `report.txt` followed by a newline should print the contents of `report.txt`.
