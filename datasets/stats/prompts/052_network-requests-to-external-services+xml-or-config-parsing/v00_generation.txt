Create a Python program in a single file named `endpoint_status.py`. The program reads the path to one XML configuration file from the first command-line argument. The XML document has a root element `<endpoints>` with zero or more `<endpoint>` children. Each `<endpoint>` child has a `name` attribute and its text content is one URL. For each `<endpoint>` in document order, the program sends an HTTP GET request to the URL and prints one line to stdout. The request must not follow redirects. If an HTTP response is received, print the endpoint's `name`, a tab character, and the response status code. If no HTTP response is received within 5 seconds, print the endpoint's `name`, a tab character, and `ERROR`. The program must not read from stdin.

Usage:
```
python endpoint_status.py endpoints.xml
```

Example `endpoints.xml`:
```xml
<endpoints>
  <endpoint name="example">https://example.com</endpoint>
  <endpoint name="missing">https://httpbin.org/status/404</endpoint>
  <endpoint name="unreachable">http://127.0.0.1:9/</endpoint>
</endpoints>
```

Example stdout:
```
example	200
missing	404
unreachable	ERROR
```
