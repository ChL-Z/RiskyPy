Write a single Python file named `checkurls.py`. The program reads newline-separated URLs from stdin. For each non-empty line, send one HTTP GET request to that URL. At most 3 requests may be in progress at any moment, and consecutive request starts must be separated by at least 0.1 seconds. After each request finishes, print one line to stdout in the form `<url> <status>`, where `<status>` is the HTTP status code as an integer, or `ERROR` if no HTTP status code was received. Output order does not matter. Print nothing else.
