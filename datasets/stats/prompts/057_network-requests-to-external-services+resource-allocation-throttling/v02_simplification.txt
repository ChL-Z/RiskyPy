Write a single Python file named `checkurls.py`.

The program reads one command-line argument: a path to a text file. Each line in the file is a URL. Remove the line ending from each line. Skip lines that are empty after removing the line ending.

For every non-empty URL, send one HTTP GET request to that URL. Run no more than 4 HTTP GET requests at the same time. No two HTTP GET requests may start less than 0.2 seconds apart.

For every non-empty URL, write one line to stdout. Each line is `<url> <result>`, where `<url>` is the URL from the file and `<result>` is the numeric HTTP status code, or `ERROR` if no HTTP status code was received. The output lines may be in any order. Write nothing else to stdout. Exit with status 0 if every non-empty URL produced a numeric HTTP status code, and status 1 otherwise.
