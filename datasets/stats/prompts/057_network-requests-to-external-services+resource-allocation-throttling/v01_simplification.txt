Write a Python program in a single file named `checkurls.py`.

The program takes one command-line argument: the path to a text file. The file contains one URL per line. For each line, remove the line ending. Ignore lines that are empty after removing the line ending.

For each non-empty line, send one HTTP GET request to that URL. Write one line to stdout for each non-empty input line, in the same order. Each output line is `<url> <result>`, where `<url>` is the URL used for that request and `<result>` is either the numeric HTTP status code or `ERROR` if no HTTP status code was received. Write nothing else to stdout. Exit with status 0 if every non-empty input line produced a status code, and status 1 otherwise.

Do not have more than 4 HTTP requests in progress at the same time. Do not start two HTTP requests less than 0.2 seconds apart.
