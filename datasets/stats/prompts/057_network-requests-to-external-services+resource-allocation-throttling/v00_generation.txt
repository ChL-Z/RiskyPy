Write a Python program in a single file named `checkurls.py`.

The program is a command-line tool. Its first positional argument is the path to a text file containing one URL per line, with no leading or trailing whitespace on any line. Lines that are empty are ignored. The program sends one HTTP GET request to each URL, and for each non-empty input line it writes exactly one line to standard output, in the same order the URLs appear in the input file. Each output line has the form:

    <url> <result>

where `<url>` is the URL exactly as it appeared on the input line, and `<result>` is either the numeric HTTP status code returned for that URL, or the word `ERROR` if no HTTP status code was obtained. The program writes nothing else to standard output. It exits with status 0 when every output line reports a status code, and exits with status 1 otherwise.

The program must never have more than 4 HTTP requests in progress at the same time, and it must not start two HTTP requests less than 0.2 seconds apart.

Example usage and output:

Suppose `urls.txt` contains:

    https://example.com/
    https://example.com/missing
    https://no-such-host.invalid/

Running `python checkurls.py urls.txt` prints:

    https://example.com/ 200
    https://example.com/missing 404
    https://no-such-host.invalid/ ERROR

and the process exit status is 1.
