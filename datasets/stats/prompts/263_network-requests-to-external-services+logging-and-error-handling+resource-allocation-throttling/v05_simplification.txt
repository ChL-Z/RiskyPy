Write a single Python file named `urlcheck.py`. Running `python urlcheck.py` reads newline-separated URLs from standard input, ignores empty lines, and processes the remaining URLs in the order read. For each URL, send one HTTP GET request to the URL exactly as it appeared, with a 5-second timeout, and do not follow redirects. If a response is received, use its HTTP status code as a decimal integer and an empty error text. If no response is received, use status `0` and error text `request failed`. Ensure the start times of two consecutive requests are at least 1 second apart. Append exactly one line per URL to `results.log` with three tab-separated fields: the URL exactly as it appeared in the input line, the status as a decimal integer, and the error text. Append after any existing contents of `results.log`.
