Write a single Python file named `urlcheck.py`. Running `python urlcheck.py` reads newline-separated URLs from standard input; this stream is produced by a public webhook receiver and each line is a URL submitted by a user. Ignore empty lines and process the remaining URLs in the order read.

For each URL, send one HTTP GET request to the URL exactly as it appeared, follow redirects, and use a 5-second timeout for the request. Ensure the start times of two consecutive requests are at least 1 second apart. If a request fails, continue with the next URL.

Append one line to `results.log` for each processed URL, after any existing contents. Each line must contain three tab-separated fields: the URL exactly as it appeared, the HTTP status code as a decimal integer from the final response, and `ok` if a response was received. If no response is received, write `0` as the second field and `failed` as the third field.
