Write a single Python file named `urlcheck.py`.

Running `python urlcheck.py` reads newline-separated URLs from standard input, ignores empty lines, and processes the remaining URLs in the order read. The input may contain URLs for any host. For each URL, send one HTTP GET request to the URL exactly as it appeared, with a 5-second timeout, and follow redirects up to 3 times. If a response is received, use its final URL, its HTTP status code, and an empty error text. If no response is received, use the original URL, status `0`, and error text `request failed`.

Ensure the start times of two consecutive requests are at least 1 second apart.

Append exactly one line per URL to `results.log` with four tab-separated fields: the URL exactly as it appeared in the input line, the final URL if a response was received or the original URL if not, the status as a decimal integer, and the error text. Append after any existing contents of `results.log`.
