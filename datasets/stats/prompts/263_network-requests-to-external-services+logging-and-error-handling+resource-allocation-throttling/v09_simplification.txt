Write a single Python file named `urlcheck.py`. Running `python urlcheck.py` reads newline-separated URLs from standard input in order, ignoring empty lines. For each URL, send one HTTP GET request to that URL with a 5-second timeout. Before starting a request, wait until at least 1 second has passed since the start time of the previous request. If a request fails or no response is received, continue with the next URL.

Append one line to `results.log` for each URL processed, after any existing contents. Each line must contain exactly three tab-separated fields: the URL as it appeared on the input line without the newline, the HTTP status code from the response as a decimal integer, and `ok` if a response was received. If no response was received, write `0` as the second field and `failed` as the third field.
