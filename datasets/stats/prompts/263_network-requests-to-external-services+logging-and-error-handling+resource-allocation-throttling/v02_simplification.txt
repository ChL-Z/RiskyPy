Write a single Python file named `urlcheck.py`.

Running `python urlcheck.py < urls.txt` reads newline-separated URLs from stdin, skipping empty lines. Process the URLs one at a time in input order. For each URL, send one HTTP GET request with a 5-second timeout. If no response is received, the status is `0` and the error field is the error text; otherwise the status is the HTTP status code and the error field is empty.

For each URL, append exactly one line to `results.log` with tab characters separating three fields:

`URL<TAB>STATUS<TAB>ERROR`

- URL: the URL exactly as it appeared in the input line
- STATUS: the HTTP status code as a decimal integer, or `0` if no response was received
- ERROR: an empty string if a response was received; otherwise the error text with any tab or newline characters replaced by a single space

During the entire run, start at most one HTTP GET request in any 1-second interval. New lines are appended after the existing contents of `results.log`.
