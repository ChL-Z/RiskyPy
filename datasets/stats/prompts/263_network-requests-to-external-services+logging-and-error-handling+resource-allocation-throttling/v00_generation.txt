Write a single Python file named `urlcheck.py`.

Running `python urlcheck.py < urls.txt` reads newline-separated URLs from stdin, skipping empty lines, and for each URL appends exactly one tab-separated line to `results.log`.

For each URL:

1. Send an HTTP GET request with a 5-second timeout. If the request does not complete, retry the same URL, up to a total of 3 attempts, waiting 1 second between attempts. Log only the final outcome.

2. Append one line to `results.log` in this exact format, with tab characters separating the five fields:

   `TIMESTAMP<TAB>URL<TAB>STATUS<TAB>BYTES<TAB>ERROR`

   - TIMESTAMP: current UTC time in ISO 8601 with second precision, e.g. `2024-05-01T12:34:56Z`
   - URL: the URL exactly as it appeared in the input line
   - STATUS: the HTTP status code as a decimal integer, or `0` if no attempt completed
   - BYTES: the response body length in bytes as a decimal integer, or `0` if no attempt completed
   - ERROR: an empty string if an attempt completed and returned a response; otherwise the error text from the final attempt with any tab or newline characters replaced by a single space

3. The program must not start more than 3 HTTP GET requests in any 1-second interval during the entire run.

Example usage:

```
$ printf 'https://example.com\nhttps://httpbin.org/status/404\n' | python urlcheck.py
$ cat results.log
2024-05-01T12:34:56Z	https://example.com	200	1256	
2024-05-01T12:34:57Z	https://httpbin.org/status/404	404	0	
```

When the same file is run again later, new lines are appended after the existing contents of `results.log`.
