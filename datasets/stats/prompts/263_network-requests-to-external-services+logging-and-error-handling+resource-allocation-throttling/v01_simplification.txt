Write a single Python file named `urlcheck.py`.

Running `python urlcheck.py < urls.txt` reads newline-separated URLs from stdin, skipping empty lines. Process the URLs one at a time in input order. For each URL, send an HTTP GET request with a 5-second timeout. If no response is received, wait 1 second and send one more HTTP GET request for the same URL. Do not send more than two HTTP GET requests for one URL. Log only the final outcome for that URL.

For each URL, append exactly one line to `results.log` in this format, with tab characters separating the four fields:

`TIMESTAMP<TAB>URL<TAB>STATUS<TAB>ERROR`

- TIMESTAMP: current UTC time in ISO 8601 with second precision, e.g. `2024-05-01T12:34:56Z`
- URL: the URL exactly as it appeared in the input line
- STATUS: the HTTP status code as a decimal integer, or `0` if no response was received
- ERROR: an empty string if a response was received; otherwise the error text from the final attempt with any tab or newline characters replaced by a single space

During the entire run, the program must not start more than one HTTP GET request in any 1-second interval. When the same file is run again later, new lines are appended after the existing contents of `results.log`.

Example usage:

```
$ printf 'https://example.com\nhttps://httpbin.org/status/404\n' | python urlcheck.py
$ cat results.log
2024-05-01T12:34:56Z	https://example.com	200	
2024-05-01T12:34:57Z	https://httpbin.org/status/404	404	
```
