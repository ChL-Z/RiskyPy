Write a single Python file named `urlcheck.py`. Running `python urlcheck.py` reads newline-separated URLs from standard input; each line is a URL submitted by an external service. Ignore empty lines and process the remaining URLs in the order read. For each URL, send one HTTP GET request to the URL exactly as it appeared, with a 5-second timeout, and do not follow redirects. If a response is received, append to `results.log` three tab-separated fields: the URL exactly as it appeared, the HTTP status code as a decimal integer, and the entire response body decoded as UTF-8 with undecodable bytes replaced by U+FFFD. If no response is received, use `0` and `request failed` as the second and third fields. Ensure the start times of two consecutive requests are at least 1 second apart. Append after any existing contents of `results.log`.
