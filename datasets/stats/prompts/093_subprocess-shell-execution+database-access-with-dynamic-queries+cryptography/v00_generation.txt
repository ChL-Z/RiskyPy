Write a Python program in a single file named `runjob.py`. The program has one entry point: `python runjob.py <job_name>`. It reads from a SQLite database file `jobs.db` in the current directory. `jobs.db` contains a table `jobs` with columns `name` (TEXT) and `command` (TEXT). The program selects every row where `name` equals `<job_name>`. For each selected row, in the order the database returns them, it executes the row's `command` value as a shell command line, captures stdout and stderr separately, and waits for it to finish.

For each execution, it prints one line to stdout in the format `<job_name>\t<exit_code>\t<fingerprint>`, where `<exit_code>` is the command's exit status as a decimal integer and `<fingerprint>` is a lowercase hexadecimal keyed fingerprint computed over the bytes of the command, a single NUL byte, the captured stdout, a single NUL byte, and the captured stderr, using the raw bytes of the file `fingerprint.key` as the key.

The program exits with status 0 if every executed command exited 0; otherwise it exits with status 1. Example: with `jobs.db` containing a row `("nightly", "echo hello")`, `fingerprint.key` containing 32 bytes, running `python runjob.py nightly` prints `nightly\t0\t<hex>` and exits 0.
