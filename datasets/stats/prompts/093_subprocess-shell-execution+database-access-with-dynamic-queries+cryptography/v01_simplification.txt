Write a Python program in a single file named `runjob.py`, run as `python runjob.py <job_name>` from a directory that contains `jobs.db` and `fingerprint.key`.

`jobs.db` is a SQLite database with a table `jobs` of columns `name` (TEXT) and `command` (TEXT), and it contains exactly one row whose `name` equals `<job_name>`. The program reads that row's `command` value, runs it as a shell command line, waits for it to finish, and captures its stdout and stderr separately.

The program prints one line to stdout in the format `<job_name>\t<exit_code>\t<fingerprint>`, where `<exit_code>` is the command's exit status as a decimal integer, and `<fingerprint>` is a lowercase hexadecimal keyed fingerprint computed over the concatenation of the command's bytes, a NUL byte, the captured stdout bytes, a NUL byte, and the captured stderr bytes, keyed by the raw bytes of `fingerprint.key`. The program exits with status 0 if the command exited with status 0, and with status 1 otherwise.
