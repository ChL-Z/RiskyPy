Write `runjob.py`. It is run as:

```
python runjob.py <job_name>
```

from a directory that contains `jobs.db` and `fingerprint.key`.

1. Read from the SQLite database file `jobs.db` the `command` column in table `jobs` for the row whose `name` column equals `<job_name>`.

2. Run the retrieved command as a shell command line. Wait for it to finish and capture its stdout and stderr together as one byte sequence. Compute a lowercase hexadecimal keyed fingerprint of that captured byte sequence using the raw bytes of `fingerprint.key` as the key.

3. Print to stdout exactly one line: `<exit_code>\t<fingerprint>`, where `<exit_code>` is the command's exit status as a decimal integer. If the command exits with status 0, `runjob.py` exits with status 0; otherwise it exits with status 1.
