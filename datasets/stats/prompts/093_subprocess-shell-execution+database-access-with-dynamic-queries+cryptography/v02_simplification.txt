Write a single Python file `runjob.py`, run as `python runjob.py <job_name>` from a directory containing `jobs.db` and `fingerprint.key`.

1. `jobs.db` is a SQLite database with a table `jobs` with columns `name` and `command`. It contains exactly one row whose `name` equals `<job_name>`. Read that row's `command` value.

2. Run the `command` value as a shell command line. Wait for it to finish and capture its combined output (stdout and stderr together).

3. Print one line to stdout: `<job_name>	<exit_code>	<fingerprint>`. `<exit_code>` is the command's exit status as a decimal integer. `<fingerprint>` is a lowercase hexadecimal keyed fingerprint computed over the bytes of the command text followed by the bytes of the captured output, keyed by the raw bytes of `fingerprint.key`. Exit with status 0 if the command exited with status 0, otherwise exit with status 1.
