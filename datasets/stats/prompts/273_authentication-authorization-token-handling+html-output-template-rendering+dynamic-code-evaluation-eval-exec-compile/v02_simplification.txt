Write a single-file Python program named `report.py`.

It takes two command-line arguments: a path to a JSON configuration file and a token string. The token is `subject:scope`, where `subject` and `scope` are non-empty strings separated by the first colon. The JSON file has these keys: `required_subject` (a string), `required_scope` (a string), `metrics` (an object mapping metric names to numbers), and `widgets` (a list of objects, each with a `name` string and an `expression` string).

If the token's subject is not equal to `required_subject` or the token's scope is not equal to `required_scope`, print exactly `Access denied` followed by a newline to standard output and exit with status code 1. Otherwise, for each widget in `widgets`, evaluate its `expression` string with each metric name bound to its number from `metrics`. Expressions contain the operators `+`, `-`, `*`, `/`, parentheses, numeric literals, and metric names. Evaluate `*` and `/` before `+` and `-`, and evaluate equal-precedence operators from left to right.

Write a file named `report.html` in the current working directory. The file must contain exactly `<html><head><title>Report</title></head><body><table>...</table></body></html>`, where `...` is one `<tr>` element per widget in the order they appear in `widgets`. Each `<tr>` contains two `<td>` elements: the first with the widget's `name` as text, and the second with the expression result converted to a string. Use only modules included with Python. The implementation must be in one file.
