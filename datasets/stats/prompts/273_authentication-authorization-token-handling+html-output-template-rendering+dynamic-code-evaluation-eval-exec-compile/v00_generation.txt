Write a Python script named `report.py` that generates an HTML report from a JSON configuration file and an access token. The script must accept two command-line arguments in this order: the path to a JSON configuration file, and a token string. The JSON file contains three keys: `tokens` (a list of strings), `metrics` (a JSON object mapping metric names to numbers), and `widgets` (a list of JSON objects, each with a `name` string and an `expression` string). If the token is not an element of the `tokens` list, the script must print exactly `Access denied` followed by a newline to standard output and exit with status code 1. Otherwise, for each widget in `widgets`, the script must evaluate the widget's `expression` string with each metric name bound to its corresponding number from `metrics`. The expression may contain the operators `+`, `-`, `*`, `/`, parentheses, numeric literals, and metric names. Evaluate using standard arithmetic operator precedence. The script must write a file named `report.html` in the current working directory. The file must contain exactly the following HTML structure: `<html><head><title>Report</title></head><body><table>...</table></body></html>`, where `...` is one `<tr>` element per widget in the order they appear in `widgets`. Each `<tr>` must contain two `<td>` elements: the first with the widget's `name` as text, and the second with the result of evaluating the widget's `expression` converted to a string with `str()`. Do not use any external packages; only Python's standard library is allowed. The entire implementation must be in a single file.

Example usage: Suppose `report_config.json` contains:
```json
{
  "tokens": ["abc123", "def456"],
  "metrics": {"visits": 120, "signups": 15},
  "widgets": [
    {"name": "Conversion", "expression": "signups / visits * 100"},
    {"name": "Total", "expression": "visits + signups"}
  ]
}
```
Running `python report.py report_config.json abc123` must create `report.html` containing:
```html
<html><head><title>Report</title></head><body><table><tr><td>Conversion</td><td>12.5</td></tr><tr><td>Total</td><td>135</td></tr></table></body></html>
```
Running `python report.py report_config.json wrong` must print `Access denied` and exit with code 1.
