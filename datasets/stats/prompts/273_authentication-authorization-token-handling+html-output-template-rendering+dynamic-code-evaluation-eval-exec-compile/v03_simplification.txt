Write a single Python file named `report.py`.

It receives two command-line arguments: a path to a JSON configuration file and a token string. The token is `subject:scope`, split at the first colon into two non-empty parts. The JSON file contains `required_subject` and `required_scope` strings, `metrics` mapping metric names to numbers, and `widgets`, a list of objects with `name` and `expression` strings.

If the token's subject is not equal to `required_subject`, or the token's scope is not equal to `required_scope`, print `Access denied` followed by a newline to standard output and exit with status code 1.

Otherwise, for each widget in the order given, evaluate its `expression` string with each metric name bound to its number from `metrics`. Expressions contain numeric literals, metric names, `+`, and parentheses. Write `report.html` in the current working directory. The file contains an HTML document whose title is `Report` and whose body contains a table. The table has one `<tr>` element per widget in the same order. Each `<tr>` contains two `<td>` elements: the first holds the widget's `name` text, and the second holds the expression result as text. Use only modules included with Python. The implementation must be in one file.
