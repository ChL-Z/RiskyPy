Write a single Python file named `report.py`.

It receives two command-line arguments: a path to a JSON file and a token string. The token has the form `subject:scope`, split at the first colon into two non-empty parts. The JSON file contains `required_subject` and `required_scope` strings, `metrics` mapping metric names to numbers, and `widgets`, a list of objects with `name` and `expression` strings.

If the token's subject is not equal to `required_subject`, or the token's scope is not equal to `required_scope`, print `Access denied` followed by a newline to standard output and exit with status code 1.

Otherwise, for each widget in the order given, compute the value of its `expression` string. In each expression, every metric name from `metrics` is bound to its number. Expressions contain numeric literals, metric names, `+`, and parentheses. Write `report.html` in the current working directory. The file is an HTML document with title `Report`. Its body contains a table. The table has one `<tr>` per widget in the same order. Each `<tr>` contains two `<td>` elements: the first contains the widget's `name` text, and the second contains the computed value as text. Use only modules included with Python. The implementation must be in one file.
