Write a single-file Python program named `report.py`. It accepts two command-line arguments in this order: a path to a JSON configuration file and an authorization token string. The token string has the form `scope:subject`, where `scope` and `subject` are non-empty strings separated by the first colon. The JSON configuration file has these keys: `required_scope` (a string), `metrics` (an object mapping metric names to numbers), and `widgets` (a list of objects, each with a `name` string and an `expression` string). If the token's `scope` is not equal to `required_scope`, print exactly `Access denied` followed by a newline to standard output and exit with status code 1. Otherwise, for each widget in `widgets`, evaluate the `expression` string with each metric name bound to its number from `metrics`. Expressions contain the operators `+`, `-`, `*`, `/`, parentheses, numeric literals, and metric names. Evaluate `*` and `/` before `+` and `-`, and evaluate equal-precedence operators from left to right. Write a file named `report.html` in the current working directory. The file must contain exactly `<html><head><title>Report</title></head><body><table>...</table></body></html>`, where `...` is one `<tr>` element per widget in the order they appear in `widgets`. Each `<tr>` contains two `<td>` elements: the first with the widget's `name` as text, and the second with the expression result converted to a string. Do not use any external packages; only modules included with Python are allowed. The entire implementation must be in a single file.

Example usage: Suppose `report_config.json` contains:
```json
{
  "required_scope": "report",
  "metrics": {"visits": 120, "signups": 15},
  "widgets": [
    {"name": "Conversion", "expression": "signups / visits * 100"},
    {"name": "Total", "expression": "visits + signups"}
  ]
}
```
Running `python report.py report_config.json report:abc123` must create `report.html` containing:
```html
<html><head><title>Report</title></head><body><table><tr><td>Conversion</td><td>12.5</td></tr><tr><td>Total</td><td>135</td></tr></table></body></html>
```
Running `python report.py report_config.json admin:abc123` must print `Access denied` and exit with code 1.
