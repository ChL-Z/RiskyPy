Write a Python program in a single file. The program is run as:

python render_template.py <url> <template_path>

Requirements:
1. Send an HTTP GET request to <url>. The response body is a JSON object whose keys are variable names and whose values are integers. The JSON object contains a key for every variable name that appears in the template. Read the file at <template_path> as UTF-8 text.
2. Replace every occurrence of `{{ <expression> }}` in the template with the decimal integer value of <expression>, using the JSON object to provide values for variable names, and write the resulting text to stdout. Inside the braces, an expression consists of variable names, decimal integer literals, whitespace, parentheses, and the operators +, -, and *. The placeholder delimiters are exactly two opening braces and two closing braces. Only the rendered text is written to stdout.

Example: if the URL returns {"price": 4, "quantity": 3} and the template file contains `Total: {{ price * quantity }}\n`, the program writes `Total: 12\n` to stdout.
