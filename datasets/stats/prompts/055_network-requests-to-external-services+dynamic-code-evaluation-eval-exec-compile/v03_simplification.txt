Write a single Python file `render_template.py` that is run as:

    python render_template.py <url> <template_path>

1. Send an HTTP GET request to `<url>`. The response body is a JSON object whose keys are variable names and whose values are integers.

2. Read `<template_path>` as UTF-8 text. The text contains placeholders written exactly as `{{ expr }}`, where `expr` contains only variable names, decimal integer literals, whitespace, and the `+` operator. Replace each placeholder with the decimal integer result of evaluating `expr`, using the JSON object for variable values. Print the resulting text to stdout and print nothing else.

Example: if the URL returns `{"price": 4, "quantity": 3}` and the template file is `Total: {{ price + quantity }}\n`, the program prints `Total: 7\n`.
