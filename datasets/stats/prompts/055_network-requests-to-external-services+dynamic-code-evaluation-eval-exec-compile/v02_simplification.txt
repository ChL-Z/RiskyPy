Write a single Python file `render_template.py` that is run as:

    python render_template.py <url> <template_path>

1. Send an HTTP GET request to `<url>` and read the response body as a JSON object. Each key is a variable name and each value is an integer. Read the file at `<template_path>` as UTF-8 text.

2. In the template text, replace every occurrence of `{{ expr }}` with the decimal integer that `expr` evaluates to. Each `expr` contains only variable names, decimal integer literals, whitespace, and the operators `+` and `*`. A variable name in `expr` takes its integer value from the JSON object. Print the replaced text to stdout and print nothing else.

Example: if the URL returns `{"price": 4, "quantity": 3}` and the template file is `Total: {{ price * quantity }}\n`, the program prints `Total: 12\n`.
