Write a Python program in a single file named render_template.py. It is run as:

python render_template.py <url> <template_path>

1. Send an HTTP GET request to <url>. The response body is a JSON object whose keys are variable names and whose values are integers. Read the file at <template_path> as UTF-8 text.

2. In the template, replace every occurrence of `{{ expr }}` with the decimal integer value obtained by evaluating `expr`. Inside `{{ }}`, `expr` consists of variable names, decimal integer literals, whitespace, parentheses, and the operators + and *. Variable names take their integer values from the JSON object. Write the fully replaced text to stdout and write nothing else to stdout.

Example: if the URL returns {"price": 4, "quantity": 3} and the template file contains `Total: {{ price * quantity }}\n`, the program writes `Total: 12\n` to stdout.
