Write a Python program in one file named `apply_updates.py`, invoked as:

python apply_updates.py <db_path> <updates_jsonl> <errors_log> <summary_json>

`<db_path>` is an SQLite database with an existing table `products` having columns `id` integer primary key, `name` text, `price` real, and `stock` integer. `<updates_jsonl>` contains lines; each line is a JSON object with key `id` and exactly one of the keys `name`, `price`, or `stock`. For each line in file order, update the `products` row whose `id` equals the line's `id`, setting the column named by the present key to that key's value.

If the row is updated, count it as updated. Otherwise, append to `<errors_log>` one line in the format `line_number<TAB>id_value<TAB>row not found`, where `line_number` starts at 1 and `id_value` is the line's `id` converted to text. Continue processing after a failure.

After all lines are processed, write `<summary_json>` as a JSON object with integer keys `updated` and `failed`, where `updated` is the count of lines that updated a row and `failed` is the count of lines that did not update a row.
