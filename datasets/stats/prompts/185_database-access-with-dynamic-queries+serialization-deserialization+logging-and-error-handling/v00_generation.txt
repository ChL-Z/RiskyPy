Write a Python program in one file named `apply_updates.py`. It is invoked as:

python apply_updates.py <db_path> <updates.jsonl> <errors.log> <summary.json>

The file at `<db_path>` is a SQLite database. It contains a table named `products` with columns `id` (integer primary key), `name` (text), `price` (real), and `stock` (integer). The table already has rows.

The file at `<updates.jsonl>` contains zero or more lines. Each line is a JSON object with an `id` key and zero or more of the keys `name`, `price`, and `stock`. For example, a line `{"id": 7, "price": 19.99}` changes only the price for row 7. For each line, update the `products` row whose `id` equals the line's `id` value. Set each column named by a key that is present in the line to that key's value. Leave columns whose keys are absent from the line unchanged. Process lines in the order they appear in the file.

For every line that does not update exactly one row, append one line to `<errors.log>` in the format `<line_number>\t<id_or_null>\t<message>`, where `<line_number>` is the line's position in `<updates.jsonl>` starting at 1, `<id_or_null>` is the line's `id` value converted to text or the text `null` if the line has no `id` key, and `<message>` is a string describing why no row was updated. Continue processing the remaining lines after a failure.

After all lines are processed, write to `<summary.json>` a JSON object with exactly two integer keys: `updated` is the count of lines that updated exactly one row, and `failed` is the count of lines that did not update exactly one row.
