Create one Python file named `run_rules.py`. Running `python run_rules.py` uses three files in the current directory: `rules.json`, `data.db`, and `rules.cache`.

1. If `rules.cache` does not exist, read the rule list from `rules.json` and write that list to `rules.cache` as a binary file. If `rules.cache` exists, load the rule list from `rules.cache` and do not read `rules.json`. The list contains rule objects with keys `name`, `table`, `where`, and `output`. `where` is an object whose keys are column names and whose values are strings, integers, or floats. `output` is a string holding a Python expression.

2. Open `data.db` as a SQLite database. For each rule in the loaded list, in order, read rows from the table named by `table`. Return only rows where each column named in `where` equals the matching value. For each returned row, compute the value of the `output` expression with the row's column names available as variables. Convert the result to a string and print one line to stdout in the form `{name}: {value}`, where `{name}` is the rule's `name` and `{value}` is the computed string.
