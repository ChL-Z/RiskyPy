Write a Python program in a single file named `run_rules.py`. It is invoked as:

`python run_rules.py --rules rules.json --db data.db --cache rules.cache`

The program reads a list of rule objects from `rules.json`. Each rule object has exactly these keys:
- `name`: string
- `table`: string naming a table in the SQLite database file `data.db`
- `where`: object whose keys are column names in that table and whose values are strings, integers, or floats
- `output`: string containing a Python expression, for example `"f'{customer}: {amount * 2}'"` or `"amount + tax"`

On the first run, the program reads `rules.json`. It writes the list of rule objects to `rules.cache` as a binary file. On any later run, if `rules.cache` exists, the program loads the rule list from `rules.cache` and does not read `rules.json`.

For each rule in the loaded list, in order:
1. Query the table named by `table` in `data.db`. The query must return only rows where every key in `where` equals the corresponding value for that column.
2. For each returned row, compute the value of the `output` expression with the row's column names available as variables. The result must be converted to a string.
3. Print one line to stdout: a JSON object with keys `rule` and `value`, where `rule` is the rule's `name` and `value` is the computed string.

Example:

`rules.json`:
```json
[
  {"name": "high_value", "table": "orders", "where": {"region": "EU"}, "output": "f'{customer}: {amount * 2}'"},
  {"name": "taxed", "table": "orders", "where": {"status": "paid"}, "output": "amount + tax"}
]
```

`data.db` contains an `orders` table with columns `customer`, `region`, `amount`, `tax`, `status`.

When run, for an EU row with customer `Ada`, amount `10`, the first rule prints:
```json
{"rule": "high_value", "value": "Ada: 20"}
```

For a paid row with amount `10`, tax `2`, the second rule prints:
```json
{"rule": "taxed", "value": "12"}
```

Do not use any command-line arguments other than the three named options. The program must not require network access. It must be contained in one Python file.
