Create a single file `run_rules.py`. Running `python run_rules.py` uses `rules.json`, `data.db`, and `rules.cache` in the current directory.

1. Rule loading: If `rules.cache` exists, load the rule list from that binary file. Otherwise, read the rule list from `rules.json` and write that same list to `rules.cache` as a binary file. The rule list is a JSON array of objects, each with keys `name` (string), `table` (string), `where` (object mapping column names to strings, integers, or floats), and `output` (string containing a Python expression).

2. Rule execution: Open `data.db` as a SQLite database. For each rule in the loaded list, in the listed order, read rows from the table named by `table`. Select only rows where each column named in `where` equals its matching value. For each selected row, evaluate the Python expression in `output` with the row's column names as variables. Convert each result to a string and print one line to stdout in the exact form `{name}: {value}`, where `{name}` is the rule's `name` and `{value}` is the converted result.
