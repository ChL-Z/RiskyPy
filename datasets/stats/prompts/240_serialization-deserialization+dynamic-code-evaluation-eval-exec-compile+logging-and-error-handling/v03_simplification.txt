Write a single Python file named `config_tool.py`. It is run as:

    python config_tool.py <template.json> <vars.json>

Both input files contain JSON objects. `<vars.json>` maps variable names to integers. `<template.json>` maps keys to JSON values.

For each value in `<template.json>` that is a string matching `{{expr}}` exactly, replace that whole string with the integer computed from `expr`. `expr` contains variable names from `<vars.json>`, integer literals, parentheses, and the operators `+`, `-`, `*`. Copy all other keys and values unchanged. Write the resulting JSON object to stdout on one line.

For each replacement, write exactly one line to stderr:

    placeholder: {{expr}} = value

where `expr` is the text between the braces and `value` is the integer written in place of the placeholder.

If reading, computing, or writing fails, write `error: <message>` to stderr, write nothing to stdout, and exit with status 1. On success, exit with status 0.
