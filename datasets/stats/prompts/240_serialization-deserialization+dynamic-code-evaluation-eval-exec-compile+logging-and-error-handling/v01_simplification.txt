Write a single Python file named `config_tool.py`. It is run as:

    python config_tool.py <template.json> <vars.json>

`<vars.json>` is a JSON object whose keys are variable names and whose values are numbers. `<template.json>` is a JSON value. For every string value in `<template.json>` at any nesting depth inside objects and arrays, replace each occurrence of a placeholder written as `{{expr}}` with the decimal text of the numeric value of `expr`. A placeholder starts at `{{` and ends at the next `}}`; the text between them is `expr` and contains no brace characters. `expr` is an arithmetic expression built from variable names, parentheses, integer and float literals, and the operators `+`, `-`, `*`, `/`, `//`, `%`, and `**`. Leave every other character of each string unchanged, and copy object keys and all non-string values through unchanged. A whole-number result is written with no decimal point; any other result is written with a decimal point. Write the resulting JSON to stdout on one line.

For every placeholder replaced, print exactly one line to stderr in the order the replacements are made:

    placeholder: {{expr}} = value

where `expr` is the text that appeared between the braces and `value` is the replacement text.

If reading, evaluating, or writing fails, print `error: <message>` to stderr, write nothing to stdout, and exit with status 1. On success, exit with status 0.
