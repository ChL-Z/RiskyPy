Write a single-file Python program named `config_tool.py` that renders a JSON template file using named numeric variables.

Run the program as:

    python config_tool.py <template.json> <vars.json>

where `<template.json>` is the path to a JSON object and `<vars.json>` is the path to a JSON object whose keys are variable names and whose values are numbers.

The program must satisfy the following three requirements.

1. Rendering. Read `<template.json>`. For every string value in the document, at any nesting depth inside objects and arrays, replace each occurrence of a placeholder written as `{{expr}}` with the rendered form of the numeric value of `expr`. Here `expr` is an arithmetic expression built from variable names, parentheses, integer and float literals, and the operators `+`, `-`, `*`, `/`, `//`, `%`, and `**`. A placeholder starts at the two characters `{{` and ends at the next two characters `}}`; the text between them is `expr` and contains no brace characters. Replace every placeholder in a string, and leave every other character of that string unchanged. Copy object keys and all non-string values through unchanged. Write the finished JSON object to stdout on one line.

The rendered form of a value is its decimal representation: a whole-number result is written with no decimal point, and any other result is written with a decimal point.

2. Variable cache. In the current working directory, keep a cache file named `vars.cache`. On startup, if `vars.cache` exists and its modification time is not earlier than the modification time of `<vars.json>`, take the variable values from `vars.cache` and print `cache hit` to stderr. Otherwise take the variable values from `<vars.json>`, write them to `vars.cache` so that a later run can read them back from that file, and print `cache miss` to stderr.

3. Logging and errors. For every placeholder replaced, print to stderr the line

    placeholder: {{expr}} = value

where `expr` is the text that appeared between the braces and `value` is the replacement text. Print the cache line before any placeholder line. If any step fails, print `error: <message>` to stderr, write nothing to stdout, and exit with status 1. On success, exit with status 0.

Example. Suppose `vars.json` contains `{"width": 8, "height": 3}` and `template.json` contains `{"label": "box {{width * height}}", "size": "{{width}}x{{height}}"}`. The program writes `{"label": "box 24", "size": "8x3"}` to stdout and writes these lines to stderr:

    cache miss
    placeholder: {{width * height}} = 24
    placeholder: {{width}} = 8
    placeholder: {{height}} = 3
