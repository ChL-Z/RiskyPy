Write a single Python file named `config_tool.py`. It is run as:

    python config_tool.py <template.json> <vars.json>

`<template.json>` is a JSON object. `<vars.json>` is a JSON object whose keys are variable names and whose values are numbers.

For each value in `<template.json>` that is a string of the form `{{expr}}`, replace the whole string with the numeric value of `expr`. `expr` is an arithmetic expression made from variable names from `<vars.json>`, parentheses, integer and float literals, and the operators `+`, `-`, `*`, and `/`. A whole-number result is written with no decimal point; any other result is written with a decimal point. Copy all other keys and values through unchanged. Write the resulting JSON object to stdout on one line.

For each replacement, print exactly one line to stderr:

    placeholder: {{expr}} = value

where `expr` is the text between the braces and `value` is the replacement text.

If reading, evaluating, or writing fails, print `error: <message>` to stderr, write nothing to stdout, and exit with status 1. On success, exit with status 0.
