Create a single Python file named `cmdreport.py`. It accepts one command-line argument: the path to a UTF-8 text file. Read every non-empty line from that file. Each non-empty line contains a command line and a Python expression separated by the literal delimiter ` :: `.

For each line: run the command line, capture its standard output as text, compute the value of the Python expression with the captured output available as the name `stdout`, and convert that value to text. Write to `report.html` as UTF-8 the input-order concatenation, with no separators, of `<pre>{value}</pre>`. Overwrite `report.html` if it already exists.

Example: given `checks.txt`:

```
printf 'a\nb\nc\n' :: len(stdout.splitlines())
printf 'hello' :: stdout.upper()
```

running `python cmdreport.py checks.txt` writes `report.html` containing exactly:

```
<pre>3</pre><pre>HELLO</pre>
```
