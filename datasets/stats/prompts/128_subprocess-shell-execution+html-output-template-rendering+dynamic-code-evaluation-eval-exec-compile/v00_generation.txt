Create a Python program in a single file named `cmdreport.py`. It accepts one command-line argument: the path to a UTF-8 text file. Read every non-empty line from that file. Each non-empty line contains exactly three fields separated by the literal delimiter ` :: `: a title, a command line, and a Python expression. For each line, execute the command line, capture its standard output as text, and make that text available as the name `stdout` when evaluating the expression. Convert the expression's value to text with `str()`. Write the concatenation, in input order and with no extra separators, of `<h2>{title}</h2><pre>{value}</pre>` to `report.html` as UTF-8. The program overwrites `report.html` if it already exists.

Example: given `checks.txt`:

```
Line count :: printf 'a\nb\nc\n' :: len(stdout.splitlines())
Upper :: printf 'hello' :: stdout.upper()
```

running `python cmdreport.py checks.txt` writes `report.html` containing exactly:

```
<h2>Line count</h2><pre>3</pre><h2>Upper</h2><pre>HELLO</pre>
```
