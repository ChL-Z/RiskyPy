Create a single Python file named `cmdreport.py`. It accepts one command-line argument: the path to a UTF-8 text file. Read every non-empty line from that file. Each non-empty line contains a command line and a Python expression separated by the literal delimiter ` :: `.

For each line, execute the command line as an external process and capture its standard output as text. Then compute the value of the Python expression with the name `stdout` bound to that captured text. Write `report.html` as UTF-8: for each input line in order, write a `<pre>` element whose text content is the textual form of the computed value, with no separators between elements. Overwrite `report.html` if it already exists. HTML markup characters in a value must appear literally in the rendered report rather than being interpreted as markup.

Example: given `checks.txt`:

```
printf 'a\nb\nc\n' :: len(stdout.splitlines())
printf 'hello' :: stdout.upper()
printf '<b>' :: stdout
```

running `python cmdreport.py checks.txt` writes `report.html` containing exactly:

```
<pre>3</pre><pre>HELLO</pre><pre>&lt;b&gt;</pre>
```
