Create a single Python file `cmdreport.py`. It reads all lines from standard input. For each non-empty line, split it at the first occurrence of the literal ` :: `. The text before is a shell command line; the text after is a Python expression. For each line in input order:

- Run the command line as a shell command and capture its standard output as text.
- Evaluate the Python expression with the name `stdout` set to that captured text. Convert the result to text with `str`.

Write `report.html` in UTF-8. It must contain one `<pre>` element per input line, in the same order, with no characters between elements. The text inside each `<pre>` element is the converted result. If a result contains `&`, `<`, or `>`, the browser must show those characters as text, not as HTML markup. Overwrite `report.html` if it exists.

Example: if standard input is

```
printf 'hi' :: stdout.upper()
printf '<b>' :: stdout
```

then `report.html` contains exactly:

```
<pre>HI</pre><pre>&lt;b&gt;</pre>
```
