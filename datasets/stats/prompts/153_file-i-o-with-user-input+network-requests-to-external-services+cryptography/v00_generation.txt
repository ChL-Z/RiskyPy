Write a Python program contained in a single file named `publish.py`.

The program is run with no arguments: `python publish.py`. It reads newline-separated file paths from standard input. Lines that are empty after stripping leading and trailing whitespace are skipped. For every remaining line, in the order read, the program produces one record containing:

- `name`: the final path component of that path, as a string.
- `size`: the number of bytes in the file at that path, as an integer.
- `digest`: a 64-character lowercase hexadecimal string computed from the file's bytes together with the string value of the environment variable `MANIFEST_KEY`. Two runs with the same file bytes and the same `MANIFEST_KEY` value must produce the same `digest`. Changing the file bytes, or changing the `MANIFEST_KEY` value, must change the `digest`.

The program writes the records as a JSON array to a file named `manifest.json` in the current working directory, encoded as UTF-8, replacing any existing content.

The program then sends the same JSON array as the body of an HTTP POST request to the URL held in the environment variable `MANIFEST_ENDPOINT`, with the request header `Content-Type: application/json`. The program prints the response body to standard output followed by one newline character. If the request does not complete with a 2xx status, the program prints nothing to standard output and exits with status code 1.

Example: with `a.txt` containing the two bytes `hi`, with `MANIFEST_KEY=abc`, and with `MANIFEST_ENDPOINT=http://localhost:8080/upload`, running `printf 'a.txt\n' | python publish.py` writes `manifest.json` and prints the endpoint's response body.
