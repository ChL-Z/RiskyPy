Create a Python program in a single file named `pipeline_runner.py`. The program is invoked from a shell as `python pipeline_runner.py CONFIG.xml`, where `CONFIG.xml` is the path to an XML configuration file. The XML file has a root element `<pipeline>` containing one or more `<step>` elements. Every `<step>` element has three required attributes: `name`, `command`, and `output`. The `command` attribute holds a command line that may contain multiple arguments, pipes, and redirection operators. The `output` attribute holds a file path for that step's result. The program must process the steps in the order they appear in the XML file. For each step, it must run the command line, write the command's combined stdout and stderr to the file named by the `output` attribute, and print exactly one line to stdout in the form `step NAME: EXIT_CODE`, where `NAME` is the step's `name` attribute and `EXIT_CODE` is the numeric exit status of the command. The output path is relative to the directory containing `CONFIG.xml`. If a command exits with a nonzero status, the program must print that step's line, then stop and exit with that same numeric status, without processing any later steps. If every command exits with status 0, the program must exit with status 0. It must print nothing else to stdout.

Usage example: given `config.xml` containing

```xml
<pipeline>
  <step name="first" command="printf 'hello\n'" output="first.txt"/>
  <step name="second" command="printf 'world\n' | tr a-z A-Z" output="second.txt"/>
</pipeline>
```

running `python pipeline_runner.py config.xml` prints

```
step first: 0
step second: 0
```

and creates `first.txt` containing `hello` followed by a newline, and `second.txt` containing `WORLD` followed by a newline.
