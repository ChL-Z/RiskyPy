Write a Python program in a single file named `render_report.py`. It accepts exactly three required command-line options: `--template PATH`, `--data PATH`, and `--output PATH`. The `--template` file is UTF-8 HTML containing placeholders written as `{{ expression }}`, where `expression` is a Python expression. The `--data` file is a UTF-8 JSON array of objects. For each object in the array, render one copy of the template by replacing every placeholder with the string form of the result of evaluating its expression, using the object's keys as variable names. Concatenate the rendered copies in array order and write them as UTF-8 to `--output`. The program must evaluate at most 4 objects concurrently, and it must start evaluating a new object only after at least 0.2 seconds have passed since the start of the previous object's evaluation. The `--output` file must be written only after all objects have been evaluated.

Example usage:

`template.html`:
```html
<section><h2>{{ title }}</h2><p>Total: {{ price * quantity }}</p></section>
```

`data.json`:
```json
[{"title":"Pen","price":2.5,"quantity":4},{"title":"Book","price":10,"quantity":1}]
```

Command:
```bash
python render_report.py --template template.html --data data.json --output report.html
```

After running the command, `report.html` contains two `<section>` elements in the order of the JSON array, with the first section showing `Total: 10.0` and the second section showing `Total: 10`.
