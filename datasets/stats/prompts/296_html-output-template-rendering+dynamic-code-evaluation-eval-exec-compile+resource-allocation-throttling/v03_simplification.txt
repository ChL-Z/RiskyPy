Write a Python script named `render_report.py`.

It reads two UTF-8 files from the current directory:
- `template.html`, containing placeholders written exactly as `{{ expression }}`.
- `data.json`, containing a JSON array of objects whose values are integers.

For each object in array order, produce the template with every `{{ expression }}` replaced by the string form of computing that arithmetic expression using the object's key-value pairs as variables. Store the rendered strings in array order. After every object has been processed, write all rendered strings concatenated to `report.html` as UTF-8.

Start processing each object at least 0.2 seconds after the start of the previous object's processing. At no time may more than 2 objects be processed at the same time.
