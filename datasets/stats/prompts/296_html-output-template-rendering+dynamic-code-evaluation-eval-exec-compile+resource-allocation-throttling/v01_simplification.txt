Create a Python file named `render_report.py`. It reads `template.html`, a UTF-8 text file containing placeholders written as `{{ expression }}`, where `expression` is a Python expression. It also reads `data.json`, a UTF-8 JSON array of objects. For each object in the array, it produces one copy of the template by replacing every placeholder with the string form of the result of evaluating its expression using the object's keys as variable names. After all objects are processed, it writes the concatenated copies in array order as UTF-8 to `report.html`. A new object starts evaluating only after at least 0.2 seconds have passed since the start of the previous object's evaluation, and at most 4 objects are evaluated at the same time. The file `report.html` is written only after all objects finish.
