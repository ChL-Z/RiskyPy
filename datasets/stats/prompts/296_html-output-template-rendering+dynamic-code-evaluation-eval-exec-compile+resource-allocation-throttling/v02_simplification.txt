Write `render_report.py`. It reads `template.html`, a UTF-8 text file containing placeholders written as `{{ expression }}`. It reads `data.json`, a UTF-8 JSON array of objects. For each object in the array, in array order, produce one copy of the template by replacing every `{{ expression }}` with the value obtained by computing that expression using the object's keys as variable names, converted to a string. Write all copies concatenated in array order as UTF-8 to `report.html` only after all objects have been processed. Process at most 2 objects at the same time, and start processing an object at least 0.2 seconds after the start of the previous object's processing.
