Write a Python 3 program in a single file named `feeddigest.py`.

Run it as `python feeddigest.py <urls_file> <output_file>`. Read `<urls_file>` as UTF-8 text, one feed URL per line, and ignore blank lines. For each URL in the order it appears, retrieve it over HTTP and read the response body as an RSS 2.0 document. From that document take the text of the `<title>` element that is a direct child of the `<channel>` element, and the text of every `<title>` element that is a direct child of an `<item>` element that is a direct child of that same `<channel>` element.

Write `<output_file>` as UTF-8 JSON: a list with one object per input URL in input order. Each object has a `url` key. For a URL whose body was read as RSS 2.0, the object also has a `title` key holding the channel title (or `null` if absent) and an `items` key holding a list of item title strings in document order. For a URL whose resource could not be retrieved, or whose body could not be read as RSS 2.0, the object instead has an `error` key holding a string message. Do not include both sets of keys in the same object.
