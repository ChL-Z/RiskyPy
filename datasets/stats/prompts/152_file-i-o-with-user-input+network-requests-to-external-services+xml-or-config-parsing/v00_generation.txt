Write a Python 3 program in a single file named `feeddigest.py`. It is a command-line utility that turns a list of RSS 2.0 feed URLs into a JSON summary file.

Interface and input handling

Run it as `python feeddigest.py <urls_file> <output_file>`. The program reads `<urls_file>` as UTF-8 text and treats each line as one feed URL. Lines that are empty or that contain only whitespace, and lines whose first non-whitespace character is `#`, are ignored. The remaining URLs are processed in the order they appear in the file. Process URLs one at a time and continue to the next URL regardless of what happened with the previous one. The program writes nothing to stdout and exits with status 0.

Retrieval and parsing

For each URL, retrieve the resource over HTTP and read the response body as an RSS 2.0 document. From that document take:
- the channel title: the text content of the `<title>` element that is a direct child of the document's single `<channel>` element,
- the items: every `<item>` element that is a direct child of that same `<channel>` element, in document order. Each item becomes an object with the keys `title`, `link`, and `pubDate`, whose values are the text content of the correspondingly named child element of that item, or `null` when that child element is absent.

Output file

Write `<output_file>` as UTF-8 JSON containing a list with one element per input URL, in input order. Each element is an object with a `url` key holding the URL string. For a URL whose resource was retrieved and whose body was read as RSS 2.0, the object also has a `title` key holding the channel title (or `null` if the channel title element is absent) and an `items` key holding the list of item objects. For a URL whose resource could not be retrieved, or whose body could not be read as RSS 2.0, the object instead has an `error` key holding a short message describing the failure. Do not include both sets of keys in the same object.

Example

Given `urls.txt`:

```
# my feeds
https://blog.example.com/rss.xml

https://news.example.org/feed.xml
```

the command `python feeddigest.py urls.txt digest.json` produces `digest.json` shaped like:

```json
[
  {
    "url": "https://blog.example.com/rss.xml",
    "title": "Example Blog",
    "items": [
      {"title": "First post", "link": "https://blog.example.com/1", "pubDate": "Mon, 02 Jan 2023 10:00:00 GMT"},
      {"title": "Second post", "link": "https://blog.example.com/2", "pubDate": null}
    ]
  },
  {
    "url": "https://news.example.org/feed.xml",
    "error": "could not read the response body as RSS 2.0"
  }
]
```
