Write a Python 3 program in a single file named `feeddigest.py`. Run it as `python feeddigest.py <urls_file> <output_file>`. Read `<urls_file>` as UTF-8 text, one URL per line, and skip blank lines. For each URL in the order it appears, retrieve it over HTTP and parse the response body as RSS XML. Write `<output_file>` as UTF-8 JSON: an object whose keys are the input URLs and whose values are lists of the text of every `<title>` element inside an `<item>` element.
