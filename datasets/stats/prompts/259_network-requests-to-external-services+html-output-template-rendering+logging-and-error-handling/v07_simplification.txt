Write a Python program in a single file named `pagereport.py`.

Read newline-separated URLs from standard input. For each URL, in input order, make an HTTP GET request with a 10-second timeout. If the request returns a response, use its integer status code and the first 100 characters of the response body text as the excerpt. If the request raises an exception, write to standard error one line containing the current UTC time formatted as `YYYY-MM-DDTHH:MM:SSZ`, a space, the URL, a space, and the exception text. For that URL, use `error` as the status and an empty excerpt.

Write to standard output one HTML document. It must start with `<!DOCTYPE html>`, contain a `<title>` element with contents `Link Report`, and contain one `<table>` element. The table's first row contains `<th>URL</th>`, `<th>Status</th>`, and `<th>Excerpt</th>`. Each following row contains three `<td>` cells: the URL, the status code as a decimal integer or `error`, and the excerpt. If standard input contains no URLs, the table contains only the header row.
