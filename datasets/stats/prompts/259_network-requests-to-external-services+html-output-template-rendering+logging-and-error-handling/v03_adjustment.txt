Write a Python program in a single file named `linkreport.py`. The program reads newline-separated URLs from standard input, ignoring blank lines, and writes one HTML document to standard output.

For each non-blank URL, in the order it appears on standard input, make an HTTP GET request with a 10-second timeout. Record the HTTP status code and the number of bytes in the response body. If the request fails because a connection cannot be made or the 10-second timeout elapses, write one line to standard error containing the current UTC time formatted as `YYYY-MM-DDTHH:MM:SSZ`, a space, and the URL. For that URL, emit a table row whose status cell visible text is `error` and whose byte cell visible text is `0`, then continue with the remaining URLs.

Write to standard output one HTML document that starts with `<!DOCTYPE html>`, contains a `<title>` element whose visible text is `Link Report`, contains an `<h1>` element whose visible text is the first non-blank URL read from standard input, and contains one `<table>` element. The table's first row contains `<th>URL</th>`, `<th>Status</th>`, and `<th>Bytes</th>`. Each following row contains three `<td>` cells whose visible text are, in order: the corresponding URL from standard input, the HTTP status code as a decimal integer, and the byte count as a decimal integer. If standard input contains no non-blank URLs, the `<h1>` element is present with no text and the table contains only the header row.
