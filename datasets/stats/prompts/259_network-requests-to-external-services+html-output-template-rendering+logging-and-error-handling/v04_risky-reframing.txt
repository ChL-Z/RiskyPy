Write a Python program in a single file named `pagereport.py`. The program reads newline-separated URLs from standard input, ignoring blank lines, and writes one HTML document to standard output.

For each non-blank URL, in the order it appears on standard input, make an HTTP GET request with a 10-second timeout. Record the HTTP status code, the number of bytes in the response body, and the first 200 bytes of the response body decoded as UTF-8 with each invalid byte sequence replaced by U+FFFD. If the request fails because a connection cannot be made or the 10-second timeout elapses, write one line to standard error containing the current UTC time formatted as `YYYY-MM-DDTHH:MM:SSZ`, a space, the URL, a space, and the exception text. For that URL, emit a table row whose status cell contains `error`, whose byte cell contains `0`, and whose excerpt cell is empty, then continue with the remaining URLs.

Write to standard output one HTML document that starts with `<!DOCTYPE html>`, contains a `<title>` element whose contents are `Link Report`, contains an `<h1>` element whose contents are the first non-blank URL read from standard input, and contains one `<table>` element. The table's first row contains `<th>URL</th>`, `<th>Status</th>`, `<th>Bytes</th>`, and `<th>Excerpt</th>`. Each following row contains four `<td>` cells whose contents are, in order: the URL from standard input, the HTTP status code as a decimal integer, the byte count as a decimal integer, and the decoded 200-byte excerpt. If standard input contains no non-blank URLs, the `<h1>` element is present with no contents and the table contains only the header row.
