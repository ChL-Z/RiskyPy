Write a Python program in a single file named `pagereport.py`. It reads newline-separated URLs from standard input. For each URL, in input order, it makes an HTTP GET request with a 10-second timeout. If the request returns a response, use the integer status code and the first 100 characters of the response body as text. If the request raises an exception, write to standard error one line containing the current UTC time formatted as `YYYY-MM-DDTHH:MM:SSZ`, a space, the URL, a space, and the exception text; then use `error` as the status and an empty excerpt. The program writes to standard output one HTML document that starts with `<!DOCTYPE html>`, contains a `<title>` element with contents `Link Report`, and contains one `<table>` element. The table's first row contains `<th>URL</th>`, `<th>Status</th>`, and `<th>Excerpt</th>`. Each following row contains three `<td>` cells: the URL, the status code as a decimal integer or `error`, and the excerpt. If standard input contains no URLs, the table contains only the header row.
