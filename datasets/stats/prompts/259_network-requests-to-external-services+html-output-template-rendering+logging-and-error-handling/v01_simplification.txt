Write a Python program in a single file named `linkreport.py`. The program reads newline-separated URLs from standard input, skipping blank lines, and writes one HTML document to standard output.

For each URL, in the order it appears on stdin, make an HTTP GET request with a 10-second timeout. Record the returned HTTP status code and the length in bytes of the response body.

Write to stdout one HTML document that begins with `<!DOCTYPE html>`, contains a `<title>` element with the text `Link Report`, and contains one `<table>` element. The first table row must contain the cells `<th>URL</th>`, `<th>Status</th>`, and `<th>Bytes</th>`. Every following row must contain three `<td>` cells: the URL, the HTTP status code written as a decimal integer, and the byte count written as a decimal integer.

If the GET request fails because of a connection error or because the 10-second timeout elapses, write one line to stderr containing the current UTC time formatted as `YYYY-MM-DDTHH:MM:SSZ`, a single space, and the URL. For that URL, emit a table row whose status cell contains the text `error` and whose byte cell contains `0`, then continue with the remaining URLs.
