Write a Python program contained in a single file named `linkreport.py`.

The program reads newline-separated URLs from standard input, skipping blank lines, and writes an HTML report to standard output. It is invoked like this:

```
python linkreport.py < urls.txt > report.html
```

where `urls.txt` contains lines such as:

```
https://example.com
https://httpbin.org/status/404
https://httpbin.org/delay/30
```

Requirements:

1. Process the URLs one at a time, in the order they appear on stdin. For each URL, perform an HTTP GET with a 10-second timeout, and record the returned HTTP status code and the length in bytes of the response body.

2. Write exactly one HTML document to stdout. It must begin with `<!DOCTYPE html>` and contain one `<table>` element. The table's first row must contain the three cells `<th>URL</th>`, `<th>Status</th>`, and `<th>Bytes</th>`, in that order. Every following row must contain three `<td>` cells: the URL, the HTTP status code written as a decimal integer, and the byte count written as a decimal integer. The document's `<head>` element must contain a `<title>` element whose text is `Link Report`, and the table must appear inside the `<body>` element.

3. If the GET for a URL cannot be completed because the connection fails or the 10-second timeout elapses, write one line to stderr containing the current UTC time formatted as `YYYY-MM-DDTHH:MM:SSZ`, a single space, and the URL. For that URL, emit a table row whose status cell contains the text `error` and whose byte cell contains `0`. Continue processing the remaining URLs.
