Write a single Python file named `render_ticket.py`. It takes exactly three command-line arguments in this order: a path to a JSON file, a path to a text template file, and a ticket token.

The JSON file contains one object. The template file contains text. The JSON object has a top-level key `ticket_token` whose value is a string. If the third command-line argument does not equal that string, write `ACCESS DENIED` to standard error and exit with status 2.

If the third command-line argument equals the `ticket_token` value, replace every `{{expression}}` in the template with the value of the arithmetic expression `expression`, converted to a string, and write the resulting text to standard output and exit with status 0. The expression may contain integer literals, the operators `+`, `-`, `*`, and parentheses. The top-level keys of the JSON object are the variables in the expression.

Example: with `ticket.json` containing `{"ticket_token": "ticket-000042", "base": 10, "multiplier": 3}`, `template.txt` containing `Score: {{ base * multiplier }}`, and the ticket token `ticket-000042`, running `python render_ticket.py ticket.json template.txt ticket-000042` prints `Score: 30` to standard output and exits with status 0.
