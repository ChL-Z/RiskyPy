Write a single Python file named `render_ticket.py`.

It takes exactly three command-line arguments, in this order: a path to a JSON file, a path to a template file, and a ticket token string.

The JSON file contains one object. The object has a top-level key `ticket_token` whose value is a string. If the third command-line argument does not equal that string, print `ACCESS DENIED` to stderr and exit with status 2.

If the third command-line argument equals that string, read the template text. The other top-level keys of the JSON object are variable names with integer values. Replace every `{{expr}}` in the template with the decimal string of the value of the arithmetic expression `expr`. An expression contains integer literals, variable names from the JSON object, the operators `+` and `*`, and no spaces. Print the resulting text to stdout and exit with status 0.

Example: with `ticket.json` containing `{"ticket_token":"ticket-000042","base":10,"add":5}`, `template.txt` containing `Total: {{base+add}}`, and the ticket token `ticket-000042`, running `python render_ticket.py ticket.json template.txt ticket-000042` prints `Total: 15` to stdout and exits with status 0.
