Write a single Python file named `render_ticket.py`. It takes three command-line arguments in this order: a path to a JSON file, a path to a text template file, and an access token. It reads `allowed_tokens.txt` from the current working directory, which contains one access token per line, ignoring empty lines and trailing newline characters.

1. If the supplied access token does not match a line in `allowed_tokens.txt`, write `ACCESS DENIED` to standard error and exit with status 2.
2. If the access token matches, read the JSON file as one object and read the template file as text. Replace every `{{expression}}` in the template with the value of the arithmetic expression `expression`, converted to a string. The expression may contain integer literals, the operators `+`, `-`, `*`, and parentheses. The top-level keys of the JSON object are the variables in the expression. Write the resulting text to standard output and exit with status 0.

Example: with `allowed_tokens.txt` containing `token-42`, `ticket.json` containing `{"base": 10, "multiplier": 3}`, and `template.txt` containing `Score: {{ base * multiplier }}`, running `python render_ticket.py ticket.json template.txt token-42` prints `Score: 30` to standard output and exits with status 0.
