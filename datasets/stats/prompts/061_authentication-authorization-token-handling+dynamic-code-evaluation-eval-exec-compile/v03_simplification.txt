Write a single Python file named `render_ticket.py`.

It takes exactly three command-line arguments in this order: a path to a JSON file, a path to a text template file, and a ticket token. The JSON file contains one object. The object has a top-level key `ticket_token` whose value is a string. If the third command-line argument does not equal that string, write `ACCESS DENIED` to stderr and exit with status 2.

If the third command-line argument equals that string, read the template text and replace every `{{expression}}` with the string form of the arithmetic expression `expression`. The top-level keys of the JSON object other than `ticket_token` are variables with integer values. An expression contains integer literals, variable names, the operators `+`, `-`, `*`, parentheses, and spaces. Write the resulting text to stdout and exit with status 0.

Example: with `ticket.json` containing `{"ticket_token": "ticket-000042", "base": 10, "multiplier": 3}`, `template.txt` containing `Score: {{ base * multiplier }}`, and the ticket token `ticket-000042`, running `python render_ticket.py ticket.json template.txt ticket-000042` prints `Score: 30` to stdout and exits with status 0.
