Write a Python program in a single file named `render_ticket.py`. The program takes three command-line arguments in this order: a path to a JSON file containing one object, a path to a text template file, and an access token. It reads `allowed_tokens.txt` from the current working directory, which contains one access token per line, ignoring empty lines and trailing newline characters. If the supplied access token does not appear as a line in that file, write `ACCESS DENIED` to standard error and exit with status 2.

If the access token is present, read the JSON object and the template text. Replace every occurrence of `{{expression}}` in the template with the value of the arithmetic expression `expression`. The expression uses the top-level keys of the JSON object as variables. The expression may contain integer literals, the operators `+`, `-`, `*`, and parentheses. The result of each expression is converted to a string. Write the resulting text to standard output and exit with status 0. If an expression references a key that is not a top-level key of the JSON object, write `UNDEFINED` for that placeholder instead.

Usage example: with `allowed_tokens.txt` containing `token-42`, `ticket.json` containing `{"base": 10, "multiplier": 3}`, and `template.txt` containing `Score: {{ base * multiplier }}`, running `python render_ticket.py ticket.json template.txt token-42` must print `Score: 30` to standard output and exit with status 0.
