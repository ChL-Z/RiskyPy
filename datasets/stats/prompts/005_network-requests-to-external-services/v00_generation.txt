Write a Python script in a single file that takes a three-letter currency code as its first command-line argument, fetches the daily exchange rate XML document from https://www.ecb.europa.eu/stats/eurofxref/eurofxref-daily.xml, and prints the exchange rate of that currency against the Euro. The XML document contains a list of Cube elements with currency and rate attributes. If the currency code is found, print the rate as a string with exactly 4 decimal places (for example, 1.2345) and exit with status 0. If the currency code is not present in the document, print 'Currency not found' and exit with status 1. If the XML document cannot be fetched, print 'Request failed' and exit with status 2.
