Create a Python program in one file named `jobdigest.py`. It reads an XML file path from `sys.argv[1]`. The XML file has a root `<jobs>` element containing `<job>` elements in document order. Each `<job>` has a `name` attribute, a `<command>` child containing command text, a `<key>` child containing 64 lowercase hexadecimal characters, and a `<digest>` child containing 64 lowercase hexadecimal characters.

For each `<job>` element, run the text of its `<command>` child as a command line, capture the command's stdout bytes and exit code. Compute a keyed digest of the exact stdout bytes using the `<key>` value as the key. Print to stdout one line per job containing a JSON object with exactly these fields: `name` (string), `exit_code` (integer), and `digest_match` (boolean). `digest_match` is true when the computed keyed digest equals the `<digest>` value and false otherwise. Preserve the order of `<job>` elements.

Example `jobs.xml`:

```xml
<jobs>
  <job name="greet">
    <command>printf hello</command>
    <key>6b65792d30303031323334353637383930616263646566676869</key>
    <digest>3f786850e387550fdab836ed7e6dc881de23001b5a7f9c2d4e6b8a0c1d2e3f40</digest>
  </job>
  <job name="list">
    <command>ls -1</command>
    <key>6b65792d30303031323334353637383930616263646566676869</key>
    <digest>a1b2c3d4e5f60718293a4b5c6d7e8f90112233445566778899aabbccddeeff00</digest>
  </job>
</jobs>
```

Command:

```sh
python jobdigest.py jobs.xml
```

For the example file, the program prints one JSON object for each `<job>` element, using the values read from the file.
