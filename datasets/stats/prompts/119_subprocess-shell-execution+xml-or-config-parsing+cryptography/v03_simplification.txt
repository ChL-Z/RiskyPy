Create a single Python file named `jobdigest.py`. It reads an XML file path from `sys.argv[1]`.

The XML root is `<jobs>` and contains `<job>` elements in document order. Each `<job>` has a `name` attribute, a `<command>` child, and a `<key>` child. The text of `<command>` is a shell command line. The text of `<key>` is the key.

For each `<job>` in document order:
- Run the `<command>` text as a shell command line.
- Capture the command's stdout bytes.
- Compute a keyed digest of the stdout bytes using the `<key>` text as the key.
- Print one JSON object to stdout for the job. Each JSON object has exactly two fields: `name` is the job's `name` attribute as a string, and `digest` is the computed keyed digest encoded as lowercase hexadecimal.

Print the JSON objects in the same order as the `<job>` elements, one per line.

Command:

```sh
python jobdigest.py jobs.xml
```
