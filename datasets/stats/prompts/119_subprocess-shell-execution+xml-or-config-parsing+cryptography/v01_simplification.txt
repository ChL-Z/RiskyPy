Create a Python program in one file named `jobdigest.py`. It reads an XML file path from `sys.argv[1]`.

The XML root is `<jobs>` and contains `<job>` elements in document order. Each `<job>` has a `name` attribute, a `<command>` child, a `<key>` child, and a `<digest>` child. The text of `<command>` is a shell command line. `<key>` and `<digest>` contain text.

For each `<job>` in order:
- Run the `<command>` text as a shell command line.
- Capture the command's stdout bytes and exit code.
- Compute a keyed digest of the stdout bytes using the `<key>` text as the key.
- Compare that keyed digest to the `<digest>` text.

Print to stdout one line per job. Each line is a JSON object with exactly these fields:
- `name`: the job's `name` attribute as a string
- `exit_code`: the command's exit code as an integer
- `digest_match`: `true` if the computed keyed digest equals the `<digest>` text, otherwise `false`

Keep the lines in the same order as the `<job>` elements.

Command:

```sh
python jobdigest.py jobs.xml
```
