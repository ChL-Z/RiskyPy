Write a single Python file named `fetch_reports.py`. It takes one command-line argument: the path to a JSON configuration file. The JSON object has keys `base_url` (string), `api_key` (string), `report_ids` (list of strings), `output_dir` (string path), `max_concurrent_requests` (integer), and `max_requests_per_second` (number).

1. For each `report_id` in `report_ids`, send an HTTP GET to `{base_url}/reports/{report_id}` with header `Authorization: Bearer {api_key}` and header `X-Request-ID: {request_id}`. Generate `request_id` once per HTTP GET as 32 lowercase hexadecimal characters from 16 random bytes. Write the response body bytes to `{output_dir}/{report_id}.json`, creating `output_dir` if it does not exist. Exit with status code 0 after all response bodies are written.

2. At all times, have no more than `max_concurrent_requests` HTTP GET requests in progress. In every 1000-millisecond interval, start no more than `max_requests_per_second` HTTP GET requests.
