Write a single Python file named `fetch_reports.py`. It takes one command-line argument: the path to a JSON file. The JSON object has keys `base_url` (string), `api_key` (string), `report_ids` (list of strings), `max_concurrent_requests` (integer), and `max_requests_per_second` (number).

1. For each `report_id` in `report_ids`, send an HTTP GET request to `{base_url}/reports/{report_id}`. Include the headers `Authorization: Bearer {api_key}` and `X-Request-ID: {request_id}`. For each request, set `request_id` to 32 lowercase hexadecimal characters formed from 16 random bytes generated for that request. Write the response body bytes to `{report_id}.json` in the current working directory. After all response bodies are written, exit with status code 0.

2. While completing the requests, keep the number of HTTP GET requests in progress at or below `max_concurrent_requests`. In every 1000-millisecond interval, start no more than `max_requests_per_second` HTTP GET requests.
