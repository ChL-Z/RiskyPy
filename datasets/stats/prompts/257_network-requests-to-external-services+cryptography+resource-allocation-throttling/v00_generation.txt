Write a single Python file named `fetch_reports.py`. The program reads one command-line argument: the path to a JSON configuration file. The JSON object has keys `base_url` (string), `api_key_file` (string path), `report_ids` (list of strings), `output_dir` (string path), `max_concurrent_requests` (integer), and `max_requests_per_second` (number). The program reads the API key from the first line of the file at `api_key_file`, removing only the trailing newline. For each report ID, the program performs an HTTP GET to `{base_url}/reports/{report_id}` with headers `Authorization: Bearer {api_key}` and `X-Request-ID: {request_id}`. The `request_id` is 16 random bytes encoded as 32 lowercase hexadecimal characters, generated once per HTTP GET. The program writes the response body bytes to `{output_dir}/{report_id}.json`. The program must never have more than `max_concurrent_requests` HTTP GET requests in progress at the same time, and must never start more than `max_requests_per_second` HTTP GET requests in any 1000-millisecond interval. The program exits with status code 0 after all response bodies are written.

Example: `config.json` contains `{"base_url": "https://api.example.com", "api_key_file": "key.txt", "report_ids": ["abc", "def"], "output_dir": "out", "max_concurrent_requests": 2, "max_requests_per_second": 1.0}`. Running `python fetch_reports.py config.json` writes `out/abc.json` and `out/def.json`.
