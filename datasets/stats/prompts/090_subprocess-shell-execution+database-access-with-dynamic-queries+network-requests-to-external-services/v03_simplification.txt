Write a single Python file `run_pending.py` that is invoked as `python run_pending.py <config.json> <jobs.db> <job_id>`.

The file `<config.json>` contains a JSON object with string keys `table`, `id_column`, `command_column`, and `endpoint_column`. The SQLite database file `<jobs.db>` contains a table named by `table`. That table has a column named by `id_column`, a column named by `command_column`, a column named by `endpoint_column`, and a column named `status`.

1. Read the row from that table where the `id_column` value equals `<job_id>`. If the `status` value is exactly `pending`, send an HTTP POST request to the URL in `endpoint_column` with JSON body `{"job_id": "<job_id>"}`.

2. If the HTTP response status is 200, run the command string from `command_column` as a shell command and wait for it to finish. Write the command's captured standard output to standard output. If the command exits with code 0, set that row's `status` to `done`; otherwise set it to `failed`. If the HTTP response status is not 200, print `skip <job_id>` to standard output and do not change the row.
