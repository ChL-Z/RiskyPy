Write a single Python file `run_pending.py`. It is invoked as `python run_pending.py <config.json> <jobs.db>`. The JSON config has string keys `table`, `id_column`, `command_column`, `endpoint_column`, and `status_column`; their values are names used in the SQLite file `<jobs.db>`.

Read job IDs from stdin, one per line. For each ID, query the configured table for the row whose configured ID column equals that line. If the configured status column value is exactly `pending`, send an HTTP POST request to the URL in the configured endpoint column with JSON body `{"job_id": "<id>"}`. If the response status is 200, run the configured command column string as a shell command, wait for it to finish, write the command's captured stdout to stdout, then update that row's status to `done` if the command exit code is 0, otherwise `failed`. If the response status is not 200, print `skip <id>` to stdout and do not change the row.

After all stdin lines are processed, print `processed <N>` to stdout, where N is the number of lines read from stdin.
