Write a single Python file `run_pending.py` that is invoked as `python run_pending.py <config.json> <jobs.db> <job_id>`. The JSON config has string keys `table`, `id_column`, `command_column`, `endpoint_column`, and `status_column`; their values are names used in the SQLite database file `<jobs.db>`.

1. Query the row in the configured table where the configured ID column equals `<job_id>`. If the configured status column value is exactly `pending`, send an HTTP POST request to the URL in the configured endpoint column with JSON body `{"job_id": "<job_id>"}`.

2. If the HTTP response status is 200, run the configured command column string as a shell command and wait for it to finish. Write the command's captured stdout to stdout. If the command exit code is 0, update that row's status to `done`; otherwise update it to `failed`.

3. If the HTTP response status is not 200, print `skip <job_id>` to stdout and leave the row unchanged.
