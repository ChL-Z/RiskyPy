Write a Python program in a single file. The program accepts one command-line argument: the path to a cache file. It reads newline-separated arithmetic expressions from standard input, one expression per line; blank lines are ignored. For each expression, the program prints one line in the form `<expression> = <value>`, where `<value>` is the result of evaluating the expression. The expressions use only integer and float literals, the binary operators +, -, *, /, and parentheses.

The program maintains a cache file that maps each expression string to its computed value. Before evaluating an expression, the program checks whether the cache file already contains that expression string; if it does, the program prints the cached value and does not evaluate the expression. After processing all input lines, the cache file contains entries for every expression seen in that run and every expression seen in previous runs. If the cache file does not exist, the program starts with an empty cache.

For example, running `printf '2+3\n4*5\n' | python calc_cache.py cache.dat` prints:
```
2+3 = 5
4*5 = 20
```
Running the same command again prints the same two lines without recomputing the values.
