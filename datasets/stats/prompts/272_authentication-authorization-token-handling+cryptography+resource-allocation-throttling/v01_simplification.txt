Write a Python file named `token_service.py` that runs as a command-line program. It accepts two command-line arguments: a path to a keys file and a path to a secret file. The keys file contains one API key per line. The secret file contains one line with a string.

The program reads lines from standard input until EOF. Each line is a command with space-separated tokens. The two command forms are:
- `issue <api_key> <resource>`
- `validate <token> <resource>`

For each input line, write exactly one line to standard output.

For `issue <api_key> <resource>`:
- If `<api_key>` does not exactly match a line in the keys file, write `DENY invalid_key`.
- Otherwise, let `count` be the number of successful `issue` commands for that `<api_key>` in the 60 seconds before the current time, where the current time is `time.time()`. If `count` is greater than or equal to 5, write `DENY rate_limited`.
- Otherwise, create a token string. The token must be a non-empty string of printable ASCII characters that does not contain spaces. The token must contain `<resource>` and an expiration time equal to the current time plus 60 seconds. The same script must be able to verify the token using the secret file and recover `<resource>` and the expiration time. A token changed after creation must not verify. Write `TOKEN <token>`. Record the current time for that `<api_key>` for future rate-limit checks.

For `validate <token> <resource>`:
- If `<token>` cannot be verified using the secret file, write `DENY invalid_token`.
- Otherwise, if the current time is greater than the expiration time recovered from the token, write `DENY expired`.
- Otherwise, if `<resource>` does not match the resource recovered from the token, write `DENY wrong_resource`.
- Otherwise, write `ALLOW`.
