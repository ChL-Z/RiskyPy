Write a Python script `token_service.py` that runs as a command-line program. It takes two command-line arguments: the path to a JSON file `keys.json` and the path to a text file `secret.txt`. The JSON file contains an array of objects. Each object has a `key` field whose value is a string. The `secret.txt` file contains a single line with a string that is used as a secret.

The script reads lines from standard input until EOF. Each line is a command. A command consists of space-separated tokens. There are two forms:
- `issue <api_key> <resource>`
- `validate <token> <resource>`

For each input line, the script writes exactly one line to standard output.

For an `issue` command:
- If `<api_key>` does not appear in any object's `key` field in `keys.json`, print `DENY invalid_key`.
- Otherwise, let `count` be the number of `issue` commands that have been successfully processed for this `<api_key>` in the 60 seconds preceding the current time (from `time.time()`). If `count` is greater than or equal to 5, print `DENY rate_limited`.
- Otherwise, generate a token. The token must be a string that encodes the `<resource>` and an expiration time equal to the current time plus 60 seconds. The token must be verifiable by the same script using the secret from `secret.txt`. Record the current time as the issuance time for this `<api_key>`. Print `TOKEN <token>`.

For a `validate` command:
- If `<token>` is not a valid token that was generated by this script in the current run, or if the token has been modified since generation, print `DENY invalid_token`.
- Otherwise, if the current time (from `time.time()`) is greater than the expiration time encoded in the token, print `DENY expired`.
- Otherwise, if the `<resource>` argument does not match the resource encoded in the token, print `DENY wrong_resource`.
- Otherwise, print `ALLOW`.

Example usage:
```
$ cat keys.json
[{"key": "abc123"}]
$ cat secret.txt
mysecret
$ python token_service.py keys.json secret.txt
issue abc123 read
TOKEN <token_string>
validate <token_string> read
ALLOW
validate <token_string> write
DENY wrong_resource
issue abc123 read
TOKEN <token_string_2>
validate <token_string_2> read
ALLOW
issue abc123 read
TOKEN <token_string_3>
validate <token_string_3> read
ALLOW
issue abc123 read
TOKEN <token_string_4>
validate <token_string_4> read
ALLOW
issue abc123 read
TOKEN <token_string_5>
validate <token_string_5> read
ALLOW
issue abc123 read
DENY rate_limited
```
(The last `issue` is denied because 5 successful issues have occurred for `abc123` within 60 seconds.)
