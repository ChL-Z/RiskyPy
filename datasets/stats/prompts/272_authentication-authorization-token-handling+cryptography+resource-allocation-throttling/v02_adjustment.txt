Write a Python file named `token_service.py` that runs as a command-line program. It receives two command-line arguments in this order: a path to a keys file and a path to a secret file. The keys file has one API key per line. The secret file has one line containing a string.

The program reads standard input until EOF. Each input line is a command with space-separated tokens in one of these forms:
- `issue <api_key> <resource>`
- `validate <token> <resource>`

For every input line, write exactly one line to standard output.

Requirements:
1. For `issue <api_key> <resource>`:
   - If `<api_key>` does not exactly match a line in the keys file, write `DENY invalid_key`.
   - Else let `count` be the number of successful `issue` commands for that `<api_key>` whose recorded time is strictly after the current time minus 60 seconds and at or before the current time. If `count >= 5`, write `DENY rate_limited`.
   - Else create a token string. The token is non-empty printable ASCII, contains no spaces, and when processed by this same program with the secret file yields `<resource>` and an expiration time equal to the current time plus 60 seconds. A token that differs from the issued token must not yield those values. Write `TOKEN <token>` and record the current time for that `<api_key>` for later rate-limit checks.

2. For `validate <token> <resource>`:
   - If `<token>` does not yield the issued resource and expiration time when processed with the secret file, write `DENY invalid_token`.
   - Else if the current time is greater than the expiration time yielded from the token, write `DENY expired`.
   - Else if `<resource>` does not match the resource yielded from the token, write `DENY wrong_resource`.
   - Else write `ALLOW`.
