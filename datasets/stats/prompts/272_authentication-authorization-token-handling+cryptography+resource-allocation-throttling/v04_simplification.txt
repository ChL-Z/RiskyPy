Write a Python file named `token_service.py` that runs as a command-line program. It takes one command-line argument: a path to a text file. The first line of this file is a secret string. Each remaining line is an API key. Remove the trailing newline from each line when reading the file.

The program reads standard input until EOF. Each input line is one command with space-separated tokens:
- `issue <api_key> <resource>`
- `validate <token> <resource>`

For each input line, write exactly one line to standard output.

1. For `issue <api_key> <resource>`:
   - If `<api_key>` does not equal any API key from the file, write `DENY invalid_key`.
   - Otherwise, if the program has already written `TOKEN ...` five times in this run, write `DENY rate_limited`.
   - Otherwise, write `TOKEN <token>`. The token string must contain only printable ASCII characters and no spaces. When the same program reads it in a `validate` command with the same file, it must recover the `<resource>` from the issue command and an expiration time equal to the current Unix time in seconds plus 60. Any token string other than the one produced must not recover that resource and expiration time.

2. For `validate <token> <resource>`:
   - If `<token>` does not recover a resource and expiration time using the secret, write `DENY invalid_token`.
   - Otherwise, if the current Unix time in seconds is greater than the recovered expiration time, write `DENY expired`.
   - Otherwise, if `<resource>` does not equal the recovered resource, write `DENY wrong_resource`.
   - Otherwise, write `ALLOW`.
