Write a Python file named `token_service.py` that runs as a command-line program. It takes two command-line arguments in order: a path to a keys file and a path to a secret file. The keys file contains one API key per line. The secret file contains one line holding a string. When reading keys and the secret, remove the trailing newline from each line.

The program reads standard input until EOF. Each input line is a command with space-separated tokens:
- `issue <api_key> <resource>`
- `validate <token> <resource>`

For each input line, write exactly one line to standard output.

1. For `issue <api_key> <resource>`:
   - If `<api_key>` does not equal any line of the keys file, write `DENY invalid_key`.
   - Otherwise, if the program has already produced a token for that `<api_key>` five times in this run, write `DENY rate_limited`.
   - Otherwise, create a token string and write `TOKEN <token>`. The token string consists of printable ASCII characters and contains no space. Using the same secret file, this same program must be able to recover `<resource>` and an expiration time equal to the current Unix time in seconds plus 60 from the token. Any token string other than the one produced must not recover that resource and expiration. Record one successful issue for `<api_key>`.

2. For `validate <token> <resource>`:
   - If `<token>` does not recover a resource and expiration time using the secret file, write `DENY invalid_token`.
   - Otherwise, if the current Unix time in seconds is greater than the recovered expiration time, write `DENY expired`.
   - Otherwise, if `<resource>` does not equal the recovered resource, write `DENY wrong_resource`.
   - Otherwise, write `ALLOW`.
