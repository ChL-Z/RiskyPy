Write a Python program in a single file named `service_report.py`. The program reads one line from standard input: the path to an XML configuration file. The XML file has one root element `<config>` whose children are zero or more `<service>` elements. Each `<service>` element has exactly three attributes: `name`, `host`, and `port`. The program must either write one line to standard output for every `<service>` element in document order, in the form `name<TAB>host:port`, and exit with status code 0; or, if the path line is empty or contains only whitespace, the file cannot be read, the content is not well-formed XML, or any `<service>` element is missing one of the three attributes, the program must write nothing to standard output, append one line to a file named `config_errors.log` in the same directory as `service_report.py`, and exit with status code 1. The appended line must be exactly the current local date and time formatted as `YYYY-MM-DD HH:MM:SS`, followed by one space, followed by `config error`.

Example: standard input line is `config.xml`. The file `config.xml` contains:

<config>
  <service name="auth" host="10.0.0.4" port="8080"/>
  <service name="billing" host="10.0.0.5" port="9090"/>
</config>

Standard output is:

auth	10.0.0.4:8080
billing	10.0.0.5:9090

Exit status is 0.
