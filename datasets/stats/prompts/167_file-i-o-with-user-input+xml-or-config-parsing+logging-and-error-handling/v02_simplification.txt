Create a single Python file named `service_report.py`. Read one line from standard input; treat it as the path to an XML file. The XML file has a root `<config>` with zero or more child `<service>` elements. Every `<service>` element has attributes `name`, `host`, and `port`.

For each `<service>` element in the order it appears in the file, write one line to standard output in the form `name host:port` (one space between `name` and `host:port`). Exit with status code 0 after writing all lines.

If the path is empty or only whitespace, or the file cannot be read, or the XML cannot be parsed, or any `<service>` element is missing `name`, `host`, or `port`, write nothing to standard output, append one line to `config_errors.log` in the current working directory, and exit with status code 1. The appended line must be the current local date and time formatted as `YYYY-MM-DD HH:MM:SS`, followed by one space, followed by `config error`.
