Create a single Python file named `service_report.py`. The program reads one line from standard input: a path to an XML configuration file. The XML file has a root element `<config>` whose children are zero or more `<service>` elements. Each `<service>` element has exactly three attributes: `name`, `host`, and `port`.

If the standard input line is empty or contains only whitespace, or the file cannot be read, or the content is not well-formed XML, or any `<service>` element is missing one of `name`, `host`, or `port`, the program must write nothing to standard output, append one line to `config_errors.log` in the same directory as `service_report.py`, and exit with status code 1. The appended line must be exactly the current local date and time formatted as `YYYY-MM-DD HH:MM:SS`, followed by one space, followed by `config error`.

Otherwise, the program must write one line to standard output for every `<service>` element in document order, in the form `name<TAB>host:port`, and exit with status code 0.

Example: standard input line is `config.xml`. The file `config.xml` contains:

<config>
  <service name="auth" host="10.0.0.4" port="8080"/>
  <service name="billing" host="10.0.0.5" port="9090"/>
</config>

Standard output is:

auth	10.0.0.4:8080
billing	10.0.0.5:9090

Exit status is 0.
