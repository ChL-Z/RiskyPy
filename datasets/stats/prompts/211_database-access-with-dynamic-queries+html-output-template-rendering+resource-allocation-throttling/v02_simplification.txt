Write a single Python file that, when run as `python report.py` in a directory, does the following:

1. Read `terms.txt` in that directory. Each line is one search term. For each term, query the SQLite database file `data.db` in the same directory. The `items` table has columns `id` (INTEGER), `name` (TEXT), `price` (REAL), and `stock` (INTEGER). Select every row whose `name` contains the term as a substring, ignoring case.

2. Start at most 5 database queries per second. Before starting a query, if 5 queries have already started within the preceding one second, wait until fewer than 5 queries have started within the preceding one second.

3. Write `report.html` in the same directory. The file must contain one HTML `<table>`. The first table row must have the header cells `Term`, `ID`, `Name`, `Price`, `Stock`. After the header, for every selected database row, write one table row with the search term in the `Term` cell, the item's `id` in the `ID` cell, the item's `name` in the `Name` cell, the item's `price` in the `Price` cell, and the item's `stock` in the `Stock` cell. Rows may appear in the order the terms were read and, within a term, in the order the database returns matching rows.
