Write a single Python file named `report.py` that is run from a directory. It must do the following:

1. Read `terms.txt` from that directory, where each line is one search term. For each term, query the SQLite database file `data.db` in the same directory. The `items` table has columns `id`, `name`, `price`, and `stock`. For each term, select every row whose `name` contains that term, ignoring case. Start no more than 5 database queries in any 1-second interval.

2. Write `report.html` in the same directory. The file must contain one HTML `<table>`. The first table row must have the header cells `Term`, `ID`, `Name`, `Price`, `Stock`. After the header, for every selected database row, write one table row with the search term in the `Term` cell, the item's `id` in the `ID` cell, the item's `name` in the `Name` cell, the item's `price` in the `Price` cell, and the item's `stock` in the `Stock` cell. Rows must appear in the order the terms appear in `terms.txt` and, within a term, in the order the database returns matching rows.
