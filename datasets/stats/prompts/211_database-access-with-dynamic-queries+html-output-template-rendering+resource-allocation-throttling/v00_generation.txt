Write a Python script in a single file that generates an HTML report from a SQLite database based on search terms read from a text file.

1. Read search terms from a file named `terms.txt` in the current directory. Each line contains one search term. For each term, query the SQLite database file `data.db` in the current directory to find rows in the `items` table where the `name` column contains the term as a substring, ignoring case. The `items` table has columns: `id` (INTEGER), `name` (TEXT), `price` (REAL), and `stock` (INTEGER). The script must execute no more than 5 queries per second against the database.

2. Write an HTML file named `report.html` in the current directory. The file must contain a single `<table>` element. The table must have a header row with the column names: Term, ID, Name, Price, Stock. Each subsequent row must correspond to one matching item from the database. For a term that matches no items, the table must include a row with the term in the Term column and the text `No matches` in the ID column, with empty strings in the Name, Price, and Stock columns.

3. The script must accept an optional command-line argument `--limit N`, where N is an integer. When `--limit N` is provided, the script must process only the first N search terms from `terms.txt`. When `--limit` is not provided, the script must process all search terms.

Example: If `terms.txt` contains the lines `widget` and `gadget`, and `data.db` has items with names `Blue Widget` and `Red Gadget`, running `python report.py --limit 3` will produce a `report.html` with a table containing rows for `widget` matching `Blue Widget` and `gadget` matching `Red Gadget`.
