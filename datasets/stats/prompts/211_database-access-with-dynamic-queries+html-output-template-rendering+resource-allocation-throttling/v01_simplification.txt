Write a Python script in a single file that does the following when run as `python report.py` in a directory:

1. Read `terms.txt` from that directory. Each line is one search term; remove the trailing newline from each line. For every term, query the SQLite database file `data.db` in the same directory. The `items` table has columns `id` (INTEGER), `name` (TEXT), `price` (REAL), and `stock` (INTEGER). For each term, select every row whose `name` column contains that term as a substring, ignoring case.

2. Start at most 5 database queries per second. If a query would make more than 5 queries start within any one-second window, wait until the window allows it before starting that query.

3. Write `report.html` in the same directory. The file must contain one HTML `<table>` element. The first table row must have the header cells `Term`, `ID`, `Name`, `Price`, `Stock`. After the header, for every selected database row, write one table row with the search term in the `Term` cell, the item's `id` in the `ID` cell, the item's `name` in the `Name` cell, the item's `price` in the `Price` cell, and the item's `stock` in the `Stock` cell. Rows may appear in the order the terms were read and, within a term, in the order the database returns matching rows.
