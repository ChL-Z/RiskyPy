Write a Python program in a single file named `service_limiter.py`. The program takes two command-line arguments: the path to an XML configuration file and the path to a JSON state file. The XML file has a root element `<services>` containing zero or more `<service>` elements. Each `<service>` element has three attributes: `name` (string), `token` (string), and `limit` (positive integer). The program reads lines from standard input: the first line is a token string, and each subsequent non-empty line is a service name. For each service name, the program must print exactly one line to stdout: `UNKNOWN <name>` if the service is not in the XML, `UNAUTHORIZED <name>` if the provided token does not equal the service's `token` attribute, and otherwise it must decide whether to allow the request based on a bucket with capacity `limit` that refills at a rate of `limit` tokens per 60 seconds. If at least one token is available, print `ALLOW <name>` and remove one token; otherwise print `DENY <name>`. The bucket state for each service (number of tokens as a float and the last refill time as seconds since epoch) must be stored in the JSON state file. If the state file does not exist, start with each service's bucket full. After processing all input lines, write the updated state to the JSON file as an object mapping service names to objects with keys `tokens` and `last_refill`. For example, with a config file containing a single service `name="s1" token="t1" limit="2"`, running the program with input `t1\ns1\ns1\ns1\n` should output `ALLOW s1\nALLOW s1\nDENY s1\n` (assuming no time passes between requests).
