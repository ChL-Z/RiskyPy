Write `service_limiter.py`. The program takes two command-line arguments in this order: an XML configuration file path and a JSON state file path. It reads two lines from standard input: line 1 is a token identifier, and line 2 is a requested service name.

Parse the XML configuration. Its root element is `<service>` with attributes `name` and `limit`. `limit` is a positive integer. The root element contains zero or more descendant `<token>` elements; each `<token>` element has an `id` attribute. The request is accepted only when line 1 equals the `id` attribute of at least one `<token>` element and line 2 equals the root `name` attribute. If the request is not accepted, print `DENY <requested>` on one line, where `<requested>` is line 2 exactly, and exit with status 0 without reading or writing the state file.

For an accepted request, process a token bucket for the service. The bucket capacity is the root `limit` attribute. The bucket gains `limit` tokens every 60 seconds and never exceeds `limit`. The JSON state file contains an object with keys `tokens` and `last_refill`, both numbers. If the file exists, read both values. If the file does not exist, use `tokens = limit` and `last_refill = now`, where `now` is the current time in seconds since the epoch at request time. If the file exists, compute `now` as the current time in seconds since the epoch. Compute `elapsed = now - last_refill`. Compute `tokens = min(limit, tokens + elapsed * limit / 60)`. If `tokens >= 1`, print `ALLOW <name>` where `<name>` is the root `name` attribute, and set `tokens = tokens - 1`. Otherwise print `DENY <name>`. Write to the state file a JSON object with the updated `tokens` and `last_refill = now`. Exit with status 0.
