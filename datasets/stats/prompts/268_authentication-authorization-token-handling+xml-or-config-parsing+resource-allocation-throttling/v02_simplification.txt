Write a Python program in a single file named `service_limiter.py`.

The program is run with two arguments: an XML configuration file path and a JSON state file path. The XML file has root `<service>` with attributes `name` (string) and `limit` (positive integer). Standard input has two lines: the first line is a comma-separated token string of service names; the second line is one requested service name.

Print exactly one line to stdout:
- `UNKNOWN <name>` if the requested name is not the XML service's `name`.
- `UNAUTHORIZED <name>` if the requested name is not in the first input line's comma-separated list.
- Otherwise, use a permit count for the service. The maximum permit count is `limit`. The permit count increases continuously at `limit` permits per 60 seconds and never exceeds `limit`. At request time, compute the permit count from the stored state and the current time, capped at `limit`. If the permit count is at least 1, print `ALLOW <name>` and reduce the permit count by 1; otherwise print `DENY <name>`.

The JSON state file stores an object mapping the service name to an object with keys `tokens` (float) and `last_refill` (seconds since epoch). If the state file does not exist or has no entry for the service, initialize `tokens` to `limit` and `last_refill` to the current time in seconds since epoch. After printing the output line, write the updated object to the JSON state file with the current permit count as `tokens` and the current time in seconds since epoch as `last_refill`.
