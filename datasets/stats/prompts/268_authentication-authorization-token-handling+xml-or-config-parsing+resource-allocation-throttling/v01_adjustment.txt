Write a Python program in a single file named `service_limiter.py`. The program takes two command-line arguments: the path to an XML configuration file and the path to a JSON state file. The XML file has a root element `<services>` containing zero or more `<service>` elements. Each `<service>` element has two attributes: `name` (string) and `limit` (positive integer). The program reads lines from standard input: the first line is a token string, and each subsequent non-empty line is a service name. The token string is a comma-separated list of service names (for example, `s1,s2`). For each service name from standard input, the program must print exactly one line to stdout:
- `UNKNOWN <name>` if the service name is not present as a `<service>` element in the XML.
- `UNAUTHORIZED <name>` if the service name is not present in the comma-separated list of the token.
- Otherwise, apply a token bucket rate limiter for that service. The bucket has capacity equal to the service's `limit` attribute and refills at a rate of `limit` tokens per 60 seconds. If the bucket contains at least one token, print `ALLOW <name>` and remove one token from the bucket; otherwise print `DENY <name>`.

The bucket state for each service (the number of tokens as a float and the last refill time as seconds since epoch) must be stored in the JSON state file. If the state file does not exist, initialize each service's bucket with `tokens` equal to its `limit` and `last_refill` equal to the current time in seconds since epoch. After processing all input lines, write the updated state to the JSON file as an object mapping service names to objects with keys `tokens` and `last_refill`.

For example, with a config file containing a single service `name="s1" limit="2"`, running the program with input `s1,s2\ns1\ns1\ns1\n` should output `ALLOW s1\nALLOW s1\nDENY s1\n` (assuming no time passes between requests).
