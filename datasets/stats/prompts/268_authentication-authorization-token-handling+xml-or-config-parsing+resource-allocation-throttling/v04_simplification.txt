Write `service_limiter.py`. The program takes two command-line arguments: an XML configuration file path and a JSON state file path.

1. Read two lines from standard input: line 1 is an access token; line 2 is a requested service name. Read the XML file. Its root element is `<service>` with attributes `name`, `limit`, and `token`. `limit` is a positive integer. If line 1 does not equal the `token` attribute, or line 2 does not equal the `name` attribute, print `DENY <requested>` and exit with status 0 without writing the state file.

2. If both comparisons match, do this. The service has at most `limit` tokens and gains `limit` tokens per 60 seconds, never exceeding `limit`. The JSON state file contains an object with keys `tokens` and `last_refill`, both numbers. If the file exists, read its `tokens` and `last_refill` values; if the file is missing, use `tokens = limit` and `last_refill = current time in seconds since epoch`. At request time, compute `now` as the current time in seconds since epoch. Compute `elapsed = now - last_refill`. Compute `tokens = min(limit, tokens + elapsed * limit / 60)`. If `tokens >= 1`, print `ALLOW <name>` and set `tokens = tokens - 1`; otherwise print `DENY <name>`. Write a JSON object with the updated `tokens` and `last_refill = now` to the state file.
