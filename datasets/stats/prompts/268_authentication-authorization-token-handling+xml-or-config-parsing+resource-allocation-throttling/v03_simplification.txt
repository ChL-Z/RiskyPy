Write `service_limiter.py`. It takes two command-line arguments: an XML configuration file path and a JSON state file path. Read two lines from standard input: line 1 is a comma-separated list of service names; line 2 is the requested service name. The XML root `<service>` has attributes `name` (string) and `limit` (positive integer).

If the requested name is not the XML `name` or is not in the comma-separated list, print `DENY <requested>` and exit. Otherwise, manage permits for the service. The service can hold at most `limit` permits, refilling at `limit` permits per 60 seconds and never exceeding `limit`. Read the JSON state file as an object mapping service name to `{tokens: float, last_refill: float}`. If the file is missing or has no entry for the service, use `tokens = limit` and `last_refill = current time in seconds since epoch`. At request time, add `(current time - last_refill) * limit / 60` to `tokens`, cap at `limit`. If `tokens >= 1`, print `ALLOW <name>` and subtract 1 from `tokens`; otherwise print `DENY <name>`. Then write the service entry with the updated `tokens` and `last_refill = current time in seconds since epoch` to the JSON state file.
