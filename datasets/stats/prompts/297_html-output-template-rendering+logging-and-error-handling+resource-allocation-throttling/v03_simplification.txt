Write a Python program in a single file named `checks.py`.

Read hostnames from standard input, one per line, ignoring blank lines. For each hostname, run the external command `ping -c 1 <hostname>` and capture its exit status and standard output text. Run the commands concurrently so that at most 4 are running at the same time.

After all commands finish, write `report.html` containing one HTML table. The first row has the three header cells `Host`, `Status`, and `Output` in that order. Then write one data row per hostname in the order the commands finished: the hostname, `OK` if the exit status is 0 otherwise `FAILED`, and the captured standard output text. Also append one line to `run.log` for each hostname in the order the commands finished, in the form `<hostname> <status>`, where `<status>` is `OK` or `FAILED`.

If reading standard input, writing `report.html`, or writing `run.log` fails, print one line to standard error and exit with status code 1.
