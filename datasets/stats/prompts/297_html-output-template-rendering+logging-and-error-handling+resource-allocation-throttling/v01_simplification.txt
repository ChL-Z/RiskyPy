Write a Python program in a single file named `checks.py`.

Read hostnames from stdin, one per line. Remove the trailing newline from each line. Skip a line if it is empty after removing the newline. For each hostname, invoke the external program `ping` with arguments `-c 1` and the hostname. Capture its exit status, its stdout text, and its stderr text. The captured output for that hostname is the stdout text followed by the stderr text. Run these checks concurrently, with at most 4 checks in progress at the same time. If the external program cannot be started for a hostname, set the exit status to nonzero and set the captured output to the error text.

After all checks finish, write `report.html`: an HTML document with one `<table>`. The first row is `<th>Host</th>`, `<th>Status</th>`, `<th>Output</th>` in that order. Then write one row per hostname in the order the hostnames appeared on stdin. Each row has three `<td>` cells: the hostname, `OK` if the check exited with status 0 otherwise `FAILED`, and the captured output text.

Append one line to `run.log` for each hostname, in the order the hostnames appeared on stdin. Each line is `<hostname> <status>`, where `<status>` is `OK` or `FAILED`. If stdin cannot be read or `report.html` cannot be written, print a line of text to stderr and exit with status code 1.
