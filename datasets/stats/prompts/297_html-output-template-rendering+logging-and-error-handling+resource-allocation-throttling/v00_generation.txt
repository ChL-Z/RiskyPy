Write a Python program in a single file named `checks.py`.

The program reads hostnames from stdin, one per line, treating each line with its trailing newline removed as a hostname and skipping lines that are empty after the newline is removed. For each hostname the program invokes the external program `ping` with the arguments `-c 1` and the hostname, and captures the concatenation of that program's stdout and stderr together with its exit status. At most 4 checks may be in progress at the same time.

After all checks finish, the program writes a file named `report.html` containing an HTML document with one `<table>`. The table's first row holds the three header cells `<th>Host</th>`, `<th>Status</th>`, and `<th>Output</th>` in that order. Each hostname produces one further table row with three `<td>` cells: the hostname, the text `OK` when the check exited with status 0 and the text `FAILED` otherwise, and the captured output. If the external program cannot be started, the row's status cell holds `FAILED` and the output cell holds the text of the error that occurred.

The program also appends one line to a file named `run.log` for each hostname, in the order the hostnames appeared on stdin. Each line is `<timestamp> <hostname> <status>`, where `<timestamp>` is the UTC time in `YYYY-MM-DDTHH:MM:SSZ` format and `<status>` is `OK` or `FAILED`.

If stdin cannot be read or `report.html` cannot be written, print a message to stderr and exit with status code 1.

Example run:

```
printf 'alpha\nexample.com\n' | python checks.py
```

produces `report.html` with a header row and two data rows, and `run.log` with two lines such as:

```
2024-06-01T12:00:00Z alpha OK
2024-06-01T12:00:01Z example.com FAILED
```
