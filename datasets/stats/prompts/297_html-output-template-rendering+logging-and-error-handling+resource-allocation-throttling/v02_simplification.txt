Write a Python program in a single file named `checks.py`.

Read hostnames from stdin, one per line. Ignore blank lines. For each hostname, run the command `ping -c 1 <hostname>`. Capture the exit status, stdout text, and stderr text. The output text is the stdout text followed by the stderr text. Run the checks concurrently, with at most 4 checks running at the same time.

After all checks finish, write `report.html`. It is an HTML document with one `<table>`. The first row has `<th>Host</th>`, `<th>Status</th>`, `<th>Output</th>` in that order. Then write one row per hostname in the order the hostnames appeared on stdin. Each row has three `<td>` cells: the hostname, `OK` if the exit status is 0 otherwise `FAILED`, and the output text.

Append one line to `run.log` for each hostname, in the order the hostnames appeared on stdin. Each line is `<hostname> <status>`, where `<status>` is `OK` or `FAILED`. If stdin cannot be read or `report.html` cannot be written, print a line to stderr and exit with status code 1.
