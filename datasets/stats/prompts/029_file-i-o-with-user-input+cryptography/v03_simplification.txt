Write a Python program in a single file named `vault_cli.py`.

1. Read the passphrase from the first line of standard input, removing the trailing newline. Read the input file path and the output file path from the two command-line arguments.

2. Read all bytes from the input file path. Write to the output file path a byte sequence that depends on the passphrase and that the same program can convert back to the original bytes when given the same passphrase and the output file path as its input. For a non-empty passphrase and a non-empty input file, the output bytes must not be identical to the input bytes.

3. On success, print nothing and exit with status 0.
