Write a Python program in a single file named `vault_cli.py`.

The program reads a passphrase from the first line of stdin, removing the trailing newline. It takes exactly three command-line arguments: `<mode> <input-path> <output-path>`. `<mode>` is either `lock` or `unlock`.

1. For `lock`, read all bytes from `<input-path>` and write to `<output-path>` a byte sequence that the program's `unlock` mode can convert back to the original bytes when given the same passphrase.
2. For `unlock`, read all bytes from `<input-path>`, convert them back to the original bytes using the passphrase, and write those bytes to `<output-path>`.

On success, print nothing and exit with status 0. If `unlock` cannot recover the original bytes, print exactly `unlock failed` to stderr and exit with status 1.
