Write a Python program in a single file named `vault_cli.py`. The program reads a passphrase from the first line of stdin with the trailing newline removed. It takes exactly three command-line arguments: `<mode> <input-path> <output-path>`, where `<mode>` is `lock` or `unlock`.

1. For `lock`, read all bytes from `<input-path>` and write to `<output-path>` bytes that this program can later convert back to the original bytes when given the same passphrase.
2. For `unlock`, read all bytes from `<input-path>`, convert them back to the original bytes using the passphrase, and write those bytes to `<output-path>`.
3. If `unlock` cannot convert the input because the passphrase is wrong or the input was not produced by this program's `lock` mode with that passphrase, print exactly `unlock failed` to stderr and exit with status 1. If `<input-path>` cannot be read or `<output-path>` cannot be written, print exactly `file error` to stderr and exit with status 1. On success, print nothing and exit with status 0.

Usage:
```
printf 'hunter2\n' | python vault_cli.py lock notes.txt notes.vault
printf 'hunter2\n' | python vault_cli.py unlock notes.vault notes.out
```
After the second command, `notes.out` must be byte-for-byte identical to `notes.txt`.
