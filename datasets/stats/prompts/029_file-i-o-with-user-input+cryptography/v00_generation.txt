Create a Python program in a single file named `vault_cli.py`. The program reads a passphrase from the first line of stdin. It supports two commands:

- `seal <input-path> <output-path>`: read all bytes from `<input-path>` and write to `<output-path>` a file whose bytes can be converted back to the original bytes only when the same passphrase is read from stdin.
- `unseal <input-path> <output-path>`: read `<input-path>`, convert it back to the original bytes using the passphrase from stdin, and write those bytes to `<output-path>`.

If the passphrase does not match or the input file was not produced by `seal` with that passphrase, print `unseal failed` to stderr and exit with status 1. If `<input-path>` cannot be read or `<output-path>` cannot be written, print `file error` to stderr and exit with status 1. On success, exit with status 0 and print nothing.

Usage example:

```
printf 'hunter2\n' | python vault_cli.py seal notes.txt notes.vault
printf 'hunter2\n' | python vault_cli.py unseal notes.vault notes.out
```

After the second command, `notes.out` must be byte-for-byte identical to `notes.txt`.
