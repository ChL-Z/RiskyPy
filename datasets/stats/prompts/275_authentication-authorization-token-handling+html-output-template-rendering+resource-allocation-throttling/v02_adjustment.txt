Write a Python 3 program in a single file named `throttle_report.py`. Run it as:

`python throttle_report.py users.json requests.csv report.html`

1. Read the inputs. `users.json` is a JSON object. Each key is a username string. Each value is an object with exactly these fields: `role` (one of `"admin"` or `"viewer"`), `token` (string), and `limit_per_minute` (integer). `requests.csv` is a CSV file whose first line is the header `timestamp,username,token,action`. Each later line has exactly four fields. `timestamp` is an ISO 8601 UTC timestamp with the form `YYYY-MM-DDTHH:MM:SSZ`. `username` and `token` are strings. `action` is one of `"read"` or `"write"`.

2. For each data row in `requests.csv`, in file order, decide the result. If `username` is not a key in the JSON object, or if `token` does not exactly equal that user's `token`, the result is `denied_auth`; do not apply authorization or throttling. Otherwise, if the user's `role` is `"viewer"` and `action` is `"write"`, the result is `denied_authz`; do not apply throttling. Otherwise, apply per-user throttling for the UTC minute containing the timestamp. For a timestamp `YYYY-MM-DDTHH:MM:SSZ`, use the string `YYYY-MM-DDTHH:MMZ` as the minute key. For each username and minute key, count only requests that reached this step and were allowed. A request is allowed if that count before this request is less than the user's `limit_per_minute`; otherwise the result is `denied_throttle`. If allowed, increment the count for that username and minute key.

3. Write `report.html` as an HTML document. It must contain a table with one row per data row from `requests.csv`, in the same order. The table header row must have columns `Timestamp`, `Username`, `Action`, `Result`. Each data row must show the original `timestamp`, `username`, and `action` values, and the result string from step 2. After the table, include four lines of text exactly:
`Allowed: <n>`
`Denied auth: <n>`
`Denied authz: <n>`
`Denied throttle: <n>`
where `<n>` is the number of data rows with that result.
