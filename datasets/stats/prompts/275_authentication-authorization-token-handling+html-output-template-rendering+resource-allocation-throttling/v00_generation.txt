Write a Python 3 program in a single file named `throttle_report.py`. The program is invoked as:

`python throttle_report.py users.json requests.csv report.html`

Read `users.json`, which is a JSON object with a key `"users"` whose value is a list of objects. Each user object has keys `"name"` (string), `"token"` (string), and `"limit"` (integer).

Read `requests.csv`, which is a CSV file with a header row `timestamp,user,token,resource` followed by data rows. The `timestamp` values are non-decreasing. Process the data rows in the order they appear.

For each data row:
- If the `user` value does not appear in any user object in `users.json`, count the row as `unknown_user`.
- Otherwise, let U be the user object. If the `token` value does not exactly equal U's `"token"` string, count the row as `bad_token`.
- Otherwise, the row is authorized. For each user, maintain a 60-second window. The first authorized row for a user starts a window at that row's `timestamp`. Within a window, the first `limit` authorized rows (including the row that started the window) are `allowed`; each subsequent authorized row in the same window is `throttled`. When an authorized row's `timestamp` is greater than or equal to the current window start timestamp plus 60, that row starts a new window, and the same rule applies.

Write `report.html` as a UTF-8 encoded HTML document. The document must contain a `<table>` with one row per user from `users.json`, in the same order as `users.json`. Each user row must contain: the user's `name` in a cell; the first 4 characters of the user's `token` followed by `...` in a cell; the count of `allowed` rows for that user in a cell; the count of `throttled` rows for that user in a cell; the count of `bad_token` rows for that user in a cell. The table must also have a final row for `unknown_user` rows: the name cell is `(unknown)`, the token cell is empty, the allowed count cell is `0`, the throttled count cell is `0`, and the bad_token count cell is the number of `unknown_user` rows.

Below the table, for each user in the same order as `users.json`, add a heading with the user's `name`, then two lists: one list of `resource` strings from rows that were `allowed` for that user, and one list of `resource` strings from rows that were `throttled` for that user. The lists must be in the order the rows appeared in `requests.csv`. For unknown users, add a heading `(unknown)` and a list of `resource` strings from `unknown_user` rows.

Example invocation:

`python throttle_report.py users.json requests.csv report.html`
