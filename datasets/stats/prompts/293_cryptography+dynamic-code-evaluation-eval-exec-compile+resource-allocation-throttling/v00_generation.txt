Write a Python script `evalcache.py` that takes three command-line arguments: `secret_key`, `input_path`, and `output_path`. The script reads `input_path` as a text file containing one arithmetic expression per line. Each expression contains only integer literals, the operators `+`, `-`, `*`, `/`, parentheses, and spaces. Evaluate each expression to an integer, truncating any fractional part toward zero, and write the results to `output_path` as a text file with one integer per line in the same order. For example, if `input_path` contains the lines `2+3*4` and `(10-2)/3`, then `output_path` must contain `14` and `2`.

To avoid recomputing the same expression in later runs, the script stores a cache in a file named `expr.cache` in the current working directory. The cache maps a 16-byte key to the integer result. The key for an expression is computed by a cryptographic function that takes the UTF-8 encoded expression string and the `secret_key` string as inputs and produces a 16-byte output. If an expression's key is already in the cache, the script writes the cached result without evaluating the expression again.

The script must not evaluate more than 5 uncached expressions per second. For each uncached expression, before evaluating it, the script pauses as needed so that no more than 5 evaluations occur within any 1-second window. The cache file must be updated after each new result so that a later run can reuse it.
