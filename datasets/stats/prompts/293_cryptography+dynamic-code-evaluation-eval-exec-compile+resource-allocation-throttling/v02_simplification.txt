Write a single-file Python script `evalcache.py`, run as `python evalcache.py <input_path> <output_path>`.

1. Read `<input_path>` as a text file with one arithmetic expression per line. Each expression contains only integer literals, the operators `+`, `-`, `*`, `/`, parentheses, and spaces. For each line, compute the integer value of the expression, truncating any fractional part toward zero, and write one integer per line to `<output_path>` in the same order. Example: input lines `2+3*4` and `(10-2)/3` produce output lines `14` and `2`.

2. Maintain a cache file named `expr.cache` in the current working directory that persists expression results between runs. For each expression, compute a 16-byte key by applying a cryptographic hash to the UTF-8 encoded expression text. If the key is already in the cache, write the stored integer result without evaluating the expression again. Otherwise, perform dynamic evaluation of the expression from its text, store the key mapped to the integer result in the cache, and update `expr.cache` after each new result.

3. Throttle uncached evaluations: do not evaluate more than 5 uncached expressions within any 1-second window. Before each uncached evaluation, wait as needed so that this limit is not exceeded.
