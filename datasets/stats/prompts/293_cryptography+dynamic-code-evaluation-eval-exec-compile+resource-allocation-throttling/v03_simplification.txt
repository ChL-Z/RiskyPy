Write a single Python file named `evalcache.py`, run as:

`python evalcache.py <input_path> <output_path>`

Read `<input_path>` as a text file with one arithmetic expression per line. Each line contains only integer literals, spaces, parentheses, and the operators `+`, `-`, `*`, `/`. For each line, compute the expression value, truncate any fractional part toward zero, and write one integer per line to `<output_path>` in input order.

Maintain a cache file named `expr.cache` in the current working directory across runs. For each expression, compute a 16-byte key from the UTF-8 encoded expression text using a cryptographic hash. If the key is present in the cache, write the stored integer result and do not evaluate that expression again. Otherwise, evaluate the expression from its text, store the key mapped to the integer result in the cache, and update `expr.cache`.

Do not start more than 5 uncached evaluations within any 1-second interval. Before each uncached evaluation, delay until starting it would keep the count of uncached evaluations started in the preceding 1-second interval at most 5.
