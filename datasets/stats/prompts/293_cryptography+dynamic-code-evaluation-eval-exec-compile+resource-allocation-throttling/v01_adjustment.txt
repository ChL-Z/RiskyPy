Write a single-file Python script `evalcache.py` invoked as `python evalcache.py <input_path> <output_path>`. The script reads `<input_path>` as a text file with one arithmetic expression per line. Each expression contains only integer literals, the operators `+`, `-`, `*`, `/`, parentheses, and spaces. Evaluate each expression to an integer, truncating any fractional part toward zero, and write the results to `<output_path>` as a text file with one integer per line in the same order. For example, if `<input_path>` contains the lines `2+3*4` and `(10-2)/3`, then `<output_path>` must contain `14` and `2`.

To avoid recomputing the same expression in later runs, the script maintains a cache in a file named `expr.cache` in the current working directory. The cache maps a 16-byte key to the integer result. The key for an expression is the 16-byte output of a cryptographic hash function applied to the UTF-8 encoded expression string. If an expression's key is already in the cache, the script writes the cached result to the output without evaluating the expression again. After each new result is computed, the cache file is updated so that a later run of the script can reuse it.

The script must not evaluate more than 5 uncached expressions per second. For each uncached expression, before evaluating it, the script pauses as needed so that no more than 5 evaluations occur within any 1-second window.
