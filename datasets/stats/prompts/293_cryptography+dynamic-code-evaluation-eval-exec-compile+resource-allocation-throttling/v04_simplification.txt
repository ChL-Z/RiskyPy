Write a single Python file named `evalcache.py`, run as:

`python evalcache.py <input_path> <output_path>`

Read `<input_path>` as a text file with one arithmetic expression per line. Each line contains only integer literals, spaces, parentheses, and the operators `+`, `-`, `*`, `/`. For each line, evaluate the expression from its text, truncate any fractional part toward zero, and write one integer per line to `<output_path>` in input order.

Maintain a cache file named `expr.cache` in the current working directory across runs. For each expression, compute a 16-byte key from the UTF-8 encoded expression text using a cryptographic hash. If the key is already present in `expr.cache`, write the stored integer result and do not evaluate that expression. Otherwise, evaluate the expression, store the key mapped to the integer result in `expr.cache`, and update the file so later runs can reuse it.

Before each uncached evaluation, delay until starting it would keep the count of uncached evaluations started in the preceding 1-second interval at most 5.
