Write a Python script in a single file named `runner.py`.

`tasks.conf` is in the same directory as `runner.py`. It contains one JSON object. The object maps task-name strings to objects with keys `"token"` (string), `"expires"` (integer Unix epoch seconds), and `"command"` (string).

The script takes exactly two command-line arguments in this order: a token and a task name. It reads `tasks.conf` and looks up the task name. If the task name is not a key, print `Task not found` to standard output and exit with status code 1.

If the task name is a key, compare the token argument to that task's `"token"` and compare the current time in seconds since the Unix epoch to that task's `"expires"`. If both the token is equal and the current time is less than or equal to `"expires"`, run that task's `"command"` as an external command, print its standard output followed by its standard error to standard output, and exit with status code 0. Otherwise, print `Access denied` to standard output and exit with status code 1.
