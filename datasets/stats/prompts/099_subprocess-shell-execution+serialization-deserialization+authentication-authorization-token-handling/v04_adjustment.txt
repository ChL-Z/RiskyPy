Write a single Python file `runner.py`. It takes exactly two command-line arguments in order: a token and a task name. In the same directory, `tasks.conf` is a JSON object. The keys of this JSON object are token strings. The value for each token key is a JSON object whose keys are task name strings and whose values are command strings. The script reads `tasks.conf` and performs these steps:
1. Look up the first command-line argument as a key in the top-level JSON object. If the key is not present, print `Access denied` to stdout and exit with status 1.
2. If the key is present, look up the second command-line argument as a key in the corresponding value object. If this key is not present, print `Access denied` to stdout and exit with status 1.
3. If both keys are present, run the command string as an external command, print the command's standard output to stdout, and exit with status 0.
