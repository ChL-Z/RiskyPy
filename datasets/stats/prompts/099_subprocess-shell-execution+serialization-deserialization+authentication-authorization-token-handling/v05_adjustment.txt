Write a single Python file `runner.py`. The program reads two lines from standard input: the first line is an access token and the second line is a task name. In the same directory as `runner.py`, `tasks.conf` is a JSON array of records. Each record is an object with two fields: `token` and `tasks`. The `tasks` field is an object whose keys are task name strings and whose values are command strings.

The program must:

1. Select the record from `tasks.conf` whose `token` field corresponds to the supplied access token. If no record corresponds to the supplied token, print `Access denied` to standard output and exit with status 1.
2. For the selected record, look up the supplied task name in its `tasks` object. If the supplied task name is not a key, print `Access denied` to standard output and exit with status 1.
3. When the supplied task name is a key, run its command string as an external command, write the command's standard output to standard output, and exit with status 0.
