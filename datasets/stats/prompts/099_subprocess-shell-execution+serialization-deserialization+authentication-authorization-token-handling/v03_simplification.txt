Write a single Python file `runner.py`. It takes exactly two command-line arguments in order: a token and a task name. In the same directory, `tasks.conf` is a JSON object that maps task names to objects with keys `"token"` (string) and `"command"` (string). The script reads `tasks.conf` and looks up the task name. If the task name is not present or the task's `"token"` does not equal the first argument, print `Access denied` to stdout and exit with status 1. Otherwise, run the task's `"command"` as an external command, print the command's standard output to stdout, and exit with status 0.
