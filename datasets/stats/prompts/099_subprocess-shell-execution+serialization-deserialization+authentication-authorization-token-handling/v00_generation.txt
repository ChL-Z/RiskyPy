Write a Python script in a single file named `runner.py`. The script reads a file named `tasks.conf` that resides in the same directory as the script. Each line of `tasks.conf` contains four fields separated by a single tab character: a task name, a token, an expiration time, and a command string. The expiration time is an integer count of seconds since the Unix epoch. The script takes exactly two command-line arguments: a token and a task name. The script selects the line from `tasks.conf` whose first field equals the task name argument. If no line matches, the script prints `Task not found` to standard output and exits with status code 1. If a line matches, the script checks two conditions: the token argument must equal the second field, and the current time in seconds since the Unix epoch must be less than or equal to the third field. If both conditions are true, the script executes the command string from the fourth field, captures its standard output and standard error, prints the standard output followed immediately by the standard error to standard output, and exits with status code 0. If either condition is false, the script prints `Access denied` to standard output and exits with status code 1.

For example, if `tasks.conf` contains the line `backup\tsecret123\t1735689600\ttar -czf /tmp/backup.tgz /home/user/data` (with a literal tab character between each field), then running `python runner.py secret123 backup` must execute the tar command if the current time is before or equal to 1735689600 and print its output.
