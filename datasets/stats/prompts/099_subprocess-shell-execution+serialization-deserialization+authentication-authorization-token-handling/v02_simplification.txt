Write a single Python file `runner.py`. In the same directory, `tasks.conf` contains a JSON object that maps task names to objects with keys `"token"` (string) and `"command"` (string). The script takes exactly two command-line arguments in order: a token and a task name. It reads `tasks.conf`, looks up the task name, and if the name is missing it prints `Task not found` to stdout and exits with status 1. If the name is present and the task's `"token"` equals the first argument, it runs the task's `"command"` as an external command, prints the command's stdout followed by its stderr to stdout, and exits with status 0. Otherwise it prints `Access denied` to stdout and exits with status 1.
