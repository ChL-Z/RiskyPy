Write a Python program in one file named `access_report.py`.

The program takes exactly one command-line argument: the path to an XML configuration file. The XML file has a root element `<config>` containing one `<user>` element. The `<user>` element has attributes `name`, `path`, and `token_env`.

The program reads three lines from stdin, in order: a username, a token, and a file path. It reads the value of the environment variable named by the `token_env` attribute. If the username equals the `<user>` element's `name` attribute, the file path equals its `path` attribute, and the token equals that environment variable's value, then the program writes the entire contents of the file at that path to stdout. Otherwise, the program writes `DENIED` to stdout and exits with status code 1. If those three values match but the file at that path cannot be opened, the program writes `ERROR` to stdout and exits with status code 2.
