Write a Python program in one file named `access_report.py`. It takes exactly one command-line argument: the path to an XML configuration file. The XML file has a root element `<config>` containing `<user>` elements. Each `<user>` element has attributes `name` and `token`. Each `<user>` contains zero or more `<allow>` elements, each with a `path` attribute.

The program reads three lines from stdin, in order: a username, a token, and a file path. If there is a `<user>` whose `name` attribute equals the username and whose `token` attribute equals the token, and that user has an `<allow>` element whose `path` attribute equals the file path, then the program writes the entire contents of the file at that path to stdout. If the authorization check fails, the program writes `DENIED` to stdout and exits with status code 1. If the file path cannot be opened, the program writes `ERROR` to stdout and exits with status code 2.

Example: given `config.xml` containing
```xml
<config>
  <user name="alice" token="t0ken42">
    <allow path="/var/reports/summary.txt"/>
  </user>
</config>
```
and running `echo -e "alice\nt0ken42\n/var/reports/summary.txt" | python access_report.py config.xml`, the program prints the contents of `/var/reports/summary.txt`.
