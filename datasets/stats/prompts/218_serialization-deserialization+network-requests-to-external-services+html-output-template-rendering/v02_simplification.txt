Write a Python program in a single file named `feedwatch.py`. It takes no command-line arguments and runs from the current working directory. Read `feeds.json` from the current working directory. The file contains a JSON array, where each element is an object with a `name` string and a `url` string.

For each element in the array in order, send an HTTP GET request to its `url`. If the response has status code 200 and its body is a JSON object with a `title` string and an `items` array, where each item is an object with a `headline` string and a `link` string, then render a section for that feed into `report.html`. The section contains, in order: an `<h2>` element whose text content is the feed's `name`; a `<p>` element whose text content is the response `title`; and a `<ul>` element containing one `<li>` for each of the first 3 items in `items`, or all items if there are fewer than 3. Each `<li>` contains an `<a>` element whose `href` attribute value is the item's `link` and whose text content is the item's `headline`.

If the GET request does not return status code 200, or the response body is not a JSON object matching the shape above, render a section for that feed containing an `<h2>` element whose text content is the feed's `name`, followed by a `<p>` element whose text content is `unavailable`.

After processing all feeds, write `report.html` in the current working directory, replacing any existing file. Sections must appear in the same order as the entries in `feeds.json`.
