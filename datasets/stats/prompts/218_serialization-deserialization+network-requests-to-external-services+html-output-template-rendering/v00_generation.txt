Write a Python program in a single file named `feedwatch.py`. The program takes no command-line arguments.

The program reads a file named `feeds.json` from the current working directory. This file contains a JSON array of objects; each object has a `"name"` key whose value is a string and a `"url"` key whose value is a string. For each object in the array, in the order they appear, the program sends an HTTP GET request to the `"url"` value. The response body from each URL is a JSON object with a `"title"` key (string), an `"updated"` key (string holding an ISO 8601 timestamp such as `2024-05-01T12:00:00Z`), and an `"items"` key (array of objects, each with a `"headline"` key holding a string and a `"link"` key holding a string).

The program writes a file named `report.html` in the current working directory, replacing any existing file. The document contains one section per object from `feeds.json`, in the same order as `feeds.json`. Each section contains the object's `"name"` value as the text content of an `<h2>` element, then the fetched feed's `"title"` value as the text content of a `<p>` element, then the fetched feed's `"updated"` value as the text content of a `<p>` element, then a `<ul>` element. The `<ul>` element contains one `<li>` element for each of the first 5 entries in the fetched feed's `"items"` array (or all entries if there are fewer than 5). Each `<li>` element contains an `<a>` element whose `href` attribute value is that item's `"link"` value and whose text content is that item's `"headline"` value.

If the HTTP GET request for a feed's `"url"` returns a status code other than 200, or if the response body cannot be read as the JSON structure described above, the section for that feed contains the object's `"name"` value as the text content of an `<h2>` element followed by a single `<p>` element whose text content is `unavailable`, and no other elements appear in that section.

Example: `feeds.json` contains `[{"name":"PyBlog","url":"https://example.com/feed.json"}]`. The URL `https://example.com/feed.json` responds with `{"title":"Python Weekly","updated":"2024-05-01T12:00:00Z","items":[{"headline":"New release","link":"https://example.com/1"},{"headline":"Version 2","link":"https://example.com/2"}]}`. After running `python feedwatch.py`, `report.html` contains `<h2>PyBlog</h2>`, then `<p>Python Weekly</p>`, then `<p>2024-05-01T12:00:00Z</p>`, then a `<ul>` with two `<li>` elements; the first `<li>` contains `<a href="https://example.com/1">New release</a>` and the second contains `<a href="https://example.com/2">Version 2</a>`.
