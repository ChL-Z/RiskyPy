Write a Python program in a single file named `feedwatch.py`. The program takes no command-line arguments. In the current working directory, it reads `feeds.json`, which contains a JSON array. Each array element is an object with a `"name"` string and a `"url"` string.

For each array element in order, the program sends an HTTP GET request to the element's `"url"`. If the response has status code 200 and its body is a JSON object with a `"title"` string and an `"items"` array, where each item object has a `"headline"` string and a `"link"` string, the program writes one section to `report.html` for that element. The section contains an `<h2>` element with the element's `"name"` as its text content, then a `<p>` element with the response's `"title"` as its text content, then a `<ul>` element. The `<ul>` element contains one `<li>` element for each of the first 3 items in the response's `"items"` array, or all items if there are fewer than 3. Each `<li>` element contains an `<a>` element whose `href` attribute value is that item's `"link"` value and whose text content is that item's `"headline"` value.

Otherwise, the section contains an `<h2>` element with the element's `"name"` as its text content followed by a `<p>` element with the text content `unavailable`, and no other elements.

The program writes `report.html` in the current working directory, replacing any existing file. Sections appear in the same order as the elements in `feeds.json`.
