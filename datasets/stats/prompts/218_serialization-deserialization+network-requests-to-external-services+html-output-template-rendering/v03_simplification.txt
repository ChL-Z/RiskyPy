Write a Python program in a single file named `feedwatch.py`. It takes no command-line arguments and runs from the current working directory.

Read `feeds.json` from the current working directory. The file contains a JSON array with at least one object; each object has a `name` string and a `url` string. Use the first object.

Send an HTTP GET request to that `url`. If the response has status code 200 and its body is a JSON object with a `title` string and an `items` array, where each item is an object with a `headline` string and a `link` string, write `report.html` in the current working directory containing an `<h2>` whose text is the feed's `name`, a `<p>` whose text is the response `title`, and a `<ul>` with one `<li>` for each of the first 3 items in `items` (or all items if there are fewer than 3). Each `<li>` contains an `<a>` whose `href` attribute is the item's `link` and whose text is the item's `headline`. Otherwise, write `report.html` containing an `<h2>` whose text is the feed's `name` followed by a `<p>` whose text is `unavailable`. Replace any existing `report.html`.
