Write a Python program in a single file named `check_runner.py`. The program is invoked as `python check_runner.py <config.xml> <database.db>`. It reads an XML configuration file and a SQLite database file, then writes one JSON object to stdout.

The XML configuration has a root element `<checks>` containing one or more `<check>` elements. Each `<check>` has attributes `name` and `type`. The `type` attribute is either `command` or `sql`. For `type="command"`, the element text is a command line. For `type="sql"`, the element text is a SQL query. Process the `<check>` elements in the order they appear in the XML document. The SQL queries in the provided configurations return only text, integer, real, and NULL values.

For each `command` check, run the command line with the same interpretation as a POSIX shell command line. Capture the complete standard output as UTF-8 text, the complete standard error as UTF-8 text, and the exit code. Add to the JSON `"checks"` array an object with keys `"name"`, `"type"` set to `"command"`, `"exit_code"` as an integer, `"stdout"` as a string, and `"stderr"` as a string.

For each `sql` check, execute the element text as a query against the SQLite database file. Add to the JSON `"checks"` array an object with keys `"name"`, `"type"` set to `"sql"`, and `"rows"` as an array of arrays, where each inner array contains the values from one result row in the order the database returns them for the query. Encode database NULL values as JSON null. Encode text values as JSON strings, integer values as JSON numbers, and real values as JSON numbers.

The JSON object has one top-level key `"checks"` whose value is the array of check result objects.

Example:
config.xml:
<checks>
  <check name="whoami" type="command">whoami</check>
  <check name="first_user" type="sql">SELECT id, name FROM users ORDER BY id LIMIT 1</check>
</checks>
Invocation:
python check_runner.py config.xml app.db
If `whoami` exits 0 and prints `alice`, and the query returns one row `(1, 'Alice')`, stdout is:
{"checks":[{"name":"whoami","type":"command","exit_code":0,"stdout":"alice\n","stderr":""},{"name":"first_user","type":"sql","rows":[[1,"Alice"]]}]}
