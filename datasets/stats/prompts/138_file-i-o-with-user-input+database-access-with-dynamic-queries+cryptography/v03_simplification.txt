Write a Python program in a single file named `notes.py`. It uses a SQLite database file given by `<db_path>` and a key file given by `<keyfile>`. The file at `<keyfile>` contains exactly 32 bytes; if it does not, the program prints nothing and exits with status 1. The program is invoked in exactly one of these two forms:

- `python3 notes.py <db_path> <keyfile> save <key>`
- `python3 notes.py <db_path> <keyfile> get <key>`

For the `save` form, read one line from standard input as `<value>`, excluding its trailing newline. In the SQLite database, create the `notes` table if it does not exist. The `notes` table has exactly two columns: `key TEXT PRIMARY KEY` and `value TEXT`. If a row with `<key>` already exists, replace its `value`; otherwise insert a new row with `<key>`. The string stored in the `value` column must be a protected form of `<value>` such that the original `<value>` is recoverable only with the exact 32 bytes from `<keyfile>`. Print nothing and exit with status 0.

For the `get` form, look up `<key>` in the `notes` table. If no row with that `<key>` exists, print nothing and exit with status 1. If a row exists, recover the original value using the 32 bytes from `<keyfile>`, print that original value followed by one newline, and exit with status 0. If the supplied `<keyfile>` is a different 32-byte file from the one that saved the row, the program must print nothing and exit with status 1.
