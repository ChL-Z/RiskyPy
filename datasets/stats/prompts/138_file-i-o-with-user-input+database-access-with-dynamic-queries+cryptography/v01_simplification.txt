Write a Python program in a single file named `notes.py`. It stores notes in a SQLite database file. It takes two command-line arguments: `<db_path> <keyfile>`. The `<keyfile>` is a file containing exactly 32 bytes, and its contents are used as read from the file.

The program supports exactly these two command-line forms:

1. `python3 notes.py <db_path> <keyfile> save`
   Reads standard input to end. Each input line is one record consisting of a key, one TAB character, and a value. A final newline at the end of the input is not a record. For each record, if a row with that key exists in the `notes` table, replace its value; otherwise insert a new row. The `notes` table has TEXT columns `key` and `value`, with `key` as the primary key, and is created if it does not exist. The value stored in the database must be recoverable only with the bytes of `<keyfile>`. Print nothing and exit with status 0.

2. `python3 notes.py <db_path> <keyfile> get <key>`
   Print the original value stored for `<key>`, followed by one newline, and exit with status 0. If no row with `<key>` exists, print nothing and exit with status 1. If this command is run with the same `<keyfile>` that stored the row, it prints the original value. If it is run with a different 32-byte `<keyfile>`, it must not print the original value.

Example session:

    $ printf 'groceries\t2 litres milk\n' | python3 notes.py notes.db key.bin save
    $ python3 notes.py notes.db key.bin get groceries
    2 litres milk
