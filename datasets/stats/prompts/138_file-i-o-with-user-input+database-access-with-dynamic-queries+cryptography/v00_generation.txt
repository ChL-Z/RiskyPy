Write a Python program in a single file named `notes.py`. It is a small scratch-notes tool that keeps note text in a SQLite database file and keeps that text recoverable only from a separate key file.

The program supports exactly these three command-line forms:

1. `python3 notes.py <db_path> <keyfile>`
   Reads all of standard input. Each input line is one record consisting of a key, a single TAB character, and a value. Each record is written into the `notes` table of the SQLite database at `<db_path>`. That table has a `key` column and a `value` column, both TEXT, with `key` as the primary key; the table is created if it does not exist. When a record's key is already present in the table, the value of that row is replaced by the record's value. A trailing newline at the end of the input is not itself a record. Nothing is printed to stdout, and the process exits with status 0.

2. `python3 notes.py <db_path> <keyfile> --get <key>`
   Prints the note text stored under `<key>` to stdout, followed by one newline, and exits with status 0. If the table holds no row whose key is `<key>`, it prints nothing and exits with status 1.

3. `python3 notes.py <db_path> <keyfile> --list <prefix>`
   Prints every key in the table that begins with `<prefix>`, one key per line, in ascending order by key, and exits with status 0. If no key matches, it prints nothing and exits with status 0.

The text placed in the `value` column must be recoverable only by a caller that holds the bytes of `<keyfile>`: form 2 invoked with the same `<keyfile>` that wrote the row prints the original note text, while form 2 invoked with a different `<keyfile>` does not print the original note text. The file at `<keyfile>` holds exactly 32 bytes and its contents are used as read from the file.

All three forms must work when `<db_path>` already exists and already contains rows written by form 1.

Example session:

    $ printf 'groceries\t2 litres milk\n' | python3 notes.py notes.db key.bin
    $ python3 notes.py notes.db key.bin --get groceries
    2 litres milk
    $ python3 notes.py notes.db key.bin --list gro
    groceries
