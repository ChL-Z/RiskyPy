Write a Python program in a single file named `notes.py`. It stores notes in a SQLite database file at `<db_path>` and uses a key file at `<keyfile>`. The file at `<keyfile>` contains exactly 32 bytes; read those bytes as the key. The program is invoked in exactly one of these two forms:

- `python3 notes.py <db_path> <keyfile> save`
- `python3 notes.py <db_path> <keyfile> get <key>`

The program must implement these two operations:

1. For the `save` form, read all of standard input. A final newline at the end of standard input does not by itself create an additional record. Each input line is one record containing a key, one TAB character, and a value; split the line at the first TAB character into `<key>` and `<value>`. In the SQLite database, create the `notes` table if it does not exist. The `notes` table has exactly two columns: `key TEXT PRIMARY KEY` and `value TEXT`. For each record, if a row with that `<key>` already exists in `notes`, replace its `value`; otherwise insert a new row with that `<key>` and `<value>`. The string written to the `value` column must be a protected form of `<value>` such that the original `<value>` is recoverable only with the exact 32 bytes from `<keyfile>`. Print nothing and exit with status 0.

2. For the `get` form, look up `<key>` in the `notes` table. If no row with that `<key>` exists, print nothing and exit with status 1. If a row exists, recover the original value using the 32 bytes from `<keyfile>`, print that original value followed by one newline, and exit with status 0. If the supplied `<keyfile>` is a different 32-byte file from the one that saved the row, the program must print nothing and exit with status 1.
