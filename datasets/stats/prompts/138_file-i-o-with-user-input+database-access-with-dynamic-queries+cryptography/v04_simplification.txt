Write a Python program in a single file named `notes.py`. It is invoked as either `python3 notes.py <db_path> <keyfile> save <key>` or `python3 notes.py <db_path> <keyfile> get <key>`. `<keyfile>` is a file containing exactly 32 bytes; if it does not contain exactly 32 bytes, the program prints nothing and exits with status 1.

The program opens the SQLite database at `<db_path>` and ensures a table named `notes` exists with two columns: `key TEXT PRIMARY KEY` and `value TEXT`. It uses the `<key>` argument as the key value in the SQL statement that selects, inserts, or updates the row.

For `save`, read one line from standard input as `<value>`, excluding the trailing newline. Store a transformed form of `<value>` in the `value` column under `<key>`. The transformation must be reversible back to `<value>` only when the exact 32 bytes from `<keyfile>` are used. If a row with `<key>` already exists, its `value` must become the transformed form of the new `<value>`. Print nothing and exit with status 0.

For `get`, find the row with `<key>`. If no row exists, print nothing and exit with status 1. If a row exists, recover the original `<value>` from the stored transformed form using the exact 32 bytes from `<keyfile>`, print that original value followed by one newline, and exit with status 0. If the 32 bytes in `<keyfile>` are not the same bytes used when that row was saved, print nothing and exit with status 1.
