Write a Python script in a single file named `query_tool.py`. It takes two command-line arguments in this order: the path to a SQLite database file and the path to a JSON file. The JSON file contains an object with keys `table` and `where`. `table` is a string. `where` is an object whose keys are column names and whose values are the values to match. The script selects all columns from `table`, adding an equality condition for each key-value pair in `where` and joining those conditions with AND. If `where` is an empty object, select all rows from `table`. Execute the statement against the SQLite database. Print the rows to stdout as a JSON array. Each row is a JSON object mapping column names to their values. If no rows are returned, print `[]`. Do not print any other text to stdout.
