Write a Python script in a single file named `query_tool.py`. It takes one command-line argument: the path to a SQLite database file. It reads a JSON object from stdin with two keys: `table` (a string) and `where` (a JSON object mapping column names to string values). The script selects every column from `table`, adding one equality condition for each key-value pair in `where`, joined with `AND`. If `where` is an empty object, it selects all rows from `table`. It prints to stdout a JSON array. Each element is a JSON array containing the row's column values in the order returned by the query. If no rows are returned, it prints `[]`. It prints no other text to stdout.
