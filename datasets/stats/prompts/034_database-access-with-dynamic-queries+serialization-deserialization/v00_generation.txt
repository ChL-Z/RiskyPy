Write a Python script in a single file named `query_tool.py`. The script reads a JSON query description and executes it against a SQLite database, printing the results as JSON.

The script takes two command-line arguments:
1. The path to a SQLite database file.
2. The path to a JSON file containing a query description.

The JSON query description is an object with these keys:
- `table` (string, required): the table name to select from.
- `columns` (list of strings, optional): the column names to select. If omitted, select all columns in the order they appear in the table schema.
- `where` (object, optional): a mapping of column names to values. Each key-value pair adds an equality condition. If omitted or empty, no filter is applied.
- `order_by` (string, optional): a column name to sort the results by in ascending order. If omitted, no ordering is applied.

Implement the following requirements:

1. Read the two command-line arguments and parse the JSON query file.
2. Construct and execute a SQL SELECT statement against the SQLite database using the provided table, columns, where conditions, and order_by.
3. Print the resulting rows to stdout as a JSON array. Each row is a JSON object mapping column names to values. SQLite integer and real values become JSON numbers, text becomes JSON strings, and null becomes JSON null. If the query returns no rows, print an empty JSON array `[]`. Do not print any other text to stdout.

Example:
```
$ python query_tool.py inventory.db query.json
```
where `query.json` contains:
```json
{
  "table": "products",
  "columns": ["id", "name", "price"],
  "where": {"category": "tools"},
  "order_by": "price"
}
```
and `inventory.db` has a `products` table. The output might be:
```json
[{"id": 3, "name": "Hammer", "price": 12.5}, {"id": 7, "name": "Wrench", "price": 8.0}]
```
