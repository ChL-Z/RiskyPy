Write a Python script in a single file named `query_tool.py`. It takes one command-line argument: the path to a SQLite database file. It reads a JSON object from stdin with exactly two keys: `table` (a string) and `where` (a JSON object with zero or one key). The selected table is the one named by `table`. Select all columns from that table. If `where` is empty, select all rows. If `where` has one key, select rows where that column equals its value. Print to stdout a JSON array. Each element is a JSON array containing the row's column values in the order returned by the query. If no rows are selected, print `[]`. Print no other text to stdout.
