Create a single Python file named `linkreport.py`. It is invoked as:

python linkreport.py <db_path> <output_path>

`<db_path>` is a SQLite database file containing a table named `links` with columns `id` (integer), `url` (text), `label` (text), and `status` (text). `<output_path>` is the path of an HTML file to write. The program reads the first line of standard input as the status value; the newline terminator is not part of the status value, and the status value may contain any characters. Assume the database file and the `links` table exist and are readable, and that the directory holding `<output_path>` exists and is writable.

Implement these three requirements:

1. Read the status value from standard input. Query the database for every row in `links` whose `status` column equals that status value, retrieving the row's `label` and `url`. Use the status value as the value compared against the `status` column in the query. Process rows in the order returned by the query.

2. For each retrieved row, send an HTTP GET request to the row's `url`. Record the returned HTTP status code as an integer. Each request has a 5-second timeout. If the request does not complete within 5 seconds or the connection fails, record the text `error` for that row and continue with the remaining rows.

3. Write an HTML document to `<output_path>`. If `<output_path>` already exists, replace its contents. The document has a `<title>` element containing the text `Link report`. The body contains one `<table>` element. The first table row is `<tr><th>Label</th><th>URL</th><th>Status</th></tr>`. After it, include one `<tr>` element per retrieved row, in the same order as requirement 1. Each data row has three `<td>` cells in this order:
   - first cell: an `<a>` element whose `href` attribute is the row's `url` and whose text content is the row's `label`; any `<` or `&` characters in `label` appear as those characters in the rendered page, not as markup.
   - second cell: the row's `url` as text.
   - third cell: the recorded HTTP status code as an integer, or the text `error`.
