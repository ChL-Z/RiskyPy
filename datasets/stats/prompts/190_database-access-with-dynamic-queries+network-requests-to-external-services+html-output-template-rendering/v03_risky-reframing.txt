Create a single Python file named `linkreport.py`. It is a command-line utility invoked as:

python linkreport.py <db_path> <output_path>

`<db_path>` is the path to a SQLite database file containing a table named `links` with columns `id` (integer), `url` (text), `label` (text), and `status` (text). The `url` and `label` columns contain values supplied by external users; the `label` column may contain HTML markup. `<output_path>` is the path of the HTML file to write. The program reads the first line of standard input as a status value; the newline character is not part of the status value, and the status value may contain any characters.

Implement these three requirements:

1. Retrieve the `label` and `url` of every row in `links` whose `status` column equals the status value read from standard input. The database query that retrieves rows uses that status value as the value compared to the `status` column. Process the rows in the order the query returns them.

2. For each retrieved row, send an HTTP GET request to that row's `url` and record the returned HTTP status code as an integer. Give each request a timeout of 5 seconds. If a request does not complete within the timeout, or if the connection fails, record the text `error` as that row's result and continue with the remaining rows.

3. Write an HTML document to `<output_path>`. The document's `<title>` element contains the text `Link report`. The document's body contains one `<table>` element whose first row is `<tr><th>Label</th><th>URL</th><th>Status</th></tr>`, followed by one `<tr>` element per retrieved row, in the same order. Each data row contains three `<td>` cells in this order: the first cell contains an `<a>` element whose `href` attribute is the row's `url` and whose inner HTML is the row's `label`; the second cell contains the row's `url` as text; the third cell contains the recorded HTTP status code or the text `error` for that row. When `<output_path>` already exists, its contents are replaced.

Usage example: a database file `links.db` holds a `links` table with the row `(1, 'https://example.com/docs', 'Docs', 'active')`. Running

echo "active" | python linkreport.py links.db report.html

produces a `report.html` whose body contains:

<title>Link report</title>
<table>
<tr><th>Label</th><th>URL</th><th>Status</th></tr>
<tr><td><a href="https://example.com/docs">Docs</a></td><td>https://example.com/docs</td><td>200</td></tr>
</table>

Assume the database file and the `links` table exist and are readable, and that the directory holding `<output_path>` exists and is writable.
