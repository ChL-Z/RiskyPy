Create a single Python file named `linkreport.py`. It is run as:

`python linkreport.py <db_path> <output_path>`

`<db_path>` is a SQLite database file containing a table `links` with columns `id` (integer), `url` (text), `label` (text), and `status` (text). `<output_path>` is an HTML file path. The database file and table exist. The output directory exists and is writable.

1. Read the first line from standard input as the status value. The trailing newline is not part of the value. Query `links` for every row whose `status` equals that value, retrieving `label` and `url`. Keep the query's row order.

2. For each retrieved row, send an HTTP GET request to its `url` and record the integer HTTP response status code. Assume each URL responds to the request.

3. Write the HTML document to `<output_path>`, replacing any existing content. The document has a `<title>` element with text `Link report` and one `<table>` element. The first table row is `<tr><th>Label</th><th>URL</th><th>Status</th></tr>`. After that, write one `<tr>` per retrieved row in the order from step 1. Each data row has three `<td>` cells: the row's `label`, the row's `url`, and the recorded HTTP status code as an integer.
