Write a Python program in a single file named `jobrunner.py`. It is a command-line tool that pulls pending jobs from an HTTP API, runs each job's command on the local machine, and reports the outcome back to the API.

The program takes exactly one command-line argument: the path to a JSON configuration file. The configuration file holds these keys:

```json
{
  "api_base_url": "https://ci.example.com/api/v1",
  "token_env_var": "CI_API_TOKEN",
  "working_dir": "/tmp/jobs",
  "timeout_seconds": 30
}
```

The API token is read from the environment variable whose name is given by the `token_env_var` value.

Requirement 1 — Fetch pending jobs. Send an HTTP GET request to `<api_base_url>/jobs?status=pending` carrying the header `Authorization: Bearer <token>`. The response body is JSON in the form `{"jobs": [{"id": "j-101", "command": "pytest -q"}, {"id": "j-102", "command": "make lint"}]}`. Each element's `command` value is a command line to run.

Requirement 2 — Run each command. For every job returned, run its `command` value with `working_dir` as the current working directory, wait for it to finish, and record its exit code, its standard output text, and its standard error text. If the command has not finished after `timeout_seconds` seconds, stop it, and record `timed_out` as true for that job; otherwise record `timed_out` as false.

Requirement 3 — Report each result. For every job, send an HTTP POST request to `<api_base_url>/jobs/<id>/result` carrying the same `Authorization` header, a `Content-Type: application/json` header, and a JSON body with exactly these keys: `exit_code` (integer, or null when `timed_out` is true), `stdout` (string), `stderr` (string), `timed_out` (boolean). After each report, print one line to standard output consisting of the job id, a single space, and then the exit code as an integer, or the text `timeout` in place of the exit code when the command was stopped.

Usage example:

```
CI_API_TOKEN=abc123 python jobrunner.py config.json
```

Expected standard output for a single job `j-101` that exits with code 0:

```
j-101 0
```
