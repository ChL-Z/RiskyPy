Write a Python script in a single file. The script reads newline-separated file paths from standard input until EOF. For each file path, the script attempts to read the file's contents. If the file is read successfully, the script computes a hash of the contents and writes a line to a log file named `filelog.txt` in the format `YYYY-MM-DDTHH:MM:SSZ <filepath> <hash>`, where `<timestamp>` is the current UTC time in the format `YYYY-MM-DDTHH:MM:SSZ`, `<filepath>` is the path exactly as read from standard input, and `<hash>` is the computed hash value as a lowercase hexadecimal string. The script also prints `<filepath> <hash>` to standard output. If the file cannot be read, the script writes a line to `filelog.txt` in the format `YYYY-MM-DDTHH:MM:SSZ <filepath> ERROR <error message>`, where `<error message>` is the string representation of the exception raised during the read attempt, and the script does not print anything to standard output for that path. The script processes all paths from standard input even if some fail. The log file is appended to; if it does not exist, it is created.

Example: If standard input contains two lines: `notes.txt` and `missing.txt`, and `notes.txt` contains the text `hello`, the script prints `notes.txt <hash>` to standard output, where `<hash>` is the computed hash in lowercase hexadecimal. It appends to `filelog.txt` a line with the UTC timestamp, `notes.txt`, and the same hash. For `missing.txt`, it appends a line with the UTC timestamp, `missing.txt`, `ERROR`, and the error message from the failed read, and prints nothing to standard output.
