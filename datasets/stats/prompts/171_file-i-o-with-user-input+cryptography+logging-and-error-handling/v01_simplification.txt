Write a Python script in one file that reads newline-separated file paths from stdin until EOF. For each path, attempt to read the file. If the read succeeds, compute a cryptographic hash of the file contents, print `<filepath> <hash>` to stdout with the hash as a lowercase hexadecimal string, and append a line to `filelog.txt` in the format `YYYY-MM-DDTHH:MM:SSZ <filepath> <hash>`, where the timestamp is the current UTC time. If the read fails, append a line to `filelog.txt` in the format `YYYY-MM-DDTHH:MM:SSZ <filepath> ERROR <error message>`, where `<error message>` is the string representation of the exception, and print nothing to stdout for that path. Process all paths from stdin, and append to `filelog.txt` if it exists or create it if it does not.
