Create a Python 3 script in a single file. The script reads `input_paths.txt` from the current working directory. Each line contains one file path with no leading or trailing whitespace. At the start, create or overwrite `manifest.txt` and `digest.log`. For each path in the order read, if the path is an existing file that can be opened for reading, compute a hexadecimal digest of the file contents, write one line to `manifest.txt` in the form `<path>` followed by a tab character followed by the hexadecimal digest, and write one line to `digest.log` in the form `INFO Processed <path>`. If the path does not exist, write `ERROR Missing file: <path>` to `digest.log`. If the path exists but cannot be opened for reading, write `ERROR Unreadable file: <path>` to `digest.log`. Do not write a manifest line for a path that does not exist or cannot be opened for reading. After all paths, write one line to `digest.log` in the form `Completed: <n> processed, <m> errors`, where `<n>` is the number of lines written to `manifest.txt` and `<m>` is the number of lines written to `digest.log` that start with `ERROR`. The script takes no command-line arguments.
