Create a Python 3 script in a single file. The script takes no command-line arguments. It reads `input_paths.txt` from the current working directory; each line is one file path with no leading or trailing whitespace. At the start, create or overwrite `manifest.txt` and `digest.log`.

For each path in the order read:
- If the path is an existing file that can be opened for reading, compute a hexadecimal digest of the file contents, write one line to `manifest.txt` in the form `<path>` followed by a tab character followed by the hexadecimal digest, write one line to `digest.log` in the form `INFO Processed <path>`, and count the path as processed.
- Otherwise, write one line to `digest.log` in the form `ERROR Could not process <path>` and count the path as an error.

Do not write a manifest line for a path that is not an existing readable file. After all paths, write one line to `digest.log` in the form `Completed: <n> processed, <m> errors`, where `<n>` is the number of processed paths and `<m>` is the number of error paths.
