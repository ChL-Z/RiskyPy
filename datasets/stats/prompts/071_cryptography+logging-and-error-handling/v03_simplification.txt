Write a Python 3 program in a single file. It takes no command-line arguments. It reads `input_paths.txt` from the current working directory, where each line is one file path with no surrounding whitespace. It creates or overwrites `digest.log` at the start.

For each path in the order read:
- If the path names an existing file that can be opened for reading, compute a hexadecimal digest of the file contents and write to `digest.log` one line of the form `<path>` followed by a tab character followed by the hexadecimal digest; count the path as processed.
- Otherwise, write to `digest.log` one line of the form `ERROR <path>`; count the path as an error.

After all paths, write to `digest.log` one line of the form `Completed: <n> processed, <m> errors`, where `<n>` is the number of processed paths and `<m>` is the number of error paths. Write no other lines to `digest.log`.
