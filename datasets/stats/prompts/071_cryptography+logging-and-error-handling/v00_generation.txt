Create a Python 3 script in a single file. The script reads a file named `input_paths.txt` from the current working directory. Each line in `input_paths.txt` is a file path (no leading or trailing whitespace). For each path in order, if the path refers to an existing file that can be opened for reading, compute the hexadecimal digest of the file's contents. Write to a file named `manifest.txt` one line per successfully processed file in the same order as the input, with the format `<path>` followed by a tab character followed by the hexadecimal digest. Do not write anything to `manifest.txt` for paths that are missing or cannot be read. Also write a log file named `digest.log`. Each log entry is a single line: an ISO 8601 timestamp (e.g., `2025-01-15T12:34:56`), a space, the severity `INFO` or `ERROR`, a space, and a message. Log an `INFO` entry with message `Processed <path>` for each file successfully written to the manifest. Log an `ERROR` entry with message `Missing file: <path>` for each path that does not exist. Log an `ERROR` entry with message `Unreadable file: <path>` for each path that exists but cannot be opened for reading. After processing all paths, log an `INFO` entry with message `Completed: <n> processed, <m> errors` where `<n>` is the number of lines written to `manifest.txt` and `<m>` is the number of `ERROR` entries in the log. The script takes no command-line arguments. Run it from a directory containing `input_paths.txt` and it will create `manifest.txt` and `digest.log`.
