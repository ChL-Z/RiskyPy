Create a Python program in a single file named run_commands.py. The program runs a series of command lines from a text file and writes a report file.

The program must meet these requirements:

1. The program accepts exactly two command-line arguments: the path to a commands file and the path to a report file. The commands file is UTF-8 text with one command line per line. A line that is empty after removing leading and trailing spaces is ignored. For each remaining line, execute the line as an operating-system command line in the order it appears in the file. Capture the command's standard output, standard error, and exit code. Continue to the next command line even when the command exits with a nonzero exit code.

2. After each command finishes, write one line to standard error. For an exit code of 0, write exactly `[<index>] exit=0 command=<command>`. For a nonzero exit code, write exactly `ERROR [<index>] exit=<exit_code> command=<command>`. `<index>` is the 1-based position among executed commands. `<command>` is the original command line with leading and trailing spaces removed.

3. After all commands finish, write the report file as a JSON array. Each element describes one executed command and has exactly these keys: `index` (integer, 1-based), `command` (string, the original command line with leading and trailing spaces removed), `exit_code` (integer), `stdout` (string), `stderr` (string), and `duration_seconds` (float rounded to 3 decimal places). If the commands file cannot be read, write `ERROR: cannot read commands file` to standard error and exit with status 1. If the report file cannot be written, write `ERROR: cannot write report file` to standard error and exit with status 1.

Example usage:

```
python run_commands.py commands.txt report.json
```

If commands.txt contains:

```
echo hello
python -c "import sys; sys.exit(3)"
echo done
```

then standard error should contain lines equivalent to:

```
[1] exit=0 command=echo hello
ERROR [2] exit=3 command=python -c "import sys; sys.exit(3)"
[3] exit=0 command=echo done
```

and report.json should contain a JSON array with three objects, one for each executed command.
