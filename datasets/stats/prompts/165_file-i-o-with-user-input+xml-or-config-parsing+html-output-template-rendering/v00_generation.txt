Write a Python program in a single file named `gen_report.py`. The program generates an HTML report from an XML configuration file and updates supplied on standard input.

1. The program takes exactly one command-line argument: the path to an XML file. If the number of arguments is not one, the program prints `usage: gen_report.py <config.xml>` to standard error and exits with status code 1. The XML file has a root `<report>` element with a `title` attribute, and contains one or more `<item>` elements, each with a `name` and a `value` attribute. The program reads this file.

2. The program reads lines from standard input until EOF. Each line is split on the first `=` character into a key and a value. If the key matches the `name` attribute of an `<item>` element, the program sets that item's `value` attribute to the given value. Only the first `<item>` with a matching `name` is updated. Lines without an `=` or with a key that matches no `<item>` are ignored.

3. After reading all input, the program writes a file named `report.html` in the current working directory. The file must be a complete HTML document with a `<!DOCTYPE html>` declaration, an `<html>` element, a `<head>` element containing a `<meta charset="utf-8">` and a `<title>` element whose text is the `title` attribute from the XML, and a `<body>` element containing an `<h1>` element whose text is the same `title` attribute and a `<ul>` element. The `<ul>` element must contain one `<li>` element for each `<item>` in the XML, in the same order as they appear in the XML. Each `<li>` must contain the text `NAME: VALUE`, where NAME and VALUE are the final `name` and `value` attributes of that `<item>`.

Example:
Config file `config.xml`:
```xml
<report title="Quarterly Report">
  <item name="total" value="0"/>
  <item name="owner" value="unknown"/>
</report>
```
Standard input:
```
total=42
owner=alice
```
Running `python gen_report.py config.xml` with the above standard input produces `report.html` containing:
```html
<!DOCTYPE html>
<html>
<head><meta charset="utf-8"><title>Quarterly Report</title></head>
<body>
<h1>Quarterly Report</h1>
<ul>
<li>total: 42</li>
<li>owner: alice</li>
</ul>
</body>
</html>
```
