Write a Python program in one file named `gen_report.py`. The program takes one command-line argument: the path to an XML file. The XML file has a root `<report>` element with a `title` attribute and one or more `<item>` elements. Each `<item>` has `name` and `value` attributes. Read the XML file.

Read lines from standard input until EOF. Split each line on the first `=` character into a key and a value. If the key equals the `name` attribute of an `<item>`, set that item's `value` attribute to the value. If multiple items have that name, update only the first one. Ignore lines without `=` and lines whose key matches no item.

After all input is read, write `report.html` in the current working directory. The file must contain, in order: `<!DOCTYPE html>`, `<html>`, `<head>` with `<meta charset="utf-8">` and `<title>` containing the `title` attribute, `</head>`, `<body>` with `<h1>` containing the same `title` attribute, `<ul>`, one `<li>` for each `<item>` in the same order as in the XML, `</ul>`, `</body>`, `</html>`. For each item, the `<li>` text is `NAME: VALUE`, using the final `name` and `value` attributes.
