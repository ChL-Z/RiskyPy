Write a Python program in a single file named `fetch_usage.py`. It reads newline-separated customer IDs from stdin. It accepts an optional `--product` argument. For each customer ID:

1. Query the `accounts` table in the SQLite database file `billing.db`. The table has columns `customer_id`, `product`, `api_key`, `api_secret`. Select the row where `customer_id` equals the input value. If `--product` is provided, also require `product` equals the argument value. If no row matches, print `<customer_id> NOT_FOUND` and continue to the next customer ID.

2. For a matched row, send a GET request to `https://billing.example.com/v1/usage/<customer_id>`. Include the header `X-Api-Key` with the row's `api_key` value. If `--product` is provided, include the query parameter `product=<product>`. The response body is JSON with the key `usage` whose value is a number. Print `<customer_id> <usage> <signature>`. `<signature>` is the lowercase hexadecimal encoding of a keyed signature over the UTF-8 string `<customer_id>:<usage>` using the row's `api_secret` value as the key.

Example: with `billing.db` containing the row `('cust-1', 'pro', 'key123', 'secret456')`, running `printf 'cust-1\ncust-2\n' | python fetch_usage.py --product pro` and receiving `{"usage": 42}` from the service for `cust-1` prints `cust-1 42 <signature>` followed by `cust-2 NOT_FOUND`.
