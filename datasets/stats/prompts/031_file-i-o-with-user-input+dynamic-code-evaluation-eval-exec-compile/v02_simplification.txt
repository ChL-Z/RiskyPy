Write a Python program in one file named `render_template.py`.

Read all input from stdin. The first line is the path to a UTF-8 template file. The second line is the path to a UTF-8 output file. Each remaining line has the form `name = expression`. `name` is a sequence of one or more letters. An expression contains only integer literals, the operators `+`, `-`, `*`, `/`, parentheses, and names defined on earlier assignment lines. Compute each expression in the order the assignment lines appear, and store its value under that name.

Read the template file. A placeholder starts with `{{`, ends with `}}`, and contains an expression between them. No spaces appear inside the braces. Replace each placeholder with the computed value of its expression, converted to a string. Replace every placeholder in the template. Write the resulting text to the output file with no trailing newline added. Print nothing to stdout.
