Write a Python program in one file named `render_template.py`.

Read all input from stdin. The first line is the path to a UTF-8 template file. The second line is the path to a UTF-8 output file. Each remaining line has the form `name = expression`. `name` is a sequence of one or more letters, digits, or underscores that starts with a letter or underscore. `expression` uses integer literals, decimal literals, the operators `+`, `-`, `*`, `/`, parentheses, and any `name` defined on an earlier assignment line. Compute each expression in the order the lines appear and store its value under that name.

Read the template file. A placeholder starts with `{{`, ends with `}}`, and contains an expression between them; spaces immediately after `{{` and immediately before `}}` are ignored. Replace each placeholder with `str(value)` of the expression, using the names computed from stdin. Replace every placeholder in the template. Write the resulting text to the output file with no extra newline at the end. Print to stdout the number of replaced placeholders as a single integer followed by a newline.
