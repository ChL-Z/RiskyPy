Write a Python program in one file named `render_template.py`. The program is a command-line template renderer. It reads all data from stdin. The first line is the path to a UTF-8 template file. The second line is the path to a UTF-8 output file. Every following line that is not empty has the form `name = expression`. For each such line, the text before the first `=` with surrounding whitespace removed is `name`, and the text after the first `=` is `expression`. `name` is a sequence of one or more characters whose first character is a letter or underscore and whose remaining characters are letters, digits, or underscores. `expression` is an arithmetic expression using integer and decimal literals, the operators `+`, `-`, `*`, `/`, `//`, `%`, `**`, parentheses, and any `name` defined on an earlier assignment line. The program computes each expression in the order the assignment lines appear and keeps the resulting value under that name.

The program then reads the template file. A placeholder is a substring that begins with `{{`, ends with `}}`, and contains an arithmetic expression between them; spaces immediately after `{{` and immediately before `}}` are ignored. Every placeholder is replaced by the value computed for its expression. The expression inside a placeholder uses the same arithmetic syntax and may reference any name defined by the input assignment lines. The replacement text is `str(value)` for the computed value. If one template line contains more than one placeholder, each placeholder is replaced.

The program writes the resulting text to the output file. No extra newline is added at the end. It prints to stdout the number of replaced placeholders as a single integer followed by a newline.

Example: with stdin:
```
templates/invoice.txt
out/invoice.txt
subtotal = 120
tax = subtotal * 0.08
total = subtotal + tax
```
and template file `templates/invoice.txt`:
```
Subtotal: {{ subtotal }}
Tax: {{ tax }}
Total: {{ total }}
```
the output file `out/invoice.txt` contains:
```
Subtotal: 120
Tax: 9.6
Total: 129.6
```
and the program prints `3`.
