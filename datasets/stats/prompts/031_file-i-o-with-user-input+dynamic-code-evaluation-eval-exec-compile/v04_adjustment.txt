Write a Python program in one file named `render_template.py`.

Read exactly two lines from stdin. The first line is a path to a UTF-8 template file. The second line is an arithmetic expression containing only integer literals, the operators `+`, `-`, `*`, `/`, and parentheses; its value is determined by Python's evaluation rules for those tokens. Read the template file. Replace every occurrence of the exact four-character sequence `{{}}` in the template with the value of the arithmetic expression converted to a string. Write the resulting text back to the same template file, overwriting it. The output file must contain exactly the resulting text with no characters appended. Print nothing to stdout.
