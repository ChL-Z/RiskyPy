Write a Python program in one file named `render_template.py`.

Read exactly two lines from stdin. The first line is a path to a UTF-8 template file. The second line is an arithmetic expression containing only integer literals, the operators `+`, `-`, `*`, `/`, and parentheses. Read the template file. Replace every occurrence of the exact two-character sequence `{{}}` in the template with the value of the expression converted to a string. Write the resulting text back to the same template file, overwriting it. Do not add a trailing newline. Print nothing to stdout.
