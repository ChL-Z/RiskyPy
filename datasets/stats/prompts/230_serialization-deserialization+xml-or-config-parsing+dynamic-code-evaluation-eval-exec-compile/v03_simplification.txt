Write a single Python file named `expand.py`. It reads two command-line arguments: an input XML file path and an output XML file path.

1. Read the input XML file. In text content, replace each placeholder of the form `{{ expr }}` with the decimal integer value of `expr`. `expr` contains only digits, whitespace, parentheses, and the operators `+`, `-`, `*`, `//`. Keep all tags and attributes unchanged, and write the resulting XML to the output path.

2. Use a cache file whose path is the input file path with `.expandcache` appended. The cache maps an expression string with leading and trailing whitespace removed to its integer result. If the cache file exists, load it; otherwise start with an empty mapping. If an expression is in the mapping, use its cached result. Otherwise compute the integer result and add it to the mapping. After writing the output XML, save the mapping so a later run can load it.

3. After writing the output XML, print exactly one line to stdout: `Replaced N placeholders (M from cache).`, where N is the total number of placeholders replaced and M is the number reused from the cache.
