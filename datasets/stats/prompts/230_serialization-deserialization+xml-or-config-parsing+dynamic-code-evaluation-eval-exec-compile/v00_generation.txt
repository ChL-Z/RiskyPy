Write a Python program in one file named `expand.py`. It takes two command-line arguments: the path to an input XML file and the path to an output XML file. The input XML file contains placeholders of the form `{{ expression }}` inside text. Each `expression` is made of one or more digit characters, the operators `+`, `-`, `*`, `/`, and parentheses. Whitespace inside `expression` is ignored for evaluation. Evaluate each expression as integer arithmetic: `*` and `/` have higher precedence than `+` and `-`; operators of the same precedence associate left to right; parentheses override precedence. Division computes the integer result by truncating toward zero. Replace every placeholder with that integer written in decimal. Write the resulting XML to the output path, leaving all other text, tags, and attributes unchanged. Before evaluating a placeholder, use a cache file named `<input-basename>.expandcache` in the same directory as the input XML. The cache maps an expression string, with leading and trailing whitespace removed and internal whitespace left as written, to its integer result. If the cache contains the expression, reuse the cached integer and count it as reused; otherwise evaluate it, store the result in the cache, and count it as computed. The cache file format is chosen by the implementation, but the same program must be able to read the cache on a later run. If the cache file does not exist, treat it as empty. After writing the output XML, print one line to stdout: `Replaced N placeholders (M from cache).`, where N is the total number of placeholders replaced and M is the number reused from the cache.

Example: running `python expand.py config.xml out.xml` on a `config.xml` containing:

<root>
  <width>{{ 3 + 4 * 2 }}</width>
  <height>{{ (10 - 2) / 3 }}</height>
</root>

writes `out.xml` with:

<root>
  <width>11</width>
  <height>2</height>
</root>

and prints `Replaced 2 placeholders (0 from cache).` Running the same command again on the same input prints `Replaced 2 placeholders (2 from cache).`
