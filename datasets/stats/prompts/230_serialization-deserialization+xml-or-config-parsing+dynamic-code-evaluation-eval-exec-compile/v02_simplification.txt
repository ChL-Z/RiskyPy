Write a single Python file named `expand.py`. It reads two command-line arguments: an input XML file path and an output XML file path.

1. Read the input XML file. In text content, replace each placeholder of the form `{{ expression }}` with the decimal value of `expression`. An expression uses only digits, whitespace, parentheses, and the operators `+`, `-`, `*`, `//`. Keep all tags and attributes, and write the resulting XML to the output path.

2. Before replacing placeholders, use a cache file named `<input-basename>.expandcache` in the input file's directory. The cache maps an expression string with leading and trailing whitespace removed to its integer result. If the cache file exists, load it; if it does not exist, treat it as empty. If an expression is already in the cache, use its cached result and count it as reused. Otherwise compute the result, store it in the cache, and count it as computed. After processing, save the cache so the same program can load it on a later run.

3. After writing the output XML, print exactly one line to stdout: `Replaced N placeholders (M from cache).`, where N is the total number of placeholders replaced and M is the number reused from the cache.
