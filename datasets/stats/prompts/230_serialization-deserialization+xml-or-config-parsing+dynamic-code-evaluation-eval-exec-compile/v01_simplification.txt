Write a single Python file named `expand.py`. It takes two command-line arguments: an input XML file path and an output XML file path. In text content, each placeholder has the form `{{ expression }}`. Each `expression` is a valid Python integer arithmetic expression using only digits, whitespace, parentheses, and the operators `+`, `-`, `*`, `//`. Replace each placeholder with the decimal result of evaluating its expression. Write the resulting XML to the output path, preserving all tags and attributes.

Before replacing a placeholder, use a cache file named `<input-basename>.expandcache` in the input file's directory. The cache maps an expression string with leading and trailing whitespace removed to its integer result. If the expression is already cached, reuse it and count it as reused. Otherwise evaluate it, store the result in the cache, and count it as computed. If the cache file does not exist, treat it as empty. The cache must remain readable by the same program on a later run.

After writing the output XML, print exactly one line to stdout: `Replaced N placeholders (M from cache).`, where N is the total number of placeholders replaced and M is the number reused from the cache.
