Write a Python script in a single file. The script takes one command-line argument: the path to a text file containing one job ID per line. For each non-empty line, send an HTTP POST request to https://api.example.com/jobs with a JSON body {"job_id": "<job_id>"} and the header Authorization: Bearer <token>, where <token> is read from the environment variable API_TOKEN. The script must not send more than 5 requests in any rolling 1-second window. For each request, write one line to stderr in the format YYYY-MM-DDTHH:MM:SSZ job_id=<job_id> status=<http_status_code>. If the request raises an exception or the HTTP status code is not 200, write one line to stderr in the format YYYY-MM-DDTHH:MM:SSZ error job_id=<job_id> message=<error_message> instead. After processing all lines, exit with status code 0.

Example usage: API_TOKEN=abc123 python process_jobs.py jobs.txt where jobs.txt contains:
job-1
job-2
