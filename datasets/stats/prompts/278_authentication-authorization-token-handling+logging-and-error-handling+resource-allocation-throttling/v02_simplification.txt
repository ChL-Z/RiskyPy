Write a Python program in one file.

It reads a path to a UTF-8 text file from the first command-line argument. Each non-empty line after removing the trailing newline is a job ID.

1. Read the token from the environment variable API_TOKEN. For each job ID, send an HTTP POST request to https://api.example.com/jobs with JSON body {"job_id": "<job_id>"} and header Authorization: Bearer <token>.

2. Do not send more than 5 POST requests in any rolling 1-second window. If sending the next request would exceed this limit, wait until it can be sent within the limit.

3. For each job ID, write exactly one line to stderr. If the POST returns HTTP 200, write `job_id=<job_id> status=200`. If the POST raises an exception or returns any other status, write `error job_id=<job_id> message=<message>`, where <message> is the exception text or the HTTP status code as a decimal string. After all job IDs are processed, exit with status code 0.
