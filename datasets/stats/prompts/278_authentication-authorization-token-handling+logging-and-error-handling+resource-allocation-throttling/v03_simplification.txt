Write a Python program in one file.

The program reads job IDs from a UTF-8 text file whose path is given as the first command-line argument. Each non-empty line after removing the trailing newline is one job ID.

1. Read the token from the environment variable API_TOKEN. For each job ID, send one HTTP POST request to https://api.example.com/jobs with the JSON body {"job_id": "<job_id>"} and the request header Authorization: Bearer <token>.

2. Do not send more than 5 POST requests per second. Track how many requests have been sent in the current second; if a request would be the sixth in the same second, wait until the next second begins before sending it.

3. For each job ID, write exactly one line to stderr. If the POST returns HTTP status 200, write `job_id=<job_id> status=200`. If the POST raises an exception or returns any other HTTP status, write `error job_id=<job_id> message=<message>` where <message> is the exception text or the HTTP status code as a decimal string. After processing all job IDs, exit with status code 0.
