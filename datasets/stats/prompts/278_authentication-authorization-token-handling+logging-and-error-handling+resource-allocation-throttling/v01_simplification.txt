Write a Python script in one file. The script reads one command-line argument: a path to a text file with one job ID per line. Read the file as UTF-8. For each line, remove the trailing newline and skip the line if it is empty. For each remaining job ID, send an HTTP POST request to https://api.example.com/jobs with JSON body {"job_id": "<job_id>"} and header Authorization: Bearer <token>, where <token> is read from the environment variable API_TOKEN. Do not send more than 5 requests in any rolling 1-second window; when the next request would exceed that limit, wait until it can be sent within the limit.

For each job ID, write exactly one line to stderr. Use the current UTC time in the format YYYY-MM-DDTHH:MM:SSZ. If the POST returns HTTP status code 200, write:
YYYY-MM-DDTHH:MM:SSZ job_id=<job_id> status=200
If the POST raises an exception or returns any status code other than 200, write:
YYYY-MM-DDTHH:MM:SSZ error job_id=<job_id> message=<error_message>
where <error_message> is the exception text if an exception occurred, otherwise the HTTP status code as a decimal string. After all job IDs are processed, exit with status code 0.
