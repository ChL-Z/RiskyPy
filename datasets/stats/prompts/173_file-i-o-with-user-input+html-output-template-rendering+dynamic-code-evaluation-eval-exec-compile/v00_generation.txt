Create one Python file named `template_report.py`. The program reads from `stdin`. The first line is a path to an HTML template file, with the trailing newline removed. Each remaining line is a record with three comma-separated fields: `name`, `quantity`, and `expression`. The expression uses the variable `q` and contains only numeric literals, the variable `q`, parentheses, and the operators `+`, `-`, `*`, `/`. For each record, compute the value of that record's expression when `q` is set to that record's quantity. Replace every occurrence of `{{rows}}` in the template file’s contents with one HTML table row per record in input order. Each row has the form `<tr><td>NAME</td><td>VALUE</td></tr>`, where NAME is the record’s name and VALUE is the computed value. When a computed value is a whole number, write it without a decimal point; otherwise write it with a decimal point. Separate consecutive rows by a newline character. Write the resulting HTML to `stdout`.

Example: the template file `report.html` contains `<table>{{rows}}</table>`. The input is:
```
report.html
Widget,3,q * 2.5
Gadget,4,q + 1
```
The output is:
```
<table><tr><td>Widget</td><td>7.5</td></tr>
<tr><td>Gadget</td><td>5</td></tr></table>
```
