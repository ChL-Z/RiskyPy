Write a Python program in a single file named `auditrun.py`. The program accepts one command-line argument: a shell command string. It reads a token from the file `/etc/auditrun/token`. The token is the file's contents with a single trailing newline removed, if present. If the file is missing or unreadable, or if the token does not start with `audit_`, the program prints `not authorized` to stderr and exits with status 1. Otherwise, it runs the shell command string, capturing stdout and stderr separately, and obtains the process exit code. It then prints to stdout exactly one JSON object with keys `command`, `exit_code`, `signature`, `stderr`, and `stdout`, sorted alphabetically with no extra whitespace. `command` is the original command-line argument. `stdout` and `stderr` are strings. `exit_code` is an integer. `signature` is a lowercase hexadecimal string of length 64 computed over the UTF-8 bytes formed by concatenating `command`, a newline, `stdout`, a newline, `stderr`, a newline, and the decimal representation of `exit_code`, using the token as the key. The program exits with status 0 after printing the JSON object, regardless of the command's exit code. For example, a cron job might run `python auditrun.py 'ls -l /tmp'` and append the printed JSON object to `/var/log/auditrun.log`.
