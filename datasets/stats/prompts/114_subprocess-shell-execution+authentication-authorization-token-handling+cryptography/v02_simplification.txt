Write a single Python file named `auditrun.py`. It takes one command-line argument: a shell command string.

Read the token from `/etc/auditrun/token` as text. Remove one trailing newline if the file ends with a newline. If the file cannot be read or the resulting token does not start with `audit_`, write `not authorized` to stderr and exit with status 1.

Otherwise, run the shell command string and capture its stdout and exit code. Print to stdout one JSON object with keys `command`, `exit_code`, `signature`, and `stdout`. `command` is the original command-line argument. `stdout` is a string. `exit_code` is an integer. `signature` is a lowercase hexadecimal string of length 64 computed as a keyed cryptographic digest of the UTF-8 bytes formed by joining `command`, `stdout`, and the decimal representation of `exit_code` in that order, using the token as the key. Exit with status 0 after printing the JSON object.
