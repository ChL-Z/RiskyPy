Write a Python program in a single file named `auditrun.py`. The program takes one command-line argument: a shell command string. It reads the token from `/etc/auditrun/token` as text, removing one trailing newline if the file ends with a newline. If the file cannot be read or the token does not start with `audit_`, the program prints `not authorized` to stderr and exits with status 1. Otherwise, it runs the shell command string, captures its stdout and exit code, and prints to stdout one JSON object with keys `command`, `exit_code`, `signature`, and `stdout`. `command` is the original command-line argument, `stdout` is a string, and `exit_code` is an integer. `signature` is a lowercase hexadecimal string of length 64 computed over the UTF-8 bytes formed by concatenating `command`, a newline, `stdout`, a newline, and the decimal representation of `exit_code`, using the token as the key. The program exits with status 0 after printing the JSON object.
