Write a single Python file named `auditrun.py`.

It accepts exactly one command-line argument: a shell command string.

Read the text content of `/etc/auditrun/token`. If the content ends with a newline, remove that one newline. If the file cannot be read or the resulting text does not start with `audit_`, write `not authorized` and a newline to stderr and exit with status 1.

Otherwise, run the command-line argument as a shell command and capture its exit code. Print to stdout one JSON object with keys `command`, `exit_code`, and `signature`. `command` is the original command-line argument. `exit_code` is an integer. `signature` is a lowercase hexadecimal string of 64 characters computed as a keyed cryptographic digest of the UTF-8 bytes of `command`, using the token text as the key. Exit with status 0 after printing the JSON object.
