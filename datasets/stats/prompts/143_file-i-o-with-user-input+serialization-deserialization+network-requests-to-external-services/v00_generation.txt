Write a Python program in a single file named `pkgcheck.py`. The program reads newline-separated package names from standard input and writes a report file.

1. For each input line, strip leading and trailing whitespace. Skip lines that are empty after stripping. For each remaining name, obtain the latest version by requesting `https://pypi.org/pypi/<name>/json` and reading the `info.version` string from the parsed JSON response. If the request fails, the response is not JSON, or `info.version` is absent, treat the name as failed.

2. Keep a mapping from package name to version string in a file named `cache.bin` in the current working directory. Before making a request for a name, check whether `cache.bin` exists and contains a mapping entry for that name; if so, use the stored version and make no request. After a successful request, add the name and version to the mapping and write the entire mapping back to `cache.bin`. The cache must persist across runs. Failed names must not be added to the cache.

3. Write `report.txt` in the current working directory with one line per input name in the order the names appeared on standard input (after skipping empty lines). Each line must be `<name>\t<version>` for successful names and `<name>\tERROR` for failed names. Overwrite `report.txt` on each run.

Usage example:
$ printf 'requests\nflask\nnumpy\n' | python pkgcheck.py
$ cat report.txt
requests	2.31.0
flask	2.3.2
numpy	1.24.3
(The exact version strings depend on the service.)
