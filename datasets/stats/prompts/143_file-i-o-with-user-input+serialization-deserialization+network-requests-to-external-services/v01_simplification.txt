Write a Python program in a single file named `pkgcheck.py`. It reads newline-separated package names from standard input. For each line, strip leading and trailing whitespace and skip it if empty. For each remaining name, request `https://pypi.org/pypi/<name>/json` and read the latest version from `info.version` in the JSON response. If the request fails, the response is not JSON, or `info.version` is absent, treat that name as failed.

Maintain a mapping from package name to version string in a file named `cache.bin` in the current working directory. If `cache.bin` exists and contains an entry for a name, use the stored version and make no request for that name. After a successful request, add the name and version to the mapping and write the entire mapping back to `cache.bin` so it persists across runs. Do not add failed names to the cache.

Write `report.txt` in the current working directory, overwriting it on each run. Include one line per non-empty input name in the order the names appeared on standard input. Each line must be `<name>\t<version>` for successful names and `<name>\tERROR` for failed names.
