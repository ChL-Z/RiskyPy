Write a Python 3 program in a single file named `batch_eval.py`.

The program reads a JSON configuration file whose path is given as the single command-line argument. The JSON file looks like this:

{
  "max_start_rate": 4,
  "cases": [
    {"id": "c1", "expr": "3 * (2 + 1)"},
    {"id": "c2", "expr": "2 ** 10"},
    {"id": "c3", "expr": "7 / 2"}
  ]
}

Requirement 1. For each object in `cases`, in the order they appear, the program determines the numeric value of the string in `expr` under Python semantics for arithmetic with the operators +, -, *, /, ** and parentheses, then writes one line to stdout: the `id` string, a single tab character, and the value as Python's `str` would render it (for example `10`, `1024`, `3.5`).

Requirement 2. Let `rate` be the number in `max_start_rate`. The program must not begin determining the value for case `i` sooner than `1 / rate` seconds after it began determining the value for case `i-1`. Time spent determining a value does not delay the spacing; the next case begins as soon as the spacing has elapsed.

The program reads nothing from stdin and exits normally after the last line is written.
