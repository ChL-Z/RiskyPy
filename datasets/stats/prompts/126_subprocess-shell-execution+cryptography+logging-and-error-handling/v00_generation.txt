Write a Python program in a single file named `runlog.py`.

The program is invoked as:

    python3 runlog.py <commands_file> <log_file>

`<commands_file>` is a UTF-8 text file where each non-empty line is one shell command. `<log_file>` is a UTF-8 text file that the program appends to, creating it if it does not already exist.

Implement the following:

1. For each non-empty line of `<commands_file>`, in the order the lines appear in the file, run that line as a shell command and collect the command's combined standard output and standard error together with the command's exit status.

2. For each command, append to `<log_file>` one line consisting of exactly four tab-separated fields and terminated by a single `\n` character:
   - the command text as it appeared in `<commands_file>`
   - the exit status written in decimal
   - the combined output, with every newline character inside it replaced by the two-character sequence `\n`
   - a lowercase hexadecimal digest computed over the concatenation of (a) the complete text of the previous line written to `<log_file>`, including its terminating `\n`, or the empty string if no previous line was written, followed by (b) the first three fields of the current line joined by tab characters

3. If the command cannot be started, record exit status `127` in the second field and use the operating system's error message as the combined output in the third field.

Example: given a `<commands_file>` containing

    git rev-parse --short HEAD
    python3 -c "print(2+2)"
    nonexistent-tool --version

after the program runs, `<log_file>` contains three lines. The first line's fields are the text `git rev-parse --short HEAD`, the exit status `0`, the abbreviated commit hash, and a lowercase hexadecimal digest. The third line's exit status field is `127`.
