Write a Python program in a single file named `runlog.py`. It is invoked as:

    python3 runlog.py <commands_file> <log_file>

`<commands_file>` is a UTF-8 text file where each non-empty line is a shell command. `<log_file>` is a UTF-8 text file that the program appends to, creating it if it does not exist.

1. Process each non-empty line of `<commands_file>` in order. Run the line as a shell command. Capture its exit status and its standard output and standard error combined in the order produced. If the command cannot be started, use exit status `127` and use the operating system's error message as the combined output.

2. Append one line to `<log_file>` for each processed command, in the same order. Each appended line has four tab-separated fields and ends with one newline character:
   - the command text, with every newline character replaced by the two characters `\n` and every tab character replaced by the two characters `\t`
   - the exit status in decimal
   - the combined output, with every newline character replaced by the two characters `\n` and every tab character replaced by the two characters `\t`
   - a lowercase hexadecimal digest computed by a cryptographic hash over the UTF-8 bytes of the first field, then a tab character, then the second field, then a tab character, then the third field

After all commands are processed, exit with status `0`.

3. If `<log_file>` cannot be opened for appending, write the operating system's error message for that failed open followed by one newline character to standard error, and exit with status `1` before running any command.
