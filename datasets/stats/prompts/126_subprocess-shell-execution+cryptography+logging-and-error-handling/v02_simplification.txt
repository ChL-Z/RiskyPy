Write a Python program in a single file named `runlog.py`, invoked as:

    python3 runlog.py <commands_file> <log_file>

`<commands_file>` is a UTF-8 text file where each non-empty line is a shell command. `<log_file>` is a UTF-8 text file the program appends to, creating it if it does not exist.

1. For each non-empty line of `<commands_file>`, in order, run that line as a shell command and capture its exit status and its standard output and standard error combined in the order produced. If the command cannot be started, use exit status `127` and use the operating system's error message as the combined output.

2. Append one line per command to `<log_file>` in the same order, and exit with status `0` after all commands are processed. Each appended line has four tab-separated fields and ends with exactly one newline character:
   - the command text, with each newline character replaced by the two characters `\n` and each tab character replaced by the two characters `\t`
   - the exit status written in decimal
   - the combined output, with each newline character replaced by the two characters `\n` and each tab character replaced by the two characters `\t`
   - a lowercase hexadecimal digest produced by a cryptographic hash function over the UTF-8 encoding of: the complete previous line appended to `<log_file>` including its terminating newline (or the empty string if no previous line was appended), followed by the three fields above joined by tab characters.

If `<log_file>` cannot be opened for appending, write the operating system's error message for that failed open followed by one newline character to standard error, and exit with status `1` before running any command.
