Write a single Python file named `feedsum.py`.

When run, it reads two lines from standard input: the path to an input file, then the path to an output file.

The input file contains exactly one line: an `http` or `https` URL, one or more spaces, then an arithmetic expression that may contain `{name}` placeholders. Fetch the URL. The response body is a JSON object whose keys are the placeholder names and whose values are numbers. Replace each `{name}` in the expression with the corresponding number, then evaluate the resulting arithmetic expression.

Create or replace the output file. Write one line: the URL, a tab, and the computed result. Write a whole-number result without a decimal point; otherwise write the result without trailing zeros after the decimal point.
