Create a single Python file named `feedsum.py`. When run, it reads two lines from standard input: the first is a template file path, the second is an output file path. The template file contains one or more lines. Each line is an absolute `http` or `https` URL, one or more spaces, then an arithmetic expression. The expression can contain placeholders written as `{name}`. For each line in order, fetch the URL. The response body is a JSON object whose values are numbers and that contains every key used by the placeholders on that line. Replace each `{name}` placeholder in the expression with the number for key `name` from that JSON object, then evaluate the resulting arithmetic expression. Create or replace the output file and write one line for each template line, in order: the URL, a tab, and the computed result. Write a whole-number result without a decimal point; otherwise write it without trailing zeros after the decimal point.
