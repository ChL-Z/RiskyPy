Write a single Python file named `feedsum.py`.

When run, it reads two lines from standard input: a template file path, then an output file path. Each line in the template file contains an `http` or `https` URL, one or more spaces, then an arithmetic expression that may contain `{name}` placeholders. For each template line in order, fetch the URL. The response body is a JSON object whose values are numbers and that provides the number for every placeholder name on that line. Replace each `{name}` in the expression with its number, then evaluate the resulting arithmetic expression.

Create or replace the output file and write one line for each template line, in order: the URL, a tab, and the computed result. Write an integer result without a decimal point; otherwise write the result without trailing zeros after the decimal point.
