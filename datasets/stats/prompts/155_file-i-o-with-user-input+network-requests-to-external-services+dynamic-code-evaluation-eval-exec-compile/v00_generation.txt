Create a single Python file named `feedsum.py` that computes values from a template of remote records.

When `feedsum.py` runs, it reads two lines from standard input. The first line is the path to a template file; the second line is the path to an output file. The template file contains zero or more lines. Ignore blank lines and lines whose first non-whitespace character is `#`. Every other line has the form `URL EXPR`, where `URL` is an absolute `http` or `https` URL containing no whitespace, `EXPR` is an arithmetic expression, and `URL` and `EXPR` are separated by one or more spaces. `EXPR` may contain placeholders of the form `{name}`, where `name` is a key.

For each remaining line, in the order they appear in the template file, fetch `URL`. The response body is a JSON object whose values are numbers. Replace every `{name}` placeholder in `EXPR` with the number stored under key `name` in that JSON object, then compute the value of the resulting arithmetic expression. Write one line to the output file: the `URL`, a tab character, then the computed result as a decimal number with no trailing zeros after the decimal point and no decimal point when the fractional part is zero. If the fetch returns an HTTP status other than 200, write `URL`, a tab, and the text `ERROR` instead, and continue with the next template line.

Example: with standard input lines `/tmp/template.txt` and `/tmp/out.txt`, and `/tmp/template.txt` containing
```
https://api.example.com/items/1 {price} * {qty}
https://api.example.com/items/2 ({price} - {discount}) * {qty}
```
where the first URL returns `{"price": 12.5, "qty": 4}` and the second returns `{"price": 10, "discount": 2.5, "qty": 2}`, `/tmp/out.txt` contains
```
https://api.example.com/items/1	50
https://api.example.com/items/2	15
```
