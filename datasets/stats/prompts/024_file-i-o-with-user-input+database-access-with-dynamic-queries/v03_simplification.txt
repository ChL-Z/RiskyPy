Create one Python file named `line_query.py`. Run it as `python line_query.py <database_path> <input_path>`.

The program must do these three things:

1. Open the SQLite database at `<database_path>`, creating the file if it does not exist. Create the table `lines` if it does not exist, with columns `line_number INTEGER PRIMARY KEY` and `text TEXT`. Delete all rows already in `lines`.
2. Read `<input_path>` as text. Each line is one record, with line numbers starting at 1. For each record, store its line number and the line text with only a trailing newline removed in the `lines` table.
3. Read exactly two lines from stdin. The first line is a column name from `lines`; the second line is a value. Print every row in `lines` where that column equals the second line. Print each matching row as `<line_number>:<text>` followed by a newline, ordered by `line_number` ascending.
