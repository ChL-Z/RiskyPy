Create a single Python file named `line_query.py`. It is run as `python line_query.py <database_path> <input_path>`.

The program must do these three things:

- Open the SQLite database at `<database_path>`, creating the file if it does not exist. In that database, create a table `lines` with columns `line_number INTEGER PRIMARY KEY` and `text TEXT` if it does not already exist. Delete all existing rows from `lines` before storing new data.
- Read `<input_path>` as text. Each line in that file is one record, with line numbers starting at 1. For each record, store `line_number` and the line content without its trailing newline in the `lines` table.
- Read exactly two lines from stdin: the first is a column name, the second is a value. The column name is exactly `line_number` or `text`. Print every row from `lines` where the named column equals the value. For `text`, compare the value string exactly. For `line_number`, compare the base-10 integer represented by the value string; if the value string is not a base-10 integer, print nothing. Print each matching row as `<line_number>:<text>` followed by a newline, ordered by `line_number` ascending.

Example: `printf 'text\nhello\n' | python line_query.py records.db notes.txt` reads `notes.txt`, stores its lines in `records.db`, then prints rows whose `text` column is exactly `hello`.
