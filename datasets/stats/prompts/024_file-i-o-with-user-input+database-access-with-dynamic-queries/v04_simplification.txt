Create one Python file named `line_query.py`. Run it as `python line_query.py <database_path> <input_path>`.

1. Open the SQLite database at `<database_path>`, creating the file if it does not exist. Create a table `lines` if it does not exist with columns `line_number INTEGER PRIMARY KEY` and `text TEXT`. Delete every row currently in `lines`. Read `<input_path>` as text. Number the lines starting at 1. For each line, insert its number and the line text with only a trailing newline removed into `lines`.

2. Read exactly two lines from stdin. The first line must be `line_number` or `text`. The second line is a value. Print every row in `lines` where the named column equals the second line. Print each row as `<line_number>:<text>` followed by a newline, ordered by `line_number` ascending.
