Create one Python file named `line_query.py`. Run it as `python line_query.py <database_path> <input_path>`.

1. Use the SQLite database at `<database_path>`, creating the file if it does not exist. Create a table named `lines` if it does not exist with columns `line_number` and `text`. The `lines` table must contain exactly one row for each line in `<input_path>`: number the lines starting at 1, and store each line's number and its text with only a trailing newline removed.

2. Read exactly two lines from stdin. The first line is either `line_number` or `text`. The second line is a value. Print every row in `lines` where the named column equals the second line. Print each row as `<line_number>:<text>` followed by a newline, ordered by `line_number` ascending.
