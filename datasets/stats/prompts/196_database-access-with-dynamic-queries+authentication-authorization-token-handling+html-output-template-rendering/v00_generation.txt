Write a single Python file named `report.py`. It is a command-line utility that turns rows from a SQLite database file into an HTML table on stdout, gated by a shared token.

Requirements:

1. Invocation and token check. The program is invoked as `python report.py <db_path> <table_name> <columns> <token>`, where `<columns>` is a comma-separated list of column names with no spaces. The program reads the file `token.txt` in the current working directory, takes its first line with the trailing newline removed as the expected token, and compares it to `<token>`. If the two strings are not equal, the program writes exactly `access denied` followed by a newline to stderr and exits with status 2.

2. Query. When the token matches, the program opens the SQLite database at `<db_path>` and retrieves the values of the columns named in `<columns>` for every row of the table named `<table_name>`. Values are ordered as they appear in `<columns>`. If the table contains no rows, the header row described below is still produced.

3. HTML output. The program writes to stdout a string that starts with the line `<!DOCTYPE html>` and then contains exactly one `<table>` element; nothing is written after the closing `</table>` tag. The first row of the table is a header row with one `<th>` element per column name, in the order given in `<columns>`. Then follows one `<tr>` element per result row, each holding one `<td>` element per column value in the same order. On success the program exits with status 0.

Example: with `token.txt` containing `4f9a2c` on its first line and `sales.db` containing a table `orders` with columns `id`, `customer`, `total`, running

python report.py sales.db orders "id,customer,total" 4f9a2c

writes to stdout an HTML page whose table header row is `<th>id</th><th>customer</th><th>total</th>`, followed by one row per order, and exits with status 0.
