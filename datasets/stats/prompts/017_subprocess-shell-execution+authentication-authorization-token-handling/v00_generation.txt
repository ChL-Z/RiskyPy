Create a single Python file named `run_with_token.py`. The script is a command-line wrapper used by a build job. It takes two or more arguments: the path to a token file, then a command and its arguments to run. It reads the first line of the token file and removes one trailing newline if present. It reads `authorized_tokens.txt` in the current directory, where each line contains one authorized token; compare the token after removing one trailing newline from each line. If the token value does not exactly match an authorized token, write `unauthorized` to stderr and exit with status 3. If the token file cannot be read or the token value is empty, write `missing token` to stderr and exit with status 2. Otherwise, run the command and arguments as a child process with an environment variable `AUTH_TOKEN` set to the token value, pass the child's stdout and stderr through to the script's stdout and stderr, and exit with the child's exit status. Usage example: `python run_with_token.py ./build.token python -c "print('deploying')"`.
