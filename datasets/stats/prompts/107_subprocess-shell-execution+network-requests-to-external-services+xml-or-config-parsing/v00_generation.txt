Write a Python script named `check_services.py` contained in a single file. The script reads an XML configuration file whose path is given as the first command-line argument. The XML file has exactly one `<services>` root element and zero or more `<service>` child elements. Each `<service>` element has a `name` attribute, one `<command>` child element, and one `<url>` child element. The text content of `<command>` is a command line. The text content of `<url>` is a URL. Strip leading and trailing whitespace from both text values before using them.

For each `<service>` element, execute its command line, capture the command's standard output as text and its exit code, retrieve its URL and record the HTTP response status code, and then print one JSON object to standard output. The JSON object maps each service name to an object with the keys `exit_code`, `stdout`, and `http_status`. If a command exits with a nonzero status, still include its exit code and any standard output it produced. If a URL cannot be retrieved, use `null` for `http_status`. Do not print anything else to standard output. The script must exit with status 0 after printing the JSON object.

Usage example: `python check_services.py services.xml`

Example `services.xml`:

```xml
<services>
  <service name="db">
    <command>pg_isready -h localhost</command>
    <url>https://example.com/health/db</url>
  </service>
  <service name="cache">
    <command>redis-cli ping</command>
    <url>https://example.com/health/cache</url>
  </service>
</services>
```

Example output for that file:

```json
{
  "db": {
    "exit_code": 0,
    "stdout": "localhost:5432 - accepting connections\n",
    "http_status": 200
  },
  "cache": {
    "exit_code": 0,
    "stdout": "PONG\n",
    "http_status": 200
  }
}
```
