Write a Python script named `check_services.py` in one file. It reads an XML configuration file path from the first command-line argument. The XML has a `<services>` root element with `<service>` child elements. Each `<service>` has a `name` attribute and contains a `<command>` child element and a `<url>` child element. The text of `<command>` is a command line, and the text of `<url>` is a URL. For each service, run the command line, capture its stdout text and exit code, then retrieve the URL and record its HTTP response status code. Print one JSON object to stdout mapping each service name to an object with the keys `exit_code`, `stdout`, and `http_status`. If a command exits with a nonzero status, still include its exit code and stdout. If the URL cannot be retrieved, set `http_status` to null. Print only that JSON object and exit with status 0.
