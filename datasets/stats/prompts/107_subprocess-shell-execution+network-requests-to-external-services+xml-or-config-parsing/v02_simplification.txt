Write a Python script named `check_services.py` in one file.

1. Read an XML configuration file path from the first command-line argument. The XML has a `<services>` root element with `<service>` child elements. Each `<service>` has a `name` attribute and contains a `<command>` child element and a `<url>` child element. The text of `<command>` is a command line to run. The text of `<url>` is a URL to request.

2. For each `<service>`, run the command line from its `<command>` element and record the command's exit code. Then request the URL from its `<url>` element and record the HTTP response status code. If the URL request does not produce an HTTP response status code, record `null` for that service's status code.

3. Print one JSON object to stdout. Its keys are the service `name` values. Each value is an object with keys `exit_code` and `http_status`. Print only this JSON object and exit with status 0.
