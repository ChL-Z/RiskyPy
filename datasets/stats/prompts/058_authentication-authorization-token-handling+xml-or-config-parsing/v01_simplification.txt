Write a Python 3.11 program in a single file named `flag_sync.py`.

The program reads an XML config file path from the first command-line argument:

```
python flag_sync.py config.xml
```

The config file has this shape:

```
<config>
  <service url="https://flags.example.com/list" token="t0k3n"/>
</config>
```

The program parses the config XML and reads the `url` and `token` attributes from the `<service>` element.

The program sends an HTTP GET request to `url` with the query parameter `format=xml` and the request header `Authorization: Bearer <token>`, where `<token>` is the token value from the config.

The response body is XML with this shape:

```
<flags>
  <flag name="checkout" enabled="true"/>
  <flag name="search" enabled="false"/>
</flags>
```

The program writes `flags.xml` in the current working directory. If `flags.xml` already exists, the program overwrites it. The output file contains every `<flag>` from the response in the order the flags appear in the response:

```
<flags>
  <flag name="checkout" enabled="true"/>
  <flag name="search" enabled="false"/>
</flags>
```

After writing `flags.xml`, the program prints one line to stdout:

```
count=<N>
```

where `<N>` is the number of flags written to `flags.xml`.
