Write a Python file named `run_queries.py`. It takes exactly two command-line arguments: the path to an XML configuration file and the path to a values file.

Read the XML configuration file as UTF-8. The file contains a `<database path="..."/>` element and a `<query>...</query>` element. Use the value of the `path` attribute as the path to a SQLite database file. Use the text inside `<query>` as a SQL query. The query contains exactly one `?` character.

For each line in the values file, remove a trailing `\n` or `\r\n` if present, and use the remaining text as one input value. Execute the query on the database with that input value for the `?` placeholder. For each row returned, print one line to stdout containing the row's column values in column order separated by commas. If no rows are returned, print nothing for that input value. Print nothing else.
