Write a Python file named `run_queries.py`. It takes two command-line arguments: the path to an INI configuration file and the path to a values file. The configuration file has two sections:

[database]
path = data.db

[query]
sql = SELECT id, name FROM users WHERE name = ?

Read the `path` value from `[database]` as the database file path. Read the `sql` value from `[query]` as a SQL query containing one `?` placeholder.

Read the values file as UTF-8 text, one value per line, removing the trailing newline. For each value, run the query on the database file with that value used for the `?` placeholder. For each result row, print one line to stdout with the row's column values in column order, separated by commas. If the query returns no rows, print nothing for that value. Print nothing else.
