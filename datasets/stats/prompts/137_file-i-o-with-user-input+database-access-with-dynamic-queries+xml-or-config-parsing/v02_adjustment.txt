1. Write a single-file Python program named `run_queries.py` that accepts exactly two command-line arguments: the path to an XML configuration file and the path to a values file. The XML configuration file has the structure:

```xml
<config>
  <database connection="sqlite:///data.db" />
  <query>SELECT id, name FROM users WHERE name = ?</query>
</config>
```

The `<database>` element has a `connection` attribute whose value is a database connection string. The `<query>` element's text is a SQL statement containing exactly one `?` character.

2. The values file is UTF-8 text with one value per line. A line's value is its text without the newline terminator. A final line without a trailing newline is a value. An empty line is a value consisting of zero characters.

3. For each value line in the values file, connect to the database using the connection string from the XML configuration and execute the configured SQL query with that line's value as the argument for the `?` placeholder. For each result row, write one line to standard output containing the row's column values in column order, separated by commas. If the query returns no rows, write no output for that value. The program writes no output other than these result lines.
