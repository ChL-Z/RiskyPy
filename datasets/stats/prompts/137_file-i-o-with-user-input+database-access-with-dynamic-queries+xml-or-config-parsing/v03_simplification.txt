Write a Python file named `run_queries.py`. It reads two command-line arguments: the path to an XML configuration file and the path to a values file. The XML file contains:

```xml
<config>
  <database connection="data.db" />
  <query>SELECT id, name FROM users WHERE name = ?</query>
</config>
```

The `<database>` element's `connection` attribute is the database file path. The `<query>` element's text is a SQL statement with one `?` placeholder.

Read the values file as UTF-8 text, one value per line. A value is the line text without the newline. A final line without a trailing newline is a value. An empty line is an empty string.

For each value, run the query on the database file named by the `connection` attribute, passing that value for the `?`. For each result row, write one line to stdout with the row's column values in column order separated by commas. If the query returns no rows, write nothing for that value. Write no other output.
