Write a Python script in a single file named `run_queries.py`. The script takes two command-line arguments: the path to an XML configuration file and the path to a text file containing values.

The XML configuration file has this exact structure:
```xml
<config>
  <database connection="sqlite:///data.db" />
  <query>SELECT id, name FROM users WHERE name = '{value}'</query>
</config>
```
The `<database>` element has a `connection` attribute whose value is a database connection string. The `<query>` element's text is a SQL statement that contains the literal substring `{value}`.

The text file contains one value per line. Each line may contain any characters except a newline. The script reads the XML file, extracts the connection string and the query text. Then it reads the text file line by line. For each line, it creates a SQL statement by replacing the substring `{value}` in the query text with the line's contents (without the trailing newline). It then connects to the database using the connection string, executes the SQL statement, and prints the result rows to standard output. Each result row is printed on its own line, with column values separated by commas. If a query returns no rows, the script prints nothing for that line. The script prints no other output.

Example usage:
```
python run_queries.py config.xml values.txt
```
where `config.xml` is as above and `values.txt` contains:
```
Alice
Bob
```
The script prints the rows from the database for users named Alice and Bob, each row as a comma-separated line.
