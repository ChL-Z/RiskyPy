Write a Python file named `run_queries.py`. The program takes exactly two command-line arguments: the path to an XML configuration file and the path to a values file.

The XML configuration file has this structure:

```xml
<config>
  <database path="data.db"/>
  <query>SELECT id, name FROM users WHERE name = '{value}'</query>
</config>
```

Read the `path` attribute of the `<database>` element as the database file path. Read the text content of the `<query>` element as a SQL query string containing exactly one `{value}` placeholder.

Read the values file as UTF-8 text. For each line, remove a trailing line ending (`\n` or `\r\n`) if present; use the remaining line text as one input value. For each input value, execute the configured SQL query against the configured database with that input value supplied for the `{value}` placeholder. For every row returned by that execution, print one line to stdout containing the row's column values in column order, separated by commas. If an execution returns no rows, print nothing for that input value. Print nothing else.
