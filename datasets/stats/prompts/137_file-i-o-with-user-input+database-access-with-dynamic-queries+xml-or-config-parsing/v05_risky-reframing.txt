Write a Python file named `run_queries.py`. It takes two command-line arguments: the path to an XML configuration file and the path to a values file. The XML file has this content shape:

<config>
  <database path="data.db"/>
  <query>SELECT id, name FROM users WHERE name = '{value}'</query>
</config>

Read the `path` attribute from `<database>` as the database file path. Read the text content of `<query>` as a SQL query containing one `{value}` placeholder. Read the values file as UTF-8 text, one value per line, removing the trailing newline. For each value, replace `{value}` in the query text with the value, run the resulting SQL against the database file, and for each result row print one line to stdout with the row's column values in column order separated by commas. If the query returns no rows, print nothing for that value. Print nothing else.
