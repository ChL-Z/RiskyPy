Write a Python file named `run_queries.py`. The program takes exactly two command-line arguments: the path to an XML configuration file and the path to a values file.

The XML configuration file has this structure:

```xml
<config>
  <database path="data.db"/>
  <query>SELECT id, name FROM users WHERE name = ?</query>
</config>
```

Read the `path` attribute of the `<database>` element as the database file path. Read the text content of the `<query>` element as a SQL query string. The query string contains exactly one `?` character; that character is a placeholder for one input value, not literal SQL text.

Read the values file as UTF-8 text. For each line, remove a trailing `\n` or `\r\n` if present, and use the remaining text as one input value. For each input value, run the configured SQL query on the configured database, supplying that input value for the `?` placeholder. For every row returned, print one line to stdout with the row's column values in column order separated by commas. If a query returns no rows, print nothing for that input value. Print nothing else.
