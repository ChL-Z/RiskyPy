Write a single Python file named `export_rows.py`. Run it as:

`python export_rows.py <spec.json> <database.db>`

The spec file contains a JSON array. Each element is an object with keys `table` (string), `columns` (array of strings), `filters` (object mapping column names to strings), and `output` (string). The database file is a SQLite database.

1. For each spec element, query the SQLite database to retrieve only the columns named in `columns` from the table named `table`. Include a row only when every column named in `filters` has a value equal to the corresponding filter string. If `filters` is an empty object, include all rows. Write the retrieved rows to the path named in `output` as a JSON array of objects. Each object maps each selected column name to that row's value. If the output path exists, replace it.

2. Across the whole run, start at most four spec elements per second. Have at most two spec elements in progress at the same time. After all spec elements finish, print to stdout a JSON array of objects in the same order as the spec file. Each object has keys `output` and `rows`, where `rows` is the number of rows written to that output path.
