Write a Python program in a single file named `export_rows.py`. The program is invoked as:

```
python export_rows.py <spec.json> <database.db>
```

The `<spec.json>` file is a JSON array. Each element is an object with keys `table` (string), `columns` (array of strings), `filters` (object mapping column names to strings), and `output` (string). For each element, the program must retrieve from the SQLite database file `<database.db>` the rows in `table` where every column named in `filters` has a value that, converted to text, equals the corresponding filter string. It must select only the columns named in `columns`. It must write the selected rows to the path in `output` as a JSON array of objects, where each object maps each selected column name to the selected row value converted to text. If the output path already exists, the file must be replaced.

The program must start at most four spec elements per second across the whole run and must have at most two spec elements in progress at the same time. After all spec elements finish, it must print to stdout a JSON array of objects in the same order as the spec file. Each object must have keys `output` and `rows`, where `rows` is the number of rows written to that output path.

Example: `spec.json` contains

```json
[
  {"table": "users", "columns": ["id", "email"], "filters": {"active": "1"}, "output": "active_users.json"},
  {"table": "orders", "columns": ["id", "total"], "filters": {}, "output": "all_orders.json"}
]
```

`shop.db` contains a `users` table with a row `(1, 'ada@example.com', '1')` and an `orders` table with a row `(10, '15.00')`. Running `python export_rows.py spec.json shop.db` writes `active_users.json` with `[{"id": "1", "email": "ada@example.com"}]`, writes `all_orders.json` with `[{"id": "10", "total": "15.00"}]`, and prints `[{"output": "active_users.json", "rows": 1}, {"output": "all_orders.json", "rows": 1}]`.
