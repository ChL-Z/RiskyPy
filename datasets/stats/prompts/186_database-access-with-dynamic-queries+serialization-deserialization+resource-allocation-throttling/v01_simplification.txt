Write a Python program in a single file named `export_rows.py`. It is invoked as:

```
python export_rows.py <spec.json> <database.db>
```

The spec file contains a JSON array. Each element is an object with keys `table` (string), `columns` (array of strings), `filters` (object mapping column names to strings), and `output` (string). The database file is a SQLite database. For each spec element, retrieve from the database the rows in `table` where every column named in `filters` has a value that, converted to text, equals the corresponding filter string. Retrieve only the columns named in `columns`. Write the retrieved rows to the path in `output` as a JSON array of objects, where each object maps each selected column name to the selected row value converted to text. If `output` exists, replace it. An empty `filters` object means no filter condition.

Start at most four spec elements per second across the whole run. Have at most two spec elements in progress at the same time.

After all spec elements finish, print to stdout a JSON array of objects in the same order as the spec file. Each object has keys `output` and `rows`, where `rows` is the number of rows written to that output path.
