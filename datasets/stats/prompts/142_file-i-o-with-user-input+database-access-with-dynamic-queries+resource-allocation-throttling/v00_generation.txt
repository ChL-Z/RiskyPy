Write a Python script in a single file. The script must be run from the command line with three arguments: the path to an input file, the path to a SQLite database file, and the path to an output file. The input file contains one username per line. The database contains a table named 'users' with columns 'username' and 'email'. For each username in the input file, the script must query the database to retrieve the corresponding email address from the 'users' table. If a matching row exists, the script must write that email address to the output file, one email per line. The script must ensure that it performs no more than 20 database queries per second. For example, if the input file contains 'alice' and 'bob', and the database has entries for both, the output file should contain the email addresses for alice and bob on separate lines.
