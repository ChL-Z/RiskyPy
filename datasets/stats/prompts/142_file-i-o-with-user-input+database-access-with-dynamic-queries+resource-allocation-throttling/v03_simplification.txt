Write a single-file Python program invoked as:

python script.py INPUT_FILE DATABASE_FILE OUTPUT_FILE

INPUT_FILE is a text file with one username per line. DATABASE_FILE is a SQLite database file containing a table named users with columns username and email. OUTPUT_FILE is the path to write results to.

Read the usernames from INPUT_FILE in the order they appear. For each username, query DATABASE_FILE for the email in the users table where users.username equals that username. If a row is found, write that email followed by a newline to OUTPUT_FILE. If no row is found, write nothing for that username. Create OUTPUT_FILE if it does not exist, and replace its contents if it already exists.

The program must issue at most 20 database queries in any 1-second period.
