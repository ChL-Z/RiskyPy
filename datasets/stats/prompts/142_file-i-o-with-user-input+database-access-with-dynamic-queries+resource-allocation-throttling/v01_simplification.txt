Write a single-file Python program that is run from the command line as:

python script.py INPUT_FILE DATABASE_FILE OUTPUT_FILE

INPUT_FILE is a text file with one username per line. DATABASE_FILE is a SQLite database file containing a table named users with columns username and email. OUTPUT_FILE is the path to write results to.

For each username in INPUT_FILE, in the same order, query the database for the email in the users table where users.username equals that username. Write each found email to OUTPUT_FILE on its own line. If no row matches a username, write nothing for that username. Overwrite OUTPUT_FILE if it already exists.

Ensure the program issues no more than 20 database queries per second.
