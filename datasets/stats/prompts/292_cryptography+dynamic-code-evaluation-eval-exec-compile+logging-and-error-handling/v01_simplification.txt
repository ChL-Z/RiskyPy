Write a single-file Python 3 program named `recipe_eval.py` with this behavior:

1. `python recipe_eval.py --make-check` reads all bytes from stdin. It writes exactly one line to stdout: `check=<hex>`. `<hex>` is a lowercase hexadecimal string computed from the stdin bytes and the value of the environment variable `RECIPE_SALT`. The same stdin bytes and same `RECIPE_SALT` value must produce the same `<hex>` on every run.

2. `python recipe_eval.py <path>` reads the file at `<path>`. The first line is exactly `check=<hex>`. The body bytes are everything in the file after the first newline. Each remaining line is a body line of the form `name = expression`, where `name` matches `[A-Za-z_][A-Za-z0-9_]*` and `expression` is a Python expression. Compute the check value for the body bytes and `RECIPE_SALT`, and compare it to `<hex>`. If they differ, write `ERROR: check mismatch` to stderr and exit 1. If they match, evaluate each body line in order, with names assigned by earlier lines available to later expressions. For each line, bind the result to `name`, print `name=value` to stdout, and write `OK name=value` to stderr, where `value` is the result's Python text representation. If a line raises an exception, write `ERROR line <n>: <message>` to stderr and exit 1 immediately, where `<n>` is the 1-based body line number. If all lines succeed, exit 0.
