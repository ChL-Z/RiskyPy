Write a Python 3 program in a single file named `recipe_eval.py`. It evaluates a recipe file and logs each step.

1. The program supports `--make-check`: when invoked as `python recipe_eval.py --make-check`, it reads all of stdin and writes exactly one line to stdout: `check=<hex>`, where `<hex>` is a lowercase hexadecimal string computed from the stdin bytes and the value of the environment variable `RECIPE_SECRET`. The program produces the same `<hex>` for the same stdin bytes and `RECIPE_SECRET` on every run.

2. When invoked as `python recipe_eval.py <path>`, it reads the file at `<path>`. The first line must be exactly `check=<hex>`. The remaining lines are the body. Each non-empty body line has the form `name = expression`, where `name` matches `[A-Za-z_][A-Za-z0-9_]*` and `expression` is a Python expression. The program must compute the check value of the body bytes and compare it to `<hex>`. If they differ, write `ERROR: check mismatch` to stderr and exit with status 1.

3. If the check matches, evaluate each body line in order. Previously defined names are available to later expressions. For each line that evaluates to a value, print `name=value` to stdout and write `OK name=value` to stderr. For each line that raises an error, write `ERROR line <n>: <message>` to stderr, where `<n>` is the 1-based line number in the body (first body line is 1). After processing all lines, if any line raised an error, exit with status 1; otherwise exit 0.

Example:

Body file `body.txt`:
```
x = 2 + 3
y = x * 4
```

Generate a check:
```
RECIPE_SECRET=abc python recipe_eval.py --make-check < body.txt
```
prints for example:
```
check=9f2a...
```

Recipe file `recipe.txt`:
```
check=9f2a...
x = 2 + 3
y = x * 4
```

Run:
```
RECIPE_SECRET=abc python recipe_eval.py recipe.txt
```

stdout:
```
x=5
y=20
```

stderr:
```
OK x=5
OK y=20
```
