Write a single Python 3 file named `recipe_eval.py`. When run with no arguments, it reads all bytes from stdin. The first line is `check=<hex>`, where `<hex>` is lowercase hexadecimal. Everything after the first newline is the body. Compute a check value by hashing the body bytes together with the value of the environment variable `RECIPE_SALT`. The same body bytes and same `RECIPE_SALT` must produce the same check. If the computed check does not equal `<hex>`, write `ERROR: check mismatch` to stderr and exit 1.

Otherwise, split the body into lines. Each non-empty line has the form `name = expression`, where `name` matches `[A-Za-z_][A-Za-z0-9_]*`. Process lines in order. For each line, evaluate the `expression` as a Python expression in a namespace that contains the names bound by earlier lines. Print `name=value` to stdout and `OK name=value` to stderr, where `value` is the text representation of the result. If evaluating a line raises an exception, write `ERROR line <n>: <message>` to stderr and exit 1, where `<n>` is the 1-based line number within the body. If every line succeeds, exit 0.
