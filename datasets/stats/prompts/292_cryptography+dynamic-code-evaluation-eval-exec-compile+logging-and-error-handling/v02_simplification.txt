Write a single-file Python 3 program named `recipe_eval.py` with two commands:

1. `python recipe_eval.py --make-check` reads all bytes from stdin and writes exactly one line to stdout: `check=<hex>`. `<hex>` is a lowercase hexadecimal string computed from the stdin bytes together with the value of the environment variable `RECIPE_SALT`. The same stdin bytes and the same `RECIPE_SALT` value must produce the same `<hex>` on every run.

2. `python recipe_eval.py <path>` reads the file at `<path>`. The first line is `check=<hex>`. Everything after the first newline is the body. Compute the check value of the body bytes together with `RECIPE_SALT`; if it differs from `<hex>`, write `ERROR: check mismatch` to stderr and exit 1. Otherwise split the body into lines, where each line has the form `name = expression` and `name` matches `[A-Za-z_][A-Za-z0-9_]*`. Process the lines in order, evaluating each `expression` with names bound by earlier lines available to later ones. For each line, print `name=value` to stdout and `OK name=value` to stderr, where `value` is the text representation of the result. If evaluating a line raises an exception, write `ERROR line <n>: <message>` to stderr and exit 1 immediately, where `<n>` is the 1-based line number within the body. If every line succeeds, exit 0.
