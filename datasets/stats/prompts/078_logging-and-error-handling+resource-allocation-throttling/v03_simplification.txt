Write a Python program in a single file named `runbatch.py`.

Read newline-separated commands from stdin. Ignore lines that are empty after removing the trailing newline. For each remaining line, before starting the command, enforce throttling: the program may start at most 5 commands during each one-second interval after the program starts. If starting a command would make more than 5 starts in the current interval, wait until the next interval begins. Then run the line text as an external command and wait for it to finish.

After each command finishes, append one JSON object as a line to `run.log` in the current directory. The object has exactly the keys `command` (the line text), `exit_status` (an integer), and `time` (an integer Unix timestamp recorded after the command finishes). If a command cannot be started or waited for, record `exit_status` 1 and continue. After all lines are processed, exit with status 0.

If reading stdin or writing `run.log` fails, stop processing, write the error text to stderr, and exit with status 1.
