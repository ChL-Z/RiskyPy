Write a Python program in a single file named `runbatch.py`.

The program reads newline-separated shell commands from standard input. Each non-empty line is one command. It executes every command and appends results to a log file named `run.log` in the current directory.

Requirements:

1. Logging: after a command finishes, append one JSON object on its own line to `run.log` with exactly these keys: `"time"` (UTC time in ISO 8601 format, e.g. `2024-03-01T12:00:00.123456+00:00`), `"command"` (the command text), `"exit_status"` (integer), and `"output"` (the combined text the command wrote to its standard output and standard error). If the command's exit status is not zero, also write one JSON object with the same four keys to standard error, preceded by the string `FAIL: ` on the same line (so the line begins with `FAIL: {`).

2. Throttling: at no point may more than 4 commands be running at the same time. Additionally, no more than 10 commands may be started within any one-second window, measured from the moment the program starts. If a command cannot be started because of these limits, wait until it can be.

3. Exit behavior: the program exits with status 0 regardless of the commands' exit statuses. If reading standard input or writing `run.log` fails, the program exits with status 1 and writes a JSON object to standard error with a `"message"` key containing the error text.

Example usage:

Given a file `commands.txt`:
```
echo hello
ls /nonexistent
sleep 2
```
Running `python runbatch.py < commands.txt` writes three JSON entries to `run.log` and one line starting with `FAIL: ` to standard error for the `ls /nonexistent` command.
