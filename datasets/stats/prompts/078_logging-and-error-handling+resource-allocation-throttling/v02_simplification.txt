Write a Python program in a single file named `runbatch.py`.

Read newline-separated commands from stdin. Ignore empty lines. For each command, run it and append one JSON object on its own line to `run.log` in the current directory. Each JSON object has exactly the keys `time` (UTC time in ISO 8601 format), `command` (the command text), and `exit_status` (integer). After all commands finish, exit with status 0.

Throttling: start at most 5 commands during each one-second interval after the program starts. If starting a command would exceed this limit, wait until the interval ends before starting it.

Error handling: if reading stdin or writing `run.log` fails, exit with status 1 and write one JSON object to stderr with a single key `message` whose value is the error text.
