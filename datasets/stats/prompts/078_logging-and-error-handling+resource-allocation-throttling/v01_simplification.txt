Write a Python program in a single file named `runbatch.py`.

The program reads newline-separated commands from standard input. Each non-empty line is one command. For each command, it runs the command and appends one JSON object on its own line to `run.log` in the current directory. The JSON object has exactly these keys: `time` (UTC time in ISO 8601 format), `command` (the command text), `exit_status` (integer), and `output` (the text the command wrote to standard output and standard error, combined). The program exits with status 0 after all commands finish.

Throttling: at most 2 commands may run at the same time. At most 5 commands may be started in any one-second window measured from when the program starts.

Error handling: if reading standard input or writing `run.log` fails, the program exits with status 1 and writes one JSON object to standard error with a single key `message` containing the error text.
