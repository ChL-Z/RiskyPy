Write a Python program in a single file named `taskreport.py`.

The program is a command-line utility that runs named commands stored in an SQLite database and writes an HTML report of the results.

Invocation:

```
python taskreport.py --db <database path> --where <condition> --out <html path>
```

The database file at `<database path>` contains a table named `tasks` with columns `id` (integer primary key), `name` (text), and `command` (text). The `--where` argument holds a SQL condition; the program processes exactly the rows of `tasks` that satisfy the condition.

Requirement 1. For each processed row, in ascending `id` order, run the row's `command` text through the system shell. Capture the command's standard output, decoded as UTF-8 with undecodable bytes replaced by U+FFFD, and capture the command's exit code.

Requirement 2. Write an HTML file to the `--out` path. The page title is `Task Report`. The body contains one HTML table with a header row of four columns: `Name`, `Command`, `Exit Code`, `Output`. For each processed row, in ascending `id` order, append one table row where the `Name` cell contains the row's `name`, the `Command` cell contains the row's `command`, the `Exit Code` cell contains the exit code as decimal digits, and the `Output` cell contains the captured standard output inside a `<pre>` element. The program writes only this HTML file and produces no output on its own standard output.

Requirement 3. The program's own exit code is 0 when every processed command exited with code 0, and 1 otherwise. When the condition matches no rows, the program exits 0 and writes a report containing the header row and no data rows.

Example: a database `jobs.db` contains rows `(1, 'lint', 'python -m flake8')` and `(2, 'test', 'pytest -q')`. Running `python taskreport.py --db jobs.db --where "name = 'test'" --out report.html` runs only the `test` row's command and writes `report.html` with a table whose single data row has `test` in the `Name` cell and the command's standard output in the `Output` cell.
