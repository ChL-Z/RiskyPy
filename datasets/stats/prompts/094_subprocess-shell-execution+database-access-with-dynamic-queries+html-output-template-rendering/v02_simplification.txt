Write a Python program in a single file named `taskreport.py`. It is run as:

```
python taskreport.py --db <database path> --where <condition> --out <html path>
```

The database file at `<database path>` is an SQLite database with a table named `tasks` with columns `id` (integer), `name` (text), and `command` (text). The `--where` value is a SQL condition.

Requirement 1: Select the rows from `tasks` that satisfy the `--where` condition, in ascending `id` order. For each selected row, run its `command` text through the system shell. Capture that command's standard output as UTF-8 text with undecodable bytes replaced by U+FFFD.

Requirement 2: Write an HTML file to the `--out` path. The page title is `Task Report`. The body contains one table with a header row of three columns: `Name`, `Command`, `Output`. For each selected row in ascending `id` order, add one table row where the `Name` cell contains the row's `name`, the `Command` cell contains the row's `command`, and the `Output` cell contains the captured standard output inside a `<pre>` element. If the condition matches no rows, write the header row and no data rows. The program writes only this HTML file, prints nothing to its own standard output, and exits with code 0.
