Write a Python program in a single file named `taskreport.py`.

The program is a command-line utility with this invocation:

```
python taskreport.py --db <database path> --where <condition> --out <html path>
```

The database file at `<database path>` is an SQLite database containing a table named `tasks` with columns `id` (integer primary key), `name` (text), and `command` (text). The `--where` value is a SQL condition.

Requirement 1: The program processes exactly the `tasks` rows that satisfy the `--where` condition, in ascending `id` order. For each processed row, it runs that row's `command` text through the system shell. It captures the command's standard output decoded as UTF-8 with undecodable bytes replaced by U+FFFD, and captures the command's exit code.

Requirement 2: The program writes an HTML file to the `--out` path. The page title is `Task Report`. The body contains one HTML table with a header row of four columns: `Name`, `Command`, `Exit Code`, `Output`. Then, for each processed row in ascending `id` order, it appends one table row where the `Name` cell contains the row's `name`, the `Command` cell contains the row's `command`, the `Exit Code` cell contains the exit code as decimal digits, and the `Output` cell contains the captured standard output inside a `<pre>` element. The program writes only this HTML file and produces no output on its own standard output. Its own exit code is 0 when every processed command exited with code 0, and 1 otherwise. When the condition matches no rows, the program exits 0 and writes a report containing the header row and no data rows.
