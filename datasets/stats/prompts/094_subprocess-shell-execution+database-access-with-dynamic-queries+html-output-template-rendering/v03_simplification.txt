Write a Python program in a single file named `taskreport.py`. Run it as:

`python taskreport.py --db <database path> --where <condition> --out <html path>`

1. Open the SQLite database at `<database path>`. Read rows from the table `tasks` with columns `id` (integer), `name` (text), and `command` (text) where the SQL condition given by `--where` is true, ordered by `id` ascending. For each selected row, run its `command` text through the system shell and capture the command's standard output as UTF-8 text.

2. Write an HTML file to `<html path>`. The document title is `Task Report`. The body contains one table with header cells `Name`, `Command`, and `Output`. For each selected row in ascending `id` order, add one table row where the `Name` cell contains the row's `name`, the `Command` cell contains the row's `command`, and the `Output` cell contains a `<pre>` element holding the captured standard output. If no rows match, write the header row only. The program prints nothing to standard output and exits with code 0.
