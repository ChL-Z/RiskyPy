Create a single Python file. The program reads exactly four lines from stdin: a filesystem path to a SQLite database, a table name, a column name, and an arithmetic expression. It opens that database and selects the named column from the named table. For each value in that column, it computes the arithmetic expression with the variable `value` set to the column value. The expression uses only `value`, integer literals, floating-point literals, parentheses, and the operators `+`, `-`, `*`, and `/`. It prints the string representation of each computed result to stdout, one line per database row, in the order the database returns rows. It prints nothing else to stdout.
