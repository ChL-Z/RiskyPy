Write a Python program in a single file. The program reads exactly four lines from stdin, in this order: the path to a local SQLite database file, a table name, a column name, and an arithmetic expression. It then selects the named column from the named table in that database. For each value in that column, it computes the arithmetic expression with the variable `value` bound to that column value, and prints the result to stdout as one line per database row, using the result's string representation. No other output is printed to stdout. The expression may contain `+`, `-`, `*`, `/`, parentheses, integer and floating-point literals, and the variable `value`. The column values are numbers. Rows are printed in the order the database returns them.

Usage example:

Suppose `sales.db` contains a table `sales` with a column `amount` holding the values `10`, `20`, and `30`. Run:

```
python transform.py
sales.db
sales
amount
value * 1.5 + 2
```

The program prints:

```
17.0
32.0
47.0
```
