Write a Python file `extract.py`. When run as `python extract.py <path>`, it reads the text file at `<path>`. Each non-empty line of that file has the form `key = value`. The key contains no spaces and matches `[A-Za-z_][A-Za-z0-9_]*`. The value is a Python expression that produces one of: an `int`, a `str`, a `bool`, `None`, a list of `int` values, or a dict mapping `str` to `int`. A value may reference any key that was defined on an earlier line of the file by writing that key's name; when this happens, the referenced key's already-parsed value is substituted into the expression before the line's value is produced.

`extract.py` processes the lines in order, building a dict that maps each line's key to the value produced by that line's expression, and prints that dict to stdout as one JSON object. If a value references a key that has not appeared on an earlier line, the program prints `error: undefined key <name>` to stderr, writes nothing to stdout, and exits with status 1. The program reads only the file given on the command line and writes only to stdout.
