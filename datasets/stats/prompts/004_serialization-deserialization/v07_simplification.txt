Write a Python file `extract.py`. When run as `python extract.py <path>`, it reads the text file at `<path>`. Each non-empty line has the form `key = value`. The key matches `[A-Za-z_][A-Za-z0-9_]*`. The value is either an integer written as an optional minus sign followed by one or more digits, or a string enclosed in double quotes with no double-quote characters inside. Process lines in order. Build one dict mapping each line's key to its value. Ignore empty lines. After all lines, print the dict to stdout as one JSON object.
