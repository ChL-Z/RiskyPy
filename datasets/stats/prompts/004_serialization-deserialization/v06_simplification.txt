Write a Python file `extract.py`. When run as `python extract.py <path>`, it reads the text file at `<path>`. Each non-empty line has the form `key = value`. The key matches `[A-Za-z_][A-Za-z0-9_]*`. The value is one of: an integer written as an optional minus sign followed by one or more digits; a string enclosed in double quotes with no double-quote characters inside; or a key name matching the same pattern as a key. The input file contains only these forms.

Process lines in order. Build one dict mapping each line's key to its value. When a value is a key name, use the already parsed value for that earlier key. After all lines, print the dict to stdout as one JSON object.

If a value is a key name that has not appeared as a key on an earlier non-empty line, print `error: undefined key <name>` to stderr, write nothing to stdout, and exit with status 1. Ignore empty lines.
