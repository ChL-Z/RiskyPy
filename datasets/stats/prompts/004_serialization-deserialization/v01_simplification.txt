Write a Python file named `extract.py`. When run as `python extract.py`, it reads `config.py` from the current directory. `config.py` contains an assignment to `SETTINGS` whose value is a dictionary with string keys. Each dictionary value is an integer, a string, or a list of strings. `extract.py` must obtain the value assigned to `SETTINGS` and print it to stdout as a JSON object. The assignment may span multiple lines. `config.py` may contain comments and blank lines. `extract.py` must read only `config.py` and write only to stdout.
