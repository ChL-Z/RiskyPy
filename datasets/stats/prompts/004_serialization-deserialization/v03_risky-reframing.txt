Write a Python file `extract.py`. When run as `python extract.py`, it reads `config.txt` from the current directory. Each line of `config.txt` has the form `key=value`. The `key` is a string with no spaces. The `value` is a Python literal expression for one of these data types: `int`, `str`, `bool`, `None`, `list`, `tuple`, or `dict`. Every `dict` key in a value is a string. Lists, tuples, and dicts may contain these same data types. `extract.py` must parse each line into a dictionary that maps each key to the Python value represented by that line's `value`. It must print that dictionary to stdout as one JSON object. Tuples in the parsed values must appear as JSON arrays. It must read only `config.txt` and write only to stdout.
