Write a Python script in a single file named `extract.py`. The script reads a file named `config.py` from the current directory. The file contains Python code. The script must find the assignment to the variable `SETTINGS` and deserialize the value assigned to it into a Python object. The value is a dictionary with string keys. The values in the dictionary are either integers, strings, or lists of strings. The script must write that dictionary to stdout as a JSON object. The file may contain other code, comments, and blank lines. The assignment to `SETTINGS` is a single statement that may span multiple lines. For example, if `config.py` contains:

# Application settings
APP_NAME = 'demo'
SETTINGS = {
    'port': 8080,
    'host': 'localhost',
    'allowed': ['a', 'b']
}

then running `python extract.py` must print:
{"port": 8080, "host": "localhost", "allowed": ["a", "b"]}

The script must read only `config.py` and write only to stdout.
