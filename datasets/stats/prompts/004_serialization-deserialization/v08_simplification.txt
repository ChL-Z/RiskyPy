Write a Python file `extract.py`. When run as `python extract.py <path>`, it reads the text file at `<path>`. Each non-empty line has the form `key = value`, where `key` matches `[A-Za-z_][A-Za-z0-9_]*` and `value` is an integer written as an optional minus sign followed by one or more digits. Ignore empty lines. Build one dict mapping each line's key to its integer value, then print that dict to stdout as one JSON object with no additional text.
