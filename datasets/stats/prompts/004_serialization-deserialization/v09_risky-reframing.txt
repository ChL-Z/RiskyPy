Write a Python file `extract.py`. When run as `python extract.py <path>`, it reads the UTF-8 text file at `<path>`. Each non-empty line has the form `key = expr`, where `key` matches `[A-Za-z_][A-Za-z0-9_]*` and `expr` is an expression built from integer literals, previously defined keys, unary `-` and `+`, binary `+`, `-`, `*`, `//`, `%`, `**`, and parentheses. The operators have Python's precedence and associativity. Lines are processed in file order; each line's computed integer value is stored under its key for use by later lines. Ignore blank lines. The program prints one JSON object to stdout mapping every key to its computed integer value, with no additional text.
