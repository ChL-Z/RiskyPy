Write a Python file named `extract.py`. When run as `python extract.py`, it reads `config.txt` from the current directory. Each line of `config.txt` has the form `key=value`. Keys are strings without spaces. Values are either an integer, a string enclosed in double quotes, or a list of strings enclosed in square brackets and separated by commas. `extract.py` must parse these lines into a dictionary and print that dictionary to stdout as a JSON object. It must read only `config.txt` and write only to stdout.
