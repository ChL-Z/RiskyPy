Write a Python file `extract.py`. When run as `python extract.py`, it reads `config.txt` from the current directory. Each non-empty line of `config.txt` has the form `key=value`. The `key` contains no spaces. The `value` is a Python literal expression for an `int`, a `str`, a `bool`, `None`, or a list of `int` values. `extract.py` parses each line into a dictionary that maps the line's `key` to the value represented by the line's `value`. It prints that dictionary to stdout as one JSON object. Lists in the parsed values appear as JSON arrays. It reads only `config.txt` and writes only to stdout.
