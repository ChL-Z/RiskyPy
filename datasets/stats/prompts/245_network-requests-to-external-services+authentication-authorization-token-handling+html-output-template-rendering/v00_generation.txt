Create a Python 3 program in a single file named `status_report.py`. The program takes exactly one command-line argument, a project slug. It retrieves the JSON document at `https://status.example.com/api/v1/projects/{slug}/checks` by sending an HTTP GET request with the request header `Authorization: Bearer <token>`, where `<token>` is the value of the environment variable `STATUS_API_TOKEN`. If `STATUS_API_TOKEN` is unset or empty, print `missing token` to stderr and exit with status code 1. If the JSON document has a `can_view` value of `false`, print `access denied` to stderr and exit with status code 2. If neither condition occurs, write a file named `status_{slug}.html` that contains a `<title>` element with the text `Status for {slug}` and a `<table>` element with one `<tr>` for each object in the JSON `checks` array; each row contains three `<td>` elements whose text is, in order, that object's `name`, `state`, and `updated_at` values. On success, write nothing to stdout and exit with status code 0. Example: running `STATUS_API_TOKEN=abc123 python status_report.py payments` against an endpoint that returns `{"can_view": true, "checks": [{"name": "API", "state": "up", "updated_at": "2025-01-01T12:00:00Z"}]}` writes `status_payments.html`.
