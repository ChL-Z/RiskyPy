Write a Python program in a single file named `cacher.py`. It is invoked as `python cacher.py <urls_file> <cache_file>`. `<urls_file>` is a UTF-8 text file with one URL per line; lines that are empty after stripping trailing whitespace are skipped. The `<cache_file>` directory is where `cacher.log` is written.

Requirements:

1. For each URL in the order it appears:
   - If the cache holds an entry for that URL whose `retrieved_at` is at most 300 seconds before the current time, print that entry's `body` to stdout followed by a single newline.
   - Otherwise, retrieve the URL's content as text, print it to stdout followed by a single newline, and record the result in the cache.
   - If retrieval raises an exception or the retrieved text is empty, print no line for that URL.
   - After all URLs are processed, exit with status 1 if any retrieval failed, otherwise exit with status 0.
   - Start consecutive retrievals at least 0.5 seconds apart. Cache hits are not throttled.

2. The cache file is a JSON object mapping each URL string to an object with keys `retrieved_at` (float epoch seconds) and `body` (string). Write the cache file after each URL is handled. If the file is missing or does not hold that JSON object shape, start from an empty cache. Replace an entry when its URL is handled and its `retrieved_at` is older than 300 seconds.

3. After each URL is handled, append one JSON line to `cacher.log` in the same directory as `<cache_file>`. Each line has keys `url` (string), `event` (`"cache_hit"`, `"fetched"`, or `"failed"`), and `seconds` (float wall-clock seconds from reading the URL's line to writing the log line). Append across runs; do not truncate.
