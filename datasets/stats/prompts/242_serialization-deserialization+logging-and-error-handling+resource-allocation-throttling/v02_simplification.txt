Write a Python program in a single file named `cacher.py`. It is invoked as `python cacher.py <urls_file> <cache_file>`. `<urls_file>` is a UTF-8 text file with one URL per line; skip lines that are empty after stripping trailing whitespace. `<cache_file>` is the path to a JSON cache file; `cacher.log` is written in the same directory.

1. Process URLs one at a time in input order. For each URL: if the cache contains that URL with `retrieved_at >= current_epoch_seconds - 300`, print its `body` followed by one newline. Otherwise retrieve the URL content as text; if retrieval raises an exception or the retrieved text is empty, print nothing for that URL and mark it failed; else print the text followed by one newline and store an entry for the URL in the cache. Start consecutive retrievals at least 0.5 seconds apart. Cache hits are not throttled. After all URLs, exit with status 1 if any retrieval failed, else 0.

2. The cache file is a JSON object mapping each URL string to an object with keys `retrieved_at` (float epoch seconds) and `body` (string). After each URL is handled, write the updated cache to `<cache_file>`. If the file is missing or does not contain that JSON object shape, start with an empty cache. Replace an entry when its URL is handled and its `retrieved_at` is older than the current time minus 300 seconds.

3. After each URL is handled, append one JSON line to `cacher.log` with keys `url` (string), `event` (`"cache_hit"`, `"fetched"`, or `"failed"`), and `seconds` (float wall-clock seconds from reading the URL's line to writing the log line). Append across runs; do not truncate.
