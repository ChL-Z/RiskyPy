Write a Python program in a single file named `cacher.py`. It is run as `python cacher.py <urls_file> <cache_file>`. `<urls_file>` is a UTF-8 text file. `<cache_file>` is the path to a JSON cache file. Write `cacher.log` in the same directory as `<cache_file>`.

For each line of `<urls_file>` in order, remove trailing whitespace. If the result is empty, skip it. Otherwise handle the URL as follows, then append one log line. If the cache contains that URL with `retrieved_at >= current_epoch_seconds - 300`, print its `body` followed by one newline. Otherwise retrieve the URL content as text. If retrieval raises an exception or the retrieved text is empty, print nothing and mark the URL failed. If retrieval succeeds, print the text followed by one newline and store `{ "retrieved_at": current_epoch_seconds, "body": text }` for that URL in the cache. Consecutive retrievals must start at least 0.5 seconds apart. Cache hits are not throttled. After all lines, exit with status 1 if any URL failed, otherwise 0.

The cache file is a JSON object mapping each URL string to an object with keys `retrieved_at` (float epoch seconds) and `body` (string). After handling each non-skipped URL, write the full cache to `<cache_file>`. If `<cache_file>` is missing or its content is not a JSON object whose values are objects with those keys and value types, start with an empty cache. Append one line to `cacher.log` after handling each non-skipped URL. Each log line is a JSON object with keys `url` (string), `event` (`"cache_hit"`, `"fetched"`, or `"failed"`), and `seconds` (float wall-clock seconds from reading that URL line to writing the log line). Append across runs; do not truncate `cacher.log`.
