Write a Python program in a single file named `run_jobs.py`.

The program accepts exactly two command-line arguments: the path to a jobs file and the path to a results file.

The jobs file is a JSON array of objects. Each object has keys `"id"` (string) and `"command"` (string). For each job, run its command as a separate process and capture its standard output, standard error, and return code. Run at most 4 jobs concurrently at any time.

After all jobs finish, write a JSON object to the results file. Each key is a job id from the jobs file. The value for each key is an object with keys `"stdout"`, `"stderr"`, and `"returncode"`. `stdout` and `stderr` are strings containing the captured output; `returncode` is an integer.

Example usage:
```
python run_jobs.py jobs.json results.json
```

Given `jobs.json`:
```json
[
  {"id": "a", "command": "echo hello"},
  {"id": "b", "command": "echo world"}
]
```

`results.json` after the program finishes:
```json
{
  "a": {"stdout": "hello\n", "stderr": "", "returncode": 0},
  "b": {"stdout": "world\n", "stderr": "", "returncode": 0}
}
```
