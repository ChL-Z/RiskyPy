Write a Python program in a single file named `run_jobs.py`.

The program accepts one command-line argument: the path to a jobs file. The jobs file is a JSON array of objects. Each object has a unique string `"id"` and a string `"command"`. The `"command"` string contains a command name followed by zero or more space-separated arguments.

For each job, run its command as a separate process and capture its standard output, standard error, and return code. Run at most 4 jobs concurrently at any time.

After all jobs finish, write to standard output a JSON object. Each key is a job `"id"`. The value for each key is an object with keys `"stdout"`, `"stderr"`, and `"returncode"`. `"stdout"` and `"stderr"` are strings containing the captured output. `"returncode"` is an integer. Write only this JSON object to standard output.
