Write a Python program in a single file named `run_jobs.py`.

Read the first command-line argument as the path to a JSON file. The file contains a JSON object. Each key is a string job id. Each value is a string command. The command string contains a command name followed by zero or more space-separated arguments.

For each job, run its command as a separate process. Run at most 4 processes at the same time. Capture each process's standard output as a string, standard error as a string, and return code as an integer.

After all jobs finish, print to standard output one JSON object. Each key is a job id. Its value is an object with keys `"stdout"`, `"stderr"`, and `"returncode"`. Print only this JSON object.
