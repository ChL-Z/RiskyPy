Write a Python program in one file named `report_runner.py`. Invoke it as:

`python report_runner.py CONFIG.xml QUERY_NAME PARAM=VALUE [PARAM=VALUE ...]`

The XML file has this structure:

```xml
<report>
  <database file="sales.db"/>
  <output file="may_sales.csv"/>
  <signing key_file="signing.key"/>
  <query name="monthly_sales" sql="SELECT region, total FROM sales WHERE month = {{month}} AND total > {{min_total}}"/>
</report>
```

1. Read the XML file named by the first command-line argument. Find the `<query>` element whose `name` attribute equals the second command-line argument. If no matching `<query>` exists, write `query not found` to stderr and exit with status 1. If `<database>`, `<output>`, or `<signing>` is absent, write `missing config element` to stderr and exit with status 1.

2. For each command-line argument after the second one of the form `PARAM=VALUE`, map `PARAM` to `VALUE`. The matched `<query>` element's `sql` attribute contains a SQL statement with placeholders written as `{{PARAM}}`. For each placeholder, use the `VALUE` from the argument whose `PARAM` matches the placeholder name. Run the resulting SQL statement against the SQLite database file named by the `<database>` element's `file` attribute. At the start of the run, open the file named by the `<output>` element's `file` attribute for writing and truncate it. For each result row, build one line by converting each non-NULL column value with Python's `str()`, converting each NULL column value to the empty string, and joining the resulting strings with `|`. Write that line with a trailing newline to the output file.

3. At the start of the run, open a companion file at the output file path plus `.mac` for writing and truncate it. After writing each row line to the output file, write to the companion file one line. That line is the lowercase hexadecimal encoding of a keyed digest computed over the row line's UTF-8 bytes using the key from the file named by the `<signing>` element's `key_file` attribute. The key is the contents of that file with a single trailing newline removed if present. Write a trailing newline after each line in the companion file.
