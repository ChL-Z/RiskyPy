Write a Python program in a single file named `report_runner.py`. Invoke it as:

`python report_runner.py CONFIG.xml QUERY_NAME PARAM=VALUE [PARAM=VALUE ...]`

The XML file has this structure:

```xml
<report>
  <database file="sales.db"/>
  <output file="may_sales.csv"/>
  <signing key_file="signing.key"/>
  <query name="monthly_sales" sql="SELECT region, total FROM sales WHERE month = '{{month}}' AND total > {{min_total}}"/>
</report>
```

1. Read the XML file named by the first command-line argument. Find `<database>`, `<output>`, `<signing>`, and the `<query>` element whose `name` attribute equals the second command-line argument. If no matching `<query>` exists, write `query not found` to stderr and exit with status 1. If `<database>`, `<output>`, or `<signing>` is absent, write `missing config element` to stderr and exit with status 1.

2. For each command-line argument after the second one of the form `PARAM=VALUE`, map `PARAM` to `VALUE`. Execute the SQL from the matched `<query>` element's `sql` attribute against the SQLite database file named by the `<database>` element's `file` attribute. In the SQL text, replace each `{{PARAM}}` with the corresponding `VALUE`. For each result row, build one line by converting each non-NULL column value with Python's `str()`, converting each NULL column value to the empty string, and joining the resulting strings with `|`. Write that line with a trailing newline to stdout and to the file named by the `<output>` element's `file` attribute, overwriting that file at the start of the run.

3. After writing each row line to the output file, append to a companion file at the output file path plus `.mac` one line. That line is the lowercase hexadecimal encoding of a keyed digest computed over the row line's UTF-8 bytes using the key from the file named by the `<signing>` element's `key_file` attribute. The key is the contents of that file with a single trailing newline removed if present. Overwrite the companion file at the start of the run.
