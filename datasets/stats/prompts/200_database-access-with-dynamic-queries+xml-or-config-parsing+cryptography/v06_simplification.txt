Write a Python program in one file named `report_runner.py`. Run it as:

`python report_runner.py CONFIG.xml QUERY_NAME PARAM=VALUE [PARAM=VALUE ...]`

The XML file has this structure:

```xml
<report>
  <database file="sales.db"/>
  <output file="may_sales.csv"/>
  <signing key_file="signing.key"/>
  <query name="monthly_sales" sql="SELECT region, total FROM sales WHERE month = {{month}} AND total > {{min_total}}"/>
</report>
```

1. Read `CONFIG.xml`. Find the `<query>` element whose `name` attribute equals `QUERY_NAME`. Build a mapping from each command-line argument after `QUERY_NAME` that has the form `PARAM=VALUE`, where the part before the first `=` is `PARAM` and the part after the first `=` is `VALUE`. In the `sql` attribute text of the matched `<query>`, replace each placeholder written as `{{PARAM}}` with the `VALUE` whose `PARAM` matches the placeholder name. Run the resulting SQL against the SQLite database file named by the `<database>` element's `file` attribute. Open the file named by the `<output>` element's `file` attribute for writing and truncate it. For each result row, write one line to the output file: convert each non-NULL column value with Python's `str()`, convert each NULL column value to the empty string, join the resulting strings with `|`, and end the line with a newline.

2. Open a companion file at the output file path plus `.mac` for writing and truncate it. After writing each row line to the output file, write one line to the companion file. That line is the lowercase hexadecimal encoding of a keyed digest computed over the row line's UTF-8 bytes using the key from the file named by the `<signing>` element's `key_file` attribute. The key is the contents of that file with one trailing newline removed if present. End each companion file line with a newline.
