Write a Python program in a single file named `report_runner.py`. The program is invoked as:

`python report_runner.py CONFIG.xml QUERY_NAME PARAM=VALUE [PARAM=VALUE ...]`

The XML file has this structure:

```xml
<report>
  <database file="sales.db"/>
  <output file="may_sales.csv"/>
  <signing key="secret-key-123"/>
  <query name="monthly_sales" sql="SELECT region, total FROM sales WHERE month = '{{month}}' AND total > {{min_total}}"/>
</report>
```

Requirements:

1. Read the XML file. Find the `<database>` element, the `<output>` element, the `<signing>` element, and the `<query>` element whose `name` attribute equals `QUERY_NAME`. If no such `<query>` element exists, write `query not found` to stderr and exit with status 1. If any of the other three elements is missing, write `missing config element` to stderr and exit with status 1.

2. For each `PARAM=VALUE` argument, replace every occurrence of `{{PARAM}}` in the query's `sql` attribute with `VALUE`. Run the resulting SQL text against the SQLite database file named by the `file` attribute of `<database>`. For each result row, print one line to stdout. Build that line by converting each non-NULL column value with Python's `str()` and each NULL column value to the empty string, then joining the resulting strings with `|`. Write that same line to the file named by the `<output>` element's `file` attribute, overwriting that file at the start of the run.

3. After writing each row line to the output file, append to a companion file at the output file's path plus `.mac` one line. That line is the lowercase hexadecimal encoding of a keyed digest computed over the row line's UTF-8 bytes using the key from the `<signing>` element's `key` attribute. The companion file is overwritten at the start of the run.

Example: with the XML above and command `python report_runner.py report.xml monthly_sales month=2024-05 min_total=1000`, if the database has a row `("North", 1500)`, stdout contains `North|1500`, the output file contains `North|1500`, and the companion file contains one hexadecimal line.
