Write a Python program in one file named `report_runner.py`. Run it as:

`python report_runner.py CONFIG.xml QUERY_NAME PARAM=VALUE [PARAM=VALUE ...]`

The XML file has this structure:

```xml
<report>
  <database file="sales.db"/>
  <output file="may_sales.csv"/>
  <signing key_file="signing.key"/>
  <query name="monthly_sales" sql="SELECT region, total FROM sales WHERE month = {{month}} AND total > {{min_total}}"/>
</report>
```

The program must:

1. Read `CONFIG.xml`. Select the `<query>` element whose `name` attribute equals `QUERY_NAME`. Build a mapping from the command-line arguments after `QUERY_NAME`: each argument has the form `PARAM=VALUE`; split at the first `=` so that the part before is `PARAM` and the part after is `VALUE`. If the same `PARAM` appears more than once, the last occurrence's `VALUE` is used. In the selected query's `sql` attribute, each substring `{{PARAM}}` denotes the `VALUE` mapped to `PARAM`. Execute the query text against the SQLite database file named by the `file` attribute of the `<database>` element, supplying each `{{PARAM}}` placeholder as a query parameter whose value is the mapped `VALUE`. Open the file named by the `file` attribute of the `<output>` element for writing and truncate it. For each result row, write one line to the output file. Convert each non-NULL column value with Python's `str()`, convert each NULL column value to the empty string, join the resulting strings with `|`, and end the line with `\n`.

2. Open a companion file at the output file path plus `.mac` for writing and truncate it. After writing each row line to the output file, write one line to the companion file. That line is the lowercase hexadecimal encoding of a keyed digest computed over the row line's UTF-8 bytes using the key from the file named by the `key_file` attribute of the `<signing>` element. The key is the contents of that file with one trailing newline removed if present. End each companion file line with `\n`.
