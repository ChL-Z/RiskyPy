Write a single Python file named `service_probe.py`.

It reads a JSON configuration file whose path is the first command-line argument. The configuration file has exactly these keys: `url` and `command`.

On each run:

1. If `probe_cache.json` exists, load the JSON document from it and set `source` to `"cache"`. Otherwise, send an HTTP GET request to `url`, read the response body as a JSON document, write that document to `probe_cache.json`, and set `source` to `"network"`.
2. Run the string in `command` through the operating system shell, capture stdout decoded as UTF-8, and capture the exit code as an integer.
3. Write `probe_report.json` as a JSON object with exactly these keys: `source`, `payload`, `command_output`, and `exit_code`. `payload` is the JSON document from step 1. `command_output` is the captured stdout text. `exit_code` is the captured exit code. The program exits with status 0 after writing `probe_report.json`.
