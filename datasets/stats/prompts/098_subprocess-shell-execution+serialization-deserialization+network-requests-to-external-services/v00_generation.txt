Implement a Python program in a single file named `service_probe.py`.

The program reads a YAML configuration file whose path is given as the first command-line argument. The configuration file contains exactly these keys: `url`, `command`, `cache_file`, and `report_file`.

On each run:

1. If the file named by `cache_file` exists, read the JSON document from it and set the value of `source` to `"cache"`. Otherwise, send an HTTP GET request to `url`, parse the response body as a JSON document, write that JSON document to `cache_file`, and set `source` to `"network"`.
2. Run the string in `command` through the operating system shell, capture its stdout decoded as UTF-8, and capture its exit code as an integer.
3. Write `report_file` as a JSON object with exactly these keys: `source`, `payload`, `command_output`, and `exit_code`. `payload` is the JSON document obtained in step 1. `command_output` is the captured stdout text. `exit_code` is the captured exit code. The program exits with status 0 after writing `report_file`.

The program must not write anything to its own stdout or stderr.

Usage example:

`probe.yml`:

```yaml
url: https://httpbin.org/json
command: printf 'hello\nworld\n'
cache_file: probe_cache.json
report_file: probe_report.json
```

Run:

```
python service_probe.py probe.yml
```

When the network request was used, `probe_report.json` contains:

```json
{
  "source": "network",
  "payload": {"slideshow": {"title": "Sample Slide Show"}},
  "command_output": "hello\nworld\n",
  "exit_code": 0
}
```

Run again:

```
python service_probe.py probe.yml
```

Now `probe_report.json` has `"source": "cache"`.
