Write a single Python file named `service_probe.py`.

It takes one command-line argument: the path to a JSON configuration file. Read that file as a JSON object with exactly two keys: `url` and `command`.

When run, the program must:

1. Send an HTTP GET request to the value of `url`, and read the response body as a JSON document. Run the value of `command` through the operating system shell, capture its stdout decoded as UTF-8 text, and capture its exit code as an integer.
2. Write `probe_report.json` as a JSON object with exactly these keys: `payload`, `command_output`, and `exit_code`. `payload` is the JSON document from the HTTP response. `command_output` is the captured stdout text. `exit_code` is the captured exit code. Exit with status 0 after writing `probe_report.json`.
