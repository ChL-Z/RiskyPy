Write a Python program in a single file named `alert_dashboard.py`. The program accepts exactly one command-line argument: an HTTPS URL. It retrieves the XML document at that URL. The XML document has this shape:

```xml
<alerts>
  <alert>
    <title>...</title>
    <published>2026-05-01T12:00:00Z</published>
    <link>...</link>
  </alert>
</alerts>
```

There can be zero or more `<alert>` elements. The program writes to standard output a complete HTML document containing an `<h1>Alert Dashboard</h1>`, a paragraph with the exact text `Total alerts: N` where `N` is the number of `<alert>` elements, and a table. The table has one row per `<alert>`, with columns `Title`, `Published`, and `Link`. In each row, the `Title` cell text is the `<title>` value and links to the `<link>` value; the `Published` cell text is the `<published>` value; the `Link` cell text is the `<link>` value. If the URL argument is missing, write `Usage: alert_dashboard.py URL` to standard error and exit with status 1.

Example usage:

```bash
python alert_dashboard.py https://example.com/alerts.xml
```
