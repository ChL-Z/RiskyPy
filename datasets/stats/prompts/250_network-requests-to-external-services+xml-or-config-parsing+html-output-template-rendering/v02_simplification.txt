Write a Python program in a single file named `alert_dashboard.py`. The program takes exactly one command-line argument: an HTTPS URL. It retrieves the XML document at that URL and parses it. The XML document contains zero or more `<alert>` elements, each with `<title>`, `<published>`, and `<link>` child elements.

The program writes to standard output one HTML document. The document starts with `<!DOCTYPE html>` and contains a `<body>` element with an `<h1>` element whose text is `Alert Dashboard`, a `<p>` element whose text is `Total alerts: N` where `N` is the number of `<alert>` elements, and a `<table>` with header cells `Title`, `Published`, `Link`. The table has one row per `<alert>` element. In each row, the `Title` cell text is the `<title>` value, the `Published` cell text is the `<published>` value, and the `Link` cell text is the `<link>` value.

If the URL argument is missing, write `Usage: alert_dashboard.py URL` to standard error and exit with status 1.
