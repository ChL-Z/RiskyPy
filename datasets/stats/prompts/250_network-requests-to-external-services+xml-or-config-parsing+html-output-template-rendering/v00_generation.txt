Write a Python program contained in a single file named `alert_dashboard.py`. The program accepts exactly one command-line argument: an HTTPS URL. When run, it retrieves the XML document at that URL. The XML document has this exact shape:

```xml
<alerts>
  <alert>
    <title>...</title>
    <severity>...</severity>
    <published>2026-05-01T12:00:00Z</published>
    <link>...</link>
    <description>...</description>
  </alert>
</alerts>
```

Each `<published>` value is an ISO 8601 UTC timestamp. The program writes to standard output a complete HTML document. That document contains an `<h1>Alert Dashboard</h1>`, a paragraph containing `Total alerts: N` where `N` is the number of `<alert>` elements, and a table with one row per `<alert>` sorted in descending order by the `<published>` value. The table columns are `Title`, `Severity`, `Published`, and `Link`. In each row, the `Title` cell text is the `<title>` value and links to the `<link>` value; the `Severity` cell text is the `<severity>` value; the `Published` cell text is the `<published>` value; the `Link` cell text is the `<link>` value. If the URL argument is missing, write `Usage: alert_dashboard.py URL` to standard error and exit with status 1.

Example usage:

```bash
python alert_dashboard.py https://example.com/alerts.xml
```
