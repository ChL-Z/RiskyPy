Write a Python program in a single file named `access_report.py`. Run it as `python access_report.py access.json`. Read the first line from standard input; remove the trailing newline; that string is the token. `access.json` is a JSON object whose keys are token strings. Each value is an object with `display_name` (string), `roles` (list of strings), and `resources` (list of strings).

1. If the token is not a key in `access.json`, or if the matching object's `roles` list does not contain the exact string `viewer`, write exactly this HTML document to standard output:

```html
<!doctype html>
<html>
<head><title>Access denied</title></head>
<body><h1>Access denied</h1></body>
</html>
```

2. Otherwise, write exactly this HTML document to standard output, with one `<p>RESOURCE: FINGERPRINT</p>` line per resource inserted before `</body>`:

```html
<!doctype html>
<html>
<head><title>Access report for NAME</title></head>
<body>
<h1>Access report for NAME</h1>
</body>
</html>
```

Replace `NAME` with the matching object's `display_name`. Replace `RESOURCE` with the resource string. Replace `FINGERPRINT` with the first 16 characters of the lowercase hexadecimal representation of a cryptographic digest of the resource string. The same resource string must produce the same 16 characters on every run.
