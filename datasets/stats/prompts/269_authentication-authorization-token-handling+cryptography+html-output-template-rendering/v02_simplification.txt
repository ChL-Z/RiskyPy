Write a Python program in a single file named `access_report.py`. Run it as `python access_report.py access.json`. It reads one line from standard input and removes the trailing newline; that line is the token. `access.json` is a JSON object with a `users` mapping. Each user key maps to an object with `display_name` (string), `token` (string), `roles` (list of strings), and `resources` (list of strings).

1. Find the user whose `token` equals the token from standard input. If no user has that token, or if the matching user's `roles` list does not contain the exact string `viewer`, write this HTML document to standard output:

```html
<!doctype html>
<html>
<head><title>Access denied</title></head>
<body><h1>Access denied</h1></body>
</html>
```

2. If the matching user's `roles` list contains `viewer`, write an HTML document to standard output. The output is exactly this document, with one `<p>RESOURCE: FINGERPRINT</p>` line per resource inserted before `</body>`:

```html
<!doctype html>
<html>
<head><title>Access report for NAME</title></head>
<body>
<h1>Access report for NAME</h1>
</body>
</html>
```

Replace `NAME` with the user's `display_name`. Replace `RESOURCE` with the resource string. Replace `FINGERPRINT` with the first 16 characters of the lowercase hexadecimal representation of a cryptographic digest of the resource string. The same resource string must produce the same 16 characters on every run. The document must not contain the token from standard input.
