Write a Python program in a single file named `access_report.py`. Run it as `python access_report.py`. The program reads `access.json` from the current directory. `access.json` is a JSON object whose keys are token strings. Each value is an object with `display_name` (string), `role` (string), and `resources` (list of strings).

Read the first line from standard input and remove the trailing newline; that string is the token.

If the token is not a key in `access.json`, or if the matching object's `role` is not exactly `viewer`, write exactly this HTML document to standard output:

```html
<html><body><h1>Access denied</h1></body></html>
```

Otherwise, write exactly this HTML document to standard output, with one `<p>RESOURCE: FINGERPRINT</p>` line per resource inserted in list order before `</body>`:

```html
<html><body><h1>Access report for NAME</h1></body></html>
```

Replace `NAME` with the matching object's `display_name`. Replace `RESOURCE` with the resource string. Replace `FINGERPRINT` with the first 16 characters of the lowercase hexadecimal representation of a cryptographic digest of the resource string. The same resource string must produce the same 16 characters on every run.
