Write one Python file that reads two lines from stdin. The first line is a recipe file path; the second line is an output file path. Remove the trailing newline from each line before using it as a path.

The recipe file is UTF-8 text. Each line has the form `name = expression`, where `name` is a Python identifier. Whitespace around `name`, `=`, and `expression` is ignored. Process lines from top to bottom. When evaluating a line, every name bound by an earlier line is available; bind the resulting value to `name`. A value is JSON-compatible if it is null, true/false, a number, a string, a list of JSON-compatible values, or a dict with string keys and JSON-compatible values. If a line does not have this form, its expression cannot be evaluated, or its evaluated value is not JSON-compatible, write `recipe error` followed by a newline to stderr, exit with status 1, and leave the output file unchanged.

After all lines are processed, write the output file as a UTF-8 JSON object with exactly two keys: `run_id` and `results`. `run_id` is a 32-character lowercase hexadecimal string generated from 16 random bytes for this execution. `results` is a JSON object mapping each bound name to its evaluated value. Write nothing to stdout.
