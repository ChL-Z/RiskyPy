Write one Python file. It reads two lines from standard input: the first line is a recipe file path, and the second line is an output file path. Remove the trailing newline from each line before using it as a path.

The recipe file is UTF-8 text. Each line has the form `name = expression`, where `name` matches `[A-Za-z_][A-Za-z0-9_]*` and `expression` is a Python expression. Whitespace around `name`, `=`, and `expression` is ignored. Process lines from top to bottom. When processing a line, every name bound by an earlier line is available while evaluating that line's expression; bind the resulting value to `name`. If a line does not have this form or its expression cannot be evaluated, write a message to standard error, exit with status 1, and leave the output file unchanged.

After all lines are processed, write the output file as a UTF-8 JSON object with exactly two keys:
- `run_id`: the lowercase hexadecimal encoding of 16 bytes of randomness generated for this execution.
- `results`: a JSON object mapping each bound name to its evaluated value, with keys in the order the names were bound.

Write nothing to standard output.
