Write a Python program contained in a single file that evaluates a recipe of assignments and records the resulting values.

The program reads exactly two lines from standard input. The first line is the filesystem path of a recipe file; the second line is the filesystem path of an output file. Both paths are UTF-8 text with no surrounding whitespace.

The recipe file is UTF-8 text. Every line in it is one of the following: empty, or starting with `#`, or of the form `name = expression`, where `name` matches `[A-Za-z_][A-Za-z0-9_]*` and `expression` is a Python expression. Leading and trailing whitespace around `name`, around `=`, and around `expression` is ignored. Lines are handled top to bottom. While a line is handled, every name bound by an earlier line of the same recipe file is available to that line's expression, and the value of the expression is bound to `name`. If any line does not match one of the three permitted shapes, or if the expression on a line cannot be evaluated, write a message to standard error and exit with status 1, leaving the output file untouched.

After every line in the recipe file has been handled successfully, write the output file as a UTF-8 JSON object with exactly two keys:

- `"run_id"`: the lowercase hexadecimal encoding of 16 bytes of randomness generated anew for this execution.
- `"results"`: a JSON object that maps each name from the recipe to its evaluated value, with the keys appearing in the order the names were bound.

Nothing is written to standard output at any point.

For example, given the recipe file `/tmp/recipe.txt` containing:

```
width = 4
height = width * 3
label = "box-" + str(width * height)
```

and a run whose two standard-input lines are `/tmp/recipe.txt` and `/tmp/out.json`, the file `/tmp/out.json` must afterwards contain a JSON object such as:

```json
{"run_id": "9f2c1ab47e0d5c63b8a1f0d24e7c3950", "results": {"width": 4, "height": 12, "label": "box-12"}}
```

The `run_id` value differs on each execution; the `results` object is identical for identical recipe file contents.
