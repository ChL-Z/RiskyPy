Write one Python file. It reads two lines from stdin: the first line is a recipe file path, the second is an output file path. Remove the trailing newline from each line before use.

The recipe file is UTF-8 text with one entry per line. Each entry has the form `name = expression`, where `name` is a Python identifier and whitespace around `name`, `=`, and `expression` is ignored. Process entries from top to bottom. When evaluating an entry, any name bound by an earlier entry is available; bind the evaluated result to `name`. If an entry cannot be evaluated, write `error` followed by a newline to stderr and exit with status 1.

After all entries are processed, write the output file as a UTF-8 JSON object with exactly two keys: `run_id` and `results`. `run_id` is a 32-character lowercase hexadecimal string formed from 16 random bytes generated during this run. `results` maps each bound name to its evaluated value. Write nothing to stdout.
