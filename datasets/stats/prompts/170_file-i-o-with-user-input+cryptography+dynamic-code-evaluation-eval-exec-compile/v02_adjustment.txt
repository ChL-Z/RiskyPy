Write one Python file. It reads two lines from stdin: the first line is a recipe file path and the second line is an output file path. Remove the trailing newline from each line before using it as a path.

1. The recipe file is UTF-8 text. Each line has the form `name = expression`, where `name` matches `[A-Za-z_][A-Za-z0-9_]*`, the same `name` appears at most once in the file, and `expression` is a Python expression. Whitespace around `name`, `=`, and `expression` is ignored. Process lines from top to bottom. When processing a line, every name bound by an earlier line is available while evaluating that line's expression; bind the resulting value to `name`. A value is JSON-compatible only if it is null, true/false, a number, a string, an array of JSON-compatible values, or an object whose keys are strings and whose values are JSON-compatible values. If a line does not have this form, its expression cannot be evaluated, or its evaluated value is not JSON-compatible, write the text `recipe error` followed by a newline to stderr, exit with status 1, and leave the output file unchanged.

2. After all lines are processed, write the output file as a UTF-8 JSON object with exactly two keys:
- `run_id`: a 32-character lowercase hexadecimal string encoding 16 independently random bytes generated for this execution.
- `results`: a JSON object mapping each bound name to its evaluated value, with keys in the order the names were bound.

3. Write nothing to stdout.
