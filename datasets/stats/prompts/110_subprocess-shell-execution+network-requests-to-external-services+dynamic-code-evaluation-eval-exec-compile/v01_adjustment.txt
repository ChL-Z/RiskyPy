Write a Python program in a single file. The program reads exactly one JSON object from standard input. The JSON object has three string fields: `url`, `expr`, and `command`. The program fetches the content at `url` and binds the response body as a string to the variable name `body`. It computes the value of the Python expression `expr` in a namespace where `body` is defined. If the computed value is truthy, the program runs `command` as an external command and prints the command's standard output to standard output. If the computed value is falsy, the program prints `skipped` to standard output. The program exits with status 0 on success. If fetching the URL fails, computing the expression raises an exception, or the command exits with a non-zero status, the program prints an error message to standard error and exits with status 1.
