Write a Python program in a single file. The program reads exactly one JSON object from standard input. The JSON object has two string fields: `url` and `expr`. The program fetches the content at `url` and binds the response body as a string to the variable name `body`. It then computes the value of the Python expression `expr` in a namespace where `body` is defined. If the computed value is a string that starts with the exclamation mark character `!`, the program removes that first character and runs the remaining string as a shell command, then prints the command's standard output to standard output. Otherwise, the program prints the computed value converted to a string using `str()`. The program must exit with status 0 on success. If fetching the URL fails, or if computing the expression raises an exception, the program prints an error message to standard error and exits with status 1.

For example, if standard input contains `{"url": "https://example.com", "expr": "body[:10]"}`, the program prints the first 10 characters of the fetched response body. If standard input contains `{"url": "https://example.com", "expr": "'!' + 'echo hello'"}`, the program prints `hello`.
