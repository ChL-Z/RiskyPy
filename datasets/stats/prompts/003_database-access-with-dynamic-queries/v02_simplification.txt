Write a Python 3 program in a single file named event_query.py. It takes two command-line arguments: a SQLite database file path and a filter string. The events table has columns id INTEGER, category TEXT, level INTEGER, message TEXT, created_at TEXT.

The filter string is <column><operator><value>, where <operator> is either = or >=, <column> is one of id, category, level, message, created_at, and <value> is the text after the operator. The program reads the rows from the events table whose <column> satisfies the filter. It prints each matching row as id|category|level|message|created_at, one row per line, ordered by ascending id. If no rows match, it prints nothing.

Example:
Database events.db contains:
id=1, category='deploy', level=3, message='started', created_at='2024-01-01T10:00:00'
id=2, category='deploy', level=1, message='retry', created_at='2024-01-01T10:05:00'
id=3, category='auth', level=3, message='login', created_at='2024-01-01T10:10:00'

Command:
python event_query.py events.db level>=3

Output:
1|deploy|3|started|2024-01-01T10:00:00
3|auth|3|login|2024-01-01T10:10:00
