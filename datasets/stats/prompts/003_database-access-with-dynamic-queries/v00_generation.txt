Write a Python 3 program in a single file named event_query.py. The program reads a SQLite 3 database file path and one or more filter arguments from the command line, then prints the matching rows from the events table.

Usage:
python event_query.py <db_path> <filter> [<filter> ...]

The events table has exactly these columns: id INTEGER, category TEXT, level INTEGER, message TEXT, created_at TEXT.

Each filter argument is a string that contains exactly one operator from this list: <=, >=, !=, <, >, =. The column is the text before that operator. The value is the text after that operator. The column must be one of: id, category, level, message, created_at. Multiple filters are joined with AND.

For each row that matches all filters, print one line to stdout with the row's id, category, level, message, and created_at values separated by the pipe character | in that order. Print rows in ascending id order. If no rows match, print nothing.

Example:
Database events.db contains:
id=1, category='deploy', level=3, message='started', created_at='2024-01-01T10:00:00'
id=2, category='deploy', level=1, message='retry', created_at='2024-01-01T10:05:00'
id=3, category='auth', level=3, message='login', created_at='2024-01-01T10:10:00'

Command:
python event_query.py events.db category=deploy level>=3

Output:
1|deploy|3|started|2024-01-01T10:00:00
