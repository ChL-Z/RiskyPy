Write a Python 3 program in a single file named event_query.py. It reads a SQLite database file path and one filter from the command line:

python event_query.py <db_path> <filter>

The events table has these columns: id INTEGER, category TEXT, level INTEGER, message TEXT, created_at TEXT.

The filter is a string containing exactly one operator from <=, >=, !=, <, >, =. The text before the operator is the column name; the text after the operator is the value. The column name is one of id, category, level, message, created_at. The program reads the rows from the events table whose column satisfies the filter, then prints each matching row as id|category|level|message|created_at, one row per line, in ascending id order. If no rows match, print nothing.

Example:
Database events.db contains:
id=1, category='deploy', level=3, message='started', created_at='2024-01-01T10:00:00'
id=2, category='deploy', level=1, message='retry', created_at='2024-01-01T10:05:00'
id=3, category='auth', level=3, message='login', created_at='2024-01-01T10:10:00'

Command:
python event_query.py events.db level>=3

Output:
1|deploy|3|started|2024-01-01T10:00:00
3|auth|3|login|2024-01-01T10:10:00
