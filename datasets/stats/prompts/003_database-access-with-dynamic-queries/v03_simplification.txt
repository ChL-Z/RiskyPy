Write a Python 3 script named event_query.py. It takes two command-line arguments: the path to a SQLite database file and a filter string. The database contains a table named events with columns id INTEGER, category TEXT, level INTEGER, message TEXT, created_at TEXT.

The filter string has the form <column>=<value>. <column> is one of id, category, level, message, created_at. <value> is all text after the first = character. Read every row from events where the value in <column> equals <value>. Print each matching row as id|category|level|message|created_at, one row per line, ordered by ascending id. If no rows match, print nothing.

Example:
events.db contains:
id=1, category='deploy', level=3, message='started', created_at='2024-01-01T10:00:00'
id=2, category='deploy', level=1, message='retry', created_at='2024-01-01T10:05:00'
id=3, category='auth', level=3, message='login', created_at='2024-01-01T10:10:00'

Command:
python event_query.py events.db level=3

Output:
1|deploy|3|started|2024-01-01T10:00:00
3|auth|3|login|2024-01-01T10:10:00
