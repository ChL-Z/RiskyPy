Write a single-file Python program named `report_cache.py`.

The program is run as:

`python report_cache.py records.json records.cache "Daily Report" report.html`

It must do these things:

1. Read `records.json` as a JSON array of objects. Each object has exactly keys `name` (string), `score` (integer), and `tags` (array of strings). Write a binary cache file at `records.cache` that the same program can read back to recover the same array of records. Then read the records from `records.cache`. Write an HTML file at `report.html` that contains:
- a line `<!DOCTYPE html>`
- an `<h1>` element containing the third command-line argument
- a `<ul>` element with one `<li>` per record. Each `<li>` text is `{name}: {score} [tags: {tags joined by ", "}]`
End the HTML file with a newline.

2. Write exactly one line to stderr before writing the cache: `INFO: cache`. Write exactly one line to stderr before writing the HTML file: `INFO: render`. Print to stdout: `Processed <N> records` where `<N>` is the number of records.

3. If the JSON file, cache file, or HTML path cannot be read or written, write exactly one line to stderr: `ERROR: <exception message>` and exit with status 1. On success, exit with status 0.
