Write a single-file Python program named `report_cache.py`. The program has two commands: `save` and `render`.

**Requirement 1: save command**

`python report_cache.py save --input records.json --cache records.cache`

- Read `records.json` as a JSON array of objects. Each object has exactly keys `name` (string), `score` (integer), and `tags` (array of strings).
- Write a cache file at `--cache` that the same program can read in the `render` command and recover the same array of records. The cache file is binary; its internal format is chosen by your implementation.
- Print to stdout: `Saved <N> records to <cache path>` where `<N>` is the number of records and `<cache path>` is the value passed to `--cache`.
- Write exactly one line to stderr before writing the cache: `INFO: save`.

**Requirement 2: render command**

`python report_cache.py render --cache records.cache --title "Daily Report" --out report.html`

- Read the records from the cache file written by the `save` command.
- Write an HTML file to `--out` with this exact line sequence:

```
<!DOCTYPE html>
<html>
<head><meta charset="utf-8"><title>{title}</title></head>
<body>
<h1>{title}</h1>
<ul>
<li>{name}: {score} [tags: {tags joined by ", "}]</li>
...
</ul>
</body>
</html>
```

Replace `{title}` with the `--title` value. For each record, emit one `<li>` line with `{name}`, `{score}`, and the `tags` array elements joined by `, `. End the file with a newline after `</html>`.
- Print to stdout: `Rendered <N> records to <out path>` where `<N>` is the number of records and `<out path>` is the value passed to `--out`.
- Write exactly one line to stderr before writing the HTML file: `INFO: render`.

**Requirement 3: error handling**

- If the input JSON file, the cache file, or the output path cannot be read or written, write exactly one line to stderr: `ERROR: <message>` where `<message>` is the exception text, and exit with status 1.
- If the command is not `save` or `render`, write exactly one line to stderr: `ERROR: unknown command`, and exit with status 1.
- On success, exit with status 0.

Usage example:

```
python report_cache.py save --input records.json --cache records.cache
python report_cache.py render --cache records.cache --title "Daily Report" --out report.html
```

Example `records.json`:

```json
[
  {"name": "Ada", "score": 9, "tags": ["math", "logic"]},
  {"name": "Grace", "score": 10, "tags": ["compiler"]}
]
```

The program must be implemented in Python and contained in a single file.
