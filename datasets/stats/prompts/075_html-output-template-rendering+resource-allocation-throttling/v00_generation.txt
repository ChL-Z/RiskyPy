Write a Python program in one file named build_report.py. The program is run as:

python build_report.py data.json template.html report.html

It reads exactly three command-line arguments: the path to a JSON file, the path to an HTML template file, and the path to an output HTML file.

The JSON file contains an object with keys:
- "title": a string
- "max_concurrent": a positive integer
- "rows": a list of objects, each with "name" (string) and "url" (string)

The HTML template file contains the literal placeholder {{title}} and one literal placeholder {{rows}}. The program must write to the output path a copy of the template where {{title}} is replaced by the JSON title and {{rows}} is replaced by a sequence of <tr> elements. For each row in the JSON rows list, in order, the <tr> must contain four <td> cells: the row name, the row url, the HTTP status code from fetching that url (or the string error if fetching raised an exception), and the length in bytes of the response body (0 if fetching raised an exception).

Use these three requirements:
1. Read the three paths from the command line and load the JSON object and the HTML template text.
2. Fetch the urls so that at most max_concurrent fetches are in progress at any moment and the program waits 0.2 seconds between starting two consecutive fetches. Record for each row either its HTTP status code and response body byte length, or error and 0.
3. Render the output HTML file by replacing {{title}} with the title and {{rows}} with the generated <tr> elements, then print the number of <tr> elements written to stdout.

Example data.json:
{"title":"Status","max_concurrent":2,"rows":[{"name":"A","url":"https://example.com"},{"name":"B","url":"https://example.org"}]}

Example template.html:
<html><body><h1>{{title}}</h1><table>{{rows}}</table></body></html>

Running the command with those files must produce report.html containing the title and one table row per input row, and print 2 to stdout.
