Write one Python file named build_report.py. It is run from the command line as:

python build_report.py data.json template.html report.html

1. Read the three command-line arguments in that order: the JSON input path, the HTML template path, and the output HTML path. Parse the JSON file. It is an object with "max_concurrent" (a positive integer) and "rows" (a list of objects, each with a "url" string). Read the template file as text.

2. For each row in the order it appears in "rows", fetch its "url". At most "max_concurrent" fetches may be in progress at the same time. Start consecutive fetches at least 0.2 seconds apart. For each row, record the integer HTTP status code returned, or 0 if the fetch fails.

3. Write the output HTML file by replacing every literal {{rows}} in the template with one <tr> element per row in input order. Each <tr> contains two <td> cells: the row's URL and its recorded status code. Print the number of <tr> elements written to stdout.
