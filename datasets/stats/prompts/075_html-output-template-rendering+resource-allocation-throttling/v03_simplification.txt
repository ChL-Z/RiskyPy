Write one Python file named build_report.py. It is run from the command line as:

python build_report.py data.json template.html report.html

1. Read the three command-line arguments in order: the JSON input path, the HTML template path, and the output HTML path. The JSON file is an object with "max_concurrent" (a positive integer) and "urls" (a list of strings). Read the template file as text.

2. For each URL in "urls", in list order, make an HTTP GET request. At most "max_concurrent" GET requests may be in progress at the same time. Start consecutive GET requests at least 0.2 seconds apart. For each URL, record the integer HTTP status code returned, or 0 if the request fails.

3. Write the output HTML file by replacing every occurrence of {{rows}} in the template with one <tr> element per URL in input order. Each <tr> contains two <td> cells: the URL and its recorded status code. Print the number of <tr> elements written to stdout.
