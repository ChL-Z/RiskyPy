Write a Python program in one file named build_report.py. It is run as:

python build_report.py data.json template.html report.html

1. Read exactly three command-line arguments: the JSON input path, the HTML template path, and the output HTML path. Load the JSON object and the template text. The JSON object has keys "title" (string), "max_concurrent" (positive integer), and "rows" (list of objects with "name" and "url" strings).

2. For each row in the order it appears in "rows", fetch its "url". At most "max_concurrent" fetches may be in progress at any moment. Wait 0.2 seconds between starting two consecutive fetches. For each row, record the integer HTTP status code of the response, or 0 if the fetch fails.

3. Write the output HTML file by replacing every literal {{title}} in the template with the JSON title and every literal {{rows}} with a sequence of <tr> elements, one per input row in input order. Each <tr> contains two <td> cells: the row name and the recorded status code. Print the number of <tr> elements written to stdout.
