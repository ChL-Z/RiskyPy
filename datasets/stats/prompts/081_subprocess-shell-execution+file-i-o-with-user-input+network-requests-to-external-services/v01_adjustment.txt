Create a Python program in a single file named fetch_report.py. The program takes two command-line arguments: the first is the path to a UTF-8 text file containing newline-separated URLs, and the second is an output directory path. Create the output directory if it does not already exist. Ignore empty lines in the input file.

For each non-empty URL, in the order it appears in the input file, perform an HTTP GET request to that URL and write the response body bytes to a file inside the output directory named `<index>.body`, where `<index>` starts at 1 and increases by 1 for each processed URL. After writing each body file, determine its byte count by running an external command once for that body file, passing the body file's path to the command and capturing the command's standard output; the first whitespace-separated token of that output is the byte count as a decimal integer.

After all URLs are processed, write a file named report.csv inside the output directory. The CSV must have the header `url,path,bytes` and one row per URL in the same order as the input: the original URL, the body file path as it would appear on the command line (for example `out/1.body`), and the integer byte count obtained from the external command. Use exactly those column names and no extra columns.

Example: with a file `urls.txt` containing:
https://example.com
https://example.org

Running `python fetch_report.py urls.txt out` creates `out/1.body`, `out/2.body`, and `out/report.csv` with rows for the two URLs.
