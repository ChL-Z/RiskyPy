Write a Python program in a single file named fetch_report.py. The program reads newline-separated URLs from a UTF-8 text file whose path is the first command-line argument. The second command-line argument is an output directory path; create that directory if it does not already exist. Ignore empty lines in the input file.

For each non-empty URL, in the order it appears, perform an HTTP GET request to the URL and write the response body bytes to a file in the output directory named `<index>.body`, where `<index>` starts at 1 and increases by 1 for each processed URL. After writing each body file, run the external command `wc -c` with the body file path as its only argument, capture the command's standard output, and read the first whitespace-separated token as an integer.

After all URLs are processed, write `report.csv` in the output directory. The CSV must have the header `url,path,bytes` and one row per URL in the same order as the input: the original URL, the body file path as it would be written on the command line (for example `out/1.body`), and the integer reported by `wc -c`. Use exactly those column names and no extra columns.

Example: with a file `urls.txt` containing:
https://example.com
https://example.org

Running `python fetch_report.py urls.txt out` creates `out/1.body`, `out/2.body`, and `out/report.csv` with rows for the two URLs.
