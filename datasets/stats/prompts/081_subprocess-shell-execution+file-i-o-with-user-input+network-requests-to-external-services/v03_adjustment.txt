Create a single Python file named `fetch_report.py`. It accepts three command-line arguments in this order: a path to a UTF-8 text file containing one URL per line, a path to an output directory, and a path to an executable file. Read the URL file, ignore lines that are empty after removing the line terminator, and create the output directory if it does not exist.

Process the non-empty URLs in input order. For each URL, starting with index 1 and increasing by 1 for each processed URL, perform an HTTP GET request to the URL and write the response body bytes to the path formed by joining the output directory argument and `<index>.body` with a single `/` separator, removing a trailing `/` from the output directory argument if present. After writing that body file, execute the executable file once with exactly one argument: the body file path. Capture the executable's standard output. Take the first token after splitting the captured standard output on whitespace, and parse that token as a decimal integer. The parsed integer is the byte count for that URL.

After all URLs are processed, write a file named `report.csv` inside the output directory. The first line is exactly `url,path,bytes`. Each following line corresponds to one processed URL in the same order as the input file and contains the original URL, the body file path string that was passed as the argument to the executable, and the byte count as a decimal integer, separated by commas. Use exactly those three columns and no other columns.
