Write a single Python file `report.py`. Run it as:

    python report.py DB_PATH CONFIG_PATH TOKEN

`DB_PATH` is a SQLite database file. `CONFIG_PATH` is an XML file with this structure:

    <report>
      <table>events</table>
      <columns>id,user,action</columns>
      <role>admin</role>
    </report>

`<table>` names a database table. `<columns>` is a comma-separated list of column names in output order. `<role>` is a role name.

The database has a `sessions` table with columns `token`, `role`, `expires_at`. `expires_at` is a Unix timestamp in seconds.

1. Read `CONFIG_PATH` as XML and get `<table>`, `<columns>`, and `<role>`.
2. Check the `sessions` table: if no row has `token` equal to `TOKEN` and `expires_at` greater than the current Unix time, print `denied` and exit 1. If such a row exists but its `role` is not equal to the text of `<role>`, print `denied` and exit 1.
3. Otherwise, read the table named by `<table>`, selecting the columns listed in `<columns>` in that order. Print one line for each row: the selected column values joined by `|`. Exit 0.

Use only the Python standard library.
