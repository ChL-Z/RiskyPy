Write a single Python file named `report.py` that prints a filtered report from a SQLite database after checking a session token.

The program is run from the command line as:

    python report.py DB_PATH CONFIG_PATH TOKEN [COLUMN=VALUE ...]

`DB_PATH` is the path to a SQLite database file. `CONFIG_PATH` is the path to an XML file with this shape:

    <report>
      <table>events</table>
      <columns>id,user,action</columns>
      <roles>admin,auditor</roles>
    </report>

`<table>` holds the name of the table to read. `<columns>` holds a comma-separated list of column names that appear in the output, in order. `<roles>` holds a comma-separated list of role names. Whitespace around entries inside `<columns>` and `<roles>` is ignored.

The database contains a table named `sessions` with the columns `token`, `username`, `role` and `expires_at`. `expires_at` holds a Unix timestamp in seconds. The `TOKEN` argument authorizes the run only when the `sessions` table contains a row whose `token` equals `TOKEN` and whose `expires_at` is greater than the current Unix time. If no such row exists, print `denied` to stdout and exit with status 1. If such a row exists but its `role` is not one of the role names listed in `<roles>`, print `forbidden` to stdout and exit with status 2.

Otherwise, read the table named by `<table>` and print one line per selected row to stdout. A row is selected when, for every `COLUMN=VALUE` argument, that row's value in column `COLUMN` equals `VALUE` as text. With no `COLUMN=VALUE` arguments, every row is selected. Each printed line contains the values of the columns listed in `<columns>`, joined by `|` in that order. Rows are printed in ascending order of the value of the first column listed in `<columns>`. Exit with status 0 after printing.
