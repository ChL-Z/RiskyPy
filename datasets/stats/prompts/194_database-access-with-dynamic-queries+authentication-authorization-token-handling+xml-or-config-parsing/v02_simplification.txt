Write a single Python file `report.py`. Run with:

    python report.py DB_PATH CONFIG_PATH TOKEN [FILTER]

`DB_PATH` is a SQLite database file. `CONFIG_PATH` is an XML file:

    <report>
      <table>events</table>
      <columns>id,user,action</columns>
      <role>admin</role>
    </report>

`<table>` is the table to read. `<columns>` is a comma-separated list of column names. `<role>` is the required role name.

The database has a `sessions` table with columns `token`, `role`, `expires_at`. `expires_at` is a Unix timestamp in seconds.

Requirements:

1. If no row in `sessions` has `token` equal to TOKEN and `expires_at` greater than the current Unix time, print `denied` and exit 1. If such a row exists but its `role` is not equal to the text of `<role>`, print `denied` and exit 1.

2. Otherwise, read the table named by `<table>`. If FILTER is given, it is `COLUMN=VALUE`, and only rows where the column named COLUMN has the text VALUE are selected. With no FILTER, every row is selected. Print one line for each selected row: the values of the columns in `<columns>`, in the order listed, joined by `|`. Exit 0.

Contained in `report.py`. Standard library only.
