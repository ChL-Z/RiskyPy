Write a single Python file named `report.py`. It is run as:

    python report.py DB_PATH CONFIG_PATH TOKEN [COLUMN=VALUE ...]

`DB_PATH` is a SQLite database file. `CONFIG_PATH` is an XML file with this shape:

    <report>
      <table>events</table>
      <columns>id,user,action</columns>
      <role>admin</role>
    </report>

`<table>` is the table name to read. `<columns>` is a comma-separated list of column names for output, in order. `<role>` is the required role name. Whitespace around entries inside `<columns>` and around `<role>` is ignored.

The database has a table `sessions` with columns `token`, `role`, `expires_at`. `token` is unique. `expires_at` is a Unix timestamp in seconds.

Requirements:

1. Token check: If no row in `sessions` has `token` equal to `TOKEN` and `expires_at` greater than the current Unix time, print `denied` to stdout and exit with status 1. If such a row exists and its `role` does not equal the `<role>` value from the config, print `forbidden` to stdout and exit with status 2.

2. Report output: Otherwise, read the table named by `<table>`. A row is selected when, for every `COLUMN=VALUE` argument, the row's value in column `COLUMN` equals `VALUE` as text. With no `COLUMN=VALUE` arguments, select every row. Print one line per selected row. Each line joins the values of the columns listed in `<columns>`, in that order, with `|`. Print rows in ascending order of the value of the first column in `<columns>`. Exit with status 0.

3. The implementation must be contained in `report.py` and use only the Python standard library.
