Write a Python program in a single file named `notify.py`. The program reads newline-separated usernames from stdin. For each username, it looks up the matching row in the SQLite database file `users.db` (table `users` with columns `username TEXT`, `email TEXT`, `allowed INTEGER`). If `allowed` is 1, it sends an HTTP POST request to the URL formed by appending `/notify` to the `api_url` value from the JSON configuration file `config.json` (which contains keys `api_url` and `api_token`). The request body is a JSON object `{"email": <email>, "message": "Hello"}` and the request must include the header `Authorization: Bearer <api_token>`. After the request, print to stdout one line containing the HTTP status code, a space, and the response body. If `allowed` is 0, print to stdout `skipped <username>`. If the username does not exist in the database, print `missing <username>`. Example: With `config.json` containing `{"api_url": "https://api.example.com", "api_token": "abc123"}` and `users.db` containing a row `("alice", "alice@example.com", 1)`, running `echo alice | python notify.py` prints `200 {"ok": true}`.
