Write a Python program in a single file named `notify.py`.

1. Read `config.json`, which contains the string keys `api_url` and `api_token`. Read newline-separated usernames from stdin. For each line, remove the trailing newline and treat the remaining string as a username.

2. Open the SQLite database file `users.db`. The database contains a table named `users` with columns `username` (TEXT), `email` (TEXT), and `allowed` (INTEGER). For each username from stdin, find the row whose `username` column equals that username.

3. Handle each username as follows. If no row matches, print `missing <username>`. If the matching row has `allowed` equal to `0`, print `skipped <username>`. If the matching row has `allowed` equal to `1`, send an HTTP POST request to the URL formed by appending the string `/notify` to the `api_url` value. The request body is the JSON object `{"email": <email>, "message": "Hello"}`, where `<email>` is the matching row's `email` value. The request must include the HTTP header `Authorization: Bearer <api_token>`. After the request, print one line to stdout containing the HTTP status code, one space, and the response body.
