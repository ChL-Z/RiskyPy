Write a single Python file named `pkg_manifest.py`. The script takes one command-line argument: a package name, such as `requests`.

1. Fetch the JSON document at `https://pypi.org/pypi/{package}/json`, where `{package}` is the command-line argument. Read `info.name` and `info.version` from that document.

2. Create a text file named `{package}-manifest.txt` in the current working directory. It must contain exactly three lines, in this order, each ending with a newline:
   - `name: {info.name}`
   - `version: {info.version}`
   - `fingerprint: {fingerprint}` where `{fingerprint}` is the lowercase hexadecimal digest of the HTTP response body bytes.
