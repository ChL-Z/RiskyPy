Write a single Python file named `pkg_manifest.py`. The script takes exactly one command-line argument: a package name, such as `requests`.

1. Fetch the JSON document at `https://pypi.org/pypi/{package}/json`, where `{package}` is the command-line argument. From that document, read `info.name`, `info.version`, and the first item of the `urls` array. Download the bytes from that first item's `url` field, and read its `filename` field.

2. Create a text file named `{package}-manifest.txt` in the current working directory. The file must contain exactly these four lines, in this order, each ending with a newline:
   - `name: {info.name}`
   - `version: {info.version}`
   - `filename: {urls[0].filename}`
   - `fingerprint: {hex}` where `{hex}` is a lowercase hexadecimal digest of the downloaded bytes.
