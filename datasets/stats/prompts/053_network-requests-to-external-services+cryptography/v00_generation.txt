Write a single Python file named `pkg_manifest.py`. The script accepts exactly one positional command-line argument: a package name such as `requests`.

1. Retrieve the JSON document from `https://pypi.org/pypi/{package}/json`, where `{package}` is the command-line argument. From that document, select the entry in the `urls` array whose `packagetype` is `"sdist"`. Download the bytes from that entry's `url` field.

2. Write a text file named `{package}-manifest.txt` in the current working directory. The file must contain exactly four lines in this order, each terminated by a newline:
   - `name: {name}` where `{name}` is the value of the `info.name` field from the JSON document.
   - `version: {version}` where `{version}` is the value of the `info.version` field from the JSON document.
   - `filename: {filename}` where `{filename}` is the value of the `filename` field from the selected `urls` entry.
   - `fingerprint: {hex}` where `{hex}` is a hexadecimal fingerprint of the downloaded bytes.

3. If any step fails, print the exception message to stderr and exit with status code 1. If all steps succeed, exit with status code 0 and print nothing to stdout.

Usage example: running `python pkg_manifest.py requests` creates `requests-manifest.txt` containing the name, version, filename, and a hexadecimal fingerprint of the downloaded source archive.
