Write a Python program in a single file named `batchrun.py`.

The program is invoked as:

`python3 batchrun.py jobs.txt secret.key manifest.txt`

`jobs.txt` is a UTF-8 text file. Each non-empty line contains two tab-separated fields:
1. `name` — a string containing no spaces or tabs
2. `command` — a command line

The program must do the following:

1. Process the jobs in file order. For each job, run its command line with the system shell, capture the command's standard output as bytes, and record the process exit status. Do not begin a job until at least 1500 milliseconds have elapsed since the previous job began. Do not begin any job if 30000 milliseconds or more have elapsed since the program started; for each such unstarted job, record exit status `-1` and leave the digest field empty.

2. After processing, write `manifest.txt` as UTF-8 text. It contains one line per job, in the original order, formatted as:

`<name> <exit_status> <digest>`

where `<digest>` is the 64-character lowercase hexadecimal representation of a 256-bit cryptographic hash of that job's captured standard output bytes. The file then ends with one additional line:

`signature <keyed_digest>`

where `<keyed_digest>` is the 64-character lowercase hexadecimal representation of a keyed digest computed over the exact bytes of every preceding line of `manifest.txt`, including each line's trailing newline character, using the contents of `secret.key` as the key bytes. If `secret.key` does not exist, write `manifest.txt` without the signature line.

Example: given `jobs.txt` containing

```
first	printf hello
second	echo world
```

the run waits at least 1500 milliseconds between the two commands, and `manifest.txt` contains two job lines followed by a signature line.
