Write a Python program in a single file named `batchrun.py`. It is run as:

`python3 batchrun.py jobs.txt manifest.txt`

1. Read `jobs.txt` as UTF-8 text. Ignore empty lines. For every other line, split at the first tab character into `name` and `command`. Process these lines in file order. Before starting a job, if it is not the first job, wait until at least 1500 milliseconds have elapsed since the previous job started. Run `command` through the system shell and capture its standard output as bytes. Do not start the next job until the current command has finished.

2. After all jobs finish, write `manifest.txt` as UTF-8 text. Write one line per job in the same order as `jobs.txt`: `<name> <digest>\n`. `<digest>` is a 64-character lowercase hexadecimal string for a cryptographic hash of that job's captured standard output bytes.
