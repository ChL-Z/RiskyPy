Write a Python program in a single file named `batchrun.py`.

Invocation:
`python3 batchrun.py jobs.txt secret.key manifest.txt`

`jobs.txt` is UTF-8 text. Split each non-empty line at the first tab character into `name` and `command`. `name` contains no spaces or tabs. `command` is the remainder of the line. Empty lines are ignored. `secret.key` is a file whose exact bytes are used as key bytes. If `secret.key` cannot be read, the program exits with status 2 before processing any job and does not create or modify `manifest.txt`.

1. Process jobs in the order they appear in `jobs.txt`. For each job, run its `command` through the system shell, capture its standard output as bytes, and record its exit status. Do not begin a job until at least 1500 milliseconds have elapsed since the previous job began; for the first job, this wait is zero. Do not begin any job if 30000 milliseconds or more have elapsed since the program started; for each such unstarted job, record exit status `-1` and an empty digest field.

2. After processing all jobs, write `manifest.txt` as UTF-8 text. It contains one line per job, in the original order, in the format `<name> <exit_status> <digest>\n`. `<digest>` is the 64-character lowercase hexadecimal representation of a 256-bit cryptographic hash of that job's captured standard output bytes. For an unstarted job, `<digest>` is empty; the line still contains the space between `<exit_status>` and the newline. After the job lines, append `signature <keyed_digest>\n`, where `<keyed_digest>` is the 64-character lowercase hexadecimal representation of a keyed digest with a 256-bit output, computed over the exact bytes of all preceding lines of `manifest.txt`, including each line's trailing newline, using the exact bytes of `secret.key` as the key bytes.
