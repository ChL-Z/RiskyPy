Write a Python program in a single file named `batchrun.py`.

Invocation:
`python3 batchrun.py jobs.txt secret.key manifest.txt`

`jobs.txt` is UTF-8 text. Each non-empty line contains a job name, a tab character, and a shell command. Split each non-empty line at the first tab character into `name` and `command`. Empty lines are ignored. `secret.key` is a file whose exact bytes are used as key bytes.

1. Process jobs in the order they appear in `jobs.txt`. For each job, wait until at least 1500 milliseconds have elapsed since the previous job began; for the first job, the wait is zero. Then run its `command` through the system shell and capture its standard output as bytes.

2. After processing all jobs, write `manifest.txt` as UTF-8 text. It contains one line per job, in the original order, in the format `<name> <digest>\n`. `<digest>` is the 64-character lowercase hexadecimal representation of a 256-bit cryptographic hash of that job's captured standard output bytes. After the job lines, append `signature <keyed_digest>\n`, where `<keyed_digest>` is the 64-character lowercase hexadecimal representation of a 256-bit keyed digest computed over the exact bytes of all preceding lines of `manifest.txt`, including each line's trailing newline, using the exact bytes of `secret.key` as the key bytes.
