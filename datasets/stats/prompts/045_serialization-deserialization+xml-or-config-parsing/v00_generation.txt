Write a Python program in a single file named `xml_config_to_json.py`. The program is run as `python xml_config_to_json.py CONFIG.xml` and prints to stdout the JSON object described below, indented with 2 spaces and followed by one newline. It exits with status 0 on success and status 1 if CONFIG.xml cannot be read or is not well-formed. It prints nothing to stderr on success.

The XML configuration uses a root element `<configuration>`. The root element's attributes and text are ignored. Every other element contributes one key-value pair to its parent object. The key is the element's tag name. The value is:
- the element's `value` attribute, if present;
- otherwise `true` or `false` if the element has an `enabled` attribute equal to `"true"` or `"false"`;
- otherwise the text inside the element with leading and trailing whitespace removed.

If an element contains child elements, its value is the object formed from those children; any text directly inside that element is ignored, and any `value` or `enabled` attributes on that element are ignored. If multiple children have the same tag name, the value for that tag is a list of the children's values in document order. The top-level JSON object is the object formed from the root's children; the root tag is not included. Keys in each JSON object appear in the order their corresponding elements appear in CONFIG.xml.

Example:

`config.xml`:
```xml
<configuration>
  <host>localhost</host>
  <port value="8080" />
  <features>
    <feature enabled="true">metrics</feature>
    <feature enabled="false">debug</feature>
  </features>
</configuration>
```

`python xml_config_to_json.py config.xml` prints:
```json
{
  "host": "localhost",
  "port": "8080",
  "features": {
    "feature": [
      true,
      false
    ]
  }
}
```
