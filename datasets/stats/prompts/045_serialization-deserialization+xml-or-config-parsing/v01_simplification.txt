Write a Python program in a single file named `xml_config_to_json.py`. It is run as `python xml_config_to_json.py CONFIG.xml`. The program reads the XML file named by the command-line argument, converts it to one JSON object, and prints that object to stdout indented with 2 spaces followed by one newline. On success, it prints nothing to stderr and exits with status 0. If the file cannot be read or is not well-formed XML, it prints nothing to stdout and exits with status 1.

The XML file has a root element named `configuration`. Ignore the root element's attributes and text. For each direct child element of the root, add one key to the top-level JSON object. The key is the child element's tag name. The value is the child's `value` attribute if that attribute is present; otherwise the value is the child's text with leading and trailing whitespace removed. If a direct child element contains child elements, its value is a JSON object formed from those child elements using the same tag-and-value rule; ignore the direct child's own text and `value` attribute in that case. Keys appear in the order their elements appear in the XML file. Assume no two elements at the same level have the same tag name.
