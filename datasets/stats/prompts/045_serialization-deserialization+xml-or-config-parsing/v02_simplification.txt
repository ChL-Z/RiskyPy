Write a Python program in a single file named `xml_config_to_json.py`. Run it as `python xml_config_to_json.py CONFIG.xml`. The program reads the XML file named by the command-line argument. The root element is `configuration`. For each direct child element of the root, add one key to a JSON object. The key is the child element's tag name. The value is the child's `value` attribute if present; otherwise the value is the child's text with leading and trailing whitespace removed. Ignore the root element's attributes and text, and ignore any elements nested inside a direct child. Assume direct child tag names are unique. Print the JSON object to stdout indented with 2 spaces followed by one newline, then exit with status 0. If the file cannot be read or is not well-formed XML, print nothing to stdout and exit with status 1.
