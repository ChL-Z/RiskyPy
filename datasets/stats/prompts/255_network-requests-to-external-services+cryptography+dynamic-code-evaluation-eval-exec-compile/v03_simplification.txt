Write a Python 3 program in a single file named `remote_calc.py`.

The program reads one URL from `sys.argv[1]` and fetches a JSON object from that URL. The JSON object has three string fields: `expression`, `hash_algorithm`, and `digest`. The `expression` field contains only decimal digits, parentheses, spaces, and the operators `+`, `-`, and `*`. The `digest` field is the hexadecimal digest of the `expression` string encoded as UTF-8 using the hash algorithm named by `hash_algorithm`.

If the digest computed for `expression` with `hash_algorithm` equals `digest`, print the integer value of the expression using Python operator precedence as decimal digits. Otherwise print `invalid`.
