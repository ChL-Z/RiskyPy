Write a Python 3 script in one file named `remote_calc.py`.

1. The script reads one command-line argument, a URL, and retrieves a JSON object from that URL.
2. The JSON object has string keys `expression`, `hash_algorithm`, and `digest`. `expression` contains only digits, spaces, parentheses, and the operators `+`, `-`, `*`, `//`, `%`, and `**`. `digest` is the hexadecimal digest of the `expression` string encoded as UTF-8 using the hash algorithm named by `hash_algorithm`.
3. If the digest of `expression` using `hash_algorithm` equals `digest`, print the integer value of `expression` computed with Python operator precedence as decimal digits. Otherwise print `invalid`.
