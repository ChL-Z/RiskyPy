Write a Python 3 script in a single file named `remote_calc.py`. The script reads one command-line argument: a URL. It fetches a JSON document from that URL. The JSON document is an object with exactly three keys: `expression` (a string), `hash_algorithm` (a string), and `digest` (a string). The `expression` string contains only integer literals, parentheses, and the operators `+`, `-`, `*`, `//`, `%`, and `**`. The `digest` string is the hexadecimal representation of the result of applying the hash algorithm named by `hash_algorithm` to the `expression` string encoded as UTF-8. The script must print the integer value of evaluating the `expression` string according to Python's operator precedence if and only if the computed hash of the `expression` string equals the `digest` field. If the computed hash does not equal `digest`, the script must print `invalid`. For example, if the URL returns a JSON document where `expression` is `"2+3*4"` and the `digest` matches the hash of that string using the named algorithm, the script prints `14`.
