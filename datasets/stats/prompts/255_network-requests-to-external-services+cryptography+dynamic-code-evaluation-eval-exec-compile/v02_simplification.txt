Write a Python 3 script in one file named `remote_calc.py`.

The script takes one command-line argument, a URL, and retrieves a JSON object from that URL. The JSON object has string fields `expression`, `hash_algorithm`, and `digest`. The `digest` is the hexadecimal digest of `expression` encoded as UTF-8 using the hash algorithm named by `hash_algorithm`. The `expression` contains only digits, spaces, parentheses, and the operators `+`, `-`, `*`, `//`, `%`, and `**`.

If the digest calculated for `expression` with `hash_algorithm` equals `digest`, print the integer value of `expression` computed with Python operator precedence as decimal digits. Otherwise print `invalid`.
