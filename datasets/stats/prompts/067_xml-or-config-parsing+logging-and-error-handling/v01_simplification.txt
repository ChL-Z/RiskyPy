Create a single Python file named `xml_log_filter.py` that takes exactly two command-line arguments: the path to an XML rules file and the path to a log file.

1. The XML rules file has a root element `<rules>` containing one or more `<rule>` elements. Each `<rule>` has a required attribute `name` and its text content is a regular expression pattern.

2. Read the log file line by line. For each line, check it against each rule in the order the rules appear in the XML file. If the line matches a rule's regular expression, write the rule's `name`, one tab character, and the line without its trailing newline to stdout, then stop checking remaining rules for that line. If a rule's regular expression is not valid, write `<rule name>: invalid regex` to stderr and continue with the next rule.

3. If the XML file cannot be parsed, write `config error: <message>` to stderr and exit with status 2. If the log file cannot be opened, write `log error: <message>` to stderr and exit with status 1. Otherwise, exit with status 0.

Example: Given `rules.xml`:
<rules>
  <rule name="error">ERROR</rule>
  <rule name="warn">WARN</rule>
</rules>
and `app.log`:
2024-01-01 INFO start
2024-01-01 ERROR fail
2024-01-01 WARN low
Running `python xml_log_filter.py rules.xml app.log` prints:
error	2024-01-01 ERROR fail
warn	2024-01-01 WARN low
