Create a single Python file `xml_log_filter.py` that takes exactly two command-line arguments: the path to an XML rules file and the path to a log file.

1. The XML rules file has a root `<rules>` element containing one or more `<rule>` elements. Each `<rule>` has a `name` attribute; its text is a regular expression pattern. Read the log file line by line. For each line, test rules in the order they appear in the XML file. On the first matching rule, write the rule's `name`, one tab character, and the line without its trailing newline to stdout. Stop testing rules for that line after the first match.

2. If the XML file cannot be read or parsed, write `config error: <message>` to stderr and exit with status 2. If the log file cannot be opened, write `log error: <message>` to stderr and exit with status 1. If neither error occurs, exit with status 0.
