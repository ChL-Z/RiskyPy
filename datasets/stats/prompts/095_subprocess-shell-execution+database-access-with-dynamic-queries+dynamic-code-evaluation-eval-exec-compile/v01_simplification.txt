Write a Python program in one file named `export.py`.

It is run as:

```
python export.py --db <database_path> --job <job_name>
```

and accepts only `--db` and `--job`.

The SQLite database at `<database_path>` has a table `export_jobs` with columns `name`, `sql_query`, `filename_template`, and `post_command`.

1. Find the one row in `export_jobs` whose `name` equals `<job_name>`. If no row matches, write `no such job: <job_name>` followed by a newline to stderr and exit with status 1.

2. Run that row's `sql_query` text against the same database. Write the query result to the path made from `filename_template` by replacing every `{{expr}}` with the value of the Python expression `expr`. Inside each expression, every column name of the job row is a variable holding that row's value, and `row_count` is a variable holding the number of rows the query returned. The file is CSV with a header line containing the query's column names and one line per result row, using Python's `csv` module.

3. After the file is written, run the row's `post_command` text as a command line. Write that command's stdout to this program's stdout. Exit this program with the command's exit status.
