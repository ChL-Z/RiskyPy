Write a Python program in one file named `export.py`. It is run exactly as:

```
python export.py --db <database_path> --job <job_name>
```

The program accepts only the `--db` and `--job` options. The file at `<database_path>` is an SQLite database with a table `export_jobs` that has columns `name`, `sql_query`, `filename_template`, and `post_command`.

1. Find the row in `export_jobs` whose `name` equals `<job_name>`. If no row matches, write `no such job: <job_name>` followed by a newline to stderr and exit with status 1. If a row matches, run that row's `sql_query` text against the same database.

2. Write the query result to the path obtained from that row's `filename_template` by replacing every `{{expr}}` with the value of the Python expression `expr`. Inside each expression, every column name of the job row is a variable holding that row's value, and `row_count` is a variable holding the number of rows returned by the query. The output file is CSV: the first line contains the query's column names, and each following line contains one result row. Fields are separated by commas; a field containing a comma, double quote, carriage return, or line feed is enclosed in double quotes, and each double quote inside such a field is written as two double quotes.

3. After the output file is written, run that row's `post_command` text as a command line. Write the command's stdout to this program's stdout. Exit this program with the command's exit status.
