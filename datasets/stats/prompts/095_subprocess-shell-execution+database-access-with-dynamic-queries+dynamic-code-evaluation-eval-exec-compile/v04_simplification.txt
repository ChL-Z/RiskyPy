Write a single Python file `export.py`, run as:

    python export.py --db <database_path> --job <job_name>

`<database_path>` is an SQLite database with table `export_jobs` containing columns `name`, `sql_query`, `filename_template`, and `post_command`.

1. Read the row from `export_jobs` whose `name` equals `<job_name>`. If no row matches, write `no such job: <job_name>` to stderr and exit with status 1. Run that row's `sql_query` against the same database and collect the result rows.

2. Create an output file whose name is `filename_template` with each `{{...}}` occurrence replaced by the value of the Python expression inside the braces. In each expression, `row_count` is the number of result rows from the query. Write the query result to that file: one line per result row, with fields separated by commas.

3. Run `post_command` as a command line. Write its stdout to this program's stdout and exit with its exit status.
