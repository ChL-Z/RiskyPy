Write a Python program in one file named `export.py`, run as:

    python export.py --db <database_path> --job <job_name>

The file at `<database_path>` is an SQLite database. It has a table `export_jobs` with columns `name`, `sql_query`, `filename_template`, `post_command`.

1. Read the row of `export_jobs` whose `name` equals `<job_name>`. If no row matches, write `no such job: <job_name>` followed by a newline to stderr and exit with status 1. Run that row's `sql_query` against the same database.

2. Build the output filename from the row's `filename_template` by replacing each `{{...}}` occurrence with the value of the Python expression inside the braces. Inside each expression, every column of the job row is available as a variable of the same name, and `row_count` is the number of rows the query returned. Write the query result to that file: the first line holds the query's column names, and each remaining line holds one result row, with fields separated by commas.

3. Run the row's `post_command` text as a command line. Write the command's stdout to this program's stdout, and exit this program with the command's exit status.
