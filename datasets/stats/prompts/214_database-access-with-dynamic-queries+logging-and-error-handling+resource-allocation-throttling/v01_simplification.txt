Write a Python program in a single file named inventory_report.py. The program takes one command-line argument: the path to a database file in SQLite format. The database contains a table named items with columns id, name, quantity, and price. Read newline-separated JSON objects from stdin. Each JSON object has one or more keys mapping column names to values. For each non-empty input line, let N be its 1-based line number in stdin. Query the items table for rows where every key in that JSON object equals the corresponding column value. Write each selected row to stdout as a JSON object with keys id, name, quantity, and price, one object per line. Write nothing else to stdout. Output line order may differ from input order. Process input lines one at a time. At most 4 queries may be unfinished at any time. Start at most 8 queries in any 1-second window; if starting a new query would exceed this limit, wait until the oldest counted start is more than 1 second old. Write logs to stderr only. For each non-empty input line N, write `INFO start N` before its query starts and `INFO done N R` after its rows are written, where R is the number of rows written for that query. If a query fails, write `ERROR N` and continue with the remaining input lines. If any query failed, exit with status 1 after all input lines are processed. If no query failed, exit with status 0.
