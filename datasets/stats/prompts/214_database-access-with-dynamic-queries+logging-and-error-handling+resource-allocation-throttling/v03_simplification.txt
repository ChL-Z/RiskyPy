Write a Python program in a single file named inventory_report.py.

The program takes one command-line argument: a path to a SQLite database file. The database has a table named items with columns id, name, quantity, and price.

Read stdin as newline-separated JSON objects. Each non-empty line is a JSON object whose keys are chosen from {id, name, quantity, price}. For each non-empty input line, let N be its 1-based line number in stdin. Query the items table for rows where every key in that JSON object equals the value in the column with that name. Write each selected row to stdout as a JSON object with keys id, name, quantity, and price, one object per line. Write nothing else to stdout.

Write all logs to stderr. For each non-empty input line N, write `INFO start N` to stderr before its query starts and `INFO done N R` to stderr after its rows are written, where R is the number of rows written for that query. If a query fails, write `ERROR N` to stderr and continue with the remaining input lines. After all input lines are processed, exit with status 1 if any query failed; otherwise exit with status 0.

Process input lines one at a time, so at most one query is unfinished at any time. Start at most 3 queries in any 1-second window. If starting a new query would exceed this limit, wait until the oldest counted start is more than 1 second old.
