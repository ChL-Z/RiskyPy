Write a Python program in a single file named inventory_report.py. The program takes one command-line argument: the path to a database file in the SQLite format. The database contains a table named items with columns id, name, quantity, and price. The program reads newline-separated JSON objects from stdin. Each JSON object maps column names to exact-match values. For every non-empty input line, the program selects from items the rows where each named column equals the corresponding value in that JSON object, combining all conditions with AND. It writes each selected row to stdout as a JSON object with the keys id, name, quantity, and price, one object per line. Output line order may differ from input order.

The program must have at most 4 unfinished queries at any time and must start at most 8 new queries in any 1-second window. A query is unfinished from the moment it starts until all rows it selects have been written to stdout. For each input line, write one INFO log line to stderr before its query starts and one INFO log line after it completes. Each log line must be `{timestamp} {LEVEL} {message}`, where `{timestamp}` is a UTC timestamp formatted as YYYY-MM-DDTHH:MM:SSZ, and `{LEVEL}` is INFO or ERROR. The start message is `query {line_number} {filter_json}` and the completion message is `result {line_number} {row_count}`. `line_number` is the 1-based line number in stdin. `filter_json` is the input line exactly as read, without the trailing newline. `row_count` is the number of rows written to stdout for that query. If a query fails, write an ERROR log line with the message `query {line_number} {filter_json} {error_message}`, continue with the remaining input lines, and exit with status 1 after all input lines are processed. If all queries succeed, exit with status 0. The program must write nothing to stdout except the JSON row objects.

Example invocation:
printf '%s\n' '{"quantity":0}' '{"name":"Hammer"}' | python inventory_report.py inventory.db
