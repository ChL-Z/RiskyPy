Write a Python program in a single file named `dedup_throttle.py`. It reads newline-separated absolute file paths from stdin. For each path, it copies the file into a cache directory named `.dedup-cache` located next to the script, unless a file with the same tag already exists there. The tag is a 16-byte value derived from the file content and a 32-byte key read from the environment variable `DEDUP_KEY`; the cache file is named with that tag encoded as a 32-character lowercase hexadecimal string and no file extension. The program starts no more than 10 copy operations in any 1-second window and has no more than 4 copy operations in progress at once. Any error for a path is written to stderr as `ERROR <path>: <message>` and processing continues. After all input paths are processed, it prints exactly one line to stdout: `OK <count>`, where `<count>` is the number of files newly copied into the cache.

Example: given `/tmp/input.txt` containing `/tmp/a.txt` and `/tmp/b.txt` on separate lines, running `DEDUP_KEY=0123456789abcdef0123456789abcdef python dedup_throttle.py < /tmp/input.txt` prints a line beginning with `OK ` and creates one cache file for each input path that was not already cached.
