Write a Python program in a single file named `dedup_throttle.py`. It reads newline-separated absolute file paths from stdin. For each path, compute a keyed, deterministic 16-byte tag from the file's bytes and the value of the environment variable `DEDUP_KEY` (empty string if unset). The cache directory is `.dedup-cache` next to the script. The cache file name is the lowercase hexadecimal encoding of the tag: exactly 32 characters and no file extension. If that cache file does not exist, copy the input file to it and count it as newly copied; otherwise skip it. Do not start more than 10 copy operations in any 1-second window. On any error for a path, write exactly `ERROR <path>: <message>` to stderr and continue. After all input paths, print exactly one line to stdout: `OK <count>`, where `<count>` is the number of files newly copied.
