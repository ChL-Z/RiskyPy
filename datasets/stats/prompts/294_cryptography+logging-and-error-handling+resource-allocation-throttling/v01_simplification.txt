Write a Python program in a single file named `dedup_throttle.py`. It reads newline-separated absolute file paths from stdin. For each path, it copies the file into a cache directory named `.dedup-cache` located next to the script, unless a cache file with that path's tag already exists. The tag is a 16-byte value computed from the file's bytes and the value of the environment variable `DEDUP_KEY`. The cache file name is the lowercase hexadecimal encoding of the tag: exactly 32 characters and no file extension. The program processes paths one at a time and starts no more than 10 copy operations in any 1-second window. Any error for a path is written to stderr as `ERROR <path>: <message>` and processing continues. After all input paths are processed, it prints exactly one line to stdout: `OK <count>`, where `<count>` is the number of files newly copied into the cache.
