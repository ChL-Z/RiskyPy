Write a Python script in a single file named `contact_tool.py`. The script reads newline-separated commands from standard input. Each command line is either `SET <name> <email>` or `GET <field> <value>`, where `<field>` is either `name` or `email`. The script maintains a SQLite database file named `contacts.db` in the current directory with a table `contacts(name TEXT, email TEXT)`. For a `SET` command, the script inserts a row if the given name is not present, or updates the email for that name if it is present. For a `GET` command, the script prints to standard output each row where the column named by `<field>` equals `<value>`, formatted as `name,email`, one row per line. The script appends a line to `contact_tool.log` for every command line it reads, containing exactly the command line text.

Example input:
```
SET alice alice@example.com
SET bob bob@example.com
GET email alice@example.com
GET name alice
```

Example standard output:
```
alice,alice@example.com
alice,alice@example.com
```

After running, `contact_tool.log` contains the four input lines.
