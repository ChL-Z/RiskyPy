Write a Python script in a single file. The script reads a CSV file path from the first command-line argument. The CSV file has a header row with exactly these column names: employee_id, name, salary.

For each data row after the header, check only the employee_id field. A row is valid when employee_id is an integer greater than 0. Write the header and every valid row to valid_records.csv in the current working directory, preserving column order.

For each invalid row, append one line to validation.log in the current working directory. Each line must be:

<ISO 8601 timestamp> <line number> Invalid employee_id: must be a positive integer

where the timestamp is the current date and time in the format YYYY-MM-DDTHH:MM:SS, and the line number is the input line number with the header counted as line 1.

If the input file cannot be opened, append one line to validation.log containing the ISO 8601 timestamp and the text Failed to open input file, then exit with a non-zero exit code.
