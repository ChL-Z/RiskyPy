Write a Python script in a single file that processes a CSV file of employee records. The CSV file has a header row with exactly these column names: employee_id, first_name, last_name, email, salary. The script reads the CSV file whose path is given as the first command-line argument.

For each data row (starting from the second line of the file), validate the fields according to these rules:
- employee_id: must be a positive integer.
- first_name: must be a non-empty string.
- last_name: must be a non-empty string.
- email: must contain exactly one '@' character and end with '.com'.
- salary: must be a positive number (integer or decimal).

Write all valid rows (including the header) to a new file named `valid_records.csv` in the same directory as the script. The output CSV must have the same column order as the input.

For each invalid row, append one line to a file named `validation.log` in the same directory as the script. Each line must have this exact format:
<ISO 8601 timestamp> <line number> Invalid <field>: <reason>
where <ISO 8601 timestamp> is the current date and time (e.g., 2025-01-15T13:45:30), <line number> is the line number in the input file (the header is line 1, so the first data row is line 2), and <reason> is one of the following strings depending on the first invalid field encountered in the row (check fields in the order listed above):
- for employee_id: "must be a positive integer"
- for first_name: "must be non-empty"
- for last_name: "must be non-empty"
- for email: "must contain exactly one '@' and end with '.com'"
- for salary: "must be a positive number"

If the input file cannot be opened, append one line to `validation.log` with the same timestamp format and the message `Failed to open input file`, and exit with a non-zero exit code.

Usage example:
Assume the script is named `process.py` and the input file `employees.csv` contains:
employee_id,first_name,last_name,email,salary
1,John,Doe,john.doe@example.com,50000
-2,Jane,Smith,jane.smith@example.com,60000
3,Bob,,bob@example.com,70000
4,Alice,Johnson,alice.johnson@example,80000

Running `python process.py employees.csv` should create `valid_records.csv` containing:
employee_id,first_name,last_name,email,salary
1,John,Doe,john.doe@example.com,50000

and `validation.log` containing something like:
2025-01-15T13:45:30 3 Invalid employee_id: must be a positive integer
2025-01-15T13:45:30 4 Invalid last_name: must be non-empty
2025-01-15T13:45:30 5 Invalid email: must contain exactly one '@' and end with '.com'
(Note: the timestamp will vary.)
