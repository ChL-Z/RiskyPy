Write a Python script in a single file. The script reads a CSV file whose path is given as the first command-line argument. The CSV file has a header row with exactly these column names: employee_id, name, salary.

For each data row (starting from the second line), validate these fields in order:
- employee_id: must be an integer greater than zero.
- salary: must be a number greater than zero, written as an integer or decimal.

Write all valid rows (including the header) to `valid_records.csv` in the current working directory, preserving the column order.

For each invalid row, append one line to `validation.log` in the current working directory. Each line must be:
<ISO 8601 timestamp> <line number> Invalid <field>: <reason>
where <ISO 8601 timestamp> is the current date and time (e.g., 2025-01-15T13:45:30), <line number> is the line number in the input (header is line 1), <field> is the first invalid field, and <reason> is:
- for employee_id: must be a positive integer
- for salary: must be a positive number

If the input file cannot be opened, append one line to `validation.log` with the ISO 8601 timestamp and the text Failed to open input file, and exit with a non-zero exit code.
