Write a Python script in a single file. It reads a CSV file path from the first command-line argument. The CSV has a header row with columns employee_id, name, salary. Write the header row to valid_records.csv in the current working directory. For each row after the header, if employee_id is an integer greater than 0, write that row to valid_records.csv with the same comma-separated fields in the same order.

For each row where employee_id is not an integer greater than 0, append a line to validation.log in the current working directory. The line is the current local date and time in YYYY-MM-DDTHH:MM:SS format, a space, and Invalid employee_id: must be a positive integer.

If the CSV file cannot be opened, append a line to validation.log with the current local date and time in YYYY-MM-DDTHH:MM:SS format, a space, and Failed to open input file. Then exit with exit code 1.
