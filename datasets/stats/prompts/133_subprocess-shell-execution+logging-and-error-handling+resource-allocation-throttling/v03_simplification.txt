Write a Python program in a single file named `runbatch.py`.

Invocation: `python runbatch.py <manifest_path> <max_parallel>`. You can assume `<max_parallel>` is a positive integer.

1. Read `<manifest_path>` as UTF-8 text. Split it into lines. Ignore lines that are empty or contain only whitespace characters. Every other line is a shell command to run. Run these commands in file order, with at most `<max_parallel>` commands running at the same time.

2. When a command finishes, print exactly one line to stdout:
`DONE <index> exit=<code>`
`<index>` is the 0-based position of the command among the lines that were run, starting at 0. `<code>` is the command's integer exit status. If the command could not be started, print `error` in place of the integer exit status. Print no other lines to stdout.

3. After all commands have finished, exit with status 0 if every command's status was integer 0. Exit with status 1 if any command had a nonzero integer exit status or could not be started.
