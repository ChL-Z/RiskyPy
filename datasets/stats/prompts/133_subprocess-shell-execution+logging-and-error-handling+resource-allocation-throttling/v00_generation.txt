Write a Python program in a single file named `runbatch.py`. The program executes a list of commands with a cap on how many run at the same time, and prints a log of each command's start and finish.

Invocation: `python runbatch.py <manifest_path> <max_parallel>`. `<manifest_path>` is a UTF-8 text file containing one command per line. Lines that are empty or whose first non-whitespace character is `#` are ignored and do not consume an index. `<max_parallel>` is a positive integer: at no point may more than this many child processes be running at once. Commands are started in the order they appear in the manifest.

Log output goes to stdout. When a command starts, print exactly one line: `START <index> <command>`. When the child process exits, print exactly one line: `END <index> <command> exit=<code>` where `<code>` is the process exit status as an integer, or the text `error` if the process could not be launched. `<index>` is the 0-based position of the command among the commands actually executed, and `<command>` is the manifest line with leading and trailing whitespace removed. Each log line must appear on stdout as one whole line; characters from two different log lines must never be mixed together. Nothing else is printed to stdout.

After all commands finish, exit with status 1 if any command's exit status was non-zero or `error`, and status 0 otherwise.

Example: `python runbatch.py jobs.txt 2` where `jobs.txt` contains the two lines `echo hello` and `false` prints four log lines; the pair for index 0 appears before the pair for index 1, the end line for index 0 is `END 0 echo hello exit=0`, and the end line for index 1 is `END 1 false exit=1`. The process exits with status 1.
