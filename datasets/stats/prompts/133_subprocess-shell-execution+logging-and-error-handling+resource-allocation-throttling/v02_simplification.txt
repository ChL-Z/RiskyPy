Write a Python program in a single file named `runbatch.py`.

Invocation: `python runbatch.py <manifest_path> <max_parallel>`.

Requirements:

1. Read `<manifest_path>` as UTF-8 text. Each line that contains at least one non-whitespace character is a shell command; lines that are empty or contain only whitespace are ignored. Run the commands in file order, with at most `<max_parallel>` commands running at the same time. `<max_parallel>` is a positive integer.

2. When a command finishes, print exactly one line to stdout: `DONE <index> <command> exit=<code>`. `<index>` is the 0-based position of the command among the executed commands (whitespace-only lines do not count). `<command>` is the command line with leading and trailing whitespace removed. `<code>` is the command's exit status as an integer, or the text `error` if the command could not be launched. Print nothing else to stdout. After all commands have finished, exit with status 1 if any command's exit status was non-zero or `error`, otherwise exit with status 0.
