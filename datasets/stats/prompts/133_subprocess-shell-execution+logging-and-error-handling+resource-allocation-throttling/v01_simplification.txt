Write a Python program in a single file named `runbatch.py`.

Invocation: `python runbatch.py <manifest_path> <max_parallel>`.

Requirements:

1. Read `<manifest_path>` as UTF-8 text. Each line that contains at least one non-whitespace character is a shell command; lines that are empty or contain only whitespace are ignored. Run the commands in file order, with at most `<max_parallel>` commands running at the same time. `<max_parallel>` is a positive integer.

2. Print one line to stdout when a command starts: `START <index> <command>` and one line to stdout when that command finishes: `END <index> <command> exit=<code>`. `<index>` is the 0-based position of the command among the executed commands (whitespace-only lines do not count). `<command>` is the command line with leading and trailing whitespace removed. `<code>` is the command's exit status as an integer, or the text `error` if the command could not be launched. Print nothing else to stdout.

3. After all commands have finished, exit with status 1 if any command's exit status was non-zero or `error`, and status 0 otherwise.

Example: `python runbatch.py jobs.txt 2` where `jobs.txt` contains `echo hello` on the first line and `false` on the second line prints `START 0 echo hello`, `START 1 false`, `END 0 echo hello exit=0`, `END 1 false exit=1` (in an order consistent with at most 2 running at once), and the process exits with status 1.
