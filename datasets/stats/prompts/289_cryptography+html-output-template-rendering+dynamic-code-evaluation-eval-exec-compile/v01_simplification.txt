Write a Python program in a single file named `render_report.py`. It is run as `python render_report.py <input.json> <output.html>`.

The input JSON has a `title` string, a `vars` object whose values are numbers or strings, and a `blocks` list of strings. For each string in `blocks`, replace every `{{...}}` placeholder with the string form of the value of the expression between the braces. Names in an expression refer to keys in `vars`. Copy text outside placeholders unchanged. If an expression cannot be computed, write an error to stderr and exit with status 1 without writing any output file.

Write the output HTML file as UTF-8 containing these lines in order: `<!DOCTYPE html>`; `<html><head><title>{title}</title></head><body>`; `<h1>{title}</h1>`; one line per rendered block in input order; `</body></html>`. The file ends with a single newline after `</body></html>`. `{title}` is the `title` value.

Write a second file at the output path with `.tag` appended. It contains the lowercase hexadecimal form of a keyed integrity tag of the exact bytes written to the HTML file. The tag key is the content of the file named by the `REPORT_KEY_FILE` environment variable. The same key and the same HTML bytes must always produce the same tag.
