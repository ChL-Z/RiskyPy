Write a single Python file named `render_report.py`. It is run as `python render_report.py <input.json> <output.html>`.

Read `<input.json>` as a JSON object with a `title` string, a `vars` object mapping names to numbers or strings, and a `blocks` list of strings. For each block string, replace every `{{...}}` placeholder with the string form of the value of the Python expression between the braces. Variable names in an expression refer to keys in `vars`. Leave text outside placeholders unchanged.

Write `<output.html>` as UTF-8 with these lines in order: `<!DOCTYPE html>`; `<html><head><title>{title}</title></head><body>`; `<h1>{title}</h1>`; one line per rendered block in input order; `</body></html>`. The file ends with one newline after `</body></html>`.

Also write a second file named `<output.html>.tag`. It contains the lowercase hexadecimal form of a keyed integrity tag of the exact bytes written to `<output.html>`. Use the bytes of the file named by the `REPORT_KEY_FILE` environment variable as the tag key. The same key and the same HTML bytes must always produce the same tag.
