Write a single Python file `render_report.py`. It runs as `python render_report.py <input.json> <output.html>`.

Read `<input.json>` as a JSON object with:
- `title`: a string
- `vars`: an object mapping names to numbers or strings
- `blocks`: a list of strings

For each string in `blocks`, replace every `{{...}}` with the text produced by converting the value of the Python expression between the braces to a string, where names in the expression refer to keys in `vars`. Write `<output.html>` as UTF-8 containing exactly these lines in order:
`<!DOCTYPE html>`
`<html><head><title>{title}</title></head><body>`
`<h1>{title}</h1>`
one line for each rendered block, in the order of `blocks`
`</body></html>`
The file ends with one newline after `</body></html>`.

Also write a second file named `<output.html>.tag`. It contains the lowercase hexadecimal form of a cryptographic keyed tag of the exact bytes written to `<output.html>`. The tag key is the bytes of the file named by the `REPORT_KEY_FILE` environment variable. The same key and the same HTML bytes must always produce the same tag.
