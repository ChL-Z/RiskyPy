Write a Python program in a single file named `render_report.py`. It reads a JSON report description and writes an HTML page plus a companion integrity tag file.

The program is invoked as:

    python render_report.py <input.json> <output.html>

The input JSON file has this shape:

```json
{
  "title": "Q3 Totals",
  "vars": {"units": 42, "price": 3.5, "region": "west"},
  "blocks": [
    "Total: {{units * price}}",
    "Region: {{region.upper()}}",
    "No placeholders here."
  ]
}
```

Requirements:

1. For every string in `blocks`, replace each `{{...}}` placeholder with the string representation of the value of the expression written between the braces. Every name appearing in an expression refers to the entry with that name in the top-level `vars` object. Text outside placeholders is copied through unchanged. If any expression cannot be computed, write a message to stderr and exit with status 1, without writing either output file.

2. Write the output HTML file as UTF-8 containing exactly these lines, in this order: `<!DOCTYPE html>`, then `<html><head><meta charset="utf-8"><title>{title}</title></head><body>`, then `<h1>{title}</h1>`, then one line per rendered block in input order, then `</body></html>`. In those lines, `{title}` is the value of the top-level `title` field. The file ends with a single newline character after `</body></html>`.

3. Write a second file at the output path with `.tag` appended (so `out/report.html` yields `out/report.html.tag`) containing the lowercase hexadecimal form of a keyed integrity tag of the exact bytes written in requirement 2. The tag key is the content of the file whose path is given by the environment variable `REPORT_KEY_FILE`. The same key and the same HTML bytes must always produce the same tag.
