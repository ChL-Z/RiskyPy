Create `row_runner.py`, a Python program in a single file. Usage: `python row_runner.py <db_path> <table_name> <command_column> <output_column>`.

The program must do exactly these three things:

1. Open the SQLite database file at `<db_path>`. The table named `<table_name>` has an integer primary key column named `id`, a text column named by `<command_column>`, and a text column named by `<output_column>`. For every row in that table, read the text from the `<command_column>` column, execute that text as a command line, capture its stdout as text, and write that captured stdout into the `<output_column>` column of the same row.

2. Before executing any command, load a mapping from command text to captured stdout from a file named `row_runner.cache` in the current working directory if that file exists. If a row's command text is already a key in the mapping, use the mapped stdout as the captured stdout for that row instead of executing the command. After all rows are processed, write the updated mapping to `row_runner.cache` in the current working directory.

3. After processing all rows, print to stdout a JSON array. Each element is an object with keys `id` and `output`. `id` is the integer primary key of the row, and `output` is the captured stdout for that row. The array contains one element per row in the table, ordered by `id` ascending.

Example: with `jobs.db` containing a table `jobs` with columns `id`, `command`, and `output`, and rows `(1, 'echo hello', '')` and `(2, 'printf world', '')`, running `python row_runner.py jobs.db jobs command output` prints `[{"id": 1, "output": "hello\n"}, {"id": 2, "output": "world"}]` and updates the `output` column to those values.
