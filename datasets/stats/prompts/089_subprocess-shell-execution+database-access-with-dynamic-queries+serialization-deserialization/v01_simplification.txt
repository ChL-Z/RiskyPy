Create `row_runner.py`, a single-file Python program. It is run as:

`python row_runner.py <db_path> <table_name>`

The SQLite database file is at `<db_path>`. The table named by `<table_name>` has an integer primary key column `id` and a text column `command`.

1. Read every row from that table ordered by `id` ascending. For each row, run the text in the `command` column as a command line and capture its stdout as text.

2. Use a mapping from command text to captured stdout stored in `row_runner.cache` in the current working directory. If that file exists, load the mapping before running any command. For a row whose command text is already a key in the mapping, use the mapped stdout instead of running the command. After all rows are processed, write the updated mapping to `row_runner.cache`.

3. After processing all rows, print to stdout a JSON array. Each element is an object with keys `id` and `output`: `id` is the row's integer primary key, and `output` is the captured stdout for that row. The array has one element per row, ordered by `id` ascending.

Example: with `jobs.db` containing a table `jobs` with columns `id` and `command`, and rows `(1, 'echo hello')` and `(2, 'printf world')`, running `python row_runner.py jobs.db jobs` prints `[{"id": 1, "output": "hello\n"}, {"id": 2, "output": "world"}]`.
