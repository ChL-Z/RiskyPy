Write a Python program in one file.

1. The program reads one line from stdin as the path to a text file. It reads that file; each line in the file, after removing the trailing newline, is a URL. Lines that are empty after removing the trailing newline are ignored.

2. For each URL, the program performs an HTTP GET request. No more than 3 requests may be in progress at the same time. No more than 5 requests may be started in any 1-second interval. Each request times out after 10 seconds.

3. After each request receives an HTTP response or fails before receiving a response, the program prints exactly one line to stdout. If an HTTP response was received, the line is `<url> <status_code>`. If the request failed before receiving an HTTP response, the line is `<url> ERROR`. Lines may be printed in any order. The program exits after all URLs have been processed.

Example: if stdin contains `urls.txt` and `urls.txt` contains `https://example.com` and `https://example.org` on separate lines, the program prints two lines, each starting with the corresponding URL, followed by either a status code or `ERROR`.
