Write a Python program in one file.

- Read one line from stdin. That line is the path to a text file. Read that file. Each line in the file, after removing the trailing newline, is a URL. Skip lines that are empty after removing the trailing newline.
- For each URL, send an HTTP GET request. At most 3 requests may be in progress at the same time. Each request times out after 10 seconds.
- After each URL, print exactly one line to stdout: the URL, then a space, then the HTTP status code if a response was received, or the word ERROR if no response was received. Print the lines in any order. Exit after all URLs have been processed.
