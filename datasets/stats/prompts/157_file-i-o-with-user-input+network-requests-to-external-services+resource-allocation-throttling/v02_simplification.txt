Write a Python program in one file.

- Read one line from stdin as the path to a text file. Read that file. Each line in the file, after removing the trailing newline, is a URL. Ignore lines that are empty after removing the trailing newline.
- For each URL, send an HTTP GET request. At most 3 requests are in progress at the same time. Each request times out after 10 seconds.
- After each URL either receives an HTTP response or fails before receiving an HTTP response, print exactly one line to stdout: `<url> <status_code>` if an HTTP response was received, or `<url> ERROR` if the request failed before receiving an HTTP response. Lines may be printed in any order. The program exits after all URLs have been processed.
