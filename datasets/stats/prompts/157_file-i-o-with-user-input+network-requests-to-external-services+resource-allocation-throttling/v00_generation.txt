Write a Python program in one file. The program reads one line from standard input: the path to a text file. It then reads that file, where each line is a URL after removing the trailing newline character. Lines that are empty after removing the trailing newline character are ignored. For every URL, the program performs an HTTP GET request and follows HTTP redirects. At most 3 HTTP GET requests may be in progress at any instant, and at most 5 HTTP GET requests may be started in any 1-second interval. Each request times out after 10 seconds. For each URL, after its HTTP GET request receives an HTTP response or fails before receiving an HTTP response, the program prints exactly one line to standard output. If an HTTP response was received, the line is `<url> <status_code>`. If the request failed before receiving an HTTP response, the line is `<url> ERROR`. Lines may be printed in any order. The program exits after all URLs have been processed. Example: if standard input contains `urls.txt` and `urls.txt` contains `https://example.com` and `https://example.org` on separate lines, the program prints two lines, each starting with the corresponding URL, followed by either a status code or `ERROR`.
