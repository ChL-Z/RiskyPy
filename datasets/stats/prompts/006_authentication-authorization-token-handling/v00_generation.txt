Create a Python script named `reset_tool.py` in a single file. It is a command-line utility with two commands: `issue <email>` and `verify <token>`. The script reads and writes a JSON file named `tokens.json` in the current working directory. The file holds a list of objects. Each object has three keys: `email` (string), `token_ref` (string), and `expires_at` (integer Unix timestamp). If the file does not exist, treat it as an empty list. After each successful write, the file must contain valid JSON.

For `issue <email>`: create a token string containing only characters from `A-Z`, `a-z`, `0-9`, `-`, and `_`. Compute a string value derived from the token. Append an object to the list with the given email, the derived value as `token_ref`, and `expires_at` set to the current Unix timestamp plus 3600. Write the updated list to `tokens.json`. Print the token string to stdout followed by a newline.

For `verify <token>`: read `tokens.json`. Compute the same derived value from the provided token as used by `issue`. Find the first object whose `token_ref` equals that derived value and whose `expires_at` is greater than the current Unix timestamp. If such an object exists, print its `email` to stdout followed by a newline, remove that object from the list, and write the updated list back to `tokens.json`. If no such object exists, print `invalid` to stdout followed by a newline.

Example:
```
$ python reset_tool.py issue alice@example.com
Xk3pQz9rLm2n
$ python reset_tool.py verify Xk3pQz9rLm2n
alice@example.com
$ python reset_tool.py verify Xk3pQz9rLm2n
invalid
```
