Create a single Python file named `reset_tool.py`. It is a command-line program with two forms:

- `python reset_tool.py issue EMAIL`
- `python reset_tool.py verify TOKEN`

The program reads and writes `tokens.json` in the current working directory. If `tokens.json` is absent, treat it as an empty JSON object. The file must always contain a JSON object. Each value is a JSON object with exactly `email` (string) and `expires_at` (integer Unix timestamp). Each key is a string that is not equal to any issued token string. The program must be able to find an entry from a token string.

For `issue EMAIL`: Generate a token string of 32 characters using only `A-Z`, `a-z`, and `0-9`. Compute a key from the token string. Store the key with `email` set to `EMAIL` and `expires_at` set to the current Unix timestamp plus 3600. Write the updated object to `tokens.json`. Print the token string to stdout followed by a newline.

For `verify TOKEN`: Read `tokens.json`. Compute the key from `TOKEN`. If the key exists and its `expires_at` is greater than the current Unix timestamp, print its `email` to stdout followed by a newline, remove that key from the object, and write the updated object to `tokens.json`. Otherwise, print `invalid` to stdout followed by a newline.
