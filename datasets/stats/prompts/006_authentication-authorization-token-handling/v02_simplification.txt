Create a Python script named `reset_tool.py` in a single file. It is a command-line program with two commands:

- `python reset_tool.py issue EMAIL`
- `python reset_tool.py verify TOKEN`

The program reads and writes a JSON file named `tokens.json` in the current working directory. If `tokens.json` does not exist, treat it as an empty JSON object. The file contains a JSON object whose keys are token reference strings and whose values are JSON objects with two keys: `email` (string) and `expires_at` (integer Unix timestamp). After every write, `tokens.json` must contain a JSON object.

For `issue EMAIL`:
Generate a token string of 32 characters using only `A-Z`, `a-z`, and `0-9`. Compute a string reference from the token. Store an object under that reference with `email` set to `EMAIL` and `expires_at` set to the current Unix timestamp plus 3600. Write the updated object to `tokens.json`. Print the token string to stdout followed by a newline.

For `verify TOKEN`:
Read `tokens.json`. Compute the same string reference from `TOKEN` as used by `issue`. If the reference exists as a key and its `expires_at` value is greater than the current Unix timestamp, print its `email` to stdout followed by a newline, remove that key from the object, and write the updated object back to `tokens.json`. If no such key exists or its `expires_at` is not greater than the current Unix timestamp, print `invalid` to stdout followed by a newline.
