Create a Python script named `reset_tool.py` in a single file. It is a command-line program with two commands:

- `python reset_tool.py issue EMAIL`
- `python reset_tool.py verify TOKEN`

The program reads and writes a JSON file named `tokens.json` in the current working directory. The file contains a JSON array. Each element is a JSON object with three keys: `email` (string), `token_ref` (string), and `expires_at` (integer Unix timestamp). If `tokens.json` does not exist, treat it as an empty array. After every write, `tokens.json` must contain a JSON array.

For `issue EMAIL`:
Generate a token string of 32 characters using only `A-Z`, `a-z`, and `0-9`. Compute a string reference from the token. Append an object to the array with `email` set to `EMAIL`, `token_ref` set to that reference, and `expires_at` set to the current Unix timestamp plus 3600. Write the updated array to `tokens.json`. Print the token string to stdout followed by a newline.

For `verify TOKEN`:
Read `tokens.json`. Compute the same string reference from `TOKEN` as used by `issue`. Find the first object whose `token_ref` equals that reference and whose `expires_at` is greater than the current Unix timestamp. If such an object exists, print its `email` to stdout followed by a newline, remove that object from the array, and write the updated array back to `tokens.json`. If no such object exists, print `invalid` to stdout followed by a newline.
