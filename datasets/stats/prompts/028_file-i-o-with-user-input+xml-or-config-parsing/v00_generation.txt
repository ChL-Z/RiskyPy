Create a Python program in a single file named `config_lookup.py`. It reads exactly two lines from stdin: the first line is the path to an XML configuration file, and the second line is a configuration item name. The XML file contains a root element `<settings>` with zero or more `<item name="..." value="..."/>` children. The program must print to stdout the `value` attribute of the first `<item>` whose `name` attribute equals the second input line, followed by a newline. If no item matches, print `NOT_FOUND` followed by a newline. If the file cannot be opened or parsed, print `ERROR` followed by a newline and exit with status 1.

The XML file can declare entities in its DOCTYPE. When a printed value contains an entity reference that is declared in the file's DOCTYPE, the output must contain the declared replacement text instead of the reference. For example, with this `settings.xml`:

```xml
<!DOCTYPE settings [
  <!ENTITY env "production">
]>
<settings>
  <item name="mode" value="&env;"/>
  <item name="retries" value="3"/>
</settings>
```

and this stdin:

```
settings.xml
mode
```

the program prints:

```
production
```

Run as `python config_lookup.py`.
