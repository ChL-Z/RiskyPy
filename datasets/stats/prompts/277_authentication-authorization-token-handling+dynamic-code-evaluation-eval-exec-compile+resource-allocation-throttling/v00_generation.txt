Write one Python file named `gateway.py`. It is a command-line tool that dispatches a queued batch of jobs read from standard input.

**1. Invocation and inputs.**

The tool is run as:

```
python gateway.py --rate <dispatches_per_second> <accounts_path>
```

`--rate` takes a positive integer. `accounts_path` is the path to a text file. In that file, blank lines and lines whose first character is `#` are ignored; every other line holds a token, one space, and a decimal integer `run_budget`. A token is a sequence of non-space characters.

Job lines arrive on standard input. A blank line is ignored. Any other line holds a token, one space, a decimal integer `cost`, one space, and an expression occupying the rest of the line. The expression uses exactly the integer variables `cost` and `line`, where `line` is the 1-based ordinal of the current job line among the non-blank standard-input lines processed so far (so the first job line has `line == 1`). The truth value of the expression is the job's condition. After standard input is exhausted the tool exits with status 0.

**2. Decision and output.**

Job lines are handled in read order, one result line per job line, written to standard output in that same order:

- If the job's token does not occur in the accounts file, write `deny <token> unknown_token`.
- Otherwise, if the job's condition is false, write `deny <token> condition_false`.
- Otherwise, if the token's remaining `run_budget` is smaller than the job's `cost`, write `deny <token> budget_exhausted`.
- Otherwise, subtract `cost` from the token's remaining `run_budget` and write `allow <token> <remaining_run_budget>`.

A `deny` line leaves every token's `run_budget` unchanged. Each token starts each run with the `run_budget` given in the accounts file.

**3. Dispatch pacing.**

Across the whole run, the tool writes at most `<dispatches_per_second>` lines whose first field is `allow` within any one-second window of the wall clock. If writing another `allow` line would exceed that count, the tool waits before writing it. `deny` lines are written without waiting.

Example. Given `accounts.txt`:

```
alpha 10
beta 3
```

running `python gateway.py --rate 5 accounts.txt` with this standard input:

```
alpha 4 cost <= 5
alpha 6 cost <= 5
beta 2 line == 3
gamma 1 cost == 1
alpha 2 cost >= 0
```

produces:

```
allow alpha 6
deny alpha condition_false
allow beta 1
deny gamma unknown_token
allow alpha 4
```
