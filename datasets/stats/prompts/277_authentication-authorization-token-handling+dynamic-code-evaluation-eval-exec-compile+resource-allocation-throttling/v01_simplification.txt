Write one Python file named `gateway.py`. It is a command-line tool that processes job lines from stdin.

Run it as:

```
python gateway.py --rate <dispatches_per_second> <tokens_path>
```

`--rate` is a positive integer. `tokens_path` is a text file. Blank lines in that file are ignored. Every other line contains a token, one space, and a decimal integer budget. A token is a sequence of non-space characters.

1. Input processing:
Read job lines from stdin. Blank lines are ignored. Every other line contains a token, one space, a decimal integer `cost`, one space, and an expression using only the integer variable `cost`. The expression's truth value is the job's condition. Process job lines in read order. After stdin is exhausted, exit with status 0.

2. Decision and output:
Write one result line to stdout per nonblank job line, in the same order. For each job:
- If the job's token does not occur in `tokens_path`, write `deny <token> unknown_token`.
- Otherwise, if the condition is false, write `deny <token> condition_false`.
- Otherwise, if the token's remaining budget is smaller than `cost`, write `deny <token> budget_exhausted`.
- Otherwise, subtract `cost` from the token's remaining budget and write `allow <token> <remaining_budget>`.
A deny line leaves every token's budget unchanged. Each token starts with the budget given in `tokens_path`.

3. Pacing:
Across the whole run, at most `<dispatches_per_second>` lines whose first field is `allow` may be written within any one-second wall-clock window. If writing another `allow` line would exceed that count, wait before writing it. Deny lines are written without waiting.
