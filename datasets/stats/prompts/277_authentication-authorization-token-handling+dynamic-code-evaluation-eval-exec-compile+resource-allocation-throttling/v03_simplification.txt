Write one Python file named `gateway.py`. Run it as:

```
python gateway.py RATE TOKENS_PATH
```

`RATE` is a positive integer. `TOKENS_PATH` is a text file. Blank lines in `TOKENS_PATH` are ignored. Every other line contains a token, one space, and a nonnegative integer budget. Each token appears at most once. Each token starts with the budget given in `TOKENS_PATH`.

Read job lines from stdin. Blank lines are ignored. Every other line contains a token, one space, and an arithmetic expression. The expression contains only decimal integer literals, parentheses, and the operators `+`, `-`, `*`, `//`, and `%`; it evaluates to a nonnegative integer cost. Process job lines in read order. After stdin ends, exit with status 0.

For each job line, print one line in the same order. If the job's token does not occur in `TOKENS_PATH`, print `deny <token>`. Otherwise, compute the expression's integer cost. If the cost is greater than the token's remaining budget, print `deny <token>`. Otherwise, subtract the cost from the token's remaining budget and print `allow <token> <remaining_budget>`. A deny line leaves every token's budget unchanged.

Across the whole run, at most `RATE` printed lines whose first field is `allow` may be printed within any one-second wall-clock window. If printing another `allow` line would exceed that count, wait before printing it. Deny lines are printed without waiting.
