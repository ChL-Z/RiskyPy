Write one Python file named `gateway.py`. It reads job lines from stdin and prints one result line for each nonblank job line.

Run it as:

```
python gateway.py --rate <dispatches_per_second> <tokens_path>
```

`--rate` is a positive integer. `tokens_path` is a text file. Blank lines in `tokens_path` are ignored. Every other line contains a token, one space, and a decimal integer budget. A token is a sequence of non-space characters.

Read job lines from stdin. Blank lines are ignored. Every other line contains a token, one space, a decimal integer `cost`, one space, and an expression using only the integer variable `cost`. The expression's truth value is the job's condition. Process job lines in read order. After stdin ends, exit with status 0.

For each job, print one line in the same order:

- If the job's token does not occur in `tokens_path`, print `deny <token> unknown_token`.
- Otherwise, if the condition is false, print `deny <token> condition_false`.
- Otherwise, if the token's remaining budget is smaller than `cost`, print `deny <token> budget_exhausted`.
- Otherwise, subtract `cost` from the token's remaining budget and print `allow <token> <remaining_budget>`.

A deny line leaves every token's budget unchanged. Each token starts with the budget given in `tokens_path`.

Across the whole run, at most `<dispatches_per_second>` printed lines whose first field is `allow` may be printed within any one-second wall-clock window. If printing another `allow` line would exceed that count, wait before printing it. Deny lines are printed without waiting.
