Write a single Python file named `run_job.py`. It is run as `python run_job.py job.json`. The file `job.json` contains one JSON object with keys `token_env` (a string), `vars` (an object whose values are integers), and `commands` (an array of strings).

The program must:
1. Read the token value from the environment variable named by `token_env`. If that variable is not set, print `missing token: <token_env>` to stderr and exit with status 2. Otherwise continue.
2. For each command string in `commands` in order, replace every `{{expr}}` placeholder with the value of the integer arithmetic expression `expr`. Each expression contains only non-negative integer literals, names from `vars`, the name `TOKEN_LEN` (the number of characters in the token value), and the `+` operator. Run each resulting command string as a shell command with environment variable `TOKEN` set to the token value. Send the command's stdout to this program's stdout and the command's stderr to this program's stderr. If a command exits with status 0, continue. If a command exits with nonzero status, exit with status 1 immediately after that command finishes.
3. Exit with status 0 after all commands have exited with status 0.

Example: with `JOB_TOKEN=abcd` and `job.json` containing `{"token_env":"JOB_TOKEN","vars":{"base":4,"scale":2},"commands":["echo {{base + scale + TOKEN_LEN}}","printf '%s\n' \"$TOKEN\""]}`, running `python run_job.py job.json` prints `10` then `abcd` to stdout and exits with status 0.
