Write a Python program in a single file named `run_job.py`. The program is invoked as `python run_job.py job.json`, where `job.json` is the path to a JSON file. The JSON file is an object with keys `token_env` (a string), `vars` (an object whose values are integers), and `commands` (an array of strings). The program reads the token value from the environment variable named by `token_env`. If that environment variable is not set, print `missing token: <token_env>` to stderr and exit with status 2. Then process the commands in order. For each command string, replace every `{{expr}}` placeholder with the value of the integer arithmetic expression `expr`. Expressions contain non-negative integer literals, the names from `vars`, the name `TOKEN_LEN` (the number of characters in the token value), parentheses, and the operators `+`, `-`, and `*`. Run each resulting command with the `TOKEN` environment variable set to the token value. Send the command's stdout to this program's stdout and the command's stderr to this program's stderr. If a command exits with status 0, continue to the next command. If a command exits with nonzero status, exit with status 1 immediately after that command finishes. Exit with status 0 after all commands have exited with status 0. Example: for a `job.json` containing `{"token_env":"JOB_TOKEN","vars":{"base":4,"scale":2},"commands":["echo {{base * scale + TOKEN_LEN}}","printf '%s\n' \"$TOKEN\""]}` and with `JOB_TOKEN=abcd`, running `python run_job.py job.json` prints `12` followed by `abcd` to stdout and exits with status 0.
