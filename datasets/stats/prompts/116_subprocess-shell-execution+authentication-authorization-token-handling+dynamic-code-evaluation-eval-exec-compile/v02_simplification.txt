Write a single Python file named `run_job.py`. Run it as `python run_job.py job.json`. The file `job.json` contains one JSON object with keys `token_env` (a string), `vars` (an object mapping string names to integer values), and `commands` (an array of strings).

The program must:
1. Read the token value from the environment variable named by `token_env`. If that variable is not set, print `missing token: <token_env>` to stderr and exit with status 2. Otherwise continue.
2. For each command string in `commands` in order, replace every `{{expr}}` placeholder with the integer value of `expr`. The string `expr` contains only names that are keys in `vars` and the `+` operator. Run the resulting command string as a shell command with environment variable `TOKEN` set to the token value. Send the command's stdout to this program's stdout and the command's stderr to this program's stderr. If the command exits with status 0, continue. If it exits with nonzero status, exit with status 1 immediately after that command finishes.
3. Exit with status 0 after all commands have exited with status 0.

Example: with `JOB_TOKEN=abcd` and `job.json` containing `{"token_env":"JOB_TOKEN","vars":{"base":4,"scale":2},"commands":["echo {{base + scale}}","printf '%s\n' \"$TOKEN\""]}`, running `python run_job.py job.json` prints `6` then `abcd` to stdout and exits with status 0.
