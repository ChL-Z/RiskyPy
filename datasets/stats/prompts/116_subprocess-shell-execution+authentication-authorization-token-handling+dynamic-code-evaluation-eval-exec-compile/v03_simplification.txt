Write a single Python file named `run_job.py`. Run it as `python run_job.py job.json`. The file `job.json` contains one JSON object with keys `token_env` (string), `vars` (object mapping string names to integer values), and `command` (string).

The program must:
1. Read the value of the environment variable named by `token_env`. If that variable is not set, write `missing token: <token_env>` to stderr and exit with status 2. `<token_env>` is the value of the `token_env` key.
2. In `command`, replace each `{{expr}}` placeholder with the integer value of `expr`. `expr` contains only names that are keys in `vars` and the `+` operator.
3. Run the resulting string as a shell command with environment variable `TOKEN` set to the token value. Write the command's stdout to this program's stdout and the command's stderr to this program's stderr. Exit with the same status code as the command.

Example: with `JOB_TOKEN=abcd` and `job.json` containing `{"token_env":"JOB_TOKEN","vars":{"base":4,"scale":2},"command":"echo {{base + scale}}; printf '%s\n' \"$TOKEN\""}`, running `python run_job.py job.json` prints `6` then `abcd` to stdout and exits with status 0.
