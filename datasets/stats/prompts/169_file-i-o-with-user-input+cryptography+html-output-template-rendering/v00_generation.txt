Write a Python program in a single file named `hash_manifest.py`. The program reads newline-separated file paths from standard input. For each path, it reads the file contents in binary mode and computes a cryptographic hash of those contents, represented as a 64-character lowercase hexadecimal string. The program then writes to standard output an HTML document with a `<title>` containing the text `File Hash Manifest` and a `<table>` with one row per input file. Each row has two cells: the first cell contains the file path exactly as it appeared in the input, and the second cell contains the hash. The HTML document must include `<html>`, `<head>`, and `<body>` tags.

Example usage:
```
printf 'notes.txt\nimage.png\n' | python hash_manifest.py > manifest.html
```
