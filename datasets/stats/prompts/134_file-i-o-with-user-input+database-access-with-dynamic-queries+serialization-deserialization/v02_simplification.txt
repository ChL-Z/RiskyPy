Write a single Python file `contact_find.py`. The program receives one command-line argument: the path to a SQLite database file. The database has a table `contacts` with columns `id` (integer), `name` (text), `email` (text), and `city` (text).

Read the first line from standard input. If that line is empty or contains only whitespace, select all rows from `contacts`. Otherwise, the line has the form `<column>=<value>`, where `<column>` is exactly one of `name`, `email`, or `city`. Select rows from `contacts` where that column equals that value. Order the selected rows by `id` ascending.

Print the selected rows to standard output as one JSON object per line, with keys `id`, `name`, `email`, and `city`. Use a cache file at `<database_path>.cache`: if the cache file does not exist, serialize the selected rows to it. If the cache file exists, deserialize the rows from it and print those rows instead of querying the database. Do not update the cache file after it is created.
