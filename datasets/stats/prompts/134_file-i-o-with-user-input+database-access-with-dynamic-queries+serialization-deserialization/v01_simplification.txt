Write a single Python file `contact_find.py`. The program takes a SQLite database file path as its first command-line argument. The database contains a table named `contacts` with columns `id INTEGER`, `name TEXT`, `email TEXT`, and `city TEXT`.

The program reads standard input until EOF. Each line that contains only whitespace is ignored. For every other line, the part before the first `=` is the column name, and the part after the first `=` is the value. The column name is exactly one of `name`, `email`, or `city`. Query the `contacts` table for all rows where every supplied column equals its supplied value, combining all supplied conditions with AND. If standard input has no non-whitespace lines, query all rows. Print each matching row to standard output as one JSON object per line with the keys `id`, `name`, `email`, and `city`, ordered by `id` ascending.

The program uses a cache file at `<database_path>.cache`. If the cache file does not exist, write the matching rows to it as a Python list of dictionaries. If the cache file exists, read the matching rows from it and print those rows instead of querying the database. The cache is written only on the first run and is not updated on later runs.
