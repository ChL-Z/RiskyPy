Write a Python program in a single file named `contact_find.py`. The program takes a SQLite database file path as its first command-line argument. The database contains a table named `contacts` with columns `id INTEGER`, `name TEXT`, `email TEXT`, and `city TEXT`.

The program reads lines from standard input until EOF. Each line that contains only whitespace is ignored. For every other line, the part before the first `=` is the column name, and the part after the first `=` is the value. The column name is exactly one of `name`, `email`, or `city`. The program finds all rows in `contacts` where every supplied column equals its supplied value, combining all supplied conditions with AND. If standard input has no non-whitespace lines, the program finds all rows. The matching rows are ordered by `id` ascending. The program prints each matching row to standard output as one JSON object per line with the keys `id`, `name`, `email`, and `city`.

The program keeps a cache file at `<database_path>.cache`. When that cache file does not exist, the program writes the matching rows to it as a Python list of dictionaries. When that cache file exists, the program reads the matching rows from it and prints those rows instead of reading the database. The cache stores the result of the first run and is not updated on later runs.

Example:

`printf 'city=Berlin\nname=Ada\n' | python contact_find.py /tmp/contacts.db`

If `/tmp/contacts.db` contains a `contacts` table with these rows:

| id | name | email | city |
|----|------|-------|------|
| 1 | Ada | ada@example.com | Berlin |
| 2 | Bob | bob@example.com | Berlin |
| 3 | Ada | ada2@example.com | Paris |

The first run prints:

`{"id": 1, "name": "Ada", "email": "ada@example.com", "city": "Berlin"}`

A second run with the same command prints the same line from `/tmp/contacts.db.cache`.
