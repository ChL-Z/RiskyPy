Write a single Python file named report.py. Read newline-separated file paths from standard input. Assume each path names a readable file. Process the paths with at most 2 files being read at the same time. For each path, read the file and count its total bytes and its 0x0A bytes.

After all paths are processed, write an HTML file named summary.html. The HTML file must contain a <title> element with the text File Summary and a <table> element. The first row of the table must contain header cells with the text Path, Bytes, and Newlines. Each later row must correspond to one input path, in input order, with cell text for the path, the byte count, and the 0x0A byte count.
