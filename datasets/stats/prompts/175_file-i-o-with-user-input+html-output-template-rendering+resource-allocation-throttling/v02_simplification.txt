Create a single Python file named report.py.

Read newline-separated file paths from standard input. Assume each path names a file that exists and can be read. Process the paths with at most 2 files being read at the same time. For each path, count the file's total bytes and count the bytes equal to 0x0A.

After all paths are processed, write an HTML file named summary.html. The HTML file must contain a <table> element with one row per input path. Each row must have three cells: the path text, the total byte count, and the 0x0A byte count.
