Write a single Python file named report.py. The program reads newline-separated file paths from standard input. Assume every path names a readable file. For each path, read the file and compute two integers: the number of bytes in the file, and the number of 0x0A bytes in the file. The program processes at most 4 files concurrently. After all files are processed, write an HTML file named summary.html. The HTML file must contain a <title> element with the text File Summary and a <table> element. The first row of the table must contain header cells with the text Path, Bytes, and Newlines. Each subsequent row corresponds to one input file, in the same order as the input, with the file path, the byte count, and the newline count as cell text. For example, running `printf 'alpha.txt
beta.txt
' | python report.py` should produce summary.html containing a table with two data rows for alpha.txt and beta.txt.
