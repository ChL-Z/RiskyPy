Write a Python script in a single file named `tasks.py`. It reads `tasks.txt` from the current working directory, where each line is one task description. It loads the existing task list from `tasks.bin` if that file exists, starts with an empty list otherwise, appends the tasks from `tasks.txt` to the list, writes the updated list back to `tasks.bin`, and prints the total number of tasks in the list. It appends one line to `tasks.log`: the current UTC timestamp in ISO 8601 format, a space, and the number of tasks added from `tasks.txt`. If reading `tasks.txt` or reading from or writing to `tasks.bin` raises an exception, it appends a line to `tasks.log` with the current UTC timestamp in ISO 8601 format, a space, and the exception message, then exits with status code 1.
