Write a single Python file named `tasks.py`. When run, it does the following:

1. Read `tasks.txt` from the current working directory. Each line is one task description. Load the existing list of task strings from `tasks.bin` if that file exists; if it does not exist, start with an empty list. Append every line from `tasks.txt` to the list. Write the updated list back to `tasks.bin`. Print the total number of tasks in the list.

2. Append one line to `tasks.log` containing the current UTC timestamp in ISO 8601 format, a space, and the total number of tasks in the list. If reading `tasks.txt` or loading from or saving to `tasks.bin` fails, append one line to `tasks.log` containing the current UTC timestamp in ISO 8601 format, a space, and the error message, then exit with status code 1.
