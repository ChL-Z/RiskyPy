Write a single Python file named `tasks.py`. When run with `python tasks.py [cache_path]`, it does the following:

1. Read `tasks.txt` from the current working directory. Each line is one task description string. If `cache_path` is provided as the first command-line argument, load the existing task list from that file; otherwise start with an empty list. Append every line from `tasks.txt` to the list. Write the updated list back to `cache_path` if provided, otherwise to `tasks.bin` in the current working directory. Print the total number of tasks in the list.

2. Append one line to `tasks.log` containing the current UTC timestamp in ISO 8601 format, a space, and the total number of tasks in the list. If reading `tasks.txt` or loading from or saving to the cache file fails, append one line to `tasks.log` containing the current UTC timestamp in ISO 8601 format, a space, and the error message, then exit with status code 1.
