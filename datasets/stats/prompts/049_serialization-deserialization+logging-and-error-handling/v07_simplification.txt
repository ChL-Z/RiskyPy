Write a single Python file named `tasks.py`. When run as `python tasks.py` in a directory that contains `tasks.txt`, it must do the following:

1. Read `tasks.txt` line by line. Remove the trailing newline from each line. If `tasks.bin` exists in the directory, load the list of task strings this script previously wrote to it; if it does not exist, use an empty list. Append every line from `tasks.txt` to the list. Write the list to `tasks.bin`. Print the number of items in the list to stdout.

2. Append one line to `tasks.log` containing the number of items in the list. If reading `tasks.txt`, loading `tasks.bin`, or writing `tasks.bin` raises an exception, append one line to `tasks.log` containing the exception message, then exit with status code 1.
