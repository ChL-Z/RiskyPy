Write a single Python file named `tasks.py`. When run with `python tasks.py`, it does the following:

1. Read `tasks.txt` from the current working directory. Each line is one task description string; remove the trailing newline before appending it. If `tasks.bin` exists in the current working directory, load the existing list of task strings from it; otherwise start with an empty list. Append every task from `tasks.txt` to the list. Write the updated list to `tasks.bin` so it can be loaded on a later run. Print the total number of tasks in the list.

2. Append one line to `tasks.log` containing the current UTC timestamp in ISO 8601 format, a space, and the total number of tasks in the list. If reading `tasks.txt`, loading `tasks.bin`, or writing `tasks.bin` fails, append one line to `tasks.log` containing the current UTC timestamp in ISO 8601 format, a space, and the error message, then exit with status code 1.
