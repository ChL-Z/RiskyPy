Write a Python script in a single file named `tasks.py`. The script reads a text file named `tasks.txt` from the current working directory. Each line in `tasks.txt` is a task description. The script maintains a persistent list of task descriptions in a binary file named `tasks.bin` in the current working directory. If `tasks.bin` does not exist, the script starts with an empty list. The script appends the tasks read from `tasks.txt` to the list, writes the updated list back to `tasks.bin`, and prints the total number of tasks in the list. The script also appends a line to a text file named `tasks.log` in the current working directory. That line must contain the current UTC timestamp in ISO 8601 format, followed by a space, followed by the number of tasks that were added from `tasks.txt`. If reading `tasks.txt` or reading from or writing to `tasks.bin` raises an exception, the script must append a line to `tasks.log` containing the current UTC timestamp in ISO 8601 format, followed by a space, followed by the exception message. In that case, the script must exit with status code 1.

For example, if `tasks.txt` contains:
```
alpha
beta
gamma
```
and `tasks.bin` does not exist, running `python tasks.py` prints `3` and creates `tasks.bin` with the three tasks. The `tasks.log` file contains one line with the timestamp and `3`. If `tasks.txt` contains the same three lines and is run again, `python tasks.py` prints `6` and `tasks.log` gets another line with the timestamp and `3`.
