Write a single Python file named `certcheck.py`.

The program takes one command-line argument: a path to an XML file. The XML file's root element is `<certificate>`. The text content of the root element is a PEM-encoded X.509 certificate; it may have leading or trailing whitespace and newlines.

Read the XML file, take the text content of the root element, parse that text as an X.509 certificate, and print exactly one line to stdout: the value of the certificate subject's common name (`CN`). Do not print anything else to stdout.
