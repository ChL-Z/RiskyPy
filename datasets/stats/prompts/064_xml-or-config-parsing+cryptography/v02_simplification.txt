Write a single Python file named `certcheck.py`.

The program takes one command-line argument: the path to an XML file. The XML file has a root `<service>` element with a `name` attribute and exactly one `<certificate>` child element. The text content of `<certificate>` is a PEM-encoded X.509 certificate and may have leading or trailing whitespace and newlines. The certificate has a subject common name.

Print exactly one line to stdout: a JSON object with exactly two keys, `name` and `common_name`. `name` is the value of the root element's `name` attribute. `common_name` is the certificate's subject common name. Do not print anything else to stdout.
