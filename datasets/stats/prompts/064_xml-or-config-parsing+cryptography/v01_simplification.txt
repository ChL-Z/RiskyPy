Write a Python program in a single file named `certcheck.py`. The program reads the path to an XML file from the first command-line argument. The XML file has a root `<service>` element with a `name` attribute and exactly one `<certificate>` child element. The text content of `<certificate>` is a PEM-encoded X.509 certificate and may include leading or trailing whitespace and newlines. Print to stdout one compact JSON object with keys `name`, `common_name`, and `not_after`. `name` is the root element's `name` attribute value. `common_name` is the certificate's subject common name. `not_after` is the certificate expiration timestamp formatted as an ISO 8601 UTC string ending in `Z`, for example `2031-04-05T12:34:56Z`. Do not print anything else to stdout.
