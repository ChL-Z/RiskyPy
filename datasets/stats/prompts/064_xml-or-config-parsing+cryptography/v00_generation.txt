Write a Python program in a single file named `certcheck.py`. The program reads the path to an XML file from the first command-line argument. The XML file has a root `<services>` element containing zero or more `<service>` elements. Each `<service>` element has a `name` attribute and exactly one `<certificate>` child element. The text content of `<certificate>` is a PEM-encoded X.509 certificate and may include leading or trailing whitespace and newlines. For every `<service>` element in document order, the program prints a JSON object with keys `name`, `common_name`, and `not_after`. The program prints a JSON array of these objects to stdout. `common_name` is the value of the subject common name field from the certificate. `not_after` is the certificate expiration timestamp formatted as an ISO 8601 UTC string ending in `Z`, for example `2031-04-05T12:34:56Z`. If there are zero `<service>` elements, print `[]`. When the `--pretty` flag is passed as the second command-line argument, the JSON array is printed with two-space indentation; otherwise it is printed as compact JSON with no extra whitespace. Do not print anything else to stdout.\n\nExample XML file `config.xml`:\n```\n<services>\n  <service name=\"billing\">\n    <certificate>\n-----BEGIN CERTIFICATE-----\nMIIB...\n-----END CERTIFICATE-----\n    </certificate>\n  </service>\n  <service name=\"reports\">\n    <certificate>\n-----BEGIN CERTIFICATE-----\nMIIB...\n-----END CERTIFICATE-----\n    </certificate>\n  </service>\n</services>\n```\n\nCommand:\n`python certcheck.py config.xml --pretty`\n\nOutput:\n```\n[\n  {\n    \"name\": \"billing\",\n    \"common_name\": \"billing.example.com\",\n    \"not_after\": \"2031-04-05T12:34:56Z\"\n  },\n  {\n    \"name\": \"reports\",\n    \"common_name\": \"reports.example.com\",\n    \"not_after\": \"2031-04-05T12:34:56Z\"\n  }\n]\n```
