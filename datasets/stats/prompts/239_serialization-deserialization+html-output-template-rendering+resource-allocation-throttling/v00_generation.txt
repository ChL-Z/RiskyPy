Write a Python 3 program in a single file named `batch_report.py`. When run with `python batch_report.py` from a directory containing `jobs.jsonl`, it processes that file and produces `report.html` in the same directory. No network access is used.

`jobs.jsonl` holds one JSON object per line. Each object has exactly two keys: `name` (a string) and `command` (a string). For example:

```
{"name": "free-space", "command": "df -h /"}
{"name": "list-tmp", "command": "ls -l /tmp"}
{"name": "who", "command": "whoami"}
```

The program must satisfy these three requirements:

1. Run every job's `command` as a command line and capture the combined text it writes to standard output and standard error, along with its exit status. At no point may more than 3 jobs be running at the same time. The start of one job must be at least 0.25 seconds after the start of the job that was started immediately before it. A job whose process exits with a nonzero status is still recorded like any other job.

2. Keep results across runs in a file named `cache.bin`. Before running a job, if `cache.bin` exists and holds a record whose stored name equals the job's `name` and whose stored command equals the job's `command`, reuse that record's captured text and exit status instead of running the command. When all jobs have been handled, `cache.bin` must contain a record for every job in `jobs.jsonl` from that run, both the reused ones and the newly run ones. The program writes `cache.bin` itself; nothing else reads or writes it.

3. Write `report.html` containing a single HTML document with a table. The table has one row per job in `jobs.jsonl`, in the order the jobs appear in that file, and each row has three cells: the job's `name`, its exit status, and its captured output text. Above the table, the document contains the line `Ran: X, Reused: Y`, where `X` is the number of jobs whose commands were actually run during this invocation and `Y` is the number whose results were reused from `cache.bin`.

Examples of the table's contents: for the three jobs above, if none of them were in the cache, the document shows `Ran: 3, Reused: 0` and three rows, one per job. If the program is run a second time with the same `jobs.jsonl` unchanged, the document shows `Ran: 0, Reused: 3` and the same three rows.

The program exits with status 0 after `report.html` has been written.
