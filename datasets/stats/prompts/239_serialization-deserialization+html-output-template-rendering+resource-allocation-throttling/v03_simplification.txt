Write a Python 3 program in one file named `batch_report.py`. Run it with `python batch_report.py` from a directory that contains `jobs.jsonl`. The program reads `jobs.jsonl`, writes `report.html` in that directory, and uses `cache.bin` in that directory to keep job results between runs.

`jobs.jsonl` contains one JSON object per line. Each object has two string keys: `name` and `command`.

The program must do these three things:

1. Process the jobs in the order they appear. Run each job's `command` as a command line. Capture its combined standard output and standard error as one text string, and capture its exit status. Run jobs sequentially: start the first immediately; start each later job at least 0.25 seconds after the previous job started. Treat zero and nonzero exit statuses the same.

2. Before running a job, if `cache.bin` exists and contains a saved record whose `name` and `command` both match the job, reuse that record's output text and exit status instead of running the command. After all jobs are handled, write `cache.bin` with one record for every job from this run, including reused and newly run jobs.

3. Write `report.html` as one HTML document. It contains the exact line `Ran: X, Reused: Y` above a table. X is the number of jobs whose commands were run during this invocation. Y is the number of jobs whose saved results were reused. The table has one row per job in `jobs.jsonl`, in the order the jobs appear. Each row has three cells: the job's `name`, its exit status, and its captured output text.

Exit with status 0 after `report.html` is written.
