Write a Python program in a single file named `pypi_latest.py`. When run, it prints `Package file: ` to stdout and reads one line from stdin. That line is the path to a text file. Each line of that text file contains one Python package name; lines that are empty or contain only spaces are ignored.

For each package name in file order, retrieve the JSON document at `https://pypi.org/pypi/<package>/json`, where `<package>` is replaced by the package name exactly as it appears in the file. From the returned JSON, read the version string at `info.version`. Print `<package>==<version>` to stdout. If the retrieval does not return an HTTP 200 status, print `<package>: unavailable` to stdout instead.

After processing all package names, write the same lines that were printed to stdout into a file named `latest_versions.txt` in the current working directory, one line per package in the same order, overwriting the file if it already exists.

Example: if the input file contains:
```
flask
numpy
```
the stdout and `latest_versions.txt` contain:
```
flask==3.0.3
numpy==2.1.0
```
The version numbers shown are examples; the program must use the version from the JSON response.
