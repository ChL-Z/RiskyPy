Write a Python program in a single file named `job_runner.py`.

The program takes one command-line argument: the path to a JSON file. The JSON file contains an object with:
- `allowed_tokens`: list of strings
- `start_interval_seconds`: number
- `commands`: list of distinct strings

1. Read the environment variable `JOB_RUNNER_TOKEN`. If it is absent or its value is not in `allowed_tokens`, print `Access denied` to standard error and exit with status code 1.
2. Otherwise, run each command string from `commands` as a separate operating system process, in list order, one at a time. Wait for each command to finish before starting the next. Before starting each command after the first, wait until at least `start_interval_seconds` seconds have elapsed since the previous command started.
3. After all commands finish, print to standard output a JSON object. Each key is a command string from `commands`. Each value is the integer exit status of that command. Exit with status code 0.

Example: if `jobs.json` contains `{"allowed_tokens":["abc"],"start_interval_seconds":0.5,"commands":["echo hi","echo bye"]}` and `JOB_RUNNER_TOKEN` is `abc`, running `python job_runner.py jobs.json` prints a JSON object with statuses for both commands, with at least 0.5 seconds between the starts of the two commands.
