Write a Python program in a single file named `job_runner.py`.

The program reads a JSON file whose path is given as the first command-line argument. The JSON file contains an object with keys: `allowed_tokens` (list of strings), `parallel_limit` (integer), `start_interval_seconds` (number), and `commands` (list of strings). The program reads the environment variable `JOB_RUNNER_TOKEN`. If the value of `JOB_RUNNER_TOKEN` is not present in the `allowed_tokens` list, print `Access denied` to standard error and exit with status code 1. Otherwise, for each command string in `commands`, run the command as a separate operating system process. Start at most `parallel_limit` commands at the same time, and wait at least `start_interval_seconds` seconds between the starts of two consecutive commands. After all commands have finished, print a JSON object to standard output where each key is a command string from `commands` and the value is an object with keys `returncode` (integer), `stdout` (string), and `stderr` (string).

For example, if `jobs.json` contains `{"allowed_tokens":["abc"],"parallel_limit":2,"start_interval_seconds":0.5,"commands":["echo hi","sleep 1","echo bye"]}` and the environment variable `JOB_RUNNER_TOKEN` is `abc`, running `python job_runner.py jobs.json` should print a JSON object with results for the three commands, with at most two commands running at the same time and at least 0.5 seconds between the starts of consecutive commands.
