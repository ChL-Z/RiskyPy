Write a single Python file named `repo_report.py`. Read all of stdin and split it into lines. For each line that is not empty after stripping surrounding whitespace, treat it as a repository slug in the form `owner/repo` and send one HTTP GET request to `https://api.github.com/repos/<owner>/<repo>`. Assume each response has status 200 and a JSON body containing an integer `stargazers_count` and a string `description`. After processing all lines, write `report.html` in the current working directory, replacing it if it exists. The file contains an HTML document whose `<body>` contains one `<table>`. The first table row contains exactly three cells with text `Repository`, `Stars`, and `Description`. For each processed input line, in input order, add one following row with exactly three cells: the slug text after stripping surrounding whitespace, the `stargazers_count` value as a decimal integer, and the `description` value.
