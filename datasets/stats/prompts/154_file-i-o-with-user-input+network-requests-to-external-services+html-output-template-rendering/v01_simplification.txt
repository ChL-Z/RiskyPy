Write a single Python file named `repo_report.py`. The program reads all of standard input and splits it into lines. Each line that is not empty after stripping surrounding whitespace is a repository slug in the form `owner/repo`. For each such line, in the order it appears, send one HTTP GET request to `https://api.github.com/repos/<owner>/<repo>`. Assume every request returns status 200 and the JSON response body contains an integer field `stargazers_count` and a string field `description`. After all lines are handled, write `report.html` in the current working directory, replacing it if it exists. The file contains an HTML document with a `<body>` containing one `<table>`. The first row has exactly three cells with text `Repository`, `Stars`, and `Description`. Each following row has exactly three cells: the slug text after stripping surrounding whitespace, the `stargazers_count` value written as a decimal integer, and the `description` value. There is exactly one following row per processed input line, in input order.
