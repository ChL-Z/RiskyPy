Write one Python file named `fingerprint_batch.py`. Run it as:

    python fingerprint_batch.py <config.xml>

1. Read the XML file path given as the first command-line argument. The XML root is `<config>` with integer attributes `max_workers` and `min_interval_ms`, and exactly one child `<salt>` whose text is the salt string. `max_workers` is positive and `min_interval_ms` is non-negative. Example:

    <config max_workers="3" min_interval_ms="200">
      <salt>pepper-2024</salt>
    </config>

2. Read newline-separated file paths from stdin until EOF. For each path, in the same order, write to stdout one line: the path as read, one tab character, then either a fingerprint or `ERROR`. If the path cannot be opened and read as a regular file, write `ERROR` for that path.

3. For each readable path, compute a 32-character lowercase hexadecimal fingerprint from a 128-bit cryptographic digest over the UTF-8 salt bytes followed by the file's raw bytes. Process paths with at most `max_workers` file reads in progress at once. Across all reads, start no file read less than `min_interval_ms` milliseconds after the previous file read began. Write result lines in original input order.
