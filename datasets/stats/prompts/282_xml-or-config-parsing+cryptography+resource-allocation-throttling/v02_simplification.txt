Write a Python program in one file named `fingerprint_batch.py`. It is run as:

    python fingerprint_batch.py <config.xml>

The program reads the XML file named by `<config.xml>`. The root element is `<config>` with integer attributes `max_workers` and `min_interval_ms`, and exactly one child `<salt>` whose text is a string. `max_workers` is positive. `min_interval_ms` is non-negative. Example:

    <config max_workers="3" min_interval_ms="200">
      <salt>pepper-2024</salt>
    </config>

1. Read newline-separated file paths from standard input until EOF. For each path, in input order, write one line to standard output: the path as given, a tab character, and either a fingerprint or `ERROR`. If the path cannot be opened and read as a regular file, write `ERROR` for that path.

2. For each readable path, compute a fingerprint deterministic from the file's raw bytes and the UTF-8 bytes of the `<salt>` text. The fingerprint is exactly 32 lowercase hexadecimal characters representing a 128-bit cryptographic digest computed over the salt bytes followed by the file bytes.

3. Process paths with at most `max_workers` file reads in progress at the same time. Do not start a file read while `max_workers` reads are already in progress. Across all reads, do not start a file read less than `min_interval_ms` milliseconds after the previous file read began. When a path remains and a read can start, start the next path as soon as the interval has elapsed and a worker is free. Write all result lines to standard output in the original input order.
