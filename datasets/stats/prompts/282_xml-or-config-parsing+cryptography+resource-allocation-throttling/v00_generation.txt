Write a Python program in a single file named `fingerprint_batch.py`. The program is invoked as:

    python fingerprint_batch.py <config.xml>

It reads the XML configuration file given by `<config.xml>`. The XML root element is `<config>` with integer attributes `max_workers` and `min_interval_ms`, and exactly one child element `<salt>` whose text is a string. Example:

    <config max_workers="3" min_interval_ms="200">
      <salt>pepper-2024</salt>
    </config>

The program reads newline-separated file paths from standard input until EOF. For each input path, in the same order as the input, it writes to standard output one line: the path, a tab character, and a 32-character lowercase hexadecimal fingerprint. The fingerprint must be deterministic and computed from the file's raw bytes and the UTF-8 bytes of the `<salt>` text. If a path cannot be read as a file, write the path, a tab, and `ERROR`.

The program must have no more than `max_workers` file reads in progress at any moment. When more than `max_workers` input paths remain, the program must keep exactly `max_workers` file reads in progress. The start times of consecutive file reads must be separated by at least `min_interval_ms` milliseconds, counting starts across all workers.
