Write a Python program in a single file named `fingerprint_batch.py`. The program is invoked as:

    python fingerprint_batch.py <config.xml>

It reads the XML configuration file given by `<config.xml>`. The XML root element is `<config>` with integer attributes `max_workers` and `min_interval_ms`, and exactly one child element `<salt>` whose text is a string. `max_workers` is positive and `min_interval_ms` is non-negative. Example:

    <config max_workers="3" min_interval_ms="200">
      <salt>pepper-2024</salt>
    </config>

1. Read newline-separated file paths from standard input until EOF. For each input path, in the same order as the input, write to standard output one line: the path as given, a tab character, and either a fingerprint or `ERROR`. If a path cannot be opened and read as a regular file, write `ERROR` for that path.

2. For each readable path, compute a fingerprint that is deterministic from the file's raw bytes and the UTF-8 bytes of the `<salt>` text. The fingerprint is the 32-character lowercase hexadecimal representation of a 128-bit cryptographic digest computed over the salt bytes followed by the file bytes. The same path bytes and salt bytes must always produce the same 32 characters.

3. Process the paths with up to `max_workers` file reads in progress at the same time. The program must not begin a file read while `max_workers` reads are already in progress. Counting all reads across all workers, the program must not begin a file read less than `min_interval_ms` milliseconds after the previous file read began. When paths remain and a read can begin, it must start the next path as soon as the interval has elapsed and a worker is free. Write all output lines to standard output in the original input order after processing.
