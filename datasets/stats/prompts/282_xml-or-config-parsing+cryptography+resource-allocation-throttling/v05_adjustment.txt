Write one Python file named `fingerprint_batch.py`. Run it as:

    python fingerprint_batch.py <config.xml>

1. Read the XML file whose path is the first command-line argument. The root element is `<config>` with attributes `max_workers`, `min_interval_ms`, and `salt`. `max_workers` and `min_interval_ms` are integers; `salt` is a string. `max_workers` is positive. `min_interval_ms` is non-negative. Example:

    <config max_workers="3" min_interval_ms="200" salt="pepper-2024"/>

2. Read newline-separated file paths from stdin until EOF. For each path, write to stdout one line: the path, one tab character, then either a 32-character lowercase hexadecimal fingerprint or `ERROR`. Write `ERROR` for that path if it does not identify a regular file or if reading its bytes fails. For a readable path, the fingerprint is the lowercase hexadecimal encoding of a cryptographic digest of the UTF-8 bytes of `salt` followed by the file's raw bytes, and the encoding has exactly 32 characters. Output lines may be written in any order.

3. While processing paths, at most `max_workers` file reads may be in progress at once. No file read may start less than `min_interval_ms` milliseconds after the previous file read started.
