Write one Python file named `fingerprint_batch.py`. Run it as:

    python fingerprint_batch.py <config.xml>

1. Parse the XML file whose path is the first command-line argument. The root is `<config>` with integer attributes `max_workers`, `min_interval_ms`, and `salt`. Example:

    <config max_workers="3" min_interval_ms="200" salt="pepper-2024"/>

   `max_workers` is positive. `min_interval_ms` is non-negative.

2. Read newline-separated file paths from stdin until EOF. For each path, write to stdout one line: the path, one tab character, then either a 32-character lowercase hexadecimal fingerprint or `ERROR`. Write `ERROR` if the path cannot be read as a regular file. For a readable path, the fingerprint is computed from a cryptographic digest over the UTF-8 bytes of `salt` followed by the file's raw bytes. Output lines may be written in any order.

3. While processing paths, at most `max_workers` file reads may be in progress at once. No file read may start less than `min_interval_ms` milliseconds after the previous file read started.
