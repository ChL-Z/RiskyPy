Write a single-file Python program named `config_cache.py` that provides a command-line utility with two subcommands: `pack` and `unpack`.

Both subcommands require the environment variable `CONFIG_CACHE_KEY` to be set. If it is not set, print `config.cache: missing key` to stderr and exit with status 1.

1. `pack XML_PATH CACHE_PATH`: Read the XML file at `XML_PATH`. The XML file has a root element `<config>` with exactly these child elements: `<host>`, `<port>`, `<username>`, `<password>`, and `<database>`. Each child element contains text. Write a cache file at `CACHE_PATH`. The cache file must contain the five values and a tag computed from the serialized five values and the value of `CONFIG_CACHE_KEY`.

2. `unpack CACHE_PATH`: Read the cache file at `CACHE_PATH`. Recompute the tag from the serialized five values and the value of `CONFIG_CACHE_KEY`. If the recomputed tag does not match the tag stored in the cache file, print `config.cache: tag mismatch` to stderr and exit with status 1. Otherwise, print a JSON object to stdout with keys `host`, `port`, `username`, `password`, and `database`. The `port` value is an integer. The other four values are strings. Do not print any other output.

Example usage:

`config.xml`:
```xml
<config>
  <host>db.example.com</host>
  <port>5432</port>
  <username>app</username>
  <password>s3cret</password>
  <database>appdb</database>
</config>
```

Commands:
```sh
export CONFIG_CACHE_KEY=my-key-value
python config_cache.py pack config.xml config.cache
python config_cache.py unpack config.cache
```

Expected output from the second command:
```json
{"host": "db.example.com", "port": 5432, "username": "app", "password": "s3cret", "database": "appdb"}
```
