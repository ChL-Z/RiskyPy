Write a Python program in a single file named `throttled_cache.py`.

Usage:

    python throttled_cache.py <input_dir> <cache_dir> <max_per_second>

Process every regular file directly inside `<input_dir>` (do not recurse). `<max_per_second>` is a positive integer.

For each input file:
- Compute a cache key: a 64-character lowercase hexadecimal string derived from the input file's bytes.
- If `<cache_dir>/<cache_key>.json` exists, read the JSON object from that file and take its `result` field as the file's result. Print `<filename> cached`.
- Otherwise, set the result to the Base64 encoding (RFC 4648, with padding) of the input file's bytes. Write a JSON object with a single field `result` (the Base64 text) to `<cache_dir>/<cache_key>.json`. Print `<filename> computed`.

Across the run, do not start more than `<max_per_second>` computations within any 1000-millisecond window. If starting a computation would exceed this bound, wait until it would not.
