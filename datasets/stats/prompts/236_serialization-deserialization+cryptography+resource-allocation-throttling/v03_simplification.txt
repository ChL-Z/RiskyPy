Write a Python program in a single file named `throttled_cache.py`.

Usage:

    python throttled_cache.py <input_dir> <cache_dir> <max_per_second>

`<input_dir>` and `<cache_dir>` are existing directories. `<max_per_second>` is a positive integer. Process each regular file directly inside `<input_dir>` in ascending lexicographic order of its filename; do not process files in subdirectories.

For each file:
- Compute a cache key: a 64-character lowercase hexadecimal string derived from the file's bytes.
- If `<cache_dir>/<cache_key>.json` exists, read the JSON object from that file and take its `result` field as the file's result. Print `<filename> cached`.
- Otherwise, set the result to the file's size in bytes. Write a JSON object with one field `result` (an integer) to `<cache_dir>/<cache_key>.json`. Print `<filename> computed`.

Assume any existing cache file contains a JSON object with an integer `result` field.

A computation is the work done when the cache file is missing. Before starting each computation, if less than `1 / <max_per_second>` seconds have passed since the start of the previous computation, wait until that much time has passed. Cache hits are not delayed.
