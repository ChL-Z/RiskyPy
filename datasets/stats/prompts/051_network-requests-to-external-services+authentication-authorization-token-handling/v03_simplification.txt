Write a Python program in a single file named `invoice_summary.py`.

Read a date in `YYYY-MM-DD` format from the first command-line argument. Read an API token from the environment variable `INVOICE_API_TOKEN`. If the token is missing or empty, print `missing token` to stderr and exit with status 2.

Send an HTTP GET request to `https://api.example.com/v1/invoices?date=<date>` with the header `Authorization: Bearer <token>`. If the response status is 401, print `unauthorized` to stderr and exit with status 3. If the response status is not 200, print the status code as a decimal integer to stderr and exit with status 4.

The response body is JSON with an `invoices` list. Each invoice has an integer `id` and a `line_items` list. Each line item has an integer `amount_cents` and an integer `quantity`.

Print to stdout a header line `id,total_cents`. Then print one line for each invoice in the order returned by the API. On each line, print the invoice `id` and its `total_cents`, separated by a comma. `total_cents` is the sum of `amount_cents * quantity` across that invoice's `line_items`.

Usage example:
```
python invoice_summary.py 2024-06-01
```
