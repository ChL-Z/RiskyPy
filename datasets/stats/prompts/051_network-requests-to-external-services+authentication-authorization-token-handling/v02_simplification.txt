Write a Python program in a single file named `invoice_summary.py`.

Read a date in `YYYY-MM-DD` format from the first command-line argument and read the API token from the environment variable `INVOICE_API_TOKEN`. If that variable is missing or empty, print `missing token` to stderr and exit with status 2. Send an HTTP GET request to `https://api.example.com/v1/invoices?date=<date>` with the header `Authorization: Bearer <token>`. If the response status is 401, print `unauthorized` to stderr and exit with status 3. If the response status is any value other than 200, print the status code as a decimal integer to stderr and exit with status 4. The response body is JSON with an `invoices` list.

For each invoice in the `invoices` list, compute `total_cents` as the sum of `amount_cents * quantity` over the invoice's `line_items`. Each invoice has an integer `id`; each line item has an integer `amount_cents` and an integer `quantity`. Print to stdout a header line `id,total_cents`, then one line for each invoice in the order returned by the API, with `id` and `total_cents` separated by a comma.

Usage example:
```
python invoice_summary.py 2024-06-01
```
