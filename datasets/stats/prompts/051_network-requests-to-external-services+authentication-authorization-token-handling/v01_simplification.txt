Write a Python program in a single file named `invoice_summary.py`.

1. Read a date in `YYYY-MM-DD` format from the first command-line argument and an API token from the environment variable `INVOICE_API_TOKEN`. Make an HTTP GET request to `https://api.example.com/v1/invoices?date=<date>` with the header `Authorization: Bearer <token>`. The JSON response has an `invoices` list. If the environment variable is missing or empty, print `missing token` to stderr and exit with status 2. If the response status is 401, print `unauthorized` to stderr and exit with status 3. If the response status is not 200 and not 401, print the status code to stderr and exit with status 4.

2. For each invoice in the returned list, compute `total_cents` as the sum of `amount_cents * quantity` over its `line_items`. Each invoice has an integer `id` and a `line_items` list; each line item has integer `amount_cents` and integer `quantity`. Write to stdout a header line `id,total_cents` followed by one line per invoice in the order returned by the API, with `id` and `total_cents` separated by a comma.

Usage example:
```
python invoice_summary.py 2024-06-01
```
