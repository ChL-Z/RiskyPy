Write a Python program in a single file named `invoice_summary.py`. It must perform the following:

1. Read a date in `YYYY-MM-DD` format from the first command-line argument and an API token from the environment variable `INVOICE_API_TOKEN`. Make HTTP GET requests to `https://api.example.com/v1/invoices?date=<date>&page=<page_number>`, starting with page 1, and include the header `Authorization: Bearer <token>`. Each JSON response has an `invoices` list and a `next_page` value that is either an integer or null. Continue requesting pages until `next_page` is null. If the environment variable is missing or empty, print `missing token` to stderr and exit with status 2. If a response status is 401, print `unauthorized` to stderr and exit with status 3. If a response status is not 200 and not 401, print the status code to stderr and exit with status 4.

2. For each invoice across all pages, compute `total_cents` as the sum of `amount_cents * quantity` over its `line_items`. Each invoice has `id` (integer) and `line_items` (list); each line item has `amount_cents` (integer) and `quantity` (integer). Write to stdout a header line `id,total_cents` followed by one line for each invoice in the order returned by the API, with the invoice `id` and computed `total_cents` separated by a comma.

Usage example:
```
python invoice_summary.py 2024-06-01
```
