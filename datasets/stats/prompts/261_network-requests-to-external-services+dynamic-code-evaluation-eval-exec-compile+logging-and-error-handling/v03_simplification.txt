Write one Python file named `probe.py`. It reads one JSON object from stdin with three keys: `template`, `expression`, and `log_path`. `expression` is a string arithmetic expression using decimal integers, spaces, parentheses, and the operators `+`, `-`, `*`. Evaluate it to an integer. Replace every occurrence of `{{expr}}` in `template` with the decimal text of that integer. Send an HTTP GET request to the resulting URL and read the response body as UTF-8 text.

Append one line to the file at `log_path`. If evaluating the expression succeeds and the GET request returns an HTTP status code, append:
`<UTC timestamp in YYYY-MM-DDTHH:MM:SSZ> INFO <final_url> <status code>`
and write the response body to stdout. If evaluating the expression fails or the GET request fails, append:
`<UTC timestamp in YYYY-MM-DDTHH:MM:SSZ> ERROR <expression> <error message>`
and write nothing to stdout.

Create the log file if it does not exist. Separate fields in each log line with one space. Exit with code 0 after a successful expression evaluation and a GET request that returns an HTTP status code. Exit with code 1 otherwise. Write nothing else to stdout.
