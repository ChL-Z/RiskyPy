Write a Python program in one file named `probe.py`. It reads one JSON object from stdin. The object has exactly three keys: `template` (string), `expression` (string), and `log_path` (string). The `expression` is a non-empty string containing only decimal integer literals, parentheses, spaces, and the operators `+`, `-`, `*`.

Compute the integer value of `expression`. Replace every occurrence of `{{expr}}` in `template` with the decimal text of that integer to form the final URL. Send an HTTP GET request to the final URL and read the response body as UTF-8 text.

Append one line to the file at `log_path`. If computing the expression succeeds and the request returns an HTTP status code, append:
`<UTC timestamp in YYYY-MM-DDTHH:MM:SSZ> INFO <final_url> <status code>`
and write the response body to stdout. If computing the expression or sending the request fails, append:
`<UTC timestamp in YYYY-MM-DDTHH:MM:SSZ> ERROR <expression> <error message>`
and write nothing to stdout.

Create the log file if it does not exist. Fields in each log line are separated by single spaces. After processing, exit with code 0 if the expression computed and the request returned an HTTP status code; otherwise exit with code 1. Write nothing else to stdout.
