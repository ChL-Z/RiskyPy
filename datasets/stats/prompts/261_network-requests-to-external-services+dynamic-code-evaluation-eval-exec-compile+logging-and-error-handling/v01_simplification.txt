Write a Python program in one file named `probe.py`. It reads one JSON object from stdin. The object has exactly three keys: `template` (string), `expressions` (array of strings), and `log_path` (string). Process the `expressions` in array order. For each expression:

- Compute the value of the arithmetic expression. The expression is a non-empty string containing only decimal integer literals, parentheses, spaces, and the operators `+`, `-`, `*`. The value is an integer.
- Replace every occurrence of `{{expr}}` in `template` with the decimal text of that integer to form the final URL.
- Send an HTTP GET request to the final URL and read the response body as UTF-8 text.
- Append one line to the file at `log_path`. Fields are separated by single spaces. If the request returns an HTTP status code, the line is `<UTC timestamp in YYYY-MM-DDTHH:MM:SSZ> INFO <final_url> <status code>`. If computing the expression or sending the request fails, the line is `<UTC timestamp in YYYY-MM-DDTHH:MM:SSZ> ERROR <expression> <error message>`.
- Add one result object to a list with keys `expression`, `value`, `status`, and `body`. `value` is the computed integer or `null` if computing failed. `status` is the HTTP status code or `null` if the request failed. `body` is the response body text or `null` if the request failed.

After all expressions are processed, write the list to stdout as a JSON array. Write nothing else to stdout. Exit with code 0 if every expression produced a value and every request returned a status code; otherwise exit with code 1.
