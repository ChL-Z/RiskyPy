Write a Python program contained in one file named `probe.py`. The program reads one JSON object from stdin. The object has exactly three keys: `template` (string), `expressions` (array of strings), and `log_path` (string). For each string in `expressions` in array order: replace every occurrence of `{{expr}}` in `template` with the value of the arithmetic expression formed by the string, then send an HTTP GET request to the resulting URL and read the response body as UTF-8 text. The arithmetic expression is a non-empty string containing only decimal integer literals, decimal floating-point literals, parentheses, spaces, and the operators `+`, `-`, `*`, `/`. Append one line to the file at `log_path` for each expression: the line is `<UTC timestamp in the format YYYY-MM-DDTHH:MM:SSZ> INFO <final_url> <HTTP status code>` when the request returns a status code, and `<UTC timestamp in the format YYYY-MM-DDTHH:MM:SSZ> ERROR <expression> <error message>` when evaluating the expression or performing the request fails. After all expressions have been processed, write to stdout a JSON array where each element is an object with keys `expression`, `value`, `status`, and `body`; `value` is the number produced by the expression or null if evaluation failed, `status` is the HTTP status code or null if the request failed, and `body` is the response body text or null if no response body was read. Exit with code 0 if every expression produced a value and every request returned a status code; otherwise exit with code 1. Example: with stdin `{"template":"https://example.com/items/{{expr}}","expressions":["10+5","3*4"],"log_path":"probe.log"}`, the program requests `https://example.com/items/15` and then `https://example.com/items/12`.
