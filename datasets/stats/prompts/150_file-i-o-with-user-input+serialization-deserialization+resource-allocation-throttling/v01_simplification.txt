Write a Python program in a single file named `stats.py`.

Read newline-separated file paths from standard input until end of input. For each path, print one line to standard output in the same order: the path, a tab, the file's byte size, a tab, and its line count. Byte size is the number of bytes in the file. Line count is the number of `\n` bytes in the file, plus 1 when the file is non-empty and its last byte is not `\n`. If a path cannot be opened for reading and is not found in the cache, print the path, a tab, and `ERROR`, then continue.

The program keeps a cache file named `.stats_cache` in the current working directory. If this file exists at startup, load the stored entries. Each entry maps an absolute file path to its byte size and line count. When a path's absolute form is in the cache, print the cached byte size and line count without opening that file. After all input paths have been handled, write the loaded entries together with the newly computed entries back to `.stats_cache`.

Process the input paths in groups of up to 4. For each group, open at most the files in that group for reading, compute their results, close them, then continue with the next group. Never have more than 4 files open for reading at any moment.
