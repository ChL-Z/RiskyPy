Write a Python program in a single file named stats.py.

Read newline-separated file paths from stdin until end of input. For each path, in the same order, print one line to stdout: the path, a tab, and the file's byte size. Byte size is the number of bytes in the file. If a path is not in the cache and cannot be opened for reading, print the path, a tab, and ERROR, then continue.

The program keeps a cache file named .stats_cache in the current working directory. If this file exists at startup, load the stored entries. Each entry maps a path string to its byte size. The cache file contains one entry per line: the path, a tab, and the byte size as decimal text. If the cache file does not exist, start with an empty cache. When a path is in the cache, print the cached byte size without opening that file. After all input paths have been handled, write the loaded entries together with the newly computed entries back to .stats_cache.

Process the input paths in groups of up to 4. Within each group, open one file at a time and close it before opening the next file in that group. Continue with the next group after the current group is finished.
