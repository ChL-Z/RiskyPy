Write a Python program in a single file named `stats.py`.

The program reads newline-separated file paths from standard input until end of input. For each path it reports the file's byte size and its line count. A file's line count is the number of `\n` bytes it contains, plus one when the file is non-empty and its last byte is not `\n`. A file's byte size is the number of bytes in the file. For each path, print one line to standard output, in the same order the paths were read: the path, a tab, the byte size, a tab, the line count. If a path cannot be opened for reading, print the path, a tab, and `ERROR` instead, then continue with the remaining paths.

The program keeps a cache file named `.stats_cache` in the current working directory. Before handling any path, if `.stats_cache` exists, the program loads the previously stored entries: each entry maps an absolute file path to its byte size, its line count, and the file's last modification time. When a path's absolute form is present in the cache and the file's current last modification time equals the cached one, the cached byte size and line count are printed without opening the file. After all paths have been handled, the program writes the updated set of entries back to `.stats_cache`, so a later run reuses them.

No more than 4 files may be open for reading at any moment. Use one worker per file that is currently being processed, so that up to 4 paths are handled at the same time.

Example: given a file `notes.txt` of 1200 bytes that ends with a newline and contains 30 `\n` bytes, and given stdin
```
notes.txt
missing.txt
```
the program prints
```
notes.txt	1200	30
missing.txt	ERROR
```
