Write a Python program in a single file named `stats.py`.

1. Read newline-separated file paths from standard input until end of input. For each path, in the same order, print one line to standard output: the path, a tab, the file's byte size, a tab, and its line count. Byte size is the number of bytes in the file. Line count is the number of `\n` bytes in the file, plus 1 when the file is non-empty and its last byte is not `\n`. If a path is not in the cache and cannot be opened for reading, print the path, a tab, and `ERROR`, then continue.

2. The program keeps a cache file named `.stats_cache` in the current working directory. If this file exists at startup, load the stored entries. Each entry maps a path string to its byte size and line count. If the cache file does not exist, start with an empty cache. When a path is in the cache, print the cached byte size and line count without opening that file. After all input paths have been handled, write the loaded entries together with the newly computed entries back to `.stats_cache`.

3. Process the input paths in groups of up to 4. Within each group, open one file at a time and close it before opening the next file in that group. Continue with the next group after the current group is finished.
