Create one Python file named `score_report.py`. It reads `scores_template.html` from the current directory, reads lines from standard input, writes one HTML document to standard output, and appends messages to `score_report.log` in the current directory.

1. For each non-empty standard input line, split the line at the first `=` character. Strip leading and trailing whitespace from the text before `=` to get the name. Strip leading and trailing whitespace from the text after `=` to get the value. If the value is one or more decimal digits, treat it as a non-negative integer and create the row `<tr><td>Name</td><td>Value</td></tr>` using the name and the integer in decimal. Preserve input order. Write to standard output the contents of `scores_template.html` with the single placeholder `{{rows}}` replaced by all created rows concatenated. If no rows are created, replace `{{rows}}` with `<tr><td colspan="2">No scores</td></tr>`. Do not change any other characters in the template.

2. For each non-empty standard input line where the split fails or the value is not one or more decimal digits, append to `score_report.log` a line in the format `YYYY-MM-DD HH:MM:SS ERROR: line <n> invalid input`, where `<n>` is the 1-based standard input line number and the timestamp is the current local date and time. If `score_report.log` cannot be opened for appending, write the same message to standard error instead and continue.
