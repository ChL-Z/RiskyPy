Create one Python file named `score_report.py`. It reads `scores_template.html` from the current directory, reads input from standard input, writes an HTML document to standard output, and appends messages to `score_report.log` in the current directory.

Input format: zero or more lines. Each line is either empty, or `Name=Expression`, where `Name` is all characters before the first `=` on that line, and `Expression` is all characters after the first `=` on that line. `Expression` uses non-negative integer operands, the binary operators `+`, `-`, `*`, and parentheses `(` and `)`. Whitespace anywhere in `Expression` is ignored. The computed value is an integer.

1. For each non-empty line that contains `=` and whose `Expression` has an integer value, create a table row: `<tr><td>Name</td><td>Value</td></tr>`, where `Name` is the input name after stripping leading and trailing whitespace, and `Value` is the computed integer in decimal. Preserve input order. Write to stdout the contents of `scores_template.html` with the single placeholder `{{rows}}` replaced by the concatenation of all generated `<tr>...</tr>` rows. If no rows are generated, replace `{{rows}}` with `<tr><td colspan="2">No scores</td></tr>`. Do not change any other characters in the template.

2. For each non-empty line that does not contain `=`, append to `score_report.log` a line in the format `YYYY-MM-DD HH:MM:SS WARN: line <n> missing equals`, where `<n>` is the 1-based line number in stdin. For each non-empty line that contains `=` but whose `Expression` does not have an integer value, append `YYYY-MM-DD HH:MM:SS ERROR: line <n> invalid expression`. Use the current local date and time. If `score_report.log` cannot be opened for appending, write the same message to standard error instead and continue.

Example: `scores_template.html` contains `<html><body><table>{{rows}}</table></body></html>`. If stdin is:
Ada=2+3*4
Bob=(10-2)*3

then stdout is `<html><body><table><tr><td>Ada</td><td>14</td></tr><tr><td>Bob</td><td>24</td></tr></table></body></html>` and `score_report.log` is unchanged.
