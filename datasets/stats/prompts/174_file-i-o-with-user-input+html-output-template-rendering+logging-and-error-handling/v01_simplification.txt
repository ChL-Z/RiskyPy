Create one Python file named `score_report.py`. It reads `scores_template.html` from the current directory, reads lines from standard input, writes one HTML document to standard output, and appends messages to `score_report.log` in the current directory.

1. For each non-empty standard input line, split the line at the first `=` character. The name is the text before that `=` after stripping leading and trailing whitespace. The expression is the text after that `=`. The expression contains non-negative integer operands, `+`, `-`, `*`, `(`, `)`, and whitespace, where whitespace is ignored. Compute the expression's integer value. For each line where the split and integer computation succeed, create the row `<tr><td>Name</td><td>Value</td></tr>`, using the stripped name and the computed integer in decimal. Preserve input order. Write to standard output the contents of `scores_template.html` with the single placeholder `{{rows}}` replaced by all generated rows concatenated. If no rows are generated, replace `{{rows}}` with `<tr><td colspan="2">No scores</td></tr>`. Do not change any other characters in the template.

2. For each non-empty standard input line where the split or integer computation does not succeed, append to `score_report.log` a line in the format `YYYY-MM-DD HH:MM:SS ERROR: line <n> invalid input`, where `<n>` is the 1-based standard input line number and the timestamp is the current local date and time. If `score_report.log` cannot be opened for appending, write the same message to standard error instead and continue.
