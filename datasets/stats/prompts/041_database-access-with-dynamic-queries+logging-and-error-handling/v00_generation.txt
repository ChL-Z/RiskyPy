Write a Python program in a single file named `query_rows.py`. It provides a command-line entry point with exactly these five options, each required and each taking one argument: `--db PATH`, `--table NAME`, `--column NAME`, `--value TEXT`, `--log PATH`. The program reads an SQLite database file at PATH, selects all rows from table NAME where the column NAME equals VALUE according to SQLite equality comparison, and writes the result to stdout. For each matching row, write one JSON object on its own line. The object keys are the table's column names in the order they appear in the table definition. SQL NULL becomes JSON null, integer and real values become JSON numbers, text becomes JSON strings, and blob values become lowercase hexadecimal JSON strings. If no rows match, write nothing to stdout.

For every invocation, append one JSON object line to the file at --log PATH, creating the file if it does not exist. The object must contain keys `timestamp`, `table`, `column`, `value`, `row_count`, and `status`. `timestamp` is the current UTC time in ISO 8601 format ending with `Z`. `row_count` is the number of rows written to stdout. `status` is `"ok"` when the query completes, or `"error"` when the database file cannot be opened, the table or column is absent, or the query raises an exception.

If the database file cannot be opened, the table or column is absent, or the query raises an exception, write `ERROR: {message}` to stderr, where `{message}` is the exception text, append a log line with `row_count` set to 0 and `status` set to `"error"`, and exit with code 1. When the query completes, exit with code 0.

Example invocation:
`python query_rows.py --db sales.db --table products --column category --value tools --log queries.log`

If `products` contains columns `id`, `name`, `category`, `price` and two matching rows, stdout is:
`{"id": 1, "name": "Hammer", "category": "tools", "price": 12.5}`
`{"id": 2, "name": "Wrench", "category": "tools", "price": 8.0}`

The appended log line is a single JSON object with the six keys described above.
