Write a Python program in a single file named `query_rows.py`. It takes exactly these five required command-line arguments, each followed by one value: `--db PATH`, `--table NAME`, `--column NAME`, `--value TEXT`, and `--log PATH`. The program queries the SQLite database file at `--db` to select all rows from the table named by `--table` where the column named by `--column` equals the text given by `--value`. For each matching row, print the row's values separated by tabs, one row per line. If no rows match, print nothing to stdout.

For every run, append one line to the file at `--log`, creating the file if it does not exist. The log line must be exactly: `<timestamp> <status> <row_count>`. `timestamp` is the current UTC time in ISO 8601 format ending with `Z`. `status` is `ok` when the query completes, or `error` when the database file cannot be opened, the table or column is missing, or the query raises an exception. `row_count` is the number of printed rows.

If the database file cannot be opened, the table or column is missing, or the query raises an exception, write `ERROR: <message>` to stderr, where `<message>` is the exception text. Append a log line with `row_count` set to `0` and `status` set to `error`. Exit with code `1`. When the query completes, exit with code `0`.
