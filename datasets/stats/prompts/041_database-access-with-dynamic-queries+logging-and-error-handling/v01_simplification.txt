Write a Python program in a single file named `query_rows.py`. The program takes exactly these five command-line arguments, each required and each followed by one value: `--db PATH`, `--table NAME`, `--column NAME`, `--value TEXT`, and `--log PATH`. It queries the SQLite database file at `--db`: select all rows from table `--table` where column `--column` equals `--value` using SQLite equality comparison. For each matching row, write one JSON object to stdout, one object per line. The JSON object keys are the table's column names. If no rows match, write nothing to stdout.

For every run, append one JSON line to the file at `--log`, creating the file if it does not exist. The JSON object must contain exactly these keys: `timestamp`, `table`, `column`, `value`, `row_count`, and `status`. `timestamp` is the current UTC time in ISO 8601 format ending with `Z`. `row_count` is the number of rows written to stdout. `status` is `"ok"` when the query completes, or `"error"` when the database file cannot be opened, the table or column is missing, or the query raises an exception.

If the database file cannot be opened, the table or column is missing, or the query raises an exception, write `ERROR: <message>` to stderr, where `<message>` is the exception text. Append a log line with `row_count` set to 0 and `status` set to `"error"`. Exit with code 1. When the query completes, exit with code 0.
