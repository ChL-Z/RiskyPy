Write a Python program in a single file named `dashboard.py`.

The program reads one line from standard input as a JSON object with keys `token` and `display_name`, removing a trailing newline character if present. The environment variable `ACCEPTED_SESSION_TOKEN` contains the accepted token string. The environment variable `SESSION_ROLE` contains a string to place into the page. The file `dashboard.html` is present in the current working directory and is a UTF-8 text file containing the placeholders `{{user}}`, `{{role}}`, and `{{admin_link}}`.

Requirement 1: If the `token` value is not exactly equal to the value of `ACCEPTED_SESSION_TOKEN`, print exactly `ACCESS DENIED` to standard output and exit with status code 1. Otherwise, continue.

Requirement 2: Read `dashboard.html`, replace every occurrence of `{{user}}` with the `display_name` value from the JSON object and every occurrence of `{{role}}` with `SESSION_ROLE`. Replace every occurrence of `{{admin_link}}` with exactly `<a href="/admin">Admin</a>` when `SESSION_ROLE` is exactly `admin`; otherwise replace every occurrence of `{{admin_link}}` with the empty string. Write the resulting text to standard output and exit with status code 0.
