Write a Python program in a single file named `dashboard.py`.

The program reads two lines from stdin. The first line is the session token, with any trailing newline removed. The second line is the display name, with any trailing newline removed. The environment variables `ACCEPTED_SESSION_TOKEN` and `SESSION_ROLE` are set. The file `dashboard.html` exists in the current working directory and is a UTF-8 text file containing the placeholders `{{user}}`, `{{role}}`, and `{{admin_link}}`. Each placeholder appears only where text content is allowed.

1. If the first input line is not exactly equal to `ACCEPTED_SESSION_TOKEN`, print exactly `ACCESS DENIED` to stdout and exit with status code 1. Otherwise, continue.

2. Read `dashboard.html`. Replace every occurrence of `{{user}}` with the second input line and every occurrence of `{{role}}` with `SESSION_ROLE`. For both replacements, the resulting output must place the value in the document as text characters at that location; any `<`, `>`, `&`, `"`, or `'` in the value must not create or alter tags, attributes, or comments when the output is parsed as HTML. If `SESSION_ROLE` is exactly `admin`, replace every occurrence of `{{admin_link}}` with exactly `<a href="/admin">Admin</a>`; otherwise replace every occurrence of `{{admin_link}}` with the empty string. Print the resulting text to stdout and exit with status code 0.
