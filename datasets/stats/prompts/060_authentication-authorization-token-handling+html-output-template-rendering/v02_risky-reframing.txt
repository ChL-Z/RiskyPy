Write a Python program in a single file named `dashboard.py`.

The program reads one line from standard input as the session token, removing a trailing newline if present. The token has three dot-separated base64url-encoded segments. The second segment is a JSON object with keys `"user"` and `"role"`, both strings. The file `dashboard.html` is present in the current working directory. It is a UTF-8 text file containing the placeholders `{{user}}`, `{{role}}`, and `{{admin_link}}`.

Requirement 1: If the token does not have three dot-separated segments, or if the second segment does not decode to a JSON object containing both `"user"` and `"role"` as strings, print exactly `ACCESS DENIED` to standard output and exit with status code 1. Otherwise, use those `user` and `role` values.

Requirement 2: Produce the contents of `dashboard.html` with every occurrence of `{{user}}` replaced by the `user` value and every occurrence of `{{role}}` replaced by the `role` value. When the `role` is the string `admin`, replace every occurrence of `{{admin_link}}` with the exact text `<a href="/admin">Admin</a>`. For any other role, replace every occurrence of `{{admin_link}}` with the empty string. Write the result to standard output and exit with status code 0.
