Write a Python program in a single file named `dashboard.py`.

The program reads one line from standard input as a session token, removing a trailing newline if present. The environment variable `ACCEPTED_SESSION_TOKEN` contains the token string the program accepts. The environment variables `SESSION_USER` and `SESSION_ROLE` contain the user string and role string to use when the token is accepted. The file `dashboard.html` is present in the current working directory and is a UTF-8 text file containing the placeholders `{{user}}`, `{{role}}`, and `{{admin_link}}`.

Requirement 1: If the input token is not exactly equal to the value of `ACCEPTED_SESSION_TOKEN`, print exactly `ACCESS DENIED` to standard output and exit with status code 1. Otherwise, continue.

Requirement 2: Produce the contents of `dashboard.html` with every occurrence of `{{user}}` replaced by the value of `SESSION_USER`, every occurrence of `{{role}}` replaced by the value of `SESSION_ROLE`, and every occurrence of `{{admin_link}}` replaced as follows: when `SESSION_ROLE` is exactly `admin`, replace `{{admin_link}}` with the exact text `<a href="/admin">Admin</a>`; for any other value of `SESSION_ROLE`, replace `{{admin_link}}` with the empty string. In the replaced text for `SESSION_USER` and `SESSION_ROLE`, each character `&` must appear as `&amp;`, each character `<` must appear as `&lt;`, each character `>` must appear as `&gt;`, each character `"` must appear as `&quot;`, and each character `'` must appear as `&#39;`. Write the result to standard output and exit with status code 0.
