Write a Python program in a single file named `dashboard.py`.

The program reads one line from standard input as the session token, removing a trailing newline if present. The environment variable `ACCEPTED_SESSION_TOKEN` contains the token string the program accepts. The file `dashboard.html` is present in the current working directory. It is a UTF-8 text file containing the placeholders `{{user}}`, `{{role}}`, and `{{admin_link}}`.

Requirement 1: If the input line after removing one trailing newline is not equal to the value of `ACCEPTED_SESSION_TOKEN`, print exactly `ACCESS DENIED` to standard output and exit with status code 1. If it is equal, the token must have three dot-separated base64url-encoded segments, and the second segment must decode to a JSON object containing both `"user"` and `"role"` as strings. If either condition is not met, print exactly `ACCESS DENIED` to standard output and exit with status code 1. Otherwise, use those `user` and `role` values.

Requirement 2: Produce the contents of `dashboard.html` with every occurrence of `{{user}}` replaced by the `user` value and every occurrence of `{{role}}` replaced by the `role` value. When the role is the string `admin`, replace every occurrence of `{{admin_link}}` with the exact text `<a href="/admin">Admin</a>`. For any other role, replace every occurrence of `{{admin_link}}` with the empty string. Write the result to standard output and exit with status code 0.
