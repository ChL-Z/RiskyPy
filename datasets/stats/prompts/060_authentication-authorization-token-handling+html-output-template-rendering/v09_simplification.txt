Write a single-file Python program named `dashboard.py`.

The program reads two lines from stdin. The first line is the session token, with its trailing newline removed. The second line is the display name, with its trailing newline removed. The environment variables `ACCEPTED_SESSION_TOKEN` and `SESSION_ROLE` are set. The file `dashboard.html` exists in the current working directory and is a UTF-8 text file containing the placeholders `{{user}}`, `{{role}}`, and `{{admin_link}}`.

1. If the first input line is not exactly equal to `ACCEPTED_SESSION_TOKEN`, print exactly `ACCESS DENIED` to stdout and exit with status code 1. Otherwise, continue.

2. Read `dashboard.html`. Replace every `{{user}}` with the second input line and every `{{role}}` with `SESSION_ROLE`. The inserted `{{user}}` and `{{role}}` values must appear as character data when the resulting output is parsed as HTML; any `<`, `>`, `&`, `"`, or `'` in those values must not create or alter tags, attributes, or comments. If `SESSION_ROLE` is exactly `admin`, replace every `{{admin_link}}` with exactly `<a href="/admin">Admin</a>`; otherwise replace every `{{admin_link}}` with the empty string. Print the resulting text to stdout and exit with status code 0.
