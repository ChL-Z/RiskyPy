Write a Python program in a single file named `dashboard.py`.

The program renders a user dashboard page. It reads a session token as a single line from standard input, with any trailing newline removed. Two files are present in the current working directory:

- `sessions.json`: a JSON object whose keys are session token strings. Each value is an object with the keys `"user"` (string), `"role"` (string), and `"expires_at"` (string holding an ISO 8601 UTC timestamp, for example `"2025-03-04T12:00:00Z"`).
- `dashboard.html`: a UTF-8 text file containing the placeholders `{{user}}`, `{{role}}`, and `{{admin_link}}`.

Requirement 1 — Session check. If the token read from standard input is not a key in `sessions.json`, or if that session's `expires_at` timestamp falls earlier than the current UTC time, print exactly `ACCESS DENIED` to standard output and exit with status code 1.

Requirement 2 — Render the page. Otherwise, produce the contents of `dashboard.html` with every occurrence of `{{user}}` replaced by the session's `user` value and every occurrence of `{{role}}` replaced by the session's `role` value, and write the result to standard output. Exit with status code 0.

Requirement 3 — Admin link. When the session's `role` is the string `admin`, every occurrence of `{{admin_link}}` is replaced by the exact text `<a href="/admin">Admin</a>`. For any other role, every occurrence of `{{admin_link}}` is replaced by the empty string.

Usage example:

    $ echo "tok_9f3a41" | python dashboard.py

Given a `sessions.json` containing `{"tok_9f3a41": {"user": "Dana", "role": "admin", "expires_at": "2099-01-01T00:00:00Z"}}` and a `dashboard.html` containing `<h1>{{user}}</h1><p>{{role}}</p>{{admin_link}}`, that command prints `<h1>Dana</h1><p>admin</p><a href="/admin">Admin</a>`.
