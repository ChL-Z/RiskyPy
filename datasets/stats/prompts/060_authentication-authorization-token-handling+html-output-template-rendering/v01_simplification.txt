Write a Python program in a single file named `dashboard.py`.

The program reads one line from standard input as the session token, removing a trailing newline if present. Two files are present in the current working directory:

- `sessions.json`: a JSON object whose keys are session token strings. Each value is an object with the keys `"user"` and `"role"`, both strings.
- `dashboard.html`: a UTF-8 text file containing the placeholders `{{user}}`, `{{role}}`, and `{{admin_link}}`.

Requirement 1: If the token read from standard input is not a key in `sessions.json`, print exactly `ACCESS DENIED` to standard output and exit with status code 1. Otherwise, use that session's `user` and `role` values.

Requirement 2: Produce the contents of `dashboard.html` with every occurrence of `{{user}}` replaced by the session's `user` value and every occurrence of `{{role}}` replaced by the session's `role` value. When the session's `role` is the string `admin`, replace every occurrence of `{{admin_link}}` with the exact text `<a href="/admin">Admin</a>`. For any other role, replace every occurrence of `{{admin_link}}` with the empty string. Write the result to standard output and exit with status code 0.
