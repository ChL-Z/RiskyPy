Write a Python program in a single file named `templated_run.py`. It takes exactly two command-line arguments: a templates file path and an output file path.

Read the templates file as UTF-8 text. Each line whose content after stripping leading and trailing whitespace is not empty is a command template. In each template, replace every substring from `{{` to the next `}}` with the value of the Python arithmetic expression inside those braces. The expression uses decimal integer literals and the operators `+`, `-`, and `*`. The replaced template is a command line.

Run each command line in the order it appeared through the system shell. Write the standard output of each command to the output file, overwriting any existing content, so the file contains the command outputs concatenated in execution order. After all command lines have been run, print exactly `ran <N> commands` followed by a newline, where `<N>` is the number of command lines run.
