Write a Python program in a single file named `templated_run.py`.

The program takes exactly two command-line arguments: a templates file path and an output file path. Read the templates file as UTF-8 text and split it into lines. Skip any line whose text after removing leading and trailing whitespace is empty. Every remaining line is a command template.

In each command template, every substring from `{{` to the next `}}` is a placeholder. The placeholder text is an integer arithmetic expression using decimal integer literals, `+`, `-`, `*`, `/`, and parentheses. Replace each placeholder with the decimal value of that expression; `/` is integer division that truncates toward zero. The result is a command line.

Run each resulting command line through the system shell, in the order the templates appeared. Write each command's standard output to the output file, creating the file if it does not exist and replacing it if it does. The output file contains the standard outputs concatenated in execution order. After all commands have run, print exactly `ran <N> commands` followed by a newline, where `<N>` is the number of command lines that were run.
