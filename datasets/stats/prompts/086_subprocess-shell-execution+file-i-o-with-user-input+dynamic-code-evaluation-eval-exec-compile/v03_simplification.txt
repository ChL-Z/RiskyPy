Write a Python program in a single file named `templated_run.py`. The first command-line argument is a path to a templates file. Read that file as UTF-8 text. Each line whose content after stripping leading and trailing whitespace is not empty is a command template. In each template, replace every substring from `{{` to the next `}}` with the result of evaluating the arithmetic expression inside those braces. The expression contains decimal integer literals and the operators `+`, `-`, and `*`. Treat the resulting string as a command line. For each command line in the order it appears, run it through the system shell, capture its standard output, and print that captured output to standard output. Print only the captured standard output.
