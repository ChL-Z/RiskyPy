Write a Python program contained in a single file named `templated_run.py`.

The program takes exactly two command-line arguments: the path of a templates file and the path of an output file. It reads the templates file as UTF-8 text and splits it into lines. A line is skipped when, after removing leading and trailing whitespace, it is empty or begins with `#`. Every other line is a command template.

Within a command template, every substring that starts with `{{` and ends at the next `}}` is a placeholder. The text between the braces is an integer arithmetic expression built from decimal integer literals, parentheses, and the operators `+`, `-`, `*`, and `/`. Evaluate that expression to an integer, where `/` is integer division that truncates toward zero. Replace each placeholder in the template with the decimal representation of its evaluated value, with no surrounding whitespace, producing the command line.

The program then executes each produced command line, in the order the templates appeared, and writes each command's standard output to the output file. The output file is created if it does not exist and replaced if it does. Its contents are the standard outputs concatenated in execution order, with no text added between them. A command whose exit status is nonzero still has its standard output written and is counted separately.

After all commands have been executed, print to stdout one line in this exact format, followed by a newline:

`ran <N> commands, <M> failed`

where `<N>` is the number of command lines that were executed and `<M>` is how many of those had a nonzero exit status.

Example. With `templates.txt` containing:

```
# two echoes
echo start {{10 / 3}}
echo total {{(2 + 4) * 7}}
```

running `python templated_run.py templates.txt out.txt` makes `out.txt` contain the line `start 3` followed by the line `total 42`, each ending with a newline, and prints:

`ran 2 commands, 0 failed`
