Write a Python program in a single file named `dispatch.py`. It reads queued jobs from a SQLite database, starts selected jobs at a limited rate, and writes one JSON receipt file per started job. Starting a job means setting that row's `status` column to `running` in the database and writing its receipt file.

The database file passed with `--db` contains a table created like this:

```sql
CREATE TABLE jobs (
  id INTEGER PRIMARY KEY,
  name TEXT NOT NULL,
  priority INTEGER NOT NULL,
  status TEXT NOT NULL,
  payload TEXT NOT NULL
);
```

The program is invoked as:

```
python dispatch.py --db jobs.db --key secret.key --outdir receipts --rate 2 --limit 5 --status pending --min-priority 3
```

Requirements:

1. Selection and starting. `--status` and `--min-priority` are optional. A row is selected when it matches every supplied option: `status` equals `--status` if that option is given; `priority` is greater than or equal to `--min-priority` if that option is given. When neither option is given, all rows are selected. Start at most `--limit` selected rows in descending `priority` order, breaking ties by ascending `id`. For each started row, set its `status` to `running` in the database and write `<outdir>/<id>.json`.

2. Rate. `--rate` is an integer number of rows per second. No more than `--rate` rows may be started within any 1.0-second interval. Start the first selected row immediately. Before each later start, if the previous 1.0 seconds already contain `--rate` starts, wait until they do not.

3. Receipts and verification. Each receipt file is a JSON object with keys `id`, `name`, `priority`, `status`, `payload`, and `tag`. `status` is `running`. `tag` is a lowercase hexadecimal string derived from those five field values together with the bytes of the key file named by `--key`. The same file must define `verify_receipt(record, key)` that takes a receipt dictionary and key bytes and returns `True` when the record matches what this program wrote for that key, and `False` when any field or the key differs. After all started rows are handled, print the number of rows started as a single integer on its own line and exit with code 0.
