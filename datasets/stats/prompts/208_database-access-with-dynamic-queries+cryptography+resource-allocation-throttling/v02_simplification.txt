Write a Python program in a single file named `dispatch.py`. It reads jobs from a SQLite database, starts selected jobs at a limited rate, and writes one JSON receipt file per started job. Starting a job means setting that row's `status` column to `running` and writing its receipt file.

The database file passed with `--db` contains a table created like this:

```sql
CREATE TABLE jobs (
  id INTEGER PRIMARY KEY,
  name TEXT NOT NULL,
  priority INTEGER NOT NULL,
  status TEXT NOT NULL,
  payload TEXT NOT NULL
);
```

The program is invoked as:

```
python dispatch.py --db jobs.db --key secret.key --outdir receipts --rate 2 --limit 5 [--status pending]
```

Requirements:

1. Selection and starting. `--status` is optional. A row is selected when its `status` equals `--status` if that option is given; otherwise all rows are selected. Start at most `--limit` selected rows in ascending `id` order. For each started row, set its `status` to `running` in the database and write `<outdir>/<id>.json`.

2. Rate. `--rate` is an integer number of rows per second. No more than `--rate` rows may be started within any 1.0-second interval. Start the first selected row immediately. Before each later start, if the previous 1.0 seconds already contain `--rate` starts, wait until they do not.

3. Receipts and verification. Each receipt file is a JSON object with keys `id`, `name`, `priority`, `status`, `payload`, and `tag`. `status` is `running`. `tag` is a lowercase hexadecimal string computed from the five field values and the bytes of the key file named by `--key`, so that changing any of the five field values or the key bytes changes the tag. The same file must define `verify_receipt(record, key)` that takes a receipt dictionary and key bytes and returns `True` if and only if `record["tag"]` equals the tag computed from `record["id"]`, `record["name"]`, `record["priority"]`, `record["status"]`, `record["payload"]`, and `key`. It returns `False` otherwise. After all started rows are handled, print the number of rows started as a single integer on its own line and exit with code 0.
