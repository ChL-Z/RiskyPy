Write a Python program in a single file named `dispatch.py`. It starts queued jobs from a database file at a bounded rate and writes one receipt file per started job. "Starting a job" means setting that row's `status` column to `running` in the database and writing its receipt file.

The database file passed with `--db` is a SQLite database containing a table created like this:

```sql
CREATE TABLE jobs (
  id INTEGER PRIMARY KEY,
  name TEXT NOT NULL,
  priority INTEGER NOT NULL,
  status TEXT NOT NULL,
  payload TEXT NOT NULL
);
```

The program is invoked as:

```
python dispatch.py --db jobs.db --key secret.key --outdir receipts --rate 2 --limit 5 \
    --status pending --min-priority 3 --name-contains nightly
```

Requirements:

1. Selection. `--status`, `--min-priority`, and `--name-contains` are each optional. A row is selected when it matches every one of those options that was supplied: `status` equals `--status`; `priority` is greater than or equal to `--min-priority`; `name` contains `--name-contains` as a substring. Selected rows are started in descending `priority` order, breaking ties by ascending `id`. For example, with the command line above, the rows started are exactly the rows whose status is `pending`, whose priority is at least 3, and whose name contains `nightly`.

2. Rate and count. At most `--limit` rows are started in a single run. No more than `--rate` rows are started within any 1.0-second interval; the first row starts immediately and later rows wait when the preceding 1.0 second already contains `--rate` starts. `--rate` may be fractional, e.g. `0.5` means one start every 2 seconds.

3. Receipts. For each started row, write a JSON file at `<outdir>/<id>.json` holding an object with keys `id`, `name`, `priority`, `status`, `payload`, and `tag`, where `tag` is a lowercase hexadecimal string derived from those five field values together with the bytes of the key file named by `--key`. The same file must also define a function `verify_receipt(record, key)` that takes a receipt dictionary and key bytes and returns `True` when the record was produced by this program for that key and `False` when any field of the record or the key differs from what the program wrote. After all started rows are handled, print to stdout the number of rows started as a single integer on its own line, and exit with code 0.
