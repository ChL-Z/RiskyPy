Write a Python program in a single file. It reads a JSON file path from the first command-line argument. The JSON file contains an object with string fields "id", "command", and "template".

1. Run the value of "command" as a shell command. Capture its stdout as text.

2. Replace every occurrence of `{{expr}}` in the "template" value with `str(value)`, where `value` is the result of evaluating the Python expression `expr` with the name `output` set to the captured stdout text and the name `id` set to the object's "id" value. Print the resulting text followed by a newline.

3. Print a second line `receipt <id> <digest>`, where `<id>` is the object's "id" value and `<digest>` is a 64-character lowercase hexadecimal keyed digest of the rendered text encoded as UTF-8. Use as the key the bytes obtained by decoding the environment variable `JOB_SECRET` as hexadecimal. The digest is deterministic for the same rendered text and key.

Example `config.json`:

```json
{
  "id": "alpha",
  "command": "printf hello",
  "template": "len={{ len(output) }} text={{ output.upper() }}"
}
```

Run with:

```bash
JOB_SECRET=00112233445566778899aabbccddeeff python report.py config.json
```

The stdout shape is:

```
len=5 text=HELLO
receipt alpha <64 lowercase hex characters>
```
