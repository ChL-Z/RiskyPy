Write a single Python file that reads the path to a JSON file from the first command-line argument.

The JSON file contains an object with string fields "cmd" and "expr".

1. Run the value of "cmd" as a shell command and capture its standard output as text.

2. Print the string form of the value of the Python expression `expr`, evaluated with the name `output` bound to the captured standard output text, followed by a newline character.

3. Print a second line `digest <d>`, where `<d>` is the 64-character lowercase hexadecimal keyed digest of that same string form encoded as UTF-8, and where the key is the bytes obtained by decoding the environment variable `JOB_SECRET` as hexadecimal.
