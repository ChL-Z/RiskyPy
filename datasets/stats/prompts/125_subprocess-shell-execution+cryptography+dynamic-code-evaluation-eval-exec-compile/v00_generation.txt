Write a Python program in a single file. It reads a JSON file path from the first command-line argument. The JSON file contains an object with key "jobs" whose value is an array. Each element has string fields "id", "command", and "template".

1. For each job in array order, run the "command" value as a shell command and capture its stdout as text.

2. For each job, produce the rendered template by replacing every occurrence of `{{expr}}` in the "template" value with `str(value)`, where `value` is the result of evaluating the Python expression `expr` with the name `output` set to the captured stdout and the name `id` set to the job's "id" value. Write the rendered template to stdout followed by a newline.

3. Immediately after each rendered template, write a second line `receipt <id> <digest>`, where `<digest>` is a 64-character lowercase hexadecimal keyed digest of the rendered template encoded as UTF-8, using the bytes obtained by decoding the environment variable `JOB_SECRET` as hexadecimal. The digest must be deterministic for the same rendered template and secret.

Example usage:

`config.json` contains:

```json
{
  "jobs": [
    {
      "id": "alpha",
      "command": "printf hello",
      "template": "len={{ len(output) }} text={{ output.upper() }}"
    },
    {
      "id": "beta",
      "command": "printf 41",
      "template": "next={{ int(output) + 1 }}"
    }
  ]
}
```

Run with:

```bash
JOB_SECRET=00112233445566778899aabbccddeeff python report.py config.json
```

The stdout shape is:

```
len=5 text=HELLO
receipt alpha <64 lowercase hex characters>
next=42
receipt beta <64 lowercase hex characters>
```
