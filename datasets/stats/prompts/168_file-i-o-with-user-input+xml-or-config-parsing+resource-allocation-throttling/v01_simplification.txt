Write a single-file Python program. It reads exactly one line from standard input: the path to an XML file. The XML root is `<jobs max_parallel="N">`, where N is an integer at least 1. Each direct child is `<job id="...">` with child elements `<command>` and `<output>`. The text of `<command>` is a command line; the text of `<output>` is a file path.

Process the `<job>` elements in document order in batches of at most N jobs. For each batch, start every command in the batch, wait until all commands in that batch have finished, then continue with the next batch. For each job, write both the command's standard output and standard error to the file named by `<output>`, overwriting that file if it exists. After each job finishes, print one line to standard output: the job's id, a single space, and the command's exit status. After all jobs finish, exit with status 0.
