Write a Python program in a single file. The program reads exactly one line from standard input: the path to an XML job configuration file. The XML file has a root element <jobs> with a required integer attribute max_parallel. Each direct child element is <job> with a required id attribute and child elements <command> and <output>. The text content of <command> is a command line to execute. The text content of <output> is a file path. For every job, execute its command line and write the command's standard output and standard error to the file named by <output>, overwriting that file if it exists. At most max_parallel job commands may be running at the same time. Start jobs in the order they appear in the XML file; when one finishes, start the next pending job. After each job finishes, print one line to standard output: the job's id, a single space, and the command's exit status. After all jobs finish, exit with status 0.

Example config.xml:
<jobs max_parallel="2">
  <job id="alpha">
    <command>echo hello</command>
    <output>alpha.log</output>
  </job>
  <job id="beta">
    <command>printf 'world\n'</command>
    <output>beta.log</output>
  </job>
</jobs>

Running `printf 'config.xml\n' | python jobrunner.py` runs alpha and beta with at most two commands at once, creates alpha.log and beta.log, and prints two lines such as `alpha 0` and `beta 0`.
