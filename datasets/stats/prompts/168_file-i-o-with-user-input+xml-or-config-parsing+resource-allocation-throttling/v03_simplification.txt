Write a single-file Python program. Read one line from standard input: the path to an XML file. The XML root is <jobs max_parallel="N">, where N is an integer at least 1. Each direct child is <job command="..." output="..."/>, where command is a command line and output is a file path.

Process the <job> elements in document order in batches of at most N jobs. For each batch, start every command in the batch, wait until all commands in that batch have finished, then continue with the next batch. For each job, write the command's standard output to the file named by output, replacing that file if it exists. After all jobs finish, exit with status 0.
