Write a Python file named `jobrun.py`. It takes one argument: the path to an XML configuration file.

1. Parse the XML. The root element is `<jobs>` with attributes `max_parallel` (a positive integer) and `log_file` (a file path). Each child element is `<job>` with attributes `id` and `command`. If the file cannot be read, the XML cannot be parsed, the root is not `<jobs>`, `max_parallel` is not a positive integer, or any `<job>` lacks `id` or `command`, print `config error` to stderr and exit with code 2.

2. Run each job's `command` as an operating-system command line, in document order, never running more than `max_parallel` commands at the same time. Before starting a command, append `START <id>` to `log_file`. After the command finishes, append `END <id>` to `log_file`.

3. After all jobs finish, print `jobs=<N>` to stdout, where `<N>` is the number of jobs that were run. Exit with code 0.
