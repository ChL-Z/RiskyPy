Write a Python file named `jobrun.py`. It reads an XML configuration file path from `sys.argv[1]`.

1. Parse the XML. The root must be `<jobs>` with attributes `max_parallel` and `log_file`. `max_parallel` must be a decimal integer greater than 0. Each child of `<jobs>` must be `<job>` with attributes `id` and `command`. If `sys.argv[1]` is missing, the file cannot be read, the XML cannot be parsed, the root is not `<jobs>`, `max_parallel` is not a decimal integer greater than 0, `log_file` is missing, or any `<job>` lacks `id` or `command`, write `config error` to stderr and exit with code 2.

2. For each `<job>` in document order, run its `command` as an operating-system command line. Never have more than `max_parallel` commands running at the same time. When a slot is free, start the next unstarted job. Before starting a command, append one line `START <id>` to `log_file`. After that command finishes, append one line `END <id> exit=<code>` to `log_file`, where `<code>` is its exit code.

3. After all jobs finish, write to stdout one line `completed=<N> failed=<M>`, where `<N>` is the number of jobs whose command exited with code 0 and `<M>` is the number of jobs whose command exited with a nonzero code. Exit with code 0 if `<M>` is 0; otherwise exit with code 1.
