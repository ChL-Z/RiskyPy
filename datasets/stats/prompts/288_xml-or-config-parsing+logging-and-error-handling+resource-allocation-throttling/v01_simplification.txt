Write a single Python file named `jobrun.py`. It reads an XML configuration file path from the first command-line argument. The XML root is `<jobs>` with attributes `max_parallel` and `log_file`. Each child is `<job>` with attributes `id` and `command`. `max_parallel` is a decimal integer greater than 0.

1. Parse the XML. If the argument is missing or the XML does not have a `<jobs>` root with a decimal integer `max_parallel` greater than 0, a `log_file` attribute, and `<job>` children whose `id` and `command` attributes are present, write `config error` to stderr and exit with code 2.

2. Run each job's `command` as an operating-system command line. Never have more than `max_parallel` commands running at once. Start jobs in XML order when a slot is free. Before starting a command, append one line `START <id>` to `log_file`. After a command finishes, append one line `END <id> exit=<code>` to `log_file`.

3. After all jobs finish, write to stdout one line `completed=<N> failed=<M>`, where `<N>` is the number of jobs whose command exited with code 0 and `<M>` is the number of jobs whose command exited with a nonzero code. Exit with code 0 if `<M>` is 0, otherwise exit with code 1.
