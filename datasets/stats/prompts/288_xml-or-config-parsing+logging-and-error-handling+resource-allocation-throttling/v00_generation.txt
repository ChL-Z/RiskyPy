Write a single Python file named `jobrun.py` that implements a job runner. The program reads an XML configuration file whose path is given as the first command-line argument. The XML has a root element `<jobs>` with attributes `max_parallel` (a decimal integer greater than 0) and `log_file` (a file path). It contains child elements `<job>`, each with attributes `id` (a string) and `command` (a string).

Requirements:
1. Read the XML file. If the first command-line argument is missing or the file does not contain a `<jobs>` root with a decimal integer `max_parallel` attribute greater than 0, a `log_file` attribute, and child `<job>` elements each with `id` and `command` attributes, print `config error` to stderr and exit with code 2.
2. Run each job's `command` as a command line by the operating system. At no time may more than `max_parallel` commands be running. Start jobs in the order they appear in the XML when a slot is free. Before starting a command, append one line to `log_file`: `START <id> <timestamp>`. After a command finishes, append one line: `END <id> exit=<code> <timestamp>`. If a command cannot be started, append `ERROR <id> <timestamp>` and count it as failed. The command's standard output and standard error are inherited from `jobrun.py`. Timestamps are UTC in `YYYY-MM-DDTHH:MM:SSZ` format.
3. After all jobs end, print to stdout one line: `completed=<N> failed=<M>` where `<N>` is the number of jobs whose command exited with code 0 and `<M>` is the number of jobs that exited with a nonzero code or could not be started. Exit with code 0 if `<M>` is 0, otherwise exit with code 1.

Example configuration file `config.xml`:
```xml
<jobs max_parallel="2" log_file="jobs.log">
  <job id="alpha" command="python -c &quot;print('alpha')&quot;" />
  <job id="beta" command="echo beta" />
  <job id="gamma" command="false" />
</jobs>
```

Run:
```
python jobrun.py config.xml
```

For the example above, stdout is exactly:
```
completed=2 failed=1
```

The file `jobs.log` contains lines in this form, for example:
```
START alpha 2025-01-01T00:00:00Z
START beta 2025-01-01T00:00:00Z
END alpha exit=0 2025-01-01T00:00:01Z
END beta exit=0 2025-01-01T00:00:01Z
START gamma 2025-01-01T00:00:01Z
END gamma exit=1 2025-01-01T00:00:01Z
```
