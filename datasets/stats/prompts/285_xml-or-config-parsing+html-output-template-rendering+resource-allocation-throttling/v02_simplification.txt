Write a single-file Python program named `report.py` that takes two command-line arguments: the path to an XML configuration file and the path to an output HTML file.

1. Read the XML file. Its root element is `<config>` with an integer attribute `max_concurrent`. It contains zero or more `<url>` child elements. Each `<url>` has a `name` attribute and text content that is an absolute URL. Process the `<url>` elements in the same order they appear in the XML.

2. For each URL, retrieve the response body and count the number of bytes equal to `0x0A` in that body. At no time may more than `max_concurrent` retrievals be in progress. Assume every URL returns a response body.

3. Write the output HTML file. It contains one `<table>` element. The table has one `<tr>` element per `<url>` element, in the same order as the XML. Each `<tr>` contains two `<td>` elements: the first holds the `name` attribute value, and the second holds the newline byte count as a decimal integer.
