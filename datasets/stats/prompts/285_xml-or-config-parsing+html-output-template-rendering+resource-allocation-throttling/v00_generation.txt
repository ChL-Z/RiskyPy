Write a Python script in a single file named `report.py`. The script takes two command-line arguments: the path to an XML configuration file and the path to an output HTML file. The XML configuration file has a root element `<config>` with an integer attribute `max_concurrent` and zero or more child elements `<url>` each with a `name` attribute and text content that is an absolute URL. For each `<url>` element, fetch the content at that URL, decode the response body as UTF-8, and count the number of `\n` characters. The script must run at most `max_concurrent` fetches at any moment. The output HTML file must contain a `<table>` element. The table must have a `<thead>` with a single `<tr>` containing two `<th>` elements with text `Name` and `Line Count`. The table must have a `<tbody>` with one `<tr>` for each `<url>` element, in the same order as they appear in the XML. Each such `<tr>` must contain two `<td>` elements: the first with the `name` attribute value, the second with the line count as a decimal integer. Assume the XML file is well-formed and follows the structure described above. Assume each URL is reachable and returns a 200 OK response with a body.

Example: given `config.xml`:
```xml
<config max_concurrent="2">
    <url name="Home">https://example.com/</url>
    <url name="About">https://example.com/about</url>
</config>
```
Running `python report.py config.xml report.html` writes `report.html` with a table whose first data row has `Home` in the first cell and the line count of the response from `https://example.com/` in the second cell, and whose second data row has `About` in the first cell and the line count of the response from `https://example.com/about` in the second cell.
