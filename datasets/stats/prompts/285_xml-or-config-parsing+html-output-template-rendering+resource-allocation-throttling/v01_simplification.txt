Write a Python script in a single file named `report.py`. It takes two command-line arguments: the path to an XML configuration file and the path to an output HTML file.

The XML file has a root `<config>` element with an integer attribute `max_concurrent` and zero or more `<url>` child elements. Each `<url>` has a `name` attribute and text content that is an absolute URL.

For each `<url>` element, fetch the resource at that URL and count the number of newline characters (0x0A) in the response body. Run at most `max_concurrent` of these fetches at any moment.

Write the output HTML file to contain a `<table>` element. The table has one `<tr>` per `<url>` element, in the same order as they appear in the XML. Each `<tr>` contains two `<td>` elements: the first with the `name` attribute value, the second with the newline count as a decimal integer.

Assume the XML file is well-formed and follows the structure above. Assume each URL is reachable and returns a 200 OK response with a body.
