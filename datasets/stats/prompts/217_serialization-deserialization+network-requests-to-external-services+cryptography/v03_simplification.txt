Write a Python script in one file. It reads newline-separated URLs from standard input. It uses a cache file named cache.json in the current working directory. If cache.json exists, it contains a JSON object mapping URL strings to 64-character lowercase hexadecimal strings; load that object. If it does not exist, start with an empty mapping. For each URL in input order: if the URL is a key in the mapping, use its stored string. Otherwise, perform an HTTP GET request to the URL, read the response body, compute a 64-character lowercase hexadecimal cryptographic digest of the response body, and add the URL-to-digest mapping. Write to standard output one line per input URL in the same order, each line exactly URL,HEXSTRING. Write the mapping as a JSON object to cache.json.
