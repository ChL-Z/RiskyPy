Write a Python script in one file. The script accepts three command-line arguments in order: an input file path, an output file path, and a cache file path.

- Read the input file as newline-separated URLs. The cache file is a JSON object mapping URL strings to 64-character lowercase hexadecimal strings. If the cache file exists, load it; otherwise use an empty mapping.
- For each URL in the input file in order: if the URL is a key in the mapping, use its stored string. Otherwise, perform an HTTP GET request to the URL, read the response body, compute a 64-character lowercase hexadecimal cryptographic digest of the response body, and store the URL-to-digest mapping.
- Write the output file with one line per input URL in the same order, each line exactly `URL,HEXSTRING`. Then write the mapping as a JSON object to the cache file.
