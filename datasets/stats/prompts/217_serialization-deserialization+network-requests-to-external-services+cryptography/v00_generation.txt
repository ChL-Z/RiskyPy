Write a Python script in a single file. The script takes three command-line arguments in this order: an input file path, an output file path, and a cache file path. The input file contains newline-separated URLs. For each URL, the script must:
- If the cache file (a binary file that stores a mapping from URL to a 64-character lowercase hexadecimal string) contains the URL, use the stored string.
- Otherwise, fetch the response body from the URL, compute a 64-character lowercase hexadecimal string that is uniquely determined by the response body, and add the URL and computed string to the cache.
The script must write to the output file one line per URL from the input file, in the same order, with the format `URL,HEXSTRING`. If the cache file does not exist, start with an empty cache. If no new URLs are fetched during a run, the cache file must remain unchanged.

Usage example: `python script.py urls.txt results.txt cache.bin` where `urls.txt` contains:
```
https://example.com
https://example.org
```
After running, `results.txt` will contain two lines, each with the URL, a comma, and a 64-character lowercase hexadecimal string. On a second run with the same inputs, the script must not fetch the URLs again and must produce the same output.
