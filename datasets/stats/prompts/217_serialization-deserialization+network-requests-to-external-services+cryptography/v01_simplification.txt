Write a Python script in one file. The script takes three command-line arguments in this order: an input file path, an output file path, and a cache file path. The input file contains newline-separated URLs. The cache file is a binary file that stores URL-to-HEXSTRING pairs, where HEXSTRING is a 64-character lowercase hexadecimal string. On start, load the cache from the cache file if it exists; otherwise start with an empty cache. For each URL in the input file, in order:

- If the cache contains the URL, use its stored HEXSTRING and do not fetch the URL.
- Otherwise, make an HTTP GET request to the URL, read the response body, compute a 64-character lowercase hexadecimal string that is uniquely determined by the response body, and add the URL and string to the cache.

After all URLs are processed, write the output file with one line per input URL, in the same order, in the format `URL,HEXSTRING`. Then save the cache to the cache file.
