Write a single Python file named `build_report.py`. The program is invoked as:

`python build_report.py <jobs_file> <report_file>`

It reads `<jobs_file>`, a JSON object with a `"jobs"` key whose value is an array of objects. Each job object has a `"name"` string and a `"command"` string. Example `jobs.json`:

```json
{
  "jobs": [
    {"name": "list", "command": "ls -1"},
    {"name": "version", "command": "python --version"}
  ]
}
```

Requirements:

1. Maintain a state file named `report_state.json` in the current working directory. If it exists, read it as a JSON object mapping job names to objects with keys `exit_code`, `stdout`, and `stderr`. If it does not exist, treat it as an empty object. For each job in the jobs array, in order: if its name is already a key in the state object, use the stored `exit_code`, `stdout`, and `stderr` for the report and do not run the command. Otherwise, run the job's `command` as an external process, capture its exit code, stdout, and stderr separately, then add or replace that job name in the state object with the captured values and write the state object back to `report_state.json`. Continue through all jobs even when a command exits with a nonzero status.

2. Write `<report_file>` as an HTML5 document with a heading `Job Report` and a `<table>` with columns `Name`, `Exit code`, `Stdout`, `Stderr`. Each job in the jobs array produces one `<tbody>` row in the same order as the input array. The `Stdout` and `Stderr` cells contain the captured text as the cell's text content.

3. The program must be in Python and contained in this single file.
