Write a Python program in one file named `run_commands.py`.

The program prints `Input file: ` to standard output, reads one line from standard input as a path, and opens that path as a text file. For each line in the file, strip leading and trailing whitespace. Skip blank lines. For each remaining line, run it as an external command, wait for it to finish, and record the line text and its integer exit code in order.

Write `report.txt` in the current working directory. For each recorded command, in the order read, write two lines:
`Command: <command text>`
`Exit code: <exit code>`
If no commands are recorded, create `report.txt` as an empty file. Exit with status 0 after writing the file.
