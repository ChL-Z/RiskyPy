Write a Python program in one file named `run_commands.py`.

The program prints `Input file: ` to standard output, reads one line from standard input as a path, and opens that path as a text file. If the file cannot be read, print `Error: cannot read input file` to standard error and exit with status 1.

For each line in the file, strip leading and trailing whitespace. Skip it if the stripped line is empty or starts with `#`. For every remaining stripped line, run it as an external command, wait for it to finish, and record the command text and its integer exit code.

Write `report.txt` in the current working directory. For each recorded command, in the order read, write two lines:
`Command: <command text>`
`Exit code: <exit code>`
After all commands, exit with status 0. If no commands were run, create `report.txt` as an empty file.
