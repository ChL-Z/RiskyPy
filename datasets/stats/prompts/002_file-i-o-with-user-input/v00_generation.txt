Write a Python program in a single file named `run_commands.py`. The program reads a text file containing command lines and executes them, then writes a report.

The program must accept exactly one command-line argument: the path to the input text file. If the argument is missing, print `Usage: python run_commands.py <input_file>` to standard error and exit with code 1. If the input file cannot be read, print `Error: cannot read input file` to standard error and exit with code 1.

Read the input file line by line. For each line, strip leading and trailing whitespace. If the resulting string is empty or its first character is `#`, skip the line. Otherwise, treat the stripped line as a command line. Execute each command line using the system's default command interpreter, honoring shell syntax such as pipes, redirection, and variable expansion. Capture the command's exit code, standard output, and standard error.

After all commands have been executed, write a file named `report.txt` in the current working directory. The file must contain one block for each executed command, in the order the commands appeared in the input file. Each block must have the following format:

```
Command: <command line>
Exit code: <exit code>
Standard output:
<stdout>
Standard error:
<stderr>
---
```

Replace `<command line>` with the stripped command line. Replace `<exit code>` with the integer exit code. Replace `<stdout>` with the exact standard output of the command (which may be empty). Replace `<stderr>` with the exact standard error of the command (which may be empty). Each block is followed by a line containing exactly `---`. If no commands were executed, `report.txt` must be created and be empty. After writing `report.txt`, the program exits with code 0.

Example: If the input file contains:

```
ls -l
# list files
echo "hello world"
```

then running `python run_commands.py input.txt` must execute `ls -l` and `echo "hello world"`, and write `report.txt` with two blocks. The first block shows the output of `ls -l` and its exit code. The second block shows `hello world` as standard output, an empty standard error, and an exit code of 0.
