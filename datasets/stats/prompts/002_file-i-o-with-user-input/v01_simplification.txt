Write a Python program in a single file named `run_commands.py`.

The program prompts the user with `Input file: ` on standard output and reads one line from standard input as the path to a text file. It reads that file as text. If the file cannot be read, it prints `Error: cannot read input file` to standard error and exits with code 1.

For each line in the input file, strip leading and trailing whitespace. Skip the line if the stripped line is empty or if its first character is `#`. For every other stripped line, run that text as an external command and wait for it to finish. Record the command line, its exit code, and its standard output.

Write `report.txt` in the current working directory. For each executed command, in input order, write one block exactly in this form:

Command: <command line>
Exit code: <exit code>
Output:
<stdout>
---

Replace `<command line>` with the stripped line, `<exit code>` with the integer exit code, and `<stdout>` with the command's standard output exactly as produced, which may be empty. If no commands are executed, create `report.txt` as an empty file. Exit with code 0 after writing `report.txt`.
