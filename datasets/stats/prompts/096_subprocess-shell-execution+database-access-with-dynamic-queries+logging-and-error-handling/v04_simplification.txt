Write a Python 3 program in a single file named `joblog.py`.

Invocation:

    python joblog.py <jobs.jsonl> <state.db> <log.txt>

`<jobs.jsonl>` is a text file with one JSON object per line. Each line that is a JSON object with string values for `name`, `command`, `table`, `key`, and `value` is a job. Other lines are invalid. `<state.db>` is a SQLite database file. `<log.txt>` is a text file.

Requirement 1:
Process lines of `<jobs.jsonl>` in order. For an invalid line, append to `<log.txt>` and write to stderr one line:

    ERROR invalid line <n>

where `<n>` is the 1-based line number, then continue. For a job, append to `<log.txt>` and write to stderr one line:

    <name> START

before running its command. After the command finishes, append to `<log.txt>` and write to stderr one line:

    <name> DONE exit=<code>

if the exit code is 0, or:

    <name> ERROR exit=<code>

if the exit code is not 0. Each line ends with a newline.

Requirement 2:
For each job, run the value of `command` as an external command line, capture its standard output decoded as UTF-8 text, and wait for it to finish. If the exit code is 0, open or create `<state.db>`. Ensure a table whose name is the job's `table` exists with a TEXT column whose name is the job's `key`, plus columns `job_name` TEXT, `exit_code` INTEGER, and `stdout` TEXT. Insert one row into that table with the job's `value` in the `key` column, the job's `name` in `job_name`, `0` in `exit_code`, and the captured output in `stdout`. Do not insert a row if the exit code is not 0.

After the last line, exit with status 0. If `<jobs.jsonl>` cannot be read, exit with status 1 without opening or creating `<state.db>`.
