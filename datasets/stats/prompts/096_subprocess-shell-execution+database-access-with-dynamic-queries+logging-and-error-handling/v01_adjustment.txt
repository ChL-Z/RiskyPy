Write a Python 3 program in a single file named `joblog.py`.

Invocation:

    python joblog.py <jobs.jsonl> <state.db> <log.txt>

`jobs.jsonl` holds one JSON object per line. Each object has exactly these keys:

- `name`: string
- `command`: string
- `table`: string
- `fields`: object whose keys are column names and whose values are strings
- `timeout_seconds`: number

`state.db` is a SQLite database file. `log.txt` is a text file.

Requirement 1 — Logging. For every line in `jobs.jsonl`, append to `log.txt` and write to standard error the log lines specified below. A log line has the shape `<timestamp> <event> <name><suffix>`, where `<timestamp>` is the current UTC time formatted as `YYYY-MM-DDTHH:MM:SSZ`, `<event>` is `START`, `DONE`, or `ERROR`, and `<suffix>` is empty for `START`, ` exit=<code>` for `DONE`, and ` <message>` for `ERROR`. Each appended line ends with a newline. For a line that is not a JSON object holding exactly those five keys with the stated value types, write one `ERROR` line with `<name>` set to the literal `-` and `<message>` set to `invalid line: <n>`, where `<n>` is the 1-based line number in `jobs.jsonl`, then continue with the next line.

Requirement 2 — Execution. Process valid objects in file order. For each valid object, first write one `START` line using the object's `name`. Then execute `command` as a command line interpreted by the operating system's command interpreter, capture its standard output decoded as UTF-8 text and its exit code, and wait at most `timeout_seconds` seconds. If the command exits with status 0 within that time, write one `DONE` line with `<code>` set to `0`. If the command exits with a nonzero status within that time, write one `ERROR` line with `<message>` set to `exit status <code>`. If the command has not finished within `timeout_seconds` seconds, terminate it and write one `ERROR` line with `<message>` set to `timed out`. After an `ERROR` line, continue with the next object.

Requirement 3 — Recording. For each valid object whose command exits with status 0 within the timeout, open or create the SQLite database file `<state.db>`. Ensure a table named exactly by the object's `table` exists with one TEXT column for each key in `fields`, plus columns `job_name` TEXT, `exit_code` INTEGER, `stdout` TEXT, and `ran_at` TEXT. Insert one row into that table containing the `fields` values, the object's `name`, the captured exit code, the captured standard output, and the timestamp used in that object's `START` line. Do not insert a row for any object whose command exits with a nonzero status, times out, or has an invalid JSON line. The program exits with status 0 after the last line, or with status 1 without writing to `state.db` when `jobs.jsonl` cannot be read.

Example. Given this `jobs.jsonl`:

    {"name":"ping","command":"echo hello","table":"runs","fields":{"host":"alpha"},"timeout_seconds":5}
    {"name":"probe","command":"exit 3","table":"runs","fields":{"host":"beta"},"timeout_seconds":5}

running `python joblog.py jobs.jsonl state.db log.txt` appends four lines to `log.txt` (two per object) and leaves `runs` holding exactly one row, with `host` set to `alpha`, `job_name` set to `ping`, `exit_code` set to 0, `stdout` set to the text `hello` followed by a newline, and `ran_at` set to the same timestamp used in the `START` line for `ping`. The second object produces no row because its command exits with status 3.
