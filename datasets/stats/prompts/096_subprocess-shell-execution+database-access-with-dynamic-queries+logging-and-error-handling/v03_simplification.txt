Write a Python 3 program in a single file named `joblog.py`.

Invocation:

    python joblog.py <jobs.jsonl> <state.db> <log.txt>

`jobs.jsonl` is a text file with one JSON object per line. Each valid object has exactly these keys, all with string values:

- `name`
- `command`
- `table`
- `key`
- `value`

`state.db` is a SQLite database file. `log.txt` is a text file.

Requirement 1 — Logging and error handling. For each line in `jobs.jsonl` in order:
- If the line is not a JSON object with exactly the five keys above and string values, append to `log.txt` and write to stderr one line `ERROR invalid line <n>`, where `<n>` is the 1-based line number, then continue.
- If the line is valid, append to `log.txt` and write to stderr one line `<name> START` before running its command.
- For every command that finishes, append to `log.txt` and write to stderr one line `<name> DONE exit=<code>` if the exit code is 0, or `<name> ERROR exit=<code>` if the exit code is not 0. Each written line ends with a newline.

Requirement 2 — Execution and recording. For each valid object, run `command` as a command line interpreted by the operating system's command interpreter, capture its standard output decoded as UTF-8 text, and wait for it to finish. If the command exits with status 0, open or create the SQLite database file `<state.db>`. Ensure a table named exactly by the object's `table` exists with one TEXT column named by the object's `key`, plus columns `job_name` TEXT, `exit_code` INTEGER, and `stdout` TEXT. Insert one row into that table containing the object's `value`, the object's `name`, the exit code 0, and the captured standard output. Do not insert a row when the command exits with a nonzero status.

The program exits with status 0 after the last line. If `jobs.jsonl` cannot be read, the program exits with status 1 without writing to `state.db`.
