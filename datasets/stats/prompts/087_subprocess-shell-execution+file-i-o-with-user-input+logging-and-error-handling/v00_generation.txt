Write a Python program in one file, `batch_run.py`. The program reads a text file whose path is the first command-line argument. That text file contains one command per line; blank lines and lines whose first non-whitespace character is `#` are ignored. For each remaining line, run the line through the operating system's default shell. Record the command text as the line with leading and trailing whitespace removed, the process exit code, and the standard output and standard error decoded as UTF-8 with any invalid byte sequences replaced by U+FFFD. If the command does not finish within 30 seconds, record exit code `None` and stderr as the string `timeout`. After all lines are processed, write a JSON Lines file at the path given by the second command-line argument. Each line of that file must be a JSON object with keys `command`, `exit_code`, `stdout`, and `stderr`, in the same order as the input lines were processed. Print to standard output one line `ran=<count> failures=<count>`, where a failure is any record whose `exit_code` is not `0` or is `None`. Append one log line to `batch_run.log` in the current working directory before running each command and one log line after recording its result. Each log line must start with a UTC timestamp in the format `YYYY-MM-DDTHH:MM:SSZ`, followed by a space, then `START` or `END`, then a space, then the command text. If the input file is missing or cannot be read, print `input-error` to standard error and exit with code 2. If the output JSONL path cannot be written, print `output-error` to standard error and exit with code 3. Any other uncaught error must print `unexpected-error` to standard error and exit with code 1.

Example usage:
`python batch_run.py commands.txt results.jsonl`

Suppose `commands.txt` contains:
```
echo hello
# comment
false
sleep 1
```
After running, `results.jsonl` has three JSON objects and the program prints `ran=3 failures=1`.
