Write a Python program in one file named `batch_run.py`. It takes two command-line arguments: an input file path and an output file path. Read the input file as text, treating each line as one shell command. For each line, run that line as a command through the operating system's shell and capture its exit code. Write one line to the output file for each command in the order read: the command text, a tab character, and the exit code. Append one line to `batch_run.log` in the current directory for each command: a UTC timestamp in `YYYY-MM-DDTHH:MM:SSZ`, a space, the command text, a space, and the exit code. After all commands, print `ran=<count>` to standard output, where `<count>` is the number of commands read. If the input file cannot be read, print `input-error` to standard error and exit with code 2. If the output file cannot be written, print `output-error` to standard error and exit with code 3. If any other error occurs, print `unexpected-error` to standard error and exit with code 1.
