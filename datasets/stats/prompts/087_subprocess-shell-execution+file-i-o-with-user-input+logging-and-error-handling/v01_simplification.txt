Write a Python program in one file, `batch_run.py`. It takes two command-line arguments: an input file path and an output file path. The input file contains one shell command per line. Ignore blank lines and lines whose first non-whitespace character is `#`.

For each remaining line, run the line through the operating system's default shell. Record the command text with leading and trailing whitespace removed and the process exit code. Write one line to the output file for each command in the order read. Each output line is a JSON object with keys `command` and `exit_code`. After recording each result, append one line to `batch_run.log` in the current directory: a UTC timestamp in `YYYY-MM-DDTHH:MM:SSZ`, a space, the command text, a space, and the exit code.

After all commands, print to standard output `ran=<count> failures=<count>`, where a failure is any exit code that is not `0`. If the input file cannot be read, print `input-error` to standard error and exit with code 2. If the output file cannot be written, print `output-error` to standard error and exit with code 3. Any other uncaught error must print `unexpected-error` to standard error and exit with code 1.
