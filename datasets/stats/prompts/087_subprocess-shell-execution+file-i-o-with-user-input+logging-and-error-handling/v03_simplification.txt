Create a single Python file named `batch_run.py`. It accepts two command-line arguments: an input file path and an output file path. Read the input file as text; each non-empty line is one shell command. Run each command in the system shell and capture its exit code. For every command, in the order read, write one line to the output file containing the command text, a tab, and the exit code, and append one line to `batch_run.log` in the current directory containing the current UTC time in `YYYY-MM-DDTHH:MM:SSZ`, a space, and the exit code. After all commands, print `ran=<count>` to standard output, where `<count>` is the number of commands read. If any error occurs while reading the input file, writing the output file, or running a command, print `error` to standard error and exit with code 1.
