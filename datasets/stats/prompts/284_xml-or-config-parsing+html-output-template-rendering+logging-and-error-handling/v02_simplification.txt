Write a Python program in a single file named `render_report.py`. It is run as:

`python render_report.py config.xml report.html app.log`

1. Before reading the first file, append this line to the file named by the third argument:
`YYYY-MM-DDTHH:MM:SS INFO: starting`
using UTC time for the timestamp.

2. Read the file named by the first argument as XML. The root element must be `<report title="...">` and may contain `<item name="..." value="..." />` children. If the file cannot be read, the XML cannot be read, the root element is not `<report>`, or any `<item>` is missing its `name` or `value` attribute, append this line to the third file:
`YYYY-MM-DDTHH:MM:SS ERROR: invalid config`
then exit with status 1. Do not create or change the HTML file in these cases.

3. On success, write an HTML file to the path named by the second argument. The HTML must contain the report title inside a `<title>` element and inside an `<h1>` element. It must also contain a `<table>` whose first row is `<th>Name</th><th>Value</th>`, followed by one `<tr>` for each `<item>` in the XML, in the same order, with two `<td>` cells holding the item's `name` and `value`. Append this line to the third file:
`YYYY-MM-DDTHH:MM:SS INFO: rendered N items`
where `N` is the number of `<item>` elements, then exit with status 0. Use the same UTC timestamp format `YYYY-MM-DDTHH:MM:SS` for all log lines.
