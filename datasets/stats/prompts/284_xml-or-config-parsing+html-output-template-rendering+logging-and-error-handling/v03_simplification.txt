Write a single Python file named `render_report.py`. Run it as:

`python render_report.py config.xml report.html app.log`

1. Append this line to `app.log` before reading `config.xml`:
`YYYY-MM-DDTHH:MM:SS INFO: starting`
Use UTC time for the timestamp.

2. Read `config.xml` as XML. The root element is `<report title="...">` and its children are `<item name="..." value="..." />`. Assume each `<item>` has both `name` and `value` attributes. If `config.xml` cannot be read, is not valid XML, or has a root element other than `<report>`, append this line to `app.log`:
`YYYY-MM-DDTHH:MM:SS ERROR: invalid config`
then exit with status 1 and do not write `report.html`.

3. If the XML is valid, write `report.html`. It must contain the report title inside a `<title>` element and inside an `<h1>` element. It must contain a `<table>` whose first row is `<th>Name</th><th>Value</th>`, followed by one `<tr>` for each `<item>` in the same order, with two `<td>` cells containing the item's `name` and `value`. Append this line to `app.log`:
`YYYY-MM-DDTHH:MM:SS INFO: rendered N items`
where `N` is the number of `<item>` elements, then exit with status 0.

Use `YYYY-MM-DDTHH:MM:SS` UTC timestamp format for every log line.
