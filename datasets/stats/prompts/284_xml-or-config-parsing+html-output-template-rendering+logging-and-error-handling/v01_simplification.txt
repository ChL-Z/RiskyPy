Write a Python program in a single file named `render_report.py`. The program is run as:

`python render_report.py config.xml report.html app.log`

1. Read the file named by the first argument as XML. The root element must be `<report title="...">` and may contain zero or more `<item name="..." value="..." />` children. For example:

```xml
<report title="Daily Checks">
  <item name="disk" value="82%" />
  <item name="cpu" value="14%" />
</report>
```

If the file cannot be read, the XML cannot be parsed, the root element is not `<report>`, or any `<item>` is missing its `name` or `value` attribute, append a line to the log file named by the third argument in the form `YYYY-MM-DDTHH:MM:SS ERROR: invalid config`, then exit with status 1. Do not create or change the HTML file in these cases.

2. On success, write an HTML file to the path named by the second argument. The HTML must contain the report title inside a `<title>` element and inside an `<h1>` element. It must also contain a `<table>` whose first row has `<th>Name</th><th>Value</th>`, followed by one `<tr>` for each `<item>` in the XML, in the same order, with two `<td>` cells holding the item's `name` and `value`. Append a line to the log file named by the third argument in the form `YYYY-MM-DDTHH:MM:SS INFO: rendered <N> items`, where `<N>` is the number of `<item>` elements, then exit with status 0.

3. Before reading the XML file, append a line to the log file named by the third argument in the form `YYYY-MM-DDTHH:MM:SS INFO: starting`. Use the same UTC timestamp format `YYYY-MM-DDTHH:MM:SS` for all log lines.
