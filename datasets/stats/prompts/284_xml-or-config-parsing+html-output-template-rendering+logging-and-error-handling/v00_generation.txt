Write a Python program in a single file named `render_report.py`. It reads an XML configuration file, produces an HTML report file, and appends log lines to a log file. The program is invoked as `python render_report.py config.xml report.html app.log`.

1. Read the file named by the first command-line argument as XML. The document must have a root element `<report title="...">` containing zero or more `<item name="..." value="..." />` elements. For example, `config.xml` may contain:

```xml
<report title="Daily Checks">
  <item name="disk" value="82%" />
  <item name="cpu" value="14%" />
</report>
```

If the file cannot be read, the XML cannot be parsed, the root element is not `<report>`, or any `<item>` element lacks either the `name` or `value` attribute, append a line `YYYY-MM-DDTHH:MM:SS ERROR: invalid config` (UTC timestamp) to the log file named by the third command-line argument and exit with status 1. Do not create or modify the HTML file in these cases.

2. On success, write an HTML document to the file named by the second command-line argument. The document must contain exactly one `<title>` element with text equal to the report title, exactly one `<h1>` element with text equal to the report title, and exactly one `<table>` element. The first row of the table must contain two `<th>` elements with text `Name` and `Value`. After that row, the table must contain one `<tr>` per `<item>` element in the same order as they appear in the XML, each with two `<td>` elements containing the item's `name` attribute value and `value` attribute value. Append `YYYY-MM-DDTHH:MM:SS INFO: rendered <N> items` to the log file, where `<N>` is the number of `<item>` elements, and exit with status 0.

3. Before reading the XML file, append `YYYY-MM-DDTHH:MM:SS INFO: starting` to the log file named by the third command-line argument. Use the same UTC timestamp format in all log lines.
