Write a Python program in a single file named `runchecks.py`.

The program takes one command-line argument: a path to a JSON file containing an array of objects with string fields `name`, `command`, and `expect`. If the argument is missing or the file cannot be read, print an error message to standard error and exit with status 2.

For each object in the array, in order:
- Run `command` as a shell command line and capture its standard output as text.
- Evaluate `expect` as a Python expression in which the name `out` is bound to that captured standard output text. If the expression value is truthy, print `PASS <name>`; otherwise print `FAIL <name>`.

After all objects have been processed, exit with status 0 if every check printed `PASS`, and exit with status 1 if any check printed `FAIL`.
