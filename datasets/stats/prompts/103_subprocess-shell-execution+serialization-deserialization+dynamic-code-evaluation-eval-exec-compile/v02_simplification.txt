Write a Python program in a single file named `runchecks.py`.

The program takes one command-line argument: a path to a JSON file. The file contains an array of objects, each with string fields `name`, `command`, and `expect`. For each object in order, run `command` as a shell command line and capture its standard output as text. Evaluate `expect` as a Python expression with the name `out` bound to that captured output. If the result is truthy, print `PASS <name>`; otherwise print `FAIL <name>`.
