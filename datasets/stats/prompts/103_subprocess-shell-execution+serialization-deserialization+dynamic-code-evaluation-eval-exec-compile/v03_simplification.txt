Write a Python program in a single file named `runchecks.py`. The program takes one command-line argument: a path to a JSON file. The file contains a JSON array of objects, each with string fields `command` and `expect`. For each object in order, run the `command` string as a shell command line and capture its stdout as text. Evaluate the `expect` string as a Python expression with the name `out` bound to that captured text. Print one line per object: `PASS` if the expression result is truthy, otherwise `FAIL`. Print the lines in the same order as the objects.
