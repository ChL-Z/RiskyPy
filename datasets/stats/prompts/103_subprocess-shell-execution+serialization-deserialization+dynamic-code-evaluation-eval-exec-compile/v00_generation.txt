Write a Python program in a single file named `runchecks.py`.

The program takes one command-line argument: the path to a JSON file whose contents are an array of check objects. Each check object has the three string members `name`, `command`, and `expect`.

For each check object, in the order it appears in the array:

- Run `command` as a shell command line and capture its standard output as text.
- Treat `expect` as a Python expression in which the name `out` refers to that check's captured standard output text. The check passes when the expression evaluates to a truthy value, and fails otherwise.
- Write one line to standard output: `PASS <name>` when the check passes, and `FAIL <name>` when it does not.

After all checks have been processed, the program exits with status 0 if every check passed and status 1 if at least one check failed. If the argument is missing, or the file cannot be read, or its contents are not an array of check objects, the program writes an error message to standard error and exits with status 2.

Example: with a file `checks.json` containing

```json
[
  {"name": "greeting", "command": "echo hello", "expect": "out.strip() == 'hello'"},
  {"name": "nonempty", "command": "printf ''", "expect": "len(out) > 0"}
]
```

running `python runchecks.py checks.json` prints

```
PASS greeting
FAIL nonempty
```

and exits with status 1.
