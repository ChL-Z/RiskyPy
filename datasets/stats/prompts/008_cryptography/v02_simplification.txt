Write a single Python file named vault.py using only the Python standard library. The program takes two command-line arguments: the first is either seal or open, and the second is a password. It reads exactly one line from stdin, without the trailing newline.

When the first argument is seal, encrypt the input line using the password and print a base64-encoded string that encodes the encrypted line. When the first argument is open, read a base64-encoded string from stdin, decrypt it using the password, and print the original line.

Running seal and then open with the same password must print the same line that was passed to seal.
