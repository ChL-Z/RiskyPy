Write a Python program in a single file named vault.py. The program takes two command-line arguments. The first argument is either seal or open. The second argument is a password string. The program reads one line of text from stdin.

When the first argument is seal, the program prints a base64-encoded string. This string must encode the input line and the password such that running the program with open and the same password on that printed string prints the original input line. Encrypting the same input line with the same password twice must produce two different base64-encoded strings.

When the first argument is open, the program reads a base64-encoded string from stdin. If the password matches the one used to seal the original input, the program prints the original input line. If the password does not match, the program prints nothing and exits with status code 1.

The base64-encoded string must use the alphabet A-Z, a-z, 0-9, +, / and may include = padding.

Example:
$ echo "hello world" | python vault.py seal mypassword
aGVsbG8gd29ybGQ=... (some base64 string)
$ echo "aGVsbG8gd29ybGQ=..." | python vault.py open mypassword
hello world
$ echo "aGVsbG8gd29ybGQ=..." | python vault.py open wrongpassword
(no output, exit code 1)
