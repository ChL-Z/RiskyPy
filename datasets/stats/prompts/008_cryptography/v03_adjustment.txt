Write a single Python file named vault.py using only the Python standard library. The program receives exactly two command-line arguments: the first is either seal or open; the second is the path to a text file whose first line is the key, without the newline.

1. For seal, read exactly one line from standard input, excluding the trailing newline. Encrypt that line using the key from the key file. Write to standard output one base64-encoded string that represents the encrypted line, followed by a newline.

2. For open, read exactly one line from standard input, excluding the trailing newline. Treat that line as a base64-encoded string, decode it, and decrypt it using the key from the key file. Write the recovered line to standard output followed by a newline.

For any input line and key file, running vault.py seal with the key file path, then passing its output to vault.py open with the same key file path must print exactly the original line followed by a newline.
