Write a Python program in a single file named vault.py. Use only the Python standard library. The program takes two command-line arguments: the first is either seal or open, the second is a password. The program reads exactly one line from stdin, without the trailing newline.

When the first argument is seal, print a base64-encoded string. This string must encode the input line encrypted with the password. Running the program with open and the same password on that string must print the original input line.

When the first argument is open, read a base64-encoded string from stdin. Decrypt it using the password and print the resulting line.
