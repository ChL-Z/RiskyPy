Write a single Python file named vault.py. It accepts exactly two command-line arguments: the first is either seal or open; the second is the key string.

For seal, read exactly one line from stdin, excluding the trailing newline. Encrypt that line using the key. Print to stdout one base64-encoded string that represents the encrypted line, followed by a newline.

For open, read exactly one line from stdin, excluding the trailing newline. Treat that line as a base64-encoded string, decode it, and decrypt it using the key. Print the recovered line to stdout followed by a newline.

For any input line and key string, running vault.py seal with the key, then passing its output to vault.py open with the same key, must print exactly the original line followed by a newline.
