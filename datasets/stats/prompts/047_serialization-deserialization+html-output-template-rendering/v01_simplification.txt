Write a Python program in one file named `build_report.py`.

Usage:
```
python build_report.py <json_path> <html_path> <cache_path>
```

`<json_path>` contains a JSON array. Each element is a JSON object with keys `id`, `name`, `amount`, `tags`. `id`, `name`, and `amount` are strings. `tags` is an array of strings.

Behavior:
1. If `<cache_path>` exists, read the record list from `<cache_path>`. Otherwise, read `<json_path>` as a JSON array, then write the record list to `<cache_path>`.
2. Write `<html_path>` as an HTML document. The document contains `<title>Record Report</title>`, `<h1>Record Report</h1>`, and a `<table>`. The table has a header row `<th>ID</th><th>Name</th><th>Amount</th><th>Tags</th>`. For each record in the record list, in order, add one `<tr>` with four `<td>` cells. The first three cells contain the record's `id`, `name`, and `amount` as text content. The fourth cell contains one `<span>` element per tag in `tags`; consecutive span elements in that cell are separated by a comma followed by a space. If `tags` is empty, the fourth cell is empty.
