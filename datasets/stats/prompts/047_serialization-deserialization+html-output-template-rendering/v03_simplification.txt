Write a Python program in one file named `build_report.py`.

Run it as:

```
python build_report.py <json_path> <html_path> <cache_path>
```

Read a JSON array from `<json_path>`. Each element is an object with keys `id`, `name`, and `amount`; the value for each key is a string.

Write the same array to `<cache_path>` as JSON.

Write `<html_path>` as an HTML document. The document contains a `<table>` with the header row `<th>ID</th><th>Name</th><th>Amount</th>`. For each record in the input array, in order, add one `<tr>` with three `<td>` cells. The first cell contains the record's `id`, the second contains its `name`, and the third contains its `amount` as text.
