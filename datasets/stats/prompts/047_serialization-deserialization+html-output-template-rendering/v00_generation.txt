Write a Python program in one file named `build_report.py`. It reads a JSON array of records and writes an HTML report. It can also store the loaded records in a cache file so a later run can produce the same report without reading the JSON file again.

Usage:
```
python build_report.py <json_path> <html_path> [--cache <cache_path>] [--rebuild]
```

`<json_path>` contains a JSON array. Each element is a JSON object with exactly these keys:
- `id`: string
- `name`: string
- `amount`: string
- `tags`: array of strings

Behavior:
1. Record source: If `--cache` is given, `<cache_path>` exists, and `--rebuild` is not given, get the record list from the object stored in `<cache_path>`. If `--cache` is given and `<cache_path>` does not exist or `--rebuild` is given, read and parse `<json_path>` as JSON, then store the record list in `<cache_path>`. If `--cache` is not given, read and parse `<json_path>` as JSON.
2. HTML output: Write `<html_path>` as an HTML document. The document contains `<title>Record Report</title>`, `<h1>Record Report</h1>`, and a `<table>` with a header row `<th>ID</th><th>Name</th><th>Amount</th><th>Tags</th>`. For each record in the record list, in order, add one `<tr>` with four `<td>` cells. The first three cells contain the record's `id`, `name`, and `amount` as text content. The fourth cell contains one `<span>` element per tag in `tags`; consecutive span elements in that cell are separated by a comma followed by a space. If `tags` is empty, the fourth cell is empty.
3. Errors: If `<json_path>` is missing when it must be read, or if the content read from `<json_path>` or `<cache_path>` does not contain a JSON array whose elements are objects with keys `id`, `name`, `amount`, and `tags`, where `id`, `name`, and `amount` are strings and `tags` is an array of strings, print `input error` to stderr and exit with status 1. Otherwise exit with status 0.

Example:
`records.json`:
```json
[
  {"id":"a1","name":"Ada","amount":"10.00","tags":["math","code"]},
  {"id":"b2","name":"Bob","amount":"5.50","tags":[]}
]
```
Running `python build_report.py records.json report.html --cache records.cache` writes `report.html` with a table whose first data row has cells `a1`, `Ada`, `10.00`, and `<span>math</span>, <span>code</span>`, and second data row has `b2`, `Bob`, `5.50`, and an empty fourth cell.
