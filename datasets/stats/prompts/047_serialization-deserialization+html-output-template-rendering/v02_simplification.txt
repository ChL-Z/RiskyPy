Write a Python program in one file named `build_report.py`.

Usage:
```
python build_report.py <json_path> <html_path> <cache_path>
```

Read a JSON array from `<json_path>`. Each element is an object with keys `id`, `name`, `amount`, and `tags`. `id`, `name`, and `amount` are strings. `tags` is an array of strings.

Write the same array to `<cache_path>` as JSON.

Write `<html_path>` as an HTML document. The document contains a `<table>` with the header row `<th>ID</th><th>Name</th><th>Amount</th><th>Tags</th>`. For each record in the input array, in order, add one `<tr>` with four `<td>` cells. The first three cells contain the record's `id`, `name`, and `amount` as text. The fourth cell contains one `<span>` element per tag in `tags`; spans are separated by a comma followed by a space. If `tags` is empty, the fourth cell is empty.
