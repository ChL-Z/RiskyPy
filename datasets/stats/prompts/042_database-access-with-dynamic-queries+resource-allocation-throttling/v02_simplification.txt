Write a Python script in a single file `runner.py`. It takes two command-line arguments: a path to a JSON file and a filter string. The JSON file contains a JSON array of objects. Each object has an `id` string and a `cmd` string. The filter string is split on the first `=` into a column name and a value.

1. For each object, start its `cmd` string as an external process. Run at most 3 such processes at the same time. After a process ends, write one row to a SQLite database file `runner.db` in the current working directory. The table is named `results` and has columns `id TEXT`, `exit_code INTEGER`, `duration REAL`. Create the table if it does not exist. For each object, write its `id`, the process exit code or -1 if the process could not be started, and the wall-clock duration in seconds from just before starting the process until just after it ends, rounded to two decimal places. If a row with the same `id` already exists, replace it.

2. After all processes have ended, use the filter column name and filter value. The column name is one of `id`, `exit_code`, or `duration`. Query the `results` table for rows where that column equals the filter value. Compare `id` as a string, `exit_code` as an integer, and `duration` as a number. Print each matching row to stdout on its own line as `id:exit_code:duration`, where `exit_code` is printed as an integer and `duration` is printed with exactly two decimal places. Rows may be printed in any order.
