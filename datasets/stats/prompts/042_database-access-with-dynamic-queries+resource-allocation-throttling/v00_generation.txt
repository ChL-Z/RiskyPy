Write a Python script in a single file named `runner.py`. The script accepts two command-line arguments: the path to a JSON file and a filter string. The filter string is split on the first `=` character into a column name and a value. The JSON file contains a JSON array of objects. Each object has exactly the keys `id` (string), `cmd` (string), and `limit` (integer between 1 and 3). The script must:

1. Run the `cmd` string of every object in the JSON array. At most 3 commands may be running at the same time across all objects. For each object, after its command finishes, insert or replace a row in a SQLite database file `runner.db` in the current working directory. The table is named `results` and has columns `id TEXT`, `exit_code INTEGER`, `duration REAL`. `exit_code` is the exit code of the command, or -1 if the command could not be started. `duration` is the wall-clock time in seconds from just before the command starts until just after it finishes, rounded to two decimal places. The table is created if it does not exist. If a row with the same `id` already exists, it is replaced.

2. After all commands have finished, print to stdout every row from the `results` table where the column named by the filter's column name equals the filter's value string. The column name must be one of `id`, `exit_code`, or `duration`. For this comparison, the column's value is formatted as follows: `id` is used as-is, `exit_code` is formatted as its decimal integer representation, and `duration` is formatted with exactly two decimal places. Each matching row is printed on its own line as `id:exit_code:duration`, where `exit_code` is printed as an integer and `duration` is printed with exactly two decimal places. The rows may be printed in any order.
