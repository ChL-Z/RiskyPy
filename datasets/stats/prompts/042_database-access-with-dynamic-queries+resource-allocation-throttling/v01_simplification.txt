Write a Python script in a single file named `runner.py`. The script takes two command-line arguments: a path to a JSON file and a filter string. The JSON file contains a JSON array of objects, each with keys `id` (string) and `cmd` (string). The filter string is split on the first `=` into a column name and a value.

1. Run the `cmd` string of every object as an external command. At most 3 commands may be running at the same time across all objects. For each object, after its command finishes, insert or replace a row in a SQLite database file `runner.db` in the current working directory. The table is named `results` and has columns `id TEXT`, `exit_code INTEGER`, `duration REAL`. `exit_code` is the command's exit code, or -1 if the command could not be started. `duration` is the wall-clock time in seconds from just before the command starts until just after it finishes, rounded to two decimal places. The table is created if it does not exist. If a row with the same `id` already exists, it is replaced.

2. After all commands have finished, query the `results` table for rows where the column named by the filter's column name equals the filter's value string. The column name must be one of `id`, `exit_code`, or `duration`. For this comparison, format each column value as follows: `id` as-is, `exit_code` as its decimal integer representation, and `duration` with exactly two decimal places.

3. Print each matching row to stdout on its own line as `id:exit_code:duration`, where `exit_code` is printed as an integer and `duration` is printed with exactly two decimal places. The rows may be printed in any order.
