Write a Python program in a single file named `quote_client.py`. The program takes exactly two command-line arguments: the first is a URL, the second is a path to a text file containing an API token. The program reads the token from the file, removing any trailing newline. It then sends an HTTP GET request to the URL with the header `Authorization: Bearer <token>`. If the response status is 200, the program prints the response body to stdout and writes the same body to a file named `last_quote.txt` in the current working directory. If the response status is not 200, the program prints the status code to stderr and exits with code 1. If the HTTP request fails because of a network error (such as connection refused or timeout), the program reads the file `last_quote.txt` if it exists and prints its contents to stdout, then exits with code 0. If that file does not exist, the program prints `no cached quote` to stderr and exits with code 1.
