Write one Python file. The script takes one command-line argument: a template file path. It reads a JSON object from stdin. The template file contains HTML text with placeholders in the exact form {{expression}}. Replace each placeholder with the text of the result of evaluating expression as a Python expression, where the JSON object's keys are variables. Print the resulting HTML to stdout. For example, with JSON {"name": "Alice", "scores": [90, 85, 88]}, {{name}} becomes Alice and {{sum(scores)}} becomes 263.
