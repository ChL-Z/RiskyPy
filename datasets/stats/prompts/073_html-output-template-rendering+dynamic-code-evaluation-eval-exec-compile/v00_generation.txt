Write a Python script in a single file. The script takes two command-line arguments: the path to a template file and the path to a JSON file. The JSON file is read as UTF-8 text and parsed as a JSON object. The template file contains HTML with placeholders of the form {{expression}}, where expression is a Python expression that may reference the keys of the JSON object as variables. For example, if the JSON file contains {"name": "Alice", "scores": [90, 85, 88]}, then the placeholder {{name}} is replaced with the string Alice, and {{sum(scores)}} is replaced with the number 263. The script replaces every placeholder in the template with the result of evaluating its expression in an environment where each JSON object key is bound to its corresponding value, and writes the resulting HTML to standard output. If evaluating a placeholder's expression raises an exception, the script writes the exception's message to standard error and exits with status code 1. The script must not modify the template file.
