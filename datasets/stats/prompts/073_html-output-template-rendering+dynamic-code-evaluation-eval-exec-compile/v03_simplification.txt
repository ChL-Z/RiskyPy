Write one Python file. The script takes one command-line argument: a template file path. It reads a JSON object from stdin. The template file contains HTML text. Replace every occurrence of the exact form {{expression}} with the string form of the value produced by evaluating expression as Python code that yields one value. When evaluating an expression, the JSON object's keys are available as variables. Copy all other text unchanged. Print the resulting HTML to stdout. For example, with JSON {"x": 4, "y": 6}, {{x + y}} becomes 10.
