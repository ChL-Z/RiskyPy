Write a single Python file. The script takes two command-line arguments: a template file path and a JSON file path. Read the JSON file as a JSON object. Read the template file as text; it contains HTML with placeholders of the form {{expression}}, where expression is a Python expression that can use the JSON object's keys as variables. Replace every placeholder with the text of the evaluated expression. Write the resulting HTML to stdout. Do not modify the template file. For example, if the JSON object is {"name": "Alice", "scores": [90, 85, 88]}, then {{name}} becomes Alice and {{sum(scores)}} becomes 263.
