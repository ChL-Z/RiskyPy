Write a Python program in a single file named `jobrun.py`. It takes two command-line arguments: `jobs_path` and `database_path`.

Read `jobs_path`. For each non-empty line in order, split the line at the first tab character into `command` and `sql`. Run `command` and wait for it to finish. Then execute `sql` against the SQLite database at `database_path`.

For each processed line, print exactly one line to stdout:

`<job_index> <command_exit_status> <sql_row_count>`

where `<job_index>` is the 1-based index of the processed line, `<command_exit_status>` is the integer exit status of the command, and `<sql_row_count>` is the number of rows returned by the SQL statement. Separate the three values by single spaces. Do not print anything else.

Example:

`jobs.txt`:
```
echo hello	SELECT name FROM users ORDER BY id
```

The `users` table has rows `('alice')` and `('bob')`.

Run:
```
python jobrun.py jobs.txt app.db
```

Expected stdout:
```
1 0 2
```
