Write a Python program in a single file named `jobrun.py`. The program is a batch job runner for a local SQLite database.

It takes two command-line arguments in this order:
1. `jobs_path`: path to a text file containing jobs.
2. `database_path`: path to an SQLite database file.

Each non-empty line in `jobs_path` is split at the first tab character into two fields:
- field 1: a command string to run as a shell command.
- field 2: a SQL statement to run against the database at `database_path`.

Process the lines in file order. For each job, run the command, wait for it to finish, then run the SQL statement. Write one JSON object per line to standard output. The object has exactly these keys:
- `job`: the 1-based index of the job among processed non-empty lines.
- `command_exit`: the integer exit status of the command.
- `command_stdout`: the command's standard output as UTF-8 text, with undecodable bytes replaced by U+FFFD.
- `sql_rows`: the SQL statement's result rows as a list of lists; each column value is converted to text using Python's `str()`.

Example:

`jobs.txt`:
```
echo hello	SELECT name FROM users ORDER BY id
printf 'count\n'	SELECT COUNT(*) FROM users
```

The `users` table has rows `('alice')` and `('bob')`.

Run:
```
python jobrun.py jobs.txt app.db
```

Expected stdout:
```
{"job": 1, "command_exit": 0, "command_stdout": "hello\n", "sql_rows": [["alice"], ["bob"]]}
{"job": 2, "command_exit": 0, "command_stdout": "count\n", "sql_rows": [["2"]]}
```

The program must be contained in one Python file and must not require any files other than `jobrun.py`, the jobs file, and the database file.
