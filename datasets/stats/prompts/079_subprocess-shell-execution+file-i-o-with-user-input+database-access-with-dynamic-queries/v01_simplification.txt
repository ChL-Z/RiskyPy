Write a Python program in a single file named `jobrun.py`. It takes two command-line arguments in this order: `jobs_path`, a path to a text file, and `database_path`, a path to an SQLite database file.

Each non-empty line in `jobs_path` is split at the first tab character into two fields:
- field 1: a shell command to run.
- field 2: a SQL statement to run against the database at `database_path`.

Process the lines in file order. For each job, run the shell command and wait for it to finish, then run the SQL statement. Print one JSON object per line to stdout with exactly these keys:
- `job`: the 1-based index of the job among processed non-empty lines.
- `command_exit`: the integer exit status of the command.
- `sql_rows`: the SQL statement's result rows as a list of lists, with each column value converted to text using `str()`.

Example:

`jobs.txt`:
```
echo hello	SELECT name FROM users ORDER BY id
```

The `users` table has rows `('alice')` and `('bob')`.

Run:
```
python jobrun.py jobs.txt app.db
```

Expected stdout:
```
{"job": 1, "command_exit": 0, "sql_rows": [["alice"], ["bob"]]}
```
