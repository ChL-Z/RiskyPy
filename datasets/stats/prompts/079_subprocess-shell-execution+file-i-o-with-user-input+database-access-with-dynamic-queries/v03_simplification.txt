Write a Python program in a single file named `jobrun.py`. It takes two command-line arguments: `jobs_path` and `database_path`.

Read `jobs_path` as text. For each line in order that is not empty, split the line at the first tab character into `command` and `sql`. Run `command` and wait for it to finish. Then execute `sql` against the SQLite database at `database_path`.

For each processed line, print one line to stdout: the 1-based index of the processed line, a single space, and the exit status of the command as an integer. Do not print anything else.
