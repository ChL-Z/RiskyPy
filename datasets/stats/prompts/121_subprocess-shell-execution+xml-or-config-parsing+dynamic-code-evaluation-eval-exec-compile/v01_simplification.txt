Write a single Python file. The program takes one command-line argument: the path to an XML file. The XML root element is `<tasks>`. Each direct child of `<tasks>` is a `<task>` element with a `name` attribute and two child elements, `<command>` and `<expr>`.

For each `<task>` in the order it appears in the XML file:
1. Run the text of `<command>` as a shell command and capture its standard output. Convert that output to an integer.
2. Evaluate the text of `<expr>` as an arithmetic expression with the variable `value` bound to that integer. The expression contains integer literals, the variable `value`, parentheses, and the operators `+` and `*`. It must produce an integer.
3. Print one line to standard output: `{name}: {result}`, where `{name}` is the task's `name` attribute and `{result}` is the expression result.

If the shell command exits with a non-zero status, its standard output cannot be converted to an integer, or the expression does not produce an integer, print `{name}: error` for that task instead.

Example XML file (`config.xml`):
```xml
<tasks>
  <task name="double">
    <command>echo 21</command>
    <expr>value * 2</expr>
  </task>
  <task name="increment">
    <command>echo 41</command>
    <expr>value + 1</expr>
  </task>
</tasks>
```

Running `python program.py config.xml` must produce:
```
double: 42
increment: 42
```
