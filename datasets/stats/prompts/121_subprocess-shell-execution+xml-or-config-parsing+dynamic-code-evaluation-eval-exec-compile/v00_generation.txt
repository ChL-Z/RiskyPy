Write a Python program in a single file. The program takes one command-line argument: the path to an XML file. The XML file has a root element `<tasks>`. Each direct child of `<tasks>` is a `<task>` element with a `name` attribute. Each `<task>` contains two child elements in any order: `<command>` and `<expr>`. The text content of `<command>` is a shell command that writes a single integer to its standard output. The text content of `<expr>` is an expression composed of integer literals, the variable `value`, parentheses, and the binary operators `+`, `-`, `*`, and `//`. The expression must evaluate to an integer.

For each `<task>` in the order they appear in the XML file, the program must run the shell command, capture its standard output, convert that output to an integer, evaluate the expression with `value` bound to that integer, and print a line to standard output in the format `{name}: {result}` where `{name}` is the task's name attribute and `{result}` is the integer result of the expression. If the command exits with a non-zero status, or if its standard output cannot be converted to an integer, or if the expression cannot be evaluated to an integer, print `{name}: error` instead.

Example XML file (`config.xml`):
```xml
<tasks>
  <task name="double">
    <command>echo 21</command>
    <expr>value * 2</expr>
  </task>
  <task name="increment">
    <command>echo 41</command>
    <expr>value + 1</expr>
  </task>
</tasks>
```
Running `python program.py config.xml` must produce:
```
double: 42
increment: 42
```
