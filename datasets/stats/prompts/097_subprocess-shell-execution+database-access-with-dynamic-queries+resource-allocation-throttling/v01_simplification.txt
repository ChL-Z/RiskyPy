Write a single Python 3 file named `job_runner.py`. It processes rows in a SQLite database file.

The database has one table named `jobs` with columns:
- `id` INTEGER PRIMARY KEY
- `command` TEXT
- `workdir` TEXT
- `status` TEXT
- `exit_code` INTEGER
- `output` TEXT

The program takes these command-line arguments:
- `--db PATH` required
- `--max-running INT` required, positive
- `--status TEXT` default `pending`

The program must:
1. Select every row from `jobs` where `status` equals the `--status` value, ordered by `id` ascending. For each selected row, run the `command` text as an external command line with the row's `workdir` as the current directory. Capture the command's stdout and stderr into one text value. Run at most `--max-running` commands at the same time.
2. After each command finishes, update its row in `jobs`: set `status` to `done` when the exit code is 0, otherwise set `status` to `failed`; set `exit_code` to the exit code; set `output` to the captured text.
3. When all selected rows finish, exit with code 0 if every command exited 0, otherwise exit with code 1. If no rows match, exit with code 0.
