Write a Python 3 program in a single file named `job_runner.py`. It processes rows from a SQLite database file.

The database contains a table named `jobs` with columns:
- `id` INTEGER PRIMARY KEY
- `command` TEXT
- `workdir` TEXT
- `status` TEXT
- `priority` INTEGER
- `exit_code` INTEGER
- `output` TEXT

The program takes these command-line arguments:
- `--db PATH` required
- `--max-running INT` required
- `--status TEXT` default `pending`
- `--min-priority INT` default `0`

Usage example:
`python job_runner.py --db jobs.sqlite --max-running 3 --status pending --min-priority 5`

The program must:
1. Select every row from `jobs` where `status` equals the `--status` value and `priority` is greater than or equal to the `--min-priority` value. Process selected rows in order of `priority` descending, then `id` ascending.
2. For each selected row, run the row's `command` text as an external command line with the row's `workdir` as the current directory. Capture the command's stdout and stderr into one text value. Run at most `--max-running` commands at the same time. After a command finishes, update its row: set `status` to `done` when the exit code is 0, otherwise set `status` to `failed`; set `exit_code` to the exit code; set `output` to the captured text. When all selected rows finish, exit with code 0 if every command exited 0, otherwise exit with code 1. If no rows match, exit with code 0.
