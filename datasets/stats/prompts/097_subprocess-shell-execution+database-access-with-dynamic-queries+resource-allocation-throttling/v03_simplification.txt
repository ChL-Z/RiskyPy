Write one Python file named `job_runner.py`. It processes rows in a SQLite database file.

The database has one table named `jobs` with columns:
- `id` INTEGER PRIMARY KEY
- `command` TEXT
- `status` TEXT
- `exit_code` INTEGER
- `output` TEXT

The program takes these command-line arguments:
- `--db PATH` required
- `--max-running INT` required, positive
- `--status TEXT` default `pending`

The program must:
1. Read every row from `jobs` where `status` equals the `--status` value, ordered by `id` ascending. Process the selected rows in groups of at most `--max-running` rows. For each group, run every row's `command` text as an external command line at the same time, wait for all commands in the group to finish, and capture each command's stdout and stderr together as one text value.
2. For each finished command, update its row in `jobs`: set `status` to `done` when the exit code is 0, otherwise set `status` to `failed`; set `exit_code` to the exit code; set `output` to the captured text.
3. Exit with code 0 if every selected command exited 0, or if no rows matched. Exit with code 1 if any selected command exited nonzero.
