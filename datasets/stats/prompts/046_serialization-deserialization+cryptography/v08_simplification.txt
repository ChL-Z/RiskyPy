Write a single Python file `signed_cache.py`. The program takes exactly three command-line arguments: the path to a document file, the path to a key file, and the path to a cache file.

Read the document file as UTF-8 text and the key file as raw bytes. Compute a tag equal to the lowercase hexadecimal representation of a cryptographic hash over the UTF-8 bytes of the document text followed by the key bytes. Write the cache file as UTF-8 text consisting of the tag, then a single newline character, then the document text.

Read the cache file back: treat everything before the first newline character as the stored tag, and everything after the first newline character as the stored document text. Recompute the tag from the stored document text and the key bytes using the same derivation. Print `OK` to stdout if the recomputed tag equals the stored tag; otherwise print `MISMATCH` to stdout.
