Write a single Python file named `signed_cache.py`. The file defines a command-line program with two subcommands: `sign` and `verify`.

`sign <document.json> <keyfile> <output.cache>`:
- Read the file at `<document.json>` as UTF-8 text.
- Read the file at `<keyfile>` as raw bytes.
- Compute a tag: a string of exactly 64 lowercase hexadecimal characters, derived from the UTF-8 bytes of the document text and the raw key bytes.
- Write `<output.cache>` as a UTF-8 JSON object with exactly two keys:
  - `"document"`: the document text as a JSON string.
  - `"tag"`: the tag string.

`verify <cachefile> <keyfile>`:
- Read `<cachefile>` as UTF-8 JSON. If it is not a JSON object with exactly the keys `"document"` and `"tag"`, or if `"document"` is not a string, or if `"tag"` is not a string of exactly 64 lowercase hexadecimal characters, print `MISMATCH` to stdout and exit with status 1.
- Read `<keyfile>` as raw bytes.
- Recompute the tag from the UTF-8 bytes of the `"document"` string and the raw key bytes using the same derivation as `sign`.
- If the recomputed tag equals the `"tag"` string, print `OK` to stdout and exit with status 0. Otherwise print `MISMATCH` to stdout and exit with status 1.
