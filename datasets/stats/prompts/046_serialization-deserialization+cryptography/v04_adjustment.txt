Write a single Python file `signed_cache.py` that provides a command-line program with two subcommands.

`sign <document.json> <keyfile> <output.cache>`
- Read `<document.json>` as UTF-8 text.
- Read `<keyfile>` as raw bytes.
- Compute a tag: the first 32 lowercase hexadecimal characters of the hexadecimal representation of the hash of the byte sequence formed by the UTF-8 bytes of the document text followed by the raw key bytes.
- Write `<output.cache>` as a UTF-8 text file containing a JSON object with exactly two keys: `"document"` whose value is the document text, and `"tag"` whose value is the tag string.

`verify <cachefile> <keyfile>`
- Read `<cachefile>` as a UTF-8 text file containing a JSON object and extract the `"document"` and `"tag"` string values.
- Read `<keyfile>` as raw bytes.
- Recompute the tag from the UTF-8 bytes of the `"document"` string followed by the raw key bytes using the same derivation as `sign`.
- Print `OK` to stdout if the recomputed tag equals the `"tag"` value; otherwise print `MISMATCH` to stdout.
