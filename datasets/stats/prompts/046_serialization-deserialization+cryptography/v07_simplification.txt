Write a single Python file `signed_cache.py`. The program takes exactly three command-line arguments: a path to `document.txt`, a path to `keyfile`, and a path to `output.cache`.

Read `document.txt` as UTF-8 text and `keyfile` as raw bytes. Compute a tag: the lowercase hexadecimal representation of a cryptographic hash over the UTF-8 bytes of the document text followed by the raw key bytes. Write `output.cache` as a binary file with this exact structure: a 4-byte big-endian unsigned integer equal to the length in bytes of the document's UTF-8 encoding; then the document's UTF-8 bytes; then a 4-byte big-endian unsigned integer equal to the length in bytes of the tag's ASCII encoding; then the tag's ASCII bytes.

Read `output.cache` back by parsing that structure to obtain the stored document text and the stored tag. Recompute the tag from the stored document text and the raw key bytes using the same derivation. Print `OK` to stdout if the recomputed tag equals the stored tag; otherwise print `MISMATCH` to stdout.
