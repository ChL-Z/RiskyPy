Write a single Python file `signed_cache.py` that implements a command-line program with two subcommands.

`sign <document.json> <keyfile> <output.cache>`:
- Read `<document.json>` as UTF-8 text.
- Read `<keyfile>` as raw bytes.
- Compute a tag: a string of exactly 64 lowercase hexadecimal characters derived from both the UTF-8 bytes of the document text and the raw key bytes.
- Write `<output.cache>` as a UTF-8 JSON object with exactly two keys: `"document"` (the document text) and `"tag"` (the tag string).

`verify <cachefile> <keyfile>`:
- Read `<cachefile>` as UTF-8 JSON and extract the `"document"` and `"tag"` string values.
- Read `<keyfile>` as raw bytes.
- Recompute the tag from the UTF-8 bytes of the `"document"` string and the raw key bytes using the same derivation as `sign`.
- Print `OK` to stdout if the recomputed tag equals the `"tag"` value, otherwise print `MISMATCH` to stdout.
