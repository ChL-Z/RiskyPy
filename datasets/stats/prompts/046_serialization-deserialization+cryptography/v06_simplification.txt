Write a single Python file `signed_cache.py` with two subcommands.

`sign <document.txt> <keyfile> <output.cache>`
- Read `<document.txt>` as UTF-8 text.
- Read `<keyfile>` as raw bytes.
- Compute a tag: the lowercase hexadecimal representation of a hash computed over the UTF-8 bytes of the document text followed by the raw key bytes.
- Write `<output.cache>` as a binary file that the `verify` subcommand can read back to obtain the document text and the tag.

`verify <cachefile> <keyfile>`
- Read `<cachefile>` written by `sign` and extract the document text and the tag.
- Read `<keyfile>` as raw bytes.
- Recompute the tag from the document text and the key bytes using the same derivation as `sign`.
- Print `OK` to stdout if the recomputed tag equals the extracted tag; otherwise print `MISMATCH` to stdout.
