Write a Python script named `cache_eval.py` in a single file.

The script reads one line from standard input, removes one trailing newline character if present, and uses the remaining text as `key`. It uses the environment variable `CACHE_PASS` and a cache file named `cache.dat` in the current working directory.

1. If `CACHE_PASS` is not set, print `ERROR` followed by a newline to standard output and exit with code 1. If `cache.dat` does not exist, start with an empty mapping from string keys to integer values. If `cache.dat` exists, load the mapping from it using `CACHE_PASS` as the passphrase. If the mapping cannot be loaded with that passphrase, print `ERROR` followed by a newline to standard output and exit with code 1.

2. If `key` is present in the mapping, print its integer value followed by a newline to standard output and exit with code 0. If `key` is not present and `key` consists only of decimal digit characters, let `value` be the integer represented by `key`, print `value` followed by a newline to standard output, and add the pair `key` -> `value` to the mapping. If `key` is not present and `key` does not consist only of decimal digit characters, print `ERROR` followed by a newline to standard output and exit with code 1.

3. If requirement 2 added a new key-value pair to the mapping, write the entire updated mapping to `cache.dat` in encrypted form that uses `CACHE_PASS` as the passphrase and can be loaded by this script when the same `CACHE_PASS` value is supplied. If requirement 2 did not add a new key-value pair, do not modify `cache.dat`.
