Write a single Python file named `cache_eval.py`.

The program reads one line from standard input, removes one trailing newline character if present, and uses the remaining text as `key`. It uses the environment variable `CACHE_PASS` and the file `cache.dat` in the current working directory. The cache is a mapping from string keys to integer values.

1. If `CACHE_PASS` is not set, print `ERROR` followed by a newline and exit with code 1. If `cache.dat` does not exist, use an empty mapping. If `cache.dat` exists, load the mapping from it using `CACHE_PASS` as the passphrase. If the mapping cannot be loaded with that passphrase, print `ERROR` followed by a newline and exit with code 1.

2. If `key` is in the mapping, print its integer value followed by a newline and exit with code 0. If `key` is not in the mapping and every character of `key` is from `0` through `9`, let `value` be the integer represented by `key`, print `value` followed by a newline, add the pair `key` -> `value` to the mapping, write the entire updated mapping to `cache.dat` in encrypted form using `CACHE_PASS` as the passphrase, and exit with code 0. If `key` is not in the mapping and any character of `key` is not from `0` through `9`, print `ERROR` followed by a newline and exit with code 1.
