Write a Python script `cache_eval.py` in a single file. The script reads one line from standard input, which is a string key. It uses a cache file named `cache.dat` in the current working directory.

The cache file stores a mapping from string keys to integer values. When the script runs, if `cache.dat` exists and the environment variable `CACHE_PASS` is set to the string that was used to write `cache.dat`, the script loads the mapping. If `cache.dat` does not exist or `CACHE_PASS` is not set to the correct string, the script prints `ERROR` to standard output and exits with code 1.

If the key read from standard input is present in the mapping, the script prints the corresponding integer value. If the key is not present, the script computes the value by evaluating the key as an arithmetic expression using only non-negative integers, parentheses, and the operators `+`, `-`, `*`, `/` (integer division). The script prints the resulting integer and adds the key-value pair to the mapping. After processing, if the mapping was modified, the script writes the updated mapping to `cache.dat` such that the file can only be read back by this script when `CACHE_PASS` is set to the same string.

If the key is not present and the expression cannot be evaluated, the script prints `ERROR` and exits with code 1.
