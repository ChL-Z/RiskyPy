Write a Python script named `cache_eval.py` in a single file.

The script reads one line from standard input, removes one trailing newline character if present, and uses the remaining text as `key`. It uses the environment variable `CACHE_PASS` and a cache file named `cache.dat` in the current working directory. Implement these three requirements:

1. Cache loading and startup: If `CACHE_PASS` is not set, print `ERROR` to standard output and exit with code 1. If `cache.dat` does not exist, start with an empty mapping from string keys to integer values. If `cache.dat` exists, attempt to load the mapping from it using `CACHE_PASS` as the passphrase. If the mapping cannot be loaded with that passphrase, print `ERROR` to standard output and exit with code 1.

2. Key resolution: If `key` is present in the mapping, print its integer value to standard output and exit with code 0. If `key` is not present, evaluate `key` as an arithmetic expression. The expression may contain only non-negative integer literals, spaces, parentheses, and the binary operators `+`, `-`, `*`, and `/`, where `/` performs integer division with the result rounded toward zero. If `key` is not a valid expression under this rule, print `ERROR` to standard output and exit with code 1. If it is valid, print the integer result to standard output and add the pair `key` -> result to the mapping.

3. Cache writing: If requirement 2 added a new key-value pair to the mapping, write the entire updated mapping to `cache.dat` in an encrypted form that uses `CACHE_PASS` as the passphrase and can be loaded by this script when the same `CACHE_PASS` value is supplied. If requirement 2 did not add a new key-value pair, do not modify `cache.dat`.
