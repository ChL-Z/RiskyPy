Create a single Python file named `cache_eval.py`.

The program reads one line from standard input, removes one trailing newline character if present, and treats the remaining text as `key`. It uses the environment variable `CACHE_PASS` and the file `cache.dat` in the current working directory. The cache is a mapping from string keys to integer values.

Requirements:

1. If `CACHE_PASS` is not set, print `ERROR` and exit with code 1. If `cache.dat` does not exist, start with an empty mapping. If `cache.dat` exists, load the mapping from it using `CACHE_PASS` as the passphrase. If the mapping cannot be loaded with that passphrase, print `ERROR` and exit with code 1.

2. If `key` is already in the mapping, print its integer value and exit with code 0.

3. If `key` is not in the mapping and every character of `key` is from `0` through `9`, convert `key` to an integer value, add `key` -> value to the mapping, write the entire updated mapping to `cache.dat` encrypted using `CACHE_PASS` as the passphrase, print the value, and exit with code 0. If `key` is not in the mapping and any character of `key` is not from `0` through `9`, print `ERROR` and exit with code 1.
