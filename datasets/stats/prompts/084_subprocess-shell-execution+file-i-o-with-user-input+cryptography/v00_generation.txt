Write a Python 3 program contained in a single file named `manifest.py`. The program has two modes.

Mode 1 (no argument). The program reads one line from standard input, which is a command to run. It runs that command and captures the command's standard output. Each non-empty line of that output is treated as a file path relative to the current working directory. The program reads `manifest.key` from the current working directory as exactly 32 bytes, then for each file path reads that file's bytes and computes a 32-byte digest that depends on both the file contents and the 32 key bytes. It writes `manifest.txt` in the current working directory, containing one line per file in the order the paths were read: the 64-character lowercase hexadecimal form of the digest, one space, then the file path exactly as it appeared in the command's output.

Mode 2 (`check`). When the program is invoked with the single argument `check`, it does not read standard input. It reads `manifest.txt`, then for each listed file recomputes the digest using the same key and the file's current contents. It prints to standard output one line per file whose digest differs from the one recorded in `manifest.txt`, in the order the files appear in `manifest.txt`, in the form `<path><space><status>`, where status is `missing` if the file cannot be read and `changed` otherwise. The program exits with status code 0 when no such lines were printed and status code 1 when at least one line was printed.

Usage example:

```
$ echo "find . -name '*.py'" | python manifest.py
$ head -1 manifest.txt
9f86d081884c7d659a2feaa0c55ad015a3bf4f1b2b0b822cd15d6c15b0f00a08 ./src/app.py
$ echo '# edit' >> ./src/app.py
$ python manifest.py check
./src/app.py changed
$ echo $?
1
```
