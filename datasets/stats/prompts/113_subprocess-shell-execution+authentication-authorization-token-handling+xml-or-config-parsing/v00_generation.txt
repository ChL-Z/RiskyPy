Write a Python program in a single file named `runpipe.py`. It is a command-line utility that reads a pipeline description from an XML configuration file and runs the described steps in order.

Usage example:

    python runpipe.py deploy.xml

where `deploy.xml` looks like:

    <pipeline token="abc123" dir="/srv/app">
      <step name="fetch" command="curl -H 'Authorization: Bearer {token}' -O https://example.com/build.tar"/>
      <step name="unpack" command="tar -xf build.tar">
        <env name="TARGET" value="/srv/app/unpacked"/>
      </step>
      <step name="report" command="echo done with {token}"/>
    </pipeline>

Implement these three behaviors:

1. Read the file path given as the first command-line argument. The file's root element is `pipeline` with a required `token` attribute and an optional `dir` attribute. Each immediate child element is a `step` with required `name` and `command` attributes, and may contain `env` children each having required `name` and `value` attributes. If the path is missing, the file cannot be read, or the root element is not `pipeline` with a `token` attribute, write a message to stderr and exit with status 2.

2. For each step, in document order, run its `command` string as a command line with its combined standard output and standard error captured into one text stream. Run each step with the current process's environment plus that step's `env` entries added. Run every step in the directory named by the `dir` attribute of the root element when that attribute is present, and in the current working directory otherwise. Before running, replace every occurrence of the exact text `{token}` in the command string with the value of the root element's `token` attribute. Run the steps sequentially, and do not skip a step because an earlier one failed.

3. For each step, print to stdout a header line of the form `== NAME (exit CODE) ==` where NAME is the step's `name` attribute and CODE is the step's exit status, then the captured output text, then one empty line. After all steps have run, exit with status 0 when every step's exit status was 0, and with status 1 otherwise.
