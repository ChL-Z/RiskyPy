Write a Python program in a single file named `runpipe.py`. It reads an XML pipeline description from the file path given as the first command-line argument, runs selected steps, and prints their results.

Usage:
    python runpipe.py deploy.xml

Example `deploy.xml`:

    <pipeline token="abc123" allowed="fetch,report">
      <step name="fetch" command="curl -H 'Authorization: Bearer {token}' -O https://example.com/build.tar"/>
      <step name="unpack" command="tar -xf build.tar"/>
      <step name="report" command="echo done with {token}"/>
    </pipeline>

Implement these three behaviors:

1. Read the file path in `sys.argv[1]`. The root element must be `pipeline` with required `token` and `allowed` attributes. Each immediate child element must be `step` with required `name` and `command` attributes. `allowed` is a comma-separated list of step names. If the path is missing, the file cannot be read, the root is not `pipeline`, `token` is missing, `allowed` is missing, or a child is not a `step` with `name` and `command`, write a message to stderr and exit with status 2.

2. For each `step` child in document order, if the step's `name` appears in the comma-separated `allowed` attribute, replace every exact occurrence of `{token}` in the step's `command` with the root element's `token` value, then run the resulting command line. Capture its combined stdout and stderr into one text stream. Run the allowed steps sequentially, and continue after a step exits with a nonzero status.

3. For each allowed step, print to stdout a header line `== NAME (exit CODE) ==`, then the captured output text, then one empty line. After all allowed steps have run, exit with status 0 when every run step's exit status was 0, and with status 1 otherwise.
