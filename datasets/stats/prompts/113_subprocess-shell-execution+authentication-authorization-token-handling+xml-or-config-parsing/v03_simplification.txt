Write a Python program in one file named `runpipe.py`. It reads one XML file path from the first command-line argument. The XML has a root `<pipeline>` with attributes `token_env` and `allowed`, and child `<step>` elements with attributes `name` and `command`. `allowed` is a comma-separated list of step names.

1. If the file cannot be read, the XML does not have that shape, or the environment variable named by `token_env` is unset, print an error message to stderr and exit with status 2.

2. For each `<step>` child in document order whose `name` is in `allowed`, run its `command` as a shell command line. The command's environment contains the variable named by `token_env` set to the value read from the existing environment. Capture combined stdout and stderr as one text stream. Continue to the next allowed step if a step exits nonzero.

3. For each run step, print to stdout `== NAME (exit CODE) ==`, then the captured output text, then one empty line. After all allowed steps, exit 0 if every run step exited 0, else exit 1.
