Write one Python file named `runpipe.py`. The program takes one XML file path as its first command-line argument. The XML root is `<pipeline>` with attribute `allowed`. `allowed` is a comma-separated list of step names. Child elements are `<step>` with attributes `name` and `command`. The program reads a token from environment variable `PIPELINE_TOKEN`.

1. Read the XML file. If reading fails or `PIPELINE_TOKEN` is unset, print an error to stderr and exit with status 2.

2. For each `<step>` in document order whose `name` is in `allowed`, run its `command` as a shell command line. The command's environment contains `PIPELINE_TOKEN` set to the value from the current environment. Capture combined stdout and stderr as one text stream. Continue to later allowed steps if a step exits nonzero.

3. For each run step, print to stdout `== NAME (exit CODE) ==`, then the captured text, then one empty line. After all allowed steps, exit 0 if every run step exited 0, else exit 1.
