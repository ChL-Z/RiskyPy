Write a Python script contained in a single file. The script is invoked as `python script.py <config_path>`, where `<config_path>` is the path to a JSON configuration file. The configuration file contains three keys: `command`, a list of strings; `inputs`, a list of strings; and `output_file`, a string path.

For each string in `inputs`, execute the command formed by the list in `command` followed by that string as the final argument. Capture the standard output, standard error, and exit status of each execution. If the command cannot be executed, record an exit status of -1 and place the error message in the standard error field.

Write to the path in `output_file` a JSON array where each element is an object with keys `input` (the input string), `stdout` (string), `stderr` (string), and `returncode` (integer). The elements must appear in the same order as the `inputs` list.

Example: given a configuration file `config.json`:

```json
{
  "command": ["wc", "-c"],
  "inputs": ["file1.txt", "file2.txt"],
  "output_file": "results.json"
}
```

Running `python script.py config.json` should produce `results.json` containing an array of two objects, each with the input filename, the output of `wc -c` for that file, any error output, and the exit status.
