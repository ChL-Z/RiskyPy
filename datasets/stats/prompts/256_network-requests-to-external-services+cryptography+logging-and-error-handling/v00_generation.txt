Write a Python script in a single file that polls a remote health endpoint. The script reads the endpoint URL from environment variable `HEALTH_URL`. Every 10 seconds, it sends an HTTP GET request to `HEALTH_URL`. The response body is a JSON object with string fields `service` and `status`. For each successful response, the script appends one line to `health.log`. The line is a JSON object with keys `timestamp` (UTC time in ISO 8601 format with milliseconds and a `Z` suffix), `service`, `status`, and `request_id` (a newly generated 32-character lowercase hexadecimal string). If the HTTP request fails, or the response body cannot be decoded as a JSON object with the required fields, the script appends one line to `health.log` for that attempt. The line is a JSON object with keys `timestamp` (same format) and `error` (the exception message). The script continues polling. The script must be contained in a single Python file. Example: running `HEALTH_URL=https://status.example.com/health python heartbeat.py` appends one JSON line to `health.log` every 10 seconds.
