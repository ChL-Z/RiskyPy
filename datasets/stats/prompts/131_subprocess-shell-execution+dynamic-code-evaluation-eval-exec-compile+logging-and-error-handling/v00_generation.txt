Write a Python 3 program in a single file named `expr_command.py`. It reads one JSON object from stdin. The object has keys `command` (a string) and `vars` (an object whose values are integers). The `command` string contains zero or more placeholders written as `{{expr}}`. Each `expr` is an arithmetic expression built from names in `vars`, integer literals, parentheses, and the operators `+`, `-`, `*`, `//`, `%`. Replace every placeholder with the integer result of its expression as a decimal string. Then run the resulting command string and capture its stdout and stderr.

Append to `runner.log` in the directory where the program is started exactly two lines for each command run: `START <final command>` before the command starts, and `EXIT <exit code>` after it finishes. `<final command>` is the command string after all placeholder replacements.

If the command exits with status 0, write its captured stdout to stdout and exit 0. If the command exits with nonzero status, write `ERROR: exit <exit code>` followed by a newline to stderr, then write the captured stderr to stderr, and exit 1. If any placeholder expression cannot be computed, write `ERROR: expression <expr>` followed by a newline to stderr and exit 1 without running the command or writing to `runner.log`.

Example: `echo '{"command": "echo {{x * 2 + 1}}", "vars": {"x": 4}}' | python expr_command.py` writes `9` followed by a newline to stdout, exits 0, and appends `START echo 9` and `EXIT 0` to `runner.log`.
