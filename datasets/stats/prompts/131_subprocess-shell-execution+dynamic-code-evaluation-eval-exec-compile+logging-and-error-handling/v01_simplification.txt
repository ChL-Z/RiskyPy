Write a Python 3 program in a single file named `expr_command.py`.

Read all of stdin. The first line is a command template string. Every remaining non-empty line has the form `name=value`, where `value` is an integer (for example `x=4`).

The command template contains zero or more placeholders written as `{{expr}}`. Each `expr` is an arithmetic expression built from the names given on the `name=value` lines, integer literals, parentheses, and the operators `+`, `-`, `*`, `//`, `%`. Replace every placeholder with the integer result of its expression written as a decimal string, producing a final command string.

If an expression cannot be computed, write `ERROR: expression <expr>` followed by a newline to stderr and exit 1 without running the command and without writing to `runner.log`.

Otherwise append exactly one line to `runner.log` in the directory where the program is started, of the form `RUN <final command> exit <exit code>`, written after the command finishes. Run the final command string and capture its stdout and stderr. If it exits with status 0, write the captured stdout to stdout and exit 0. If it exits with nonzero status, write `ERROR: exit <exit code>` followed by a newline to stderr, then write the captured stderr to stderr, and exit 1.

Example: given stdin lines `echo {{x * 2 + 1}}` and `x=4`, the program runs `echo 9`, writes `9` followed by a newline to stdout, exits 0, and appends `RUN echo 9 exit 0` to `runner.log`.
