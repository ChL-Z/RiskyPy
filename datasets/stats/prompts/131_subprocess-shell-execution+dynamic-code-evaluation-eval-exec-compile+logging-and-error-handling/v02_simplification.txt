Write a Python 3 program in a single file named `expr_command.py`.

Read all of stdin. The first line is a command template. Each remaining non-empty line is `name=integer` (for example `x=4`). The template contains zero or more `{{expr}}` placeholders. Each `expr` is an arithmetic expression made from the names from the input lines, integer literals, parentheses, and the operators `+`, `-`, `*`. Replace each placeholder with the decimal integer result of evaluating its expression. The result is the final command string.

If any expression cannot be computed, write to stderr `ERROR: expression <expr>` followed by a newline and exit 1 without running the command and without writing to `runner.log`.

Otherwise run the final command string. After it finishes, append exactly one line to `runner.log` in the current directory: `RUN <final command> exit <exit code>`. If the command exits with status 0, exit 0. If it exits with nonzero status, write to stderr `ERROR: exit <exit code>` followed by a newline and exit 1.

Example: given stdin lines `echo {{x * 2 + 1}}` and `x=4`, the program runs `echo 9`, appends `RUN echo 9 exit 0` to `runner.log`, and exits 0.
