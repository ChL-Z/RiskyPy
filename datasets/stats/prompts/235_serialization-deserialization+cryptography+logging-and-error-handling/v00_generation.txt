Write a Python 3 program in a single file named `kvstore.py` that provides a command-line cache for Python values.

The program supports exactly two commands:
- `python kvstore.py save KEY`: reads all of stdin as one Python literal, creates the directory `kvstore` if it does not exist, and writes an entry file at `kvstore/KEY`.
- `python kvstore.py load KEY`: reads the entry file at `kvstore/KEY` and writes to stdout a Python literal that evaluates to the stored object, followed by a newline.

Each entry file contains, in order: 16 bytes of tag, then the serialized object bytes. The tag is computed from the serialized object bytes and the value of the environment variable `KVSTORE_KEY`. On `load`, recompute the tag from the file's serialized object bytes and `KVSTORE_KEY`; if it does not match the stored tag, append an error line to `kvstore.log` and exit with status 1.

Append one line to `kvstore.log` for every `save` and `load` invocation. Each line must contain an ISO 8601 timestamp, the command, the key, and either `ok` or `error`, separated by spaces. If the entry file for `load` does not exist, or `save` cannot write the entry file, append an error line to `kvstore.log` and exit with status 1.

Example:
```
$ export KVSTORE_KEY='book-key'
$ echo "{'pages': 320, 'tags': ['history', 'paperback']}" | python kvstore.py save book:42
$ python kvstore.py load book:42
{'pages': 320, 'tags': ['history', 'paperback']}
```
