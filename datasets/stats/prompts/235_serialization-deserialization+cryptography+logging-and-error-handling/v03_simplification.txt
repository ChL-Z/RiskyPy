Write a single-file Python 3 program named `kvstore.py`. It supports exactly two command-line forms:

1. `python kvstore.py save KEY`
   - Read all of stdin as one JSON value.
   - Write the file `KEY.cache` in the current directory. The file contains a 16-byte tag followed by the JSON text of the value encoded as UTF-8 bytes.
   - The tag is computed from those JSON bytes and the value of the environment variable `KVSTORE_KEY`.
   - Append `save KEY ok` to `kvstore.log` and exit 0.

2. `python kvstore.py load KEY`
   - Read `KEY.cache`. The first 16 bytes are the tag; the remaining bytes are the JSON bytes.
   - Compute the tag from the remaining bytes and `KVSTORE_KEY`.
   - If the two tags are equal, write the remaining bytes to stdout followed by one newline, append `load KEY ok` to `kvstore.log`, and exit 0.

For either command, if `KVSTORE_KEY` is not set, if `save` cannot write `KEY.cache`, if `load` cannot read `KEY.cache`, or if a loaded tag does not match the computed tag, append `<command> KEY error` to `kvstore.log` and exit 1. `<command>` is `save` or `load`.
