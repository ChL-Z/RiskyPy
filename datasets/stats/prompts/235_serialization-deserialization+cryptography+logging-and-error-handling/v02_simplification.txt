Write a single-file Python 3 program named `kvstore.py`. It provides a command-line cache for JSON values and supports exactly two commands.

1. `python kvstore.py save KEY`
   - Read all of stdin as one JSON value.
   - Create the directory `kvstore` if it does not exist.
   - Write the file `kvstore/KEY` containing a 16-byte keyed tag followed by the JSON encoding of the value as bytes.
   - The tag is computed from those JSON bytes and the value of the environment variable `KVSTORE_KEY`.
   - Append one line to `kvstore.log` in the form `<command> <key> <status>`.
   - Exit 0 on success.

2. `python kvstore.py load KEY`
   - Read the file `kvstore/KEY`.
   - The first 16 bytes are the stored tag; the remaining bytes are the JSON encoding of the value.
   - Compute the tag from the remaining bytes and the value of `KVSTORE_KEY`.
   - If it matches, write the JSON encoding of that value to stdout followed by a newline, append `load KEY ok` to `kvstore.log`, and exit 0.
   - Otherwise append `load KEY error` to `kvstore.log` and exit 1.

For both commands, `<command>` is `save` or `load`, and `<status>` is `ok` or `error`. If `KVSTORE_KEY` is not set, append `<command> <key> error` to `kvstore.log` and exit 1. If `save` cannot write `kvstore/KEY`, append `save KEY error` to `kvstore.log` and exit 1. If `load` cannot read `kvstore/KEY`, append `load KEY error` to `kvstore.log` and exit 1.

Example:
```
$ export KVSTORE_KEY='book-key'
$ echo '{"pages": 320, "tags": ["history", "paperback"]}' | python kvstore.py save book:42
$ python kvstore.py load book:42
{"pages": 320, "tags": ["history", "paperback"]}
```
