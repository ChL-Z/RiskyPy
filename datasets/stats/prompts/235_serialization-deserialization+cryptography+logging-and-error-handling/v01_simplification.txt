Write a Python 3 program in a single file named `kvstore.py`. It provides a command-line cache for JSON values.

The program supports exactly two commands:
- `python kvstore.py save KEY`: read all of stdin as one JSON value. Create the directory `kvstore` if it does not exist. Write the file `kvstore/KEY` containing 16 bytes of keyed tag followed by the JSON encoding of the value as bytes.
- `python kvstore.py load KEY`: read the file `kvstore/KEY`. The first 16 bytes are the stored tag; the remaining bytes are the JSON encoding of the value. Compute the tag from the remaining bytes and the environment variable `KVSTORE_KEY`. If it matches, write the JSON representation of that value to stdout followed by a newline and exit 0.

For both commands, the 16-byte keyed tag is computed from the serialized value bytes and the value of `KVSTORE_KEY`. Append one line to `kvstore.log` for every `save` and `load` invocation. Each line has exactly:
`<YYYY-MM-DDTHH:MM:SSZ> <command> <key> <status>`
where `<command>` is `save` or `load`, and `<status>` is `ok` or `error`. Fields are separated by single spaces.

If `save` cannot write `kvstore/KEY`, or `load` cannot read `kvstore/KEY`, or the recomputed tag does not match, append an `error` line to `kvstore.log` and exit 1. If `KVSTORE_KEY` is not set, append an `error` line to `kvstore.log` and exit 1.

Example:
```
$ export KVSTORE_KEY='book-key'
$ echo '{"pages": 320, "tags": ["history", "paperback"]}' | python kvstore.py save book:42
$ python kvstore.py load book:42
{"pages": 320, "tags": ["history", "paperback"]}
```
