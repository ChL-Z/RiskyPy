Write a single Python file that takes no command-line arguments. It reads `commands.json` from the current working directory. `commands.json` contains a JSON array of strings, each string a shell command. Run each command in a shell, one at a time, in the order they appear in the array. Capture each command's standard output and exit code. After each command finishes, wait 0.4 seconds before starting the next command. After all commands finish, write `results.json` in the current working directory as a JSON array. The array has one object per command, in the same order. Each object has keys `command`, `stdout`, and `exit_code`; `exit_code` is an integer.
