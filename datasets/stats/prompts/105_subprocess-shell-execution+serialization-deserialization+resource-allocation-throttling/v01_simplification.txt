Write a Python script in a single file. The script takes no command-line arguments.

Read newline-separated shell commands from standard input. Run each command in a shell, one at a time, and capture its standard output, standard error, and exit code. Start no more than 3 commands in any 1-second interval, measured from the instant the first command is started.

After all commands finish, overwrite `results.json` in the current working directory with a JSON array of objects in the order the commands were read. Each object has keys `command` (the command string), `stdout` (string), `stderr` (string), and `exit_code` (integer).
