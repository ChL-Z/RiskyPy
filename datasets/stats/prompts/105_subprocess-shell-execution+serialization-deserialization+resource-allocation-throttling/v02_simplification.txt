Write a Python script in a single file. The script takes no command-line arguments.

Read newline-separated shell commands from standard input. Run each command in a shell, one at a time, and capture its standard output, standard error, and exit code. After each command finishes, wait 0.4 seconds before starting the next command.

After all commands finish, overwrite `results.json` in the current working directory with a JSON array. The array has one object per input command, in the order the commands were read. Each object has keys `command`, `stdout`, `stderr`, and `exit_code` (integer).
