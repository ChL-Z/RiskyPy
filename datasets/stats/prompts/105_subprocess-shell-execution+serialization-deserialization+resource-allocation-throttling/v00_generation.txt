Write a Python script in a single file. The script reads newline-separated shell commands from standard input. It executes each command sequentially in a shell, capturing the command's standard output, standard error, and exit code. The script enforces a rate limit: it must not start more than 3 commands in any 1-second interval, where the interval is measured from the instant the first command is started. After all commands have finished, the script writes a file named `results.json` in the current working directory. The file must contain a JSON array of objects, one per command, in the order the commands were read. Each object has keys: `command` (the original command string), `stdout` (string), `stderr` (string), and `exit_code` (integer). If the file already exists, it is overwritten. The script takes no command-line arguments.

Example: If standard input contains:
```
echo hello
ls /nonexistent
```
The script runs `echo hello`, waits as needed to respect the rate limit, runs `ls /nonexistent`, and then writes `results.json` with two objects.
