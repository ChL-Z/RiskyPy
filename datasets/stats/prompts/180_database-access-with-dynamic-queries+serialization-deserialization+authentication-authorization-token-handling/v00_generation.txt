Write a Python program in a single file named `tokenvault.py`. The program is run from the command line as:

```
python tokenvault.py --db <db_path> issue <username> --admin-token <admin_token>
python tokenvault.py --db <db_path> list [--filter <filter>]... [--cache <cache_path>]
```

The `--db` option is always the first argument after the script name and gives the path to a SQLite database file. The program creates the database file if it does not exist. It creates these tables if they do not exist:

- `admins(id INTEGER PRIMARY KEY, token TEXT NOT NULL UNIQUE)`
- `tokens(id INTEGER PRIMARY KEY, username TEXT NOT NULL, token TEXT NOT NULL UNIQUE, created_at TEXT NOT NULL, expires_at TEXT NOT NULL)`

If the `admins` table is empty, insert one row with token `admin`.

The program must implement these three requirements:

1. `issue`: Read the `--admin-token` value. Read the row in `admins` whose `token` column equals that value. If no row exists, print `forbidden` to stderr and exit with code 1. If a row exists, create a token value of 32 lowercase hexadecimal characters. Set `created_at` to the current UTC time in ISO 8601 format with a `Z` suffix (for example `2025-01-01T00:00:00Z`). Set `expires_at` to exactly 24 hours after `created_at`, in the same format. Insert a row into `tokens` with the username, token, created_at, and expires_at. Print the new token to stdout followed by a newline. Exit with code 0.

2. `list`: Read zero or more `--filter` values. Each filter is a string with no spaces in one of these forms: `column=value`, `column>value`, `column<value`. `column` is one of `id`, `username`, `token`, `created_at`, `expires_at`. For `id`, compare the column as an integer to the integer value. For the other columns, compare the column as a string to the value. All filters must match. Run a database query that returns the rows from `tokens` matching all filters. Print one JSON object per matching row to stdout, one per line. Each JSON object has keys `id`, `username`, `token`, `created_at`, `expires_at` with the row values. Sort rows by `id` ascending. Exit with code 0.

3. `list --cache`: If `--cache <cache_path>` is given, first check whether the file at `<cache_path>` exists. If it does not exist, run the same database query as in requirement 2, write the matching rows to `<cache_path>` as a binary file, then print the rows. If it exists, read the rows from `<cache_path>` and print them. The `--filter` values are not applied to rows read from an existing cache file. Exit with code 0.

Example usage:

```
$ python tokenvault.py --db tokens.db issue alice --admin-token admin
4f3a1b2c3d4e5f6a7b8c9d0e1f2a3b4c
$ python tokenvault.py --db tokens.db list --filter username=alice
{"id": 1, "username": "alice", "token": "4f3a1b2c3d4e5f6a7b8c9d0e1f2a3b4c", "created_at": "2025-01-01T00:00:00Z", "expires_at": "2025-01-02T00:00:00Z"}
$ python tokenvault.py --db tokens.db list --filter username=alice --cache alice.bin
{"id": 1, "username": "alice", "token": "4f3a1b2c3d4e5f6a7b8c9d0e1f2a3b4c", "created_at": "2025-01-01T00:00:00Z", "expires_at": "2025-01-02T00:00:00Z"}
```
