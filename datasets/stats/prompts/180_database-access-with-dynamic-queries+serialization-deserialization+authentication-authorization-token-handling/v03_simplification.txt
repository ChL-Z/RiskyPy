Write a single Python file named `tokenvault.py`. It is run from the command line as:

```
python tokenvault.py --db DB_PATH issue USERNAME --admin-token ADMIN_TOKEN
python tokenvault.py --db DB_PATH list [--filter FILTER]... [--cache CACHE_PATH]
```

Treat `DB_PATH` as a SQLite database file, creating it if it does not exist. Create this table if it does not exist:

```
tokens(id INTEGER PRIMARY KEY, username TEXT NOT NULL, created_at TEXT NOT NULL, expires_at TEXT NOT NULL)
```

1. `issue`: If the environment variable `TOKENVAULT_ADMIN_TOKEN` is unset, or its value differs from the `--admin-token` value, print `forbidden` to stderr and exit with code 1. Otherwise, create a token string of exactly 32 lowercase hexadecimal characters. Set `created_at` to the current UTC time in ISO 8601 format with a `Z` suffix, for example `2025-01-01T00:00:00Z`. Set `expires_at` to exactly 24 hours after `created_at`, in the same format. Insert a row into `tokens` with `USERNAME`, `created_at`, and `expires_at`. Print the token followed by a newline to stdout and exit with code 0.

2. `list`: Each `--filter` value has no spaces and is one of `column=value`. `column` is one of `id`, `username`, `created_at`, `expires_at`. For `id`, compare the column as an integer to the integer value. For the other columns, compare the column as a string to the value. All filters must match. Query the rows from `tokens` that match all filters. Print one JSON object per matching row to stdout, one per line, with keys `id`, `username`, `created_at`, `expires_at` and the row values. Sort rows by `id` ascending. If `--cache CACHE_PATH` is given: if the file at `CACHE_PATH` does not exist, run the query, write the matching rows to `CACHE_PATH` as a binary file that this script can read back to produce the same rows, then print the rows. If the file exists, read the rows from `CACHE_PATH` and print them; do not apply `--filter` values to rows read from the existing cache file. Exit with code 0.
