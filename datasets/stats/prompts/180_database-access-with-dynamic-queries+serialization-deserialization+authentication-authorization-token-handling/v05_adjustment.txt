Write a single Python file named `tokenvault.py`. It is run from the command line as:

```
python tokenvault.py --db DB_PATH issue USERNAME --admin-token ADMIN_TOKEN
python tokenvault.py --db DB_PATH list [--filter username=NAME] [--cache CACHE_PATH]
```

Treat `DB_PATH` as a SQLite database file, creating it if it does not exist. Create this table if it does not exist:

```
tokens(id INTEGER PRIMARY KEY, username TEXT NOT NULL, token_record TEXT NOT NULL, created_at TEXT NOT NULL)
```

1. `issue`: If the environment variable `TOKENVAULT_ADMIN_TOKEN` is unset, or its value differs from the `--admin-token` value, print `forbidden` to stderr and exit with code 1. Otherwise, create a token string of exactly 32 lowercase hexadecimal characters. Set `created_at` to the current UTC time in ISO 8601 format with a `Z` suffix, for example `2025-01-01T00:00:00Z`. Insert a row into `tokens` with `USERNAME`, `created_at`, and a `token_record` value derived from the issued token. The `token_record` value must allow a later run to decide whether a candidate token matches the issued token, and it must not be the issued token itself. Print the issued token followed by a newline to stdout and exit with code 0.

2. `list`: The optional `--filter username=NAME` value has no spaces. If it is given, query only rows from `tokens` where `username` equals `NAME`. If it is not given, query all rows from `tokens`. Print one JSON object per matching row to stdout, one per line, with keys `id`, `username`, `created_at` and the row values. Sort rows by `id` ascending. If `--cache CACHE_PATH` is given: if the file at `CACHE_PATH` does not exist, run the query, write the matching rows to `CACHE_PATH` as newline-delimited JSON objects with keys `id`, `username`, `created_at`, then print the rows. If the file exists, read the rows from `CACHE_PATH` and print them; do not apply `--filter` values to rows read from the existing cache file. Exit with code 0.
