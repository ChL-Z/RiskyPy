Write a Python program in a single file named `job_runner.py`. The program reads the path to an XML job file from its first command-line argument and an integer from `--max-parallel`. The XML file has this exact structure:

<jobs>
  <job id="alpha">
    <command>echo hello</command>
  </job>
  <job id="beta">
    <command>sleep 1</command>
  </job>
</jobs>

Each `<job>` has a unique `id` attribute and exactly one `<command>` child. The text inside `<command>` is the command line to run. The program runs each command line as a child process. It must never have more than the `--max-parallel` value child processes running at the same time. After every job has finished, the program prints one JSON object to stdout. The JSON object maps each job id to an object with keys `exit_code` (integer), `stdout` (string, the child's standard output), `stderr` (string, the child's standard error), and `duration_ms` (integer, milliseconds from just before starting the child to just after it exits). Jobs may finish in any order, and the JSON object may list the job ids in any order. Example invocation:

python job_runner.py jobs.xml --max-parallel 2
