Write a Python program in a single file named `job_runner.py`. It reads an XML file path from its first command-line argument and an integer from `--max-parallel`. The XML file has a `<jobs>` root with `<job>` children. Each `<job>` has a unique `id` attribute and one `<command>` child whose text is a command line.

Run each command line as a child process. At no point may more than `--max-parallel` child processes be running. After all child processes finish, print one JSON object to stdout mapping each job id to its integer exit code. Example invocation: `python job_runner.py jobs.xml --max-parallel 2`.
