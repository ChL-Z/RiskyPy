Create a Python program in a single file named `link_check.py`. The program takes one command-line argument: the path to a text file containing newline-separated absolute HTTP or HTTPS URLs. The program must:

1. For each URL in the order it appears, send an HTTP GET request with a 5-second timeout and with redirect following enabled. If the request completes, record the integer HTTP status code. If the request does not complete, record the string representation of the failure. The program must process every URL even when earlier URLs fail.

2. After processing all URLs, print to stdout one JSON object whose keys are the URL strings and whose values are objects with two keys: `status` (the integer HTTP status code, or `null` when the request did not complete) and `error` (the string representation of the failure, or `null` when the request completed).

3. Append to a file named `check.log` in the current working directory one line per URL, in the same order. Each line must have this exact format: `YYYY-MM-DDTHH:MM:SSZ <url> <status-or-error>` where the timestamp is the UTC moment the line is written, `<url>` is the exact URL string as it appeared in the input file, and `<status-or-error>` is either the integer status code or the literal text `ERROR: ` followed by the string representation of the failure. Create `check.log` if it does not exist; do not remove existing lines.

Example: running `python link_check.py urls.txt` where `urls.txt` contains:
https://example.com
https://httpbin.org/status/404
must print a JSON object with keys `https://example.com` and `https://httpbin.org/status/404`, and must append two lines to `check.log`.
