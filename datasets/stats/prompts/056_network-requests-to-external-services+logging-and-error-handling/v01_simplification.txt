Create a Python file named link_check.py. It reads one command-line argument: a path to a text file with one http or https URL per line. For each URL in the order it appears, send an HTTP GET request with a 5-second timeout. If the request completes, record the integer HTTP status code. If the request fails, record the error message string. Continue to the next URL after any failure.

After all URLs are processed, print to stdout one JSON object. Its keys are the URL strings exactly as read, and each value is either the integer status code or the error message string.

Also append to check.log in the current directory one line per URL, in the same order. Each line must start with the UTC timestamp in YYYY-MM-DDTHH:MM:SSZ format, then the URL, then either the integer status code or the error message string, separated by spaces. Create check.log if it does not exist and do not remove existing lines.
