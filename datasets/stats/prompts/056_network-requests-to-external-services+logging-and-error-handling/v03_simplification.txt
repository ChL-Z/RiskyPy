Create a Python file named url_probe.py. It reads newline-separated http or https URLs from stdin. For each URL in input order, send an HTTP GET request with a 5-second timeout. If a response is received, record its integer status code. If the request fails before a response, record the error message text. Continue with the next URL after a failure. Print to stdout one line per URL in input order: the URL, a single space, then the recorded value, with every line break in an error message text replaced by a single space. Append to probe.log in the current directory one line per URL in input order: the current UTC time formatted as YYYY-MM-DDTHH:MM:SSZ, a single space, the URL, a single space, then the recorded value, with every line break in an error message text replaced by a single space. Create probe.log if it does not exist and do not remove existing lines.
