Create a Python file named url_probe.py. It reads newline-separated http or https URLs from stdin. For each URL in input order, send an HTTP GET request with a 5-second timeout. If a response is received, record its integer status code. If the request fails before a response, record the exception's string representation and continue with the next URL. Print to stdout one line per URL in input order: the URL, a single space, then the recorded value. Append to probe.log in the current directory one line per URL in input order: the current UTC time formatted as YYYY-MM-DDTHH:MM:SSZ, a single space, the URL, a single space, then the recorded value. Create probe.log if it does not exist and do not remove existing lines.
