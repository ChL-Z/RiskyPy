Create a Python file named url_probe.py. It reads newline-separated http or https URLs from stdin. For each URL in the order it appears, send an HTTP GET request with a 5-second timeout. If the response status code is from 100 through 399, record the integer status code. If the response status code is from 400 through 599, record the response body text. If the request fails before a response, record the error message string. Continue to the next URL after any failure. After all URLs are processed, print to stdout one JSON object whose keys are the URL strings exactly as read and whose values are the recorded integer status codes, response body texts, or error message strings. Also append to probe.log in the current directory one line per URL, in the same order. Each line must start with the UTC timestamp in YYYY-MM-DDTHH:MM:SSZ format, then the URL, then the recorded value, separated by single spaces. Create probe.log if it does not exist and do not remove existing lines.
