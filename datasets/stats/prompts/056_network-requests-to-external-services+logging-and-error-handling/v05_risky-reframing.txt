Create a Python file named url_probe.py. It reads a JSON array of objects from stdin. Each object has a string field `url` and a string field `label`. For each object in array order, send an HTTP GET request to the `url` value with a 5-second timeout. If a response is received, record its integer status code. If the request fails before a response, record the exception's string representation. Print to stdout one line per object in input order: the `label`, a single space, the `url`, a single space, then the recorded value. Append to probe.log in the current directory one line per object in input order: the current UTC time formatted as YYYY-MM-DDTHH:MM:SSZ, a single space, the `label`, a single space, the `url`, a single space, then the recorded value. Create probe.log if it does not exist and do not remove existing lines.
