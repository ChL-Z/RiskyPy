Create a Python file named `url_probe.py`.

1. Read lines from stdin. Each line contains a `label`, one space, and a `url`.
2. For each line in input order, send an HTTP GET request to the `url` with a 5-second timeout. Record the HTTP status code as an integer if a response arrives; record the exception's string representation if the request fails before a response.
3. For each line in input order, print to stdout: the `label`, one space, and the recorded value. Append to `probe.log` in the current directory the same text, one line per input line. Create `probe.log` if it does not exist; keep existing lines.
