Write a Python program in a single file named `fetch.py`.

Invoke it as:

```
python fetch.py <urls-file> <out-dir> <log-file> <rate>
```

`<rate>` is a positive integer meaning requests per second.

Requirements:

1. Read `<urls-file>` as UTF-8 text; each non-empty line is one URL with surrounding whitespace stripped. For each URL in order, retrieve the resource at that URL and write the retrieved body bytes to `<out-dir>/0001.bin`, `<out-dir>/0002.bin`, and so on, where the number is the 1-based line index zero-padded to four digits. Create `<out-dir>` if it does not exist.

2. Between retrievals, wait until at least `1 / <rate>` seconds have passed since the previous retrieval started. The first retrieval has no preceding wait.

3. After each retrieval attempt, append one line to `<log-file>` (create it if it does not exist). Each line has three tab-separated fields: an ISO-8601 UTC timestamp `YYYY-MM-DDTHH:MM:SSZ`, the URL, and either `ok <byte_count>` or `error <message>`. After writing an error line, continue with the remaining URLs.
