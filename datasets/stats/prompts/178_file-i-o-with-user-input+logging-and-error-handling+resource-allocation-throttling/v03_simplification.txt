Write a Python program in a single file named `fetch.py`.

Run it as:

```
python fetch.py <urls_file> <out_dir> <log_file> <rate>
```

`<rate>` is a positive integer meaning retrievals per second.

1. Read `<urls_file>` as UTF-8 text. Each line after stripping surrounding whitespace is one URL; skip empty lines. For each URL in order, retrieve the resource at that URL and write its body bytes to `<out_dir>/1.bin`, `<out_dir>/2.bin`, and so on, using the 1-based URL number. Create `<out_dir>` if it does not exist.

2. Start each retrieval at least `1 / <rate>` seconds after the previous retrieval started. The first retrieval has no preceding wait.

3. After each retrieval attempt, append one line to `<log_file>`, creating it if it does not exist. Each line has three tab-separated fields: an ISO-8601 UTC timestamp `YYYY-MM-DDTHH:MM:SSZ`, the URL, and either `ok <byte_count>` or `error <message>`. After an error line, continue with the remaining URLs.
