Write a Python program in a single file named `access_check.py`.

1. Input and output: The program takes one command-line argument: the path to a SQLite database file. It reads lines from standard input. Each non-empty line contains three tab-separated fields: `token`, `resource`, and `context_json`. `context_json` is a JSON object whose values are strings, numbers, or booleans. For each non-empty input line, print exactly one output line to standard output.

2. Token and rule lookup: The database has two tables: `tokens(token TEXT, user TEXT, expires_at TEXT)` and `rules(id TEXT, user TEXT, resource_pattern TEXT, condition TEXT, priority INTEGER)`. For an input `token`, find the row in `tokens` whose `token` column equals the input token. If no such row exists, or if its `expires_at` is less than or equal to the current UTC time written as an ISO 8601 string such as `2099-12-31T23:59:59Z`, print `DENY no_token`. Otherwise, among rows in `rules` where `user` equals the token row's user and `resource_pattern` equals the input `resource`, choose the row with the smallest `priority`; if multiple rows have that smallest priority, choose the row with the lexicographically smallest `id`. If no such row exists, print `DENY no_rule`.

3. Condition result: If a rule was chosen, evaluate its `condition` text as a Python expression with variables `user` (the token row's user), `resource` (the input resource), and `ctx` (the parsed `context_json` object). If the result is truthy, print `ALLOW <rule id>` using the chosen rule's `id`. Otherwise, print `DENY condition_false`.
