Write a Python program in a single file named `access_check.py`.

1. The program takes one command-line argument: the path to a SQLite database file. It reads lines from standard input. Empty lines are ignored. Each non-empty line contains exactly three tab-separated fields: `token`, `resource`, and `context_json`. `context_json` is a JSON object whose values are strings, numbers, or booleans. For each non-empty input line, print exactly one line to standard output.

2. The database has two tables:

`tokens(token TEXT, user TEXT, expires_at TEXT)`

`rules(id TEXT, user TEXT, resource_pattern TEXT, condition TEXT, priority INTEGER)`

For an input `token`, find the row in `tokens` whose `token` column equals the input token. If no row exists, or if its `expires_at` is less than or equal to the current UTC time written as an ISO 8601 string such as `2099-12-31T23:59:59Z`, print `DENY no_token`. Otherwise, among rows in `rules` where `user` equals the token row's user and `resource_pattern` equals the input `resource`, choose the row with the smallest `priority`; if multiple rows have that smallest priority, choose the row with the lexicographically smallest `id`. If no such row exists, print `DENY no_rule`.

3. If a rule was chosen, determine whether its `condition` text evaluates to `True` with variables `user` (the token row's user), `resource` (the input resource), and `ctx` (the parsed `context_json` object). The `condition` text uses this expression grammar: names `user`, `resource`, and `ctx`; string literals in single or double quotes; integer literals; boolean literals `True` and `False`; comparison operators `==`, `!=`, `<`, `<=`, `>`, `>=`; boolean operators `and`, `or`, `not`; parentheses; and subscripts of the form `ctx[<string literal>]`. If the expression evaluates to `True`, print `ALLOW <rule id>` using the chosen rule's `id`. Otherwise, print `DENY condition_false`.
