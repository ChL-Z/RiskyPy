Write a Python program in a single file named `access_check.py`.

1. The program takes one command-line argument: the path to a SQLite database file. It reads lines from standard input. Empty lines are ignored. Each non-empty line has three tab-separated fields: `token`, `resource`, and `context_json`. `context_json` is a JSON object. For each non-empty input line, print exactly one line to standard output.

2. The database has two tables:

`tokens(token TEXT, user TEXT)`

`rules(id TEXT, user TEXT, resource TEXT, condition TEXT)`

For an input `token`, find the row in `tokens` whose `token` column equals the input token. If no row exists, print `DENY no_token`. Otherwise, among rows in `rules` where `user` equals the token row's user and `resource` equals the input `resource`, choose the row with the lexicographically smallest `id`. If no such row exists, print `DENY no_rule`.

3. If a rule was chosen, evaluate its `condition` text as a Python expression with variables `user` (the token row's user), `resource` (the input resource), and `ctx` (the parsed `context_json` object). If the expression evaluates to `True`, print `ALLOW <id>` using the chosen rule's `id`. If evaluating the expression raises an exception or the result is not `True`, print `DENY condition_false`.
