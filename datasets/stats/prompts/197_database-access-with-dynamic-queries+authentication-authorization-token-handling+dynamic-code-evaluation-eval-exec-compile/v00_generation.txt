Write a Python program contained in a single file named `access_check.py`. The program takes one command-line argument: the path to a SQLite database file. It reads lines from standard input. Each non-empty line is tab-separated into three fields: `token`, `resource`, and `context_json`. `context_json` is a JSON object whose values are strings, numbers, or booleans.

The database has two tables:
`tokens` with columns `token` (TEXT), `user` (TEXT), `expires_at` (TEXT). `expires_at` is an ISO 8601 UTC timestamp string such as `2099-12-31T23:59:59Z`.
`rules` with columns `id` (TEXT), `user` (TEXT), `resource_pattern` (TEXT), `condition` (TEXT), `priority` (INTEGER).

For each input line, produce one output line. If `token` is not present in `tokens`, or its `expires_at` is less than or equal to the current UTC time in the same ISO 8601 format, print `DENY no_token`. Otherwise, find the matching rule with the smallest `priority` among rows where `rules.user` equals the token's `user` and `rules.resource_pattern` matches the entire `resource` string. A `*` in `resource_pattern` matches any sequence of characters, including an empty sequence. If two matching rules have the same smallest `priority`, use the one whose `id` is lexicographically smallest. If no rule matches, print `DENY no_rule`. If a rule matches, evaluate its `condition` text as a Python expression. The expression may use the variables `user`, `resource`, and each key from `context_json`. If the result is truthy, print `ALLOW <rule id>`; otherwise print `DENY condition_false`.

Example database contents:
`tokens`: row (`tok123`, `alice`, `2099-12-31T23:59:59Z`)
`rules`: row (`r1`, `alice`, `/projects/42/*`, `hour >= 9`, `5`)

Running:
`printf 'tok123\t/projects/42/edit\t{"hour": 14}\n' | python access_check.py policy.db`
prints:
`ALLOW r1`
