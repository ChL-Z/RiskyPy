Write a Python program in one file named `exprreport.py`.

It reads one command-line argument: the path to an XML configuration file. The root element is `<report>` and it contains `<field>` child elements in document order. Each `<field>` has two string attributes: `name` and `expr`.

Process the `<field>` elements in document order. Each `expr` is an arithmetic expression using integer or decimal numeric literals, the operators `+`, `-`, `*`, `/`, parentheses, and names of earlier `<field>` elements. Evaluate each `expr` using the numeric values already recorded for earlier field names. If a name has no recorded value, or if the expression does not produce a number, record no value for that field. For every field, write exactly one line to stderr: `INFO <name> <value>` when a value was recorded, or `ERROR <name>` when no value was recorded.

After processing all fields, write to stdout one JSON object mapping each recorded field name to its numeric value. Write nothing else to stdout. Exit with status 0 if at least one field value was recorded, and status 1 if no field value was recorded.
