Write a Python program in a single file named `exprreport.py`.

It takes one command-line argument: the path to an XML configuration file. The file's root element is `<report>`. It contains one or more `<field>` child elements. Each `<field>` has a `name` attribute and an `expr` attribute. Both are strings. Fields are in dependency order: an `expr` may use names of fields that appear before it. An `expr` is an arithmetic expression using integer or decimal numeric literals, the operators `+`, `-`, `*`, `/`, parentheses, and names of earlier fields.

Process the `<field>` elements in document order. For each field, compute the numeric value of its `expr` using values already recorded for earlier field names. If a name has no recorded value, or the expression does not produce a number, record no value for that field and continue with the next field. For every field, write exactly one log message to stderr: level INFO if the field value was recorded, level ERROR if it was not.

After processing all fields, write to stdout one JSON object mapping each recorded field name to its computed numeric value. Write no other output to stdout. Exit with status 0 if at least one field value was recorded, and status 1 if no field value was recorded.
