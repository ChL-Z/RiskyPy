Write a Python program contained in a single file named `exprreport.py`.

The program takes one command-line argument: the path to an XML configuration file. The XML file has a root element `<report>` containing one or more `<field>` elements as direct children. Each `<field>` has a `name` attribute (a string) and an `expr` attribute (a string). Fields appear in dependency order: the expression of a field may refer to the names of fields that appear earlier in the document.

Example configuration file `sample.xml`:

```xml
<report>
  <field name="width" expr="4"/>
  <field name="height" expr="7"/>
  <field name="area" expr="width * height"/>
  <field name="perimeter" expr="2 * (width + height)"/>
</report>
```

An `expr` value is an arithmetic expression composed of integer and decimal numeric literals, the operators `+`, `-`, `*`, `/`, `//`, `%`, `**`, parentheses, and names of fields defined earlier in the document.

For each `<field>` in document order, the program computes the numeric value of its `expr` and records it under the field's `name`. When a field references a name that has no recorded value, or when the expression cannot be evaluated to a number, the program records no value for that field.

The program logs to stderr one message per field: at level INFO when the field was recorded successfully, and at level ERROR when it was not. Field processing continues after a failure.

After processing every field, the program writes to stdout a single JSON object mapping each recorded field name to its computed numeric value, with no extra output.

The program exits with status 0 if at least one field was recorded, and with status 1 if no field was recorded.
