Write a Python program contained in a single file named `build_watch.py`. The program runs once when invoked and takes the path to a JSON configuration file as its first command-line argument. The JSON object has exactly these string keys: `url`, `command`, `state_path`, and `log_path`.

The program must satisfy these requirements:

1. Read the configuration file. Send an HTTP GET request to `url` with a 10-second timeout. The response status must be 200, and the response body must be a JSON object with a string field named `build_id`. Read the current contents of `state_path` as raw text. If `state_path` does not exist, or its contents differ from `build_id`, execute `command` as a shell command and wait for it to complete. If the command exits with status 0, write `build_id` to `state_path`. If the command exits with a nonzero status, log an error and exit with status 1.

2. Append one line to `log_path` and print the same line to stdout for each run. Each line must begin with a UTC timestamp in ISO 8601 format followed by a space, then one of `CHANGED`, `SAME`, or `ERROR`, followed by a space, then a message. For `CHANGED`, the message is `old=<old> new=<new>`, where `<old>` is `none` when `state_path` did not exist and `<new>` is the new `build_id`. For `SAME`, the message is `build_id=<build_id>`. For `ERROR`, the message is the error text.

3. If the configuration file is missing, cannot be read, is not valid JSON, is missing any required key, or if the HTTP request fails, returns a status other than 200, or the response body is not a JSON object containing a string `build_id`, log an `ERROR` line and exit with status 1.

Usage example:

```
python build_watch.py config.json
```

Example `config.json`:

```json
{
  "url": "https://example.com/api/build",
  "command": "python refresh_cache.py",
  "state_path": "last_build_id.txt",
  "log_path": "build_watch.log"
}
```

Example log lines:

```
2025-02-14T12:00:00Z SAME build_id=42
2025-02-14T12:05:00Z CHANGED old=42 new=43
2025-02-14T12:10:00Z ERROR HTTP status 500
```
