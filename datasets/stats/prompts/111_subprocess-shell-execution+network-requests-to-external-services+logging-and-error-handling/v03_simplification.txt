Write a Python program in a single file named `build_watch.py`. It is invoked once as `python build_watch.py CONFIG_PATH`. `CONFIG_PATH` is a JSON file whose object has string keys `url`, `command`, `state_path`, and `log_path`.

1. Read `CONFIG_PATH`. If reading fails, the JSON is invalid, or a required key is missing or is not a string, print an `ERROR` line to stdout only and exit with status 1.

2. Send an HTTP GET request to `url` with a 10-second timeout. The response status must be 200, and the response body must be a JSON object with a string field named `build_id`. Read `state_path` as text if it exists. If `state_path` does not exist, or its full contents differ from `build_id`, run `command` and wait for it to finish. If the command exits with status 0, write `build_id` to `state_path` as the full file contents. If the command exits with nonzero status, treat it as an error.

3. After `CONFIG_PATH` has been read, append exactly one line to `log_path` and print the same line to stdout. The line must be:

`YYYY-MM-DDTHH:MM:SSZ TAG MESSAGE`

where the timestamp is the current UTC time in ISO 8601 format ending with `Z`. `TAG` is `CHANGED` when the command ran and exited with status 0, `SAME` when the command did not run because `state_path` already contained `build_id`, or `ERROR` when a step failed. `MESSAGE` is:
- for `CHANGED`: `old=<old> new=<new>`, where `<old>` is `none` when `state_path` did not exist, and `<new>` is `build_id`;
- for `SAME`: `build_id=<build_id>`;
- for `ERROR`: a one-line failure description with no newline characters.

If `log_path` cannot be written, print the line to stdout and exit with status 1. For any failure after `CONFIG_PATH` is read, use the `log_path` line rule above and exit with status 1.
