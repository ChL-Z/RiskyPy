Write a Python program in a single file named `build_watch.py`. The program runs once when invoked and takes the path to a JSON configuration file as its first command-line argument. The JSON object has string keys `url`, `command`, `state_path`, and `log_path`; each required key must be present with a string value. The object may contain other keys.

1. Load the configuration file. Send an HTTP GET request to `url` with a 10-second timeout. The response status must be 200, and the response body must be a JSON object with a string field named `build_id`. Read the current contents of `state_path` as raw text. If `state_path` does not exist, or its contents differ from `build_id`, run `command` as a shell command and wait for it to complete. If the command exits with status 0, write `build_id` to `state_path` as the full file contents. If the command exits with nonzero status, emit an `ERROR` line and exit with status 1.

2. For a run where the configuration file was loaded, append one line to `log_path` and print the same line to stdout. The line must be:

`YYYY-MM-DDTHH:MM:SSZ TAG MESSAGE`

where the timestamp is the current UTC time in ISO 8601 format ending with `Z`, `TAG` is `CHANGED`, `SAME`, or `ERROR`, and `MESSAGE` is:

- for `CHANGED`: `old=<old> new=<new>`, where `<old>` is `none` when `state_path` did not exist and `<new>` is the new `build_id`;
- for `SAME`: `build_id=<build_id>`;
- for `ERROR`: a description of the failure that contains no newline characters.

If `log_path` cannot be written, print the line to stdout and exit with status 1. For a run where the configuration file was not loaded, print the `ERROR` line to stdout only and exit with status 1.

3. Emit an `ERROR` line and exit with status 1 when: the configuration file is missing, cannot be read, is not valid JSON, or is missing a required key with a string value; the HTTP request fails, returns a status other than 200, or the response body is not a JSON object containing a string `build_id`; `state_path` exists but cannot be read; `state_path` cannot be written after a successful command; the command cannot be started or exits with nonzero status. For failures after the configuration file was loaded, use `log_path` as in requirement 2. For failures before the configuration file was loaded, print the `ERROR` line to stdout only.

Usage example:

```
python build_watch.py config.json
```

Example `config.json`:

```json
{
  "url": "https://example.com/api/build",
  "command": "python refresh_cache.py",
  "state_path": "last_build_id.txt",
  "log_path": "build_watch.log"
}
```

Example log lines:

```
2025-02-14T12:00:00Z SAME build_id=42
2025-02-14T12:05:00Z CHANGED old=42 new=43
2025-02-14T12:10:00Z ERROR HTTP status 500
```
