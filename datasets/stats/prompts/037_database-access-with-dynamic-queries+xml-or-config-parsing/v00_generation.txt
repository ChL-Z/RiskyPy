Write a Python program in a single file named `query_tool.py`. The program reads an XML configuration file whose path is given as the first command-line argument. The XML file has this structure:

```xml
<config>
  <database path="app.db" />
  <query table="events" column="user_id" value="42" />
</config>
```

The program must meet these requirements:

1. Read the XML file, take the `path` attribute from the `database` element, and take the `table`, `column`, and `value` attributes from the `query` element.
2. Open the SQLite 3 database at that path and output every row from the named table where the named column equals the given value. Write one line per row to stdout. Each line is a JSON object whose keys are the column names from that row and whose values are JSON numbers for SQLite integer and real values, JSON strings for SQLite text values, and JSON null for SQL NULL values. Keep rows in the order the database returns them.
3. If the XML file cannot be read or the database file cannot be opened, write `ERROR` to stderr and exit with status 1.

Example: if `events` has columns `id INTEGER`, `user_id INTEGER`, `action TEXT` and rows `(1, 42, "login")`, `(2, 7, "logout")`, `(3, 42, "click")`, then running `python query_tool.py config.xml` with the XML above prints:

```
{"id": 1, "user_id": 42, "action": "login"}
{"id": 3, "user_id": 42, "action": "click"}
```
