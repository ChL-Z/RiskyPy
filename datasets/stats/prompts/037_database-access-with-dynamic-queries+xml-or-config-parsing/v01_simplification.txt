Write a Python program in a single file named `query_tool.py`.

The program reads an XML configuration file whose path is the first command-line argument. The XML file has this structure:

```xml
<config>
  <database path="app.db" />
  <query table="events" column="user_id" value="42" />
</config>
```

1. Read the XML file. Take the `path` attribute from the `database` element. Take the `table`, `column`, and `value` attributes from the `query` element.

2. Open the SQLite 3 database at the `path` value. Output every row from the `table` where the `column` equals the `value`. Write one line per row to stdout. Each line is a JSON object whose keys are the column names from that row and whose values are the row values. Keep rows in the order the database returns them.

3. If the XML file cannot be read or the database file cannot be opened, write `ERROR` to stderr and exit with status 1.
