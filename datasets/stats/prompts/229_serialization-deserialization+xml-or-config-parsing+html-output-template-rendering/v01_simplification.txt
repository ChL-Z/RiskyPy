Write a Python program in a single file named `render_report.py`.

Run it as:

```
python3 render_report.py config.xml
```

The input file is XML. Its root element is `<report>` with a `title` attribute. It contains zero or more `<row>` elements, each with `label` and `amount` attributes. Example:

```xml
<report title="Q3 Totals">
  <row label="Alpha" amount="12.5"/>
  <row label="Beta &amp; Co" amount="7"/>
  <row label="Gamma" amount="0"/>
</report>
```

The program does two things:

1. Write to stdout an HTML document. It contains an `<h1>` whose visible text is the `title` attribute, then a `<table>`. The first table row has two cells with visible text `Label` and `Amount`. Each `<row>` becomes one table row in the same order as in the XML. The first cell's visible text is that row's `label` attribute. The second cell's visible text is that row's `amount` attribute written with two digits after the decimal point. For example, `label="Beta &amp; Co"` must display as `Beta & Co`, and `amount="7"` must display as `7.00`.

2. Write a JSON file in the same directory as the XML file. If the XML file name ends with `.xml`, replace that suffix with `.json`. The JSON file contains one object with keys `"title"` and `"rows"`. `"title"` is a string. `"rows"` is an array in the same order as the XML rows. Each element is an object with keys `"label"` (string) and `"amount"` (number). For the example above, the JSON is:

```json
{"title": "Q3 Totals", "rows": [{"label": "Alpha", "amount": 12.5}, {"label": "Beta & Co", "amount": 7.0}, {"label": "Gamma", "amount": 0.0}]}
```
