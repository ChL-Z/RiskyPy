Write a Python program in a single file named `run_recipes.py`. It is run as `python3 run_recipes.py <xml-path> <html-path>`.

Read the XML file at `<xml-path>`. Its root element is `<recipes>`. Process each `<recipe>` child element in document order. Each `<recipe>` has a `name` attribute and one `<command>` child element. The text inside `<command>` is an executable name followed by zero or more arguments separated by single spaces; it contains no quoting or shell metacharacters. Remove leading and trailing whitespace from that text, run it as an external command, and capture its standard output and exit status.

Write an HTML file to `<html-path>` containing a `<title>` element with text `Recipe Run Report`, an `<h1>` element with text `Recipe Run Report`, and a `<table>`. The table has a header row with cells `Recipe`, `Exit Code`, and `Output`, followed by one row per `<recipe>` in the same order. Each row contains the recipe name, the exit status as a decimal integer, and the captured standard output. The recipe name and captured standard output must appear as text content of their cells, so the characters `<`, `>`, and `&` are displayed as themselves. The program exits with status 0 after writing the HTML file.
