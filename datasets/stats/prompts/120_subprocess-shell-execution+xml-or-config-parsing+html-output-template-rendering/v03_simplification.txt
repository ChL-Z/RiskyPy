Write a Python program in a single file named `run_recipes.py`. Run it as `python3 run_recipes.py <xml-path> <html-path>`.

Read the XML file at `<xml-path>`. Its root element is `<recipes>`. For each `<recipe>` child in document order, read its `name` attribute and the text of its single `<command>` child. Trim leading and trailing whitespace from the command text, run that text as an external command, and capture its stdout and exit code. The command text contains an executable name followed by zero or more arguments separated by single spaces, with no quoting.

Write an HTML file to `<html-path>` containing a `<title>` element with text `Recipe Run Report`, an `<h1>` element with text `Recipe Run Report`, and a `<table>`. The table must have a header row with cells `Recipe`, `Exit Code`, and `Output`, then one row per `<recipe>` in the same order. Each row must contain the recipe name, the exit code as a decimal integer, and the captured stdout. Within each cell, the recipe name and captured stdout must appear as text content, so `<`, `>`, and `&` are displayed as themselves. After writing the HTML file, exit with status 0.
