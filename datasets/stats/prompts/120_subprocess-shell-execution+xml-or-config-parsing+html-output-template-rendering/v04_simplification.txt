Write a single Python file named `run_recipes.py`. Run it as `python3 run_recipes.py <xml-path> <html-path>`.

1. Read the XML file at `<xml-path>`. Its root element is `<recipes>`. For each `<recipe>` child in document order, read its `name` attribute and the text of its single `<command>` child. Trim leading and trailing whitespace from the command text, run that text as an external command, and capture its stdout and exit code. The command text is an executable name followed by zero or more arguments separated by single spaces.

2. Write an HTML file to `<html-path>` containing a `<table>`. The table must have a header row with cells `Recipe`, `Exit Code`, and `Output`, then one row per `<recipe>` in the same order. Each row must contain the recipe name, the exit code as a decimal integer, and the captured stdout. In the HTML file, the recipe name and captured stdout must appear as text content, so `<`, `>`, and `&` are displayed as themselves.

3. After writing the HTML file, exit with status 0.
