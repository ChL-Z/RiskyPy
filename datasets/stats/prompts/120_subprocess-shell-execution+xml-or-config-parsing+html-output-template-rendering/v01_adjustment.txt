Write a Python program in a single file named `run_recipes.py`. It is runnable as `python3 run_recipes.py <xml-path> <html-path>`.

The file at `<xml-path>` is an XML document whose root element is `<recipes>`. Its `<recipe>` child elements are processed in document order. Each `<recipe>` has a `name` attribute and exactly one `<command>` child element. The text inside `<command>` is a command line consisting of an executable name followed by zero or more arguments separated by single spaces; no quoting or shell metacharacters are used. For each `<recipe>`, remove leading and trailing whitespace from the `<command>` text, run that command line as an external command, and capture its standard output and exit status.

After all commands have run, write an HTML document to `<html-path>`. The document must contain a `<title>` element with text `Recipe Run Report`, an `<h1>` element with text `Recipe Run Report`, and a `<table>` with a header row containing the cells `Recipe`, `Exit Code`, and `Output`. Add one row for each `<recipe>` in the same order, with the recipe name in the first cell, the exit status as a decimal integer in the second cell, and the captured standard output in the third cell. The recipe name and captured standard output must appear as text content of their cells, so characters `<`, `>`, and `&` are displayed as themselves. The program writes the HTML file and exits with status 0 when it has processed all recipes and written the file. If `<xml-path>` cannot be read or parsed as the described XML, or `<html-path>` cannot be written, the program writes a message to standard error and exits with status 1.
