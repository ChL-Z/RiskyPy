Write a Python program in a single file named `report_tool.py`.

The program reads one argument from the command line: the path to an XML configuration file. The XML file has a `<report>` root element. Its child elements appear in document order and are either `<variable name="NAME" value="INTEGER"/>` or `<expression name="NAME">TEXT</expression>`. `NAME` is matched exactly as written. `INTEGER` is a decimal integer.

For each `<expression>` element in document order, evaluate `TEXT` at runtime to an integer using the values of names defined earlier in the document. `TEXT` contains decimal integer literals, parentheses, the operators `+`, `-`, and `*`, and names that refer to earlier `<variable>` or `<expression>` elements. A variable's value is its `value` attribute. An expression's value is its evaluated result. Print one line per `<expression>` in the form `NAME = VALUE`, where `VALUE` is the integer result. Do not print lines for `<variable>` elements.

Example: for XML file `config.xml` containing `<report><variable name="base" value="12"/><expression name="doubled">base * 2</expression><expression name="total">doubled + base</expression></report>`, running `python report_tool.py config.xml` prints:
doubled = 24
total = 36
