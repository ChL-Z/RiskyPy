Write a Python program in a single file named `report_tool.py`.

The program reads the path to an XML configuration file from the first command-line argument. The XML file has a `<report>` root element. Its children appear in document order and are either:

- `<variable name="NAME" value="INTEGER"/>`
- `<expression name="NAME">EXPRESSION_TEXT</expression>`

`NAME` is a case-sensitive string. `INTEGER` is a decimal integer. `EXPRESSION_TEXT` contains integer literals, the operators `+`, `-`, `*`, parentheses, and names that refer to variables or to expressions that appeared earlier in the document.

The program prints one line for each `<expression>` element, in document order, in the form:

name = value

where `value` is the integer result of computing the expression text using the current values of the named variables and earlier expressions. The program does not print anything for `<variable>` elements.

Example XML file `config.xml`:

<report>
  <variable name="base" value="12"/>
  <expression name="doubled">base * 2</expression>
  <expression name="total">doubled + base</expression>
</report>

Running `python report_tool.py config.xml` prints:

doubled = 24
total = 36
