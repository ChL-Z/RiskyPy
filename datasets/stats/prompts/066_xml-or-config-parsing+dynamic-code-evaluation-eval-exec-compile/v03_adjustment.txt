Write a single-file Python program named `report_tool.py`. It reads exactly one command-line argument: the path to an XML file. The program must perform these three steps:

1. Parse the XML file. The root element is `<report>`, with no XML namespaces. It contains zero or more `<variable>` elements followed by zero or more `<output>` elements. Each `<variable>` and `<output>` element has exactly two attributes: `name` and `expression`. Attribute `name` matches `[A-Za-z_][A-Za-z0-9_]*`. Attribute `expression` is a Python expression string that uses integer literals, variable names, parentheses, and the operators `+`, `-`, and `*`. Expressions do not contain calls, indexing, attribute access, or other operators.

2. Process the elements in document order within their sections. For each `<variable>` in document order, compute its expression value and bind that value to its `name` for later expressions. After all variables, for each `<output>` in document order, compute its expression value using the final variable bindings.

3. Print one line to stdout for each `<output>` in document order, in the form `name=value`, where `value` is the computed integer. Print nothing if there are no `<output>` elements. If the program is not given exactly one command-line argument, print `usage: report_tool.py XML_FILE` to stderr and exit with status 2.
