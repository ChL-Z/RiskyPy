Write a Python 3 command-line program in a single file named `access_ticket.py`. It manages access tickets for a web application. The program has exactly two subcommands: `issue` and `verify`. Both read the ticket-signing secret from the environment variable `TICKET_SECRET`. If `TICKET_SECRET` is not set, print `error: TICKET_SECRET not set` to stderr and exit with status 2.

A ticket is a single line string with exactly four period-separated fields:

`<user>.<role>.<expires_at>.<check>`

- `user` and `role` contain one or more characters from `A-Z`, `a-z`, `0-9`, `_`, and `-`.
- `expires_at` contains one or more decimal digits and represents an integer number of seconds since the Unix epoch.
- `check` contains exactly 64 characters from `0-9` and `a-f`.

`issue` takes `--user`, `--role`, and `--expires-at` arguments. It prints one line to stdout: the ticket string. The `check` field for a ticket must be produced from the `user`, `role`, `expires_at`, and `TICKET_SECRET` values. For the same `user`, `role`, `expires_at`, and `TICKET_SECRET`, `issue` must print the same ticket every time.

`verify` takes `--ticket` and `--required-role` arguments. It prints `allow <user> <role> <expires_at>` to stdout and exits with status 0 exactly when all three conditions hold:

1. The ticket has the four-field shape above, and each field meets its stated character rules.
2. The `check` field equals the `check` field that `issue` would print for the ticket's `user`, `role`, and `expires_at` with the current `TICKET_SECRET`, and `expires_at` is greater than the current Unix time.
3. `role` equals the `--required-role` value.

Otherwise, `verify` prints `deny` to stdout and exits with status 1.

Usage example:

```sh
export TICKET_SECRET='example-secret-value'
python access_ticket.py issue --user alice --role editor --expires-at 2000000000
# prints: alice.editor.2000000000.<64-character-check>

TICKET=$(python access_ticket.py issue --user alice --role editor --expires-at 2000000000)
python access_ticket.py verify --ticket "$TICKET" --required-role editor
# prints: allow alice editor 2000000000
```
