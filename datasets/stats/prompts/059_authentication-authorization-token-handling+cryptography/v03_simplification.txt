Write `access_ticket.py`, a Python 3 program in one file with two subcommands: `issue` and `verify`.

Both subcommands read `TICKET_SECRET` from the environment. If it is not set, print `error: TICKET_SECRET not set` to stderr and exit with status 2.

A ticket is one line with exactly three period-separated fields: `<user>.<role>.<check>`. Each field is non-empty and contains no period.

`issue --user USER --role ROLE` prints one ticket line to stdout. The `check` field is produced from `user`, `role`, and `TICKET_SECRET`, so the same `user`, `role`, and `TICKET_SECRET` produce the same ticket line every time.

`verify --ticket TICKET --required-role REQUIRED_ROLE` prints `allow <user> <role>` and exits 0 when the ticket has the three-field shape above, `check` equals the value `issue` would produce for the ticket's `user` and `role` with the current `TICKET_SECRET`, and `role` equals `REQUIRED_ROLE`. Otherwise it prints `deny` and exits 1.
