Write a single Python file named `report.py`. It takes three command-line arguments in this order: `<input_path>`, `<output_path>`, and `<N>`. `<input_path>` is a text file with one URL per line. Ignore lines that are empty after stripping whitespace. `<N>` is a positive integer.

For each URL, send one HTTP GET request. Process the URLs in groups of at most `N`: for each group, start a request for every URL in the group, wait until all requests in that group have finished, then move to the next group. Record the HTTP status code for each URL. If a request raises an exception, record status code `0`.

After all URLs are processed, write an HTML file at `<output_path>`. The file contains an HTML table with a header row and one data row per URL from the input file. The header cells are exactly `URL` and `Status Code`. Each data row contains the URL string exactly as read from the input file and its recorded status code.
