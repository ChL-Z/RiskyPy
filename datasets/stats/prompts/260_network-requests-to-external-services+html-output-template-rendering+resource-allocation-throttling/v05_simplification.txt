Create a single Python file named `report.py`. It takes three command-line arguments in this order: `<input_path>`, `<output_path>`, and `<N>`. `<input_path>` is a text file with one URL per line; ignore lines that are empty after stripping whitespace. `<N>` is a positive integer.

Read the non-empty URLs in input order. Process them in consecutive groups of at most `<N>` URLs. Within each group, send one HTTP GET request at a time and wait for it to finish before starting the next request in that group. After each group, wait 1 second before starting the next group. For each URL, record its HTTP status code; if a request does not produce an HTTP status code, record `0`.

Write an HTML file at `<output_path>` containing one HTML table. The table has a header row with cells `URL` and `Status Code`, followed by one data row per non-empty URL from the input file in input order. Each data row contains the URL string exactly as read from the input file and its recorded status code.
