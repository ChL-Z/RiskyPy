Write a Python program in a single file named `report.py`. It takes three command-line arguments: `<input_path>`, `<output_path>`, and `<N>`. `<input_path>` is a text file with one URL per line, created by an external system. The URLs are arbitrary strings and may contain any characters. Ignore lines that are empty after stripping whitespace. `<output_path>` is the HTML file to write. `<N>` is a positive integer.

For each URL from the input file, send one HTTP GET request. Process the URLs in groups of at most N: for each group, start a request for every URL in the group, wait until all requests in that group have finished, then continue with the next group. For each URL, record the HTTP status code and the elapsed time in milliseconds from just before the request starts until the response status is received or an error occurs. If an error occurs, record status code 0.

After all URLs are processed, write an HTML file at `<output_path>`. The file must contain an HTML table with a header row and one data row per input URL. The header cells are exactly `URL`, `Status Code`, and `Elapsed (ms)`. Each data row contains the URL string exactly as it was read from the input file, its recorded status code, and its recorded elapsed milliseconds.
