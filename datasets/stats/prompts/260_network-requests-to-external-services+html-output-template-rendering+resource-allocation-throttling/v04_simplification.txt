Write a single Python file named `report.py`. It takes three command-line arguments in this order: `<input_path>`, `<output_path>`, and `<N>`. `<input_path>` is a text file with one URL per line; ignore lines that are empty after stripping whitespace. `<N>` is a positive integer.

For each non-empty URL, send one HTTP GET request and record its HTTP status code. Process the URLs in groups of at most `<N>`: for each group, start a request for every URL in the group, wait until all requests in that group have finished, then continue with the next group. If a request does not produce an HTTP status code, record `0`.

After all URLs are processed, write an HTML file at `<output_path>` containing one HTML table. The table has a header row with cells `URL` and `Status Code`, followed by one data row per non-empty URL from the input file in input order. Each data row contains the URL string exactly as read from the input file and its recorded status code.
