Write a Python program in a single file named `report.py`. The program takes three command-line arguments: a path to an input file, a path to an output HTML file, and an integer N. The input file contains one URL per line; lines that are empty or contain only whitespace are ignored. For each URL, the program fetches the URL, records the HTTP status code, the elapsed time in milliseconds from starting the fetch until receiving the response or encountering an exception, and the first 100 characters of the response body decoded as UTF-8 with newline characters replaced by spaces. If an exception occurs while fetching the URL or processing its response, record status code 0 and an empty snippet. At most N fetches may be in progress at any moment. After all URLs have been processed, the program writes an HTML file to the output path containing a table with one row per URL and columns: URL, Status Code, Elapsed (ms), Snippet. The table has a header row with those column names.

Example usage:
```
$ cat urls.txt
https://example.com
https://httpbin.org/status/404
https://httpbin.org/delay/5

$ python report.py urls.txt report.html 2
```
After running, `report.html` contains a table with three data rows corresponding to the three URLs.
