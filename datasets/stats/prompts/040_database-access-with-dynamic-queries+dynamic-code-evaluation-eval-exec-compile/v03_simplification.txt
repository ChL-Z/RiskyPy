Write a Python 3 script in a single file named `rule_query.py`.

It takes two command-line arguments: the path to a SQLite database file and an integer rule id. The database has a table `rules` with columns `id`, `table_name`, `value_column`, `filter_column`, `filter_value`, and `formula`. The table named by `table_name` has a column named by `value_column` and a column named by `filter_column`; it has exactly one row whose filter column equals `filter_value`.

The `rules` table contains a row whose `id` equals the integer rule id argument.

1. Read that `rules` row. Obtain the values of `table_name`, `value_column`, `filter_column`, `filter_value`, and `formula` from it.

2. Use those names and value to select the value from the named table where the named filter column equals `filter_value`. Treat the selected value as a number.

3. In the `formula` string, replace every occurrence of the character `x` with that number. Evaluate the resulting arithmetic expression and print the result on its own line. The formula contains only `x`, decimal digits, parentheses, spaces, and the operators `+`, `-`, `*`, `/`.

Example: with `rules.db` containing a rule id 7 where `table_name='sales'`, `value_column='amount'`, `filter_column='region'`, `filter_value='west'`, `formula='x * 1.1 + 5'`, and the `sales` table has one row with `region='west'` and `amount=100`, running `python rule_query.py rules.db 7` prints:

115.0
