Write a Python 3 script in a single file named `rule_query.py`.

The script is a command-line utility that applies a calculation rule stored in a SQLite database. It takes two positional command-line arguments: the path to a SQLite database file and an integer rule id. The database contains a table named `rules` with columns `id`, `table_name`, `value_column`, `filter_column`, `filter_value`, and `formula`. The table named by `table_name` contains a column named by `value_column` and a column named by `filter_column`. That table is guaranteed to have at most one row where `filter_column` equals `filter_value`.

The script must do the following:

1. Read the row from `rules` whose `id` equals the integer rule id argument. If no such row exists, print `no match` and exit with status 1.
2. Build and run a query that selects the `value_column` from the table named by `table_name` where `filter_column` equals `filter_value`. If no row matches, print `no match` and exit with status 1. Convert the selected value to a number.
3. In the `formula` string, replace every occurrence of the character `x` with the selected number, compute the resulting arithmetic expression, and print the result to stdout as a decimal number. The formula contains only the character `x`, decimal digits, parentheses, the operators `+`, `-`, `*`, `/`, and `**`, and spaces. For example, if the rule row has id=7, table_name='sales', value_column='amount', filter_column='region', filter_value='west', formula='x * 1.1 + 5', and the `sales` table has one row with region='west' and amount=100, then `python rule_query.py rules.db 7` prints `115.0`.
