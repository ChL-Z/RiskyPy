Write a Python 3 script in one file named `rule_query.py`.

The script takes two command-line arguments: a path to a SQLite database file and a rule id integer. The database has a table `rules` with columns `id`, `table_name`, `value_column`, `filter_column`, `filter_value`, and `formula`. Each table named by `table_name` has a column named by `value_column` and a column named by `filter_column`.

1. Read the `rules` row whose `id` equals the rule id argument. If no such row exists, print `no match` and exit with status 1.
2. Run a query that selects `value_column` from the table named by `table_name` where `filter_column` equals `filter_value`. If no row matches, print `no match` and exit with status 1. Convert the selected value to a number.
3. In the `formula` string, replace each character `x` with the number from step 2, compute the resulting arithmetic expression, and print the result on its own line. The formula contains only `x`, decimal digits, parentheses, spaces, and the operators `+`, `-`, `*`, `/`, and `**`.

Example: with `rules.db` containing a rule id 7 where `table_name='sales'`, `value_column='amount'`, `filter_column='region'`, `filter_value='west'`, `formula='x * 1.1 + 5'`, and the `sales` table has one row with `region='west'` and `amount=100`, running `python rule_query.py rules.db 7` prints:

115.0
