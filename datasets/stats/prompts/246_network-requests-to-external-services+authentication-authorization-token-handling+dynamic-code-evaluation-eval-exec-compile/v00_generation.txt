Write a single Python file named `formulas.py`. Running `python formulas.py` with no arguments starts a command-line tool that applies arithmetic formulas published by a remote service to pairs of numbers read from stdin.

Environment variables:
- `FORMULA_URL` holds the endpoint URL.
- `FORMULA_TOKEN` holds the access token.

1. At startup, retrieve a JSON object from `FORMULA_URL` using an HTTP GET request whose `Authorization` header is exactly `Bearer <FORMULA_TOKEN>` (the literal word `Bearer`, one space, then the token value). The JSON object's keys are field names and its values are expression strings. Each expression contains only the variable names `a` and `b`, decimal number literals, whitespace, parentheses, and the operators `+`, `-`, `*`, `/`. If the response status is not 200, print `error: fetch failed` to stderr and exit with code 3.

2. Then read stdin to EOF. Each input line contains two whitespace-separated decimal numbers. For every input line, print one output line per key of the JSON object, in the order that object lists its keys, in the form `name=value`, where `value` is the result of that key's expression with `a` and `b` bound to the two numbers of the input line, printed with `repr()`. Input lines that are empty after stripping are skipped. If a key's expression cannot produce a result for an input line, print `name=error` for that key and continue with the remaining keys and input lines.

3. After stdin ends, exit with code 0.

Example: with `FORMULA_URL=http://localhost:8080/formulas` and `FORMULA_TOKEN=abc123`, the service returns `{"total": "a + b", "double": "a * 2"}`. Given stdin lines `3 4` and `1.5 2`, the tool prints:
```
total=7.0
double=6.0
total=3.5
double=3.0
```
