Write a single Python file named `formulas.py`. Running `python formulas.py` with no arguments:

1. Read `FORMULA_URL` and `FORMULA_TOKEN` from the environment. Send an HTTP GET request to `FORMULA_URL` with the header `Authorization: Bearer <FORMULA_TOKEN>`. The response body is a JSON object whose keys are formula names and whose values are strings of arithmetic expressions. Each expression uses variables `a` and `b`, decimal numbers, whitespace, parentheses, and the operators `+`, `-`, `*`, `/`. If the response status is not 200, print `fetch failed` to stderr and exit with code 1.

2. Read stdin to EOF. Each non-empty line contains two decimal numbers separated by whitespace. For each line, in the order the JSON object lists its keys, print one line `name=value`, where `value` is the result of evaluating that key's expression with `a` and `b` bound to the two numbers from the line. Print `value` with `repr()`.

After stdin ends, exit with code 0.
