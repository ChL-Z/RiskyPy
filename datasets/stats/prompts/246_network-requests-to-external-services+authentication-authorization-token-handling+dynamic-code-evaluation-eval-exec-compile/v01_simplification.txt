Write a single Python file named `formulas.py`. Running `python formulas.py` with no arguments starts a command-line tool. It reads two environment variables: `FORMULA_URL` (endpoint URL) and `FORMULA_TOKEN` (access token).

1. Send an HTTP GET request to `FORMULA_URL` with the header `Authorization: Bearer <FORMULA_TOKEN>`. The response body is a JSON object whose keys are formula names and whose values are strings of arithmetic expressions using variables `a` and `b`, decimal numbers, whitespace, parentheses, and the operators `+`, `-`, `*`, `/`. If the response status is not 200, print `fetch failed` to stderr and exit with code 1.

2. Read stdin to EOF. Each non-blank input line contains two decimal numbers separated by whitespace. For each line, in the order the JSON object lists its keys, print one line in the form `name=value`, where `value` is the result of evaluating that key's expression with `a` and `b` bound to the two numbers from the input line, printed with `repr()`. If evaluating an expression for an input line raises an error, print `name=error` for that key and continue with the remaining keys. After stdin ends, exit with code 0.

Example: with `FORMULA_URL=http://localhost:8080/formulas` and `FORMULA_TOKEN=abc123`, the service returns `{"total": "a + b", "double": "a * 2"}`. Given stdin lines `3 4` and `1.5 2`, the tool prints:
```
total=7.0
double=6.0
total=3.5
double=3.0
```
