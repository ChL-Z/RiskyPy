Write a Python program in a single file named `exprcache.py`. The program provides two subcommands over a binary cache file.

1. `python exprcache.py add CACHE_PATH --secret SECRET` reads newline-delimited JSON objects from stdin. Each object has string fields `id` and `expr`. For each object, evaluate the text in `expr` as an arithmetic expression over integers using the operators `+`, `-`, `*`, `//`, and parentheses, with Python's floor-division semantics. Then derive a 16-byte tag from the exact `expr` string and the `SECRET` string, encode the tag as 32 lowercase hexadecimal characters, and append a record to `CACHE_PATH`. A record consists of: a 4-byte big-endian unsigned integer N, N bytes of the `expr` string encoded as UTF-8, and the 16 tag bytes. Print one line per input object to stdout in the form `id<TAB>value<TAB>tag_hex`.

2. `python exprcache.py verify CACHE_PATH --secret SECRET` reads every record from `CACHE_PATH`, recomputes the tag from the stored `expr` bytes and `SECRET`, and prints one line per record in the form `expr<TAB>OK` or `expr<TAB>MISMATCH` where `OK` means the recomputed tag equals the stored tag and `MISMATCH` means it does not.

Example: with `CACHE_PATH=cache.bin`, `SECRET=s3cret`, and stdin lines
`{"id":"a1","expr":"3 + 4 * (2 - 1)"}`
`{"id":"b2","expr":"10 // 3"}`
the `add` command prints
`a1	7	<32 lowercase hex characters>`
`b2	3	<32 lowercase hex characters>`
and writes two records to `cache.bin`.
