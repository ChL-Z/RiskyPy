Write a Python program in a single file named `exprcache.py` with these two subcommands:

1. `python exprcache.py add CACHE_PATH --secret SECRET` reads lines from stdin. Each line contains an id, a single tab character, and an arithmetic expression. Evaluate the expression as integer arithmetic using the operators `+`, `-`, `*`, `//`, and parentheses, with Python floor-division semantics. Compute a 16-byte cryptographic tag using SECRET as the key and the exact expression bytes as the message. Print one line to stdout in the form `id<TAB>value<TAB>tag_hex`, where `tag_hex` is the 32 lowercase hexadecimal characters of the tag. Append to CACHE_PATH one record consisting of: a 4-byte big-endian unsigned integer N, then N bytes of the expression string encoded as UTF-8, then the 16 tag bytes.

2. `python exprcache.py verify CACHE_PATH --secret SECRET` reads all records from CACHE_PATH in order. For each record, recompute the 16-byte cryptographic tag from the stored expression bytes and SECRET. Print the stored expression bytes decoded as UTF-8, a tab, and `OK` if the recomputed tag equals the stored tag, otherwise print the stored expression bytes decoded as UTF-8, a tab, and `MISMATCH`.
