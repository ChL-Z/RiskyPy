Write a Python program in a single file named `exprcache.py` with two subcommands.

1. `python exprcache.py add CACHE_PATH --secret SECRET` reads lines from stdin. Each input line is one arithmetic expression; ignore the trailing newline. Evaluate the expression as integer arithmetic using the operators `+`, `-`, `*`, `//`, and parentheses, where `//` is floor division. Print the resulting integer followed by a newline. Then append to `CACHE_PATH` one record consisting of: a 4-byte big-endian unsigned integer N, then N bytes of the expression string encoded as UTF-8, then a 16-byte cryptographic tag computed from `SECRET` as the key and the expression string encoded as UTF-8 as the message.

2. `python exprcache.py verify CACHE_PATH --secret SECRET` reads all records from `CACHE_PATH` in order. For each record, recompute the 16-byte cryptographic tag from the stored expression bytes and `SECRET`. Print the stored expression bytes decoded as UTF-8, a tab, and `OK` if the recomputed tag equals the stored tag, otherwise print the stored expression bytes decoded as UTF-8, a tab, and `MISMATCH`.
