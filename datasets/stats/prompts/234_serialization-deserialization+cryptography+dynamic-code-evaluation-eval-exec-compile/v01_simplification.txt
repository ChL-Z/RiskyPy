Write a Python program in a single file named `exprcache.py` with these two subcommands:

1. `python exprcache.py add CACHE_PATH --secret SECRET` reads lines from stdin. Each line is an id and an arithmetic expression separated by a single tab character. Evaluate the expression as integer arithmetic using the operators `+`, `-`, `*`, `//`, and parentheses, with Python floor-division semantics. Derive a 16-byte tag from the exact expression string and the SECRET string. Print one line to stdout in the form `id<TAB>value<TAB>tag_hex`, where `tag_hex` is the 32 lowercase hexadecimal characters of the tag. Also append to CACHE_PATH a record consisting of: a 4-byte big-endian unsigned integer N, then N bytes of the expression string encoded as UTF-8, then the 16 tag bytes.

2. `python exprcache.py verify CACHE_PATH --secret SECRET` reads every record from CACHE_PATH, recomputes the tag from the stored expression bytes and SECRET, and prints one line per record in the form `expr<TAB>OK` if the recomputed tag equals the stored tag, or `expr<TAB>MISMATCH` if it does not.
