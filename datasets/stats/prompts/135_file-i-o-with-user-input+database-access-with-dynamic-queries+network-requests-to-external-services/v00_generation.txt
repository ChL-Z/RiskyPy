Write a Python script in a single file. The script reads one line from standard input, strips the trailing newline, and uses that string as a username. It then looks up the row in the SQLite database file `users.db` (table `users`, columns `username`, `email`, `signup_date`) where the `username` column equals the provided username. It also fetches `https://api.example.com/status/{username}` (where `{username}` is replaced by the provided username) and reads the `status` field from the JSON response. The script prints one line to standard output with the user's email, signup date, and status, separated by commas, in that order.
