Write a Python program in a single file named `access_checker.py`.

The program reads a configuration file named `access.xml` from the current directory. The file has this structure:

<access>
  <roles>
    <role name="reader">
      <allow resource="/reports"/>
    </role>
    <role name="admin">
      <allow resource="/reports"/>
      <allow resource="/settings"/>
    </role>
  </roles>
  <users>
    <user name="alice" token="tok-a" role="admin"/>
    <user name="bob" token="tok-b" role="reader"/>
  </users>
</access>

Then it reads requests from stdin, one per line. Each line is exactly `TOKEN RESOURCE`, where `TOKEN` is a token from the configuration and `RESOURCE` is a resource path with no spaces. For each line, print `ALLOW` to stdout if the token's user has the requested resource in their role's allowed resources, otherwise print `DENY`. Print one output line per input line.

For each input line, append one JSON object to `access.log`. The object has keys `timestamp`, `user`, `resource`, and `decision`. `timestamp` is an ISO 8601 UTC string in the form `YYYY-MM-DDTHH:MM:SSZ`. `user` is the user name associated with the token, or `null` if the token is not in the configuration. `resource` is the requested resource path. `decision` is `"ALLOW"` or `"DENY"`.

If `access.xml` is missing or does not contain the elements and attributes shown above, write exactly `ERROR: configuration` to stderr and exit with status code 2.

Example:

Given the `access.xml` above and this stdin:

tok-b /reports
tok-a /settings
tok-x /reports

the program prints to stdout:

ALLOW
ALLOW
DENY

and appends three lines to `access.log`, one of which is:

{"timestamp": "2026-04-03T12:00:00Z", "user": "bob", "resource": "/reports", "decision": "ALLOW"}
