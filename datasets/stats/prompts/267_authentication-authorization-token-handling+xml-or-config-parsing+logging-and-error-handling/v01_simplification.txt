Write a Python program in a single file named `access_checker.py`.

The program reads `access.xml` from the current directory. The file has this structure:

<access>
  <user name="alice" token="tok-a" role="admin"/>
  <user name="bob" token="tok-b" role="reader"/>
  <role name="admin" resource="/reports"/>
  <role name="admin" resource="/settings"/>
  <role name="reader" resource="/reports"/>
</access>

A `<user>` has `name`, `token`, and `role` attributes. A `<role>` has `name` and `resource` attributes. A role may appear multiple times with the same `name`, once for each allowed resource.

The program reads lines from stdin. Each line is `TOKEN RESOURCE`, where `TOKEN` is a token from the configuration and `RESOURCE` is a resource path without spaces. For each input line, print `ALLOW` to stdout if the token belongs to a user whose role has a matching `resource` value; otherwise print `DENY`. Print one output line per input line.

For each input line, append one JSON object as a line to `access.log`. The object has keys `timestamp`, `user`, `resource`, and `decision`. `timestamp` is the current UTC time formatted as `YYYY-MM-DDTHH:MM:SSZ`. `user` is the user name for the token, or `null` if the token is not in the configuration. `resource` is the input resource path. `decision` is `"ALLOW"` or `"DENY"`.

If `access.xml` is missing or cannot be parsed, write exactly `ERROR: configuration` to stderr and exit with status code 2.
