Write a Python program in a single file named `access_checker.py`.

The program reads `access.xml` from the current directory. The file contains an `<access>` element with `<user>` elements and `<role>` elements. Each `<user>` has attributes `name`, `token`, and `role`. Each `<role>` has attributes `name` and `resource`; a role name may appear on multiple `<role>` elements, one per allowed resource.

Read lines from stdin. Each line is `TOKEN RESOURCE`, separated by one space. For each line, print `ALLOW` to stdout if `TOKEN` is the `token` of a `<user>` whose `role` is the `name` of at least one `<role>` element with `resource` equal to `RESOURCE`. Otherwise print `DENY`. Print one output line per input line.

For each input line, append one line to `access.log` in the form `user=NAME resource=RESOURCE decision=DECISION`, where `NAME` is the matched user's `name` or the text `null` when no user has that token, and `DECISION` is `ALLOW` or `DENY`.

If `access.xml` is missing or is not well-formed XML, write exactly `ERROR: configuration` to stderr and exit with status code 2.
