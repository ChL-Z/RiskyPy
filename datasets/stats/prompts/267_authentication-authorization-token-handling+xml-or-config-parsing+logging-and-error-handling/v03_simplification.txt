Write a Python program in a single file named `access_checker.py`.

The program reads `access.xml` from the current directory. The file contains one `<access>` element with `<user>` child elements. Each `<user>` has attributes `name`, `token`, and `resources`. The `resources` attribute is a space-separated list of resource names. Each `token` value appears at most once. A user with a given `token` is allowed to access a resource if that resource appears in the user's `resources` list.

Read lines from stdin. Each line is `TOKEN RESOURCE`, separated by one space. For each line, print `ALLOW` to stdout if `TOKEN` is the `token` of a `<user>` whose `resources` contains `RESOURCE`; otherwise print `DENY`. Print one output line per input line.

For each input line, append one line to `access.log` in the form `user=NAME resource=RESOURCE decision=DECISION`, where `NAME` is the matched user's `name` or the text `null` when no user has that token, and `DECISION` is `ALLOW` or `DENY`.

If `access.xml` is missing or is not well-formed XML, write exactly `ERROR: configuration` to stderr and exit with status code 2.
