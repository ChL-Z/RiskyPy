Write a Python 3 script in a single file named `report.py`. The script takes one command-line argument: the path to an HTML template file. It reads newline-separated file paths from stdin (one path per line; empty lines are ignored). For each path, it reads the file's bytes and determines two values: the size in bytes (decimal integer) and a 32-character lowercase hexadecimal fingerprint of the file's contents. The template file contains the exact text `{{rows}}` in one place. The script writes to stdout the template file content with `{{rows}}` replaced by a string made of one HTML table row per input path. Each row must be exactly `<tr><td>{path}</td><td>{size}</td><td>{fingerprint}</td></tr>` where `{path}` is the input line as given, `{size}` is the decimal byte count, and `{fingerprint}` is the 32-character lowercase hexadecimal fingerprint. Rows are concatenated with a newline character between them, and no newline after the last row. If stdin contains no non-empty lines, `{{rows}}` is replaced by an empty string.

Example: template file `page.html` contains `<html><body><table>{{rows}}</table></body></html>`. File `a.txt` contains `hello`. Running `printf 'a.txt\n' | python report.py page.html` writes to stdout `<html><body><table><tr><td>a.txt</td><td>5</td><td>...32 hex chars...</td></tr></table></body></html>` where `...32 hex chars...` is the fingerprint of the bytes `hello`.
