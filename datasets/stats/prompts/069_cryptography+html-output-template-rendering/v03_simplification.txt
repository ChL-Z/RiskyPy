Write a Python 3 script in a single file named `report.py`. The script reads newline-separated file paths from stdin, ignoring empty lines. For each path, it reads the file as bytes and computes two values: the number of bytes and a 32-character lowercase hexadecimal fingerprint of those bytes. The script then reads the file `template.html` (in the current working directory) and writes to stdout its content with the single occurrence of `{{rows}}` replaced by one `<tr>` element per input path in input order. Each `<tr>` element is exactly `<tr><td>{path}</td><td>{size}</td><td>{fingerprint}</td></tr>`, where `{path}` is the input path with `&` replaced by `&amp;`, then `<` replaced by `&lt;`, then `>` replaced by `&gt;`, and `{size}` and `{fingerprint}` are the two computed values.
