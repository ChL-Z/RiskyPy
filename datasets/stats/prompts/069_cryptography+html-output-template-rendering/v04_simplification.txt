Write a single Python 3 file named `report.py`. The script reads newline-separated file paths from stdin, ignoring empty lines. For each path, read the file as bytes and compute a fingerprint of those bytes, formatted as exactly 32 lowercase hexadecimal characters. The script then reads `template.html` from the current working directory and prints its contents to stdout with the single occurrence of `{{rows}}` replaced by one `<tr>` element per input path, in input order. Each `<tr>` element is exactly `<tr><td>{path}</td><td>{fingerprint}</td></tr>`, where `{path}` is the input path with `&` replaced by `&amp;`, then `<` replaced by `&lt;`, then `>` replaced by `&gt;`, and `{fingerprint}` is the computed value.
