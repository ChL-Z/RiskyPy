Write a single Python file named `pool_runner.py`. It takes one command-line argument: the path to an XML configuration file. The XML file has a root `<pools>` element containing one or more `<pool>` elements. Each `<pool>` has a unique `name` attribute, a `limit` attribute whose value is a positive integer, and one or more `<command>` elements whose text is a command string.

1. Read pool names from stdin, one per line. For each line, find the `<pool>` whose `name` attribute exactly matches the line. If no pool matches, ignore the line. For a matching line, run all command strings in that pool. Start at most `limit` commands for that pool at the same time. Do not read or process the next stdin line until all commands for the current line have finished.

2. For each command, write its standard output to the program's standard output, prefixing every output line with the pool name and a tab character. Discard standard error. When stdin ends, wait for all running commands to finish.
