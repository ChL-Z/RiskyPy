Write a single Python file named `pool_runner.py`. It takes one command-line argument: the path to an XML configuration file. The XML file has a root `<pools>` element containing one or more `<pool name="..." limit="...">` elements. Pool names are unique. Each pool contains one or more `<command>` elements whose text is a command string. The `limit` attribute is a positive integer. Read newline-separated pool names from stdin. For each line, find the pool whose `name` exactly matches (case-sensitive) the line. Run every command in that pool, allowing at most the pool's `limit` commands to run at the same time. Do not read the next stdin line until all commands for the current line have finished. If no pool matches a line, continue to the next line. For each command, write its combined stdout and stderr to stdout, with every line prefixed by the pool name and a tab. When stdin ends, wait for all running commands to finish.
