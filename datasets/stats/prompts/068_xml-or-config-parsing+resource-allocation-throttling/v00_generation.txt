Create a single Python file named `pool_runner.py`. The program takes one command-line argument: the path to an XML configuration file. The XML has a root `<pools>` element containing one or more `<pool name="..." limit="...">` elements. Each `<pool>` contains one or more `<command>` elements whose text is a command to run. The `limit` attribute is a positive integer. The program reads newline-separated pool names from stdin. Process stdin lines in order. For each line, select the matching pool by exact, case-sensitive name, start every command in that pool, allow no more than the pool's `limit` commands to run concurrently, and do not read the next stdin line until all commands for the current line have finished.

For each command, write its combined stdout and stderr to stdout, with every line prefixed by the pool name and a tab character. Write a command's output only after that command has finished, in the order commands finish. When stdin ends, wait for all running commands to finish. Exit with status 0 if every command exited with status 0; otherwise exit with status 1.

Example: `config.xml` contains `<pools><pool name="build" limit="2"><command>printf 'a\n'</command><command>printf 'b\n'</command></pool></pools>`. Running `printf 'build\nbuild\n' | python pool_runner.py config.xml` runs the two commands for the first `build` line while allowing up to two at once, then runs them again for the second `build` line.
