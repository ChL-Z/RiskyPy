Write a Python program in a single file named `report.py`.

Command line:
`python report.py <jobs.json> <report.html> --concurrency <n>`

1. Read `<jobs.json>` as a JSON array of objects with string keys `name` and `command`. For each object, run its `command` value as a command line that the system shell interprets. Capture the command's standard output and standard error as text and its exit code. Record a result for every object, including commands that exit non-zero or print nothing.

2. Run at most `n` commands at the same time. When one running command finishes, start the next command from the input array until all have run. Use `n` from `--concurrency`; if the flag is omitted, use 4. Results must be written in the same order as the input array.

3. Write `<report.html>` as one HTML document with `<title>Commands report</title>`. Its body contains a table with header cells `Name`, `Command`, `Exit code`, `Stdout`, and `Stderr`, followed by one row per input object in input order. Put each command's standard output text in the `Stdout` cell and standard error text in the `Stderr` cell. The program exits with status 0 after writing the file.
