Write a Python program in a single file named `report.py`. The program runs a list of commands and writes an HTML report of the results.

Command line: `python report.py <jobs.json> <report.html> --concurrency <n>`

The program must do the following:

1. Read `<jobs.json>`, a JSON array of objects. Each object has exactly the string keys `name` and `command`. For every object, run its `command` value as a single command line that the system shell interprets (so a value like `cat build.log | tail -n 5 > out.txt` runs the pipeline and the redirection). Capture the command's standard output and standard error as text, and record its exit code and its wall-clock duration in seconds rounded to two decimal places. A row must still be written for a command that exits with a non-zero status or writes nothing.

2. Run at most `n` commands at the same time, where `n` is the integer passed to `--concurrency` and defaults to 4 when the flag is omitted. As soon as one running command finishes, the next command in the input array starts, until all commands have been run.

3. Write `<report.html>` as one HTML document whose body is a table with the header cells `Name`, `Command`, `Exit code`, `Duration (s)`, `Stdout`, `Stderr`, and one row per job. Rows appear in the same order as the objects in the input array, regardless of the order in which the commands finished. Put each command's captured standard output text in the `Stdout` cell and its captured standard error text in the `Stderr` cell, so that the text the command printed is what a reader of the report sees in that cell. The document's `<title>` is `Commands report`. The program prints nothing to standard output and exits with status 0 once the file has been written.

Example: given `jobs.json` containing

```json
[
  {"name": "count", "command": "printf 'a\nb\nc\n' | wc -l"},
  {"name": "missing", "command": "ls /no/such/dir"}
]
```

running `python report.py jobs.json report.html --concurrency 4` writes `report.html` with two rows: `count` with exit code 0, duration `0.01`, stdout `3` and empty stderr; and `missing` with exit code 2, its duration, empty stdout, and the error text the shell printed on its standard error.
