Write a Python program in a single file named `report.py`.

Command line:
`python report.py <commands.txt> <report.html> --concurrency <n>`

1. Read `<commands.txt>`. Each non-empty line is one command string. For each command, run it with the system shell, capture its standard output as text and its exit code as an integer. Record one result for every command in input order, including commands that exit non-zero or produce no output.

2. Run at most `n` commands at the same time. Start commands in input order. When a running command finishes, start the next unstarted command until all commands have finished. Read `n` from `--concurrency`; if that flag is absent, use 4. Keep results in input order.

3. Write `<report.html>` as one HTML document. The document includes `<title>Commands report</title>` and a table. The table's first row has header cells `Command`, `Exit code`, `Stdout`. After the header row, add one row per command in input order. Each row's cells contain the recorded command, exit code, and standard output as text. After writing the file, exit with status 0.
