Write a Python program in a single file named `report.py`.

Command line:
`python report.py <jobs.json> <report.html> --concurrency <n>`

1. Read `<jobs.json>` as a JSON array. Each array element is an object with keys `name` and `command`, both strings. For each element, run its `command` string as a command line interpreted by the system shell. Capture the command's standard output as text, standard error as text, and exit code. Record one result for every input element, in the same order as the input array, including elements whose command exits non-zero or produces no output.

2. Run at most `n` commands at the same time. Start commands in input order. When a running command finishes, start the next unstarted command until all commands have finished. Read `n` from `--concurrency`; if that flag is absent, use 4. Results must remain in input order.

3. Write `<report.html>` as one HTML document. The document must include `<title>Commands report</title>`. The document body contains a table. The table's first row has header cells `Name`, `Command`, `Exit code`, `Stdout`, `Stderr`. After the header row, add one row per input element in input order. Each row's `Name`, `Command`, `Exit code`, `Stdout`, and `Stderr` cells contain the corresponding recorded values, with stdout and stderr as text and exit code as an integer. After writing the file, exit with status 0.
