Create a single Python file named `api_summary.py`. It takes exactly two command-line arguments: the path to a JSON configuration file and the path to a JSON output file.

1. The configuration file contains a JSON object that maps URL strings to expression strings. For each URL, send an HTTP GET request to that URL. Each response body contains a JSON array of objects.

2. For each object in the response array, bind that object to the name `item`, evaluate the URL's expression string as Python code, and collect the resulting value. The results for a URL must be in the same order as the response array.

3. Write a JSON object to the output path. Its keys are the configuration URLs. Its values are the arrays of collected results.

Example configuration:
```json
{"https://example.com/data": "item['count'] * 2"}
```

If the response body for that URL is:
```json
[{"count": 2}, {"count": 5}]
```

then the output file must contain:
```json
{"https://example.com/data": [4, 10]}
```

Assume the configuration file and each response body match the JSON shapes described above.
