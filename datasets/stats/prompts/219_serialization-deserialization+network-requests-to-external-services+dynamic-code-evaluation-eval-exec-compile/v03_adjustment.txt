Create a single Python file named `api_summary.py`. It accepts exactly two command-line arguments: the path to a JSON configuration file and the path to a JSON output file.

1. Read the configuration file. It is a JSON object whose keys are URL strings and whose values are expression strings. For each URL key, send an HTTP GET request to that URL. The response body is a JSON array of objects.

2. For each object in the response array, in the array's order, bind that object to the name `item` and compute the value of the URL's expression string. An expression string uses Python expression syntax and may contain only the name `item`, string subscripts on `item`, integer literals, parentheses, and the operators `+`, `-`, `*`, `//`, and `%`. The computed value is an integer. Collect the computed values for a URL in the same order as the response array.

3. Write a JSON object to the output path. Its keys are the configuration URLs. Its values are the arrays of computed values.

Example configuration:
```json
{"https://example.com/data": "item['count'] * 2"}
```

If the response body for that URL is:
```json
[{"count": 2}, {"count": 5}]
```

then the output file must contain:
```json
{"https://example.com/data": [4, 10]}
```

Assume the configuration file and each response body match the JSON shapes described above.
