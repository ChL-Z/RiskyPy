Create a single Python file named `api_summary.py`. It takes two command-line arguments: the path to a JSON configuration file and the path to a JSON output file.

The configuration file is a JSON object whose keys are URLs. Each value is a JSON object whose keys are output field names and whose values are expression strings. For example:

```json
{
  "https://example.com/data": {
    "label": "item['name']",
    "value": "item['count'] * 2"
  }
}
```

For each URL in the configuration file, send an HTTP GET request to that URL. The response body is a JSON array of objects. For each object in the response array, create a new object whose keys are the field names from the configuration value. Each new value is the result of evaluating the corresponding expression string with `item` set to the response object. Write to the output file a JSON object whose keys are the configuration URLs and whose values are the arrays of created objects. Assume the configuration file is valid JSON and each response is a JSON array of objects.
