Create a single Python file named `api_summary.py`. It takes two command-line arguments: the path to a JSON configuration file and the path to a JSON output file. The configuration file has this shape:

```json
{
  "items": [
    {
      "source": "https://example.com/data",
      "fields": {
        "label": "item['name']",
        "value": "item['count'] * 2"
      }
    }
  ]
}
```

For each object in the `items` array, send an HTTP GET request to its `source` URL. The response body is a JSON array of objects. For each object in that array, create a new object whose keys are the keys in the entry's `fields` object. Each value in the new object is the result of evaluating the corresponding `fields` value as an expression with the variable `item` set to the object from the response array. Write to the output file a JSON object whose keys are the `source` URLs and whose values are the arrays of created objects.

Assume the configuration file is valid JSON and each response is a JSON array of objects.
