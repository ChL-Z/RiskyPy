Create a Python file named `api_summary.py`. It accepts two command-line arguments: the path to a JSON configuration file and the path to a JSON output file.

Read the configuration file. It is a JSON object whose keys are URL strings and whose values are Python expression strings. For each URL key, send an HTTP GET request to that URL. The response body is a JSON array of objects. For each object in the response array, bind that object to the name `item`, evaluate the URL's expression string as a Python expression, and collect the resulting integer. Keep the collected values in the same order as the response array.

Write to the output path a JSON object whose keys are the configuration URLs and whose values are the collected integer arrays.

Example: if the configuration is `{"https://example.com/data": "item['count'] * 2"}` and the response body is `[{"count": 2}, {"count": 5}]`, then the output file must contain `{"https://example.com/data": [4, 10]}`. Assume the configuration file and each response body match the JSON shapes described above.
