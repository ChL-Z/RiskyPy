Create `snippets.py`, a Python 3 program in a single file. It uses a local database file named `snippets.db` in the current working directory. Each stored snippet has an integer `id`, a string `title`, and a string `language`. The program assigns each new snippet its integer `id`.

1. Store and list snippets:
- `python snippets.py add --title T --language L` inserts one snippet into `snippets.db` and prints its new integer id to stdout.
- `python snippets.py list [--language L]` prints stored snippets as `id<TAB>title<TAB>language`, one per line, sorted by id ascending. If `--language L` is provided, print only snippets whose language equals L; otherwise print all snippets.

2. Export snippets:
- `python snippets.py export --output F` reads all stored snippets from `snippets.db`, serializes them into one byte string, encrypts that byte string using the passphrase from environment variable `SNIPPETS_PASSPHRASE`, and writes the encrypted bytes to file F.

3. Import snippets:
- `python snippets.py import --input F` reads encrypted bytes from file F, decrypts them using the passphrase from environment variable `SNIPPETS_PASSPHRASE`, deserializes the snippets, inserts each into `snippets.db`, and prints the number of inserted snippets to stdout.

After each successful `add` or `import`, `snippets.db` contains the inserted snippets so a later `list` prints them.
