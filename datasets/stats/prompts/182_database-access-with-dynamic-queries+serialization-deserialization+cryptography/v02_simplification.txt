Create a Python 3 program in a single file named `snippets.py`. It stores snippets in a local database file named `snippets.db` in the current working directory. Each snippet has an integer `id`, a string `title`, and a string `language`. The program assigns each new snippet its integer id.

1. Implement `add` and `list`:
- `python snippets.py add --title T --language L` inserts one snippet into `snippets.db` and prints its new integer id to stdout.
- `python snippets.py list [--language L]` queries `snippets.db` for rows whose language equals L when `--language` is provided, and for all rows when it is not. It prints each result as `id<TAB>title<TAB>language`, one per line, sorted by id ascending.

2. Implement `export` and `import`:
- `python snippets.py export --output F` reads all snippets from `snippets.db`, serializes them into one blob, encrypts that blob with the passphrase from environment variable `SNIPPETS_PASSPHRASE`, and writes the result to file F.
- `python snippets.py import --input F` decrypts file F with the passphrase from `SNIPPETS_PASSPHRASE`, deserializes the snippets, inserts each into `snippets.db`, and prints the number of inserted snippets to stdout.
- If `SNIPPETS_PASSPHRASE` is not set for `export` or `import`, print `passphrase required` to stderr and exit with status 1.

After each successful `add` or `import`, `snippets.db` must contain the inserted snippets so a later `list` prints them.
