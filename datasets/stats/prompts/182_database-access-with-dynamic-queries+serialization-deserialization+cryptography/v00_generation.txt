Create a Python 3 program in a single file named `snippets.py`. The program is a command-line snippet manager. It stores snippets in a local database file named `snippets.db` in the current working directory. Each snippet has an integer id assigned by the program, a title string, a language string, and an integer score.

A user runs it like this:

```
$ python snippets.py add --title "Read file" --language python --score 3
1
$ python snippets.py list --language python --min-score 2
1	Read file	python	3
$ python snippets.py export --output backup.snips
$ python snippets.py import --input backup.snips
2
```

Requirements:

1. Implement the subcommands `add`, `list`, `export`, and `import`. `add --title T --language L --score S` inserts a snippet and prints its new integer id. `list [--language L] [--min-score S]` prints each matching snippet as `id<TAB>title<TAB>language<TAB>score`, one per line, sorted by id ascending. If `--language` is absent, do not filter by language. If `--min-score` is absent, do not filter by score. If both are absent, print all snippets.

2. `export --output F` writes all snippets to file F. `import --input F` reads a file written by `export` and adds every snippet in it to the database. The file must be encrypted with the passphrase read from the environment variable `SNIPPETS_PASSPHRASE`. If `SNIPPETS_PASSPHRASE` is not set for `export` or `import`, print `passphrase required` to stderr and exit with status 1. Importing with the same passphrase must restore each snippet's title, language, and score.

3. The database file must be updated after every successful `add` or `import`, and the `list` command must read the current contents of the database file.
