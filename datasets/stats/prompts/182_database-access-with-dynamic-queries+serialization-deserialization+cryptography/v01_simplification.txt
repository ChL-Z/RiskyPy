Create a Python 3 program in a single file named `snippets.py`. It manages snippets in a local database file named `snippets.db` in the current working directory. Each snippet has an integer id assigned by the program, a title string, a language string, and an integer score.

1. Implement `add` and `list`. `python snippets.py add --title T --language L --score S` inserts a snippet and prints its new integer id to stdout. `python snippets.py list [--language L]` queries the database for snippets matching the optional language filter and prints each result as `id<TAB>title<TAB>language<TAB>score`, one per line, sorted by id ascending. If `--language` is omitted, print all snippets.

2. Implement `export` and `import`. `python snippets.py export --output F` serializes all snippets to file F and encrypts the file with the passphrase read from environment variable `SNIPPETS_PASSPHRASE`. `python snippets.py import --input F` decrypts file F with the passphrase from `SNIPPETS_PASSPHRASE`, deserializes the snippets, inserts each into the database, and prints the number of inserted snippets to stdout. If `SNIPPETS_PASSPHRASE` is not set for `export` or `import`, print `passphrase required` to stderr and exit with status 1.

3. The database file must be updated after every successful `add` or `import`. The `list` command must read the current contents of the database file. Importing a file written by `export` with the same passphrase must restore each snippet's title, language, and score.
