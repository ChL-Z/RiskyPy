Write a Python program in a single file named `jobrunner.py`.

The program takes a file path as its first command-line argument and an optional `--concurrency N` argument. If `--concurrency` is omitted, N is 1. Each non-empty line in the file is a command.

For each command, replace every `{{expr}}` placeholder with the decimal integer value of `expr`. `expr` contains only non-negative integer literals, `+`, and `*`, with `*` evaluated before `+`. Then run the resulting command as an external command and capture its standard output and standard error together into one string. Run at most N commands at the same time.

After all commands finish, print to standard output one JSON object per input command, one object per line. Each object has exactly keys `command`, `output`, and `exit_code`. `command` is the command after placeholder replacement, `output` is the captured combined output, and `exit_code` is an integer. The order of the JSON objects does not matter.
