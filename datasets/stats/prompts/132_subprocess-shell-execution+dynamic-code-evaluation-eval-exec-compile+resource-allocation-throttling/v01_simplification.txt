Implement a Python program in a single file named `jobrunner.py`. It takes one positional argument: the path to a text file. Each non-empty line of that file is a command. Before running a command, replace every `{{...}}` placeholder in it with the decimal integer result of the arithmetic expression between the braces. Expressions contain only non-negative integer literals, `+`, `*`, and parentheses. The program runs each resulting command as an external command, capturing its standard output and standard error together into one string. It accepts a `--concurrency` flag whose value is the maximum number of external commands allowed to run at the same time. The program prints one JSON object per input line to standard output, in input order. Each object has keys `line` (1-based line number in the file, counting empty lines), `command` (the command after placeholder replacement), `output` (the captured combined output), and `exit_code` (integer).
