Implement a Python program in a single file named `jobrunner.py`. The program reads command lines from a file whose path is given as the first positional command-line argument. Empty lines are ignored. Each remaining line is a command string that may contain zero or more `{{...}}` placeholders. For each placeholder, replace the text `{{...}}` with the decimal representation of the integer result of computing the expression between the braces; the expression contains only integer literals, `+`, `-`, `*`, `%`, and parentheses. The program runs each resulting command string as an external command, capturing standard output and standard error together as a single text string. The program accepts `--concurrency` (the maximum number of external commands running at the same time) and `--rate` (the maximum number of external commands started per second across the whole run). The program writes to stdout one JSON object per non-empty input line, in the same order as the input lines, with keys `line` (the 1-based line number in the input file, counting empty lines), `command` (the post-substitution command string), `output` (the captured combined output), and `exit_code` (an integer). Example: `python jobrunner.py commands.txt --concurrency 4 --rate 2` with `commands.txt` containing `echo {{2+3}}` and `sleep {{1+1}}`.
