Write a Python program in a single file named `jobrunner.py`.

The program reads a text file path from its first command-line argument. Each non-empty line in that file is a command. For each command, replace every `{{...}}` placeholder with the decimal integer result of the arithmetic expression between the braces. Expressions contain only non-negative integer literals, `+`, and `*`. Then run the resulting command as an external command, capturing its standard output and standard error together into one string.

The program accepts an optional `--concurrency N` argument. It must run at most N commands at the same time. If `--concurrency` is omitted, N is 1.

After all commands finish, print one JSON object per input line to standard output. The order of the objects does not matter. For each line, the object has keys `line` (1-based line number in the file, counting empty lines), `command` (the command after placeholder replacement), `output` (the captured combined output), and `exit_code` (integer).
