Write a Python program in a single file named `audit_query.py`.

1. Token check: Read the file path from environment variable `AUDIT_TOKEN_FILE` and the token text from environment variable `AUDIT_TOKEN`. Read the text of the file named by `AUDIT_TOKEN_FILE` and remove one trailing newline if present. If either environment variable is unset, the file cannot be read, or that text after removing one trailing newline does not equal `AUDIT_TOKEN`, print `error: authorization failed` to stderr and exit with status 1. Do not access the database or write the log in this case.

2. Query and output: Accept command-line arguments `--db PATH`, `--table NAME`, and `--status TEXT`. The file at `--db` is a SQLite database. The table named by `--table` has columns `id`, `owner`, `status`. Select rows where the `status` column equals the text given by `--status`. Print each selected row to stdout as one JSON object per line with keys `id`, `owner`, `status`. If the database cannot be opened, the table is not present, or the query fails, print `error: query failed` to stderr and exit with status 1.

3. Logging: If the token check passes, append one line to the file named by environment variable `AUDIT_LOG` after the query attempt. The line has three tab-separated fields: the current UTC time in `YYYY-MM-DDTHH:MM:SSZ`, the number of rows printed, and `ok` if the query completed, otherwise `error`. If the query fails, use `0` as the row count. If `AUDIT_LOG` is unset or the file cannot be appended to, print `error: log failed` to stderr and exit with status 1.
