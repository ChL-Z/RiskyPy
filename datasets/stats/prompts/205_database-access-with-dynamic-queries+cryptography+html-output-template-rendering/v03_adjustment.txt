Write a Python program in a single file named `report.py`. The program takes four command-line arguments in order: a path to a SQLite database file, a path to a query file, a path to a JSON file, and a path to an output HTML file.

1. The query file contains a SQL statement with placeholders written as `{{name}}`. The JSON file contains a single object with string values. The program executes the SQL statement against the database, supplying for each `{{name}}` the value of key `name` from the JSON object, or the empty string if the key is absent, and fetches all rows of the result.

2. The program renders HTML by replacing the placeholder `{{table}}` in the template string `<html><body>{{table}}</body></html>` with an HTML `<table>` element. The table contains one `<tr>` element for each row of the query result. Each `<tr>` contains one `<td>` element for each value in that row, with the value converted to a string. Any character in a value that has special meaning in HTML text is written as its corresponding HTML character reference. The program writes the rendered HTML to the output file.

3. The program computes a hash of the rendered HTML and prints the hash to stdout as a lowercase hexadecimal string followed by a newline.
