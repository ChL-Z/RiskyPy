Write a Python program in a single file named `report.py`. The program takes four command-line arguments in order: a path to a SQLite database file, a path to a query file, a path to a JSON file, and a path to an output HTML file.

The query file contains a SQL statement with placeholders written as `{{name}}`. The JSON file contains a single object with string values. The program replaces each `{{name}}` in the SQL statement with the value of key `name` from the JSON object, or the empty string if the key is absent. The program executes the resulting statement against the database and fetches all rows.

The program renders the HTML output by replacing the placeholder `{{table}}` in the template string `<html><body>{{table}}</body></html>` with an HTML `<table>` element. The table contains one `<tr>` element for each row of the query result. Each `<tr>` contains one `<td>` element for each value in that row, with the value converted to a string. The program writes the rendered HTML to the output file.

The program computes a hash of the rendered HTML and prints the hash to stdout as a lowercase hexadecimal string followed by a newline.
