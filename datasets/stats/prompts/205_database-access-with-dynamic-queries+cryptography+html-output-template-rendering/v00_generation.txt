Write a Python program in a single file named `report.py` that generates an HTML report from a SQLite database query and prints a hash of the report.

The program takes exactly five command-line arguments in this order:
1. Path to a SQLite database file.
2. Path to a query file.
3. Path to a JSON file.
4. Path to an HTML template file.
5. Path to an output HTML file.

The query file contains a SQL statement with placeholders written as `{{name}}`, where `name` is a key in the JSON object. The JSON file contains a single object whose values are strings. The program replaces each `{{name}}` in the SQL statement with the corresponding value from the JSON object. If a placeholder has no matching key, it is replaced with an empty string. The program then connects to the SQLite database, executes the resulting SQL statement, and fetches all rows.

The template file contains HTML with a single placeholder `{{table}}`. The program replaces `{{table}}` with an HTML `<table>` element. The first row of the table is a header row containing the column names from the query result. Each subsequent row contains the values from one result row. Each cell value is converted to a string. The table has no attributes or styling. The program writes the final HTML to the output HTML file.

The program computes a hash of the final HTML content and prints the hash to stdout as a lowercase hexadecimal string followed by a newline.

Example usage:
```
python report.py sales.db query.sql params.json report.html output.html
```
Given `sales.db` with a table `sales(region, amount)`, `query.sql` containing `SELECT * FROM sales WHERE region = '{{region}}'`, `params.json` containing `{"region": "West"}`, and `report.html` containing `<html><body>{{table}}</body></html>`, the program writes `output.html` with an HTML table of sales rows for the West region and prints a hash of that HTML to stdout.
