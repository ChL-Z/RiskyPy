Write a Python file `cmd_cache.py`. The script receives an argument list: the command name as `sys.argv[1]` and its arguments as `sys.argv[2:]`. It reads a cache file named `.cmd_cache` from the current working directory when that file exists. The cache file stores a mapping from each argument list (the command and its arguments after the script name) to the stdout text captured when that command was previously run.

1. If the current argument list is already a key in the cache, print the cached stdout to stdout and exit with status 0 without running the command.

2. If the current argument list is not in the cache, run the external command named by the first element of the argument list, passing the remaining elements as arguments. Capture the command's stdout and stderr. Print the stdout to stdout, add the stdout text to the cache under the current argument list, write the updated cache to `.cmd_cache`, and exit with status 0.

3. If the external command exits with a non-zero status, print its captured stderr to stderr, exit with that same non-zero status, and leave `.cmd_cache` unchanged.
