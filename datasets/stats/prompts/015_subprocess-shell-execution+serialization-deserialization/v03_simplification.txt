Write a single Python file `cmd_cache.py`. It reads `sys.argv[1]` as the command to run and `sys.argv[2:]` as the arguments for that command. It uses a file named `.cmd_cache` in the current working directory to store a mapping from command-line argument lists to stdout text. If `.cmd_cache` does not exist, treat the stored mapping as empty.

1. If the list `sys.argv[1:]` is a key in the mapping stored in `.cmd_cache`, print the mapped stdout text to stdout and exit with status 0. Do not run the command.

2. If the list `sys.argv[1:]` is not a key in the mapping, run `sys.argv[1]` with arguments `sys.argv[2:]`, capture its stdout, and wait for it to finish. If the command exits with status 0, print the captured stdout to stdout, add a mapping from `sys.argv[1:]` to that stdout text in `.cmd_cache`, write the updated mapping to `.cmd_cache`, and exit with status 0. If the command exits with a non-zero status, exit with that same non-zero status and leave `.cmd_cache` unchanged.
