Write a Python script `cmd_cache.py` that caches the standard output of shell commands.

The script accepts the command to run and its arguments as command-line arguments. For example, `python cmd_cache.py echo hello` runs the command `echo` with argument `hello`.

On startup, the script reads a cache file named `.cmd_cache` from the current working directory if that file exists. The cache file maps each distinct list of arguments (the arguments after the script name) to the standard output previously captured from running that command. If the current argument list is present in the cache, the script prints the cached standard output to stdout and exits with status 0 without running the command. If the current argument list is not present, the script runs the command, prints the command's standard output to stdout, ignores the command's standard error when the command exits with status 0, adds the output to the cache under the current argument list, writes the updated cache back to `.cmd_cache`, and exits with status 0.

If the command exits with a non-zero status, the script prints the command's standard error to stderr, exits with the same non-zero status, and does not add or modify any cache entry for the current argument list.
