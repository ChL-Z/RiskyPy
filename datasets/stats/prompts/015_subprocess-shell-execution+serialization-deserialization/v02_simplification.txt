Write a single Python file `cmd_cache.py`.

The script reads `sys.argv[1]` as the command to run and `sys.argv[2:]` as that command's arguments. It uses a file named `.cmd_cache` in the current working directory to store a mapping from argument lists to stdout text. The argument list for the current run is `sys.argv[1:]`. If `.cmd_cache` does not exist, treat the stored mapping as empty.

1. If `sys.argv[1:]` is present in the mapping stored in `.cmd_cache`, print the mapped stdout text to stdout and exit with status 0. Do not run the command.

2. If `sys.argv[1:]` is not present in the mapping, run `sys.argv[1]` with arguments `sys.argv[2:]`, capture its stdout and stderr, print the captured stdout to stdout, add a mapping from `sys.argv[1:]` to that stdout text in `.cmd_cache`, write the updated mapping to `.cmd_cache`, and exit with status 0.

3. If the command exits with a non-zero status, print its captured stderr to stderr, exit with that same non-zero status, and leave `.cmd_cache` unchanged.
