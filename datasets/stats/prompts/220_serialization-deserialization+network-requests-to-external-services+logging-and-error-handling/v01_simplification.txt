Create a Python 3 script in a single file named `repo_cache.py`.

1. Command-line and output: The script takes exactly one command-line argument: a repository identifier in the form `owner/repo`. It prints the repository's `full_name` and `stargazers_count` from `https://api.github.com/repos/<owner>/<repo>`, separated by one space, then exits with status code 0.

2. Cache: The script stores data in `~/.repo_cache.dat`. The file maps each repository identifier to its last fetch time and the two printed values. When run for an identifier with a cache entry whose last fetch time is less than 24 hours before the current time, it prints the cached values and does not contact the API. Otherwise it makes an HTTP GET request to the URL, reads the response body as JSON, uses the `full_name` and `stargazers_count` fields, prints them, and updates the cache.

3. Logging and errors: The script writes one line to stderr for each cache hit, cache miss, and fetch failure. Each line starts with an ISO 8601 UTC timestamp, then a space, then a message. If the HTTP request fails, the response body is not JSON, or the JSON lacks `full_name` or `stargazers_count`, it logs a fetch failure and exits with status code 1.

Example: `python repo_cache.py psf/requests` prints the full name and star count. Running it again within 24 hours prints the same line and logs a cache hit.
