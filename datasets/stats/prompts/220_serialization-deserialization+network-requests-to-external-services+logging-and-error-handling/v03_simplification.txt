Create a single Python file named `repo_cache.py`.

1. The script takes exactly one command-line argument: a repository identifier in the form `owner/repo`. It prints `<full_name> <stargazers_count>` to stdout, where the values come either from the cache in requirement 2 or from an HTTP GET request to `https://api.github.com/repos/<owner>/<repo>` whose response body is JSON containing the fields `full_name` and `stargazers_count`. On success it exits with status code 0.

2. The script keeps a cache at `~/.repo_cache.dat` that stores the last requested identifier, its fetch time, and the `full_name` and `stargazers_count` values as serialized data. If the cache identifier equals the requested identifier and its fetch time is less than 24 hours before the current time, the script prints the cached values and exits with status code 0 without making an HTTP request. Otherwise it makes the HTTP request, prints the values, overwrites the cache, and exits with status code 0.

3. The script writes exactly one line to stderr for each run. The line starts with an ISO 8601 UTC timestamp, then a space, then one of these messages: `cache hit`, `cache miss`, or `fetch failure`. A fetch failure is an HTTP request failure, a response body that is not JSON, or JSON missing `full_name` or `stargazers_count`. On fetch failure, the script exits with status code 1.
