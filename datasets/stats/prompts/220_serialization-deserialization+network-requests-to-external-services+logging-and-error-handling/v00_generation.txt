Create a Python 3 script in a single file named `repo_cache.py`. The script accepts exactly one command-line argument: a repository identifier in the form `owner/repo`. It must print the repository's `full_name` and `stargazers_count` from GitHub's public API, separated by a single space, and exit with status code 0. The script must cache the result in a file at `~/.repo_cache.dat` so that re-running the script within 24 hours prints the same values without contacting the API again. The cache file must map each repository identifier to its last fetch time and the two printed values. On a cache miss or expired entry, fetch `https://api.github.com/repos/<owner>/<repo>`, read the response body as JSON, and use the `full_name` and `stargazers_count` fields. Log to stderr one line per cache hit, cache miss, fetch attempt, and fetch failure. Each log line must begin with an ISO 8601 UTC timestamp followed by a space and a message. On any fetch failure or a response body that does not contain both required fields, log the failure and exit with status code 1. Example invocation: `python repo_cache.py psf/requests` should print the repository's full name and star count; running it again within 24 hours should print the same line and log a cache hit.
