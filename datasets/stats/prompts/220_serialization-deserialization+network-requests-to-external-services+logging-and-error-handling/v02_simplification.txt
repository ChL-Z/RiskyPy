Create a Python 3 script in a single file named `repo_cache.py`.

1. The script accepts exactly one command-line argument: a repository identifier in the form `owner/repo`. It makes an HTTP GET request to `https://api.github.com/repos/<owner>/<repo>`, reads the response body as JSON, prints the values of the `full_name` and `stargazers_count` fields separated by one space, and exits with status code 0.

2. The script stores a cache in `~/.repo_cache.dat`. The cache holds the last requested identifier, its fetch time, and the two printed values. If the cache identifier matches the requested identifier and the fetch time is less than 24 hours before the current time, the script prints the cached values and exits with status code 0 without making an HTTP request. Otherwise the script makes the request, prints the values, overwrites the cache, and exits with status code 0. The cache is written and read as serialized data.

3. The script writes one line to stderr for each cache hit, cache miss, and fetch failure. Each line starts with an ISO 8601 UTC timestamp, then a space, then a message. A fetch failure is: the HTTP request fails, the response body is not JSON, or the JSON lacks `full_name` or `stargazers_count`. On fetch failure, the script logs the failure and exits with status code 1.

Example: `python repo_cache.py psf/requests` prints the full name and star count. Running it again within 24 hours prints the same line and logs a cache hit.
