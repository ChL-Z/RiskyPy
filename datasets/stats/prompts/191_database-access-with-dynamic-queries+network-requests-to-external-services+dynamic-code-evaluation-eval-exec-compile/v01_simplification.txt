Write a Python program in a single file named `alertcheck.py`. It is run as `python alertcheck.py checks.json`, where `checks.json` is the path to a JSON file with one key `"checks"` whose value is a list of objects with keys `"name"` (string), `"db"` (string, path to an existing SQLite database file), `"query"` (string, a SQL statement that may contain `{{...}}` placeholders), `"threshold"` (number), and `"webhook"` (string, an absolute URL).

For each check in the order the checks appear in the list:

1. Replace every `{{...}}` placeholder in `"query"` with the value of the arithmetic expression inside the braces, rendered as a decimal integer. The expression uses integer literals, the operators `+ - * /`, unary minus, and parentheses. Run the resulting SQL statement against the SQLite database at `"db"` and take the value in the first column of the first result row as an integer.

2. If that integer is greater than `"threshold"`, send an HTTP POST request to `"webhook"` whose body is the JSON object `{"check": "<name>", "value": <integer>}` and whose `Content-Type` request header is `application/json`. If a response is received with a status code below 400, the check's outcome is `sent`; if a response is received with a status code of 400 or higher, or the request cannot be completed, the outcome is `failed`. If the integer is not greater than the threshold, no request is made and the outcome is `skipped`.

3. Print exactly one line to stdout containing the check's `"name"`, the integer value, and the outcome, separated by single spaces. Write nothing else to stdout.
