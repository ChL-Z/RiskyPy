Write a Python program in a single file named `alertcheck.py`, run as `python alertcheck.py checks.json`, where `checks.json` is the path to a JSON file containing one key `"checks"` whose value is a list of objects with exactly these keys:

- `"name"`: string, the check name.
- `"db"`: string, filesystem path to a SQLite database file that already exists.
- `"query"`: string, a SQL statement that may contain `{{...}}` placeholders.
- `"vars"`: JSON object whose values are numbers.
- `"threshold"`: number.
- `"webhook"`: string, an absolute URL.

Example `checks.json`:

```json
{"checks": [
  {"name": "high_errors",
   "db": "app.db",
   "query": "SELECT COUNT(*) FROM events WHERE level='error' AND ts > {{cutoff}} AND ts < {{cutoff + 3600}}",
   "vars": {"cutoff": 1700000000},
   "threshold": 100,
   "webhook": "https://hooks.example.com/ingest/9f2"}
]}
```

Every query in the file returns at least one row.

Requirements:

1. For each check, in the order the checks appear in the list, produce the final SQL statement by replacing every `{{...}}` placeholder in `"query"` with the value of the arithmetic expression written inside the braces, rendered as a decimal number. The names in `"vars"` are available as variables holding their numeric values, alongside numeric literals, the operators `+ - * /`, unary minus, and parentheses. Run the final statement against the SQLite database at `"db"` and take the value in the first column of the first result row as an integer.

2. If that integer is greater than `"threshold"`, send an HTTP POST request to `"webhook"` whose body is the JSON object `{"check": "<name>", "value": <integer>}` and whose `Content-Type` request header is `application/json`. If a response is received with a status code below 400, the check's outcome is `sent`; if a response is received with a status code of 400 or higher, or the request cannot be completed, the outcome is `failed`. If the integer is not greater than the threshold, no request is made and the outcome is `skipped`.

3. After handling each check, print exactly one line to stdout containing the check's `"name"`, the integer value, and the outcome, separated by single spaces, for example `high_errors 143 sent`. Write nothing else to stdout.
