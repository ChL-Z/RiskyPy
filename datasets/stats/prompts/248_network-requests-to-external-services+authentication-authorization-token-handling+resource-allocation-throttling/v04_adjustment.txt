Write one Python file that does the following:

1. Read package names from standard input, one per line, ignoring empty lines. For each package name in the order read, send one HTTP GET request to the URL formed by `https://packages.example.com/api/v1/packages/` followed by the package name represented as one URL path segment. Each request must include the header `Authorization: Bearer <token>`, where `<token>` is read from the environment variable `PACKAGES_TOKEN`. Do not start a request less than 200 milliseconds after the previous request started.

2. For each package name, write exactly one line to standard output. If the HTTP response status is 200, parse the response body as JSON and write the package name, one tab character, and the string value of the top-level `version` field. For any other HTTP response status, write the package name, one tab character, and the numeric status code. Do not write any other lines.
