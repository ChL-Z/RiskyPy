Write one Python file. It reads package names from stdin, one per line, skipping empty lines. For each name in input order, send an HTTP GET request to `https://packages.example.com/api/v1/packages/{name}`, inserting the name unchanged into the URL. Every request includes the header `Authorization: Bearer <token>`, where `<token>` is the value of the environment variable `PACKAGES_TOKEN`. Send no more than one request every 200 milliseconds.

For each input package name, write exactly one line to stdout. If the response status is 200, parse the JSON response body and write `name<TAB>version`, using the `version` field. For any other response status, write `name<TAB>status`, where `status` is the numeric HTTP status code. Use one tab character between fields.
