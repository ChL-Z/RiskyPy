Write a Python program in a single file. The program reads package names from stdin, one per line, ignoring empty lines. For each package name, it sends an HTTP GET request to `https://packages.example.com/api/v1/packages/{name}`, where `{name}` is inserted unchanged. Each request must carry the header `Authorization: Bearer <token>`, where `<token>` is read from the environment variable `PACKAGES_TOKEN`. The program writes one line to stdout for each input package name, in the same order as the input, in the format `name<TAB>version<TAB>license`, using the `version` and `license` values from the JSON response body. If the response status is 404, write `name<TAB>not-found<TAB>not-found`. If the response status is 403, write `name<TAB>forbidden<TAB>403`. For any other response status outside 200-299, write `name<TAB>error<TAB>status`, where `status` is the numeric HTTP status code. The program must not start more than 5 requests in any 1000 ms interval. Example: if stdin is

```
alpha
beta
```

and the service returns `{"version": "1.2.3", "license": "MIT"}` for alpha and HTTP 404 for beta, stdout is

```
alpha	1.2.3	MIT
beta	not-found	not-found
```

The program must be contained in one Python file and can be run with `python program.py < packages.txt`.
