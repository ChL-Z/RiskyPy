Write a Python program in one file that is run as `python program.py < packages.txt`. It reads package names from stdin, one per line, skipping empty lines. For each package name in input order, it sends an HTTP GET request to `https://packages.example.com/api/v1/packages/{name}`, where `{name}` is inserted unchanged. Each request includes the header `Authorization: Bearer <token>`, where `<token>` is read from the environment variable `PACKAGES_TOKEN`. The program sends at most 5 requests in any 1000 ms interval. For each input package name, it writes exactly one line to stdout: if the response status is 200, parse the JSON response body and write `name<TAB>version<TAB>license` using the `version` and `license` fields; for any other response status, write `name<TAB>error<TAB>status`, where `status` is the numeric HTTP status code. Example: if stdin is

alpha
beta

and the service returns `{"version": "1.2.3", "license": "MIT"}` for alpha and HTTP 404 for beta, stdout is

alpha	1.2.3	MIT
beta	error	404
