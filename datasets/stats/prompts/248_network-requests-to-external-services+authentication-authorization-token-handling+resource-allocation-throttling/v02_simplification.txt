Write one Python file. It reads package names from stdin, one per line, skipping empty lines. For each name in input order, send an HTTP GET request to `https://packages.example.com/api/v1/packages/{name}`, inserting the name unchanged into the URL. Each request includes the header `Authorization: Bearer <token>`, where `<token>` is read from the environment variable `PACKAGES_TOKEN`. Send at most 5 requests in any 1000-millisecond interval.

For each input package name, write exactly one line to stdout. If the response status is 200, parse the JSON response body and write `name<TAB>version`, using the `version` field. For any other response status, write `name<TAB>error<TAB>status`, where `status` is the numeric HTTP status code. Use one tab character between fields.
