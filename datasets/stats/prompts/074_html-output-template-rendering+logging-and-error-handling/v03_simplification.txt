Write one Python file named `fill_template.py`. It is run from the command line as:

`python fill_template.py <template_path> <data_path>`

1. Read `<template_path>` as UTF-8 text. Read `<data_path>` as UTF-8 JSON whose root value is an object mapping string keys to string values. If `<data_path>` cannot be read, cannot be parsed as JSON, or its root value is not an object, write exactly `error: cannot read data` to stderr and exit with status 1. Write nothing to stdout in that case.

2. Replace every `{{key}}` in the original template text with the value stored under `key` in the JSON object. `key` is one or more characters that are not `{` or `}`. If `key` is absent from the JSON object, replace that occurrence with the empty string and write exactly `missing key: <key>` to stderr for each missing placeholder occurrence. Write the resulting HTML text to stdout.
