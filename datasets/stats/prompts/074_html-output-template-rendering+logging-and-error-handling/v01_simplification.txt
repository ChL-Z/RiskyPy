Write one Python file, `fill_template.py`, run from the command line as:

```
python fill_template.py <template_path> <data_path>
```

Requirement 1 — inputs and data errors. Read `<template_path>` as UTF-8 HTML text. Read `<data_path>` as UTF-8 JSON whose root value is an object mapping string keys to string values. If `<data_path>` cannot be read, cannot be parsed as JSON, or its root value is not an object, write exactly `error: cannot read data` to stderr and exit with status 1. Do not write anything to stdout in that case.

Requirement 2 — rendering and missing keys. Replace every occurrence of `{{key}}` in the HTML template text with the value stored under `key` in the JSON object. `key` is one or more characters that are not `{` or `}`. If `key` is absent from the JSON object, replace that occurrence with the empty string and write exactly `missing key: <key>` to stderr, in the order the occurrences appear in the template. Text inserted by a replacement is not scanned again for placeholders. Write the final HTML text to stdout exactly, adding no newline that was not already present in the template.
