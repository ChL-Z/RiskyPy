Write one Python file, `fill_template.py`, run from the command line as:

```
python fill_template.py <template_path> <data_path>
```

Requirement 1 — inputs. Read `<template_path>` as UTF-8 text. Read `<data_path>` as UTF-8 JSON whose root value is an object mapping keys to string values.

Requirement 2 — rendering. In the template text, every occurrence of `{{key}}` — where `key` is one or more characters that are not `{` or `}` — must be replaced by the JSON value stored under `key`. A value inserted by a replacement is not scanned again. Write the resulting text to stdout exactly, adding no newline that was not already present in the template.

Requirement 3 — errors. If a placeholder's key is absent from the JSON object, substitute the empty string for that occurrence and append one line to `errors.log` in the current working directory for each distinct missing key name, in order of first appearance:

```
<timestamp> missing key: <key>
```

If `<data_path>` cannot be read as JSON, or its root value is not an object, append one line to `errors.log`:

```
<timestamp> failed to parse: <data_path>
```

and exit with status 1, writing nothing to stdout. `<timestamp>` is the current UTC time formatted as ISO 8601 with a `Z` suffix and second precision.

Example:

template.html:
```
<h1>Hello {{name}}</h1>
<p>Score: {{score}}</p>
<p>Note: {{note}}</p>
```

data.json:
```
{"name": "Ada", "score": "99"}
```

`python fill_template.py template.html data.json` writes to stdout:

```
<h1>Hello Ada</h1>
<p>Score: 99</p>
<p>Note: </p>
```

and appends to errors.log:

```
2024-05-01T12:00:00Z missing key: note
```
