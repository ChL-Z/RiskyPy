Write a Python program in a single file named `render_report.py`. It renders an HTML page from an HTML template file and a JSON file of numeric values, and it records each run in a log file.

The program is run as:

    python render_report.py TEMPLATE_PATH VALUES_PATH

1. Rendering. Read `TEMPLATE_PATH` as UTF-8 text and `VALUES_PATH` as a UTF-8 JSON object whose keys are strings and whose values are numbers. Replace every `{{expr}}` placeholder in the template with the numeric value of the arithmetic expression `expr`, formatted with exactly two digits after the decimal point. `expr` is the text between the braces and may contain decimal number literals, whitespace, the operators `+`, `-`, `*`, `/`, parentheses, and names that are keys of the values object. A placeholder may appear any number of times. Text produced by a replacement is not scanned again for placeholders. Every other character of the template, including HTML tags and newlines, is copied to the output unchanged. Write the rendered page to stdout and exit with status code 0.

2. Logging and failures. Append one line to `render.log` in the current working directory for every run. After a successful render, the line is `<timestamp> INFO rendered <TEMPLATE_PATH>`. If the run fails, the line is `<timestamp> ERROR <message>`, where `<message>` is a non-empty text description of the failure, nothing is written to stdout, and the exit status is 1. A run fails when `TEMPLATE_PATH` or `VALUES_PATH` cannot be read, when the contents of `VALUES_PATH` are not a JSON object whose values are numbers, or when a `{{expr}}` placeholder contains a name absent from the values object or does not hold an arithmetic expression that produces a number. `<timestamp>` is the local date and time in ISO 8601 form with second precision, for example `2024-05-17T09:31:04`. Log lines are appended, and earlier content of `render.log` is left in place.
