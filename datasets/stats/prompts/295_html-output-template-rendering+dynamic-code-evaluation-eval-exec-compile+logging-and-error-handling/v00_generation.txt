Write a Python program in a single file named `render_report.py`. It renders an HTML page from an HTML template file and a JSON file of numeric values, and it records what it does in a log file.

The program is run as:

    python render_report.py TEMPLATE_PATH VALUES_PATH

## Requirements

**1. Rendering.** Read `TEMPLATE_PATH` as UTF-8 text and `VALUES_PATH` as a UTF-8 JSON object whose keys are strings and whose values are numbers. Write the rendered page to stdout and exit with status code 0.

Two placeholder forms appear in the template text and are replaced:

- `{{key}}` is replaced by the number stored under `key` in the values object, written with exactly two digits after the decimal point.
- `[[expr]]` is replaced by the value of the arithmetic expression `expr`, written with exactly two digits after the decimal point. `expr` is the text between the brackets and may contain decimal number literals, whitespace, the operators `+`, `-`, `*`, `/`, parentheses, and names that are keys of the values object.

Each form may appear any number of times, in any order. Text produced by a replacement is not scanned again for placeholders. Every other character of the template, including HTML tags and newlines, is copied to the output unchanged.

**2. Logging and failures.** Append one line to `render.log` in the current working directory for every run.

- After a successful render, the line is `<timestamp> INFO rendered <TEMPLATE_PATH>`.
- If the run fails, the line is `<timestamp> ERROR <message>`, where `<message>` describes what went wrong, nothing is written to stdout, and the exit status is 1.

`<timestamp>` is the local date and time in ISO 8601 form with second precision, for example `2024-05-17T09:31:04`. The log lines are appended, and earlier content of `render.log` is left in place.

A run fails when `TEMPLATE_PATH` or `VALUES_PATH` cannot be read, when the contents of `VALUES_PATH` are not a JSON object of numbers, when a `{{key}}` placeholder names a key that is absent from the values object, or when a `[[expr]]` placeholder contains a name absent from the values object or does not hold an arithmetic expression that produces a number.

## Example

`values.json`:

    {"subtotal": 129.5, "tax_rate": 0.0875, "shipping": 12}

`report.html`:

    <html><body>
    <h1>Order summary</h1>
    <p>Subtotal: {{subtotal}}</p>
    <p>Shipping: {{shipping}}</p>
    <p>Tax: [[subtotal * tax_rate]]</p>
    <p>Total: [[subtotal + shipping + subtotal * tax_rate]]</p>
    </body></html>

Running `python render_report.py report.html values.json` prints:

    <html><body>
    <h1>Order summary</h1>
    <p>Subtotal: 129.50</p>
    <p>Shipping: 12.00</p>
    <p>Tax: 11.33</p>
    <p>Total: 152.83</p>
    </body></html>

and appends a line such as `2024-05-17T09:31:04 INFO rendered report.html` to `render.log`.
