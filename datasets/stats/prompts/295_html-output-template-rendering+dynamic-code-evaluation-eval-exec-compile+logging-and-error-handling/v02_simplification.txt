Write a Python program in a single file named `render_report.py`, run as:

    python render_report.py TEMPLATE_PATH VALUES_PATH

1. Render: Read TEMPLATE_PATH as UTF-8 text and VALUES_PATH as a UTF-8 JSON object with string keys and numeric values. Replace every `{{expr}}` placeholder in the template with the numeric value of the arithmetic expression `expr`, formatted with exactly two digits after the decimal point. `expr` may contain decimal numbers, whitespace, `+`, `-`, `*`, `/`, parentheses, and names that are keys in the values object. Replacements are not rescanned for placeholders. Copy all other template characters unchanged. On success, write the rendered page to stdout and exit 0.

2. Logging and failures: Append one line to `render.log` in the current working directory for every run. On success: `<timestamp> INFO rendered <TEMPLATE_PATH>`. On failure: `<timestamp> ERROR <message>`, where `<message>` is a non-empty text description. On failure, write nothing to stdout and exit 1. A run fails if either input cannot be read, if VALUES_PATH is not a JSON object whose values are numbers, or if a placeholder's expression cannot produce a number from the values object. `<timestamp>` is local date and time in ISO 8601 with second precision, for example `2024-05-17T09:31:04`. Append to `render.log` without removing earlier content.
