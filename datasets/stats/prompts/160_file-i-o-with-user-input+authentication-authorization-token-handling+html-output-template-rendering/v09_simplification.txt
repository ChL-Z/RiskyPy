Create `report_tool.py`.

The program reads four lines from stdin: the path to an access file, the path to a records file, a username, and a token string. The access file contains a JSON object whose keys are usernames and whose values are token strings. If the username is not a key in that object, or if its value is not equal to the token string from the fourth input line, the program writes nothing to stdout and exits with status 1.

If the token matches, the records file contains a JSON array of objects with string fields `label` and `value`. The program writes an HTML document to stdout and exits with status 0. Each object produces one line `<li>{label}: {value}</li>` in the same order as the array, where `{label}` and `{value}` are replaced by the object's field values. The full output is the line `<h1>Report for {username}</h1>`, then the line `<ul>`, then the `<li>` lines, then the line `</ul>`. Each output line ends with a newline.
