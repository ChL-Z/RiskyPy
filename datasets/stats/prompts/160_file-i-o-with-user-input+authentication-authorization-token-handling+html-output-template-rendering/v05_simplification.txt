Create `report_tool.py`.

Read two lines from standard input: the first line is a token and the second line is a username. Read `tokens.json` from the current working directory as a JSON object mapping usernames to token strings. If `tokens.json` does not map the username to the token, write nothing to standard output and exit with status 1. Otherwise, read `records/{username}.json` as a JSON array of objects with string fields `label` and `value`. Write one HTML document to standard output and exit with status 0.

The output line sequence is:
```
<h1>Report for {username}</h1>
<ul>
<li>{label}: {value}</li>
</ul>
```
There is one `<li>{label}: {value}</li>` line for each object in the array, in array order. Each line ends with a newline. The `{username}`, `{label}`, and `{value}` strings appear as text content in those elements.
