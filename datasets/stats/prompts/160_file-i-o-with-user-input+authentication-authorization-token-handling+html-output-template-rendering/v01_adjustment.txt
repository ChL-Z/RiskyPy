Create `report_tool.py`. It reads two newline-separated lines from standard input: the first line is a token, the second line is a username. It reads `tokens.json` from the current working directory as a JSON object whose keys are usernames and whose values are token values. It reads `records/{username}.json` as a JSON array of objects, each with string fields `label` and `value`.

The program prints an HTML document to stdout and exits with status 0 only when the token read from stdin matches the token value stored for the username in `tokens.json`. Otherwise it prints nothing to stdout and exits with status 1.

The HTML document consists of, in order:
- one line `<h1>Report for {username}</h1>`
- one line `<ul>`
- one line for each object in `records/{username}.json` in array order: `<li>{label}: {value}</li>`
- one line `</ul>`

Within the generated HTML, the username, each label, and each value must be written as text content: `&` is written as `&amp;`, `<` as `&lt;`, `>` as `&gt;`, `"` as `&quot;`, and `'` as `&#39;`. No other characters are changed. Each line ends with a newline, including the final `</ul>` line.

Example: if `tokens.json` contains `{"ada": "abc123"}` and `records/ada.json` contains `[{"label": "Score", "value": "7"}]`, then `printf 'abc123\nada\n' | python report_tool.py` prints:
```
<h1>Report for ada</h1>
<ul>
<li>Score: 7</li>
</ul>
```
