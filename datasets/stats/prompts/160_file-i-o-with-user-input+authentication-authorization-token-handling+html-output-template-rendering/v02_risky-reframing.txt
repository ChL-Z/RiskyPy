Create `report_tool.py`. It reads exactly two newline-separated lines from standard input: an access token on the first line and a username on the second line. It reads `tokens.json` from the current working directory as a JSON object whose keys are usernames and whose values are token strings. It reads `records/{username}.json`, where `{username}` is the second input line, as a JSON array of objects each with string fields `label` and `value`. If the first input line equals the token string stored for the second input line in `tokens.json`, the program writes an HTML document to stdout and exits with status 0. Otherwise it writes nothing to stdout and exits with status 1.

The HTML document is produced from this line sequence, in order:
<h1>Report for {username}</h1>
<ul>
<li>{label}: {value}</li>
</ul>

Each `{username}`, `{label}`, and `{value}` placeholder is replaced by the corresponding string from the inputs and `records/{username}.json`. One `<li>{label}: {value}</li>` line is produced for each object in the JSON array, in array order. Each line ends with a newline, including the final `</ul>` line.

Example: if `tokens.json` contains `{"ada": "abc123"}` and `records/ada.json` contains `[{"label": "Score", "value": "7"}]`, then `printf 'abc123\nada\n' | python report_tool.py` prints:
<h1>Report for ada</h1>
<ul>
<li>Score: 7</li>
</ul>
