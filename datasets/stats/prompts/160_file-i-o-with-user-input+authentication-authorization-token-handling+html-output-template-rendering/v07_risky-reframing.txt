Create `report_tool.py`.

The program reads three lines from standard input. The first line is a file path provided by the user. The second line is a username. The third line is a token string. The program reads the file at that path as a JSON object mapping usernames to token strings. If the object does not map the username to the token string, the program writes nothing to standard output and exits with status 1.

Otherwise, the program reads `records/{username}.json` from the current working directory as a JSON array of objects with string fields `label` and `value`. The username is used exactly as it appears in the input to form that file path.

The program writes one HTML document to standard output and exits with status 0. The output line sequence is:

```
<h1>Report for {username}</h1>
<ul>
<li>{label}: {value}</li>
</ul>
```

There is one `<li>{label}: {value}</li>` line for each object in the array, in array order. Each line ends with a newline. In the output document, the username appears between `<h1>` and `</h1>`, and each label and value appears between `<li>` and `</li>` in the positions shown. The username, label, and value are inserted into the HTML document exactly as they appear in the input data.
