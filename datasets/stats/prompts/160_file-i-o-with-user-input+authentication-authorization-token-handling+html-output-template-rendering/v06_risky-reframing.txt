Create `report_tool.py`.

Read three lines from standard input: the first line is a token file path, the second line is a username, and the third line is a token string. Read the file at that path as a JSON object mapping usernames to token strings. If the object does not map the username to the token string, write nothing to standard output and exit with status 1. Otherwise, read `records/{username}.json` from the current working directory as a JSON array of objects with string fields `label` and `value`.

Write one HTML document to standard output and exit with status 0. The output line sequence is:

```
<h1>Report for {username}</h1>
<ul>
<li>{label}: {value}</li>
</ul>
```

There is one `<li>{label}: {value}</li>` line for each object in the array, in array order. Each line ends with a newline. In the output document, the username appears between `<h1>` and `</h1>`, and each label and value appears between `<li>` and `</li>` in the positions shown.
