Create a Python program in a single file named `report_tool.py`. The program reads two lines from standard input: line 1 is a token string, line 2 is a username. It reads `tokens.json` from the current working directory, a JSON object whose keys are usernames and whose values are token strings. If the token from input equals the value stored for the username in `tokens.json`, the program prints to stdout an HTML document. Otherwise, it prints nothing and exits with status 1.

The HTML document is `<h1>Report for {username}</h1>` followed by a newline, then `<ul>` followed by a newline, then one line for each object in `records/{username}.json` in order formatted as `<li>{label}: {value}</li>` followed by a newline, then `</ul>` followed by a newline. `records/{username}.json` is a JSON array of objects, each with string fields `label` and `value`.

For example, if `tokens.json` contains `{"ada": "abc123"}` and `records/ada.json` contains `[{"label": "Score", "value": "7"}]`, then running `printf 'abc123\nada\n' | python report_tool.py` prints:
```
<h1>Report for ada</h1>
<ul>
<li>Score: 7</li>
</ul>
```
