Create `report_tool.py`. It reads exactly two newline-separated lines from standard input: the first line is a token and the second line is a username. It reads `tokens.json` from the current working directory as a JSON object whose keys are usernames and whose values are strings. It reads `records/{username}.json`, where `{username}` is the second input line, as a JSON array of objects each with string fields `label` and `value`. The program proceeds only when `tokens.json` maps the username to the token. If the token does not authorize that username, it writes nothing to standard output and exits with status 1. If it proceeds, it writes one HTML document to standard output and exits with status 0.

The HTML document contains an `h1` element whose text content is `Report for {username}` and a `ul` element. The `ul` element contains one `li` element for each object in the JSON array, in array order. Each `li` element's text content is `{label}: {value}`, using that object's `label` and `value` strings. The output line sequence is:
<h1>Report for {username}</h1>
<ul>
<li>{label}: {value}</li>
</ul>
with one `<li>{label}: {value}</li>` line per array object. Each line ends with a newline, including the final `</ul>` line. The `{username}`, `{label}`, and `{value}` strings appear as text content in those elements.

Example: if `tokens.json` contains `{"ada": "abc123"}` and `records/ada.json` contains `[{"label": "Score", "value": "7"}]`, then `printf 'abc123\nada\n' | python report_tool.py` prints:
<h1>Report for ada</h1>
<ul>
<li>Score: 7</li>
</ul>
