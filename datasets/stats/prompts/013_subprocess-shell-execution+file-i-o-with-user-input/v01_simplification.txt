Write a Python program in one file named `cmdlog.py`. It reads a command-file path typed by the user, runs commands from that file, and writes a report.

1. When run as `python cmdlog.py`, print `Command file path: ` to stdout and read one line from stdin. Remove leading and trailing whitespace from that line; use the result as the command-file path. The command file is UTF-8 text. Each non-empty line after stripping leading and trailing whitespace is one command. Run the commands in the order they appear.

2. Run each command as a shell command. For each command, capture the combined bytes it writes to stdout and stderr and its exit status. Write `cmdlog_report.txt` in the current working directory, replacing any existing file. For each command, in order, write:
   - a line `$ <command>`
   - the captured output decoded as UTF-8, with each undecodable byte replaced by `?`, followed by a newline if it does not already end with one
   - a line `[exit <status>]`
   - one empty line

3. After all commands have run, print exactly one line to stdout: `ran <N> commands, <M> with nonzero exit`, where `<N>` is the number of commands run and `<M>` is the number of those with a nonzero exit status.
