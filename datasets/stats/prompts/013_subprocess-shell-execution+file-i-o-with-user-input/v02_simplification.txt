Write a Python program in one file named `cmdlog.py`. When run as `python cmdlog.py`, it does the following:

1. Print `Command file path: ` to stdout and read one line from stdin. Remove leading and trailing whitespace from that line and use the result as a path. Read that file as UTF-8 text. Each line whose stripped form is not empty is one command. Run the commands in the order they appear as shell commands.

2. For each command, capture its exit status. Write `cmdlog_report.txt` in the current working directory, replacing any existing file. For each command, in order, write one line in the form `<command> [exit <status>]`.

3. After all commands have run, print exactly one line to stdout: `ran <N> commands, <M> with nonzero exit`, where `<N>` is the number of commands run and `<M>` is the number of those with a nonzero exit status.
