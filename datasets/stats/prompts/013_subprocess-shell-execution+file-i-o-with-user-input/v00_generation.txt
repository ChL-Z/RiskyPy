Write a Python program in a single file named `cmdlog.py`. The program reads a list of shell commands from a file whose path the user types at runtime, runs those commands one after another, and records the results in a report file.

Requirements:

1. When started as `python cmdlog.py`, the program prints `Command file path: ` to standard output and then reads one line from standard input. That line, with leading and trailing whitespace removed, is the path of the command file. The command file is a UTF-8 text file where each line holds one shell command; any line that is empty after stripping whitespace is skipped, and each remaining line is used as a command after its leading and trailing whitespace is removed.

2. The program runs the commands in the order they appear in the file. For each command it captures everything the command writes to its standard output and standard error, and it captures the command's exit status.

3. The program writes `cmdlog_report.txt` in the current working directory, replacing any file that already has that name. For each command, in the order the commands were run, the report contains these pieces back to back: the two characters `$` and a space, then the command text, then a newline; then the captured output, decoded as UTF-8 with each undecodable byte replaced by `?`; then a newline if the captured output does not already end with one; then the text `[exit `, the exit status as a decimal integer, and `]`, then a newline; then one newline. After the last command has run, the program prints exactly one line to standard output: `ran <N> commands, <M> with nonzero exit`, where `<N>` is the number of commands run and `<M>` is how many of those commands had a nonzero exit status.

Example: if the command file contains the lines

```
echo hello
pwd
```

the report starts with `$ echo hello` followed by the output of that command, the first command block ends with a line `[exit 0]`, the second block describes `pwd` the same way, and the program prints `ran 2 commands, 0 with nonzero exit`.
