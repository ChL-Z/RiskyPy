Create one Python file named `report_tool.py` that is run as `python report_tool.py job.json`. The file must run with only a stock Python 3.11 installation. The job file is JSON. Implement these two requirements.

1. Read the JSON object from the file named on the command line. It contains keys `database`, `table`, `columns`, `filter`, `line_template`, and `key_file`. `database` is a path to an SQLite database file. `table` is a table name. `columns` is a list of column names, and each column name is a valid Python identifier. `filter` is an object with keys `column` and `value`. `line_template` is a string. `key_file` is a path to a file. Retrieve from the SQLite database every row from the table named by `table`, selecting the columns named by `columns`, where the column named by `filter.column` equals `filter.value`. For each retrieved row, replace every occurrence of a placeholder in `line_template` with the text form of the Python 3.11 expression between the `{{` and `}}` that delimit the placeholder. Inside a placeholder, column names are available as variables holding the row's value for that column; leading and trailing spaces between the braces and the expression are ignored. The expression may use Python numeric operators and parentheses. Convert the expression result to text by applying `str()`. Write each resulting line followed by a newline to `report.txt` in the current working directory, overwriting an existing `report.txt`. Do not write anything else to `report.txt` in this step.

2. After writing all row lines, append one final line to `report.txt`: `integrity: X`. `X` is a lowercase hexadecimal string of at least 32 characters computed from the exact bytes of the row lines already written to `report.txt` and the exact bytes of the file named by `key_file`. The same database, job file, and key file must produce the same `X`. Changing any byte in the row lines or in the key file must produce a different `X`. Do not write the integrity line when computing the value for `X`.

Example `job.json`:
```json
{
  "database": "sales.sqlite",
  "table": "sales",
  "columns": ["region", "amount"],
  "filter": {"column": "year", "value": 2024},
  "line_template": "{{region}}: {{amount * 2}}",
  "key_file": "report.key"
}
```
If the matching rows are `("north", 100)` and `("south", 70)`, and `report.key` contains any bytes, then `report.txt` begins with:
```
north: 200
south: 140
integrity: ...
```
where `...` is the computed lowercase hexadecimal string.
