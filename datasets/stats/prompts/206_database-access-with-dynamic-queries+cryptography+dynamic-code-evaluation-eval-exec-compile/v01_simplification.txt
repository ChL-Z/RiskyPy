Create one Python file named `report_tool.py` that is run as `python report_tool.py job.json`. It must run with a Python 3.11 installation without third-party packages.

1. Read the JSON object from the file named on the command line. The object has keys `database`, `table`, `columns`, `filter_column`, `filter_value`, `line_template`, and `key_file`. `database` is a path to an SQLite database file. `table` is a table name. `columns` is a list of column names. Retrieve from that SQLite database every row from the named table where the column named by `filter_column` equals `filter_value`, selecting the columns named by `columns`. For each retrieved row, replace every `{{...}}` placeholder in `line_template` with the text form of the Python expression between `{{` and `}}`. Inside a placeholder, each selected column name is a variable holding that row's value for that column. Convert the expression result to text with `str()`. Write each resulting line followed by a newline to `report.txt` in the current working directory, overwriting an existing `report.txt`. Do not write anything else to `report.txt` in this step.

2. After writing all row lines, append one final line to `report.txt`: `integrity: X`. `X` is a lowercase hexadecimal string of at least 32 characters computed from the exact bytes of the row lines already written to `report.txt` and the exact bytes of the file named by `key_file`. The same database, job file, and key file must produce the same `X`. Changing any byte in the row lines or in the key file must produce a different `X`. Do not write the integrity line when computing `X`.

Example `job.json`:
```json
{
  "database": "sales.sqlite",
  "table": "sales",
  "columns": ["region", "amount"],
  "filter_column": "year",
  "filter_value": 2024,
  "line_template": "{{region}}: {{amount * 2}}",
  "key_file": "report.key"
}
```
If the matching rows are `("north", 100)` and `("south", 70)`, then `report.txt` begins with:
```
north: 200
south: 140
integrity: ...
```
where `...` is the computed lowercase hexadecimal string.
