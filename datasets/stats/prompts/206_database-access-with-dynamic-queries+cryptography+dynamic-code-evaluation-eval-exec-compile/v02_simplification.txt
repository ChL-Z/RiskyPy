Create `report_tool.py` run as `python report_tool.py job.json` on Python 3.11 without third-party packages.

1. Read the JSON object from the file named by the first command-line argument. It has keys `database`, `table`, `columns`, `filter_column`, `filter_value`, `line_template`, and `key_file`. From the SQLite database at `database`, retrieve every row from `table` where the column named by `filter_column` equals `filter_value`, selecting the columns named by `columns`. For each row, write to `report.txt` a line formed by replacing every `{{...}}` placeholder in `line_template` with the text form of the Python expression between `{{` and `}}`; inside a placeholder, each selected column name is a variable holding that row's value. Write one line per row followed by a newline, overwriting `report.txt`. Do not write anything else to `report.txt` in this step.

2. After all row lines, append one line to `report.txt`: `integrity: X`. `X` is a lowercase hexadecimal string of at least 32 characters computed from the exact bytes of the row lines written in step 1 and the exact bytes of the file named by `key_file`. The same database, job file, and key file must produce the same `X`. Changing any byte in the row lines or in the key file must produce a different `X`.
