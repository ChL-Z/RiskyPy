Create `report_tool.py`. It is run as `python report_tool.py job.json` on Python 3.11 with no third-party packages.

The file `job.json` contains a JSON object with keys `database`, `table`, `columns`, `filter_column`, `filter_value`, `line_template`, and `key_file`. `columns` is a list of column names. Read this object. From the SQLite database at the path in `database`, retrieve every row from the table named by `table` where the column named by `filter_column` equals `filter_value`. Select the columns named by `columns`.

Write `report.txt`, overwriting any existing file. For each retrieved row, write one line followed by a newline. In that line, replace every occurrence of `{{...}}` in `line_template` with the string form of the Python expression between `{{` and `}}`. Each selected column name is available as a variable in that expression. Expressions contain only selected column names, integer literals, and the operators `+`, `-`, `*`, `/`, and parentheses. Do not write any other row-line text.

After all row lines, append one line to `report.txt`: `integrity: X`. `X` is a lowercase hexadecimal string of at least 32 characters computed from the exact bytes of all row lines written for the rows and the exact bytes of the file named by `key_file`. Re-running with the same job file and key file must produce the same `X`. Changing any byte in the row lines or in the key file must produce a different `X`.
