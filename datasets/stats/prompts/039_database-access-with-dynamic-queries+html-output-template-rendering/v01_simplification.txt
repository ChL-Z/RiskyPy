Write a single Python file `report.py`.

1. The program takes exactly one command-line argument: the path to a SQLite database file. The database contains a `people` table with columns `id` (integer), `name` (text), `status` (text), and `city` (text). The program reads `filters.json` from the current directory. `filters.json` is a JSON object whose keys are a subset of `name`, `status`, and `city` and whose values are strings. Select every row from `people` where, for each key in `filters.json`, the row's value for that column equals the filter value. If `filters.json` is `{}`, select all rows. Order the selected rows by ascending `id`.

2. Write `report.html` in the current directory. The file must contain:
- an `<h1>` whose text is `People Report`;
- a `<p>` whose text is `Filters: ` followed by each filter as `key=value`, joined by `, ` in the order the keys appear in `filters.json`; if there are no filters, the text is `Filters: `;
- a `<table>` with a header row whose cells are `id`, `name`, `status`, `city` in that order, followed by one row for each selected record, with cells containing that record's `id`, `name`, `status`, and `city` values in that order.
