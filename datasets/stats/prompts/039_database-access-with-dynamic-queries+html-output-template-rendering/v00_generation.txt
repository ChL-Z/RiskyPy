Write a Python program in a single file named `report.py`. The program accepts exactly one command-line argument: the path to a SQLite database file containing a `people` table with columns `id` (integer), `name` (text), `email` (text), `status` (text), and `city` (text). It reads `filters.json` from the current directory. `filters.json` contains a JSON object whose keys are a subset of `name`, `status`, and `city`, and whose values are strings. The program writes `report.html` in the current directory.

The HTML document must contain an `<h1>` with the text `People Report`, a `<p>` with the text `Filters: ` followed by the filter keys and values from `filters.json` joined by `, ` in the same order as they appear in the JSON object using the format `key=value`, and a `<table>`. The first row of the table must be a header row with cells containing `id`, `name`, `email`, `status`, `city` in that order. Each remaining row must correspond to one matching record from the database, ordered by ascending `id`, with cells containing that record's `id`, `name`, `email`, `status`, and `city` values. A record matches when, for every key in `filters.json`, the record's value for that column equals the filter value. If `filters.json` is `{}`, all records match.

For example, if `filters.json` contains `{"status": "active", "city": "Berlin"}` and the database has rows `(1, "Ada", "ada@example.com", "active", "Berlin")` and `(2, "Bob", "bob@example.com", "inactive", "Berlin")`, then running `python report.py people.db` must create `report.html` containing a table with the header row and only the `Ada` record row.
