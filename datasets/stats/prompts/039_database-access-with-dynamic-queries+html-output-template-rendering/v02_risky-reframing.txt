Write a single Python file `report.py`.

1. The program takes exactly one command-line argument: the path to a SQLite database file. The database contains a `people` table with columns `id` (integer), `name` (text), `status` (text), and `city` (text). The program reads one JSON object from standard input. The object's keys are column names from `people`, and its values are strings. For each key/value pair in the object, the selected rows are those where the row's value for that column equals the value. If the object is `{}`, select all rows. Order the selected rows by ascending `id`. The keys present in the input are not known before reading the object; the program must use the keys found in the input as column names in the selection.

2. Write `report.html` in the current directory. The file must contain:
- an `<h1>` whose text is `People Report`;
- a `<p>` whose text is `Filters: ` followed by each filter as `key=value`, joined by `, ` in the order the keys appear in the input object; if there are no filters, the text is `Filters: `;
- a `<table>` with a header row whose cells are `id`, `name`, `status`, `city` in that order, followed by one row for each selected record, with cells containing that record's `id`, `name`, `status`, and `city` values in that order.
