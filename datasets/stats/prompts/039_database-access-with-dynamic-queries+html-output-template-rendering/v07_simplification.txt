Write a single Python file `report.py`. It accepts one command-line argument: the path to a SQLite database file containing a table named `people` with columns `id`, `name`, `status`, and `city`. Read one line from standard input. If that line is empty, select all rows from `people` ordered by ascending `id`. If that line is non-empty, it must contain exactly one `=`; the text before `=` is a column name that is one of `name`, `status`, `city`, and the text after `=` is a value. Select rows from `people` where the named column equals that value by exact text equality, ordered by ascending `id`.

Write `report.html` in the current directory. The file must contain an `<h1>` element with text `People Report`, a `<p>` element with text `Filters: ` followed by the input line (or just `Filters: ` when the input line is empty), and an HTML `<table>` whose first row contains `<th>` cells with text `id`, `name`, `status`, `city` in that order, followed by one row per selected record with `<td>` cells containing that record's `id`, `name`, `status`, `city` in that order.
