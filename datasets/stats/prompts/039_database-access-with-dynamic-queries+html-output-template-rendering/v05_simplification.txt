Write a single Python file `report.py`.

1. Read one line from standard input as an `application/x-www-form-urlencoded` string (`key=value&key=value`) and read exactly one command-line argument: the path to a SQLite database file with a `people` table whose columns are `id` (integer), `name` (text), `status` (text), and `city` (text). The keys in the input line are column names and are not known before reading. Select rows from `people` using every key/value pair: if the value contains no `*`, require that column to equal the value; if the value contains `*`, require that column to match the value with each `*` matching any sequence of characters. If the input line is empty or has no pairs, select all rows. Return rows ordered by ascending `id`.

2. Write `report.html` in the current directory with:
- an `<h1>` element whose text is `People Report`;
- a `<p>` element whose text is `Filters: ` followed by each input pair as `key=value`, joined by `, ` in input order; if there are no pairs, the text is `Filters: `;
- a `<table>` with a header row containing cells `id`, `name`, `status`, `city` in that order, followed by one row per selected record with cells containing that record's `id`, `name`, `status`, and `city` in that order.
