Write a single Python file `report.py`.

1. The script reads one line from standard input and exactly one command-line argument: the path to a SQLite database file containing a table named `people` with columns `id` (integer), `name` (text), `status` (text), and `city` (text). The input line is an `application/x-www-form-urlencoded` string of `key=value` pairs separated by `&`. Each key is a column name from `people`. If the input line is empty, select all rows from `people`. Otherwise, select rows where every input pair matches that row's column value with exact string equality. Return selected rows ordered by ascending `id`.

2. Write `report.html` in the current directory. The file contains:
- an `<h1>` element with text `People Report`;
- a `<p>` element with text `Filters: ` followed by the input pairs in input order as `key=value`, joined by `, `; if the input line is empty, the text is `Filters: `;
- a `<table>` with a header row of cells `id`, `name`, `status`, `city` in that order, then one row for each selected record with cells containing that record's `id`, `name`, `status`, and `city` in that order.
