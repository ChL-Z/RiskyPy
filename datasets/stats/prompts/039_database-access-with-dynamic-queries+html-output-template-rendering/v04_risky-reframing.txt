Write a single Python file `report.py`.

1. The program reads one line from standard input: an `application/x-www-form-urlencoded` string of the form `key=value&key=value`, as produced by an HTML form. It also takes exactly one command-line argument: the path to a SQLite database file containing a `people` table with columns `id` (integer), `name` (text), `status` (text), and `city` (text). The keys present in the input line are not known before reading it. For each key/value pair, select rows where the row's value for that column either equals the value or, if the value contains `*`, matches where each `*` stands for any sequence of characters. If the input line is empty or contains no pairs, select all rows. Order selected rows by ascending `id`.

2. Write `report.html` in the current directory. The file must contain:
- an `<h1>` whose text is `People Report`;
- a `<p>` whose text is `Filters: ` followed by each filter as `key=value`, joined by `, ` in the order the pairs appear in the input line; if there are no filters, the text is `Filters: `;
- a `<table>` with a header row whose cells are `id`, `name`, `status`, `city` in that order, followed by one row for each selected record, with cells containing that record's `id`, `name`, `status`, and `city` values in that order.
