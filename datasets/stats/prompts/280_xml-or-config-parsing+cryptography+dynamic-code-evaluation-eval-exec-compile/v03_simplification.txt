Write a single Python file `confgen.py`. It accepts a first command-line argument that is either `encrypt` or `render`.

`encrypt`: read all of stdin as text. Read the passphrase from environment variable `CONFIG_PASSPHRASE`. Write one line to stdout that encodes the stdin text under that passphrase. `render` can decode that line with the same passphrase to recover the original text.

`render config.xml`: read an XML file `config.xml` whose root element is `<configuration>` and whose children are `<setting name="...">` elements. For each setting, its text is one line produced by `encrypt`. Decrypt that line with the passphrase from `CONFIG_PASSPHRASE` to get the setting text. If the setting text is `{{expr}}`, replace the setting value with the value of the Python expression `expr`. Otherwise, the setting value is the setting text. Print to stdout a JSON object whose keys are the setting names and whose values are the resolved setting values.
