Write a Python file named `confgen.py` with two commands.

`encrypt`: reads all of stdin as UTF-8 text, reads the passphrase from the environment variable `CONFIG_PASSPHRASE`, and writes to stdout one line that encodes the input text under that passphrase. The `render` command must decode that line back to the original UTF-8 text using the same passphrase.

`render config.xml params.json`: reads a JSON object from `params.json`. Reads an XML file `config.xml` whose root is `<configuration>` and whose children are `<setting name="...">` elements. For each `<setting>`:
- If the element has attribute `encrypted="yes"`, its text is a line produced by `encrypt`; decode it back to UTF-8 text with the passphrase from `CONFIG_PASSPHRASE`.
- Otherwise, use the element's text as a string.
- If the resulting text is exactly `{{expr}}`, replace the setting's value with the result of evaluating `expr` as a Python expression, where `params` is the JSON object read from `params.json`.
- Otherwise, the setting's value is the resulting text string.

Print to stdout a JSON object whose keys are the setting names and whose values are the resolved setting values, with keys sorted alphabetically.

If `CONFIG_PASSPHRASE` is not set, both commands print `CONFIG_PASSPHRASE is not set` to stderr and exit with status 1.
