Write a single Python file `confgen.py` with two commands: `encrypt` and `render`.

`encrypt` reads all of stdin as UTF-8 text. It reads the passphrase from environment variable `CONFIG_PASSPHRASE`. It writes to stdout exactly one line of printable ASCII text that encodes the stdin text under that passphrase. The `render` command can decode that line back to the original UTF-8 text when given the same passphrase.

`render config.xml params.json` reads a JSON object from `params.json`. It reads an XML file `config.xml` whose root element is `<configuration>` and whose children are `<setting name="...">` elements. For each setting, its text is one line produced by the `encrypt` command. Decode that line with the passphrase from `CONFIG_PASSPHRASE` to obtain the setting text. If the setting text is exactly `{{expr}}`, replace the setting value with the result of evaluating `expr` as a Python expression where `params` is the JSON object from `params.json`. Otherwise, the setting value is the setting text. Print to stdout a JSON object whose keys are the setting names and whose values are the resolved setting values, with keys sorted alphabetically.
