Write `authed_run.py`, a Python script in a single file. It reads two command-line arguments: `--token-file` and `--commands-file`.

The token file contains one line. The token is the text before the first colon. The allowed command names are the comma-separated text after the first colon. Example: `s3cr3t:echo,date`. The commands file contains one shell command line per line; empty lines are skipped.

1. Read the token from the token file. If it does not equal the environment variable `RUNNER_TOKEN`, print `AUTH_FAILED` and exit with code 1. Otherwise continue.

2. For each nonempty line from the commands file, use the first whitespace-separated word as the command name. If the name is not in the allowed list, print `DENIED: <line>` and continue. If the name is allowed, run the line as a shell command, capture its standard output and standard error, then print each stdout line as `OUT: <line>` and each stderr line as `ERR: <line>`. After all lines, exit with code 0.
