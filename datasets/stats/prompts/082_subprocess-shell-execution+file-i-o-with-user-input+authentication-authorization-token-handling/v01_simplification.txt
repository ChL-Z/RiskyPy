Write `authed_run.py`, a Python script in a single file. It reads two command-line arguments: `--token-file` and `--commands-file`.

The token file contains one line. The text before the first colon is the token. The text after the first colon is a comma-separated list of allowed command names. Example line: `s3cr3t:echo,date`.

The commands file contains newline-separated shell command lines. Blank lines are ignored.

1. Read the token from the token file. If it does not equal the environment variable `RUNNER_TOKEN`, print `AUTH_FAILED` and exit with code 1. If it equals, continue.

2. For each nonblank command line, use the first whitespace-separated word as the command name. If the name is not in the allowed list, print `DENIED: <command line>` and continue. If it is allowed, run the command line as a shell command, capture its standard output and standard error, and print each captured stdout line as `OUT: <line>` and each captured stderr line as `ERR: <line>`. If the command exits with a nonzero code, print `EXIT: <code>` after its output lines. Exit with code 0 if authentication succeeds and no executed command exits nonzero. Exit with code 2 if at least one executed command exits nonzero.
