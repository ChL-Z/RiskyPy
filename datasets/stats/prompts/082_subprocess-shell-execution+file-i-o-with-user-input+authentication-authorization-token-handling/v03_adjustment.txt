Write `authed_run.py`, a Python program in one file. It accepts two command-line arguments: `--token-file` and `--commands-file`.

1. Read the token file. Treat its first line as the token file content, removing one trailing newline if present. The token is the substring before the first `:`. The authorized command names are the substrings after the first `:` split on `,`. If the token does not equal the value of the environment variable `RUNNER_TOKEN`, print exactly `AUTH_FAILED` and exit with status 1. Otherwise proceed.

2. Read the commands file. For each nonempty line, split the line on whitespace into fields. The first field is the command name; the remaining fields are the command arguments. If the command name is not one of the authorized command names, print exactly `DENIED: <line>` where `<line>` is the original line, and continue with the next line. If the command name is authorized, run the command as an external process with the remaining fields as separate arguments. Capture its standard output and standard error. Print each captured standard output line in order as `OUT: <line>`, then each captured standard error line in order as `ERR: <line>`.

3. After all lines in the commands file have been processed, exit with status 0.
