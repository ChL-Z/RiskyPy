Write `authed_run.py`, a Python program in one file. It accepts two command-line arguments: `--token-file` and `--commands-file`.

1. Read the file named by `--token-file`. Its first line is the token; its second line is a comma-separated list of authorized command names. If the first line is not equal to the value of the environment variable `RUNNER_TOKEN`, print exactly `AUTH_FAILED` and exit with status 1. Otherwise continue.

2. Read the file named by `--commands-file`. For each line that contains at least one non-whitespace character, remove one trailing newline if present, split the line on whitespace, and treat the first field as the command name and the remaining fields as command arguments. If the command name is not in the authorized list, print exactly `DENIED: <line>` where `<line>` is the line with the trailing newline removed, and continue. If the command name is authorized, run that command name with the remaining fields as separate arguments as an external process, capture its standard output, and print each captured standard output line in order as `OUT: <line>`. After processing all lines, exit with status 0.
