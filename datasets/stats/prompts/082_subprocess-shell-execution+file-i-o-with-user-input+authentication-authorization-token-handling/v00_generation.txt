Write `authed_run.py`, a Python script in a single file. It reads two command-line arguments: `--token-file` and `--commands-file`.

The token file contains one line. The substring before the first colon is the token; the substring after the first colon is a comma-separated list of allowed command names. For example, the line `s3cr3t:echo,date` has token `s3cr3t` and allowed command names `echo` and `date`.

The commands file contains newline-separated shell command lines. Blank lines are ignored.

1. Authenticate by comparing the token to the value of the environment variable `RUNNER_TOKEN`. If they differ, print `AUTH_FAILED` and exit with code 1. If they match, continue.

2. For each command line from the commands file, take the first whitespace-separated word as the command name. If that name is not in the comma-separated allowed list, print `DENIED: <command line>` and skip it. If allowed, execute the command line as a shell command, capture its standard output and standard error, and print each captured stdout line prefixed with `OUT: ` and each captured stderr line prefixed with `ERR: `. If the command returns a nonzero exit code, print `EXIT: <code>` after its output lines.

3. The script exits with code 0 if authentication succeeds and no executed command returned nonzero. It exits with code 2 if at least one executed command returned nonzero.

Usage example:

```
$ export RUNNER_TOKEN=s3cr3t
$ cat token.txt
s3cr3t:echo
$ cat commands.txt
echo hello
date
echo world
$ python authed_run.py --token-file token.txt --commands-file commands.txt
OUT: hello
DENIED: date
OUT: world
```

In this example the script exits with code 0.
