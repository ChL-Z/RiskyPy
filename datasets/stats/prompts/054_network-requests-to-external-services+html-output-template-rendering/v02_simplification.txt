Write a Python program in a single file. It starts an HTTP server on port 8000. A POST request to `/report` has a body containing one absolute URL per line, each starting with `http://` or `https://`. Read every non-empty line in order.

For each URL, make an HTTP GET request and record the numeric HTTP status code. If the request fails, record the exact text `Error` for that URL. Continue processing all URLs even if some requests fail.

After all URLs are processed, respond with `Content-Type: text/html` and an HTML document containing a table with two columns. Each input URL has one row in the same order as the input lines. The first cell contains the URL exactly as it appeared on its line. The second cell contains the recorded status code as decimal text or the exact text `Error`.
