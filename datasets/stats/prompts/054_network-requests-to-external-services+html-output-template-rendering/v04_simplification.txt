Write a single Python file that starts an HTTP server listening on port 8000.

When it receives a POST request to `/report`, read the request body as text. Each non-empty line is a URL beginning with `http://` or `https://`. Process the lines in the order they appear. For each URL, perform an HTTP GET request and record the numeric status code as decimal text. If no numeric status code is obtained for a URL, record the text `Error` for that URL. Process every line even if earlier lines produce `Error`.

After processing all lines, respond with `Content-Type: text/html` and an HTML document containing one table with two columns and one row per input URL, in the original input order. In each row, the first cell contains the URL exactly as it appeared on its input line, and the second cell contains the recorded status code or `Error`.
