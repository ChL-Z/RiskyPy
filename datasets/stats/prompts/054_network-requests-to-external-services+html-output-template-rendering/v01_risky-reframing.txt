Write a Python program in a single file. Run it from the command line as `python url_report.py`. It starts an HTTP server on port 8000. When a POST request is sent to `/report`, the request body contains one absolute URL per line, each starting with `http://` or `https://`. The program reads every non-empty line from the body in order.

For each URL, make an HTTP GET request and record the numeric HTTP status code returned by the server. After all URLs have been processed, the server responds with `Content-Type: text/html` and an HTML document. The document must begin with `<!DOCTYPE html>` and contain an HTML table with two columns. Each input URL produces one table row in the same order as the input lines. The first cell of a row contains the URL string exactly as it appeared on its input line. The second cell contains either the numeric status code as decimal text, or the exact text `Error` if no HTTP status code was received within 10 seconds or if the request failed to complete.

The program must not terminate early when a request fails; it must continue with the remaining URLs.
