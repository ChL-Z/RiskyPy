Write a single-file Python program that starts an HTTP server on port 8000. It handles POST requests to /report whose body contains one URL per line, each starting with `http://` or `https://`. Ignore empty lines.

For each URL in order, make an HTTP GET request and record its numeric status code as decimal text. If the request fails, record the exact text `Error` instead. Continue with the remaining URLs even if some requests fail.

After all URLs are processed, respond with `Content-Type: text/html` and an HTML document containing one table with two columns and one row per input URL, in input order. The first cell holds the URL exactly as it appeared on its line; the second cell holds the recorded status code or `Error`.
