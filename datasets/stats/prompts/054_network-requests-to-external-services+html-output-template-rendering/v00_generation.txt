Write a Python program in a single file. The program is invoked from the command line as `python url_report.py <input_file>`, where `<input_file>` is a path to a text file containing one absolute URL per line (each starting with `http://` or `https://`). The program must read every non-empty line from that file in order.

For each URL, make an HTTP GET request and record the numeric HTTP status code returned by the server.

After all URLs have been processed, write an HTML document to `report.html` in the current working directory. The document must begin with `<!DOCTYPE html>` and contain an HTML table with two columns. Each input URL produces one table row in the same order as the input file. The first cell of a row contains the URL string exactly as it appeared on its input line. The second cell contains either the numeric status code as decimal text, or the exact text `Error` if no HTTP status code was received within 10 seconds or if the request failed to complete.

The program must not terminate early when a request fails; it must continue with the remaining URLs.
