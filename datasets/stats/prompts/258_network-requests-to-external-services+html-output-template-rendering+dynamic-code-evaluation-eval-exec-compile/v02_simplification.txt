Write a single Python file named `report_renderer.py`. It accepts two command-line arguments: a URL and the path to an HTML template file. Read the template file and retrieve a JSON object from the URL. The JSON object has string keys and number values.

The template is HTML text containing placeholders written as `{{ expression }}`. Each expression is an arithmetic expression that may use the JSON keys as variables and the operators `+`, `-`, `*`, `/`, and parentheses. Replace every placeholder with the string form of the evaluated expression result. For example, if the URL returns `{"revenue": 1200, "cost": 450.5}` and the template contains `<p>Profit: {{ revenue - cost }}</p>`, write `<p>Profit: 749.5</p>` to stdout. Write only the completed HTML to stdout.

If the URL cannot be retrieved or the template file cannot be read, write a line starting with `Error: ` to stderr and exit with status 1.
