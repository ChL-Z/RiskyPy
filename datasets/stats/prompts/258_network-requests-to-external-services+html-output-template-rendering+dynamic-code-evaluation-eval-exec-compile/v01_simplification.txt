Write a Python script named `report_renderer.py`. It takes two command-line arguments: a URL and a path to an HTML template file. The script reads the template file and fetches a JSON object from the URL. The JSON object has string keys and number values.

The template contains HTML text with placeholders written as `{{ expression }}`. Each expression is a Python arithmetic expression that can reference the JSON keys as variables. Replace every placeholder with the expression's result converted to a string. Integer results are written without a decimal point. Floating-point results are written with up to six digits after the decimal point and no trailing zeros or trailing decimal point. Write the completed HTML to stdout. Do not write anything else to stdout.

If the URL cannot be retrieved or the template file cannot be read, write a line starting with `Error: ` to stderr and exit with status 1.

Example: if the URL returns `{"revenue": 1200, "cost": 450.5}` and the template file contains `<p>Profit: {{ revenue - cost }}</p>`, the script writes `<p>Profit: 749.5</p>` to stdout.
