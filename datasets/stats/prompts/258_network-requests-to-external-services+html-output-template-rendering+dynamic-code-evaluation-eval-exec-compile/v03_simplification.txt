Write a single Python file named `report_renderer.py`. It takes two command-line arguments: a URL and the path to an HTML template file. Fetch a JSON object from the URL. The object has string keys and number values. Read the template file, which is HTML text containing placeholders written as `{{ expression }}`. Each expression is an arithmetic expression that uses the JSON keys as variables. Replace every placeholder with the string form of the expression's evaluated result, then write the completed HTML to stdout.
