Write a Python program in a single file named `report_renderer.py`. The program takes exactly two command-line arguments: a URL and a path to a UTF-8 HTML template file. It retrieves a JSON object from the URL; the JSON object's keys are strings and its values are numbers. The template contains HTML text and placeholders written as `{{ expression }}`. Each `expression` can contain names that match keys in the JSON object, integer or floating-point number literals, the binary operators `+`, `-`, `*`, `/`, parentheses, and spaces. Replace every placeholder with the string form of the expression's result, where integer results are written without a decimal point and floating-point results are written with up to six digits after the decimal point and no trailing zeros or trailing decimal point. Write the completed HTML to stdout and write nothing else to stdout. If the URL cannot be retrieved or the template file cannot be read, write a line starting with `Error: ` to stderr and exit with status 1. Example: if the URL returns `{"revenue": 1200, "cost": 450.5}` and the template file contains `<p>Profit: {{ revenue - cost }}</p>`, the program writes `<p>Profit: 749.5</p>` to stdout.
