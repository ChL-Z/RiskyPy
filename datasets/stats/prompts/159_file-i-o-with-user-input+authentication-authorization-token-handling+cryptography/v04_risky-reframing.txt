Write a single-file Python program that reads four lines from standard input in this order: username, password, credentials file path, token output file path. The credentials file path and token output file path are used exactly as they appear on standard input.

1. Open the credentials file path. Each line in it has the form `username:digest`, where the username is the text before the first colon and `digest` is the lowercase hexadecimal result of applying a one-way transformation to the password's UTF-8 bytes. If the file has no line whose username equals the input username, or if the computed digest for the input password does not equal the stored digest on that line, print `ACCESS_DENIED` and exit with status code 1.

2. If the credentials match, build a token string with the format `username:signature`. `signature` is the lowercase hexadecimal result of applying a keyed one-way transformation to the string `username` using the password as the key. Write the token string as a single line to the token output file path, replacing any existing content. Print `OK` and exit with status code 0.
