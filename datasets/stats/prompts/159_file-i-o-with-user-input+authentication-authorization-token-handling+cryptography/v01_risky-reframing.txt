Write a single-file Python program. It reads five lines from standard input in this order: username, password, database file path, key file path, and token output file path. The database file contains one record per line in the format `username:salt:digest`, where `salt` and `digest` are hexadecimal strings. The digest is the result of applying a one-way transformation to the byte string formed by concatenating the salt's raw bytes with the password's UTF-8 bytes.

1. If the username is not present in the database file, or the computed digest does not equal the stored digest, print `ACCESS_DENIED` and exit with status code 1.

2. If the credentials match, read the key file, which contains a single line of text. Create a token string with the format `username:expiry:signature`, where `expiry` is the current Unix timestamp plus 3600 seconds, and `signature` is a hexadecimal string produced by applying a keyed one-way transformation to the string `username:expiry` using the key.

3. Write the token string as a single line to the token output file path, overwriting any existing content. Print `OK` and exit with status code 0.
