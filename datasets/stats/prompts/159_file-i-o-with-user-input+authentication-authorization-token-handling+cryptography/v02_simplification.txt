Write a single-file Python program. It reads three lines from standard input in this order: username, password, token output file path.

Read credentials from a file named `users.txt` in the current directory. Each line is `username:digest`, where `digest` is the hexadecimal result of applying a one-way transformation to the password's UTF-8 bytes.

1. If the username is not present in `users.txt`, or the computed digest does not equal the stored digest, print `ACCESS_DENIED` and exit with status code 1.

2. If the credentials match, create a token string with the format `username:expiry:signature`. `expiry` is the current Unix timestamp plus 3600 seconds. `signature` is the hexadecimal result of applying a keyed one-way transformation to the string `username:expiry` using the password as the key.

3. Write the token string as a single line to the token output file path, overwriting any existing content. Print `OK` and exit with status code 0.
