Write a Python program in one file. It reads four lines from stdin: token, username, password, and credentials file path. Each line is used without the trailing newline.

1. Open the credentials file. Each line is `username:digest`. The digest is the lowercase hexadecimal result of applying a one-way transformation to the password's UTF-8 bytes. If no line has the input username, or the digest for the input password does not equal that line's digest, print `ACCESS_DENIED` and exit with status 1.

2. If the username and digest match, write to a file whose name is the token value in the current working directory, replacing any existing file with that name, the line `username:signature`. The signature is the lowercase hexadecimal result of applying a one-way transformation to the string `username` followed by the password. Print `username:signature` and exit with status 0.
