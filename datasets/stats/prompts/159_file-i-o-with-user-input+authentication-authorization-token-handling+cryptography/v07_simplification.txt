Write a Python program in one file. Read four lines from stdin: token, username, password, and credentials file path. Use each line without the trailing newline.

1. Read the credentials file. Each line is `username:secret`. The `secret` is the lowercase hexadecimal result of applying a one-way transformation to the password. If no line has the given username, or the `secret` on that line is not equal to the lowercase hexadecimal result of applying the same one-way transformation to the given password, print `ACCESS_DENIED` and exit with status 1.

2. If the username and password match, write a file in the current working directory named exactly the token value, replacing any existing file with that name. The file contains one line: `username:signature`. The signature is the lowercase hexadecimal result of applying a one-way transformation to the username. Print `username:signature` and exit with status 0.
