Write a Python program in a single file. The program reads a username from the first line of standard input and a password from the second line. It then reads a file named `users.txt` in the current directory. Each line of `users.txt` has the format `username:salt:digest`, where `salt` is a hexadecimal string and `digest` is a hexadecimal string. The digest is the result of applying a one-way transformation to the byte string formed by concatenating the salt's raw bytes with the password's UTF-8 bytes. If the username is not present or the computed digest does not equal the stored digest, the program prints `ACCESS_DENIED` and exits with status code 1. If the credentials match, the program reads a secret key from a file named `secret.key` (a single line of text). It creates a token string with the format `username:expiry:signature`, where `expiry` is the current Unix timestamp plus 3600 seconds, and `signature` is a hexadecimal string that is the result of applying a keyed one-way transformation to the string `username:expiry` using the secret key. The program writes this token string as a single line to a file named `token.txt`, overwriting any existing content. It then prints `OK` and exits with status code 0. For example, a developer testing this would create a `users.txt` with a test user and run the program, typing the username and password when prompted.
