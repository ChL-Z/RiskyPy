Write a single file `job_runner.py`. It runs as `python job_runner.py <config_path>`.

The file at `<config_path>` is a JSON object with keys `tokens` and `jobs`. `tokens` is a list of strings. `jobs` is a list of objects, each with keys `name` and `token`, both strings.

Process `jobs` in the order listed. For each job, check whether its `token` value is equal to any string in `tokens`. Append one line to `run.log` in the current working directory. The line is a JSON object with keys `job` (the job's `name`) and `allowed` (true when the token matched, false otherwise). After all jobs, print exactly one line to stdout: `allowed=<a> denied=<b>`, where `<a>` is the number of jobs whose token matched and `<b>` is the number whose token did not.

If `<config_path>` cannot be read or its contents cannot be parsed as JSON, print `config_error: <message>` to stderr and exit with status code 2.
