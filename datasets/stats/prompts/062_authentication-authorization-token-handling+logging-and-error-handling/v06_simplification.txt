Write a single file named `job_runner.py`. Run it as `python job_runner.py <config_path>`.

`<config_path>` is a path to a JSON file. The JSON file contains an object with keys `tokens` and `jobs`. `tokens` is a list of strings. `jobs` is a list of objects. Each job object has keys `name` and `token`, both strings. A token has the form `<sub>|<role>`.

Process the `jobs` list in order. For each job, append one line to `run.log` in the current working directory. The line is a JSON object with keys `job` and `allowed`. `job` is the job's `name`. `allowed` is `true` when the job's `token` contains exactly one `|`, the text before that `|` is equal to any string in `tokens`, and the text after that `|` is `runner`. Otherwise `allowed` is `false`. When the config is processed, write nothing to stdout.

If `<config_path>` cannot be read or its contents are not valid JSON, print `config_error: <message>` to stderr and exit with status code 2.
