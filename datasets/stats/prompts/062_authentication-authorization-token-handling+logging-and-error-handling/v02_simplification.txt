Write a Python program in a single file named `job_runner.py`. It runs as `python job_runner.py <config_path>`. The file at `<config_path>` is a JSON object with keys `tokens` and `jobs`. `tokens` is a list of strings. `jobs` is a list of objects, each with keys `name`, `command`, and `token`, all strings.

1. For each job in the order listed: if its `token` is equal to a string in `tokens`, run its `command` string and capture the combined stdout and stderr as text. Otherwise, do not run the command. After all jobs, print to stdout one line: `ran=<a> skipped=<b>`, where `a` is the number of jobs whose command ran and `b` is the number whose command did not run.

2. Append exactly one JSON object per job, in job order, to `run.log` in the current working directory. Each log object has keys `job` (the job's `name`), `ran` (a boolean: true if the command ran, false otherwise), `exit_code` (the command's exit code as an integer if it ran, otherwise null), and `output` (the captured stdout and stderr as text if the command ran, otherwise an empty string).

3. If the configuration file cannot be read or its contents cannot be parsed as JSON, print `config_error: <message>` to stderr and exit with status code 2.
