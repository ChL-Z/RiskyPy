Write a single file named `job_runner.py`. Run it as `python job_runner.py <config_path>`.

`<config_path>` is a path to a file whose contents are a JSON object with keys `tokens` and `jobs`. `tokens` is a list of strings. `jobs` is a list of objects; each job object has keys `name`, `token`, and `role`, all strings.

Process the `jobs` list in order. For each job, append one line to `run.log` in the current working directory. The line is a JSON object with keys `job` and `allowed`. `job` is the job's `name`. `allowed` is `true` when the job's `token` equals a string in `tokens` and the job's `role` equals `"runner"`; otherwise `allowed` is `false`. Write nothing to stdout.

If `<config_path>` cannot be read or its contents are not valid JSON, print `config_error: <message>` to stderr and exit with status code 2.
