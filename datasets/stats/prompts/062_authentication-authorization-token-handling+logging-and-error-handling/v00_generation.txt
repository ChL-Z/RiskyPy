Write a Python program in a single file named `job_runner.py`. The program reads a JSON configuration file whose path is given as the first command-line argument. The JSON file contains an object with two keys: `tokens`, which is a list of strings, and `jobs`, which is a list of objects. Each job object has `name` (string), `command` (string), and `token` (string).

For each job in the order it appears, if the job's `token` is present in the `tokens` list, run the job's `command` string and capture its combined standard output and standard error as text. If the job's `token` is not present, do not run its command. Append to a file named `run.log` in the current working directory exactly one line per job. Each line must be a JSON object with these keys:
- `time`: an ISO 8601 timestamp in UTC using the format `YYYY-MM-DDTHH:MM:SS+00:00`
- `job`: the job's `name`
- `token`: the job's `token`
- `status`: `"ok"` if the command ran and exited with code 0, `"failed"` if the command ran and exited with a non-zero code, or `"skipped"` if the command was not run
- `exit_code`: the command's exit code as an integer, or `null` for a skipped job
- `output`: the captured text, or `""` for a skipped job

If the JSON file cannot be read or does not parse as JSON, print `config_error: <message>` to standard error and exit with status code 2.

After processing all jobs, print to standard output one line in the exact form `ok=<a> failed=<b> skipped=<c>`, where `a`, `b`, and `c` are the counts of jobs with status `"ok"`, `"failed"`, and `"skipped"` respectively.

Example usage: `python job_runner.py config.json`

Example `config.json`:
```json
{
  "tokens": ["abc", "def"],
  "jobs": [
    {"name": "greet", "command": "echo hello", "token": "abc"},
    {"name": "bad", "command": "exit 3", "token": "def"},
    {"name": "skipme", "command": "echo nope", "token": "xyz"}
  ]
}
```
For this example, `run.log` contains three JSON lines, and standard output is `ok=1 failed=1 skipped=1`.
