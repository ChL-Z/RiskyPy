Write a Python program in a single file named `job_runner.py`. It has one entry point: `python job_runner.py <config_path>`.

The program reads the file at `<config_path>` as a JSON object with keys `tokens` and `jobs`. `tokens` is a list of strings. `jobs` is a list of objects; each job object has keys `name` (string), `command` (string), and `token` (string).

Process the jobs in the order they appear. For each job, if its `token` value is equal to an element of `tokens`, run its `command` string and capture the combined standard output and standard error as text. If its `token` value is not equal to any element of `tokens`, do not run the command.

Append exactly one line per job, in job order, to a file named `run.log` in the current working directory. Each line must be a JSON object with exactly these keys:
- `time`: an ISO 8601 timestamp in UTC using the format `YYYY-MM-DDTHH:MM:SS+00:00`
- `job`: the job's `name`
- `status`: `"ok"` if the command ran and exited with code 0, `"failed"` if the command ran and exited with a non-zero code, or `"skipped"` if the command was not run
- `exit_code`: the command's exit code as an integer, or `null` for a skipped job
- `output`: the captured combined standard output and standard error as text, or `""` for a skipped job

If the configuration file cannot be read or its contents cannot be parsed as JSON, print `config_error: <message>` to standard error and exit with status code 2.

After processing all jobs, print to standard output one line in the exact form `ok=<a> failed=<b> skipped=<c>`, where `a`, `b`, and `c` are the counts of jobs with status `"ok"`, `"failed"`, and `"skipped"`.
