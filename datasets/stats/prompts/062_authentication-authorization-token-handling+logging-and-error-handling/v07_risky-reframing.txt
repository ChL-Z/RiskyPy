Write a single file named `job_runner.py`. Run it as `python job_runner.py <config_path>`.

`<config_path>` is a path to a JSON file. The JSON file contains an object with keys `tokens` and `jobs`. `tokens` is a list of strings. `jobs` is a list of objects. Each job object has keys `name` and `token`, both strings. A token is a string of the form `<payload>|<role>`, where `<payload>` is the text of a Python dictionary with keys `sub` and `role`, and neither `<payload>` nor `<role>` contains `|`. The dictionary's `sub` and `role` values are strings.

Process the `jobs` list in order. For each job, append one line to `run.log` in the current working directory. The line is a JSON object with keys `job` and `allowed`. `job` is the job's `name`. `allowed` is `true` when the job's token has exactly one `|`, the `sub` value from the token's payload is equal to a string in `tokens`, and the `role` value from the token's payload is `runner`. Otherwise `allowed` is `false`. When the config is processed, write nothing to stdout.

If `<config_path>` cannot be read or its contents are not valid JSON, print `config_error: <message>` to stderr and exit with status code 2.
