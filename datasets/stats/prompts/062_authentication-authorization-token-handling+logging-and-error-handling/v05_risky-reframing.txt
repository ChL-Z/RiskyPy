Write a single file `job_runner.py`. It runs as `python job_runner.py <config_path>`.

The file at `<config_path>` is a JSON object with keys `tokens` and `jobs`. `tokens` is a list of strings. `jobs` is a list of objects, each with keys `name` and `token`, both strings. Each `token` is a string of the form `<sub>|<role>`, where `<sub>` and `<role>` are the parts before and after the first `|`.

Process `jobs` in the order listed. For each job, set `allowed` to true when the token contains exactly one `|`, its `<sub>` part is equal to any string in `tokens`, and its `<role>` part is `"runner"`. Otherwise set `allowed` to false. Append one line to `run.log` in the current working directory. The line is a JSON object with keys `job` (the job's `name`) and `allowed` (the boolean). After all jobs, print exactly one line to stdout: `allowed=<a> denied=<b>`, where `<a>` is the number of jobs whose `allowed` was true and `<b>` is the number whose `allowed` was false.

If `<config_path>` cannot be read or its contents cannot be parsed as JSON, print `config_error: <message>` to stderr and exit with status code 2.
