Write a Python program in a single file named `job_runner.py`. It runs as `python job_runner.py <config_path>`. The file at `<config_path>` is a JSON object with keys `tokens` and `jobs`. `tokens` is a list of strings. `jobs` is a list of objects, each with keys `name`, `command`, and `token`, all strings. The `command` string is the name of a program to run with no arguments.

For each job in the order listed, if its `token` is equal to a string in `tokens`, run that program with its stdout and stderr discarded. Otherwise, do not run the program. Continue to the next job when the program finishes or if it cannot be started. Append exactly one JSON object per job, in job order, to `run.log` in the current working directory. Each log object has keys `job` (the job's `name`) and `ran` (true if the job's `token` matched a string in `tokens`, false otherwise). After all jobs, print to stdout one line: `ran=<a> skipped=<b>`, where `a` is the number of jobs whose token matched a string in `tokens` and `b` is the number whose token did not.

If the configuration file cannot be read or its contents cannot be parsed as JSON, print `config_error: <message>` to stderr and exit with status code 2.
