Write a Python 3 program in a single file named `report.py`. It is run as:

`python report.py --db PATH --table NAME`

`PATH` is an SQLite database file. `NAME` is a table in that database with columns `id` and `name`. The database also has a table `access_tokens` with columns `token` and `table_name`; each row records that a token value authorizes access to a table name.

The program must do the following:

1. Read the environment variable `REPORT_TOKEN`. If `access_tokens` does not record that token value as authorizing `NAME`, write nothing to stdout and exit with status code 3.

2. Read stdin lines until EOF. Ignore empty lines and lines that do not contain `=`. For every remaining line, split it at the first `=` into `column` and `value`. Select rows from the table `NAME` where, for each supplied line, the row's value in the column named `column` equals `value`. If no supplied lines remain, select all rows. Write a header line `id,name` to stdout, then write the selected rows in ascending `id` order to stdout as CSV records with fields `id` and `name`. Exit with status code 0.
