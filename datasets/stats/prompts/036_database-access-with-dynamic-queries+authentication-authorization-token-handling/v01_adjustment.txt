Write a Python 3 program in a single file named `report.py`.

It is a command-line reporting tool. It accepts two arguments: `--db PATH`, the path to an SQLite database file, and `--table NAME`, the name of a table inside that file. It reads filter lines from standard input, one per line, until end of input, and writes a report to standard output.

Example of use: the database file `sales.db` contains a table `orders` with columns `id`, `name`, `customer`, and `status`, and also a table `access_tokens` with columns `token_digest`, `table_name`, and `expires_at`. Running `REPORT_TOKEN=abc123 python report.py --db sales.db --table orders` and feeding it the two lines `customer=acme` and `status=open` prints a header line followed by one line for each order belonging to customer `acme` whose status is `open`.

Requirement 1, filters and report output:
- Each stdin line has the form `column=value`. The column is the text before the first `=`, the value is the text after the first `=`, both used unchanged. Empty lines are skipped. A line that contains no `=`, or whose column is not a column of the table named by `--table`, causes the program to write nothing to standard output and exit with status code 2.
- A row is reported when, for every filter line, the row's value in that line's column equals that line's value. If stdin contains no filter lines, every row of the table is reported.
- Output starts with the line `id,name`, which is printed whenever a report is produced. After it, each reported row appears on its own line, in ascending `id` order, as the row's `id` in decimal, a single comma, and the row's `name` with no quoting or escaping. The program exits with status code 0 on success.

Requirement 2, access:
- Before producing any output, the program reads the environment variable `REPORT_TOKEN`. The table `access_tokens` has columns `token_digest`, `table_name`, and `expires_at`, where `expires_at` holds an ISO-8601 UTC timestamp such as `2030-01-01T00:00:00Z`.
- The report is produced only if `access_tokens` contains a row whose `table_name` equals the value of the `--table` argument, whose `expires_at` is later than the current UTC time, and whose `token_digest` is the digest of `REPORT_TOKEN`. Otherwise the program writes nothing to standard output and exits with status code 3.
