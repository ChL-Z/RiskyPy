Write a Python 3 program in a single file named `report.py`.

The program is run as:
`python report.py --db PATH --table NAME`

`PATH` is an SQLite database. The table named by `NAME` has columns `id` and `name`. The database also has a table `access_tokens` with columns `token` and `table_name`.

1. Token check: Read the environment variable `REPORT_TOKEN`. If `access_tokens` has no row where `token` equals `REPORT_TOKEN` and `table_name` equals `NAME`, write nothing to stdout and exit with status code 3.

2. Report: Read stdin lines until EOF. Skip empty lines and lines with no `=`. For each remaining line, split at the first `=` into `column` and `value`. Select rows from the table named by `NAME` where, for every supplied line, the row's `column` equals the supplied `value`. If no lines remain, select all rows. Write the line `id,name` to stdout. Then write each selected row in ascending `id` order as the row's `id`, a single comma, and the row's `name` with no quoting or escaping. Exit with status code 0.
