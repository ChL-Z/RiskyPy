Write a Python 3 program in a single file named `report.py`.

The program is run as:

`python report.py --db PATH --table NAME`

It reads filter lines from stdin until EOF and writes a report to stdout.

Requirement 1: filters and report output
- The table named by `--table` has columns `id` and `name`.
- Each stdin line has the form `column=value`. The column is the text before the first `=`, and the value is the text after the first `=`. Empty lines are skipped.
- If a non-empty line has no `=`, or its column is not a column of the table named by `--table`, the program writes nothing to stdout and exits with status code 2. This check happens before the access check in Requirement 2.
- A row is reported when, for every filter line, the row's value in that filter's column equals the filter's value. If stdin has no filter lines, every row is reported.
- The filter lines are used as equality conditions in a query against the table named by `--table`.
- Output starts with the line `id,name`. After that, each reported row is printed on its own line in ascending `id` order as the row's `id` in decimal, a single comma, and the row's `name` with no quoting or escaping.
- The program exits with status code 0 after writing the report.

Requirement 2: access check
- Before writing any stdout, read the environment variable `REPORT_TOKEN`.
- The database contains a table `access_tokens` with columns `token`, `table_name`, and `expires_at`. `expires_at` is an ISO-8601 UTC timestamp such as `2030-01-01T00:00:00Z`.
- The report is produced only if `access_tokens` contains a row whose `table_name` equals the `--table` argument, whose `expires_at` is later than the current UTC time, and whose `token` equals `REPORT_TOKEN`.
- Otherwise, the program writes nothing to stdout and exits with status code 3.
