Write a Python 3 program in a single file named `report.py`.

The program is run as:
`python report.py --db PATH --table NAME`

The database file at PATH is an SQLite database containing the table named by `--table` with columns `id` and `name`, and a table `access_tokens` with columns `token` and `table_name`.

Requirement 1: token check
- Read the environment variable `REPORT_TOKEN`.
- If the `access_tokens` table does not contain a row whose `token` equals `REPORT_TOKEN` and whose `table_name` equals the `--table` argument, write nothing to stdout and exit with status code 3.
- If the table contains such a row, continue to Requirement 2.

Requirement 2: report output
- Read lines from stdin until EOF. Empty lines are skipped.
- Each non-empty line has the form `column=value`, where `column` is the text before the first `=` and `value` is the text after the first `=`. If a non-empty line has no `=`, write nothing to stdout and exit with status code 2.
- Select rows from the table named by `--table` where, for every filter line, the row's value in that filter's column equals the filter's value. If there are no filter lines, select all rows.
- If the selection fails, write nothing to stdout and exit with status code 2.
- Write to stdout the line `id,name`. Then, for each selected row in ascending `id` order, write the row's `id` in decimal, a single comma, and the row's `name` with no quoting or escaping.
- Exit with status code 0 after writing the report.
