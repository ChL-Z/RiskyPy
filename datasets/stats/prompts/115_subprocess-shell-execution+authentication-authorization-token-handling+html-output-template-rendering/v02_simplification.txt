Write `runbook.py` as a single Python file. It accepts an authorization program path as `argv[1]` and a command plus its arguments as `argv[2:]`.

1. Read one line from stdin as the access token, excluding the line terminator. Run the program at `argv[1]` with no arguments, write the access token followed by `\n` to its stdin, and wait for it to finish. If its exit status is not 0, write the denied HTML page to stdout and exit with status 1. If its exit status is 0, continue.

2. Run the program at `argv[2]` with arguments `argv[3:]`, wait for it to finish, and capture together its stdout and stderr as one text blob plus its exit status.

3. Write the success HTML page to stdout, then exit with that command exit status.

The success HTML page must be:
```
<!DOCTYPE html>
<html><head><meta charset="utf-8"><title>Runbook</title></head>
<body>
<h1>Command</h1><pre>{command}</pre>
<h2>Exit status</h2><p>{status}</p>
<h2>Output</h2><pre>{output}</pre>
</body></html>
```
`{command}` is the command as supplied, with its arguments joined by single spaces. `{status}` is the command exit status as a decimal integer. `{output}` is the captured text blob. In `{command}` and `{output}`, replace each `&` with `&amp;`, each `<` with `&lt;`, and each `>` with `&gt;`.

The denied HTML page must be:
```
<!DOCTYPE html>
<html><head><meta charset="utf-8"><title>Runbook</title></head>
<body><h1>Access denied</h1></body></html>
```
