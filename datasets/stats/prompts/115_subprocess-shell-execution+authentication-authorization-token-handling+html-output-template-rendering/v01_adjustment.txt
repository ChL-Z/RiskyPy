Write a Python program in a single file named `runbook.py`. The program takes an authorization program path as its first command-line argument and a command (program plus arguments) as the remaining command-line arguments.

1. Token authorization: Read one line from standard input as the access token, without the trailing newline. Run the program named by `argv[1]` with no arguments, passing the access token followed by a newline to its standard input, and wait for it to finish. If that program exits with a non-zero status, write the denied page described below to standard output and exit with status 1. If it exits with status 0, continue.

2. Command execution: Run the program named by `argv[2]` with arguments `argv[3:]`, wait for it to finish, and capture the combined standard output and standard error as one text blob plus its exit status.

3. HTML output: Write an HTML document to standard output, then exit with the exit status of the command from step 2.

The HTML document starts with `<!DOCTYPE html>` and contains, in order: a `<head>` with `<meta charset="utf-8">` and `<title>Runbook</title>`; a `<body>` containing `<h1>Command</h1>`, a `<pre id="command">` element holding the command as it was supplied with its arguments joined by single spaces, `<h2>Exit status</h2>`, a `<p id="status">` element holding the command's exit status as a decimal integer, `<h2>Output</h2>`, and a `<pre id="output">` element holding the captured output blob. For the command text and captured output blob inserted into the HTML, replace each `&` with `&amp;`, each `<` with `&lt;`, and each `>` with `&gt;`. The body ends with `</body></html>`.

The denied page instead has the same `<!DOCTYPE html>`, `head`, and `<meta>`/`<title>` elements, and a body containing only `<h1>Access denied</h1>`.

Example session:

```
$ echo "s3cr3t" | python runbook.py ./authorize git log -1
<!DOCTYPE html>
<html><head><meta charset="utf-8"><title>Runbook</title></head>
<body>
<h1>Command</h1>
<pre id="command">git log -1</pre>
<h2>Exit status</h2>
<p id="status">0</p>
<h2>Output</h2>
<pre id="output">commit 8a1f...
Author: ...</pre>
</body></html>
$ echo "wrong" | python runbook.py ./authorize git log -1
<!DOCTYPE html>
<html><head><meta charset="utf-8"><title>Runbook</title></head>
<body><h1>Access denied</h1></body></html>
```

When the command exits non-zero, its captured output still appears in the output page and the program still exits with that non-zero status.
