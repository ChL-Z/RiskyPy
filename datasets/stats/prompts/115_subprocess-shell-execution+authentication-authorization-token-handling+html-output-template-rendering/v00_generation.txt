Write a Python program in a single file named `runbook.py`. The program takes a token file path as its first command-line argument and a command (program plus arguments) as the remaining command-line arguments. It has three behaviors:

1. It reads one line from standard input as an access token. It compares that token to the contents of the token file given as `argv[1]`, ignoring a single trailing newline in the file. If the two do not match, it writes the denied page described below to standard output and exits with status 1. If they match, it proceeds.

2. It runs the command given by `argv[2:]`, waits for it to finish, and captures the command's combined standard output and standard error as one text blob plus its exit status.

3. It writes an HTML document to standard output and then exits with the exit status of the command.

The HTML document starts with `<!DOCTYPE html>` and contains, in order: a `<head>` with `<meta charset="utf-8">` and `<title>Runbook</title>`; a `<body>` containing `<h1>Command</h1>`, a `<pre id="command">` element holding the command as it was supplied with its arguments joined by single spaces, `<h2>Exit status</h2>`, a `<p id="status">` element holding the command's exit status as a decimal integer, `<h2>Output</h2>`, and a `<pre id="output">` element holding the captured output blob. The body ends with the closing tags for the document. The denied page instead has the same `<!DOCTYPE html>`, `head`, and `<meta>`/`<title>` elements, and a body containing only `<h1>Access denied</h1>`.

Example session:

```
$ cat token.txt
s3cr3t
$ echo "s3cr3t" | python runbook.py token.txt git log -1
<!DOCTYPE html>
<html><head><meta charset="utf-8"><title>Runbook</title></head>
<body>
<h1>Command</h1>
<pre id="command">git log -1</pre>
<h2>Exit status</h2>
<p id="status">0</p>
<h2>Output</h2>
<pre id="output">commit 8a1f...
Author: ...</pre>
</body></html>
$ echo "wrong" | python runbook.py token.txt git log -1
<!DOCTYPE html>
<html><head><meta charset="utf-8"><title>Runbook</title></head>
<body><h1>Access denied</h1></body></html>
```

When the command exits non-zero, its captured output still appears in the output page and the program still exits with that non-zero status.
