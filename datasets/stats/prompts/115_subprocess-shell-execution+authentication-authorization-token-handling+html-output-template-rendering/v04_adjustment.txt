Write `runbook.py` as a single Python file. It accepts exactly two command-line arguments: `argv[1]` is the path to an authorization program, and `argv[2]` is a command line string. The program must perform these three steps in order.

1. Read one line from standard input as the access token, excluding the line terminator. Run the program at `argv[1]` with no command-line arguments. Write the access token followed by a newline to that program's standard input. Wait for that program to terminate. If its exit status is not 0, write the denied HTML page to standard output and exit with status 1. If its exit status is 0, continue to step 2.

2. Run the command line given by `argv[2]`. `argv[2]` is an executable name followed by zero or more arguments separated by single spaces; it contains no quotation marks, escape sequences, pipes, redirections, or shell operators. Wait for the command to terminate. Capture its standard output and standard error together as one text value, and capture its exit status.

3. Write the success HTML page to standard output, then exit with the captured exit status.

Success HTML page:
```html
<!DOCTYPE html>
<html><head><meta charset="utf-8"><title>Runbook</title></head>
<body><h1>Runbook</h1><pre>Command: COMMAND
Exit status: STATUS
Output: OUTPUT</pre></body></html>
```
In the `<pre>` element, `COMMAND` is `argv[2]`, `STATUS` is the captured exit status as a decimal integer, and `OUTPUT` is the captured standard output and standard error text. Each of `COMMAND`, `STATUS`, and `OUTPUT` must appear in the rendered page as the literal characters of that value; any character in those values that would otherwise be interpreted as HTML markup must be represented so the browser displays the original character.

Denied HTML page:
```html
<!DOCTYPE html>
<html><head><meta charset="utf-8"><title>Runbook</title></head>
<body><h1>Access denied</h1></body></html>
```
