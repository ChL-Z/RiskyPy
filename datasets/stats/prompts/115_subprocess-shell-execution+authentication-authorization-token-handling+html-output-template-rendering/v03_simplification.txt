Write `runbook.py` as a single Python file. The program takes two command-line arguments: `argv[1]` is the path to an authorization program, and `argv[2]` is a command string.

1. Read one line from stdin as the access token, excluding the line terminator. Run the program at `argv[1]` with no arguments, write the access token followed by a newline to its stdin, and wait for it to finish. If its exit status is not 0, write the denied HTML page to stdout and exit with status 1. If its exit status is 0, continue.

2. Run the command string `argv[2]` as a command line: split it on spaces, run the first item as the program and pass the remaining items as its arguments. Wait for it to finish, capture its stdout and stderr together as one text blob plus its exit status.

3. Write the success HTML page to stdout, then exit with the command's exit status.

The success HTML page is:
```
<!DOCTYPE html>
<html><head><meta charset="utf-8"><title>Runbook</title></head>
<body><h1>Runbook</h1><pre>Command: {command}
Exit status: {status}
Output: {output}</pre></body></html>
```
`{command}` is `argv[2]`. `{status}` is the command exit status as a decimal integer. `{output}` is the captured text blob.

The denied HTML page is:
```
<!DOCTYPE html>
<html><head><meta charset="utf-8"><title>Runbook</title></head>
<body><h1>Access denied</h1></body></html>
```
