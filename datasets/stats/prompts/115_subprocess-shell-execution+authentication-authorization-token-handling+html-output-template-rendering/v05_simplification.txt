Write `runbook.py` as a single Python file. It accepts command-line arguments: `argv[1]` is the path to an authorization program, `argv[2]` is an executable name, and `argv[3:]` are zero or more arguments for that executable.

1. Read one line from stdin as the access token, excluding the line terminator. Run the program at `argv[1]` with no command-line arguments. Write the access token followed by a newline to that program's stdin. Wait for it to terminate. If its exit status is not 0, write `<html><body><h1>Access denied</h1></body></html>` to stdout and exit with status 1. If its exit status is 0, continue.

2. Run `argv[2]` with `argv[3:]` as its arguments. Wait for it to terminate. Capture its stdout and stderr together as one text value, and capture its exit status.

3. Write `<html><body><h1>Runbook</h1><pre>Command: CMD
Exit status: STATUS
Output: OUTPUT</pre></body></html>` to stdout, then exit with the captured exit status. `CMD` is `argv[2]` followed by `argv[3:]` separated by single spaces. `STATUS` is the captured exit status as a decimal integer. `OUTPUT` is the captured stdout and stderr text.
