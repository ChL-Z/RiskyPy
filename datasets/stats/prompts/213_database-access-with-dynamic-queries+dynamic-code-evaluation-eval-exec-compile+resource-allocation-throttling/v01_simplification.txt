Write a single Python file `apply_rules.py`. It is run as:

python apply_rules.py rules.tsv data.sqlite3 --max-rows-per-second N

N is an integer greater than 0.

The rules file is UTF-8 with LF line endings:
- line 1: one table name.
- line 2: comma-separated column names, no spaces.
- each remaining non-empty line: rule name, a TAB character, and an arithmetic expression.

Rule names are distinct. An expression uses the column names from line 2, integer or float literals, `+`, `-`, `*`, `/`, and parentheses. No other operators appear.

The program must do exactly this:
1. Open the SQLite database file. Read the columns listed on line 2 from the table named on line 1, one row at a time, in the order the database returns rows. For each row, compute every rule expression using that row's column values. Count a rule when its computed value is greater than 0.
2. After reading a row, do not read the next row until at least 1/N seconds have passed since that row was read. Apply this to every row.
3. Write to stdout one line per rule, in the order the rules appear in the rules file. Each line is the rule name, a TAB character, and the count of rows where that rule's computed value was greater than 0. Write nothing else to stdout.
