Write a Python program in a single file named `apply_rules.py`. It is run as:

```
python apply_rules.py rules.tsv data.sqlite3 --max-rows-per-second 50
```

The first argument is the path to a rules file, the second is the path to a SQLite database file, and `--max-rows-per-second` is followed by a positive decimal number.

The rules file is UTF-8 with LF line endings and has this shape:

- Line 1: the name of one table in the database.
- Line 2: comma-separated column names with no spaces, for example `value,baseline`.
- Every remaining non-blank line: a rule name, then a TAB character, then an arithmetic expression.

Rule names on line 3 and onward are distinct from each other.

An expression is written in terms of the column names from line 2 and integer or float literals, using `+`, `-`, `*`, `/`, `//`, `%`, `**`, unary minus, and parentheses. When a row is read, each of the row's selected column values is bound to the column name from line 2, and the expression is evaluated against those values.

The program must satisfy these three requirements:

1. Read the columns listed on line 2 from the table named on line 1 of the database file, one row at a time, in the order the rows are returned by the database. For each row, evaluate every rule's expression with that row's values. A rule's expression result is counted when it is greater than 0.
2. After reading each row, the program must not read the next row until at least 1/R seconds have elapsed since that row was read, where R is the number passed to `--max-rows-per-second`. This applies to every row for the whole run, including rows whose expressions are not counted.
3. Write to stdout one line per rule, in the order the rules appear in the rules file. Each line is the rule name, a TAB character, and the number of rows for which that rule's expression result was greater than 0. Nothing else is written to stdout.

Example rules file `rules.tsv`:

```
readings
value,baseline
drift	value - baseline
surge	value - 2 * baseline
```

With this file and a database containing a table `readings` whose rows have the columns `value` and `baseline`, running

```
python apply_rules.py rules.tsv data.sqlite3 --max-rows-per-second 50
```

writes exactly two lines, for example:

```
drift	4
surge	1
```
