Write a Python program in a single file named `render_pages.py`. The program builds one HTML file for each data row of a CSV file.

Command line:

`python render_pages.py <template_file> <csv_file> <output_dir>`

The template file is UTF-8 text containing the placeholders `{{id}}`, `{{title}}`, `{{body}}`, and `{{nonce}}`. The CSV file is UTF-8 and has a header row exactly `id,title,body`; every data row has three fields. Each `id` value is a string of ASCII letters, digits, `_`, and `-`. For each data row, the program writes `<output_dir>/<id>.html`. The output HTML is the template text with each occurrence of `{{id}}`, `{{title}}`, and `{{body}}` replaced by the corresponding CSV field value, and each occurrence of `{{nonce}}` replaced by that row's nonce string. The program prints each output file path to stdout as soon as its output file is written and closed, one path per line, and exits with status 0 after all rows have been written.

Requirements:
1. For each output file, `{{nonce}}` is replaced by a string of exactly 32 lowercase hexadecimal characters. No two output files produced in one run may contain the same nonce string.
2. At no time may more than 3 data rows be in progress at once. A row is in progress from the moment the program begins replacing placeholders for that row until its output file is written and closed.
3. Whenever fewer than 3 rows are in progress, at least 0.2 seconds have passed since the previous row start, and unstarted rows remain, the program must start the next unstarted row in CSV order. Rows may complete in any order.

Example usage:

Create `card.html` with this content:

```html
<html><head><meta name="nonce" content="{{nonce}}"></head><body><h1>{{title}}</h1><p>{{body}}</p></body></html>
```

Create `people.csv` with this content:

```csv
id,title,body
a1,Alice,Hello
b2,Bob,World
```

Run:

```
python render_pages.py card.html people.csv out
```

The program creates `out/a1.html` and `out/b2.html`. Each file contains a different 32-character lowercase hexadecimal nonce in its `<meta name="nonce">` tag.
