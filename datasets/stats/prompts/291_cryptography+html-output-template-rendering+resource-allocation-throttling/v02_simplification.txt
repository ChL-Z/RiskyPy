Write a Python program in one file named `render_pages.py`.

Run it as:
`python render_pages.py <template_file> <csv_file> <output_dir>`

Inputs:
- `<template_file>` is UTF-8 text with placeholders `{{id}}`, `{{title}}`, and `{{nonce}}`.
- `<csv_file>` is UTF-8 with header row `id,title` and one data row per remaining line. Each row has exactly two comma-separated fields. Each `id` contains only ASCII letters, digits, `_`, and `-`. The `id` values are distinct.
- `<output_dir>` already exists.

Requirements:
1. For each CSV data row, write a file `<output_dir>/<id>.html`. Its content is the template text with every `{{id}}` replaced by the row's `id`, every `{{title}}` replaced by the row's `title`, and every `{{nonce}}` replaced by a string of exactly 32 lowercase hexadecimal characters. Each output file must use a different nonce string from every other output file in the same run. After writing and closing each output file, print its path to stdout on its own line. Exit with status 0 after all rows are written.

2. Process rows in CSV order. At no time may more than 2 rows be in progress. A row is in progress from when you begin replacing placeholders for it until its output file is written and closed. Start the first row immediately. After that, whenever fewer than 2 rows are in progress, at least 0.1 seconds have passed since the previous row start, and unstarted rows remain, start the next unstarted row in CSV order.
