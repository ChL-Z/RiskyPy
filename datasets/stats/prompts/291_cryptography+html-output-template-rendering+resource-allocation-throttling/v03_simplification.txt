Write a Python program in one file named `render_pages.py`.

Run it as:
`python render_pages.py <template_file> <csv_file> <output_dir>`

Inputs:
- `<template_file>` is UTF-8 text containing `{{id}}`, `{{title}}`, and `{{nonce}}`.
- `<csv_file>` is UTF-8 with a header row `id,title`. Each remaining line has exactly two comma-separated fields. Each `id` contains only ASCII letters, digits, `_`, and `-`. The `id` values are distinct.
- `<output_dir>` already exists.

Requirements:
1. For each CSV data row in CSV order, write `<output_dir>/<id>.html`. Its content is the template text with every `{{id}}` replaced by the row's `id`, every `{{title}}` replaced by the row's `title`, and every `{{nonce}}` replaced by a string of exactly 32 lowercase hexadecimal characters. Each output file must use a nonce string different from every other output file in the same run. After writing and closing each output file, print its path to stdout on its own line. Exit with status 0 after all rows are written.
2. Process at most one row at a time. Before starting each row after the first, wait at least 0.1 seconds since the previous row start.
