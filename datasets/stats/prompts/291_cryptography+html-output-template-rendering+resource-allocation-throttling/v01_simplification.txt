Write a Python program in a single file named `render_pages.py`.

Command line:
`python render_pages.py <template_file> <csv_file> <output_dir>`

The template file is UTF-8 text containing the placeholders `{{id}}`, `{{title}}`, and `{{nonce}}`. The CSV file is UTF-8 with a header row exactly `id,title`; every data row has two fields. Each `id` value is a string of ASCII letters, digits, `_`, and `-`. The output directory exists before the program starts. For each data row, write `<output_dir>/<id>.html`. The output HTML is the template text with each occurrence of `{{id}}` and `{{title}}` replaced by the corresponding CSV field value, and each occurrence of `{{nonce}}` replaced by that row's nonce string. Print each output file path to stdout as soon as its output file is written and closed, one path per line. Exit with status 0 after all rows have been written.

Requirements:
1. For each output file, `{{nonce}}` is replaced by a string of exactly 32 lowercase hexadecimal characters. No two output files produced in one run may contain the same nonce string.
2. At no time may more than 2 data rows be in progress at once. A row is in progress from the moment the program begins replacing placeholders for that row until its output file is written and closed.
3. Whenever fewer than 2 rows are in progress, at least 0.1 seconds have passed since the previous row start, and unstarted rows remain, the program must start the next unstarted row in CSV order. Rows may complete in any order.
