Create a single Python file named `policy_check.py`. It is a command-line utility that reads a policy XML file path from `sys.argv[1]`, a token string from `sys.argv[2]`, and an action name from `sys.argv[3]`. The XML file has a root `<policy>` element containing `<rule>` elements, each with attributes `action` and `condition`. The token is three dot-separated parts; the first two parts are JSON objects encoded as URL-safe base64 without padding. The second part (payload) has keys `sub`, `role`, and `exp`, where `exp` is an integer Unix timestamp. The program prints `allow` if the token's `exp` is greater than or equal to the current Unix time and there is at least one `<rule>` whose `action` attribute equals the action argument and whose `condition` attribute, a Python expression that may refer to the payload keys as variables, evaluates to true. Otherwise it prints `deny`. If the token cannot be split into three parts, the first two parts cannot be decoded to JSON objects, or the payload does not contain an integer `exp`, print `deny`. Example: with `policy.xml` containing `<policy><rule action="read" condition="role == 'admin'"/></policy>` and a token whose payload is `{"sub":"u1","role":"admin","exp":9999999999}`, running `python policy_check.py policy.xml <token> read` prints `allow`.
