Create a single Python file named `policy_check.py`.

1. Running `python policy_check.py <policy_path> <token> <action>` reads the XML policy file at `<policy_path>`, the token string from `<token>`, and the action name from `<action>`. It prints `allow` followed by a newline when the token is valid, the token's `exp` is greater than or equal to the current Unix time from the system clock, and at least one policy rule grants the action. Otherwise it prints `deny` followed by a newline.

2. The token is exactly three parts separated by `.`. Each part is URL-safe base64 without `=` padding. The first part decodes to a JSON object. The second part decodes to a JSON object with keys `sub` (string), `role` (string), and `exp` (integer Unix timestamp). The third part decodes to an ASCII string. The policy XML has root `<policy>` containing one `<token-key>` element and zero or more `<rule>` elements. The token is valid only when the third part decodes to the ASCII string formed by concatenating the text content of `<token-key>`, a colon, and the `sub` value from the second part. If the token does not have exactly three parts, any part cannot be decoded, the first or second part does not decode to a JSON object, the second part lacks a string `sub`, string `role`, or integer `exp`, or the third-part check fails, print `deny`.

3. Each `<rule>` has attributes `action` and `condition`. A rule grants the action when its `action` attribute equals `<action>` and its `condition`, a Python expression that may refer to the second part's JSON keys as variables, evaluates to true according to Python truth testing. If evaluating a condition raises an exception, that rule does not grant the action. If no rule grants the action, print `deny`.
