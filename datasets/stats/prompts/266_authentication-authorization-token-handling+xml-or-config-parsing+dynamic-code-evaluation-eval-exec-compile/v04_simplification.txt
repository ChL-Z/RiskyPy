Create a single Python file named `policy_check.py`.

1. Running `python policy_check.py <policy_path> <token> <action>` reads the XML file at `<policy_path>`. The XML root element is `<policy>`, containing exactly one `<token-id>` element and zero or more `<rule>` elements. Each `<rule>` element has an `action` attribute and a `condition` attribute. Print `allow` followed by a newline when the token check passes, the expiry check passes, and at least one rule grants the action. Otherwise print `deny` followed by a newline.

2. The token is exactly two parts separated by `.`: the first part is a nonempty string, and the second part is an integer Unix timestamp. The token check passes when the first part equals the text content of `<token-id>` with leading and trailing whitespace removed. The expiry check passes when the second part is greater than or equal to the current Unix time from the system clock. If the token does not have exactly two parts, if the second part is not an integer, or if the token check fails, print `deny` followed by a newline and do not evaluate any rule.

3. A rule grants the action when its `action` attribute equals `<action>` and its `condition` attribute is a Python expression that evaluates to a truthy value with variable `user` bound to the token's first part. If that evaluation raises an exception, the rule does not grant the action. If the token check and expiry check pass but no rule grants the action, print `deny` followed by a newline.
