Create a single Python file named `policy_check.py`.

Running `python policy_check.py <policy_path> <token> <action>` reads the XML file at `<policy_path>`, uses the token string `<token>`, and uses the action name `<action>`. Print `allow` followed by a newline if the token check passes, the token expiry has not passed, and at least one policy rule grants the action. Otherwise print `deny` followed by a newline. The token expiry has not passed when the `exp` value described in item 2 is greater than or equal to the current Unix time from the system clock.

The token is exactly three parts separated by `.` characters. The first part is ignored. The second part is URL-safe base64 text with no `=` padding; decoding it yields a JSON object with keys `sub`, `role`, and `exp`, where `exp` is an integer Unix timestamp. The third part is URL-safe base64 text with no `=` padding; decoding it yields an ASCII string. The policy XML has a root element `<policy>` containing exactly one `<token-id>` element and zero or more `<rule>` elements. The token check passes when the third part decodes to an ASCII string equal to the text content of `<token-id>` with leading and trailing whitespace removed. When the token check fails, print `deny` followed by a newline and do not evaluate any rule.

Each `<rule>` element has an `action` attribute and a `condition` attribute. A rule grants the action when its `action` attribute equals `<action>` and its `condition` attribute contains Python source for an expression that evaluates to a truthy value when evaluated with each key from the decoded second part bound as a variable name set to the corresponding value. If that evaluation raises an exception, the rule does not grant the action. If the token check passes and the expiry has not passed, but no rule grants the action, print `deny` followed by a newline.
