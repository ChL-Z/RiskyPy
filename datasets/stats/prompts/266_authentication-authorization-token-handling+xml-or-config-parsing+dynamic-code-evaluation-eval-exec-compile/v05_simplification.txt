Create a single Python file named `policy_check.py`. Running `python policy_check.py <policy_path> <token> <action>` reads the XML file at `<policy_path>`. The XML root is `<policy>`, containing one `<token-id>` child and zero or more `<rule>` children. Print `allow` followed by a newline if the token is valid, not expired, and at least one rule grants `<action>`; otherwise print `deny` followed by a newline.

A token is `<user>.<expiry>`, where `<user>` is the text before the single period and `<expiry>` is the text after it. The token is valid when `<user>` equals the `<token-id>` text with leading and trailing whitespace removed. It is not expired when `<expiry>` is an integer Unix timestamp greater than or equal to the current Unix time from the system clock. If the token does not contain exactly one period or `<expiry>` is not an integer, print `deny` followed by a newline.

A `<rule>` grants `<action>` when its `action` attribute equals `<action>` and its `condition` attribute is a Python expression that, with name `user` bound to the token's `<user>` part, evaluates to a truthy value. If evaluating that expression raises an exception, that rule does not grant.
