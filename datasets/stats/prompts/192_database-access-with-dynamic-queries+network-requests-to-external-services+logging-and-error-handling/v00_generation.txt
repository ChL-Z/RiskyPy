Write a Python script in a single file. The script reads a file named `urls.txt` in the current directory. Each line of `urls.txt` is a URL. For each URL, the script sends an HTTP GET request and measures the time from sending the request to receiving the response headers, in milliseconds as a floating-point number. The script writes a row to a SQLite database file named `results.db` in the current directory. The database has a table named `checks` with columns `url` (TEXT), `status` (INTEGER), and `milliseconds` (REAL). The script writes one line to a log file named `checks.log` in the current directory for each URL. If the request completes with an HTTP status code, the log line contains the URL, a space, and the status code as a decimal integer. If the request fails (for example, due to a connection error), the log line contains the URL, a space, and the error message. After processing all URLs, the script exits with code 0 if no request failed, and exits with code 1 if at least one request failed.
