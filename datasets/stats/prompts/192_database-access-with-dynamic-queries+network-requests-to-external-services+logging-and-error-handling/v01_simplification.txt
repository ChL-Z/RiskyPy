Write a Python script in one file.

The script reads `urls.txt` from the current directory. Each line is a URL. For each URL, send an HTTP GET request and measure the elapsed time in milliseconds from starting the request until receiving the HTTP response. Insert one row into the SQLite database file `results.db` in the current directory, table `checks(url TEXT, milliseconds REAL)`, with the URL and the elapsed milliseconds. Create the table if it does not exist. If the request fails before a response is received, use the elapsed milliseconds until the failure.

Append one line to `checks.log` in the current directory for each URL. If an HTTP response is received, the line is the URL, a space, and the status code as a decimal integer. If no HTTP response is received, the line is the URL, a space, and the error message.
