Write a Python 3 program in a single file named `run_jobs.py`. Invoke it as:

python run_jobs.py <JOBS_FILE> <STATE_FILE> <RATE>

`JOBS_FILE` is a JSON file with this shape:
{
  "vars": {"base": 4, "step": 3},
  "jobs": [
    {"id": "j1", "expr": "base + step * 2"},
    {"id": "j2", "expr": "(base ** 2) % 7"},
    {"id": "j3", "expr": "base // step"}
  ]
}
`vars` maps names to integers. `jobs` is a list of records; each has a unique string `id` and a string `expr`. `STATE_FILE` is a file path that may or may not exist. `RATE` is a positive integer argument.

The program must do the following:

1. For each job in the order given, if its id is not already recorded in `STATE_FILE`, compute the integer value of the arithmetic expression in `expr`. The expression uses names bound in `vars`, integer literals, parentheses, and the operators `+`, `-`, `*`, `//`, `%`, and `**`. Print one line to stdout containing the job `id`, a single space, the value in decimal notation, and a newline, then flush stdout.

2. Pace the jobs so that no more than `RATE` jobs begin within any 1.0-second interval. Concretely: when a job is about to begin and at least `RATE` jobs have already begun during this run, let `E` be the job that began `RATE` positions before it in this run; if less than 1.0 second has elapsed since `E` began, wait until exactly 1.0 second has elapsed since `E` began, then begin the current job. The first job that begins in a run begins immediately.

3. `STATE_FILE` holds the ids of jobs completed by earlier runs. At startup, if `STATE_FILE` exists, read the ids it contains; if it does not exist, treat it as empty. A job whose id is already recorded is skipped: no expression is computed, no output line is written, and it does not count as a begun job for the pacing rule in requirement 2. After printing a job's output line, add that job's id to `STATE_FILE` and rewrite `STATE_FILE` on disk with one id per line before the next job begins. A file written by one run must be readable by a later run.

Exit with status code 0 after the last job.

Example:
$ cat jobs.json
{"vars": {"base": 4, "step": 3}, "jobs": [{"id": "j1", "expr": "base + step * 2"}, {"id": "j2", "expr": "(base ** 2) % 7"}, {"id": "j3", "expr": "base // step"}]}
$ python run_jobs.py jobs.json progress.txt 2
j1 10
j2 2
j3 1
$ python run_jobs.py jobs.json progress.txt 2
$ echo $?
0
