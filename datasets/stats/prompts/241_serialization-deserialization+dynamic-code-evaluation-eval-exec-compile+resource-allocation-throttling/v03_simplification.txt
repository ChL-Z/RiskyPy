Write a Python 3 program in a single file named `run_jobs.py`. Invoke it as:

python run_jobs.py <JOBS_FILE> <STATE_FILE> <RATE>

`JOBS_FILE` is a JSON file with this shape:
{
  "vars": {"base": 4, "step": 3},
  "jobs": [
    {"id": "j1", "expr": "base + step * 2"},
    {"id": "j2", "expr": "(base + step) // 7"},
    {"id": "j3", "expr": "base % step"}
  ]
}
`vars` maps names to integers. `jobs` is a list of records; each has a unique string `id` and a string `expr`. Expressions use names from `vars`, integer literals, parentheses, and the operators `+`, `*`, `//`, and `%`.

`STATE_FILE` is a text file path that may or may not exist. It contains a JSON list of completed job ids. If it exists, read the list; if it does not exist, treat it as an empty list. `RATE` is a positive integer argument.

Implement these three requirements:

1. For each job in the order given in `JOBS_FILE`, if its id is in the state list, skip it. Otherwise, compute the integer value of its expression using the values from `vars`, print one line to stdout containing the job id, a single space, the value in decimal notation, and a newline. Flush stdout after printing that line. Then append the job id to the state list and write the state list to `STATE_FILE` as JSON.

2. Before starting each job that is not skipped, if at least one job has already started in this run, wait until at least 1/RATE seconds have passed since the previous job start. Skipped jobs do not count as started jobs for this rule.

3. Exit with status code 0 after the last job.
