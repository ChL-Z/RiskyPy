Write a single-file Python program `batch_run.py` that executes a batch of commands from a JSON manifest and records each result.

The program takes exactly one command-line argument: the path to a UTF-8 JSON file. That file contains a JSON array of objects. Each object has exactly two keys: `name` (a string) and `command` (a string). The program processes the objects in array order.

Requirements:

1. For each object, run `command` as an external command. Capture the combined standard output and standard error text produced by the command, and capture the process exit status. Measure the wall-clock duration in integer milliseconds. If the command cannot be started, use exit status `127` and put the startup error text into the captured output.

2. After all objects are processed, write a UTF-8 JSON file next to the input file. If the input path is `/path/to/jobs.json`, the output path is `/path/to/jobs.results.json`. The output file contains a JSON array with one object per input object, in the same order. Each output object has exactly four keys: `name` (string), `exit_code` (integer), `output` (string), and `duration_ms` (integer).

3. Print one line to standard error for each processed object in this exact format: `name: exit_code=<code> duration_ms=<ms>`. If reading the input file fails or the input file does not contain valid JSON, print `error: <message>` to standard error and exit with status `2`; do not write the results file. If all commands have exit status `0`, exit with status `0`. Otherwise, exit with status `1`.

Example usage:

Given `jobs.json`:
```json
[
  {"name": "build", "command": "python -c \"print('ok')\""},
  {"name": "missing", "command": "definitely-not-a-command"}
]
```

Running `python batch_run.py jobs.json` writes `jobs.results.json` containing objects such as `{"name": "build", "exit_code": 0, "output": "ok\n", "duration_ms": 12}` and `{"name": "missing", "exit_code": 127, "output": "...", "duration_ms": 3}`. It prints lines like:
```
build: exit_code=0 duration_ms=12
missing: exit_code=127 duration_ms=3
```
It exits with status `1`.
