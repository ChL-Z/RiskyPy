Write a Python program in a single file named `issue_grant.py`.

Run it from the command line as:

    python issue_grant.py <db_path> <username> <resource_id> <ttl_seconds>

`<db_path>` is a SQLite database file with two tables:

    users(username TEXT PRIMARY KEY, secret TEXT NOT NULL, active INTEGER NOT NULL)
    grants(username TEXT NOT NULL, resource_id TEXT NOT NULL)

The `secret` column holds 64 lowercase hexadecimal characters. `<ttl_seconds>` is a decimal integer.

Requirements:

1. Query the database using the `<username>` and `<resource_id>` arguments. If `users` has no row for `<username>`, or its `active` column is not 1, or `grants` has no row for that `<username>` and `<resource_id>`, write exactly the line `denied` to stdout and exit with status code 3.

2. Otherwise, let `<expiry>` be the current Unix time in whole seconds plus `<ttl_seconds>`. Form the payload text `<username>:<resource_id>:<expiry>`. Write exactly one line to stdout: the payload text, then a `.`, then a 64-character lowercase hexadecimal tag. The tag must be deterministic from the payload text and the user's `secret`: the same payload text and same `secret` always produce the same tag, and changing any one character in either the payload text or the `secret` changes the tag. Exit with status code 0.
