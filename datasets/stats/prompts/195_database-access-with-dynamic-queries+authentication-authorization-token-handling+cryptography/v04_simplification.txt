Write a Python program in a single file named `issue_grant.py`.

Run it from the command line as:

    python issue_grant.py <db_path>

The program reads one JSON object from stdin. The object has keys `username`, `password`, `resource_id`, and `ttl_seconds`. `ttl_seconds` is an integer from 1 to 86400.

`<db_path>` is a SQLite database file with two tables:

    users(username TEXT PRIMARY KEY, secret TEXT NOT NULL)
    grants(username TEXT NOT NULL, resource_id TEXT NOT NULL)

Program behavior:

1. Look up a row in `users` for the `username` value from stdin. If no row exists, or `password` does not equal that row's `secret`, or `grants` has no row for that `username` and `resource_id`, write exactly `denied` to stdout and exit with status code 3.

2. Otherwise, let `expiry` be the current Unix time in whole seconds plus `ttl_seconds`. Form the payload text `username:resource_id:expiry`. Write exactly one line to stdout: the payload text, then a `.`, then a 64-character lowercase hexadecimal tag. The tag is deterministic from the payload text and the user's `secret`: the same payload text and same `secret` always produce the same tag, and changing any one character in either the payload text or the `secret` changes the tag. Exit with status code 0.
