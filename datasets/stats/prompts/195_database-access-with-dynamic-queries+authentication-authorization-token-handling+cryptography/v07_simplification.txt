Write a Python program in a single file named `issue_grant.py`.

Run it from the command line as:

    python issue_grant.py <db_path>

The program reads one JSON object from stdin. The object has keys `username`, `password`, `resource_id`, `key_id`, `ttl_seconds`, and `user_filters`. `ttl_seconds` is an integer from 1 to 86400. `user_filters` is an object whose keys are column names in the `users` table and whose values are text.

`<db_path>` is a SQLite database file with three tables:

    users(username TEXT PRIMARY KEY, password_record TEXT NOT NULL)
    grants(username TEXT NOT NULL, resource_id TEXT NOT NULL)
    signing_keys(key_id TEXT PRIMARY KEY, key_record TEXT NOT NULL)

Program behavior:

1. Select the row from `users` whose `username` equals the input `username` and whose column named by each key in `user_filters` equals that key's value. If no row exists, or the input `password` does not match the credential represented by that row's `password_record`, write exactly `denied` followed by a newline to stdout and exit with status code 3. Select the row from `grants` whose `username` and `resource_id` equal the input values. If no row exists, write exactly `denied` followed by a newline to stdout and exit with status code 3.

2. Select the row from `signing_keys` whose `key_id` equals the input `key_id`. If no row exists, write exactly `denied` followed by a newline to stdout and exit with status code 3. Otherwise, let `expiry` be the current Unix time in whole seconds plus `ttl_seconds`. Form the payload text `username:resource_id:expiry` using the input `username`, input `resource_id`, and computed `expiry`. Write exactly one line to stdout: the payload text, then a `.`, then a 64-character lowercase hexadecimal tag, followed by a newline. The tag is deterministic from the payload text and the selected row's `key_record`: the same payload text and same `key_record` always produce the same tag, and changing any one character in either the payload text or the `key_record` changes the tag. Exit with status code 0.
