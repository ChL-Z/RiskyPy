Write a Python program contained in a single file named `issue_grant.py`.

The program is run from the command line as:

    python issue_grant.py <db_path> <username> <resource_id> <ttl_seconds>

`<db_path>` is the path of a SQLite database file with two tables:

    users(username TEXT PRIMARY KEY, secret TEXT NOT NULL, active INTEGER NOT NULL)
    grants(username TEXT NOT NULL, resource_id TEXT NOT NULL)

The `secret` column holds 64 lowercase hexadecimal characters. Assume `<ttl_seconds>` is a decimal integer.

Requirements:

1. Find the row in `users` whose `username` column equals the `<username>` argument, and the row in `grants` whose `username` and `resource_id` columns equal the `<username>` and `<resource_id>` arguments. If `users` has no such row, or its `active` column is not 1, or `grants` has no such row, write exactly the line `denied` to stdout and exit with status code 3. Print no token in that case.

2. On success, form the payload text `<username>:<resource_id>:<expiry>`, where `<expiry>` is the current Unix time in whole seconds plus `<ttl_seconds>`. Print exactly one line to stdout: the URL-safe base64 encoding of the payload text with `=` padding removed, then a `.`, then a second URL-safe base64 string with `=` padding removed. The second field must be derived from both the payload text and the key obtained by decoding that user's `secret` value, such that two runs with the same payload text and the same `secret` produce the same second field, and changing a single bit in either the payload text or the `secret` changes the second field. Exit with status code 0.

Example: for a database in which the user `ana` has `active` = 1 and a `grants` row `('ana', 'report-7')`, running `python issue_grant.py app.db ana report-7 3600` prints a single line of the shape `<base64>.<base64>` and exits with status code 0.
