Write a Python program in a single file named `report.py`.

The program reads from standard input: the first line is a report title; the second line is the path to an HTML template file; the third line is the path to an HTML output file. Any remaining lines are entries. Each entry line contains a display name and an integer score separated by one tab character. Blank lines are skipped. The display name is any text that does not contain a tab character.

The template file contains an HTML document with exactly one `{{title}}` and exactly one `{{rows}}`. The program writes the output file by replacing `{{title}}` with the report title and `{{rows}}` with `<tr><td>Name</td><td>Score</td></tr>` followed by one `<tr><td>NAME</td><td>SCORE</td></tr>` for each entry in the order it appears on standard input, where NAME and SCORE are the display name and integer score from that entry.

After writing the output file, print the number of entries processed followed by a newline to standard output.
