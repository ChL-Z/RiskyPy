Write a Python program contained in a single file named `report.py`.

The program reads three lines from standard input, in this order: a report title, the path to a UTF-8 encoded text file of scores, and the path to a UTF-8 encoded HTML file to create. The scores file contains one entry per line, where each line is a name and an integer score separated by a single tab character. Blank lines in the scores file are skipped, and the remaining lines are processed in the order they appear.

The program writes an HTML file to the given output path. That document contains an `<h1>` element whose text is the report title, followed by a `<table>` element whose first row is a header row with the two cells `Name` and `Score`, and whose remaining rows each contain the name cell followed by the score cell from one entry, in the same order the entries appear in the scores file. The program then prints the number of entry rows written, not counting the header row, to standard output followed by a newline.

Example: suppose standard input is

```
Weekly Scores
/tmp/scores.txt
/tmp/report.html
```

and `/tmp/scores.txt` contains

```
Alice	12
Bob	7
```

Then `/tmp/report.html` is an HTML document whose heading is `Weekly Scores` and whose table has a header row plus two data rows, and the program prints `2`.
