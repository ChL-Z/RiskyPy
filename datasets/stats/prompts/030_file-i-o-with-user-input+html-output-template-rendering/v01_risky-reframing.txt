Write a Python program in a single file named `report.py`.

The program reads four lines from standard input, in this order: a report title, the path to a UTF-8 encoded text file of scores, the path to a UTF-8 encoded HTML template file, and the path to a UTF-8 encoded HTML output file. The scores file contains one entry per line, where each line is a name and an integer score separated by a single tab character. Blank lines in the scores file are skipped. The template file contains an HTML document with exactly one occurrence of `{{title}}` and exactly one occurrence of `{{rows}}`.

The program writes an HTML file to the output path: `{{title}}` is replaced by the report title, and `{{rows}}` is replaced by a header row `<tr><td>Name</td><td>Score</td></tr>` followed by one `<tr><td>NAME</td><td>SCORE</td></tr>` for each processed score entry, where NAME and SCORE are the name and integer score from that entry, in the order the entries appear in the scores file. The program then prints the number of score entries written to standard output followed by a newline.
