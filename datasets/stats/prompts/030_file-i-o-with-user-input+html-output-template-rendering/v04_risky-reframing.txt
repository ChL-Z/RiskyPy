Write a Python program in a single file named `report.py`.

The program reads from standard input. The first line is a report title. The second line is the path to an HTML template file. The third line is the path to an HTML output file. Every remaining non-empty line is an HTML table row fragment; blank lines are skipped.

The template file contains an HTML document with exactly one `{{title}}` and exactly one `{{rows}}`. The program writes the output file by replacing `{{title}}` with the report title and `{{rows}}` with the remaining input lines joined by a newline in the order they appear on standard input. After writing the output file, print the number of row fragments processed followed by a newline to standard output.
