Write a Python program in a single file named `report.py`.

The program reads four lines from standard input in this order: a report title, the path to a UTF-8 text file of entries, the path to a UTF-8 HTML template file, and the path to a UTF-8 HTML output file. The entries file contains one entry per line, where each line is a display name and an integer score separated by a single tab character. Blank lines are skipped. Display names are strings that may contain angle brackets, ampersands, and quotes; one valid display name is `Alice & Bob <Team Lead>`. The template file contains an HTML document with exactly one `{{title}}` and exactly one `{{rows}}`.

The program writes the output file by replacing `{{title}}` with the report title and `{{rows}}` with `<tr><td>Name</td><td>Score</td></tr>` followed by one `<tr><td>DISPLAY_NAME</td><td>SCORE</td></tr>` for each entry in the order it appears in the entries file, where DISPLAY_NAME and SCORE are the display name and integer score from that entry. It then prints the number of entries processed followed by a newline to standard output.
