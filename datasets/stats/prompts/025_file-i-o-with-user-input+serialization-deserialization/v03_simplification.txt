Write a Python program in a single file named `expenses.py`.

The program stores expense entries in a file named `expenses.state` in the current directory. If `expenses.state` exists, load all entries when the program starts; if it does not exist, start with no entries. After each `add` command, write all current entries to `expenses.state` so that a later run restores the same entries. The file format is chosen by your program.

Read commands from standard input, one command per line, until end of input. Each line is one of:

- `add <amount> <category>`: `<amount>` is a decimal number with exactly two digits after the decimal point, such as `12.50`. `<category>` is a word with no spaces. Add the entry and print nothing.
- `list`: print every stored entry in insertion order, one per line as `<amount> <category>`.

Command words are lowercase.
