Write a Python program in a single file named `expenses.py`.

The program keeps expense entries in a file named `expenses.state` in the current directory. Each entry is stored as one line with the exact text `<amount> <category>`, where `<amount>` has exactly two digits after the decimal point and `<category>` has no spaces. When the program starts, if `expenses.state` exists, read its lines and load each line as an entry in that order; otherwise start with no entries.

Read lines from standard input until end of input. Each input line is one command:
- `add <amount> <category>`: append that entry, then write all entries to `expenses.state` in their current order, one per line, using the format above. Print nothing.
- `list`: print every entry in insertion order, one per line, as `<amount> <category>`.

Command words are lowercase.
