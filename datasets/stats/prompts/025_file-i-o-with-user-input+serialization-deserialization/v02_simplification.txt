Write a Python program in a single file named `expenses.py`. The program uses a file named `expenses.state` in the current directory to keep expense entries between runs. If `expenses.state` exists, load all entries from it at startup; if it does not exist, start with no entries. After each `add` command, write all current entries to `expenses.state` so that a later run restores the same amounts and categories. The format of `expenses.state` is defined by your implementation.

The program then reads commands from standard input, one command per line, until end of input. Each line is exactly one of:

- `add <amount> <category>`: `<amount>` is a decimal number with exactly two digits after the decimal point, such as `12.50`; `<category>` is a word with no spaces. Add the entry and print nothing.
- `list`: print every stored entry in insertion order, one per line as `<amount> <category>`.
- `total`: print the sum of all stored amounts, with exactly two digits after the decimal point.

The command words are lowercase.
