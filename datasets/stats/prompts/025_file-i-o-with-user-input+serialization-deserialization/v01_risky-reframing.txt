Write a Python program in a single file named `expenses.py`. The program receives one command-line argument: the path of a state file. If that file exists, the program loads from it all expense entries before reading standard input. If the file does not exist, the program starts with no entries. The state file is a serialized snapshot of the expense entries as Python data structures, written by this program on an earlier run. The format is defined by your implementation, but a later run of this same program must restore every amount and category exactly, with amounts kept as exact decimal values rather than binary floating-point values.

The program then reads commands from standard input, one command per line, until end of input. Each line is one of:

- `add <amount> <category>`: `<amount>` is a decimal number such as `12.50`; `<category>` is a word with no space characters. The line has exactly these three tokens separated by spaces. Append one expense entry. Print no output. After each add, write all entries back to the state file path from the command-line argument.
- `list`: print every stored entry in insertion order, one per line as `<amount> <category>`, where `<amount>` has exactly two digits after the decimal point.
- `total`: print the sum of all stored amounts, with exactly two digits after the decimal point.

The command words are lowercase.
