Write a Python program in a single file named `expenses.py`. The program reads commands from standard input, one command per line, until end of input. Each input line is one of:

- `add <amount> <category>`: append an expense entry. `<amount>` is a decimal number such as `12.50`. `<category>` is a word containing no space characters. The line contains exactly these three tokens separated by spaces. `add` prints no output.
- `list`: print every stored expense entry in the order it was added, one per line, as `<amount> <category>`, where `<amount>` is formatted with exactly two digits after the decimal point.
- `total`: print the sum of all stored amounts, formatted with exactly two digits after the decimal point.

The command words `add`, `list`, and `total` are lowercase.

On startup, before reading commands, load all expense entries from a file named `expenses.state` in the current working directory. If that file does not exist, start with no expense entries. After each `add` command, write all expense entries to `expenses.state`. The file format is determined by your implementation; it only needs to be readable by this same program on a later run.

Example invocation:

$ printf 'add 12.50 food\nadd 3.00 transport\nlist\ntotal\n' | python expenses.py
12.50 food
3.00 transport
15.50

A later invocation:

$ printf 'list\n' | python expenses.py
12.50 food
3.00 transport
