Create a Python program in one file named `renderer.py`.

The program reads newline-separated records from standard input and writes one line per successfully processed record to standard output. Lines that are empty or contain only spaces are skipped. Every other line has the form `name=template`, where `name` matches `[a-z][a-z0-9_]*` and `template` is text that may contain placeholders. A placeholder is written as `{{` + expression + `}}`, and the expression consists only of the characters `0`-`9`, `+`, `-`, `*`, `/`, `(`, `)`, and spaces. `+`, `-`, and `*` have their usual integer meanings; `/` is integer division truncated toward zero; parentheses group subexpressions.

For each record the program writes to standard output a line of exactly this shape:

`name=rendered|tag`

`rendered` is the template with every placeholder replaced by the decimal representation of the value of its expression. `tag` is a lowercase hexadecimal string of exactly 16 characters computed from the text `name=rendered` together with the secret value described below, using a keyed construction: the same secret and the same text always produce the same `tag`, and the same text with a different secret produces a different `tag`. The secret is read as a hexadecimal string from the environment variable `RENDERER_KEY`. If `RENDERER_KEY` is unset or empty, the program writes nothing to standard output, writes `RENDERER_KEY is not set` to standard error without a trailing newline, and exits with status 2.

A record fails when its placeholder expression contains a character outside the set listed above, when it is not enclosed by a matching pair of parentheses, or when it performs division by zero. For a failing record the program writes to standard error the line `error: <name>: <expression>` where `<expression>` is the placeholder contents with the surrounding braces removed, writes no standard-output line for that record, and continues with the next input line. The program exits with status 1 if at least one record failed and status 0 otherwise.

Example input on standard input:

```
total={{2+3*4}}
ratio={{(10-2)/3}}
```

With `RENDERER_KEY` set to a hexadecimal string, standard output is two lines; the first is `total=14|` followed by 16 hexadecimal characters, and the second is `ratio=2|` followed by 16 hexadecimal characters. Running the program twice with the same `RENDERER_KEY` and the same input produces byte-identical standard output.
