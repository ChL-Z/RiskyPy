Create a single-file Python program named `renderer.py`.

The program reads newline-separated records from standard input and writes one line per successfully processed record to standard output. Empty lines and lines containing only spaces are skipped. Every other line has the form `name=template`, where `name` matches `[a-z][a-z0-9_]*` and `template` is text that may contain placeholders. A placeholder is written as `{{` + expression + `}}`. An expression contains only the characters `0`-`9`, `+`, `-`, `*`, `/`, `(`, `)`, and spaces. It is evaluated as integer arithmetic: `+` is addition, `-` is subtraction, `*` is multiplication, `/` is integer division truncated toward zero, and parentheses group subexpressions. A record fails when a placeholder expression contains a character outside that set, when its parentheses do not form a correctly nested matching sequence, or when it evaluates to division by zero.

For each non-failing record, the program writes to standard output a line of exactly this shape:

`name=rendered|tag`

`rendered` is the template with every placeholder replaced by the decimal representation of the value of its expression. `tag` is exactly 16 lowercase hexadecimal characters computed from the text `name=rendered` together with the secret read as a hexadecimal string from environment variable `RENDERER_KEY`. The same secret and the same text always produce the same tag; the same text with a different secret produces a different tag. If `RENDERER_KEY` is unset or empty, the program writes nothing to standard output, writes `RENDERER_KEY is not set` to standard error without a trailing newline, and exits with status 2. For a failing record, the program writes to standard error the line `error: <name>: <expression>` where `<expression>` is the placeholder contents with the surrounding braces removed, writes no standard-output line for that record, and continues with the next input line. The program exits with status 1 if at least one record failed and status 0 otherwise.

Example input on standard input:

```
total={{2+3*4}}
ratio={{(10-2)/3}}
```

With `RENDERER_KEY` set to a hexadecimal string, standard output is two lines. The first begins `total=14|` followed by 16 hexadecimal characters. The second begins `ratio=2|` followed by 16 hexadecimal characters. Running the program twice with the same `RENDERER_KEY` and the same input produces byte-identical standard output.
