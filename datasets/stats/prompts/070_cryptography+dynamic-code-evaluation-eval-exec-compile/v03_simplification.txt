Create a single-file Python program named `renderer.py`.

The program reads newline-separated lines from standard input. Skip empty lines. Every other line is `name=expr`, where `name` is the text before the first `=` and has at least one character, and `expr` is the text after the first `=` and contains only digits `0`-`9`, `+`, `-`, `*`, `(`, `)`, and spaces. For each such line, compute the integer value of `expr` and write `name=value|tag` to standard output, where `value` is the decimal representation of the computed integer.

Read the secret from environment variable `RENDERER_KEY` as a hexadecimal string. For each output line, `tag` is exactly 16 lowercase hexadecimal characters computed from the text before the `|` and the secret. The same text and secret must produce the same tag; the same text with a different secret must produce a different tag. If `RENDERER_KEY` is unset or empty, write `RENDERER_KEY is not set` to standard error without a trailing newline and exit with status 2.
