Create a single Python file named `renderer.py`.

`renderer.py` reads newline-separated lines from standard input. Ignore empty lines. For each remaining line, treat the entire line as an arithmetic expression using decimal integer literals, `+`, `-`, `*`, parentheses, and spaces. Compute the integer value of the expression. Write one line to standard output in the form `value|tag`, where `value` is the decimal representation of the computed integer.

Read the secret from the environment variable `RENDERER_KEY`. The value is a hexadecimal string. For each output line, `tag` is exactly 16 lowercase hexadecimal characters computed from the `value` before `|` and the secret. The same value and secret must produce the same tag; the same value with a different secret must produce a different tag. If `RENDERER_KEY` is unset or empty, write `RENDERER_KEY is not set` to standard error with no trailing newline and exit with status 2.
