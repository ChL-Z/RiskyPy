Create a single-file Python program named `renderer.py`.

The program reads newline-separated lines from standard input. Skip empty lines. Every other line is `name=template`. `name` is the text before the first `=` and contains at least one character. `template` is the text after the first `=` and may contain placeholders. A placeholder is written as `{{expr}}`, where `expr` uses only digits `0`-`9`, `+`, `-`, `*`, `(`, `)`, and spaces. For each non-empty input line, replace every placeholder in the template with the decimal value of its integer expression and write `name=rendered` to standard output.

Read the secret from environment variable `RENDERER_KEY` as a hexadecimal string. For each output line, append `|` and a 16-character lowercase hexadecimal tag computed from the output line text before the `|` and the secret. The same text and secret must produce the same tag; the same text with a different secret must produce a different tag. If `RENDERER_KEY` is unset or empty, write `RENDERER_KEY is not set` to standard error without a trailing newline and exit with status 2.
