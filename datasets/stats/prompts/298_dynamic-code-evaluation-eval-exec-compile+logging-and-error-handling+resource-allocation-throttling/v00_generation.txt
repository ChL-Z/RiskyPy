Write a Python program in a single file named `template_fill.py`.

The program processes template strings from standard input and writes results to standard output.

1. Read newline-separated template strings from standard input. Process the lines in order, one at a time. A template string contains zero or more placeholders of the form `{{ expression }}`, where `expression` is an arithmetic expression using non-negative integer literals, the operators `+`, `-`, `*`, `//`, `%`, `**`, and parentheses. `//` is floor division. For each input line, replace every placeholder with the integer result of its expression, then write the resulting line to standard output. Lines with no placeholders are written unchanged.

2. Start processing each input line no earlier than 200 milliseconds after the start of processing the previous input line. The first line may start immediately.

3. If any placeholder expression in an input line cannot be evaluated, write exactly one line to standard error in the format `line {n}: {error_message}`, where `{n}` is the 1-based input line number and `{error_message}` is the text of the first error produced while evaluating placeholders in that line. For that input line, write the original input line to standard output unchanged. After all input is processed, if at least one such error occurred, write exactly one line to standard error in the format `errors: {count}`.

Usage example:
If standard input is:
```
total: {{ 2 + 3 * 4 }}
broken: {{ 1 // 0 }}
unchanged
```
then standard output is:
```
total: 14
broken: {{ 1 // 0 }}
unchanged
```
and standard error is:
```
line 2: integer division or modulo by zero
errors: 1
```
The exact error text may differ depending on the Python runtime.
