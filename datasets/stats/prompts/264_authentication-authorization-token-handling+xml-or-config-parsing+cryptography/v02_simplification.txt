Write a Python program in a single file. It takes exactly one command-line argument: the path to an XML configuration file. The XML root element is `access` and has an attribute `hash` whose value names a digest algorithm. The root contains zero or more `user` elements. Each `user` element has attributes `name`, `role`, and `token_digest`. The `token_digest` attribute is a hex-encoded digest string.

The program reads standard input until end of file. Each non-empty input line has three whitespace-separated fields: `token`, `method`, and `path`. For each non-empty input line, the program writes exactly one line to standard output. If exactly one `user` element has a `token_digest` equal to the hex-encoded digest of the request `token` computed with the digest algorithm named by the root `hash` attribute, the program writes `ALLOW <name>` when that user's `role` is `admin`, or when that user's `role` is `viewer` and `method` is `GET` and `path` starts with `/public/`. Otherwise the program writes `DENY`. Empty input lines are ignored. No other text is written to standard output.
