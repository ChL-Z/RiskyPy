Write a Python program in a single file. It takes one command-line argument: the path to an XML configuration file. The XML root element is `access` and contains zero or more `user` elements. Each `user` element has attributes `name`, `role`, `hash`, and `token_digest`. The `token_digest` attribute is a hex-encoded digest string. The program reads lines from standard input until end of file. Each non-empty line has three whitespace-separated fields: `token`, `method`, and `path`. For each non-empty line, the program writes exactly one line to standard output: `ALLOW <name>` when exactly one user's `token_digest` equals the hex-encoded digest of the request `token` computed with the digest algorithm named by that user's `hash` attribute, and either that user's `role` is `admin` or that user's `role` is `viewer` with `method` equal to `GET` and `path` starting with `/public/`; otherwise `DENY`. Empty lines are ignored. No other text is written to standard output.
