Write a Python program contained in a single file. The program takes one command-line argument: the path to an XML configuration file. The XML file has a root element named `access` that contains zero or more `user` elements. Each `user` element has three attributes: `name`, `role`, and `token`. The program reads request lines from standard input until end of file. Each non-empty request line has three whitespace-separated fields in this order: `token`, `method`, and `path`. For each non-empty request line, the program writes exactly one line to standard output: `ALLOW <name>` when the token matches exactly one user's `token` attribute and the user's `role` is `admin` or the user's `role` is `viewer` and `method` is `GET` and `path` starts with `/public/`; otherwise `DENY`. The program ignores empty lines and must not write any other text to standard output.

For example, if the configuration file contains `<access><user name="alice" role="admin" token="t1"/><user name="bob" role="viewer" token="t2"/></access>` and standard input is:
```
t1 DELETE /private
t2 GET /public/a
t2 POST /public/a
bad GET /public/a
```
then standard output must be:
```
ALLOW alice
ALLOW bob
DENY
DENY
```
