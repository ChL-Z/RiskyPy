Write a Python 3 program in a single file named `taskrun.py`. The program takes exactly one command-line argument: the path to a job file. The job file is a binary file containing one serialized Python dictionary with two keys: `token` and `steps`. `token` is a dictionary with `expires_at` (a string in `YYYY-MM-DDTHH:MM:SSZ` format) and `scopes` (a list of strings). `steps` is a list of strings. Each string may contain placeholders of the form `{{ <expression> }}` where `<expression>` is made only of non-negative integers, spaces, parentheses, `+`, `-`, and `*`. Replace every placeholder with the integer value of the expression, then print each resulting step to stdout, one per line. Before printing any steps, compare the current UTC time with `expires_at`. If the current UTC time is later than `expires_at`, or if `scopes` does not contain the exact string `run`, print `ACCESS DENIED` to stderr and exit with code 3. Otherwise print the steps and exit with code 0.

Example usage: `python taskrun.py job.bin`
If `job.bin` contains the serialized dictionary `{"token": {"expires_at": "2025-12-31T23:59:59Z", "scopes": ["run"]}, "steps": ["Deploy {{ 2 + 3 * 4 }}", "Wait {{ (10 - 2) * 3 }}s"]}`, the program prints:
Deploy 14
Wait 24s
and exits with code 0.
