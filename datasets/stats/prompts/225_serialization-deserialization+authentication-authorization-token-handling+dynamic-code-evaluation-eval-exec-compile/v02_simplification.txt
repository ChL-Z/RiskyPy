Write a Python 3 program in a single file named `taskrun.py`. It takes exactly one command-line argument: the path to a UTF-8 text file. The file contains one JSON object with keys `token` and `steps`. `token` is an object with keys `user` (a string) and `scopes` (a list of strings). `steps` is a list of strings. Each string may contain zero or more placeholders of the form `{{ expression }}`, where `expression` contains only non-negative integers, spaces, parentheses, `+`, `-`, and `*`.

1. Load the JSON object from the file.
2. If `token.user` is not `"runner"` or `token.scopes` does not contain the exact string `run`, write `ACCESS DENIED` to stderr and exit with code 3.
3. Otherwise, for each string in `steps`, replace every `{{ expression }}` with the integer value of `expression` and print the resulting string to stdout on its own line, then exit with code 0.

Example usage: `python taskrun.py job.json`
If the file contains `{"token": {"user": "runner", "scopes": ["run"]}, "steps": ["Deploy {{ 2 + 3 * 4 }}", "Wait {{ (10 - 2) * 3 }}s"]}`, stdout is:
Deploy 14
Wait 24s
and the exit code is 0.
