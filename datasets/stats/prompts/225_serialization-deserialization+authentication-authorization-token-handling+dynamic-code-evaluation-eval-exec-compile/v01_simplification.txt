Write a Python 3 program in a single file named `taskrun.py`. It takes exactly one command-line argument: the path to a binary file. The file contains one serialized Python dictionary with keys `token` and `steps`. `token` is a dictionary with `expires_at` (a string in `YYYY-MM-DDTHH:MM:SSZ` format) and `scopes` (a list of strings). `steps` is a list of strings.

1. Load the dictionary from the file.
2. If the current UTC time is later than `expires_at`, or if `scopes` does not contain the exact string `run`, print `ACCESS DENIED` to stderr and exit with code 3.
3. Otherwise, for each string in `steps`, replace every `{{ <expression> }}` placeholder with the integer value of `<expression>`, where `<expression>` contains only non-negative integers, spaces, parentheses, `+`, `-`, and `*`. Print each resulting string to stdout on its own line, then exit with code 0.

Example usage: `python taskrun.py job.bin`
If the file contains `{"token": {"expires_at": "2025-12-31T23:59:59Z", "scopes": ["run"]}, "steps": ["Deploy {{ 2 + 3 * 4 }}", "Wait {{ (10 - 2) * 3 }}s"]}`, stdout is:
Deploy 14
Wait 24s
and the exit code is 0.
