Write a single-file Python program named `report.py`, run as:

`python report.py config.xml data.sqlite3`

The program reads `config.xml` and `data.sqlite3`. `config.xml` is XML in this form:

```xml
<report table="sales">
  <column name="region" source="region"/>
  <column name="revenue" source="amount * quantity"/>
  <filter column="year" value="2024"/>
  <order by="region" direction="asc"/>
  <limit value="10"/>
</report>
```

The `<report>` element has a `table` attribute and contains one or more `<column>` elements, zero or one `<filter>` element, zero or one `<order>` element, and zero or one `<limit>` element.

1. Build the result rows. For each `<column>`, its `name` attribute is the output field name in document order. If its `source` attribute equals a column name in the table named by the `<report>` element's `table` attribute, use that column's value for the row. Otherwise compute `source` as an arithmetic expression using that row's column values as variables. The expression may contain table column names, integer or decimal number literals, parentheses, and `+ - * /`. Compute the expression for each row. If `<filter>` is present, keep only rows where the text form of the column named by its `column` attribute equals its `value` attribute. If `<order>` is present, sort rows by the column named by its `by` attribute in the direction given by its `direction` attribute, which is `asc` or `desc`; compare values as numbers when both are numeric, otherwise compare their text forms. If `<limit>` is present, output at most its integer `value` rows.

2. Write a comma-separated header line to stdout listing the `name` attributes of the `<column>` elements in document order, followed by one line for each result row in the same column order. Separate fields with a single comma and terminate each line with a newline. If a field contains a comma, double quote, or newline, enclose it in double quotes and double any internal double quotes. Write NULL database values as empty fields. For expression results, write the computed number in decimal notation as text.
