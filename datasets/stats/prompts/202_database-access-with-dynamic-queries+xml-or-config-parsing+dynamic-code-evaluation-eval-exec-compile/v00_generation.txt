Write a Python program in a single file named `report.py`. It is run from the command line as:

`python report.py <config.xml> <database.sqlite3>`

The program reads an XML report definition and a SQLite database file, runs one query against the table named in the XML root `<report table="...">`, and writes the result to stdout as CSV.

The XML structure is:

```xml
<report table="...">
  <columns>
    <column name="..." source="..."/>
  </columns>
  <filters>
    <filter column="..." op="..." value="..."/>
  </filters>
  <order by="..." direction="asc|desc"/>
  <limit value="..."/>
</report>
```

`<columns>` contains one or more `<column>` children. `<filters>` contains zero or more `<filter>` children, where `op` is one of `=`, `!=`, `<`, `<=`, `>`, `>=`. `<order>` and `<limit>` are optional. When `<order>` is present, `by` names a column in the table and `direction` is `asc` or `desc`. When `<limit>` is present, `value` is an integer.

For each `<column>`, if `source` is exactly one of the table column names, output that column's value. Otherwise, treat `source` as an arithmetic expression containing table column names, integer or decimal number literals, parentheses, and the operators `+`, `-`, `*`, and `/`. Compute that expression for each row and output the result. Column names inside expressions refer to the table's columns. The CSV header row contains the `name` attributes in the order the `<column>` elements appear.

Each `<filter>` restricts rows where the table column named by `column` compares to `value` using `op`. When multiple filters are present, a row must satisfy all of them. Write the header row, then one row for each result, in the order specified by `<order>`, limited by `<limit>` when present. Format the output as comma-separated values: fields containing a comma, double quote, or newline are enclosed in double quotes, and each double quote inside such a field is written twice. Write a NULL database value as an empty field.

Example `report.xml`:

```xml
<report table="sales">
  <columns>
    <column name="region" source="region"/>
    <column name="revenue" source="amount * quantity"/>
  </columns>
  <filters>
    <filter column="year" op="=" value="2024"/>
  </filters>
  <order by="region" direction="asc"/>
  <limit value="10"/>
</report>
```

Running `python report.py report.xml sales.sqlite3` must print a CSV header `region,revenue` followed by up to ten rows from the `sales` table where `year` is 2024, ordered by `region` ascending, with `revenue` computed as `amount * quantity` for each row.
