Write a single Python file `report.py` that is run as:

`python report.py config.xml data.sqlite3`

`config.xml` has this form:

```xml
<report table="sales">
  <column name="region" source="region"/>
  <column name="revenue" source="amount * quantity"/>
</report>
```

The `<report>` element has one `table` attribute and one or more `<column>` elements. Each `<column>` has `name` and `source` attributes.

Implement this behavior:

1. Parse `config.xml`. Read the `table` attribute and the `<column>` elements in document order. For each column element, record its `name` and `source` attributes.

2. Read all rows from the table named by the `table` attribute in the SQLite database `data.sqlite3`. For each database row and each column element in order, determine the output value:
   - If `source` equals a column name in the current row, use that row's value.
   - Otherwise, compute the value of `source` as an arithmetic expression that uses the current row's column names as variables. The expression contains only column names, integer or decimal number literals, parentheses, and the operators `+`, `-`, `*`, `/`.

3. Write to stdout as comma-separated records. The first line is the `name` attributes of the `<column>` elements in document order. Each following line contains the output values for one database row in the same column order. Write NULL database values as empty fields. Write computed numbers in decimal notation. If a field contains a comma, double quote, or newline, enclose the field in double quotes and double each internal double quote. Print nothing else to stdout.
