Write a single Python file `report.py`, run as:

`python report.py config.xml data.sqlite3`

`config.xml` has this form:

```xml
<report table="sales">
  <column name="region" source="region"/>
  <column name="revenue" source="amount * quantity"/>
  <filter column="year" value="2024"/>
</report>
```

The `<report>` element has a `table` attribute and one or more `<column>` elements. Each `<column>` has `name` and `source` attributes. There is zero or one `<filter>` element with `column` and `value` attributes.

The program must do three things:

1. Parse `config.xml`. For each `<column>`, `name` is the output field name. If `source` is a column name in the table given by the `<report>` element's `table` attribute, use that column's value from the current database row. Otherwise compute `source` as an arithmetic expression using the current row's column values as variables. The expression may contain table column names, integer or decimal number literals, parentheses, and `+ - * /`.

2. Read the SQLite database `data.sqlite3`. If `<filter>` is present, keep only rows where the text value of the column named by its `column` attribute equals its `value` attribute. For each kept row, produce one output row with the values for the `<column>` elements in document order.

3. Write to stdout using the `csv` module. The first line is the `name` attributes of the `<column>` elements in document order. Each following line contains the output values for one kept database row, in the same column order. Write NULL database values as empty fields. Write computed numbers in decimal notation.
