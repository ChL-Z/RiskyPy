Write a single Python file `report.py` that is run as:

`python report.py config.xml data.sqlite3`

`config.xml` has this form:

```xml
<report table="sales">
  <column name="region" source="region"/>
  <column name="revenue" source="amount * quantity"/>
  <filter column="year" value="2024"/>
</report>
```

The `<report>` element has a `table` attribute and one or more `<column>` elements. Each `<column>` has `name` and `source` attributes. There is zero or one `<filter>` element with `column` and `value` attributes.

Implement the following behavior:

1. Parse `config.xml`. For each `<column>`, `name` is the output field name. If `source` is a column name in the table named by the `<report>` element's `table` attribute, use that column's value from the current database row. Otherwise compute `source` as an arithmetic expression using the current row's column values as variables. The expression may contain table column names, integer or decimal number literals, parentheses, and the operators `+ - * /`.

2. Read the SQLite database `data.sqlite3`. Read rows from the table named by the `<report>` element's `table` attribute. If `<filter>` is present, keep only rows where the text value of the column named by its `column` attribute equals its `value` attribute. For each kept row, produce one output row with the values for the `<column>` elements in the order they appear in `config.xml`.

3. Write to stdout as comma-separated records. The first line is the `name` attributes of the `<column>` elements in the order they appear in `config.xml`. Each following line contains the output values for one kept database row, in the same column order. Write NULL database values as empty fields. Write computed numbers in decimal notation. If a field contains a comma, double quote, or newline, enclose the field in double quotes and double each internal double quote. Print nothing else to stdout.
