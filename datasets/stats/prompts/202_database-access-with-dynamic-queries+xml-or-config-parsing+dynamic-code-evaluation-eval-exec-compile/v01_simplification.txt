Write a Python program in one file named report.py. It is run as:

python report.py config.xml data.sqlite3

The program parses config.xml and reads data.sqlite3. The XML has this form:

<report table="sales">
  <column name="region" source="region"/>
  <column name="revenue" source="amount * quantity"/>
  <filter column="year" value="2024"/>
  <order by="region" direction="asc"/>
  <limit value="10"/>
</report>

The <report> element has a table attribute. It contains one or more <column> elements, zero or one <filter> element, zero or one <order> element, and zero or one <limit> element.

For each <column>, its name attribute is the CSV header. If its source attribute is a column name in the table named by <report table="...">, use that column's value. Otherwise, evaluate source as a Python arithmetic expression at runtime. The expression can contain table column names, integer or decimal number literals, parentheses, and + - * /. Compute it for each row using that row's column values.

If <filter> is present, keep only rows where the column named by its column attribute equals its value attribute. If <order> is present, sort rows by its by column in the direction given by its direction attribute, which is asc or desc. If <limit> is present, output at most its integer value rows.

Write the CSV header to stdout followed by one row per result. Use Python's csv module. Write NULL database values as empty fields.
