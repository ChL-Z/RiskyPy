Write a Python program in a single file named `throttled_runner.py`. It takes two command-line arguments: the path to a configuration JSON file and the path to a jobs JSON file.

The configuration JSON file is an object with one key: `rate_per_second` (a positive number). The jobs JSON file is an array of objects; each object has an `id` (string) and a `command` (string). For example, the configuration file could contain `{"rate_per_second": 0.5}` and the jobs file could contain `[{"id": "a", "command": "echo a"}, {"id": "b", "command": "echo b"}, {"id": "c", "command": "echo c"}]`.

The program must process the jobs in the order they appear in the jobs file. Before starting each job's command line, it must ensure that no two command line starts occur less than `1 / rate_per_second` seconds apart. For each job, after its command line finishes, print one JSON object followed by a newline to stdout. Each JSON object must contain exactly the keys `id`, `exit_code`, and `started_at`. `id` is the job's id string. `exit_code` is the integer exit code of the command line, or 127 if the command line could not be started. `started_at` is the number of seconds since the program started when the command line was started, rounded to 3 decimal places.

Run `python throttled_runner.py config.json jobs.json` from a directory containing those two files. For `rate_per_second` equal to 0.5, the program waits at least 2 seconds between starting each job.
