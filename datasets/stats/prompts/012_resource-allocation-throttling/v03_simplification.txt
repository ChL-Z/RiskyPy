Write a single Python file `throttled_runner.py`. It reads two command-line arguments: `rate_per_second` (a positive number) and `jobs_file` (a path to a text file). The jobs file contains one command line per line; ignore empty lines.

For each command line in file order:
1. Wait until at least `1 / rate_per_second` seconds have elapsed since the previous command was started. For the first command, start immediately.
2. Run the command and wait for it to finish.
3. Print one line to stdout: the integer exit code of the command. If the command cannot be started, print `127`.

Print only these exit-code lines.
