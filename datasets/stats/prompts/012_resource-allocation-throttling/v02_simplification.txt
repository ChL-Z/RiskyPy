Write a single Python file `throttled_runner.py`. It reads two command-line arguments: the path to a config JSON file and the path to a jobs JSON file. The config file is a JSON object with key `rate_per_second`, a positive number. The jobs file is a JSON array of objects, each with `id` (string) and `command` (string).

Process the jobs in file order. For each job, wait until at least `1 / rate_per_second` seconds have passed since the previous job's command was started, then start that job's `command`. After the command finishes, print one line to stdout with the job's `id`, a single space, and the command's integer exit code. If the command cannot be started, print exit code `127`. Print only these lines.
