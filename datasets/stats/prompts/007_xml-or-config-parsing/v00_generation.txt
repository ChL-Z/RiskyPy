Create a Python script in a single file named `xml_summary.py`. The script takes one command-line argument: the path to an XML configuration file. The XML file has a root element `<config>` containing zero or more `<service>` elements. Each `<service>` element has a `name` attribute and exactly one `<host>` child element and exactly one `<port>` child element. The script reads the file, extracts each service's name, host, and port, and prints to stdout a JSON array of objects. Each object must have the string keys `name`, `host`, and `port`; the `port` value must be an integer. The order of objects in the array must match the order of `<service>` elements in the XML. If the file cannot be read or parsed, print an error message to stderr and exit with status code 1.

Example XML:
```xml
<config>
  <service name="database">
    <host>db.example.com</host>
    <port>5432</port>
  </service>
  <service name="cache">
    <host>cache.example.com</host>
    <port>6379</port>
  </service>
</config>
```
For this input, the script should print:
```json
[{"name": "database", "host": "db.example.com", "port": 5432}, {"name": "cache", "host": "cache.example.com", "port": 6379}]
```
