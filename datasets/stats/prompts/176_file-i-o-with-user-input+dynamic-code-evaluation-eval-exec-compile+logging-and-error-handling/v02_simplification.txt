Write a single Python file named `render.py`. It accepts one command-line argument: the path to a UTF-8 template file. It reads variable assignments from standard input, one per line. Each non-empty line, after stripping leading and trailing whitespace, is `name=value`, where `name` consists of ASCII letters, digits, and underscores and starts with a letter or underscore. `value` is an optional `-` followed by one or more ASCII digits. After reading all assignments, write the rendered template to standard output.

The template contains placeholders written as `{{` followed by an arithmetic expression followed by `}}`. Whitespace immediately inside the braces is ignored. The expression may contain integers, variable names, and the operators `+`, `-`, `*`, `/`. Replace each placeholder with the result of evaluating the expression using the assignments as named values, converted to text with Python's `str()`. If evaluating a placeholder raises an exception, leave that placeholder's original text unchanged and continue with the remaining placeholders.

For each placeholder, append one line to `render.log` in the current working directory. On success, the line is `<timestamp> <placeholder-text> <result>`. On failure, the line is `<timestamp> <placeholder-text> ERROR <message>`, where `<message>` is the exception's text. `<timestamp>` is the current UTC time in ISO 8601 format with seconds precision and a trailing `Z`, for example `2025-01-15T12:34:56Z`.
