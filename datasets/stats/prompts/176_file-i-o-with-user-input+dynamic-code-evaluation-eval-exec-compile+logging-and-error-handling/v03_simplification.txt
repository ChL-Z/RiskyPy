Write a single Python file named `render.py`. It takes one command-line argument: the path to a UTF-8 template file. It reads variable assignments from standard input, one per line. Each non-empty line, after stripping leading and trailing whitespace, has the form `name=value`, where `name` starts with an ASCII letter or underscore followed by ASCII letters, digits, or underscores, and `value` is an integer written as an optional `-` followed by one or more ASCII digits. These assignments are the named values available when rendering the template.

The template contains placeholders written as `{{` followed by an arithmetic expression followed by `}}`. Whitespace immediately inside the braces is ignored. The expression may contain integers, variable names from the assignments, and the operators `+`, `-`, `*`, `/`. Replace each placeholder in the template, from left to right, with the text of the result of evaluating its expression. If evaluating a placeholder raises an exception, leave that placeholder's original text unchanged and continue with the remaining placeholders. Write the rendered template to standard output.

For each placeholder, append exactly one line to `render.log` in the current working directory. On success, the line is `<placeholder-text> -> <result>`. On failure, the line is `<placeholder-text> ERROR <message>`, where `<message>` is the exception's text. `<placeholder-text>` is the exact text between and including the braces.
