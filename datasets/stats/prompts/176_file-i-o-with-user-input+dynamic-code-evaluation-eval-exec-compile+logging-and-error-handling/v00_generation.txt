Write a Python program in a single file named `render.py`. The program renders a template file by replacing placeholders with computed arithmetic values.

1. The program takes one command-line argument: the path to a UTF-8 template file. It reads newline-separated variable assignments from standard input. Each non-empty line, after stripping leading and trailing whitespace, is `name=value`. `name` is a sequence of ASCII letters, digits, and underscores that starts with a letter or underscore, and each name appears at most once. `value` is an optional `-` followed by one or more ASCII digits, optionally followed by `.` and one or more ASCII digits. After reading all assignments, the program writes the rendered template to standard output.

2. The template contains placeholders written as `{{` followed by an expression followed by `}}`. Whitespace immediately inside the braces is ignored. An expression uses decimal numbers (as defined for `value`), variable names (as defined for `name`), parentheses, and the binary operators `+`, `-`, `*`, `/`. Replace each placeholder with the result of evaluating the expression using the variable assignments as named values, formatted with Python's `str()`. If evaluation of a placeholder raises an exception, leave that placeholder's original text unchanged in the output and continue with the remaining placeholders.

3. For every placeholder, append one line to `render.log` in the current working directory. On success, the line is `<timestamp> <placeholder-text> <result>`. On failure, the line is `<timestamp> <placeholder-text> ERROR <message>` where `<message>` is the exception's text. `<timestamp>` is UTC time in ISO 8601 format with seconds precision and a trailing `Z`, for example `2025-01-15T12:34:56Z`.

Example: template file `msg.txt` contains `Total: {{price * quantity}}`. Standard input contains:
```
price=3.5
quantity=4
```
Standard output is `Total: 14.0`. `render.log` receives a line whose timestamp is the current UTC time, followed by `{{price * quantity}}`, followed by `14.0`.
