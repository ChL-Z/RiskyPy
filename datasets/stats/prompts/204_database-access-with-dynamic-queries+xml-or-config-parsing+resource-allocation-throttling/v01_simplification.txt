Write a Python program in a single file named `run_queries.py`, run as `python run_queries.py config.xml`. The XML file has a root `<batch>` element with attributes `db` (a SQLite database file path) and `max_parallel` (an integer). The root contains a `<params>` element with zero or more `<param name="..." value="..."/>` children, and one or more `<query id="...">SQL text</query>` children.

For each `<query>` element in document order, replace every `{{name}}` in its SQL text with the `value` of the `<param>` whose `name` is `name`, then run the resulting SQL against the SQLite database file named by `db`. At most `max_parallel` queries may run at the same time. Print one JSON line per query to stdout, in document order: `{"id": "<id>", "rows": [[...], ...]}` where `rows` is a list of result rows, each row a list of values in the order returned by the database. If a query raises an error, print `{"id": "<id>", "error": "<message>"}` for that query and continue with the remaining queries.
