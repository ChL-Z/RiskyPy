Write a single-file Python program `run_queries.py` invoked as `python run_queries.py config.xml`.

The XML file has a root `<batch>` element with attributes `db` and `max_parallel`. `db` is the path to a SQLite database file. `max_parallel` is an integer. The root contains one or more `<query id="...">SQL text</query>` children. For every `<query>` element in document order, execute its SQL text against the SQLite database at `db`. Run at most `max_parallel` queries at the same time. After a query fails, continue with the remaining queries.

Print one JSON line to stdout per query, in the same order as the `<query>` elements in the XML document. On success, print `{"id": "<id>", "rows": [[...], ...]}` where `rows` is the list of result rows and each row is a list of column values in the order the database returned them. On failure, print `{"id": "<id>", "error": "<message>"}` where `<message>` is the exception's message string.
