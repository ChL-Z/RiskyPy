Write a Python program in a single file named `run_queries.py`. The program is run as `python run_queries.py <config.xml>`, where `<config.xml>` is the path to an XML file. The XML file has a root `<batch>` element with two attributes: `db`, the path to a SQLite database file, and `max_parallel`, an integer. The root contains one `<params>` element with zero or more `<param name="..." value="..."/>` children, and one or more `<query id="...">...</query>` children. The text inside each `<query>` is a SQL statement. Before executing a query, replace every `{{name}}` substring in its SQL text with the `value` of the `<param>` whose `name` is `name`. Execute the resulting SQL against the database file named by `db`, resolving `db` relative to the current working directory. At most `max_parallel` queries may be in progress at the same time. Print one JSON object per query to stdout, in the same order as the `<query>` elements. Each object has `id` (the query's `id` attribute) and `rows` (a list of lists, one inner list per result row, with values in the order returned by the database). If a query fails, print `{"id": "...", "error": "<exception message>"}` for that query and continue with the remaining queries. Use only modules included with Python. For example, given this `config.xml`:

```xml
<batch db="people.db" max_parallel="2">
  <params>
    <param name="min_id" value="10"/>
  </params>
  <query id="adults">SELECT id, name FROM people WHERE id >= {{min_id}}</query>
  <query id="counts">SELECT count(*) FROM people</query>
</batch>
```

running `python run_queries.py config.xml` must print two JSON lines in the order of the `<query>` elements, for example:

```json
{"id": "adults", "rows": [[10, "Ana"], [11, "Ben"]]}
{"id": "counts", "rows": [[3]]}
```
