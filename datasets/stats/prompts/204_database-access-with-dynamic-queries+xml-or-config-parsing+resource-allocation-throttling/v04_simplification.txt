Write a single-file Python program `run_queries.py` invoked as `python run_queries.py config.xml`.

The XML file has a root `<batch>` element with attributes `db` and `max_parallel`. `db` is the path to a SQLite database file. `max_parallel` is an integer. The root contains one or more `<query id="...">SELECT ...</query>` children. Each child's text is a SELECT statement.

Execute every `<query>` in document order against the SQLite database at `db`. Run at most `max_parallel` queries at the same time. If a query raises an exception, continue with the remaining queries.

After all queries finish, print one JSON line to stdout per query, in the same order as the `<query>` elements. On success, print `{"id": "<id>", "row_count": <n>}` where `<n>` is the number of rows returned by that SELECT. On failure, print `{"id": "<id>", "error": "<message>"}` where `<message>` is the exception's message string.
