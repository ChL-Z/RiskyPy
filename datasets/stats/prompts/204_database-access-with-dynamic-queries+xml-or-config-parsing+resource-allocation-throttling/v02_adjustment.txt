Write a single-file Python program `run_queries.py` invoked as `python run_queries.py config.xml`.

The XML file has a root `<batch>` element with attributes `db` (a path to a SQLite database file) and `max_parallel` (an integer). The root contains one `<params>` element with zero or more `<param name="..." value="..."/>` children, and one or more `<query id="...">SQL text</query>` children. Each query's SQL text may contain `{{name}}` placeholders; for each placeholder `{{name}}`, the value to use for that placeholder in the query execution is the `value` attribute of the `<param>` element whose `name` attribute equals `name`.

For every `<query>` element in document order, execute its SQL against the SQLite database at `db` with the placeholder-to-param mapping above, at most `max_parallel` queries running at the same time. Print one JSON line to stdout per query, in document order, with this exact shape:

- On success: `{"id": "<id>", "rows": [[...], ...]}` where `rows` is a list of result rows and each row is a list of column values in the order the database returned them.
- On error: `{"id": "<id>", "error": "<message>"}` where `<message>` is the exception's message string. After an error, continue with the remaining queries.

Output lines must appear in the same order as the `<query>` elements in the XML document, regardless of the order in which concurrent executions finish.
