Write a Python program in one file named `profile_cli.py`. The program has one command-line entry point and takes no arguments. When run, it must do the following:

1. Read the access token from `~/.config/profilecli/token.json`. That file contains a JSON object with the key `access_token` whose value is a string.

2. If `profile_cache.bin` exists in the current working directory and its modification time is less than 600 seconds before the current time, read the profile mapping from `profile_cache.bin` and use it as the profile. Otherwise, send an HTTP GET request to `https://api.example.com/v1/users/u_1042` with the header `Authorization: Bearer <access_token>`, where `<access_token>` is the string read in step 1. The response body is a JSON object with keys `display_name` and `email`. Convert that JSON object to a Python mapping, write that mapping to `profile_cache.bin` in the current working directory so a later run can read it back, and use it as the profile.

3. Print exactly two lines to stdout:
   `name: <display_name>`
   `email: <email>`
   where `<display_name>` and `<email>` are the values from the profile mapping.

Example: `~/.config/profilecli/token.json` contains `{"access_token": "t_abc123"}`. A request to `https://api.example.com/v1/users/u_1042` returns `{"display_name": "Ada Lovelace", "email": "ada@example.com"}`. Running `python profile_cli.py` prints:
`name: Ada Lovelace`
`email: ada@example.com`
