Create a single Python file named `table_report.py`. Run it as:

`python table_report.py <database_path> <table_name> <filter_json_path>`

The first argument is a SQLite database file path, the second is a table name, and the third is a JSON file path. The JSON file contains an object. Each key is a column name and each value is a string. Select all columns from the named table. Keep rows where every filter key equals the corresponding column value. If the JSON object is empty, keep all rows.

Write `report.json` in the current directory. It is a JSON array. Each element is an object whose keys are the selected column names in the order the database returns them. Each value is the row value converted to a string, with NULL written as an empty string.

Print to stdout exactly one HTML document. It starts with `<!DOCTYPE html>` and contains `<h1>Report: <table_name></h1>` followed by one `<table>`. The first table row has a `<th>` cell for each selected column name in order. Each following table row has a `<td>` cell for each row value in column order, converted to a string with NULL written as an empty string. Do not write any other text to stdout.
