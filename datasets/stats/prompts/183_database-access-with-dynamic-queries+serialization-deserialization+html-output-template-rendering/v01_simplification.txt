Create a single Python file `table_report.py` that reads a SQLite database and prints an HTML report to stdout, and writes a JSON file named `report.json` in the current directory.

Run it as:
python table_report.py <database_path> <table_name> <filter_json_path>

The filter JSON file contains a JSON object. Each key is a column name in the table, and each value is a string. Select every column from the named table. For each key in the filter object, include a condition that the named column equals the given string. All conditions must be true for a row to be selected. If the filter object is empty, select every row. Write `report.json` as a JSON object with two keys: `columns`, a list of the selected column names in the order the database returns them, and `rows`, a list where each element is a list of strings for one database row in column order. Write NULL as an empty string.

Print to stdout an HTML document. It starts with `<!DOCTYPE html>`, then `<h1>Report: <table_name></h1>`, then one `<table>`. The first row has a `<th>` cell for each selected column name, in order. Each following row has a `<td>` cell for each value in the database row, in column order, converted to text with NULL as an empty string. Do not write any other text to stdout.
