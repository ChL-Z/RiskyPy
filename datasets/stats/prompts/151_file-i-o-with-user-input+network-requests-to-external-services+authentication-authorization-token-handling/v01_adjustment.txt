Create a single-file Python program named `note_uploader.py`. It is invoked as `python note_uploader.py <file_path> <title>` and must implement exactly these two requirements:

1. Read `<file_path>` as UTF-8 text to use as the note body. Determine the bearer token as follows: if the environment variable `NOTE_API_TOKEN` is present and its value is not the empty string, use its value as the bearer token; otherwise, read exactly one line from stdin, remove one trailing `\n` if present, and use that line as the bearer token. Send an HTTP POST request to `https://api.notes.example.com/v1/notes` with a JSON request body containing exactly the keys `title` and `body`. `title` is the second command-line argument. `body` is the file content. The request must include the header `Authorization` with the value `Bearer ` followed by the bearer token.

2. When the service responds with HTTP status code 201, print the value of the `url` field from the JSON response body to stdout and exit with status 0. For any other HTTP status code, write the response body to stderr and exit with status 1.
