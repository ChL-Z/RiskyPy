Create a Python program contained in a single file named `note_uploader.py`. The program is invoked as `python note_uploader.py <file_path> <title>`. It reads `<file_path>` as UTF-8 text to form the note body. It sends an HTTP POST request to `https://api.notes.example.com/v1/notes` with a JSON request body containing exactly the keys `title` and `body`, where `title` is the second command-line argument and `body` is the file content. The request includes the header `Authorization` with the value `Bearer <token>`. The token is obtained in this order: the value of the environment variable `NOTE_API_TOKEN` when that variable is set; otherwise the first line of `~/.note_token` when that file exists; otherwise one line read from stdin, which the program writes as the only line of `~/.note_token` before using it. When the service responds with status code 201, the program prints the value of the `url` field from the JSON response body to stdout and exits with status 0. For any other status code, the program prints the response body to stderr and exits with status 1.
