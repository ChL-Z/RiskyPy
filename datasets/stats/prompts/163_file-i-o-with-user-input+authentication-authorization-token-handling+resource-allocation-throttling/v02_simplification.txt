Write a single Python file named `fetch.py`. It is run as `python fetch.py urls.txt`.

1. Read `urls.txt` line by line. For each non-empty line, treat that line as one URL. In the same directory as `urls.txt`, read `tokens.txt`. Each line in `tokens.txt` contains a hostname, one tab character, and a token string.

2. For each URL in order, determine its hostname as the text after `://` and before the next `/`, `:`, or the end of the string. If no line in `tokens.txt` has that hostname, print `DENIED <url>`. Otherwise send one HTTP GET request to the URL with the header `Authorization: Bearer <token>` using the token from the matching line. If a response arrives within 5 seconds, print `<status_code> <url>`. If no response arrives within 5 seconds, print `ERROR <url>`.

3. Start the first HTTP request immediately. Wait 0.7 seconds before starting each later HTTP request. Print each result on its own line.
