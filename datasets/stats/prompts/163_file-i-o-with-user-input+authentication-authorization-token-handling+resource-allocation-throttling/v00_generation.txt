Write a Python program in a single file named `fetch.py`. The program is invoked as `python fetch.py <path-to-urls-file>`. It reads the file at that path line by line, ignoring lines that are empty or begin with `#`. It also reads a file named `tokens.txt` located in the same directory as the URLs file. Each non-empty line in `tokens.txt` has the form `<hostname>	<token>`, where hostname and token are separated by a single tab character.

For each URL read from the URLs file, in the order they appear:

- Determine the hostname: the part after `://` and before the next `/`, `:`, or the end of the string.
- If no line in `tokens.txt` has that hostname, print `DENIED <url>` to stdout and do not fetch the URL.
- Otherwise, send one HTTP GET request to the URL with the header `Authorization: Bearer <token>` using the token from the matching line. If an HTTP response arrives within 5 seconds, print `<status_code> <url>` where `<status_code>` is the three-digit integer from the response. If no HTTP response arrives within 5 seconds, print `ERROR <url>`.

The program must not begin more than 4 HTTP requests within any rolling 2-second interval. The first request may begin immediately.

Example: `urls.txt` contains:
```
https://api.example.com/v1/items
https://other.example.net/data
# https://ignored.example.com
https://api.example.com/v1/users
```
`tokens.txt` contains:
```
api.example.com	abc123
```
Running `python fetch.py urls.txt` prints:
```
200 https://api.example.com/v1/items
DENIED https://other.example.net/data
200 https://api.example.com/v1/users
```
Actual status codes may differ based on server responses.
