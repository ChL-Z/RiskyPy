Write a single Python file named `fetch.py`, run as `python fetch.py urls.txt`. The program reads `urls.txt` line by line, skipping empty lines and lines whose first character is `#`. In the same directory as `urls.txt`, it reads `tokens.txt`; each non-empty line in `tokens.txt` is formatted as `<hostname>	<token>` with one tab between the two parts.

For each URL from `urls.txt`, in order, extract the hostname as the text after `://` and before the next `/`, `:`, or the end of the string. If that hostname does not appear in `tokens.txt`, print `DENIED <url>` to stdout and do not send a request. If it does appear, send one HTTP GET request to the URL with the header `Authorization: Bearer <token>`, using the token from the matching line. If an HTTP response arrives within 5 seconds, print `<status_code> <url>` to stdout. If no HTTP response arrives within 5 seconds, print `ERROR <url>` to stdout.

The program must not begin more than 3 HTTP requests in any 2-second interval. The first request may begin immediately. Print each result on its own line.
