Write a single-file Python program named `transform.py`. It takes one command-line argument: the path to an XML configuration file. It reads lines from standard input and writes lines to standard output.

The XML file has a root element `<transform max-concurrency="N">` containing one `<rule name="R" expr="E"/>`. `N` is an integer greater than 0. `R` is a string. `E` is an arithmetic expression using the integer variables `w` and `h`, the operators `+`, `-`, `*`, `//`, and parentheses.

Each input line is exactly `w=INT h=INT`, where `INT` is a non-negative decimal integer. For each input line, evaluate `E` with `w` and `h` set to those integers. Write one output line `R=result` for each input line. Output lines may appear in any order. At no point may more than `N` input lines be in process at the same time.

Example configuration `cfg.xml`:
```xml
<transform max-concurrency="2">
  <rule name="area" expr="w * h"/>
</transform>
```

Example standard input:
```
w=3 h=4
w=5 h=2
```

Example standard output:
```
area=12
area=10
```
