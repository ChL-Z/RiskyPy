Write `transform.py`, a single-file Python program. It takes one command-line argument: the path to an XML configuration file. It reads lines from standard input and writes lines to standard output.

The XML file has a root element `<transform max-concurrency="N">` containing one child element `<expr>E</expr>`. `N` is a positive integer. `E` is an arithmetic expression using the integer variables `w` and `h`, the operators `+`, `*`, and parentheses.

Each standard input line is exactly `w=INT h=INT`, where `INT` is a non-negative decimal integer. For each input line, evaluate `E` with `w` and `h` set to those integers. Write one line containing only the result to standard output. Output lines may appear in any order. At no time may more than `N` input lines be in process at the same time.
