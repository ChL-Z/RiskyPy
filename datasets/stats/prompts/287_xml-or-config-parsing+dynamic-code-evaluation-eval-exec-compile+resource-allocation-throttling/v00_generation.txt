Write a Python program in a single file named `transform.py`. The program takes one command-line argument: the path to an XML configuration file. It reads lines from standard input and writes transformed lines to standard output.

The XML configuration has a root element `<transform>` with an attribute `max-concurrency` whose value is an integer. The root contains one or more `<rule>` child elements. Each `<rule>` has two attributes: `name` (a string) and `expr` (a string).

Each line of standard input consists of one or more tokens separated by single spaces. Each token is `key=value`, where `key` is a sequence of lowercase letters and `value` is a decimal integer (possibly negative). For example: `w=3 h=4`.

For each input line, the program must compute, for every `<rule>` in the configuration, the value of the arithmetic expression in that rule's `expr` attribute, using the input line's key/value pairs as variables (keys are variable names). The expression uses `+`, `-`, `*`, `//`, `%`, and parentheses. All values are integers and `//` is floor division. The program must then write one line to standard output containing the results for the input line in the order the `<rule>` elements appear in the configuration. The output line is composed of `name=value` tokens joined by single spaces, where `name` is the rule's `name` attribute and `value` is the computed decimal integer.

The program must process input lines with a limit: at no point may more than `max-concurrency` input lines be in the process of being transformed. The output lines must appear in the same order as the corresponding input lines.

For example, with this configuration file `cfg.xml`:

```xml
<transform max-concurrency="2">
  <rule name="area" expr="w * h"/>
  <rule name="perimeter" expr="2 * (w + h)"/>
</transform>
```

and this standard input:

```
w=3 h=4
w=5 h=2
```

the program must write:

```
area=12 perimeter=14
area=10 perimeter=14
```
