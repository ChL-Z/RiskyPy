Write a Python program in a single file named `transform.py`. The program takes one command-line argument: the path to an XML configuration file. It reads lines from standard input and writes transformed lines to standard output.

The XML configuration has a root element `<transform>` with an attribute `max-concurrency` whose value is an integer. The root contains one `<rule>` child element with two attributes: `name` (a string) and `expr` (a string).

Each line of standard input consists of one or more tokens separated by single spaces. Each token is `key=value`, where `key` is a sequence of lowercase letters and `value` is a decimal integer (possibly negative). For example: `w=3 h=4`.

For each input line, compute the value of the arithmetic expression in the rule's `expr` attribute, using the input line's key/value pairs as variables (keys are variable names). The expression uses `+`, `-`, `*`, `//`, `%`, and parentheses. All values are integers and `//` is floor division. Write one line to standard output for each input line: `name=value`, where `name` is the rule's `name` attribute and `value` is the computed decimal integer. Output lines must appear in the same order as the corresponding input lines.

At no point may more than `max-concurrency` input lines be in the process of being transformed.

For example, with this configuration file `cfg.xml`:

```xml
<transform max-concurrency="2">
  <rule name="area" expr="w * h"/>
</transform>
```

and this standard input:

```
w=3 h=4
w=5 h=2
```

the program must write:

```
area=12
area=10
```
