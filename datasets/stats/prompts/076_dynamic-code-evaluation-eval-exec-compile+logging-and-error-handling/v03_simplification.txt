Write a Python program in a single file named `render_templates.py`. Run it as `python render_templates.py TEMPLATE_PATH JSON_PATH`.

1. Read `JSON_PATH` as a JSON object. Its keys are variable names and its values are integers. Read `TEMPLATE_PATH` as text lines; line numbers start at 1.

2. For each template line, replace every `{{ ... }}` placeholder with the integer result of evaluating the arithmetic expression inside the braces. Remove leading and trailing whitespace from the text between `{{` and `}}`. The expression uses integer literals, variable names from the JSON object, operators `+`, `-`, `*`, and parentheses. Replace the placeholder with the result in decimal form. Print the resulting line to stdout. A line with no placeholders is printed unchanged.

3. If any placeholder on a line cannot be replaced, do not print that line to stdout. Append one line to `errors.log` in the current working directory for the first failing placeholder on that line, scanning placeholders from left to right, in the format `Line {line_number}: {original_line} | {message}`. Use the original line text without its trailing newline for `{original_line}`. Use `missing variable {name}` when the expression names a variable not in the JSON object. Use `expression did not evaluate to an integer` when evaluating the expression does not produce an integer. Continue with the remaining template lines.
