Write a Python program in one file named `render_templates.py`. Run it as `python render_templates.py TEMPLATE_PATH JSON_PATH`.

1. Read `JSON_PATH` as a JSON object whose values are integers. Read `TEMPLATE_PATH` as text lines. Line numbers start at 1.

2. For each template line, if it contains at most one `{{ expression }}` placeholder, replace that placeholder with the integer result of evaluating `expression`. The text inside `{{` and `}}` may have leading or trailing whitespace; ignore that whitespace. The expression contains integer literals, variable names from the JSON object, the operators `+`, `-`, `*`, and parentheses. Print the resulting line to stdout. If the line has no placeholder, print it unchanged.

3. If the placeholder cannot be evaluated, do not print that line. Append one line to `errors.log` in the current working directory:
   - `Line {line_number}: missing variable {name}` if the expression names a variable that is not a key in the JSON object.
   - `Line {line_number}: expression did not evaluate to an integer` if evaluation does not produce an integer.
Continue with the remaining template lines.
