Write a Python program in a single file named `render_templates.py`. Run it as `python render_templates.py TEMPLATE_PATH JSON_PATH`.

Read `JSON_PATH` as a JSON object whose keys are variable names and whose values are integers. Read `TEMPLATE_PATH` as text lines, with line numbers starting at 1. For each line, print to stdout the line with every `{{ ... }}` placeholder replaced. For a placeholder, remove leading and trailing whitespace from the text between `{{` and `}}`; the first character is `=`. The text after `=` is an arithmetic expression using integer literals, variable names from the JSON object, operators `+`, `-`, `*`, `//`, `%`, and parentheses. Replace the placeholder with the integer result in decimal form.

If a placeholder cannot be replaced as described, do not print that line to stdout. Append one line to `errors.log` in the current working directory for the first failing placeholder on that line, scanning placeholders from left to right, in the format `Line {line_number}: {original_line} | {message}`. If the expression names a variable not in the JSON object, `{message}` is `missing variable {name}`. If evaluating the expression does not produce an integer, `{message}` is `expression did not evaluate to an integer`. Continue with the remaining template lines after logging.
