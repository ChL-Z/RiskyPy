Write a Python program in a single file named `render_templates.py`. The program reads two command-line arguments: the path to a template file and the path to a JSON file. The JSON file contains an object whose keys are variable names and whose values are integers or strings. Each line in the template file is rendered and printed to stdout.

Placeholders of the form `{{name}}` are replaced by the value of the variable `name` from the JSON object. Placeholders of the form `{{= expression }}` are replaced by the result of evaluating `expression` as an arithmetic expression that uses the variables from the JSON object as integers. For example, with JSON `{"a": 3, "b": 4}` and template line `Sum is {{= a + b }}`, the program prints `Sum is 7`.

If a placeholder refers to a variable that is not in the JSON object, or if the expression cannot be evaluated to an integer, the program appends a line to a file named `errors.log` in the following format: `Line {line_number}: {original_line} | {exception_text}`. The program continues processing the remaining lines.

Example usage:

Given `vars.json` containing `{"x": 10, "y": 2}` and `templates.txt` containing:
```
Value: {{x}}
Quotient: {{= x / y }}
Missing: {{z}}
```
Running `python render_templates.py templates.txt vars.json` prints:
```
Value: 10
Quotient: 5.0
```
and appends to `errors.log` a line beginning with `Line 3: Missing: {{z}} |`.
