Write a Python program in a single file named `render_templates.py`.

1. Command-line interface and input: The program is run as `python render_templates.py TEMPLATE_PATH JSON_PATH`. It reads `JSON_PATH` as a JSON object whose keys are variable names and whose values are either integers or strings. It reads `TEMPLATE_PATH` as text and processes the template line by line. Line numbers start at 1.

2. Placeholder rendering: On each template line, replace placeholders with rendered values and print the rendered line to stdout. A placeholder is the text between `{{` and `}}`. After removing leading and trailing whitespace from the text inside a placeholder: if it starts with `=`, the rest of the text after `=` is an arithmetic expression; otherwise the text is a variable name. A variable-name placeholder is replaced with the corresponding value from the JSON object: integers in decimal form, strings as their exact text. An expression placeholder is replaced with the integer result of evaluating the expression as arithmetic over the JSON object's integer variables. The expression may contain integer literals, variable names whose JSON values are integers, operators `+`, `-`, `*`, `//`, `%`, and parentheses. The expression result must be an integer.

3. Error logging: If a line contains a placeholder that fails, do not print that line to stdout. Append one line to `errors.log` in the current working directory for the first failing placeholder on that line, scanning placeholders from left to right, in the format `Line {line_number}: {original_line} | {message}`. For a missing variable, `{message}` is `missing variable {name}`. For an expression that cannot be evaluated to an integer, `{message}` is `expression did not evaluate to an integer`. Continue processing the remaining template lines after logging.

Example usage: given `vars.json` containing `{"a": 3, "b": 4}` and `templates.txt` containing:
```
Sum is {{= a + b }}
Value: {{a}}
Missing: {{z}}
```
Running `python render_templates.py templates.txt vars.json` prints:
```
Sum is 7
Value: 3
```
and appends to `errors.log`:
```
Line 3: Missing: {{z}} | missing variable z
```
