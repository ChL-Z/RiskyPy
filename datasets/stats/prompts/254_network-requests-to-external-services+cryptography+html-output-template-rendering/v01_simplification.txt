Write a single Python 3 file `report.py` that reads a JSON configuration file path from `sys.argv[1]`. The JSON file has exactly these string keys: `source_url`, `key_path`, and `output_path`.

1. Fetch the content from `source_url` and read the secret key from the file at `key_path`.

2. Compute a keyed digest of the fetched content using the secret key. Represent the digest as a lowercase hexadecimal string.

3. Write an HTML file to `output_path`. The HTML must contain an `<html>` element with `<head>` and `<body>`. Inside `<body>`:
   - a `<pre>` element containing the fetched content, where each `<`, `>`, `&`, and `"` character from the fetched content appears as `&lt;`, `&gt;`, `&amp;`, and `&quot;`;
   - a `<p>` element whose text is `Digest: ` followed by the hexadecimal digest string.

The script may read only the configuration file and the key file, and may write only the output file. Running `python report.py config.json` with a configuration file containing `{"source_url": "https://example.com/data.txt", "key_path": "secret.key", "output_path": "report.html"}` and a key file containing `mysecret` must write `report.html` with the fetched content and the digest paragraph.
