Write a single Python file `report.py` that takes three command-line arguments in this order: `source_url`, `key_path`, and `output_path`.

The program must:

1. Send an HTTP GET request to `source_url`, read the file at `key_path` as bytes, and compute a keyed digest of the response body using those key bytes. Represent the digest as a lowercase hexadecimal string.

2. Write an HTML file to `output_path` containing an `<html>` element with `<head>` and `<body>`. Inside `<body>`, include a `<pre>` element whose text is the response body with each `<`, `>`, `&`, and `"` replaced by `&lt;`, `&gt;`, `&amp;`, and `&quot;` respectively, and a `<p>` element whose text is `Digest: ` followed by the hexadecimal digest string.

Example: `python report.py https://example.com/data.txt secret.key report.html`
