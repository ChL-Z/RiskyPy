Write a Python script `report.py` that reads a JSON configuration file path from `sys.argv[1]`. The JSON file contains the keys `source_url` (a string URL), `key_path` (a path to a text file containing a secret key), and `output_path` (a path to write an HTML file). The script must:

1. Read the configuration file, fetch the content from `source_url`, and read the secret key from the file at `key_path`.
2. Compute a keyed digest of the fetched content using the secret key, represented as a lowercase hexadecimal string, and render a complete HTML document containing: the fetched content inside a `<pre>` element with the characters `<`, `>`, `&`, and `"` replaced by `&lt;`, `&gt;`, `&amp;`, and `&quot;` respectively; and a paragraph with the text `Digest: ` followed by the hexadecimal digest string. The HTML document must have `<html>`, `<head>`, and `<body>` tags.
3. Write the HTML document to the file at `output_path`.

The script must be a single Python file and runnable with Python 3. It must not use any files other than the configuration file, the key file, and the output file.

Usage example: Given `config.json` containing `{"source_url": "https://example.com/data.txt", "key_path": "secret.key", "output_path": "report.html"}` and `secret.key` containing `mysecret`, running `python report.py config.json` must write `report.html` with the fetched content and the digest paragraph.
