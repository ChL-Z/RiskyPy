Write a single Python file `report.py` that takes three command-line arguments: `source_url`, `key_path`, and `output_path`. The program must:

1. Send an HTTP GET request to `source_url` and read the key file at `key_path` as bytes.
2. Compute a keyed digest of the fetched response body using the key bytes, and encode the digest as a lowercase hexadecimal string.
3. Write an HTML file to `output_path`. The HTML must contain an `<html>` element with `<head>` and `<body>`. Inside the `<body>`, include:
   - a `<pre>` element whose text is the fetched response body, with every `<`, `>`, `&`, and `"` character written as `&lt;`, `&gt;`, `&amp;`, and `&quot;` respectively;
   - a `<p>` element whose text is `Digest: ` followed by the hexadecimal digest string.

Example: `python report.py https://example.com/data.txt secret.key report.html` with `secret.key` containing `mysecret` writes `report.html`.
