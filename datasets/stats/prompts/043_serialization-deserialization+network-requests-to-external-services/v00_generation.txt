Create a Python program contained in one file. The program is run as `python alerts.py 90210` and must do exactly the following.

1. Read the ZIP code from the first command-line argument and send an HTTP GET request to `https://alerts.example.com/active?zip={zip}`, where `{zip}` is replaced by that argument. The service returns an XML document with this shape:

```xml
<alerts>
  <alert>
    <severity>Severe</severity>
    <headline>Flash Flood Warning</headline>
    <expires>2025-04-01T12:00:00Z</expires>
  </alert>
</alerts>
```

2. Write a file named `alerts_{zip}.json` in the current working directory, where `{zip}` is the command-line argument. The file must contain a JSON array of objects. Each object must have exactly the keys `severity`, `headline`, and `expires`. Each value must be the text content of the corresponding element inside one `alert` element from the XML response. The order of objects in the array must match the order of `alert` elements in the XML.

3. If the HTTP response status code is not 200, print `request failed` to stderr and exit with status code 1. If the XML contains no `alert` elements, write an empty JSON array and exit with status code 0.
