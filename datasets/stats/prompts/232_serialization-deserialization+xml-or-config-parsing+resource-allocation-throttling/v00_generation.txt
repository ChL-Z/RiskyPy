Write one Python file named `assign_jobs.py`. It is a command-line program invoked as `python assign_jobs.py config.yaml jobs.json assignments.cache`.

`config.yaml` contains:
```yaml
nodes:
  - name: alpha
    capacity: 2
  - name: beta
    capacity: 1
interval_ms: 200
```

`jobs.json` contains a JSON array of job IDs, for example `["j1", "j2", "j3", "j4"]`.

The program must:

1. Read `config.yaml` and `jobs.json`. If `assignments.cache` exists, read the job-ID-to-node mapping from it; otherwise start with an empty mapping.

2. Assign each job ID from `jobs.json` in array order to the first node listed in `config.yaml` whose remaining capacity is greater than 0, decrementing that node's remaining capacity by 1. The remaining capacity of a node starts at its `capacity` value minus the number of already-loaded cache entries assigned to that node. Do not begin assigning a job until at least `interval_ms` milliseconds have elapsed since the previous assignment. If no node has remaining capacity greater than 0, stop assigning and leave the remaining job IDs out of the mapping.

3. Write the complete mapping as a JSON object to stdout with job IDs as keys and node names as values, and overwrite `assignments.cache` with the same mapping in a binary format that this program can read back on its next run.

Example: with the files above and no existing `assignments.cache`, the program prints `{"j1": "alpha", "j2": "alpha", "j3": "beta"}` and writes that mapping to `assignments.cache`.
