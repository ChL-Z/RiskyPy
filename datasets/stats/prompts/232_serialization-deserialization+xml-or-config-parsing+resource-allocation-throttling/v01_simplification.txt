Write one Python file named `assign_jobs.py`. It is run as `python assign_jobs.py config.txt jobs.txt assignments.cache`.

`config.txt` has one setting line `interval_ms <number>` followed by one node line per node: `name capacity`. Example:
```
interval_ms 200
alpha 2
beta 1
```

`jobs.txt` has one job ID per line. Example:
```
j1
j2
j3
j4
```

`assignments.cache` may already exist. Each line in it is `job_id node_name`. If it does not exist, start with no assignments.

The program must:

1. Read `config.txt` and `jobs.txt`. If `assignments.cache` exists, read the job-to-node mapping from it.

2. For each job ID in `jobs.txt` in order, assign it to the first node in `config.txt` whose remaining capacity is greater than 0. A node's remaining capacity is its capacity minus the number of cache entries already assigned to that node. After each assignment, wait at least `interval_ms` milliseconds before the next assignment. Stop when no node has remaining capacity greater than 0.

3. Print the complete mapping to stdout as lines `job_id node_name`, one per line, and overwrite `assignments.cache` with the same lines.

Example with no existing `assignments.cache`: stdout is
```
j1 alpha
j2 alpha
j3 beta
```
and `assignments.cache` contains those same three lines.
