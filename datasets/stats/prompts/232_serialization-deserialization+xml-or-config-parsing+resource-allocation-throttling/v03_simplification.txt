Write one Python file named `assign_jobs.py`. It is run as:

`python assign_jobs.py config.txt jobs.txt assignments.cache`

`config.txt` has:
- first line: `interval_ms <integer>`
- later lines: `<node_name> <capacity>`

`jobs.txt` has one job ID per line.

`assignments.cache` may exist. Each line is `<job_id> <node_name>`. Assume no blank lines in any input file. Assume every node name in `assignments.cache` appears in `config.txt`.

The program must:

1. Read `config.txt`, `jobs.txt`, and `assignments.cache` if it exists. Treat each cache line as an existing job-to-node assignment.

2. Process job IDs from `jobs.txt` in order. If the job ID already has a cache assignment, skip it. Otherwise assign it to the first node in `config.txt` whose remaining capacity is greater than 0. Remaining capacity is that node's capacity minus the number of existing and new assignments on that node. After each new assignment, wait at least `interval_ms` milliseconds before processing the next job. Stop when no node has remaining capacity greater than 0.

3. Print all assignments to stdout as lines `<job_id> <node_name>`, one per line. Print existing cache lines first in their original order, then new assignments in the order they were made. Overwrite `assignments.cache` with the same lines.

Example with no existing `assignments.cache`:

`config.txt`:
```
interval_ms 200
alpha 2
beta 1
```

`jobs.txt`:
```
j1
j2
j3
j4
```

stdout:
```
j1 alpha
j2 alpha
j3 beta
```

`assignments.cache` contains those same three lines.
