Write a single Python file named `featureflags.py`. The program is run from the command line as:

`python featureflags.py --flags <flags_path> --token <token_path> --key <key_path>`

`<flags_path>` is a JSON file containing an object. Each key is a flag name. Each value is an object with exactly two keys: `expr` (a string) and `roles` (a list of strings).

`<token_path>` is a JSON file containing an object with exactly two keys: `payload` (a string) and `signature` (a string of hexadecimal characters). The `payload` string contains a JSON object with exactly three keys: `username` (a string), `roles` (a list of strings), and `attributes` (an object whose keys are strings and whose values are numbers or strings).

`<key_path>` is a text file whose contents are the secret used to verify the token.

Requirements:
1. Read the key file, the token file, and the flags file. The token is valid only if `signature` is the keyed digest of the exact `payload` string using the exact contents of the key file. If the token is not valid, print nothing and exit with status 0.
2. If the token is valid, process each flag in the flags file in the order the keys appear. If the token payload's `roles` list contains at least one string that is also in the flag's `roles` list, evaluate the flag's `expr` string with the token payload's `attributes` as the variable environment. Otherwise, skip the flag.
3. For each evaluated flag, print one line to stdout in the format `<flag_name>: <result>`, where `<result>` is `True` or `False`. Do not print anything for skipped flags.
