Write a single Python file named `featureflags.py`. The program is run from the command line as:

`python featureflags.py <flags_path> <token_path> <key_path>`

`<flags_path>` is a JSON file containing an object. Each key is a flag name. Each value is an object with `expr` (a string) and `role` (a string).

`<token_path>` is a text file with two lines. The first line, without its trailing newline, is the payload string. The second line is a signature string of hexadecimal characters. The payload string is a JSON object with `role` (a string) and `attributes` (an object whose keys are strings and whose values are numbers or strings).

`<key_path>` is a text file whose contents are used for the keyed digest.

Requirements:
1. Read the flags file, token file, and key file. If the signature is not the keyed digest of the exact payload line using the exact contents of the key file, print nothing and exit with status 0.
2. If the signature matches, process flags in the order their keys appear in the flags JSON. For each flag, if the payload's `role` equals the flag's `role`, evaluate the flag's `expr` string with the payload's `attributes` object as the variable environment. Print one line `<flag_name>: True` when the evaluated result is true and `<flag_name>: False` when it is false. Do not print for flags whose roles do not match.
