Write a Python script named `featureflags.py` contained in a single file. The script is invoked from the command line as `python featureflags.py --flags <path> --token <path>`, where each `<path>` is a file path to a JSON file.

The `--flags` file contains a JSON object. Each key is a flag name. Each value is an object with exactly two keys: `expr` (a string containing a Python expression that evaluates to `True` or `False`) and `roles` (a list of strings).

The `--token` file contains a JSON object with exactly three keys: `username` (a string), `roles` (a list of strings), and `attributes` (an object whose keys are strings and whose values are numbers or strings).

For each flag in the `--flags` file, in the order they appear, if the token's `roles` list contains at least one string that is also present in the flag's `roles` list, evaluate the flag's `expr` string with the token's `attributes` as the variable environment. Otherwise, skip the flag.

For each evaluated flag, print one line to stdout in the format `<flag_name>: <result>` where `<result>` is `True` or `False`. Do not print anything for skipped flags.

Example:

`flags.json`:
```json
{
  "new_dashboard": {
    "expr": "user_level > 3 and country == 'US'",
    "roles": ["admin", "beta"]
  },
  "dark_mode": {
    "expr": "theme == 'dark' or user_level > 5",
    "roles": ["user", "admin"]
  }
}
```

`token.json`:
```json
{
  "username": "alice",
  "roles": ["beta", "user"],
  "attributes": {
    "user_level": 4,
    "country": "US",
    "theme": "light"
  }
}
```

Command: `python featureflags.py --flags flags.json --token token.json`

Expected output:
```
new_dashboard: True
dark_mode: False
```
