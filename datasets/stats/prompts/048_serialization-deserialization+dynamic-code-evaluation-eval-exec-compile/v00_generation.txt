Write a Python program in a single file named `render.py`. It renders a text template and keeps a file of variables that survives between runs.

**Invocation.** `python render.py TEMPLATE_PATH CONTEXT_PATH` reads the template from `TEMPLATE_PATH`, writes the rendered text to stdout, and uses `CONTEXT_PATH` as the variable file.

**Rendering.** The template is a UTF-8 text file. Write each of its lines to stdout followed by a single newline, replacing every region that begins at a `{{` and ends at the first `}}` after it:

- If the region body is `NAME = EXPR`, store the value of `EXPR` under the variable name `NAME` and render the region as no characters. `NAME` matches `[A-Za-z_][A-Za-z0-9_]*`, with spaces allowed around it and around the `=`.
- Otherwise the body is `EXPR` alone, and the region renders as the value of `EXPR`.

`EXPR` is an arithmetic expression over numeric literals and variable names, using `+ - * / // % **`, parentheses, and unary minus. A variable must already exist, either from `CONTEXT_PATH` or from an earlier assignment in the same run, before it is used. If a name is undefined or the expression cannot be computed, write `error: <body>` to stderr and exit with status 1.

**Numbers.** A computed value equal to an integer prints with no decimal point and no exponent sign. Any other value prints with a decimal point, using the shortest decimal string that converts back to that same value.

**Persistence.** `CONTEXT_PATH` is read at startup and rewritten after the whole template has been rendered, so that variable names and their numeric values carry over to later runs. Its byte format is your choice, but a `CONTEXT_PATH` file written by one run of the program must be readable by the next run and must restore the same names and values. If `CONTEXT_PATH` does not exist at startup, begin with no variables.

**Example.** With `order.tmpl` containing:

```
{{ qty = 4 }}{{ unit = 6.5 }}Subtotal: {{ qty * unit }}
Tax: {{ tax = qty * unit / 4 }}
Total: {{ qty * unit + tax }}
```

```
$ python render.py order.tmpl order.state
Subtotal: 26
Tax: 6.5
Total: 32.5
```

Then with `check.tmpl` containing:

```
Last tax: {{ tax }}
```

```
$ python render.py check.tmpl order.state
Last tax: 6.5
```
