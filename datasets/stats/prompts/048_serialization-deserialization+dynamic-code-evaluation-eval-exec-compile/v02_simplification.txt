Write a Python program in a single file named `render.py`. It is run as `python render.py TEMPLATE_PATH CONTEXT_PATH`. It reads the UTF-8 text file `TEMPLATE_PATH` and writes rendered text to stdout.

Process each line of `TEMPLATE_PATH`. If the line, after trimming leading and trailing spaces, has the form `NAME = EXPR`, where `NAME` matches `[A-Za-z_][A-Za-z0-9_]*`, set variable `NAME` to the value of `EXPR` and write no output for that line. Otherwise, replace every region of the form `{{ ... }}` in the line with the value of the trimmed body, then write the resulting line followed by one newline to stdout. `EXPR` is an arithmetic expression using numeric literals, variable names, parentheses, and the operators `+`, `-`, `*`, `/`. Variables come from `CONTEXT_PATH` or from earlier assignments in the same run. If a name is undefined or an expression cannot be evaluated, write `error: <trimmed body>` to stderr and exit with status 1. If the value is an integer, write it without a decimal point; otherwise write it with a decimal point.

At startup, if `CONTEXT_PATH` exists, read it as lines of `NAME=VALUE`, one variable per line, and restore the variables. After all template lines are processed, write all current variables to `CONTEXT_PATH` as lines of `NAME=VALUE`, one per line, using the same number formatting as above. A file written by one run must be readable by the next run and restore the same names and values.
