Write a Python program in a single file named `render.py`.

The program is run as `python render.py TEMPLATE_PATH CONTEXT_PATH`. It reads the UTF-8 text file `TEMPLATE_PATH`, writes the rendered text to stdout, and uses `CONTEXT_PATH` as the variable file.

The template contains regions of the form `{{ ... }}`. For each line, write the line to stdout with every region replaced. The body inside `{{` and `}}` is trimmed of leading and trailing spaces. If the trimmed body is `NAME = EXPR`, store the value of `EXPR` under `NAME` and replace the region with an empty string. `NAME` matches `[A-Za-z_][A-Za-z0-9_]*`. Otherwise the trimmed body is `EXPR`, and the region is replaced by the value of `EXPR`. After each line, write one newline to stdout.

`EXPR` is an arithmetic expression over numeric literals, variable names, parentheses, and the operators `+`, `-`, `*`, `/`. Variable names must come from `CONTEXT_PATH` or from an earlier assignment in the same run. If a name is undefined or the expression cannot be evaluated, write `error: <trimmed body>` to stderr and exit with status 1. If the computed value is an integer, print it without a decimal point; otherwise print it with a decimal point.

At startup, read `CONTEXT_PATH` if it exists and restore the variable names and numeric values stored there. If it does not exist, start with no variables. After the whole template has been rendered, write all current variable names and numeric values to `CONTEXT_PATH`. The byte format is your choice, but a file written by one run must be readable by the next run and must restore the same names and values.
