Write a single-file Python program `render.py`, run as `python render.py TEMPLATE_PATH CONTEXT_PATH`.

1. If `CONTEXT_PATH` exists, read it as UTF-8 text. Each non-empty line has the form `NAME=VALUE`, where `NAME` matches `[A-Za-z_][A-Za-z0-9_]*` and `VALUE` is an integer written in decimal. Set each `NAME` to its integer `VALUE`.

2. Read `TEMPLATE_PATH` as UTF-8 text line by line. For each line:
   - If the line, after removing leading and trailing spaces, has the form `NAME = EXPR`, where `NAME` matches `[A-Za-z_][A-Za-z0-9_]*`, compute the integer value of `EXPR` and set `NAME` to that value. Write nothing for this line.
   - Otherwise, replace every substring of the form `{{ ... }}` in the line with the integer value of the trimmed text inside the braces, computed using variables currently set. Write the resulting line followed by one newline to stdout.
   `EXPR` uses integer literals, variable names, parentheses, and the operators `+`, `-`, `*`. Every name in an expression is already set.

3. After all template lines are processed, write every variable currently set to `CONTEXT_PATH` as UTF-8 text, one line per variable, in the form `NAME=VALUE`, where `VALUE` is the integer value in decimal. A file written by one run must be readable by the next run and restore the same names and integer values.
