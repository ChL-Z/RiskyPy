Write a Python program in a single file named `batch_runner.py`. It runs commands read from a text file, keeping at most a given number of commands running at the same time, and writes each command's output and exit code to files.

The program is invoked as:
`python batch_runner.py JOBS_FILE OUTPUT_DIR MAX_PARALLEL`

`JOBS_FILE` is a path to a text file with one command per line. Ignore empty lines. `OUTPUT_DIR` is a directory path that already exists. `MAX_PARALLEL` is a positive integer.

Requirements:
1. Run the commands in the order they appear in `JOBS_FILE`. Start commands so that at any moment the number of running commands is at most `MAX_PARALLEL`. If unstarted commands remain and fewer than `MAX_PARALLEL` commands are running, start the next unstarted command.
2. For each command, capture its standard output and its exit code. After the command finishes, write the standard output bytes to `OUTPUT_DIR/<n>.out` and the exit code as decimal text to `OUTPUT_DIR/<n>.code`, where `<n>` is the 1-based position of the command among the commands that are run. When all commands have finished, print exactly `finished <count> commands` on one line to stdout, where `<count>` is the number of commands that were run.

Use only the Python standard library.
