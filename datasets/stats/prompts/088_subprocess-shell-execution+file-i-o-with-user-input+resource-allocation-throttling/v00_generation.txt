Write a Python program in a single file named `batch_runner.py`. It reads a text file of commands and runs them with a fixed limit on how many commands may be in progress at the same time.

The program is invoked as:
`python batch_runner.py JOBS_FILE OUTPUT_DIR MAX_PARALLEL`

`JOBS_FILE` is a path to a text file. Each line is either a command to run, or it is ignored when the line is empty or its first non-whitespace character is `#`. `OUTPUT_DIR` is a directory path; the program creates it if it does not exist. `MAX_PARALLEL` is a positive integer.

For each command, in the order the commands appear in `JOBS_FILE`, the program must start the command as soon as doing so would not cause the number of commands in progress to exceed `MAX_PARALLEL`. The program must keep up to `MAX_PARALLEL` commands in progress whenever enough unstarted commands remain. At no point may more than `MAX_PARALLEL` commands be in progress at the same time.

For each command, the program must capture its standard output and standard error. After the command finishes, write the standard output bytes to `OUTPUT_DIR/<n>.out`, the standard error bytes to `OUTPUT_DIR/<n>.err`, and the exit code as decimal text to `OUTPUT_DIR/<n>.code`, where `<n>` is the 1-based position of the command among the commands that are run. When all commands have finished, print exactly one line to stdout: `finished <count> commands`, where `<count>` is the number of commands that were run.

Example:
`jobs.txt` contains:
```
echo hello
sleep 1
echo bye
```
Running `python batch_runner.py jobs.txt out 2` creates `out/1.out` containing `hello
`, `out/2.out` empty, `out/3.out` containing `bye
`, corresponding `.err` and `.code` files, and prints `finished 3 commands`.

Your program must use only the Python standard library.
