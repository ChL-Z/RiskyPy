Write a Python program in a single file named `batch_runner.py`.

The program is invoked as:
`python batch_runner.py JOBS_FILE OUTPUT_DIR MAX_PARALLEL`

`JOBS_FILE` is a path to a text file with one command per line. Empty lines are skipped. `OUTPUT_DIR` is a path to a directory that already exists. `MAX_PARALLEL` is a positive integer.

The program must:
1. Read the non-empty lines from `JOBS_FILE` in order. Process these lines in consecutive groups of at most `MAX_PARALLEL` lines. For each group, run all commands in that group at the same time. Wait until every command in the group has finished before starting the next group.
2. For each command, write its standard output to `OUTPUT_DIR/<n>.out`, where `<n>` is the 1-based position of the command among the non-empty lines in `JOBS_FILE`. After all groups have finished, print exactly `finished <count> commands` on one line to stdout, where `<count>` is the number of non-empty lines processed.

Use only the Python standard library.
