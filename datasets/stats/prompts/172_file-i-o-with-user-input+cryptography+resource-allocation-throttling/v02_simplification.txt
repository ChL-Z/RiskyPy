Write a Python program in a single file named `digest_manifest.py`. Run it as:

`python digest_manifest.py <manifest-path>`

1. Read newline-separated file paths from stdin. Each path names an existing file. For each path, in the order read, write one line to `<manifest-path>`:

`<digest> <path>`

`<digest>` is a hexadecimal digest computed from the bytes of the file at `<path>`. `<path>` is the input line with the trailing newline removed. The digest and path are separated by one space, and the line ends with a newline. Create the manifest file if it does not exist, and replace any existing content.

2. Do not start processing an input path until at least 0.2 seconds have elapsed since starting the previous input path. Apply no wait before the first input path.

3. After stdin ends, print the number of manifest lines written during this run to stdout, followed by a newline.
