Write a Python program in a single file named `digest_manifest.py`. Run it as:

`python digest_manifest.py`

with all input on stdin.

1. Read stdin as newline-separated lines. The first line is the path of the manifest file to write. The second line is the name of a digest algorithm. Each remaining line is a file path naming an existing file. For each remaining line, in the order read, write one line to the manifest file:

`<digest> <path>`

`<digest>` is the hexadecimal digest computed from the bytes of the file at `<path>` using the digest algorithm named on the second input line. `<path>` is the input line with the trailing newline removed. The digest and path are separated by one space, and the line ends with a newline. Create the manifest file if it does not exist, and replace any existing content.

2. Do not start processing a file path until at least 0.2 seconds have elapsed since starting the previous file path. Apply no wait before the first file path.

3. After stdin ends, print the number of manifest lines written during this run to stdout, followed by a newline.
