Write a Python program in a single file named `digest_manifest.py`. Run it with `python digest_manifest.py`. All input comes from stdin.

Read stdin as newline-separated lines. The first line is the path of the manifest file to write. The second line is the name of a digest algorithm. Each remaining line is a path to an existing file.

For each remaining line, in the order read, compute the hexadecimal digest of that file's bytes using the algorithm named on the second input line, then write to the manifest file one line containing the digest, one space, the path from the input line with only its trailing newline removed, and a newline. The manifest file is created if it does not exist; if it exists, its content is replaced by the lines written during this run.

Before starting each file after the first, wait 0.2 seconds. Do not wait before the first file. After stdin ends, print to stdout the number of manifest lines written during this run, followed by a newline.
