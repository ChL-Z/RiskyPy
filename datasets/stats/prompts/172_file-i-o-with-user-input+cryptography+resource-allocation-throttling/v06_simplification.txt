Write a Python program in a single file named `digest_manifest.py`. Run it with `python digest_manifest.py`. All input comes from stdin.

Read stdin as newline-separated lines. The first line is the name of a digest algorithm. Each remaining line is a path to an existing file.

For each remaining line, in the order read: wait 0.2 seconds, read the file's bytes, compute the hexadecimal digest of those bytes using the named algorithm, then write to `manifest.txt` one line containing the digest, one space, the path from the input line with only its trailing newline removed, and a newline.

`manifest.txt` is created if it does not exist. If it exists, its content is replaced by the lines written during this run. After stdin ends, print to stdout the number of manifest lines written during this run, followed by a newline.
