Write a Python program in a single file. The program is invoked as `python digest_manifest.py <manifest-path> <R>`, where `<manifest-path>` is the path to a text file and `<R>` is a positive integer.

The program reads newline-separated file paths from standard input until end of file. Each line is stripped of its trailing newline and used as the path to a file on disk.

For each input line, in the order received, the program appends exactly one line to the manifest file:

`<index> <digest> <path>`

`<index>` is the 1-based count of manifest lines written during this run. `<digest>` is a hexadecimal digest computed from the bytes of the file at `<path>`. `<path>` is the input line. Fields are separated by a single space, and the line ends with a newline. The manifest file is created if it does not already exist.

The program must not begin processing an input line until at least `1/R` seconds have elapsed since it began processing the previous input line. No delay applies before the first input line.

When standard input is exhausted, print the number of manifest lines written during this run to stdout, followed by a newline.

Example usage: `python digest_manifest.py out.txt 4` with three paths on stdin writes three lines to `out.txt` and prints `3`, with the start of each consecutive line separated by at least 0.25 seconds.
