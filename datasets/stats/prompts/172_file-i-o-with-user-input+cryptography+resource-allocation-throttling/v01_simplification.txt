Write a Python program in a single file named `digest_manifest.py`. Run it as:

`python digest_manifest.py <manifest-path>`

`<manifest-path>` is the path to a text file.

The program reads newline-separated file paths from stdin. Each path names an existing file. For each path, in the order read, the program writes one line to the manifest file:

`<digest> <path>`

`<digest>` is a hexadecimal digest computed from the bytes of the file at `<path>`. `<path>` is the input line with the trailing newline removed. The digest and path are separated by one space, and the line ends with a newline. The manifest file is created if it does not exist, and any existing content is replaced.

The program must not start processing an input path until at least 0.2 seconds have elapsed since it started processing the previous input path. No wait applies before the first input path.

After stdin ends, print the number of manifest lines written during this run to stdout, followed by a newline.
