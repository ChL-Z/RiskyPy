Write a Python program in a single file named `digest_manifest.py`. Run it with:

`python digest_manifest.py`

All input comes from stdin.

1. Read stdin as newline-separated lines. The first line is the path of the manifest file to write. The second line is the name of a digest algorithm. Each remaining line is a path to an existing file. For each remaining line, in the order read, compute the hexadecimal digest of the file's bytes using the algorithm named on the second input line, then write to the manifest file one line containing the digest, one space, the path from the input line without its trailing newline, and a newline. Create the manifest file if it does not exist; if it exists, replace its content with the new lines.

2. Do not start processing a file path until at least 0.2 seconds have elapsed since starting the previous file path. Do not wait before the first file path. After stdin ends, print to stdout the number of manifest lines written during this run, followed by a newline.
