Write a Python program in a single file named `sysreport.py`. It is invoked as `python sysreport.py <commands_path> <output_path>`.

The program reads `<commands_path>` as a text file. Each line in that file is a command line to execute. Lines that are empty or contain only whitespace are skipped. For each remaining line, execute the command line and capture its standard output, standard error, and exit status.

The program writes an HTML document to `<output_path>`. The document begins with the line `<!DOCTYPE html>` and contains a `<table id="report">`. The first row of that table contains four `<th>` cells whose displayed text is exactly `Command`, `Exit Code`, `Stdout`, and `Stderr`. For each executed command, in the order the lines appear in the input file, the table contains a `<tr class="result">` with four cells: a `<td class="command">` whose displayed text is the command line from the input file, a `<td class="exit-code">` whose displayed text is the exit status as a decimal integer, a `<td class="stdout">` containing a `<pre>` whose displayed text is the captured standard output, and a `<td class="stderr">` containing a `<pre>` whose displayed text is the captured standard error.

Example: `commands.txt` contains the lines `echo hello` and `false`. Running `python sysreport.py commands.txt report.html` writes `report.html`. That file, when loaded in a browser, shows a table with two result rows. The first row shows command `echo hello`, exit code `0`, and `hello` in the stdout cell. The second row shows command `false`, exit code `1`, an empty stdout cell, and an empty stderr cell.
