Write a Python script named `audit_token.py`. It must be a single-file command-line program. It reads exactly two lines from standard input:

1. A token string of the form `<payload_b64>.<sig_b64>`. `<payload_b64>` is the base64url encoding without padding of a JSON object with keys `sub` (string), `exp` (integer Unix timestamp in seconds), and `scopes` (array of strings). `<sig_b64>` is a base64url string.
2. A requested action name (string).

The script must perform these steps in order:

1. Read `signatures.json` from the current working directory. This file contains a JSON object mapping `payload_b64` strings to `sig_b64` strings. If the token's `<payload_b64>` is not a key in this object, or the corresponding value is not equal to the token's `<sig_b64>`, write `INVALID` to standard output and exit with code 3. Otherwise, decode the payload. If the current Unix time in seconds is greater than or equal to `exp`, write `EXPIRED` to standard output and exit with code 1.
2. Read `policy.json` from the current working directory. This file contains a JSON object mapping action names to arrays of scope strings, for example `{"read": ["docs:read"], "write": ["docs:write"]}`. If the requested action is not a key in this object, write `DENIED` to standard output and exit with code 2.
3. If every scope string listed for the requested action is present in the token's `scopes` array, append a JSON object to `audit.jsonl` in the current working directory with keys `sub`, `action`, `granted` (boolean true), and `at` (current Unix timestamp in seconds), then write `GRANTED` to standard output and exit with code 0. Otherwise, append a JSON object with the same keys but `granted` set to boolean false, write `DENIED` to standard output, and exit with code 2. Each line in `audit.jsonl` must be a single JSON object followed by a newline character.

Usage example: Suppose `signatures.json` contains the mapping for the token's payload, `policy.json` contains `{"read": ["docs:read"]}`, and the token payload decodes to `{"sub": "alice", "exp": 2000000000, "scopes": ["docs:read"]}`. Running the script and providing the token on the first line and `read` on the second line prints `GRANTED` and appends a line to `audit.jsonl`.
