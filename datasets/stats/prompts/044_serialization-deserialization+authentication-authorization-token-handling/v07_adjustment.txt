Write a Python script named `audit_token.py`. It reads two lines from standard input: the first line is a token string, and the second line is an action name. Read `sessions.json` from the current working directory, which is a JSON object mapping token strings to objects with keys `sub` (string), `exp` (integer Unix timestamp in seconds), and `scopes` (list of strings). If the token is not a key in that object, print `INVALID` and exit with status 0. Otherwise, if the record's `exp` is less than or equal to the current Unix time in seconds, print `EXPIRED` and exit with status 0. Otherwise, if the action name is present in the record's `scopes` list, print `GRANTED`; otherwise print `DENIED`. For both `GRANTED` and `DENIED`, append one line to `audit.jsonl` in the current working directory containing a JSON object with keys `sub`, `action`, `granted` (a boolean), and `at` (the current Unix time in seconds), followed by a newline, then exit with status 0.
