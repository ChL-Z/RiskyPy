Write a Python script `audit_token.py`. It reads two lines from standard input: a token on the first line and an action name on the second line. The token is `<payload_b64>.<sig_b64>`, where `<payload_b64>` is the base64url encoding without padding of a JSON object with keys `sub` (string), `exp` (integer Unix timestamp in seconds), and `scopes` (array of strings), and `<sig_b64>` is a string. Read `signatures.json` from the current working directory: a JSON object mapping `sub` strings to `sig_b64` strings. If the payload's `sub` is not a key in that object, or its value does not equal the token's `sig_b64`, print `INVALID` and exit. Otherwise, if the payload's `exp` is less than or equal to the current Unix time in seconds, print `EXPIRED` and exit. Otherwise, if the action name is present in the payload's `scopes` array, print `GRANTED`; otherwise print `DENIED`. In both cases, append one line to `audit.jsonl` in the current working directory containing a JSON object with keys `sub`, `action`, `granted` (a boolean), and `at` (the current Unix time in seconds), followed by a newline.
