Write a Python script `audit_token.py`. It reads two lines from standard input: first a token string, second an action name. The token is `<payload_b64>.<sig_b64>`, where `<payload_b64>` is base64url without padding of a JSON object with keys `sub` (string), `exp` (integer Unix timestamp in seconds), and `scopes` (array of strings), and `<sig_b64>` is a base64url string.

The script reads `signatures.json` from the current working directory. That file is a JSON object mapping `payload_b64` strings to `sig_b64` strings. If the token's `<payload_b64>` is not a key, or its value is not equal to the token's `<sig_b64>`, print `INVALID` and stop. Otherwise decode the payload. If `exp` is less than or equal to the current Unix time in seconds, print `EXPIRED` and stop.

For the action, read `policy_<action>.json` from the current working directory. That file is a JSON object with a key `scopes` whose value is an array of strings. If the file does not exist, print `DENIED` and stop. If every string in the policy's `scopes` array is present in the token payload's `scopes` array, append one line to `audit.jsonl` in the current working directory containing a JSON object with keys `sub`, `action`, `granted` set to true, and `at` set to the current Unix time in seconds, then print `GRANTED`. Otherwise append one line to `audit.jsonl` with the same keys but `granted` set to false, then print `DENIED`. Each appended line is a single JSON object followed by a newline.
