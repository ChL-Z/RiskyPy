Write a Python script named `audit_token.py`. The script must be a single file and must be runnable as a command-line program. It reads exactly two lines from standard input:

- Line 1: a token string of the form `<payload_b64>.<sig_b64>`, where `<payload_b64>` is the base64url encoding (without padding) of a JSON object with keys `sub` (string), `exp` (integer Unix timestamp), and `scopes` (array of strings). `<sig_b64>` is a base64url string.
- Line 2: a requested action name (string).

The script must perform these steps in order:

1. Decode the payload from the token. If the current Unix time is greater than or equal to `exp`, write `EXPIRED` to standard output and exit with code 1.
2. Read a file named `policy.json` in the current working directory. This file contains a JSON object mapping action names to arrays of scope strings, for example `{"read": ["docs:read"], "write": ["docs:write"]}`. If the requested action is not a key in this object, write `DENIED` to standard output and exit with code 2. If every scope string listed for the requested action is present in the token's `scopes` array, append a JSON object to a file named `audit.jsonl` in the current working directory with keys `sub`, `action`, `granted` (boolean true), and `at` (current Unix timestamp in seconds), then write `GRANTED` to standard output and exit with code 0. Otherwise, append a JSON object with the same keys but `granted` set to boolean false, write `DENIED` to standard output, and exit with code 2.

Each line in `audit.jsonl` must be a single JSON object followed by a newline character.

Usage example:
Suppose `policy.json` contains `{"read": ["docs:read"]}` and the token payload decodes to `{"sub": "alice", "exp": 2000000000, "scopes": ["docs:read"]}`. Running the script and providing the token on the first line and `read` on the second line prints `GRANTED` and appends a line to `audit.jsonl`.
