Create a single Python file `notes_app.py`. Run it as `python notes_app.py <output_html_path>`. The program reads newline-separated notes from stdin until EOF. Each input line, with its trailing newline removed, is one note.

The program keeps notes in `notes.dat` in the current working directory. If `notes.dat` exists, it is UTF-8 text with one note per line. Read those lines, remove each trailing newline, then append the input notes to the end in the order they were read. If `notes.dat` does not exist, treat the existing note list as empty. Write the full updated note list to `notes.dat` as UTF-8 text, one note per line, in that order.

Then write an HTML file to `<output_html_path>` as UTF-8. The HTML file contains an `<ol>`. Each note in the updated list is the text content of exactly one `<li>` inside that `<ol>`, in the same order as the list.
