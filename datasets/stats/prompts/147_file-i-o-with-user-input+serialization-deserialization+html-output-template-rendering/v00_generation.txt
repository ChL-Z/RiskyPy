Implement a Python program in a single file named `notes_app.py`. The program is run as `python notes_app.py <output_html_path>`. It reads newline-separated note lines from stdin until EOF. Lines that are empty after removing the trailing newline are ignored. If `<output_html_path>` is missing, write `usage: notes_app.py <output_html_path>` to stderr and exit with status 1.

The program maintains a note list in a file named `notes.dat` in the current working directory. If `notes.dat` exists, load the note list from it before reading stdin. After reading stdin, append the new note lines to the list, write the updated list to `notes.dat`, then write the HTML output.

Write a full HTML document to `<output_html_path>`. The document has `<!DOCTYPE html>`, `<html lang="en">`, `<head><meta charset="utf-8"><title>Notes</title></head>`, and `<body>` containing an `<ol>` element. Each note in the list appears as an `<li>` element in the same order, with the note line placed inside the `<li>` element. Write the file as UTF-8.

Example usage:

```
$ printf 'Buy milk\nCall Ada\n' | python notes_app.py today.html
$ printf 'Read chapter 4\n' | python notes_app.py today.html
```

After the second run, `today.html` lists `Buy milk`, `Call Ada`, and `Read chapter 4` in that order.
