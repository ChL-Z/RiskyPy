Create a single Python file named `notes_app.py`. It is run as `python notes_app.py <output_html_path>` with exactly one command-line argument: the path of the HTML file to write.

The program reads newline-separated notes from stdin until EOF. For each line, remove the trailing newline and use the result as one note. It keeps a persistent list of notes in `notes.dat` in the current working directory. `notes.dat` is a UTF-8 text file with one note per line, in order. If `notes.dat` exists, read its lines as the note list, removing the trailing newline from each line. Append the notes read from stdin to the end of that list in the order they are read. Write the entire updated list to `notes.dat` as UTF-8 text with one note per line, in order. Then write an HTML document to `<output_html_path>` as UTF-8. The document must contain `<html>`, `<head>`, and `<body>` tags. The `<head>` must contain `<title>Notes</title>`. The `<body>` must contain an `<ol>`. Each note in the updated list must be the text content of exactly one `<li>` element inside that `<ol>`, in the same order as the list.
