Create a single Python file named `notes_app.py`. It is run as `python notes_app.py <output_html_path>`. It reads newline-separated note lines from stdin until EOF, ignoring lines that are empty after removing the trailing newline. If `<output_html_path>` is missing, print `usage: notes_app.py <output_html_path>` to stderr and exit with status 1.

The program keeps a persistent list of notes in `notes.dat` in the current working directory. If `notes.dat` exists, load the note list from it before reading stdin. Append the note lines read from stdin in order, save the updated list to `notes.dat`, and then write the HTML output.

Write an HTML document to `<output_html_path>` as UTF-8. The document must have `<html>`, `<head>`, and `<body>` tags. The `<head>` must contain a `<title>` with `Notes`. The `<body>` must contain an `<ol>`, and each note in the updated list must appear as one `<li>` element inside that `<ol>`, in the same order as the list.
