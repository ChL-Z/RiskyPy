Write a Python program in a single file named `inventory_report.py`.

It reads rows from table `items` in a SQLite database file given by `--db PATH`. The table has columns `name` (text), `category` (text), and `price` (real). The command also accepts `--out PATH` for an HTML output file and `--log PATH` for a log file. It accepts one optional argument `--min-price NUMBER`. If `--min-price` is given, select only rows with `price >= NUMBER`; otherwise select all rows. Order selected rows by `price` ascending, then `name` ascending.

Write an HTML file to `--out`. It contains an `<h1>` element with text `Inventory Report` and a `<table>` element. The table's first row has header cells with texts `Name`, `Category`, and `Price`. Each selected row becomes one table row with three cells: the name, the category, and the price formatted with exactly two digits after the decimal point. If no rows match, the table has only the header row.

Write log entries to `--log`. Each entry is one line: a timestamp in ISO 8601 format, a space, the level (`INFO` or `ERROR`), a space, and a message. On start, write `INFO Starting report`. On success, write `INFO Wrote <n> rows to <out>`. If the database query fails or the HTML file cannot be written, write an `ERROR` line containing the failure message and exit with status 1. If the log file cannot be opened for writing, exit with status 1 without writing a log line. Otherwise exit with status 0.
