Write a Python program in a single file named `inventory_report.py`. The program is a command-line utility that reads inventory data from a SQLite database and writes an HTML report. It accepts these arguments: `--db PATH` (database file), `--table NAME` (table to read), `--out PATH` (HTML output path), `--log PATH` (log file path), and optional filters `--name-contains TEXT`, `--category TEXT`, `--min-price NUMBER`, `--max-price NUMBER`. Example: `python inventory_report.py --db inventory.db --table items --name-contains lamp --min-price 10 --out report.html --log app.log`.

The target table has columns `name` (text), `category` (text), and `price` (real). The program must select rows where: if `--name-contains` is given, the row's name contains that text ignoring letter case; if `--category` is given, the row's category equals that text; if `--min-price` is given, the row's price is greater than or equal to it; if `--max-price` is given, the row's price is less than or equal to it. Omitted filters do not restrict rows. Results are ordered by `price` ascending, then `name` ascending.

The program must write an HTML file to `--out`. The file must contain an `<h1>` element with text `Inventory Report` and a `<table>` element. The table's first row contains header cells with texts `Name`, `Category`, and `Price`. Each selected row becomes one table row with three cells: the name, the category, and the price formatted with exactly two digits after the decimal point. If no rows match, the table contains only the header row.

The program must write log entries to `--log`. Each log entry is one line: an ISO 8601 timestamp, a space, the level (`INFO` or `ERROR`), a space, and a message. On start, write `INFO Starting report for table <table>`. On success, write `INFO Wrote <n> rows to <out>`. If the database query fails or the output file cannot be written, write an `ERROR` line with the failure message and exit with status 1. If the log file cannot be opened for writing, exit with status 1 without writing a log line. Otherwise exit with status 0.
