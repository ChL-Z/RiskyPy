Write a Python program in a single file named `inventory_report.py`.

1. The program accepts `--db PATH`, `--out PATH`, `--log PATH`, and `--filter PATH`. The file at `--filter` contains one line: an SQL condition that refers to the columns `name`, `category`, and `price` of the `items` table. Read rows from table `items` in the SQLite database file at `--db`, and include each row whose column values satisfy that condition. The table has columns `name`, `category`, and `price`.

2. Write an HTML file to `--out`. The file contains an `<h1>` element with the text `Inventory Report` and a `<table>` element. Each included row becomes one table row with three cells: the value of `name`, the value of `category`, and the value of `price` formatted with exactly two digits after the decimal point.

3. Write log entries to `--log`. Each entry is one line: an ISO 8601 timestamp, a space, the level (`INFO` or `ERROR`), a space, and a message. On success, write an `INFO` entry that includes the number of rows written. If reading the database, reading the filter file, or writing the HTML file fails, write an `ERROR` entry that includes the failure message and exit with status 1. If `--log` cannot be opened for writing, exit with status 1 without writing a log line. Otherwise exit with status 0.
