Write a Python program in a single file named `build_report.py`.

The program accepts zero or one command-line argument. If one argument is given, it is the path to an HTML template file. If no argument is given, the template path is `report_template.html` in the current working directory.

The program reads newline-separated command lines from standard input until end of file. Lines that are empty or contain only whitespace are skipped. Each remaining line is run as an external command, and the program waits for that command to finish. The program records the original line, the process exit status, the process standard output, and the process standard error.

The program writes a file named `build-report.html` in the current working directory. That file begins as the contents of the template file. Every occurrence of the exact string `<!--RESULTS-->` in the template is replaced with the HTML for all recorded commands, in the order the command lines were read. For each command, the replacement is:

```html
<section>
<h2>COMMAND_TEXT</h2>
<pre>STDOUT</pre>
<pre>STDERR</pre>
<p>Exit status: EXIT_CODE</p>
</section>
```

where `COMMAND_TEXT` is the original line, `STDOUT` is the captured standard output, `STDERR` is the captured standard error, and `EXIT_CODE` is the integer exit status. If the template contains no `<!--RESULTS-->`, the file is written unchanged.

For example, if `report_template.html` contains `<html><body><!--RESULTS--></body></html>` and standard input contains:

```
echo hello
false
```

then after running `python build_report.py`, the file `build-report.html` contains one section for `echo hello` showing exit status `0` and its output, followed by one section for `false` showing exit status `1` and its output.
