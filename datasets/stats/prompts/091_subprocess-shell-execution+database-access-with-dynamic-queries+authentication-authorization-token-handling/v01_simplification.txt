Write a Python program in a single file named `run_audit.py`. The program reads one JSON object from standard input. The object has three string fields: `token`, `sql`, and `command`.

The program checks `token` against a SQLite database file `auth.db` in the current directory. `auth.db` contains a table `users` with columns `token TEXT` and `active INTEGER`. A token is valid when a row exists with that exact token value and `active` is 1. If the token is not valid, print exactly `invalid token` to standard output and exit with code 1.

If the token is valid, open another SQLite database file `audit.db` in the current directory and run the SQL statement from `sql`. If the SQL statement raises an error, print exactly `query failed` and exit with code 2. If it succeeds, then run the `command` string, wait for it to finish, and capture its standard output as text. Print one JSON object to standard output with keys `rows` and `command_stdout`. `rows` is a JSON array of objects, where each object uses the column names returned by the SQL statement as keys. `command_stdout` is the captured standard output text. Exit with code 0.

Example: with `auth.db` containing a row `('t1', 1)`, reading `{"token":"t1","sql":"SELECT id, message FROM logs WHERE level = 'error'","command":"uname -a"}` from stdin should print a JSON object whose `rows` contains the matching rows from `audit.db` and whose `command_stdout` contains the output of `uname -a`.
