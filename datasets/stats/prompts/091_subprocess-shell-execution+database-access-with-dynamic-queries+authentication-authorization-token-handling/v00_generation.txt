Write a Python program in a single file named `run_audit.py`. The program reads one JSON object from standard input. The object has three string fields: `token`, `sql`, and `command`.

The program checks `token` against a SQLite database file `auth.db` in the current directory. The database contains a table `users` with columns `token TEXT`, `username TEXT`, and `expires_at TEXT`. A token is valid when a row exists with that exact token value and `expires_at` is later than the current UTC time. `expires_at` is written as an ISO 8601 UTC timestamp ending in `Z`, for example `2030-01-01T00:00:00Z`. If the token is not valid, print exactly `{"ok": false, "error": "invalid token"}` to standard output and exit with code 1.

If the token is valid, the program opens another SQLite database file `audit.db` in the current directory and runs the SQL statement from the `sql` field. Print the resulting rows as a JSON array of objects under the key `rows`; each object uses the column names from the query as keys. If running the SQL statement raises an error, print exactly `{"ok": false, "error": "query failed"}` and exit with code 2.

After the SQL statement succeeds, the program runs the `command` string, waits for it to finish, and captures its standard output and standard error as text. Then print one JSON object with keys `ok` (true), `rows`, `command_stdout`, `command_stderr`, and `command_exit_code`. The `command_exit_code` value is the process exit code.

Example: with `auth.db` containing a row `('t1', 'alice', '2030-01-01T00:00:00Z')`, reading `{"token":"t1","sql":"SELECT id, message FROM logs WHERE level = 'error'","command":"uname -a"}` from stdin should print a JSON object whose `rows` contains the matching rows from `audit.db` and whose `command_stdout` contains the output of `uname -a`.
