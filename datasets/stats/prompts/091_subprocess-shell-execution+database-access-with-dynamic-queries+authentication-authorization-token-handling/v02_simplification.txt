Write a Python program in a single file named `run_audit.py`.

Read three newline-separated lines from stdin: the first line is `token`, the second line is `sql` (a single SQL SELECT statement), the third line is `command`. Check `token` against the SQLite database file `data.db` in the current directory. `data.db` contains a table `users` with columns `token TEXT` and `active INTEGER`. A token is valid when a row exists with that exact token value and `active` is 1. If the token is not valid, print exactly `invalid token` to stdout and exit with code 1.

If the token is valid, run the SQL SELECT statement from `sql` against the same `data.db` file. If the SQL statement raises an error, print exactly `query failed` and exit with code 2. If it succeeds, run the `command` string, wait for it to finish, and capture its stdout as text.

Print one JSON object to stdout with keys `rows` and `command_stdout`. `rows` is a JSON array of objects, where each object uses the column names returned by the SQL statement as keys. `command_stdout` is the captured stdout text. Exit with code 0.
