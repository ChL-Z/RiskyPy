Write a Python file named `render_template.py`. The program reads lines from stdin and writes lines to stdout.

A line that starts with `@` has the form `@name = N`, where `name` is one or more non-space characters and `N` is a non-negative decimal integer. Store integer `N` under `name`. Do not write this line.

For every other line, replace each substring that starts with `{{` and ends with `}}` by the decimal string of the integer value of the expression between those braces after removing leading and trailing spaces. The expression contains non-negative integer literals, variable names stored by earlier `@` lines, parentheses, and the operators `+`, `-`, and `*`. Write the resulting line to stdout followed by a newline character.

Example input:
@w = 10
@h = 5
Area: {{ w * h }}

Example output:
Area: 50
