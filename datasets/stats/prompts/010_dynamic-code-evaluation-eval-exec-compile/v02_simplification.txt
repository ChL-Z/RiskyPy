Write a Python file named `render_template.py`. It reads template lines from stdin and writes rendered lines to stdout.

A line that starts with `@` has the form `@name = expression`. `name` starts with a letter and contains only letters, digits, and underscores. Evaluate `expression` as a Python expression using the variables defined by earlier `@` lines, store its integer value under `name`, and do not write the line.

For every other line, replace each substring that starts with `{{` and ends with `}}` by the decimal string of the integer value of the text between those braces after removing leading and trailing spaces. Evaluate that text as a Python expression using the variables defined by earlier `@` lines. Write the resulting line to stdout followed by a newline character.

The `expression` text contains non-negative integer literals, variable names defined by earlier `@` lines, parentheses, and the operators `+`, `-`, and `*`.

Example input:
@w = 10
@h = 5
Area: {{ w * h }}

Example output:
Area: 50
