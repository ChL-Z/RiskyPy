Write a Python script named `render_template.py` that reads a template file and writes the rendered result to standard output.

The script takes one command-line argument: the path to the template file. It reads the file line by line.

A line matching `@name = expr` defines a variable `name` as the integer value of the arithmetic expression `expr`; the line is not written to standard output. `name` consists of letters, digits, and underscores and starts with a letter. `expr` may contain non-negative integer literals, variable names defined earlier, parentheses, and the operators `+`, `-`, and `*`. Multiplication binds tighter than addition and subtraction, and addition and subtraction are evaluated left to right.

Every other line is written to standard output with each `{{ expr }}` replaced by the decimal string of the integer value of `expr`, using the same expression syntax and the variables defined so far. Each output line ends with a newline character.

Example:
template file contents:
@w = 10
@h = 5
Area: {{ w * h }}

running `python render_template.py template.txt` prints:
Area: 50
