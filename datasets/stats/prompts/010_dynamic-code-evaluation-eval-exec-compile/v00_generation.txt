Write a Python script named `render_template.py` that reads a template file and writes the rendered output to standard output. The script must be contained in a single file.

The script takes one command-line argument: the path to the template file. It reads the file line by line. Lines that start with `@` are variable definitions and are not written to standard output. A variable definition has the form `@name = expression`, where `name` consists of letters, digits, and underscores and starts with a letter. The `expression` is an arithmetic expression containing non-negative integer literals, previously defined variable names, parentheses, and the binary operators `+`, `-`, and `*`. Operators follow the usual precedence: parentheses first, then multiplication, then addition and subtraction from left to right. Whitespace may appear around the `=` and within the expression, and is ignored. The value of the variable is the integer result of evaluating the expression.

Any line that does not start with `@` is written to standard output after replacing every placeholder with its computed value. A placeholder has the form `{{ expression }}`, where the opening is two left braces, the closing is two right braces, and `expression` uses the same syntax and variables as variable definitions. Whitespace may appear between the braces and the expression. The placeholder is replaced by the decimal string representation of the integer result of evaluating the expression. All placeholders on a line are replaced. Each output line is followed by a newline character.

Example: if the template file contains:
@width = 10
@height = 5
Area: {{ width * height }}
Perimeter: {{ 2 * (width + height) }}

then running `python render_template.py template.txt` prints to standard output:
Area: 50
Perimeter: 30

The script must not use any external libraries beyond the Python standard library.
