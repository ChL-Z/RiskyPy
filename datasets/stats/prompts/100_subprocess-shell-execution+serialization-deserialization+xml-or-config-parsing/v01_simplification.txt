Write a Python 3 program in a single file named `jobrunner.py`. It reads an XML configuration file whose path is the first command-line argument. The XML root is `<jobs>` and contains zero or more `<job>` elements. Each `<job>` has a `name` attribute and a `command` attribute. For each `<job>` in document order, the cache path is the `name` attribute followed by `.cache`. If that cache file exists, read its contents as UTF-8 text. Otherwise, run the `command` attribute as a command line, capture its standard output as UTF-8 text, write that text to the cache path as UTF-8 text, and use it as the result. Print each result to standard output in this exact format: `--- <name> ---` on one line, then the result text. If the result text does not end with a newline, write one newline after it. After all jobs, exit with status 0.
