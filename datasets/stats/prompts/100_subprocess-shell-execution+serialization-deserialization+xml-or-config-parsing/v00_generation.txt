Write a Python 3 program in a single file named `jobrunner.py`. It reads an XML configuration file whose path is given as the first command-line argument. The XML document has a root element `<jobs>` containing zero or more `<job>` elements in document order. Each `<job>` element has three attributes: `name`, `command`, and `cache`. The `name` attribute is a text label. The `command` attribute is a command line to execute. The `cache` attribute is a filesystem path.

For each `<job>` element in document order, the program must produce one result. If the file at the `cache` path exists, the program reads the result from that file as UTF-8 text. Otherwise, the program executes the `command` attribute as a command line, captures the command's standard output as UTF-8 text, and writes that text to the `cache` path as a binary file. If the command exits with a non-zero status, the result is the text `ERROR` and no cache file is written. The program writes each result to standard output in this exact format:

```
--- <name> ---
<result>
```

where `<name>` is the `name` attribute and `<result>` is the result text. If the result text does not end with a newline, the program writes one newline after it. The program processes all jobs and then exits with status 0.

Example: with `config.xml` containing

```xml
<jobs>
  <job name="year" command="date +%Y" cache="year.cache"/>
  <job name="files" command="ls" cache="files.cache"/>
</jobs>
```

running `python jobrunner.py config.xml` on the first run executes both commands and writes `year.cache` and `files.cache`. On a second run the same command reads those two files and prints the cached outputs.
