Write a Python 3 program in a single file named `jobrunner.py`. It takes one command-line argument: the path to an XML file. The XML root is `<jobs>` and contains zero or more `<job>` elements. Each `<job>` has a `name` attribute and a `command` attribute.

For each `<job>` in document order, use the file `<name>.cache` in the current directory as its cached result. If that file exists, read its contents as UTF-8 text. Otherwise, run the `command` attribute as a command line, capture its standard output as UTF-8 text, write that text to the cache file as UTF-8 text, and use it as the result.

For each job, print `--- <name> ---` on one line, then the result text, then one newline. Exit with status 0 after all jobs.
