Write a Python 3 program in a single file named `jobrunner.py`. The program takes one command-line argument: the path to an XML file. The XML root is `<jobs>` and contains zero or more `<job>` elements. Each `<job>` has a `name` attribute and a `command` attribute.

For each `<job>` in document order, use the file `<name>.cache` in the current directory as its result when that file exists. That cache file is UTF-8 text containing a JSON object with one key `"output"` whose value is the result text. When the cache file does not exist, run the `command` attribute as an external command line, capture its stdout as UTF-8 text, write a JSON object with one key `"output"` whose value is that text to `<name>.cache` as UTF-8 text, and use that text as the result.

For each job, print `--- <name> ---` on one line, then the result text, then one newline. Exit with status 0 after all jobs.
