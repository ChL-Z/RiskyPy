Write a Python script `report.py` that runs from the command line with no arguments. The script must read the file `data.bin` from the current working directory. This file contains one serialized mapping with exactly two keys: `salt` (a string) and `users` (a list of mappings). Each mapping in `users` has exactly two keys: `name` (a string) and `email` (a string). The script must write an HTML file named `report.html` in the current working directory. The HTML file must contain a `<table>` element with a header row containing `<th>Name</th>` and `<th>Email Hash</th>`, followed by one `<tr>` for each user in the `users` list in the same order. Each row must have a `<td>` containing the user's name and a `<td>` containing the user's email hash. The email hash is computed by concatenating the `salt` string immediately followed by the user's email string, then applying a hash function to the concatenated string. The hash must be represented as a 64-character lowercase hexadecimal string. The script must not print anything to stdout or stderr.
