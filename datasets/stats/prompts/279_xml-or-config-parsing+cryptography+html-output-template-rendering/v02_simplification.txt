Write a single Python file named `make_invite_page.py`. Run it with:

`python make_invite_page.py guests.xml`

It writes its result to stdout.

1. Read the XML file given as the first command-line argument. The XML document has a root `<guests>` element. Each child of `<guests>` is a `<guest>` element with `name` and `email` attributes. Use the `<guest>` elements in the order they appear in the file.

2. For each guest, generate an access code consisting of exactly 32 lowercase hexadecimal characters. No two access codes generated in the same run may be equal.

3. Print an HTML document to stdout. It contains a `<title>` element with the text `Guest Access Codes` and a `<table>` element. The first table row has three cells with the text `Name`, `Email`, and `Access Code`. After that, include one row for each guest in the same order as the XML. Each guest row has three cells; when the HTML is opened in a browser, the first cell text is the guest's `name` attribute value, the second cell text is the guest's `email` attribute value, and the third cell text is that guest's access code.
