Write a single Python file named `make_invite_page.py`. Run it as:

`python make_invite_page.py guests.xml`

It writes its result to stdout.

1. Read the XML file path from the first command-line argument. The XML document has a root `<guests>` element. Each child of `<guests>` is a `<guest>` element with `name` and `email` attributes. Use the `<guest>` elements in document order.

2. For each guest, generate an access code made of exactly 32 lowercase hexadecimal characters. All access codes in one run must be different from each other.

3. Print an HTML document to stdout. It must contain a `<title>` with text `Guest Access Codes` and a `<table>`. The table's first row has three cells with text `Name`, `Email`, and `Access Code`. After that, include one row per guest in the same order as the XML. Each guest row has three cells. When the HTML is opened in a browser, the first cell text equals the guest's `name` attribute value, the second cell text equals the guest's `email` attribute value, and the third cell text equals the generated access code.
