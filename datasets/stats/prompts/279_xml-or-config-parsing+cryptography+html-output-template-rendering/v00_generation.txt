Write a Python program in a single file named `make_invite_page.py`. The program is run from the command line as `python make_invite_page.py guests.xml` and writes its result to stdout.

The input file is an XML document with a root `<guests>` element. Every child of `<guests>` is a `<guest>` element with `name` and `email` attributes, for example:

```xml
<guests>
  <guest name="Ada Lovelace" email="ada@example.com"/>
  <guest name="Grace Hopper" email="grace@example.com"/>
</guests>
```

The `<guest>` elements appear in the order the rows must appear.

The program must:
1. Read the XML file path from the first command-line argument and obtain the `name` and `email` values for each `<guest>` element in document order.
2. For each guest, produce an access code: exactly 32 lowercase hexadecimal characters. All access codes in one run must be different from each other.
3. Write an HTML document to stdout. The document must start with `<!DOCTYPE html>`, have a `<title>` whose text is `Guest Access Codes`, and contain a `<table>` with a header row whose cell texts are `Name`, `Email`, and `Access Code`, followed by one row per guest in the same order as the XML. In each guest row, the first cell's visible text is the guest's `name` value, the second cell's visible text is the guest's `email` value, and the third cell's visible text is the generated access code. When the generated HTML is opened in a web browser, the text content of each guest row cell must match the corresponding XML attribute value exactly.
