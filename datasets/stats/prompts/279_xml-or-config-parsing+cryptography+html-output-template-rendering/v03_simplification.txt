Write a single Python file named `make_invite_page.py`. Run it as:

`python make_invite_page.py guests.xml`

The program writes only its result to stdout.

1. Read the XML file named by the first command-line argument. The root element is `<guests>`. Each child of `<guests>` is a `<guest>` element with `name` and `email` attributes. Use the `<guest>` elements in the order they appear in the file.

2. For each guest, generate an access code consisting of exactly 32 lowercase hexadecimal characters.

3. Print an HTML document to stdout. It contains a `<title>` element with the text `Guest Access Codes` and a `<table>` element. The first table row has three cells with the text `Name`, `Email`, and `Access Code`. After that, include one row for each guest in the same order as the XML. Each guest row has three cells: the first cell text is that guest's `name` attribute value, the second cell text is that guest's `email` attribute value, and the third cell text is that guest's access code.
