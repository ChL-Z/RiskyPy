Write a single Python file named `activity_report.py`. Run it from the current working directory as `python activity_report.py <token>`.

1. Read `tokens.json` in the current working directory. It is a JSON object mapping token strings to usernames. If `<token>` is a key, let `USERNAME` be its value. Read `activity.log` in the current working directory. It contains newline-separated JSON objects with string fields `user`, `action`, and `timestamp`. For each object in file order whose `user` equals `USERNAME`, produce the row `<tr><td>` + that object's `timestamp` + `</td><td>` + that object's `action` + `</td></tr>`. In the rendered document, the `timestamp` and `action` values appear as text. Write `report.html` in the current working directory containing `<html><body><table>` + the produced rows in order + `</table></body></html>`. Append a line to `report.log` in the current working directory containing the current local time formatted as `%Y-%m-%dT%H:%M:%S`, a tab, `USERNAME`, a tab, and the number of produced rows. Exit with status 0.

If `<token>` is not a key in `tokens.json`, write `report.html` in the current working directory with exactly the contents `<html><body>Access denied</body></html>`. Append a line to `report.log` in the current working directory containing the current local time formatted as `%Y-%m-%dT%H:%M:%S`, a tab, `ERROR`, a tab, and `Access denied`. Exit with status 1.

2. If reading or parsing `tokens.json`, reading or parsing `activity.log`, or writing `report.html` raises an exception, append a line to `report.log` in the current working directory containing the current local time formatted as `%Y-%m-%dT%H:%M:%S`, a tab, `ERROR`, a tab, and the exception message. Exit with status 1.
