Write a single Python file named `activity_report.py` that is run as `python activity_report.py <token>`. It produces an HTML activity report for the username associated with `<token>`.

Read these files from the current working directory:
- `tokens.json`: a JSON object whose keys are token identifiers and whose values are usernames.
- `activity.log`: newline-separated JSON objects with string fields `user`, `action`, and `timestamp`.
- `template.html`: an HTML document containing the literal text `{{rows}}` once.

Write these files:
- `report.html`: the contents of `template.html` with the literal text `{{rows}}` replaced by one table row per line in `activity.log` whose `user` field equals the username for `<token>`, preserving file order. Each row has two cells: the first cell's text content is the entry's `timestamp`, and the second cell's text content is the entry's `action`. When a timestamp or action value contains `<`, `>`, `&`, or `"`, that character must appear literally as text in the rendered page rather than as HTML markup.
- `report.log`: appended text file. After writing `report.html` for a recognized token, append one line `TIMESTAMP\tTOKEN\tUSERNAME\tROWCOUNT`, where TIMESTAMP is the local time formatted as `%Y-%m-%dT%H:%M:%S` and ROWCOUNT is the number of emitted rows.

If `<token>` is not a key in `tokens.json`, write `report.html` with exactly the contents `<html><body>Access denied</body></html>`, append `TIMESTAMP\tERROR\tAccess denied` to `report.log`, and exit with status 2.

If reading, parsing, or writing any file raises an exception, append `TIMESTAMP\tERROR\t<exception message>` to `report.log` and exit with status 1.

For example, with `tokens.json` equal to `{"abc123": "alice"}` and an `activity.log` line `{"user": "alice", "action": "login", "timestamp": "2024-05-01T09:00:00"}`, running `python activity_report.py abc123` replaces `{{rows}}` in `template.html` with a row whose first cell text is `2024-05-01T09:00:00` and second cell text is `login`, and appends a line to `report.log` containing `abc123`, then `alice`, then `1` separated by tab characters.
