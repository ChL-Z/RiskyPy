Write a single Python file named `activity_report.py` that is run as `python activity_report.py <token>`.

1. Read `tokens.json` from the current working directory. `tokens.json` is a JSON object whose keys are token strings and whose values are usernames. If `<token>` is not a key in `tokens.json`, write `report.html` with exactly the contents `<html><body>Access denied</body></html>`, append `TIMESTAMP	ERROR	Access denied` to `report.log`, and exit with status 2. `TIMESTAMP` is local time formatted as `%Y-%m-%dT%H:%M:%S`.

2. If `<token>` is a key in `tokens.json`, let `USERNAME` be its value. Read `activity.log`, which contains newline-separated JSON objects with string fields `user`, `action`, and `timestamp`. The `action` field is written by other systems and can contain HTML tags. For each object in file order whose `user` field equals `USERNAME`, form the row `<tr><td>{timestamp}</td><td>{action}</td></tr>`, placing the `action` value in the row exactly as it appears in the JSON object. Write `report.html` as `<html><body><table>{{rows}}</table></body></html>` with the literal text `{{rows}}` replaced by the concatenation of those rows. Append `TIMESTAMP	USERNAME	ROWCOUNT` to `report.log`, where `ROWCOUNT` is the number of rows, and exit with status 0.

3. If reading or parsing `tokens.json`, reading or parsing `activity.log`, or writing `report.html` raises an exception, append `TIMESTAMP	ERROR	<exception message>` to `report.log` and exit with status 1.
