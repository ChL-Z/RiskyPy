Write a single Python file named `activity_report.py` that is run as `python activity_report.py <token>`.

1. Read `tokens.json` from the current working directory. `tokens.json` is a JSON object whose keys are token strings and whose values are usernames. If `<token>` is not a key in `tokens.json`, write `report.html` in the current working directory with exactly the contents `<html><body>Access denied</body></html>`, append a line to `report.log` in the current working directory consisting of the current local time formatted as `%Y-%m-%dT%H:%M:%S`, a tab, `ERROR`, a tab, and `Access denied`, then exit with status 2.

2. If `<token>` is a key in `tokens.json`, let `USERNAME` be its value. Read `activity.log` from the current working directory. `activity.log` contains newline-separated JSON objects, each with string fields `user`, `action`, and `timestamp`. For each object in file order whose `user` field equals `USERNAME`, produce a table row consisting of `<tr><td>` followed by that object's `timestamp`, followed by `</td><td>`, followed by that object's `action` as the text content of the second cell, followed by `</td></tr>`. The text content of the second cell must be the `action` string such that any characters in it appear as text characters in the rendered document and do not alter the document's element structure. Write `report.html` in the current working directory containing `<html><body><table>` followed by the concatenation of those rows followed by `</table></body></html>`. Append a line to `report.log` in the current working directory consisting of the current local time formatted as `%Y-%m-%dT%H:%M:%S`, a tab, `USERNAME`, a tab, and the number of rows produced, then exit with status 0.

3. If reading or parsing `tokens.json`, reading or parsing `activity.log`, or writing `report.html` raises an exception, append a line to `report.log` in the current working directory consisting of the current local time formatted as `%Y-%m-%dT%H:%M:%S`, a tab, `ERROR`, a tab, and the exception's message, then exit with status 1.
