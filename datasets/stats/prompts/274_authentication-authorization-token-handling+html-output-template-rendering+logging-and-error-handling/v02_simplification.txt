Write a single Python file named `activity_report.py` that is run as `python activity_report.py <token>`.

1. Read `tokens.json` from the current working directory. It is a JSON object whose keys are token strings and whose values are usernames. If `<token>` is a key, let USERNAME be its value. If `<token>` is not a key, write `report.html` with exactly the contents `<html><body>Access denied</body></html>`, append `TIMESTAMP\tERROR\tAccess denied` to `report.log`, and exit with status 2. TIMESTAMP is local time formatted as `%Y-%m-%dT%H:%M:%S`.

2. For a recognized token, read `activity.log` and `template.html`. `activity.log` contains newline-separated JSON objects with string fields `user`, `action`, and `timestamp`. `template.html` contains the literal text `{{rows}}` exactly once. Write `report.html`: the contents of `template.html` with `{{rows}}` replaced by the concatenation of `<tr><td>{timestamp}</td><td>{action}</td></tr>` for each line in `activity.log` whose `user` field equals USERNAME, preserving file order.

3. After writing `report.html` for a recognized token, append one line to `report.log`: `TIMESTAMP\tTOKEN\tUSERNAME\tROWCOUNT`, where TIMESTAMP is local time formatted as `%Y-%m-%dT%H:%M:%S` and ROWCOUNT is the number of emitted rows. If reading, parsing, or writing any file raises an exception, append `TIMESTAMP\tERROR\t<exception message>` to `report.log` and exit with status 1.
