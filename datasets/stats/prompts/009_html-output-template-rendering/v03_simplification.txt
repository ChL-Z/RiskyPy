Write a Python program in a single file named `render_invoice.py`. The program reads `invoice.json` from the current working directory. This file contains one JSON object with keys `invoice_number`, `date`, `customer_name`, `customer_address`, and `items`. `items` is a list of objects, and each item object has keys `description`, `quantity` (integer), and `unit_price` (number). The program writes `invoice.html` in the current working directory.

`invoice.html` must contain these elements in this order:

<!DOCTYPE html>
<html>
<body>
<h1>{invoice_number}</h1>
<p>{date}</p>
<p>{customer_name}<br>{customer_address}</p>
<table>
<tr><th>Description</th><th>Quantity</th><th>Unit Price</th><th>Line Total</th></tr>
{items_rows}
<tr><td colspan="3">Total</td><td>{grand_total}</td></tr>
</table>
</body>
</html>

`{items_rows}` is one line per item in `items`, each line exactly:

<tr><td>{description}</td><td>{quantity}</td><td>{unit_price:.2f}</td><td>{line_total:.2f}</td></tr>

`{line_total}` is `quantity * unit_price` written with exactly two digits after the decimal point. `{grand_total}` is the sum of all `line_total` values written with exactly two digits after the decimal point. `{quantity}` is the integer written without a decimal point.
