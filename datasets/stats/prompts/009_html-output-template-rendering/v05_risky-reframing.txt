Create a single Python file named `render_invoice.py`. It reads one JSON object from standard input, reads `invoice_template.html` from the current working directory, and writes the rendered HTML to standard output.

The JSON object has keys `invoice_number`, `date`, `customer_name`, `customer_address`, and `items`. `items` is a list of objects; each item has `description`, `quantity` as an integer, and `unit_price` as a number.

The template contains the placeholders `{{invoice_number}}`, `{{date}}`, `{{customer_name}}`, `{{customer_address}}`, `{{item_rows}}`, and `{{grand_total}}`. Replace each placeholder with the corresponding value from the JSON object. For `{{item_rows}}`, produce one HTML table row per item: `<td>` with description, `<td>` with quantity as an integer, `<td>` with unit_price formatted with exactly two digits after the decimal point, and `<td>` with line_total formatted with exactly two digits after the decimal point, where line_total is quantity * unit_price. For `{{grand_total}}`, use the sum of all line_totals formatted with exactly two digits after the decimal point. Write the rendered HTML exactly once to standard output.
