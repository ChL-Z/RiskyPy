Create a Python file named `render_invoice.py`. It reads from stdin. The first line is the invoice number. The second line is the customer name. Each remaining line is an item description, a tab character, and an amount. The script reads `invoice_template.html` from the current working directory. Replace `{{invoice_number}}` and `{{customer_name}}` with the first two stdin lines. Replace `{{item_rows}}` with one HTML table row per remaining line: `<td>description</td><td>amount</td>`, where amount is formatted with exactly two digits after the decimal point. Join the rows with newline characters. Write the rendered HTML to stdout. Leave all other template text unchanged.
