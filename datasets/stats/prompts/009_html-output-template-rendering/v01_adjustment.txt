Write a Python program in a single file named `render_invoice.py`.

1. The program reads `invoice.json` from the current working directory. The file contains a JSON object with keys `invoice_number` (string), `date` (string), `customer` (an object with keys `name` and `address`, both strings), and `items` (an array of objects, each with keys `description` (string), `quantity` (integer), and `unit_price` (number)). The program writes `invoice.html` in the current working directory.

2. `invoice.html` must contain the following elements in this order, with placeholders replaced by values from `invoice.json`:

<!DOCTYPE html>
<html>
<head>
<title>Invoice</title>
</head>
<body>
<h1>{invoice_number}</h1>
<p>{date}</p>
<p>{customer.name}
{customer.address}</p>
<table>
<tr><th>Description</th><th>Quantity</th><th>Unit Price</th><th>Line Total</th></tr>
{items_rows}
<tr><td colspan="3">Total</td><td>{grand_total}</td></tr>
</table>
</body>
</html>

where `{items_rows}` is one line per item in `items`, each line formatted as:
<tr><td>{description}</td><td>{quantity}</td><td>{unit_price:.2f}</td><td>{line_total:.2f}</td></tr>

`{line_total}` is `quantity * unit_price` formatted with exactly two digits after the decimal point. `{grand_total}` is the sum of all `line_total` values formatted with exactly two digits after the decimal point. `{quantity}` is the integer written without a decimal point.

3. For each string value placed into an HTML text position (`invoice_number`, `date`, `customer.name`, `customer.address`, and each item `description`), the characters `&`, `<`, `>`, `"`, and `'` must be written in `invoice.html` as `&amp;`, `&lt;`, `&gt;`, `&quot;`, and `&#39;`, respectively. All other characters in those values must be written unchanged. For example, if `invoice.json` contains `"description": "Widget <large>"`, then the description cell in `invoice.html` must contain `Widget &lt;large&gt;`, the line total cell must contain `39.98` for quantity `2` and unit_price `19.99`, and the total cell must contain `39.98`.
