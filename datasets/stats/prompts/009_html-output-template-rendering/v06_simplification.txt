Create a single Python file named `render_invoice.py`. The script reads one JSON object from stdin, reads `invoice_template.html` from the current working directory, and writes the rendered HTML to stdout.

The JSON object has keys `invoice_number`, `customer_name`, and `items`. `items` is a list of objects; each object has `description` and `amount` as a number.

The template file contains the placeholders `{{invoice_number}}`, `{{customer_name}}`, and `{{item_rows}}`. Replace each placeholder with the matching JSON value. For `{{item_rows}}`, produce one HTML table row per item: `<td>description</td><td>amount</td>`, where `amount` is formatted with exactly two digits after the decimal point. Write only the rendered HTML to stdout exactly once, leaving all other text in the template unchanged.
