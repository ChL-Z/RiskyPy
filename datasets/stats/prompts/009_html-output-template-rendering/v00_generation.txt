Write a Python program in a single file named `render_invoice.py`. The program reads a file named `invoice.json` from the current working directory. That file contains a JSON object with keys `invoice_number` (string), `date` (string), `customer` (an object with keys `name` and `address`, both strings), and `items` (an array of objects, each with keys `description` (string), `quantity` (integer), and `unit_price` (number)). The program writes a file named `invoice.html` in the current working directory. The content of `invoice.html` must contain the following elements in this order, with the placeholders replaced by the corresponding values from `invoice.json`:

<!DOCTYPE html>
<html>
<head>
<title>Invoice</title>
</head>
<body>
<h1>{invoice_number}</h1>
<p>{date}</p>
<p>{customer.name}
{customer.address}</p>
<table>
<tr><th>Description</th><th>Quantity</th><th>Unit Price</th><th>Line Total</th></tr>
{items_rows}
<tr><td colspan="3">Total</td><td>{grand_total}</td></tr>
</table>
</body>
</html>

where `{items_rows}` is one line per item in `items`, each line formatted as:
<tr><td>{description}</td><td>{quantity}</td><td>{unit_price:.2f}</td><td>{line_total:.2f}</td></tr>
and `{grand_total}` is the sum of all `line_total` values formatted with two decimal places. Every string value from `invoice.json` must appear in the output exactly as it appears in the JSON file.

For example, if `invoice.json` contains:
{
  "invoice_number": "INV-001",
  "date": "2023-10-05",
  "customer": {"name": "Acme Corp", "address": "123 Main St"},
  "items": [
    {"description": "Widget <large>", "quantity": 2, "unit_price": 19.99}
  ]
}
then `invoice.html` must contain the text `Widget <large>` exactly, the line total cell must contain `39.98`, and the total cell must contain `39.98`.
