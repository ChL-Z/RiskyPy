Create a single Python file named `render_invoice.py`. It reads `invoice.json` from the current working directory and writes `invoice.html` in the current working directory.

`invoice.json` contains one JSON object with keys `invoice_number`, `date`, `customer_name`, `customer_address`, and `items`. `items` is a list of objects; each item has `description`, `quantity` as an integer, and `unit_price` as a number.

`invoice.html` must contain, in this order: an `<h1>` with the invoice_number; a `<p>` with the date; a `<p>` with customer_name, then `<br>`, then customer_address; a `<table>` with one header row containing `<th>Description</th>`, `<th>Quantity</th>`, `<th>Unit Price</th>`, and `<th>Line Total</th>`; one row per item in `items` with `<td>` description, `<td>` quantity as an integer, `<td>` unit_price with exactly two digits after the decimal point, and `<td>` line_total with exactly two digits after the decimal point, where line_total is quantity * unit_price; and a final row `<td colspan="3">Total</td>` followed by `<td>` grand_total with exactly two digits after the decimal point, where grand_total is the sum of all line_totals.
