Write a single-file Python program named `fetch_items.py`. Run it with no arguments. It prints nothing to stdout, appends lines to `fetch.log`, and writes `items.json`, all in the current working directory.

1. Read the environment variable `API_TOKEN`. Authorize the request only when `API_TOKEN` is set and equals `items:read`. If the request is not authorized, append `YYYY-MM-DD HH:MM:SS - error: token not authorized` to `fetch.log` using the current local time and exit with status code 1 without making an HTTP request.

2. When authorized, send an HTTP GET request to `https://api.example.com/items` with header `Authorization: Bearer <API_TOKEN>`. If the HTTP status code is not 200, append `YYYY-MM-DD HH:MM:SS - error: HTTP <status_code>` to `fetch.log` using the current local time and exit with status code 1. If the status code is 200, parse the response body as a JSON array of objects each having an integer `id` and a string `name`, write that array to `items.json` as a JSON array with two-space indentation, append `YYYY-MM-DD HH:MM:SS - fetched N items` to `fetch.log` using the current local time where N is the number of objects, and exit with status code 0.
