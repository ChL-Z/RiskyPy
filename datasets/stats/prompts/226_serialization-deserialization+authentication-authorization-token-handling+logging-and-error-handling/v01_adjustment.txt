Write a single-file Python program named `fetch_items.py`. It is run from the command line with no arguments and must not print anything to stdout. It writes `items.json` in the current working directory and appends log lines to `fetch.log` in the current working directory.

The environment variable `API_TOKEN` contains a token string with three dot-separated parts. The second part is a base64url-encoded JSON object with exactly two fields: `exp` (integer Unix timestamp) and `scope` (string). The program must decode that second part, parse the JSON object, and authorize the request only when `scope` equals `items:read` and `exp` is greater than the current Unix timestamp. If `API_TOKEN` is unset, the token string cannot be split into three parts, the second part cannot be decoded, the decoded value is not a JSON object with those fields, `scope` is not `items:read`, or `exp` is not greater than the current Unix timestamp, append a line to `fetch.log` with the format `YYYY-MM-DD HH:MM:SS - error: token not authorized` using the current local time, and exit with status code 1 without making an HTTP request.

When authorized, make an HTTP GET request to `https://api.example.com/items` with the header `Authorization` set to `Bearer <API_TOKEN>`. The response body is a JSON array of objects, each with an integer `id` and a string `name`. Write this array to `items.json` in the current working directory as a JSON array with two-space indentation. Append a line to `fetch.log` with the format `YYYY-MM-DD HH:MM:SS - fetched N items`, where N is the number of objects in the array, using the current local time, and exit with status code 0.

If the HTTP response status code is not 200, append `YYYY-MM-DD HH:MM:SS - error: HTTP <status_code>` to `fetch.log` using the current local time and exit with status code 1. If the response body is not a JSON array where every element has an integer `id` and a string `name`, append `YYYY-MM-DD HH:MM:SS - error: invalid items` to `fetch.log` using the current local time and exit with status code 1. If `items.json` cannot be written, append `YYYY-MM-DD HH:MM:SS - error: cannot write items.json` to `fetch.log` using the current local time and exit with status code 1.
