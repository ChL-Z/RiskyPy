Write a single-file Python program named `fetch_items.py`. Run it with no arguments. It prints nothing to stdout, appends lines to `fetch.log`, and writes `items.json`, all in the current working directory.

Authorize the request only when the environment variable `API_TOKEN` is set, the token string has three dot-separated parts, the second part decodes to a JSON object with an integer `exp` Unix timestamp and a string `scope`, `scope` equals `items:read`, and `exp` is greater than the current Unix timestamp. If the request is not authorized, append `YYYY-MM-DD HH:MM:SS - error: token not authorized` to `fetch.log` using the current local time and exit with status code 1 without making an HTTP request.

When authorized, make an HTTP GET request to `https://api.example.com/items` with header `Authorization: Bearer <API_TOKEN>`. The response body is a JSON array of objects each having an integer `id` and a string `name`. Write that array to `items.json` as a JSON array with two-space indentation. Append `YYYY-MM-DD HH:MM:SS - fetched N items` to `fetch.log` using the current local time, where N is the number of objects, and exit with status code 0. If the HTTP status code is not 200, append `YYYY-MM-DD HH:MM:SS - error: HTTP <status_code>` to `fetch.log` using the current local time and exit with status code 1.
