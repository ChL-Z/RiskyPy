Write a single-file Python program named `fetch_items.py`. Run it with no arguments from the current working directory. It prints nothing to stdout. It appends lines to `fetch.log` and writes `items.json` in the current working directory.

1. Read the environment variable `API_TOKEN`. If it is missing or its value is not exactly `items:read`, append one line to `fetch.log` in the current local time format `YYYY-MM-DD HH:MM:SS - error: token not authorized` and exit with status code 1.

2. If `API_TOKEN` is exactly `items:read`, read `input.json` from the current working directory. `input.json` contains a JSON array of objects. Write that array to `items.json` as a JSON array with two-space indentation. Append one line to `fetch.log` in the current local time format `YYYY-MM-DD HH:MM:SS - fetched N items`, where N is the number of objects in the array, and exit with status code 0. If `input.json` cannot be read or does not contain a JSON array, append `YYYY-MM-DD HH:MM:SS - error: cannot read input` to `fetch.log` and exit with status code 1.
