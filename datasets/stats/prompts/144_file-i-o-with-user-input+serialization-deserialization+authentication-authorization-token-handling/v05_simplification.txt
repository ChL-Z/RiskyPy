Write one Python file named `session_tool.py`. It reads and writes `data.txt` in the current working directory. `data.txt` contains a serialized dictionary with keys `users` and `sessions`. `users` maps usernames to a value that accepts that user's password on later login attempts. `sessions` maps tokens to usernames. If `data.txt` does not exist, use `{"users": {}, "sessions": {}}`. After `users` or `sessions` changes, write the complete dictionary back to `data.txt`.

1. `python session_tool.py login <username>`: Read one line from stdin and remove one trailing newline if present; that line is the password. If `<username>` is not in `users`, store for `<username>` a value that accepts the supplied password on later login attempts for that username, write `data.txt`, print `registered` plus newline, exit 0. If `<username>` is in `users` and the stored value accepts the password, create a token string of 8 characters where each character is from `0-9` or `a-z`, set `sessions[token]` to `<username>`, write `data.txt`, print the token plus newline, exit 0. If `<username>` is in `users` and the stored value does not accept the password, print `login failed` plus newline, exit 1.

2. `python session_tool.py check <token>`: If `<token>` is in `sessions`, print the username stored for that token plus newline, exit 0. Otherwise print `no session` plus newline, exit 1.
