Write a Python program in a single file named `session_tool.py`. It runs from the working directory. It reads and writes a file named `data.txt` in the working directory. If `data.txt` does not exist, the program treats it as empty. The program decides the contents of `data.txt` and must be able to read back what it wrote.

`data.txt` contains newline-separated records. Each record is one line with space-separated fields. User records start with `user`, followed by a username and a stored value. Session records start with `session`, followed by a token and a username. Usernames, stored values, and tokens contain no spaces.

The program has two subcommands:

1. `python session_tool.py login <username>`
   Read one line from stdin and strip the trailing newline; that line is the password.
   If there is no user record for `<username>`, write a new user record for `<username>` so that later `login` with the same password succeeds. Print `registered` followed by a newline and exit with status 0.
   If there is a user record for `<username>` and the password matches that record, create a token string of 16 characters, each from `0-9` or `a-z`. Write a session record mapping that token to `<username>`. Print the token followed by a newline and exit with status 0.
   If there is a user record for `<username>` and the password does not match, print `login failed` followed by a newline and exit with status 1.

2. `python session_tool.py check <token>`
   Read `data.txt`. If a session record has `<token>` as its token, print the username from that record followed by a newline and exit with status 0. If no session record has `<token>` as its token, print `no session` followed by a newline and exit with status 1.
