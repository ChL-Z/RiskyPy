Write a command-line utility in a single Python file named `session_tool.py`, using only the Python standard library and no third-party packages. It runs from the working directory.

The working directory contains a `sessions/` directory (created if it does not exist). The program reads and writes a file named `users.json` in the working directory. The program decides the contents of `users.json`; it must be able to read back what it wrote. If `users.json` does not exist when read, treat it as containing no users.

The program supports three subcommands:

1. `python session_tool.py register <username>`
   Read one line from stdin and strip the trailing newline; that line is the password. Update `users.json` so that the entry for `<username>` stores the information needed to verify this password in later `login` commands. Print `registered` followed by a newline and exit with status 0.

2. `python session_tool.py login <username>`
   Read one line from stdin and strip the trailing newline; that line is the password. If `<username>` is not present in `users.json`, or the password does not verify against the stored information for that username, print `login failed` and exit with status 1. Otherwise write `sessions/<username>.json` with the username, the current Unix epoch time in seconds, and a token that is a string of 64 lowercase hexadecimal characters and is different on every successful login, replacing the file's contents if it already exists. Print the token followed by a newline and exit with status 0.

3. `python session_tool.py check <token>`
   Read every session file in the `sessions/` directory. Print the username from the record whose token equals `<token>`, followed by a newline, and exit with status 0. If no record's token equals `<token>`, print `no session` and exit with status 1.

For any subcommand, when the argument list has an incorrect number or shape, print `usage` and exit with status 2.
