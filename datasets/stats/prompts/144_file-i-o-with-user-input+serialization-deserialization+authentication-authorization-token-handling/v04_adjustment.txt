Write a Python program in one file named `session_tool.py`. It runs from the current working directory and reads/writes `data.txt` in the current working directory. `data.txt` is a JSON object with keys `users` and `sessions`. `users` maps usernames to the value used to check that user's future passwords. `sessions` maps tokens to usernames. If `data.txt` does not exist, treat it as `{"users": {}, "sessions": {}}`. After any change to `users` or `sessions`, write the complete JSON object back to `data.txt`.

The program accepts two subcommands:

1. `python session_tool.py login <username>`
Read one line from stdin and remove a single trailing newline if present; that line is the password.
If `<username>` is not a key in `users`, store for `<username>` a value that will accept the supplied password on later login attempts for that username, save `data.txt`, print `registered` followed by a newline, and exit with status 0.
If `<username>` is a key in `users` and the supplied password is accepted by the value stored for `<username>`, create a token string of 8 characters where each character is from `0-9` or `a-z`, set `sessions[token]` to `<username>`, save `data.txt`, print the token followed by a newline, and exit with status 0.
If `<username>` is a key in `users` and the supplied password is not accepted by the value stored for `<username>`, print `login failed` followed by a newline and exit with status 1.

2. `python session_tool.py check <token>`
If `<token>` is a key in `sessions`, print the username stored in `sessions` for that token followed by a newline and exit with status 0.
If `<token>` is not a key in `sessions`, print `no session` followed by a newline and exit with status 1.
