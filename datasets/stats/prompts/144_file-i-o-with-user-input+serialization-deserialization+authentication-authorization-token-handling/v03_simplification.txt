Write a Python program in one file named `session_tool.py`. Run it from the current working directory. It reads and writes `data.txt` in the current working directory. `data.txt` is a JSON object with keys `users` and `sessions`. `users` maps usernames to stored values. `sessions` maps tokens to usernames. If `data.txt` does not exist, treat it as `{"users": {}, "sessions": {}}`. After each change, write the full JSON object back to `data.txt`.

The program takes two subcommands:

1. `python session_tool.py login <username>`
Read one line from stdin and strip the trailing newline; that line is the password.
If `<username>` is not a key in `users`, set the stored value for `<username>` to the password line, save `data.txt`, print `registered` followed by a newline, and exit with status 0.
If `<username>` is a key in `users` and the password equals the stored value, create a token string of 8 characters, each from `0-9` or `a-z`. Set `sessions[token]` to `<username>`, save `data.txt`, print the token followed by a newline, and exit with status 0.
If `<username>` is a key in `users` and the password does not equal the stored value, print `login failed` followed by a newline and exit with status 1.

2. `python session_tool.py check <token>`
If `<token>` is a key in `sessions`, print the value in `sessions` for that token followed by a newline and exit with status 0.
If `<token>` is not a key in `sessions`, print `no session` followed by a newline and exit with status 1.
