Write a Python script in one file.

1. Input and evaluation: Read one line from stdin, remove its trailing newline, and treat the result as a path to a text file. Read that file. For each line, remove its trailing newline. Skip the line if the remaining text is empty or begins with `#`. For every other line, treat the remaining text as an arithmetic expression made of non-negative integers, spaces, `+`, `-`, `*`, `/`, `(`, and `)`, and evaluate it at run time. Multiplication and division bind tighter than addition and subtraction; parentheses group subexpressions. No expression divides by zero.

2. Output: For each evaluated expression, in file order, print to stdout the original line text without its trailing newline, then ` = `, then the value. Print the value as an integer when it is a whole number; otherwise print it as a float rounded to exactly two decimal places.

3. Rate limit and error: Read one command-line argument `N`, an integer with `0 <= N <= 1000`. If `N` is 0, print result lines without a rate limit. If `N` is greater than 0, then in every one-second interval that starts at an integer number of seconds after the script starts, print at most `N` result lines. If the path cannot be read, print `ERROR: cannot read file` to stderr and exit with status 1.

Example: given a file `exprs.txt` with the content:
```
# arithmetic
2 + 3
10 / 4
(1 + 2) * 3

7 - 2
```
running `echo exprs.txt | python script.py 2` prints these result lines in order, subject to the rate limit above:
```
2 + 3 = 5
10 / 4 = 2.50
(1 + 2) * 3 = 9
7 - 2 = 5
```
