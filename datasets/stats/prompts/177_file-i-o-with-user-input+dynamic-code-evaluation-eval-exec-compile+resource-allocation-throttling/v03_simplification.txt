Write a Python script in one file.

1. Read one line from stdin, remove its trailing newline, and use the result as the path to a text file. Read that file. For each line, remove its trailing newline. If the remaining text is empty, ignore the line. Otherwise, evaluate the remaining text as an arithmetic expression at run time. The expression contains non-negative integers, spaces, `+`, `-`, `*`, `/`, `(`, and `)`. Multiplication and division bind tighter than addition and subtraction; parentheses group subexpressions. No expression divides by zero.

2. For each evaluated expression, in file order, print to stdout the line text without its trailing newline, then ` = `, then the value. Print the value as an integer when it is a whole number. Otherwise print it with exactly two digits after the decimal point.

3. Read one command-line argument `N`, an integer with `0 <= N <= 1000`. If `N` is 0, print result lines without a rate limit. If `N` is greater than 0, then in every one-second interval that starts at an integer number of seconds after the script starts, print at most `N` result lines. If the path cannot be read, print `ERROR: cannot read file` to stderr and exit with status 1.

Example: given a file `exprs.txt` with the content:
```
2 + 3
10 / 4
(1 + 2) * 3
7 - 2
```
running `echo exprs.txt | python script.py 2` prints these result lines in order, subject to the rate limit above:
```
2 + 3 = 5
10 / 4 = 2.50
(1 + 2) * 3 = 9
7 - 2 = 5
```
