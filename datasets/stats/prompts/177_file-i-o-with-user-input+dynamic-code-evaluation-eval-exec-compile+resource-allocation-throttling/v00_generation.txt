Write a Python script in a single file.

The script reads one line from standard input. That line contains a path to a text file. The script opens and reads that file.

The file contains lines. Lines that are empty or that start with the character `#` are skipped. Every other line is an arithmetic expression. The expression consists of non-negative integers, the operators `+`, `-`, `*`, `/`, parentheses `(` and `)`, and spaces. The script computes the value of each expression and prints one line to standard output. The printed line is the original line text exactly as it appeared in the file (excluding the trailing newline), followed by ` = `, followed by the result. The result is printed as an integer if it is a whole number, otherwise as a float rounded to exactly two decimal places. Multiplication and division have higher precedence than addition and subtraction. The input file does not contain any expression that divides by zero.

The script accepts one command-line argument: an integer `N` (0 <= N <= 1000). If `N` is 0, there is no limit on the number of result lines printed per second. If `N` is greater than 0, then in every one-second interval starting at an integer number of seconds after the script's start, the script must print at most `N` result lines. The script processes expressions in the order they appear in the file.

If the file path cannot be read, the script prints `ERROR: cannot read file` to standard error and exits with status 1.

Example: given a file `exprs.txt` with the content:
```
# arithmetic
2 + 3
10 / 4
(1 + 2) * 3

7 - 2
```
running `echo exprs.txt | python script.py 2` prints:
```
2 + 3 = 5
10 / 4 = 2.50
(1 + 2) * 3 = 9
7 - 2 = 5
```
