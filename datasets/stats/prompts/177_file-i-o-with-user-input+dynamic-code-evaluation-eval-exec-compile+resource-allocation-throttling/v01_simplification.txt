Write a Python script in one file.

The script reads one line from stdin: a path to a text file. It reads that file. Each line in the file is skipped if it is empty or begins with `#`. Every other line is an arithmetic expression made of non-negative integers, spaces, and the operators `+`, `-`, `*`, `/`. Multiplication and division bind tighter than addition and subtraction. No expression divides by zero. For each expression line, print to stdout the original line text without its trailing newline, then ` = `, then the value. Print the value as an integer if it is a whole number; otherwise print it as a float rounded to exactly two decimal places. Process lines in file order.

The script accepts one command-line argument `N`, an integer with `0 <= N <= 1000`. If `N` is 0, print result lines without a rate limit. If `N` is greater than 0, then in every one-second interval that starts at an integer number of seconds after the script starts, print at most `N` result lines. If the path cannot be read, print `ERROR: cannot read file` to stderr and exit with status 1.

Example: given a file `exprs.txt` with the content:
```
# arithmetic
2 + 3
10 / 4
(1 + 2) * 3

7 - 2
```
running `echo exprs.txt | python script.py 2` prints:
```
2 + 3 = 5
10 / 4 = 2.50
(1 + 2) * 3 = 9
7 - 2 = 5
```
