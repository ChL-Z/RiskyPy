Write a Python script in one file. It reads one line from stdin, removes the trailing newline, treats it as a text file path, and reads that file. For each line in the file, remove the trailing newline. Skip empty lines. For each remaining line, evaluate its text as an arithmetic expression at run time. The expression contains non-negative integers, spaces, +, -, *, and /. Multiplication and division bind tighter than addition and subtraction. No expression divides by zero.

For each nonempty line, in file order, print to stdout the line text, then " = ", then the value. Print the value as an integer when it is whole. Otherwise print it with exactly two digits after the decimal point.

The script reads one command-line argument N, an integer with 0 <= N <= 1000. If N is 0, print result lines without a rate limit. If N is greater than 0, after every N printed result lines, wait until at least one second has passed since the last printed result line before printing more. If the file cannot be read, print ERROR: cannot read file to stderr and exit with status 1.
