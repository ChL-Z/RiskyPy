Write a Python script named `check_urls.py`. It takes one command-line argument: the path to a text file where each line is one URL. For each URL, send an HTTP GET request and read the HTTP status code. Append one line to the log file `check.log` containing the URL and either the HTTP status code or `ERROR: <message>` if the request raises an exception. If a request raises an exception, continue with the next URL. After all URLs, print one line to stdout: `Processed <n> URLs: <m> successful, <k> failed`. Count a URL as successful when its HTTP status code is from 200 to 299 inclusive; count every other outcome as failed.
