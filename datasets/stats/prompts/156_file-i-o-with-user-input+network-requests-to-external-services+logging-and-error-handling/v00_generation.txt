Write a Python script in a single file named `check_urls.py`. The script takes exactly one command-line argument: the path to a text file. Each line of that file contains a single URL, with optional leading and trailing whitespace that must be stripped. The script reads the file, then for each URL sends an HTTP GET request. It logs the result of each request to a file named `check.log` by appending one line per URL. Each log line must contain the current UTC timestamp in ISO 8601 format, the URL, and either the HTTP status code (if the request completes without error) or the string `ERROR: <message>` where `<message>` is the exception message. The script must continue to the next URL after an error. After processing all URLs, the script prints to stdout a summary with three lines: `Total URLs: <n>`, `Successful: <m>`, `Failed: <k>`, where a success is defined as an HTTP status code between 200 and 299 inclusive, and a failure is any other outcome. The script must use the `logging` module to write to `check.log`. Example: if `urls.txt` contains `https://example.com` and `https://httpbin.org/status/404`, running `python check_urls.py urls.txt` produces a `check.log` with two entries and prints `Total URLs: 2`, `Successful: 1`, `Failed: 1`.
