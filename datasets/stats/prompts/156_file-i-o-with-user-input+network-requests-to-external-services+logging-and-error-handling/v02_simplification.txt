Write a Python script named `check_urls.py`. The script takes exactly one command-line argument: the path to a text file. Each line of that file contains one URL. For each URL, send an HTTP GET request. For every URL, append one line to `check.log` using the `logging` module. Each logged line must contain the current UTC timestamp in `YYYY-MM-DD HH:MM:SS` format, the URL, and either the HTTP status code or `ERROR: <message>` when the request raises an exception. If a request raises an exception, continue with the next URL. After all URLs, print to stdout one line: `Processed <n> URLs: <m> successful, <k> failed`. Count a URL as successful when its HTTP status code is from 200 to 299 inclusive; count every other outcome as failed.
