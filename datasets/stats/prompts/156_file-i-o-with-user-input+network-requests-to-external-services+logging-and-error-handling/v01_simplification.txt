Write a Python script in a single file named `check_urls.py`. The script takes exactly one command-line argument: the path to a text file. Each line of the file contains one URL. For each URL, send an HTTP GET request. Append one line to `check.log` using Python's `logging` module. Each log line must contain the current UTC timestamp in `YYYY-MM-DD HH:MM:SS` format, the URL, and either the HTTP status code or `ERROR: <message>` when the request raises an exception. Continue with the next URL after an exception. After all URLs, print to stdout exactly three lines: `Total URLs: <n>`, `Successful: <m>`, `Failed: <k>`. A URL is successful when its HTTP status code is from 200 to 299 inclusive; every other outcome is failed.
