Write a Python program in a single file named `feed_aggregator.py`.

Read `feeds.xml` from the current working directory. The file is XML. Its root element contains `<feed>` child elements. Each `<feed>` element has a `url` attribute containing an absolute `http` or `https` URL. Process the `<feed>` elements in document order.

For each feed, perform these steps sequentially:
- Send one HTTP GET request to the feed URL and read the response body.
- Parse the response body as XML. Locate every `<item>` or `<entry>` element that is a descendant of the response root. For each such element, locate its direct child `<title>`. Assume each `<title>` element contains only text. Print to stdout one line in the format `<feed_url>|<title_text>`, where `<title_text>` is the text content of the `<title>` element.
- If the request or XML parsing fails for that feed, skip that feed and continue with the next feed.

The program must start no more than 5 HTTP GET requests in any 1000-millisecond interval. It must have at most 1 HTTP GET request in flight at a time. Before starting a request, if either limit would be exceeded, wait until the request can start.
