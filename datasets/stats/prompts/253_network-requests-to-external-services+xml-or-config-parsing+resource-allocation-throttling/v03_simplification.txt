Write a Python program in a single file named `feed_aggregator.py`.

Read `feeds.xml` from the current working directory. The file is XML. Its root element contains `<feed>` child elements. Each `<feed>` element has a `url` attribute containing an absolute `http` or `https` URL. Process the `<feed>` elements in document order.

For each feed URL, do these steps in sequence:
1. Send one HTTP GET request to the URL and read the response body.
2. Parse the response body as XML. Find every `<item>` element that is a descendant of the XML root. Each `<item>` has a direct child `<title>`. Print one line to stdout in the format `<feed_url>|<title_text>`, where `<title_text>` is the text content of that `<title>` element.

If the request fails or the response XML cannot be parsed for a feed, skip that feed and continue with the next feed.

The program must start at most 5 HTTP GET requests in any 1000-millisecond interval. It must have at most 1 HTTP GET request in flight at a time. Before starting a request, if either limit would be exceeded, wait until the request can start.
