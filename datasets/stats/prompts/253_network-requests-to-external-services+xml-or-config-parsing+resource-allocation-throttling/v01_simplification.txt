Write a Python program in a single file named `feed_aggregator.py`. The program reads `feeds.xml` from the current working directory. The file contains `<feed>` elements, each with a `url` attribute. Process the feeds in the order they appear in the file.

For each feed, fetch the URL, parse the response body as XML, and for every `<item>` or `<entry>` element under the response root, find its direct child `<title>` element. Print each title to stdout in the format `<feed_url>|<title_text>`, one line per title. If fetching or parsing fails for a feed, skip that feed and continue with the next feed.

The program must start no more than 5 requests in any 1-second interval and must never have more than 2 requests in flight at the same time. If a limit would be exceeded, wait until the request can be started.
