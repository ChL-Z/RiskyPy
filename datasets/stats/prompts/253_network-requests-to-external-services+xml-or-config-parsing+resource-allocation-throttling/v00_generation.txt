Write a Python program in a single file named `feed_aggregator.py`. The program reads an XML configuration file named `feeds.xml` from the current working directory. The configuration file contains one or more `<feed>` elements, each with a `url` attribute. For each `<feed>` element, in the order they appear in the file, the program must:

- Fetch the URL.
- Parse the response body as XML.
- For every `<item>` or `<entry>` element, find its direct child `<title>` element and collect the text content of that title.

After processing all feeds, print each collected title to stdout, one per line, in the format `<feed_url>|<title_text>`. If fetching or parsing a feed fails, write a line to stderr in the format `ERROR <feed_url>: <error_message>` and continue with the next feed.

The program must enforce two limits on network requests: at most 2 requests may be in flight at the same time, and no more than 5 requests may be started within any 1-second interval. A request is considered in flight from the moment it is started until its response body has been fully read.

For example, if `feeds.xml` contains:

```xml
<feeds>
  <feed url="https://example.com/feed1.xml" />
  <feed url="https://example.com/feed2.xml" />
</feeds>
```

and the first feed returns XML with two `<item>` elements having titles "First" and "Second", and the second feed returns XML with one `<entry>` having title "Third", the program prints:

```
https://example.com/feed1.xml|First
https://example.com/feed1.xml|Second
https://example.com/feed2.xml|Third
```
