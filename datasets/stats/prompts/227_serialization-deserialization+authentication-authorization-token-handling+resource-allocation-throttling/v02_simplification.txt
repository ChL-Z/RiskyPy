Write a single Python file `quota_runner.py`, invoked as `python quota_runner.py`.

1. Read the first line from stdin as `current_token`. Read `accounts.json` from the current working directory. `accounts.json` is a JSON object mapping owner name strings to token strings. Let `current_owner` be the owner name whose token string equals `current_token`. If no such owner exists, print `Unknown token` to stderr and exit with status 1. Read `tasks.json` from the current working directory. `tasks.json` is a JSON array of objects, each with an `owner` string and a `command` list of strings. Process tasks in array order, but only tasks whose `owner` equals `current_owner`. Skip all other tasks without printing anything.

2. Before running a matching task, count the timestamps for `current_owner` in `state.json` that are greater than or equal to the current time in float seconds since the epoch minus 60. If the count is 5 or more, print `Rate limit exceeded for <current_owner>` to stdout and skip the task. Otherwise, run the task's `command` list as an executable with its arguments, print `Ran <command joined by single spaces> for <current_owner>` to stdout, and append the current time in float seconds since the epoch to the list of timestamps for `current_owner` in the state.

3. Read `state.json` from the current working directory at startup if it exists; otherwise start with an empty JSON object. `state.json` is a JSON object mapping owner name strings to arrays of numbers (UNIX timestamps). After all tasks have been processed, remove from every owner's array all timestamps less than the current time in float seconds since the epoch minus 60, then write the state to `state.json` in the current working directory.
