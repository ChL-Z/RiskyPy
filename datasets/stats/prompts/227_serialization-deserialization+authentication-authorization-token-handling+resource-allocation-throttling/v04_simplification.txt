Write a single Python file named `quota_runner.py`. Running `python quota_runner.py` performs the following steps:

1. Read the first line from stdin as `current_token`. Read `accounts.json` in the current working directory. It is a JSON object whose keys are owner name strings and whose values are token verifier records. Determine the owner whose record verifies `current_token`. If no record verifies it, or if more than one record verifies it, print `Unknown token` to stderr and exit with status 1. Otherwise set `current_owner` to that owner name. Read `tasks.json` in the current working directory. It is a JSON array of objects. Each object has an `owner` string and a `command` list of strings.

2. Read `state.json` in the current working directory if it exists; otherwise use an empty JSON object. `state.json` is a JSON object mapping owner name strings to arrays of numbers. Process the tasks from `tasks.json` in array order. For each task whose `owner` equals `current_owner`:
   - Let `now` be the current time in float seconds since the epoch. Count the timestamps in the array for `current_owner` that are greater than or equal to `now - 60`.
   - If the count is 5 or more, print `Rate limit exceeded for <current_owner>` to stdout and skip the task.
   - Otherwise, run the task's `command` list as an executable with its arguments, print `Ran <command joined by single spaces> for <current_owner>` to stdout, and append `now` to the array for `current_owner`.
   Skip all tasks whose `owner` does not equal `current_owner` without printing anything.

3. After all tasks have been processed, remove from every owner's array in the state all timestamps less than the current time in float seconds since the epoch minus 60. Write the resulting JSON object to `state.json` in the current working directory.
