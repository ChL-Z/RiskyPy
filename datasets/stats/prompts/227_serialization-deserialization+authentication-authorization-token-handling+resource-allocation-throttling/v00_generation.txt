Write a Python script `quota_runner.py` that processes a list of tasks for a shared build server. The script is invoked as `python quota_runner.py <token>`. It reads `tokens.json` from the current working directory, which contains a JSON object mapping tokens (strings) to owner names (strings). It reads `tasks.json` from the current working directory, which contains a JSON array of task objects. Each task object has an `owner` key (string) and a `command` key (a list of strings representing an executable and its arguments). The script also reads and writes `state.json` in the current working directory.

First requirement: The script must authenticate the provided token by looking it up in `tokens.json`. If the token is not present, print `Unknown token` to stderr and exit with status 1. Otherwise, let `current_owner` be the owner name associated with the token. The script must process only tasks whose `owner` equals `current_owner`, in the order they appear in `tasks.json`, skipping all others without printing anything. For each such task, it must enforce a rate limit of at most 5 tasks within any 60-second window per owner. To do this, before running a task, count how many timestamps for `current_owner` in the state are greater than or equal to the current time (as a float in seconds since the epoch) minus 60. If that count is 5 or more, print `Rate limit exceeded for <current_owner>` and skip the task. Otherwise, run the command (the list of strings), print `Ran <command joined by spaces> for <current_owner>`, and append the current time to the list of timestamps for `current_owner` in the state.

Second requirement: The script must maintain `state.json` as a JSON object where each key is an owner name and each value is a list of numbers (UNIX timestamps). If `state.json` exists, load it at startup; otherwise start with an empty object. After processing all tasks, remove from each owner's list all timestamps that are less than the current time minus 60, then write the state back to `state.json`.

Example: If `tokens.json` contains `{"abc123": "alice"}` and `tasks.json` contains `[{"owner": "alice", "command": ["echo", "hello"]}, {"owner": "bob", "command": ["ls"]}]`, running `python quota_runner.py abc123` prints `Ran echo hello for alice` and writes `state.json` containing an entry for `alice` with the current timestamp. The task for `bob` is skipped.
