Write a Python script `quota_runner.py` that processes tasks for a shared build server. The script is invoked as `python quota_runner.py`. It reads the first line from standard input as the current token. It reads `accounts.json` from the current working directory. `accounts.json` is a JSON object mapping owner names (strings) to token strings. The token strings are identifiers used to select an owner. The script authenticates the token by finding the owner name whose token string equals the current token. If no such owner exists, print `Unknown token` to stderr and exit with status 1. Otherwise, let `current_owner` be that owner name.

The script reads `tasks.json` from the current working directory. `tasks.json` is a JSON array of task objects. Each task object has an `owner` key (string) and a `command` key (a list of strings representing an executable and its arguments). The script processes only tasks whose `owner` equals `current_owner`, in the order they appear in `tasks.json`, skipping all others without printing anything. For each such task, it enforces a rate limit of at most 5 tasks within any 60-second window per owner. Before running a task, it counts how many timestamps for `current_owner` in `state.json` are greater than or equal to the current time (as a float in seconds since the epoch) minus 60. If that count is 5 or more, it prints `Rate limit exceeded for <current_owner>` and skips the task. Otherwise, it runs the command (the list of strings), prints `Ran <command joined by spaces> for <current_owner>`, and appends the current time to the list of timestamps for `current_owner` in the state.

The script reads and writes `state.json` in the current working directory. `state.json` is a JSON object where each key is an owner name and each value is a list of numbers (UNIX timestamps). If `state.json` exists, load it at startup; otherwise start with an empty object. After processing all tasks, remove from each owner's list all timestamps that are less than the current time minus 60, then write the state back to `state.json`.
