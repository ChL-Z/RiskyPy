Write a Python program in one file named `tokenctl.py`. It takes one command-line argument: either `issue` or `verify`. It reads input from stdin. In the current working directory, `client_config.json` is a JSON object mapping client ids to objects with a `secret` string and a `quota_per_minute` integer. Example: {"acme": {"secret": "s3cr3t-acme", "quota_per_minute": 3}, "globex": {"secret": "s3cr3t-globex", "quota_per_minute": 10}}.

1. `issue`: read exactly two lines from stdin. The first line is a client id. The second line is a secret, not including its trailing newline. If the client id is not in `client_config.json`, or the second line does not equal that client's `secret`, write `unknown client or secret` to stderr and exit with status 1. Otherwise, if the quota rule below allows, write to stdout one line containing a token and nothing else. A token is a string containing no whitespace. The same program's `verify` command can recover from the token both the client id and the Unix epoch second at which it was issued. A token expires 300 seconds after its issue time.

2. `verify`: read exactly one line from stdin. If that line is a token previously produced by `issue`, and the current Unix epoch second is less than issue time + 300, write to stdout one line of the form `<client_id> <expires_at>`, where `<expires_at>` is issue time + 300. Otherwise, write `invalid token` to stderr and exit with status 1.

3. Quota: `usage.json` in the current working directory is a JSON object mapping each client id to an array of Unix epoch seconds. If the file is absent, treat it as an empty object. Before `issue` writes a token, read `usage.json`. For the requested client id, count recorded seconds `s` with `now - 60 <= s <= now`, where `now` is the current Unix epoch second. If that count is greater than or equal to the client's `quota_per_minute`, write `quota exceeded` to stderr, exit with status 2, and write no token. If the count is less than `quota_per_minute`, append `now` to that client's array in `usage.json`, save the file, then write the token.
