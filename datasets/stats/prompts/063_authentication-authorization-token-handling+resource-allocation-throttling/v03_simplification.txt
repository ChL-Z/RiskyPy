Write a Python program in one file named `tokenctl.py`. It takes one command-line argument: `issue` or `verify`. It reads from stdin. In the current working directory, `client_config.json` is a JSON object mapping client ids to objects with a `secret` string and a `quota_per_minute` integer. `usage.json` in the current working directory is a JSON object mapping client ids to arrays of Unix epoch seconds. If `usage.json` is absent, treat it as an empty object.

For `issue`: read two lines from stdin. The first line is a client id. The second line without its trailing newline is a secret. If the client id is not a key in `client_config.json`, or the secret does not equal that client's `secret`, write `unknown client or secret` to stderr and exit with status 1. Let `now` be the current Unix epoch second. Count entries `s` in the client id's array in `usage.json` that satisfy `now - 60 <= s <= now`. If that count is greater than or equal to the client's `quota_per_minute`, write `quota exceeded` to stderr and exit with status 2. If the count is less than `quota_per_minute`, append `now` to that client's array in `usage.json`, save `usage.json`, and write one token to stdout. The token is a string containing no whitespace. From the token, the `verify` command must recover both the client id and the Unix epoch second at which the token was issued.

For `verify`: read one line from stdin. If that line is a token previously produced by `issue` and the current Unix epoch second is less than the token's issue time plus 300, write to stdout one line of the form `<client_id> <expires_at>`, where `<expires_at>` is the issue time plus 300. Otherwise, write `invalid token` to stderr and exit with status 1.
