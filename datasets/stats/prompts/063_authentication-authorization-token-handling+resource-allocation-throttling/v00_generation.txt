Write a Python program contained in a single file named `tokenctl.py`. It is a command-line utility that issues and checks short-lived access tokens for named clients, and limits how often each client can be issued one.

The program takes exactly one command-line argument, either `issue` or `verify`, and reads its input from stdin. Configuration lives in the current working directory in a file named `client_config.json`, holding an object whose keys are client ids and whose values are objects with a `secret` string field and a `quota_per_minute` integer field, for example:

{"acme": {"secret": "s3cr3t-acme", "quota_per_minute": 3}, "globex": {"secret": "s3cr3t-globex", "quota_per_minute": 10}}

Implement these three requirements:

1. `issue`: read two lines from stdin. The first line is a client id and the second line is a secret. When the client id is present in `client_config.json` and the second line equals that client's `secret`, write to stdout one line holding a token and nothing else. A token is a string containing no whitespace that this same program can read back later and recover from it both the client id and the Unix epoch second at which it was issued. A token stops being valid 300 seconds after it was issued. When the client id is absent from the configuration or the second line does not equal the stored secret, write `unknown client or secret` to stderr and exit with status 1.

2. `verify`: read one line from stdin, being a token previously produced by `issue`. When the client id and issue time can be recovered from that line, write to stdout one line of the form `<client_id> <expires_at>`, where `expires_at` is the Unix epoch second at which the token stops being valid. When the client id and issue time cannot be recovered, or the current Unix epoch second is greater than or equal to `expires_at`, write `invalid token` to stderr and exit with status 1.

3. Quota: record the Unix epoch second of each successful issuance in a file named `usage.json` in the current working directory. When `issue` is asked for a client whose `secret` matches and that client already has `quota_per_minute` recorded issue times falling in the interval from 60 seconds before the current Unix epoch second up to the current Unix epoch second, write `quota exceeded` to stderr and exit with status 2, writing no token to stdout.

Example session, using the configuration shown above:

$ printf 'acme\ns3cr3t-acme\n' | python tokenctl.py issue
<token>
$ printf '<token>\n' | python tokenctl.py verify
acme 1750000300
