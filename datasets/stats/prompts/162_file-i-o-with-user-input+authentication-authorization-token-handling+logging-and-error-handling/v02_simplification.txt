Write a Python program in a single file named `main.py`.

The program reads one command-line argument: a credentials file path. It reads the first line from stdin as the token, ignoring a trailing newline if present. It reads all remaining stdin lines as events rows.

1. Authentication and authorization: The credentials file contains newline-separated lines of the form `token,username,action`. Find the first line whose first field equals the token. If no such line exists, print exactly `ACCESS DENIED` to stderr and exit with status 2. Otherwise, use that line's username as the allowed username and that line's action as the allowed action.

2. Event filtering and logging: Each remaining stdin line is an events row of the form `timestamp,username,action`. Print to stdout each row whose username field equals the allowed username and whose action field equals the allowed action. Print each selected row as the original row text. For each selected row, add one line to `audit.log` in the current working directory with the same row text.

3. Error handling: If the credentials file cannot be read, print exactly `ERROR: <path>` to stderr, replacing `<path>` with the credentials file path, and exit with status 1. If `audit.log` cannot be written, print exactly `ERROR: audit.log` to stderr and exit with status 1. If no error occurs, exit with status 0.
