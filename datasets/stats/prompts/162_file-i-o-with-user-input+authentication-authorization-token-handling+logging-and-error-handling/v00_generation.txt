Write a Python program in a single file named `main.py`. The program reads three command-line arguments in this order: a credentials file path, an events CSV file path, and an audit file path. It reads one access token from stdin as a single line, removing the trailing newline if present. The credentials file contains newline-separated lines of the form `token,username,action1|action2|action3`; the first line whose first field equals the provided token establishes the username and the list of allowed actions. The events CSV file contains newline-separated rows of the form `timestamp,username,action,detail`.

1. Print to stdout every row from the events CSV file whose `username` field equals the token's username and whose `action` field appears in the token's allowed actions. Each printed row must be the original row text without adding or removing fields.
2. For every printed row, append a line to the audit file in the form `timestamp,username,action` using the values from that row.
3. If the token line is empty or does not match any line in the credentials file, print exactly `ACCESS DENIED` to stderr and exit with status 2. If any required file cannot be read or written, print `ERROR: <path>` to stderr, replacing `<path>` with the path of the file that could not be read or written, and exit with status 1. If no error occurs, exit with status 0.

Usage example: `credentials.txt` contains `abc123,alice,read|export`. `events.csv` contains `2024-05-01T10:00:00Z,alice,read,file1` and `2024-05-01T10:01:00Z,bob,read,file2`. Running `python main.py credentials.txt events.csv audit.log` and typing `abc123` followed by Enter prints the first row and appends `2024-05-01T10:00:00Z,alice,read` to `audit.log`.
