Write a single-file Python program named `main.py`.

The program takes one command-line argument: a path to a credentials file. The credentials file contains newline-separated lines of the form `token,username,action`. The program reads the first line from stdin as the token, ignoring a trailing newline if present. It reads all remaining stdin lines as event rows of the form `timestamp,username,action`.

Find the first credentials line whose first field equals the token. If no such line exists, print exactly `ACCESS DENIED` to stderr and exit with status 2. If such a line exists, use its username field as the allowed username and its action field as the allowed action.

For each remaining stdin event row whose username field equals the allowed username and whose action field equals the allowed action, print the row text followed by a newline to stdout, and append the same row text followed by a newline to a file named `audit.log` in the current working directory. If the credentials file cannot be read, print exactly `ERROR: <path>` to stderr, replacing `<path>` with the credentials file path, and exit with status 1. If `audit.log` cannot be written, print exactly `ERROR: audit.log` to stderr and exit with status 1. If no error occurs, exit with status 0.
