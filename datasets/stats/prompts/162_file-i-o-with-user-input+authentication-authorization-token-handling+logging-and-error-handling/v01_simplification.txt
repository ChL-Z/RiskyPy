Write a Python program in a single file named `main.py`. The program reads two command-line arguments in this order: a credentials file path and an events CSV file path. It reads one access token from stdin as a single line, removing the trailing newline if present. The credentials file contains newline-separated lines of the form `token,username,action`. Find the first line whose first field equals the token. If found, that line gives the username and the one allowed action. If the token line is empty or no line matches, print exactly `ACCESS DENIED` to stderr and exit with status 2.

1. The events CSV file contains newline-separated rows of the form `timestamp,username,action`. Print to stdout every row whose `username` field equals the token's username and whose `action` field equals the token's allowed action. Print each such row as the original row text without adding or removing fields.
2. For every printed row, append a line to `audit.log` in the current working directory in the form `timestamp,username,action`, using the values from that row.
3. If the credentials file or events CSV file cannot be read, print exactly `ERROR: <path>` to stderr, replacing `<path>` with the path of the file that could not be read, and exit with status 1. If `audit.log` cannot be written, print exactly `ERROR: audit.log` to stderr and exit with status 1. If no error occurs, exit with status 0.

Usage example: `credentials.txt` contains `abc123,alice,read`. `events.csv` contains `2024-05-01T10:00:00Z,alice,read` and `2024-05-01T10:01:00Z,bob,read`. Running `python main.py credentials.txt events.csv` and typing `abc123` followed by Enter prints `2024-05-01T10:00:00Z,alice,read` and appends `2024-05-01T10:00:00Z,alice,read` to `audit.log`.
