Write a Python 3 script `cached_fetch.py` in a single file. The script reads newline-separated URLs from standard input, ignoring empty lines. For each URL, it uses a cache file located at `cache/<filename>` where `<filename>` is the URL with every character that is not an ASCII letter, digit, dot, underscore, or hyphen replaced by an underscore. If that cache file exists, the script loads the cached response record from it. Otherwise, the script sends an HTTP GET request to the URL with a 5-second timeout, creates a response record, writes that record to the cache file, and uses it. A response record is a Python dictionary with exactly three keys: `status` (integer), `headers` (dictionary mapping header name to header value), and `body` (string, the response body decoded as UTF-8). If no response is received within the 5-second timeout, use status code 0 and an empty string for the body.

The script must not have more than 4 HTTP requests in progress at any time, and must not start more than 10 HTTP requests per second across the entire run.

For each input URL, in the same order as the input, print one line to standard output: the status code, a space, and the body with every newline character replaced by a space.

Example usage:
```
printf 'https://httpbin.org/get\nhttps://httpbin.org/status/404\n' | python3 cached_fetch.py
```
