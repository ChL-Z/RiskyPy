Write a single-file Python 3 script `cached_fetch.py`. It reads newline-separated URLs from standard input and ignores empty lines. For the Nth non-empty URL, the cache file is `cache/N` (for example, the first URL uses `cache/1`).

1. If that cache file exists, load the response record from it. Otherwise, send an HTTP GET request to the URL with a 5-second timeout, create a response record, write that record to the cache file, and use it. Create the `cache` directory if it does not exist. A response record has exactly two keys: `status` (integer) and `body` (string, the response body decoded as UTF-8). If no response is received within the 5-second timeout, use status code 0 and an empty string for the body.

2. Never have more than 4 HTTP requests in progress at any time. Start HTTP requests at most once every 0.1 seconds across the entire run.

3. For each input URL, in the same order as the input, print one line to standard output: the status code, one space, and the body with every newline character replaced by a space.
