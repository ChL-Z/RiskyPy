Write a single-file Python 3 script `cached_fetch.py`. It reads newline-separated URLs from standard input and ignores empty lines. For the Nth non-empty URL, the cache file is `cache/N` (for example, the first URL uses `cache/1`).

1. If that cache file exists, read the status code and body from it. Otherwise, send an HTTP GET request to the URL with a 5-second timeout, create the `cache` directory if it does not exist, write the status code and body to the cache file, and use them. The body is the response body decoded as UTF-8. If no response is received within 5 seconds, use status code 0 and an empty string for the body.

2. Never have more than 4 HTTP requests in progress at any time.

3. For each input URL, in the same order as the input, print one line to standard output: the status code, one space, and the body with every newline character replaced by a space.
