Write a single-file Python 3 script `cached_fetch.py`.

It reads newline-separated URLs from standard input and ignores empty lines. For each non-empty URL, the cache file path is `cache/N`, where N is its 1-based position among non-empty URLs (the first non-empty URL uses `cache/1`).

1. For each URL, if its cache file exists, read the status code and body from it. Otherwise, send an HTTP GET request to the URL with a 5-second timeout. If a response is received, use its status code and its body decoded as UTF-8. If no response is received within 5 seconds, use status code 0 and an empty body. Write the status code and body to the cache file, creating the `cache` directory first if needed. The cache file contains the status code as decimal digits on the first line, then a newline, then the body encoded as UTF-8.

2. At most 4 HTTP requests may be in progress at any time.

3. For each input URL, in the same order as the input, print one line to standard output: the status code, one space, and the body with every newline character replaced by a space.
