Write a Python program in a file named `renderer.py`. It takes one command-line argument: a path to an XML file. The XML file has one root element `<calc>` containing one or more `<field>` elements. Each `<field>` has a `name` attribute. The text of a `<field>` is an arithmetic expression containing decimal numbers, the operators `+`, `-`, `*`, `/`, and variable names made of letters `a`-`z` and `A`-`Z`.

The program reads zero or more lines from stdin. Ignore lines containing only whitespace. Each other line has the form `name=value`, where `name` is a variable name and `value` is a decimal number that may start with `-` and may contain a `.`. Every variable name used in any `<field>` expression is provided by a line on stdin. For each `<field>` in the order it appears in the XML file, print one line to stdout: `name=result`, where `name` is the field's `name` attribute and `result` is the value of the field's arithmetic expression using the values read from stdin.
