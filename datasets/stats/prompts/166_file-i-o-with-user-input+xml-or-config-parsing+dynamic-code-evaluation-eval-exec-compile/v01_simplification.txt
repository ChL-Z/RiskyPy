Write a Python program in a single file named `renderer.py`. The program takes one command-line argument: the path to an XML file. It reads zero or more lines from stdin. Each non-empty line has the form `key=value`, where `key` is one or more letters (`a`–`z`, `A`–`Z`) and `value` is a decimal number that may start with `-` and may contain a `.`. Lines containing only whitespace are ignored.

The XML file has one root element `<calc>` containing one or more `<field>` elements. Each `<field>` has a `name` attribute. The text of a `<field>` is an arithmetic expression using numeric literals, parentheses, the operators `+`, `-`, `*`, `/`, and identifiers that match keys from stdin.

For each `<field>` in the order it appears in the file, print one line to stdout: `name=value`, where `name` is the field's `name` attribute and `value` is the result of computing the expression using the values read from stdin. If an expression uses an identifier that was not read from stdin, print `name=error` for that field and continue with the remaining fields.
