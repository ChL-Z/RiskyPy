Write a Python file named `renderer.py`. It takes one command-line argument: the path to an XML file. The XML file has one root element `<calc>` containing one or more `<field>` elements. Each `<field>` has a `name` attribute. The text of a `<field>` is an arithmetic expression containing decimal numbers, the operators `+`, `-`, `*`, `/`, and identifiers made of letters `a`–`z` and `A`–`Z`.

The program reads zero or more lines from stdin. Each non-empty line has the form `name=value`, where `name` is one or more letters and `value` is a decimal number that may start with `-` and may contain a `.`. Lines containing only whitespace are ignored. Every identifier used in any `<field>` expression is provided by a line on stdin.

For each `<field>` in the order it appears in the XML file, print one line to stdout: `name=result`, where `name` is the field's `name` attribute and `result` is the value of the field's expression using the values read from stdin.
