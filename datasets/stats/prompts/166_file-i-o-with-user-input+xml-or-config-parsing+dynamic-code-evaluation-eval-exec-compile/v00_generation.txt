Write a Python program contained in a single file named `renderer.py`. The program computes named fields from an XML configuration file using values supplied on standard input.

The program accepts one command-line argument: the path to an XML file. Standard input contains zero or more lines, each of the form `key=value`, terminated by a newline. `key` consists of one or more letters (`a`–`z`, `A`–`Z`). `value` is a decimal number that may begin with `-` and may contain a `.`. Lines that are empty or contain only whitespace are ignored. Example standard input:

```
w=3
h=4.5
```

The XML file has a single root element `<calc>` containing one or more `<field>` elements. Each `<field>` has a `name` attribute whose value is a non-empty string. The text content of a `<field>` element is an arithmetic expression that may contain numeric literals, parentheses `(` and `)`, the operators `+`, `-`, `*`, `/`, and identifiers that match the keys read from standard input. For each `<field>` element in the order it appears in the file, the program prints one line to standard output of the form `name=value`, where `name` is the value of the element's `name` attribute and `value` is the result of computing the arithmetic expression using the values read from standard input. A result with no fractional part is printed without a decimal point; any other result is printed with at most six digits after the decimal point, with trailing zeros removed. If a `<field>` expression references a key that was not provided on standard input, the program prints `name=error` for that field and continues with the remaining fields.

Example: given `calc.xml` containing

```xml
<calc>
  <field name="area">w * h</field>
  <field name="perimeter">2 * (w + h)</field>
</calc>
```

and standard input

```
w=3
h=4.5
```

the program prints

```
area=13.5
perimeter=15
```
