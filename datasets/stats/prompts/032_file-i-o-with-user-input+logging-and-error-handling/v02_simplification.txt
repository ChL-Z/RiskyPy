Write a single-file Python program named `linereport.py`. It takes no command-line arguments and reads all input from stdin. The first line of stdin is a search term. The second line is the path of a text log file. Each remaining line is a path to a text file.

1. For each path after the first two lines, in the order they appear on stdin, read that text file and count how many lines contain the search term as a substring, comparing characters exactly and case-sensitively. A trailing newline at the end of the file does not create an extra empty line to count.

2. Append one line to the log file for each processed path, in the same order. Each appended line must have exactly three fields separated by single spaces and end with a newline: the status `OK` or `FAIL`, the path exactly as it appeared on stdin, and the matching line count as a decimal integer. Use `-1` as the count for `FAIL`. Create the log file if it does not exist, and append to it if it does. When a path cannot be read, record `FAIL` for that path and continue with the remaining paths instead of stopping.

3. After all paths have been processed, print exactly one line to stdout in the form `<ok> processed, <fail> failed`, where `<ok>` and `<fail>` are decimal integers for the number of paths with status `OK` and `FAIL`. Exit with status code 0 when `<fail>` is 0, and status code 1 otherwise. Do not print anything else to stdout.
