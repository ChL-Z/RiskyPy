Write a Python program in a single file named `linereport.py`. It takes no command-line arguments and reads all input from stdin. The first stdin line is a search term. The second stdin line is the path of a log file. Each remaining stdin line is a path to a UTF-8 text file.

For each remaining path, in the order it appears on stdin, read that UTF-8 text file and count how many lines contain the search term as an exact, case-sensitive substring. A trailing newline at the end of the file does not create an extra empty line to count.

For each remaining path, in the same order, append to the log file the string formed by `<STATUS>`, a space, `<path>`, a space, `<detail>`, and a newline. Use `OK` for `<STATUS>` when the text file was read, and `FAIL` when it could not be read. `<path>` is the path exactly as it appeared on stdin. `<detail>` is the matching line count as a decimal integer for `OK`, or the exception text produced by the failed read attempt for `FAIL`. Create the log file if it does not exist, and append to it if it does. If a path cannot be read, append its `FAIL` entry and continue with the remaining paths without raising an unhandled exception.
