Write a single Python file `linereport.py`. The program reads lines from standard input, removing the trailing newline from each line. The first line is a search term. Each later line is a file path. For each path, read the file as UTF-8 text and count the lines that contain the search term as a substring. Append one line to `linereport.log` for each path, followed by a newline: `OK <path> <count>` when the file is read, or `FAIL <path> <exception message>` when reading the file raises an exception. After writing a `FAIL` line, continue with the remaining paths.
