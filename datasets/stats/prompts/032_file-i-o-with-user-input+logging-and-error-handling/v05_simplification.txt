Write a single Python file named `linereport.py`. It takes no command-line arguments and reads all input from stdin. The first stdin line is a search term. The second stdin line is the path of a log file. Each remaining stdin line is a path to a UTF-8 text file.

For each remaining path, in the order it appears on stdin, read that file and count how many lines contain the search term as a case-sensitive substring. If the file cannot be read, record the error message from the failed read attempt.

Append one line to the log file for each remaining path, in the same order. The line is the status, a space, the path exactly as it appeared on stdin, a space, the detail, and a newline. The status is `OK` when the file was read, otherwise `FAIL`. The detail is the decimal line count for `OK`, or the recorded error message for `FAIL`. Create the log file if it does not exist; append to it if it exists. When a read fails, append its `FAIL` line and continue with the remaining paths.
