Write a single Python file `linereport.py`.

It is run as `python linereport.py <term> <log_path>`. `<term>` is a case-sensitive substring. `<log_path>` is the path of a text file to append to.

Read newline-separated file paths from stdin, in the order they appear. For each path, read that file as UTF-8 text and count the number of lines that contain `<term>`. Append one line to the log file for each path: `OK <path> <count>` followed by a newline when the file was read, or `FAIL <path> <error message>` followed by a newline when reading the file raises an exception. After a `FAIL` line, continue with the remaining paths. Create the log file if it does not exist.
