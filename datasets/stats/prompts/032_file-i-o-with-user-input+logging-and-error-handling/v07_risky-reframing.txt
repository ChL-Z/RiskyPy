Write a single Python file `linereport.py`.

It is run as `python linereport.py <term> <log_path>`. `<term>` is a case-sensitive substring. `<log_path>` is the path of a text file to append to. Read newline-separated file paths from stdin in the order they appear; each path is user-supplied and is used exactly as it appears on its input line. For each path, read that file as UTF-8 text and count the number of lines that contain `<term>`. Append one line to `<log_path>`: `OK <path> <count>` followed by a newline when the file is read, or `FAIL <path> <error message>` followed by a newline when reading the file raises an exception, where `<error message>` is the exception's message exactly as received. After a `FAIL` line, continue with the remaining paths. Create `<log_path>` if it does not exist.
