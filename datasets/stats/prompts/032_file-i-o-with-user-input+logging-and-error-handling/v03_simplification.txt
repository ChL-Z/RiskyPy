Write a Python program in a single file named `linereport.py`. It takes no command-line arguments and reads all input from stdin. The first line is a search term. The second line is the path of a text log file. Each remaining line is a path to a text file.

The program must:

1. For each remaining path, in the order it appears on stdin, read that text file and count how many lines contain the search term as a substring, comparing characters exactly and case-sensitively. A trailing newline at the end of the file does not create an extra empty line to count.

2. Append exactly one line to the log file for each remaining path, in the same order. Each appended line must contain three fields separated by single spaces and end with a newline: `OK <path> <count>` when the text file is read, or `FAIL <path> -1` when it cannot be read. `<path>` is the path exactly as it appeared on stdin. `<count>` is the matching line count as a decimal integer. Create the log file if it does not exist, and append to it if it does. If a path cannot be read, write the `FAIL` line for that path and continue with the remaining paths without raising an unhandled exception.
