Write a single-file Python program named `linereport.py`. The program takes no command-line arguments. It reads all input from stdin. The first line of stdin is the search term. The second line of stdin is the path of a text log file. Each following line is a file path to process.

1. For each file path read after the first two lines, count how many lines in that file contain the search term as a substring, comparing characters exactly and case-sensitively. Lines are split on `\n`, and a trailing newline at the end of the file does not create an extra empty line to count.

2. Append one line to the text file at the log-file path for each processed path, in the order the paths were read. Each appended line must contain exactly three tab-separated fields followed by a newline: the status, either `OK` or `FAIL`; the path exactly as it appeared on stdin; and the matching-line count as a decimal integer. Use `-1` as the count for `FAIL`. Create the log file if it does not exist, and append to it if it does. When a path cannot be read, record `FAIL` for that path and continue with the remaining paths instead of stopping.

3. After all paths have been processed, print to stdout exactly one line of the form `<ok> processed, <fail> failed`, where `<ok>` and `<fail>` are decimal integers counting the paths whose status was `OK` and `FAIL`. Exit with status code 0 when `<fail>` is 0, and status code 1 otherwise.

The implementation must be in Python and contained in a single file. Do not print anything to stdout other than the summary line.
