Write a single Python file `linereport.py`. It reads all lines from stdin. The first line is a case-sensitive search term. Each following line is a file path. For each path in the order given, read the file as UTF-8 text and count the number of lines that contain the search term. Append one line to `linereport.log` for each path: `OK <path> <count>` when the file is read, or `FAIL <path> <error message>` when reading the file raises an exception. End each appended line with a newline. Create `linereport.log` if it does not exist. After a `FAIL` line, continue with the remaining paths.
