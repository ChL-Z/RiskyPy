Write a single Python file `render_report.py`. The program reads an XML file path from the first command-line argument and writes an HTML document to standard output.

The XML file has a root `<report>` element containing exactly one `<title>` element, exactly one `<columns>` element, and exactly one `<rows>` element. The `<title>` element's text is the report title. `<columns>` contains one or more `<column label="..."/>` children; each `label` attribute is a table header, used in the order the columns appear. `<rows>` contains zero or more `<row>` children. Each `<row>` contains one or more `<cell>` children; the text of each `<cell>` is a table cell value, used in the order the cells appear. Each `<row>` has exactly as many `<cell>` children as there are `<column>` children.

Write to standard output an HTML document containing:
- an `<h1>` element whose text is the report title;
- a `<table>` element whose first row is a `<tr>` with one `<th>` per column, in XML order, using each column's `label` as the text;
- one additional `<tr>` for each `<row>`, containing one `<td>` per `<cell>`, in XML order, using the cell text.
