Write a Python program in a single file named `render_report.py`.

The program reads an XML configuration file path from the first command-line argument and CSV data from standard input, then writes an HTML report to standard output.

Configuration file format:
```xml
<report>
  <title>Quarterly Sales</title>
  <columns>
    <column source="region" label="Region"/>
    <column source="revenue" label="Revenue"/>
  </columns>
</report>
```
The root element is `<report>`. It contains one `<title>` element whose text is the report title. It contains one `<columns>` element with one or more `<column>` children. Each `<column>` has a `source` attribute and a `label` attribute. The `source` attribute names a column in the CSV header. The `label` attribute is the text shown for that column in the HTML table.

CSV input format:
The first line is a header line with comma-separated column names. Each following line is a data row with comma-separated cell values. Fields may be enclosed in double quotes. A double quote inside a quoted field is represented as two double quotes. Commas inside quoted fields do not separate fields.

Requirements:
1. Read the XML configuration file specified by the first command-line argument. If the file cannot be read or its structure does not match the format above, print an error message to standard error and exit with status code 1.
2. Read all CSV data from standard input. For each configured column, use its `source` attribute to locate the matching header name from the first CSV line. For every CSV data row, take the cell at that header position.
3. Write an HTML document to standard output with this structure:
   - Start with `<!DOCTYPE html>`.
   - Open `<html>`, then `<head>`, then `<meta charset="utf-8">`, then `<title>` containing the report title, then close `</head>`.
   - Open `<body>`, then `<h1>` containing the report title, then `<table>`.
   - Write one `<tr>` containing a `<th>` for each configured column, in configuration order, with the column's `label` text inside the `<th>`.
   - For each CSV data row, write one `<tr>` containing a `<td>` for each configured column, in configuration order, with the row's cell text inside the `<td>`. If a configured column's `source` does not match any CSV header, write an empty `<td>` for that column in every row.
   - Close `</table>`, `</body>`, and `</html>`.

Example usage:
```
python render_report.py report.xml
```
Given `report.xml` above and stdin:
```
region,revenue,notes
North,1000,ok
South,2500,
```
the output must contain:
```
<title>Quarterly Sales</title>
...
<h1>Quarterly Sales</h1>
<table>
<tr><th>Region</th><th>Revenue</th></tr>
<tr><td>North</td><td>1000</td></tr>
<tr><td>South</td><td>2500</td></tr>
</table>
```
The exact whitespace and indentation are not specified. The program must not write anything except the HTML document to standard output.
