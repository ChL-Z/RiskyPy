Write a single Python file `render_report.py` that does exactly this:

- Reads an XML configuration file path from the first command-line argument. The XML must have root `<report>` containing one `<title>...</title>` element and one `<columns>` element with one or more `<column source="name" label="text"/>` children. If the file cannot be read or this structure is absent, write `invalid config` to standard error and exit with code 1.
- Reads CSV from standard input. The first line is a comma-separated header. Each later line is a comma-separated data row. Fields are not quoted.
- Writes an HTML document to standard output. The document starts with `<!DOCTYPE html>` and contains `<html><head><meta charset="utf-8"><title>TITLE</title></head><body><h1>TITLE</h1><table>`, where `TITLE` is the text inside the configuration `<title>` element. Then write one `<tr>` with a `<th>LABEL</th>` for each configured column in configuration order, where `LABEL` is the column's `label` attribute. Then for each CSV data row, write one `<tr>` with a `<td>` for each configured column in configuration order: the CSV cell whose header matches the column's `source` attribute, or an empty string if no header matches. Close with `</table></body></html>`. Do not write anything else to standard output.
