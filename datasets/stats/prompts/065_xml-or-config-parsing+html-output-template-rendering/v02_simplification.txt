Write a single Python file `render_report.py`. The program reads an XML configuration file path from the first command-line argument, reads CSV from standard input, and writes an HTML document to standard output.

The XML file has a root `<report>` element containing one `<title>` element and one `<columns>` element. The `<columns>` element contains one or more `<column name="..." label="..."/>` children. The `<title>` text and each column's `name` and `label` attribute are read from the file.

Standard input begins with a comma-separated header line, followed by zero or more comma-separated data lines. Fields are not quoted.

Standard output is an HTML document containing an `<h1>` element whose text is the configuration title, followed by a `<table>` element. The table's first row is a `<tr>` containing one `<th>` per configured column, in configuration order, with that column's `label` as the text. Each CSV data line produces one `<tr>` containing one `<td>` per configured column, in configuration order. A `<td>` contains the CSV field whose header equals that column's `name`, or an empty string if no header matches.
