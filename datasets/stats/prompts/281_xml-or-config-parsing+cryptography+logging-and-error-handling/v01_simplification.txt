Write a Python program in one file named `config_lookup.py`.

The program takes two command-line arguments: an XML configuration file path and a key name. The XML file has a root element `<config>` with zero or more `<entry key="..." value="..."/>` children. If the file cannot be opened or parsed, write `ERROR cannot read config` to stderr and exit with status 2.

Look up the key in the `<entry>` elements. If found, write one line to stdout with three tab-separated fields: the key, the matching `value` attribute, and a 16-character lowercase hexadecimal fingerprint of the UTF-8 bytes of `key + "\x00" + value`. If not found, write one line to stdout with three tab-separated fields: the key, `MISSING`, and `-`.

For each lookup, write one line to stderr using UTC time in `YYYY-MM-DDTHH:MM:SSZ` format: `INFO key=<key> result=found` when found, or `WARN key=<key> result=missing` when not found.
