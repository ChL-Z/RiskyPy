Write a Python program in one file named `config_lookup.py`.

The program reads an XML configuration file path from `sys.argv[1]`, then reads newline-separated key names from stdin until EOF. The XML file has a root element `<config>` with zero or more `<entry key="..." value="..."/>` child elements, and each `key` attribute appears at most once. For each input key, the program writes exactly one line to stdout with three tab-separated fields: the key, the matching `value` attribute, and a fingerprint. If there is no matching `<entry>`, the second field is `MISSING` and the third field is `-`. The fingerprint field is 16 lowercase hexadecimal characters computed from the UTF-8 bytes of `key + "\x00" + value`. The program writes exactly one line to stderr for each input key using UTC time in the format `YYYY-MM-DDTHH:MM:SSZ`: `INFO key=<key> result=found` for a match, or `WARN key=<key> result=missing` for no match. If the XML file cannot be opened or parsed, the program writes `ERROR cannot read config` to stderr and exits with status 2.

Example: `config.xml` contains:
```xml
<config>
  <entry key="api_host" value="db.internal"/>
  <entry key="retries" value="3"/>
</config>
```
Running `python config_lookup.py config.xml` and entering:
```
api_host
timeout
```
writes to stdout:
```
api_host	db.internal	a1b2c3d4e5f60718
timeout	MISSING	-
```
and writes to stderr:
```
2026-01-01T00:00:00Z INFO key=api_host result=found
2026-01-01T00:00:00Z WARN key=timeout result=missing
```
