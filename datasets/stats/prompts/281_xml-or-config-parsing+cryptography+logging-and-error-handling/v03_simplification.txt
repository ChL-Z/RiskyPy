Write a single Python file `config_lookup.py`.

It reads exactly two command-line arguments: the path to an XML configuration file, and a key name. The XML root element is `<config>` and it contains zero or more `<entry key="..." value="..."/>` child elements. If the file cannot be opened or cannot be parsed as XML, write the line `ERROR cannot read config` to stderr and exit with status 2.

Look up the key name among the `<entry>` elements by matching the `key` attribute. Write exactly one line to stdout with three tab-separated fields. If an entry matches, the fields are the key name, the matching `value` attribute, and a 16-character lowercase hexadecimal fingerprint derived deterministically from the key name and the value (the same key name and value must always produce the same fingerprint). If no entry matches, the fields are the key name, `MISSING`, and `-`.

For the lookup, write exactly one line to stderr with a UTC timestamp in `YYYY-MM-DDTHH:MM:SSZ` format: `INFO key=<key> result=found` when an entry matched, or `WARN key=<key> result=missing` when no entry matched.
