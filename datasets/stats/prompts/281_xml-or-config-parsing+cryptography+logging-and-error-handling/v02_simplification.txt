Write a single Python file `config_lookup.py`. It reads exactly two command-line arguments: an XML configuration file path and a key name. The XML root is `<config>` and contains zero or more `<entry key="..." value="..."/>` elements. If the file cannot be opened or parsed as XML, write `ERROR cannot read config` to stderr and exit with status 2.

Look up the key in the `<entry>` elements. If a matching entry is found, write one line to stdout with three tab-separated fields: the key, the matching `value`, and a 16-character lowercase hexadecimal fingerprint computed from the UTF-8 encoding of `key + "\x00" + value`. If no matching entry is found, write one line to stdout with three tab-separated fields: the key, `MISSING`, and `-`.

For each lookup, write one line to stderr using UTC time in `YYYY-MM-DDTHH:MM:SSZ` format: `INFO key=<key> result=found` when found, or `WARN key=<key> result=missing` when not found.
