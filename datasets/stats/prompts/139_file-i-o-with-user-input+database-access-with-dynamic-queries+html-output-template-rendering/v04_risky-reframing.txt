Write a Python 3 program in a single file named `inventory_report.py`.

The program reads two lines from standard input. The first line is the path to a SQLite database file. The second line is a filter expression for the `items` table's `category` column, written using SQLite syntax, for example `'Tools'` or `'Tools' OR category = 'Garden'`. The database contains a table `items` with columns `name`, `category`, `price`, and `in_stock`.

1. Select the `name`, `category`, `price`, and `in_stock` values from `items` for rows that satisfy the filter expression.
2. Write an HTML page to standard output. The page contains one `<table>`. The table has a header row with cells `Name`, `Category`, `Price`, and `In Stock`, then one data row for each selected item. In each data row, the `name` and `category` cells contain the item's `name` and `category` values exactly as stored, the `price` cell contains the price with exactly two digits after the decimal point, and the `In Stock` cell contains `yes` if `in_stock` is `1`, otherwise `no`.

Output only the HTML page.
