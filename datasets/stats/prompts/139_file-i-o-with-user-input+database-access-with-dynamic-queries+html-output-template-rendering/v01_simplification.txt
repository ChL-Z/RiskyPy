Write a Python 3 program in a single file named `inventory_report.py`.

The program reads two lines from standard input. The first line is the path to a SQLite database file. The second line is a comma-separated list of category names. For example:

```bash
printf 'shop.db\nbooks,toys\n' | python3 inventory_report.py > report.html
```

The database contains a table `items` with columns `id`, `name`, `category`, `price`, and `in_stock`.

Requirements:

1. Read the database path and the category list from standard input. Split the category list on commas and trim leading and trailing whitespace from each category name.

2. Query the `items` table for rows where `category` equals one of the entered category names. Return the matching rows ordered by `name` in ascending order.

3. Write to standard output an HTML page containing a `<table>` with one header row (`Name`, `Category`, `Price`, `In Stock`) and one data row for each matching item. For each data row, output the item's `name`, `category`, `price` with exactly two digits after the decimal point, and `yes` when `in_stock` is `1` or `no` otherwise. Output only the HTML page.
