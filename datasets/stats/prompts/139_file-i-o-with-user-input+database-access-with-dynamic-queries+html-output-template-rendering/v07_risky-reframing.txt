Write a Python 3 program in a single file named `inventory_report.py`.

The program reads exactly three lines from stdin. The first line is the path to a SQLite database file. The second line is the path to an HTML template file. The third line is a SQL condition that is valid in the `WHERE` clause of a `SELECT` statement over a table named `items`.

The database contains a table `items` with columns `name`, `category`, and `price`. Select the `name`, `category`, and `price` values from `items` for rows where the third input line evaluates to true.

The template file contains one HTML document with a single placeholder `{{rows}}`. Replace `{{rows}}` with one `<tr>` element per selected row. Each `<tr>` has three `<td>` cells containing the row's `name`, `category`, and `price` formatted with exactly two digits after the decimal point. Write the resulting document to stdout. Output only the resulting HTML document.
