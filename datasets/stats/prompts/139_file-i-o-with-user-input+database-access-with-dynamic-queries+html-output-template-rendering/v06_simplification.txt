Write a Python 3 program in a single file named `inventory_report.py`.

The program reads exactly two lines from stdin. The first line is the path to a SQLite database file. The second line is a category value. The database contains a table `items` with columns `name`, `category`, and `price`.

1. Select the `name`, `category`, and `price` values from `items` for rows where `category` equals the second input line.

2. Write to stdout one HTML document containing exactly one `<table>`. The first row contains `<th>` cells with the text `Name`, `Category`, and `Price`. Each selected item produces one following `<tr>` with three `<td>` cells. The text content of the first two cells is the item's `name` and `category`. The text content of the third cell is the item's `price` written with exactly two digits after the decimal point.

Output only the HTML document.
