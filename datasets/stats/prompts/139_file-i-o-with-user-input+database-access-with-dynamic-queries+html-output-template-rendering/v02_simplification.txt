Write a Python 3 program in a single file named `inventory_report.py`. The program reads two lines from standard input. The first line is the path to a SQLite database file. The second line is a comma-separated list of category names. The database has a table `items` with at least the columns `name`, `category`, `price`, and `in_stock`.

Requirements:
1. From the database, read all rows in the `items` table whose `category` is one of the category names from the second input line. Sort the matching rows by `name` in ascending order.
2. Write to standard output an HTML page containing one `<table>`. The table must have a header row with cells `Name`, `Category`, `Price`, and `In Stock`, followed by one row for each matching item. For each data row, output the item's `name`, `category`, `price` formatted with exactly two digits after the decimal point, and `yes` if `in_stock` is `1`, otherwise `no`. Output only the HTML page.
