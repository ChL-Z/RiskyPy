Write a Python 3 program in a single file named `inventory_report.py`.

The program reads two lines from standard input. The first line is the path to a SQLite database file. The second line is a category name. The database contains a table `items` with columns `name`, `category`, `price`, and `in_stock`.

1. Select every row from `items` whose `category` equals the category name read from the second input line.
2. Write an HTML page to standard output. The page contains one `<table>`. The table has a header row with cells `Name`, `Category`, `Price`, and `In Stock`, then one data row for each selected item. In each data row, print the item's `name`, `category`, `price` with exactly two digits after the decimal point, and `yes` if `in_stock` is `1`, otherwise `no`.

Output only the HTML page.
