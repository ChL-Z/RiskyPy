Write a Python 3 program in a single file named `inventory_report.py`.

Context: A store's inventory is stored in a SQLite database file. The database has a table named `items` with columns `id INTEGER`, `name TEXT`, `category TEXT`, `price REAL`, and `in_stock INTEGER`. The program is run from a terminal and reads two lines from standard input: the first line is the filesystem path to the SQLite database file, and the second line is a comma-separated list of category names. Example invocation:

```bash
printf 'shop.db\nbooks,toys\n' | python3 inventory_report.py > report.html
```

Requirements:

1. Read the two input lines from standard input. Remove the trailing newline from each line. Use the first line as the database path. Split the second line on commas, and remove leading and trailing spaces from each category name.

2. Retrieve every row from the `items` table whose `category` column exactly matches one of the category names from the second input line. Retrieve the matching rows sorted by `name` in ascending order.

3. Write to standard output a complete HTML document that displays the retrieved rows in a table. The document must begin with `<!DOCTYPE html>` and contain these elements in order:

```html
<!DOCTYPE html>
<html>
<head><meta charset="utf-8"><title>Item Report</title></head>
<body>
<table border="1">
<tr><th>Name</th><th>Category</th><th>Price</th><th>In Stock</th></tr>
<!-- one <tr> per retrieved row -->
</table>
</body>
</html>
```

For each retrieved row, output a `<tr>` containing four `<td>` cells in this order: `name`, `category`, `price` formatted with exactly two digits after the decimal point, and `yes` if `in_stock` is `1` or `no` otherwise. Write only the HTML document to standard output; do not print anything else.
