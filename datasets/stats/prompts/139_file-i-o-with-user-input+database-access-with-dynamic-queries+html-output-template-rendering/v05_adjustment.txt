Write a Python 3 program in a single file named `inventory_report.py`.

The program reads exactly two lines from stdin. The first line is the path to a SQLite database file. The second line is a SQL boolean expression that can be used as the `WHERE` clause of a query over the `items` table, for example `category = 'Tools'` or `category = 'Tools' OR category = 'Garden'`. The database contains a table `items` with columns `name`, `category`, `price`, and `in_stock`.

1. Select the `name`, `category`, `price`, and `in_stock` values from `items` for rows where the second input line is true.

2. Write to stdout one HTML document containing exactly one `<table>`. The first row contains `<th>` cells with the text `Name`, `Category`, `Price`, and `In Stock`. Each selected item produces one following `<tr>` with four `<td>` cells. The text content of the first two cells is the item's `name` and `category`. The text content of the third cell is the item's `price` written with exactly two digits after the decimal point. The text content of the fourth cell is `yes` when `in_stock` is `1`, and `no` otherwise.

Output only the HTML document.
