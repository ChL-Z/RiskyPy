Create a single-file Python program named `filtered_export.py`. The program accepts one command-line argument: the path to a YAML configuration file. That configuration file has two keys: `webhook_url` (a string URL) and `filters` (a list of objects, each with `column` and `value` strings). The program must read the configuration file, open the SQLite database file `contacts.db` in the current working directory, and select all columns from the `contacts` table for rows where every filter matches: for each filter, the value in the column named by `column` equals the filter's `value`. Filters combine with AND. The selected rows must be represented as a JSON array of objects, using the database column names as object keys. The program must send that JSON array as the body of an HTTP POST request to `webhook_url` with the `Content-Type` header set to `application/json`, then print the integer HTTP status code returned by the request.

Usage example: `python filtered_export.py config.yaml`, where `config.yaml` contains:

```yaml
webhook_url: https://example.com/hooks/contacts
filters:
  - column: country
    value: US
  - column: status
    value: active
```

If `contacts.db` has a `contacts` table with columns `id`, `name`, `country`, and `status`, the program posts a JSON array containing every row where `country` is `US` and `status` is `active`.
