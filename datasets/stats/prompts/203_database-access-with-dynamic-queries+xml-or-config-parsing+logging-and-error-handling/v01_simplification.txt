Write a Python program in a single file named `export_report.py`. It is run as:

`python export_report.py <config.xml> <output.csv>`

The config file is XML with this structure:

```xml
<report>
  <database path="sales.db" />
  <table name="orders" columns="order_id,customer,amount" />
</report>
```

The `path` attribute is a file path to a database in SQLite format. The `name` attribute is a table name. The `columns` attribute is a comma-separated list of column names.

1. Read the config file. Query the database for all rows from the named table, selecting only the listed columns. Write the result to `output.csv` as comma-separated values: the first line is the column names in the order given, followed by one line per database row.

2. Write one line to standard error for each of these events, in the format `YYYY-MM-DD HH:MM:SS [LEVEL] message`:
   - before reading the config: message contains `config`
   - before querying the database: message contains `query`
   - after writing the CSV: message contains `done`
   If an exception occurs, write one line with `LEVEL` `ERROR` and the exception text as the message, then exit with status code 1. After writing the CSV and the finish log line without an exception, exit with status code 0.
