Write a Python program in a single file named `export_report.py`. It is invoked as:

`python export_report.py <config.xml> <output.csv>`

The configuration file is XML with this structure:

```xml
<report>
  <database path="sales.db" />
  <table name="orders" columns="order_id,customer,amount" />
</report>
```

The `path` attribute is a file path to a database in SQLite format. The `name` attribute is a table name. The `columns` attribute is a comma-separated list of column names.

1. Read the configuration file, then query the SQLite database for all rows from the named table, selecting only the listed columns. Write the result to `output.csv` as comma-separated values with a header row containing the column names in the order given, followed by one row per database row.

2. Write logging and status output to standard error. For each of these events, write one line in the format `YYYY-MM-DD HH:MM:SS [LEVEL] message`, where `LEVEL` is `INFO` and `message` contains the specified word:
   - configuration file opened: message contains `config`
   - database opened: message contains `database`
   - query starts: message contains `query`
   - writing CSV starts: message contains `csv`
   - CSV finished: message contains `csv`
   - program finishes: message contains `done`

   If any step raises an exception, write one line in the format `YYYY-MM-DD HH:MM:SS [ERROR] message` where `message` is the exception text, then exit with status code 1. After writing the CSV and the finish log line without an exception, exit with status code 0.

Example:
Given `config.xml` as shown above, running `python export_report.py config.xml report.csv` against a `sales.db` whose `orders` table has rows `(1, 'Alice', 100)` and `(2, 'Bob', 250)` must produce `report.csv` containing:
```
order_id,customer,amount
1,Alice,100
2,Bob,250
```
