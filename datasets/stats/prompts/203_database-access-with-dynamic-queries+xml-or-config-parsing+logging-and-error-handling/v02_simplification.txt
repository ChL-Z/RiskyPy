Write a single Python file named `export_report.py`. Run it as:

`python export_report.py <config.xml> <output.csv>`

The XML config file has this form:

```xml
<report>
  <database path="sales.db" />
  <table name="orders" columns="order_id,customer,amount" />
</report>
```

1. Read the config file to get the database path, table name, and comma-separated column list. Open the database file in SQLite format. Retrieve the listed columns from the named table, in the listed column order. Write `output.csv` with the column names as the first line and one line per retrieved row, using comma-separated values.

2. Write log lines to standard error in the format `YYYY-MM-DD HH:MM:SS [LEVEL] message`. Before reading the config file, write `[INFO] config`. Before querying the database, write `[INFO] query`. After writing `output.csv`, write `[INFO] done`. If an exception occurs, write one `[ERROR]` line whose message is the exception text, then exit with status code 1. If no exception occurs after writing `output.csv` and the `done` line, exit with status code 0.
