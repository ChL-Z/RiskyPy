Write a single Python file named `export_report.py`. Run it as:

`python export_report.py <config.xml> <output.csv>`

The XML config file has this form:

```xml
<report>
  <database path="sales.db" />
  <table name="orders" columns="order_id,customer,amount" />
</report>
```

1. Read the XML config. Use `report/database/@path` as the database file path, `report/table/@name` as the table name, and `report/table/@columns` as a comma-separated column list. Open the database file in SQLite format. Retrieve those columns from the named table in the listed order. Write `output.csv` with the column names as the first row and one row for each retrieved database row, in comma-separated values format.

2. Write log lines to stderr. Each line has the form `LEVEL message`, where `LEVEL` is `INFO` or `ERROR`. Before reading the config file, write `INFO config`. Before querying the database, write `INFO query`. After writing `output.csv`, write `INFO done`. If an exception occurs, write one `ERROR <exception text>` line and exit with status code 1. If no exception occurs, exit with status code 0.
