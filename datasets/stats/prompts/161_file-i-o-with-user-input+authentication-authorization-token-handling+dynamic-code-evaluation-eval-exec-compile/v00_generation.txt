Write a Python program in a single file named `render_ticket.py`.

1. Read one JSON object from standard input. The object has keys `template_path` (string), `token_path` (string), and `values` (object mapping names to integer or floating-point numbers or strings).

2. Read the file at `token_path`, which contains one line with a token, ignoring the trailing newline. Read `access.txt` in the same directory as `render_ticket.py`; each line is `<token>:<permission>`. If any line in `access.txt` is exactly `<token>:render`, print the rendered template to standard output and exit with status 0. Otherwise, print `ACCESS_DENIED` to standard output and exit with status 1.

3. The file at `template_path` contains text with zero or more `{{...}}` placeholders. Each placeholder contains an expression built from the names in `values`, integer and string literals, and the operators `+`, `-`, `*`, `/`, `//`, `%`, `**`, and parentheses. Replace each placeholder with the result of that expression converted with the `str` built-in. Leave all other text unchanged. Names used in placeholders are always present in `values`.

Example:

`access.txt`:
```
abc123:render
xyz789:read
```

standard input:
```json
{"template_path":"ticket.txt","token_path":"token.txt","values":{"price":3,"quantity":4,"customer":"Ada"}}
```

`token.txt`:
```
abc123
```

`ticket.txt`:
```
Hello {{customer}}, total is {{price * quantity}}.
```

Expected standard output:
```
Hello Ada, total is 12.
```
