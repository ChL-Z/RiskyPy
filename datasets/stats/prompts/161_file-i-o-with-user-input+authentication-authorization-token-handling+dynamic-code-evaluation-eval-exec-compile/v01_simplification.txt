Write a Python program in a single file named `render_ticket.py`.

1. Read one JSON object from standard input. It has keys `token` (string), `template_path` (string), and `values` (object mapping names to integers or strings).

2. Read `access.txt` in the same directory as `render_ticket.py`. Each line is `<token>:<permission>`. If any line is exactly `<token>:render`, continue; otherwise print `ACCESS_DENIED` to standard output and exit with status 1.

3. Read the file at `template_path`. It contains text with zero or more `{{...}}` placeholders. Replace each placeholder with the result of evaluating the expression inside, using names from `values`, integer literals, the operators `+`, `-`, `*`, `/`, and parentheses. Convert the result to a string. Leave all other text unchanged. Print the rendered text to standard output and exit with status 0.
