Write a Python program in a single file named `render_ticket.py`.

1. Read from standard input: the first line is a token string; the second line is a template file path; each remaining line is `name=integer`. Store each `name=integer` pair as a name-to-integer mapping.

2. Read `access.txt` from the same directory as `render_ticket.py`. If its first line is not exactly the token read from standard input followed immediately by `:render`, print `ACCESS_DENIED` to standard output and exit with status 1. Otherwise continue.

3. Read the file at the template file path. It contains text with zero or more placeholders of the form `{{expression}}`. For each placeholder, compute the arithmetic expression inside using the stored names, integer literals, the operators `+` and `-`, and parentheses. Replace the placeholder with the computed result converted to a string. Leave all other text unchanged. Print the resulting text to standard output and exit with status 0.
