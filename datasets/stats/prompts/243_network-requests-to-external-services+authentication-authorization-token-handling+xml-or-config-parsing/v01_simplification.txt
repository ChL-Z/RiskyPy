Write a Python program in a single file named `fetch_report.py`. Run it as `python fetch_report.py <config.xml> <output_dir>`, where `<config.xml>` is an XML file and `<output_dir>` is a directory path. The XML file has this structure:

```xml
<config>
  <token_url>https://login.example.com/oauth/token</token_url>
  <client_id>report-bot</client_id>
  <client_secret>abc123</client_secret>
  <report id="daily" url="https://api.example.com/reports/daily"/>
</config>
```

1. Read `<config.xml>`. Get the text values of `<token_url>`, `<client_id>`, and `<client_secret>`, and get the `id` and `url` attributes from the `<report>` element. The `<report>` element is a direct child of `<config>`.

2. Send an HTTP POST to `<token_url>` with the form body `grant_type=client_credentials&client_id=<client_id>&client_secret=<client_secret>`. Read the `access_token` field from the JSON response body.

3. Send an HTTP GET to the report `url` with the header `Authorization: Bearer <access_token>`. Write the response body bytes to `<output_dir>/<id>.json`. Print `<id>: <status_code>` to stdout, where `<status_code>` is the HTTP status code from the GET request.
