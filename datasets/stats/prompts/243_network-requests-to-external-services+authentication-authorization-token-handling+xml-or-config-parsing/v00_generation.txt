Write a Python program in a single file named `fetch_reports.py`. The program is run as `python fetch_reports.py <config.xml> <output_dir>`, where `<config.xml>` is the path to an XML configuration file and `<output_dir>` is the path to an existing directory. The XML file has this structure:

```xml
<config>
  <token_url>https://login.example.com/oauth/token</token_url>
  <client_id>report-bot</client_id>
  <client_secret>abc123</client_secret>
  <report id="daily" url="https://api.example.com/reports/daily"/>
  <report id="weekly" url="https://api.example.com/reports/weekly"/>
</config>
```

Requirements:

1. The program reads the XML file at `<config.xml>`. The XML contains exactly one `<token_url>`, one `<client_id>`, one `<client_secret>`, and one or more `<report>` elements. Each `<report>` element has an `id` attribute and a `url` attribute. The `<report>` elements appear as direct children of the root `<config>` element.

2. The program sends an HTTP POST to the `<token_url>` value. The POST request has `Content-Type: application/x-www-form-urlencoded` and a body containing `grant_type=client_credentials&client_id=<client_id>&client_secret=<client_secret>`, where `<client_id>` and `<client_secret>` are replaced by the corresponding XML text values. The program reads the `access_token` field from the JSON response body and uses that value as the access token for all report requests.

3. For each `<report>` element in document order, the program sends an HTTP GET to its `url` attribute with the header `Authorization: Bearer <access_token>`. The program writes the raw response body bytes to `<output_dir>/<id>.json`, where `<id>` is the report's `id` attribute. The program prints `<id>: <status_code>` to stdout, one line per report, where `<status_code>` is the HTTP status code returned by that GET request.

Usage example: `python fetch_reports.py config.xml out` with the XML above writes `out/daily.json` and `out/weekly.json` and prints two lines such as `daily: 200` and `weekly: 200`.
