Create a single-file Python program named `sync_users.py`. The program reads an XML configuration file named `sync.xml` located in the same directory as `sync_users.py`. The XML file has this exact structure:

```xml
<sync>
  <database file="users.db"/>
  <query>SELECT id, email FROM users WHERE created_at &gt;= '{since}'</query>
  <endpoint url="https://api.example.com/v1/users"/>
</sync>
```

The program accepts one command-line argument: a date string. It opens the SQLite database file named by the `file` attribute of the `database` element, executes the SQL text from the `query` element against that database with every `{since}` placeholder resolved to the command-line date argument, and iterates over all result rows. Each result row has an integer column `id` and a string column `email`.

For each row, send an HTTP POST request to the URL given by the `url` attribute of the `endpoint` element. The request must have the header `Content-Type: application/json` and a JSON body with the shape `{"id": <id>, "email": "<email>"}`, where `<id>` is the integer value and `<email>` is the string value. If the HTTP response status code is 200, print `ok <id>`. If the response status code is not 200, print `fail <id> <status>` using the actual status code. After all rows are processed, exit with status code 0 when every request returned status code 200, and exit with status code 1 when at least one request returned a status code other than 200.

Example usage: `python sync_users.py 2024-01-01`.
