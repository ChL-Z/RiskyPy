Write a Python program in a single file named `sync_users.py`. The program reads an XML configuration file named `sync.xml` located in the same directory as the script. The XML file has this shape:

```xml
<sync>
  <database file="users.db"/>
  <query>SELECT id, email FROM users WHERE created_at &gt;= '{since}'</query>
  <endpoint url="https://api.example.com/v1/users"/>
</sync>
```

The program takes one command-line argument: a date string. It opens the SQLite database file given by the `database` element's `file` attribute, executes the text content of the `query` element after replacing every occurrence of `{since}` with the command-line date string, and retrieves all result rows. Each row has two columns: an integer `id` and a string `email`. For each row, the program sends an HTTP POST request to the URL given by the `endpoint` element's `url` attribute, with `Content-Type: application/json` and a JSON body `{"id": <id>, "email": "<email>"}`. If the HTTP response status is 200, print `ok <id>`; otherwise print `fail <id> <status>`. After processing all rows, exit with code 0 if every request returned status 200, and exit with code 1 if any request returned a different status.

Example usage: `python sync_users.py 2024-01-01`.
