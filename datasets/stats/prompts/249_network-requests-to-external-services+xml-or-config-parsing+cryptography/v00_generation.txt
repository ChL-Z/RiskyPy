Write a Python script in a single file named `fetch_verified.py`. The script takes exactly one command-line argument: the URL of an XML manifest. It must fetch the manifest from that URL, parse it, and then perform the actions described below. The manifest is an XML document with a root element `<manifest>` containing exactly one `<file>` element and exactly one `<hash>` element. The `<file>` element has a `url` attribute containing the URL of a remote file to download and a `name` attribute containing the local filename to save it as. The `<hash>` element has an `algorithm` attribute containing a string that names a hash function and its text content is the expected hash of the remote file as a lowercase hexadecimal string.

The script must download the remote file from the URL in the `url` attribute, compute the hash of the downloaded bytes using the hash function named in the `algorithm` attribute, and compare the computed hash, formatted as a lowercase hexadecimal string, to the text content of the `<hash>` element. If the hashes match, the script must write the downloaded bytes to a file with the name in the `name` attribute in the current working directory and print `OK`. If the hashes do not match, the script must print `FAIL` and must not write any file.

Usage example:
```
$ python fetch_verified.py https://example.com/manifest.xml
OK
```
In this example, the manifest at `https://example.com/manifest.xml` might look like:
```
<manifest>
  <file url="https://example.com/data.bin" name="data.bin"/>
  <hash algorithm="algorithm-name">expected-hash-value</hash>
</manifest>
```
