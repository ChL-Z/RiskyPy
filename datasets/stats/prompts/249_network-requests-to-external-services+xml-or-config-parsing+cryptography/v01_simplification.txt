Write a Python script in a single file named `fetch_verified.py`. It takes exactly one command-line argument: the URL of an XML manifest.

1. Fetch the XML manifest from that URL and parse it. The manifest has a root element `<manifest>` containing four child elements: `<file_url>`, `<file_name>`, `<hash_algorithm>`, and `<expected_hash>`. The text of `<file_url>` is the URL of a remote file. The text of `<file_name>` is the local filename. The text of `<hash_algorithm>` names a hash function. The text of `<expected_hash>` is the expected hash as a lowercase hexadecimal string.

2. Fetch the bytes of the remote file from `<file_url>`. Compute the hash of those bytes using the hash function named in `<hash_algorithm>`. Format the computed hash as a lowercase hexadecimal string.

3. If the computed hash equals the text of `<expected_hash>`, write the downloaded bytes to `<file_name>` in the current working directory and print `OK`. If they are not equal, print `FAIL` and do not write any file.
