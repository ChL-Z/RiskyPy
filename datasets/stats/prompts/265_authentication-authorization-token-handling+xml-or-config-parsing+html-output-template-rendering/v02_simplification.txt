Write a single Python file named `session_report.py`. It takes two command-line arguments in this order: the path to an XML file and a token string. The XML file has a `<config>` root containing one or more `<user>` elements. Each `<user>` has `name` and `token` attributes and contains `<item>` elements. Each `<item>` has `id` and `label` attributes.

Find the first `<user>` whose `token` attribute equals the token string. If such a user exists, write `dashboard.html` in the current directory. The file must contain an `<h1>` element whose text is that user's `name`, followed by a `<table>` element. The table must have one row for each `<item>` under that user. Each row must contain two `<td>` elements: the first with the item's `id`, the second with the item's `label`. Exit with status code 0.

If no `<user>` matches, print exactly `Access denied` to standard output and exit with status code 1.

Example invocation:
`python session_report.py config.xml abc123`
