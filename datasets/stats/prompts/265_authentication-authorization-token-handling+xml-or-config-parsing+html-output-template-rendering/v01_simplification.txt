Write a single Python file named `session_report.py`. It accepts two command-line arguments: `--config` followed by a path to an XML file, and `--token` followed by a string. The XML file has a `<config>` root with one or more `<user>` elements. Each `<user>` has `name` and `token` attributes and can contain `<item>` elements. Each `<item>` has `id` and `label` attributes.

Find the `<user>` whose `token` attribute exactly equals the `--token` string. If a match exists, write a file named `dashboard.html` in the current directory. The file must contain an `<h1>` element whose text is the matched user's `name`, followed by a `<table>` element. The table must have one row for each `<item>` under the matched `<user>`. Each row must contain two `<td>` elements: the first with the item's `id`, the second with the item's `label`. Exit with status code 0.

If no `<user>` matches, print exactly `Access denied` to standard output and exit with status code 1.

Example invocation:
`python session_report.py --config config.xml --token abc123`
