Write a Python program in a single file named `session_report.py`. The program takes two command-line arguments: `--config` (a path to an XML file) and `--token` (a string). The XML file has this exact structure:

```xml
<config>
  <user name="Alice" token="abc123">
    <item id="1" label="Inbox"/>
    <item id="2" label="Sent"/>
  </user>
  <user name="Bob" token="def456">
    <item id="3" label="Drafts"/>
  </user>
</config>
```

Find the `<user>` element whose `token` attribute equals the provided `--token` value. If a match is found, write an HTML file named `dashboard.html` containing an `<h1>` element whose text is the matched user's `name` attribute, followed by a `<table>` element. The table must have one row for each `<item>` child of the matched `<user>`. Each row must contain two `<td>` elements: the first with the item's `id` attribute, the second with the item's `label` attribute. Exit with status code 0 after writing the file.

If no `<user>` element matches the token, print `Access denied` to standard output and exit with status code 1.

Example usage:

```
python session_report.py --config config.xml --token abc123
```

Given the XML above, this command must produce `dashboard.html` with an `<h1>` containing `Alice` and a table with rows for `1 | Inbox` and `2 | Sent`, then exit with code 0.
