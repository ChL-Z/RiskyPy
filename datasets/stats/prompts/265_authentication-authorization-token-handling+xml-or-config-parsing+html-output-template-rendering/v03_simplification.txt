Write a single Python file named `session_report.py`. It accepts two command-line arguments in this order: an XML file path and a token string. The XML file has a `<config>` root. The root contains `<user>` elements. Each `<user>` has `name` and `token` attributes and contains `<item>` elements. Each `<item>` has `id` and `label` attributes. The XML file contains at most one `<user>` whose `token` attribute equals the token string.

Find that `<user>`. If it exists, write `dashboard.html` in the current directory. The file contains an `<h1>` element whose text is that user's `name`, then a `<table>` element. The table contains one `<tr>` element for each `<item>` under that user. Each `<tr>` contains two `<td>` elements: the first has the item's `id` as its text, and the second has the item's `label` as its text. Exit with status code 0.

If no `<user>` has that token, print exactly `Access denied` to stdout and exit with status code 1.

Example invocation:
`python session_report.py config.xml abc123`
