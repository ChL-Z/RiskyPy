Write a Python program in a single file named `runner.py`. The program reads `tasks.json` from the current working directory. `tasks.json` is a JSON array of objects; each object has string keys `url` and `expr`. For each object in order, send an HTTP GET request to `url`. If the request does not return a 2xx status or the response body cannot be parsed as JSON, set `result` to the string `"error"`. Otherwise, compute the value of the Python expression in `expr`, with the parsed JSON body available as the variable `data`, and set `result` to that value. If the expression cannot be computed, set `result` to `"error"`. Print one JSON object per line to stdout. Each printed object has exactly the keys `url` and `result`, using the original `url` and the computed `result`. Send at most 4 HTTP GET requests per second across the whole run.
