Write a Python program in one file named `runner.py`. The program reads `tasks.json` from the current working directory. `tasks.json` is a JSON array of objects, and each object has string keys `url` and `expr`. For each object, send an HTTP GET request to `url`. If the request fails, the response status is not in the 200-299 range, or the response body is not JSON, set `result` to the string `"error"`. Otherwise, compute the value of the Python expression in `expr`, with the parsed JSON body available as the variable `data`, and set `result` to that value. If the expression cannot be computed, set `result` to the string `"error"`. Print one JSON object per line to stdout. Each printed object has exactly the keys `url` and `result`, using the original `url` and the computed `result`. Send no more than 4 HTTP GET requests per second across the whole run.
