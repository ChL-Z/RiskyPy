Write a Python program in a single file named `runner.py`. The program reads a JSON file named `tasks.json` from the current working directory. The file contains a JSON array of objects. Each object has two keys: `"url"` (a string containing an HTTP or HTTPS URL) and `"expr"` (a string containing a Python expression). For each object in the array, in order, the program must:

1. Send an HTTP GET request to the URL and parse the response body as JSON. If the request fails or the body is not valid JSON, the result for that task is the string `"error"`.
2. Evaluate the Python expression in `"expr"` with the parsed JSON object available as the variable `data`. The result of the expression is the task's result.

The program must print one JSON object per line to stdout, each containing the original `"url"` and the computed `"result"`. The program must not send more than 4 requests per second across all tasks.

Example `tasks.json`:
[
  {"url": "https://api.example.com/user/1", "expr": "data['name']"},
  {"url": "https://api.example.com/user/2", "expr": "data['age'] + 1"}
]

Example output:
{"url": "https://api.example.com/user/1", "result": "Alice"}
{"url": "https://api.example.com/user/2", "result": 31}

The program must be contained in a single Python file.
