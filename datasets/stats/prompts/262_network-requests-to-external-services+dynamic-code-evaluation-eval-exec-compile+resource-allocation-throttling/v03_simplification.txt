Write one Python file named `runner.py`. The program reads `tasks.json` from the current working directory. `tasks.json` is a JSON array of objects with string keys `url` and `expr`.

For each object, send an HTTP GET request to `url`. If the request fails, the response status is outside 200-299, or the response body is not JSON, set `result` to the string `"error"`. Otherwise, parse the response body as JSON and compute the value of the Python expression in `expr` with the parsed JSON available as the variable `data`; set `result` to that value. If the expression cannot be computed, set `result` to `"error"`.

Print one JSON object per line to stdout. Each printed object has exactly the keys `url` and `result`, using the original `url` and the computed `result`.

The program must send no more than 4 HTTP GET requests per second across the whole run.
